# 中文首页 SDK 与 Demo 入口按钮设计

## 目标

将中文首页顶部的“SDK 下载”和“体验 Demo”从资源卡片改为紧凑的快捷按钮，匹配已确认的视觉参考，并让“热门场景”成为首页的第一个内容分区。

## 设计

- “体验 Demo”位于左侧，作为深色主按钮。
- “下载 SDK”位于右侧，作为浅色描边次按钮。
- 两个入口继续使用现有 `/zh-CN/reference/demo` 和 `/zh-CN/reference/sdks` 链接。
- 保留播放、下载和右箭头图标，以及键盘焦点样式和悬停反馈。
- 移除首页 MDX 中对应的两张资源卡，避免重复入口。
- 按钮组下方添加底部分隔线和适度留白，再进入“热门场景”标题。
- 仅影响中文首页，不改变其他页面的资源卡组件。

## 验证

- 组件测试确认两个链接的文本和 href 不变。
- 中文区域本地预览确认按钮顺序、主次层级、分隔线和响应式换行。
