# SDK 与 Demo 下载后的登录/注册引导设计

## 背景

中文文档站的 SDK 下载和 Demo 体验入口需要增加账号转化引导，但不能把登录或注册变成下载、打开 Demo 或查看文档的前置条件。源站 `shengwang-doc-source` 已有官方 SSO 行为，本设计复用其入口语义，同时不在 docs-portal 首版接入认证成功回调。

## 目标

- 在 SDK 直接下载和外部 Demo 体验动作完成后，展示一个可关闭的登录/注册引导。
- 原始下载或 Demo 导航先执行，弹窗和统计逻辑不得阻塞原始动作。
- 同一浏览器标签页会话内最多展示一次引导。
- 使用单一「登录/注册」入口跳转到官方 SSO 页面，由 SSO 承接登录和注册。
- 记录匿名的展示、入口点击和关闭事件，不记录账号、邮箱、手机号或认证结果。

## 非目标

- 不在 docs-portal 内嵌或实现账号密码表单。
- 不要求用户登录后才能下载 SDK 或体验 Demo。
- 不识别登录/注册是否成功，不实现 `/api/oauth`、`/api/userinfo` 或登出同步。
- 不在首版收集联系方式或写入 CRM/营销系统。
- 不为 Demo 总览卡片进入详情页、源码链接、包管理器链接或二维码图片触发引导。

## 用户流程

### SDK 下载

1. 用户点击 SDK 直接下载链接。
2. 现有 `target="_blank"` 下载行为立即执行。
3. 原页面异步显示一次账号引导。
4. 用户可以点击「登录/注册」、关闭或暂不操作。

### Demo 体验

1. 用户在 Demo 详情页点击标记为“立即体验”的外部链接。
2. 外部 Demo 链接立即打开。
3. 原文档页面异步显示一次账号引导。
4. 用户可以点击「登录/注册」、关闭或暂不操作。

## 源站 SSO 参考

源站正式环境使用 `/api/v0/oauth/authorize`，携带 `response_type=code`、`client_id=docs`、`scope=basic_info`、当前页面 `state` 和 `/api/oauth` 回调；未接入 OAuth 的环境打开 `https://sso.shengwang.cn/cn/v5/login/with-sms`。docs-portal 当前没有这些后端接口，因此首版只使用统一 SSO 页面入口，不复制源站的登录态同步和回调逻辑。

SSO URL 由固定配置提供，首版不把 SDK、Demo、来源页面或其他上下文拼入 SSO URL，也不向 SSO 传递个人信息。

## 组件与数据流

### 账号引导组件

新增一个全局、客户端渲染的账号引导组件，挂载在 `DocsShell` 外层内容区域，使状态跨同一文档壳内的路由导航共享。组件负责：

- 维护当前会话是否已经展示过引导；
- 响应被标记的 Resource action；
- 渲染可访问的 Dialog、关闭按钮和单一 SSO CTA；
- 调用匿名 PostHog 事件封装。

使用 `sessionStorage` 保存展示标记；存储不可用时退化为当前内存状态，不影响原始链接动作。

### 触发标记

- `SdksCatalog` 的两个直接下载渲染分支为链接添加统一的账号引导数据属性，并附带产品、平台和版本等非个人上下文。
- Demo 详情页仅为“立即体验” `Card` 添加账号引导数据属性；“Demo 源码”保持不触发。
- 账号引导监听只处理这些显式标记，不按“所有外部链接”推断，避免误触发。

### 事件

事件统一通过 `src/lib/analytics/posthog.ts` 封装：

- `account_guidance_shown`
- `account_guidance_login_clicked`
- `account_guidance_dismissed`

事件属性只包括 action 类型、产品、平台、版本、Demo 标识、页面路径和 locale 等匿名上下文；不发送 SSO userInfo、邮箱、手机号或认证成功状态。

## 访问性与失败处理

- Dialog 使用现有 UI 原语，提供标题、说明、关闭按钮和可见的键盘焦点。
- 点击 SSO CTA 使用新标签页打开，原页面状态保持不变。
- PostHog 未配置、加载失败或 `sessionStorage` 被禁用时，仍正常完成下载、Demo 导航和弹窗关闭。
- 弹窗渲染或埋点异常不得抛出到原始链接事件处理流程。

## 测试与验收

- 账号引导组件测试：默认隐藏、当前会话只展示一次、关闭行为、SSO CTA、键盘/ARIA 标签和存储不可用回退。
- SDK 组件测试：两个直接下载分支包含触发标记和上下文，包管理器链接不包含触发标记。
- Demo MDX/组件测试：立即体验 Card 包含触发标记，源码 Card 不包含触发标记。
- Analytics 测试：无 PostHog key 时不抛错；事件名称和匿名属性正确；不包含认证身份字段。
- 运行相关 Vitest 测试、`bun run types:check` 和 `bun run lint`。

## 后续评审点

- 是否为 docs-portal 提供与源站一致的 OAuth 回调、登录态查询和登出接口。
- 是否需要在登录成功后回传原页面并记录认证完成事件。
- 是否需要将匿名账号引导事件接入其他分析系统。
