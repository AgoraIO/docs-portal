# SDK 与 Demo 下载后的登录/注册引导需求

## 背景

在中文文档站的 SDK 下载和 Demo 体验场景中，增加一个轻量的登录/注册引导，帮助开发者进入声网账号体系。

这项引导不能影响开发者当前正在进行的下载或 Demo 体验，也不能要求开发者先登录或注册。登录或注册成功后，用户可以根据当前 SDK/Demo 上下文进入对应的声网 Console 服务页。

## 适用范围

首期只在中文站生效：

- SDK 下载页：`/zh-CN/reference/sdks`
- Demo 详情页：`/zh-CN/reference/demo/*`

## 触发条件

只有以下两类实际操作触发引导：

1. 用户点击 SDK 的直接下载入口。
2. 用户在 Demo 详情页点击「立即体验」并打开外部 Demo。

若能确认用户已经登录声网账号，则不展示登录/注册引导。登录状态判断不得延迟 SDK 下载或 Demo 打开。

以下操作不触发引导：

- 进入 Demo 详情页；
- 点击 Demo 源码；
- 点击包管理器链接；
- 查看二维码；
- 其他普通文档链接。

## 用户交互

### SDK 下载

1. 用户点击「下载 SDK」。
2. SDK 下载立即开始，不等待任何登录/注册操作。
3. 下载动作开始后，未登录用户在当前文档页看到登录/注册引导。

### Demo 体验

1. 用户点击「立即体验」。
2. 外部 Demo 立即在新标签页打开。
3. 未登录用户在原文档页看到登录/注册引导。

### 引导内容

引导使用当前文档页面内的 Modal 对话框：不跳转当前页面、不新开浏览器页面，原文档内容继续显示在对话框下方。点击「登录/注册」后，才在新标签页打开 SSO 页面。Modal 包含：

- 标题：登录/注册声网账号
- 说明：登录或注册可继续使用声网控制台等服务；当前 SDK 下载或 Demo 体验不受影响
- 主按钮：登录/注册
- 次按钮：暂不登录
- 右上角关闭按钮

「登录/注册」只提供一个入口，由声网 SSO 页面承接登录和注册，不在文档站内展示账号密码表单。

点击「登录/注册」后：

- 在新标签页打开正式 SSO 页面：`https://sso.shengwang.cn/cn/v5/login/with-sms`
- 当前文档页保持不变；
- 弹窗立即关闭。

### 登录成功后的跳转

登录或注册成功后，根据触发引导的 SDK 或 Demo 上下文跳转到对应的 Console 服务页。

- SDK 和 Demo 的上下文都必须支持映射到 Console 服务页；
- 没有对应映射时，跳转到 Console 首页：`https://console.shengwang.cn/`；
- 映射关系和具体服务页 URL 由研发维护，并应便于后续补充或调整；
- 登录失败、用户主动返回或无法确认登录结果时，不影响已完成的 SDK 下载或 Demo 体验。

点击「暂不登录」或关闭弹窗后，当前下载或 Demo 体验保持不变。两种操作都表示暂时不登录，统一记录为一次跳过行为。

## 埋点需求

按行为发生的阶段分别记录，不能把登录前的匿名点击重复算作一次已识别用户点击。

| 行为 | 事件 | 身份口径 |
| --- | --- | --- |
| 点击「登录/注册」 | `account_guidance_login_clicked` | 匿名点击事件 |
| 从该入口完成登录或注册 | `account_guidance_login_succeeded` | 已识别用户事件，关联原始匿名点击 |
| 关闭 Modal 或点击「暂不登录」 | `account_guidance_dismissed` | 统一的匿名跳过事件，不区分两个操作 |

匿名点击和登录成功事件使用相同的来源上下文：

- `resource_type`：SDK 或 Demo；
- `resource_id`：产品或 Demo 标识；
- `platform`：平台；
- `version`：版本；
- `source_path`：来源文档路径；
- `console_target`：本次对应的 Console 服务页，无映射时为 Console 首页；
- 原始点击的关联 ID，用于关联点击与登录成功。

登录成功事件额外关联稳定账号 ID。账号 ID 使用 `accountUid`、`companyId` 或其他标识，由 Console 研发确认其含义和使用口径，不发送邮箱、手机号或姓名。

埋点只发送上述明确的上下文，不直接发送完整来源 URL、query、hash、referrer 或 SSO 参数。已识别用户事件的接收系统及身份关联方式，由 Console 研发确认。

## 展示频率

同一浏览器标签页会话内，登录/注册引导最多展示一次。用户继续点击其他 SDK 下载或 Demo 体验入口时，不重复展示。

新的浏览器标签页或新的会话可以再次展示。

## 不阻断要求

以下要求必须满足：

- 不得在下载或外部 Demo 打开前等待弹窗或 SSO；
- 不得要求登录/注册后才能下载 SDK 或体验 Demo；
- 弹窗加载失败、关闭、SSO 打开失败，都不能影响原始下载或 Demo 体验；
- 登录/注册入口点击必须记录匿名点击事件；
- 首期不在文档站收集姓名、邮箱、手机号或其他联系方式。

## 参考行为

交互参考 `shengwang-doc-source` 的登录入口：使用统一 SSO 页面承接登录和注册，不在文档站内维护两套账号入口。登录成功后的回调和上下文跳转需要研发与 SSO/Console 相关同事确认接口契约。

## 研发实现边界

本文只定义用户可见的交互、埋点需求和产品约束。具体的组件拆分、状态保存、事件关联、异常处理实现方式和测试方案由研发根据现有 docs-portal 架构确定。稳定账号 ID、已识别事件接收系统和 SSO/Console 接口契约需由 Console 研发确认。
