# 中文产品参考导航分组 IA 设计

## 目标

优化以下两个中文产品的“参考”导航，降低长列表的扫描成本，同时保留重要页面的直接可见性：

- `/zh-CN/realtime-media/rtm`
- `/zh-CN/solutions/flexible-classroom`

只调整侧边栏信息架构，不修改文档正文、路由或页面内容。

## 已确认的导航结构

### 实时消息 RTM

直出页面：

- 下载
- 服务端 API
- 迁移指南
- 数据安全
- 退休政策

折叠分组：

- 使用限制与错误处理
  - API 使用限制
  - 错误码
- 能力与兼容性
  - 特性列表
  - 平台支持

### 灵动课堂

直出页面：

- 下载
- 服务端 API
- 升级指南

折叠分组：

- API 使用与限制
  - 如何调用 API
  - 响应状态码
  - 配额限制
- 能力与兼容性
  - 基本概念
  - 平台支持
  - 技术架构

## 约束与验收标准

- 只在两个产品的 `reference/meta.json` 中调整页面组织。
- 使用现有的可折叠 group 导航结构；每个分组的 `collapsible` 为 `true`。
- 所有页面仍然保留在导航中，不能因为分组而丢失或改动 URL。
- 直出页面保持用户无需展开即可看到。
- 不改变产品级导航中现有的发版说明、计费说明或账号与计费入口。
- 运行相关导航测试，确认生成的导航结构与上述列表一致。
