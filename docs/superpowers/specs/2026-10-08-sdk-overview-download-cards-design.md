# 中文 SDK 总览卡片下载内容设计

## 目标

更新 `/zh-CN/reference/sdks` 的产品卡片：展开卡片后直接展示与产品下载页相同的详细下载卡片，同时保留平台下拉选择和“查看下载页”入口。

## 现状与问题

总览页的产品卡片展开后目前展示安装命令、复制按钮、下载链接、包管理器和版本详情；产品下载页则使用 `SdkDownloadCard` 展示版本、包名、MD5、发布日期和下载操作。两处信息事实来自同一份 SDK 数据，但视觉和内容结构不一致。

## 设计

- 总览页的折叠摘要行保留产品图标、名称和描述。
- 摘要行增加“查看下载页”链接；链接指向当前产品和所选平台对应的独立下载页。
- 展开后保留当前平台下拉选择器。
- 展开区移除安装命令、复制按钮、直接下载链接和内嵌版本详情。
- 展开区按当前平台渲染 `SdkDownloadCard`，卡片显示下载页中的版本、包名、MD5、发布日期、下载/包管理器入口。
- 平台切换时重新选择当前平台的最新版本卡片；卡片没有可用版本时不渲染空下载区。
- 只有存在独立下载页的产品显示“查看下载页”；没有独立下载页的产品继续使用现有总览页下载内容。
- 产品下载页现有的 `ProductSdkDownloads` 和 `RtcSdkDownloads` 行为保持不变。

## 下载页路由

总览产品 ID 到下载页的映射集中在 SDK 下载组件中。RTC 视频和语音共用 RTC 下载页；其他产品使用各自的产品下载页。平台 ID 复用现有数据中的平台标识，并按下载页路由需要转换 `mini-program`、`react-js` 和 `unreal-engine` 等特殊值。

## 验收标准

- 总览页展开的视频、语音、RTM、白板等产品显示详细下载卡片，而不是旧的命令块。
- 每个支持多个平台的产品都能通过平台下拉切换，并更新下载卡片内容。
- 有独立下载页的产品显示正确的“查看下载页”链接；链接包含当前平台。
- 详细下载页中的卡片继续显示下载、包管理器、版本、包名、MD5 和发布日期。
- 没有独立下载页的产品不显示失效链接，且现有下载能力不回归。
- 增加组件测试覆盖卡片替换、平台切换和下载页链接。
