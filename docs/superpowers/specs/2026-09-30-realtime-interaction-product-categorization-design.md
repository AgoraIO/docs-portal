# 实时互动产品分类调整设计

## 目标

将中文站“解决方案”下的 Status Page 和 PPT 转码服务归入“实时互动”产品导航，使这两项产品出现在与其功能属性相符的分组中。

## 导航与内容归属

- Status Page 放入“实时互动 → 监控与分析”，与用量分析同组。
- PPT 转码服务放入“实时互动 → 扩展能力与生态”，作为互动白板旁边的同级产品。它具有独立的开通流程、服务端 API、计费与渲染 SDK，不作为互动白板的子页面。
- 本次只调整 zh-CN 内容。英文站当前不以这两个独立产品页面呈现，本次不改变英文信息架构。

## URL 与链接兼容

将两个产品内容目录从 `content/docs/zh-CN/solutions/` 移至 `content/docs/zh-CN/realtime-media/`，新页面根路径分别为：

- `/zh-CN/realtime-media/status-page`
- `/zh-CN/realtime-media/ppt-transcoding`

更新导航元数据、解决方案概览中的产品卡片，以及代码中指向旧页面的产品/API 路径。旧的 `/zh-CN/solutions/...` 页面路径和已有旧文档迁移入口需继续重定向到新的实时互动路径，避免历史链接失效。

## 验收标准

1. 两项产品仅在实时互动导航中出现，且所属分组正确。
2. 解决方案概览不再列出这两项产品。
3. 站内相关链接和产品/API 参考入口指向新路径。
4. 原产品页面 URL 可重定向到新页面，包括子页面路径。
5. 针对导航、站内跳转和旧路径重定向的测试通过。

## 验证范围

为元数据和内容路径调整补充或更新聚焦测试；运行相关 Vitest 测试，并执行 `bun run types:check` 检查内容路由生成和类型。
