## 实现与文件选择

- `src/lib/retired-cn-docs.mjs`：集中维护中文下线目录、专属分析页和公开 YAML 的边界。
- `source.config.ts`：从文档和导航元数据的编译集合中排除下线源文件，避免内容进入浏览器包或静态文档产物。
- `src/lib/openapi/lanes.ts`：保留原 lane 定义，仅从已发布 lane 集合排除融合 CDN；原 YAML 和 bundled source 映射保留。
- `scripts/sync-openapi-assets.mjs`：不复制下线的 YAML 至公开目录，其他 API 资源正常同步。
- 页面路由与 `loadDocsPagePayload`：在历史重定向及内容加载前返回未找到；预渲染候选集合同步排除。
- `vercel.base.json` 及生成的 `vercel.json`：对中文有前缀、无前缀的下线路径以及 YAML 返回 HTTP 404，防止静态站 fallback 变成软 404。
- 产品及 API 的父级 `meta.json`：沿用排除条目的模式；专属目录内原文和导航文件全部保留。
- 概览和教学方案中的原卡片、原表格行以 MDX 注释保留。
- MDX 编译时移除纯注释表达式，确保保留的隐藏片段不会进入公开 Markdown；代码块中的注释和含有效表达式的节点保留。
- API 卡片展示集合过滤下线记录，生成 JSON 保留；中文 FAQ 过滤展示标签，原始数据保留。
- 中文搜索排除产品与旧 URL；不会写入或替换正式搜索索引。
- 现有 Vercel preview 工作流增加可选 `docs_region` 输入，默认仍为 global；本次手动选择 cn，确保在线预览实际构建中文站，而非仅提供英文预览。
