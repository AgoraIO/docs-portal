# 中文产品 Build 导航 IA 备选方案

## 范围与判定原则

本文覆盖以下产品的 Build 功能指南：旁路推流（13 篇）、本地服务端录制（23 篇）、水晶球（11 篇可见页面）、灵动课堂（16 篇）和秀场直播（17 篇）。每篇页面均根据其正文简介和章节结构归纳任务目标、前置条件与产出。

Build 只承载把产品接入业务、配置能力与保障运行的任务；产品介绍、快速开始、计费、下载和 API 参考不并入 Build。水晶球目录中被 `!` 隐藏的“指标 ID 表”和“分析信令数据”不计入用户指定的 11 篇范围。

共同设计准则：按任务依赖排序；一个分类对应一个主要目标；可独立完成的单一任务直接展示为页面；低优先级或已废弃内容默认折叠；保留 RTC、REST、Webhook、SEI 等必要术语，其余采用稳定的“动作 + 对象”命名。
