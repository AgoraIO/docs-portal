# RTC 小程序开通独立页面

用户已确认采用“拆出小程序开通子页面”的方案。

## 内容与导航

- 新增接入准备下的“开通小程序服务”，使用普通 MDX 和小程序平台标识。
- 将公共开通页中的小程序四步操作及两张图片完整移入子页面；子页面链接公共页的项目准备和临时 Token。
- 公共页保留一个明确标注适用范围的链接入口，不再展示小程序操作与截图。
- 小程序快速开始、示例项目和 401 错误排查直接链接子页面。
- 公共页原 `#enable`、`#开启小程序服务` 锚点落到新入口；子页面同样保留这些锚点。无需新增运行时重定向或平台过滤组件。

## 范围

本次调整仅拆分小程序开通任务，沿用 #1302 的公共准备去重、其他指南去重和平台分享修复。平台过滤机制、搜索以及 Web / RESTful 流程重组不在本次增量内。

## 验收

- 公共页不再显示小程序操作和截图，旧锚点仍能定位入口。
- 新页面保留全部操作、两张可读取图片及“启用”提示。
- 侧栏入口、小程序指南、401 错误链接、返回公共准备均可使用。
- 更新后的文档链接审计、类型检查、lint 和完整测试通过；浏览器检查正文、目录与旧锚点。
