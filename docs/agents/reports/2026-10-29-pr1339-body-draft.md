## Summary

Integrates the English Voice Agent API and Conversational AI Platform (Preview)
documentation with Main/Preview switching, including the latest #1208 content
at `fe18eecf3`. Keep this PR draft; this update delivers the implementation.

```text
Ordinary documentation entry
  → saved Main/Preview choice, or Main by default
Explicit documentation link
  → its specified version; saved choice is unchanged
Deliberate version selection
  → save the shared choice; open the matching topic or explain overview fallback
Reference / Voice Agents
  → one control for REST and Python/TypeScript/Go SDK links
```

Main retains the existing Voice Agent, app, Studio and dedicated-device
navigation. Preview has its own navigation and product notice. Mobile controls
stay inside the collapsed navigation sheet. Voice Agents is the SDK product;
Main and Preview identify documentation for the two APIs, not separate SDK
products. Versioned URLs, Markdown and machine-readable indexes identify the
same documentation independently of browser preferences.

Only product documentation is published. Both versioning demos, their mock
OpenAPI sources, navigation/callout entries and runtime registrations have
been removed. Generic fixtures remain in tests only.

Review preview: https://docs-portal-pr-1339.vercel.app. The preview workflow
updates this host from the integration branch.

## Merge Danger

**Door:** two-way

Documentation and configuration can be reverted. Canonical legacy URLs remain
explicit, and no browser-preference migration is introduced.

**Blast Radius:** documentation

Changes affect navigation, Reference links, search labels and machine-readable
output for registered groups. Production publication still needs agreement on
the Preview content list, REST operation mappings, deferred-file publication,
SDK availability, release version/date and production indexing. Test demos are
already removed from publication.
