# 白板 HarmonyOS 正文跳转修复（2026-10-30）

用户指出概览中的类型/成员跳转丢失。以源 `72dd878e3`（0.0.537）对照 PR #1338 的 `879bbca1d` 重现：源概览含 89 个正文链接，新站 Markdown 和实际 DOM 均为 0，表格名称被转换为纯文本。此前文字/代码完整性检查及现存链接检查没有覆盖“链接已被消去”的情况，不能据此认为这部分链接一致。

## 原因与修复

1. 本次增量转换使用旧 API 路由表，未先注册新增鸿蒙文档。转换器对无映射的内部链接返回空 href 并记录 warning，随后降为纯文本。修复转换输入：按真实目标 `_migration.sourcePath` 及拟迁移索引建立完整路由注册，使用现有 `buildLegacyRouteMap` 处理带/不带 `.html` 的别名，不猜测 URL。
2. 通用转换器以 `_source.html` 字串识别实现源码页面，误命中了 `class_background_image_source.html`。现明确区分 Doxygen 类型页与 `_8h_source.html` 等文件视图，保留公开类型所在的正文块；真实源码导航的既有清理测试仍通过。
3. 精简侧栏时也把页面树限制成六项，导致非主菜单类型及成员索引访问后失去 SDK 上下文。现在页面树保留完整页面，以既有 `navScope.sidebar` 单独声明可见六项，版本选择与主目录结构保持用户确认的方案。
