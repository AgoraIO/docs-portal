# 新旧站内搜索效果对比

测试日期：2026-11-04（北京时间）。结论：**新站在页面去重、部分同义词和错字检索上有明确改善，但存在技术语言名区分、产品入口排序和默认结果展示的退步，尚不能认定已完整替代旧站。**

## 结论与优先级

| 维度 | 实测结论 |
| --- | --- |
| 精确 API | 核心样本两站都命中；新站 `manualSOS` 默认 API 首批覆盖 Android/iOS/Web，旧站首批仅 Android/iOS。 |
| 同义词与错字 | 新站 `云录制`、`发布消息`、`屏幕共亨` 的目标入口更靠前；两站都支持大小写和常见 API 错拼。 |
| 结果组织 | 新站将同页多个章节合并，减少旧站同页占满结果的情况；但全部视图有时只显示发版说明，挤出已收录教程。 |
| 产品导航 | `实时消息` 的产品概览/快速开始在新站默认首批缺席；`灵动课堂` 还存在迁移范围疑问。 |
| 技术语言 | 新站 `C++` 与 `C#` 的默认 13 篇结果及顺序完全相同，前列偏向 C 端计费和 C API。 |
| 自然语言 | `Token 过期怎么办`、`听不到声音` 可找到答案；`如何开启云端录制` 的首位和目标章节仍需优化。 |
| 功能与链接 | 筛选、加载更多/分页、刷新条件、清空、后退、移动端和快捷键抽查可用；22 个落地页未见 404，21 个 hash 均找到可见目标。 |
| 响应速度 | 每站 15 次，本机中位数新站 255.3 ms、旧站 216.5 ms；样本不足以判断总体谁更快。 |

共记录 **5 项问题（4 中、1 低）及 1 项迁移范围缺口**；未发现阻断整个搜索流程的问题。建议先处理 P1：区分 C++/C#、改善产品名查询的入口排序，同时确认灵动课堂是否在新站承诺覆盖范围内。再处理全部视图教程可见性与 React 错误，最后清理摘要语法标记。

## 问题与待确认项

### ISSUE-001：新站搜索摘要泄露内容标记（低，P3）

1. 新站搜索 `manualSOS`。
2. 查看首个产品文档「手动控制说话开始和结束」摘要。
3. 摘要直接出现 `tabGroup="language"`，且代码片段从中间截断，降低可读性。

预期：隐藏文档语法标记，优先展示与目标 API 相关的完整说明。旧站同一查询摘要也有语言名称拼接，但未见该 `tabGroup` 标记。

证据：[新站复查入口](https://docs-portal-staging.sh3.agoralab.co/search?q=manualSOS&type=all&page=1)；初始人工查询与批量查询重复确认。静态加载即可复现，无需视频。

### ISSUE-002：C++ 与 C# 查询退化成相同结果（中，建议 P1）

1. 在全部产品、全部平台、全部文档下搜索 `C++`。
2. 再搜索 `C#`。
3. 两次默认展示的 13 篇文档及顺序完全相同。产品文档前两条都是「C 端用户计费策略推荐」，其后是 C API 示例、隐私白皮书、C SDK 下载；API 还混入 Objective-C。

旧站 `C++` 产品文档第 1 条是「下载 SDK (C++)」；`C#` 第 2 条为「通过 NuGet 集成 SDK (C#)」，虽然也有噪声，但能区分两个输入。

预期：技术语言名保留语义，优先命中对应 SDK 下载、集成及 API。原因尚未做代码/索引诊断，不能直接认定是哪个分词配置造成。

证据：[新站结果快照](evidence/2026-11-04-search-comparison/new-queries.json)和[旧站结果快照](evidence/2026-11-04-search-comparison/old-queries.json)的第 34、35 组。批量测试及独立人工复测均复现。静态加载即可复现，无需视频。

### ISSUE-003：产品词「实时消息」的导航相关性下降（中，建议 P1）

相同默认条件搜索 `实时消息`。旧站产品文档第 1 条为产品入口，前 5 条还包含开通服务和实现收发消息；新站前 5 条是合规说明、Web Demo、媒体流加速发版说明和两个教学方案集成指引，未出现实时消息产品概览/快速入门。

预期：以产品名检索时，产品入口和快速开始应在合规声明及其他产品中的正文提及之前。

证据：[新站结果快照](evidence/2026-11-04-search-comparison/new-queries.json)和[旧站结果快照](evidence/2026-11-04-search-comparison/old-queries.json)的第 11 组。这证明首批结果的可发现性退步，不证明整个产品内容未收录。

### GAP-001：灵动课堂入口在新站默认搜索中缺失（迁移范围待确认）

旧站搜索 `灵动课堂` 产品文档前 3 条是产品入口、配置、集成。新站前 5 条为教育信息化场景、RTC 概览和其他 RTC 文章；新站产品筛选列表也没有「灵动课堂」。需确认这是否是本次迁移的预期范围，若仍承诺覆盖旧站，应列为高优先级缺口。

证据：[新站结果快照](evidence/2026-11-04-search-comparison/new-queries.json)和[旧站结果快照](evidence/2026-11-04-search-comparison/old-queries.json)的第 12 组。当前没有进行全索引审计，不宣称所有灵动课堂文档均未收录。

### ISSUE-004：全部视图未展示已收录的虚拟背景教程（中，P2）

新站搜索 `虚拟背景`，默认产品文档仅展示「发版说明」和「插件发版说明」；旧站首批包含插件使用、开启虚拟背景和设置步骤。新站 API 召回相关，但开发者寻找集成教程时需要进一步搜索。

证据：[新站结果快照](evidence/2026-11-04-search-comparison/new-queries.json)的第 7 组为等待完成后的复测结果。最初加载中的状态仅留在本地，不作为无结果证据。已进一步验证：切换至「产品文档」，第 3 篇出现「使用虚拟背景插件」，证明教程已收录。问题出在默认展示的可发现性；尚未审计代码，不能确认裁剪/聚合的实现原因。


复现 ISSUE-004 的切换步骤：

1. 打开全部文档搜索 `虚拟背景`，产品区只有两篇发版说明：[全部文档复查入口](https://docs-portal-staging.sh3.agoralab.co/search?q=%E8%99%9A%E6%8B%9F%E8%83%8C%E6%99%AF&type=all&page=1)。
2. 点击「产品文档」，教程出现在第 3 篇：[产品文档复查入口](https://docs-portal-staging.sh3.agoralab.co/search?q=%E8%99%9A%E6%8B%9F%E8%83%8C%E6%99%AF&type=docs&page=1)。
3. [切换前后文本快照](evidence/2026-11-04-search-comparison/virtual-background-view-switch.json)随报告提交；截图与完整可访问性快照保留在本地。

### ISSUE-005：搜索页直接加载/刷新新增 React #418 错误（中，P2）

打开新站 `Token` 搜索页，再连续刷新两次，浏览器异常列表每次新增一条 `Minified React error #418`。日志为会话累计值，两次复测分别为 5 条与 6 条，不能解释为单次刷新产生 5/6 条。旧站同类会话的未捕获异常列表为空。

预期：搜索页不产生此类运行时异常。本轮未观察到搜索阻断，未读取应用代码，也未验证它是否影响分析事件或交互状态。

证据：[第一次日志](evidence/2026-11-04-search-comparison/new-reload-errors-1.json)、[第二次日志](evidence/2026-11-04-search-comparison/new-reload-errors-2.json)。这是加载时可观察错误，没有对应的可见错误弹窗。
