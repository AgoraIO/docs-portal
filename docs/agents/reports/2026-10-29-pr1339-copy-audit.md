## Standards: recorded source-content findings

Four findings were identified in the source. They are reported here, rather
than edited independently of #1208:

1. The active interruption guide's description and introduction still promised
   a server REST interruption API. The same source file records that API as
   deferred, and the current overview excludes it. The original wording remains
   under the content PR's ownership.
2. The three SDK descriptions still used the former “Agora agents” branding.
   `CONTEXT.md` uses Voice Agents. This naming difference is recorded without
   changing the original descriptions. Implementation-owned SDK headings use
   the repository term. Package/import paths and `client.v3` are preserved.
3. Fifteen OpenAPI prose occurrences and one status-code description used
   “stage/stages” after the guide terminology changed to “block/blocks”. This
   source inconsistency remains recorded for the content PR; schema identifiers
   such as `StageHeaders` must not be renamed editorially.
4. Release notes said “Released on October 29, 2026” while the adjacent source
   TODO still marked the date unconfirmed. Both the date and `v1.0` label remain
   as supplied by the source, with their confirmation question recorded below.

Standards: 4 source-content findings recorded. The most material is the active
guide's promise of the deferred server interruption API. These are content
follow-ups, not implementation blockers or questions assigned to the user.

   now distinguishes real `convoai` groups from isolated samples.

   local review and this audit. Its old default, entry, SDK and release-note
   statements must not be used as the current specification.
4. The review snapshot's PR body described a Platform default and independent
   SDK behavior. The [replacement body](2026-10-29-pr1339-body-draft.md)
   describes the resulting implementation and is used for the PR update.

Exported Markdown also uses plain “Documentation” and Main/Preview names,
without appending internal group/version IDs. Version-specific index URLs
retain their identifiers. “This release only” in an index became “this
documentation version only” to avoid implying an API or SDK release.

Spec: 4 stale descriptions addressed locally. Main/Preview labels, Main default,
the Preview product name and the configured entry behavior match the current
channel feedback. Supporting descriptions are authored copy, not claimed as
verbatim product approval.
