# 中文 API 侧栏与旧站展示一致性复核（2026-10-29）

源基线为 `shengwang-doc-source/master@72dd878e3`（0.0.537）；目标复核起点为 `docs-portal@6c435fbe6`，工作分支 `codex/cn-whiteboard-hotfix-20261028`，PR #1338。本轮对齐文档条目、名称、顺序、分组及目标平台，保留新站已确认的产品命名、版本边界和独立 API 视图。

## 范围与结论

- 原始 API 目录数据共 102 项，按现有退役规则排除 6 项后，当前目录为 96 项：86 项本地入口和 10 项 IM 外站入口。退役项继续返回 404，没有重新公开。
- 对照并展开检查 50 个专用 SDK/API 入口：48 个当前公开入口，加 2 个保持隐藏的历史 REST Client 入口。依据固定源的侧栏、Oxygen TOC、页面 frontmatter，并用 16 个旧站实际页面样本复核。Agent SDK 的 `sidebar_label` 覆盖了配置字面标签，实际 Go/Python/TypeScript 名称按现场保留。
- 另外检查 20 个从普通产品指南拆出的独立 API 视图和 18 个 RESTful/OpenAPI 入口，现有本地页面均返回 200。它们继续遵循既定 API/产品指南边界和 OpenAPI 发布规则，不把普通文档的整套侧栏搬入 API 中心。10 个外站入口未在本轮改动。
- 修正 32 份中文导航配置；没有修改任何 MDX 正文，没有新增或改动图片，也没有修改英文文档。

同时修正了两处共性行为：单页 SDK 可在 `navScope.sidebar` 声明可见侧栏，沿用现有渲染器，优先保留版本专属声明；上一篇/下一篇使用同一份声明，避免导向隐藏的自动目录或受普通文档上下文干扰。导航保留外链标记，防止跨栏目指南链接被正文来源过滤误删。

旧格式 `rtm/toc-configuration/configuration.cpp` 等兼容链接原会进入 Android 页面并带 `platform=cpp`；现在在确有对应页面时直接进入 C++ 页面，同时保留查询参数。缺少对应平台页面时保留原有共享页回退，不生成不存在的 URL。

## 保留的已确认规则

- 白板 HarmonyOS 保持用户明确批准的 6 个真实公开接口入口；旧站误用 Android 侧栏的行为不复制。92 个鸿蒙 API 正文未改。
- C# 的人脸检测、虚拟节拍器、摄像头管理旧源无正文，按此前用户要求继续隐藏，历史 URL 保留，参见 `cn-empty-page-parity-20261023.md`。
- 本地录制的 Legacy API 独立范围、RTC Server SDK 的“通用错误码”名称，以及 React/Web 的版本边界属于已确定的新站适配，继续保留；相应页面没有丢失。
- 新站公共导航头部的位置及样式沿用现有界面，不把折叠态、公共返回按钮或已退役产品当成遗漏的文章。
