# 中文文档剩余显式图片尺寸恢复

## 承接范围

本批接续 #1268，从 `codex/cn-newdoc-html-api-migration` 的 `90edd5afbd` 开始，只恢复可发布中文文档中能够对应旧源页面/平台的显式图片尺寸。复用现有 `DocsImage`，不新增全局图片地址尺寸规则，也不修改图片资源、正文内容、导航或发布范围。

## 数量与排除规则

此前仓库扫描的 690 处包含已停用内容。依据 `isRetiredCnDocsPath`，其中 86 处属于 15 个停用文档；排除后，初筛可发布内容候选为 604 处。

| 分类 | 处数 | 本批处理 |
| --- | --- | --- |
| 初筛仅出现一种非 100% 旧尺寸 | 574 | 再按实际源页面/平台核对 |
| 对应源页面确有显式尺寸 | 556 | 恢复：554 处百分比宽度、2 处最大高度 |
| 相同资源在别处有尺寸，但对应源页面原本无尺寸 | 18 | 保持原样，作为误报保护项 |
| 多种旧尺寸仍待消歧 | 13 | 不修改 |
| 旧宽度为 100% | 17 | 不修改 |

最终恢复涉及 158 篇文档。最后三类共 48 处保持原样；其中真正待决的尺寸候选为 30 处，另外 18 处已经确认是跨页面或跨平台复用资源产生的扫描误报。

## 源页面核对，避免同图全局套用

只按资源 URL 汇总显式尺寸会漏掉两类信息：旧 `Image` 没有声明宽高，或旧页面使用了普通 Markdown 图片。两种情况都不能套用其他页面的尺寸。

本批在初筛的 574 处中识别并保护以下 18 处：

| 对应文档/平台 | 处数 | 旧源设置 |
| --- | --- | --- |
| RTC Server SDK 云代理：C++ / Java | 2 | 云代理图未设置宽高 |
| RTC Token 鉴权：Web / Windows / 小程序 / Unreal C++ / Blueprint | 5 | Token 流程图未设置宽高 |
| RTC Token 升级：Web | 1 | Token 流程图未设置宽高 |
| RTC 防火墙：Web | 1 | 云代理图使用普通 Markdown，无显式尺寸 |
| RTC Token 鉴权：Electron / Unity / Flutter / React Native | 4 | 获取 App 证书图使用普通 Markdown，无显式尺寸 |
| RTC Token 升级：Android / iOS / macOS / Web / Windows | 5 | 获取 App 证书图使用普通 Markdown，无显式尺寸 |

例如，同一 Token 流程图在 Android 旧页使用 `85%`，在 Web 旧页未设置尺寸；因此只恢复前者。会议产品使用过的 `90%` 证书截图也不能套到 RTC Token 页。

## 实现与防回归

- `src/lib/mdx/fixtures/cn-docs-image-dimensions.json` 固定恢复清单、计数、旧源依据和不修改的实例。
- 扩展现有 `src/lib/mdx/cn-image-parity.test.ts`，保留前批测试，并检查每个实例的组件、尺寸、alt、title、重复出现次数及所属平台。
- 同一文档可能在某些平台恢复 `DocsImage`，在其他平台继续保留 Markdown 图片；负控不能按整个 URL 禁止所有恢复，必须识别对应实例。
- 仅用 Markdown AST 的节点源位置生成替换，避免修改同 URL 的代码示例或周边正文。原有非空 alt 与 title 保留；空 alt 按图片所在正文语义补充描述。
- 停用目录按发布规则排除，不恢复下线页面，也不修改其图片引用。
- 本地扫描、替换脚本、完整测试日志和视觉验收截图均位于忽略目录 `.agent/artifacts/`，不提交 QA 图片或托管截图链接。

## 系统性截图抽查（2026-10-23）

- 在本地完整开发预览、深色主题下，对 24 个页面/平台 URL 的 27 组分层样本进行桌面 1440×1000 和手机 390×844 检查，共 54 个视口状态；包含 24 组恢复项、3 组保留项，覆盖 20 种百分比宽度及两种最大高度。
- 54 个状态的目标图片均正常加载，尺寸规则、纵横比和横向溢出检查通过；另检查 12 次点击放大，均正常加载、适配视口且不继承缩略图尺寸限制。这是抽样验收，不代表逐图检查全部 556 处。
- 待另行处理：深色主题首屏 hydration mismatch；Token React Native 内容出现非法 `<p><div>` 嵌套；深色主题下白底图片的预览关闭图标对比不足。
- 可用性观察：部分百分比截图在手机上文字较小，需要点击放大；长流程图的弹窗按视口完整适配时，可能比桌面缩略图略小。当前批次仅恢复原尺寸，不调整响应式策略或图片查看器。
- 上述问题来自本地开发预览的 DOM、控制台和截图，未做生产环境或基线归因；本轮截图抽查未修改产品代码。截图、测量数据及详细报告仅保留在忽略目录 `.agent/artifacts/`。
