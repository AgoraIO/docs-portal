# 中文文档新站上线质量报告

报告日期：2026-10-26。

更新日期：2026-10-27。

适用范围：中文新站替换旧站的迁移质量与上线准备。本报告汇总迁移记录、专项审计和检查结果，说明各维度的验证情况及剩余工作。

依据：[迁移控制规范](../../../spec.md)、[迁移验收要求](../../migration/verification-checklist.md)、各维度所列原始审计记录及[图片图床承接报告](2026-10-26-cn-image-hosting.md)。

## 一、总体结论

迁移范围、源文件与目标页面的对应关系已有文件级映射和执行台账，API 入口及导航目标有专项审计记录。旧地址重定向产物通过一致性检查；中文断链专项另有修复分支的网络、正文和锚点定位验证。搜索已有索引覆盖及点击定位验收，收录相关配置已实现并配有测试。

内容保真通过转换规则、脚本实现、源与目标内容对照及批量审计记录进行追溯，并有平台正文、发版说明等专项复核。展示与结构已开展列表、表格、图片、折叠和目录检查，完成对应修复及抽样验证。

当前剩余工作集中在图床承接：3 张本地图上传与引用替换，以及 1 张失效图片找回或替换。

各项检查对应的提交、环境和覆盖范围见第五节及原始报告。

### 2. 内容保真：转换规则与内容对照

原迁移流程已建立以下证据链：

1. [迁移控制规范](../../../spec.md)和[验收要求](../../migration/verification-checklist.md)规定保留原意、标题、示例、警告及限制。
2. [组件转换规则](../../migration/component-map.yaml)与[语法映射](../../migration/syntax-map.md)定义提示框、表格、代码、平台及折叠内容的转换方式。
3. [迁移脚本](../../../scripts/migrate-legacy-docs.mjs)展开共享依赖与产品／平台上下文，记录源目标、规则命中、残留和需复核事项。
4. [内容审计脚本](../../../scripts/audit-single-doc-fidelity.mjs)比较源与目标的标题、正文、列表、表格、代码等记录，识别新增、缺失、变化、移动及未支持结构。
5. [实际批量报告](../../migration/generated/full-redirect-pass-1-audit/report.md)保存逐行运行结果，后续[平台保真复核](2026-10-22-platform-content-fidelity.md)和[发版折叠保真](2026-10-19-cn-release-notes-accordion-parity.md)继续补强。

其中平台专项覆盖 13 篇 RTM 的 110 个 SDK 投影、2,865 个正文／表格／代码单元；发版折叠专项核对 757 条版本记录、4,740 个标题及转换前后的正文签名。转换规则、脚本实现和逐行运行结果均可追溯。

### 7. 图床承接最新进展

根据[10-26 图床报告](2026-10-26-cn-image-hosting.md)及其[统计记录](2026-10-26-cn-image-hosting/summary.json)：发布范围内有 426 个含图文件、1,764 处正文图片引用、1,014 个唯一资源。远程资源 1,011 个，其中 1,010 个返回 HTTP 200、1 个返回 HTTP 410；另有 3 个本地资源存在且解码成功，并完成 12 张图片内容抽样。

1,010 张旧图床图片沿用现有地址。其中一张含外部依赖的 SVG 已确认展示正常，继续使用现有引用。

剩余主要处理为：

- 3 张本地图上传并替换正文引用：注销工作空间截图、RTSA License 预授权截图、Android 下载二维码。
- 找回或确认等价替代图，修复 1 张 HTTP 410 的屏幕共享截图及两处 API 正文引用。
- 为实际执行的替换记录目标地址、执行结果及资源复验。另有 6 张 PNG 可正常解码，其 Content-Type 需要规范，详见图床报告。
