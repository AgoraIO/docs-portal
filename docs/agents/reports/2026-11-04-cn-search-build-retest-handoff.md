## 页面怎么测

以下路径均拼在本次构建的 Staging/候选域名后使用；测试前记录实际版本。全部文档/产品文档/API/FAQ 与平台选项都需从页面实际点击。

| 输入/路径 | 操作和验收重点 |
| --- | --- |
| `/search?q=C%2B%2B&type=all&page=1` | 查看下载 SDK (C++) 入口及 C++ API 概览/列表；点击下载章节并刷新，仍为 Windows 正确锚点，不出现 C 端计费误匹配 |
| `/search?q=C%23&type=all&page=1` | 查看 NuGet C# 入口及 C# Windows API；切 C# 平台、API 分类，再刷新。HTTP 认证代码示例不应挤占直接下载入口 |
| `rtm` / `RTMP` / `录制` | 各自概览入口优先；RTM 不被 RTMP 挤占。保留其他产品/API/FAQ 的合理召回 |
| `大小流` / `双流` | 查看双流概念与开启配置章节，实际点击；检查“如何处理视频模糊问题？”等相关 FAQ 是否保留，不仅看结果数量 |
| `audioScenario` / `audioScenario 示例` | 分别查看 API 定义、产品说明/配置及示例是否符合任务；两种输入的产品文档顺序仍需文档同学签收 |
| `manualSOS` / `HTTP 认证` | 摘要应为说明文字，不出现 tabGroup、CodeBlockTabs 或多语言代码拼接；API 精确命中不倒退 |
| `屏幕共享 JavaScript` | 产品结果应进入 Web，正文含 createScreenVideoTrack，刷新不切回 Android；同时检查带平台查询的 FAQ 变化 |
| `如何开启云端录制` | 可找到开通服务及快速开始；确认用户首要任务是开通权限还是启动录制任务 |
| `Token` 直接 URL | 首次打开、连续刷新、切分类/平台均检查控制台 React 418，结果与 URL 一致。请用本次静态发布构建，不仅测开发服务器 |
| 原始 Top30 × all/docs/api/faq | 120 项请求及页面分类检查；API/FAQ 不出现“搜索暂时不可用”。再运行质量命令对比旧站/冻结候选，并检查筛选、分页、移动端和实际链接锚点 |

`search-keywords-top30.json` 是真实 30 个查询；`top40.json` 是 40 个 API 热门页和 40 个产品热门页，不是 80 个历史搜索词。由标题生成的查询是补充场景，不混淆统计口径。
