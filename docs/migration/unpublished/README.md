# 未发布页面归档

这些页面的旧源文件或目录以下划线开头，旧站构建明确跳过它们。迁移时误将其作为正式页面收录，现移出 `content/docs`，保留原稿以供追溯。`manifest.json` 记录源路径、原发布路径和原稿 SHA-256。

本目录不是文档发布集合，不应生成页面、搜索条目、sitemap 或 Markdown/LLM 输出。不要仅根据归档中多出的 SDK 方法推断现行 API 文档缺失；如需重新发布，先单独确认版本和内容。

旧站原本没有发布这些入口，因此本次不创建推导出来的旧站重定向。新站误发布地址恢复为正常 404；正式 LocalUser 和 IRTCConnectionObserver 页面保持可用。
