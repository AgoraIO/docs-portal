对话式 AI 引擎以实时语音参与用户会话，突破传统文字交互，实现高拟真、自然流畅的双向对话体验。

适用于智能助手、情感陪伴、口语陪练、智能客服、智能硬件、沉浸式游戏 NPC 等创新场景。

在声网中，你可以通过对话式 AI 引擎在 App 中构建语音智能体，也可以通过对话式 AI 开发套件在专用设备上构建语音智能体。两条路径共享同一套实时语音交互心智：将用户接入 RTC 频道，让智能体以低延迟加入同一个会话，并通过 ASR、LLM、TTS 和可选的多模态能力完成“听懂用户、理解上下文、生成回答、用语音回复”的完整闭环。开发者无需从零搭建实时传输、智能体运行时和模型编排链路，可以把精力放在业务场景、对话体验和模型行为设计上。

## 适用场景

- **智能助手和智能客服**：让用户通过语音完成咨询、预约、查询、售后和业务办理。
- **情感陪伴和口语陪练**：构建更自然、更有停顿和打断感知的陪伴式对话体验。
- **智能硬件和 IoT 设备**：让玩具、穿戴设备、陪伴设备、自助终端等硬件具备实时语音交互能力。
- **沉浸式娱乐和游戏 NPC**：为虚拟角色接入可实时响应的语音对话能力，提升互动感和沉浸感。

## 产品能力

<CardGrid>
  <FeatureCard title="低延迟实时对话">
    基于声网实时传输能力，让用户和智能体在同一个实时会话中自然对话，减少传统语音机器人常见的等待感。
  </FeatureCard>
  <FeatureCard title="语音智能体生命周期管理">
    通过 RESTful API 创建、更新、查询和停止智能体，管理智能体加入频道、离开频道和运行状态。
  </FeatureCard>
  <FeatureCard title="自然轮次和打断">
    支持对话轮次控制、用户打断和手动 SoS/EoS，适配面试、陪练、客服等对发言边界要求更高的场景。
  </FeatureCard>
  <FeatureCard title="灵活模型接入">
    可按业务需要配置 ASR、LLM 和 TTS，也可以接入自定义大语言模型，控制智能体的知识、语气和回答策略。
  </FeatureCard>
  <FeatureCard title="多模态理解">
    在语音对话之外发送图片等多模态消息，帮助智能体结合更多上下文理解用户意图。
  </FeatureCard>
  <FeatureCard title="事件和服务端编排">
    通过客户端事件、消息通知和 Webhook 获取智能体状态、对话历史、错误和指标，便于接入业务系统。
  </FeatureCard>
</CardGrid>

## 工作方式

一个实时语音智能体通常由四层组成：实时传输负责低延迟传输音频和事件；智能体运行时负责会话生命周期、打断、轮次和上下文；模型能力负责 ASR、LLM、TTS 和多模态理解；终端体验则把智能体交付到 App 或智能硬件中。

如果你的目标是在 App 中接入语音智能体，请从[使用 RESTful API 实现对话式 AI 引擎](/zh-CN/ai/get-started/quick-start)开始。如果你的目标是在智能硬件上运行语音智能体，请从[运行 R1 Demo](/zh-CN/ai/device-kit/build/run-r1-demo)开始。
