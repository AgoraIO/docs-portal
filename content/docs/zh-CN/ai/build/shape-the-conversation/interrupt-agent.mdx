与智能体互动期间，你可能需要打断智能体发言来开启新一轮对话。

声网对话式 AI 引擎支持通过以下两种方式打断智能体：

- **语音打断**：系统根据用户的语音输入自动判断并打断智能体说话。
- **手动打断**：通过调用 RESTful API 或客户端组件 API 主动发起打断请求，实现点击按钮或发送特定命令来打断智能体。

本文介绍打断智能体的实现方式。

## 语音打断

声网对话式 AI 引擎支持开启优雅打断功能，开启后，用户与智能体互动时，支持基于语义判定用户当前是否结束发言，实现更自然的对话交互体验。

:::info[信息]
- 优雅打断为增值服务，开启后会收取费用，详见[计费说明](/zh-CN/ai/overview/billing)。
- 当语义判定用户未结束发言时，会等待一段时间才最终判定对话结束，此时响应延时会有所增加。
:::

优雅打断功能默认关闭。通过 Agents SDK 创建会话或调用 [POST 创建对话式智能体](/zh-CN/api-reference/api-ref/conversational-ai/join)时，设置 `turn_detection.config.end_of_speech.mode` 为 `semantic` 即可开启优雅打断。以下示例只展示语音打断相关配置，其他 STT、LLM、TTS 和频道参数请参考[启动和停止智能体](/zh-CN/ai/build/start-stop-agent)。

#### 请求示例

```go tab="Go SDK" tabGroup="agent-sdk-language"
import (
    Agora "github.com/AgoraIO/agora-agents-go/v2"
    agentkit "github.com/AgoraIO/agora-agents-go/v2/agentkit/cn"
)

agent := agentkit.NewAgent(client,
    agentkit.WithTurnDetectionConfig(&agentkit.TurnDetectionConfig{
        Mode: Agora.String("default"),
        Config: &agentkit.TurnDetectionNestedConfig{
            SpeechThreshold: Agora.Float64(0.5),
            StartOfSpeech: &agentkit.StartOfSpeechConfig{
                Mode: Agora.String("vad"),
                VadConfig: &agentkit.StartOfSpeechVadConfig{
                    InterruptDurationMs:         Agora.Float64(160),
                    SpeakingInterruptDurationMs: Agora.Float64(320),
                    PrefixPaddingMs:             Agora.Float64(800),
                },
            },
            EndOfSpeech: &agentkit.EndOfSpeechConfig{
                Mode: Agora.String("semantic"),
                SemanticConfig: &agentkit.EndOfSpeechSemanticConfig{
                    SilenceDurationMs: Agora.Float64(320),
                    MaxWaitMs:         Agora.Float64(3000),
                },
            },
        },
    }),
)
```

## 手动打断

声网对话式 AI 引擎支持通过调用 RESTful API 或客户端组件 API 主动发起打断请求，从而实现点击按钮或发送特定命令来打断智能体。

### 方案一：在服务端调用打断接口

你可以通过 Agents SDK 或 [POST 打断智能体](/zh-CN/api-reference/api-ref/conversational-ai/interrupt)接口主动发起打断请求。

#### 请求示例

```go tab="Go SDK" tabGroup="agent-sdk-language"
if err := session.Interrupt(ctx); err != nil {
    log.Fatal(err)
}
```

```typescript tab="TypeScript SDK" tabGroup="agent-sdk-language"
await session.interrupt();
```

```python tab="Python SDK" tabGroup="agent-sdk-language"
session.interrupt()
```

```bash tab="REST API" tabGroup="agent-sdk-language"
curl --request POST \
  --url https://api.agora.io/cn/api/conversational-ai-agent/v2/projects/:appid/agents/:agentId/interrupt \
  --header 'Authorization: agora token="007abcxxxxxxx123"' \
  --data '{}'
```

#### 响应示例

请求成功时返回 200 状态码，响应体如下：

```json
{
  "agent_id": "1NT29XxxxxxxxxELWEHC8OS",
  "channel": "test_channel",
  "start_ts": 1744877089
}
```

### 方案二：调用客户端组件 API

声网提供一套灵活可扩展、标准化的对话式 AI 引擎客户端组件（以下简称组件）。该组件支持 iOS、Android、Web 平台，封装了多个场景化 API，你只需要调用这些 API 即可结合声网[实时互动 (RTC) SDK](/zh-CN/realtime-media/rtc) 和[实时消息 (RTM) SDK](/zh-CN/realtime-media/rtm) 的能力实现以下功能：

- [打断智能体](/zh-CN/ai/build/shape-the-conversation/interrupt-agent)
- [实时字幕](/zh-CN/ai/build/transcripts)
- [监听智能体相关事件](/zh-CN/ai/build/handle-runtime-events/event-notifications)
- [设置最佳音频参数](/zh-CN/ai/best-practices/audio-setup) （仅支持 Android 和 iOS）
- [发送图片消息](/zh-CN/ai/build/send-multimodal-messages)

#### 前提条件

开始前，请确保完成以下准备工作：

- 已集成 RTC SDK v4.5.1 及以上版本，且已在 App 中实现基本的实时音视频功能并获取相关设备权限。请参考[实现音视频互动](/zh-CN/realtime-media/rtc/get-started/quick-start)。
- 已在[控制台](https://console.shengwang.cn/)为项目启用 RTM 服务，并在 App 中实现基本的实时消息功能。请参考[实现收发消息](/zh-CN/realtime-media/rtm/get-started/quick-start)。
- 已参考[实现对话式智能体](/zh-CN/ai/get-started/quick-start)实现与智能体对话的基本逻辑。
- 确保 RTC 可用、RTM 已登录，且 RTC 和 RTM 实例的生命周期大于组件的生命周期。组件内部不负责维护 RTC，RTM 的初始化、生命周期以及鉴权/登录状态的逻辑。

#### 初始化组件

为 RTC 和 RTM 实例创建配置对象，之后创建组件实例：

```java tab="Android" tabGroup="language"
// 为 RTC 和 RTM 实例创建配置对象
val config = ConversationalAIAPIConfig(
    rtcEngine = rtcEngineInstance,
    rtmClient = rtmClientInstance,
    enableLog = true
)
// 创建组件实例
val api = ConversationalAIAPIImpl(config)
```

```swift tab="iOS" tabGroup="language"
// 为 RTC 和 RTM 实例创建配置对象
let config = ConversationalAIAPIConfig(
    rtcEngine: rtcEngine, 
    rtmEngine: rtmEngine,
    enableLog: true
)
/// 创建组件实例
convoAIAPI = ConversationalAIAPIImpl(config: config)
```

```typescript tab="Web" tabGroup="language"
// 为 RTC 和 RTM 实例创建配置对象
ConversationalAIAPI.init({
    rtcEngine,
    rtmEngine,
    })

// 获取 API 实例（单例）
const conversationalAIAPI = ConversationalAIAPI.getInstance()
```

#### 智能体加入频道

调用 [POST 创建对话式智能体](/zh-CN/api-reference/api-ref/conversational-ai/join)接口，并完成以下参数设置：

- `advanced_features.enable_rtm: true` —— （必选）启动 RTM 服务
- `parameters.data_channel: "rtm"` —— （必选）开启 RTM 数据传输通道
- `parameters.enable_metrics: true` —— （按需开启）接收智能体性能数据
- `parameters.enable_error_message: true` —— （按需开启）接收智能体错误事件

调用成功后，智能体会加入指定 RTC 频道，用户可以开始与智能体互动。

#### 打断智能体

调用 `interrupt` 方法，打断智能体。

```kotlin tab="Android" tabGroup="language"
api.interrupt("agentId") { error -> /* ... */ }
```

```swift tab="iOS" tabGroup="language"
convoAIAPI.interrupt(agentUserId: "\(agentUid)") { error in
    if let error = error {
        print("打断失败: \(error.message)")
    } else {
        print("打断成功")
    }
}
```

```typescript tab="Web" tabGroup="language"
await conversationalAIAPI.interrupt(`${agent_rtc_uid}`)
```

#### 销毁组件实例

结束 AI 对话场景后或关闭 App 前，你需要销毁组件实例，以释放组件的所有资源。

```kotlin tab="Android" tabGroup="language"
api.destroy()
```

```swift tab="iOS" tabGroup="language"
convoAIAPI.destroy()
```

```typescript tab="Web" tabGroup="language"
conversationalAIAPI.destroy()
```
