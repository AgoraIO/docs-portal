- 已参考[开通服务](/zh-CN/ai/get-started/enable-service)开通对话式 AI 引擎服务。

<a id="使用-token-认证"></a>
## 使用 Token 认证（推荐）

推荐使用 Token 认证调用对话式 AI 引擎 RESTful API。将 Token 填入 HTTP 请求 Header 的 `Authorization` 字段，格式为 `agora token="<token>"`。

### 使用临时 Token

测试环境下，你可以参考[开通服务](/zh-CN/ai/get-started/enable-service#获取临时-token)从声网控制台为你的项目生成临时 Token，有效期为 24 小时。

### 在服务端生成 Token

生产环境下，你需要在自己的服务端生成 Token。本节以生成包含 ConvoAI、RTC 和 RTM service 的 Token 为例。请先从[声网控制台](https://console.shengwang.cn/)获取 App ID 和 App Certificate，再参考以下示例生成 Token。

以下示例使用 Go 的 [`convoaitokenbuilder.BuildToken`](https://github.com/AgoraIO/Tools/blob/b75635c32d30cedd25fd1199926fd55219533688/DynamicKey/AgoraDynamicKey/go/src/convoaitokenbuilder/convoaitokenbuilder.go) 生成包含 ConvoAI、RTC 和 RTM service 的 Token。

将 `appID` 和 `appCertificate` 替换为你的 App ID 和 App 证书：

```go
package main

import (
	"fmt"
	"log"
	"github.com/AgoraIO/Tools/DynamicKey/AgoraDynamicKey/go/src/convoaitokenbuilder"
)

func main() {
	appID := "<your_app_id>"
	appCertificate := "<your_app_certificate>"
	channelName := "testChannel"
	account := "0" // 智能体 UID

	tokenExpire := uint32(24 * 60 * 60) // Token 有效期，单位：秒
	privilegeExpire := uint32(60 * 60)  // RTC 和 RTM 权限有效期，单位：秒

	token, err := convoaitokenbuilder.BuildToken(
            appID,
            appCertificate,
            channelName,
            account,
            tokenExpire,
            privilegeExpire,
        )
	if err != nil {
		log.Fatal(err)
	}

	fmt.Println(token)
}
```

### 使用 Token

使用上述示例生成 Token 时，请确保以下参数与请求体保持一致：

- `channelName` 与 `properties.channel` 保持一致。
- `account` 与 `properties.agent_rtc_uid` 保持一致。

将生成的 Token 同时填入以下两个位置：

- HTTP Header：`Authorization: agora token="<token>"`，用于 ConvoAI REST API 鉴权。
- Request Body：`properties.token`，用于 Agent 加入 RTC 频道。

## 使用 HTTP 基本认证

除推荐的 Token 认证外，你也可以使用 HTTP 基本认证（HTTP Basic Auth）。该方式使用声网提供的客户 ID 和客户密钥，而非 Token，生成 Base64 编码的凭证，并填入 HTTP 请求 Header 的 `Authorization` 字段中。本节介绍如何获取用于 HTTP 基本认证的 `Authorization` 字段。

### 使用三方工具生成

你可以使用[第三方在线工具](https://www.debugbear.com/basic-auth-header-generator)快速得到 Authorization 值。将客户 ID 和客户密钥分别填入 Username 和 Password 框，得到形如 `Authorization: Basic NDI1OTQ3N2I4MzYy...YwZjA=` 的结果。冒号后的内容即是 `Authorization` 值。

### 使用示例代码生成

复制如下代码，填入你的客户 ID 和客户密钥，即可生成对应的 `Authorization` 字段：

```java tab="Java" tabGroup="operating-systems"
import java.io.IOException;
import java.net.URI;
import java.util.Base64;

public class Base64Encoding {

    public static void main(String[] args) throws IOException, InterruptedException {

        // 客户 ID
        // 需要设置环境变量 AGORA_CUSTOMER_KEY
        final String customerKey = System.getenv("AGORA_CUSTOMER_KEY");
        // 客户密钥
        // 需要设置环境变量 AGORA_CUSTOMER_SECRET
        final String customerSecret = System.getenv("AGORA_CUSTOMER_SECRET");

        // 拼接客户 ID 和客户密钥并使用 base64 编码
        String plainCredentials = customerKey + ":" + customerSecret;
        String base64Credentials = new String(Base64.getEncoder().encode(plainCredentials.getBytes()));
        // 创建 authorization header
        String authorizationHeader = "Basic " + base64Credentials;
    }
}
```

```go tab="Golang" tabGroup="operating-systems"
package main

import (
    "fmt"
    "os"
    "encoding/base64"
)

func main() {
    // 客户 ID
    // 需要设置环境变量 AGORA_CUSTOMER_KEY
    customerKey := os.Getenv("AGORA_CUSTOMER_KEY")
    // 客户密钥
    // 需要设置环境变量 AGORA_CUSTOMER_SECRET
    customerSecret := os.Getenv("AGORA_CUSTOMER_SECRET")

    // 拼接客户 ID 和客户密钥并使用 base64 进行编码
    plainCredentials := customerKey + ":" + customerSecret
    base64Credentials := base64.StdEncoding.EncodeToString([]byte(plainCredentials))
    // 创建 Authorization header
    authHeader := "Basic " + base64Credentials
    // 打印生成的认证头部
    fmt.Println(authHeader)
}
```
