与对话式智能体进行实时互动时，你可能需要实时字幕来显示你与智能体的对话内容。本文介绍如何在你的 App 中实现实时字幕功能。

## 技术原理

声网提供一套灵活可扩展、标准化的对话式 AI 引擎客户端组件（以下简称组件）。该组件支持 iOS、Android、Web 平台，封装了多个场景化 API，你只需要调用这些 API 即可结合声网[实时互动 (RTC) SDK](/zh-CN/realtime-media/rtc) 和[实时消息 (RTM) SDK](/zh-CN/realtime-media/rtm) 的能力实现以下功能：

- [打断智能体](/zh-CN/ai/build/shape-the-conversation/interrupt-agent)
- [实时字幕](/zh-CN/ai/build/transcripts)
- [监听智能体相关事件](/zh-CN/ai/build/handle-runtime-events/event-notifications)
- [设置最佳音频参数](/zh-CN/ai/build/harden-and-optimize/audio-setup) （仅支持 Android 和 iOS）
- [发送图片消息](/zh-CN/ai/build/send-multimodal-messages)

组件通过 `onTranscriptUpdated` 回调接收字幕转录内容，支持监听不同类型的字幕转录信息：

- **智能体字幕**：智能体的语音转录内容，包括实时更新和最终结果。
- **用户字幕**：用户的语音转录内容，支持实时显示和状态管理。
- **字幕转录状态**：支持进行中、完成、中断等不同状态的处理。

    }

</TabsContent>

<TabsContent value="web">

每次 `TRANSCRIPT_UPDATED` 事件都返回完整的对话列表，最近几条字幕可能发生变化。用这个列表替换当前显示的内容。下面的 React 组件在挂载时注册监听，在卸载时移除同一个监听函数：

```tsx
import { useEffect, useState } from 'react';
import {
  AgoraVoiceAIEvents,
  ConversationalAIAPI,
  type TranscriptHelperItem,
} from 'agora-agent-client-toolkit';

export function ChatHistory() {
  const [messages, setMessages] = useState<TranscriptHelperItem<unknown>[]>([]);

  useEffect(() => {
    const api = ConversationalAIAPI.getInstance();
    api.on(AgoraVoiceAIEvents.TRANSCRIPT_UPDATED, setMessages);
    return () => {
      api.off(AgoraVoiceAIEvents.TRANSCRIPT_UPDATED, setMessages);
    };
  }, []);

  return (
    <>
      {messages.map((message) => (
        <div key={`${message.uid}-${message.turn_id}`}>
          {message.uid}: {message.text}
        </div>
      ))}
    </>
  );
}
```

### 智能体加入频道

调用 [POST 创建对话式智能体](/zh-CN/api-reference/api-ref/conversational-ai/join) 接口，或在 Agents SDK 的会话配置中完成以下设置。

首先，开启 RTM 服务和数据传输通道，以接收字幕消息：

- 将 `advanced_features.enable_rtm` 设置为 `true`。
- 将 `parameters.data_channel` 设置为 `"rtm"`。

然后，选择支持实时字幕的 TTS 供应商，将 `properties.tts.vendor` 设置为下表中对应的值：

| TTS 供应商 | `tts.vendor` 值 |
| --- | --- |
| 火山引擎 TTS | `bytedance` |
| 火山引擎双向流式 TTS | `bytedance_duplex` |
| Minimax TTS | `minimax` |
| 阿里云 CosyVoice TTS | `cosyvoice` |

如需同时接收智能体性能数据或错误事件，还可以按需开启以下配置：

- 将 `parameters.enable_metrics` 设置为 `true`，接收智能体性能数据。
- 将 `parameters.enable_error_message` 设置为 `true`，接收智能体错误事件。

调用成功后，智能体会加入指定 RTC 频道，用户可以开始与智能体互动。
