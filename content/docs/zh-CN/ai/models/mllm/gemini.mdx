---
title: Google Gemini Live
description: 在 Voice Agent 中使用 Google Gemini Live 作为 MLLM。
---

Google Gemini Live 提供原生实时音频处理能力，适合使用 Google AI Studio 体系进行接入的团队。

## 示例配置

```json
"mllm": {
  "enable": true,
  "api_key": "<gemini_key>",
  "params": {
    "model": "gemini-3.1-flash-live-preview",
    "instructions": "You are a friendly assistant.",
    "voice": "Charon",
    "transcribe_agent": true,
    "transcribe_user": true
  },
  "input_modalities": ["audio"],
  "output_modalities": ["audio"],
  "vendor": "gemini"
}
```

## 关键参数

- `api_key`：Gemini API key
- `params.model`：Gemini Live 模型名
- `params.voice`：语音风格
- `transcribe_agent` / `transcribe_user`：是否实时转写
