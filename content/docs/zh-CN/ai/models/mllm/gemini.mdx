title: Google Gemini Live

---

Google Gemini Live 提供原生实时音频处理能力，适合使用 Google AI Studio 体系进行接入的团队。

## 支持的模型

| 模型 | 说明 |
| --- | --- |
| `gemini-3.1-flash-live-preview` | 通用 Gemini Live 模型。 |
| `gemini-3.5-live` | Gemini Live 模型。 |
| `gemini-3.5-live-thinking` | Gemini Live 思考模型。 |

## 示例配置

:::info[预览端点]
`gemini-3.5-live` 和 `gemini-3.5-live-thinking` 目前为早期访问预览版。使用任一模型时，请将[启动对话式 AI 智能体](/en/api-reference/api-ref/conversational-ai/join)请求发送至以下预览端点，而非标准端点，并包含所需请求头：

- **URL**：`https://partner.ai.agora.io/preview/api/conversational-ai-agent/v2/projects/<APP_ID>/join`
- **请求头**：`agora-feature: gemini-live`
:::

```json
"mllm": {
  "enable": true,
  "api_key": "<gemini_key>",
  "params": {
    "model": "gemini-3.5-live",
    "instructions": "You are a friendly assistant.",
    "voice": "Charon",
    "transcribe_agent": true,
    "transcribe_user": true
  },
  "input_modalities": ["audio"],
  "output_modalities": ["audio"],
  "vendor": "gemini"
}
```

## 关键参数

- `api_key`：Gemini API key
- `params.model`：Gemini Live 模型名。支持 `gemini-3.1-flash-live-preview`、`gemini-3.5-live` 和 `gemini-3.5-live-thinking`
- `params.voice`：语音风格
- `transcribe_agent` / `transcribe_user`：是否实时转写
