---
title: Akool（Beta）
description: 在 Voice Agent 中集成 Akool 数字人。
---

Akool 提供带口型同步和面部表情的数字人能力，适合需要视频化角色表达的场景。

> **信息**
> Akool 只支持 `16000 Hz` 音频采样率。若 TTS 使用其他采样率，可能会报错。

## 示例配置

```json
"avatar": {
  "vendor": "akool",
  "enable": true,
  "params": {
    "api_key": "<akool_key>",
    "agora_uid": "<avatar_rtc_uid>",
    "agora_token": "<avatar_rtc_token>",
    "avatar_id": "<akool_avatar_id>"
  }
}
```
