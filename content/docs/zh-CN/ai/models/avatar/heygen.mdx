---
title: LiveAvatar（Beta）
description: 在 Voice Agent 中集成 HeyGen LiveAvatar。
---

HeyGen LiveAvatar 提供高质量的数字人视频渲染能力，适合对视觉表现要求较高的场景。

> **信息**
> LiveAvatar 只支持 `24000 Hz` 音频采样率。若 TTS 采样率不匹配，可能会报错。

## 示例配置

```json
"avatar": {
  "vendor": "liveavatar",
  "enable": true,
  "params": {
    "agora_token": "<avatar_rtc_token>",
    "agora_uid": "<avatar_rtc_uid>",
    "quality": "high",
    "avatar_id": "65f9e3c9-d48b-4118-b73a-4ae2e3cbb8f0",
    "api_key": "<liveavatar_key>"
  }
}
```
