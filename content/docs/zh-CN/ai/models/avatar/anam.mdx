---
title: Anam（Beta）
description: 在 Voice Agent 中集成 Anam 数字人。
---

Anam 提供支持实时视频渲染的数字人能力，适合需要自然视频互动体验的场景。

## 示例配置

```json
"avatar": {
  "vendor": "anam",
  "enable": true,
  "params": {
    "api_key": "<anam_key>",
    "avatar_id": "960f614f-ea88-47c3-9883-f02094f70874",
    "agora_uid": "<avatar_rtc_uid>",
    "agora_token": "<avatar_rtc_token>",
    "sample_rate": 24000,
    "quality": "high",
    "video_encoding": "H264"
  }
}
```
