---
title: Cartesia
description: 在 Voice Agent 中使用 Cartesia 作为 TTS 服务。
---

Cartesia 适合需要较低延迟流式语音输出的场景。

## 示例配置

```json
"tts": {
  "vendor": "cartesia",
  "params": {
    "api_key": "<cartesia_key>",
    "model_id": "sonic-3.6",
    "voice": {
      "mode": "id",
      "id": "<voice_id>"
    }
  }
}
```
