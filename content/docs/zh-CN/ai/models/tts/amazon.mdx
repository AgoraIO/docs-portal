---
title: Amazon Polly
description: 在 Voice Agent 中使用 Amazon Polly 作为 TTS 服务。
---

Amazon Polly 适合已经在 AWS 内统一管理语音服务的接入场景。

## 示例配置

```json
"tts": {
  "vendor": "amazon",
  "params": {
    "access_key": "<aws_access_key_id>",
    "secret_key": "<aws_secret_access_key>",
    "region": "us-east-1",
    "voice_id": "Joanna"
  }
}
```
