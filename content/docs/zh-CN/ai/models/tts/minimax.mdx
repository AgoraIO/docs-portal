MiniMax 提供多种音色和低延迟流式输出能力。

## 使用预设

可直接使用以下预设：

- `minimax_speech_2_6_turbo`
- `minimax_speech_2_8_turbo`

使用预设时，无需提供 API key、group ID、模型名和端点地址。

## 示例配置

### 使用预设

```json
"preset": "minimax_speech_2_8_turbo",
"properties": {
  "tts": {
    "params": {
      "voice_setting": {
        "voice_id": "English_captivating_female1"
      }
    }
  }
}
```

### 使用自带 key

```json
"tts": {
  "vendor": "minimax",
  "params": {
    "key": "<minimax_key>",
    "group_id": "<minimax_group_id>",
    "model": "speech-02-turbo",
    "voice_setting": {
      "voice_id": "English_captivating_female1"
    },
    "url": "wss://api-uw.minimax.io/ws/v1/t2a_v2"
  }
}
```

## 关键参数

- `params.key`：MiniMax API key
- `params.group_id`：账号 group ID
- `params.model`：TTS 模型名
- `params.voice_setting.voice_id`：音色 ID
- `params.url`：流式 TTS WebSocket 地址
