---
title: Google
description: 在 Voice Agent 中使用 Google 作为 TTS 服务。
---

Google 提供多语言文本转语音能力，适合已经在 Google Cloud 管理语音服务的团队。

## 示例配置

```json
"tts": {
  "vendor": "google",
  "params": {
    "project_id": "<project_id>",
    "adc_credentials_string": "<adc_credentials>",
    "voice_name": "en-US-Neural2-C"
  }
}
```
