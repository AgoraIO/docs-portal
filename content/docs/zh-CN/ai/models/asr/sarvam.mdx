---
title: Sarvam
description: 在 Voice Agent 中使用 Sarvam 作为 ASR 服务。
---

Sarvam 提供面向多语言语音场景的自动语音识别能力，适合需要特定语言覆盖的接入场景。

## 示例配置

```json
"asr": {
  "vendor": "sarvam",
  "params": {
    "api_key": "<sarvam_key>",
    "language": "hi-IN"
  }
}
```

## 关键参数

- `params.api_key`：Sarvam API key
- `params.language`：识别语言代码
