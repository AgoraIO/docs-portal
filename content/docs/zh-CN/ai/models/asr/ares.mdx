title: ARES
description: 在 Voice Agent 中使用 ARES 作为实时语音识别服务。
---

ARES 是声网内建的实时语音识别能力，适合低延迟对话式场景。

> **信息**
> 使用 ARES ASR 会按对应的 ARES 语音识别计费项收费。

## 示例配置

```json
"asr": {
  "vendor": "ares",
  "language": "zh-CN"
}
```

## 关键参数

- `vendor`：固定为 `ares`
- `language`：识别语言，使用 BCP-47 语言标记，例如 `zh-CN`、`en-US`
