---
title: Speechmatics
description: 在 Voice Agent 中使用 Speechmatics 作为 ASR 服务。
---

Speechmatics 提供适合实时转写场景的多语言语音识别能力。

## 示例配置

```json
"asr": {
  "vendor": "speechmatics",
  "params": {
    "api_key": "<speechmatics_key>",
    "language": "en"
  }
}
```

## 关键参数

- `params.api_key`：Speechmatics API key
- `params.language`：识别语言代码
