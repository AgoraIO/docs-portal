Google Vertex AI 通过 Google Cloud 提供企业级的生成式模型接入方式，适合已经在 GCP 上管理 AI 工作负载的团队。

## 示例配置

```json
"llm": {
  "url": "https://{region}-aiplatform.googleapis.com/v1/projects/{project}/locations/{region}/publishers/google/models/{model}:streamGenerateContent?alt=sse",
  "api_key": "$(gcloud auth print-access-token)",
  "system_messages": [
    {
      "role": "user",
      "parts": [{ "text": "You are a helpful chatbot." }]
    }
  ],
  "max_history": 32,
  "greeting_message": "你好，很高兴见到你！",
  "failure_message": "请稍等一下。",
  "params": {
    "model": "gemini-2.0-flash-001"
  },
  "style": "gemini"
}
```

## 关键参数

- `api_key`：通常使用 GCP access token
- `url`：需要带上 GCP 项目 ID 和 region
- `system_messages`：使用 `parts` 数组
- `style`：设为 `gemini`
