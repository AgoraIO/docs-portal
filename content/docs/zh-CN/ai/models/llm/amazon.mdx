Amazon Bedrock 通过 AWS 托管服务接入多种基础模型，适合在 AWS 内统一管理模型调用的团队。

## 示例配置

```json
"llm": {
  "url": "https://bedrock-runtime.us-east-1.amazonaws.com/model/us.anthropic.claude-sonnet-4-20250514-v1:0/converse-stream",
  "api_key": "<your_bedrock_api_key>",
  "access_key": "<your_aws_access_key_id>",
  "secret_key": "<your_aws_secret_access_key>",
  "region": "us-east-1",
  "model": "us.anthropic.claude-sonnet-4-20250514-v1:0",
  "system_messages": [
    {
      "role": "system",
      "content": "You are a helpful chatbot."
    }
  ],
  "style": "bedrock"
}
```

## 关键参数

- `url`：目标区域和模型对应的 Bedrock runtime endpoint
- `api_key` 或 `access_key` + `secret_key`：鉴权方式
- `region`：AWS 区域
- `style`：设为 `bedrock`
