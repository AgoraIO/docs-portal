## 课前准备

通过声网频道管理服务查询课堂相关信息，并管理学生在上课过程中发送音视频和实时消息的权限。

### 课堂管理

### 课前设备和网络检测

在线教育场景非常重视音视频的效果和稳定性，因此声网强烈建议教师端和学生端都进行课前检测，检测麦克风、摄像头等音视频设备能否正常工作，并检测网络状况是否满足要求，详见[通话前网络和设备检测](/zh-CN/realtime-media/rtc/build/optimize-and-operate/lastmile-quality)。

## 课堂互动

### 实时音视频互动

使用声网 RTC SDK 实现实时音视频互动功能。教师对学生讲课，学生就上课内容向老师提问，形成良好的互动式课堂氛围。详见：

- [RTC SDK 下载地址](/zh-CN/api-reference/sdks?product=video)
- [RTC SDK 快速开始](/zh-CN/realtime-media/rtc/get-started/quick-start)

- [RTC API 参考](/api-ref/rtc//API/rtc_api_overview)

- [RTC API 参考](/api-ref/rtc/javascript/overview)

- [RTC GitHub 示例项目](https://github.com/AgoraIO/API-Examples)

### 实时消息互动

使用声网云信令 SDK 实现实时消息互动功能。教师和学生在课堂中发送文字消息进行互动。详见：

- [云信令 SDK 下载地址](/zh-CN/api-reference/sdks?product=signaling)
- [云信令 SDK 集成指引](https://docportal.shengwang.cn/cn/Real-time-Messaging/messaging_android?platform=Android)
- [云信令 API 参考](https://docportal.shengwang.cn/cn/Real-time-Messaging/api-ref?platform=All%20Platforms)
- [云信令 GitHub 示例项目](https://github.com/AgoraIO/RTM)

### 互动白板

教师在白板上涂鸦、上传文件（PPT、Word 和 PDF）或播放视频，有助于提炼教学重点，帮助学生理解或记忆。学生也可使用白板与老师进行实时互动。详见：

- [互动白板 SDK](/doc/whiteboard//whiteboard-sdk/landing-page)
- [开启和配置互动白板服务](/doc/whiteboard//whiteboard-sdk/get-started/enable-service)

### 屏幕共享

通过声网 RTC SDK 提供的 API，教师可将自己屏幕的内容分享给学生观看，提高教学效果。详见[屏幕共享](/zh-CN/realtime-media/rtc/build/video/screen-share)。

### 客户端播放媒体文件

教师可通过[媒体播放器组件](/zh-CN/realtime-media/rtc/build/audio/media-player)（MediaPlayer Kit）在客户端播放本地或在线的媒体资源，将媒体资源同步分享给声网频道内的远端学生观看和收听。

### 服务端播放在线媒体流

开发者可通过[服务端输入在线媒体流服务](/zh-CN/realtime-media/media-pull)，将事先准备的音视频素材作为一个发送端输入正在进行的课堂，教师和学生可以一起观看该媒体流并实时互动。

### 监课端

监课端在在线教育场景中扮演的角色类似于现实中的助教，主要处理如下任务：

- 处理紧急突发问题，确保课程正常完成。
- 管理教室、课件、教师和学生等。

你可以使用 RTC Web SDK，也可以使用 RTC Native SDK 实现监课端，把监课端想象成一个上课过程中只收流、不发流的特殊客户端。

监课端也可应用于家长旁听等场景。

## 课后回顾

### 录制

使用声网录制服务将课堂内容录制下来，并生成回放链接，方便学生课后复习和学校评估教学质量。详见：

- [云端录制](/zh-CN/realtime-media/recording/cloud-recording)（推荐）
- [本地服务端录制](/zh-CN/realtime-media/recording/local-server-recording)

### 高光时刻

在上课过程中插入 SEI，录制回放时通过解析 SEI 实现快速定位或生成精彩集锦，可用于定位学生的互动过程、教师的重点内容等。如需使用此功能，请联系 sales@shengwang.cn。

### 口语测评

在使用声网 SDK 的基础上，可集成云知声语音评测组件，为客户增加智能口语评测能力，快速实现智能评分，教评结合，提升效率和口语成绩。详见[口语测评 GitHub 示例项目](https://github.com/AgoraIO/Advanced-Audio/tree/dev/backup/Pronunciation-Assess)。

## 问题调查和课堂质量监测

### 课中网络质量监测

声网建议在课堂中进行网络质量监测，并在 App 界面中提示用户监测结果，告知用户本地和远端的网络质量，详见[通话中质量监测](/doc/rtc//advanced-features/in-call-quality)。

### 水晶球

通过声网提供的全周期通话质量监测、回溯和分析工具[水晶球](https://analytics-lab.shengwang.cn/analytics/call/search)，及时发现问题、定位原因，并最终解决问题以提升终端用户体验。

## 更多功能

### 实时美颜

通过声网 SDK 提供的 API 实现基础美颜功能，调整美白、磨皮、祛痘、红润效果等美颜参数，实现自然的美颜效果。详见[美颜 API](/api-ref/rtc//API/toc_video_enhance_option#api_irtcengine_setbeautyeffectoptions)。

### 变声和美声

通过声网 SDK 提供的 API 美化人声或为人声增添丰富的音效，增添课堂的趣味性并提升互动体验。声网 SDK 提供预设的人声效果，也支持通过音调、声音均衡和混响等设置自定义人声效果。详见：

- [设置人声效果](/doc/rtc//advanced-features/voice-changer)
- [美声音效在线 Demo](https://www.agora.io/cn/audio-demo)

### 实时审核（鉴黄）

审核实时音视频涉黄、涉恐、涉暴等敏感内容。如需使用此功能，请联系 sales@shengwang.cn。
