本页介绍语聊 PaaS 方案中高频调用的实时互动 RTC API。

| API | 描述 |
| --- | --- |
| [create](/api-ref/rtc/android/API/toc_initialize#api_irtcengine_initialize) | 创建并初始化 `RtcEngine`。 |
| [joinChannel](/api-ref/rtc/android/API/toc_channel#api_irtcengine_joinchannel2) | 加入 RTC 频道。 |
| [setChannelProfile](/api-ref/rtc/android/API/toc_channel#api_irtcengine_setchannelprofile) | 设置频道模式。 |
| [setAudioProfile](/api-ref/rtc/android/API/toc_audio_basic#api_irtcengine_setaudioprofile2) | 设置音频属性。 |
| [setAudioScenario](/api-ref/rtc/android/API/toc_audio_basic#api_irtcengine_setaudioscenario) | 设置音频场景。 |
| [setParameters](/api-ref/rtc/android/API/toc_network#api_irtcengine_setparameters) | 设置私有参数。 |
| [setClientRole](/api-ref/rtc/android/API/toc_channel#api_irtcengine_setclientrole) | 设置用户角色。 |
| [muteLocalAudioStream](/api-ref/rtc/android/API/toc_publishnsubscribe#api_irtcengine_mutelocalaudiostream) | 停止发送本地音频流。 |
| [leaveChannel](/api-ref/rtc/android/API/toc_channel#api_irtcengine_leavechannel) | 离开 RTC 频道。 |
| [destroy](/api-ref/rtc/android/API/toc_initialize#api_irtcengine_release) | 销毁 `RtcEngine`。 |
