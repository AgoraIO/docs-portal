## 下载 SDK

语聊 PaaS 方案使用实时互动 RTC SDK 和即时通讯 IM SDK 共同搭建。

推荐通过 Maven 集成 SDK：

```groovy
dependencies {
    implementation 'io.agora.rtc:full-sdk:4.4.1'
    implementation 'io.agora.rtc:chat-sdk:1.1.0'
}
```
