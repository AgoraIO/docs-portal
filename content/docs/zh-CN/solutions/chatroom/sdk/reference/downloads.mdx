## 下载 SDK

语聊 PaaS 方案使用实时互动 RTC SDK 和即时通讯 IM SDK 共同搭建。

推荐通过 Maven 集成 SDK：

```groovy
...
dependencies {
    ...
    // 集成 RTC SDK
    implementation 'io.agora.rtc:full-sdk:4.4.1'
    // 集成 IM SDK
    implementation 'io.agora.rtc:chat-sdk:1.1.0'
}
```

RTC SDK 的其他获取方式详见[实时互动下载](/zh-CN/realtime-media/rtc/reference/downloads)。

推荐通过 CocoaPods 集成 SDK：

```ruby
platform :ios, '11.0'
target 'Your App' do
    # 集成 RTC SDK
    pod 'AgoraRtcEngine_iOS', '4.4.1'
    # 集成 IM SDK
    pod 'Agora_Chat_iOS'
end
```

其他 SDK 获取方式详见[实时互动下载](/zh-CN/realtime-media/rtc/reference/downloads)和[集成即时通讯 IM SDK](https://docs-preprod.agora.io/cn/agora-chat/agora_chat_get_started_ios?platform=iOS#%E9%9B%86%E6%88%90%E5%8D%B3%E6%97%B6%E9%80%9A%E8%AE%AF-im-sdk)。
