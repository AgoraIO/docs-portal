title: "方案对比"
---
声动语聊解决方案提供两种技术方案：PaaS 方案和 UIKit 开源方案。

本文对比这两种技术方案。

| PaaS 方案 | UIKit 开源方案 |
| --- | --- |
| <Slot name="solution-compare-html-0-1-0" /> | <Slot name="solution-compare-html-0-1-1" /> |

<Slot for="solution-compare-html-0-1-0">

- **灵活开发**：交互逻辑完全在客户端实现，修改业务逻辑时无需依赖后端介入，便于按需调整客户端实现。

    - **全面功能演示**：含有最新的功能迭代，提供更全面的效果演示能力。

    - **丰富最佳实践参考**：积累了丰富的语聊集成最佳实践，为开发者提供更多可参考的代码逻辑。

</Slot>

<Slot for="solution-compare-html-0-1-1">

- **模块化 UI**：支持你使用语聊 UI 组件提供的互动、送礼物、直播等模块，快速搭建语聊业务逻辑。

    - **低学习成本、短开发时间**：无需深入理解模型层逻辑即可自定义 UI。只需修改少量代码，便可快速运行 AUIVoiceRoom 示例项目。若人力有限或项目周期紧迫，可以优先考虑含 UI 组件的方案。

    - **强大的拓展性**：当有更灵活的自定义需求时，可以利用 AUIKit 提供的 UI 和 Service 组件进行进一步开发。

</Slot>
