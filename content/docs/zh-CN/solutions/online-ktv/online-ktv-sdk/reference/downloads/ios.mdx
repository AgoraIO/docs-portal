## 通过 CocoaPods 集成 SDK

```ruby tab="视频 SDK" tabGroup="integrate-sdk"
platform :ios, '9.0'
target 'Your App' do
    pod 'AgoraRtcEngine_iOS', '4.4.0'
    pod 'AgoraRtcEngine_iOS', '4.4.0', :subspecs => ['RtcBasic', 'AINS', 'ClearVision']
end
```

```ruby tab="音频 SDK" tabGroup="integrate-sdk"
platform :ios, '9.0'
target 'Your App' do
    pod 'AgoraAudio_iOS', '4.4.0'
    pod 'AgoraAudio_iOS', '4.4.0', :subspecs => ['RtcBasic', 'AINS', 'AudioBeauty']
end
```
