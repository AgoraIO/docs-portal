## 概述

本文展示声网在线 K 歌房解决方案的计费方式。

当你使用声网在线 K 歌房解决方案时，声网收取实时音频费用和内容订阅费用。计费方式分为如下两部分：

- 实时音频费用：声网实时音视频服务的计费方式详见[计费文档](/zh-CN/realtime-media/rtc/reference/billing-strategy)。

- 实时音频费用：声网实时音视频服务的计费方式详见[计费文档](/zh-CN/realtime-media/rtc/reference/billing-strategy)。

- 内容订阅费用：声网按月计算内容中心音乐版权的使用费用，并[发布账单、进行扣款](/zh-CN/api-reference/faq/account/billing_account)。

如果[账户冻结](/zh-CN/api-reference/faq/account/billing_account)，声网提供 6 个月的应用数据保存服务，你需要及时解冻账户或在数据被删除前进行导出。

## 内容订阅费用计算

每月结束时，声网会统计你的[声网账号](/zh-CN/introduction/quickstart#注册账号)下内容中心项目的用量，并根据场景将用量乘以相应的单价，得出本月总费用，计算公式如下：

**费用** = **用量** × **不同场景下的单价**

### 用量

声网根据你账号下内容中心项目在语聊、VR 场景中的用量，计算当月账单。

### 场景及单价

**语聊场景 K 歌**

在语聊场景下 K 歌，声网将根据歌曲的有效调用次数计费。一首歌曲的播放时长大于等于 **15 秒**视为一次有效调用。

| 有效调用次数            | 有效调用次数单价（元） |
| :---------------------- | :---------------------- |
| 0 - 500,000             | 0.2                     |
| 500,001 - 1,000,000     | 0.19                    |
| 1,000,001 - 2,000,000   | 0.18                    |
| 2,000,001 - 4,000,000   | 0.17                    |
| 4,000,001 - 10,000,000  | 0.16                    |
| 10,000,001 - 20,000,000 | 0.15                    |
| 20,000,001 以上         | 0.14                    |

**语聊场景播放背景音乐**

在语聊场景下播放背景音乐，声网将根据歌曲的有效调用次数计费。一首歌曲的播放时长大于等于 **15 秒**视为一次有效调用。

| 有效调用次数            | 有效调用次数单价（元） |
| :---------------------- | :---------------------- |
| 0 - 500,000             | 0.2                     |
| 500,001 - 1,000,000     | 0.19                    |
| 1,000,001 - 2,000,000   | 0.18                    |
| 2,000,001 - 4,000,000   | 0.17                    |
| 4,000,001 - 10,000,000  | 0.16                    |
| 10,000,001 - 20,000,000 | 0.15                    |
| 20,000,001 以上         | 0.14                    |

**VR 场景**

在 VR 场景下 K 歌、播放背景音乐，声网将根据歌曲的有效调用次数计费。一首歌曲的播放时长大于等于 **15 秒**视为一次有效调用。

有效调用次数单价：0.4 元/次
