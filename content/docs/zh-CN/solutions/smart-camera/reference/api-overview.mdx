本页提供设备端使用的 RTSA Lite SDK，以及客户端使用的 RTC SDK 和 RTM SDK 的 API 参考。

设备端信令接口包含在 RTSA Lite SDK 中。客户端示例的版本说明见[设备控制](/zh-CN/solutions/smart-camera/reference/advanced-feature#设备控制)。下方 RTM API 参考展示当前版本；从 RTM 1.x 升级到 RTM 2 时，请参考[迁移指南](/zh-CN/realtime-media/rtm/reference/migration-guide)。

| API 文档 | 描述 |
| --- | --- |
| [RTSA Lite SDK（设备端）](/zh-CN/api-reference/rtsa/c/overview) | 实现设备端媒体流传输和内置 RTM 信令交互 |
| [RTC SDK（客户端）](/zh-CN/api-reference/rtc/android/rtc-api-overview) | 实现客户端媒体流采集、编解码、传输、渲染等功能 |
| [RTM SDK（客户端）](/zh-CN/api-reference/rtm/android) | 在客户端收发信令，实现与设备端的可靠信令交互 |
