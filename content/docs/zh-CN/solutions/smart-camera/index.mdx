title: 智能摄像头概览
---
声网智能摄像头场景解决方案为设备端和客户端提供实时音视频和可靠信令的全场景服务。其中，设备端 SDK 适用于网络摄像机 (IP Camera)、可视门铃、行车记录仪等轻量级嵌入式设备，客户端 SDK 适用于移动端 (Android/iOS)、桌面端 (macOS/Windows) 或 Web 端 App。通过接入声网的 [SD-RTN™](/basics/glossary#sd-rtn)，可以实现设备端和客户端 App 的实时互动。

例如，在使用网络摄像机的场景中，用户可以在手机上查看摄像机画面，手机客户端还可以与摄像机设备端进行双向语音对讲。

## 应用场景

智能摄像头场景解决方案支持实时监控、远程回看等功能，可以广泛应用于教育、商业、医疗、公共事业等多个领域。

| 场景 | 描述                                                     |
| :------- | :----------------------------------------------------------- |
| 银行、超市、道路等公共场所监控 | 提高环境安全程度和工作人员响应速度，帮助及时发现问题并解决问题。 |
| 智能办公 | 免除不必要的商务活动，让企业及时、直观地掌握公司情况。 |
| 家庭安防监控、宠物/老人/婴儿看护等 | 让家庭成员掌握家中实时动态。 |

## 功能列表

智能摄像头场景解决方案支持以下功能：

| 主要功能 | 功能描述                                                     |
| :------- | :----------------------------------------------------------- |
| 异常检测通知 | 设备端通过自身集成的 AI 检测能力（如移动侦测、人形检测、烟雾感知、异声感知、跌倒检测等）检测到异常后实时通知客户端；用户可通过客户端及时浏览现场情况。              |
| 实时监控 | 用户可以通过客户端 App 或网页查看摄像头的视频画面。一个摄像头的视频画面能同时被多个客户端查看。一个客户端能同时查看多个摄像头的视频画面。 |
| 双向对讲 | 用户可以通过客户端 App 或网页和设备端进行语音通话。              |
| 控制信令 | 通过云信令 (RTM) SDK 实现可靠信令交互，用户可通过客户端 App 或网页远程控制设备。例如实时控制摄像头云台转动，全面实时了解摄像头周边状态。一般情况下，网络摄像头产品支持多个分辨率档位，用户可以通过客户端 App 主动选择分辨率。 |

图中视频编码支持 H.264 格式，音频编码支持 AAC、Opus 或 PCM 格式。如果有自研的音频编码器，你可以自行编码 AAC 或 Opus 格式的音频数据，然后通过 RTSA Lite SDK 传输；如果没有自研音频编码能力，你可以直接传输 PCM 音频数据，RTSA Lite SDK 会使用内置的 Opus 编码器完成音频编码并传输。

## 方案优势

**全场景解决方案**

提供实时媒体 + 信令控制的全场景一站式实时互动和互联互通解决方案。

支持视频传输编码码流，音频灵活传输编码前/后格式，支持发送可靠控制消息和任意格式 Generic codec。

**轻量级设备端 SDK**

极小包体、超低功耗，帮助 IoT 设备开发者实现极佳的实时互动级体验，节省设备成本和资源开销。

**兼容性强**

设备端支持 ARM/MIPS/X86 等 Linux 全平台和 Android 平台，支持 LiteOS、Harmony 等主流 RTOS 平台，覆盖了主流设备端平台和系统，同时支持设备定制。

依托 SD-RTN™，设备端可和客户端全平台实时音视频互通。

**易用性佳**

简单、易用、稳定，良好的可扩展性，灵活应对更丰富的 IoT 实时互动场景需求变化。

**超低延时**

声网 SD-RTN™ 网络节点覆盖全球 200 多个国家和地区，通过就近接入、智能路由等控制策略，保证全球平均端到端延时 < 400 ms。

**稳定可靠**

提供 SLA 质量保证，登录成功率 > 99%，全年可用时间高达 99.99%。

**极致弱网对抗能力**

业界领先的弱网对抗算法，保证在 70% 丢包情况下，音视频通话流畅，真正做到低卡顿、不掉线。

**质量透明**

通过声网[水晶球](https://analytics-lab.agora.io/analytics/call/search)工具，显示端到端全链路的质量监控数据，帮助排查定位问题。
