## 智能摄像头是什么？

![guide](/img/smart-camera/landing-page.png)

声网智能摄像头场景解决方案为设备端和客户端提供实时音视频和可靠信令的全场景服务。其中，设备端 SDK 适用于网络摄像机 (IP Camera)、可视门铃、行车记录仪等轻量级嵌入式设备，客户端 SDK 适用于移动端、桌面端或 Web 端 App。通过接入声网的 SD-RTN™，可以实现设备端和客户端 App 的实时互动。
