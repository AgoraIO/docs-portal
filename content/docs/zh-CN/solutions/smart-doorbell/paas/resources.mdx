| SDK | 下载链接 |
| --- | --- |
| RTC SDK | 前往[实时互动 SDK 下载](/zh-CN/realtime-media/rtc/resources)获取目标平台的 SDK。 |
| RTSA Lite SDK | 前往[媒体流加速 SDK 下载](/zh-CN/realtime-media/rtsa/resources.c)获取目标平台的 SDK。 |
| RTM SDK | 前往[实时消息 SDK 下载](https://docportal.shengwang.cn/cn/Real-time-Messaging/downloads?platform=All%20Platforms)获取目标平台的 SDK（仅支持 RTM 1.x 版本）。 |
