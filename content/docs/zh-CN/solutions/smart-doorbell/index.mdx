声网提供智能门铃场景化解决方案，适用于可视门铃、视频门锁、智能猫眼等设备开发。

该方案基于声网实时音视频、云信令、离线推送等全栈服务，通过云芯一体的设备端 SDK、客户端 SDK、灵隼物联网云平台服务端，提供简单易用的一站式上云解决方案。

## 应用场景

智能门铃场景化解决方案可实现实时监控、告警等功能，广泛应用于家庭安防、智慧养老、智慧社区等多个场景。

| 应用场景 | 描述                                                         |
| :------- | :----------------------------------------------------------- |
| 家庭安防 | 让家庭成员掌握家门口的实时动态，提升家庭的安全等级。         |
| 智慧养老 | 通过设置紧急按钮，实现一键音视频呼叫、紧急求助等功能，为独居老人和监护人员提供便利。 |
| 智慧社区 | 在社区解决方案中，融入智能门锁，实现远程开锁等功能。         |

## 技术方案

声网针对智能门铃场景提供 PaaS 和 aPaaS 两种解决方案。

![解决方案架构图](https://web-cdn.agora.io/docs-files/1666592737672)

下表列出这两种解决方案的详细区别：

|         对比项                | PaaS 解决方案                                                | aPaaS 解决方案                                               |
| :---------------------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
| 方案介绍                | 通过 RTSA Lite SDK、实时互动 (RTC) SDK、云信令 (RTM) SDK 和云端录制服务共同搭建智能门铃场景。 | 使用第三方物联网开发框架和声网灵隼物联网云平台来实现智能门铃场景。 |
| 适用对象                | 拥有自己的 IOT 管理后台，只需要声网提供音视频传输服务的用户。 | 需要呼叫、实时音视频、设备管理、上下行消息收发等 IOT 一站式解决方案的用户。 |
| 开发成本                | 纯传输，高代码                                               | 端到端，低代码                                               |
| 通用功能                | 视频实时预览 (RTC)，远程实时控制 (RTM)                     |                                   视频实时预览 (RTC)，远程实时控制 (RTM)                           |
| 设备连接管理            | 客户自行实现                     | 支持                                                         |
| 双向音视频呼叫/呼叫管理 | 客户自行实现                                                 | 支持                                                         |
| 事件云存储              | 客户自行实现或对接第三方 OSS                                                 | 支持                                                         |
| 告警服务（消息推送）    | 客户自行实现或集成第三方（环信）[即时推送](https://docs-im.easemob.com/push/apppush/introducton)                                  | 支持                                                         |
| OTA                     | 客户自行实现 | 支持                                                         |
| 交付物                  | SDK                                                 | SDK 和示例代码                                               |
