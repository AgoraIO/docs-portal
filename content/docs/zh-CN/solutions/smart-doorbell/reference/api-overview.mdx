你可以使用声网 RTC SDK、RTM SDK (1.x) 和 RTSA SDK 共同搭建智能门铃场景。

本页提供你在搭建过程中可以参考的 API 文档。

| API 文档 | 描述 |
| --- | --- |
| [RTSA SDK](/zh-CN/api-reference/rtsa/c/overview) | 使用 RTSA Lite SDK 在设备端实现媒体流传输功能 |
| [RTC SDK](/zh-CN/api-reference/rtc/android/rtc-api-overview)| 使用 RTC SDK 在客户端实现媒体流采集、编解码、传输、渲染等功能 |
| [RTM SDK (1.x)](/zh-CN/api-reference/rtm/android)| 使用 RTM SDK 在设备端和客户端实现可靠信令交互 |
