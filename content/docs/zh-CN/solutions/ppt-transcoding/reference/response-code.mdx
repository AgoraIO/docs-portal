---
title: 响应状态码
description: 查看 PPT 转码服务 RESTful API 的 HTTP 状态码和错误码。
---

调用 PPT 转码服务 RESTful API 时，如果状态码为 `200` 或 `201`，表示请求成功。如果状态码不为 `200` 或 `201`，表示请求失败，响应包体中可能包含 `error.code`、`error.title` 等字段。

```json
{
  "error": {
    "code": "2010201",
    "title": "unsupported file format",
    "messages": [],
    "requestId": "iUxxxXS_gGxxxXWw",
    "region": "cn-hz",
    "traceStack": ["cn-hz-shunt-api-7bxxxxxx8d-67stw"]
  }
}
```

## HTTP 响应状态码

| HTTP 状态码 | 描述 | 处理建议 |
| --- | --- | --- |
| `200 OK` | 请求成功，服务器成功返回请求的数据。 | 无需处理。 |
| `201 Created` | 请求成功，服务器成功新建或修改数据。 | 无需处理。 |
| `400 Invalid request` | 请求参数错误，服务器没有进行新建或修改数据的操作。 | 根据响应包体中的 `code` 和 `message` 处理。 |
| `401 Unauthorized` | 用户没有权限，通常是 Token 错误。 | 重新生成拥有对应权限的 Token。 |
| `403 Forbidden` | 用户已认证，但没有访问对应资源的权限。 | 检查房间或资源的访问权限。 |
| `404 Not found` | 服务器无法找到请求的资源。 | 检查请求路径和资源 ID 是否正确。 |
| `500 Internal server error` | 服务器内部错误，无法完成请求。 | 重试或[联系技术支持](https://ticket.shengwang.cn/)。 |
