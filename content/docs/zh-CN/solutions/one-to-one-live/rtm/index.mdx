1v1 私密房是声网提供的 1v1 视频社交场景化解决方案，结合声网 RTC 和 RTM SDK 等产品和能力，将保证 1v1 流畅、高清、秒接通等最佳效果的 API 进行整合，充分降低了开发门槛，支持快速上线。

1v1 私密房场景解决方案支持如下两种玩法：

- 1v1 私密房。即用户根据头像、个人简介等选择感兴趣的其他用户，并发起 1v1 私密视频通话。
- 秀场转 1v1。直播过程中，观众可以向主播发起呼叫，然后和主播进行 1v1 私密视频通话。私密通话结束后，主播继续进行直播。可以作为秀场直播的一个付费玩法。

声网 1v1 私密房默认 RTM 方案支持 Android 和 iOS。

## 方案优势

声网 1v1 私密房默认 RTM 方案基于 1v1 场景化 API 搭建，同时将保证流畅、高清、秒接通等最佳效果的 API 进行整合，因此具有如下优势：

**易于集成**

- 易用：支持快速调试，一周快速上线
- 完整：覆盖一对一通话（呼叫、接通、挂断等）、计费逻辑参考、匹配逻辑参考、美颜、防薅羊毛、即时消息等功能模块
- 方便问题调查：上报机制完善，支持开发者通话日志定位问题

**实现效果**

- 流畅、高清的视频通话：针对全球区域弱网地区，均自适应最佳弱网策略
- 呼叫秒接通、秒出图：针对全球跨区通话，支持快速实现接通一对一视频通话的刚需
- 跨区域通话超低延迟：针对全球跨区通话，超低延迟支持
- 合理的计费策略逻辑：协助开发者计费更精准，让用户更满意

**数据监测**

- 提供各区域指标的上限和下限标准，和指导实现的最佳实践
