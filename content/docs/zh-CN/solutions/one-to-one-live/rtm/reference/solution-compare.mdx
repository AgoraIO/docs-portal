为满足不同需求，声网针对一对一私密房场景提供如下解决方案：

- 场景化 API（默认 RTM）方案：基于声网 1v1 场景化 API 搭建，将呼叫和通话逻辑进行简化封装，同时整合流畅、高清、秒接通等实践，可帮助你更快实现一对一私密房的秒接通、秒出图能力，减少 70% 的开发工作量。
- 场景化 API（自定义信令）方案：使用声网 RTC SDK 和三方信令厂商的 SDK 搭建，为有接入自研信令、其它厂商三方信令的开发者提供秒接通、秒出图的最佳效果集成指导。

两种方案对比如下：

| 对比项  | 默认 RTM 方案 | 自定义信令方案 |
| --- | --- | --- |
| 适用对象 | 开发排期紧、需快速上线、对海外区域接通率、接通耗时有严格要求的开发者 | 开发能力强、定制化需求高，且需要接入自研信令或三方信令厂商 SDK 的开发者 |
| 功能实现难度 | 较低；场景化 API 代码结构较为简单，使用场景化 API 可以简化呼叫、接听、挂断等等逻辑，但房间管理、麦位管理等功能及 UI 需自行开发设计 | 中等；需直接使用实时互动 SDK 接口，并按照声网推荐的最佳实践自行接入三方信令，并自行开发实现所有业务逻辑和 UI |
| 可扩展性 | 较高；开源函数支持开发者自行进行功能定制化修改 | 高；可自行进行功能定制化修改 |
| 接入难度 | 较低；需要集成场景化 API、实时互动 SDK | 需要根据自己实际的业务需求自行集成各个厂商功能模块 SDK |
