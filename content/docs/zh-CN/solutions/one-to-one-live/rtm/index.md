1v1 指一对一视频通话和一对一音频通话，是社交和即时通信类 App 的必备功能。在陌生人社交领域，1v1 又可细分为 1v1 私密房和秀场转 1v1 两类玩法。

声网 1v1 私密房默认 RTM 方案基于场景化 API (CallAPI) 开发，包含 1v1 音视频、定向邀约、用户管理，及音频体验、计费策略推荐等最佳实践于一体，支持最快一周内上线，显著降低开发成本。
