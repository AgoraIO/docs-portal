---
title: "实时互动 API"
---
本页展示 1v1 私密房自定义信令方案中高频调用的实时互动 SDK API。

| API 名称                                                     | 描述                                                         |
| ------------------------------------------------------------ | ------------------------------------------------------------ |
| [create](/api-ref/rtc/android/API/toc_initialize#api_irtcengine_initialize) | 创建并初始化 RtcEngine。                                     |
| [destroy](/api-ref/rtc/android/API/toc_initialize#api_irtcengine_release) | 销毁 RtcEngine 对象。                                        |
| [setClientRole](/api-ref/rtc/android/API/toc_channel#api_irtcengine_setclientrole2) | 秀场转 1v1 场景下设置直播或观众的角色。                                        |
| [enableLocalVideo](/api-ref/rtc/android/API/toc_video_basic#api_irtcengine_enablelocalvideo)  | 秀场转 1v1 场景下开启或关闭本地视频采集。 |
| [enableLocalAudio](/api-ref/rtc/android/API/toc_audio_capture#api_irtcengine_enablelocalaudio) | 秀场转 1v1 场景下开启或关闭本地音频采集。|                                                  |
| [joinChannel [2/2]](/api-ref/rtc/android/API/toc_channel#api_irtcengine_joinchannel2) | 秀场转 1v1 场景下设置媒体选项并加入频道。                                     |                                             |
| [updateChannelMediaOptions](/api-ref/rtc/android/API/toc_channel#api_irtcengine_updatechannelmediaoptions) | 秀场转 1v1 场景下加入频道后更新频道媒体选项。                                 |
