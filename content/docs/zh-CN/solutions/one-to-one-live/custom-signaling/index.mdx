1v1 指一对一视频通话和一对一音频通话，是社交和即时通信类 App 的必备功能。在陌生人社交领域，1v1 又可细分为 1v1 私密房和秀场转 1v1 两类玩法。

声网 1v1 私密房三方信令方案基于场景化 API (CallAPI) 开发，支持使用自定义信令替换声网默认的 RTM 信令。只需实现一个简单的接口文件，即可轻松替换。

1v1 私密房场景解决方案支持如下两种玩法：

- 1v1 私密房。即用户根据头像、个人简介等选择感兴趣的其他用户，并发起 1v1 私密视频通话。
- 秀场转 1v1。直播过程中，观众可以向主播发起呼叫，然后和主播进行 1v1 私密视频通话。私密通话结束后，主播继续进行直播。可以作为秀场直播的一个付费玩法。
