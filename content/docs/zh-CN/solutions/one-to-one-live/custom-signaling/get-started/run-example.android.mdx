本文介绍如何快速跑通该示例项目，体验直播效果。

## 前提条件

开始前，请确保满足如下前提条件：

- 参考[开通服务](/zh-CN/solutions/one-to-one-live/custom-signaling/get-started/enable-service)在控制台创建项目，获取 App ID 和 App 证书，并[开通三方信令服务的权限](/zh-CN/solutions/one-to-one-live/custom-signaling/get-started/enable-service#开通第三方信令服务)
- [Git](https://git-scm.com/downloads)
- [Java Development Kit](https://www.oracle.com/java/technologies/javase-downloads.html)
- [Android Studio](https://developer.android.com/studio/) 4.1 及以上
- Android 手机，版本 Android 5.0（API Level 21）及以上

    :::warning[注意]
    声网推荐使用真机运行项目。部分模拟机可能存在功能缺失或者性能问题。
    :::

## 克隆仓库

运行以下命令克隆仓库到本地：

```shell
git clone git@github.com:AgoraIO-Community/CallAPI.git
```

## 配置示例项目

运行项目前，你需要在 `/CallAPI/Android/gradle.properties` 文件中设置如下参数：

```kotlin
AG_APP_ID=
AG_APP_CERTIFICATE=
IM_APP_KEY=
```

填入你在[开通服务](/zh-CN/solutions/one-to-one-live/custom-signaling/get-started/enable-service)时获取的声网项目的 App ID、App 证书和环信项目的 App Key：

| 参数 | 描述   | 获取方式 |
|----|----|----|
| `AG_APP_ID`    | 声网项目的 App ID     | [获取 App ID](/zh-CN/solutions/one-to-one-live/custom-signaling/get-started/enable-service#获取-app-id)  |
| `AG_APP_CERTIFICATE` | 声网项目的 App 证书 |[获取 App 证书](/zh-CN/solutions/one-to-one-live/custom-signaling/get-started/enable-service#获取-app-证书)   |
| `IM_APP_KEY` | 环信项目的 App Key | [获取 App Key](/zh-CN/solutions/one-to-one-live/custom-signaling/get-started/enable-service#开通第三方信令服务) |

## 编译并运行示例项目

按照如下步骤进行操作：

:::warning[注意]
声网自定义信令方案的 1v1 私密房和秀场转 1v1 示例项目基于 CallAPI 和三方信令服务共同开发。运行前请确保你的项目已[开通三方信令服务权限](/zh-CN/solutions/one-to-one-live/custom-signaling/get-started/enable-service#开通第三方信令服务)。
:::

1. 开启 Android 设备的开发者选项，打开 USB 调试，通过 USB 连接线将 Android 设备接入电脑。

2. 用 **Android Studio** 打开 `/CallAPI/Android` 文件夹。

3. 在 **Android Studio** 中，点击 **Sync Project with Gradle Files** 按钮，以让项目与 Gradle 文件同步。

4. 待同步成功后，点击 `Run 'app'`。片刻后，**CallAPI** 应用便会安装到你的 Android 设备上。

5. 打开应用，点击 **1v1 私密房**或**秀场转 1v1 私密房**，即可进行体验。

   :::warning[注意]
   你需要在两个客户端都打开应用，且都选择 **1v1 私密房**或**秀场转 1v1 私密房**才能进行互动体验。
   :::
