## 功能和场景

声网灵隼支持以下功能和场景。

### 一站式开发模式

提供基于乐鑫 ESP32 S3 的低功耗门铃场景一站式开发 (Turnkey) 方案，支持二次开发。

### 自主开发模式

通过设备端 SDK 和客户端示例项目提供包含产品管理和设备管理的核心能力，支持包括双向呼叫、音视频实时通话、云录云播、事件告警、远程控制、设备状态上报等能力集合。你可以通过管理平台定制产品物模型，并根据产品需要选择相应功能支持、自定义开发新产品方案。自主开发模式支持以下方案：

- 全功能方案：使用全功能版本设备端 SDK 和客户端示例项目。如果你没有自研的设备管理等模块，声网建议你使用全功能版本。
    - 设备端 SDK：包含呼叫、实时音视频、设备管理、连接认证、上下行消息收发等服务。
    - 客户端示例项目：用户注册/登录、绑定/解绑设备、Wi-Fi 二维码配网、呼叫、实时音视频等功能。
- 纯呼叫方案：使用纯呼叫版本设备端 SDK 和客户端示例项目。如果你已有自研的账号和设备管理等模块，声网建议你使用纯呼叫版本。
    - 设备端 SDK：包含呼叫、实时音视频等服务。
    - 客户端示例项目：呼叫、实时音视频等功能。

:::warning[注意]
- 全功能方案和纯呼叫方案的技术实现有较大差异，你需要根据自身的业务需求正确选择方案。否则，如果后续需要更换技术方案，可能带来较大的迁移成本。
- 小程序端仅支持纯呼叫方案。
:::

## 服务质量保障

在中国和美洲区域，声网灵隼默认保障 1 万台以内线上设备的服务质量。如果线上设备超过 1 万台，为保证正常使用声网灵隼服务，你需要提前 7 个工作日与 sales@shengwang.cn 联系，以便声网安排运维资源并提供全程保障服务。

在欧洲、亚洲等其他区域，如果有使用声网灵隼的需求，联系 sales@shengwang.cn。
