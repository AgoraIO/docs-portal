## 前提条件

- 开通声网灵隼服务并创建一个产品。参考[开通声网灵隼服务](/zh-CN/solutions/iot-apaas/build/setup-and-access/enable-service)。
- 联系 sales@shengwang.cn 开通告警事件云存储服务的权限。

## 实现云存储服务

### 购买并支付云存储套餐

当你使用声网云存储服务时，声网会收取费用，而你可以自行选择是否向终端用户收取费用。

如果你无需向终端用户收取费用，可略过本章节直接查看[服务端授权并查询云存储套餐](#restful)章节。

如果你向终端用户收取费用，你需要自行实现相关功能。参考流程如下：

1. 在客户端设计一个云存储套餐的购买界面。
2. 终端用户在客户端选择套餐类型。
3. 终端用户购买套餐并支付费用。
4. 为终端用户开通云存储权限。

<a id="restful"></a>
### 服务端授权并查询云存储套餐

在服务端调用 [RESTful API](/zh-CN/solutions/iot-apaas/reference/restful) 来授权声网灵隼 Token、开通和查询云存储套餐。
