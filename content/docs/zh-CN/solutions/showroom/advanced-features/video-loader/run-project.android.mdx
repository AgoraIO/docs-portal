## 前提条件

开始前，请确保满足以下前提条件：

- [Git](https://git-scm.com/downloads)
- [Java Development Kit](https://www.oracle.com/java/technologies/javase-downloads.html) 11
- [Android Studio](https://developer.android.com/studio/) 3.5 及以上
- [开通服务](/zh-CN/solutions/showroom/get-started/enable-service)
- Android 手机，版本 Android 5.0（API Level 21）及以上
    :::warning[注意]
    声网推荐使用真机运行项目。部分模拟机可能存在功能缺失或者性能问题。
    :::

## 克隆仓库

运行以下命令克隆仓库到本地：

```shell
git clone git@github.com:AgoraIO-Community/VideoLoaderAPI.git
```

## 配置示例项目

运行 `VideoLoaderAPI` 项目前，你需要在 `gradle.properties` 文件中设置如下参数：

```kotlin
AGORA_APP_ID=
AGORA_APP_CERTIFICATE=
CLOUD_PLAYER_KEY=
CLOUD_PLAYER_SECRET=
```

你可以在[创建声网项目](/zh-CN/solutions/showroom/get-started/enable-service#创建声网项目)后，从控制台获取这些参数的值，详情如下：

| 参数 | 描述   | 获取方式 |
|----|----|----|
| `AGORA_APP_ID`    | 声网项目的 App ID     | [获取 App ID](/zh-CN/solutions/showroom/get-started/enable-service#获取-app-id)  |
| `AGORA_APP_CERTIFICATE` | 声网项目的 App 证书 |[获取 App 证书](/zh-CN/solutions/showroom/get-started/enable-service#获取-app-证书)   |
| `CLOUD_PLAYER_KEY` | 声网输入在线媒体流 RESTful 服务所需的客户 ID       | [获取客户 ID 和密钥](/zh-CN/solutions/showroom/get-started/enable-service#获取客户-id-和客户密钥)    |
| `CLOUD_PLAYER_SECRET` | 声网输入在线媒体流 RESTful 服务所需的客户密钥   | [获取客户 ID 和密钥](/zh-CN/solutions/showroom/get-started/enable-service#获取客户-id-和客户密钥)   |

## 编译并运行示例项目

按照如下步骤进行操作：

1. 开启 Android 设备的开发者选项，打开 USB 调试，通过 USB 连接线将 Android 设备接入电脑。

2. 用 Android Studio 打开 `VideoLoaderAPI/Android` 文件夹。

3. 在 Android Studio 中，点击 **Sync Project with Gradle Files** 按钮，以让项目与 Gradle 文件同步。

4. 待同步成功后，点击 `Run 'app'`。片刻后，**秒开秒切**应用便会安装到你的 Android 设备上。

5. 打开应用，点击任意一个房间，即可进入房间并体验秒开。在房间内，上下滑动，即可切换房间并体验秒切。
