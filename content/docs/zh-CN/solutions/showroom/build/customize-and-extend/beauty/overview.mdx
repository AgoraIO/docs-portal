实时音视频互动中，美颜功能可以让用户展现更好的精神面貌，并提供有趣的贴纸特效。

声网与第三方厂商合作，开发了声网美颜场景化 API，使开发者能够方便地集成美颜功能。声网美颜场景化 API，也称为 Beauty API，封装了声网 RTC SDK 和第三方美颜 SDK 的 API 调用逻辑，开发者只需几行代码就能在声网的实时音视频互动中使用第三方提供的丰富美颜功能。

## 获取资源
