本页介绍showroom中高频调用的实时互动 RTC API。

| API | 描述 |
| --- | --- |
| [create](/api-ref/rtc/android/API/toc_initialize#create%20[2/2]) | 创建并初始化 `RtcEngine`。 |
| [registerVideoFrameObserver](/api-ref/rtc/android/API/toc_video_raw#registerVideoFrameObserver) | 注册原始视频数据观测器。 |
| [enableVideo](/api-ref/rtc/android/API/toc_video_basic#enableVideo) | 开启视频。 |
| [joinChannelEx](/api-ref/rtc/android/API/toc_channel#joinChannelEx) | 加入频道。 |
| [setupLocalVideo](/api-ref/rtc/android/API/toc_video_rendering#setupLocalVideo) | 设置并渲染本地视图。 |
| [setupRemoteVideoEx](/api-ref/rtc/android/API/toc_video_rendering#setupRemoteVideoEx) | 设置并渲染远端视图。 |
| [setVideoEncoderConfiguration](/api-ref/rtc//API/toc_video_basic#api_irtcengine_setvideoencoderconfiguration) | 设置视频编码分辨率、帧率、码率等。 |
| [updateChannelMediaOptionsEx](/api-ref/rtc/android/API/toc_channel#updateChannelMediaOptionsEx) | 更新频道媒体选项。 |
| [leaveChannelEx](/api-ref/rtc/android/API/toc_channel#leaveChannelEx%20[1/2]) | 离开频道。 |
| [destroy](/api-ref/rtc/android/API/toc_initialize#destroy) | 销毁 `RtcEngine`。 |
