你可以使用声网教育特殊版 SDK、RTM SDK 和互动白板 SDK 共同搭建在线美术教学场景。

本页提供你在搭建过程中可以使用的开发资源。

| SDK 或服务 | 下载链接 |
| --- | --- |
| RTC 教育特殊版 SDK | [联系技术支持](https://ticket.shengwang.cn)获取 SDK 下载链接 |
| 实时消息 SDK | 前往[实时消息 SDK 下载](/zh-CN/api-reference/sdks?product=signaling)页面获取所需平台的 SDK。 |
| 互动白板 SDK | 前往[互动白板资源获取](/zh-CN/api-reference/sdks?product=whiteboard)页面获取白板下载源码 |
| 云端录制 | 云端录制通过 RESTful API 提供服务。点击[云端录制 RESTful API 文档](/zh-CN/api-reference/api-ref/cloud-recording/acquire)了解接口及使用详情 |
