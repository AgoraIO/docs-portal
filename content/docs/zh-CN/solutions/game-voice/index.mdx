---
title: 游戏语音概览
---
游戏语音是声网专门针对游戏行业推出的一站式游戏内置语音解决方案，针对游戏场景提供实时语音互动、语音录制、语音内容安全审核等服务。该解决方案支持手游、端游、页游，且支持这些游戏的多平台互通。适用于实现 FPS（第一人称射击游戏）、MOBA（多人在线战术竞技游戏）、MMORPG（大型多人在线角色扮演游戏）、社交元宇宙等游戏场景的语音功能。

## 功能列表

游戏语音支持的功能如下：

| 功能         | 说明         |
| ------------ | ----------------------------------------- |
| 实时音频互动     | 在游戏内实现多人实时音频互动。支持小队语音、开黑语音、范围音频、空间音频等多种功能。          |
| 云端音频录制     | 支持将音频通话的内容录制储存下来，提供给更多的人在方便的时间观看，或者提交音频内容审核使用。音频录制需要单独采购方可使用，详细功能介绍和计费说明见[云端录制](/zh-CN/realtime-media/recording/cloud-recording)、[本地服务端录制](/zh-CN/realtime-media/recording/local-server-recording)。 |
| 内容安全审核 | 支持将游戏内的音频、文字、图片进行审核，过滤黄、暴、政等敏感和不良信息。内容安全审核需要单独采购声网云市场的三方插件，你可以访问声网云市场查看。 |

## 适用场景

游戏语音提供的特色功能让你可以在如下诸多场景中使用：

| 游戏语音特色功能 | 代表游戏 | 场景玩法 |
| --- | --- | --- |
| 低功耗语音 | Moba、FPS、大逃杀吃鸡等对战类游戏 | 在 5V5、3V3 红蓝组队对抗的对战游戏中，团战时语音沟通频次剧增。玩家对网络抖动和帧率非常敏感，因此这类游戏对功耗要求极高，需要降低 CPU 和内存消耗，以确保游戏延迟和帧率不受影响。声网游戏语音解决方案通过采样、传输、编解码等多个方面的算法优化，达到在保证音质的同时减轻客户端的硬件负担。此外，还针对各种手游机型进行充分适配。 |
| 小队语音、开黑语音 | 市面上大部分游戏 | <Slot name="product-overview-html-0-2-2" /> |
| 空间音频、范围音频（基础版） | FPS、大逃杀吃鸡、元宇宙、派对游戏 | 在 3D 游戏或追求音效立体感的游戏中，空间音频和范围音频技术使玩家能够分辨声音的方向和距离，当声音距离超过一定范围时，声音会逐渐衰减直至消失。声网游戏语音 SDK 内置空间音频和范围音频功能，可通过信令系统同步游戏内玩家坐标，并在用户本地实时计算其他玩家在 3D 空间中的声源坐标和距离，实现听声辨位和范围衰减等功能。详见[使用 SDK 实现空间音频](/zh-CN/solutions/game-voice/build/customize-and-extend/spatial-audio-sdk)。 |
| 空间音频、范围音频（高阶版） | FPS、大逃杀吃鸡、元宇宙、派对游戏 | <Slot name="product-overview-html-0-4-2" /> |

<Slot for="product-overview-html-0-2-2">

以 Moba 游戏为例，游戏里有不同的语音沟通方式：

    - 小队语音：通过随机匹配组成的 5 人小队，队员可以自由地进行内部语音交流。
    - 开黑语音：私密通话，只有好友或 CP 组成的开黑队伍成员可以听到。

    此外，还可以自由切换小队语音和开黑语音。例如，玩家 A 和 B 组成开黑队伍，然后与随机匹配的其他三名玩家组成一个 5 人小队。当 A 处于开黑语音模式时，只有 A 和 B 可以听到 A 的声音。但当 A 切换到小队语音模式时，整个小队玩家都能听到 A 的声音。

</Slot>

<Slot for="product-overview-html-0-4-2">

大型 3D 游戏需要处理复杂的音效。如果你的游戏工作室有 Wwise 工程师，你可以考虑使用声网 Wwise 插件方案实现，详见[使用 Wwise 插件实现空间音频](/zh-CN/solutions/game-voice/build/customize-and-extend/spatial-audio-wwise)。

    Wwise 插件方案有如下优势：

    - 统一管理和设计游戏语音和背景音乐。
    - 解决游戏中的开麦音质和音量跳变问题。
    - 提供高级的空间音频和范围音频效果。
    - 模拟语音的物理衍射、反射和音障等效果。
    - 提供更多音效和语音玩法。

</Slot>
