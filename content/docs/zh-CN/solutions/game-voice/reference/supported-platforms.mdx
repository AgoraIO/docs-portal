游戏语音解决方案提供的 SDK 支持多种平台，并保障平台间互通，详见下表：

| 平台 | 支持版本 |
| --- | --- |
| Unity | <Slot name="supported-platforms-html-0-0-1" /> |
| Unreal Engine (C++/Blueprint) | <Slot name="supported-platforms-html-0-1-1" /> |

<Slot for="supported-platforms-html-0-0-1">

≥ 2017

Unity SDK 支持如下平台：

- Android（armeabi-v7a、arm64-v8a、x86）
- iOS
- Windows（x86、x86-64）
- macOS

</Slot>

<Slot for="supported-platforms-html-0-1-1">

≥ 4.27

Unreal SDK 支持如下平台：

- Android（armeabi-v7a、arm64-v8a、x86）
- iOS
- Windows（x86、x86-64）
- macOS

</Slot>
