## 下载 SDK

本文介绍游戏语音解决方案提供的可下载 SDK、示例项目。

游戏语音解决方案使用实时互动产品的音频 SDK。请参考[实时互动下载](/zh-CN/reference/sdks?product=voice)文档获取 SDK。

:::info[信息]
- 当你[创建游戏语音项目](/zh-CN/solutions/game-voice/build/setup-and-access/enable-service#创建游戏语音项目)后，SDK 会针对游戏场景进行差异化的功能适配。

- 如果你的游戏场景较特殊，例如除了语音外，还需要进行视频直播或其他类型的视频互动，那么[联系技术支持](https://ticket.shengwang.cn/)获取专门的 SDK。
:::
