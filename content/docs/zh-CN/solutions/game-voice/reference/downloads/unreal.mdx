## 下载 SDK

游戏语音解决方案使用实时互动产品的音频 SDK。请参考 [Unreal 音频 SDK 下载](/zh-CN/reference/sdks?product=voice&platform=unreal-engine)获取 SDK。

:::info[信息]
接入前，请参考[接入准备](/zh-CN/solutions/game-voice/build/enable-service#创建游戏语音项目)创建声网项目并获取 App ID。

如果你的游戏场景较特殊，例如除了语音外，还需要进行视频直播或其他类型的视频互动，那么[联系技术支持](https://ticket.shengwang.cn/)获取专门的 SDK。
:::
