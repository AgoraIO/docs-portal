title: "资源获取"
---
你可以使用声网教育特殊版 SDK、RTM SDK 和互动白板 SDK 共同搭建在线音乐教学场景。本页提供你在搭建过程中可以使用的开发资源。

| SDK 或服务 | 下载链接 |
| --- | --- |
| RTC 教育特殊版 SDK | [联系技术支持](https://ticket.shengwang.cn)获取 SDK 下载链接 |
| 实时消息 SDK | 前往[实时消息 SDK 下载](https://docportal.shengwang.cn/cn/Real-time-Messaging/downloads?platform=All%20Platforms)获取你需要平台的 SDK（仅支持 RTM 1.x） |
| 互动白板 SDK | 前往[互动白板资源获取](/doc/whiteboard//whiteboard-sdk/resources-wb)页面获取白板下载源码 |
| 云端录制 | 云端录制通过 RESTful API 提供服务。点击[云端录制 RESTful API 文档](/doc/cloud-recording/restful/cloud-recording/operations/post-v1-apps-appid-cloud_recording-acquire)了解接口及使用详情 |
