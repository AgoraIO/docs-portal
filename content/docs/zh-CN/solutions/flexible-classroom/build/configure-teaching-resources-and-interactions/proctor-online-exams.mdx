在线监考指在线上考试中通过网络摄像头、麦克风和共享考生屏幕的方式在线监督考生的行为。灵动课堂提供 Proctor SDK 帮助用户实现在线监考。声网推荐的在线监考场景为 1 个考官同时监考 25 到 50 个考生。你可以通过灵动课堂 Demo 体验在线监考功能。

## 应用场景

- 学校专业考试
- 证书考试
- 企业招聘

## 前提条件

使用在线监考功能前，请确认你的本地环境满足如下要求：

| 角色 | 使用前提 |
| --- | --- |
| 考生 | <Slot name="proctor-online-exams-android-ios-javascript-electron-markdown-0-1-1" /> |
| 考官 | <Slot name="proctor-online-exams-android-ios-javascript-electron-markdown-0-2-1" /> |

<Slot for="proctor-online-exams-android-ios-javascript-electron-markdown-0-1-1">

- 合适的考试设备（台式电脑/笔记本电脑/平板电脑/移动设备）
- 网络连接：PC 端需要同时发送屏幕共享 1080p 及视频窗口 240p，建议上行带宽 20M 以上
- 摄像头和麦克风
- Chrome 浏览器

</Slot>

## 功能介绍

在线监考支持的功能及面向的用户角色如下表所示：

| 功能                            | 面向角色 | 说明                            |
| :----------------------------- | :------- | :--------------------------- |
| 硬件设备检测                                                 | 考官，考生    | 麦克风、摄像头、扬声器检测           |
| 全员广播                                                     | 考官     | 老师对学生发起全体通话                                       |
| 屏幕分享                                                     | 考生     | 学生共享桌面，防止作弊。如考生在考试中关闭屏幕分享，将被停止考试。 |
| 主机位监控                                                   | 考生    | 台式机/笔记本摄像头监控                                      |
| 副机位监控                                                   | 考生    | 移动设备摄像头监控                                           |
| 监控视频墙                                                   | 考官      | 考官以视频墙的方式监控考生考试行为                           |
| 考生实时监控                                                 | 考官      | 实时监控考试主机位、副机位、屏幕画面                         |
| 考生录像回放                                                 | 考官      | 录制考试主机位、副机位、屏幕画面并进行回放                   |
| 考官/ AI 考试异常状况记录  | 考官   | 考官手动记录考试异常状况；AI 自动记录考试异常状况（需要你自己实现）         |
| 在线考题                                                     | 考生      | 支持房间内集成预设的考题                                     |

## 使用步骤

以下内容以灵动课堂的 Demo 为例，说明考官与考生如何使用在线监考功能。

### 考官角色使用

1. 打开[灵动课堂 Web 端 Demo](/zh-CN/solutions/flexible-classroom/reference/downloads)，在首页点击**创建课堂**。

![创建在线监考课堂截图](https://web-cdn.agora.io/docs-files/1670575908165)

2. 输入课堂房间名称，课堂开始时间和结束时间，在课堂模式中选择**在线监考**，点击**创建**。

![填写在线监考课堂信息截图](https://web-cdn.agora.io/docs-files/1670575988038)

   至此，你成功创建了一个监考场景下的灵动课堂。

   :::info[信息]
   在灵动课堂 Demo 中，默认房间创建者为考官角色。
   :::

3. 进入考场前需要进行设备调试，确保你可以正常监控考场。

![考官设备调试页面截图](https://web-cdn.agora.io/docs-files/1670576023570)

   各设备调试项具体的作用如下：

   | 设备调试项 | 说明                               |
   | ---------- | ---------------------------------- |
   | 摄像头     | 对全体考生进行广播，传输考官视频。 |
   | 麦克风     | 对全体考生进行广播，传输考官语音。 |
   | 扬声器     | 监听考生考试环境的声音。           |

4. 进入考场后，到了考试时间会自动开始考试，也可以手动点击**开始考试**提前开始考试。
   考试期间你会看到所有考生的监控画面列表。

![考官监控画面列表截图](https://web-cdn.agora.io/docs-files/1670576052966)

   你可以进行以下操作：

   - 切换考生监控画面列表布局。

   - 向所有考生广播视频和语音。

![考官全员广播操作截图](https://web-cdn.agora.io/docs-files/1670830934291)

   - 点击单个考生的监控视图，进入监控明细页。在监控明细页，你可以看到录像视图和监控视图。

![考生监控明细页截图](https://web-cdn.agora.io/docs-files/1670576083982)

     - 监控视图显示考生的实时视频画面与屏幕分享画面。如考生有异常考试行为（作弊），可选择对应事件并提交。预设的异常事件包括多人入镜，小抄，身份验证，使用电子设备。此外，你也可以自定义更多异常事件。

     - 录像视图显示考生从考试开始时到当前时间的视频画面与屏幕分享的录像。你可以拖动时间轴跳转到特定时间，或点击已提交的异常事件跳转到该事件的时间点。

   - 筛选异常/关注考生监控画面。对于有作弊嫌疑但没有证据的考生，可在监控视图点击关注图标，以便在监控画面列表中进行筛选。

5. 考试时间结束时会自动结束考试，也可手动点击**结束考试**提前结束考试。

### 考生角色使用

1. 打开[灵动课堂 Web 端 Demo](/zh-CN/solutions/flexible-classroom/reference/downloads)，在首页点击**加入课堂**。

![考生加入课堂入口截图](https://web-cdn.agora.io/docs-files/1670576120315)

2. 输入课堂房间名称，在角色中选择**学生**，点击**加入**。

![考生加入考试页面截图](https://web-cdn.agora.io/docs-files/1670576139055)

   :::info[信息]
   在灵动课堂 Demo中，默认房间加入者为考生角色。
   :::

3. 进入考场前需要进行 3 项设备检测，全部通过后，点击**加入考试**。

![考生考前设备检测页面截图](https://web-cdn.agora.io/docs-files/1670576179942)

   各设备调试项具体的作用如下：

   | 设备检测项 | 说明 |
   | --- | --- |
   | 硬件检测 | <Slot name="proctor-online-exams-android-ios-javascript-electron-markdown-2-1-1" /> |
   | 人像拍照 | 核对考生身份 |
   | 屏幕共享 | 监控考生电脑屏幕 |

   <Slot for="proctor-online-exams-android-ios-javascript-electron-markdown-2-1-1">

   - 麦克风：监听考生周围环境音
   - 摄像头：监控考生考试环境画面
   - 扬声器：播放考官的广播声音

   </Slot>

4. 进入考场后，你会看到考卷，你的主机位视频画面，副机位视频画面和屏幕画面。当考官广播时你会看到考官的视频画面。

![考生考试中页面截图](https://web-cdn.agora.io/docs-files/1670576201406)

   :::info[信息]
   考卷会在考试开始时自动显示；考试结束时，如未提交，系统会自动提交。
   :::

5. 考试完成后，点击**离开考场**。

## 使用步骤

以下内容以灵动课堂的 Demo 为例，说明考官与考生如何使用在线监考功能。

### 考官角色使用

1. 打开[灵动课堂 Web 端 Demo](/zh-CN/solutions/flexible-classroom/reference/downloads)，在首页点击**创建课堂**。

![创建在线监考课堂截图](https://web-cdn.agora.io/docs-files/1670575908165)

2. 输入课堂房间名称，课堂开始时间和结束时间，在课堂模式中选择**在线监考**，点击**创建**。

![填写在线监考课堂信息截图](https://web-cdn.agora.io/docs-files/1670575988038)

   至此，你成功创建了一个监考场景下的灵动课堂。

   :::info[信息]
   在灵动课堂 Demo 中，默认房间创建者为考官角色。
   :::

3. 进入考场前需要进行设备调试，确保你可以正常监控考场。

![考官设备调试页面截图](https://web-cdn.agora.io/docs-files/1670576023570)

   各设备调试项具体的作用如下：

   | 设备调试项 | 说明                               |
   | ---------- | ---------------------------------- |
   | 摄像头     | 对全体考生进行广播，传输考官视频。 |
   | 麦克风     | 对全体考生进行广播，传输考官语音。 |
   | 扬声器     | 监听考生考试环境的声音。           |

4. 进入考场后，到了考试时间会自动开始考试，也可以手动点击**开始考试**提前开始考试。
   考试期间你会看到所有考生的监控画面列表。

![考官监控画面列表截图](https://web-cdn.agora.io/docs-files/1670576052966)

   你可以进行以下操作：

   - 切换考生监控画面列表布局。

   - 向所有考生广播视频和语音。

![考官全员广播操作截图](https://web-cdn.agora.io/docs-files/1670830934291)

   - 点击单个考生的监控视图，进入监控明细页。在监控明细页，你可以看到录像视图和监控视图。

![考生监控明细页截图](https://web-cdn.agora.io/docs-files/1670576083982)

     - 监控视图显示考生的实时视频画面与屏幕分享画面。如考生有异常考试行为（作弊），可选择对应事件并提交。预设的异常事件包括多人入镜，小抄，身份验证，使用电子设备。此外，你也可以自定义更多异常事件。

     - 录像视图显示考生从考试开始时到当前时间的视频画面与屏幕分享的录像。你可以拖动时间轴跳转到特定时间，或点击已提交的异常事件跳转到该事件的时间点。

   - 筛选异常/关注考生监控画面。对于有作弊嫌疑但没有证据的考生，可在监控视图点击关注图标，以便在监控画面列表中进行筛选。

5. 考试时间结束时会自动结束考试，也可手动点击**结束考试**提前结束考试。

### 考生角色使用

![考生加入课堂入口截图](https://web-cdn.agora.io/docs-files/1670576120315)

2. 输入课堂房间名称，在角色中选择**学生**，点击**加入**。

![考生加入考试页面截图](https://web-cdn.agora.io/docs-files/1670576139055)

   :::info[信息]
   在灵动课堂 Demo中，默认房间加入者为考生角色。
   :::

3. 进入考场前需要进行 3 项设备检测，全部通过后，点击**加入考试**。

![考生考前设备检测页面截图](https://web-cdn.agora.io/docs-files/1670576179942)

   各设备调试项具体的作用如下：

   | 设备检测项 | 说明 |
   | --- | --- |
   | 硬件检测 | <Slot name="proctor-online-exams-android-ios-javascript-electron-markdown-2-1-1" /> |
   | 人像拍照 | 核对考生身份 |
   | 屏幕共享 | 监控考生电脑屏幕 |

   <Slot for="proctor-online-exams-android-ios-javascript-electron-markdown-2-1-1">

   - 麦克风：监听考生周围环境音
   - 摄像头：监控考生考试环境画面
   - 扬声器：播放考官的广播声音

   </Slot>

4. 进入考场后，你会看到考卷，你的主机位视频画面，副机位视频画面和屏幕画面。当考官广播时你会看到考官的视频画面。

![考生考试中页面截图](https://web-cdn.agora.io/docs-files/1670576201406)

   :::info[信息]
   考卷会在考试开始时自动显示；考试结束时，如未提交，系统会自动提交。
   :::
