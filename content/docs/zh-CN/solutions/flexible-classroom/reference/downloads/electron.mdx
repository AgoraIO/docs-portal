## 通过 CDN 链接集成 SDK

如果直接使用灵动课堂的默认 UI，可以直接在项目的 HTML 文件中添加以下代码，集成 SDK。详细步骤参考[集成灵动课堂](/zh-CN/solutions/flexible-classroom/get-started/integrate)。

```html
<script src="https://download.agora.io/edu-apaas/release/edu_sdk@2.9.40.bundle.js"></script>
<script src="https://download.agora.io/edu-apaas/release/edu_widget@2.9.40.bundle.js"></script>
```

## 集成 GitHub 源码

如果你希望自定义课堂 UI，则可以通过下载或克隆 GitHub 源码进行集成。详细步骤参考[集成灵动课堂](/zh-CN/solutions/flexible-classroom/get-started/integrate)。

```shell
git clone https://github.com/AgoraIO-Community/flexible-classroom-desktop.git
```
