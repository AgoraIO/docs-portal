## 通过 npm 集成 SDK

如果你使用灵动课堂的默认 UI，声网推荐通过 npm 在项目中集成 SDK。不同模块说明和详细集成步骤参考集成灵动课堂 [Classroom SDK & Proctor SDK](/zh-CN/solutions/flexible-classroom/get-started/integrate) 或 [FcrUIScene](/zh-CN/solutions/flexible-classroom/get-started/integrate-new)。

```shell tab="集成教育模块" tabGroup="sdk-types"
npm install agora-classroom-sdk agora-plugin-gallery
```

```shell tab="集成监考模块" tabGroup="sdk-types"
npm install agora-proctor-sdk agora-plugin-gallery
```

```shell tab="集成云课堂模块" tabGroup="sdk-types"
npm install fcr-ui-scene agora-plugin-gallery
```

## 通过 CDN 链接集成 SDK

如果直接使用灵动课堂的默认 UI，还可以通过直接在项目的 HTML 文件中添加 CDN 链接，集成 SDK。不同模块介绍和详细集成步骤参考集成灵动课堂 [Classroom SDK & Proctor SDK](/zh-CN/solutions/flexible-classroom/get-started/integrate) 或 [FcrUIScene](/zh-CN/solutions/flexible-classroom/get-started/integrate-new)。

```html tab="集成教育模块" tabGroup="sdk-types"
<script src="https://download.agora.io/edu-apaas/release/edu_sdk@2.9.40.bundle.js"></script>
<script src="https://download.agora.io/edu-apaas/release/edu_widget@2.9.40.bundle.js"></script>
```

```html tab="集成监考模块" tabGroup="sdk-types"
<script src="https://download.agora.io/edu-apaas/release/proctor_sdk@1.0.40.bundle.js"></script>
<script src="https://download.agora.io/edu-apaas/release/proctor_widget@1.0.40.bundle.js"></script>
```

```html tab="集成云课堂模块" tabGroup="sdk-types"
<script src="https://download.agora.io/edu-apaas/release/scene_sdk@1.0.40.bundle.js"></script>
<script src="https://download.agora.io/edu-apaas/release/scene_widget@1.0.40.bundle.js"></script>
```

git clone https://github.com/AgoraIO-Community/flexible-classroom-desktop.git
