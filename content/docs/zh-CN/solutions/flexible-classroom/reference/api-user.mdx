## 查询指定用户

接口原型：

-   方法：GET
-   接入点：`/{region}/edu/apps/{appId}/v2/rooms/{roomUuid}/users/{userUuid}`

### 请求参数

#### URL 参数

| 参数 | 类型 | 是否必填 | 描述 |
| --- | --- | --- | --- |
| `region` | String | 必填 | <Slot name="api-user-restful-html-0-1-3" /> |
| `appId` | String | 必填 | 你在声网控制台创建的项目的 App ID，详见[获取 App ID](/zh-CN/solutions/flexible-classroom/build/setup-and-access/enable#获取-app-id)。 |
| `roomUuid` | String | 必填 | 课堂 UUID。这是课堂的唯一标识符，也是加入 RTC 和 RTM 时所使用的频道名。长度在 64 字符以内。若该课堂需要使用页面录制，长度需在 50 字符内。 |
| `userUuid` | String | 必填 | 用户 UUID。这是用户的唯一标识符，也是登录 RTM 系统时所使用的用户 ID。长度在 64 字符以内。 |

<Slot for="api-user-restful-html-0-1-3">

服务区域，可设为如下值：

- `cn`：中国大陆
- `ap`：亚太
- `na`：北美
- `eu`：欧洲

:::warning[注意]
对于同一课堂，服务端接口调用的区域需要与客户端课堂创建的区域一致，否则会报告“房间不存在”的错误。
:::

</Slot>

### 请求示例

```shell
curl -X GET 'https://api.sd-rtn.com/{region}/edu/apps/{yourAppId}/v2/rooms/test_class/users/test_user' \
-H 'Authorization: agora token={educationToken}' 
```

### 响应参数

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| `code` | Integer | <Slot name="api-user-restful-html-1-1-2" /> |
| `msg` | String | 接口响应的文字信息。 |
| `ts` | Number | 当前服务端的 Unix 时间戳，UTC 时间，单位为毫秒。 |
| `data` | Object | <Slot name="api-user-restful-html-1-4-2" /> |

<Slot for="api-user-restful-html-1-1-2">

响应状态码：

- `0`: 请求成功。
- 非 `0`: 请求失败。详见[响应状态码](/zh-CN/solutions/flexible-classroom/reference/response-code)。

</Slot>

<Slot for="api-user-restful-html-1-4-2">

返回数据，包含以下字段：

      - `userUuid`: 用户 ID。
      - `userName`: 用户名称。
      - `role`: 用户角色：

        - `1`: 老师
        - `2`: 学生
        - `3`: 助教

      - `streamUuid`: 流 ID。
      - `state`: 该用户是否在线：

        - `0`：不在线
        - `1`：在线

      - `userProperties`: 用户属性。
      - `updateTime`: 更新时间。

</Slot>

### 响应示例

```json
{
  "msg": "Success",
  "code": 0,
  "ts": 1658126805245,
  "data": {
    "userName": "jasoncai",
    "userUuid": "681d9aca4924e9a84ad301e8cca438a71",
    "role": "1",
    "userProperties": {},
    "updateTime": 1658126782174,
    "streamUuid": "1417753684",
    "state": 1
  }
}
```

## 更新用户自定义属性

-   方法：PUT
-   接入点：`/{region}/edu/apps/{appId}/v2/rooms/{roomUuid}/users/{userUuid}/properties`

#### URL 参数

| 参数 | 类型 | 是否必填 | 描述 |
| --- | --- | --- | --- |
| `region` | String | 必填 | <Slot name="api-user-restful-html-2-1-3" /> |
| `appId` | String | 必填 | 你在声网控制台创建的项目的 App ID，详见[获取 App ID](/zh-CN/solutions/flexible-classroom/build/setup-and-access/enable#获取-app-id)。 |
| `roomUuid` | String | 必填 | 课堂 UUID。这是课堂的唯一标识符，也是加入 RTC 和 RTM 时所使用的频道名。长度在 64 字符以内。若该课堂需要使用页面录制，长度需在 50 字符内。 |
| `userUuid` | String | 必填 | 用户 UUID。这是用户的唯一标识符，也是登录 RTM 系统时所使用的用户 ID。长度在 64 字符以内。 |

<Slot for="api-user-restful-html-2-1-3">

服务区域，可设为如下值：

- `cn`：中国大陆
- `ap`：亚太
- `na`：北美
- `eu`：欧洲

:::warning[注意]
对于同一课堂，服务端接口调用的区域需要与客户端课堂创建的区域一致，否则会报告“房间不存在”的错误。
:::

</Slot>

#### 请求包体参数

| 参数         | 类型   | 是否必填 | 描述           |
| :----------- | :----- |:-----|:-------------|

<Slot for="api-user-restful-html-3-1-2">

响应状态码：

- `0`: 请求成功。
- 非 `0`: 请求失败。详见[响应状态码](/zh-CN/solutions/flexible-classroom/reference/response-code)。

## 踢人

将指定用户从课堂中踢出。成功调用此接口后，服务端会触发一个用户进出课堂事件。你可通过该接口的 `dirty` 参数设置该用户后续是否还能再加入课堂。

接口原型：

-   方法：POST
-   接入点：`/{region}/edu/apps/{appId}/v2/rooms/{roomUuid}/users/{userUuid}/exit`

### 请求参数

#### URL 参数

| 参数 | 类型 | 是否必填 | 描述 |
| --- | --- | --- | --- |
| `region` | String | 必填 | <Slot name="api-user-restful-html-6-1-3" /> |
| `appId` | String | 必填 | 你在声网控制台创建的项目的 App ID，详见[获取 App ID](/zh-CN/solutions/flexible-classroom/build/setup-and-access/enable#获取-app-id)。 |
| `roomUuid` | String | 必填 | 课堂 UUID。这是课堂的唯一标识符，也是加入 RTC 和 RTM 时所使用的频道名。长度在 64 字符以内。若该课堂需要使用页面录制，长度需在 50 字符内。 |
| `userUuid` | String | 必填 | 用户 UUID。这是用户的唯一标识符，也是登录 RTM 系统时所使用的用户 ID。长度在 64 字符以内。 |

<Slot for="api-user-restful-html-6-1-3">

服务区域，可设为如下值：

- `cn`：中国大陆
- `ap`：亚太
- `na`：北美
- `eu`：欧洲

:::warning[注意]
对于同一课堂，服务端接口调用的区域需要与客户端课堂创建的区域一致，否则会报告“房间不存在”的错误。
:::

</Slot>

#### 请求包体参数

| 参数 | 类型 | 是否必填 | 描述 |
| --- | --- | --- | --- |
| `dirty` | Object | 非必填 | <Slot name="api-user-restful-html-7-1-3" /> |

<Slot for="api-user-restful-html-7-1-3">

用户踢人标记，包含以下字段：

      - `state`: Integer 型，踢人状态：
        - `1`: 被踢，无法进入课堂。
        - `0`: 未被踢，可以进入课堂。
      - `duration`: Number 型，临时踢人持续时间，单位为秒。该字段仅在 `state` 为 `1` 时生效。从被踢出时开始计时，过了 `duration` 设置的时长后，用户自动恢复为未被踢状态。若不传该参数，则用户被永久踢出。

</Slot>

### 请求示例

```shell
curl -X POST 'https://api.sd-rtn.com/{region}/edu/apps/{yourAppId}/v2/rooms/test_class/users/test_user/exit' \
-H 'Content-Type: application/json;charset=UTF-8' \
-H 'Authorization: agora token={educationToken}' \
--data-raw '{
  "dirty": {
    "state": 1,
    "duration": 600
  }
}'
```

### 响应参数

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| `code` | Integer | <Slot name="api-user-restful-html-8-1-2" /> |

| `ts` | Number | 当前服务端的 Unix 时间戳，UTC 时间，单位为毫秒。 |

<Slot for="api-user-restful-html-8-1-2">

响应状态码：

- 非 `0`: 请求失败。详见[响应状态码](/zh-CN/solutions/flexible-classroom/reference/response-code)。

### 响应示例

```json
{
  "msg": "Success",
  "code": 0,
  "ts": 1610167740309
}
```
