## 查询指定类型事件

查询指定课堂内指定类型的事件。

你可以通过 `nextId` 分批查询，每批最多查询 100 条数据。

:::info[信息]
- 同一事件可重复查询。
- 仅能查询未销毁课堂内的事件。默认情况下，课堂会在结束后一小时销毁。
:::

接口原型：

-   方法：GET
-   接入点：`/{region}/edu/apps/{appId}/v2/rooms/{roomUuid}/sequences`

### 请求参数

#### URL 参数

| 参数 | 类型 | 是否必填 | 描述 |
| --- | --- | --- | --- |
| `region` | String | 必填 | <Slot name="api-sync-restful-html-0-1-3" /> |
| `appId` | String | 必填 | 你在声网控制台创建的项目的 App ID，详见[获取 App ID](/zh-CN/solutions/flexible-classroom/get-started/enable#获取-app-id)。 |
| `roomUuid` | String | 必填 | 课堂 UUID。这是课堂的唯一标识符，也是加入 RTC 和 RTM 时所使用的频道名。长度在 64 字符以内。若该课堂需要使用页面录制，长度需在 50 字符内。 |

<Slot for="api-sync-restful-html-0-1-3">

服务区域，可设为如下值：

- `cn`：中国大陆
- `ap`：亚太
- `na`：北美
- `eu`：欧洲

:::warning[注意]
对于同一课堂，服务端接口调用的区域需要与客户端课堂创建的区域一致，否则会报告“房间不存在”的错误。
:::

</Slot>

#### Query 参数

| 参数       | 类型    | 是否必填 | 描述                                                |
|:---------| :------ |:-----|:--------------------------------------------------|
| `nextId` | String   | 非必填  | 下一批数据的起始 ID。第一次查询可传 null，后续查询传入响应结果里得到的 `nextId` 的值。 |
| `cmd`    | Integer | 非必填  | 事件类型，详见[事件枚举](#事件枚举)。 |

### 请求示例

```shell
curl -X GET 'https://api.sd-rtn.com/{region}/edu/apps/{yourAppId}/v2/rooms/test_class/sequences?cmd=20' \
-H 'Authorization: agora token={educationToken}'
```

### 响应参数

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| `code` | Integer | <Slot name="api-sync-restful-html-1-1-2" /> |
| `msg` | String | 接口响应的文字信息。 |
| `ts` | Number | 当前服务端的 Unix 时间戳，UTC 时间，单位为毫秒。 |
| `data` | Object | <Slot name="api-sync-restful-html-1-4-2" /> |

<Slot for="api-sync-restful-html-1-1-2">

响应状态码：

- `0`: 请求成功。
- 非 `0`: 请求失败。详见[响应状态码](/zh-CN/solutions/flexible-classroom/response-code.restful)。

</Slot>

<Slot for="api-sync-restful-html-1-4-2">

返回数据，包含以下字段：

      - `count`: Integer 型，本批数据条数。
      - `list`: 由多个 Object 组成的数组。每个 Object 包含以下字段：

        - `roomUuid`: String 型，课堂 uuid。
        - `cmd`: Integer 型，事件类型。详见[事件枚举](#事件枚举)。
        - `sequence`: Integer 型，事件序号，是每个课堂内事件的唯一标识符，课堂内全局自增，用于确保事件的有序性。
        - `version`: Integer 型，版本号。
        - `data`: Object 型，事件的具体数据，不同事件类型返回不同数据。详见[事件枚举](#事件枚举)。

      - `nextId`: String 型，下一批数据的起始 ID。如为 null，则表示没有下一批数据。如不为 null，则可用此 `nextId` 继续查询，直到查到 null 为止。

</Slot>

### 响应示例

```json
{
  "msg": "Success",
  "code": 0,
  "ts": 1610433913533,
  "data": {
    "total": 1,
    "list": [
      {
        "roomUuid": "",
        "cmd": 20,
        "sequence": 1,
        "version": 1,
        "data": {}
      }
    ],
    "nextId": null,
    "count": 1
  }
}
```

## 查询指定 Widget 事件

查询指定课堂内指定 Widget 的相关事件。

你可以通过 `nextId` 分批查询，每批最多查询 100 条数据。

:::info[信息]
- 同一事件可重复查询。
- 仅能查询未销毁课堂内的事件。默认情况下，课堂会在结束后一小时销毁。
:::

接口原型：

-   方法：GET
-   接入点：`/{region}/edu/apps/{appId}/v2/rooms/{roomUuid}/widgets/{widgetUuid}/sequences`

### 请求参数

#### URL 参数

| 参数 | 类型 | 是否必填 | 描述 |
| --- | --- | --- | --- |
| `region` | String | 必填 | <Slot name="api-sync-restful-html-2-1-3" /> |
| `appId` | String | 必填 | 你在声网控制台创建的项目的 App ID，详见[获取 App ID](/zh-CN/solutions/flexible-classroom/get-started/enable#获取-app-id)。 |
| `roomUuid` | String | 必填 | 课堂 UUID。这是课堂的唯一标识符，也是加入 RTC 和 RTM 时所使用的频道名。长度在 64 字符以内。若该课堂需要使用页面录制，长度需在 50 字符内。 |
| `widgetUuid` | String | 必填 | <Slot name="api-sync-restful-html-2-4-3" /> |

<Slot for="api-sync-restful-html-2-1-3">

服务区域，可设为如下值：

- `cn`：中国大陆
- `ap`：亚太
- `na`：北美
- `eu`：欧洲

:::warning[注意]
对于同一课堂，服务端接口调用的区域需要与客户端课堂创建的区域一致，否则会报告“房间不存在”的错误。
:::

</Slot>

<Slot for="api-sync-restful-html-2-4-3">

Widget uuid。长度在 64 字符以内。 以下为支持的字符集范围（共 89 个字符）:

- 26 个小写英文字母 a-Z
- 26 个大写英文字母 A-Z
- 10 个数字 0-9
- 空格
- `!`, `#`, `$`, `%`, `&`, `(`, `)`, `+`, `-`, `:`, `;`, `<`, `=`, `.`, `>`, `?`, `@`, `[`, `]`, `^`, `_`, `{`, `}`, `|`, `~`, `,`

</Slot>

#### Query 参数

| 参数     | 类型    |  是否必填 | 描述                                                         |
| :------- | :------ | :-----|:----------------------------------------------------------- |
| `nextId` | String  | 非必填   | 下一批数据的起始 ID。第一次查询可传 null，后续查询传入响应结果里得到的 `nextId` 的值。 |

### 请求示例

```shell
curl -X GET 'https://api.sd-rtn.com/{region}/edu/apps/{yourAppId}/v2/rooms/test_class/widgets/test_widget/sequences' \
-H 'Authorization: agora token={educationToken}'
```

### 响应参数

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| `code` | Integer | <Slot name="api-sync-restful-html-3-1-2" /> |
| `msg` | String | 接口响应的文字信息。 |
| `ts` | Number | 当前服务端的 Unix 时间戳，UTC 时间，单位为毫秒。 |
| `data` | Object | <Slot name="api-sync-restful-html-3-4-2" /> |

<Slot for="api-sync-restful-html-3-1-2">

响应状态码：

- `0`: 请求成功。
- 非 `0`: 请求失败。详见[响应状态码](/zh-CN/solutions/flexible-classroom/response-code.restful)。

</Slot>

<Slot for="api-sync-restful-html-3-4-2">

返回数据，包含以下字段：

      - `count`: Integer 型，本批数据条数。
      - `list`: 由多个 Object 组成的数组。每个 Object 包含以下内容：

        - `roomUuid`: String 型，课堂 UUID。
        - `cmd`: Integer 型，事件类型，此处为 `1110`。
        - `sequence`: Integer 型。事件序号，是每个课堂内事件的唯一标识符，课堂内全局自增，用于确保事件的有序性。
        - `version`: Integer 型，版本号。
        - `data`: Object 型，事件的具体数据，包含以下字段：

          - `action`: Integer 型，属性操作类型：

            - `1`: 设置属性
            - `2`: 删除属性

        - `widgetUuid`: String 型，本次查询的 widget 的 uuid。
        - `changeProperties`: Object 型，本次变更的 widget 用户属性。

          - `position`: Object 型，本次变更的位置。
          - `size`: Object 型，本次变更的大小。
          - `extra`: Object 型，本次变更的 widget 房间属性。

        - `fromUser`: Object 型，更新属性的用户。当事件为更新 widget 用户属性事件时，该字段有值。包含以下字段：

          - `userUuid`: String 型，用户 UUID。
          - `userName`: String 型，用户名。
          - `role`: Integer 型，用户角色。

        - `operator`: Object 型，操作人，包含以下字段：

          - `userUuid`: String 型，用户 UUID。
          - `userName`: String 型，用户名。
          - `role`: Integer 型，用户角色。

      - `nextId`: String 型，下一批数据的起始 ID。如为 null，则表示没有下一批数据。如不为 null，则可用此 `nextId` 继续查询，直到查到 null 为止。

</Slot>

### 响应示例

```json
{
  "msg": "Success",
  "code": 0,
  "ts": 1610433913533,
  "data": {
    "total": 1,
```

## 事件枚举

### 课堂状态变更

`cmd` 为 `1` 时，该事件提示课堂状态发生变更，`data` 中包含以下字段：

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| `state` | Integer | <Slot name="api-sync-restful-html-14-1-2" /> |
| `startTime` | Number | 课堂开始时间，Unix 时间戳（毫秒），UTC 时间。当state=1时，此字段有值。 |
| `endTime` | Number | 课堂结束时间，Unix 时间戳（毫秒），UTC 时间。当state=2时，此字段有值。 |
| `closeTime` | Number | 课堂关闭时间，Unix 时间戳（毫秒），UTC 时间。当state=3时，此字段有值。 |

<Slot for="api-sync-restful-html-14-1-2">

      - `0`: 未开始。
      - `1`: 进行中。
