## 删除 Widget

删除指定 Widget。

灵动课堂会将这个变化同步到所有端，以此来实现你自己的扩展业务。

接口原型：

-   方法：DELETE
-   接入点：`/{region}/edu/apps/{appId}/v2/rooms/{roomUuid}/widgets/{widgetUuid}`

### 请求参数

#### URL 参数

| 参数 | 类型 | 是否必填 | 描述 |
| --- | --- | --- | --- |
| `region` | String | 必填 | <Slot name="api-widget-restful-html-0-1-3" /> |
| `appId` | String | 必填 | 你在声网控制台创建的项目的 App ID，详见[获取 App ID](/zh-CN/solutions/flexible-classroom/get-started/enable#获取-app-id)。 |
| `roomUuid` | String | 必填 | 课堂 UUID。这是课堂的唯一标识符，也是加入 RTC 和 RTM 时所使用的频道名。长度在 64 字符以内。若该课堂需要使用页面录制，长度需在 50 字符内。 |
| `widgetUuid` | String | 必填 | <Slot name="api-widget-restful-html-0-4-3" /> |

<Slot for="api-widget-restful-html-0-1-3">

服务区域，可设为如下值：

- `cn`：中国大陆
- `ap`：亚太
- `na`：北美
- `eu`：欧洲

:::warning[注意]
对于同一课堂，服务端接口调用的区域需要与客户端课堂创建的区域一致，否则会报告“房间不存在”的错误。
:::

</Slot>

<Slot for="api-widget-restful-html-0-4-3">

Widget uuid。长度在 64 字符以内。以下为支持的字符集范围（共 89 个字符）:

- 26 个小写英文字母 a-Z
- 26 个大写英文字母 A-Z
- 10 个数字 0-9
- 空格
- `!`, `#`, `$`, `%`, `&`, `(`, `)`, `+`, `-`, `:`, `;`, `<`, `=`, `.`, `>`, `?`, `@`, `[`, `]`, `^`, `_`, `{`, `}`, `|`, `~`, `,`

</Slot>

#### 请求包体参数

| 参数         | 类型       | 是否必填 | 描述            |
| :----------- |:---------|:-----|:--------------|
| `cause`      | Object   | 非必填  | 本次删除原因。       |

### 请求示例

```shell
curl -X DELETE 'https://api.sd-rtn.com/{region}/edu/apps/{yourAppId}/v2/rooms/test_class/widgets/test_widget' \
-H 'Content-Type: application/json;charset=UTF-8' \
-H 'Authorization: agora token={educationToken}' \
--data-raw '{
  "cause": {}
}'
```

### 响应参数

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| `code` | Integer | <Slot name="api-widget-restful-html-1-1-2" /> |
| `msg` | String | 接口响应的文字信息。 |
| `ts` | Number | 当前服务端的 Unix 时间戳，UTC 时间，单位为毫秒。 |

<Slot for="api-widget-restful-html-1-1-2">

响应状态码：

- `0`: 请求成功。
- 非 `0`: 请求失败。详见[响应状态码](/zh-CN/solutions/flexible-classroom/response-code.restful)。

</Slot>

### 响应示例

```json
{
  "msg": "Success",
  "code": 0,
  "ts": 1610167740309
}
```

| `roomUuid` | String | 必填 | 课堂 UUID。这是课堂的唯一标识符，也是加入 RTC 和 RTM 时所使用的频道名。长度在 64 字符以内。若该课堂需要使用页面录制，长度需在 50 字符内。 |
| `widgetUuid` | String | 必填 | <Slot name="api-widget-restful-html-2-4-3" /> |

<Slot for="api-widget-restful-html-2-1-3">

服务区域，可设为如下值：

- `cn`：中国大陆

</Slot>
