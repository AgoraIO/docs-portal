## 创建课堂

课堂创建后，默认保留 5 天。

接口原型：

-   方法：POST
-   接入点：`/{region}/edu/apps/{appId}/v2/rooms/{roomUuid}`

### 请求参数

#### URL 参数

| 参数 | 类型 | 是否必填 | 描述 |
| --- | --- | --- | --- |
| `region` | String | 必填 | <Slot name="api-classroom-restful-html-0-1-3" /> |
| `appId` | String | 必填 | 你在声网控制台创建的项目的 App ID，详见[获取 App ID](/zh-CN/solutions/flexible-classroom/get-started/enable#获取-app-id)。 |
| `roomUuid` | String | 必填 | 课堂 UUID。这是课堂的唯一标识符，也是加入 RTC 和 RTM 时所使用的频道名。长度在 64 字符以内。若该课堂需要使用页面录制，长度需在 50 字符内。 |

<Slot for="api-classroom-restful-html-0-1-3">

服务区域，可设为如下值：

- `cn`：中国大陆
- `ap`：亚太
- `na`：北美
- `eu`：欧洲

:::warning[注意]
对于同一课堂，服务端接口调用的区域需要与客户端课堂创建的区域一致，否则会报告“房间不存在”的错误。
:::

</Slot>

#### 创建云课堂房间

若要使用云课堂，需要先调用服务端接口创建房间，以下是创建云课堂房间的请求示例。

```shell
curl -X POST 'https://api.agora.io/{region}/edu/apps/{YourAppId}/v2/rooms/test_room' \
-H 'Content-Type: application/json;charset=UTF-8' \
-H 'Authorization: agora token={educationToken}' \
--data-raw '{
  "roomName": "test_class",  //(Required)
  "roomType": 4,  // (Required)
  "roleConfig": {  // (Required) The audio and video permissions of students joining the room are turned on or off by default.
    "2": {
      "limit": 50,
      "defaultStream": {
        "state": 1,
        "videoState": 1,
        "audioState": 1
      }
    }
  },
  "roomProperties": {
    "schedule": {
      "startTime": 1655452800000,
      "duration": 600,
      "closeDelay": 300
    },
    "flexProps": {  // (Optional) The user's backend can pass customized parameters to the room through this parameter.Users can set custom attributes for any classroom based on their own business needs. Flexible Classroom will synchronize changes in this attribute to all clients in the classroom to realize your own business expansion.
      "exampleKey": "exampleValue"
    },
    "widgets": {  // The state of the widgets in the classroom : on or off
      "netlessBoard": {  // (Required)
        "state": 0
      },
      "easemobIM": {
        "state": 1
      }
    }
  }
}'
```

## 设置课堂状态

- `0`: 未开始。
- `1`: 开始。
- `2`: 结束。课堂时间结束，但在拖堂时间内，用户可以加入课堂和在课堂内逗留。
- `3`: 关闭。拖堂时间结束，课堂关闭，所有用户被踢出并无法再进入。

详见[灵动课堂有哪些课堂状态？](/faq/integration-issues/class-states)

接口原型：

-   方法：PUT
-   接入点：`/{region}/edu/apps/{appId}/v2/rooms/{roomUuid}/states/{state}`

### 请求参数

#### URL 参数

| 参数 | 类型 | 是否必填 | 描述 |

| `roomUuid` | String | 必填 | 课堂 UUID。这是课堂的唯一标识符，也是加入 RTC 和 RTM 时所使用的频道名。长度在 64 字符以内。若该课堂需要使用页面录制，长度需在 50 字符内。 |
| `state` | Integer | 必填 | <Slot name="api-classroom-restful-html-5-4-3" /> |

<Slot for="api-classroom-restful-html-5-1-3">

</Slot>

## 删除课堂自定义属性

删除指定课堂的自定义属性。

你可以删除任意课堂自定义属性，灵动课堂会将这个属性的变更同步到所有端，以此来实现你自己的扩展业务。详见[如何设置自定义用户属性和课堂属性？](/faq/integration-issues/class-properties)

### 请求参数

#### URL 参数

| 参数 | 类型 | 是否必填 | 描述 |

| `roomUUid` | String | 必填 | 课堂 UUID。这是课堂的唯一标识符，也是加入 RTC 和 RTM 时所使用的频道名。长度在 64 字符以内。若该课堂需要使用页面录制，长度需在 50 字符内。 |

<Slot for="api-classroom-restful-html-11-1-3">

</Slot>
