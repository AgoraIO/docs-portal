## 通过 Maven 集成 SDK

如果你使用灵动课堂的默认 UI，声网推荐通过 Maven 在项目中集成 SDK。不同模块介绍和详细集成步骤参考[集成灵动课堂](/zh-CN/solutions/flexible-classroom/get-started/integrate)。

```groovy tab="集成教育模块" tabGroup="sdk-types"
dependencies {
    implementation "io.github.agora-apaas:AgoraEduCore:2.8.101"
    implementation "io.github.agora-apaas:AgoraEduUIKit:2.8.101"
    implementation "io.github.agora-apaas:AgoraClassSDK:2.8.101"
}
```

```groovy tab="集成云课堂模块" tabGroup="sdk-types"
dependencies {
    implementation "io.github.agora-apaas:AgoraEduCore:2.8.70"
    implementation "io.github.agora-apaas:AgoraCloudScene:2.8.70"
}
```

## 下载 SDK

如果你希望自定义课堂 UI，则可以直接下载并集成 SDK。本节提供最新版本 SDK 的下载链接。

  :::info[信息]
  - 各版本 SDK 的发版详情请参考[发版说明](/zh-CN/solutions/flexible-classroom/overview/release-notes)。
      - 如何使用 SDK 实现各种实时互动课堂功能请参考[集成灵动课堂](/zh-CN/solutions/flexible-classroom/get-started/integrate)。
  :::

灵动课堂 SDK 中提供了简单易用的 API，帮助开发者在 App 中构建各种实时互动课堂场景。

- SDK 名称：灵动课堂 SDK
- 开发者：上海声网科技有限公司
- 灵动课堂 SDK 合规使用说明请参考[灵动课堂 SDK 合规使用说明](/basics/security/flexible-classroom-sdk)，个人信息处理规则请参考 [SDK 个人信息处理规则](https://www.shengwang.cn/SDK-privacy-policy/)。

- [Android](https://s01.oss.sonatype.org/content/repositories/releases/io/github/agoraio-community/AgoraClassSDK/2.8.101/AgoraClassSDK-2.8.101.aar)

## 通过 CocoaPods 集成 SDK

如果你使用灵动课堂的默认 UI，声网推荐通过 CocoaPods 添加远程依赖进行集成。不同模块介绍和详细集成步骤参考[集成灵动课堂](/zh-CN/solutions/flexible-classroom/get-started/integrate)。

```ruby tab="集成教育模块" tabGroup="sdk-types"
# third-party libs
pod 'SwifterSwift',   '5.2.0'
pod 'Masonry',        '1.1.0'
pod 'SDWebImage',     '5.12.0'
pod 'AgoraRtcEngine_Special_iOS', '3.7.2.133'
pod 'Whiteboard',     :git => 'https://github.com/netless-io/Whiteboard-iOS', :branch => 'effect-mixing'
# open-source libs
pod 'AgoraClassroomSDK_iOS', '2.8.111'
pod 'AgoraWidgets',          '2.8.111'
```

```ruby tab="集成监考模块" tabGroup="sdk-types"
# third-party libs
pod 'SwifterSwift',     '5.2.0'
pod 'Masonry',          '1.1.0'
pod 'SDWebImage',       '5.12.0'
pod 'AgoraRtcEngine_Special_iOS', '3.7.2.133'
# open-source libs
pod 'AgoraProctorSDK',  '1.0.2'
```

## 通过 npm 集成 SDK

如果你使用灵动课堂的默认 UI，声网推荐通过 npm 在项目中集成 SDK。不同模块说明和详细集成步骤参考集成灵动课堂 [Classroom SDK & Proctor SDK](/zh-CN/solutions/flexible-classroom/get-started/integrate) 或 [FcrUIScene](/zh-CN/solutions/flexible-classroom/get-started/integrate-new)。

```shell tab="集成教育模块" tabGroup="sdk-types"
npm install agora-classroom-sdk agora-plugin-gallery
```

```shell tab="集成监考模块" tabGroup="sdk-types"
npm install agora-proctor-sdk agora-plugin-gallery
```

```shell tab="集成云课堂模块" tabGroup="sdk-types"
npm install fcr-ui-scene agora-plugin-gallery
```

## 通过 CDN 链接集成 SDK

如果直接使用灵动课堂的默认 UI，还可以通过直接在项目的 HTML 文件中添加 CDN 链接，集成 SDK。不同模块介绍和详细集成步骤参考集成灵动课堂 [Classroom SDK & Proctor SDK](/zh-CN/solutions/flexible-classroom/get-started/integrate) 或 [FcrUIScene](/zh-CN/solutions/flexible-classroom/get-started/integrate-new)。

```html tab="集成教育模块" tabGroup="sdk-types"
<script src="https://download.agora.io/edu-apaas/release/edu_sdk@2.9.40.bundle.js"></script>
<script src="https://download.agora.io/edu-apaas/release/edu_widget@2.9.40.bundle.js"></script>
```

```html tab="集成监考模块" tabGroup="sdk-types"
<script src="https://download.agora.io/edu-apaas/release/proctor_sdk@1.0.40.bundle.js"></script>
<script src="https://download.agora.io/edu-apaas/release/proctor_widget@1.0.40.bundle.js"></script>
```

```html tab="集成云课堂模块" tabGroup="sdk-types"
<script src="https://download.agora.io/edu-apaas/release/scene_sdk@1.0.40.bundle.js"></script>
<script src="https://download.agora.io/edu-apaas/release/scene_widget@1.0.40.bundle.js"></script>
```

## 集成 GitHub 源码

如果你希望自定义课堂 UI，则可以通过下载或克隆 GitHub 源码进行集成。详细步骤参考集成灵动课堂 [Classroom SDK & Proctor SDK](/zh-CN/solutions/flexible-classroom/get-started/integrate) 或 [FcrUIScene](/zh-CN/solutions/flexible-classroom/get-started/integrate-new)。

```shell
git clone https://github.com/AgoraIO-Community/flexible-classroom-desktop.git
```
