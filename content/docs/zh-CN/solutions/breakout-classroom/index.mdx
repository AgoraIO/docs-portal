当前在线教育平台普遍面临名师资源稀缺、大班课学习效果不佳、下沉市场客单价不高等痛点。

针对这些痛点，声网推出超级小班课解决方案。

超级小班课支持一个万人直播大班课里的学生拆分成若干个小班。每个小班人数不定，推荐为 4 - 6 人，小班的数量无上限。大班中主讲老师进行直播授课，小班中学生进行实时音视频分组讨论。此外，小班中还可配备助教老师。主讲老师专注提升教学内容，助教老师负责教学辅导，两者分工明确，相互配合。

超级小班课有以下班型玩法：

- 1 个主讲老师 + N 个互动小班。
- N 个主讲老师 + N 个互动小班。
- 1 个主讲老师 + N 个互动小班 + N 个助教。
- 1 个主讲老师 + N 个互动小班 + 监课。

在此基础上，超级小班课还支持主讲老师小班轮巡互动、组内互动 PK、跨组互动 PK 等互动玩法。

声网超级小班课解决方案将直播大班课的规模优势和互动小班课的教学体验相结合，实现“**大班规模 + 小班体验**”，适用于低幼语培以及 K12 教学，有助于高效复用名校和名师资源，利用学生之间分组学习的激励，提高学习投入度。
