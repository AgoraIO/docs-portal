# 登录声网控制台

本文介绍如何在声网控制台开通灵动会议服务。

如果你是第一次使用声网服务，点击[注册账号](https://sso.shengwang.cn/cn/v4/signup/with-sms)前往控制台进行注册。注册成功后会自动登录。

如果你已经拥有声网账号，可以直接[登录控制台](https://console.shengwang.cn//)。

:::info[信息]
注册和登录过程中如果遇到疑问，可以查看[快速开始](/zh-CN/introduction/quickstart)。
:::

## 创建灵动会议项目

成功登录控制台后，按照以下步骤创建一个声网项目：

1. 展开控制台左上角下拉框，点击**创建项目**按钮。
2. 在弹出的对话框内，依次选择**项目类型**，输入**项目名称**，选择**场景标签**和**鉴权机制**。其中鉴权机制推荐选择**安全模式**，**调试模式**的安全性较低。

:::warning[注意]
项目类型必须勾选**灵动会议**。
:::

![开通会议](https://web-cdn.agora.io/docs-portal/img/meeting/console-enable.png)

## 获取 App ID

成功创建项目后，声网会给每个项目自动分配一个 App ID 作为项目唯一标识。你可以直接在**总览**页面的**项目信息**栏，点击 App ID 右侧的复制按钮来获取当前项目的 App ID。

你需要保存好复制的 App ID，后续调用 API 进行初始化等操作时需要传入你获取的 App ID。

## 获取 App 证书

创建好项目后，你可以参考如下步骤获取项目的 App 证书。

在声网控制台**总览**页面的**项目信息**栏，点击**主要证书**/**次要证书**下面的复制图标，即可获取项目的主次 App 证书。

![获取 App 证书示意图](https://web-cdn.agora.io/docs-files/1637637672988)

## 生成临时 Token

对于鉴权机制为安全模式的项目，在后续调用 API 进行加入频道等操作时，你还需要传入频道名和 Token 来对用户进行鉴权。

为方便体验和测试，在 App 调试阶段你可以先从控制台获取临时 Token（有效期为 24 小时），无需自行部署 Token 服务器。但在 App 正式上线前，你必须在自己的服务端部署并生成 Token。

在控制台左上角的下拉框，切换到你想要获取临时 Token 的项目，然后按如下步骤获取临时 Token：

1. 在**总览**页面的**项目信息**栏，点击**临时 Token 生成器**。
2. 在**生成临时 Token** 页面，点击**添加产品**。
3. 选择**灵动会议**产品，输入用户 ID 和房间 ID，例如 `user1` 和 `room1`，再选择用户角色，例如主持人。然后保存好输入的内容。
4. 点击**确认**。
5. 成功生成临时 Token 后，点击 Token 右侧的复制按钮，保存好复制的 Token。

## 开通灵动会议服务

按照以下步骤，在声网控制台开通灵动会议服务：

1. 登录声网[控制台](https://console.shengwang.cn/)，点击左侧导航栏的**全部产品**，选择**灵动会议**，进入灵动会议页面。

2. 在灵动会议页面，切换到**功能配置**页签，点击下方的**开启**按钮。

    点击后，控制台会自动弹出窗口，提示启用灵动会议后会开启的扩展能力。点击**启用**。

3. 成功开通灵动会议服务后，状态会变为**已启用**。

:::warning[注意]
如果要在灵动会议中使用互动白板、实时录制和实时消息功能，必须对白板、实时消息、实时录制相关模块的存储和权限进行配置，否则无法使用。
:::

## 后续步骤

成功开通灵动会议服务后，接下来你可根据目标平台，参考[配置灵动会议](/zh-CN/solutions/meeting/build/manage-classroom/configure-meeting)在该页面为灵动会议配置其使用的互动白板、云端录制、环信 IM，然后集成灵动会议。
