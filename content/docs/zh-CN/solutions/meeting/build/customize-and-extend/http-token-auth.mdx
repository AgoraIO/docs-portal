本文介绍如何实现 HTTP Token 鉴权。

动会议的 RESTful API 使用 HTTP Token 鉴权。每次发起 HTTP 请求时，你需要在请求 Header 的 `Authorization` 字段中传入灵动会议 Token。

```shell
curl -X GET 'https://api.sd-rtn.com/{region}/conference/apps/{yourAppId}/v1/rooms/{roomUuid}/records' \
// highlight-start
-H 'Authorization: agora token={apaasToken}'
// highlight-end
```

灵动会议 RESTful API 所需的 Token 是通过 `BuildAppToken` 函数生成的。你需要先在服务端使用 `BuildAppToken` 函数生成一个 Token，然后将其传入 `Authorization` 字段。具体操作步骤详见[生成鉴权 Token](/zh-CN/solutions/meeting/build/customize-and-extend/generate-token)。
