## 通过 CocoaPods 集成依赖

1. 在终端里进入项目文件夹，运行 `pod init`。

2. 打开 `Podfile` 文件，修改为如下内容：

```ruby
platform :ios, '11.0'
use_frameworks!

target 'YourTargetName' do
    pod 'FcrUIScene', '3.1.0'
    pod "AgoraRtm_OC_Special", '2.2.1.1'
end
```

3. 在终端里进入项目文件夹，运行如下命令安装依赖：

```shell
pod install
```
