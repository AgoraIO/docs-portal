智能云会议引擎是声网推出的一款高清流畅、安全可靠、易于集成和扩展的音视频会议产品。

智能云会议引擎以全球领先的音视频实时通信（RTC）技术和声网生成式 AI 能力平台为核心，为客户提供卓越的体验。

智能云会议引擎支持多种部署方式，提供 SFU 和 MCU 混合架构部署能力，能够无缝对接业务后台和现有的会议设备，全面满足用户的会议、协作和调度需求。

## 适用场景

智能云会议引擎全面覆盖线上与线下的多种应用场景：

- **线上场景**：适用于远程音视频会议、在线协作、会议录制和大型研讨会。
- **线下场景**：支持大屏 ROOMS 终端，支持通过声网会议室连接器实现与 SIP 和 H.323 等设备的互通。

## 功能列表

智能云会议引擎覆盖所有的会议场景所需功能，并提供开放的第三方插件扩展。智能云会议引擎的核心功能如下：

| 功能 | 描述 |
| --- | --- |
| 音视频互动 | 支持千人以上实时音视频互动，多人同时开启摄像头，画质支持标清、高清、2K+。 |
| 会议录制 | 支持云端录制，录制样式可自由定义。 |
| 屏幕分享 | 支持会中分享桌面、应用和窗口，电脑和手机上均可共享。 |
| 实时消息 | <Slot name="product-overview-html-1-4-1" /> |
| 互动白板 | 包含画笔、文本框、图形、橡皮擦、分页、激光笔、撤销、重做等功能。 |
| 会议管理 | <Slot name="product-overview-html-1-6-1" /> |
| AI 引擎 | <Slot name="product-overview-html-1-7-1" /> |
| 多种设备互通 | <Slot name="product-overview-html-1-8-1" /> |

<Slot for="product-overview-html-1-4-1">

- 多种消息类型：支持文字、表情、图片等。
    - 全面的消息管理服务：支持公告、禁言、私聊等。

</Slot>

<Slot for="product-overview-html-1-6-1">

- 分组讨论：支持一键分组、小组独立讨论。
    - 等候室管理：支持会中指定成员进出，会议便捷管理。
    - 自定义布局：支持会中切换布局样式，包含演讲者布局、宫格布局等。
    - 成员权限管理：支持主持人、联席主持人权限。支持麦克风、摄像头、聊天、进出会议室权限管理。
    - 其他功能：支持不同形式加入会议，例如，会议号、会议链接、座机号码等。支持不登录也可入会。

    - 支持国内外主流生成式大模型，也支持替换成智能云会议引擎的 AI 引擎。
    - 提供超低延时、体验流畅的 AI 应用通道，并提前支持多模态模型对接能力。

</Slot>

<Slot for="product-overview-html-1-8-1">

- 支持通过会议室连接器将企业已有的 SIP 和 H.323 设备与智能云会议引擎联通。

    - 终端设备管理能力：灵活布局、静音、解除静音等。

</Slot>
