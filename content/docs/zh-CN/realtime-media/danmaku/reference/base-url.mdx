---
title: "Base URL 说明"
---
弹幕玩法 RESTful API Base URL 为 `https://{domain}/v2/projects/{appid}`，其中包含两个变量：

- `domain`：API 域名。分为以下两种：
    - 正式环境域名：`api.sd-rtn.com`，与生产环境的游戏配套使用，切换后会并且会按照礼物消息进行计量计费。访问正式环境域名的最佳实践，请参考[保障 REST 服务高可用](https://doc.shengwang.cn/doc/rtc/restful/best-practice/rest-availability)。
    - 测试环境域名：`api-test.agora.io`, 与测试的游戏配套使用，不产生费用，但有调用容量限制, 不保证可用性。

- `appid`：你的项目使用的 [App ID](/zh-CN/realtime-media/danmaku/build/setup-and-access/enable-service#获取开发参数)。

:::warning[注意]
声网 RESTful API 仅支持 HTTP 1.1 和 HTTP 2.0 协议。如果使用 HTTPS 连接，请确保使用 TLS 1.0、1.1 或 1.2 版本进行加密通信。使用其他协议版本可能导致连接失败。
:::
