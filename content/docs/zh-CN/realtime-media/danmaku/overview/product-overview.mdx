弹幕玩法是时下火爆的游戏直播互动玩法，通过信令和实时音视频技术实现游戏画面和直播间交互。相比于传统的游戏直播主播掌控游戏进程，在弹幕玩法中，观众可以通过弹幕或者礼物影响游戏的进程，在直播间内刷更高等级的礼物加强己方的战斗力，从而赢得胜利。弹幕玩法在头部平台如抖音、快手已非常成熟，目前正逐渐在往中腰部平台渗透。

声网弹幕玩法解决方案支持以下方式开播：

| 支持场景                       | 主播                                                         | 观众                                                     |
| ------------------------------ | ------------------------------------------------------------ | -------------------------------------------------------- |
| Windows 端开播                       | 本地安装玩法包.exe，启动玩法将自己的画面通过屏幕共享分享给观众。 | 通过发送弹幕指令，如 1、2、红、蓝、或者送礼影响游戏进程。 |
| 移动端 (iOS/Android) 云渲染开播 | 无需安装玩法包，App 服务端调用获取云游戏列表，启动云游戏服务。        | 通过发送弹幕指令，如 1、2、红、蓝、或者送礼影响游戏进程。 |

## 方案优势

弹幕玩法解决方案有如下优势：

- **丰富的玩法储备**：储备多 、质量优（抖音、快手、腾讯头部弹幕玩法均有覆盖）。
- **接入无门槛**：PC、移动端开播都支持，支持使用一套接口在 PC/移动端开播。
- **领先的云渲染平台服务**
  - 整合各种云主机供应商的能力，覆盖不同的机型、不同的地域。比单纯的云主机供应商覆盖更多、机型更多。
  - 采用在业界内领先的单云主机多实例管理技术，允许在一个主机上启动多个实例（比如游戏），实现资源的最大利用，降本增效。
  - 开播端支持移动端（Android，iOS）和 Windows 端，观众端全终端支持。
- **低延迟远程控制技术**：结合实时消息（Real-Time Messaging，RTM）技术和 Window 虚拟键盘注入技术，将远程控制（主播操作）延迟控制在 100～200 ms 内。
- **领先的屏幕采集技术的支持**：不仅支持 1080P，还支持 2K；客户无需做任何设置、也不需要关注设备兼容，通过接口选择平台即可自动完成高清设置。
- **成熟的出海能力**
  - 储备出海游戏供给
  - 支持本地化部署
  - 支持海外主播、运营扶持
