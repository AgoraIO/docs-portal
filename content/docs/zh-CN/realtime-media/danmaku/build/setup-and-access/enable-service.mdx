---
title: "开通弹幕服务"
---
实现弹幕玩法前，你需要先在[声网控制台](https://console.shengwang.cn/)创建项目并获取开发参数。

## 登录声网控制台

如果你是第一次使用声网服务，点击[注册账号](https://sso.shengwang.cn/cn/v4/signup/with-sms)前往控制台进行注册。注册成功后会自动登录。

如果你已经拥有声网账号，可以直接[登录控制台](https://console.shengwang.cn//)。

:::info[信息]
注册和登录过程中如果遇到疑问，可以查看[快速开始](/zh-CN/introduction/quickstart)。
:::

## 创建声网项目

成功登录控制台后，按照以下步骤创建一个声网项目：

1. 展开控制台左上角下拉框，点击**创建项目**按钮。
2. 在弹出的对话框内，依次选择**项目类型**，输入**项目名称**，选择**场景标签**和**鉴权机制**。其中鉴权机制推荐选择**安全模式**，**调试模式**的安全性较低。

:::warning[注意]
为使用danmaku服务创建项目时，项目类型选择**通用项目**。
:::

## 获取开发参数

实现弹幕玩法需要在控制台获取以下关键开发参数：

- APP ID：在**控制台 - 总览 - 项目信息栏**，你可以便捷地获取 App ID、生成临时 Token 以及查看和管理 App 证书。

- RESTful API 密钥：在声网控制台点击右上角账户名，在下拉菜单中进入 **RESTful API** 页面获取调用弹幕玩法 RESTful API 所需的客户 ID 和客户密钥。

## 开通弹幕玩法

[联系销售](https://www.shengwang.cn/contact-sales/)开通弹幕玩法服务。
