本文介绍实时转录翻译服务的版本更新说明。

## v7.2.3

该版本于 2026 年 7 月 20 日发布。

### 新增特性

#### 新增 RTC Token 即将过期 Webhook 事件

该版本新增 [`104 token will expire`](/zh-CN/realtime-media/speech-to-text/reference/ncs-events#104-token-will-expire) 事件。当实时转录翻译引擎使用的 RTC Token 距离过期还有 30 秒时，消息通知服务会向你的业务服务器发送预警通知。如果 RTC Token 的有效期小于或等于 30 秒，平台不会发送该事件。该事件仅用于提前通知，不会触发任务结束，也不会改变任务的最终状态。

### 升级必看

#### 空闲超时和任务最长运行时长规则更新

该版本更新了 [`maxIdleTime`](/zh-CN/api-reference/api-ref/speech-to-text/join#request.body.maxIdleTime) 参数规则：取值范围调整为 `[0,259200]` 秒，`0` 表示禁用空闲自动结束。

任务还存在与空闲超时相互独立的最长运行时长上限，默认为 72 小时。到达最长运行时长后，任务会被强制结束，即使 `maxIdleTime` 为 `0` 也不例外。因任务达到最长运行时长上限而退出时，[`102 agent left`](/zh-CN/realtime-media/speech-to-text/reference/ncs-events#102-agent-left) 事件中的 `message` 字段返回 `Task exceeded maximum lifetime`。

#### 转录和翻译结果支持同时返回稳定片段和实时片段

转录和翻译结果可能在同一次更新中同时包含已稳定的前缀片段和仍会变化的实时片段。为承载该场景，`transcript` 和 `translation` 消息新增 `results[]` 字段，用于返回一个或多个片段。单片段场景下 `results[]` 长度为 `1`；mixed 场景下 `results[]` 长度可能大于 `1`。

如果你的客户端启用了 JSON 协议，请遍历 `results[]` 处理每个片段，并兼容 `results[]` 为空数组的消息。Protobuf 协议字段不变，但单次消息也可能承载多个片段。字段说明和示例见 [JSON 协议数据结构](/zh-CN/realtime-media/speech-to-text/build/process-transcription-data/how-to-use-protobuf#json-协议数据结构)。

## v7.2.2

该版本于 2026 年 5 月 22 日发布。

### 新增特性

#### 支持语言列表新增 5 个语种

实时转录和实时翻译支持语言列表新增以下 5 个语种：

- `be-BY`：白俄罗斯语
- `tl-PH`：他加禄语（菲律宾）
- `cmn-CN`：中原官话（陕西话，河南话），西南官话（湖北话），江淮官话（安徽话）
- `hsn-CN`：湘语（湖南话）
- `nan-CN`：闽南语，潮汕话

### 升级必看

#### 实时翻译目标语言配置规则更新

该版本更新了实时翻译中源语言和目标语言的配置规则，适用于单语言输入和多语言混合输入场景：

- 当源语言为单语言输入时，翻译的目标语言必须和源语言不同，否则会报错。例如，中文输入时，目标语言不能选择中文。
- 当源语言为多语言混合输入时，翻译的目标语言可以与源语言中的某一种语言相同。例如，中文和英文混合输入时，目标语言可以设置为中文，此时输入中的中文和英文都会被翻译为中文。

## v7.2.1

该版本于 2026 年 4 月 17 日发布。

### 新增特性

#### 字幕存储支持标准 S3 兼容对象存储

该版本新增支持将录制字幕写入标准 S3 兼容对象存储。你可以在转写请求的 `captionConfig.extensionParams` 中配置 `endpoint`、`type`、`provider` 等参数，对接 MinIO 等 S3 兼容存储服务，以及部分自建对象存储。详见[录制字幕](/zh-CN/realtime-media/speech-to-text/build/process-transcription-data/record-captions)。

#### 获取任务列表 API

该版本新增 [GET 获取任务列表](/zh-CN/api-reference/api-ref/speech-to-text/list) 接口，用于按频道、时间范围和任务状态检索符合条件的实时转录翻译任务。

## v7.2

该版本于 2026 年 3 月 30 日发布。

### 新增特性

#### 热词功能（Keywords）

转写 API 支持配置热词，用于提升对专有名词、行业术语等特定词汇的识别准确率。单次请求最多可配置 500 个热词。在创建转写任务或实时转写服务时，通过请求 Body 中的 `keywords` 参数传入热词列表即可生效。

#### 字幕唯一 ID（sentence_id）

解析转写数据时，每条字幕会携带唯一标识 `sentence_id`。在原文与译文场景下，可通过该 ID 将同一句话的原文与译文字幕一一对应，实现更精准的字幕对齐与展示。
