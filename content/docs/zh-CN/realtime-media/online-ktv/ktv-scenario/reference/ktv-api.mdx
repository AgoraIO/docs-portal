<a id="createKTVApi"></a>
### createKTVApi

```kotlin
fun createKTVApi(config: KTVApiConfig): KTVApi = KTVApiImpl(config)
```

创建并初始化 KTV API 实例。调用该方法可以初始化 KTV API 模块内部变量和缓存数据，并注册相应的回调监听。

:::warning[注意]
- 如果你的业务场景是大合唱场景，请调用 [`createKTVGiantChorusApi`](#createKTVGiantChorusApi) 来创建并初始化大合唱场景的 KTV API 实例。
- 调用其他 KTV API 之前，你需要先调用本方法创建并初始化。
:::

#### 参数

- `config`：初始化配置，详见 [`KTVApiConfig`](#KTVApiConfig)。

<a id="renewtoken"></a>
### renewToken

```kotlin
fun renewToken(
    rtmToken: String,
    chorusChannelRtcToken: String
)
```

更新 Token。

当你收到 `onTokenPrivilegeWillExpire` 回调报告 Token 即将过期时，需要主动调用此方法更新 Token。

#### 参数

- `rtmToken`：用于音乐内容中心鉴权的 RTM Token，详见 [部署 RTM Token 服务器](https://doc.shengwang.cn/doc/rtm2/javascript/user-guide/token/token-generation)。
- `chorusChannelRtcToken`：加入合唱子频道的 Token。在合唱场景下，领唱需要加入两个频道，加入主频道发布人声和播放器的混流，加入合唱子频道发布麦克风采集的音频流，伴唱需要加入合唱子频道来同步领唱的人声。

<a id="fetchmusiccharts"></a>
### fetchMusicCharts

```kotlin
fun fetchMusicCharts(
    onMusicChartResultListener: (
        requestId: String?,
        status: Int,
        list: Array<out MusicChartInfo>?
    ) -> Unit
)
```

获取歌曲榜单。

该方法用于获取各类歌曲榜单，并提供一个回调函数用于处理异步调用的结果。

#### 参数

- `onMusicChartResultListener`：歌曲榜单列表回调，包含以下参数：
  - `requestId`：请求 ID。本次请求的唯一标识。
  - `status`：请求状态。
    - 0：请求成功。
    - 1：一般错误，无明确归因。
    - 2：网关异常。可能的原因有：
      - 当前使用的 Token 已过期。请重新生成 Token。
      - 传入的 Token 无效。请确保你使用的是 RTM Token。
      - 网络错误。请检查你的网络。
    - 3：权限错误或歌曲不存在。请确保你的项目已开通声网音乐内容中心权限。
    - 4：内部数据解析错误。
    - 5：歌曲加载时出错。
    - 6：歌曲解密时出错。
  - `list`：[`MusicChartInfo`](/api-ref/rtc/android/API/class_musicchartinfo) 对象数组，包含歌曲榜单信息。

- `page`：当前页面编号，默认从 1 开始。

- `jsonOption`：扩展 JSON 字段，默认为 `NULL`。你可以通过该字段来筛选出你需要的音乐资源，目前支持筛选可打分的音乐资源及音乐资源的副歌片段：

  | pitchType | <Slot name="ktv-api-android-markdown-0-1-1" /> | `{"pitchType": 1}` |
  | needHighPart | <Slot name="ktv-api-android-markdown-0-2-1" /> | `{"needHighPart": true}` |

  <Slot for="ktv-api-android-markdown-0-1-1">

  是否支持打分：

  - 1：支持打分的音乐资源。
  - 2：不支持打分的音乐资源。

  </Slot>

  <Slot for="ktv-api-android-markdown-0-2-1">

  是否需要副歌片段资源：

  - `true`：需要副歌片段资源。
  - `false`：不需要副歌片段资源。

  </Slot>

- `onMusicCollectionResultListener`：获取歌曲资源列表回调，包含以下参数：
  - `requestId`：请求 ID。本次请求的唯一标识。
  - `status`：请求状态。
    - 0：请求成功。
    - 1：一般错误，无明确归因。
    - 2：网关异常。可能的原因有：
      - 当前使用的 Token 已过期。请重新生成 Token。
      - 传入的 Token 无效。请确保你使用的是 RTM Token。
      - 网络错误。请检查你的网络。
    - 3：权限错误或歌曲不存在。请确保你的项目已开通声网音乐内容中心权限。
    - 4：内部数据解析错误。
    - 5：歌曲加载时出错。
    - 6：歌曲解密时出错。
  - `page`：当前页面编号，默认从 1 开始。
  - `pageSize`：当前歌曲资源列表的总页面数量，最大值为 50。
  - `total`：列表内歌曲资源的总数量。
  - `list`：[Music](/api-ref/rtc/android/API/class_music) 对象数组，包含歌曲的详细信息。

<a id="loadmusic"></a>
### loadMusic[1/2]

```kotlin
fun loadMusic(
    songCode: Long,
    config: KTVLoadMusicConfiguration,
    musicLoadStateListener: IMusicLoadStateListener
)
```

通过歌曲编号加载歌曲和歌词。

传入歌曲编号和加载配置，调用 `loadMusic` 加载歌曲和歌词。加载结果会通过 `IMusicLoadStateListener` 回调异步通知你。

:::warning[注意]
目前一次仅支持加载一首歌曲，请在一首歌曲加载完成后再加载下一首。
:::

#### 参数

- `songCode`: 歌曲编号，用于标识一个音乐资源。你可以通过 `searchMusicByMusicChartId` 或 `searchMusicByKeyword` 获取需要加载的歌曲编号，也可以通过 RESTful API 来获取[曲库所有歌曲列表](/zh-CN/realtime-media/online-ktv/ktv-scenario/reference/music-content-center#获取曲库所有歌曲列表)或[增量歌曲列表](/zh-CN/realtime-media/online-ktv/ktv-scenario/reference/music-content-center#获取增量歌曲列表)。
- `config`: 加载配置。详见 [`KTVLoadMusicConfiguration`](#KTVLoadMusicConfiguration)。
- `musicLoadStateListener`: 歌曲加载状态，详见 [`IMusicLoadStateListener`](#imusicloadstatelistener)。

<a id="switchsingerrole"></a>
### switchSingerRole

```kotlin
fun switchSingerRole(
    newRole: KTVSingRole,
    switchRoleStateListener: ISwitchRoleStateListener?
)
```

切换 K 歌时的用户角色。

KTV API 初始化时默认用户角色为听众，如果需要开始独唱或加入合唱，需要调用 `switchSingerRole` 来切换至相应的角色。你可以参考[切换说明](/zh-CN/realtime-media/online-ktv/ktv-scenario/get-started/integrate-ktvapi#5-切换角色)来进行角色切换。

KTV API 内部会根据角色的切换来控制演唱过程中音乐播放器的播放、同步，以及订阅和发布音频流的行为。角色切换的结果会通过 `ISwitchRoleStateListener` 回调异步通知你。

#### 参数

- `newRole`: 切换后的用户角色，详见 [`KTVSingRole`](#KTVSingRole)。
- `switchRoleStateListener`：用户角色切换结果回调，详见 [`ISwitchRoleStateListener`](#iswitchrolestatelistener)。

- 听众：收到一个 `isLocal` 为 `false` 的回调报告主唱端播放器的状态改变。

小合唱K 歌配置：

:::info[信息]
你可以获取临时 RTM Token 用于测试，但在正式生产环境中，你需要自己部署一个 RTM Token 服务器来生成、更新 Token，详见 [部署 RTM Token 服务器](/zh-CN/realtime-media/rtm/build/security-and-auth/token-generation)。
:::

- `engine`：[`AgoraRtcEngineKit`](/api-ref/rtc/ios/API/rtc_interface_class#class_irtcengine) 对象。

- `channelName`：频道名。

- `localUid`：本地用户的 ID。频道内的每个用户 ID 都必须是唯一，需是 32 位无符号整数，建议取值范围为 [1,232-1]。

- `chorusChannelName`: 合唱子频道的名称。在合唱场景下，领唱需要加入两个频道，主频道用户发布人声和播放器的混流，加入合唱子频道发布麦克风采集的音频流，伴唱需要加入合唱子频道来同步领唱的人声。在独唱场景下，该参数可以为空。

- `chorusChannelToken`：合唱场景下，根据合唱子频道的名称和用户 ID 生成的 Token，用于加入合唱子频道时进行鉴权。在独唱场景下，该参数可以为空。

- `type`：K 歌场景，详见 [`KTVType`](#KTVType)。

- `maxCacheSize`：可缓存的音乐资源数量，最多不能超过 50。

- `musicType`：音乐资源类型，详见 [`loadMusicType`](#loadMusicType)。

- `localUid`：本地用户的 ID。频道内的每个用户 ID 都必须是唯一，需是 32 位无符号整数，建议取值范围为 [1,232-1]。

- `chorusChannelName`：演唱频道的频道名。领唱和伴唱需要加入该频道发布人声、音乐流。
- `chorusChannelToken`：加入演唱频道的 Token。
- `maxCacheSize`：可缓存的音乐资源数量，默认值为 10，不得超过 50。
- `musicType`：音乐资源类型，详见 [KTVMusicType](#KTVMusicType)。
- `audienceChannelToken`：加入听众频道的 Token。
- `musicStreamUid`：发布音乐流的用户 ID。领唱需要发布音乐流到频道中。
- `musicChannelToken`：基于发布音乐流的用户 ID 和频道名生成的 Token，用于发布音乐流至频道内时鉴权。
