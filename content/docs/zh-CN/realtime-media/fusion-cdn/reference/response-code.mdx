---
title: "响应状态码"
---
在调用融合 CDN 直播 RESTful API 过程中，你可能收到如下 HTTP 状态码：

- 如果 HTTP 状态码为 `2XX`，则请求成功。
- 如果 HTTP 状态码不为 `2XX`，则请求失败，你可以根据对应响应体中出现的 `message` 字段排查问题。

例如，请求失败时，你可能收到如下响应：

```json
# 401 Unauthorized
{
  "message": "Invalid authentication credentials"
}
```

## 状态码

下表列出在使用融合 CDN 过程中可能收到的响应状态码、错误原因和解决方案。

| 状态码 | 错误原因 | 解决方法 |
| --- | --- | --- |
| `200 OK` | 请求执行成功。 | 无需解决。 |
| `201 Created` | <Slot name="response-code-html-0-2-1" /> | 无需解决。 |
| `400 Bad Request` | 参数非法。 在不同的 API 中，400 具体代表的错误不同，详见 [400 状态码详情](#400-状态码详情)。 | 详见 [400 状态码详情](#400-状态码详情)。 |
| `401 Unauthorized` | 服务未经授权，如客户 ID 和客户密钥匹配错误。 | 参考[实现 HTTP HMAC 认证](/zh-CN/realtime-media/fusion-cdn/build/setup-and-access/http-hmac-auth)重新获取 `Authorization` 字段。 |
| `404 Not Found` | 服务器无法根据请求找到资源，即请求的域名不存在或者请求的 URI 路径非法。 | 检查请求中的 URI 路径是否正确。 |
| `500 Internal Server Error` | 服务器内部错误，无法完成请求。 | 使用退避策略重试三次。例如，调用后等待 1 秒再重试。 |
| `504 Gateway Timeout` | 服务器内部错误。充当网关或代理的服务器未从远端服务器获取请求。 | 使用退避策略重试三次。例如，调用后等待 1 秒再重试。 |

<Slot for="response-code-html-0-2-1">

资源创建成功。

    在不同的 API 中，201 可能代表的资源如下：

    - 在域名管理 API 中，表示域名创建成功。
    - 在发布点管理 API 中，表示发布点创建成功。

</Slot>

## 400 状态码详情

本节介绍在调用不同的 API 时，400 状态码代表的错误原因和解决方法。

| API 功能 | 错误原因 | 解决方法 |
| --- | --- | --- |
| 域名管理 | <Slot name="response-code-html-1-1-1" /> | 检查请求里的 `appid` 或者 `domain` 是否合法。 |
| 发布点管理 | <Slot name="response-code-html-1-2-1" /> | 检查请求里的 `appid` 或者 `entry_point` 是否合法。 |
| 直播流管理、推流和播流数据 | <Slot name="response-code-html-1-3-1" /> | <Slot name="response-code-html-1-3-2" /> |
| 录制、截图及存储 | <Slot name="response-code-html-1-4-1" /> | <Slot name="response-code-html-1-4-2" /> |
| 直播流鉴权 | `appid` 或者 `domain` 为空。 | 检查请求里的 `appid` 或者 `domain` 是否存在。 |
| 转码、直播转推 | `appid` 或者 `name` 为空。 | <Slot name="response-code-html-1-6-2" /> |
| 水印、延播、回源拉流 | `appid` 或者 `entry_point` 为空。 | 检查请求里的 `appid` 或者 `entry_point` 是否存在。 |

<Slot for="response-code-html-1-1-1">

- `appid` 或者 `domain` 为空。
      - 要增加的域名已经存在。

</Slot>

<Slot for="response-code-html-1-2-1">

- `appid` 或者 `entry_point` 为空。
      - 要增加的发布点已经存在。
      - 发布点数目超出上限。

</Slot>

<Slot for="response-code-html-1-3-1">

- `appid` 或者 `entry_point` 为空。
      - 查询时间格式不正确。

</Slot>

<Slot for="response-code-html-1-3-2">

- 检查请求里的 `appid` 或者 `entry_point` 是否合法。
      - 检查时间是否符合 RFC 3339 格式。

</Slot>

<Slot for="response-code-html-1-4-1">

- `appid` 或者 `entry_point` 为空。
      - `region` 参数值非法。

</Slot>

<Slot for="response-code-html-1-4-2">

- 检查请求里的 `appid` 或者 `entry_point` 是否合法。
      - `region` 只能在 `cn`、`ap`、`na` 和 `eu` 中取值。

</Slot>

<Slot for="response-code-html-1-6-2">

- 检查请求里的 `appid` 是否合法。
      - 检查请求里的 `name` 是否存在。

</Slot>
