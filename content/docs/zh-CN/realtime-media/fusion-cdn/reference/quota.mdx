## API 限速

本文介绍融合 CDN 直播的配额限制。

针对每个声网账号，fusion-cdn 服务的每秒请求数（QPS）上限为 50 次/秒。

如果调用频率超出上限，请参考[如何处理服务端 RESTful API 调用超出频率限制](/zh-CN/reference/faq/integration/restful_api_call_frequency)。

## 路数限制

为保障服务质量，声网融合 CDN 直播在部分地区限制了最大推流路数。

| 中国大陆 | 除中国大陆之外的亚太地区 |
| --- | --- |
| <Slot name="quota-html-0-1-0" /> | <Slot name="quota-html-0-1-1" /> |

<Slot for="quota-html-0-1-0">

- SD：60
    - HD：50
    - FHD：20

</Slot>

<Slot for="quota-html-0-1-1">

- SD：30
    - HD：20
    - FHD：10

</Slot>

:::info[信息]
视频分辨率说明：

- SD：标清视频，分辨率 ≤ 640 × 360
- HD：高清视频，640 × 360 < 分辨率 ≤ 1280 × 720
- FHD：全高清视频，1280 × 720 < 分辨率 ≤ 1920 × 1080
:::

如果你需要同时推多种档位的流，请确保满足以下要求：

- 总路数不超过所选档位支持路数之中的最大值，即 Max(档位 1 支持的最大路数, ..., 档位 n 支持的最大路数)。
- 各档位推流路数不超过该档位支持的最大路数。

以在中国大陆使用融合 CDN 直播服务为例：同时推标清和高清档位的流，则推流总路数不能超过 60，并且高清档位的推流路数不能超过 50。
