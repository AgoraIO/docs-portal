声网融合 CDN 直播每个月提供 800 GB 的免费用量。

每月结束时，声网会根据所有项目当月在各个地区产生的总流量确定对应的单价，再将各个地区产生的流量按照单价从低到高的顺序抵扣免费用量后乘以相应的单价，相加计算得出本月费用。

## 流量阶梯单价

下表列出各个流量阶梯下每个地区的流量单价。

| 月度总流量 X (GB)          | 中国内地（元/GB） | 海外及港澳台（元/GB） |
| :----------------------- | :------- | :--- |
| X ＜ 10,000               | 0.25     | 0.48 |
| 10,000 ≤ X ＜ 50,000     | 0.23     | 0.46 |
| 50,000 ≤ X ＜ 100,000   | 0.21     | 0.42 |
| 100,000 ≤ X ＜ 1,000,000 | 0.19     | 0.38 |
| X ≥ 1,000,000     | 0.16     | 0.32 |

## 计费示例

假设你的声网账号下有一个项目使用了融合 CDN 直播服务，一个月产生的直播流量如下：

| 区域      | 流量 (GB) |
| :-------- | :--------- |
| 中国内地  | 500.000    |
| 海外及港澳台     | 10,400.000 |

月度费用计算过程如下：

1. 计算月度总流量：500 + 10,400 = 10,900 GB
2. 确定流量单价：10,900 在 10,000 到 50,000 之间，因此按照流量阶梯单价表的第二行计算。
3. 将每个区域产生的流量按照单价从低到高的顺序抵扣免费用量，然后计算抵扣后流量的费用，如下表所示：

   | 区域      | 实际流量 (GB) | 抵扣后流量 (GB)              | 单价（元/GB） | 费用（元）            |
   | :-------- | :------------- | :---------------------------- | :------------ | :-------------------- |
   | 中国内地  | 500            | 500 - 500 = 0                 | 0.23          | 0 × 0.23 = 0          |
   | 海外及港澳台     | 10,400         | 10,400 - (800 - 500) = 10,100 | 0.46          | 10,100 × 0.46 = 4,646 |

4. 将各区域费用相加，得出月度总费用：0 + 4,646 = 4,646 元。

## 欠费与关闭服务

如果你的声网账号处于欠费或注销状态超过 15 天，或者你主动关闭了融合 CDN 服务，声网将清理你在使用服务期间产生的所有数据，包括域名配置、证书数据、录制数据、截图数据等。为避免丢失数据，声网建议及时查看账单并支付费用。
