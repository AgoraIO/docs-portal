录制直播流是指将原始的直播流封装成指定格式的视频文件。

本文介绍如何使用融合 CDN 直播提供的录制直播流功能。

## 功能简介

### 录制模式

根据文件的存储方式，可以分为标准录制和自定义录制两种模式：

- 标准录制：使用声网默认的存储空间，并且支持点播分发、DRM 转码加密、精彩片段截取、定点截图。
- 自定义录制：支持使用多个主流的第三方云存储服务，如七牛云、Amazon S3、阿里云等。

### 注意事项

如果同一个项目（即 App ID 相同）下有多个发布点，不同发布点的录制行为必须统一。以一个具有 A、B 两个发布点的项目为例，仅支持下表列出的录制行为：

| 发布点 A                   | 发布点 B                   |
| -------------------------- | -------------------------- |
| 为**所有**直播流开启**标准录制**   | 为**所有**直播流开启**标准录制**   |
| 为**所有**直播流开启**自定义录制** | 为**所有**直播流开启**自定义录制** |
| 为**部分**直播流开启**标准录制**   | 为**部分**直播流开启**标准录制**   |
| 为**部分**直播流开启**自定义录制**   | 为**部分**直播流开启**自定义录制**   |

## 录制发布点下所有直播流

同一 App ID 下的发布点必须使用相同的录制模式，不同 App ID 下的发布点可以根据需要使用不同的录制模式，实现灵活管理。

## 录制发布点下部分直播流

在某些场景，你可能只需要录制某个发布点的一部分直播流。此时必须先关闭该发布点下所有直播流的录制，然后依次为每一条直播流手动开启录制。

为单条直播流开启录制的有效期为 24 小时。例如，调用 API 同时对直播流 A、B 和 C 开启录制：

![直播流的录制情况](https://web-cdn.agora.io/docs-portal/img/fusion-cdn/stream-recording.png)

每条流的录制情况如下：

- 直播流 A 已经在推流，因此录制会立即开始，持续到推流结束。
- 直播流 B 在开启录制后的 24 小时内开始推流，录制会在推流时开始，持续到推流结束。
- 直播流 C 在开启录制超过 24 小时后才开始推流，因此不会被录制。

<TabsList>

<TabsContent value="standard">

对部分直播流进行标准录制需要调用以下 API：

1. 调用[设置标准录制配置](/zh-CN/api-reference/api-ref/fusion-cdn/standard-recording-config-update) API，设置录制文件的格式。
2. 调用[开启/关闭发布点的标准录制](/zh-CN/api-reference/api-ref/fusion-cdn/standard-recording-auto-update) API，将 `enabled` 设为 `false`，关闭对该发布点的录制。
3. 对于每一条需要录制的直播流，调用[开启单条流的标准录制](/zh-CN/api-reference/api-ref/fusion-cdn/standard-recording-stream-enable) API 并设置直播流名称等参数。

</TabsContent>

<TabsContent value="custom">

对部分直播流进行自定义录制需要调用以下 API：

1. 调用[设置自定义录制配置](/zh-CN/api-reference/api-ref/fusion-cdn/custom-recording-config-update) API，设置录制文件的格式和第三方云存储。
2. 调用[开启/关闭发布点的自定义录制](/zh-CN/api-reference/api-ref/fusion-cdn/custom-recording-auto-update) API，将 `enabled` 设为 `false`，关闭对该发布点的录制。
3. 对于每一条需要录制的直播流，调用[开启单条流的自定义录制](/zh-CN/api-reference/api-ref/fusion-cdn/custom-recording-stream-enable) API 并设置直播流名称等参数。

</TabsContent>
</Tabs>

## 参考信息

在标准录制模式下，如果你需要使用点播分发功能，请参考以下步骤配置点播域名：

1. 联系声网[技术支持](https://ticket.shengwang.cn)并提供你的点播域名，等待域名配置完成。
2. 使用点播域名拼接文件 URI（例如：录制文件 URI、DRM 文件 URI、截图文件 URI），即可通过点播域名访问到对应的文件。
