## 前提条件

- 已注册声网账号并可访问目标项目。
- 已确认业务需要开通音频审核、视频审核，或同时开通两者。
- 已准备可接收审核结果的服务端回调地址。
- 如需通过 RTC SDK 启动审核，已准备可用的 RTC Token。

## 创建声网项目并获取 App ID

<a id="获取-app-id"></a>

1. 登录[声网控制台](https://console.shengwang.cn/)。
2. 创建或选择一个项目。
3. 在项目配置中复制 App ID。

你需要保存好 App ID，后续调用 API 进行初始化等操作时需要传入该参数。

## 获取临时 Token

对于鉴权机制为安全模式的项目，后续调用 API 加入频道等操作时，还需要传入频道名和 Token 对用户进行鉴权。

在调试阶段，你可以先从控制台获取有效期为 24 小时的临时 Token；在 App 正式上线前，你必须在自己的服务端部署并生成 Token。

:::warning[注意]
通过 SDK 启动内容审核时，当前必须使用以 `007` 开头的 RTC Token，即 AccessToken2。
:::

## 开启音频审核和视频审核

首次使用前，请按以下步骤在声网控制台启用内容审核服务：

1. 登录声网控制台，在左上角选择需要配置内容审核的项目。
2. 在左侧导航栏依次进入**全部产品 > 拓展能力 > 内容审核**。
3. 在**内容审核**页面切换到**功能配置**页，填写邮箱、回调地址等必要信息，并分别开启音频审核和视频审核。
4. 开启成功后，你可以在**功能配置**页面看到对应功能已处于启用状态。

![内容审核功能配置页面](https://web-cdn.agora.io/docs-portal/img/content-moderation/console-function-configuration.png)

:::info[信息]
内容审核开通后默认提供 7 天测试期。测试期结束后，你需要购买内容审核套餐包才能继续使用服务。
:::

## 配置项说明

首次开通内容审核时，建议重点确认以下配置项：

- 邮箱：用于接收音频审核相关的第三方平台登录信息。
- 回调地址：用于接收审核结果回调，建议配置为稳定、可监控、支持验签和幂等处理的服务端接口。
- 审核能力：按业务实际需要开启音频审核、视频审核，或同时开启两者。

## 网易易盾控制台相关说明

### 音频审核平台账号说明

在声网控制台成功开通音频审核服务后，声网会使用你填写的邮箱在网易易盾平台创建新的登录账号。你可以在该邮箱中获取网易易盾平台登录信息，用于精细化审核模型选择、策略配置等。

:::caution[注意]
创建成功后，暂不支持在声网控制台修改该邮箱。请在首次配置时确认该邮箱可长期使用。
:::

### 登录网易易盾后台

通过 [网易易盾审核平台](https://shengwangai.cms.dun.163.com/login)登录。输入子账号名称及密码后即可登录。首次初始化登录密码会发送到邮件中，建议首次登录后及时修改密码。

![网易易盾登录页面](https://web-cdn.agora.io/docs-portal/img/content-moderation/yidun-login.png)

### 审核过检模型配置

在网易易盾后台的**产品业务管理 > 业务管理**页面，对当前已开通的业务进行审核模型配置。

![网易易盾业务管理入口](https://web-cdn.agora.io/docs-portal/img/content-moderation/yidun-business-management-entry.png)

#### 视频（图片）审核业务

图片、视频业务按检测模型计费，模型与内容一级大类一一对应。业务开通后，系统会自动初始化标签配置。

声网视频审核默认创建覆盖色情、性感低俗、涉政、暴恐、违禁、涉价值观、广告、二维码的审核模型，覆盖主流审核场景，不建议调整。

- 若需调整一级大类：关联计费规则，改动易造成计费异常。修改前须审慎评估，建议对接易盾策略经理确认。
- 仅调整已勾选一级大类下的二、三级标签：不产生额外计费，可按需操作。
- 新增其他内容分析能力：暂未开放自助配置通道，需联系易盾策略经理开通。

#### 直播音频业务

音频业务按检测语种计费。声网音频审核默认创建中文音频检测能力；新增小语种检测能力需联系易盾策略经理配置。业务计费场景确认后，调整音频一、二、三级分类标签，均不改变原有计费标准。

### 审核基础自定义策略配置

你可以通过**策略配置 > 名单策略**进行简单的个性化策略调整。

![网易易盾名单策略页面](https://web-cdn.agora.io/docs-portal/img/content-moderation/yidun-list-policy.jpg)

- 关键词名单：适用于文本、图片、视频、音频全品类业务，统一管理关键词审核策略，支持配置黑白关键词；提升机器识别精度，减少人工审核投入。
- 忽略词名单：支持录入屏蔽词汇、网址链接；文本命中条目后自动清除对应内容，规避机器检测误判拦截。
- 文本特征名单：针对无独立明确关键词、需整句判定的文本审核场景，用于文本业务特征策略运维；提升机审识别能力，压降人审成本。
- 图片名单：面向图片、视频业务搭建图像样本库，支持图像黑白名单配置，机器比对图像特征并执行预设处置规则；库内连续 1 年无命中样本自动清理，优化审核效率、缩减人工复核量。
- 用户 ID/IP 名单：用于用户身份维度审核策略管控，可对指定用户 ID、IP 配置黑白名单；分层优化机审流程，降低人工审核压力。

### 审核配置支持

任何网易易盾审核策略配置相关问题，请提交**问题反馈**工单，并备注声网渠道客户；同时请附上邮箱中收到的登录域名和账号名称，方便网易易盾运营支持定位账号信息。网易易盾运营支持将提供服务。

## 开通后的下一步

完成服务开通后，建议按以下顺序继续配置和验证：

1. 阅读[配置说明](/zh-CN/realtime-media/content-moderation/build/configuration)，确认透传字段和回调地址配置方式。
2. 按需接入[使用网易易盾视频审核](/zh-CN/realtime-media/content-moderation/build/netease-yidun-video-moderation)或[使用网易易盾音频审核](/zh-CN/realtime-media/content-moderation/build/audio-moderation-api)。
3. 参考[内容审核最佳实践](/zh-CN/realtime-media/content-moderation/build/best-practices)完成回调联调和问题排查。
4. 查看[计费说明](/zh-CN/realtime-media/content-moderation/reference/billing)，确认测试期结束后的套餐和费用规则。
