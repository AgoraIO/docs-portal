本文提供声网 RTSA Java SDK 的下架计划，请及时迁移或升级你的解决方案。

## 退休计划

亲爱的用户，感谢你一直以来对声网产品的关注与支持。我们发现，在过去近两年时间里，RTSA Java SDK 几乎没有新用户使用，也没有收到新的功能改进需求，目前版本还停留在 v1.9.2。但 RTSA 技术本身已经更新到了 v1.9.5。为把更多精力集中在给大家带来更好体验的产品上，经过慎重考虑，我们决定启动 RTSA Java SDK 退休计划。

RTSA Java SDK 已完成下架。历史下架时间点如下：

- 2025 年 4 月 30 日（不含），正式停止提供 RTSA Java SDK 新功能申请，不再提供 SDK 下载。
- 2025 年 6 月 30 日（不含），正式下线 RTSA Java SDK 文档。
- 2025 年 12 月 30 日后，不再提供对 RTSA Java SDK 的技术支持。

## 迁移方案

如果你仍在维护既有项目，请迁移到更为成熟的 [RTC Android SDK](/zh-CN/realtime-media/rtc/resources) 或 [RTC HarmonyOS SDK](/zh-CN/realtime-media/rtc/resources)；下述时间点为历史下架节点。迁移完成后，请仔细测试你的应用，确保各项功能都能正常使用。

- [RTC Android SDK 文档](/zh-CN/realtime-media/rtc)
- [RTC HarmonyOS SDK 文档](/zh-CN/realtime-media/rtc)

再次感谢你的理解与支持。如果你在迁移过程中有任何疑问，欢迎随时联系我们的[技术支持](https://ticket.shengwang.cn)团队，我们将全力协助你完成迁移工作。
