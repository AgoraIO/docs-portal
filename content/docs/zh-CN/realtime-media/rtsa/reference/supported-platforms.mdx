当前 RTSA SDK 使用 C 接口，支持的系统和架构如下。Java SDK 的历史兼容性单独列在文末。

SDK 核心基于 C99 和 [AOSL](https://github.com/AgoraIO-Community/aosl) 设计，具备良好的平台可移植性，可适配 Linux、RTOS 及裸机 MCU。具体兼容性要求见下表。

| 平台 | 支持版本 |
| --- | --- |
| Linux | <Slot name="supported-platforms-html-0-0-1" /> |
| RTOS | <Slot name="supported-platforms-rtos" /> |

<Slot for="supported-platforms-html-0-0-1">

- X86 / X86_64 架构：gcc 内核 2.6.35 及以上
- ARM 架构：
  - arm-linux-gnueabi 4.4.x 及以上
  - arm-linux-gnueabihf 4.8.x 及以上
  - aarch64-linux-gnu 4.8.x 及以上
  - arm-linux-musleabihf 5.2.x 及以上
  - arm-linux-musleabi 5.5.x 及以上
  - aarch64-linux-musl 5.5.x 及以上
  - arm-linux-uclibceabi 4.4.x 及以上
  - arm-linux-uclibceabihf 4.8.x 及以上
- MIPS 架构：
  - mips-linux-uclibceabihf 4.7.x 及以上
  - mips-linux-gnu 4.7.x 及以上
- RISCV 架构：
  - riscv32-linux-gnu
  - riscv32-linux-musl
  - riscv64-linux-gnu
  - riscv64-linux-musl
- 已适配芯片平台：全志、安凯微、瑞昱、君正、杰理及联发科的部分 Linux 芯片系列。

</Slot>

<Slot for="supported-platforms-rtos">

支持系统：FreeRTOS、LiteOS、ThreadX、Zephyr RTOS、RT-Thread、NuttX... 及厂商定制化 RTOS

已适配芯片平台：

- esp32 系列
- BK72xx 系列
- 展锐 rtos 系列
- ...

</Slot>

## 已下架的 Java SDK（历史兼容性）

:::warning[Java SDK 已下架]
RTSA Java SDK 已完成下架，以下兼容性表仅供历史项目参考，不属于当前可集成的 SDK 平台范围。2025 年 4 月 30 日起不再提供下载，2025 年 6 月 30 日起下线文档，2025 年 12 月 30 日后停止技术支持。迁移建议见 [RTSA Java SDK 退休计划](/zh-CN/realtime-media/rtsa/reference/sunset)。
:::
