## C 语言

媒体流加速 C 语言支持 Linux、Android 和 HarmonyOS 平台。

RTSA SDK 具体的兼容性要求见下表：

<table>
  <thead>
    <tr>
      <th>平台</th>
      <th>支持版本</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td style={{ verticalAlign: 'middle' }}>Linux</td>
      <td><div><ul><li>X86 / X86_64 架构：gcc 内核 2.6.35 及以上</li><li>ARM 架构：<ul><li>arm-linux-gnueabi 4.4.x 及以上</li><li>arm-linux-gnueabihf 4.8.x 及以上</li><li>aarch64-linux-gnu 4.8.x 及以上</li><li>arm-linux-musleabihf 5.2.x 及以上</li><li>arm-linux-musleabi 5.5.x 及以上</li><li>aarch64-linux-musl 5.5.x 及以上</li><li>arm-linux-uclibceabi 4.4.x 及以上</li><li>arm-linux-uclibceabihf 4.8.x 及以上</li></ul></li><li>MIPS 架构：mips-linux-uclibceabihf 4.7.x 及以上</li></ul></div></td>
    </tr>
    <tr>
      <td style={{ verticalAlign: 'middle' }}>HarmonyOS</td>
      <td><div><p>ARM 架构：arm-liteos-eabi 内核 liteOS 2.0</p></div></td>
    </tr>
    <tr>
      <td style={{ verticalAlign: 'middle' }}>Android</td>
      <td><div><p>Android 版本 ≥ 4.1</p><p>Android SDK 支持如下 ABI：</p><ul><li>armeabi-v7a</li><li>arm64-v8a</li><li>x86</li><li>x86-64</li></ul></div></td>
    </tr>
  </tbody>
</table>
