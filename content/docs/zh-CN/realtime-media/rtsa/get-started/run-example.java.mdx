## 前提条件

开始前，请确保满足如下要求：

- 一台开发机，安装 Windows、macOS 或 Linux 系统，并安装 Android Studio 最新版。
- 一台 Android 设备或虚拟机。Android 版本 4.1 或以上。
- 参考[开通服务](/zh-CN/realtime-media/rtsa/get-started/enable-service)获取 App ID 和 RTC 临时 Token。

## 获取 SDK

点击[下载](/zh-CN/realtime-media/rtsa/resources.c) RTSA Android SDK 并解压。

## 设置 App ID 和 RTC Token

在 SDK 包 `App` 目录下找到并打开 `MainActivity.java` 并修改以下值：

- 把 `APPID` 的值设置为你获取的 App ID。
- 把 `CHANNEL_NAME` 的值设置为 "demo_channel"。

    ```java
    private final static String APPID = <#APPID#>;
    private final static String CHANNEL_NAME = "demo_channel";
    ```

- 把 `null` 替换为你获取的 RTC 临时 Token。

    ```java
    int ret = mRtcService.joinChannel(CHANNEL_NAME, "0", null, chnlOption);
    ```

## 编译并运行示例项目

连接上 Android 设备后，用 Android Studio 打开示例项目，然后编译并运行示例项目。

运行成功后，你会在 Android 设备上看到如下画面。

![](https://web-cdn.agora.io/docs-files/1651128630591)

允许 App 请求的权限，点击 **START** 按钮即可体验示例项目。

## 验证推流效果

运行媒体流示例项目之后，你可以按如下步骤进行验证：

1. 打开 [Web Demo](https://webdemo.agora.io/index.html)，选择一个项目，然后填入 App ID 和 App 证书，完成初始化设置。
2. 点击左侧**快速开始**下的**音视频通话**。
3. 输入频道名 `Channel`、任意用户名 `User ID` 和 Token，点击 **Join**。成功加入频道后，你就可以看到和听到实时音视频流了。
