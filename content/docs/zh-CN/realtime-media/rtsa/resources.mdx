:::info[信息]
- 各版本 SDK 的发版详情请参考[发版说明](/zh-CN/realtime-media/rtsa/overview/release-notes)。
- 如何使用 SDK 实现 RTSA 基本功能请参考[实现媒体流和信令传输](/zh-CN/realtime-media/rtsa/get-started/implement-transmission)。
:::

媒体流加速 RTSA SDK 是轻量级的智能硬件专属 SDK。其极小包体、极低功耗的特性能够帮助硬件自编解码开发者实现音视频码流在互联网上的实时传输。如有其他平台适配或剪裁需求，请联系 sales@shengwang.cn。

你可以根据 SDK 包的命名了解支持的架构、操作系统、编辑工具链所用 C 库及编译选项等信息。
例如，armv7a-linux-uclibceabi 表示 SDK 支持 armv7 架构、Linux 系统，编译工具链采用 uClibc，编译选项为软浮点。
aarch64-linux-gnu 表示 SDK 支持 armv8 架构、Linux 系统，编译工具链采用 Glibc，编译选项为软浮点。
mipsel-linux-uclibceabihf 表示 SDK 支持 mipsel 架构、Linux 系统，编译工具链采用 uClibc，编译选项为硬浮点（包名带 hf 为硬浮点，否则为软浮点）。
