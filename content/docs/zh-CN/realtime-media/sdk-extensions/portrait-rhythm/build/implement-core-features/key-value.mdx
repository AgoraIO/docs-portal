参考下表在调用 `setExtensionProperty` 时传入对应的 `key` 和 `value`，即可实现对应的摄像头律动效果。

参考下表在调用 `setExtensionPropertyWithVendor` 时传入对应的 `key` 和 `value`，即可实现对应的摄像头律动效果。

| 摄像头律动效果 | key    | value | 效果说明                                                       |
| -------------- | ------ | ----- | ------------------------------------------------------------ |
| 心跳律动   | `mode` | `1`   | 焦距迅速变大再变小，类似心跳的节奏。                         |
| 人像律动       | `mode` | `2`   | 焦距缓慢变大然后变小，并且在最小的时候，图像抖动一下，并叠加一个人像虚影。 |
| 前后运镜   | `mode` | `3`   | 焦距缓慢变大然后变小，变焦速率平滑但不均匀。                 |
| 上下运镜   | `mode` | `4`   | 镜头先上移再下移。                                            |
| 左右运镜   | `mode` | `5`   | 镜头先左移再右移。                                            |
| 人像锁定 L | `mode` | `6`   | 人脸中心锁定在固定点位（画面中上部 2/5 处）。                 |
| 人像锁定 P | `mode` | `7`   | 人脸中心锁定在屏幕中轴上。                                   |
