## 适用场景

摄像头律动插件可灵活运用于以下场景：

- 娱乐直播领域：通过多种镜头律动模式凸显主播的独特风格和表达方式。
- 会议和教育场景：应用人像锁定模式，通过智能追踪和镜头调整，使视觉焦点持续聚焦于关键演示者，提升会议和教学的专业性和互动体验。

## 功能介绍

摄像头律动插件主要包含以下功能：

| 功能 | 描述 |
| --- | --- |
| 人像锁定模式 | 利用人脸识别技术实时追踪和锁定人像主体，保持其在画面中居中，避免主体偏移而影响互动体验。 |
| 心跳模式 | 通过智能算法模拟人类心跳的规律并融入到画面中，使画面变化更具动感。 |
| 人像光影模式 | 在主播身后显示人像的虚影，营造出独特的光影效果，使主播的表现更引人注目。 |
| 上下律动 | 不同的律动模式为镜头的运动提供了更加自由、灵活的选择，使画面呈现出更加多样化的视角，为用户提供更加开阔的交互空间。 |

| 前后律动 |  |
