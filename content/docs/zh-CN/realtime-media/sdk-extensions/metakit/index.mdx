## 适用场景

MetaKit 插件能够实现丰富的视频互动效果，你可以根据自己的场景需求灵活选用。

- 社交娱乐：通过 Animoji、人像边缘火焰等功能为主播提供更多创意和个性化的展示方式，增加社交娱乐和直播时的趣味性。
- 在线教育：通过 360 背景创造更为生动多彩的教学环境，提高学生的学习兴趣。
- 在线会议：通过 3D 打光营造媲美专业效果的演示环境，提升展示的视觉效果。

## 功能介绍

MetaKit 插件主要包含以下功能：

| 功能 | 描述 |
| --- | --- |
| 虚拟人 | 支持轻松生成虚拟人物，并通过捏脸、时尚换装等自定义选项打造独一无二的虚拟形象。实时捕捉用户表情，并在虚拟形象上进行还原渲染，增强互动的趣味性。 |
| Animoji | 通过 AR 和面捕技术，实时将各种 Animoji 效果应用于人像，呈现人像头部动态和表情的实时变化，展现出独特的个性。 |
| Sticker | 支持基于面捕关键点，选择不同的挂件和贴纸（包括 2D 和 3D 效果）进行装饰，如口罩、面纱、眼镜和头饰，增强互动趣味性。 |
| 打光 | 为用户提供了精准高效的光影效果，包括 3D 灯（一盏灯光，可自定义运动轨迹）、氛围灯（模拟多盏真实灯光效果，运动轨迹固定）、广告灯等模式。通过智能光影调控，用户可以在虚拟环境中体验到更真实的光影效果。 |
| 氛围特效 | 利用灯光特效为用户打造艺术氛围感，包括人像边缘火焰、人像边缘光线、极光、波纹等模式。 |
| 背景特效 | 为用户提供自定义 2D 背景、3D 背景和 360 全景虚拟背景效果。 |

  :::info[信息]
  声网 MetaKit 插件提供开放的美术生态，支持**一键导入**按声网美术标准制作的虚拟人、Animoji 和 Sticker 形象，为用户提供更灵活的创作和集成选项。如需使用该功能，请[联系技术支持](https://ticket.shengwang.cn/)。
  :::
