## Face

本文以 girl 虚拟人形象为例，介绍 MetaKit 插件提供的虚拟人捏脸资源。

对脸颊的突出 (`CK_raise_1`) 和脸颊的塌陷 (`CK_raise_2`) 的调节示例如下：

<video controls width="30%" height="auto" src="https://web-cdn.agora.io/doc-cms/uploads/1706758897677-Face_脸颊.mp4"></video>

支持对脸型的下列精细部位进行捏脸操作：

| 资源 ID         | 部位说明       |
|----------------|-------------------|
| FE_raise_1     | 额头的突出        |
| FE_raise_2     | 额头的塌陷        |
| TP_raise_1     | 太阳穴的突出      |
| TP_raise_2     | 太阳穴的塌陷      |
| CK_raise_1     | 脸颊的突出        |
| CK_raise_2     | 脸颊的塌陷        |
| MD_width_1     | 下颌骨向外        |
| MD_width_2     | 下颌骨向内        |
| MD_updown_1    | 下颌骨向下        |
| MD_updown_2    | 下颌骨向上        |
| C_width_1      | 下巴左右拉伸      |
| C_width_2      | 下巴左右紧缩      |
| C_updown_1     | 下巴上拉伸        |
| C_updown_2     | 下巴下拉伸        |
