## 功能介绍

SDK 拓展插件基于实时互动 SDK 能力，为音视频互动场景提供体验增强、智能特效和第三方能力集成。

## 常见场景

- 接入定制化音视频特效。
- 在实时互动场景中集成扩展能力。
- 快速使用第三方增强模块。
