---
title: "响应状态码"
---
在调用云端录制 RESTful API 过程中，你可能收到如下 HTTP 状态码：

- 如果 HTTP 状态码为 200，则请求成功。

- 如果 HTTP 状态码不为 200，则请求失败。你可以根据对应的响应 Body 中可能出现的如下字段排查问题：

  - `message`
  - `code` 和 `reason`
例如，请求失败时，你可能收到如下响应：

```json
# 401 Unauthorized
# 仅有 message
{
  "message": "Invalid authentication credentials"
}
```

```json
# 400 Bad Request
# 仅有 code 和 reason
{
  "code": 2,
  "reason": "Acquire: invalid resourceExpiredHour value!"
}
```

本文介绍你在调用云端录制 API 过程中可能会收到的错误码及其含义。你可以根据文档进行问题定位和排障。

## 通用状态码

| 状态码 | `message` 字段 | 错误说明 | 解决方法 |
| --- | --- | --- | --- |
| `400 Bad Request` | <Slot name="response-code-html-0-1-1" /> | 使用了非法的 App ID。 | 服务未开通，请先[开通服务](/zh-CN/realtime-media/recording/cloud-recording/get-started/enable-service)再调用 API。 |
| `401 Unauthorized` | <Slot name="response-code-html-0-2-1" /> | Authorization 缺失。 | 没有进行 HTTP 基础认证。在调用 API 时请确保[使用 HTTP 基础认证](/zh-CN/realtime-media/recording/cloud-recording/user-guides/http-basic-auth)获取 Authorization 的值。 |
| `401 Unauthorized` | <Slot name="response-code-html-0-3-1" /> | 非法的 Authorization。 | <Slot name="response-code-html-0-3-3" /> |
| `404 Not Found` | <Slot name="response-code-html-0-4-1" /> | 请求路由错误。 | 请检查发送请求的接口和 URL 是否正确 |
| `429 Too Many Requests` | <Slot name="response-code-html-0-5-1" /> | 被限流了。 | 请求太快被限制，可以[联系技术支持](https://ticket.shengwang.cn) 申请提高 API 配额，或者稍后进行重试，同时检查集成避免过多的 API 调用。 |

### Acquire

在调用 [`Acquire`](/doc/cloud-recording/restful/cloud-recording/operations/post-v1-apps-appid-cloud_recording-acquire) 后，响应中可能返回的状态码及报错信息如下：



| 状态码 | `code` 和 `reason` 字段 | 错误说明 | 解决方法 |
| --- | --- | --- | --- |
| `400 Bad Request` | <Slot name="response-code-html-1-1-1" /> | 请求参数错误。 | 请求 Header、接口、URL 或请求 Body 错误，请检查集成。具体原因可以参考 `reason` 字段的内容。 |
| `400 Bad Request` | <Slot name="response-code-html-1-2-1" /> | 使用了非法的 App ID。 | 服务未开通，请先[开通服务](/zh-CN/realtime-media/recording/cloud-recording/get-started/enable-service)再调用 API。 |

| `400 Bad Request` | <Slot name="response-code-html-1-4-1" /> | App 状态异常。 | App 服务异常，可能是由于欠费停机，请自行检查。 |
| `400 Bad Request` | <Slot name="response-code-html-1-5-1" /> | 配额受限。 | 并发任务数量限制，可以[联系技术支持](https://ticket.shengwang.cn) 申请提高 API 配额，或者稍后进行重试，同时检查集成避免任务泄漏。 |
| `500 Internal Server Error` | <Slot name="response-code-html-1-6-1" /> | 内部错误。 | 服务端错误，进行退避重试。 |
| `500 Internal Server Error` | <Slot name="response-code-html-1-7-1" /> | 无资源可用。 | 服务端错误，进行退避重试。 |
| `500 Internal Server Error` | <Slot name="response-code-html-1-8-1" /> | 请求超时。 | 服务端错误，进行退避重试。 |

### Start

在调用 [`Start`](/doc/cloud-recording/restful/cloud-recording/operations/post-v1-apps-appid-cloud_recording-resourceid-resourceid-mode-mode-start) 后，响应中可能返回的状态码及报错信息如下：

| 状态码 | `code` 和 `reason` 字段 | 错误说明 | 解决方法 |
| --- | --- | --- | --- |
| `201 Created` | <Slot name="response-code-html-2-1-1" /> | 任务已经启动了，重复调用 `Start` 方法。 |  |
| `206 Partial Content` | <Slot name="response-code-html-2-2-1" /> | 请求未完成。 | 请求已发送到后端，但是响应超时，建议进行重试。如果重试失败，建议重新调用 `Acquire` + `Start` 启动另外一路任务。 |
| `400 Bad Request` | <Slot name="response-code-html-2-3-1" /> | 请求参数错误。 | 请求 Header、接口、URL 或请求 Body 错误，请检查集成。具体原因可以参考 `reason` 字段的内容。 |
| `400 Bad Request` | <Slot name="response-code-html-2-4-1" /> | 重复启动，已经存在相同的 `cname` + `uid` 的任务。 | 检查集成避免该问题，或者更换 `cname` + `uid` 重新调用 `Acquire` + `Start` 启动任务。 |
| `500 Internal Server Error` | <Slot name="response-code-html-2-5-1" /> | 无资源可用。 | 建议重新调用 `Acquire` + `Start` 启动另外一路任务。 |
| `500 Internal Server Error` | <Slot name="response-code-html-2-6-1" /> | 请求超时。 | 后端服务暂时不可用，建议进行重试。\n如果重试失败，建议重新调用 `Acquire` + `Start` 启动另外一路任务。 |
