---
title: "实现合流录制"
---
云端录制支持单流录制、合流录制和页面录制三种模式。[合流录制](/zh-CN/realtime-media/recording/cloud-recording/overview/concepts#合流录制)模式指录制并混合频道内所有指定用户 ID 的音视频，生成一个包含所有指定用户 ID 音视频的 HLS (HTTP Live Streaming) 流媒体点播文件和可选的 MP4 格式文件。

## 前提条件

开始前，请参考[使用 RESTful API 开始云端录制](/zh-CN/realtime-media/recording/cloud-recording/get-started/quick-start)进行一次完整的录制流程体验。

## 实现步骤

本节介绍如何在[申请录制服务器资源](/zh-CN/realtime-media/recording/cloud-recording/get-started/quick-start#申请录制服务器资源)后，实现合流录制。

### 开始录制

在调用 [`start`](/doc/cloud-recording/restful/cloud-recording/operations/post-v1-apps-appid-cloud_recording-resourceid-resourceid-mode-mode-start) 方法时，你需要将 `mode` 参数设置为 `mix`，开启合流录制模式。

:::warning[注意]
录制模式的设置必须在开始录制的时候完成，不支持在录制开始后切换模式。
:::

以下介绍设置合流录制的 `clientRequest` 关键配置，确保你进行正确设置以实现预期的录制效果。

| 字段                  | 配置内容                         |
| :-------------------- | :------------------------------- |
| `recordingConfig`     | JSON Object，用于配置音频流订阅、转码、输出音频属性。 |
| `storageConfig`       |  JSON Object，第三方云存储设置。                  |

请求示例如下：

- 请求 URL：

    ```text
    https://api.sd-rtn.com/v1/apps/<yourappid>/cloud_recording/resourceid/<resourceid>/mode/mix/start
    ```

- 请求 Body 内容：

    以下示例重点展示 `recordingConfig` 和 `storageConfig` 的配置。

    ```json
    {
      "uid": "527841",
      "cname": "httpClient463224",
      "clientRequest": {
        "token": "<token if any>",
        //highlight-start
        "recordingConfig": {
          "maxIdleTime": 30,
          "streamTypes": 2,
          "audioProfile": 1,
          "channelType": 0,
          "videoStreamType": 0,
          "transcodingConfig": {
            "height": 640,
            "width": 360,
            "bitrate": 500,
            "fps": 15,
            "mixedVideoLayout": 1,
            "backgroundColor": "#FF0000"
          },
          "subscribeVideoUids": [
            "123",
            "456"
          ],
          "subscribeAudioUids": [
            "123",
            "456"
          ],
          "subscribeUidGroup": 0
        },
        //highlight-end
        "recordingFileConfig": {
          "avFileType": [
            "hls",
            "mp4"
          ]
        },
        //highlight-start
        "storageConfig": {
          "accessKey": "xxxxxxf",
          "region": 3,
          "bucket": "xxxxx",
          "secretKey": "xxxxx",
          "vendor": 2,
          "fileNamePrefix": [
            "directory1",
            "directory2"
          ]
        }
        //highlight-end
      }
    }
    ```

### 停止录制

录制完成后，调用 [`stop`](/doc/cloud-recording/restful/cloud-recording/operations/post-v1-apps-appid-cloud_recording-resourceid-resourceid-sid-sid-mode-mode-stop) 方法离开频道，停止录制。录制停止后如需再次录制，必须再调用 `acquire` 方法请求一个新的 Resource ID。

请求示例如下：

- 请求 URL：

    ```text
    https://api.sd-rtn.com/v1/apps/<yourappid>/cloud_recording/resourceid/<resourceid>/sid/<sid>/mode/mix/stop
    ```

- 请求 Body 内容：

    ```json
    {
      "cname": "httpClient463224",
      "uid": "527841",
      "clientRequest": {}
    }
    ```

## 录制生成文件

录制后共生成一个 M3U8 文件和多个 TS 文件。根据 `avFileType` 字段的设置，还有可能生成一个或多个 MP4 文件。录制文件的切片和命名原则详见[录制文件介绍](/zh-CN/realtime-media/recording/cloud-recording/user-guides/manage-file/introduce-recorded-files)。

## 开发注意事项

Native 端、Web 端及框架端用户在用户中途停止发流或退出频道后的显示策略如下：

| 取消发布本地视频 | 禁用视频轨道 | 退出频道 |
| --- | --- | --- |
| <Slot name="set-composite-html-0-1-0" /> | <Slot name="set-composite-html-0-1-1" /> | 优先显示画布背景图，如无画布背景图则显示画布背景色。如果画布背景色也未设置，则显示默认的黑色画布背景色。 |

<Slot for="set-composite-html-0-1-0">

- 3.5 秒内显示视频画面的最后一帧。
        - 3.5 秒后显示预设的用户背景图或画布背景图。如果未设置背景图，则显示画布背景色。如果画布背景色也未设置，则显示默认的黑色画布背景色。

</Slot>

<Slot for="set-composite-html-0-1-1">

- 3.5 秒内显示视频画面的最后一帧。
        - 3.5 秒后显示预设的用户背景图或画布背景图。如果未设置背景图，则显示画布背景色。如果画布背景色也未设置，则显示默认的黑色画布背景色。

</Slot>
