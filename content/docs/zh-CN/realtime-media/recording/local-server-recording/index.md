title: "本地服务端录制"
---
本地服务端录制 SDK 是声网针对音视频互动研发的录制组件，与声网 RTC SDK 兼容，能帮助开发者快速、灵活地部署录制服务，实现音视频通话或直播录制，生成 MP4 格式的录制文件。

  本地服务端录制 SDK 需要部署在 Linux 服务器上。如果你不想自行部署和维护，也可以选用声网[云端录制](/zh-CN/realtime-media/recording/cloud-recording)。
