本文介绍如何开通云市场服务。

## 登录声网控制台

如果你是第一次使用声网服务，点击[注册账号](https://sso.shengwang.cn/cn/v4/signup/with-sms)前往控制台进行注册。注册成功后会自动登录。

如果你已经拥有声网账号，可以直接[登录控制台](https://console.shengwang.cn//)。

:::info[信息]
注册和登录过程中如果遇到疑问，可以查看[快速开始](/zh-CN/introduction/quickstart)。
:::

## 创建声网项目
成功登录控制台后，按照以下步骤创建一个声网项目：

1. 展开控制台左上角下拉框，点击**创建项目**按钮。
2. 在弹出的对话框内，依次选择**项目类型**，输入**项目名称**，选择**场景标签**和**鉴权机制**。其中鉴权机制推荐选择**安全模式**，**调试模式**的安全性较低。

## 获取 App ID
成功创建项目后，声网会给每个项目自动分配一个 App ID 作为项目唯一标识。你可以直接在**总览**页面的**项目信息**栏，点击 App ID 右侧的复制按钮来获取当前项目的 App ID。

你需要保存好复制的 App ID，后续调用 API 进行初始化等操作时需要传入你获取的 App ID。

## 获取临时 Token
对于鉴权机制为安全模式的项目，在后续调用 API 进行加入频道等操作时，你还需要传入频道名和 Token 来对用户进行鉴权。

为方便体验和测试，在 App 调试阶段你可以先从控制台获取临时 Token（有效期为 24 小时），无需自行部署 Token 服务器。但在 App 正式上线前，你必须在自己的服务端部署并生成 Token。

在控制台左上角的下拉框，切换到你想要获取临时 Token 的项目，然后按如下步骤获取临时 Token：

1. 在**总览**页面的**项目信息**栏，点击**临时 Token 生成器**。
2. 在**生成临时 Token** 页面，点击**添加产品**。
3. 选择 **RTC** 产品，输入频道名，例如 `testChannel`。然后保存好输入的内容。
4. 点击**确认**。
5. 成功生成临时 Token 后，点击 Token 右侧的复制按钮，保存好复制的 Token。

## 购买和激活插件

部分云市场插件支持通过声网控制台自助购买。

### 1. 购买插件

参考如下步骤购买插件：

1. 进入声网控制台上的插件购买页：
    - 方式一：在声网控制台上的[云市场](https://console.shengwang.cn/marketplace/list/all)页面点击需要购买的插件。
    - 方式二：浏览[声网云市场](https://www.agora.io/cn/marketplace)页面，点击需要购买的插件，然后点击**进入控制台**。

![进入控制台](/img/marketplace/enter-console.png)

2. 在插件购买页，选择需要的套餐、数量等，点击**购买**。如果插件购买页显示**联系我们**，请按照界面提示联系销售购买，无需进行下文的后续步骤。
3. 阅读并勾选同意服务条款和隐私政策，点击**确认**。
4. （可选）如果插件使用 License 计费，你还需要在弹窗中配置 License 的具体信息，然后点击**确定**。部分插件的 License 需要审核，请耐心等待 2～3 个工作日。

![license 弹窗](https://web-cdn.agora.io/docs-files/1659602353600)

5. 根据屏幕提示，完成支付。

### 2. 激活插件

插件购买成功后，需要在声网项目中激活才能在 App 中使用。参考如下步骤激活插件：

1. 进入声网控制台左侧导航栏的[云市场 - 我的云产品](https://console.shengwang.cn/marketplace/list/own)页面。
2. 点击需要激活的插件，进入插件配置页。
3. 在插件配置页找到需要激活插件的项目，点击激活按钮。

![激活插件](/img/marketplace/activate.png)

  在弹窗中点击**确认**，激活插件。

:::info[信息]
插件激活成功后，对应的 `appKey` 和 `appSecret`（用于插件服务商对你的 App 鉴权）会显示在页面顶部的弹窗中。你需要自行保存，以便后续使用。
:::
