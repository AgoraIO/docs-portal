智能会议纪要服务融合了讯飞的语音实时转写能力和多家厂商的大模型能力，可以获取声网 RTC 频道中的音频流并生成结构化的会议总结，并且支持自定义会议纪要的输出格式和风格。

本文介绍如何为你的项目部署智能会议纪要服务。

## 部署服务

参考以下步骤，使用声网提供的 Dockerfile 构建和部署：

1. 联系 sales@shengwang.cn 获取示例项目。
2. 打开 `smart_meeting_minutes_go_app/manifest.json` 文件，将以下字段替换为对应信息：
    - `<AGORA_RTC_APP_ID>`：声网 App ID，获取方式参考[开通云市场服务](/zh-CN/realtime-media/marketplace/get-started/enable-service#购买和激活插件)。
    - `<IFLY_APP_ID>`、`<IFLY_API_KEY>` 和 `<IFLY_API_SECRET>`：讯飞语音实时转写相关配置。详情请联系声网获取。
    - 大模型相关配置。详情请联系声网获取。
3. 构建镜像，命令行如下：

    ```shell
    # 构建镜像
    cd out/linux/x64/test/rte_runtime/dev/go/smart_meeting_minutes_go
    docker build -t smart_meeting_minutes_go:$version$ -f <RTE_SRC>/test/rte_runtime/dev/go/smart_meeting_minutes_go/dockerfile/all_in_one.dockerfile .
    # （可选）给镜像打上标签
    docker tag smart_meeting_minutes_go:$version$ hub-master.agoralab.co/server/app/smart_meeting_minutes_go:$version$
    # （可选）将镜像推送到你的 Docker Hub
    docker push hub-master.agoralab.co/server/app/smart_meeting_minutes_go:$version$
    ```

4. 运行镜像，命令行如下：

    ```shell
    docker run -p 8001:8001 smart_meeting_minutes_go:$version$
    ```
