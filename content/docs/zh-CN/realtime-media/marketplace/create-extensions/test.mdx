---
title: "测试插件"
---
开发插件以及打通服务开通和计量计费后，你需要对插件接口的功能和性能进行自测。

本页介绍测试插件的必需步骤。

## 测试插件相关接口

在正式发布之前，你需要自行测试插件相关接口的功能和性能，并将测试报告提交给声网。

测试报告中必须包含如下信息：

- 以下功能已经实现的证明：
  - 插件可以在声网 SDK 内正常开启和加载。
  - 通过 `setExtensionProperty` 方法设置的所有 key-value 键值对可以正常生效。
  - 插件的所有回调可以通过 `IMediaExtensionObserver`正常返回。
- 以下性能数据：
  - 处理每一帧音频或视频所需的时间。
  - 最大内存需求。
  - 最大 CPU/GPU 需求。

## 测试服务开通和计量计费接口

为了确保买家在声网控制台上可以购买和激活你的插件，你需要对服务开通和计量计费 RESTful API 进行测试。具体步骤如下：

1. 联系声网，提交 RESTful API 接口的详细信息，包括接口 URL、apiKey、apiSecret 等。

   声网工作人员完成信息审核后，会向你发送测试环境地址和登录账号。

2. 在测试环境中登录，并进行如下操作：

   1. 找到你的插件，点击**了解更多**。
   2. 在一个项目中启用、购买、停用你的插件，检查对应的服务开通 RESTful API 是否正常工作。
   3. 在一个项目中使用一段时间你的插件，检查对应的计量计费 RESTful API 是否正常工作。

## 后续步骤

你的插件需要提交给声网进行发布前的最终审核。详见[发布插件](/zh-CN/realtime-media/marketplace/create-extensions/publish)。
