---
title: "发布插件"
---
开发和测试完毕后，你需要将插件提交给声网进行发布前的最终审核，包括最新的插件详细信息。

本页介绍如何将插件发布到声网云市场。

## 前提条件

在发布插件之前，请确保你已经完成[测试插件](/zh-CN/realtime-media/marketplace/create-extensions/test)的所有步骤。

## 申请审核

插件经过审核才能发布。你需要联系声网并提供以下材料：

1. 开发好的插件。

   请确保你的插件为正确的格式：

   - Android： `.aar` 或 `.so`
   - iOS/macOS： `.framework` 或 `.xcframework`
   - Windows：`.dll`
   - Web：npm 下载链接

2. 插件的测试报告，需要包括插件接口的功能测试和性能测试。具体要求详见[测试插件](/zh-CN/realtime-media/marketplace/create-extensions/test)。
3. 插件详情页的内容：

      | 序号 | 内容 | 要求 |
| --- | --- | --- |
| 1 | 产品名称 | ”品牌名+产品功能”，例如“云知声实时语音转写”、“火山引擎智能美化特效”。 |
| 2 | 公司名称 | 准确的公司名称。 |
| 3 | 公司官网链接 | 需要 https 的链接。 |
| 4 | 公司 Logo（方形） | 500 x 500 像素的 PNG、JPG 或 JPEG 文件。 |
| 5 | 公司 Logo（矩形） | 1000 x 500 像素的 PNG、JPG 或 JPEG 文件。 |
| 6 | 产品简介 | 简要介绍产品功能。 |
| 7 | 产品详细介绍 | 分为概览、使用场景、产品优势三个部分。 |
| 8 | 产品效果图 | <Slot name="publish-html-0-8-2" /> |
| 9 | 技术支持链接 | 需要 https 的链接。 |
| 10 | 使用条款链接 | 需要 https 的链接。 |
| 11 | 隐私政策链接 | 需要 https 的链接。 |
| 12 | 插件说明文档 | 介绍如何使用插件以及每个 API 的功能。可以参考[编写插件说明文档](/zh-CN/realtime-media/marketplace/create-extensions/doc-template)直接编辑。 |

<Slot for="publish-html-0-8-2">

5 张 1600 x 900 像素的图片，图片支持以下格式：

            - 静态图：PNG、JPG 或 JPEG 文件。
            - 动态图：GIF 文件，长宽比为 16:9。

</Slot>

收到你的申请后，声网会在 7 个工作日内进行审核。如果审核通过，声网会向你发送通知邮件。如果审核不通过，你需要根据审核结果处理存在的问题。

## 正式发布

审核结束后，声网会在[声网云市场](https://www.agora.io/cn/marketplace)上发布你的插件，所有 App 开发者都可以浏览和购买。
