title: 云市场概览
---
声网云市场提供可以在声网 SDK 中快速添加并集成的第三方插件，帮助开发者在 App 中轻松实现丰富的实时音视频互动功能。

开发者往往需要花费大量的时间选择、比价、集成和测试不同的音视频 SDK 组合，导致 App 的整体开发周期较长。声网云市场能够帮助开发者缩短实时互动 App 的开发时间，让开发者更加专注于业务逻辑和用户体验。

## 优势介绍

声网云市场的参与者包括 App 开发者和插件服务商：

- App 开发者：希望基于声网 SDK 在 App 中快速添加实时音视频互动特性的开发者。
- 插件服务商：提供美颜、语音识别等实时音视频互动插件的第三方厂商。

本节分别介绍声网云市场为 App 开发者和插件服务商提供的主要优势。

### App 开发者

对实时互动 App 开发者来说，声网云市场插件具有以下优势：

- **集成更简单快速**：凭借插件，开发者可以快速简单地在 App 中实现新功能。集成声网 SDK 后，开发者只需要调用几个接口就能实现插件提供的音视频互动功能，省去了手写几百行代码的麻烦。
- **选择丰富，灵活搭配**：声网云市场的合作伙伴覆盖音视频行业主流插件服务商，提供美颜、测评、语音转写、AI 视觉等插件。你可以在声网 SDK 中同时添加多个插件，组合成丰富的应用场景。
- **一站式体验**：你可以在声网控制台上管理所有插件、查看每个插件的详细信息，无需跳转多个网页。

### 插件服务商

对插件服务商来说，入驻声网云市场具有以下优势：

- **用户增长**：声网为全球开发者提供优质产品和服务。通过声网云市场，你可以触达规模可观的开发者群体，创造更多收入。
- **用户黏性更高**：插件大大丰富了声网 SDK 的功能。声网和插件服务商一起致力于打造更好的用户体验，建立强大的生态系统。

## 平台支持

云市场插件需要与 RTC SDK v4.x 搭配使用，支持 iOS、Android、macOS、Windows、Web、Flutter 平台，对应的平台兼容性要求与 RTC SDK 相同。
