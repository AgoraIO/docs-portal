title: "Fastboard SDK 概览"
description: "用预置白板 UI 和组件快速集成实时视觉协作能力。"
---

Fastboard SDK 基于 Whiteboard SDK 构建，提供默认白板 UI、可自定义样式的小组件和常用插件能力，默认支持多窗口模式。它适合希望快速上线白板体验，同时保留一定自定义空间的在线教育、会议协作和互动娱乐场景。

如果你需要更高程度的自定义，也可以结合 Whiteboard SDK 的底层能力，自行实现业务 UI、状态同步和复杂白板工作流。

## 产品特性

<CardGrid>
  <FeatureCard title="预置白板 UI">
    内置常用白板界面和交互组件，减少从零实现 UI 的工作量，帮助你更快完成集成。
  </FeatureCard>
  <FeatureCard title="文件展示与文档转换">
    支持展示图片、PPT、PPTX、Word 和 PDF 等资料，并可结合文档转换服务展示课件内容。
  </FeatureCard>
  <FeatureCard title="多窗口与插件">
    默认支持多窗口模式，并可通过插件扩展白板体验，例如展示课件、小窗应用和自定义组件。
  </FeatureCard>
  <FeatureCard title="可定制组件">
    在保留默认 UI 的基础上，可根据业务需要调整组件样式和交互行为。
  </FeatureCard>
  <FeatureCard title="服务端 API">
    通过 RESTful API 完成 Token 生成、房间管理、截图管理、场景管理和文档转换等服务端操作。
  </FeatureCard>
  <FeatureCard title="稳定可靠">
    声网全球分布式服务和容灾机制为白板实时协作提供高可用保障。
  </FeatureCard>
</CardGrid>
