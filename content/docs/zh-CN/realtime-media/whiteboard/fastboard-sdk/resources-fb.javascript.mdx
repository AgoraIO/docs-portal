## 通过 npm 集成 SDK

使用该方法需要先安装 npm，详见 [npm 快速入门](https://www.npmjs.com.cn/getting-started/installing-node/)。

在项目目录下，使用命令行运行以下命令：

```shell
npm add @netless/fastboard @netless/window-manager white-web-sdk
```
