title: "方案对比"
---
为满足不同的需求，声网互动白板提供如下两套客户端 SDK 供你选择：

:::warning[注意]
Fastboard SDK 与 Whiteboard SDK **不互通**，声网建议你根据自身需求从中选择一套使用。
:::

| Fastboard SDK | Whiteboard SDK | Column 3 | Column 4 |
| --- | --- | --- | --- |
| 产品定位 | 互动白板新一代 SDK。Fastboard SDK 基于 Whiteboard SDK 开发，简化了 API，并提供核心功能的实现和默认 UI；此外，Fastboard SDK 还集成窗口管理器（[window-manager](https://github.com/netless-io/window-manager)）和开源插件库 [netless-app](https://github.com/netless-io/netless-app) 中的部分插件，方便开发者快速添加插件。 | 声网互动白板 PaaS 解决方案，提供丰富的数据和状态回调，支持高度自定义业务逻辑和 UI。 |  |
| 产品边界 | UI | 带 UI 交付，UI 是开源的，可以直接使用，包括工具条、页面控制组件、视角控制组件、重做和撤销按钮等，并提供设置 UI 的 API。如不符合需求需自己覆盖默认 UI 进行重写，官方不提供自定义 UI 支持。 | 无界面 UI，纯 API 交付。你需要自行实现所有 UI。 |
| 白板插件 | 官方内置开源插件，包括 docsViewr、MediaPlayer、Monaco、Countdown、GeoGebra、EmbeddedPage、Plyr，如不符合需求需自己基于开源代码进行二次开发，官方不提供自定义功能支持。 | 不支持 |  |
| 社区开源插件 | 社区贡献插件包括：PDF.js、Quill、flowchart 等，官方不提供自定义功能支持，可参考[社区插件开发文档](https://github.com/netless-io/window-manager/blob/master/docs/develop-app.md)进行开发。 | 不提供 |  |
| 适用客户 | 适用于开发资源有限、排期紧，且需要快速上线在线互动教学场景并有定制化需求的客户。 | 适用于开发资源充足、对定制化需求较高的客户。 |  |
| 开发成本 | 低 | 较高 |  |
| 特性支持 | 所有特性 | 所有特性 |  |
| 平台支持 | <Slot name="solution-compare-html-0-8-1" /> | <Slot name="solution-compare-html-0-8-2" /> |  |

- Android：Android 5.0（SDK API Level 21）及以上版本
- iOS：iOS 9.0 及以上版本，支持平台间互通
