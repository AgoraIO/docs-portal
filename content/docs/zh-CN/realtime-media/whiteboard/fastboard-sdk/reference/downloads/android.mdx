## 通过 Maven 集成 SDK

```groovy
dependencyResolutionManagement {
  repositoriesMode.set(RepositoriesMode.FAIL_ON_PROJECT_REPOS)
  repositories {
      google()
      mavenCentral()
      maven { url 'https://jitpack.io' }
  }
}
```

```groovy
dependencies {
    implementation 'com.github.netless-io:fastboard-android:1.8.2'
}
```
