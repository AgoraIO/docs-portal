## 通过 CocoaPods 集成 SDK

```ruby
platform :ios, '10.0'
use_frameworks!
target 'ExampleFastboard' do
    pod 'Fastboard'
end
```

:::info[更新 SDK]
对于已通过 CocoaPods 集成旧版本 Fastboard SDK 的工程，运行 `pod update Fastboard` 即可更新 Fastboard iOS SDK 的版本至最新。最新版本号以及相关更新内容请查看[发版说明](/zh-CN/realtime-media/whiteboard/fastboard-sdk/reference/release-notes-fb)。
:::
