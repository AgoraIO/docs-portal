:::info[SDK 合规信息公示]
**功能介绍：** 为开发者提供基于互动白板能力的默认白板 UI、多窗口、插件和可自定义组件。

**基本信息：** SDK 名称为 Fastboard SDK；开发者为上海声网科技有限公司；版本号、发布日期、包名和 MD5 值见下列下载选项。

**使用说明：** 各版本 SDK 的发版详情请参考[发版说明](/zh-CN/realtime-media/whiteboard/fastboard-sdk/reference/release-notes-fb)，加入白板房间请参考[加入白板房间](/zh-CN/realtime-media/whiteboard/fastboard-sdk/get-started/join-room-fb)，个人信息处理规则请参考 [SDK 隐私政策](https://www.shengwang.cn/SDK-privacy-policy/)。
:::

## 集成方式

```bash tab="Web" tabGroup="fastboard-install"
npm add @netless/fastboard @netless/window-manager white-web-sdk
```

```groovy tab="Android" tabGroup="fastboard-install"
dependencies {
    implementation 'com.github.netless-io:fastboard-android:1.6.2'
}
```

```ruby tab="iOS" tabGroup="fastboard-install"
platform :ios, '10.0'
use_frameworks!
target 'ExampleFastboard' do
    pod 'Fastboard'
end
```
