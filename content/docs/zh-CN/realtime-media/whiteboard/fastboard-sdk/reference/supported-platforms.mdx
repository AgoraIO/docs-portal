---
title: "平台支持"
description: "Fastboard SDK 支持的平台、系统版本和浏览器要求。"
---

Fastboard SDK 支持多种平台，并支持平台间互通，具体的兼容性要求见下表：

| 平台 | 支持版本 | 支持版本 | 支持版本 | 支持版本 |
| --- | --- | --- | --- | --- |
| Android | 兼容 Android 5.0 (SDK API Level 21) 及以上版本 |  |  |  |
| iOS | 兼容 iOS 9.0 及以上版本 |  |  |  |
| Web | Windows | Chrome | 69+ | 完整支持 69+，降级版本 58+ |
|  | Windows | Edge | 79+ | 完整支持 79+，降级版本 12+ |
|  | Windows | Firefox | 105+ | 完整支持 105+，降级版本 58+ |
|  | macOS | Chrome | 69+ | 完整支持 69+，降级版本 58+ |
|  | macOS | Safari | 16+ | 完整支持 16+，降级版本 11+ |
|  | macOS | Firefox | 105+ | 完整支持 105+，降级版本 58+ |
