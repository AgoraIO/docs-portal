本文提供声网 Fastboard SDK for Android 的发版说明。

声网 Fastboard SDK 是为帮助开发人员快速构建白板应用推出的新一代白板 SDK。Fastboard SDK 基于互动白板 SDK 开发，对复杂的 API 进行封装，简化了接口调用逻辑，并提供核心功能的实现和默认 UI；此外，Fastboard SDK 还集成窗口管理器（[Window Manager](https://github.com/netless-io/window-manager)）和常用插件，帮助开发者轻松扩展白板应用的功能。使用 Fastboard SDK，你无需深入学习互动白板复杂的概念，只需几行代码即可加入白板房间，并立即使用丰富的工具体验实时互动协作。

## 1.7.2 版

该版本于 2025 年 7 月 11 日发布。

### 新增特性

#### 注册第三方窗口应用

该版本在 `FastRoom` 类下新增 [`registerApp`](/api-ref/fastboard/android/fastboard-api#registerapp) 方法，用于向白板房间注册第三方窗口应用。该方法允许你注册可以在白板内作为独立窗口运行的外部应用，支持两种注册方式：

- **本地脚本注册**：使用本地 JavaScript 代码（推荐方式，可靠性高）
- **远程包注册**：使用远程 URL（可能因网络原因失败）

同时新增 [`FastRegisterAppParams`](/api-ref/fastboard/android/fastboard-api#fastregisterappparams) 类，用于配置注册参数，包含应用名称、脚本代码、URL 地址等配置选项。

:::warning[注意]
- 注册必须在加入房间前完成，以确保应用能够正常加载。
- 确保所有客户端使用一致的应用版本，避免运行时问题。
:::

#### 设置画笔粗细范围

该版本在 `FastUiSettings` 类下新增 [`setStrokeRange`](/api-ref/fastboard/android/fastboard-api#setstrokerange) 方法，用于设置工具箱中线条宽度滑块的范围。该方法配置工具箱扩展面板中线条宽度滑块的最小值和最大值，用户在使用铅笔、矩形、圆形等绘图工具时，可以在此范围内调整线条宽度。默认范围为 1 到 24。

### 问题修复

- 调用 [`setToolboxEdgeMargin`](/api-ref/fastboard/android/fastboard-api#settoolboxedgemargin) 时，如果未指定 Toolbox Gravity，则该方法无效。
- 首次调用 [`setResource`](/api-ref/fastboard/android/fastboard-api#setresource) UI 更新不生效。
- 调用 [`setToolsColors`](/api-ref/fastboard/android/fastboard-api#settoolscolors) 设置了自定义颜色列表后，初次进入房间时的画笔颜色不在这组颜色里，不符合预期。

### API 变更

#### 新增

- [`registerApp`](/api-ref/fastboard/android/fastboard-api#registerapp)
- [`FastRegisterAppParams`](/api-ref/fastboard/android/fastboard-api#fastregisterappparams)
- [`setStrokeRange`](/api-ref/fastboard/android/fastboard-api#setstrokerange)

## 1.6.2 版

该版本于 2024 年 9 月 14 日发布。

### 新增特性

#### 手动加载白板视图

该版本新增 [`preloadWhiteboardView`](/api-ref/fastboard/android/fastboard-api#preloadwhiteboardview) 方法，用于手动执行一次白板视图预加载，提升下次加入房间的速度。使用该功能前需要确保 [`FastboardConfig`](/api-ref/fastboard/android/fastboard-api#fastboardconfig) 中的 `autoPreload` 为 `false`。

### API 变更

#### 新增

- `preloadWhiteboardView`
- `FastboardConfig` 新增 `autoPreload`

## 1.6.0 版

该版本于 2024 年 2 月 4 日发布。

### 新增特性

#### 插入文档

`FastRoom` 类新增 [`insertStaticDoc`](/api-ref/fastboard/android/fastboard-api#insertstaticdoc) 和 [`insertPptx`](/api-ref/fastboard/android/fastboard-api#insertpptx) 方法，分别用于插入转换后的 PDF 等静态文档和 PPTX 动态文档。

#### 白板预加载

新增 [`FastboardConfig`](/api-ref/fastboard/android/fastboard-api#fastboardconfig) 类用于 `Fastboard` 对象的辅助配置，可通过调用 `setConfig` 方法修改配置。其中，`FastboardConfig.enablePreload` 和 `FastboardConfig.preloadCount` 分别用于开关白板预加载功能和指定预加载的 WebView 数量，配置后可提升白板加载速度。

#### 新白板教具

该版本新增了以下白板教具：

- 新增铅笔橡皮工具 `FastAppliance.PENCIL_ERASER`，用于擦除局部铅笔笔迹。
- 新增抓手工具 `FastAppliance.HAND`，用于移动视图。

#### 白板日志记录

该版本新增 [`FastLogger`](/api-ref/fastboard/android/fastboard-api#fastlogger) 类，提供了一个灵活的白板运行日志记录工具，可以方便地记录 `debug`、`info`、`warn`、`error` 共四种不同级别的日志信息。你既可以调用 `setLogger` 方法自定义日志记录器，以适应不同的日志记录需求，也可以使用系统的 `Log` 类进行日志记录。

### 优化

- 调用 `FastRoom.insertImage` 方法插入图片，默认将图片置于当前视图的中心。
- 禁用了房间加入成功后的全量房间状态回调 `roomState`，客户端需要通过 `Room.getRoomState()` 来获取完整的 `RoomState`。

### API 变更

#### 新增

- `insertStaticDoc`
- `insertPptx`
- `DocPage`
- `setConfig`
- `FastboardConfig`
- `FastAppliance` 下新增：
  - `PENCIL_ERASER`
  - `HAND`
- `FastLogger`
  - `setLogger`
  - `Logger`
  - `warn`
  - `debug`
  - `info`
  - `error`

#### 废弃

- `insertDocs`

## 1.3.4 版

该版本于 2023 年 4 月 25 日发布。

### 新增特性

#### 修改白板底色

该版本在 `FastRoom` 类下新增 [`setResource`](/api-ref/fastboard/android/fastboard-api#setresource) 方法，用于修改白板的相关颜色资源。你可以通过重写 [`FastResource`](/api-ref/fastboard/android/fastboard-api#fastresource) 类中的方法来自定义颜色。

#### 设置窗口比例

该版本在 [`FastRoomOptions`](/api-ref/fastboard/android/fastboard-api#fastroomoptions) 类中新增 `containerSizeRatio` 属性，用于修改本地显示窗口中内容的高宽比。

#### 显示用户光标

该版本在 [`FastRoomOptions`](/api-ref/fastboard/android/fastboard-api#fastroomoptions) 类中新增 `userPayload` 属性，用于在白板房间中同步其他用户的光标位置并显示对应昵称和头像。

#### 设置房间读写权限

该版本在 `FastRoom` 类下新增了以下方法：

- [`setWritable [1/2]`](/api-ref/fastboard/android/fastboard-api#setwritable1) 和 [`setWritable [2/2]`](/api-ref/fastboard/android/fastboard-api#setwritable2)：设置用户在房间中为具有读写权限的**互动模式**或只有只读权限的**订阅模式**，其中，`setWritable [2/2]` 支持通过回调函数异步处理调用结果。
- [`isWritable`](/api-ref/fastboard/android/fastboard-api#iswritable)：获取本地用户在当前互动白板实时房间是否为互动模式。

:::tip[提示]
在用户数量较多的房间中，限制房间中处于互动模式的用户数量可以有效提高白板房间连接的稳定性和房间可承载人数上限。
:::

#### 调整工具条边距

该版本在 `FastUiSettings` 类下新增 [`setToolboxEdgeMargin`](/api-ref/fastboard/android/fastboard-api#settoolboxedgemargin) 方法，用于设置工具条和白板侧边的边距。

### 改进

该版本优化了用户界面，并调整了白板工具图标样式和白板工具条的默认边距。

### 问题修复

该版本修复了以下问题：

- 使用文字工具时偶现失焦。
- `FastUiSettings` 类下的 `hideRoomController` 在启动阶段偶现失效。

## 1.2.3 版

该版本于 2022 年 10 月 28 日发布。

### 升级必看

#### API 更名

`FastRoom` 类下的 `setStokeWidth` 更名为 `setStrokeWidth`，详见 [`setStrokeWidth`](/api-ref/fastboard/android/fastboard-api#setstrokewidth)。

### 新增特性

#### 新版文档转换服务支持

该版本在 [`FastInsertDocParams`](/api-ref/fastboard/android/fastboard-api#insertdocs) 类中新增以下属性以支持新版文档转换服务：

- `dynamicDoc`: Boolean。文档转换任务类型是否为动态转换。

- `converterType`：枚举。文档转换服务版本，取值如下：
  - `Projector`：新版。详见[新版文档转换服务](/zh-CN/realtime-media/whiteboard/fastboard-sdk/build/extend-whiteboard/convert-files)。
  - `WhiteboardConverter`：旧版（默认值）。旧版文档转换服务当前已不再维护。

### 问题修复

该版本修复了 `FastInsertDocParams` 中的参数顺序错误。

## 1.2.0 版

该版本于 2022 年 5 月 27 日发布。

### 新增特性

#### 白板用户界面的控件配置

为支持自定义白板用户界面，该版本在 `FastUiSettings` 类中新增如下方法，用于设置白板用户界面上的控件：

- [`showRoomController`](/api-ref/fastboard/android/fastboard-api#showroomcontroller)：展示白板用户界面上的控件。
- [`hideRoomController`](/api-ref/fastboard/android/fastboard-api#hideroomcontroller)：隐藏白板用户界面上的控件。
- [`setToolsExpandAppliances`](/api-ref/fastboard/android/fastboard-api#settoolsexpandappliances)：设置展开模式下工具条包含的工具集
- [`setToolsCollapseAppliances`](/api-ref/fastboard/android/fastboard-api#settoolscollapseappliances)：设置折叠模式下工具条包含的工具集。
- [`setToolsColors`](/api-ref/fastboard/android/fastboard-api#settoolscolors)：设置白板工具的颜色。
- [`setToolboxGravity`](/api-ref/fastboard/android/fastboard-api#settoolboxgravity)：设置工具条在白板上的位置。

#### 白板用户界面的样式配置

该版本在 `FastRoom` 类中新增 [`setFastStyle`](/api-ref/fastboard/android/fastboard-api#setfaststyle) 方法，用于设置白板用户界面的样式。通过该方法，你可以修改白板用户界面的主题色彩和主题模式。

## 1.0.0 版

该版本于 2022 年 3 月 16 日发布，是 Fastboard SDK 首个版本。

### 功能特性

#### 白板核心功能的默认实现和 UI

该版本直接实现了互动白板的核心基础功能，并提供默认的 UI。集成 Fastboard SDK 并调用 `join` 方法加入白板房间后，即可使用这些功能。该版本实现的核心功能如下：

- 白板工具栏，包括铅笔、文本编辑、图形工具等所有白板基础编辑工具，并支持设置线条粗细、字体大小和颜色。
- 页面管理，包括新增页面、页面跳转、页面缩放。
- 撤销、重做

尽管 Fastboard SDK 提供了上述功能的默认实现，但也提供了如下 API，方便你根据需要自行开发：

- `setAppliance`
- `setStrokeWidth`
- `setStrokeColor`
- `undo`
- `redo`

#### 展示文件

Fastboard SDK 支持在白板中插入和展示多种形式的文件，例如，PNG、JPG 格式的图片，MP3、MP4 格式的音视频，以及 PPT、PPTX、DOC、DOCX、PDF 等格式的文档。具体实现步骤参考[展示文件](/zh-CN/realtime-media/whiteboard/fastboard-sdk/build/manage-whiteboard/present-files-fb)。

#### 修改白板用户界面的主题

#### 启用/禁用 Apple Pencil 的系统默认功能

该版本在 `FastRoom` 类中提供 [`followSystemPencilBehavior`](/api-ref/fastboard/ios/fastboard-api#followsystempencilbehavior) 属性，用于在白板应用中启用/禁用 Apple Pencil 的系统默认功能。当 `followSystemPencilBehavior` 设为 `YES`，表示使用白板应用时，Apple Pencil 的行为跟随系统设置，用户可以使用 Apple Pencil 的系统默认功能操作白板，例如，双击切换当前工具为橡皮擦，双击显示调色板，使用 Apple Pencil 涂鸦等。当 `followSystemPencilBehavior` 设为 `NO`，表示使用白板应用时，Apple Pencil 的行为不跟随系统设置，即 Apple Pencil 的系统默认功能不可用。

## 1.1.0 版

该版本于 2025 年 7 月 11 日发布。

### 新增特性

#### 主视图管理小窗应用

[`FastboardOptions`](/api-ref/fastboard/javascript/fastboard-api#fastboardoptions) 新增 `enableAppInMainViewPlugin` 配置项，用于启用 [`@netless/app-in-mainview-plugin`](https://www.npmjs.com/package/@netless/app-in-mainview-plugin) 插件，支持在白板主视图管理[小窗应用](/zh-CN/realtime-media/whiteboard/fastboard-sdk/reference/concepts#小窗应用)。该插件基于 [`@netless/window-manager`](https://www.npmjs.com/package/@netless/window-manager) 的多窗口模式，把 App 窗口（课件、插件）集成到主窗口中，App 窗口可以随着主白板的页面切换而隐藏或显示，详见 [`appInMainView`](https://github.com/netless-io/appInMainView)。

#### 激光铅笔

启用 `appliance-plugin` 插件后，Fastboard UI 新增激光铅笔工具 `laserPen`。

### 问题修复

该版本修复了如下问题：

- 使用全打包方式引用时，声明文件 `full.d.ts` 丢失。
- 悬浮条为 `false` 时，工具栏无法显示。

## 0.3.22 版

该版本于 2024 年 11 月 28 日发布。

### 新增特性

#### 全打包方式引用

自该版本起，Fastboard SDK 新增全打包文件 `@netless/fastboard/full` 和 `@netless/fastboard-react/full`，用于解决内外依赖冲突问题。使用全打包方式引用时，无需再安装 `@netless/window-manager` 和 `white-web-sdk` 等依赖。

:::warning[注意]
使用全打包方式引用时，你需要在项目中移除 `@netless/window-manager`、`white-web-sdk` 和 `jspdf` 依赖。
:::

```javascript tab="JavaScript 中引用" tabGroup="preq"
// 全打包方式引用
import { createFastboard, createUI } from "@netless/fastboard/full";

// 分包方式引用
import { createFastboard, createUI } from "@netless/fastboard";
```

```jsx tab="React 中引用" tabGroup="preq"
// 全打包方式引用
import { useFastboard, Fastboard } from "@netless/fastboard-react/full";
// 分包方式引用
import { useFastboard, Fastboard } from "@netless/fastboard-react";
```

#### 高性能白板绘制工具

该版本新增 `appliance-plugin` 插件，实现了一套高性能的白板绘制工具，且支持在多窗口模式下使用。安装 `@netless/appliance-plugin` 后，你可以通过 `FastboardOptions.enableAppliancePlugin` 和 `managerConfig.supportAppliancePlugin` 配置项启用该插件。详见[`appliance-plugin`](https://github.com/netless-io/fastboard/blob/main/docs/zh/appliance-plugin.md)。

:::warning[注意]
- `@netless/appliance-plugin` 为必需外部依赖，不包含在全打包文件中，需要单独安装。
- 为确保笔迹正常显示，请在所有终端（Web、Android 和 iOS）上都开启 `appliance-plugin` 插件。如果某个终端未开启，其他终端使用 `appliance-plugin` 绘制的笔迹将无法在该终端显示。
- 开启 `appliance-plugin` 插件后，白板上的历史内容仍会显示，但无法对其进行操作或升级。为避免影响使用体验，建议在全新的白板上使用该插件。关闭插件后，使用该插件绘制的内容将会丢失。
- 浏览器需完整支持 Web API [`OffscreenCanvas`](https://developer.mozilla.org/zh-CN/docs/Web/API/OffscreenCanvas)，才能获得最佳性能和完整的教具功能体验。
:::
