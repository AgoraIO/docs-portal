为满足不同的需求，声网互动白板提供如下两套客户端 SDK 供你选择：

:::warning[注意]
Fastboard SDK 与 Whiteboard SDK **不互通**，声网建议你根据自身需求从中选择一套使用。
:::

<td>声网互动白板 PaaS 解决方案，提供丰富的数据和状态回调，支持高度自定义业务逻辑和 UI。</td>

<td>无界面 UI，纯 API 交付。你需要自行实现所有 UI。</td>
