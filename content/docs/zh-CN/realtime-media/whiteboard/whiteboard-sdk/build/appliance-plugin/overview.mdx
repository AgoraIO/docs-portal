<PlatformStructured platform="android">

适用于 **Whiteboard Android SDK 2.16.134**，内嵌 **Appliance Plugin 1.1.45**。本章的 `Version` 条件指插件版本。

推荐在新接入房间中开启 `enableAppliancePlugin`，使用内嵌的高性能教具插件。插件负责笔迹绘制、元素选中和编辑、图片交互、文字编辑、撤销重做及多窗口中的教具显示，业务继续使用 SDK 的公开接口。

## 开启插件

```java
import com.herewhite.sdk.RoomParams;
import com.herewhite.sdk.WhiteSdkConfiguration;
import com.herewhite.sdk.domain.Region;

WhiteSdkConfiguration config = new WhiteSdkConfiguration("APP_IDENTIFIER", true);
config.setRegion(Region.cn);
config.setUseMultiViews(true);
config.setEnableAppliancePlugin(true);

RoomParams params = new RoomParams("ROOM_UUID", "ROOM_TOKEN", "CLIENT_UID");
params.setRegion(Region.cn);
params.setWritable(true);
params.setUsingFloatBar(true);
// config 传给 WhiteSdk 构造函数，params 传给 joinRoom。
```

插件开关在创建 `WhiteSdk` 前配置。`appliancePluginOptions` 放在 `RoomParams`，在调用 `joinRoom` 前设置。房间方法在 `Promise<Room>.then` 中取得 `Room` 后调用。

当前版本需同时配置 `useMultiViews=true` 与 `enableAppliancePlugin=true`。未启用动态配置且本地未设置时，插件开关默认 `false`；启用动态配置时，未显式配置的字段允许继承远端值。同一房间的互动端和只读显示端应一致启用插件，保证插件内容的同步显示；迁移已有房间时先核对已有内容的显示和编辑效果。

SDK 已内嵌插件和绘制资源，无需在本端工程单独安装 npm 包或配置 Worker URL。插件为白板提供绘制与编辑交互，业务应用仍需提供自己的教具切换按钮。

## 教具与操作

| 教具 | 用途 | 主要配置 |
| --- | --- | --- |
| Pencil | 自由书写和标注 | 线条颜色、粗细；扩展线型见自定义教具 |
| Selector | 选中、移动、缩放元素；符合条件的单个图片可使用旋转手柄 | 内置属性栏与选择框样式 |
| Rectangle / Ellipse / Straight / Arrow | 绘制矩形、椭圆、直线和箭头 | 线条颜色与粗细 |
| Shape | 绘制三角形、菱形、五角星和气泡框 | shapeType；填充色和透明度见自定义教具 |
| Text | 输入和编辑文字 | 文字颜色、字号、文字编辑器选项 |
| Eraser | 擦除命中的整个可擦除元素 | 通过 `Appliance.ERASER` 选择 |
| Pencil Eraser | 擦除局部笔迹 | 通过本端教具入口选择 |
| Hand / Clicker | 移动视角、点击课件 | 通过本端教具入口选择 |

例如，入房成功后切换铅笔并设置颜色、粗细：

```java
import com.herewhite.sdk.domain.Appliance;
import com.herewhite.sdk.domain.MemberState;

MemberState pencil = new MemberState();
pencil.setCurrentApplianceName(Appliance.PENCIL);
pencil.setStrokeColor(new int[]{32, 102, 255});
pencil.setStrokeWidth(4);
room.setMemberState(pencil);
```

复制、删除、撤销和重做仍使用 SDK 的对应公开接口。只读用户用于显示内容，不开放写入或编辑操作。

## 初始化前开启

```objc
WhiteSdkConfiguration *config = [[WhiteSdkConfiguration alloc] initWithApp:appIdentifier];
config.useMultiViews = YES;
config.enableAppliancePlugin = YES;

WhiteRoomConfig *roomConfig = [[WhiteRoomConfig alloc] initWithUUID:uuid roomToken:roomToken uid:uid];
WhiteAppliancePluginOptions *options = [WhiteAppliancePluginOptions new];
options.extras = @{ @"useBackgroundThread": @YES };
roomConfig.appliancePluginOptions = options;
```

在创建 `WhiteSDK` 前设置 config，入房前设置 roomConfig。同房间各端保持启用状态一致；不要注入额外 Web 插件脚本。布尔/数字 extras 使用 NSNumber，函数回调使用本端 delegate。

<PlatformStructured platform="web">

适用于 **Appliance Plugin 1.1.45**。插件负责教具绘制、选中、文字编辑、撤销重做及多窗口 View 绑定。

## 安装和 Worker 资源

```shell
npm install white-web-sdk@2.16.59 @netless/window-manager@1.0.25 @netless/appliance-plugin@1.1.45
```

将同一插件版本的 `dist/fullWorker.js`、`dist/subWorker.js` 复制到站点静态资源目录 `/appliance-1.1.45/`，确保以 JavaScript MIME 返回，并按站点 CSP 允许 Worker 加载。两份 Worker 与主线程插件必须来自同一版本。

```shell
mkdir -p public/appliance-1.1.45
cp node_modules/@netless/appliance-plugin/dist/fullWorker.js public/appliance-1.1.45/
cp node_modules/@netless/appliance-plugin/dist/subWorker.js public/appliance-1.1.45/
```

## 启用插件

```typescript
import { WhiteWebSdk, type InvisiblePluginClass } from 'white-web-sdk';
import { WindowManager } from '@netless/window-manager';
import { ApplianceMultiPlugin } from '@netless/appliance-plugin';
import '@netless/window-manager/dist/style.css';
import '@netless/appliance-plugin/dist/style.css';

const sdk = new WhiteWebSdk({ appIdentifier, region: 'cn-hz', useMobXState: true });
const room = await sdk.joinRoom({
  uuid, roomToken, uid, region: 'cn-hz',
  useMultiViews: true,
  disableMagixEventDispatchLimit: true,
  invisiblePlugins: [WindowManager as unknown as InvisiblePluginClass<string, object, object>, ApplianceMultiPlugin]
});
const manager = await WindowManager.mount({
  room, container, cursor: true, supportAppliancePlugin: true
});
const plugin = await ApplianceMultiPlugin.getInstance(manager, {
  options: {
    cdn: {
      fullWorkerUrl: '/appliance-1.1.45/fullWorker.js',
      subWorkerUrl: '/appliance-1.1.45/subWorker.js'
    },
    extras: { useBackgroundThread: true }
  },
  callbacks: {
    onInitLoadingChange: info => console.log(info),
    onBackgroundImageLoadEvent: event => console.log(event)
  }
});
```

Web 多窗口通过注册 `ApplianceMultiPlugin`、设置 `supportAppliancePlugin` 和创建插件实例启用教具插件。应用与这些插件使用同一份 `white-web-sdk`。

先 mount 主 View，再初始化插件。离开页面时先解除业务监听，等待 `plugin.destroy()`，再等待 `manager.destroy()`、`room.disconnect()`；若使用 Blob Worker URL，完成销毁后再 revoke URL。插件初始化返回不表示每个 App 的所有资源和首帧均已完成。

import { WhiteboardOptions, Region } from '@shengwang/whiteboard';

const options: WhiteboardOptions = {
