## 通过 Maven 集成 SDK

参考以下步骤使用 Maven 在项目中集成 SDK：

1. 打开根目录下的 `build.gradle` 进行以下配置：

  ```groovy
  allprojects {
      repositories {
          jcenter()
          // 添加 JitPack 仓库
          maven { url 'https://jitpack.io' }
          // 对于国内用户，如果 Gradle sync 失败，可以选择国内镜像，例如阿里云 Maven 镜像
          maven { url 'https://maven.aliyun.com/nexus/content/repositories/releases/'}
      }
  }
  ```

2. 打开 app 目录下的 `build.gradle` 进行如下配置：

  ```groovy
  dependencies {
      implementation 'com.github.netless-io:whiteboard-android:2.16.100'
  }
  ```

## 通过 CocoaPods 集成 SDK

参考以下步骤使用 CocoaPods 在项目中集成 SDK：

1. 在项目路径的 `Podfile` 文件中添加如下内容：

    ```ruby
    platform :ios, '10.0'
    target 'Whiteboard' do
        pod 'Whiteboard'
    end
    ```

2. 运行以下命令安装 SDK：

    ```shell
    pod install
    ```

    安装完成后，你可以点击打开项目的 `Whiteboard.xcworkspace` 文件，对项目进行后续编辑。

## 通过 npm 集成 SDK

使用该方法需要先安装 npm，详见 [npm 快速入门](https://www.npmjs.com.cn/getting-started/installing-node/)。

1. 命令行运行安装命令

    ```shell
    npm install white-web-sdk
    ```

2. 在项目的 JavaScript 代码中引入声网互动白板 SDK

    ```javascript
    var WhiteWebSdk = require("white-web-sdk");
    ```

## 通过 CDN 集成 SDK

在 `index.html` 中，将如下代码添加到 `<head>` 的下一行：

```html
<head>
  <script src="https://sdk.netless.link/white-web-sdk/2.16.53.js"></script>
</head>
```
