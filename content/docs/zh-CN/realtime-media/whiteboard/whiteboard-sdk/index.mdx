互动白板 SDK (Whiteboard SDK) 是不含 UI 实现的高定制化白板方案，提供丰富的数据和状态回调 API，支持高度自定义业务和 UI。可用于在线教育、在线会议、协作办公、在线互动娱乐等场景。

## 产品能力

<CardGrid>
  <FeatureCard title="实时互动白板">
    提供低延时白板房间，支持多人实时书写、绘制、擦除、选择、编辑和同步白板内容。
  </FeatureCard>
  <FeatureCard title="完整 UI 自定义">
    提供基础白板能力和状态接口，你可以按业务需要自定义工具栏、页面结构、交互流程和视觉样式。
  </FeatureCard>
  <FeatureCard title="文档转换和文件展示">
    支持静态文档转换和动态文档转换，将 PPT、PPTX、Word、PDF、图片、音视频等内容用于白板演示。
  </FeatureCard>
  <FeatureCard title="场景、页面和视角管理">
    支持场景路径、分页、侧边预览、视角跟随、页面缩放和轨迹同步，适合课堂、会议和协作办公场景。
  </FeatureCard>
  <FeatureCard title="扩展事件和全局状态">
    支持自定义事件和自定义全局状态，让白板可以承载聊天、点赞、业务状态同步和协同控制等能力。
  </FeatureCard>
  <FeatureCard title="录制和回放">
    支持云端高保真信令录制，记录白板操作、动态课件和自定义事件，并支持多端回放。
  </FeatureCard>
</CardGrid>

## 适用场景

互动白板 SDK 适用于在线教育、在线会议、协作办公和互动娱乐等需要深度定制白板体验的场景。如果你希望使用默认 UI 并减少界面开发成本，可以选择[Fastboard SDK](/zh-CN/realtime-media/whiteboard/fastboard-sdk)。

## 与当前客户端 SDK 配合

服务端先创建房间和签发 Room Token，再交给客户端加入。房间 UUID、region 和 Token 对应的权限应保持一致；SDK Token 保存在业务服务端。RESTful v5 路径由服务端接口定义，客户端 SDK 版本升级无需更改这些路径。

| 客户端 | 推荐正式版本 |
| --- | --- |
| Whiteboard Web | 2.16.59 |
| Whiteboard iOS | 2.16.147 |
| Whiteboard Android | 2.16.134 |
| Whiteboard HarmonyOS | 0.2.11 |
| Fastboard Web | 1.1.10 |
| Fastboard iOS | 1.4.6 |
| Fastboard Android | 1.8.2 |

Appliance Plugin 是客户端初始化与绘制配置：服务端创建房间、生成 Token、转换课件后，各客户端按自己的 SDK 入口开启插件。配置示例见 [Web 教具插件](/zh-CN/realtime-media/whiteboard/whiteboard-sdk/build/appliance-plugin/overview)、[Android 教具插件](/zh-CN/realtime-media/whiteboard/whiteboard-sdk/build/appliance-plugin/overview)、[iOS 教具插件](/zh-CN/realtime-media/whiteboard/whiteboard-sdk/build/appliance-plugin/overview)。
