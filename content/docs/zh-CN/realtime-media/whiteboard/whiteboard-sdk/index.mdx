description: "在应用中集成实时白板、标注、文件展示和视觉协作能力。"
---

Whiteboard SDK 是高定制化的互动白板方案，提供绘制、标注、场景管理、状态回调和文档展示等能力。你可以基于它构建在线课堂、会议协作、远程办公和互动娱乐场景中的实时视觉协作体验。

如果你希望更快集成带默认 UI 的白板体验，也可以选择 Fastboard SDK；如果你需要完全自定义业务 UI 和交互，Whiteboard SDK 更适合作为底层能力接入。

## 产品特性

<CardGrid>
  <FeatureCard title="白板编辑与房间工具">
    提供绘制、书写、擦除、场景管理、房间状态管理和多用户协作等核心能力。
  </FeatureCard>
  <FeatureCard title="文件展示与文档转换">
    支持将 PPT、PPTX、Word 和 PDF 等文件转换并展示在白板中，满足课堂和会议资料演示需求。
  </FeatureCard>
  <FeatureCard title="高度自定义">
    不内置固定 UI，你可以按业务需求自定义界面、工具栏、交互流程和状态同步逻辑。
  </FeatureCard>
  <FeatureCard title="录制与回放">
    支持记录白板操作、动态 PPT 和自定义事件，并在需要时进行多端回放。
  </FeatureCard>
  <FeatureCard title="服务端 API">
    通过 RESTful API 完成 Token 生成、房间管理、截图管理、场景管理和文档转换等服务端操作。
  </FeatureCard>
  <FeatureCard title="稳定可靠">
    声网全球分布式服务和容灾机制为白板实时协作提供高可用保障。
  </FeatureCard>
</CardGrid>
