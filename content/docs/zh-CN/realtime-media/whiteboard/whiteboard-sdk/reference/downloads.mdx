## 集成方式

```bash tab="Web" tabGroup="whiteboard-install"
npm install white-web-sdk
```

```groovy tab="Android" tabGroup="whiteboard-install"
dependencies {
    implementation 'com.github.netless-io:whiteboard-android:2.16.100'
}
```

```ruby tab="iOS" tabGroup="whiteboard-install"
platform :ios, '10.0'
target 'Whiteboard' do
    pod 'Whiteboard'
end
```
