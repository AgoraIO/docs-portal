title: "从 Netless 迁移"
---

<PlatformStructured platform="android">

声网已经收购 Netless，并且基于 Netless 白板服务正式推出声网互动白板。本文介绍如何将 Netless 账号下的项目迁移到声网控制台。

## 前提条件

本文适用于已有 Netless 账号，想要迁移至声网账号的开发者。对于没有 Netless 账号的开发者，可以参考[开启和配置互动白板服务](/zh-CN/realtime-media/whiteboard/whiteboard-sdk/build/setup-and-access/enable-service)直接开启互动白板服务。

:::warning[注意]
声网目前不支持将 Netless 项目迁移到使用第三方账号注册的声网开发者账号，例如用微信、谷歌、GitHub 等账号注册的声网开发者账号。
:::

## 迁移步骤

根据你的账号情况，参考以下步骤迁移 Netless 账号下的项目。

:::warning[注意]
在迁移完成之前，请不要在声网控制台上开启互动白板服务，否则可能会迁移失败。
:::

- **有 Netless 账号，无声网开发者账号**
    1. 使用你的 Netless 账号所绑定的邮箱登录[声网控制台](https://console.shengwang.cn/)。
    2. 点击**发送邮件**。
    3. 根据邮件提示重新设置密码。声网会使用与你的 Netless 账号绑定的邮箱创建一个新的声网开发者账号。
    4. 使用新设置的密码登录[声网控制台](https://console.shengwang.cn/)。
    5. 根据屏幕提示进行操作，然后点击**迁移**。声网会自动将你的 Netless 账号下的所有项目迁移到声网控制台。

- **有 Netless 账号和声网开发者账号，并且两个账号绑定的邮箱相同**
    1. 使用绑定的邮箱登录[声网控制台](https://console.shengwang.cn/)。
    2. 根据屏幕提示进行操作，然后点击**迁移**。声网会自动将你的 Netless 账号下的所有项目迁移到声网控制台。

- **有 Netless 账号和声网开发者账号，并且两个账号绑定的邮箱不同**
    - 如果要迁移到你现有的声网开发者账号，请联系销售[联系销售](https://www.shengwang.cn/contact-sales/)。
    - 如果要创建一个新的声网开发者账号用于迁移，参考“有 Netless 账号，无声网开发者账号”时的方案。

## 相关文档

迁移成功后，你可以参考以下文档，在项目中开启和使用互动白板服务：

- [开启和配置互动白板服务](/zh-CN/realtime-media/whiteboard/whiteboard-sdk/build/setup-and-access/enable-service)
- [加入白板房间](/zh-CN/realtime-media/whiteboard/whiteboard-sdk/get-started/join-room-wb)
