使用[文档转换服务](/zh-CN/realtime-media/whiteboard/whiteboard-sdk/build/extend-whiteboard/convert-files)将由 Microsoft Office PowerPoint 制作的 PPT 或 PPTX 文件转换为动态 HTML 网页时，可能会遇到因 PPT 中使用的部分元素、特效、图片、动画等解析失败而导致转换后的 PPT 中部分效果失效或效果不好的情况。本文列出文档转换服务对 PPT 中各功能的支持情况，帮助你定位问题元素并修复 PPT。

:::info[信息]
- 此文档仅适用于 Microsoft PowerPoint 制作的 PPT 或 PPTX 文件。对于使用 WPS 制作的 PPT 文件，声网不保证转换效果。
- 对于未在列表中提到的功能或效果，可能是版本差异导致功能不一致，建议手动测试。
:::

## 修复 PPT 最佳实践

如果转换后的 PPT 中部分效果存在缺失或与原 PPT 有差异的情况，你可以参考以下步骤定位问题元素并修复：

1. **定位问题元素**

    对比转换前后的 PPT，找出问题元素。

2. **处理问题元素**

    根据实际情况，你可以：

    - 直接删除问题元素或删除元素上不支持的效果。
    - 为问题元素替换其他文档转换已支持的效果。
    - 将问题元素另存为图片，删除问题元素，之后重新插入图片至原位置。如果问题元素较多，可以先组合问题元素再进行转图片操作。

3. **重新发起转换**

    重新调用 RESTful API 发起转换。转换成功后，再次对比转换前后的 PPT 效果，如果依然存在问题，重复以上步骤。
