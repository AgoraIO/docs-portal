## 通过 Maven 集成 SDK

```groovy
allprojects {
    repositories {
        jcenter()
        maven { url 'https://jitpack.io' }
        maven { url 'https://maven.aliyun.com/nexus/content/repositories/releases/' }
    }
}
```

```groovy
dependencies {
    implementation 'com.github.netless-io:whiteboard-android:2.16.134'
}
```
