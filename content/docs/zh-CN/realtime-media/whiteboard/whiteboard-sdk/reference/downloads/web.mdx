## 通过 npm 集成 SDK

```shell
npm install white-web-sdk@2.16.59
```

在项目的 JavaScript 代码中引入 SDK：

```javascript
import { WhiteWebSdk } from "white-web-sdk";
```

## 通过 CDN 集成 SDK

```html
<head>
  <script src="https://sdk.netless.link/white-web-sdk/2.16.59.js"></script>
</head>
```
