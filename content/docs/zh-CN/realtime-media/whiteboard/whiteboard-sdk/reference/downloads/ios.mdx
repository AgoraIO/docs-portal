## 通过 CocoaPods 集成 SDK

```ruby
platform :ios, '10.0'
target 'Whiteboard' do
    pod 'Whiteboard', '2.16.147'
end
```

## 通过 Swift Package Manager 集成 SDK

使用 Xcode 15+（Swift 5.9）和 iOS 12.0+。在 **File > Add Package Dependencies** 中添加 `https://github.com/netless-io/Whiteboard-iOS.git`，选择 **Exact Version** `2.16.147`，将 `Whiteboard` 产品添加到应用 Target。与 CocoaPods 任选一种方式，完整步骤见[加入白板房间](/zh-CN/realtime-media/whiteboard/whiteboard-sdk/get-started/join-room-wb/ios)。
