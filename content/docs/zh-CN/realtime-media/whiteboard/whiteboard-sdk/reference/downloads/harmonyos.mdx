当前正式版本：**@shengwang/whiteboard 0.2.11**，发布日期：**2026 年 10 月 21 日**。

## 通过 OHPM 集成

```shell
ohpm install @shengwang/whiteboard@0.2.11
```

包入口为 `Index.ets`。通过 `@shengwang/whiteboard` 导入 `Whiteboard`、`WhiteboardOptions`、`WhiteboardController`、`WhiteboardCallbacks` 等公开类型。
