## 如何选择互动白板 SDK 和 Fastboard SDK

Fastboard SDK 基于互动白板 SDK 开发，提供默认白板 UI、窗口管理器和插件中心，适合更快完成接入。互动白板 SDK 提供更底层的白板能力和状态接口，适合需要完整自定义 UI 与业务逻辑的应用。

:::warning[注意]
Fastboard SDK 与互动白板 SDK 不互通。请在项目接入前根据业务需求选择其中一套 SDK。
:::

| 对比项 | Fastboard SDK | 互动白板 SDK |
| --- | --- | --- |
| 产品定位 | 新一代互动白板 SDK，封装默认 UI、窗口管理器和常用插件，减少基础界面开发工作。 | 互动白板 PaaS SDK，提供房间、场景、状态和事件等基础能力，支持深度自定义。 |
| UI 边界 | 提供默认白板 UI，包括工具条、页面控制、视角控制、重做、撤销等组件；如默认 UI 不满足需求，需要自行覆盖或重写。 | 不提供默认业务 UI，你需要自行实现工具栏、页面管理、交互流程和视觉样式。 |
| 插件能力 | 内置窗口管理器和部分开源插件，如文档展示、播放器、代码编辑器、倒计时、GeoGebra、网页嵌入等；也可以基于开源插件扩展。 | 不内置 Fastboard 的默认插件体系，适合自行设计插件、业务组件和交互逻辑。 |
| 适用团队 | 适合开发资源有限、排期紧，希望快速上线在线课堂、会议协作或互动演示，同时仍有一定定制需求的团队。 | 适合开发资源充足、对 UI、状态管理、业务流程和扩展能力有较高定制要求的团队。 |
| 开发成本 | 较低 | 较高 |
| 平台支持 | Web：Chrome 58+ 或 Safari 11+（macOS 10+）；Android：Android 5.0（SDK API Level 21）及以上版本；iOS：iOS 12.0 及以上版本。 | Web：Chrome 58+ 或 Safari 11+（macOS 10+）；Android：Android 5.0（SDK API Level 21）及以上版本；iOS：CocoaPods 为 iOS 10.0+，SwiftPM 为 iOS 12.0+。 |

## 功能概述

声网互动白板提供以下核心功能：

| 功能       | 描述                                                         |
| :------------- | :----------------------------------------------------------- |
| 互动白板       | 超低延时、实时互动、全球互联的白板房间，支持上传和展示多种格式的文件，提供丰富的白板操作工具，支持多人实时互动。 |
| 文档转图片     | 静态文档转换，支持将 PPT、PPTX、WORD、PDF 等格式的文件转换成图片，丰富白板演示素材。 |
| 文档转网页     | 动态文档转换，支持将 PPTX 转换成网页，保留原文件中的动画效果、音视频，帮助完整生动呈现信息。 |
| 多窗口应用 | 支持在白板主窗口中开启多个应用子窗口，如音视频播放器、代码编辑器、文档演示等，轻松扩展白板的功能，丰富用户的协作体验。 |
| 白板录制和回放&emsp; | 支持云端高保真信令录制，实时记录白板上的所有操作、动态 PPT和自定义事件。支持多端回放，回放时支持前进、倒退、倍速播放，随时随地回看白板实时房间的全部内容。 |

## 产品优势

**超低延时**

- 声网自研引擎和算法，减少传输冗余数据，白板操作延迟低至 100 ms，节约带宽资源的同时，打造真正无感知的实时互动体验。
- 服务部署于全球多个节点，通过就近接入、智能路由等控制策略，给不同地域的用户带来同样顺畅的体验。

**稳定可靠**

全球分布式集群部署，提供双重灾备方案，确保服务的高可用性。

**功能齐全，可扩展性强**

提供从基础到高阶丰富的工具，支持上传并展示静态图片、动态 PPT、H5 课件等多种格式的文件，支持多用户实时协作互动，白板录制与回放、文档转换等功能一应俱全。

此外，互动白板还提供窗口管理器和插件中心，帮你在白板中快速添加和使用插件，轻松扩展白板应用的功能。

**支持多平台，集成简单**

声网互动白板客户端 SDK 覆盖 Web、Android、iOS 等主流平台，几行代码即可快速接入。

Fastboard SDK 在互动白板 SDK 的基础上简化了接口，提供默认的 UI 实现，并集成了窗口管理器和插件中心等组件，进一步降低了开发难度。

**灵活组合**

声网互动白板 SDK 作为独立、可自定义的白板产品，灵活易用，可满足不同场景的需求:

- 可与声网或非声网音视频、信令等产品搭配使用，丰富应用的功能。
- 提供基础界面元素，也支持自定义界面元素，满足多样化的风格需求。

## 平台支持

互动白板 SDK 和 Fastboard SDK 均支持多平台，并支持平台间互通。移动端兼容性要求如下：

| SDK | Android | iOS |
| --- | --- | --- |
| 互动白板 SDK | Android 5.0（SDK API Level 21）及以上版本 | CocoaPods：iOS 10.0 及以上；SwiftPM：iOS 12.0 及以上 |
| Fastboard SDK | Android 5.0（SDK API Level 21）及以上版本 | iOS 12.0 及以上版本 |

Web 端的完整支持版本与可降级使用版本如下：

| 操作系统 | 浏览器/WebView | 完整支持版本 | 降级支持版本 |
| --- | --- | --- | --- |
| Windows | Chrome | 69+ | 58+ |
| Windows | Edge | 79+ | 12+ |
| Windows | Firefox | 105+ | 58+ |
| macOS | Chrome | 69+ | 58+ |
| macOS | Safari | 16+ | 11+ |
| macOS | Firefox | 105+ | 58+ |
