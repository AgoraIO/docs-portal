本文介绍调用水晶球 RESTful API 时的限制。

水晶球 RESTful API 的调用限制取决于你订阅的水晶球套餐包。

:::warning[注意]
- 自 2021 年 5 月 20 日起，水晶球提供免费版、专业版、旗舰版三个档位的套餐包。各套餐包的区别见[计费说明](/zh-CN/realtime-media/usage-analytics/reference/billing)。
- 免费版套餐包不支持调用通话调查 RESTful API。
:::

:::info[信息]
- 请求次数的计算以服务器的 UTC 时间为准。
- 数据延迟是指从数据产生到可查询到该数据所需要等待的时间。
:::
