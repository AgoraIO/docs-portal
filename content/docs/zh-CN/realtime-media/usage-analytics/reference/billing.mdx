本文介绍声网水晶球的计费方式。

水晶球通过套餐包收费，每个套餐包都支持[通话调查](/zh-CN/realtime-media/usage-analytics/build/rtc/call-search/overview)、[数据洞察](/zh-CN/realtime-media/usage-analytics/build/rtc/data-insight/basic)、[实时监控](/zh-CN/realtime-media/usage-analytics/build/rtc/monitor)和[水晶球内嵌](/zh-CN/realtime-media/usage-analytics/build/rtc/embeded)功能，但具体支持的子功能会有差异，详见[套餐包详情](#套餐包详情)。

[订阅套餐包](#subscribe)后，相关功能会自动开通，你可以立即体验套餐包支持的各项功能。

:::warning[注意]
为更好满足不同用户的需求，水晶球自 2021 年 5 月 20 日起提供免费版、专业版、旗舰版三个档位的套餐包。
:::

### 计费标准

套餐包提供后付费和一口价两种计费方式：

**后付费**

|            | 免费版 | 专业版 | 旗舰版 |
| :---------| :----- | :----- | :----- |
| 订阅费用（元/月）        | 0      |1999   | 3999   |
| 套餐额度（分钟/月）①      | 无限制 |  100 万 | 100 万 |
| 超额价格（元/1000 分钟）① | 0   | 0.99   | 0.95   |

以订阅专业版的后付费套餐包为例，假设当月产生的时长用量是 200 万分钟，那么当月需支付的总费用为：1999 + (2,000,000-1,000,000) × 0.99/1000 = 2989 元。

**一口价**

|           | 专业版 | 旗舰版 |
| :---------| :----- | :----- |
| 订阅费用（元/月）| 29,999  | 49,999   |
| 套餐额度（分钟/月）①  |  无限制 | 无限制 |

:::info[信息]
① 分钟数指的是使用声网实时音视频服务产生的总时长用量，计算方式详见[实时音视频计费](/zh-CN/realtime-media/rtc/reference/billing-strategy)。
:::

## 管理套餐包
### 订阅套餐包

参考如下步骤订阅水晶球套餐包：

1. 登录[控制台](https://console.shengwang.cn/)。
2. 点击左侧菜单栏中的**水晶球** > **水晶球套餐**。
3. 选择需要订阅的套餐包，点击**立即订阅**。旗舰版套餐包请[联系销售](https://www.shengwang.cn/contact-sales/)订阅。
4. 按照屏幕提示完成支付。

套餐订阅后立即生效并扣费。你可以在**水晶球套餐**页面右上角点击**我的套餐包**，查看订阅详情。

所有档位的水晶球套餐包都默认开启自动续订。你可以随时取消订阅，详见[取消或更改订阅](#cancel)。

声网会在每月 1 日发布账单，直到订阅取消。其中月账单包含上个月的水晶球套餐超额费用，一次性账单包含下个月的水晶球套餐订阅费用。关于账单和扣费，详见[什么是账单、扣费与账户冻结？](/faq/account-and-billing/billing-account)。

<a id="cancel"></a>
### 取消或更改订阅

取消订阅套餐包，可参考以下步骤：

1. 在控制台点击左侧导航栏中的**水晶球套餐**。
2. 在页面右上角点击**我的套餐包**。
3. 找到需要取消订阅的套餐包，点击**操作**下面的**取消订阅**。

更换套餐包，可参考以下步骤：

1. 在控制台点击左侧导航栏中的**水晶球套餐**。
2. 选择想要更换的套餐包，点击**立即订阅**。
3. 仔细阅读弹窗提示内容后，如果确认要更换套餐包，点击**确认切换**。

取消订阅或者更换套餐包将于次月 1 日生效，不影响当月使用。当月的订阅费用不会退款，当月产生的超额用量会按照原有套餐包的超额价格收取费用。
