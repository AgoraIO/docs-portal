## 简介

声网水晶球为云信令（原实时消息）提供用量和质量数据的阶段性分析，帮助你掌握用量变化趋势、跟踪产品质量情况。

云信令相关的水晶球指标含义详见[名词解释](/zh-CN/realtime-media/usage-analytics/reference/concept-rtm)。

### 功能概述

声网水晶球为云信令提供以下功能：

- 自动采集、处理和存储多个用量和质量指标的数据，数据延时为 6 小时。
- 查看用户数、消息数、活跃频道数、Metadata 操作次数的变化趋势。
- 查看登录成功率、客户端错误率等。

### 开通云信令相关功能

水晶球的云信令相关功能默认开启，无需额外操作，并且不收取额外费用。

## 用量洞察

参考以下步骤查看云信令用量洞察页面：

1. 登录[控制台](https://console.shengwang.cn/)，在左侧菜单栏中点击**水晶球** > **云信令用量洞察**。

2. 在页面左上方的下拉菜单中选择需要查看的声网项目。

3. （可选）在页面右上方选择按天或小时展示某一时间范围的数据。默认是按天展示最近 7 天的数据。

    :::info[信息]
    按天的粒度下，支持查询最近 90 天的数据。按小时的粒度下，支持查询最近 7 天的数据，单次查询的时间范围不能超过 72 小时。
    :::

4. 在页面上方点击版块名称，跳转至对应版块：

    |               | 描述                                                         | 示例 |
    | :------------ | :----------------------------------------------------------- | ---- |
    | 用户活跃情况  | 展示活跃用户数、最高同时在线人数在某一时间范围内的变化趋势。 |  ![](https://web-cdn.agora.io/docs-files/1665719690480)  |
    | 消息收发情况  | 展示消息发送数、消息接收数、消息收发总数在某一时间范围内的变化趋势。 |  ![](https://web-cdn.agora.io/docs-files/1665719757549)  |
    | 频道活跃情况  | 展示活跃频道数和最高同时活跃频道数在某一时间范围内的变化趋势，以及频道最高同时活跃人数的分布。 |   ![](https://web-cdn.agora.io/docs-files/1665719796683)   |
    | Metadata 情况 | 展示 User Metadata 操作次数和 Channel Metadata 操作次数在某一时间范围内的变化趋势。 |  ![](https://web-cdn.agora.io/docs-files/1665719818474)    |

5. 在任一版块，你都可以进行以下操作：
  - 点击指标图例，隐藏该指标的折线图。
  - 如果选择**按天**展示，点击折线图上的任一数据点将自动切换至**按小时**展示。例如，点击 10 月 10 日对应的数据点，时间范围自动调整为 10 月 10 日的 00:00–23:59。点击**返回上次时间**按钮即可恢复原来的时间范围。
  - 点击右上方的**数据明细**，查看指标的环比变化幅度并且下载数据。如果选择**按天**，弹窗中展示指标的周环比数据；如果选择**按小时**，弹窗中展示指标的日环比数据。

## 质量洞察

1. 登录[控制台](https://console.shengwang.cn/)，在左侧菜单栏中点击**水晶球** > **云信令质量洞察**。

2. 在页面左上方的下拉菜单中选择需要查看的声网项目。

3. （可选）在页面右上方选择按天或小时展示某一时间范围的数据。默认是按天展示最近 7 天的数据。

  :::info[信息]

  :::

4. 在页面上方点击版块名称，跳转至对应版块：

    |            | 描述                                                         | 示例 |
    | ---------- | ------------------------------------------------------------ | ---- |
    | 运行质量   | 按地域展示登录成功率。在左侧地图中，登录人次越高，该区域的颜色越深； 气泡直径越大，该区域的登录成功率越低。点击左侧地图上的任一区域，右侧将展示该区域的折线图。 |   ![](https://web-cdn.agora.io/docs-files/1665719885350)  |
    | 客户端错误 | 展示客户端错误数和错误率在某一时间范围内的变化趋势。         |   ![](https://web-cdn.agora.io/docs-files/1665719921699)   |

5. 在任一版块，你都可以进行以下操作：

  - 点击指标图例，隐藏该指标的折线图。
