## 前提条件

本文结合案例介绍如何排查异常数据产生的原因。

开始排查之前，你需要了解[如何使用数据洞察 Plus](/zh-CN/realtime-media/usage-analytics/build/rtc/data-insight/plus)。

## 案例：视频/音频卡顿率异常

如果观察到某一时间段的视频/音频卡顿率异常偏高，可以按照以下思路排查：

### 1. 查看维度分析，定位共性问题

在时序图中点击异常数据点，选择**维度分解**开始维度分析。

![维度分解入口示意图](https://web-cdn.agora.io/docs-files/1690856505323)

查看**维度分析-分布概览**，定位共性问题。

![维度分析分布概览示意图](https://web-cdn.agora.io/docs-files/1690856514159)

观察到 3.7.2.1 版本整体卡顿率偏高，需要进一步分析。

### 2. 缩小范围，定位根因

将 SDK 版本的 3.7.2.1 版添加为**全局筛选**条件，查看时序图，对异常点进行**数据采样**，进一步了解受影响的用户范围。

![选定 SDK 版本后的数据采样入口示意图](https://web-cdn.agora.io/docs-files/1690856522657)

拖动橙色的**采样滑块**至卡顿率最高的时间段（滑块覆盖 30 分钟），在下方查看视频卡顿率分布情况。

![采样滑块和视频卡顿率分布示意图](https://web-cdn.agora.io/docs-files/1690856529578)

观察到大部分用户卡顿率良好（低于 1%），仅少数用户的卡顿率异常。在柱形分布图右侧取消展示卡顿率为 0% 到 2% 的用户，聚焦高卡顿率用户，之后可点击柱形图进行**用户采样**，并针对问题用户开启**通话调查**。

![高卡顿率用户的用户采样示意图](https://web-cdn.agora.io/docs-files/1690856537940)

**结论**：在该时间段内卡顿率数据异常是由于少数用户的视频卡顿率偏高，导致整体卡顿率升高，非声网 SDK 质量问题。你可以据此采取进一步的运营措施。
