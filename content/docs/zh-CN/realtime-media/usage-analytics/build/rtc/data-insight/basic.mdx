---
title: "数据洞察普通版"
---
水晶球的**数据洞察普通版**功能提供基础通话用量和质量数据的阶段性分析，帮助你了解用量和质量的总体趋势、不同维度的分布情况、以及每天、每小时、每分钟的数据明细。

:::warning[注意]
- 自 2022 年 8 月 3 日起，数据洞察新增数据重算机制，每天的数据会在 T+2 天重新计算一次。例如，2022 年 7 月 6 号的数据将在 7 月 8 日凌晨进行重算。在内部资源调度、用户网络不佳等原因导致数据上报延迟的情况下，数据重算机制可以保证历史数据的完整性。
- 当前仅提供 2020 年 7 月 1 日起声网 RTC SDK 的用量和质量数据。
- 自 2023 年 11 月 21 日起，视频卡顿率指标下计入视频卡顿时长的标准发生变化，由“视频卡顿超过 600 ms 被计入卡顿时长”，修改为“视频卡顿超过 500 ms 被计入卡顿时长”，详见[质量指标](#质量指标)。
:::

## 使用步骤

按以下步骤使用数据洞察普通版：

1. [订阅水晶球套餐包](/zh-CN/realtime-media/usage-analytics/reference/billing#如何订阅)，开通数据洞察功能。
2. 登录[控制台](https://console.shengwang.cn/)，点击左侧菜单栏中的**水晶球**。
3. 在水晶球页面的左侧菜单中选择你要查看的项目。点击**用量概览**查看用量数据，或者点击**质量概览**查看质量数据。
4. 设置筛选条件：
    - **用量概览**：在页面右上角选择时区（北京时间或 UTC 时间）、数据粒度（按天或按小时）、时间范围。![用量概览筛选条件示意图](https://web-cdn.agora.io/docs-files/1626085179597)
    - **质量概览**：在页面左上角选择客户端类型（Native 或 Web RTC），右上角指定时区（北京时间或 UTC 时间）、数据粒度（按天、小时或分钟）、时间范围。![质量概览筛选条件示意图](https://web-cdn.agora.io/docs-files/1626085191947)

    :::warning[注意]
    设置筛选条件时，数据粒度、时间范围的具体选项取决于你订阅的套餐包。详见[套餐包详情](/zh-CN/realtime-media/usage-analytics/reference/billing#套餐包详情)。
    :::

## 用量概览

用量概览页面由**总览**和**指标分析**两个面板组成，可以帮助你定位用量异常的时间，了解产生用量的主要国家和地区、操作系统等。

:::error[警告]
用量概览页面提供的用量数据仅供参考，不用作实际计费依据。
:::

### 总览

总览面板包含**最大在线**、**频道和用户**、**用量分析**和**实时互动拓展服务**四个版块。每个版块上方以卡片显示指标的累计值或峰值及达到峰值的时间，下方以曲线图展示指标随时间变化的趋势。你可以点击版块右上角的**明细**，以表格形式查看数据或下载数据到本地。例如：

![用量概览总览面板示意图](https://web-cdn.agora.io/docs-files/1680503897637)

各指标的含义详见[用量指标](#用量指标)。

总览面板的每个曲线图都提供以下功能：

- 隐藏和显示：点击上方的指标卡片可以隐藏对应的曲线，再次点击则恢复显示。
- 修改时间筛选条件：如果筛选条件设为**按天**，可以点击曲线图上的数据点，然后点击**查看小时**，将数据粒度切换到按小时、时间范围切换到对应日期的 24 小时，此时各项指标和曲线图都会相应更新。查看完毕后，可以点击**返回原始时间**，恢复原来的筛选条件。
- 快速查看指标分析：点击曲线图上的数据点，然后点击**查看分布**，可以跳转到该数据点对应时间的**指标分析**面板，查看对应指标在各个维度的数据。查看完毕后，可以点击**重置时间**，恢复原来的筛选条件。

:::warning[注意]
- 部分套餐包不支持查看小时的功能。详见[套餐包详情](/zh-CN/realtime-media/usage-analytics/reference/billing#套餐包详情)。
- 最大同时在线频道数、最大同时在线人数、频道数的曲线暂不支持查看分布。
- 实时互动拓展服务板块将根据云录制、输入在线流媒体和旁路推流的开启情况决定是否展示相关指标，若所有服务均未开启，则该板块不展示。
:::

### 指标分析

指标分析面板包含**地域**、**网络类型**、**操作系统**、**SDK 版本**、**设备类型**共 5 个版块，每个版块以条形图展示用量指标在各个维度排名前六的数据。

在指标分析面板的上方，你可以选择要查看的用量指标。在各个维度版块的右上角，你可以点击**明细**，以表格形式查看所有用量指标在该维度的数据，或者下载数据到本地。例如：

![用量概览指标分析面板示意图](https://web-cdn.agora.io/docs-files/1680503914006)

各维度的含义详见[维度](#维度)。

:::warning[注意]
- 地域版块的地区条形图中，默认展示排名第一的国家的地区排名。如果要查看其它国家的地区排名，在地图上点击对应的国家即可。
- 如果某个维度没有用量或用量信息不全，条形图可能无法显示或显示不全。
:::

## 质量概览

质量概览页面由**总览**和**指标分析**两个面板组成，可以帮助你定位质量异常的时间，从多个维度了解质量与用量的关系。

### 总览

总览面板包含**用户体验**和**加入频道**两个版块。每个版块上方以卡片显示指标的峰值或谷值以及达到该值的时间，下方以曲线图展示指标随时间变化的趋势。你可以点击版块的**更多**，以表格形式查看数据或下载数据到本地。例如：

![质量概览总览面板示意图](https://web-cdn.agora.io/docs-files/1680503928301)

各指标的含义详见[质量指标](#质量指标)。

:::warning[注意]
Web RTC 的质量指标不包括音频卡顿率。如果你在质量概览页面的左上角选择平台为 Web RTC，用户体验版块下不会显示音频卡顿率的指标卡片。
:::

总览面板的每个曲线图都提供以下功能：

- 隐藏和显示：点击上方的指标卡片可以隐藏对应的曲线，再次点击则恢复显示。
- 修改时间筛选条件：
  - 如果筛选条件设为**按天**，可以点击曲线图上的数据点，然后点击**查看小时**，将数据粒度切换到按小时、时间范围切换到对应日期的 24 小时，此时各项指标和曲线图都会相应更新。点击页面上方的**返回原始时间**可以恢复到最初始的筛选条件。
  - 如果筛选条件设为**按小时**，可以点击曲线图上的数据点，然后点击**查看分钟**，将数据粒度切换到按分钟、时间范围切换到对应小时的 60 分钟，此时各项指标和曲线图都会相应更新。点击页面上方的**返回原始时间**可以恢复到最初始的筛选条件。
- 快速查看指标分析：点击曲线图上的任一数据点，然后点击**查看分布**，可以跳转到该数据点对应时间的**指标分析**面板，查看对应指标在各个维度的数据。查看完毕后，可以点击**重置时间**，恢复原来的筛选条件。

此外，用户体验版块下的曲线图还提供数据采样功能：

- 频道采样：如果筛选条件设为**按小时**或**按分钟**，点击曲线图上的数据点，然后点击**频道数据采样**，可以看到对应时间的散点图。散点图的纵坐标为对应的指标，横坐标详见[质量指标](#质量指标)。
- 用户采样：在频道数据采样的散点图上，点击数据点，然后点击**用户数据采样**，可以看到频道中卡顿率最高的六位用户的数据。如果需要查看某位用户更详细的通话质量数据，可以点击与该用户对应的**通话调查**。通话调查提供的数据详见[通话调查](/zh-CN/realtime-media/usage-analytics/build/rtc/call-search/overview)。

:::warning[注意]
- 部分套餐包不支持查看小时、查看分钟和数据采样的功能。详见[套餐包详情](/zh-CN/realtime-media/usage-analytics/reference/billing#套餐包详情)。
- 只有点击的数据点符合对应的[采样规则](#采样规则)时，采样选项才会出现。
:::

###  指标分析

指标分析面板包含**地域**、**网络类型**、**操作系统**、**SDK 版本**、**设备类型**共 5 个版块。在指标分析面板的右上角，你可以选择要查看的质量指标。在各个维度版块的右上角，你可以点击**明细**，以表格形式查看所有质量指标在该维度的数据，或者下载数据到本地。例如：

![质量概览指标分析面板示意图](https://web-cdn.agora.io/docs-files/1680503943647)

各维度的含义详见[维度](#维度)。

气泡图展示所选的质量指标在当前维度下与用量的关系，纵坐标为所选指标，对应的横坐标详见[质量指标](#质量指标)。绿色气泡表示指标数据正常，红色气泡表示指标数据异常，异常情况包括：

- 视频卡顿率大于 5%
- 音频卡顿率大于 3%
- 网络延迟率大于 10%
- 登录成功率或 5 s 登录成功率小于 95%

:::warning[注意]
- 地域版块的地区气泡图中，默认展示排名第一的国家的地区排名。如果要查看其它国家的地区排名，在地图上点击对应的国家即可。
- 如果某个维度没有用量或用量信息不全，气泡可能无法显示或显示不全。
:::

## 参考信息

### 名词解释

本节介绍数据洞察普通版涉及的名词解释。

#### 频道

使用声网 SDK 进行的所有通话都是在频道内发生的。我们把一个 App 比作一栋大楼的话，频道就好比大楼里面的一个房间。

数据洞察在统计频道数时，会将每一次从有用户加入一个频道到所有用户离开频道计为一个频道（即使频道名相同也会按次数统计）。

#### 用户

频道中的每个用户都有唯一的用户 ID 用于标识在实时音视频互动频道中的用户。App ID 一致的前提下，用户 ID 是用户的唯一标识符。

数据洞察在统计用户人数时，会将相同频道名且相同用户 ID 的用户计为一个人。如果一个真实用户以不同的用户 ID 加入一个频道或者以相同的用户 ID 加入不同频道，均会被计算为多个用户。

#### 用量指标

| 指标名称 | 指标说明 |
| --- | --- |
| 最大同时在线频道数 | 在线频道指有用户加入的频道。 |
| 最大同时在线人数 | 同时在线人数指各频道正在进行通话的人数之和。 |
| 频道数 | 从第一个用户加入频道到最后一个用户离开频道，计为一个频道。 |
| 通话人数 | 按用户 ID 和频道名去重。同一真实用户如果以不同的用户 ID 加入不同频道，会计为多人。 |
| 通话进出人次 | 一个用户进入一次频道，计为一人次。 |
| 通话时长 | 使用声网 RTC SDK 进行视频通话和音频通话的时长。 |
| 视频通话时长 | 使用声网 RTC SDK 进行视频通话的时长。 |
| 音频通话时长 | 使用声网 RTC SDK 进行音频通话的时长。 |
| 云录制最大并发任务数 | 每次调用 `start` 方法开启云端录制即创建一个云端录制任务。仅开启云端录制时展示，详见[云端录制](https://docs.agora.io/cn/cloud-recording/product_cloud_recording)。 |

| 旁路推流最大并发任务数 | <Slot name="basic-markdown-0-11-1" /> |

#### 质量指标

| 指标名称      | 指标说明                                                     | 散点图中对应的横坐标 |
| :------------ | :----------------------------------------------------------- | :------------------- |
| 视频卡顿率    | 视频发生卡顿的时长 / 总视频时长 × 100%。视频卡顿超过 500 ms，即被计入卡顿时长。 | 总视频时长           |
| 音频卡顿率    | 音频发生卡顿的时长 / 总音频时长 × 100%。音频卡顿超过 200 ms，即被计入卡顿时长。 | 总音频时长           |
| 网络延迟率    | 端到端网络延时的时长 / 音频和视频总时长 × 100%。端到端网络延迟超过 400 ms，即被计入延时时长。 | 音频和视频总时长     |
| 登录成功率    | 加入频道成功人数 / 尝试加入频道总人数 × 100%。               | 尝试加入频道总人数   |
| 5 s 登录成功率 | 5 秒内加入频道成功人数 / 尝试加入频道总人数 × 100%。         | 尝试加入频道总人数   |

:::warning[注意]
用于计算质量指标的总视频时长、总音频时长、音频和视频总时长均为[按流计算](#按流计算)的时长用量。
:::

####  维度

| 维度名称 | 维度说明                                 |
| :------- | :--------------------------------------- |
| 地域     | 用户所在的国家和地区。                   |
| 网络类型 | 用户通话时使用的网络，如 Wi-Fi、4G 等。  |
| 操作系统 | 用户使用的操作系统，如 Windows、iOS 等。 |
| SDK 版本 | 用户通话使用的 SDK 版本。                |
| 设备类型 | 用户使用的设备类型，如 iPad 7.5 等。     |

#### 按流计算

在按流计算的方式下，如果一个用户同时订阅了多路音视频流，其接收的每路音视频流都会纳入时长用量的计算。例如：用户 A 同时和用户 B、C、D 视频 10 分钟，那用户 A 按流计算的视频时长为 30 分钟。

### 采样规则

质量概览页面总览版块下的曲线图支持数据采样功能。各指标的采样规则如下：

| 指标名称   | 采样规则                                                     |
| :--------- | :----------------------------------------------------------- |
| 视频卡顿率 | 视频卡顿率大于 5%、1 分钟内所有频道的视频时长之和超过 100 分钟。 |
| 音频卡顿率 | 音频卡顿率大于 3%、1 分钟内所有频道的音频时长之和超过 100 分钟。 |
| 网络延迟率 | 网络延迟率大于 10%、1 分钟内所有频道的音视频时长之和超过 100 分钟。 |

:::warning[注意]
- 采样规则中的视频时长、音频时长、音频和视频总时长均为[按流计算](#按流计算)的时长用量。
- 登录成功率、5 s 登录成功率暂不支持采样。
:::
