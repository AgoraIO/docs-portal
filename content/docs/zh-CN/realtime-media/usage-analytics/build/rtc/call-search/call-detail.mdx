# 通话详情主页

本文介绍如何查看通话详情页面的三个子页面。

参考如下步骤查看通话详情主页：
![通话详情主页示意图](https://web-cdn.agora.io/docs-files/1650254747493)

1. [使用通话检索](/zh-CN/realtime-media/usage-analytics/build/rtc/call-search/overview#使用通话检索)找到要查看的通话，点击**操作**下面的**查看通话详情**。
   - 如果[累计通话人数（ACU）](/zh-CN/realtime-media/usage-analytics/reference/concept#acu累计通话人数)大于或等于 50 人，会自动进入通话全景页面。你需要在页面上方点击**通话详情**页签，切换到通话详情主页。
   - 如果累计通话人数小于 50 人，会自动进入通话详情主页。
2. 添加用户：
   - 逐一添加：输入用户 ID，然后点击**添加用户**。
   - 批量添加：点击**高级搜索**，根据需要设置单个或多个筛选条件，然后点击**查询**。在查询结果中勾选要添加的用户，点击**保存**。
3. 选择展示已添加用户的[音视频质量指标](/zh-CN/realtime-media/usage-analytics/build/rtc/call-search/call-detail)：点击**查看详情**下面的开关即可。最多同时展示 20 个用户的指标详情。
4. 选择要查看的时间区间。改变时间区间后，音视频质量指标的数据会更新。

### 关键事件

关键事件展示每个打开**查看详情**开关的用户在所选时间范围内经历的事件，提供时间轴和列表两种视图。

**时间轴**

时间轴上的圆圈代表事件，圆圈越大，表示对应时间点发生的事件越多。如果发生了需要关注的事件，圆圈会标为红色。
![事件时间轴示意图](https://web-cdn.agora.io/docs-files/1650254782123)

你可以对时间轴进行以下操作：

- 鼠标悬浮在时间轴上的圆圈，查看详情。
- 点击右上角的放大或缩小按钮，调整时间刻度。
- 在右上方的下拉列表中选择要查看的事件类型，包含**登录-退出**、**网络传输**、**视频-发送**、**音频-发送**。
- 点击右上角的**切换为列表**，切换到列表视图。

**列表**

列表包含时间、标签、事件三列，与对应用户的关键质量指标曲线图并排显示。

![事件列表视图示意图](https://web-cdn.agora.io/docs-files/1650254820399)

你可以对列表进行以下操作：

- 在右上方的下拉列表中选择要查看的事件类型，包含**登录-退出**、**网络传输**、**视频-发送**、**视频-接收**、**音频-发送**、**音频-接收**。
- 点击右上角的**切换为时间轴**，切换到时间轴视图。

### 音视频质量指标

音视频质量指标通过统计接收端与发送端最核心的音视频质量指标，准确反映每个打开**查看详情**开关的用户（以下简称“已选用户”）在所选时间范围内的体验质量。

各指标的含义详见[用户级别指标](/zh-CN/realtime-media/usage-analytics/reference/concept#用户级别指标)。

**发送端视角**

点击**发送端视角**，然后点击**音频**或**视频**，即可查看已选用户中所有[发送端用户](/zh-CN/realtime-media/usage-analytics/reference/concept#发送端用户主播)的发送码率和上行丢包率。

![发送端视角音视频质量指标示意图](https://web-cdn.agora.io/docs-files/1650255218008)

参考以下步骤定位异常的发送端用户：

- 如果曲线图上红色毛刺较多，代表上行丢包率较高。点击曲线图右上角的**查看发送端详情**，跳转到[发送端详情页面](/zh-CN/realtime-media/usage-analytics/build/rtc/call-search/call-detail)进一步调查。
- 如果右上角出现感叹号![](https://web-cdn.agora.io/docs-files/1650255317903)，代表该用户可能遇到了严重影响体验的问题。点击感叹号即可跳转到针对该用户的[通话诊断（Beta）](/zh-CN/realtime-media/usage-analytics/build/rtc/call-search/overview#查看通话诊断beta)页面。

**接收端视角**

点击**接收端视角**，然后点击**音频**或**视频**，即可查看已选用户中所有[接收端用户](/zh-CN/realtime-media/usage-analytics/reference/concept#接收端用户观众)的接收码率和卡顿时间。如果接收了多个发送端的音视频，会用不同颜色的曲线区分。

![接收端视角音视频质量指标示意图](https://web-cdn.agora.io/docs-files/1650255600517)

参考以下步骤定位异常的接收端用户：

- 如果曲线图上红色毛刺较多，代表卡顿比较严重。点击曲线图右上角的**选择发送端查看详情**，在下拉列表中选择对应的发送端用户 ID，跳转到[端到端详情页面](/zh-CN/realtime-media/usage-analytics/build/rtc/call-search/call-detail)进一步调查。
- 如果右上角出现感叹号![](https://web-cdn.agora.io/docs-files/1650255317903)，代表该用户可能遇到了严重影响体验的问题。点击感叹号即可跳转到针对该用户的[通话诊断（Beta）](/zh-CN/realtime-media/usage-analytics/build/rtc/call-search/overview#查看通话诊断beta)页面。

## 端到端详情页面

端到端详情页面展示所选接收端用户与发送端用户的以下信息：

- 诊断结论。如果所选的接收端与发送端用户没有遇到可能严重影响体验的问题，则不展示。
- 网络状态、设备状态、音视频质量相关的指标详情，指标含义详见[用户级别指标](/zh-CN/realtime-media/usage-analytics/reference/concept#用户级别指标)。
- 关键事件，包括时间轴和列表视图。在列表视图下，你可以在左上方的下拉菜单中筛选事件类型。

![端到端详情页面示意图](https://web-cdn.agora.io/docs-files/1650256370872)

## 发送端详情页面

发送端详情页面展示所选发送端用户的以下信息：

- 通话诊断结论。如果该发送端用户没有遇到可能严重影响体验的问题，则不展示。
- 网络状态、设备状态、音视频质量相关的指标详情，指标含义详见[用户级别指标](/zh-CN/realtime-media/usage-analytics/reference/concept#用户级别指标)。
- 关键事件，包括时间轴和列表视图。你可以在右上角的下拉菜单中筛选事件类型。

![发送端详情页面示意图](https://web-cdn.agora.io/docs-files/1650256613929)
