## 开启本地日志

当你的应用处于开发、测试阶段时，你可能需要 SDK 输出更详细的信息来定位并修复问题。你可以在初始化 RTM 实例的时候通过设置 `RtmConfig` 中的 `RtmLogConfig` 来开启日志输出并设置日志信息等级，之后即可在 IDE 中查看日志信息。

```typescript
import { RtmClient, RtmConfig, RtmLogConfig, RtmLogLevel } from '@shengwang/rtm-full';

// Configure log settings
const logConfig: RtmLogConfig = {
  filePath: 'your_log_path',
  fileSizeInKB: 10240, // 10MB
  level: RtmLogLevel.INFO
};

// Create RTM configuration
const config: RtmConfig = {
  appId: 'your_appid',
  userId: 'your_userid',
  logConfig: logConfig
};

try {
  const rtmClient = new RtmClient(config);
  console.log('RTM Client initialized successfully');
} catch (error) {
  console.error('Failed to create RTM client:', error);
}
```

`level` 字段可以设置为 `RtmLogLevel.INFO`、`RtmLogLevel.WARN`、`RtmLogLevel.ERROR`、`RtmLogLevel.FATAL`、`RtmLogLevel.NONE` 五个等级之一，其中 `RtmLogLevel.INFO` 输出最详细的日志信息，`RtmLogLevel.NONE` 不输出日志信息。

:::info[信息]
当你的应用上线时，请将日志信息等级设置为 `INFO`。
:::
