本文介绍 RTM 微信小程序 SDK 的错误排查方式。

## 开启本地日志

当你的应用处于开发、测试阶段时，你可能需要 SDK 输出更详细的信息来定位并修复问题。你可以在初始化 RTM 实例的时候通过设置 `` 中的 `` 来开启日志输出并设置日志信息等级，之后即可在微信开发者工具控制台或真机调试日志中查看日志信息。

```javascript showLineNumbers
import AgoraRTM from 'shengwang-rtm-miniapp';

const { RTM } = AgoraRTM;
const rtmConfig = { logLevel: 'debug' };
const rtm = new RTM('yourAppId', 'Tony', rtmConfig);
```

`logLevel` 字段可以设置为 `debug`、`info`、`warn`、`error`、`none` 五个等级之一，其中 `debug` 输出最详细的日志信息，`none` 不输出日志信息。

:::info[信息]
当你的应用上线时，请将日志信息等级设置为 ``。
:::

## 开启日志上传

当你遇到在本地调试无法解决的错误时，可以联系声网技术支持协助你排查问题。此时，你需要开启日志上传功能，声网技术支持会根据你的日志信息来定位错误原因。你需要在初始化 RTM 实例的时候通过设置 `rtmConfig` 参数中的 `logUpload` 参数开启日志上传功能。

```javascript showLineNumbers
const { RTM } = AgoraRTM;
const rtmConfig = {
  logLevel: 'debug',
  logUpload: true,
};
const rtm = new RTM('yourAppId', 'Tony', rtmConfig);
```

:::info[信息]
为避免产生不必要的存储计费，你需要在故障解决后及时关闭日志上传功能。
:::

## 错误码对照表

RTM 微信小程序 SDK 支持并推荐你使用 Async/Await 编程模式，以便在业务中处理 JavaScript 异步操作。在调用 RTM 微信小程序 API 时，如果发生错误，SDK 会抛出一个 `` 类型的错误对象，你需要使用 `try...catch` 捕获该对象。`` 包含以下属性：

```javascript showLineNumbers
type ErrorInfo = {
  error: boolean;      // 本次操作是否出错
  operation: string;   // 本次操作的 API 名称
  errorCode: number;   // 错误码
  reason: string;      // 错误描述
}
```
