## 通过 Maven 集成 SDK

在项目的 Gradle 仓库配置中添加 Maven Central：

```groovy
repositories {
    mavenCentral()
}
```

在应用模块的 `build.gradle` 中添加依赖：

```groovy
dependencies {
    implementation 'cn.shengwang.rtm:android-java:2.3.0'
}
```

完整接入步骤见[实现收发消息](/zh-CN/realtime-media/rtm/get-started/quick-start/android)。
