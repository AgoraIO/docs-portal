---
title: "发送消息"
---
发送消息是 RTM 的基本能力之一，本文主要介绍如何在不同类型的频道中发送消息。同时，你也可以查看[实现收发消息](/zh-CN/realtime-media/rtm/get-started/quick-start)快速构建一个示例程序并体验如何收发消息。

RTM 目前只支持字符串和二进制类型的消息数据格式。如果你的业务中使用了 JSON、Object 等其他数据类型，或者 protobuf 等第三方数据构建工具，那么你需要在发送消息之前对消息数据进行序列化。关于如何有效构建负载数据结构及推荐的序列化方式可以参考[消息负载结构化](/zh-CN/realtime-media/rtm/user-guide/message/constructed)和[消息负载序列化](/zh-CN/realtime-media/rtm/user-guide/message/serialized)。

## Message Channel 中发送消息

在 Message Channel 中，你只需调用 `message.publish` 方法即可发送消息，无需提前订阅频道。该方法一次只能向一个频道发送消息，如需向多个频道发送消息，你需要多次调用该方法。RTM 并不限制你向多少个频道发送消息，也不限制有多少用户向一个频道发送消息，但是对你同时向一个频道发送消息的频率有一定的限制，详见 [API 使用限制](/zh-CN/realtime-media/rtm/user-guide/setup/api-limits)。

:::info[信息]
`message.publish` 方法仅适用于 Message Channel 和 User Channel，你无法使用该方法向 Stream Channel 发送消息。
:::

:::info[信息]
`message.publish` 方法仅适用于 Message Channel，你无法使用该方法向 Stream Channel 发送消息。
:::

发送字符串消息和二进制消息的示例代码如下：

```csharp
// 发送字符串消息
string message = "Hello World";
string channelName = "chat_room";
var options = new PublishOptions();
options.customType = "PlainTxt";

var (status,response) = await rtmClient.PublishAsync(channelName, message, options);
if (status.Error)
{
    Debug.Log(string.Format("{0} is failed, ErrorCode {1}, due to: {2}", status.Operation, status.ErrorCode, status.Reason));
}
else
{
    Debug.Log("Publish Message Success!");
}
```

```javascript
// 发送字符串消息
const payload = "Hello Agora!";
const channelName = "chat_room";
const options = {
    customType: "PlainTxt",
    channelType: "MESSAGE",
};
try {
    const result = await rtm.publish(channelName, payload, options);
} catch (status) {
    const { operation, reason, errorCode } = status;
    console.log(`${operation} failed, ErrorCode: ${errorCode}, due to: ${reason}.`);
}
```

## User Channel 中发送消息

在 User Channel 中，你只需调用 `message.publish` 方法，将 `channelType` 参数设为 `enumv.channeltypeuser`，并将 `channelName` 参数设为指定用户的 `userId`，即可向指定用户发送点对点消息。该方法一次只能向一位用户发送消息，如需向多位用户发送消息，你需要多次调用该方法。RTM 并不限制你向多少用户发送消息，也不限制有多少用户向你发送消息，但是对你向用户发送消息的频率有一定的限制。

:::info[信息]
`message.publish` 方法仅适用于 Message Channel 和 User Channel，你无法使用该方法向 Stream Channel 发送消息。
:::

## Stream Channel 中发送消息

与 Message Channel 不同，在 Stream Channel 中发送消息，你首先需要具备三个前提条件：

1. 你需要创建一个 `channel.istreamchannel` 实例。

2. 你需要调用 `channel.join` 方法加入该频道。

3. 你需要调用 `topic.join` 方法注册成为指定 Topic 的消息发布者。

满足上述条件后，你就可以调用 `topic.publish` 方法向指定的 Topic 发送消息了。该方法一次只能向一个 Topic 发送消息，如需向多个 Topic 发送消息，你可以多次调用该方法。

RTM 规定一位用户同时只能注册成为不超过 8 个 Topic 的消息发布者，即同时只能加入不超过 8 个 Topic，但并不限制一个 Topic 可容纳的用户数量。你向一个 Topic 发送消息的频率可以达到 120 QPS，此特性在需要数据高频大并发的场景中十分有效，例如：元宇宙中的位置状态同步、协同办公中的画板应用、 平行操控中的操作指令传输等。

## 消息负载包体积限制

RTM 对在 Message 类型频道和 Stream 类型频道中发送的消息负载包体积有限制：Message 类型频道中的限制为 32 KB，Stream 类型频道中的限制为 1 KB。消息负载包体积包含消息负载自身加上 `customType` 字段大小。当消息负载包体积超出限制时，你会收到以下返回值：

```csharp
// Status
{
    Error = true;
    ErrorCode =  -11010;
    Operation = "PublishTopicMessageOperation";
    Reason = "CHANNEL_MESSAGE_LENGTH_EXCEED_LIMITATION";
}
```

// When message size exceeds limit, you will receive:
try {
  await rtmClient.publish(channelName, veryLongMessage, options);
} catch (error) {
  if (error instanceof RtmError) {
    console.error(`Operation: ${error.operation}`); // "publish" or "publishTopicMessage"
    console.error(`Error code: ${error.errorCode}`); // -11010
    console.error(`Reason: ${error.reason}`); // "Message length exceeds limit"
