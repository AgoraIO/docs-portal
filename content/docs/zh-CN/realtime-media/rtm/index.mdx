## RTM 是什么？

实时消息（Real-Time Messaging，RTM）负责管理应用实时通信层所需的基础设施。它可以在保障服务可用性的同时，帮助开发者快速接入消息、信令、Presence、Storage 和 Topic 等能力，避免自行开发和运维实时状态同步网络带来的成本和风险。

RTM 适合和 RTC、白板、云端录制、业务服务等能力组合使用。例如，在音视频通话中用 RTM 发送呼叫邀请、麦位变化、礼物消息或房间状态；在 IoT 场景中同步设备状态；在协同场景中同步用户在线状态和业务控制指令。

## RTM 应用场景

RTM 可用于以下类型的实时互动场景：

- **互动直播和语聊房**：同步麦位、礼物、弹幕、房间公告、连麦邀请和主播状态。
- **在线教育和协同办公**：同步课堂状态、课件进度、举手、成员状态和协作控制指令。
- **互动游戏和元宇宙**：同步玩家状态、轻量级游戏事件、房间状态和实时互动指令。
- **IoT 和智能设备**：同步设备在线状态、控制指令、告警消息和设备侧事件。
- **远程医疗、交通运输和金融科技**：同步业务状态、流程节点、位置更新和安全相关事件。

## 阅读路径

如果你首次集成 RTM，请先完成[快速开始](/zh-CN/realtime-media/rtm/get-started/quick-start)，跑通登录和收发消息。进入生产环境前，继续完成[应用配置](/zh-CN/realtime-media/rtm/build/setup-and-access/application-setup)、[Token 鉴权](/zh-CN/realtime-media/rtm/build/security-and-auth/token-generation)和[平台支持](/zh-CN/realtime-media/rtm/reference/platform-support)检查。

如果你是 RTM 旧版本用户，想升级至 v2，请先阅读[迁移指南](/zh-CN/realtime-media/rtm/reference/migration-guide)，再对照当前 SDK 的频道、消息、Presence、Storage 和 Topic 能力调整实现。
