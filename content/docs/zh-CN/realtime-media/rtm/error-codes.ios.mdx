## 开启本地日志

当你的应用处于开发、测试阶段时，你可能需要 SDK 输出更详细的信息来定位并修复问题。你可以在初始化 RTM 实例的时候通过设置 `AgoraRtmClientConfig` 中的 `AgoraRtmLogConfig` 来开启日志输出并设置日志信息等级，之后即可在 IDE 中查看日志信息。

```objc showLineNumbers
AgoraRtmClientConfig* rtm_cfg = [[AgoraRtmClientConfig alloc] initWithAppId:@"your_appid" userId:@"your_userid"];

AgoraRtmLogConfig* log_cfg = [[AgoraRtmLogConfig alloc] init];
log_cfg.level= AgoraRtmLogLevelError;
log_cfg.filePath= @"your_path";
log_cfg.fileSizeInKB = 512;

rtm_cfg.logConfig = log_cfg;
```

`level` 字段可以设置为 `AgoraRtmLogLevelInfo`、`AgoraRtmLogLevelWarn`、`AgoraRtmLogLevelError`、`AgoraRtmLogLevelFatal`、`AgoraRtmLogLevelNone` 五个等级之一，其中 `AgoraRtmLogLevelInfo` 输出最详细的日志信息，`AgoraRtmLogLevelNone` 不输出日志信息。

:::info[信息]
当你的应用上线时，请将日志信息等级设置为 `AgoraRtmLogLevelInfo`。
:::

## 错误码对照表

在调用 RTM iOS/Swift API 时，如果发生错误，SDK 会执行 `completion` 回调并且返回一个 `AgoraRtmErrorInfo` 类型的 `errorInfo` 返回值：

|  属性  |  类型  | 描述                            |
| ---- | ------- | --------- |
| `errorCode` | `AgoraRtmErrorCode` | 本次操作错误码。 |
| `reason` | NSString | 本次操作出错原因。 |
| `operation` | NSString | 本次操作类型。 |

| `-10002` | `AgoraRtmErrorNotLogin` | 用户未登录 RTM 系统、掉线超时或者主动退出登录后调用 API。请先登录 RTM 系统。 |
