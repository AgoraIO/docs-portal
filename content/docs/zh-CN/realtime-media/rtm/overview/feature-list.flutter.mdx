## Setup

| 功能 | API 接口 |
| --- | --- |
| 创建实例 | [`Future<(RtmStatus, RtmClient)> RTM(...)`](/api-ref/rtm2/flutter/toc-configuration/configuration#create) |
| 销毁实例 | [`Future<RtmStatus> release()`](/api-ref/rtm2/flutter/toc-configuration/configuration#release) |
| Token 设置 | [`Future<(RtmStatus, LoginResult?)> login(String token)`](/api-ref/rtm2/flutter/toc-configuration/configuration#login) 接口中的 `token` 参数 |
| 端侧加密 | [`RtmEncryptionConfig`](/api-ref/rtm2/flutter/toc-configuration/configuration#RtmEncryptionConfig) 中的 `encryptionMode`、`encryptionKey`、`encryptionSalt` 参数 |
| Presence 超时设置 | [`RtmConfig`](/api-ref/rtm2/flutter/toc-configuration/configuration#RtmConfig) 中的 `presenceTimeout` 参数 |
| 日志等级设置 | [`RtmLogConfig`](/api-ref/rtm2/flutter/toc-configuration/configuration#RtmLogConfig) 中的 `level` 参数 |
| Proxy 设置 | [`RtmProxyConfig`](/api-ref/rtm2/flutter/toc-configuration/configuration#RtmProxyConfig) 中的 `proxyType`、`server`、`port`、`account`、`password` 参数 |
| 消息传输协议设置 | [`RtmConfig`](/api-ref/rtm2/flutter/toc-configuration/configuration#RtmConfig) 中的 `protocolType` 参数 |
| 私有化部署设置 | [`RtmPrivateConfig`](/api-ref/rtm2/flutter/toc-configuration/configuration#RtmPrivateConfig) 中的 `serviceType`、`accessPointHosts` 参数 |
| 事件监听 | <Slot name="feature-list-flutter-html-0-10-1" /> |
| 登录服务 | [`Future<(RtmStatus, LoginResult?)> login(String token)`](/api-ref/rtm2/flutter/toc-configuration/configuration#login) |
| 登出服务 | [`Future<(RtmStatus, LogoutResult?)> logout()`](/api-ref/rtm2/flutter/toc-configuration/configuration#logout) |
