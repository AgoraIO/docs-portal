---
title: "计费策略"
---
本文展示输入在线媒体流的计费方式。

如果你已与我们的销售签约，则实际计费信息以合同为准。

## 费用组成

通过 RESTful API 创建云端播放器，你可以将一路在线媒体流作为直播视频源输入到声网频道内。声网输入在线媒体流服务费用由转码费用和订阅费用组成。其中：

- 订阅费用：指云端播放器作为虚拟主播加入 RTC 频道后产生的订阅费用。
- 转码费用：指云端播放器把在线媒体流转码并输入到 RTC 频道中的费用。

:::warning[注意]
通过 `isPause` 暂停播放媒体流时，不会触发 `idleTimeout` 倒计时销毁播放器，因此，暂停状态下依然会产生转码和订阅费用。
:::

## 订阅费用

云端播放器加入 RTC 频道后订阅主播端音视频流的过程，和实时互动产品中观众订阅主播端的音视频流相同。因此，订阅费用计费规则请参考[实时音视频计费说明](/zh-CN/realtime-media/rtc/reference/billing-strategy)。

## 转码费用

### 计费公式

云端播放器将在线媒体流转码并输入到 RTC 频道中时会产生转码费用。

计费公式如下：**费用** = **音频转码费用 + 视频转码费用** = **音频转码单价 × 音频转码时长 + 视频转码单价 × 视频转码时长**

### 时长用量

对每个转码过程，声网监测你成功创建云端播放器到其被销毁的时刻，统计你从成功开始转码到最终结束转码的时长，并根据该时长收取转码费用。

如果云端播放器在频道内对视频流进行转码，则计为**视频转码时长**；否则计为**音频转码时长**。

:::warning[注意]
如果你使用云端播放器的定时播放功能，即设置的 `playTs` 时间戳大于 `createTs` 时间戳，则这两个时间戳之间的时间差，按音频转码计费。
:::

### 转码单价

输入在线媒体流的转码单价如下表：

| 类型 | 档位 | 单价（元/千分钟） |
| ---------------- | ---------------- | ---------------- |
| 音频      | N/A      | 8      |
| 高清 HD 视频 | 转码输出的视频分辨率 &le; 921,600（1280 × 720）| 48 |
| 全高清 FHD 视频 | 921,600（1280 × 720）< 转码输出的视频分辨率 &le; 2,073,600（1920 × 1080）| 108 |
