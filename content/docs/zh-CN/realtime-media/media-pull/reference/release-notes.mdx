# 2022.12

本文提供输入在线媒体流服务的更新说明。

本次发布新增 `Update` 接口，用于更新指定的云端播放器配置。

## 2022.06

本次发布改动如下：

1. 新增 `dataStreamOptions` 可选参数，用于设置是否传入声网数据流类型的 SEI 信息。该参数仅适用于点播流。
2. 新增 `seekPosition` 可选参数，用于指定点播文件的播放位置（秒）。该参数仅适用于点播流。
3. 新增 `audioOptions` 和 `videoOptions` 可选参数，用于设置音频和视频转码。
4. 支持设置 `streamUrl` 为图片 URL，输入 JPEG 和 PNG 格式的图片到声网频道。

## 2022.06 前

往期发布改动如下：

1. 支持视频源流 Codec：H.264、H.265、VP8。
2. 支持音频源流 Codec：AAC、OPUS。
3. 支持流媒体协议：HTTP、HTTPS、RTMP、HLS。
4. 支持封装格式：FLV、MP4、MPEG-TS、Matroska (MKV)、MP3。
5. 支持定时播放。你可以设置播放在线媒体流的起始时间，实现在线媒体流的定时播放。
6. 支持限定访问区域。你可以在请求中指定播放在线媒体流的区域，保障媒体流的传输质量。
7. 支持点播流循环播放。
