本文介绍如何通过命令行的方式获取本地视频截图，以便分析视频内容，例如对直播内容进行鉴黄以确保合法合规。

阅读本文前，请确保你已经完成本地服务端录制 SDK 的环境准备和集成工作并且了解如何使用命令行开始录制，详见[集成客户端](/zh-CN/realtime-media/local-server-recording/build/legacy/integrate-sdk)和[命令行录制](/zh-CN/realtime-media/local-server-recording/build/legacy/record-by-cmd)。

## 实现方法

你可通过 `getVideoFrame` 参数设置录制文件格式来获得截图。此外，你还可以通过 `captureInterval` 参数设置截图时间间隔。

:::info[信息]
目前仅支持在单流录制模式下截图。
:::

### 设置录制文件格式

通过 `getVideoFrame` 参数设置录制文件的格式，如下所示。

单流录制模式（`isMixingEnabled` 为 `0`）下，`getVideoFrame` 参数可设为 `3`，`4`，`5`。

### 设置截图时间间隔

通过 `captureInterval` 参数设置截图时间间隔。默认值为 5 秒，最小值为 1 秒。

## 命令行示例

以下命令为单流模式下只录制视频时获取 JPG 截图。

```shell
./recorder_local --appId <你的 App ID> --channel <待录制的频道名> --uid 0 --appliteDir ~/Agora_Recording_SDK_for_Linux_FULL/bin --isVideoOnly 1 --getVideoFrame 4
```
