本文介绍如何调用录制 4.x SDK 的 API 实现本地服务端录制。

## 前提条件

开始前请确保你已经参考[开始录制音视频](/zh-CN/realtime-media/local-server-recording/get-started/start-recording)完成 SDK 集成，并了解实现一个极简录制任务所需的核心 API 时序。

## 调用 API 实现录制

### 初始化服务资源

调用 [`createAgoraService`](/zh-CN/api-reference/local-server-recording/cpp/iagoraservice.cpp#createagoraservice) 创建服务实例，并调用 [`initialize`](/zh-CN/api-reference/local-server-recording/cpp/iagoraservice.cpp#initialize) 方法进行初始化，设置 App ID 和音视频相关配置。

```cpp
auto service = createAgoraService();
agora::base::AgoraServiceConfiguration service_config;
service_config.appId = config.appId.c_str();
service->initialize(service_config);
```

### 创建并初始化 Recorder

调用 [`createAgoraMediaComponentFactory`](/zh-CN/api-reference/local-server-recording/cpp/iagoramediacomponentfactory.cpp#createagoramediacomponentfactory) 和 [`createMediaRtcRecorder`](/zh-CN/api-reference/local-server-recording/cpp/iagoramediacomponentfactory.cpp#createmediartcrecorder) 创建录制实例，然后调用 [`IAgoraMediaRtcRecorder::initialize`](/zh-CN/api-reference/local-server-recording/cpp/iagoramediartcrecorder.cpp#initialize) 方法初始化录制实例，并通过 `enable_mix` 参数选择单流或合流录制模式。

```cpp
agora::rtc::IMediaComponentFactory* factory = createAgoraMediaComponentFactory();
agora::agora_refptr<agora::rtc::IAgoraMediaRtcRecorder> recorder = factory->createMediaRtcRecorder();
// enable_mix 为 false 表示单流录制，true 表示合流录制
recorder->initialize(service, /* enable_mix */ false);
```

### 注册事件处理器

调用 [`registerRecorderEventHandle`](/zh-CN/api-reference/local-server-recording/cpp/iagoramediartcrecorder.cpp#registerrecordereventhandle) 注册录制事件的回调处理器，接收和处理录制过程中的事件通知，如连接状态变化、用户加入/离开等。

```cpp
std::unique_ptr<RecorderEventHandler> eventHandler{new RecorderEventHandler(recorder, config)};
recorder->registerRecorderEventHandle(eventHandler.get());
```

### 订阅音视频流

调用 [`subscribeAllAudio`](/zh-CN/api-reference/local-server-recording/cpp/iagoramediartcrecorder.cpp#subscribeallaudio)、[`subscribeAllVideo`](/zh-CN/api-reference/local-server-recording/cpp/iagoramediartcrecorder.cpp#subscribeallvideo) 订阅频道内所有用户的音视频流；如只需录制指定用户，可改用 [`subscribeAudio`](/zh-CN/api-reference/local-server-recording/cpp/iagoramediartcrecorder.cpp#subscribeaudio)、[`subscribeVideo`](/zh-CN/api-reference/local-server-recording/cpp/iagoramediartcrecorder.cpp#subscribevideo) 按 UID 订阅。

```cpp
recorder->subscribeAllAudio();
recorder->subscribeAllVideo(options);
```

### 设置录制参数

调用 [`setRecorderConfig`](/zh-CN/api-reference/local-server-recording/cpp/iagoramediartcrecorder.cpp#setrecorderconfig)（合流录制）或 [`setRecorderConfigByUid`](/zh-CN/api-reference/local-server-recording/cpp/iagoramediartcrecorder.cpp#setrecorderconfigbyuid)（单流录制）设置录制配置，包括分辨率、帧率、存储路径等。

```cpp
agora::media::MediaRecorderConfiguration recorder_config;
recorder_config.width = config.video.width;
recorder_config.height = config.video.height;
recorder_config.fps = config.video.fps;
recorder_config.storagePath = config.recorderPath.c_str();
recorder->setRecorderConfig(recorder_config);
```

### 加入频道并开始录制

调用 [`joinChannel`](/zh-CN/api-reference/local-server-recording/cpp/iagoramediartcrecorder.cpp#joinchannel) 加入指定频道，然后调用合流录制对应的 [`startRecording`](/zh-CN/api-reference/local-server-recording/cpp/iagoramediartcrecorder.cpp#startrecording) 或单流录制对应的 [`startSingleRecordingByUid`](/zh-CN/api-reference/local-server-recording/cpp/iagoramediartcrecorder.cpp#startsinglerecordingbyuid) 开始录制。

```cpp
recorder->joinChannel(config.token.c_str(), config.ChannelName.c_str(), config.UserId.c_str());
recorder->startRecording();
```

:::info[信息]
单流和合流录制下可调用的 API 不同，详见[单流录制和合流录制](/zh-CN/realtime-media/local-server-recording/build/recording-modes/recording-mode)。
:::

### 结束录制和释放资源

录制完成后，调用相应方法取消订阅流、停止录制、退出频道并释放资源。

```cpp
recorder->unsubscribeAllAudio();
recorder->unsubscribeAllVideo();
recorder->stopRecording();
recorder->unregisterRecorderEventHandle(eventHandler.get());
recorder->leaveChannel();
service->release();
```

本文介绍如何调用录制 4.x SDK 的 API 实现本地服务端录制。

## 前提条件

开始前请确保你已经参考[开始录制音视频](/zh-CN/realtime-media/local-server-recording/get-started/start-recording)完成 SDK 集成，并了解实现一个极简录制任务所需的核心 API 时序。

## 调用 API 实现录制

### 初始化服务资源

创建一个 `AgoraService` 服务实例，并调用 [`initialize`](/zh-CN/api-reference/local-server-recording/java/agoraservice.java#initialize) 方法进行初始化，设置 App ID 和音视频相关配置。

```java
AgoraService agoraService = new AgoraService();
AgoraServiceConfiguration config = new AgoraServiceConfiguration();
config.setAppId(recorderConfig.getAppId());
agoraService.initialize(config);
```

### 创建并初始化 Recorder

调用 [`createMediaRtcRecorder`](/zh-CN/api-reference/local-server-recording/java/agoraservice.java#createmediartcrecorder) 创建录制实例，然后调用 [`AgoraMediaRtcRecorder.initialize`](/zh-CN/api-reference/local-server-recording/java/agoramediartcrecorder.java#initialize) 方法初始化录制实例，并通过 `enableMix` 参数选择单流或合流录制模式。

```java
AgoraMediaRtcRecorder agoraMediaRtcRecorder = agoraService.createMediaRtcRecorder();
// enableMix 为 false 表示单流录制，true 表示合流录制
agoraMediaRtcRecorder.initialize(agoraService, false);
```

### 注册事件处理器

调用 [`registerRecorderEventHandler`](/zh-CN/api-reference/local-server-recording/java/agoramediartcrecorder.java#registerrecordereventhandler) 注册录制事件的回调处理器，接收和处理录制过程中的事件通知，如连接状态变化、用户加入/离开等。

```java
agoraMediaRtcRecorder.registerRecorderEventHandler(eventHandler);
```

### 订阅音视频流

调用 [`subscribeAllAudio`](/zh-CN/api-reference/local-server-recording/java/agoramediartcrecorder.java#subscribeallaudio)、[`subscribeAllVideo`](/zh-CN/api-reference/local-server-recording/java/agoramediartcrecorder.java#subscribeallvideo) 订阅频道内所有用户的音视频流；如只需录制指定用户，可改用 `subscribeAudio`、`subscribeVideo` 按 UID 订阅。

```java
agoraMediaRtcRecorder.subscribeAllAudio();
VideoSubscriptionOptions options = new VideoSubscriptionOptions();
options.setEncodedFrameOnly(false);
agoraMediaRtcRecorder.subscribeAllVideo(options);
```

### 设置录制参数

调用 [`setRecorderConfig`](/zh-CN/api-reference/local-server-recording/java/agoramediartcrecorder.java#setrecorderconfig)（合流录制）或 [`setRecorderConfigByUid`](/zh-CN/api-reference/local-server-recording/java/agoramediartcrecorder.java#setrecorderconfigbyuid)（单流录制）设置录制配置，包括分辨率、帧率、存储路径等。

```java
MediaRecorderConfiguration mediaRecorderConfiguration = new MediaRecorderConfiguration();
mediaRecorderConfiguration.setWidth(recorderConfig.getVideo().getWidth());
mediaRecorderConfiguration.setHeight(recorderConfig.getVideo().getHeight());
mediaRecorderConfiguration.setStoragePath(recorderConfig.getRecorderPath());
agoraMediaRtcRecorder.setRecorderConfig(mediaRecorderConfiguration);
```

### 加入频道并开始录制

调用 [`joinChannel`](/zh-CN/api-reference/local-server-recording/java/agoramediartcrecorder.java#joinchannel) 加入指定频道，然后调用合流录制对应的 [`startRecording`](/zh-CN/api-reference/local-server-recording/java/agoramediartcrecorder.java#startrecording) 或单流录制对应的 [`startSingleRecordingByUid`](/zh-CN/api-reference/local-server-recording/java/agoramediartcrecorder.java#startsinglerecordingbyuid) 开始录制。

```java
agoraMediaRtcRecorder.joinChannel(recorderConfig.getToken(),
                recorderConfig.getChannelName(),
                recorderConfig.getUserId());
agoraMediaRtcRecorder.startRecording();
```

:::info[信息]
单流和合流录制下可调用的 API 不同，详见[单流录制和合流录制](/zh-CN/realtime-media/local-server-recording/build/recording-modes/recording-mode)。
:::

### 结束录制和释放资源

录制完成后，调用相应方法取消订阅流、停止录制、退出频道并释放资源。

```java
agoraMediaRtcRecorder.unsubscribeAllAudio();
agoraMediaRtcRecorder.unsubscribeAllVideo();
agoraMediaRtcRecorder.stopRecording();
agoraMediaRtcRecorder.unregisterRecorderEventHandler(eventHandler);
agoraMediaRtcRecorder.leaveChannel();
agoraMediaRtcRecorder.release();
agoraService.release();
```
