---

声网 RTC Server SDK 部署在你的服务端环境中，可通过声网实时网络与客户端 SDK 互通，实现服务端发送、接收和处理音视频流。它适合云端媒体处理、呼叫中心、自动化测试、AI 互动课堂等需要服务端参与实时频道的场景。

RTC Server SDK 支持 YUV、PCM、编码音视频等多种媒体格式，并支持按需配置发送、接收、多频道处理、合图、媒体加密和区域访问限制等能力，帮助你在服务端保持更灵活的媒体控制。

## 产品特性

<CardGrid>
  <FeatureCard title="支持多类服务端场景">
    适用于呼叫中心、在线教育、网络测试和 AI 互动等服务端需要加入 RTC 频道的场景。
  </FeatureCard>
  <FeatureCard title="多格式收发媒体流">
    支持收发 YUV、PCM、编码音视频等多种媒体格式，便于在服务端接入自定义媒体处理链路。
  </FeatureCard>
  <FeatureCard title="灵活配置收发流程">
    可同时发送和接收媒体流，也可以只发送或只接收音频、视频流，满足不同服务端工作流。
  </FeatureCard>
  <FeatureCard title="多频道能力">
    支持同时向多个频道发送媒体流，或从多个频道接收媒体流。
  </FeatureCard>
  <FeatureCard title="合图与媒体加密">
    支持合图、音频混音和媒体加密，帮助你在服务端完成更复杂的媒体处理。
  </FeatureCard>
  <FeatureCard title="区域访问限制">
    支持限制媒体连接区域，满足特定地区访问、合规或部署要求。
  </FeatureCard>
</CardGrid>
