本文提供你在使用声网 RTC 服务端 SDK 中可以使用的资源。

## 通过 Maven 集成 SDK

打开 `pom.xml` 文件，在 `dependencies` 中添加 SDK 的依赖。

```xml
<dependencies>
  <dependency>
    <groupId>io.agora.rtc</groupId>
    <artifactId>linux-java-sdk</artifactId>
    <version>4.4.32</version>
  </dependency>
</dependencies>
```

## 通过 pip 集成 SDK

在终端中，进入你的项目根目录，然后运行以下命令集成 SDK：

```bash
pip install agora_python_server_sdk
```

## 通过 Go Module 集成 SDK

按照以下步骤集成 SDK：

1. 在终端中，运行以下命令下载 SDK。

   ```bash
   git clone https://github.com/AgoraIO-Extensions/Agora-Golang-Server-SDK.git go_rtc_sdk
   ```

2. 依次运行以下命令编译项目。

   ```bash
   # 进入 SDK 目录
   cd go_rtc_sdk
   # 执行编译
   make build
   ```

3. 在项目的 `go.mod` 文件中添加以下配置，增加 SDK 所需依赖。

   ```bash
   # 将 /path/to/go_rtc_sdk 修改为你在步骤 1 中下载的 SDK 的实际路径
   replace github.com/AgoraIO-Extensions/Agora-Golang-Server-SDK/v2 => /path/to/go_rtc_sdk
   # 将 version_number 修改为 SDK 实际版本号，你可以在发版说明中获取版本号，例如 v2.1.0
   require github.com/AgoraIO-Extensions/Agora-Golang-Server-SDK/v2 version_number
   ```
