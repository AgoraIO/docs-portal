## 通过 Maven 集成 Java SDK

打开 `pom.xml` 文件，在 `dependencies` 中添加 SDK 依赖。

```xml
<dependencies>
  <dependency>
    <groupId>io.agora.rtc</groupId>
    <artifactId>linux-java-sdk</artifactId>
    <version>4.4.32</version>
  </dependency>
</dependencies>
```

## 通过 pip 集成 Python SDK

```bash
pip install agora_python_server_sdk
```
