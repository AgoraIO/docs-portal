在调用 RTMP 网关 API 过程中，你可能收到如下 HTTP 响应状态码：

- 如果 HTTP 状态码为 2XX，则请求成功。

- 如果 HTTP 状态码不为 2XX，则请求失败。你可以根据对应的响应 Body 中可能出现的 `message` 字段排查问题。

例如，请求失败时，你可能收到如下响应：

```json
# 400 Bad Request
{
  "message": "appid is invalid"
}
```

## 推流码响应状态码

| 状态码 | 可能的 `message` 字段内容 | 原因 | 建议措施 |
| --- | --- | --- | --- |
| `200 OK` | / | 请求执行成功。 | 无需处理。 |
| `400 Bad Request` | <Slot name="response-code-html-0-2-1" /> | 请求参数错误。 | 根据 `message` 字段的具体内容进行排查。 |
| `401 Unauthorized` | Invalid authentication credentials. | RESTful API 鉴权失败。 | 重新执行 [HTTP 鉴权](/zh-CN/realtime-media/rtmp-gateway/build/setup-and-access/http-auth)。 |
| `403 Forbidden` | <Slot name="response-code-html-0-4-1" /> | <Slot name="response-code-html-0-4-2" /> | <Slot name="response-code-html-0-4-3" /> |
| `404 Not Found` | Resource is not found and destroyed. | 请求的资源不存在。 | 检查传入的 `streamKey` 是否正确。 |
| `409 Conflict` | Resource with the same name already exists. | 并发请求过多。 | 采取退避策略重试。例如，第一次等待 1 秒后重试，第二次等待 3 秒后重试，第三次等待 6 秒后重试。 |
| `429 Too Many Requests` | <Slot name="response-code-html-0-7-1" /> | 并发请求过多。 | 采取退避策略重试。例如，第一次等待 1 秒后重试，第二次等待 3 秒后重试，第三次等待 6 秒后重试。 |
| `500 Internal Server Error` | Some internal error happened. Contact us to help fix it. | 服务端内部错误。 | 采取退避策略重试。例如，第一次等待 1 秒后重试，第二次等待 3 秒后重试，第三次等待 6 秒后重试。 |
| `503 Service Unavailable` | <Slot name="response-code-html-0-9-1" /> | 服务端内部错误。 | 采取退避策略重试。例如，第一次等待 1 秒后重试，第二次等待 3 秒后重试，第三次等待 6 秒后重试。 |
| `504 Gateway Timeout` | Gateway timeout. Query to check whether the player has been created, or to create another one instead. | 服务端内部错误。 | 采取退避策略重试。例如，第一次等待 1 秒后重试，第二次等待 3 秒后重试，第三次等待 6 秒后重试。 |

      - Parameter 'channel' is invalid formatted.
      - Streamkey exists in region:na.

</Slot>

<Slot for="response-code-html-0-4-1">

- This project has not enabled RTMP Gateway yet. Contact us to enable it.
      - Stream does not belong to this app ID.

</Slot>

<Slot for="response-code-html-0-4-2">

- 未开通 RTMP 网关服务。
      - 查询的推流码不属于该  App ID。

</Slot>

<Slot for="response-code-html-0-4-3">

- [联系技术支持](https://ticket.shengwang.cn)开通 RTMP 网关服务。
      - 检查传入的 `streamKey` 和 App ID 是否匹配。

</Slot>

<Slot for="response-code-html-0-7-1">

- Request rate limit exceeded.
      - Resources quota limit exceeded.
      - No available resources.

</Slot>

      - Service unavailable temporarily. Retry with back off strategy.

</Slot>
