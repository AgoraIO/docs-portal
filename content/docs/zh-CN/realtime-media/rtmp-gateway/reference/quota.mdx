<a id="pcw"></a>
## 峰值并发任务数

峰值并发任务数（PCW, Peak Concurrent Workload）指最大并发任务数，即在一个项目下最多同时推送的流的总数。可以同时推送 RTMP 和 SRT 流，或只推其中一种，以最终总数为准。

分为以下两种情况：

- 开启视频转码：默认 10 条
- 不开启视频转码：默认 50 条

:::info[信息]
该限制适用于所有区域。
:::

## 调用频率限制

声网服务器限制 RTMP 网关 API 调用速率，超出限制速率时会返回状态码 `429(Too Many Requests)`。

在有并发任务场景下，rtmp-gateway服务的每秒请求数不能超过最大并发任务数的 10%。

下表展示各 API 调用频率限制：

| API      | 调用频率限制                                                     |
| :------- | :----------------------------------------------------------- |
| `Create` | 一个项目中，创建推流码的速率上限为 50 次/秒。 |
| `Delete` | 一个项目中，销毁推流码的速率上限为 50 次/秒。           |
| `Query`   | 一个项目中，查询的速率上限为 100 次/秒。 |
| `Update`   | 一个项目中，设置服务配置的速率上限为 50 次/秒。 |
