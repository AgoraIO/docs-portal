## 通过 Maven Central 集成 SDK

打开 `/app/build.gradle` 文件，在 `dependencies` 中添加声网 RTC SDK 的依赖。

```groovy tab="视频 SDK" tabGroup="integrate-sdk"
...
dependencies {
    ...
    // 集成 Full SDK
    implementation 'cn.shengwang.rtc:full-sdk:4.6.3'
    // 集成 Lite SDK
    implementation 'cn.shengwang.rtc:lite-sdk:4.6.3'
}
```

```groovy tab="音频 SDK" tabGroup="integrate-sdk"
...
dependencies {
    ...
    // 集成音频 SDK
    implementation 'cn.shengwang.rtc:voice-sdk:4.6.3'
}
```

## 通过 Cocoapods 集成 SDK

本节提供通过 Cocoapods 集成 SDK 的方式。

```ruby tab="视频 SDK" tabGroup="integrate-sdk"
platform :ios, '9.0'
target 'Your App' do
    # 集成 Full SDK
    pod 'ShengwangRtcEngine_iOS', '4.6.2'
    # 选择性集成 Full SDK 中的基础库和指定动态库
    pod 'ShengwangRtcEngine_iOS', '4.6.2', :subspecs => ['RtcBasic', 'AINS', 'ClearVision']
    # 集成 Lite SDK
    pod 'ShengwangLite_iOS', '4.6.2',
end
```

```ruby tab="音频 SDK" tabGroup="integrate-sdk"
platform :ios, '9.0'
target 'Your App' do
    # 集成音频 SDK
    pod 'ShengwangAudio_iOS', '4.6.2'
    # 选择性集成音频 SDK 中的基础库和指定动态库
    pod 'ShengwangAudio_iOS', '4.6.2', :subspecs => ['RtcBasic', 'AINS', 'AudioBeauty']
end
```
