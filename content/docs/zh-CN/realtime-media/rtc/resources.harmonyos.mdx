## 下载 SDK

本节提供 SDK 最新版本的 CDN 下载链接。

:::info[信息]
- 各版本 SDK 的发版详情请参考[发版说明](/zh-CN/realtime-media/rtc/overview/release-notes.harmonyos)。
  - 如何使用 SDK 实现各种音视频互动功能请参考[实现音视频互动](/zh-CN/realtime-media/rtc/get-started/quick-start.harmonyos)。
:::

视频 SDK 中提供了简单易用的 API，帮助开发者在 App 中构建各种实时音视频互动场景。

- SDK 名称：视频 SDK
- 开发者：上海声网科技有限公司
- 视频 SDK 合规使用说明请参考[视频 SDK 合规使用说明](/basics/security/video-sdk)，个人信息处理规则请参考 [SDK 个人信息处理规则](https://www.shengwang.cn/SDK-privacy-policy/)。

  - [HarmonyOS NEXT Full](https://download.agora.io/sdk/release/Agora_Native_SDK_for_HarmonyOS_v4.4.2_FULL.har)

</TabsContent>

<TabsContent value="audio">

音频 SDK 中提供了简单易用的 API，帮助开发者在 App 中构建纯语音互动场景。

- SDK 名称：音频 SDK
- 开发者：上海声网科技有限公司
- 音频 SDK 合规使用说明请参考[音频 SDK 合规使用说明](/basics/security/voice-sdk)，个人信息处理规则请参考 [SDK 个人信息处理规则](https://www.shengwang.cn/SDK-privacy-policy/)。

  - [HarmonyOS NEXT Audio](https://download.agora.io/sdk/release/Agora_Native_SDK_for_HarmonyOS_V4.4.2_VOICE.har)

</TabsContent>
