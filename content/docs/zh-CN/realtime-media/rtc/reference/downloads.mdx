本文提供实时互动 SDK 的下载和集成入口。下载数据与全局 [SDK 下载](/zh-CN/api-reference/sdks?product=rtc)页共用同一来源，默认显示当前官网明确列出的版本。

:::info[SDK 合规信息公示]
**功能介绍：** 为开发者提供实时音视频通话、互动直播、极速直播和纯音频互动能力。

**基本信息：** SDK 名称为视频 SDK 或语音 SDK；开发者为上海声网科技有限公司；版本号、发布日期、包名和 MD5 值见下列下载选项。

**使用说明：** 各版本 SDK 的发版详情请参考[发版说明](/zh-CN/realtime-media/rtc/reference/release-notes)，个人信息处理规则请参考 [SDK 个人信息处理规则](https://www.shengwang.cn/SDK-privacy-policy/)。
:::
