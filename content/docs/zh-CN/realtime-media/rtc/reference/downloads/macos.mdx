## 通过 CocoaPods 集成 SDK

通过 CocoaPods 集成 macOS SDK 前，请在 `Podfile` 顶部添加声网 CocoaPods CDN 源。请保留项目中已有的源配置；如果项目还依赖公共仓库中的其他 Pod，请同时保留公共源，例如 `source 'https://cdn.cocoapods.org/'`。

以下示例将 CocoaPods 官方公共源放在声网源前面，默认集成完整 SDK。如需按需集成，请注释默认的 `pod` 行，并取消对应行的注释。

将 `Your App` 替换为你的 Target 名称。`Podfile` 中的平台版本应与工程的 **macOS Deployment Target** 保持一致，且不低于 SDK 支持的最低版本。

```ruby
source 'https://cdn.cocoapods.org/'
source 'https://download.shengwang.cn/cocoapods/'

platform :macos, '10.11'
target 'Your App' do
    # 集成 SDK
    pod 'ShengwangRtcEngine_macOS', '4.7.0'
    # 或选择性集成 SDK 中的基础库和指定动态库
    # pod 'ShengwangRtcEngine_macOS', '4.7.0', :subspecs => ['RtcBasic', 'AINS', 'ClearVision']
end
```

在 `Podfile` 所在目录执行 `pod install --repo-update`，安装所需版本的 SDK。如遇安装问题，请参考 [CocoaPods 常见问题](/zh-CN/reference/faq/integration/cocoapods_problems#无法安装最新版-rtc-sdk)。

## 通过 SPM 集成 SDK

按以下步骤，通过 Swift Package Manager 在 Xcode 工程中集成 SDK：

1. 在 Xcode 中，选择 **File > Add Package Dependencies...**。
2. 输入以下 HTTPS 仓库地址：

```text
https://github.com/Shengwang-Lab/ShengwangRtcEngine_macOS.git
```

3. 在 **Dependency Rule** 中选择 **Exact Version**，输入 `4.7.0`，然后点击 **Add Package**。
4. 在产品列表中，为应用的 Target 选择 `RtcBasic` 基础组件，其他组件按功能需要选择，然后完成添加。

添加完成后，可在工程的 **Package Dependencies** 中确认 SDK 版本。
