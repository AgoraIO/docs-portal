## 通过 CocoaPods 集成 SDK

```ruby
platform :macos, '10.11'
target 'Your App' do
    pod 'ShengwangRtcEngine_macOS', '4.6.2'
    pod 'ShengwangRtcEngine_macOS', '4.6.2', :subspecs => ['RtcBasic', 'AINS', 'ClearVision']
end
```

## 通过 SPM 集成 SDK

```text
github:git@github.com:Shengwang-Lab/ShengwangRtcEngine_macOS.git | tag:4.6.2
```
