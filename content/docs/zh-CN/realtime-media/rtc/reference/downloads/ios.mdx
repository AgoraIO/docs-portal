本文提供获取 SDK、Demo 和示例项目的方式。

## 通过 CocoaPods 集成 SDK

本节提供通过 CocoaPods 集成 SDK 的方式。

```ruby tab="视频 SDK" tabGroup="ios-integrate-sdk"
platform :ios, '9.0'
target 'Your App' do
    # 集成 Full SDK
    pod 'ShengwangRtcEngine_iOS', '4.7.0'
    # 选择性集成 Full SDK 中的基础库和指定动态库
    pod 'ShengwangRtcEngine_iOS', '4.7.0', :subspecs => ['RtcBasic', 'AINS', 'ClearVision']
    # 集成 Lite SDK
    pod 'ShengwangLite_iOS', '4.7.0'
end
```

```ruby tab="音频 SDK" tabGroup="ios-integrate-sdk"
platform :ios, '9.0'
target 'Your App' do
    # 集成音频 SDK
    pod 'ShengwangAudio_iOS', '4.7.0'
    # 选择性集成音频 SDK 中的基础库和指定动态库
    pod 'ShengwangAudio_iOS', '4.7.0', :subspecs => ['RtcBasic', 'AINS', 'AudioBeauty']
end
```

## 通过 SPM 集成 SDK

本节提供通过 SPM (Swift Package Manager) 集成 SDK 的方式。

```text tab="视频 SDK" tabGroup="ios-spm-sdk"
// 集成 Full SDK
github:git@github.com:Shengwang-Lab/ShengwangRtcEngine_iOS.git | tag:4.7.0

// 集成 Lite SDK
github:git@github.com:Shengwang-Lab/ShengwangLite_iOS.git | tag:4.7.0
```

```text tab="音频 SDK" tabGroup="ios-spm-sdk"
github:git@github.com:Shengwang-Lab/ShengwangAudio_iOS.git | tag:4.7.0
```

## 下载 SDK

本节提供 SDK 最新版本的 CDN 下载链接。

:::info[信息]
- SDK 默认使用 libc++ (LLVM)，如需使用 libstdc++ (GNU)，请联系 sales@shengwang.cn。SDK 提供的库是 FAT Image，包含 32/64 位模拟器、32/64 位真机版本。
- 各版本 SDK 的发版详情请参考[发版说明](/zh-CN/realtime-media/rtc/reference/release-notes)。
- 如何使用 SDK 实现各种音视频互动功能请参考[实现音视频互动](/zh-CN/realtime-media/rtc/get-started/quick-start)。
- 集成 SDK 后增加的实际包体积数据会根据集成的动态库的不同而有所差异，本页提供的数据仅供参考。
:::
