## 通过 CocoaPods 集成 SDK

通过 CocoaPods 集成 iOS SDK 前，请在 `Podfile` 顶部添加声网 CocoaPods CDN 源。请保留项目中已有的源配置；如果项目还依赖公共仓库中的其他 Pod，请同时保留公共源，例如 `source 'https://cdn.cocoapods.org/'`。

以下示例将 CocoaPods 官方公共源放在声网源前面，默认集成 Full SDK 或音频 SDK。如需使用其他集成方式，请注释默认的 `pod` 行，并取消对应行的注释。

将 `Your App` 替换为你的 Target 名称。`Podfile` 中的平台版本应与工程的 **iOS Deployment Target** 保持一致，且不低于 SDK 支持的最低版本。

```ruby tab="视频 SDK" tabGroup="ios-integrate-sdk"
source 'https://cdn.cocoapods.org/'
source 'https://download.shengwang.cn/cocoapods/'

platform :ios, '9.0'
target 'Your App' do
    # 集成 Full SDK
    pod 'ShengwangRtcEngine_iOS', '4.7.1'
    # 或选择性集成 Full SDK 中的基础库和指定动态库
    # pod 'ShengwangRtcEngine_iOS', '4.7.1', :subspecs => ['RtcBasic', 'AINS', 'ClearVision']
    # 或集成 Lite SDK
    # pod 'ShengwangLite_iOS', '4.7.1'
end
```

```ruby tab="音频 SDK" tabGroup="ios-integrate-sdk"
source 'https://cdn.cocoapods.org/'
source 'https://download.shengwang.cn/cocoapods/'

platform :ios, '9.0'
target 'Your App' do
    # 集成音频 SDK
    pod 'ShengwangAudio_iOS', '4.7.1'
    # 或选择性集成音频 SDK 中的基础库和指定动态库
    # pod 'ShengwangAudio_iOS', '4.7.1', :subspecs => ['RtcBasic', 'AINS', 'AudioBeauty']
end
```

在 `Podfile` 所在目录执行 `pod install --repo-update`，安装所需版本的 SDK。如遇安装问题，请参考 [CocoaPods 常见问题](/zh-CN/reference/faq/integration/cocoapods_problems#无法安装最新版-rtc-sdk)。

## 通过 SPM 集成 SDK

按以下步骤，通过 Swift Package Manager 在 Xcode 工程中集成 SDK：

1. 在 Xcode 中，选择 **File > Add Package Dependencies...**。
2. 根据需要集成的 SDK 类型，输入对应的 HTTPS 仓库地址：

<Tabs defaultValue="swift-video" groupId="ios-spm-sdk" persist>
<TabsList>
  <TabsTrigger value="swift-video">视频 SDK</TabsTrigger>
  <TabsTrigger value="swift-audio">音频 SDK</TabsTrigger>
</TabsList>

<TabsContent value="swift-video">

**Full SDK**

```text
https://github.com/Shengwang-Lab/ShengwangRtcEngine_iOS.git
```

**Lite SDK**

```text
https://github.com/Shengwang-Lab/ShengwangLite_iOS.git
```

Lite SDK 仅需选择 `RtcBasic` 基础组件。

</TabsContent>

<TabsContent value="swift-audio">

```text
https://github.com/Shengwang-Lab/ShengwangAudio_iOS.git
```

</TabsContent>
</Tabs>

3. 在 **Dependency Rule** 中选择 **Exact Version**，输入 `4.7.1`，然后点击 **Add Package**。
4. 在产品列表中，为应用的 Target 选择 `RtcBasic` 基础组件，其他组件按功能需要选择，然后完成添加。

添加完成后，可在工程的 **Package Dependencies** 中确认 SDK 版本。
