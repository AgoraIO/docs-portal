## 通过 npm 集成 SDK

```shell
npm install agora-rtc-sdk-ng
```

使用 npm 集成 Web SDK 还支持开启 Tree shaking 来减小集成 SDK 后的 App 体积，详见[使用 Tree shaking](/zh-CN/realtime-media/rtc/build/optimize-and-operate/tree-shaking)。

## 下载 SDK

视频 SDK 中提供了简单易用的 API，帮助开发者在 App 中构建各种实时音视频互动场景。

- SDK 名称：视频 SDK
- 开发者：上海声网科技有限公司
- 视频 SDK 合规使用说明请参考[视频 SDK 合规使用说明](/zh-CN/introduction/security/video-sdk)，个人信息处理规则请参考 [SDK 个人信息处理规则](https://www.shengwang.cn/SDK-privacy-policy/)。
