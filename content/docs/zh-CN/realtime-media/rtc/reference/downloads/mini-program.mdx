## 通过 npm 集成 SDK

```json
"dependencies": {
  "agora-miniapp-sdk": "latest"
}
```

详细步骤请参考[集成 SDK](/zh-CN/realtime-media/rtc/get-started/quick-start#5-集成-sdk)。

## 下载 SDK

视频 SDK 中提供了简单易用的 API，帮助开发者在 App 中构建各种实时音视频互动场景。

- SDK 名称：视频 SDK
- 开发者：上海声网科技有限公司
- 视频 SDK 合规使用说明请参考[视频 SDK 合规使用说明](/zh-CN/introduction/security/sdk-compliance/video-sdk)，个人信息处理规则请参考 [SDK 个人信息处理规则](https://www.shengwang.cn/SDK-privacy-policy/)。
