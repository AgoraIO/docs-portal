## 通过 Gradle 自动集成 SDK

在添加 SDK 依赖前，请先添加声网 Maven CDN 仓库。请保留项目中已有的 Maven 仓库配置，尤其是 `mavenCentral()`。

进入项目根目录，打开 `settings.gradle` 文件，在 `dependencyResolutionManagement` 的 `repositories` 中添加如下配置：

:::warning[注意]
如果你在 `settings.gradle` 中找不到 `dependencyResolutionManagement` 字段，可能是因为你的 Android Gradle Plugin 版本低于 v7.1.0。

相关信息请参考 [Android Gradle Plugin Release Note v7.1.0](https://developer.android.com/build/releases/past-releases/agp-7-1-0-release-notes)。
:::

```groovy
dependencyResolutionManagement {
    repositoriesMode.set(RepositoriesMode.FAIL_ON_PROJECT_REPOS)
    repositories {
        mavenCentral()
        maven { url = 'https://download.shengwang.cn/maven/' }
    }
}
```

若你的 Android Gradle Plugin 版本低于 v7.1.0，请打开项目根目录下的 `build.gradle` 文件，在 `allprojects` 的 `repositories` 中添加如下配置：

```groovy
allprojects {
    repositories {
        mavenCentral()
        maven { url = 'https://download.shengwang.cn/maven/' }
    }
}
```

打开 `/app/build.gradle` 文件，在 `dependencies` 中添加声网 RTC SDK 的依赖。

```groovy tab="视频 SDK" tabGroup="integrate-sdk"
...
dependencies {
    ...
    // 视频 SDK 提供 Full SDK 和 Lite SDK 两种依赖。请根据业务需要选择其中一种。
    // 集成 Full SDK
    implementation 'cn.shengwang.rtc:full-sdk:4.7.0'
    // 或集成 Lite SDK
    implementation 'cn.shengwang.rtc:lite-sdk:4.7.0'
}
```

```groovy tab="音频 SDK" tabGroup="integrate-sdk"
...
dependencies {
    ...
    // 集成音频 SDK
    implementation 'cn.shengwang.rtc:voice-sdk:4.7.0'
}
```

## 下载 SDK

:::info[信息]
- SDK 默认使用 libc++ (LLVM)，如需使用 libstdc++ (GNU)，请联系 sales@shengwang.cn。SDK 提供的库是 FAT Image，包含 32/64 位模拟器、32/64 位真机版本。
- 各版本 SDK 的发版详情请参考[发版说明](/zh-CN/realtime-media/rtc/reference/release-notes)。
- 如何使用 SDK 实现各种音视频互动功能请参考[实现音视频互动](/zh-CN/realtime-media/rtc/get-started/quick-start)。
- 集成 SDK 后增加的实际包体积数据会根据集成的动态库的不同而有所差异，本页提供的数据仅供参考。
:::
