## 通过 Maven Central 集成 SDK

打开 `/app/build.gradle` 文件，在 `dependencies` 中添加声网 RTC SDK 的依赖。

```groovy tab="视频 SDK" tabGroup="android-integrate-sdk"
...
dependencies {
    ...
    implementation 'cn.shengwang.rtc:full-sdk:4.6.4'
    implementation 'cn.shengwang.rtc:lite-sdk:4.6.4'
}
```

```groovy tab="音频 SDK" tabGroup="android-integrate-sdk"
...
dependencies {
    ...
    implementation 'cn.shengwang.rtc:voice-sdk:4.6.4'
}
```

## 通过 Gradle 自动集成 SDK

在添加 SDK 依赖前，请在 `settings.gradle` 中的 `dependencyResolutionManagement.repositories` 添加声网 Maven CDN：

```groovy
maven { url = 'https://download.shengwang.cn/maven/' }
```

如果 Android Gradle Plugin 低于 v7.1.0，请在根目录 `build.gradle` 的 `allprojects.repositories` 中添加该仓库。
