本文介绍如何在声网控制台开启实时互动 RTC 的小程序服务。

## 前提条件

参考[开通 RTC 服务](/zh-CN/realtime-media/rtc/build/setup-and-access/enable-service)，在控制台创建项目、获取 App ID 和临时 Token。

<a id="enable"></a>
<a id="开启小程序服务"></a>

## 开通步骤

第一次使用微信小程序时，需要参考如下步骤开通服务：

1. 登录声网[控制台](https://console.shengwang.cn/)，点击左侧导航栏的**全部产品**，选择**实时互动 RTC**，进入实时互动 RTC 页面。

2. 在实时互动 RTC 页面，切换到**功能配置**页签。

   ![开通服务一](https://web-cdn.agora.io/docs-portal/img/rtc/enable-service-mini-program1.png)

3. 选择**小程序**，然后点击下方的**开启**按钮。

   ![开通服务二](https://web-cdn.agora.io/docs-portal/img/rtc/enable-service-mini-program2.png)

   点击后，控制台会自动发出弹窗，提示小程序最大并发频道数。点击**启用**。

4. 成功启用小程序后，你可以通过下方的**前往查看**按钮查看小程序项目的用量。
