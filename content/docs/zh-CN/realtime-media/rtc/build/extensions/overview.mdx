为进一步拓展实时互动的业务场景，声网 RTC Web SDK 通过插件的形式提供一系列高级功能，如美颜、合图、虚拟背景等。

可以根据实际场景需要，选择合适的插件进行集成。

## 插件技术原理

声网 Web SDK 的媒体传输管道包含采集、前处理、编码、传输、解码、后处理和播放等环节。在前处理阶段，插件可以对管道中的音视频数据进行处理，从而实现虚拟背景、降噪、美颜、语音活动检测等功能。

## 插件列表

| 插件名称 | 功能描述 |
| -------- | -------- |
| [AI 降噪插件](/zh-CN/realtime-media/rtc/build/extensions/noise-reduction) | 使用声网人工智能噪声消除算法，降低上百种噪声，减少多人同时说话时的人声失真。|
| [VAD 插件 (Beta)](/zh-CN/realtime-media/rtc/build/extensions/voice-activity-detection) | 实时检测音频流中的人声活动状态，支持静音检测和语音检测两种模式。|
| [虚拟背景插件](/zh-CN/realtime-media/rtc/build/extensions/virtual-background) | 在视频通话中替换或模糊用户的背景，实现虚拟背景效果。|
| [美颜插件 (Beta)](/zh-CN/realtime-media/rtc/build/extensions/image-enhancement) | 提供多种美颜效果，如磨皮、美白、祛痘、红润等，提升用户视频画面质量。|
| [合图插件 (Beta)](/zh-CN/realtime-media/rtc/build/extensions/video-compositing) | 支持将多个视频流合成为一个视频流，适用于多主播同屏等场景。|
| [AI 画质插件 (Beta)](/zh-CN/realtime-media/rtc/build/extensions/super-clarity) | 利用 AI 技术提升视频画质，增强视频清晰度和细节表现。|
| [水印插件 (Beta)](/zh-CN/realtime-media/rtc/build/extensions/watermark) | 在视频流上添加自定义水印，保护内容版权。
