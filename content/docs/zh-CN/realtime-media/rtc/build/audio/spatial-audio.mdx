空间音频能够将真实世界的声音体验带到虚拟数字世界，为用户提供更具吸引力的在线体验。通过声网提供的空间音频技术，你可以在虚拟互动场景下模拟声音在现实环境中的传播特点：

**超拟真空间塑造效果**

利用范围音频、声音模糊、空气衰减模拟等技术，完美模拟现实听觉感受。

- 当声源和其他角色之间的距离、方位或朝向发生变化时，不同的角色听到的声音大小和方向均不相同。
- 当声源和其他角色之间的距离超过设置的范围后，后者无法听到声源发出的声音。
- 通过设置隔声区域、空气衰减、声音模糊等音效，完美模拟现实的听觉感受。

**3D 高保真**

- 根据面部朝向、音源朝向、3D 空间内音源的相对位置进行音效处理渲染。
- 支持 48 kHz 全频带采样和 3D 高保真音效处理及渲染。

**多平台适配**

支持 iOS、Android、macOS、Windows、Web、Unity、Flutter、React Native、Electron、Unreal 等平台。

**超低延时、低功耗、低成本**

空间音频算法采用先进的前端处理模式，并通过云服务同步空间坐标，端云协同处理模式能够有效降低整体延时和功耗。

相比传统的左右声道立体声，声网提供的空间音频技术在声音的立体感和空间感上都有明显的提升，两者区别如下所示：

| 对比项   | 传统立体声                                   | 声网空间音频                                        |
| -------- | -------------------------------------------- | --------------------------------------------------- |
| 立体感   | 左右两个维度                           | 以世界坐标系的 x、y、z 坐标轴表示右、上、前三个维度 |
| 空间感   | 通过调节左右声道的音量，体现具有空间感的声音 | 使用空间音频算法，通过设置距离、方位、朝向等参数，塑造声音的空间感                  |
| 用户体验 | 平面                                         | 立体、自然、真实                                    |

![跟传统立体声对比](https://web-cdn.agora.io/docs-portal/img/rtc/spatial-audio/comparison.png)

## 适用场景

#### 社交语聊

在语聊房 App 界面中，以九宫格的形式展示所有用户头像，并对每个用户赋予一个坐标和朝向。在互动过程中，你可以感受到周围的用户发出的声音大小和方位跟其所在的位置有关。如果你在屏幕中拖动自己的头像，随着你跟某个用户之间的距离逐渐变远，你会听到该用户的声音也越来越小，超出一定范围后会彻底听不到，符合现实环境中声音的传播特点。

![社交语聊场景](https://web-cdn.agora.io/docs-portal/img/rtc/spatial-audio/chatroom.png)

#### 游戏 & 元宇宙

在游戏和元宇宙这类 3D 场景中，你可以使用空间音频技术实现更多功能，如下表所示：

| 功能 | 描述 |
| --- | --- |
| 声音模糊 | 对指定远端用户或媒体播放器开启声音模糊处理。 例如：在咖啡厅场景中，如果需要制造两个虚拟角色 “说悄悄话” 的效果，可以对他们开启声音模糊处理模式，其他角色会听到被处理过的、模糊的声音。 |
| 范围音频 | <Slot name="spatial-audio-android-html-0-2-1" /> |

## 技术原理

实现用户空间音频和媒体播放器空间音频时的原理有所不同：

- 用户空间音频：自行部署服务器，用于发送本地空间位置以及接收远端用户的空间位置，然后由 SDK 计算用户间的相对位置，从而计算出相应的空间音频参数。
- 媒体播放器空间音频：通过 SDK 计算本地用户和媒体播放器的相对位置，然后计算出相应的空间音频参数。

## 实现空间音频

本节介绍如何使用 SDK 实现空间音频，API 调用时序如下图所示。

![实现流程](https://web-cdn.agora.io/docs-portal/img/rtc/spatial-audio/spatial-audio-process.svg)

### 初始化空间音频引擎

调用 `ILocalSpatialAudioEngine` 类中的 `create` 和 `initialize` 初始化 `ILocalSpatialAudioEngine` 对象，开启空间音频。

```java
localSpatial = ILocalSpatialAudioEngine.create();
LocalSpatialAudioConfig localSpatialAudioConfig = new LocalSpatialAudioConfig();
localSpatialAudioConfig.mRtcEngine = engine;
localSpatial.initialize(localSpatialAudioConfig);
```

### 设置音频属性和场景

1. 调用 `setAudioProfile`，将 `profile` 设置为你预期的音频编码属性。
1. 调用 `setAudioScenario`，将 `scenario` 设置为 `AUDIO_SCENARIO_GAME_STREAMING`，以获得预期的音质效果。

```java
 engine.setAudioProfile(io.agora.rtc2.Constants.AUDIO_PROFILE_MUSIC_STANDARD);
 engine.setAudioScenario(io.agora.rtc2.Constants.AUDIO_SCENARIO_GAME_STREAMING);
 ```

### 设置音频接收范围

- 调用 `setMaxAudioRecvCount` 设置音频接收范围内最多可接收的音频流数，建议 `maxCount` 取值 ≤ 16。
- 调用 `setAudioRecvRange` 设置可接收音频的最大范围，单位为米，建议 `range` 取值 ＞ 0。

```java
localSpatial.setMaxAudioRecvCount(2);
localSpatial.setAudioRecvRange(AXIS_MAX_DISTANCE);
```

### 更新空间位置

- 在用户空间音频场景下，调用 `updateSelfPosition` 和 `updateRemotePosition` 方法，分别更新本地用户和远端用户的位置。
- 在媒体播放器空间音频场景下，调用 `updateSelfPosition` 和 `updatePlayerPositionInfo` 方法，分别更新本地用户和媒体播放器的位置。

推荐的调用时机如下所示：

- 当频道内有新用户加入。
- 当本地、远端用户或媒体播放器的相对位置发生改变。
- 根据实际需求调用。

```java
// 更新本地用户位置
float[] pos = getVoicePosition(localIv);
float[] forward = new float[]{1.0F, 0.0F, 0.0F};
float[] right = new float[]{0.0F, 1.0F, 0.0F};
float[] up = new float[]{0.0F, 0.0F, 1.0F};
localSpatial.updateSelfPosition(pos, forward, right, up);

// 更新远端用户位置
if (remoteLeftTv.getTag() == null) {
    remoteLeftTv.setTag(uid);
    remoteLeftTv.setVisibility(View.VISIBLE);
    remoteLeftTv.setText(uid + "");
    RemoteVoicePositionInfo info = getVoicePositionInfo(remoteLeftTv);
    Log.d(TAG, "left remote user >> pos=" + Arrays.toString(info.position));
    localSpatial.updateRemotePosition(uid, info);
    remoteLeftTv.setOnClickListener(v -> showRemoteUserSettingDialog(uid));
} else if (remoteRightTv.getTag() == null) {
    remoteRightTv.setTag(uid);
    remoteRightTv.setVisibility(View.VISIBLE);
    remoteRightTv.setText(uid + "");
    localSpatial.updateRemotePosition(uid, getVoicePositionInfo(remoteRightTv));
    remoteRightTv.setOnClickListener(v -> showRemoteUserSettingDialog(uid));
            }
```

### 设置空间音频参数

调用 `setRemoteUserSpatialAudioParams` 或 `setSpatialAudioParams`，针对远端用户或媒体播放器设置空间音频参数。如果要实现特定音效，可参考如下参数设置：

- 空气衰减效果：将 `enable_air_absorb` 设置为 `true`；并将 `speaker_attenuation` 设置为预期的声音衰减系数。
- 声音模糊效果：将 `enable_blur` 设置为 `true`。

```java
// 开启空气衰减效果
spatialAudioParams.enable_air_absorb = true;

// 开启声音模糊效果
spatialAudioParams.enable_blur = true;

// 以设置媒体播放器空间音频参数为例
engine.setRemoteUserSpatialAudioParams(uid, spatialAudioParams);
```

### （可选）设置隔声区域

1. 调用 `setZones` 设置一个隔声区域和声音衰减系数。当音源（可以为用户或媒体播放器）跟接收方分属于隔声区域内部和外部时，会体验到类似真实环境中声音在遇到建筑隔断时的衰减效果。
1. （可选）调用 `setRemoteAudioAttenuation` 或 `setPlayerAttenuation` 分别针对用户和媒体播放器设置声音衰减属性，并指定是否使用该设置强制覆盖 `setZones` 中的声音衰减系数。

```java
SpatialAudioZone mediaPlayerLeftZone = new SpatialAudioZone();
// 隔声区域的 ID
mediaPlayerLeftZone.zoneSetId = 1;
// 隔声区域和外部互通时的声音衰减系数
mediaPlayerLeftZone.audioAttenuation = 1f;
float[] voicePosition = getVoicePosition(zoneTv);
float[] viewRelativeSizeInAxis = getViewRelativeSizeInAxis(zoneTv);
// 隔声区域的空间中心点
mediaPlayerLeftZone.position = new float[]{voicePosition[0], voicePosition[1], 0};
// 以 position 为起点，向前的单位向量
mediaPlayerLeftZone.forward = new float[]{1.f, 0, 0};
// 以 position 为起点，向右的单位向量
mediaPlayerLeftZone.right = new float[]{0, 1.f, 0};
// 以 position 为起点，向上的单位向量
mediaPlayerLeftZone.up = new float[]{0, 0, 1.f};
// 隔声区域的前向长度
mediaPlayerLeftZone.forwardLength = viewRelativeSizeInAxis[1];
// 隔声区域的右向长度
mediaPlayerLeftZone.rightLength = viewRelativeSizeInAxis[0];
// 隔声区域的上向长度
mediaPlayerLeftZone.upLength = AXIS_MAX_DISTANCE;
localSpatial.setZones(new SpatialAudioZone[]{mediaPlayerLeftZone});

localSpatial.setRemoteAudioAttenuation(uid, 0.5f, false);
localSpatial.setPlayerAttenuation(mediaPlayer.getMediaPlayerId(), 0.5f, false);
```

### （可选）设置耳机均衡效果

1. 调用 `setHeadphoneEQPreset` 方法，选择预设的耳机均衡器收听音频，以达到预期的音频体验。
1. （可选）如果执行上一步后仍未达到预期，你可以调用 `setHeadphoneEQParameters` 自行调节耳机均衡效果，执行该方法后，`setHeadphoneEQPreset` 方法设置的预设值会被覆盖。

```java
engine.setHeadphoneEQPreset(io.agora.rtc2.Constants.HEADPHONE_EQUALIZER_OVEREAR);
engine.setHeadphoneEQParameters(10, 10);
```

### 关闭空间音频

在互动过程中，你可选择暂停或关闭空间音频。

#### 暂停指定远端用户在本地的空间音频

1. 如果不想继续体验远端用户在本地的空间音频、或远端用户已退出频道，调用 `removeRemotePosition` 删除该用户的空间位置信息，以节省计算资源。

    :::warning[注意]
    当远端用户离开频道时，必须调用 `removeRemotePosition` 删除该用户的空间位置信息，否则可能导致本地听不到来自其他远端用户的空间音频。
    :::

1. （可选）如果之后想恢复该用户在本地的空间音频，可调用 `updateRemotePosition` 方法重新设置远端用户的位置信息。

```java
// 暂停指定远端用户在本地的空间音频
localSpatial.removeRemotePosition(uid)
// 恢复指定远端用户在本地的空间音频
localSpatial.updateRemotePosition(uid, getVoicePositionInfo(remoteLeftTv));
```

#### 暂停所有远端用户在本地的空间音频

1. 如果你不想再继续体验本地的空间音频，可以调用 `clearRemotePositions` 删除所有远端用户的空间位置信息。
    :::warning[注意]
    调用该方法会导致本地听不到所有远端用户的音频，声网建议你谨慎调用该方法。
    :::
1. （可选）如果之后还需要听到远端用户的音频，你需要重新调用 `ILocalSpatialAudioEngine` 中的 `muteAllRemoteAudioStreams(false)` 恢复订阅远端用户的音频流。

    ```java
    // 删除所有远端用户的空间位置信息
    localSpatial.clearRemotePositions();
    // 恢复订阅远端用户的音频流
    localSpatial.muteAllRemoteAudioStreams(false);
    ```

#### 暂停本地用户在远端的空间音频

1. 调用 `ILocalSpatialAudioEngine` 中的 `muteLocalAudioStream(true)`，取消发布本地音频流。
1. （可选）如果之后想再次开启空间音频，可再次调用该方法并将参数设置为 `false`，即可恢复空间音频。

    ```java
    // 取消发布本地音频流
    localSpatial.muteLocalAudioStream(true);
    // 恢复发布本地音频流
    localSpatial.muteLocalAudioStream(false);
    ```

#### 关闭空间音频

1. 在频道内调用 `RtcEngine` 中的 `enableSpatialAudio` 并将参数设置为 `false`，此时所有跟空间音频相关的设置都会被重置。
1. （可选）如果之后想再次开启空间音频，可再次调用该方法并将参数设置为 `true`，然后重新调用相关 API 设置空间音频效果。
1. （可选）调用 `ILocalSpatialAudioEngine` 中的 `destroy` 销毁 `ILocalSpatialAudioEngine` 对象。

    ```java
    // 关闭空间音频
    engine.enableSpatialAudio(false);
    // 销毁 ILocalSpatialAudioEngine 对象
    localSpatial.destroy();
    ```

**多平台适配**

支持 iOS、Android、macOS、Windows、Web、Unity、Flutter、React Native、Electron、Unreal 等平台。

**超低延时、低功耗、低成本**

空间音频算法采用先进的前端处理模式，并通过云服务同步空间坐标，端云协同处理模式能够有效降低整体延时和功耗。

相比传统的左右声道立体声，声网提供的空间音频技术在声音的立体感和空间感上都有明显的提升，两者区别如下所示：

| 对比项   | 传统立体声                                   | 声网空间音频                                        |

| 空间感   | 通过调节左右声道的音量，体现具有空间感的声音 | 使用空间音频算法，通过设置距离、方位、朝向等参数，塑造声音的空间感                  |
| 用户体验 | 平面                                         | 立体、自然、真实                                    |

## 技术原理

实现用户空间音频和媒体播放器空间音频时的原理有所不同：

- 用户空间音频：自行部署服务器，用于发送本地空间位置以及接收远端用户的空间位置，然后由 SDK 计算用户间的相对位置，从而计算出相应的空间音频参数。
- 媒体播放器空间音频：通过 SDK 计算本地用户和媒体播放器的相对位置，然后计算出相应的空间音频参数。

## 实现空间音频

本节介绍如何使用 SDK 实现空间音频，API 调用时序如下图所示。

![实现流程](https://web-cdn.agora.io/docs-portal/img/rtc/spatial-audio/spatial-audio-process.svg)

### 初始化空间音频引擎

调用 `AgoraLocalSpatialAudioKit` 类中 `sharedLocalSpatialAudioWithConfig` 初始化 `AgoraLocalSpatialAudioKit` 对象，开启空间音频。

```swift
agoraKit = AgoraRtcEngineKit.sharedEngine(withAppId: KeyCenter.AppId, delegate: self)
let localSpatialConfig = AgoraLocalSpatialAudioConfig()
localSpatialConfig.rtcEngine = agoraKit
localSpatial = AgoraLocalSpatialAudioKit.sharedLocalSpatialAudio(with: localSpatialConfig)
```

### 设置音频属性和场景

1. 调用 `setAudioProfile`，将 `profile` 设置为你预期的音频编码属性。
2. 调用 `setAudioScenario`，将 `scenario` 设置为 `AgoraAudioScenarioGameStreaming`，以获得预期的音质效果。

```swift
agoraKit.setAudioProfile(.musicStandard)
agoraKit.setAudioScenario(.gameStreaming)
```

### 设置音频接收范围

- 调用 `setMaxAudioRecvCount` 设置音频接收范围内最多可接收的音频流数，建议 `maxCount` 取值 ≤ 16。
- 调用 `setAudioRecvRange` 设置可接收音频的最大范围，单位为米，建议 `range` 取值 ＞ 0。

```swift
localSpatial.setMaxAudioRecvCount(2)
localSpatial.setAudioRecvRange(Float(SCREENSIZE.height))
```

### 更新空间位置

- 在用户空间音频场景下，调用 `updateSelfPosition` 和 `updateRemotePosition` 方法，分别更新本地用户和远端用户的位置。
- 在媒体播放器空间音频场景下，调用 `updateSelfPosition` 和 `updatePlayerPositionInfo` 方法，分别更新本地用户和媒体播放器的位置。

推荐的调用时机如下所示：

- 当频道内有新用户加入。
- 当本地、远端用户或媒体播放器的相对位置发生改变。
- 根据实际需求调用。

```swift
// 更新本地用户位置
let pos = getViewCenterPostion(view: selfPostionView)
localSpatial.updateSelfPosition(pos, axisForward: forward, axisRight: right, axisUp: up)

// 更新远端用户位置
if remoteUserButton1.tag <= 0 {
    remoteUserButton1.setTitle("\(uid)", for: .normal)
    remoteUserButton1.tag = Int(uid)
    remoteUserButton1.isHidden = false
    localSpatial.updateRemotePosition(uid, positionInfo: getPlayerPostion(view: remoteUserButton1))
} else if remoteUserButton2.tag <= 0 {
    remoteUserButton2.setTitle("\(uid)", for: .normal)
    remoteUserButton2.tag = Int(uid)
    remoteUserButton2.isHidden = false
    localSpatial.updateRemotePosition(uid, positionInfo: getPlayerPostion(view: remoteUserButton2))
}
```

### 设置空间音频参数

调用 `setRemoteUserSpatialAudioParams` 或 `setSpatialAudioParams`，针对远端用户或媒体播放器设置空间音频参数。如果要实现特定音效，可参考如下参数设置：

- 空气衰减效果：将 `enable_air_absorb` 设置为 `true`；并将 `speaker_attenuation` 设置为预期的声音衰减系数。
- 声音模糊效果：将 `enable_blur` 设置为 `true`。

```swift
// 开启空气衰减效果
let params = AgoraSpatialAudioParams()
params.enable_air_absorb = true

// 开启声音模糊效果
params.enable_blur = true

// 以设置媒体播放器空间音频参数为例
mediaPlayer.setSpatialAudioParams(params)
```

### （可选）设置隔声区域

1. 调用 `setZones` 设置一个隔声区域和声音衰减系数。当音源（可以为用户或媒体播放器）跟接收方分属于隔声区域内部和外部时，会体验到类似真实环境中声音在遇到建筑隔断时的衰减效果。
2. （可选）调用 `setRemoteAudioAttenuation` 或 `setPlayerAttenuation` 分别针对用户和媒体播放器设置声音衰减属性，并指定是否使用该设置强制覆盖 `setZones` 中的声音衰减系数。

```swift
let audioZone = AgoraSpatialAudioZone()
// 隔声区域的 ID
audioZone.zoneSetId = 1
// 隔声区域和外部互通时的声音衰减系数
audioZone.audioAttenuation = 1
// 以 position 为起点，向前的单位向量
audioZone.forward = forward
// 以 position 为起点，向右的单位向量
audioZone.right = right
// 以 position 为起点，向上的单位向量
audioZone.up = up
// 隔声区域的空间中心点
audioZone.position = getViewCenterPostion(view: voiceContainerView1)
// 隔声区域的前向长度
audioZone.forwardLength = Float(voiceContainerView1.frame.width)
// 隔声区域的右向长度
audioZone.rightLength = Float(voiceContainerView1.frame.height)
// 隔声区域的上向长度
audioZone.upLength = Float(maxDistance)
localSpatial.setZones([audioZone])

localSpatial.setRemoteAudioAttenuation(uid, attenuation: 0.5, forceSet: false)
localSpatial.setPlayerAttenuation(0.5, playerId: UInt(mediaPlayer.getMediaPlayerId()), forceSet: false)
```

### （可选）设置耳机均衡效果

1. 调用 `setHeadphoneEQPreset` 方法，选择预设的耳机均衡器收听音频，以达到预期的音频体验。
2. （可选）如果执行上一步后仍未达到预期，你可以调用 `setHeadphoneEQParameters` 自行调节耳机均衡效果，执行该方法后，`setHeadphoneEQPreset` 方法设置的预设值会被覆盖。

```swift
agoraKit.setHeadphoneEQPreset(.overEar)
agoraKit.setHeadphoneEQParameters(10, gain: 10)
```

### 关闭空间音频

在互动过程中，你可选择暂停或关闭空间音频。

##### 暂停指定远端用户在本地的空间音频

1. 如果不想继续体验远端用户在本地的空间音频、或远端用户已退出频道，调用 `removeRemotePosition` 删除该用户的空间位置信息，以节省计算资源。

    :::warning[注意]
    当远端用户离开频道时，必须调用 `removeRemotePosition` 删除该用户的空间位置信息，否则可能导致本地听不到来自其他远端用户的空间音频。
    :::

2. （可选）如果之后想恢复该用户在本地的空间音频，可调用 `updateRemotePosition` 方法重新设置远端用户的位置信息。

```swift
// 暂停指定远端用户在本地的空间音频
localSpatial.removeRemotePosition(uid)

// 恢复指定远端用户在本地的空间音频
localSpatial.updateRemotePosition(uid, positionInfo: getPlayerPostion(view: remoteLeftTv))
```

#### 暂停所有远端用户在本地的空间音频

1. 如果你不想再继续体验本地的空间音频，可以调用 `clearRemotePositions` 删除所有远端用户的空间位置信息。

    :::warning[注意]
    调用该方法会导致本地听不到所有远端用户的音频，声网建议你谨慎调用该方法。
    :::

2. （可选）如果之后还需要听到远端用户的音频，你需要重新调用 `AgoraLocalSpatialAudioKit` 中的 `muteAllRemoteAudioStreams(false)` 恢复订阅远端用户的音频流。

```swift
// 删除所有远端用户的空间位置信息
localSpatial.clearRemotePositions()

// 恢复订阅远端用户的音频流
localSpatial.muteAllRemoteAudioStreams(false)
```

#### 暂停本地用户在远端的空间音频

1. 调用 `AgoraLocalSpatialAudioKit` 中的 `muteLocalAudioStream(true)`，取消发布本地音频流。
2. （可选）如果之后想再次开启空间音频，可再次调用该方法并将参数设置为 `false`，即可恢复空间音频。

```swift
// 取消发布本地音频流
localSpatial.muteLocalAudioStream(true)
// 恢复发布本地音频流
localSpatial.muteLocalAudioStream(false)
```

#### 关闭空间音频

1. 在频道内调用 `AgoraRtcEngineKit` 中的 `enableSpatialAudio` 并将参数设置为 `false`，此时所有跟空间音频相关的设置都会被重置。
2. （可选）如果之后想再次开启空间音频，可再次调用该方法并将参数设置为 `true`，然后重新调用相关 API 设置空间音频效果。
3. （可选）调用 `AgoraLocalSpatialAudioKit` 中的 `destroy` 销毁 `AgoraLocalSpatialAudioKit` 对象。

```swift
// 关闭空间音频
agoraKit.enableSpatialAudio(false)
// 销毁 AgoraLocalSpatialAudioKit 对象
AgoraLocalSpatialAudioKit.destroy()
```

## 技术原理

实现用户空间音频和媒体播放器空间音频时的原理有所不同：

- 用户空间音频：自行部署服务器，用于发送本地空间位置以及接收远端用户的空间位置，然后由 SDK 计算用户间的相对位置，从而计算出相应的空间音频参数。
- 媒体播放器空间音频：通过 SDK 计算本地用户和媒体播放器的相对位置，然后计算出相应的空间音频参数。

## 实现空间音频

本节介绍如何使用 SDK 实现空间音频，API 调用时序如下图所示。

![实现流程](https://web-cdn.agora.io/docs-portal/img/rtc/spatial-audio/spatial-audio-process.svg)

### 初始化空间音频引擎

调用 `AgoraLocalSpatialAudioKit` 类中 `sharedLocalSpatialAudioWithConfig` 初始化 `AgoraLocalSpatialAudioKit` 对象，开启空间音频。

```swift
agoraKit = AgoraRtcEngineKit.sharedEngine(withAppId: KeyCenter.AppId, delegate: self)
let localSpatialConfig = AgoraLocalSpatialAudioConfig()
localSpatialConfig.rtcEngine = agoraKit
localSpatial = AgoraLocalSpatialAudioKit.sharedLocalSpatialAudio(with: localSpatialConfig)
```

### 设置音频属性和场景

1. 调用 `setAudioProfile`，将 `profile` 设置为你预期的音频编码属性。
2. 调用 `setAudioScenario`，将 `scenario` 设置为 `AgoraAudioScenarioGameStreaming`，以获得预期的音质效果。

```swift
agoraKit.setAudioProfile(.musicStandard)
agoraKit.setAudioScenario(.gameStreaming)
```

### 设置音频接收范围

- 调用 `setMaxAudioRecvCount` 设置音频接收范围内最多可接收的音频流数，建议 `maxCount` 取值 ≤ 16。
- 调用 `setAudioRecvRange` 设置可接收音频的最大范围，单位为米，建议 `range` 取值 ＞ 0。

```swift
localSpatial.setMaxAudioRecvCount(2)
localSpatial.setAudioRecvRange(Float(SCREENSIZE.height))
```

### 更新空间位置

- 在用户空间音频场景下，调用 `updateSelfPosition` 和 `updateRemotePosition` 方法，分别更新本地用户和远端用户的位置。
- 在媒体播放器空间音频场景下，调用 `updateSelfPosition` 和 `updatePlayerPositionInfo` 方法，分别更新本地用户和媒体播放器的位置。

推荐的调用时机如下所示：

- 当频道内有新用户加入。
- 当本地、远端用户或媒体播放器的相对位置发生改变。
- 根据实际需求调用。

```swift
// 更新本地用户位置
let pos = getViewCenterPostion(view: selfPostionView)
localSpatial.updateSelfPosition(pos, axisForward: forward, axisRight: right, axisUp: up)

// 更新远端用户位置
if remoteUserButton1.tag <= 0 {
    remoteUserButton1.setTitle("\(uid)", for: .normal)
    remoteUserButton1.tag = Int(uid)
    remoteUserButton1.isHidden = false
    localSpatial.updateRemotePosition(uid, positionInfo: getPlayerPostion(view: remoteUserButton1))
} else if remoteUserButton2.tag <= 0 {
    remoteUserButton2.setTitle("\(uid)", for: .normal)
    remoteUserButton2.tag = Int(uid)
    remoteUserButton2.isHidden = false
    localSpatial.updateRemotePosition(uid, positionInfo: getPlayerPostion(view: remoteUserButton2))
}
```

### 设置空间音频参数

调用 `setRemoteUserSpatialAudioParams` 或 `setSpatialAudioParams`，针对远端用户或媒体播放器设置空间音频参数。如果要实现特定音效，可参考如下参数设置：

- 空气衰减效果：将 `enable_air_absorb` 设置为 `true`；并将 `speaker_attenuation` 设置为预期的声音衰减系数。
- 声音模糊效果：将 `enable_blur` 设置为 `true`。

```swift
// 开启空气衰减效果
let params = AgoraSpatialAudioParams()
params.enable_air_absorb = true

// 开启声音模糊效果
params.enable_blur = true

// 以设置媒体播放器空间音频参数为例
mediaPlayer.setSpatialAudioParams(params)
```

### （可选）设置隔声区域

1. 调用 `setZones` 设置一个隔声区域和声音衰减系数。当音源（可以为用户或媒体播放器）跟接收方分属于隔声区域内部和外部时，会体验到类似真实环境中声音在遇到建筑隔断时的衰减效果。
2. （可选）调用 `setRemoteAudioAttenuation` 或 `setPlayerAttenuation` 分别针对用户和媒体播放器设置声音衰减属性，并指定是否使用该设置强制覆盖 `setZones` 中的声音衰减系数。

```swift
let audioZone = AgoraSpatialAudioZone()
// 隔声区域的 ID
audioZone.zoneSetId = 1
// 隔声区域和外部互通时的声音衰减系数
audioZone.audioAttenuation = 1
// 以 position 为起点，向前的单位向量
audioZone.forward = forward
// 以 position 为起点，向右的单位向量
audioZone.right = right
// 以 position 为起点，向上的单位向量
audioZone.up = up
// 隔声区域的空间中心点
audioZone.position = getViewCenterPostion(view: voiceContainerView1)
// 隔声区域的前向长度
audioZone.forwardLength = Float(voiceContainerView1.frame.width)
// 隔声区域的右向长度
audioZone.rightLength = Float(voiceContainerView1.frame.height)
// 隔声区域的上向长度
audioZone.upLength = Float(maxDistance)
localSpatial.setZones([audioZone])

localSpatial.setRemoteAudioAttenuation(uid, attenuation: 0.5, forceSet: false)
localSpatial.setPlayerAttenuation(0.5, playerId: UInt(mediaPlayer.getMediaPlayerId()), forceSet: false)
```

### （可选）设置耳机均衡效果

1. 调用 `setHeadphoneEQPreset` 方法，选择预设的耳机均衡器收听音频，以达到预期的音频体验。
2. （可选）如果执行上一步后仍未达到预期，你可以调用 `setHeadphoneEQParameters` 自行调节耳机均衡效果，执行该方法后，`setHeadphoneEQPreset` 方法设置的预设值会被覆盖。

```swift
agoraKit.setHeadphoneEQPreset(.overEar)
agoraKit.setHeadphoneEQParameters(10, gain: 10)
```

### 关闭空间音频

在互动过程中，你可选择暂停或关闭空间音频。

##### 暂停指定远端用户在本地的空间音频

1. 如果不想继续体验远端用户在本地的空间音频、或远端用户已退出频道，调用 `removeRemotePosition` 删除该用户的空间位置信息，以节省计算资源。

    :::warning[注意]
    当远端用户离开频道时，必须调用 `removeRemotePosition` 删除该用户的空间位置信息，否则可能导致本地听不到来自其他远端用户的空间音频。
    :::

2. （可选）如果之后想恢复该用户在本地的空间音频，可调用 `updateRemotePosition` 方法重新设置远端用户的位置信息。

```swift
// 暂停指定远端用户在本地的空间音频
localSpatial.removeRemotePosition(uid)

// 恢复指定远端用户在本地的空间音频
localSpatial.updateRemotePosition(uid, positionInfo: getPlayerPostion(view: remoteLeftTv))
```

#### 暂停所有远端用户在本地的空间音频

1. 如果你不想再继续体验本地的空间音频，可以调用 `clearRemotePositions` 删除所有远端用户的空间位置信息。

    :::warning[注意]
    调用该方法会导致本地听不到所有远端用户的音频，声网建议你谨慎调用该方法。
    :::

2. （可选）如果之后还需要听到远端用户的音频，你需要重新调用 `AgoraLocalSpatialAudioKit` 中的 `muteAllRemoteAudioStreams(false)` 恢复订阅远端用户的音频流。

```swift
// 删除所有远端用户的空间位置信息
localSpatial.clearRemotePositions()

// 恢复订阅远端用户的音频流
localSpatial.muteAllRemoteAudioStreams(false)
```

#### 暂停本地用户在远端的空间音频

1. 调用 `AgoraLocalSpatialAudioKit` 中的 `muteLocalAudioStream(true)`，取消发布本地音频流。
2. （可选）如果之后想再次开启空间音频，可再次调用该方法并将参数设置为 `false`，即可恢复空间音频。

```swift
// 取消发布本地音频流
localSpatial.muteLocalAudioStream(true)
// 恢复发布本地音频流
localSpatial.muteLocalAudioStream(false)
```

#### 关闭空间音频

1. 在频道内调用 `AgoraRtcEngineKit` 中的 `enableSpatialAudio` 并将参数设置为 `false`，此时所有跟空间音频相关的设置都会被重置。
2. （可选）如果之后想再次开启空间音频，可再次调用该方法并将参数设置为 `true`，然后重新调用相关 API 设置空间音频效果。
3. （可选）调用 `AgoraLocalSpatialAudioKit` 中的 `destroy` 销毁 `AgoraLocalSpatialAudioKit` 对象。

```swift
// 关闭空间音频
agoraKit.enableSpatialAudio(false)
// 销毁 AgoraLocalSpatialAudioKit 对象
AgoraLocalSpatialAudioKit.destroy()
```

## 技术原理

实现用户空间音频和媒体播放器空间音频时的原理有所不同：

- 用户空间音频：自行部署服务器，用于发送本地空间位置以及接收远端用户的空间位置，然后由 SDK 计算用户间的相对位置，从而计算出相应的空间音频参数。
- 媒体播放器空间音频：通过 SDK 计算本地用户和媒体播放器的相对位置，然后计算出相应的空间音频参数。

## 实现空间音频

本节介绍如何使用 SDK 实现空间音频，API 调用时序如下图所示。

![实现流程](https://web-cdn.agora.io/docs-portal/img/rtc/spatial-audio/spatial-audio-process.svg)

### 初始化空间音频引擎

调用 `ILocalSpatialAudioEngine` 类中的 `initialize` 初始化 `ILocalSpatialAudioEngine` 对象，开启空间音频。

```cpp
m_localSpatial = nullptr;

m_rtcEngine->queryInterface(AGORA_IID_LOCAL_SPATIAL_AUDIO, (void**)&m_localSpatial);
LocalSpatialAudioConfig config;
config.rtcEngine = m_rtcEngine;
m_localSpatial->initialize(config);
```

### 设置音频属性和场景

1. 调用 `setAudioProfile`，将 `profile` 设置为你预期的音频编码属性。
2. 调用 `setAudioScenario`，将 `scenario` 设置为 `AUDIO_SCENARIO_GAME_STREAMING`，以获得预期的音质效果。

```cpp
m_rtcEngine->setAudioProfile(AUDIO_PROFILE_MUSIC_STANDARD);
m_rtcEngine->setAudioScenario(AUDIO_SCENARIO_GAME_STREAMING);
```

### 设置音频接收范围

- 调用 `setMaxAudioRecvCount` 设置音频接收范围内最多可接收的音频流数，建议 `maxCount` 取值 ≤ 16。
- 调用 `setAudioRecvRange` 设置可接收音频的最大范围，单位为米，建议 `range` 取值 ＞ 0。

```cpp
m_localSpatial->setMaxAudioRecvCount(2);
m_localSpatial->setAudioRecvRange(AXIS_MAX_DISTANCE);
```

### 更新空间位置

- 在用户空间音频场景下，调用 `updateSelfPosition` 和 `updateRemotePosition` 方法，分别更新本地用户和远端用户的位置。
- 在媒体播放器空间音频场景下，调用 `updateSelfPosition` 和 `updatePlayerPositionInfo` 方法，分别更新本地用户和媒体播放器的位置。

推荐的调用时机如下所示：

- 当频道内有新用户加入。
- 当本地、远端用户或媒体播放器的相对位置发生改变。
- 根据实际需求调用。

```cpp
// 更新本地用户位置
float pos[3] = { 0 };
CaculateObjectPosition(m_staLocalMove, pos);
float forward[3] = { 1.0f, 0, 0 };
float right[3] = { 0, 1.0f, 0 };
float up[3] = { 0, 0, 1.0f };
m_localSpatial->updateSelfPosition(pos, forward, right, up);

// 更新远端用户位置
if (remoteLeftUid == 0) {
    remoteLeftUid = wParam;

    m_staRemoteLeft.ShowWindow(TRUE);

    RemoteVoicePositionInfo posInfo;
    memset(&posInfo, 0, sizeof(RemoteVoicePositionInfo));
    CaculateObjectPosition(m_staRemoteLeft, posInfo.position);
    m_localSpatial->updateRemotePosition(remoteLeftUid, posInfo);
} else if (remoteRightUid == 0) {
    remoteRightUid = wParam;

    m_staRemoteRight.ShowWindow(TRUE);

    RemoteVoicePositionInfo posInfo;
    memset(&posInfo, 0, sizeof(RemoteVoicePositionInfo));
    CaculateObjectPosition(m_staRemoteRight, posInfo.position);
    m_localSpatial->updateRemotePosition(remoteRightUid, posInfo);
}
```

### 设置空间音频参数

调用 `setRemoteUserSpatialAudioParams` 或 `setSpatialAudioParams`，针对远端用户或媒体播放器设置空间音频参数。如果要实现特定音效，可参考如下参数设置：

- 空气衰减效果：将 `enable_air_absorb` 设置为 `true`；并将 `speaker_attenuation` 设置为预期的声音衰减系数。
- 声音模糊效果：将 `enable_blur` 设置为 `true`。

```cpp
// 设置空气衰减效果
spatialAudioParams.enable_air_absorb = true;

// 设置声音模糊效果
spatialAudioParams.enable_blur = true;

// 以设置媒体播放器空间音频参数为例
m_mediaPlayerLeft->setSpatialAudioParams(spatialAudioParams);
```

### （可选）设置隔声区域

1. 调用 `setZones` 设置一个隔声区域和声音衰减系数。当音源（可以为用户或媒体播放器）跟接收方分属于隔声区域内部和外部时，会体验到类似真实环境中声音在遇到建筑隔断时的衰减效果。
2. （可选）调用 `setRemoteAudioAttenuation` 或 `setPlayerAttenuation` 分别针对用户和媒体播放器设置声音衰减属性，并指定是否使用该设置强制覆盖 `setZones` 中的声音衰减系数。

```cpp
SpatialAudioZone mediaPlayerLeftZone;
memset(&mediaPlayerLeftZone, 0, sizeof(SpatialAudioZone));
// 隔声区域和外部互通时的声音衰减系数
mediaPlayerLeftZone.audioAttenuation = 1.0f;

// 隔声区域的空间中心点
CaculateObjectPosition(m_staZone, mediaPlayerLeftZone.position);

// 以 position 为起点，向前的单位向量
mediaPlayerLeftZone.forward[0] = 1.0f;
// 以 position 为起点，向右的单位向量
mediaPlayerLeftZone.right[1] = 1.0f;
// 以 position 为起点，向上的单位向量
mediaPlayerLeftZone.up[2] = 1.0f;

RECT zoneSize;
CaculateZoneRect(m_staZone, &zoneSize);
// 隔声区域的前向长度
mediaPlayerLeftZone.forwardLength = zoneSize.bottom - zoneSize.top * 1.0f;
// 隔声区域的右向长度
mediaPlayerLeftZone.rightLength = zoneSize.right - zoneSize.left * 1.0f;
// 隔声区域的上向长度
mediaPlayerLeftZone.upLength = AXIS_MAX_DISTANCE;

m_localSpatial->setZones(&mediaPlayerLeftZone, 1);

m_localSpatial->setRemoteAudioAttenuation(uid, 0.5f, false);
m_localSpatial->setPlayerAttenuation(mediaPlayer.getMediaPlayerId(), 0.5f, false);
```

### （可选）设置耳机均衡效果

1. 调用 `setHeadphoneEQPreset` 方法，选择预设的耳机均衡器收听音频，以达到预期的音频体验。
2. （可选）如果执行上一步后仍未达到预期，你可以调用 `setHeadphoneEQParameters` 自行调节耳机均衡效果，执行该方法后，`setHeadphoneEQPreset` 方法设置的预设值会被覆盖。

```cpp
m_rtcEngine->setHeadphoneEQPreset(HEADPHONE_EQUALIZER_OVEREAR);
m_rtcEngine->setHeadphoneEQParameters(10, 10);
```

### 关闭空间音频

在互动过程中，你可选择暂停或关闭空间音频。

#### 暂停指定远端用户在本地的空间音频

1. 如果不想继续体验远端用户在本地的空间音频、或远端用户已退出频道，调用 `removeRemotePosition` 删除该用户的空间位置信息，以节省计算资源。

    :::warning[注意]
    当远端用户离开频道时，必须调用 `removeRemotePosition` 删除该用户的空间位置信息，否则可能导致本地听不到来自其他远端用户的空间音频。
    :::

2. （可选）如果之后想恢复该用户在本地的空间音频，可调用 `updateRemotePosition` 方法重新设置远端用户的位置信息。

```cpp
// 暂停指定远端用户在本地的空间音频
m_localSpatial->removeRemotePosition(uid)
// 恢复指定远端用户在本地的空间音频
m_localSpatial->updateRemotePosition(uid, getVoicePositionInfo(remoteLeftTv));
```

#### 暂停所有远端用户在本地的空间音频

1. 如果你不想再继续体验本地的空间音频，可以调用 `clearRemotePositions` 删除所有远端用户的空间位置信息。

    :::warning[注意]
    调用该方法会导致本地听不到所有远端用户的音频，声网建议你谨慎调用该方法。
    :::

2. （可选）如果之后还需要听到远端用户的音频，你需要重新调用 `ILocalSpatialAudioEngine` 中的 `muteAllRemoteAudioStreams(false)` 恢复订阅远端用户的音频流。

```cpp
// 删除所有远端用户的空间位置信息
m_localSpatial->clearRemotePositions();
// 恢复订阅远端用户的音频流
m_localSpatial->muteAllRemoteAudioStreams(false);
```

#### 暂停本地用户在远端的空间音频

1. 调用 `ILocalSpatialAudioEngine` 中的 `muteLocalAudioStream(true)`，取消发布本地音频流。
2. （可选）如果之后想再次开启空间音频，可再次调用该方法并将参数设置为 `false`，即可恢复空间音频。

```cpp
// 取消发布本地音频流
m_localSpatial->muteLocalAudioStream(true);
// 恢复发布本地音频流
m_localSpatial->muteLocalAudioStream(false);
```

#### 关闭空间音频

1. 在频道内调用 `IRtcEngine` 中的 `enableSpatialAudio` 并将参数设置为 `false`，此时所有跟空间音频相关的设置都会被重置。
2. （可选）如果之后想再次开启空间音频，可再次调用该方法并将参数设置为 `true`，然后重新调用相关 API 设置空间音频效果。
3. （可选）调用 `ILocalSpatialAudioEngine` 中的 `destroy` 销毁 `ILocalSpatialAudioEngine` 对象。

```cpp
// 关闭空间音频
m_rtcEngine->enableSpatialAudio(false);
// 销毁 ILocalSpatialAudioEngine 对象
m_localSpatial->release();
```

## 技术原理

实现用户空间音频和媒体播放器空间音频时的原理有所不同：

- 用户空间音频：自行部署服务器，用于发送本地空间位置以及接收远端用户的空间位置，然后由 SDK 计算用户间的相对位置，从而计算出相应的空间音频参数。
- 媒体播放器空间音频：通过 SDK 计算本地用户和媒体播放器的相对位置，然后计算出相应的空间音频参数。

## 实现空间音频

本节介绍如何使用 SDK 实现空间音频，API 调用时序如下图所示。

![实现流程](https://web-cdn.agora.io/docs-portal/img/rtc/spatial-audio/spatial-audio-process.svg)

### 初始化空间音频引擎

调用 `getLocalSpatialAudioEngine` 和 `initialize` 初始化 `ILocalSpatialAudioEngine` 对象，开启空间音频。

```typescript
rtcEngine = createAgoraRtcEngine();
localSpatial = rtcEngine.getLocalSpatialAudioEngine()
localSpatial.initialize();
```

### 设置音频属性和场景

1. 调用 `setAudioProfile`，将 `profile` 设置为你预期的音频编码属性。
2. 调用 `setAudioScenario`，将 `scenario` 设置为 `AudioScenarioGameStreaming`，以获得预期的音质效果。

```typescript
rtcEngine.setAudioProfile(AudioProfileType.AudioProfileSpeechStandard);
rtcEngine.setAudioScenario(AudioScenarioType.AudioScenarioGameStreaming);
```

### 设置音频接收范围

- 调用 `setMaxAudioRecvCount` 设置音频接收范围内最多可接收的音频流数，建议 `maxCount` 取值 ≤ 16。
- 调用 `setAudioRecvRange` 设置可接收音频的最大范围，单位为米，建议 `range` 取值 ＞ 0。

```typescript
localSpatial.setMaxAudioRecvCount(2);
localSpatial.setAudioRecvRange(50);
```

### 更新空间位置

- 在用户空间音频场景下，调用 `updateSelfPosition` 和 `updateRemotePosition` 方法，分别更新本地用户和远端用户的位置。
- 在媒体播放器空间音频场景下，调用 `updateSelfPosition` 和 `updatePlayerPositionInfo` 方法，分别更新本地用户和媒体播放器的位置。

推荐的调用时机如下所示：

- 当频道内有新用户加入。
- 当本地、远端用户或媒体播放器的相对位置发生改变。
- 根据实际需求调用。

```typescript
// 更新本地用户位置
localSpatial.updateSelfPosition(
    [0, 0, 0],  // position
    [1, 0, 0],  // axisForward
    [0, 1, 0],  // axisRight
    [0, 0, 1]   // axisUp
);

// 更新远端用户位置
localSpatial.updateRemotePosition(
    uid,  // 远端用户 ID
    {
        position: [0, 0, 0],
        axisForward: [1, 0, 0],
    }
);

// 更新媒体播放器位置
localSpatial.updatePlayerPositionInfo(
    mediaPlayer.getMediaPlayerId(),  // 媒体播放器 ID
    {
        position: [0, 0, 0],
        axisForward: [1, 0, 0],
    }
);
```

### 设置空间音频参数

调用 `setRemoteUserSpatialAudioParams` 或 `setSpatialAudioParams`，针对远端用户或媒体播放器设置空间音频参数。如果要实现特定音效，可参考如下参数设置：

- 空气衰减效果：将 `enable_air_absorb` 设置为 `true`；并将 `speaker_attenuation` 设置为预期的声音衰减系数。
- 声音模糊效果：将 `enable_blur` 设置为 `true`。

```typescript
rtcEngine.setRemoteUserSpatialAudioParams(
    uid, 
    {
        enable_air_absorb: true,
        speaker_attenuation: 0.5,
        enable_blur: true,
    }
);
```

### （可选）设置隔声区域

1. 调用 `setZones` 设置一个隔声区域和声音衰减系数。当音源（可以为用户或媒体播放器）跟接收方分属于隔声区域内部和外部时，会体验到类似真实环境中声音在遇到建筑隔断时的衰减效果。
1. （可选）调用 `setRemoteAudioAttenuation` 或 `setPlayerAttenuation` 分别针对用户和媒体播放器设置声音衰减属性，并指定是否使用该设置强制覆盖 `setZones` 中的声音衰减系数。

```typescript
localSpatial.setZones(
    [
        {
            zoneSetId: 1, // 隔声区域的 ID
            position: [0, 0, 0], // 隔声区域的空间中心点
            forward: [1, 0, 0], // 以 position 为起点，向前的单位向量   
            right: [0, 1, 0], // 以 position 为起点，向右的单位向量
            up: [0, 0, 1], // 以 position 为起点，向上的单位向量
            forwardLength: 10, // 隔声区域的前向长度
            rightLength: 10, // 隔声区域的右向长度
            upLength: 10, // 隔声区域的上向长度
            audioAttenuation: 0.5, // 隔声区域和外部互通时的声音衰减系数
        }
    ],
    1
);
localSpatial.setRemoteAudioAttenuation(
    mediaPlayer.getMediaPlayerId(),  // 媒体播放器 ID
    0.5, 
    false
);

localSpatial.setPlayerAttenuation(
    mediaPlayer.getMediaPlayerId(),  // 媒体播放器 ID
    0.5, 
    false
);
```

### （可选）设置耳机均衡效果

1. 调用 `setHeadphoneEQPreset` 方法，选择预设的耳机均衡器收听音频，以达到预期的音频体验。
1. （可选）如果执行上一步后仍未达到预期，你可以调用 `setHeadphoneEQParameters` 自行调节耳机均衡效果，执行该方法后，`setHeadphoneEQPreset` 方法设置的预设值会被覆盖。

```typescript
rtcEngine.setHeadphoneEQPreset(HeadphoneEqualizerPreset.HeadphoneEqualizerOverear);
rtcEngine.setHeadphoneEQParameters(10, 10);
```

### 关闭空间音频

在互动过程中，你可选择暂停或关闭空间音频。

#### 暂停指定远端用户在本地的空间音频

1. 如果不想继续体验远端用户在本地的空间音频、或远端用户已退出频道，调用 `removeRemotePosition` 删除该用户的空间位置信息，以节省计算资源。

    :::warning[注意]
    当远端用户离开频道时，必须调用 `removeRemotePosition` 删除该用户的空间位置信息，否则可能导致本地听不到来自其他远端用户的空间音频。
    :::

1. （可选）如果之后想恢复该用户在本地的空间音频，可调用 `updateRemotePosition` 方法重新设置远端用户的位置信息。

```typescript
// 暂停指定远端用户在本地的空间音频
localSpatial.removeRemotePosition(uid)
// 恢复指定远端用户在本地的空间音频
localSpatial.updateRemotePosition(
    uid,  // 远端用户 ID
    {
        position: [0, 0, 0], 
        axisForward: [1, 0, 0], 
    }
);
```

#### 暂停所有远端用户在本地的空间音频

1. 如果你不想再继续体验本地的空间音频，可以调用 `clearRemotePositions` 删除所有远端用户的空间位置信息。
    :::warning[注意]
    调用该方法会导致本地听不到所有远端用户的音频，声网建议你谨慎调用该方法。
    :::
1. （可选）如果之后还需要听到远端用户的音频，你需要重新调用 `ILocalSpatialAudioEngine` 中的 `muteAllRemoteAudioStreams(false)` 恢复订阅远端用户的音频流。

    ```typescript
    // 删除所有远端用户的空间位置信息
    localSpatial.clearRemotePositions();
    // 恢复订阅远端用户的音频流
    localSpatial.muteAllRemoteAudioStreams(false);
    ```

#### 暂停本地用户在远端的空间音频

1. 调用 `ILocalSpatialAudioEngine` 中的 `muteLocalAudioStream(true)`，取消发布本地音频流。
1. （可选）如果之后想再次开启空间音频，可再次调用该方法并将参数设置为 `false`，即可恢复空间音频。

    ```typescript
    // 取消发布本地音频流
    localSpatial.muteLocalAudioStream(true);
    // 恢复发布本地音频流
    localSpatial.muteLocalAudioStream(false);
    ```

#### 关闭空间音频

1. 在频道内调用 `RtcEngine` 中的 `enableSpatialAudio` 并将参数设置为 `false`，此时所有跟空间音频相关的设置都会被重置。
2. （可选）如果之后想再次开启空间音频，可再次调用该方法并将参数设置为 `true`，然后重新调用相关 API 设置空间音频效果。
3. 调用 `ILocalSpatialAudioEngine` 中的 `release` 销毁 `ILocalSpatialAudioEngine` 对象。

    ```typescript
    // 关闭空间音频
    rtcEngine.enableSpatialAudio(false);
    // 销毁 ILocalSpatialAudioEngine 对象
    localSpatial.release();
    ```

## 技术原理

实现用户空间音频和媒体播放器空间音频时的原理有所不同：

- 用户空间音频：自行部署服务器，用于发送本地空间位置以及接收远端用户的空间位置，然后由 SDK 计算用户间的相对位置，从而计算出相应的空间音频参数。
- 媒体播放器空间音频：通过 SDK 计算本地用户和媒体播放器的相对位置，然后计算出相应的空间音频参数。

![用户空间音频](https://web-cdn.agora.io/docs-portal/img/rtc/spatial-audio/tech-normal.png)

![媒体播放器空间音频](https://web-cdn.agora.io/docs-portal/img/rtc/spatial-audio/tech-mpk.png)

## 实现空间音频

本节介绍如何使用 SDK 实现空间音频，API 调用时序如下图所示。

![实现流程](https://web-cdn.agora.io/docs-portal/img/rtc/spatial-audio/spatial-audio-process.svg)

### 初始化空间音频引擎

调用 `IRtcEngine` 类中的 `GetLocalSpatialAudioEngine` 获取 `ILocalSpatialAudioEngine` 对象，调用 `ILocalSpatialAudioEngine` 类下的 `Initialize` 初始化对象，开启空间音频。

```csharp
SpatialAudioEngine = RtcEngine.GetLocalSpatialAudioEngine();
var ret = SpatialAudioEngine.Initialize();
Debug.Log("_spatialAudioEngine: Initialize " + ret);
```

### 设置音频属性和场景

- 调用 `SetAudioProfile` 设置音频编码属性。
- 调用 `SetAudioScenario` 设置音频应用场景。声网推荐你将 `scenario` 设置为 `AUDIO_SCENARIO_GAME_STREAMING`。

```csharp
RtcEngine.SetAudioProfile(AUDIO_PROFILE_TYPE.AUDIO_PROFILE_DEFAULT);
RtcEngine.SetAudioScenario(AUDIO_SCENARIO_TYPE.AUDIO_SCENARIO_GAME_STREAMING);
```

### 设置音频接收范围

- 调用 `SetAudioRecvRange` 设置可接收音频的最大范围，单位为米，建议 `range` 取值 ＞ 0。
- 调用 `SetMaxAudioRecvCount` 设置音频接收范围内最多可接收的音频流数，建议 `maxCount` 取值 ≤ 16。

```csharp
SpatialAudioEngine.SetAudioRecvRange(30);
SpatialAudioEngine.SetMaxAudioRecvCount(10);
```

### 更新空间位置

- 在用户空间音频场景下，调用 `UpdateSelfPosition` 和 `UpdateRemotePosition` 方法，分别更新本地用户和远端用户的位置。
- 在媒体播放器空间音频场景下，调用 `UpdateSelfPosition` 和 `UpdatePlayerPositionInfo` 方法，分别更新本地用户和媒体播放器的位置。

推荐的调用时机如下所示：

- 当频道内有新用户加入。
- 当本地、远端用户或媒体播放器的相对位置发生改变。
- 根据实际需求调用。

```csharp
// 更新本地用户位置
// 隔声区域的空间中心点
float[] localUserPosition = new float[] { 0.0f, 0.0f, 0.0f };
// 以 position 为起点，向前的单位向量，对应 Unity Vector3 的 z 轴
float[] forward = new float[] { 1.0f, 0.0f, 0.0f };
// 以 position 为起点，向右的单位向量，对应 Unity Vector3 的 x 轴
float[] right = new float[] { 0.0f, 1.0f, 0.0f };
// 以 position 为起点，向上的单位向量，对应 Unity Vector3 的 y 轴
float[] up = new float[] { 0.0f, 0.0f, 1.0f };
var ret = SpatialAudioEngine.UpdateSelfPosition(localUserPosition, forward, right, up);
Debug.Log("UpdateSelfPosition return: " + ret);

// 更新远端用户位置
float[] positionRemote = { 0.0f, 1.0f, 0.0f };
float[] forwardRemote = { 0, 0, 0 };
RemoteVoicePositionInfo remoteVoicePositionInfo = new RemoteVoicePositionInfo(positionRemote, forwardRemote);
var ret = SpatialAudioEngine.UpdateRemotePosition(UidUseInMPK, remoteVoicePositionInfo);
Debug.Log("_spatialAudio.UpdateRemotePosition returns: " + ret);
```

### 设置空间音频参数

调用 `SetRemoteUserSpatialAudioParams` 或 `SetSpatialAudioParams` 为远端用户或媒体播放器设置空间音频参数。如果要实现特定音效，可参考如下参数设置：

- 空气衰减效果：即模拟声音在空气中传播的音色衰减效果。在一定的传输距离下，高频声音衰减速度快、低频声音衰减速度慢。你可以通过 `enable_air_absorb` 控制是否开启空气衰减效果。开启后需确认 `speaker_attenuation` 的值不为 `0`，否则该设置不生效。
- 声音模糊效果：将 `enable_blur` 设置为 `true`。

```csharp
SpatialAudioParams audioParams = new SpatialAudioParams();
// 开启空气衰减效果
audioParams.enable_air_absorb.SetValue(true);
// 开启声音模糊效果
audioParams.enable_blur.SetValue(true);
// 以设置远端用户空间音频参数为例
RtcEngine.SetRemoteUserSpatialAudioParams(uid, audioParams);
```

### （可选）设置隔声区域

1. 调用 `SetZones` 设置一个隔声区域和声音衰减系数。当音源（可以为用户或媒体播放器）跟接收方分属于隔声区域内部和外部时，会体验到类似真实环境中，声音在遇到建筑隔断时的衰减效果。
2. 调用 `SetRemoteAudioAttenuation` 或 `SetPlayerAttenuation` 分别针对用户和媒体播放器设置声音衰减属性，并指定是否使用该设置强制覆盖 `SetZones` 中的声音衰减系数。

```csharp
SpatialAudioZone mediaPlayerLeftZone = new SpatialAudioZone();
mediaPlayerLeftZone.zoneSetId = 1;
mediaPlayerLeftZone.audioAttenuation = 1.0f;
float[] voicePosition = { 0.0f, 0.0f, 0.0f };
float[] viewRelativeSizeInAxis = { 1.0f, 1.0f, 1.0f };
// 在世界坐标系中的坐标
mediaPlayerLeftZone.position = new float[] { voicePosition[0], voicePosition[1], 0 };
// 以 position 为起点，向前的单位向量，对应 Unity Vector3 的 z 轴
mediaPlayerLeftZone.forward = new float[] { 1.0f, 0, 0 };
// 以 position 为起点，向右的单位向量，对应 Unity Vector3 的 x 轴
mediaPlayerLeftZone.right = new float[] { 0, 1.0f, 0 };
// 以 position 为起点，向上的单位向量，对应 Unity Vector3 的 y 轴
mediaPlayerLeftZone.up = new float[] { 0, 0, 1.0f };
// 隔声区域的前向长度
mediaPlayerLeftZone.forwardLength = viewRelativeSizeInAxis[1];
// 隔声区域的右向长度
mediaPlayerLeftZone.rightLength = viewRelativeSizeInAxis[0];
// 隔声区域的上向长度
mediaPlayerLeftZone.upLength = viewRelativeSizeInAxis[2];
SpatialAudioEngine.SetZones(new SpatialAudioZone[] { mediaPlayerLeftZone },1);
// 针对用户设置声音衰减属性
SpatialAudioEngine.SetRemoteAudioAttenuation(uid, 0.5f, false);
// 针对媒体播放器设置声音衰减属性
SpatialAudioEngine.SetPlayerAttenuation(MediaPlayer.GetId(), 0.5f, false);
```

### （可选）设置耳机均衡效果

1. 调用 `SetHeadphoneEQPreset` 方法，选择预设的耳机均衡器收听音频，以达到预期的音频体验。
2. 如果执行上一步后仍未达到预期，你可以调用 `SetHeadphoneEQParameters` 自行调节耳机均衡效果，执行该方法后，`SetHeadphoneEQPreset` 方法设置的预设值会被覆盖。

```csharp
RtcEngine.SetHeadphoneEQPreset(HEADPHONE_EQUALIZER_PRESET.HEADPHONE_EQUALIZER_OVEREAR);
RtcEngine.SetHeadphoneEQParameters(10, 10);
```

### 暂停或关闭空间音频

在互动过程中，你可选择暂停或关闭空间音频。

#### （可选）暂停指定远端用户在本地的空间音频

1. 如果不想继续体验远端用户在本地的空间音频、或远端用户已退出频道，调用 `RemoveRemotePosition` 删除该用户的空间位置信息，以节省计算资源。

    :::warning[注意]
    当远端用户离开频道时，必须调用 `RemoveRemotePosition` 删除该用户的空间位置信息，否则可能导致本地听不到来自其他远端用户的空间音频。
    :::

2. 如果之后想恢复该用户在本地的空间音频，可调用 `UpdateRemotePosition` 方法重新设置远端用户的位置信息。

```csharp
// 暂停指定远端用户在本地的空间音频
SpatialAudioEngine.RemoveRemotePosition(uid);

// 恢复指定远端用户在本地的空间音频系统下的坐标和朝向
float[] position = new float[] { 1.0f, 1.0f, 1.0f };
// 以 position 为起点，向右的单位向量，对应 Unity Vector3 的 x 轴
float[] forward = new float[] { 1.0f, 1.0f, 1.0f };
RemoteVoicePositionInfo positionInfo = new RemoteVoicePositionInfo(position, forward);
SpatialAudioEngine.UpdateRemotePosition(uid, positionInfo);
```

#### （可选）暂停所有远端用户在本地的空间音频

1. 如果你不想再继续体验本地的空间音频，可以调用 `ClearRemotePositions` 删除所有远端用户的空间位置信息。

   :::warning[注意]
   调用该方法会导致本地听不到所有远端用户的音频，声网建议你谨慎调用该方法。
   :::

2. 如果之后还需要听到远端用户的音频，你需要重新调用 `ILocalSpatialAudioEngine` 中的 `MuteAllRemoteAudioStreams` 并将 `mute` 设为 `false` 恢复订阅远端用户的音频流。

```csharp
// 删除所有远端用户的空间位置信息
SpatialAudioEngine.ClearRemotePositions();
// 恢复订阅远端用户的音频流
SpatialAudioEngine.MuteAllRemoteAudioStreams(false);
```

#### （可选）暂停本地用户在远端的空间音频

1. 调用 `ILocalSpatialAudioEngine` 中的 `MuteLocalAudioStream` 并将 `mute` 设为 `true` 以取消发布本地音频流。
2. 如果之后想再次开启空间音频，可再次调用该方法并将参数设置为 `false`，即可恢复空间音频。

```csharp
// 取消发布本地音频流
SpatialAudioEngine.MuteLocalAudioStream(true);
// 恢复发布本地音频流
SpatialAudioEngine.MuteLocalAudioStream(false);
```

#### 关闭空间音频

1. 在频道内调用 `IRtcEngine` 中的 `EnableSpatialAudio` 并将 `enabled` 参数设置为 `false`，此时所有跟空间音频相关的设置都会被重置。
2. 如果之后想再次开启空间音频，可再次调用该方法并将参数设置为 `true`，然后重新调用相关 API 设置空间音频效果。
3. 如果你不需要再使用空间音频功能，调用 `ILocalSpatialAudioEngine` 中的 `Dispose` 销毁 `ILocalSpatialAudioEngine` 对象。

```csharp
// 关闭空间音频
RtcEngine.EnableSpatialAudio(false);
// 销毁 ILocalSpatialAudioEngine 对象
SpatialAudioEngine.Dispose();
```

## 技术原理

实现用户空间音频和媒体播放器空间音频时的原理有所不同：

- 用户空间音频：自行部署服务器，用于发送本地空间位置以及接收远端用户的空间位置，然后由 SDK 计算用户间的相对位置，从而计算出相应的空间音频参数。
- 媒体播放器空间音频：通过 SDK 计算本地用户和媒体播放器的相对位置，然后计算出相应的空间音频参数。

![用户空间音频](https://web-cdn.agora.io/docs-portal/img/rtc/spatial-audio/tech-normal.png)

![媒体播放器空间音频](https://web-cdn.agora.io/docs-portal/img/rtc/spatial-audio/tech-mpk.png)

## 前提条件

在进行操作之前，请确保你已经在项目中实现了基本的实时音视频功能。详见[实现音视频互动](/zh-CN/realtime-media/rtc/get-started/quick-start)。

## 实现空间音频

本节介绍如何使用 SDK 实现空间音频，API 调用时序如下图所示。

![实现流程](https://web-cdn.agora.io/docs-portal/img/rtc/spatial-audio/spatial-audio-process.svg)

### 初始化空间音频引擎

调用 `getLocalSpatialAudioEngine` 和 `initialize` 初始化 `ILocalSpatialAudioEngine` 对象，开启空间音频。

```typescript
rtcEngine = createAgoraRtcEngine();
localSpatial = rtcEngine.getLocalSpatialAudioEngine()
localSpatial.initialize();
```

### 设置音频属性和场景

1. 调用 `setAudioProfile`，将 `profile` 设置为你预期的音频编码属性。
2. 调用 `setAudioScenario`，将 `scenario` 设置为 `AudioScenarioGameStreaming`，以获得预期的音质效果。

```typescript
rtcEngine.setAudioProfile(AudioProfileType.AudioProfileSpeechStandard);
rtcEngine.setAudioScenario(AudioScenarioType.AudioScenarioGameStreaming);
```

### 设置音频接收范围

- 调用 `setMaxAudioRecvCount` 设置音频接收范围内最多可接收的音频流数，建议 `maxCount` 取值 ≤ 16。
- 调用 `setAudioRecvRange` 设置可接收音频的最大范围，单位为米，建议 `range` 取值 ＞ 0。

```typescript
localSpatial.setMaxAudioRecvCount(2);
localSpatial.setAudioRecvRange(50);
```

### 更新空间位置

- 在用户空间音频场景下，调用 `updateSelfPosition` 和 `updateRemotePosition` 方法，分别更新本地用户和远端用户的位置。
- 在媒体播放器空间音频场景下，调用 `updateSelfPosition` 和 `updatePlayerPositionInfo` 方法，分别更新本地用户和媒体播放器的位置。

推荐的调用时机如下所示：

- 当频道内有新用户加入。
- 当本地、远端用户或媒体播放器的相对位置发生改变。
- 根据实际需求调用。

```typescript
// 更新本地用户位置
localSpatial.updateSelfPosition(
    [0, 0, 0],  // position
    [1, 0, 0],  // axisForward
    [0, 1, 0],  // axisRight
    [0, 0, 1]   // axisUp
);

// 更新远端用户位置
localSpatial.updateRemotePosition(
    uid,  // 远端用户 ID
    {
        position: [0, 0, 0],
        axisForward: [1, 0, 0],
    }
);

// 更新媒体播放器位置
localSpatial.updatePlayerPositionInfo(
    mediaPlayer.getMediaPlayerId(),  // 媒体播放器 ID
    {
        position: [0, 0, 0],
        axisForward: [1, 0, 0],
    }
);
```

### 设置空间音频参数

调用 `setRemoteUserSpatialAudioParams` 或 `setSpatialAudioParams`，针对远端用户或媒体播放器设置空间音频参数。如果要实现特定音效，可参考如下参数设置：

- 空气衰减效果：将 `enable_air_absorb` 设置为 `true`；并将 `speaker_attenuation` 设置为预期的声音衰减系数。
- 声音模糊效果：将 `enable_blur` 设置为 `true`。

```typescript
rtcEngine.setRemoteUserSpatialAudioParams(
    uid, 
    {
        enable_air_absorb: true,
        speaker_attenuation: 0.5,
        enable_blur: true,
    }
);
```

### （可选）设置隔声区域

1. 调用 `setZones` 设置一个隔声区域和声音衰减系数。当音源（可以为用户或媒体播放器）跟接收方分属于隔声区域内部和外部时，会体验到类似真实环境中声音在遇到建筑隔断时的衰减效果。
1. （可选）调用 `setRemoteAudioAttenuation` 或 `setPlayerAttenuation` 分别针对用户和媒体播放器设置声音衰减属性，并指定是否使用该设置强制覆盖 `setZones` 中的声音衰减系数。

```typescript
localSpatial.setZones(
    [
        {
            zoneSetId: 1, // 隔声区域的 ID
            position: [0, 0, 0], // 隔声区域的空间中心点
            forward: [1, 0, 0], // 以 position 为起点，向前的单位向量   
            right: [0, 1, 0], // 以 position 为起点，向右的单位向量
            up: [0, 0, 1], // 以 position 为起点，向上的单位向量
            forwardLength: 10, // 隔声区域的前向长度
            rightLength: 10, // 隔声区域的右向长度
            upLength: 10, // 隔声区域的上向长度
            audioAttenuation: 0.5, // 隔声区域和外部互通时的声音衰减系数
        }
    ],
    1
);
localSpatial.setRemoteAudioAttenuation(
    mediaPlayer.getMediaPlayerId(),  // 媒体播放器 ID
    0.5, 
    false
);

localSpatial.setPlayerAttenuation(
    mediaPlayer.getMediaPlayerId(),  // 媒体播放器 ID
    0.5, 
    false
);
```

### （可选）设置耳机均衡效果

1. 调用 `setHeadphoneEQPreset` 方法，选择预设的耳机均衡器收听音频，以达到预期的音频体验。
1. （可选）如果执行上一步后仍未达到预期，你可以调用 `setHeadphoneEQParameters` 自行调节耳机均衡效果，执行该方法后，`setHeadphoneEQPreset` 方法设置的预设值会被覆盖。

```typescript
rtcEngine.setHeadphoneEQPreset(HeadphoneEqualizerPreset.HeadphoneEqualizerOverear);
rtcEngine.setHeadphoneEQParameters(10, 10);
```

### 关闭空间音频

在互动过程中，你可选择暂停或关闭空间音频。

#### 暂停指定远端用户在本地的空间音频

1. 如果不想继续体验远端用户在本地的空间音频、或远端用户已退出频道，调用 `removeRemotePosition` 删除该用户的空间位置信息，以节省计算资源。

    :::warning[注意]
    当远端用户离开频道时，必须调用 `removeRemotePosition` 删除该用户的空间位置信息，否则可能导致本地听不到来自其他远端用户的空间音频。
    :::

1. （可选）如果之后想恢复该用户在本地的空间音频，可调用 `updateRemotePosition` 方法重新设置远端用户的位置信息。

```typescript
// 暂停指定远端用户在本地的空间音频
localSpatial.removeRemotePosition(uid)
// 恢复指定远端用户在本地的空间音频
localSpatial.updateRemotePosition(
    uid,  // 远端用户 ID
    {
        position: [0, 0, 0], 
        axisForward: [1, 0, 0], 
    }
);
```

#### 暂停所有远端用户在本地的空间音频

1. 如果你不想再继续体验本地的空间音频，可以调用 `clearRemotePositions` 删除所有远端用户的空间位置信息。
    :::warning[注意]
    调用该方法会导致本地听不到所有远端用户的音频，声网建议你谨慎调用该方法。
    :::
1. （可选）如果之后还需要听到远端用户的音频，你需要重新调用 `ILocalSpatialAudioEngine` 中的 `muteAllRemoteAudioStreams(false)` 恢复订阅远端用户的音频流。

    ```typescript
    // 删除所有远端用户的空间位置信息
    localSpatial.clearRemotePositions();
    // 恢复订阅远端用户的音频流
    localSpatial.muteAllRemoteAudioStreams(false);
    ```

#### 暂停本地用户在远端的空间音频

1. 调用 `ILocalSpatialAudioEngine` 中的 `muteLocalAudioStream(true)`，取消发布本地音频流。
1. （可选）如果之后想再次开启空间音频，可再次调用该方法并将参数设置为 `false`，即可恢复空间音频。

    ```typescript
    // 取消发布本地音频流
    localSpatial.muteLocalAudioStream(true);
    // 恢复发布本地音频流
    localSpatial.muteLocalAudioStream(false);
    ```

#### 关闭空间音频

1. 在频道内调用 `RtcEngine` 中的 `enableSpatialAudio` 并将参数设置为 `false`，此时所有跟空间音频相关的设置都会被重置。
2. （可选）如果之后想再次开启空间音频，可再次调用该方法并将参数设置为 `true`，然后重新调用相关 API 设置空间音频效果。
3. 调用 `ILocalSpatialAudioEngine` 中的 `release` 销毁 `ILocalSpatialAudioEngine` 对象。

    ```typescript
    // 关闭空间音频
    rtcEngine.enableSpatialAudio(false);
    // 销毁 ILocalSpatialAudioEngine 对象
    localSpatial.release();
    ```
