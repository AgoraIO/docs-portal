---
高清视频算法通过实现更好的数据压缩和更高的带宽利用率，能够有效提升图像质量和视频观看体验。

:::info[信息]
该功能需要集成特定版本的 SDK，请[联系技术支持](https://ticket.shengwang.cn)启用该功能以及获取相关注意事项。
:::

## 适用场景

高清视频算法适用于以下对实时性要求较高的场景：

- 高清视频和虚拟现实：提供更好的视频质量，同时减少对网络带宽的需求。

- 视频会议和远程通信：占用较低的带宽，提供更高的图像质量。

- 监控和安防系统：保持图像细节清晰的同时减少带宽消耗。

## 技术优势

该高清视频算法具备以下技术优势：

| 特性 | 描述 |
| --- | --- |
| 压缩性能 | 在保持相同视频质量的情况下，能够将视频数据的大小压缩到原来的一半，占用更低的带宽。 |
| 视频质量 | 在更低码率下，提供更高的颜色深度、色彩范围和动态范围。 |
| 分辨率支持 | 支持多种分辨率，满足超高清应用需求。 |
| 噪声抑制能力 | 在低码率高动态画面中具有优势，有效抑制码流引起的噪声。 |
| 误码容忍能力 | 采用重建滤波技术，保证丢包、错包网络环境下视频连贯性和完整性。 |
