---
title: "减小 App 体积"
---
App 体积是影响用户体验的重要因素之一，更小的包体积意味着用户可以消耗更少的带宽和时间下载 App。
在以下场景中，减小 App 体积对提升用户体验具有重要意义：

- App 的应用场景对 App 体积有严格要求。例如运行在储存空间有限的智能穿戴设备上。
- App 的目标用户群体位于欠发达地区，网络环境较差，导致 App 下载时间过长。

本文介绍如何减少集成声网实时互动 SDK 的 App 体积。

## 使用音频 SDK

Unity 视频 SDK 支持音频和视频功能，包体积大。如果你只需使用音频功能，建议你集成 Unity 音频 SDK，详见[实现纯语音互动](/zh-CN/realtime-media/rtc/basic-features/audio-quick-start.unity#集成-sdk)。

## 删除不需要的插件

SDK 提供了可选的插件动态库，插件的命名以 `extension` 为后缀，插件功能和大小等信息详见[插件列表](#插件列表)。你可以参考如下方式不集成这些插件，以减小 App 体积。

### 在集成 SDK 时删除
在 Unity Editor 中打开 `Assets/Agora-RTC-Plugin/Agora-Unity-RTC-SDK/Plugins` 文件夹。其中分别包含了 iOS、macOS、Windows 和 Android 四个平台的动态库。如下图所示：

![unity editor](/img/rtc/unity-app-size.png)

- **Android**：如果你的目标平台为 Android，可以在 `Android/AgoraRtcEngineKit.plugin/libs` 路径下，根据需求删除 `arm64-v8a`、`armeabi-v7a`、`x86`、`x86_64` 文件夹中的 `_extension.so` 文件。
- **iOS**：如果你的目标平台为 iOS ，可以根据需求删除 `iOS` 文件夹中无需使用的 `***Extension.framework` 文件。
- **macOS**：如果你的目标平台为 macOS，可以在 `macOS/AgoraRtcWrapperUnity.bundle/Contents/Frameworks` 路径下，根据需求删除无需使用的 `***Extension.framework` 文件。
- **Windows**：如果你的目标平台为 Windows，可以根据需求删除 `x86` 或 `x86_64` 文件夹中无需使用的 `***extension.dll` 或 `***extension.dll.lib` 文件。

### 在导出的原生工程中删除

当你导出某个目标平台的原生工程后，Unity Editor 里对应平台的动态库也会一起拷贝到原生工程中。此时你可以在导出后的原生工程中直接删除以 `extension` 结尾的动态库。

<Accordion title="美声插件">
