## 通过 Cocoapods 集成 SDK

本节提供通过 Cocoapods 集成 SDK 的方式。

```ruby
platform :macos, '10.11'
target 'Your App' do
    # 集成 SDK
    pod 'ShengwangRtcEngine_macOS', '4.6.2'
    # 选择性集成 SDK 中的基础库和指定动态库
    pod 'ShengwangRtcEngine_macOS', '4.6.2', :subspecs => ['RtcBasic', 'AINS', 'ClearVision']

end
    ```

## 通过 SPM 集成 SDK

本节提供通过 SPM (Swift Package Manager) 集成 SDK 的方式。

```text
github:git@github.com:Shengwang-Lab/ShengwangRtcEngine_macOS.git | tag:4.6.2
```

## 下载 SDK

本节提供最新版本的 SDK。

  :::info[信息]
  - SDK 默认使用 libc++ (LLVM)，如需使用 libstdc++ (GNU)，请联系 sales@shengwang.cn。SDK 提供的库是 FAT Image，包含 32/64 位模拟器、32/64 位真机版本。
      - 各版本 SDK 的发版详情请参考[发版说明](/zh-CN/realtime-media/rtc/overview/release-notes.macos)。
      - 如何使用 SDK 实现各种音视频互动功能请参考[实现音视频互动](/zh-CN/realtime-media/rtc/get-started/quick-start.macos)。
  :::

  视频 SDK 中提供了简单易用的 API，帮助开发者在 App 中构建各种实时音视频互动场景。

  - SDK 名称：视频 SDK
  - 开发者：上海声网科技有限公司
  - 视频 SDK 合规使用说明请参考[视频 SDK 合规使用说明](/basics/security/video-sdk)，个人信息处理规则请参考 [SDK 个人信息处理规则](https://www.shengwang.cn/SDK-privacy-policy/)。

      - [macOS](https://download.shengwang.cn/sdk/release/Shengwang_Native_SDK_for_Mac_v4.6.2_FULL.zip)
