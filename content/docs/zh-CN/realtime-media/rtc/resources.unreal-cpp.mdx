## 下载 SDK

本节提供最新版本的 SDK。

  :::info[信息]
  - SDK 默认使用 libc++ (LLVM)，如需使用 libstdc++ (GNU)，请联系 sales@shengwang.cn。SDK 提供的库是 FAT Image，包含 32/64 位模拟器、32/64 位真机版本。
      - 各版本 SDK 的发版详情请参考[发版说明](/zh-CN/realtime-media/rtc/overview/release-notes.unreal-cpp)。
      - 如何使用 SDK 实现各种音视频互动功能请参考[实现音视频互动](/zh-CN/realtime-media/rtc/get-started/quick-start.unreal-cpp)。
  :::

  :::warning[注意]
  声网 Unreal SDK 支持 C++ 和 Blueprint 两种集成方式，当前推荐使用稳定性更优的 C++ 版本。
  :::
