声网语音与视频 SDK 提供超低延时、高质量的实时音视频能力，支持一对一通话、多人通话、互动直播、屏幕共享和跨平台接入。借助声网实时网络，你可以在复杂网络环境下为用户提供稳定、流畅的实时互动体验。

你还可以结合云端录制、实时转写、内容审核、虚拟背景、美颜和扩展插件等能力，完善通话、直播和协作场景中的生产级体验。

## 产品特性

<CardGrid>
  <FeatureCard title="全球实时网络">
    声网软件定义实时网络覆盖全球 200 多个国家和地区，帮助用户就近接入并稳定传输音视频流。
  </FeatureCard>
  <FeatureCard title="高质量音视频">
    支持高清实时视频、清晰语音、动态分辨率调整和弱网优化，在复杂网络环境下保持顺畅体验。
  </FeatureCard>
  <FeatureCard title="多路音视频轨道">
    支持在一个或多个频道中发布多路音频和视频轨道，覆盖多摄像头、多麦克风和复杂媒体采集场景。
  </FeatureCard>
  <FeatureCard title="屏幕共享与协作">
    可结合屏幕共享、互动白板和文件展示能力，构建会议、课堂和远程协作体验。
  </FeatureCard>
  <FeatureCard title="AI 音频增强">
    支持空间音频、AI 降噪、音量增益、变声和混音等能力，提升实时互动中的听觉体验。
  </FeatureCard>
  <FeatureCard title="录制与内容处理">
    可将实时音视频与云端录制、本地服务端录制、实时转写和内容审核等服务组合使用。
  </FeatureCard>
</CardGrid>
