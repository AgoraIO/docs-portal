## 通过 npm 集成 SDK

声网推荐通过 npm 在项目中集成 SDK。

```shell
npm install agora-rtc-sdk-ng
```

使用 npm 集成 Web SDK 还支持开启 Tree shaking 来减小集成 SDK 后的 App 体积，详见[使用 Tree shaking](/zh-CN/realtime-media/rtc/basic-features/tree-shaking.javascript)。

## 下载 SDK

本节提供 SDK 最新版本的下载链接。

  :::info[信息]
  - SDK 默认使用 libc++ (LLVM)，如需使用 libstdc++ (GNU)，请联系 sales@shengwang.cn。SDK 提供的库是 FAT Image，包含 32/64 位模拟器、32/64 位真机版本。
      - 各版本 SDK 的发版详情请参考[发版说明](/zh-CN/realtime-media/rtc/overview/release-notes.javascript)。
      - 如何使用 SDK 实现各种音视频互动功能请参考[实现音视频互动](/zh-CN/realtime-media/rtc/get-started/quick-start.javascript)。
  :::

 视频 SDK 中提供了简单易用的 API，帮助开发者在 App 中构建各种实时音视频互动场景。

  - SDK 名称：视频 SDK
  - 开发者：上海声网科技有限公司
  - 视频 SDK 合规使用说明请参考[视频 SDK 合规使用说明](/basics/security/video-sdk)，个人信息处理规则请参考 [SDK 个人信息处理规则](https://www.shengwang.cn/SDK-privacy-policy/)。

    - [Web](https://download.agora.io/sdk/release/Agora_Web_SDK_v4_24_5_FULL.zip)
