## v4.4.2

该版本于 2024 年 11 月 29 日发布。

### 升级必看

- 该版本将访问区域（`areaCode`）的默认值从 `GLOB` 变更为 `CN`。

### 新增特性

- 该版本新增 `setEnableSpeakerphone` 方法，支持设置是否使用扬声器播放。

### 问题修复

该版本修复了以下问题：

- `isSpeakerphoneEnabled` 回调返回结果不准确。
- 在鸿蒙 NEXT 0.0.107 系统的设备上，调用 `leaveChannel` 后偶现崩溃。

## v4.4.1

该版本于 2024 年 10 月 24 日发布，适配 HarmonyOS NEXT Release 版本，确保其在最新操作系统上的兼容性和性能表现。

### 升级必看

该版本对 SDK 进行了以下优化和变更，为确保项目的正常运行，你需要在升级到该版本后更新 App 中的代码。

- 包名变更为 `@shengwang/rtc-full`（视频 SDK）或 `@shengwang/rtc-voice`（音频 SDK），请在添加依赖项和导入 SDK 组件的代码处修改包名，详见[实现音视频互动](/zh-CN/realtime-media/rtc/get-started/quick-start.harmonyos)或[实现纯语音互动](/zh-CN/realtime-media/rtc/basic-features/audio-quick-start.harmonyos)。
- HAR 包变更为字节码格式，你需要在 `build-profile.json5` 项目文件中增加以下编译选项：

    ```json
    "products": [
      {
        "name": "default",
        "signingConfig": "default",
        "compatibleSdkVersion": "5.0.0(12)",
        "runtimeOS": "HarmonyOS",
        // highlight-start
        "buildOption": {
          "strictMode": {
            "useNormalizedOHMUrl": true
          }
        }
        // highlight-end
      }
    ],
    ```

### 新增特性

该版本包含以下新增特性：

- SDK 中包含 C/C++ 头文件，你可以在项目中直接使用 C/C++ 语言开发，无需另外拷贝。
- 支持内置媒体播放器和播放版权音乐功能。

### 改进

该版本包含以下改进：

- 提升了视频解码的流畅度。
- 优化了音频路由切换的体验。
- 提升了视频解码器的稳定性。

### 问题修复

该版本修复了以下问题：

- 音视频录制偶现崩溃。
- 偶现 `onVideSizeChanged` 回调无法正常上报。

## v4.4.0

该版本于 2024 年 10 月 8 日发布。

#### 功能简介

该 SDK 由声网为开发者设计，旨在为鸿蒙系统的开发者提供简单且用户友好的实时互动解决方案。

SDK 提供了一套强大的 API，使开发者可以轻松构建具备实时音视频互动功能的应用程序，并可以利用鸿蒙系统的独特优势，增强应用的性能和用户体验。通过集成该 SDK，开发者可以快速实现高质量的音视频通话和互动直播等功能，提升应用的互动性和用户粘性。
