声网小程序实时互动 SDK 支持实现一对一及多人音视频互动，可用于线上课堂、在线医疗等众多场景。

## 技术方案

下图为小程序连麦的声网实现架构图：

![小程序架构图](https://web-cdn.agora.io/docs-files/1675996941048)

在这个架构图中：

1. 在声网 SD-RTN™ 边缘节点部署协议转换服务对小程序端发出的 RTMP 流进行转换；
2. 将转换后的流通过 UDP 传输到声网 SD-RTN™ 上；
3. 通过声网 SD-RTN™ 与声网其他平台 SDK 实现音频互通。

## 功能列表

| 主要功能          | 功能描述                                                     |
| ----------------- | ------------------------------------------------------------ |
| 伴奏混音          | 接收远端用户播放的伴奏混音。 |
| 使用双声道/高音质 | 支持高音质、双声道的音频设置。                               |
| 基础美颜 | 可设置光滑美颜或自然美颜，支持设置色彩滤镜。|
| 屏幕共享 | 支持观看远端用户的共享屏幕。|

## 适用场景

结合微信小程序，你可以实现如下场景：

- 互动课堂：1 对 1 及 1 对多线上小班课，老师、学生进行实时互动。
- 在线医疗：突破医疗资源的地域限制，实现多方视频会诊，降低诊断成本。
- 高端客服：对高价值的 VIP 客户提供远程视频服务，1 对 1 实时交流。
- 远程报警：一键报警，通过实时视频通信，为警方提供一手现场情况。
- 银行开户：实时视频认证，清晰画质、超低延时、隐私保护，提升开户效率。
- 智能硬件：支持与收发 G711 编码格式音频的 IoT 设备（如 IPC、门铃、手表等）双向互通，支持单向接收 IoT 设备发出的 JPEG 格式图像。如需使用小程序 SDK 与 IoT 设备互通，请联系 sales@shengwang.cn。开通服务的邮件模板参考[设置 RTC 小程序 SDK](/zh-CN/realtime-media/rtsa/best-practices/interoperate-rtc#设置-rtc-小程序-sdk)。
