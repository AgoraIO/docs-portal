## 通过 Maven Central 集成 SDK

打开 `/app/build.gradle` 文件，在 `dependencies` 中添加声网 RTC SDK 的依赖。

```groovy tab="视频 SDK" tabGroup="integrate-sdk"
...
dependencies {
    ...
    // 集成 Full SDK
    implementation 'cn.shengwang.rtc:full-sdk:4.6.3'
    // 集成 Lite SDK
    implementation 'cn.shengwang.rtc:lite-sdk:4.6.3'
}
```

```groovy tab="音频 SDK" tabGroup="integrate-sdk"
...
dependencies {
    ...
    // 集成音频 SDK
    implementation 'cn.shengwang.rtc:voice-sdk:4.6.3'
}
```

## 下载 SDK

本节提供最新版本的 SDK。

  :::info[信息]
  - SDK 默认使用 libc++ (LLVM)，如需使用 libstdc++ (GNU)，请联系 sales@shengwang.cn。SDK 提供的库是 FAT Image，包含 32/64 位模拟器、32/64 位真机版本。
      - 各版本 SDK 的发版详情请参考[发版说明](/zh-CN/realtime-media/rtc/overview/release-notes.android)。
      - 如何使用 SDK 实现各种音视频互动功能请参考[实现音视频互动](/zh-CN/realtime-media/rtc/get-started/quick-start.android)。
      - 集成 SDK 后增加的实际包体积数据会根据集成的动态库的不同而有所差异，本页提供的数据仅供参考。
  :::
