---
title: "实现极速直播"
---
本文介绍如何集成声网实时互动 SDK，在基础的音视频互动能力上进行少量代码修改，即可实现一个极速直播 App。

极速直播是区别于互动直播的一种直播场景，两者的区别在于观众端的延时级别：

- 互动直播：观众端的延时级别为**超低延时**，以便满足主播和观众需要频繁进行音视频互动的需求。
- 极速直播：观众端的延时级别为**低延时**，可以满足主播与观众较低频率的音视频互动，或者回应观众文字、弹幕及打赏信息。

更多关于极速直播的延时指标、同步性、互动体验以及费用介绍，详见[直播场景区别](/faq/general-product-inquiry/streaming-difference)和[计费策略](/zh-CN/realtime-media/rtc/billing/billing-strategy)。

## 前提条件

开始前，请确保已在你的项目中实现基本的实时音视频功能。详见[实现音视频互动](/zh-CN/realtime-media/rtc/get-started/quick-start.flutter)。

## 实现步骤

将直播场景下观众端的延时级别修改为低延时，即可将一个互动直播 App 修改为极速直播 App，有以下两种实现方式：

- 在加入频道后，调用 `setClientRole` 方法，将 `role` 参数设置为 `clientRoleAudience`（观众）；将 `options` 参数设置为 `audienceLatencyLevelLowLatency`（低延时）。
- 在调用 `joinChannel` 加入频道时，将 `clientRoleType` 参数设置为 `clientRoleAudience`（观众）；将 `audienceLatencyLevel` 参数设置为 `audienceLatencyLevelLowLatency`（低延时）。示例代码如下：

```dart
await _engine.joinChannel(
  token: token,
  channelId: channel,
  options: const ChannelMediaOptions(
    // 自动订阅所有视频流
    autoSubscribeVideo: true,
    // 自动订阅所有音频流
    autoSubscribeAudio: true,
    // 发布摄像头采集的视频
    publishCameraTrack: true,
    // 发布麦克风采集的音频
    publishMicrophoneTrack: true,
    // highlight-start
    // 设置用户角色为 clientRoleAudience（观众）
    clientRoleType: ClientRoleType.clientRoleAudience,
    // 设置低延时级别
    audienceLatencyLevel: AudienceLatencyLevelType.audienceLatencyLevelLowLatency),
    // highlight-end
  uid: 0,
);
```

## 后续步骤

本文的示例使用了临时 Token 加入频道。在测试或生产环境中，为保证通信安全，声网推荐从服务器中获取 Token，详情请参考[使用 Token 鉴权](/zh-CN/realtime-media/rtc/basic-features/token-authentication.flutter)。
