## 功能描述

大型企业、医院、高校、银行等安全需求较高的机构会部署防火墙将办公环境与外网隔离开来，保护内部信息安全。为避免这些企业用户因防火墙无法使用声网的服务，声网微信小程序 SDK 提供防火墙白名单方案。

:::warning[注意]
- 如果你想通过 VPN 使用声网的服务，请确保已联系 VPN 运营商将对应端口添加到白名单中，否则可能会遇到通话失败等未定义行为。
- 如无特殊说明，源地址就是集成了声网 SDK 的客户端。
:::

## 设置企业防火墙

参考以下步骤设置防火墙，即可在网络受限的环境下使用声网的服务：

1. 把以下域名添加到防火墙的白名单中：

    ```shell
     miniapp.agoraio.cn
     miniapp-1.agoraio.cn
     miniapp-2.agoraio.cn
     miniapp-3.agoraio.cn
     miniapp-4.agoraio.cn
     uni-webcollector.agora.io
     miniapp.agoraio.cn
    ```

2. 开放以下端口且不对 IP 地址设限：

   | 目标端口                                                     | 协议 | 操作 |
   | ------------------------------------------------------------ | ---- | ---- |
   | 80；443；3433；5668；5669；5866 - 5890；6080；6443；8667；9667 | TCP  | 允许 |
   | 3478；10000 - 65535                                          | UDP  | 允许 |
