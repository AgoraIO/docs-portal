---
title: "设置视频编码属性"
---
你可以根据终端用户的设备、浏览器、网络状况和实际应用场景设置视频属性，调整视频的清晰度和流畅度，从而获得较高的用户体验。

点击[在线体验](https://webdemo.agora.io/example/advanced/adjustVideoProfile/index.html)试用设置视频属性功能。

## 前提条件

开始前，请确保你已参考[快速开始](/zh-CN/realtime-media/rtc/get-started/quick-start.javascript)在你的项目中实现基本的实时音视频功能。

## 实现方法

声网 Web SDK 提供两种方式设置视频属性：

- 在创建视频轨道时设置：
  - 调用 `AgoraRTC.createCameraVideoTrack` 创建摄像头视频轨道时，通过修改 `encoderConfig` 参数设置使用 SDK 预设值或者自定义配置。
  - 调用 `AgoraRTC.createScreenVideoTrack` 创建屏幕共享视频轨道时，通过修改 `encoderConfig` 参数设置使用 SDK 预设值或者自定义配置。
  - 调用 `AgoraRTC.createCustomVideoTrack` 创建自定义视频轨道时，通过修改 `bitrateMax`、`bitrateMin` 参数设置码率。自 v4.17.1 起，还可以通过 `width`、`height`、`frameRate` 参数设置分辨率和帧率。
- 创建视频轨道后动态调整（发布前和发布后都支持）：
  - 摄像头视频轨道可以调用 `CameraVideoTrack.setEncoderConfiguration` 动态调整视频属性。
  - 自 v4.17.1 起，屏幕共享视频轨道和自定义视频轨道也可以调用 `LocalVideoTrack.setEncoderConfiguration` 动态调整视频属性。

以摄像头视频轨道为例：

**创建时使用预设视频编码属性**

```javascript
AgoraRTC.createCameraVideoTrack({
  encoderConfig: "720p_1",
}).then(localVideoTrack => { /** ... **/ });
```

SDK 支持的预设视频属性可参考下方的[分辨率和浏览器对照表](#preset-video-profiles)。SDK 默认的视频属性为 `"480p_1"`。

**创建时自定义视频编码属性**

```javascript
AgoraRTC.createCameraVideoTrack({
  encoderConfig: {
    width: 640,
    // 支持指定一个范围和参考值，具体配置参考相关 API 文档
    height: { ideal: 480, min: 400, max: 500 },
    frameRate: 15,
    bitrateMin: 600, bitrateMax: 1000,
  },
}).then(localVideoTrack => {/** ... **/ });
```

**创建后通过预设值动态调整视频编码属性**

```javascript
CameraVideoTrack.setEncoderConfiguration("480p_1").then(() => { /** ... **/ })
```

**创建后动态调整自定义视频编码属性**

```javascript
CameraVideoTrack.setEncoderConfiguration({ width: 1280, height: 720 }).then(() => { /** ... **/ })
```

## 参考信息

### 开发注意事项

- 不同的浏览器对分辨率的支持可能不同，具体的支持情况详见[分辨率和浏览器对照表](#preset-video-profiles)。
- 由于部分浏览器的限制，用户通过 SDK 设置的分辨率有一定概率与实际采集的分辨率不符。当浏览器不支持用户设置的分辨率时，计量计费会以实际采集的分辨率为准，实际采集的分辨率有可能大于或者小于设置的分辨率。
- 视频能否达到 1080p 以上的分辨率取决于设备的性能，在性能配备较低的设备上有可能无法实现。如果采用 720p 分辨率而设备性能跟不上，则有可能出现帧率过低的情况。
- Safari 浏览器视频帧率为 30 fps，不支持自定义视频帧率。
- 动态修改视频属性仅支持 Chrome 63 及以上版本和 Safari 11 及以上版本。在部分 iOS 设备上动态修改视频属性可能会导致视频出现黑边。

### 常用分辨率、帧率和码率
通常来讲，视频属性的选择要根据产品实际情况来确定，比如，如果是一对一场景，老师和学生的窗口比较大，要求分辨率会高一点，随之帧率和码率也要高一点；如果是一对四场景，老师和学生的窗口都比较小，分辨率可以低一点，对应的码率帧率也会低一点，以减少编解码的资源消耗和缓解下行带宽压力。

一般可按以下场景推荐值进行设置。

- 2 人视频通话场景：
  - 分辨率 320 × 240、帧率 15 fps、码率 200 Kbps
  - 分辨率 640 × 360、帧率 15 fps、码率 400 Kbps
- 多人视频通话场景：
  - 分辨率 160 × 120、帧率 15 fps、码率 65 Kbps
  - 分辨率 320 × 180、帧率 15 fps、码率 140 Kbps
  - 分辨率 320 × 240、帧率 15 fps、码率 200 Kbps
