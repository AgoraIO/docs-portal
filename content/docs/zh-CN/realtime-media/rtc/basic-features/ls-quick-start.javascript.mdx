---
title: "实现极速直播"
---
本文介绍如何集成声网实时互动 SDK，在基础的音视频互动能力上进行少量代码修改，即可实现一个极速直播 App。

极速直播是区别于互动直播的一种直播场景，两者的区别在于观众端的延时级别：

- 互动直播：观众端的延时级别为**超低延时**，以便满足主播和观众需要频繁进行音视频互动的需求。
- 极速直播：观众端的延时级别为**低延时**，可以满足主播与观众较低频率的音视频互动，或者回应观众文字、弹幕及打赏信息。

更多关于极速直播的延时指标、同步性、互动体验以及费用介绍，详见[直播场景区别](/faq/general-product-inquiry/streaming-difference)和[计费策略](/zh-CN/realtime-media/rtc/billing/billing-strategy)。

## 前提条件

开始前，请确保已在你的项目中实现基本的实时音视频功能。详见[实现音视频互动](/zh-CN/realtime-media/rtc/get-started/quick-start.javascript)。

## 实现低延时观众端

调用 [`setClientRole`](/api-ref/rtc/javascript/interfaces/iagorartcclient#setclientrole) 方法时，除了将角色 `role` 设为 `"audience"`（观众），你还需要将延时等级 `level` 设为 `1`，即可将直播场景下观众端的延时级别修改为低延时。

```javascript
// 添加以下代码
let clientRoleOptions = {
    // 设置观众端的延时级别为低延时
    level: 1
}

// 修改 setClientRole 中传入的参数
rtc.client.setClientRole(options.role, clientRoleOptions);
```

### 其它集成方式

使用 npm 集成 Web SDK 还支持开启 Tree shaking 来减小集成 SDK 后的 App 体积，详见[使用 Tree shaking](/zh-CN/realtime-media/rtc/basic-features/tree-shaking.javascript)。

除使用 npm 获取 Web SDK 之外，你还可以使用以下方法获取 SDK：

- 在项目 HTML 文件中，添加如下代码，使用 CDN 方法获取 SDK：

  ```html
  <script src="https://download.agora.io/sdk/release/AgoraRTC_N-4.24.5.js"></script>
  ```

- 下载[声网 Web SDK 4.x 版本 SDK 包](/zh-CN/realtime-media/rtc/resources.javascript)至本地，将 SDK 包中的 `.js` 文件保存到项目文件所在的目录下，然后在项目 HTML 文件中添加如下代码：

  ```html
  <script src="./AgoraRTC_N-4.24.5.js"></script>
  ```

:::info[信息]
在以上方法中，SDK 都会在全局导出一个 `AgoraRTC` 对象，直接访问这个对象即可操作 SDK。
:::
