语音转文字 Demo，主要结合以下基础能力：

- 实时语音交互产品 RTC
- 实时消息产品 RTM
- 语音转文字产品 RTT

展示以下功能：

- 实时字幕
- 实时翻译
- 字幕云存储
- 回放字幕
- 实时音视频互通

- 发布时间：2024-05-01

### 使用指南

#### 环境准备

1. 请参考 [开通服务](/zh-CN/realtime-media/rtc/build/setup-and-access/enable-service?platform=web) 以了解如何获取 App ID 和 App 证书（必须启用证书）。
2. 在控制台开通 RTM 服务。
3. 联系技术支持以激活 RTT 权限。点击 [联系技术支持](https://ticket.shengwang.cn/)。

找到 `.env` 文件并根据指引填入参数。

#### 安装依赖

在项目路径运行以下命令以安装依赖项。

```bash
npm install
```

#### 开发

运行以下命令启动开发环境。

```bash
npm run dev
```

#### 编译

运行以下命令以编译示例项目。

```bash
npm run build
```
