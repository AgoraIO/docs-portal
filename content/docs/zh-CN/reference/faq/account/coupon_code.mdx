---
title: "如何使用套餐包抵扣码？"
---
本文介绍如何在购买套餐包时使用优惠抵扣码。

:::info[信息]
你可以通过关注声网的市场活动、微信公众号等获取抵扣码的相关信息。
:::

**适用账户**：中国地区已实名认证的声网开发者账户。

**优惠策略**：使用抵扣码购买抵扣码活动对应的套餐包，即可抵扣相应金额。

**使用方法**：

1. 登录[控制台](https://console.shengwang.cn/)。

2. 点击左侧导航栏**套餐包**，进入**分钟数套餐包**页面。

3. 选择想要购买的套餐包，输入购买数量，点击**添加到购物车**，进入购物车中进行结算。

  ![](https://web-cdn.agora.io/doc-cms/uploads/1715583466996-buy-combo.png)

4. 勾选**我有抵扣码**，输入抵扣码，点击**应用**，即可对选购的套餐包抵扣相应的金额。点击**立即支付**，进入选择**支付方式**页面。

  ![](https://web-cdn.agora.io/doc-cms/uploads/1715582603016-coupon-code.png)

5. 选择支付方式，点击**立即支付**，完成付款。
