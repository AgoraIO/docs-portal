# 查看当前项目的用量

本文介绍如何在声网控制台查看项目用量。

成功开通某项服务后，你可以通过如下步骤查看用量：

1. 通过**功能配置**页下方的**前往查看**按钮查看当前项目的该项服务用量。

![查看当前项目用量](https://web-cdn.agora.io/doc-cms/uploads/1705905918280-product-usage.png)

2. 在**用量统计（当前项目）**标签页上，查看不同**产品类型**和**计量模型**的用量统计，并按需选择用量统计单位和时间范围。

![当前项目用量统计细节](https://web-cdn.agora.io/doc-cms/uploads/1705909520536-product-usage-details.png)

   如果项目涉及不同的用量类型（例如**观众**和**全部**用量），你可以在**用量类型**下拉框切换至想要查看的用量类型。

![切换用量类型](https://web-cdn.agora.io/doc-cms/uploads/1705910730849-switch-usage-type.png)

## 查看所有项目聚合用量

你可以点击**用量统计（当前项目）**标签页右侧的切换按钮，查看该服务在所有项目中的聚合用量。

![查看所有项目聚合用量](https://web-cdn.agora.io/doc-cms/uploads/1705910280477-switch-to-total-usage.png)
