# 查询 Token 信息

你可以在控制台左侧导航栏的辅助工具中点击 Token 生成/校验，然后在 Token 校验标签页查询你生成的 Token 相关信息，并校验相同参数配置下 Token 的一致性。

参考以下步骤查询 Token 信息：

1. 将要校验的 Token 粘贴至文本框内，点击**解析**按钮。

2. 即可在**解析结果**栏查看 Token 的详细信息。**解析结果**主要包含**产品**、**权限**和**过期时间**等信息。

## 校验 Token 一致性

你可以使用相同的参数配置，校验生成的 Token 是否一致。

需要填写以下参数：

- **Salt**：用于生成 Token 的随机值。
- **APPID**：声网为你的项目分配的唯一标识符。你可以在控制台**总览**页的**项目信息**栏查看并复制当前项目的 App ID。
- **证书**：声网控制台为开发项目生成的随机字符串，用于生成 Token。你可以在控制台**总览**页的**项目信息**栏查看并复制当前项目的主要证书。
