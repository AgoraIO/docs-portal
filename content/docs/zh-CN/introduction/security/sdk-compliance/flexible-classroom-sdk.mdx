## 一、概述

根据中国法律法规和监管部门规章要求，App 开发运营者在提供网络产品服务时应尊重和保护最终用户个人信息，不得违法违规收集使用个人信息，保证个人信息处理行为获得最终用户的授权同意，遵循最小必要原则，并采取有效的技术措施和组织措施确保个人信息安全。

为帮助开发者在使用 SDK 的过程中更好地落实用户个人信息保护相关要求，避免出现侵害用户个人信息权益情形，上海声网科技有限公司制定本 **灵动课堂 SDK** 合规使用说明。

### 2. SDK 初始化及业务功能调用时机说明

您应确保在登录注册页面及 App 首次运行时，通过简洁、明显且易于访问方式向最终用户告知涵盖个人信息处理主体、处理目的、处理方式、处理类型、保存期限等内容的 App 个人信息处理规则（App 隐私政策）。

您应确保在最终用户同意 App 隐私政策后，再进行灵动课堂 SDK 的初始化。并且，在用户同意隐私政策前，您应避免动态申请涉及用户个人信息的敏感设备权限；也应避免私自采集和上报个人信息。如果最终用户不同意 App 隐私政策，则不能初始化灵动课堂 SDK，无法使用 SDK 功能。

### 3. SDK 隐私政策披露要求与示例说明

请您根据集成灵动课堂 SDK 的实际情况，在您的 App 隐私政策中披露：第三方 SDK 名称、SDK 公司名称、SDK 使用目的和功能场景、SDK 涉及个人信息类型、实现 SDK 功能所需的权限、SDK 隐私政策链接。

请在您的 App 隐私政策中，以文字或列表的方式向公众披露第三方 SDK 的相关信息。

第三方 SDK 披露示例（仅供参考）：

#### Android 示例

- SDK 名称：灵动课堂 SDK
- SDK 公司名称：上海声网科技有限公司
- SDK 使用目的和功能场景：提供搭建线上实时互动课堂的能力
- SDK 涉及的个人信息类型：设备品牌、设备型号、操作系统版本、CPU 信息、内存使用情况、电池电量信息、屏幕分辨率、IP 地址、网络接入方式和类型、加速度传感器信息（设备屏幕旋转方向）、频道内用户 ID
- 实现 SDK 功能所需权限：摄像头、麦克风、麦克风设置、蓝牙连接、读取电话状态、访问网络、查看网络状态、查看 WiFi 状态
- SDK 隐私政策链接：[shengwang.cn/SDK-privacy-policy/](https://www.shengwang.cn/SDK-privacy-policy/)

#### iOS 示例

- SDK 名称：灵动课堂 SDK
- SDK 公司名称：上海声网科技有限公司
- SDK 使用目的和功能场景：提供搭建线上实时互动课堂的能力
- SDK 涉及的个人信息类型：设备品牌、设备型号、操作系统版本、CPU 信息、内存使用情况、电池电量信息、屏幕分辨率、IP 地址、网络接入方式和类型、加速度传感器信息（设备屏幕旋转方向）、频道内用户 ID
- 实现 SDK 功能所需权限：摄像头、麦克风、麦克风设置、蓝牙连接、读取电话状态、访问网络、查看网络状态、查看 WiFi 状态

### 4. 最终用户同意方式的建议方式说明

App 首次运行时应当有隐私弹窗，隐私弹窗中应公示隐私政策内容并附完整隐私政策链接，并明确提示最终用户阅读并选择是否同意隐私政策；隐私弹窗应提供同意按钮和拒绝同意的按钮，并由最终用户主动选择。

![App 隐私弹窗示例](https://web-cdn.agora.io/docs-portal/img/security/app-alert.png)

App 取得敏感权限前，应通过隐私弹窗获得用户单独授权同意（如：麦克风权限、摄像头权限等）。

### 5. 最终用户行使权利的配置说明

开发者在其 App 中集成灵动课堂 SDK 后，SDK 的正常运行会收集和处理必要的最终用户的个人信息用于提供 SDK 产品和服务目的。

SDK 提供以下接口配置，以便您帮助最终用户实现其个人信息权利的请求。在最终用户撤销同意处理其个人信息的授权时，您可以通过调用接口，停止和关闭 SDK 功能，并停止收集相应的用户数据。

App 开发者应根据相关法律法规为最终用户提供行使个人信息主体权利的路径功能，需要灵动课堂 SDK 配合的，请与 SDK 及时进行联系。

相关配置操作，请查阅相关配置文档：
- Android：[集成灵动课堂](/zh-CN/solutions/flexible-classroom/get-started/integrate)
- iOS：[集成灵动课堂](/zh-CN/solutions/flexible-classroom/get-started/integrate)

### 6. 开发者合规注意事项

- 在 App 隐私政策中清晰说明所集成 SDK 的名称、开发者名称、处理的个人信息类型、处理目的、处理方式和 SDK 隐私政策链接。
- 在最终用户同意 App 隐私政策后，再初始化并调用相关 SDK。
- 仅在实现业务功能所必需的场景下申请系统权限，并向最终用户说明权限用途。
- 如你的 App 面向未成年人、教育、医疗、金融等特殊场景，请结合适用法律法规补充更严格的合规措施。
