title: "使用技能集成"

你可以借助 AI Coding Agent 更高效地集成声网产品。通过配置 Shengwang skills，Coding Agent 可获得面向声网产品的任务路由、接入流程和生成规则，并结合最新官方文档内容，在需求分析、产品接入、代码生成和问题排查等场景中提供更准确、更高效的协助。

## 安装 Shengwang skills

选择以下方式安装 skills：

<TabsList>
  <TabsTrigger value="skills-cli">Skills CLI</TabsTrigger>
  <TabsTrigger value="claude-plugin">Claude Code Plugin Marketplace</TabsTrigger>
  <TabsTrigger value="openclaw-skills">OpenClaw</TabsTrigger>
</TabsList>

<TabsContent value="skills-cli">

使用 `CLI` 安装：

```bash
npx skills add Shengwang-Community/skills
```

这是最直接的安装方式。安装完成后，再按对应 Coding Agent 的说明重启会话或刷新技能列表。

</TabsContent>

<TabsContent value="claude-plugin">

在 `Claude Code` 中执行下面的命令安装：

```bash
plugin marketplace add Shengwang-Community/skills
```

</TabsContent>

<TabsContent value="openclaw-skills">

通过 `ClawHub` 安装：

```bash
clawhub install voice-ai-integration
clawhub update voice-ai-integration
```

首次安装使用 `install`，后续更新使用 `update`。

</TabsContent>
</Tabs>

## 最佳实践

完成 skills 配置后，你就可以直接在 Coding Agent 中描述接入、生成代码或排查问题等任务。Skills 会帮助 Coding Agent 选择合适的接入流程和生成规则，并补充最新的声网文档内容，从而让代码生成、配置说明和问题定位更准确。

- 在提示词中明确写出声网产品名称、目标平台、开发语言和目标功能。
- 尽量补充更多上下文信息，例如你当前的技术栈、已有代码、期望的交互流程、是否需要 Token、是否需要服务端示例等，这样 AI 更容易给出可直接落地的方案。
- 如果是在排查问题，尽量同时提供错误现象、复现步骤、报错日志、错误码，以及控制台截图或调用栈信息，便于 Coding Agent 更快缩小问题范围。
- 对于复杂任务，优先使用模型能力更强、功能支持更完整的 AI IDE，以获得更稳定的代码生成和问题分析效果。

## 提示词示例

完成 skills 配置后，可将以下内容作为提示词发给 Coding Agent，用于生成带实时字幕的 AI 语音对话示例项目：

```text
帮我做一个 AI 语音对话 Demo，用户打开网页后点击"开始对话"就能和 AI 语音交流，页面实时显示对话字幕。

## 技术栈

- 前端：Next.js + React + TypeScript + Tailwind CSS
- 后端：FastAPI (Python)

## 功能要求

1. 一键开始/结束语音对话
2. 实时显示用户和 AI 的对话字幕
3. 麦克风静音/取消静音
4. 显示 AI 状态（聆听中、思考中、说话中）
5. 系统日志面板
```
