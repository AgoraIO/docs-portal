配置 Agora MCP 后，AI Coding Agent 可以在回答问题、生成代码或排查问题前搜索声网官方文档，确认当前 SDK 方法、参数、快速开始流程和平台差异。

当任务的风险主要来自文档是否最新时，优先使用 Agora MCP。如果还需要 Agent 判断“先做什么”或“该走哪条官方路径”，可以同时配置 [Agora Skills](/zh-CN/introduction/skills-integrate)。

## 连接 Agora MCP

Agora MCP 的服务地址为 `https://mcp.agora.io`。

选择你的 AI 编程工具，并按对应方式连接 Agora MCP：

<TabsContent value="trae">

**手动配置：**

在 Trae 的 Settings > MCP 中手动添加以下配置：

```json
{
  "mcpServers": {
    "shengwang-docs": {
      "type": "http",
      "url": "https://doc-mcp.shengwang.cn/mcp"
    }
  }
}
```

</TabsContent>

## 可用工具

- `search-docs`：搜索相关文档。
- `list-docs`：浏览文档分类和文档列表。
- `get-doc-content`：读取指定文档的完整内容。

## 从提示词开始

配置完成后，让 AI Coding Agent 在生成代码前先查询声网官方文档。提示词中建议包含声网产品、目标平台和要完成的任务。

```text
使用 Agora MCP 查询网页端对话式 AI 的最新快速开始文档，并说明浏览器语音 Demo 的最小配置。
```

## 在工作流中使用

在 Agent Mode 下，你可以直接描述需求，由 AI Coding Agent 判断是否调用 Agora MCP。

如果你的 AI 编程工具支持在提示词中指定工具，也可以显式要求它先搜索并读取文档：

```text
#search-docs #get-doc-content 先搜索声网对话式 AI 文档，读取相关页面内容，再告诉我如何实现与 AI 智能体对话互动。
```
