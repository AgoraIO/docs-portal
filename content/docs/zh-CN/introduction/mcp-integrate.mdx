配置声网 MCP 后，AI 编程助手可以在回答问题、生成代码或排查问题前搜索声网官方文档，确认当前 SDK 方法、参数、快速开始流程和平台差异。

当任务需要查询最新文档时，使用声网 MCP。如果还需要助手判断“先做什么”或“该走哪条官方路径”，可以同时配置 [声网 Skills](/zh-CN/introduction/skills-integrate)。

## 使用 AI 助手问文档

如果只需要解释文档，可以使用 [DeepSeek](https://chat.deepseek.com/)、[豆包](https://www.doubao.com/chat/)、[千问](https://www.qianwen.com/)或 [Kimi](https://www.kimi.com/)：

1. 在要阅读的文档页打开“复制页面”的更多操作菜单。
2. 点击“复制 AI 提问内容”，复制包含页面正文的提问内容。
3. 打开 AI 助手，粘贴内容并补充你的问题。

需要助手自动调用文档查询工具时，请使用下面的 MCP 集成方式。

## 连接声网 MCP

声网 MCP 的服务地址为 `https://doc-mcp.shengwang.cn/mcp`。选择你的 AI 编程工具，按以下示例配置；其他支持使用 Streamable HTTP 传输的 MCP 客户端也可以使用同一地址。

<TabsContent value="trae">

在 TRAE 的 **设置 > MCP > 添加 > 手动添加** 中填入以下配置：

```json
{
  "mcpServers": {
    "shengwang-docs": {
      "url": "https://doc-mcp.shengwang.cn/mcp"
    }
  }
}
```

也可以将配置保存为项目根目录下的 `.trae/mcp.json`，并在 **设置 > MCP** 中启用项目级 MCP。随后在使用的智能体中启用 `shengwang-docs`。

配置方式见 [TRAE 官方 MCP 文档](https://docs.trae.cn/ide_add-mcp-servers)。

</TabsContent>

<TabsContent value="kimi-code">

将以下配置保存为项目根目录下的 `.kimi-code/mcp.json`：

```json
{
  "mcpServers": {
    "shengwang-docs": {
      "url": "https://doc-mcp.shengwang.cn/mcp"
    }
  }
}
```

如果希望在所有项目中使用，可以将同样的配置写入 `~/.kimi-code/mcp.json`。

保存后新建 Kimi Code 会话。在终端界面中运行 `/mcp`，检查 `shengwang-docs` 的连接状态；也可以使用 `/mcp-config` 交互式添加或编辑服务。

配置方式见 [Kimi Code 官方 MCP 文档](https://www.kimi.com/code/docs/kimi-code-cli/customization/mcp.html)。

</TabsContent>

<TabsContent value="codex">

在终端中运行以下命令添加服务：

```bash
codex mcp add shengwang-docs --url https://doc-mcp.shengwang.cn/mcp
```

也可以将以下配置加入用户级配置文件 `~/.codex/config.toml`：

```text title="config.toml"
[mcp_servers.shengwang-docs]
url = "https://doc-mcp.shengwang.cn/mcp"
```

如果只在当前项目中使用，将配置加入项目根目录的 `.codex/config.toml`；项目级配置仅在受信任的项目中加载。

运行 `codex mcp list` 确认服务已配置，并在 Codex 会话中使用 `/mcp` 查看连接状态。配置方式见 [Codex 官方 MCP 文档](https://developers.openai.com/codex/mcp/)。

</TabsContent>

<TabsContent value="claude-code">

在终端中运行以下命令，将服务添加到当前项目的 `.mcp.json`：

```bash
claude mcp add --transport http --scope project shengwang-docs https://doc-mcp.shengwang.cn/mcp
```

也可以手动将以下配置加入项目根目录的 `.mcp.json`：

```json
{
  "mcpServers": {
    "shengwang-docs": {
      "type": "http",
      "url": "https://doc-mcp.shengwang.cn/mcp"
    }
  }
}
```

如果希望在所有项目中使用，将命令中的 `--scope project` 改为 `--scope user`。在 Claude Code 中确认启用项目 MCP 服务后，使用 `/mcp` 查看连接状态。

配置方式见 [Claude Code 官方 MCP 文档](https://code.claude.com/docs/en/mcp)。

</TabsContent>

配置方式见 [Cursor 官方 MCP 文档](https://cursor.com/docs/mcp)。

<TabsContent value="vscode">

## 可用工具

- `search-docs`：搜索相关文档。
- `list-docs`：浏览文档分类和文档列表。
- `get-doc-content`：读取指定文档的完整内容。

## 从提示词开始

配置完成后，让 AI 编程助手在生成代码前先查询声网官方文档。提示词中建议包含声网产品、目标平台和要完成的任务。

```text
使用声网 MCP 查询网页端对话式 AI 引擎的最新快速开始文档，并说明浏览器语音 Demo 的最小配置。
```

如果需要指定查询工具，可以明确要求助手先搜索并读取文档：

```text
先调用 search-docs 搜索声网对话式 AI 引擎文档，再用 get-doc-content 读取相关页面，告诉我如何实现与 AI 智能体对话互动。
```
