# 注册账号

你可以按照本文的步骤快速开始使用声网控制台的基本功能。

1. 进入[声网注册页面](https://sso.shengwang.cn/login)，填写你的手机号码。

2. 阅读**服务条款**、**隐私政策**和**可接受使用政策**之后勾选已阅读并同意。

3. 点击**继续**，输入收到的验证码，然后点击**确认**。

4. 根据屏幕指引设置用户名和登录密码。完成后，你就拥有了声网用户账号。

5. 成功创建用户账号后，你可以点击右上角头像，在下拉菜单中进入**个人中心**页面，完善或更新更多个人信息，包括姓名、密码、手机、邮箱以及第三方登录方式、登录保护设置等。你也可以绑定第三方登录方式，方便快捷地登录声网控制台。

## 登录用户账号

你可以使用注册时填写的手机号码、邮箱或绑定的第三方账号进行登录。

## 创建/加入工作空间

如果你是第一次注册并登录控制台，完成登录后可以根据屏幕指引创建声网工作空间：

![创建工作空间](https://web-cdn.agora.io/docs-portal/img/console/create-workspace.png)

也可以接受其他工作空间的邀请并加入：

![接受邀请](https://web-cdn.agora.io/docs-portal/img/console/accept-invitation.png)

## 实名认证

根据国家互联网用户实名制相关要求，同时为了保护你的账号和资产安全，在创建声网项目和使用各项产品服务前，你必须先进行实名认证。

实名认证有两种方式：分别为个人实名认证和企业实名认证，具体步骤可参考[实名认证](/zh-CN/introduction/user-guides/user-identity-verification)。

## 创建项目

成功登录控制台后，按照以下步骤创建一个声网项目：

1. 展开控制台左上角下拉框，点击**创建项目**按钮。
2. 在弹出的对话框内，依次选择**项目类型**，输入**项目名称**，选择**场景标签**和**鉴权机制**。其中鉴权机制推荐选择**安全模式**，**调试模式**的安全性较低。

关于创建项目时的**鉴权方式**选择，可参考[管理鉴权方式](/zh-CN/introduction/user-guides/manage_authentication)。

## 开通服务

参考如下步骤开通声网服务：

1. 登录声网[控制台](https://console.shengwang.cn/)，点击左侧导航栏的**全部产品**，选择想要开通的产品。

2. 进入产品页面，切换到**功能配置**子页面。**功能配置**页面列出了和该产品相关的所有功能。

![相关功能配置](https://web-cdn.agora.io/doc-cms/uploads/1705907507921-product-related-functions.png)

3. 切换到想要开通的功能标签页，将**状态**选项设置为开启。

   以开启**实时互动 RTC** 产品的**云端录制**功能为例，在**功能配置**页面打开**云端录制**标签页，将**状态**选项设置为开启。

![开通云端录制](https://web-cdn.agora.io/doc-cms/uploads/1705905036731-enable-cloud-recording.png)

4. 成功开启该功能后，你可以在**功能配置**页面看到该功能标签上的绿色状态灯。你可以通过**功能配置**页标签的状态灯快速获取各功能的开启状态。

![项目开启绿灯](https://web-cdn.agora.io/doc-cms/uploads/1705908327494-green-banner.png)

## 获取开发参数

你可以根据需要在控制台的**总览页**获取各类开发参数。

- 在**项目信息栏**，你可以便捷地获取 App ID、生成临时 Token 以及查看和管理 App 证书。

- 在声网控制台点击右上角账户名，在下拉菜单中进入 **RESTful API** 页面获取客户 ID 和客户密钥。

## 查看产品用量

你可以在控制台**总览**页直接查看过去 7 天的 RTC 用量统计。如需了解当前项目更详细的用量统计信息，你可以点击**更多**进行查看。

关于每个产品的用量统计，你可以进入具体产品的**用量统计**页进行查看。具体详见[查看用量](/zh-CN/introduction/user-guides/usage)。

## 校验 Token

你可以点击**辅助工具**下的 **Token 生成/校验**菜单，在 **Token 校验**标签页查询你生成的 Token 相关信息以及校验相同参数配置下 Token 的一致性。

Token 校验的具体步骤可以参考 [Token 校验](/zh-CN/introduction/user-guides/token_authentication)。
