## 实时互动 AI 开发工具包

声网实时互动 AI 开发工具包提供一组开发工具和资源，帮助你使用 Codex、Claude Code、Cursor 等 AI 编程助手构建应用。应用所需的实时互动能力由声网 [SDK](/zh-CN/reference/sdks) 和 [API](/zh-CN/api-reference) 提供。

你可以用它创建新项目，也可以为已有应用接入音视频通话、互动直播和对话式 AI 功能。

工具包包括：

| 组件 | 用途 |
| --- | --- |
| [Skills](/zh-CN/introduction/skills-integrate) | 指导编程助手按照声网的开发流程和集成方式完成接入。 |
| [CLI](/zh-CN/introduction/agora-cli) | 创建项目、配置项目环境和排查本地环境问题。 |
| [MCP](/zh-CN/introduction/mcp-integrate) | 让编程助手搜索和读取最新声网官方文档。 |

## 接入流程

### 1. 安装 声网 CLI

声网 CLI 需要 Node.js 18 或更高版本。使用 npm 全局安装：

```bash
npm install -g agoraio-cli
```

安装完成后，运行以下命令确认 CLI 可用：

```bash
agora version
```

使用中国区区域参数登录：

```bash
agora login --region cn
```

### 2. 配置 声网 Skills

安装 [声网 Skills](/zh-CN/introduction/skills-integrate)，让 AI Coding Agent 在编辑代码前选择正确的声网工作流、Starter 和接入步骤。

<Tabs>
<TabsList>
  <TabsTrigger value="skills-cli">Skills CLI</TabsTrigger>
  <TabsTrigger value="manual">手动安装</TabsTrigger>
</TabsList>

<TabsContent value="skills-cli">

```bash
npx skills add AgoraIO/skills
```

</TabsContent>

<TabsContent value="manual">

克隆仓库，并将 AI Coding Agent 指向 声网 Skills 文件：

```bash
git clone https://github.com/AgoraIO/skills.git ~/agora-skills
```

使用 `skills/agora/` 作为目录入口；如果你的工具需要单个根文件，也可以直接加载 `SKILL.md`。

</TabsContent>
</Tabs>

如果你的工具偏好本地指令文件，请将它指向 `skills/agora/` 或顶层 `SKILL.md`。

如果你只需要文档查询能力，不需要工作流指导，可以只安装 [声网 MCP](/zh-CN/introduction/mcp-integrate)。如果希望 Agent 同时具备工作流选择和官方文档查询能力，建议同时配置 声网 Skills 和 声网 MCP。

### 3. 提示词

现在告诉 AI Coding Agent 你想构建什么，以及希望它如何处理接入流程。一个清晰的提示词应包含声网产品、目标平台、开发语言或 Starter 偏好，以及最终目标。

```text
使用 声网 Skills 帮我用 Python 构建一个网页端对话式 AI 引擎 Demo。
请先查询官方文档，选择合适的 Starter，并使用 声网 CLI 完成中国区项目配置。
```

接下来，让 AI Coding Agent 选择合适的 Starter，运行 `agora login --region cn`，初始化项目，并解释写入本地的环境变量。

## 如何判断配置成功

当 AI Coding Agent 能完成以下任务时，说明工作流已经进入正确状态：

- 使用 `agora login --region cn` 登录中国区。
- 使用 声网 CLI 创建或切换项目，并启用 `rtc` 和 `convoai` 能力。
- 将项目凭证写入本地 `.env` 文件。
- 按 声网 Skills 提供的流程选择合适的示例、SDK、Token 和服务端接入方式。
