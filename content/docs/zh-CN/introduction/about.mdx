## 声网是什么？

声网是全球实时音视频云服务开创者，为人与人、人与智能体、智能体与智能体的实时互动提供基础能力与云服务。开发者可以通过声网 API 和 SDK，在应用内快速构建对话式 AI、音视频通话、互动直播、实时协作和智能硬件等实时交互场景。

基于声网自建的底层实时传输网络 SD-RTN™，声网为实时音视频和数据流提供低延迟、高可靠的传输、路由、同步和会话管理能力，帮助开发者获得稳定、高性能的实时互动体验。

如果你还不确定该看哪个产品，建议先按业务目标选择入口。通常，每个场景通常是一组实时通信、AI、媒体处理和管理能力的组合。

| 你要构建的场景 | 通常需要的能力 | 建议入口 |

| 互动直播 / 语聊房 | RTC + RTM + 连麦 + 旁路推流 + 录制 + 内容审核 | [解决方案概览](/zh-CN/solutions/overview) |

## 场景如何组合能力

声网文档按场景组织入口，但底层能力可以复用。你可以先跑通最小链路，再按业务需要补充信令、录制、审核、转写、推流或观测能力。

- `RTC + RTM`：先把通话、直播或会话同步跑通，再补在线状态、信令和会控。
- `RTC + AI`：让语音智能体作为会话参与者进入实时房间，与用户进行语音或多模态交互。
- `RTC + 录制 / 转写 / 转码`：把直播、课堂或会议扩展成可回放、可搜索、可分发的流程。
- `RTSA + 设备`：把摄像头、麦克风、扬声器和设备控制接入实时链路。
- `场景化方案 + API 参考`：先按业务目标确定产品组合，再回到接口层细化实现。

## 产品文档

当你已经知道场景需要哪些能力，可以再按产品家族查找具体文档：

| 能力 | 代表产品 | 适合解决什么 |
| --- | --- | --- |
| 对话式 AI | 对话式 AI 引擎、对话式 AI 开发套件 | 让语音智能体进入实时会话，做助手、客服、陪练或设备对话。 |
| 实时互动基础能力 | RTC、RTM、RTSA、IM | 做通话、直播、消息同步、状态传递，以及设备侧实时接入。 |
| 会话后处理 | 云端录制、本地服务端录制、实时转录翻译、云端转码、旁路推流、输入在线媒体流、RTMP 网关 | 录制、字幕、转写、翻译、分发和内容转换。 |
| 协作与治理 | 互动白板、内容审核、SDK 拓展插件、RTC 服务端 SDK | 在会话里增加协作、控制、审核和自定义处理能力。 |
| 监测与分析 | 水晶球 | 监控、回溯和分析质量、用量和异常。 |
| 管理与工具 | 控制台、CLI、MCP、Skills、API 参考 | 管项目、找接口、做接入和自动化。 |

## 下一步

如果你已经确定业务场景，下一步通常是选择一个最小可运行路径：

- 构建 AI 语音助手或智能客服，进入[对话式 AI](/zh-CN/ai)。
- 构建通话、直播、消息同步或设备接入，进入[实时互动概览](/zh-CN/realtime-media/overview)。
- 按会议、教育、直播、语聊或智能硬件等业务目标选型，进入[解决方案概览](/zh-CN/solutions/overview)。
- 已经确定 SDK 或接口，进入 [API 参考](/zh-CN/api-reference/overview)。
