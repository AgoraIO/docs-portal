声网提供用于实时语音、视频和 AI 对话的 SDK 与云服务。你可以通过两种互动模型，把用户彼此连接起来，或把用户连接到 AI 智能体：

- **人与人互动**：使用**实时互动 RTC** 实现语音通话、视频通话和互动直播。
- **人与智能体互动**：让用户与**语音智能体**进行实时对话。

**对话式 AI 引擎**是声网用于构建语音智能体的产品。它会使用你配置的模型和工具运行对话，而**实时互动 RTC** 负责在用户和智能体之间传输实时音频。

## 声网平台如何工作

实时对话需要在已连接的参与者之间持续采集、传输和播放音频或视频。你的应用提供用户界面和业务逻辑：客户端 SDK 负责采集和播放媒体，你的后端负责管理访问权限和会话，声网服务负责在参与者之间传输媒体。在语音智能体场景中，对话式 AI 引擎还会使用你配置的模型和工具生成回复。

<a id="connect-people-with-rtc" />
<a id="human-to-human-realtime-communication" />

### 用户如何通过实时互动 RTC 连接

![RTC 客户端从你的后端获取凭证，加入同一个频道，并发布和订阅实时音视频。](/images/developer-journey/rtc-connection.svg)

同一个声网项目中的客户端加入同一个**频道**。频道是一组用于交换媒体的逻辑空间。**发布**表示发送音频或视频，**订阅**表示接收音频或视频。在双向通话中，双方都会发布和订阅。在互动直播中，主播发布媒体，观众订阅媒体。集成细节见[实时互动 RTC 概览](/zh-CN/realtime-media/rtc)。

<a id="connect-people-with-a-voice-agent" />
<a id="human-to-agent-voice-agent" />

### 用户如何连接到语音智能体

![你的后端使用 Agents SDK 启动或停止声网托管的对话式 AI 引擎会话。智能体加入 RTC 频道并与客户端交换音频。](/images/developer-journey/voice-agent-connection.svg)

你的后端使用 **Agents SDK** 启动和停止会话。声网托管的**对话式 AI 引擎**会把智能体加入 RTC 频道，并使用你配置的模型和工具生成回复。用户客户端和智能体通过实时互动 RTC 交换音频。

同一个应用可以同时支持**人与人互动**和**人与智能体互动**。如果需要了解模型选项、业务工具和 App 或设备集成方式，参考[对话式 AI 引擎概览](/zh-CN/ai)。

## 相关产品如何协同

实时互动 RTC 负责传输实时音频和视频。对话式 AI 引擎负责加入语音智能体。下面这些服务可以在实时互动基础上增加应用数据、媒体处理能力，或连接外部系统。按你的应用需要选择即可。

| 产品或集成 | 如何连接到你的应用 |
| --- | --- |
| [实时消息 RTM](/zh-CN/realtime-media/rtm) | 在 RTC 音视频之外交换应用消息、在线状态和共享状态。 |
| [即时通讯 IM](https://im.shengwang.cn) | 在语音和视频通话之外增加持久化的一对一或群组消息。 |
| [互动白板](/zh-CN/realtime-media/whiteboard) | 在参与者通过 RTC 交流时，提供共享画布、绘图和文档协作能力。 |
| [云端录制](/zh-CN/realtime-media/cloud-recording) | 将 RTC 音视频和语音智能体对话录制到云存储。 |
| [语音转写](/zh-CN/realtime-media/speech-to-text) | 将 RTC 音频转换为实时字幕、转写文本或翻译文本。 |
| [云端转码](/zh-CN/realtime-media/transcoding) | 对 RTC 音视频进行合流和转码，再把处理后的流发布回 RTC 频道。 |
| [输入在线媒体流](/zh-CN/realtime-media/media-pull) | 将在线媒体流输入 RTC 频道。 |
| [RTMP 网关](/zh-CN/realtime-media/rtmp-gateway) | 将 RTMP 或 SRT 媒体源接入 RTC 频道。 |
| [旁路推流](/zh-CN/realtime-media/media-push) | 将 RTC 音视频发送到 CDN 或外部直播平台。 |
| [RTC 服务端 SDK](/zh-CN/realtime-media/rtc-server-sdk) | 让你的服务端应用在 RTC 频道中发送和接收音视频。 |
| [水晶球](/zh-CN/realtime-media/usage-analytics) | 分析 RTC 通话用量和质量，帮助定位连接和媒体问题。 |

更多选项见[实时互动概览](/zh-CN/realtime-media/overview)。

**配置和访问权限。** 项目用于标识你的应用，每项服务都有自己的鉴权要求。项目凭证、客户端和服务端职责见[核心概念](/zh-CN/introduction/glossary)。

## 如何构建

先确认应用需要哪种互动方式，再选择开发流程。使用 AI 辅助开发或直接写代码，都可以构建实时互动 RTC 或语音智能体应用。

<a id="with-a-coding-assistant" />

### 使用 AI 构建

三个工具可以在开发过程中辅助你的 AI Coding Agent：

| 工具 | 作用 |
| --- | --- |
| [Agora Skills](/zh-CN/introduction/skills-integrate) | 提供声网相关的工作流和实现指导。 |
| [Agora CLI](/zh-CN/introduction/agora-cli) | 准备受支持的 Starter，配置项目，并诊断接入问题。 |
| [Agora MCP](/zh-CN/introduction/mcp-integrate) | 让 AI Coding Agent 查询声网文档。 |

[AI 快速接入](/zh-CN/introduction/start-with-ai)会把这些工具串成一个开发流程。**AI Coding Agent** 帮你编写应用，**语音智能体**则在应用中与用户对话。文档 MCP 服务于 AI Coding Agent，运行时 MCP 工具服务于语音智能体。

<a id="with-sdks-and-apis" />

### 使用代码构建

使用 RTC 客户端 SDK 让用户接入实时媒体，使用 Agents SDK 从后端控制对话式 AI 引擎会话。你可以从[对话式 AI 引擎快速开始](/zh-CN/ai/get-started/quick-start-agent)开始，也可以从[实时互动 RTC 快速开始](/zh-CN/realtime-media/rtc/get-started/quick-start)开始。
