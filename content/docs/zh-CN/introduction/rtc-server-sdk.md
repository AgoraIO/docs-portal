## 这项能力解决什么问题

RTC 服务端 SDK 部署在服务端，可与集成了 RTC 客户端 SDK 的应用通过 SD-RTN 进行实时通信，实现收发音视频流与服务端控制。

## 典型适用场景

- 服务端收发流
- 服务端混流或合图
- 云代理、权限与网络控制
- 需要后端参与 RTC 媒体处理的系统

## 推荐阅读路径

1. 先看产品首页，确认你的后端是否真的要直接参与媒体流。
2. 再跑通发送和接收媒体流的最小示例。
3. 后续再补合图、代理、String UID 与发布说明。

## 为什么应该放进能力区

很多团队并不是从客户端开始接入，而是从服务端链路、控制面和媒体流处理开始，所以 RTC 服务端 SDK 应该在能力区里有单独入口。
