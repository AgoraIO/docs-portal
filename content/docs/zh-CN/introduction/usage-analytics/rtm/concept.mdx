---
title: "名词解释"
---
本文解释云信令功能相关的指标含义。

## 用户指标

### 活跃用户数

指定时间范围内累计的活跃用户数量。

### 最高同时在线人数

指定时间范围内同时登录云信令系统的人数峰值。

## 消息量指标

### 消息发送数

指定时间范围内所有用户发送的消息数以及系统服务发送的事件通知消息数，单位为条。

### 消息接收数

指定时间范围内所有用户收到的消息数，消息包含其他用户发送的消息以及系统服务发送的事件通知消息，单位为条。

### 消息收发总数

消息发送数与消息接收数的和。

## 频道指标

### 活跃频道数

指定时间范围内累计的活跃频道数。至少有一个用户订阅或加入的频道称为活跃频道。

### 最高同时活跃频道数

指定时间范围内同时活跃频道数的峰值。至少有一个用户订阅或加入的频道称为活跃频道。

## Metadata 指标

User Metadata 指云信令中用户属性相关数据，Channel Metadata 指云信令中频道属性相关数据。

### User Metadata 操作次数

指定时间范围内所有客户端调用 API 操作 User Metadata 的次数。操作行为包括设置、获取、删除、更新等。

### User Metadata 错误数

指定时间范围内所有客户端调用 API 操作 User Metadata 发生错误的次数。

### User Metadata 错误率

User Metadata 错误数 ÷ User Metadata 操作次数 × 100%。

### Channel Metadata 操作次数

指定时间范围内所有客户端调用 API 操作 Channel Metadata 的次数。操作行为包括设置、获取、删除、更新等。

### Channel Metadata 错误数

指定时间范围内所有客户端调用 API 操作 Channel Metadata 发生错误的次数。

### Channel Metadata 错误率

Channel Metadata 错误数 ÷ Channel Metadata 操作次数 × 100%。

## 运行质量指标

### 登录成功率

**1 s/2 s/5 s 登录成功率** = 用户在 1 s/2 s/5 s 内成功登录云信令系统的次数 ÷ 总登录次数① × 100%。

① 总登录次数不包括因为用户操作不当而登录失败的次数。用户操作不当包括以下情况：

- App ID 失效
- Token 失效或过期
- 用户重复登录
- 登录超时
- 登录异常
- 签名验证失败
- 客户未激活云信令服务
- Token 使用错误，具体包括：
  - 没有开启 Token 鉴权时，使用了 Token
  - 开启鉴权后，没有使用 Token
