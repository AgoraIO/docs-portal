---
title: "数据洞察 Plus"
---
水晶球的**数据洞察**功能提供通话用量和质量数据的阶段性分析，帮助你了解用量和质量的总体趋势、不同维度的分布情况，以及每天、每小时、每分钟的数据明细。

目前，**数据洞察普通版**仅支持时序图查询分析与单维度查询分析。相比普通版，**数据洞察 Plus** 支持多维度交叉分析、采样分析和对比分析，且支持查询更多指标。数据洞察普通版和 Plus 版的功能对比详见[版本对比](/zh-CN/introduction/usage-analytics/overview/billing#数据洞察功能)。

## 使用步骤

按以下步骤使用数据洞察 Plus：

1. **订阅套餐**

   [订阅水晶球套餐包](/zh-CN/introduction/usage-analytics/overview/billing#订阅套餐包)，开通数据洞察 Plus 功能。

2. **进入数据洞察 Plus 页面**

   登录[控制台](https://console.shengwang.cn/)，点击左侧菜单栏中的**水晶球**，之后在水晶球页面的左侧菜单中选择 **RTC** 产品下的**数据洞察 Plus**。

   数据洞察 Plus 功能页分为**指标选择区**和**分析区**，其中分析区包含**全局筛选区**、**时序分析区**、**维度分析区**和**采样分析区**，它们的分布如下：

   ![数据洞察 Plus 页面布局示意图](https://web-cdn.agora.io/docs-files/1690856289849)

3. **选择要分析的指标**

   数据洞察 Plus 页面左侧为**指标选择区**，分为核心指标和全部指标：

   - **核心指标**下展示业务常用的七个核心指标和各指标对应的**聚合值**及**缩略图**，所有指标的解释详见[名词解释](#名词解释)。
	  - 聚合值：根据指标不同，展示选定时间范围（默认为最近一周）的总值（如通话数）、峰值（如并发通话数）或平均值（如 5 s 加入频道成功率）。
     - 缩略图：聚合值右侧为对应指标的缩略时序图（默认时间范围为最近一周），鼠标悬停于缩略图上任一点，可显示对应时间点与指标值。

	- **全部指标**下则展示了所有可进行分析的指标，你可根据产品和指标用途进行选择。所有指标的解释详见[名词解释](#名词解释)。

	点击任意指标后，该指标将作为**主分析指标**进行后续分析。

    :::info[信息]
    你可以点击指标选择区右上角的![折叠指标选择区](https://web-cdn.agora.io/docs-files/1687245932265)按钮折叠指标选择区，以便专注于后续分析。之后，你也可以点击![展开指标选择区](https://web-cdn.agora.io/docs-files/1687245969188)按钮重新展开指标选择区。
    :::

![指标选择区示意图](https://web-cdn.agora.io/docs-files/1688025816367)

4. **设置全局筛选条件**

   分析区顶部为**全局筛选区**。该区域的筛选条件对页面全局数据生效。

   ![全局筛选区示意图](https://web-cdn.agora.io/docs-files/1688026110869)

   - **维度筛选**：点击左侧**添加筛选**按钮即可在下拉框中选择维度进行筛选，最高支持同时选择三个维度。选择维度后，弹出的列表包含最多 200 条该维度下的值，这些可勾选的值会按近 5 天内各维度值对应通话活跃次数的总和从大到小排列，以供参考。

   - **时间筛选**：全局筛选区的右侧为时间选择器，可以自定义**时间范围**、**时间粒度**（按天/按小时）和**时区**（本地/ UTC 时间），支持最早查询 90 天内的数据，且单次最长查询范围为 30 天。

    :::info[信息]
    指标选择区的聚合值和缩略图仅遵守全局筛选中的时间筛选条件，而忽略维度筛选条件。
    :::

5. **开始分析**

   选择了需要分析的指标，并设定好全局筛选条件后，你就可以在右侧的**分析区**查看指标数据并开始分析了。

   数据洞察 Plus 支持**时序分析**，**维度分析**，**采样分析**，**对比分析**四种分析方式，下文将逐一介绍。

    :::error[警告]
    数据洞察 Plus 页面提供的数据仅供分析使用，不用作实际计费依据。
    :::

如果你想了解使用数据洞察 Plus 功能观测到异常数据后如何针对性排查问题，你可以参考[案例：常见问题排查指南](/zh-CN/introduction/usage-analytics/rtc/data-insight/troubleshooting)。

## 时序分析

分析区上方为**时序分析区**，展示在选定条件下，指标随时间变化的情况。

![时序分析区示意图](https://web-cdn.agora.io/docs-files/1690856315457)

时序分析包含以下功能：

- **联动全局筛选条件**：时序分析图展示的数据将根据全局筛选中的设定的时间和维度条件产生。
- **聚合值**：根据指标不同，展示选定时间范围的总值（如通话数）、峰值（如并发通话数）或平均值（如 500 ms 视频卡顿率）。
- **折线图互动**
  - 鼠标悬停于数据点：展示指标或维度分组名、时间和指标值。
  - 点击数据点
    - 查看小时级数据：以该数据点生成新的时序图，时间粒度切换为小时。
    - 维度分解：对该数据点进行维度分析。并发类指标不支持维度分解，如并发通话数、并发用户数。
    - 数据采样：对该数据点进行采样分析。目前仅音频卡顿率、视频卡顿率、网络传输延迟率支持数据采样。
- **辅助参考指标**：质量体验类指标（加入频道成功率、音频/视频卡顿率、网络延迟率）的时序图下方会额外展示辅助参考指标，用于辅助判断数据的有效性。鼠标悬停于辅助指标柱形图时展示该时间点的时间戳、指标/维度分组名和指标数值。

## 维度分析

数据洞察 Plus 页面分析区下方为**维度分析区**，展示在各维度下选定指标的分布情况。

![维度分析区示意图](https://web-cdn.agora.io/docs-files/1687246114788)

维度分析包含以下功能：

- **维度时间选择器**

  - 维度分析区拥有独立的时间选择器，其可选时间范围为时序分析区中选定的时间区间，时间粒度保持一致，即时序分析区的一个数据点。
  - 当时序分析图的时间区间选定后，维度分析默认展示该时间区间内最后一个数据点的维度分析结果。
  - 你可以在维度时间选择器中手动调整时间；也可以在时序分析图中点击数据点，然后选择**维度分解**来查看该点的维度分析结果。

- **快捷分布**：选择主分析指标后，维度分析区将默认展示该指标的数个常用维度分布图。每个指标对应支持的维度不尽相同，每个维度展示的方式也有所区别，你可以自行探索。

- **单维度分析**：除快捷分布外，维度分析区左侧展示选中指标支持的分析维度，点击任意维度后，右侧将显示该维度的分析结果列表。

  ![单维度分析结果列表示意图](https://web-cdn.agora.io/docs-files/1687246135877)

- **联动全局筛选条件**：维度分析快捷分布中的图表和单维度分析的结果都将根据全局筛选中设定的筛选条件产生。

## 采样分析

当前仅支持对 **500 ms 视频卡顿率**、**200 ms 音频卡顿率**和**端到端网络传输延迟率**三个指标进行采样分析。在这三个指标的时序分析图中点击任意数据点，选择**数据采样**进行该数据点的采样分析。

![采样分析区示意图](https://web-cdn.agora.io/docs-files/1687246153475)

采样分析包含以下功能：

- **拖动滑块采样**：橙色采样滑块覆盖的时间区间为 30 分钟。拖动橙色滑块至曲线图任意位置后，下方将展示这 30 分钟内指标变化和梯度分布情况。点击右上方**退出采样**按钮可退出采样分析，重新选点采样。
- **堆叠柱形图**：滑块采样结果将以堆叠柱形图的形式展示这 30 分钟的指标分布情况，点击柱形中的色块可对该组数据进行用户采样。点击柱形图右侧颜色注释方块可取消展示/开启展示对应分组数据。
- **用户采样**
  - 点击柱形色块后，该组用户的相关信息将以列表的形式在下方展示，包括用户 ID、设备类型、网络类型等。最多展示 500 组数据。
  - 点击**详细信息**将跳转至对应通话的“通话调查-通话详情”页。通话详情页的介绍详见[查看通话详情](/zh-CN/introduction/usage-analytics/rtc/call-search/call-detail)。
  - 点击表头项目将以该项为基准对所有结果进行升序或降序排序。

## 对比分析

对比分析支持**指标对比**、**时间对比**和**全局对比**三种方式。在分析区右上角可找到对比分析按钮，点击并选择期望的分析方式后即可开始对比分析。

![对比分析](https://web-cdn.agora.io/docs-files/1688025988999)

### 指标对比

指标对比用于对比不同指标在同一时间段的变化趋势。

![指标对比示意图](https://web-cdn.agora.io/docs-files/1688025968440)

使用时需注意：

- 支持选择最多 3 个指标与主分析指标对比。
- 选择多指标并应用后将清空维度全局筛选条件以初始化对比模式，之后可重新添加维度全局筛选条件。
- 选择多指标并应用后，时序分析区展示多指标时序图，维度分析区的单维度分析展示多指标对应的维度数据。

### **时间对比**

时间对比用于比较同一指标在不同时间段的数据表现和变化趋势。

![时间对比示意图](https://web-cdn.agora.io/docs-files/1688025947576)

使用时需注意：

- 对比方式支持选择**与上周期比较**、**与上月比较**和**自定义时间**。以上图为例，时间选择器选择**最近 14 天**（2023-06-15 至 2023-06-29），三种比较方式的含义为：
  - 与上周期比较：与上个 14 天周期比较，即对比 2023-05-31 至 2023-06-14 的数据。
  - 与上月比较：与上个月的同时间段比较，即对比 2023-05-15 至 2023-05-29 的数据。
  - 自定义时间：自行选择对比周期，粒度为天，需保持选择天数与当前时间周期一致。本例中可选择一个跨度为 14 天的时间段进行对比。
- 所有对比时间周期的开始时间不得早于套餐包限制的最早查询时间。

### **全局对比**

全局对比用于对比某一指标在指定维度条件下的结果与无维度筛选条件下的结果，即全局结果。

![全局对比示意图](https://web-cdn.agora.io/docs-files/1688026063301)

:::info[信息]
全局对比仅在选择了主分析指标，且添加了维度筛选条件时生效。
:::

## 参考信息

### 名词解释

本节介绍数据洞察涉及的重要名词及解释。

#### 频道

使用声网 SDK 进行的所有通话都是在频道内发生的。我们把一个 App 比作一栋大楼的话，频道就好比大楼里面的一个房间。

#### 用户

频道中的每个用户都有唯一的用户 ID 用于标识在实时音视频互动频道中的用户。App ID 一致的前提下，用户 ID 是用户的唯一标识符。

数据洞察在统计用户人数时，会将相同频道名且相同用户 ID 的用户计为一个人。如果一个真实用户以不同的用户 ID 加入一个频道或者以相同的用户 ID 加入不同频道，均会被计算为多个用户。

<Slot for="plus-markdown-0-3-1">

<Slot for="plus-markdown-0-4-1">

端到端网络延迟率 = 音视频网络传输延时总时长 ÷ 音视频总时长 × 100%

</Slot>

####  维度

| 维度名称 | 维度说明                                             |
| :------- | :--------------------------------------------------- |
| 国家     | 用户所在的国家。                                     |
| 地域     | 用户所在的地区。                                     |
| 操作系统 | 用户使用的操作系统，如 Windows、iOS 等。             |
| 设备类型 | 用户使用的设备类型，如 iPad 7.5 等。                 |
| SDK 产品 | 用户通话使用的 SDK 产品，包括 RTC Native 和 Web SDK。 |
| SDK 版本 | 用户通话使用的 SDK 版本。                            |
| 网络类型 | 用户通话时使用的网络，如 Wi-Fi、4G 等。              |
