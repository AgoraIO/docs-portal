---
title: "如何为录制文件指定动态存储路径？"
---
在声网控制台通过 `fileNamePrefix` 字段配置录制文件存储路径时，你可以使用内置变量来指定动态路径用于存储录制文件。当录制发起时，会用真实的值替换变量。目前支持固定变量和日期变量。

## 固定变量

| 变量                        | 说明     |
|-------------------------------------------|---------------------------|
| `${appId}`                  | App ID |
| `${roomUuid}`                               | 待录制房间的 `Uuid`               |

## 日期变量

| 变量                        | 说明     |
|-------------------------------------------|---------------------------|
| `${yyyy}`                   | 年      |
| `${MM}`                                     | 月                         |
| `${dd}`                                     | 日                         |
| `${yyyyMMdd}`、`${yyyyMM}`、`${yyyy-dd}`、`${MM_dd}` 等 | 日期变量可组合，如年月日、年月、年-日、月_日等 |

例如，你可以将 `fileNamePrefix` 字段设为以下值：

```json
"fileNamePrefix": [
  "scenario",
  "recording",
  "${appId}",
  "${yyyyMM}",
  "${roomUuid}"
]
```

录制存储路径为 `/scenario/recording/xxxxxxxxx/202107/demo/xxxxxxx_demo_0.mp4`。
