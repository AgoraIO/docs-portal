`IRtcConnection` 类，用于管理 SDK 与 RTC 频道之间的连接。 连接完成之后，你可以通过 `ILocalUser` 对象在 RTC 频道中发送和接收媒体流。 连接频道是异步操作，你可以通过 [IRtcConnectionObserver](/zh-CN/api-reference/rtc-server-sdk/cpp-api/classagora-1-1rtc-1-1-i-rtc-connection-observer) 对象监听连接状态变化和事件。 `IRtcConnection` 还可以监控频道中的远端用户是否加入或离开频道。

### connect()

```cpp
virtual int agora::rtc::IRtcConnection::connect(const char* token, const char* channelId, user_id_t userId) pure virtual
```

连接 RTC 频道。

方法成功时，连接状态由 `CONNECTION_STATE_DISCONNECTED(1)` 变更为 `CONNECTION_STATE_CONNECTING(2)`。

根据连接是否成功，连接状态会变更为 `CONNECTION_STATE_CONNECTED(3)` 或 `CONNECTION_STATE_FAILED(5)`。 SDK 会触发 `onConnected` 或 `onDisconnected` 提醒连接状态变更。

#### Parameters

| Name | Description |
| --- | --- |
| token | RTC Token。详见 [使用 Token 鉴权](https://docs.agora.io/cn/Interactive%20Broadcast/token_server)。如果你的项目中未开启 App 证书，则仅需在该参数中填写你声网项目的 App ID。 |
| channelId | 频道名。必须为字符串且长度不超过 64 字节。支持的字符类型包括：<br />- 全部小写字母： a to z<br />- 全部大写字母：A to Z<br />- 全部阿拉伯数字： 0 to 9<br />- 空格。<br />- 标点符号和其他特殊符号： "!", "#", "$", "%", "&", "(", ")", "+", "-", ":", ";", "&lt;", "=", ".", "&gt;", "?", "@", "[", "]", "^", "_", " \{", "\}", "\|", "~", "," |
| userId | 本地用户 ID。长度不超过 64 字节。如果你不设置用户 ID 或设为 NULL，SDK 在 [onConnected](/zh-CN/api-reference/rtc-server-sdk/cpp-api/classagora-1-1rtc-1-1-i-rtc-connection-observer#a1df408778b1886055df47cd7d0ff8e5c) 回调中自动返回一个 user ID。 你必须自行记录并管理此 ID。根据你在 [initialize](/zh-CN/api-reference/rtc-server-sdk/cpp-api/classagora-1-1base-1-1-i-agora-service#a6f1fb6e792c564dee46903cbb3bc35fc) 方法中选择的用户 ID 类型，该参数支持的字符集也不同：<br />- int 型用户 ID 支持的字符集包括：<br />  - 10 个数字 0-9<br />- String 型用户 ID 支持的字符集包括：<br />  - 26 个小写英文字母 a-z<br />  - 26 个大写英文字母 A-Z<br />  - 10 个数字 0-9<br />  - 空格<br />  - "!", "#", "$", "%", "&", "(", ")", "+", "-", ":", ";", "&lt;", "=", ".", "&gt;", "?", "@", "[", "]", "^", "_", " \{", "\}", "\|", "~", "," |

#### Returns

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。
  - -2(ERR_INVALID_ARGUMENT)：参数无效。
  - -8(ERR_INVALID_STATE): 当前连接状态不是 CONNECTION_STATE_DISCONNECTED(1)。

### startLastmileProbeTest()

```cpp
virtual int agora::rtc::IRtcConnection::startLastmileProbeTest(const LastmileProbeConfig& config) pure virtual
```

开始通话前网络质量探测。

开始通话前网络质量探测，向用户反馈上下行网络的带宽、丢包、网络抖动和往返时延数据。

启用该方法后，SDK 会依次返回如下 2 个回调：

- onLastmileQuality: 视网络情况约 2 秒内返回。该回调通过打分反馈上下行网络质量，更贴近用户的主观感受。
- onLastmileProbeResult: 视网络情况约 30 秒内返回。该回调通过具体数据反馈上下行网络质量，更加客观。 ### `注解`
- 调用该方法后，在收到 onLastmileQuality 和 onLastmileProbeResult 回调之前请不要调用其他方法，否则可能会由于 API 操作过于频繁导致此方法无法执行。
- 在直播场景中，如果本地用户为主播，请勿加入频道后调用该方法。

#### Parameters

| Name | Description |
| --- | --- |
| config | Last mile 网络探测配置，详见 [LastmileProbeConfig](/zh-CN/api-reference/rtc-server-sdk/cpp-api/structagora-1-1rtc-1-1-lastmile-probe-config)。 |

#### Returns

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。

### createDataStream()

```cpp
virtual int agora::rtc::IRtcConnection::createDataStream(int* streamId, bool reliable, bool ordered, bool sync) pure virtual
```

创建数据流。

每个用户在每个频道中最多只能创建 5 个数据流。

##### `注解`

- 声网不支持你将 reliable 设为 true 且 ordered 设为 false。
- 当需要数据包立刻到达接收端时，不能将 ordered 参数设置为 true。
- 设置为与音频同步后，如果数据包的延迟在音频延迟的范围内，SDK 会在播放音频的同时触发与该音频包同步的 onStreamMessage 回调。 当需要数据包立刻到达接收端时，不能将 sync 参数设置为 true。声网推荐你仅在需要实现特殊场景，例如歌词同步时，设置为与音频同步。

#### Parameters

| Name | Description |
| --- | --- |
| streamId | 输出参数，数据流 ID。 |
| reliable | 该数据流是否可靠：<br />- true: 接收方 5 秒内会收到发送方所发送的数据。<br />- false: 接收方不保证收到，就算数据丢失也不会报错。 |
| ordered | 该数据流是否有序：<br />- true: 接收方会按照发送方发送的顺序收到数据包。<br />- false: 接收方不保证按照发送方发送的顺序收到数据包。 |
| sync | 是否与本地发送的音频流同步：<br />- true: 数据流与音频流同步。<br />- false: 数据流与音频流不同步。 |

#### Returns

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。

### sendStreamMessage()

```cpp
virtual int agora::rtc::IRtcConnection::sendStreamMessage(int streamId, const char* data, size_t length) pure virtual
```

发送数据流消息。

该方法发送数据流消息到频道内所有用户。SDK 对该方法的实现进行了如下限制：

- 频道内每秒最多能发送 30 个包，且每个包最大为 1 KB。
- 每个客户端每秒最多能发送 6 KB 数据。
- 频道内每人最多能同时有 5 个数据通道。

成功调用该方法后，远端会触发 [onStreamMessage](/zh-CN/api-reference/rtc-server-sdk/cpp-api/classagora-1-1rtc-1-1-i-local-user-observer#a0a0af52ad5ef54b08919df497b738f8b) 回调，远端用户可以在该回调中获取接收到的流消息。

##### `注解`

- 请确保在调用该方法前，已调用 createDataStream 创建了数据通道。
- 直播场景下，该方法仅适用于主播用户。

#### Parameters

| Name | Description |
| --- | --- |
| streamId | 数据流 ID。可以通过 `createDataStream` 获取。 |
| data | 待发送的数据。 |
| length | 数据长度。 |

#### Returns

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。

### enableEncryption()

```cpp
virtual int agora::rtc::IRtcConnection::enableEncryption(bool enabled, const EncryptionConfig& config) pure virtual
```

开启或关闭内置加密。

在安全要求较高的场景下，声网建议你在加入频道前，调用本方法开启内置加密。

同一频道内所有用户必须使用相同的加密模式和密钥。用户离开频道后，SDK 会自动关闭加密。如需重新开启加密，你需要在用户再次加入频道前调用该方法。

##### `注解`

- 如果开启了内置加密，则不能使用直推 CDN 功能。

#### Parameters

| Name | Description |
| --- | --- |
| enabled | 是否开启内置加密：<br />- true: 开启内置加密。<br />- false: 关闭内置加密。 |
| config | 配置内置加密模式和密钥。详见 [EncryptionConfig](/zh-CN/api-reference/rtc-server-sdk/cpp-api/structagora-1-1rtc-1-1-encryption-config)。 |

#### Returns

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。
