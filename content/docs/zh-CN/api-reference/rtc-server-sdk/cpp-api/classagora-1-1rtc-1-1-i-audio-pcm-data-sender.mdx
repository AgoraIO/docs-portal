### sendAudioPcmData()

```cpp
virtual int agora::rtc::IAudioPcmDataSender::sendAudioPcmData(const void* audio_data, uint32_t capture_timestamp, int64_t presentation_ms, const size_t samples_per_channel, const agora::rtc::BYTES_PER_SAMPLE bytes_per_sample, const size_t number_of_channels, const uint32_t sample_rate) pure virtual
```

将 PCM 格式的音频数据发送到本地音频轨道。

#### Parameters

| Name | Description |
| --- | --- |
| audio_data | 需要发送的 PCM 音频数据。 |
| capture_timestamp | 音频数据采集时间戳（毫秒）。 |
| presentation_ms | 音频数据发送时间戳（毫秒）。如果没有灵活控制音画同步时间戳的需求，你可以将该参数设置为 0。 |
| samples_per_channel | 对于每个声道，10 毫秒内采集的音频样本数。 |
| bytes_per_sample | 每个样本的字节数。 |
| number_of_channels | 每个样本的声道数。 |
| sample_rate | 采样率 (Hz)。最小值是 8000。 |

#### Returns

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。
