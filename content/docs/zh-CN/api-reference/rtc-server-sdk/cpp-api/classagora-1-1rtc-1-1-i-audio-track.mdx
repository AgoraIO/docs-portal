### addAudioSink()

```cpp

```

添加音频接收模块，用于从音频轨道获取 PCM 数据。

#### Parameters

| Name | Description |
| --- | --- |
| sink | 音频接收模块： [IAudioSinkBase](/zh-CN/api-reference/rtc-server-sdk/cpp-api/classagora-1-1rtc-1-1-i-audio-sink-base)。 |
| wants | 音频帧发送到接收模块时需要具备的属性。详见 [AudioSinkWants](/zh-CN/api-reference/rtc-server-sdk/cpp-api/structagora-1-1rtc-1-1-audio-sink-wants)。 |
| ares | 用于 SDK 的生命周期保护，填写默认值即可。 |

#### Returns

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。
