视频帧的属性设置。 视频数据的格式为 YUV420。缓冲区给出的是指向指针的指针，该接口不能修改缓冲区的指针，只能修改缓冲区的内容。

### rotation

```cpp
int agora::VideoFrame::rotation
```

在渲染视频前设置该帧的顺时针旋转角度，目前支持 0 度、90 度、180 度，和 270 度。

<a id="aae12f2c8b660aa8a058841fa8b34e1c5"></a>

### renderTimeMs

```cpp
int64_t agora::VideoFrame::renderTimeMs
```

外部音频帧的时间戳。该参数为必填。你可以使用该时间戳还原音频帧顺序；在有视频的场景中（包含使用外部视频源的场景），该参数可以帮助实现音视频同步。
