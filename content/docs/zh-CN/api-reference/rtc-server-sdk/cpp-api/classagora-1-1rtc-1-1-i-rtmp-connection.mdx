`IRtmpConnection` 类，用于管理 SDK 与 CDN 之间的连接。 连接完成之后，你可以通过 [IRtmpLocalUser](/zh-CN/api-reference/rtc-server-sdk/cpp-api/classagora-1-1rtc-1-1-i-rtmp-local-user) 对象在 CDN 中推流。 连接 CDN 是异步操作，你可以通过 [IRtmpConnectionObserver](/zh-CN/api-reference/rtc-server-sdk/cpp-api/classagora-1-1rtc-1-1-i-rtmp-connection-observer) 对象监听连接状态变化和事件。

### connect()

```cpp
virtual int agora::rtc::IRtmpConnection::connect(const char* url, aosl_ref_t ares = AOSL_REF_INVALID) pure virtual
```

连接 CDN。

成功调用该方法后，连接状态由 `STATE_DISCONNECTED(1)` 变更为 `STATE_CONNECTING(2)`。

根据连接是否成功，连接状态会有如下变化：

- 连接成功：连接状态变更为 STATE_CONNECTED(3)，SDK 会触发 onConnected 回调。
- 连接失败：连接状态变更为 STATE_FAILED(5)，SDK 会触发 onConnectionFailure 回调。

#### Parameters

| Name | Description |
| --- | --- |
| url | CDN 推流地址。格式为 RTMP。字符长度不能超过 1024 字节。不支持中文字符等特殊字符。 |
| ares | 用于 SDK 的生命周期保护，填写默认值即可。 |

#### Returns

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。
  - -2 (ERR_INVALID_ARGUMENT): 参数无效。
  - -8(ERR_INVALID_STATE): 当前连接状态不是 STATE_DISCONNECTED(1)。

### disconnect()

```cpp
virtual int agora::rtc::IRtmpConnection::disconnect(aosl_ref_t ares = AOSL_REF_INVALID) pure virtual
```

与 CDN 断开连接。

成功调用该方法后，连接状态变更为 `STATE_DISCONNECTED(1)`，同时 SDK 会触发 [onDisconnected](/zh-CN/api-reference/rtc-server-sdk/cpp-api/classagora-1-1rtc-1-1-i-rtmp-connection-observer#a676896b8556082f878cb2abfff4f60db) 回调。

#### Parameters

| Name | Description |
| --- | --- |
| ares | 用于 SDK 的生命周期保护，填写默认值即可。 |

#### Returns

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。
