### SetLocalAccessPoint()

```cpp
virtual int agora::rtc::IConfigCenter::SetLocalAccessPoint(const LocalAccessPointConfiguration& config) pure virtual
```

配置与声网私有媒体服务器接入模块的连接。

##### `自从`

4.2.30

成功部署声网私有媒体服务器并在内网终端集成 SDK 后，你可以调用该方法指定 Local Access Point，给 SDK 分配 Native 接入模块。

##### `注解`

- 该方法仅在部署声网混合云方案后生效。你可以联系 [sales@shengwang.cn](mailto:sales@shengwang.cn) 了解和部署声网混合云。
- 该方法需要在加入频道前调用。

#### Parameters

| Name | Description |
| --- | --- |
| config | Local Access Point 配置。详见 [LocalAccessPointConfiguration](/zh-CN/api-reference/rtc-server-sdk/cpp-api/structagora-1-1-local-access-point-configuration)。 |

#### Returns

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。
