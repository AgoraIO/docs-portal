### type

```cpp
VIDEO_STREAM_TYPE agora::rtc::VideoSubscriptionOptions::type
```

订阅的视频类型。

默认为 `VIDEO_STREAM_HIGH`，即视频大流。

<a id="abd960971e4de2f99b94e7580debb2605"></a>

### encodedFrameOnly

```cpp
bool agora::rtc::VideoSubscriptionOptions::encodedFrameOnly
```

是否仅订阅已编码的视频数据：

- true: 仅订阅已编码的视频数据。
- false: (Default) 仅订阅已解码的视频数据。
