### OnEncodedVideoImageReceived()

```cpp
virtual bool agora::rtc::IVideoEncodedImageReceiver::OnEncodedVideoImageReceived(const uint8_t* imageBuffer, size_t length, const EncodedVideoFrameInfo& videoEncodedFrameInfo) pure virtual
```

SDK 每次收到已编码视频帧时触发。

#### Parameters

| Name | Description |
| --- | --- |
| imageBuffer | 视频帧缓冲区。 |
| length | 视频帧数据长度。 |
| videoEncodedFrameInfo | 已编码视频帧的信息。 |

#### Returns

是否接受已编码视频帧。

- true: 接受已编码视频帧。
- false: 不接受已编码视频帧。
