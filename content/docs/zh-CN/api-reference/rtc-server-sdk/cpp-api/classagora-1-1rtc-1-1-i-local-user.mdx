`ILocalUser` 类。 定义了本地用户的行为和状态。 每个 RTC 连接都有自己的用户。你可以通过 [IRtcConnection::getLocalUser](/zh-CN/api-reference/rtc-server-sdk/cpp-api/classagora-1-1rtc-1-1-i-rtc-connection#a1cf54986a330713047da51c1503ec86c) 获取本地 user。 每个用户有两种角色: 主播 (能发送和接收音视频流) 和 观众 (只能接收音视频流)。

### setMixedAudioFrameParameters()

```cpp
virtual int agora::rtc::ILocalUser::setMixedAudioFrameParameters(size_t numberOfChannels, uint32_t sampleRateHz, int samplesPerCall = 0, aosl_ref_t ares = AOSL_REF_INVALID) pure virtual
```

设置 [onMixedAudioFrame](/zh-CN/api-reference/rtc-server-sdk/cpp-api/class-i-audio-frame-observer-base#a6b3f76a4245bf27b6a7c5cbc44f1c1dd) 报告的音频数据格式。

##### `注解`

SDK 会根据该方法设置的采样间隔（秒）定期触发 `onMixedAudioFrame` 回调。 采样间隔 = samplesPerCall/(sampleRate x channel)。请确保你的取值能满足采样间隔大于或等于 0.01 秒。

#### Parameters

| Name | Description |
| --- | --- |
| numberOfChannels | 音频数据声道数，可设置为 1（单声道） 或 2（双声道）。 |
| sampleRateHz | 音频数据采样率 (Hz)，可设置为 8000、 16000、32000、 44100 或 48000。 |
| samplesPerCall | 指定 `onMixedAudioFrame` 中返回数据的采样点数，如 RTMP/RTMPS 推流应用中通常为 1024。 |

#### Returns

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。
