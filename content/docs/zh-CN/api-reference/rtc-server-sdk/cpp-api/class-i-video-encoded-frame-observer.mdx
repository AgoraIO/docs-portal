### OnEncodedVideoFrame()

```cpp
virtual bool IVideoEncodedFrameObserver::OnEncodedVideoFrame(rtc::uid_t uid, const uint8_t* imageBuffer, size_t length, const rtc::EncodedVideoFrameInfo& videoEncodedFrameInfo) pure virtual
```

每次 SDK 收到已编码视频帧时触发。

#### Parameters

| Name | Description |
| --- | --- |
| uid | 远端用户的 ID。 |
| imageBuffer | 视频帧缓冲区。 |
| length | 视频帧数据长度。 |
| videoEncodedFrameInfo | 已编码视频帧信息。 |

#### Returns

是否接受已编码视频帧。

- true: 接受。
- false: 不接受。
