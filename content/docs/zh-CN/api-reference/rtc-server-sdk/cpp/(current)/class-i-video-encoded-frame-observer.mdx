| --- | --- |

每次 SDK 收到已编码视频帧时触发。

### 参数

| uid | 远端用户的 ID。 |
| --- | --- |
| imageBuffer | 视频帧缓冲区。 |
| length | 视频帧数据长度。 |
| videoEncodedFrameInfo | 已编码视频帧信息。 |

- true: 接受。
- false: 不接受。
