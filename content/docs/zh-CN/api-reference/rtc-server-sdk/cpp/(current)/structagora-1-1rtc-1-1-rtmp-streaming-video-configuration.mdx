## ◆width

| int agora::rtc::RtmpStreamingVideoConfiguration::width |
| --- |

视频宽度，单位为像素。默认值为 640。

### 注解

该参数与 `height` 参数决定的视频尺寸不会影响视频编码的方向模式。 如需设置视频编码的方向模式，详见 `orientationMode` 参数。

## ◆height

| int agora::rtc::RtmpStreamingVideoConfiguration::height |
| --- |

视频高度，单位为像素。默认值为 360。

### 注解

该参数与 `width` 参数决定的视频尺寸不会影响视频编码的方向模式。 如需设置视频编码的方向模式，详见 `orientationMode` 参数。
