## 详细描述

[`IVideoMixerSource`](/zh-CN/api-reference/rtc-server-sdk/cpp/classagora-1-1rtc-1-1-i-video-mixer-source) 类是一个多输入多输出视频源，可以从本地或远端接收多个视频轨道，并根据指定格式生成混合流。
