### addRenderer()

<ApiSignature labels="pure virtual">

virtual bool agora::rtc::IVideoTrack::addRenderer([agora_refptr](/zh-CN/api-reference/rtc-server-sdk/cpp/classagora-1-1agora-refptr)&lt; [IVideoSinkBase](/zh-CN/api-reference/rtc-server-sdk/cpp/classagora-1-1rtc-1-1-i-video-sink-base) &gt; *videoRenderer*, media::base::VIDEO_MODULE_POSITION *position* = `media::base::POSITION_POST_FILTERS`, aosl_ref_t *ares* = `AOSL_REF_INVALID`)

</ApiSignature>

将视频接收模块加入视频轨道，用于接收视频帧。

你可以通过以下方式添加视频接收模块：

- 通过实现 [`IMediaNodeFactory`](/zh-CN/api-reference/rtc-server-sdk/cpp/classagora-1-1rtc-1-1-i-media-node-factory) 类中的 `IVideoRenderer` 实现内置视频接收模块。
- 通过实现 [`IVideoSinkBase`](/zh-CN/api-reference/rtc-server-sdk/cpp/classagora-1-1rtc-1-1-i-video-sink-base) 类实现自定义视频接收模块。

<ParameterList title="参数">
<Parameter name="videoRenderer">

需要添加的视频接收模块: [IVideoSinkBase](/zh-CN/api-reference/rtc-server-sdk/cpp/classagora-1-1rtc-1-1-i-video-sink-base) 。

</Parameter>
<Parameter name="position">

视频接收模块添加的位置：VIDEO_MODULE_POSITION 。

</Parameter>
<Parameter name="ares">

用于 SDK 的生命周期保护，填写默认值即可。

</Parameter>
</ParameterList>

<h4 data-toc-hidden="true" id={"返回值"}>返回值</h4>

- `true`: 成功添加视频接收模块。
- `false`: 视频接收模块添加失败。
