## 详细描述

[`IRtmpConnection`](/zh-CN/api-reference/rtc-server-sdk/cpp/classagora-1-1rtc-1-1-i-rtmp-connection) 类，用于管理 SDK 与 CDN 之间的连接。

连接完成之后，你可以通过 [IRtmpLocalUser](/zh-CN/api-reference/rtc-server-sdk/cpp/classagora-1-1rtc-1-1-i-rtmp-local-user) 对象在 CDN 中推流。

连接 CDN 是异步操作，你可以通过 [IRtmpConnectionObserver](/zh-CN/api-reference/rtc-server-sdk/cpp/classagora-1-1rtc-1-1-i-rtmp-connection-observer) 对象监听连接状态变化和事件。

## ◆connect()

| virtual int agora::rtc::IRtmpConnection::connect ( const char * *url*, aosl_ref_t *ares* = `AOSL_REF_INVALID`) | pure virtual |
| --- | --- |

连接 CDN。

成功调用该方法后，连接状态由 `STATE_DISCONNECTED(1)` 变更为 `STATE_CONNECTING(2)`。

根据连接是否成功，连接状态会有如下变化：

- 连接成功：连接状态变更为 `STATE_CONNECTED(3)`，SDK 会触发 [onConnected](/zh-CN/api-reference/rtc-server-sdk/cpp/classagora-1-1rtc-1-1-i-rtmp-connection-observer#a4048ee1d38dff83649d33bfef93a30f6) 回调。
- 连接失败：连接状态变更为 `STATE_FAILED(5)`，SDK 会触发 [onConnectionFailure](/zh-CN/api-reference/rtc-server-sdk/cpp/classagora-1-1rtc-1-1-i-rtmp-connection-observer#a86658e80515ca6a85ebde8c230c71f16) 回调。

### 参数

| url | CDN 推流地址。格式为 RTMP。字符长度不能超过 1024 字节。不支持中文字符等特殊字符。 |
| --- | --- |
| ares | 用于 SDK 的生命周期保护，填写默认值即可。 |

### 返回

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。

  - -2 (`ERR_INVALID_ARGUMENT`): 参数无效。
  - -8(`ERR_INVALID_STATE`): 当前连接状态不是 `STATE_DISCONNECTED(1)`。
