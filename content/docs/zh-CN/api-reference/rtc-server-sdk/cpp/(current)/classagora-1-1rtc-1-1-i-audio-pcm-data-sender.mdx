### sendAudioPcmData()

| virtual int agora::rtc::IAudioPcmDataSender::sendAudioPcmData ( const void * *audio_data*, uint32_t *capture_timestamp*, int64_t *presentation_ms*, const size_t *samples_per_channel*, const [agora::rtc::BYTES_PER_SAMPLE](/zh-CN/api-reference/rtc-server-sdk/cpp/namespaceagora-1-1rtc#a74143af8b2847d195090020877e7369d) *bytes_per_sample*, const size_t *number_of_channels*, const uint32_t *sample_rate*) | pure virtual |

将 PCM 格式的音频数据发送到本地音频轨道。

<ParameterList title="参数">
<Parameter name="audio_data">

需要发送的 PCM 音频数据。

</Parameter>
<Parameter name="capture_timestamp">

音频数据采集时间戳（毫秒）。

</Parameter>
<Parameter name="presentation_ms">

音频数据发送时间戳（毫秒）。如果没有灵活控制音画同步时间戳的需求，你可以将该参数设置为 0。

</Parameter>
<Parameter name="samples_per_channel">

对于每个声道，10 毫秒内采集的音频样本数。

</Parameter>
<Parameter name="bytes_per_sample">

每个样本的字节数。

</Parameter>
<Parameter name="number_of_channels">

每个样本的声道数。

</Parameter>
<Parameter name="sample_rate">

采样率 (Hz)。最小值是 8000。

</Parameter>
</ParameterList>

<h4 data-toc-hidden="true" id={"返回值"}>返回值</h4>

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。
