## ◆SetLocalAccessPoint()

| virtual int agora::rtc::IConfigCenter::SetLocalAccessPoint ( const [LocalAccessPointConfiguration](/zh-CN/api-reference/rtc-server-sdk/cpp/structagora-1-1-local-access-point-configuration) & *config*) | pure virtual |
| --- | --- |

配置与声网私有媒体服务器接入模块的连接。

:::info[自从]
4.2.30
:::

成功部署声网私有媒体服务器并在内网终端集成 SDK 后，你可以调用该方法指定 Local Access Point，给 SDK 分配 Native 接入模块。

### 注解

- 该方法仅在部署声网混合云方案后生效。你可以联系 [sales.nosp@m.@she.nosp@m.ngwan.nosp@m.g.cn](/zh-CN/api-reference/rtc-server-sdk/cpp/classagora-1-1rtc-1-1-i-config-center) 了解和部署声网混合云。
- 该方法需要在加入频道前调用。

### 参数

| config | Local Access Point 配置。详见 [LocalAccessPointConfiguration](/zh-CN/api-reference/rtc-server-sdk/cpp/structagora-1-1-local-access-point-configuration)。 |
| --- | --- |

### 返回

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。
