## 详细描述

Last mile 网络探测配置。

## 类成员变量说明

<a id="a1e2faafc2b91e2f46a01afb2764dfc55"></a>

### probeUplink

<ApiSignature>

bool agora::rtc::LastmileProbeConfig::probeUplink

</ApiSignature>

是否探测上行网络。有些用户，如直播频道中的普通观众，不需要进行网络探测:

- true：探测。
- false：不探测。
