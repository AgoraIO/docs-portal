### encryptionKey

| const char* agora::rtc::EncryptionConfig::encryptionKey |
| --- |

内置加密密钥，字符串类型，长度无限制。声网推荐使用 32 字节的密钥。

:::info[注解]
如果未指定该参数或将该参数设置为空，则无法启用内置加密，且 SDK 会返回错误码 ERR_INVALID_ARGUMENT (-2) 。
:::
