### onPreEncodeVideoFrame()

<ApiSignature labels="pure virtual">

virtual bool IVideoFrameObserver::onPreEncodeVideoFrame([VideoFrame](/zh-CN/api-reference/rtc-server-sdk/cpp/class-i-video-frame-observer#af51dfbf9b64421e2cc0209cec4eded52) & *videoFrame*)

</ApiSignature>

获取本地视频编码前的视频数据。

成功注册视频数据 observer后，SDK 会在捕捉到每个视频帧时触发该回调。你可以在回调中获取编码前的视频数据，然后根据场景需要，对视频数据进行处理。

完成处理后，你可以在该回调中，传入处理后的视频数据将其发送回 SDK。

<ParameterList title="参数">
<Parameter name="videoFrame">

视频帧数据。

</Parameter>
</ParameterList>

<h4 data-toc-hidden="true" id={"返回值"}>返回值</h4>

如果视频前处理失败，是否忽略该帧视频：

- true: 不忽略。
- false: 忽略，则该帧数据不再发送回 SDK。
