### onReadyToSendMetadata()

<ApiSignature labels="pure virtual">

virtual bool agora::rtc::IMetadataObserver::onReadyToSendMetadata([Metadata](/zh-CN/api-reference/rtc-server-sdk/cpp/structagora-1-1rtc-1-1-i-metadata-observer-1-1-metadata) & *metadata*, [VIDEO_SOURCE_TYPE](/zh-CN/api-reference/rtc-server-sdk/cpp/namespaceagora-1-1rtc#ac6699b3c40e047af097d877115dde751) *source_type*)

SDK 准备发送 [Metadata](/zh-CN/api-reference/rtc-server-sdk/cpp/structagora-1-1rtc-1-1-i-metadata-observer-1-1-metadata) 时触发。将数据写入 SDK 提供的缓冲区，并设置大小。

:::info[注解]
[Metadata](/zh-CN/api-reference/rtc-server-sdk/cpp/structagora-1-1rtc-1-1-i-metadata-observer-1-1-metadata) 大小不得超过 getMaxMetadataSize 返回的值。
:::

<ParameterList title="参数">
<Parameter name="metadata" direction="[in,out]">

待发送的 Metadata。

</Parameter>
<Parameter name="source_type">

视频源类型：VIDEO_SOURCE_TYPE。

</Parameter>
</ParameterList>

<h4 data-toc-hidden="true" id={"返回值-1"}>返回值</h4>

`true`：发送 Metadata；`false`：不发送 Metadata。
