## 详细描述

[`ILocalUser`](/zh-CN/api-reference/rtc-server-sdk/cpp/classagora-1-1rtc-1-1-i-local-user) 类。 定义了本地用户的行为和状态。

每个 RTC 连接都有自己的用户。你可以通过 [IRtcConnection::getLocalUser](/zh-CN/api-reference/rtc-server-sdk/cpp/classagora-1-1rtc-1-1-i-rtc-connection#a1cf54986a330713047da51c1503ec86c) 获取本地 user。

每个用户有两种角色: 主播 (能发送和接收音视频流) 和 观众 (只能接收音视频流)。
