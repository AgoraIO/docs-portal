## 详细描述

[`IRtmpLocalUser`](/zh-CN/api-reference/rtc-server-sdk/cpp/classagora-1-1rtc-1-1-i-rtmp-local-user) 类。定义了 CDN 推流用户的行为和状态。

每个 CDN 连接都有自己的用户。你可以通过 [getRtmpLocalUser](/zh-CN/api-reference/rtc-server-sdk/cpp/classagora-1-1rtc-1-1-i-rtmp-connection#a87b6eedbf3b26da33c0f65135826349b) 获取本地用户对象的指针。

### adjustVideoBitrate()

<ApiSignature labels="pure virtual">

virtual void agora::rtc::IRtmpLocalUser::adjustVideoBitrate([VideoBitrateAdjustType](/zh-CN/api-reference/rtc-server-sdk/cpp/classagora-1-1rtc-1-1-i-rtmp-local-user#a692c5ab59e1da5664535c3f4df4789b6) *type*)

</ApiSignature>

调节主播端直接向 CDN 推流时的视频编码码率。

如果多次调用该方法，调节效果会叠加。以当前视频编码码率为 200 kbps 为例：

1. 调用该方法并设置 `type` 为 `Increasing`，则视频编码码率会增加 50 kbps，当前视频编码码率变为 250 kbps。
2. 再次调用该方法并设置 `type` 为 `Decreasing`，则视频编码码率会减少 100 kbps，当前视频编码码率变为 150 kbps。

<ParameterList title="参数">
<Parameter name="type">

视频编码码率的调节类型，详见 [VideoBitrateAdjustType](/zh-CN/api-reference/rtc-server-sdk/cpp/classagora-1-1rtc-1-1-i-rtmp-local-user#a692c5ab59e1da5664535c3f4df4789b6) 。

</Parameter>
