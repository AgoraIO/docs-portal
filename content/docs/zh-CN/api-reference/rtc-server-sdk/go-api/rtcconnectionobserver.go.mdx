<a id="onconnected"></a>
## OnConnected

```go
OnConnected func(con *RtcConnection, conInfo *RtcConnectionInfo, reason int)
```

<span className="index-desc-onconnected">SDK 与频道的连接状态变更为 `3` 时触发。</span>

#### 参数

| 参数 | 描述 |
| --- | --- |
| `con` | RTC 连接对象。详见 [`RtcConnection`](/zh-CN/api-reference/rtc-server-sdk/go-api/rtcconnection.go)。 |
| `conInfo` | 连接信息。详见 [`RtcConnectionInfo`](/zh-CN/api-reference/rtc-server-sdk/go-api/apidatatype.go#rtcconninfo)。 |
| `reason` | <Slot name="rtcconnectionobserver-go-html-0-3-1" /> |

<Slot for="rtcconnectionobserver-go-html-0-3-1">

连接状态变更原因：

    - `0`: 建立网络连接中。
    - `1`: 成功加入频道。
    - `2`: 网络连接中断。
    - `3`: 网络连接被服务器禁止。
    - `4`: 加入频道失败。
    - `5`: 离开频道。
    - `6`: 不是有效的 APP ID。请更换有效的 APP ID 重新加入频道。
    - `7`: 不是有效的频道名。请更换有效的频道名重新加入频道。
    - `8`: 生成的 Token 无效。一般有以下原因：
      - 在控制台上启用了 App Certificate，但加入频道未使用 Token。当启用了 App Certificate，必须使用 Token。
      - 在调用 [`Connect`](/zh-CN/api-reference/rtc-server-sdk/go-api/rtcconnection.go#connect) 加入频道时指定的 uid 与生成 Token 时传入的 uid 不一致。
    - `9`: 生成的 Token 无效。
    - `10`: 此用户被服务器禁止。
    - `11`: 由于设置了代理服务器，SDK 尝试重连。
    - `12`: 更新 Token 引起网络连接状态改变。
    - `13`: 客户端 IP 地址变更，可能是由于网络类型，或网络运营商的 IP 或端口发生改变引起。
    - `14`: SDK 和服务器连接保活超时，进入自动重连状态。
    - `15`: 重新加入频道成功。
    - `16`: SDK 和服务器失去连接。
    - `17`: 连接状态变化由回声测试引起。
    - `18`: 用户更改了本地 IP 地址。

</Slot>

<a id="ontokenprivilegewillexpire"></a>
## OnTokenPrivilegeWillExpire

```go
OnTokenPrivilegeWillExpire func(con *RtcConnection, token string)
```

<span className="index-desc-ontokenprivilegewillexpire">Token 服务将在 30s 内过期回调。</span>

在通话过程中如果 Token 即将失效，SDK 会提前 30 秒触发该回调，提醒 app 更新 Token。
当收到该回调时，你需要重新在服务端生成新的 Token，然后调用 [`RenewToken`](/zh-CN/api-reference/rtc-server-sdk/go-api/rtcconnection.go#renewtoken) 将新生成的 Token 传给 SDK。

#### 参数

| 参数 | 描述 |
|---------------|------------|
| `con` | RTC 连接对象。详见 [`RtcConnection`](/zh-CN/api-reference/rtc-server-sdk/go-api/rtcconnection.go)。 |
| `token` | 即将过期的 Token。 |

```go
OnTokenPrivilegeDidExpire func(con *RtcConnection)
```

|---------------|------------|
| `con` | RTC 连接对象。详见 [`RtcConnection`](/zh-CN/api-reference/rtc-server-sdk/go-api/rtcconnection.go)。 |

## OnStreamMessageError

```go
OnStreamMessageError func(con *RtcConnection, uid string, streamId int, errCode int, missed int, cached int)
```

<span className="index-desc-onstreammessageerror">接收数据流消息发生错误的回调。该回调表示本地用户未收到远端用户调用 [`send_stream_message`](/zh-CN/api-reference/rtc-server-sdk/go-api/rtcconnection.go#sendstreammessage) 方法发送的流消息。</span>

#### 参数

| 参数        | 描述  |
|-------------|----------|
| `con` | RTC 连接对象。详见 [`RtcConnection`](/zh-CN/api-reference/rtc-server-sdk/go-api/rtcconnection.go)。 |
| `uid`   | 发送消息的用户 ID。              |
| `streamId` | 接收到的消息的 Stream ID。         |
| `errCode`      | 发生错误的错误码。                |
| `missed`    | 丢失的消息数量。                     |
| `cached`    | 数据流中断时，后面缓存的消息数量。          |

## OnError

```go
OnError func(con *RtcConnection, err int, msg string)
```

<span className="index-desc-onerror">发生错误回调。该回调方法表示 SDK 运行时出现了网络或媒体相关的错误。通常情况下，SDK 上报的错误意味着 SDK 无法自动恢复，需要 App 干预或提示用户。</span>

#### 参数

| 参数        | 描述  |
|-------------|----------|
| `con`   | RTC 连接对象。详见 [`RtcConnection`](/zh-CN/api-reference/rtc-server-sdk/go-api/rtcconnection.go)。              |
| `err` | 错误码。         |
| `msg`      | 错误描述。                |
