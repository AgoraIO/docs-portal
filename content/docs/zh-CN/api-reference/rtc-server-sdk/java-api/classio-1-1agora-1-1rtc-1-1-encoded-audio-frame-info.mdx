### EncodedAudioFrameInfo() [2/2]

```cpp
io.agora.rtc.EncodedAudioFrameInfo.EncodedAudioFrameInfo(int codec, int sampleRateHz, int samplesPerChannel, int numberOfChannels, EncodedAudioFrameAdvancedSettings advancedSettings, long captureTimeMs)
```

构造函数。

#### Parameters

| Name | Description |
| --- | --- |
| codec | 音频编码类型。<br />- 1：OPUS。<br />- 3：PCMA。<br />- 4：PCMU。<br />- 5：G722。<br />- 8：AAC LC。<br />- 9：HE AAC。<br />- 11：HEAAC2。 |
| sampleRateHz | 音频帧采样率（Hz）。 |
| samplesPerChannel | 每个声道的样本数。对于 aac 编码格式，默认为 1024；对于 Opus 编码格式，默认为 960。 |
| numberOfChannels | 音频帧的声道数。 |
| advancedSettings | 音频帧高级设置。 |
| captureTimeMs | 音频采集时间戳（毫秒）。 |
