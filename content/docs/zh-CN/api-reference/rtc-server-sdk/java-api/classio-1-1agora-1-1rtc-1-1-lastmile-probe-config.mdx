### LastmileProbeConfig() [2/2]

```cpp
io.agora.rtc.LastmileProbeConfig.LastmileProbeConfig(int probeUplink, int probeDownlink, int expectedUplinkBitrate, int expectedDownlinkBitrate)
```

构造函数。

#### Parameters

| Name | Description |
| --- | --- |
| probeUplink | 是否探测上行网络。有些用户，如直播频道中的普通观众，不需要进行网络探测：<br />- 0: 探测<br />- 1: 不探测 |
| probeDownlink | 是否探测下行网络：<br />- 0: 探测<br />- 1: 不探测 |
| expectedUplinkBitrate | 用户期望的最高发送码率，单位为 bps，范围为 [100000, 5000000]。声网推荐参考 setVideoEncoderConfiguration 中的码率值设置该参数的值。 |
| expectedDownlinkBitrate | 用户期望的最高接收码率，单位为 bps，范围为 [100000, 5000000]。 |
