### EncodedVideoFrameInfo() [2/2]

```cpp
io.agora.rtc.EncodedVideoFrameInfo.EncodedVideoFrameInfo(int codecType, int width, int height, int framesPerSecond, int frameType, int rotation, int trackId, long captureTimeMs, long renderTimeMs, long internalSendTs, int uid, int streamType)
```

构造函数。

#### Parameters

| Name | Description |
| --- | --- |
| codecType | 视频编码类型<br />- 0：无。<br />- 1：VP8。<br />- 2：H.264。<br />- 3：H.265。<br />- 5：VP9。<br />- 6：Generic。<br />- 7：Generic H264。<br />- 12：AV1。<br />- 20：JPEG。 |
| width | 视频宽度（像素）。 |
| height | 视频高度（像素）。 |
| framesPerSecond | 每秒的视频帧数量。用于计算编码视频帧的时间戳。 |
| frameType | 已编码视频帧类型。<br />- 0：空白帧。<br />- 3：关键帧。对于 H.264 编码格式，SDK 把带有 sps 和 pps 信息的 I 帧归类为关键帧。<br />- 4：Delta 帧。对于 H.264 编码格式，SDK 把 P 帧和不带 sps 和 pps 信息的 I 帧都归类为 Delta 帧。<br />- 5：B 帧。<br />- 6：丢弃帧。<br />- 7：未知。 |
| rotation | 已编码视频帧旋转信息。<br />- 0：顺时针旋转 0 度。<br />- 90：顺时针旋转 90 度。<br />- 180：顺时针旋转 180 度。<br />- 270：顺时针旋转 270 度。 |
| trackId | 视频帧的轨道 ID。 |
| captureTimeMs | 视频采集时间戳（毫秒）。 |
| renderTimeMs | 视频渲染时间戳（毫秒）。 |
| internalSendTs | 该时间戳用于音视频同步。你可以通过 [onEncodedVideoImageReceived](/zh-CN/api-reference/rtc-server-sdk/java-api/interfaceio-1-1agora-1-1rtc-1-1-i-video-encoded-image-receiver#a5cdf9fc01442f7799c9b8034b808438d) 回调获取。 encodedFrameOnly 需要设为 0。 |
| uid | 用户 ID。 |
| streamType | 视频流类型。<br />- VIDEO_STREAM_HIGH (0): 视频大流，即高分辨率、高码率视频流。<br />- VIDEO_STREAM_LOW (1): 视频小流，即低分辨率、低码率视频流。 |
