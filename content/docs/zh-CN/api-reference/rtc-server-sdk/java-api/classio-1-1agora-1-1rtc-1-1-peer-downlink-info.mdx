### PeerDownlinkInfo() [2/2]

```cpp
io.agora.rtc.PeerDownlinkInfo.PeerDownlinkInfo(java.lang.String uid, int streamType, int currentDownscaleLevel, int expectedBitrateBps)
```

构造函数。

#### Parameters

| Name | Description |
| --- | --- |
| uid | 远端视频流的用户 ID。 |
| streamType | 远端视频流类型：<br />- 0: 大流。分辨率和码率较高。<br />- 1: 小流。分辨率和码率较低。 |
| currentDownscaleLevel | 远端视频缩小程度。远端视频缩小级别。级别越高，缩小程度越高。<br />- 0: 不缩小。<br />- 1: 级别 1。<br />- 2: 级别 2。<br />- 3: 级别 3。<br />- 4: 级别 4。 |
| expectedBitrateBps | The expected bitrate in bps. |
