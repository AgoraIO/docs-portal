### onEncodedVideoFrame()

```cpp
int io.agora.rtc.IVideoEncodedFrameObserver.onEncodedVideoFrame(AgoraVideoEncodedFrameObserver observer, int userId, ByteBuffer buffer, EncodedVideoFrameInfo info)
```

接收到远端用户编码后的视频数据回调。

##### `注解`

为保证数据传输效率，视频数据缓存使用 DirectByteBuffer 类型。请确保同步提取回调中的 Byte 数组的值，然后将其发送到非同步线程进行处理。

#### Parameters

| Name | Description |
| --- | --- |
| observer | [AgoraVideoEncodedFrameObserver](/zh-CN/api-reference/rtc-server-sdk/java-api/classio-1-1agora-1-1rtc-1-1-agora-video-encoded-frame-observer)。 |
| userId | 远端用户 ID。 |
| buffer | 编码后的视频数据缓存。 |
| info | 编码后的视频数据信息： [EncodedVideoFrameInfo](/zh-CN/api-reference/rtc-server-sdk/java-api/classio-1-1agora-1-1rtc-1-1-encoded-video-frame-info)。 |

#### Returns

返回 0 或 1。返回值当前没有实际意义。
