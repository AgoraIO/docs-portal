
你需要在该方法中实现一个 AgoraMediaPacketReceiver 类。成功注册后，SDK 会在接收到音频包时触发 onMediaPacketReceived 回调。

#### Parameters

| Name | Description |
| --- | --- |
| agora_media_packet_receiver | AgoraMediaPacketReceiver 对象。 |

#### Returns

- 0: 方法调用成功。
