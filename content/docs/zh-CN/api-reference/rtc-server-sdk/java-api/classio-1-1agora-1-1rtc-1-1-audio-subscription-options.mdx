### AudioSubscriptionOptions() [2/2]

```cpp
io.agora.rtc.AudioSubscriptionOptions.AudioSubscriptionOptions(int packetOnly, int pcmDataOnly, int bytesPerSample, int numberOfChannels, int sampleRateHz)
```

构造函数。

##### `注解`

如果该参数设为 1，结构体中的其他参数无效。

#### Parameters

| Name | Description |
| --- | --- |
| packetOnly | 是否仅订阅音频包：<br />- 1: 仅订阅音频包。SDK 不会对音频进行解码。<br />- 0: (默认) SDK 自动对音频进行解码。 |
