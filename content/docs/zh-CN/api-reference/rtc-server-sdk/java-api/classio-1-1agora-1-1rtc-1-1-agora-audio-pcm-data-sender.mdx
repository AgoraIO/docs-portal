AgoraAudioPcmDataSender 类。 在涉及自定义音频源的场景中，你可以使用该类直接将 PCM 的音频数据发送至音频轨道。 如果音频轨道未启用，则发送的音频数据自动被丢弃。

### send()

```cpp
native int io.agora.rtc.AgoraAudioPcmDataSender.send(byte[] audio_data, int capture_timestamp, int samples_per_channel, int bytes_per_sample, int number_of_channels, int sample_rate)
```

将 PCM 音频数据发送至本地音频轨道。

##### `**[弃用](/zh-CN/api-reference/rtc-server-sdk/java-api/deprecated#_deprecated000001)**`

请改用 [sendAudioPcmData](#a1a109d7059fdffdfebfa9dc476957ab4)。

#### Parameters

| Name | Description |
| --- | --- |
| audio_data | 待发送的 PCM 音频数据。 |
| capture_timestamp | 音频帧的采集时间。 |
| samples_per_channel | 每个声道 10 ms 内的采样点数。 |
| bytes_per_sample | 每个采样点的字节数 (byte)。 |
| number_of_channels | 声道数。 |
| sample_rate | 采样率 (Hz)。最小值为 8000。 |

#### Returns

- 0: 方法调用成功
- &lt; 0: 方法调用失败
