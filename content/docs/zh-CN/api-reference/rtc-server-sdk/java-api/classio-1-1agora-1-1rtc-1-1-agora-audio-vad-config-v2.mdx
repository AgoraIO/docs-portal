### activePercent

```cpp
float io.agora.rtc.AgoraAudioVadConfigV2.activePercent private
```

<a id="aba466dc5a4f9f6502b31271e36fc4bb8"></a>

### inactivePercent

```cpp
float io.agora.rtc.AgoraAudioVadConfigV2.inactivePercent private
```

在 stopRecognizeCount 帧数中需要的非活跃音频帧的百分比，用来决定是否进入停止讲话状态。默认值为 0.5，也就是 50。取值范围 [0.0, 1.0]。

<a id="a64a99fbc0c1d9d0dbf2eb7cc6b1e3b99"></a>

### startRecognizeCount

```cpp
int io.agora.rtc.AgoraAudioVadConfigV2.startRecognizeCount private
```

确认正在讲话状态的音频帧数。默认值为 30，取值范围为 [1, 2^31 - 1]。

<a id="a2e2fdae56549df23b0466b6526380081"></a>

### startRmsThreshold

```cpp
int io.agora.rtc.AgoraAudioVadConfigV2.startRmsThreshold private
```

开始语音检测的 RMS 阈值。默认值为 -50，取值范围为 [-100, 0]。

指标的值越大，则语音活跃度检测越灵敏。

- 在安静环境中，可以设为 -50。
- 在嘈杂环境中，可以设为 -40 到 -30 之间。

<a id="a8177fabcf69f33d14733a2d7a961c42d"></a>

### startVoiceProb

```cpp
int io.agora.rtc.AgoraAudioVadConfigV2.startVoiceProb private
```

开始语音检测的概率阈值。默认值为 70，取值范围为 [0, 100]。

概率越低，音频帧越容易被判断为活跃状态，从而更早进入开始讲话状态； 反之，概率越高，音频帧越不容易被判断为活跃状态，从而更晚进入开始讲话状态。

<a id="a38f628ab2e80f21ad53c5c2047999738"></a>

<a id="a202eda18e370115b4f95d6b82730b9b1"></a>

### stopRmsThreshold

```cpp
int io.agora.rtc.AgoraAudioVadConfigV2.stopRmsThreshold private
```

停止语音检测的 RMS 阈值。默认值为 -50，取值范围为 [-100, 0]。

指标的值越大，则语音活跃度检测越灵敏。

- 在安静环境中，可以设为 -50。
- 在嘈杂环境中，可以设为 -40 到 -30 之间。

<a id="ae9899de018860ecb61e6ecfb1ed5eb7d"></a>

### stopVoiceProb

```cpp
int io.agora.rtc.AgoraAudioVadConfigV2.stopVoiceProb private
```

停止语音检测的概率阈值。默认值为 70，取值范围为 [0, 100]。

概率越低，音频帧越容易被判断为活跃状态，从而更晚进入停止讲话状态； 反之，概率越高，音频帧越不容易被判断为活跃状态，从而更早进入停止讲话状态。
