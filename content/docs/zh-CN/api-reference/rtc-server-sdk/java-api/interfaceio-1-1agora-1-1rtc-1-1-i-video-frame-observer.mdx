### onPreEncodeVideoFrame()

```cpp
int io.agora.rtc.IVideoFrameObserver.onPreEncodeVideoFrame(AgoraVideoFrameObserver agora_video_frame_observer, VideoFrame frame)
```

每次获取本地视频编码前的视频数据时触发。

成功注册视频数据 observer 后，SDK 会在捕捉到每个视频帧时触发该回调。你可以在回调中获取编码前的视频数据，然后根据场景需要，对视频数据进行处理。

完成处理后，你可以在该回调中，通过 videoFrame 参数传入处理后的视频数据将其发送回 SDK。

该回调获取的视频数据已经过预处理，即裁剪和旋转内容，优化图片。

#### Parameters

| Name | Description |
| --- | --- |
| agora_video_frame_observer | 一个 AgoraVideoFrameObserver 对象。 |
| frame | 视频帧数据。 |

#### Returns

如果视频前处理失败，是否忽略该帧视频：

- 0：不忽略。
- 1：忽略，则该帧数据不再发送回 SDK。

### onRenderVideoFrame()

```cpp
int io.agora.rtc.IVideoFrameObserver.onRenderVideoFrame(AgoraVideoFrameObserver agora_video_frame_observer, String channel_id, int uid, VideoFrame frame)
```

每次接收到远端用户发送的视频帧时触发。

成功注册视频数据 observer 后，SDK 会在接收到每个视频帧时触发该回调。你可以在回调中获取编码前的视频数据，然后根据场景需要，对视频数据进行后处理。

完成处理后，你可以在该回调中，通过 videoFrame 参数传入处理后的视频数据将其发送回 SDK。

#### Parameters

| Name | Description |
| --- | --- |
| agora_video_frame_observer | 一个 AgoraVideoFrameObserver 对象。 |
| channel_id | 频道名。 |
| uid | 发送该视频帧的远端用户的 ID。 |
| frame | 视频帧数据。 |

#### Returns

如果视频后处理失败，是否忽略该帧视频：

- true：不忽略。
- false：忽略，则该帧数据不再发送回 SDK。
