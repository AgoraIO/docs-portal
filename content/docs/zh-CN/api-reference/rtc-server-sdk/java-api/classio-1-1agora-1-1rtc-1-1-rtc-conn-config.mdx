### clientRoleType

```cpp
int io.agora.rtc.RtcConnConfig.clientRoleType private
```

用户角色：

- 1: 主播。主播可以同时发送和接收媒体流。
- 2:（默认）观众。观众只能接收媒体流。

### enableAudioRecordingOrPlayout

```cpp
int io.agora.rtc.RtcConnConfig.enableAudioRecordingOrPlayout private
```

是否开启音频录制或播放。

- 0: 仅用来播放不包含麦克风采集的外部音频数据，或用于无需音频播放的场景。
- 1: 开启音频录制或播放。
