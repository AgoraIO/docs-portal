---
title: "LocalUser 类"
---
<span className="index-desc-localuser">`LocalUser` 类。定义了本地用户的行为和状态。每个 RTC 连接都有自己的用户。你可以通过 [`get_local_user`](/zh-CN/api-reference/rtc-server-sdk/python-api/rtcconnection.python#getlocaluser) 获取本地用户。每个用户有两种角色：主播（能发送和接收音视频流）和观众（只能接收音视频流）。</span>

<a id="setuserrole"></a>
## set_user_role

```python
def set_user_role(self, role)
```

<span className="index-desc-setuserrole">设置用户角色。你可以在用户连接频道前或连接频道后调用该方法。</span>

:::warning[注意]
如果 [`connect`](/zh-CN/api-reference/rtc-server-sdk/python-api/rtcconnection.python#connect) 中的 `token` 与 `role` 参数设置的角色不同，连接会失败。
:::

#### 参数

| 参数 | 描述 |
| --- | --- |
| `role` | 用户角色。详见 [`ClientRoleType`](/zh-CN/api-reference/rtc-server-sdk/python-api/apidatatype.python#clientroletype)。 |

#### 返回值

- 0: 方法调用成功。
- < 0: 方法调用失败。

<a id="publishaudio"></a>
## publish_audio

```python
def publish_audio(self, agora_local_audio_track:LocalAudioTrack)
```

<span className="index-desc-publishaudio">将本地音频轨道发送到频道。默认情况下，所有发布的音频轨道都会进行混音。</span>

#### 参数

| 参数 | 描述 |
|---------------|----------------------------------------------------------------------|
| `agora_local_audio_track` | 需要发布的本地音频轨道。详见 [`LocalAudioTrack`](/zh-CN/api-reference/rtc-server-sdk/python-api/localaudiotrack.python)。 |

#### 返回值

- 0: 方法调用成功。
- < 0: 方法调用失败。
  - `-5`: 如果本地用户的角色不是主播，会返回此错误。
