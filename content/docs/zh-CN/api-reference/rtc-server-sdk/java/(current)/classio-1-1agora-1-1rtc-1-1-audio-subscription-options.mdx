构造函数。

### 参数

| packetOnly | 是否仅订阅音频包：1: 仅订阅音频包。SDK 不会对音频进行解码。 0: (默认) SDK 自动对音频进行解码。 |
| --- | --- |

### 注解

如果该参数设为 1，结构体中的其他参数无效。

### 参数

| pcmDataOnly | 是否仅订阅 PCM 数据：1: 仅订阅 PCM 数据。 0:（默认）SDK 自动对远端音频流进行编码。 |
| --- | --- |
| bytesPerSample | 每个音频采样的字节数。 |
| numberOfChannels | 音频声道数。 |
| sampleRateHz | 音频采样率（Hz）。 |
