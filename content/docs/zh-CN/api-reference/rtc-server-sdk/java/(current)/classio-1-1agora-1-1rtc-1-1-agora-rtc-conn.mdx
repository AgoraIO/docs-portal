<a id="details"></a>

<a id="header-details"></a>

AgoraRtcConn 类，用于管理 SDK 与 RTC 频道之间的连接。

连接完成之后，你可以通过 AgoraLocalUser 对象在 RTC 频道中发送和接收媒体流。

连接频道是异步操作，你可以通过 IRtcConnObserver 对象监听连接状态变化和事件。 AgoraRtcConn 还可以监控频道中的远端用户是否加入或离开频道。

### connect()

<ApiSignature>

native int io.agora.rtc.AgoraRtcConn.connect(String *token*, String *chan_id*, String *user_id*)

</ApiSignature>

连接 RTC 频道。

方法成功时，连接状态由 CONNECTION_STATE_DISCONNECTED(1) 变更为 CONNECTION_STATE_CONNECTING(2)。

根据连接是否成功，连接状态会变更为 CONNECTION_STATE_CONNECTED(3) 或 CONNECTION_STATE_FAILED(5)。SDK 会触发 onConnected 或 onDisconnected 提醒连接状态变更。

<ParameterList title="参数">
<Parameter name="token">

RTC token。

</Parameter>
<Parameter name="chan_id">

频道名。必须为字符串且长度不超过 64 字节。支持的字符类型包括：

- 全部小写字母： a to z
- 全部大写字母：A to Z
- 全部阿拉伯数字：0 to 9
- 空格
- 标点符号和其他特殊符号： "!", "#", "$", "%", "&", "(", ")", "+", "-", ":", ";", "&lt;", "=", ".", "&gt;", "?", "@", "[", "]", "^", "_", " \{", "\}", "|", "~", ","

</Parameter>
<Parameter name="user_id">

本地用户 ID。长度不超过 64 字节。如果你不设置用户 ID 或设为 null， SDK 在 [onConnected](/zh-CN/api-reference/rtc-server-sdk/java/interfaceio-1-1agora-1-1rtc-1-1-i-rtc-conn-observer#a4077abc157aa8be3c0060c97f394f48a) 回调中自动返回一个 user ID。你必须自行记录并管理此 ID。根据你在 initialize 方法中选择的用户 ID 类型，该参数支持的字符集也不同：

- int 型用户 ID 支持的字符集包括：

  - 10 个数字 0-9
- String 型用户 ID 支持的字符集包括：

  - 26 个小写英文字母 a-z
  - 26 个大写英文字母 A-Z
  - 10 个数字 0-9
  - 空格
  - "!", "#", "$", "%", "&", "(", ")", "+", "-", ":", ";", "&lt;", "=", ".", "&gt;", "?", "@", "[", "]", "^", "_", " \{", "\}", "|", "~", ","

</Parameter>
</ParameterList>

<h4 data-toc-hidden="true" id={"返回值"}>返回值</h4>

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。

### createDataStream()

<ApiSignature>

native int io.agora.rtc.AgoraRtcConn.createDataStream(Out *stream_id*, int *reliable*, int *ordered*)

</ApiSignature>

创建数据流。

每个用户在每个频道中最多只能创建 5 个数据流。

:::info[注解]
- 声网不支持你将 reliable 设为 1 且 ordered 设为 0。
- 当需要数据包立刻到达接收端时，不能将 ordered 参数设置为 0。
:::

<ParameterList title="参数">
<Parameter name="stream_id">

输出参数，数据流 ID。

</Parameter>
<Parameter name="reliable">

该数据流是否可靠：

- 0: 接收方 5 秒内会收到发送方所发送的数据。
- 1: 接收方不保证收到，就算数据丢失也不会报错。

</Parameter>
<Parameter name="ordered">

该数据流是否有序：

- 0: 接收方会按照发送方发送的顺序收到数据包。
- 1: 接收方不保证按照发送方发送的顺序收到数据包。

</Parameter>
</ParameterList>

<h4 data-toc-hidden="true" id={"返回值-1"}>返回值</h4>

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。

- 直播场景下，该方法仅适用于主播用户。
