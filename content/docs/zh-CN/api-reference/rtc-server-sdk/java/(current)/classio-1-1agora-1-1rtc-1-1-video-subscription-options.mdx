<ParameterList title="参数">
<Parameter name="type">

订阅的视频流类型。

- 0: 视频大流，分辨率和码率高。
- 1: 视频小流，分辨率和码率低。

</Parameter>
<Parameter name="encodedFrameOnly">

是否仅订阅视频编码数据：

- true：仅订阅视频编码数据。
- false：（默认）仅订阅视频解码数据。

</Parameter>
