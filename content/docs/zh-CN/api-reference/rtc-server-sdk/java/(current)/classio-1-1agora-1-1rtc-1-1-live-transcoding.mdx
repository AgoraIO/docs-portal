### LiveTranscoding() [2/2]

<ApiSignature>

io.agora.rtc.LiveTranscoding.LiveTranscoding(int *width*, int *height*, int *videoBitrate*, int *videoFrameRate*, int *lowLatency*, int *videoGop*, int *videoCodecProfile*, int *backgroundColor*, int *userCount*, [TranscodingUser](/zh-CN/api-reference/rtc-server-sdk/java/classio-1-1agora-1-1rtc-1-1-transcoding-user) *transcodingUsers*, java.lang.String *transcodingExtraInfo*, java.lang.String *metadata*, [RtcImage](/zh-CN/api-reference/rtc-server-sdk/java/classio-1-1agora-1-1rtc-1-1-rtc-image) *watermark*, int *watermarkCount*, [RtcImage](/zh-CN/api-reference/rtc-server-sdk/java/classio-1-1agora-1-1rtc-1-1-rtc-image) *backgroundImage*, int *backgroundImageCount*, int *audioSampleRate*, int *audioBitrate*, int *audioChannels*, int *audioCodecProfile*)

</ApiSignature>

构造函数。

<ParameterList title="参数">
<Parameter name="width">

推流视频的总宽度，默认值 360，单位为像素。

- 如果推视频流，width 不得低于 64；否则，声网服务器会自动调整为 64。
- 如果推音频流，width 和 height 需设为 0。

</Parameter>
<Parameter name="height">

推流视频的总高度，默认值 640，单位为像素。

- 如果推视频流，height 不得低于 64；否则，声网服务器会自动调整为 64。
- 如果推音频流，width 和 height 需设为 0。

</Parameter>
<Parameter name="videoBitrate">

推流视频的码率，单位为 Kbps，默认值为 400 Kbps。请参考 VideoEncoderConfiguration 中 bitrate 设置 videoBitrate。如果设置的码率超出合理范围，声网服务器会在合理区间内自动调整码率值。

</Parameter>
<Parameter name="videoFrameRate">

推流视频的帧率，单位为 fps，取值范围为 (0, 30]，默认值为 15 fps。服务器会将高于 30 的帧率设置改为 30。

</Parameter>
<Parameter name="lowLatency">

是否启用低延时模式：

- true: 低延时，不保证画质
- false: （默认值）高延时，保证画质

</Parameter>
<Parameter name="videoGop">

用于旁路直播的输出视频的 GOP，单位为帧。默认值为 30 帧。

</Parameter>
<Parameter name="videoCodecProfile">

用于旁路直播的输出视频的编解码规格

- 66: Baseline 级别的视频编码规格，一般用于视频通话、手机视频等。
- 77: Main 级别的视频编码规格，一般用于主流消费类电子产品，如 mp4、便携的视频播放器、PSP 和 iPad 等。
- 100: （默认）High 级别的视频编码规格，一般用于广播及视频碟片存储，高清电视。

</Parameter>
<Parameter name="backgroundColor">

用于旁路直播的输出视频的背景色，格式为 RGB 定义下的 Hex 值，不要带 # 号，如 0xFFB6C1 表示浅粉色。默认0x000000，黑色。

</Parameter>
<Parameter name="userCount">

旁路直播中的主播人数。

</Parameter>
<Parameter name="transcodingUsers">

参与旁路直播的视频转码合图的主播布局。

</Parameter>
<Parameter name="transcodingExtraInfo">

预留参数。 用户自定义的发送到旁路推流客户端的信息，用于填充 H264/H265 视频中 SEI 帧内容。

</Parameter>
<Parameter name="metadata">

发送给 CDN 客户端的 metadata。

</Parameter>
<Parameter name="watermark">

直播视频上的水印。必须为 PNG 格式。添加后所有旁路直播的观众都可以看到水印。

</Parameter>
<Parameter name="watermarkCount">

水印数量。该参数需与 watermark 一起使用。

</Parameter>
<Parameter name="backgroundImage">

直播视频上的背景图。必须为 PNG 格式。添加后所有旁路直播的观众都可以看到背景图片。

</Parameter>
<Parameter name="backgroundImageCount">

背景图数量。水印和背景图的总数量需大于等于 0 且小于等于 10。该参数需与 backgroundImage 一起使用。

</Parameter>
<Parameter name="audioSampleRate">

用于旁路直播的输出音频的采样率：

- 32000: 32 KHz
- 44100: 44.1 KHz
- 48000: 48 KHz

</Parameter>
<Parameter name="audioBitrate">

The bitrate (Kbps) of the audio output stream set for CDN live. The default value is 48 and the highest value is 128.

</Parameter>
<Parameter name="audioChannels">

用于旁路直播的输出音频的声道数，取值范围为 [1, 5] 中的整型，默认值为 1。建议取 1 或 2，其余三个选项需要特殊播放器支持。

</Parameter>
<Parameter name="audioCodecProfile">

用于旁路直播的输出音频的编解码规格：

- 0: （默认）LC-AAC 规格。
- 1: HE-AAC 规格。

</Parameter>
</ParameterList>
