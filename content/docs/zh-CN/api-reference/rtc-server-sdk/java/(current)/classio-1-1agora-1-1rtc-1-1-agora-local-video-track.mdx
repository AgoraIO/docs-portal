### setVideoEncoderConfig()

<ApiSignature>

native int io.agora.rtc.AgoraLocalVideoTrack.setVideoEncoderConfig([VideoEncoderConfig](/zh-CN/api-reference/rtc-server-sdk/java/classio-1-1agora-1-1rtc-1-1-video-encoder-config) *config*)

</ApiSignature>

设置视频编码属性。

视频编码属性对应一套视频参数，包括分辨率、帧率、码率和方向属性。

该方法中指定的属性是理想网络条件下的最大值。如果视频引擎因网络等问题无法按指定参数渲染视频，SDK 会取最接近最大值的那个值。

</Parameter>
</ParameterList>
