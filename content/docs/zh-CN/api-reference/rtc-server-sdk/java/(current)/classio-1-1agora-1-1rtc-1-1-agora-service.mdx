### setLogFile()

| native int io.agora.rtc.AgoraService.setLogFile | ( | String | *file_path*, |
| --- | --- | --- | --- |
|  |  | int | *file_size*) |

设置 SDK 日志文件的路径和大小。

默认情况下，SDK 会生成 2 个 SDK 日志文件，每个 SDK 日志文件的默认大小为 512 KB。如果你将 file_size 设为 1024 KB， SDK 会最多输出总计 2 MB 的日志文件。如果日志文件的总大小超过所设置的值，旧的日志会被新的日志覆盖。

:::info[注解]
为保证输出日志的完成性，声网建议你在调用 [initialize](/zh-CN/api-reference/rtc-server-sdk/java/classio-1-1agora-1-1rtc-1-1-agora-service#a822287e735267b7c8f1c9aee77cbb1c9) 方法后立即调用此方法。
:::

<ParameterList title="参数">
<Parameter name="file_path">

指向日志文件的指针。请确保指定的目录存在而且可写。

</Parameter>
<Parameter name="file_size">

SDK 日志文件的大小（KB）。

</Parameter>
</ParameterList>

### setLogFilter()

| native int io.agora.rtc.AgoraService.setLogFilter | ( | int | *filters* | ) |  |
| --- | --- | --- | --- | --- | --- |

设置日志输出等级。

日志级别顺序依次为 OFF、CRITICAL、ERROR、WARNING、INFO 和 DEBUG。

选择一个级别，你就可以看到在该级别之前所有级别的日志信息。 例如，你选择 WARNING 级别，就可以看到在 CRITICAL、ERROR 和 WARNING 级别上的所有日志信息。

<ParameterList title="参数">
<Parameter name="filters">

日志输出等级：

- LOG_LEVEL_NONE (0x0000): 不输出任何日志。
- LOG_LEVEL_INFO (0x0001): （推荐）输出 INFO 级别的日志信息。
- LOG_LEVEL_WARN (0x0002): 输出 WARN 级别的日志信息。
- LOG_LEVEL_ERROR (0x0004): 输出 ERROR 级别的日志信息。
- LOG_LEVEL_FATAL (0x0008): 输出 FATAL 级别的日志信息。

</Parameter>
</ParameterList>
