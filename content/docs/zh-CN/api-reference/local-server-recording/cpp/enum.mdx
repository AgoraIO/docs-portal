<a id="channel_profile_type"></a>
## CHANNEL_PROFILE_TYPE

频道场景。

#### 枚举值

| 枚举值 | 描述 |
| --- | --- |
| `CHANNEL_PROFILE_COMMUNICATION` | （0）：通信场景。优先保证通话流畅性，适用于一对一通话。 |
| `CHANNEL_PROFILE_LIVE_BROADCASTING` | （1）：（默认）极速直播场景。优先支持频道中有大量观众的直播场景。 |
| `CHANNEL_PROFILE_GAME` | （2）：游戏场景。该枚举值已废弃。 |
| `CHANNEL_PROFILE_CLOUD_GAMING` | （3）：云游戏场景。该枚举值已废弃。 |
| `CHANNEL_PROFILE_COMMUNICATION_1v1` | （4）：通信 1v1 场景。该枚举值已废弃。 |

<Slot for="enum-cpp-html-1-18-1">

（109）： Token 已过期，通常有以下原因：

    - Token 授权超时： Token 生成后必须在 24 小时内使用，否则会超时失效；
    - Token 权限过期：生成 Token 时设置的权限过期时间已到。例如设置为 7 天，则 Token 在使用后 7 天过期，届时无法访问声网服务，用户无法通话或被踢出频道。

    解决方案：无论是 Token 授权超时还是权限过期，都需要在服务器上重新生成 Token，并尝试重新加入频道。

</Slot>

<Slot for="enum-cpp-html-1-19-1">

（110）： Token 无效，通常有以下原因：

    - 项目启用了 App 证书但加入频道时未提供 Token；
    - 项目未启用 App 证书但尝试使用 Token 加入频道；
    - 用于生成 Token 的 App ID、用户 ID 和频道名与加入频道时使用的不一致。

    解决方案：加入频道前请检查项目是否启用了 App 证书，若启用则必须提供 Token，未启用则无需提供；使用 Token 加入频道时，请确保用于生成 Token 的 App ID 与初始化声网服务时使用的 App ID 一致，用户 ID 和频道名也需一致。

</Slot>

<a id="encryption_mode"></a>
## ENCRYPTION_MODE

内置加密模式。

声网推荐使用 `AES_128_GCM2` 或 `AES_256_GCM2` 加密模式。这两种模式支持使用 salt，以提供更高的安全性。

#### 枚举值

| 枚举值 | 描述 |
| --- | --- |
| `AES_128_XTS` | （1）：128 位 AES 加密，XTS 模式。 |
| `AES_128_ECB` | （2）：128 位 AES 加密，ECB 模式。 |
| `AES_256_XTS` | （3）：256 位 AES 加密，XTS 模式。 |
| `SM4_128_ECB` | （4）：128 位 SM4 加密，ECB 模式。 |
| `AES_128_GCM` | （5）：128 位 AES 加密，GCM 模式。 |
| `AES_256_GCM` | （6）：256 位 AES 加密，GCM 模式。 |
| `AES_128_GCM2` | （7）：（默认）128 位 AES 加密，GCM 模式。该模式需设置 salt（`encryptionKdfSalt`）。 |
| `AES_256_GCM2` | （8）：256 位 AES 加密，GCM 模式。该模式需设置 salt（`encryptionKdfSalt`）。 |
| `MODE_END` | （9）：枚举结束标志。 |

#### 枚举值

| `ENCRYPTION_ERROR_DECRYPTION_FAILURE` | （1）：媒体流解密失败。请确保接收端和发送端使用相同的加密模式和密钥。 |
| `ENCRYPTION_ERROR_ENCRYPTION_FAILURE` | （2）：媒体流加密失败。 |
| `ENCRYPTION_ERROR_DATASTREAM_DECRYPTION_FAILURE` | （3）：数据流解密失败。请确保接收端和发送端使用相同的加密模式和密钥。 |
| `ENCRYPTION_ERROR_DATASTREAM_ENCRYPTION_FAILURE` | （4）：数据流加密失败。 |
