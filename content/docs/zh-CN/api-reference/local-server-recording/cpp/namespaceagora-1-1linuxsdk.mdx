### LEAVE_PATH_CODE

```cpp
enum agora::linuxsdk::LEAVE_PATH_CODE
```

录制端离开频道的原因。将 `LEAVE_PATH_CODE` 与各枚举值逐一进行按位与运算，计算结果非零的，即为退出原因。例如，code 为 `6` （二进制 110）时，将其与各枚举值逐一进行按位与计算， `LEAVE_CODE_SIG` (二进制 10）与 `LEAVE_CODE_NO_USERS` (二进制 100）的结果非零，则退出原因包括收到 SIGINT 信号以及录制超时。

#### Values

| Name | Description |
| --- | --- |
| <a id="a9bed76add2c986c154d0ab761a7a07aca1db899a2146c02cce119b5d4c0eeedb2"></a> LEAVE_CODE_INIT | 0：初始化失败。 |
| <a id="a9bed76add2c986c154d0ab761a7a07aca7ffbd32955bc508166a6cef320ae95e7"></a> LEAVE_CODE_SIG | 2（二进制 10）：AgoraCoreService 收到 SIGINT 信号而触发的退出。 |
| <a id="a9bed76add2c986c154d0ab761a7a07aca67fb28084c8653162efefdb537f8c04d"></a> LEAVE_CODE_NO_USERS | 4（二进制 100）：频道内除录制端外没有其他用户，录制端自动离开频道。 |
| <a id="a9bed76add2c986c154d0ab761a7a07aca018d08044909bc0dfd09a42d11d177ae"></a> LEAVE_CODE_TIMER_CATCH | 8（二进制 1000）：可忽略。 |
| <a id="a9bed76add2c986c154d0ab761a7a07aca8941a7e5bb71f7ec6eeaa2e7d676dccd"></a> LEAVE_CODE_CLIENT_LEAVE | 16（二进制 10000）：录制端调用 [leaveChannel](/zh-CN/api-reference/local-server-recording/cpp/classagora-1-1recording-1-1-i-recording-engine#adafb45815ad0f02dc1c8b3cadb7cd2e3) 方法退出频道。 |
