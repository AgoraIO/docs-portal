屏幕（画布）的背景颜色。可根据所需颜色填写对应的 6 位 RGB 值，如 "#000000"。

##### `注解`

如果你调用 [joinChannel](/zh-CN/api-reference/local-server-recording/cpp/classagora-1-1recording-1-1-i-recording-engine#a011ff5c4a47816050be60b26ba0fb431) 方法加入频道时设置了 [Recordingconfig](/zh-CN/api-reference/local-server-recording/cpp/structagora-1-1recording-1-1-recording-config) 中的 [defaultVideoBg](/zh-CN/api-reference/local-server-recording/cpp/structagora-1-1recording-1-1-recording-config#abf37d73566b06c334822c77564912ac5) 参数， `backgroundColor` 不会生效。

### keepLastFrame

```cpp
bool agora::linuxsdk::VideoMixingLayout::keepLastFrame
```

用户（通信模式）/主播（直播模式）离开频道后，是否显示其视频的最后一帧：

- true: 显示视频最后一帧。
- false: （默认）不显示视频的最后一帧。

### wm_num

```cpp
uint32_t agora::linuxsdk::VideoMixingLayout::wm_num
```

设置水印的个数。

录制 SDK 最多支持 15 个水印，其中文字水印最多 10 个，时间戳水印最多 1 个，图片水印最多 4 个。
