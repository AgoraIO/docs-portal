用于录制声网 RTC 媒体流。

支持录制频道中的音视频流，提供流混合、加密和选择性订阅等功能。

## enableRecorderVideoFrameCapture

```java
public int enableRecorderVideoFrameCapture(boolean enable, RecorderVideoFrameCaptureConfig config)
```

启用或关闭录制器实例的视频帧采集功能。

启用该功能后，视频帧会根据配置的 [`VideoFrameCaptureType`](/zh-CN/api-reference/local-server-recording/java/enum#videoframecapturetype) 类型传递给观察者：

- `VIDEO_FORMAT_JPG_FILE_TYPE`

当使用 `VIDEO_FORMAT_JPG_FILE_TYPE` 类型时，必须在 [`RecorderVideoFrameCaptureConfig`](/zh-CN/api-reference/local-server-recording/java/struct#recordervideoframecaptureconfig) 中设置 `jpgFileStorePath` 和 `jpgCaptureIntervalInSec`。

| `enable` | `boolean` | <Slot name="agoramediartcrecorder-java-html-22-1-2" /> |

<Slot for="agoramediartcrecorder-java-html-22-1-2">
