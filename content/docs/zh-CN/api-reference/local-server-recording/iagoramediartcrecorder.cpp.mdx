<a id="initialize"></a>
## initialize

```cpp
virtual int initialize(base::IAgoraService* agora_service, bool enable_mix = true, bool recordEncodedOnly = false) = 0;
```

初始化录制器实例。

:::warning[注意]
- `recordEncodedOnly` 参数仅在 `enable_mix` 为 `false` 时有效。
- 如果你将 `recordEncodedOnly` 设为 `true`，则无法在录制过程中使用水印功能。
:::

#### 参数

| 参数 | 数据类型 | 描述 |
| --- | --- | --- |
| `agora_service` | `base::IAgoraService*` | 声网服务对象，请确保已完成初始化。详见 [`IAgoraService`](/zh-CN/api-reference/local-server-recording/iagoraservice.cpp)。 |
| `enable_mix` | `bool` | <Slot name="iagoramediartcrecorder-cpp-html-0-2-2" /> |
| `recordEncodedOnly` | `bool` | <Slot name="iagoramediartcrecorder-cpp-html-0-3-2" /> |

<Slot for="iagoramediartcrecorder-cpp-html-0-2-2">

录制时是否启用合流模式：

    - `true`：（默认）启用合流录制。
    - `false`：启用单流录制。

</Slot>

<Slot for="iagoramediartcrecorder-cpp-html-0-3-2">

是否仅录制编码后的视频：

    - `true`：接收到的视频不会被解码，视频数据将以编码格式录制。该模式下仅支持 H264 和 H265。
    - `false`：（默认）接收到的视频将被解码并重新编码。

</Slot>

#### 返回值

- 0：方法调用成功。
- < 0：方法调用失败。

<a id="enableencryption"></a>
## enableEncryption

```cpp
virtual int enableEncryption(bool enabled, const EncryptionConfig& config) = 0;
```

启用或禁用内置加密功能。

在高安全性场景下，建议你在加入频道前调用该方法启用内置加密功能。

同一频道内的所有用户必须使用相同的加密模式和加密密钥。当所有用户离开频道后，该频道的加密密钥会被自动清除。

#### 参数

| 参数 | 数据类型 | 描述 |
| --- | --- | --- |
| `enabled` | `bool` | <Slot name="iagoramediartcrecorder-cpp-html-2-1-2" /> |
| `config` | `const EncryptionConfig&` | 内置加密配置。详见 [`EncryptionConfig`](/zh-CN/api-reference/local-server-recording/struct.cpp#encryptionconfig)。 |

<Slot for="iagoramediartcrecorder-cpp-html-2-1-2">

是否启用内置加密功能：

    - `true`：启用内置加密功能。
    - `false`：（默认）禁用内置加密功能。

</Slot>

#### 返回值

- 0：方法调用成功。
- < 0：方法调用失败。

<a id="renewtoken"></a>
## renewToken

```cpp
virtual int renewToken(const char* token) = 0;
```

更新 Token。

 Token 在一段时间后会过期。你必须在以下任一情况下从服务器重新生成新的 Token，并调用该方法进行更新，否则 SDK 会断开与频道的连接：

- [`onError`](/zh-CN/api-reference/local-server-recording/iagoramediartcrecordereventhandler.cpp#onerror) 回调报告错误码 ERR_TOKEN_EXPIRED(109)。
- 触发 [`onTokenPrivilegeWillExpire`](/zh-CN/api-reference/local-server-recording/iagoramediartcrecordereventhandler.cpp#ontokenprivilegewillexpire) 回调。
- 触发 [`onTokenPrivilegeDidExpire`](/zh-CN/api-reference/local-server-recording/iagoramediartcrecordereventhandler.cpp#ontokenprivilegedidexpire) 回调。

#### 参数

| 参数 | 数据类型 | 描述 |
| --- | --- | --- |
| `token` | `const char*` | 指向新 Token 的指针。 |

#### 返回值

- 0：方法调用成功。
