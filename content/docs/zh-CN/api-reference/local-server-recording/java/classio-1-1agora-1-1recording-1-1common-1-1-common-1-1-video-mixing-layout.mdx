### backgroundColor

```cpp

```

如果你调用 [createChannel](/zh-CN/api-reference/local-server-recording/java/classio-1-1agora-1-1recording-1-1-recording-s-d-k#ae55bfee56ef78d93993e0d04d7b1402b) 方法加入频道时设置了 [RecordingConfig](/zh-CN/api-reference/local-server-recording/java/classio-1-1agora-1-1recording-1-1common-1-1-recording-config) 中的 [defaultVideoBgPath](/zh-CN/api-reference/local-server-recording/java/classio-1-1agora-1-1recording-1-1common-1-1-recording-config#a31ea0b5b53f3b396cb113918e2c7e138) 参数， `backgroundColor` 不会生效。

### keepLastFrame

```cpp
int io.agora.recording.common.Common.VideoMixingLayout.keepLastFrame = 0
```

用户（通信模式）/主播（直播模式）离开频道后，是否显示其视频的最后一帧：

- true: 显示视频最后一帧。
- false: （默认）不显示视频的最后一帧。
