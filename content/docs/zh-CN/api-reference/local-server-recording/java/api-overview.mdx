| API | 描述 |

|[`enableEncryption`](/zh-CN/api-reference/local-server-recording/java/agoramediartcrecorder.java#enableencryption) | 启用或禁用内置加密。 |
|[`subscribeAllAudio`](/zh-CN/api-reference/local-server-recording/java/agoramediartcrecorder.java#subscribeallaudio) | 订阅频道中所有远端用户的音频流。 |
|[`subscribeAllVideo`](/zh-CN/api-reference/local-server-recording/java/agoramediartcrecorder.java#subscribeallvideo) | 订阅频道中所有远端用户的视频流。 |
|[`unsubscribeAllAudio`](/zh-CN/api-reference/local-server-recording/java/agoramediartcrecorder.java#unsubscribeallaudio) | 停止订阅所有远端用户的音频流。 |
|[`unsubscribeAllVideo`](/zh-CN/api-reference/local-server-recording/java/agoramediartcrecorder.java#unsubscribeallvideo) | 停止订阅所有远端用户的视频流。 |
|[`subscribeAudio`](/zh-CN/api-reference/local-server-recording/java/agoramediartcrecorder.java#subscribeaudio) | 订阅指定远端用户的音频流。 |
|[`unsubscribeAudio`](/zh-CN/api-reference/local-server-recording/java/agoramediartcrecorder.java#unsubscribeaudio) | 停止订阅指定远端用户的音频流。 |
|[`subscribeVideo`](/zh-CN/api-reference/local-server-recording/java/agoramediartcrecorder.java#subscribevideo) | 订阅指定远端用户的视频流。 |
|[`unsubscribeVideo`](/zh-CN/api-reference/local-server-recording/java/agoramediartcrecorder.java#unsubscribevideo) | 停止订阅指定远端用户的视频流。 |
|[`setAudioVolumeIndicationParameters`](/zh-CN/api-reference/local-server-recording/java/agoramediartcrecorder.java#setaudiovolumeindicationparameters) | 设置 [`onAudioVolumeIndication`](/zh-CN/api-reference/local-server-recording/java/iagoramediartcrecordereventhandler#onaudiovolumeindication) 回调的时间间隔。 |
|[`setVideoMixingLayout`](/zh-CN/api-reference/local-server-recording/java/agoramediartcrecorder.java#setvideomixinglayout) | 设置视频合流布局。 |
|[`setRecorderConfig`](/zh-CN/api-reference/local-server-recording/java/agoramediartcrecorder.java#setrecorderconfig) | 配置录制器实例的设置。 |
|[`setRecorderConfigByUid`](/zh-CN/api-reference/local-server-recording/java/agoramediartcrecorder.java#setrecorderconfigbyuid) | 为指定用户设置录制器实例的配置。 |
|[`startRecording`](/zh-CN/api-reference/local-server-recording/java/agoramediartcrecorder.java#startrecording) | 启动录制过程。 |
|[`stopRecording`](/zh-CN/api-reference/local-server-recording/java/agoramediartcrecorder.java#stoprecording) | 停止所有正在进行的录制并保存录制文件。 |
|[`startSingleRecordingByUid`](/zh-CN/api-reference/local-server-recording/java/agoramediartcrecorder.java#startsinglerecordingbyuid) | 启动指定用户的录制流程。 |
|[`stopSingleRecordingByUid`](/zh-CN/api-reference/local-server-recording/java/agoramediartcrecorder.java#stopsinglerecordingbyuid) | 停止指定用户的录制进程。 |
|[`registerRecorderEventHandler`](/zh-CN/api-reference/local-server-recording/java/agoramediartcrecorder.java#registerrecordereventhandler) | 注册用于录制事件的事件处理器。 |
|[`unregisterRecorderEventHandler`](/zh-CN/api-reference/local-server-recording/java/agoramediartcrecorder.java#unregisterrecordereventhandler) | 取消注册之前注册的事件处理器。 |
|[`enableAndUpdateVideoWatermarks`](/zh-CN/api-reference/local-server-recording/java/agoramediartcrecorder.java#enableandupdatevideowatermarks) | 为视频流添加水印。 |
|[`disableVideoWatermarks`](/zh-CN/api-reference/local-server-recording/java/agoramediartcrecorder.java#disablevideowatermarks) | 禁用视频流中的水印。 |
|[`enableAndUpdateVideoWatermarksByUid`](/zh-CN/api-reference/local-server-recording/java/agoramediartcrecorder.java#enableandupdatevideowatermarksbyuid) | 为指定用户的视频流添加水印。 |
|[`disableVideoWatermarksByUid`](/zh-CN/api-reference/local-server-recording/java/agoramediartcrecorder.java#disablevideowatermarksbyuid) | 通过用户 ID 禁用其视频流上的水印。 |
|[`renewToken`](/zh-CN/api-reference/local-server-recording/java/agoramediartcrecorder.java#renewtoken) | 为当前会话更新 Token。 |
|[`enableRecorderVideoFrameCapture`](/zh-CN/api-reference/local-server-recording/java/agoramediartcrecorder.java#enablerecordervideoframecapture) | 启用或关闭录制器实例的视频帧采集功能。 |
|[`release`](/zh-CN/api-reference/local-server-recording/java/agoramediartcrecorder.java#release) | 释放与 `Recorder` 实例关联的原生资源。 |
