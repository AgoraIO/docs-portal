## 详细描述

设置频道模式。

### 注解

录制的频道模式必须和 Native SDK 或 Web SDK 设置的频道模式保持一致，否则可能导致问题。

## 类成员变量说明

<a id="aca8e80a441bc6d131f96536f1a5661e3"></a>

### CHANNEL_PROFILE_COMMUNICATION

| io.agora.recording.common.Common.CHANNEL_PROFILE_TYPE.CHANNEL_PROFILE_COMMUNICATION =(0) |
| --- |

0：通信（默认），即常见的 1 对 1 单聊或群聊，频道内任何用户可以自由说话。

<a id="a2ce4e4f37e8b1edeae6c171a099936bd"></a>

### CHANNEL_PROFILE_LIVE_BROADCASTING

| io.agora.recording.common.Common.CHANNEL_PROFILE_TYPE.CHANNEL_PROFILE_LIVE_BROADCASTING =(1) |
| --- |

1： 直播，有两种用户角色：主播和观众。主播可以发送和接收音视频，而观众只能接收音视频。
