## 详细描述

定义动态时间戳水印设置。

### 注解

- 时间戳显示录制服务器的当前时间，是动态变化的，显示形式为“2019\:06\:18 14\:30\:35"。
- 时间戳颜色为黑色或白色，会根据视频画布的颜色自动调整。若视频背景较暗，则颜色为白色；若视频背景较亮，则颜色为黑色。当视频背景不均匀时，颜色为黑白相间。
