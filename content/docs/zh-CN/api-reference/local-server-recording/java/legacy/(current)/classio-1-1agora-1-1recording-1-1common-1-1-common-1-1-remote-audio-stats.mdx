## 详细描述

远端音频流的统计信息。请参考远端音频流统计信息报告。

### quality

<ApiSignature>

int io.agora.recording.common.Common.RemoteAudioStats.quality = 0

</ApiSignature>

音频接收质量。

- 0: 质量未知。
- 1: 质量极好。
- 2: 用户主观感觉和 1 差不多，但码率可能略低于 1。
- 3: 用户主观感受有瑕疵但不影响沟通。
- 4: 勉强能沟通但不顺畅。
- 5: 网络质量非常差，基本不能沟通。
- 6: 网络连接已断开，完全无法沟通。
- 7: 暂时无法检测质量（未使用）。
- 8: 质量检测已开始，但还没完成。
