## 详细描述

定义图片水印设置。

## 类成员变量说明

<a id="a997210caff231fed7f4f54752027aa72"></a>

### imagePath

| String io.agora.recording.common.Common.ImageWatermarkConfig.imagePath = "" |
| --- |

指定图片文件路径。

:::info[注解]
- 只支持本地 PNG 格式的图片。
- 建议图片分辨率不超过 480p。
- 如果图片小于水印框，图片居中显示，不拉伸；如果图片大于水印框，图片等比缩小至合适水平，再居中显示。
:::

<a id="a5c783af39cd1ed2b05493dd824527b4a"></a>

### offsetX

| int io.agora.recording.common.Common.ImageWatermarkConfig.offsetX = 0 |
| --- |

水印框左上角与视频画布左上角的水平距离。单位为像素（pixel），默认值为 0。
