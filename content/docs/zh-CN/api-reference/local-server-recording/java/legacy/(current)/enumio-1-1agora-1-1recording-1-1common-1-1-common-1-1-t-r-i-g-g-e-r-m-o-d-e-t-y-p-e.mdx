## 类成员变量说明

### AUTOMATICALLY_MODE

<ApiSignature>

io.agora.recording.common.Common.TRIGGER_MODE_TYPE.AUTOMATICALLY_MODE =(0)

</ApiSignature>

0：（默认）自动模式。此模式下，录制端加入频道即开始录制，退出频道即停止录制。
