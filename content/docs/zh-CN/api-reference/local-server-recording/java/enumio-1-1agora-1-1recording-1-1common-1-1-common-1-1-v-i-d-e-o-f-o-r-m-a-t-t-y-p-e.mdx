视频解码格式。

## 类成员变量说明

<a id="aa644a407c98654a0c50179a42a7ead9e"></a>

### VIDEO_FORMAT_DEFAULT_TYPE

```cpp
io.agora.recording.common.Common.VIDEO_FORMAT_TYPE.VIDEO_FORMAT_DEFAULT_TYPE =(0)
```

0：默认视频格式。基于你的 codec 设置，默认视频格式可能为 MP4 或 WebM。

<a id="a8bc87d81a20691532eebc24a3fde1029"></a>

```cpp

```

1：原始视频数据 H.264 帧格式。

##### `**[弃用:](/zh-CN/api-reference/local-server-recording/java/deprecated#_deprecated000001)**`

从 v2.9.0 起废弃，请改用 VIDEO_FORMAT_ENCODED_FRAME_TYPE(1)。

### VIDEO_FORMAT_ENCODED_FRAME_TYPE

```cpp
io.agora.recording.common.Common.VIDEO_FORMAT_TYPE.VIDEO_FORMAT_ENCODED_FRAME_TYPE =(1)
```

1：原始视频数据 H.264 或 H.265 帧格式。如设置该格式，你可通过 [videoFrameReceived](/zh-CN/api-reference/local-server-recording/java/interfaceio-1-1agora-1-1recording-1-1-recording-event-handler#ae2e1e70d70f12bddf1ff01e255c0d800) 回调接收原始视频数据。

原始视频数据 H.264 或 H.265 帧格式。

<a id="afd82ee18fa3ebf8f1ce303e3455b483d"></a>

### VIDEO_FORMAT_JPG_VIDEO_FILE_TYPE

```cpp
io.agora.recording.common.Common.VIDEO_FORMAT_TYPE.VIDEO_FORMAT_JPG_VIDEO_FILE_TYPE =(5)
```

5：JPG 文件格式 + MP4 或 WebM 视频文件格式。

- 单流模式 (isMixingEnabled 为 false) 下，录制得到 MP4 或 WebM 视频文件，并截图获得 JPG 文件。
- 合流模式 (isMixingEnabled 为 true) 下，对合流录制，得到 MP4 或 WebM 视频文件，并对各单流截图，获得 JPG 文件。
