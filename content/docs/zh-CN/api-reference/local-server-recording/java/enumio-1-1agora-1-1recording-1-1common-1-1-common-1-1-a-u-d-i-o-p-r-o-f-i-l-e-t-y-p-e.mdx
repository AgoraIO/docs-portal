录制文件的音频编码配置。设置采样率，码率，编码模式和声道数。 只在合流模式（isMixingEnabled 为 true）下生效。

## 类成员变量说明

<a id="a00155eda83311532013d04f7c072ffd6"></a>

### AUDIO_PROFILE_DEFAULT

```cpp
io.agora.recording.common.Common.AUDIO_PROFILE_TYPE.AUDIO_PROFILE_DEFAULT =(0)
```

0：（默认）音频默认设置，采样率 48 KHz，单声道，编码码率为 48 Kbps。

<a id="ad3df0c05c965e1f2769a9e8f20353fc2"></a>

### AUDIO_PROFILE_HIGH_QUALITY

```cpp
io.agora.recording.common.Common.AUDIO_PROFILE_TYPE.AUDIO_PROFILE_HIGH_QUALITY =(1)
```

1：高音质模式，采样率 48 KHz，单声道，编码码率 128 Kbps。

<a id="afb54912877c95532e021d2301a785926"></a>

### AUDIO_PROFILE_HIGH_QUALITY_STEREO

```cpp
io.agora.recording.common.Common.AUDIO_PROFILE_TYPE.AUDIO_PROFILE_HIGH_QUALITY_STEREO =(2)
```

2：高音质立体声，采样率 48 KHz，双声道，编码码率 192 Kbps。
