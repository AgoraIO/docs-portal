public class AgoraServiceConfiguration {
    private boolean enableAudioProcessor = true;

<Slot for="struct-java-html-2-1-2">

是否启用音频处理模块。

    - `true`：（默认）启用音频处理模块。
    - `false`：禁用音频处理模块。禁用后无法创建音频轨道。

</Slot>

<Slot for="struct-java-html-2-2-2">

是否启用音频设备模块。

    - `true`：（默认）启用音频设备模块。
    - `false`：禁用音频设备模块。

    :::warning[注意]
    在录制场景下，确保将该参数设置为 `false`。如果设置为 `true`，SDK 会报错，因为录制器实例没有任何音频设备。
    :::

</Slot>

<Slot for="struct-java-html-2-3-2">

是否启用视频功能。

    - `true`：启用视频。
    - `false`：（默认）禁用视频。

</Slot>

<Slot for="struct-java-html-2-11-2">

是否启用字符串类型的用户 ID（`uid`）。

    - `true`：启用字符串类型的用户 ID。
    - `false`：（默认）不启用字符串类型的用户 ID。

</Slot>

<Slot for="struct-java-html-2-12-2">

是否使用当前线程中的 EGL 上下文，作为 SDK 的根 EGL 上下文，并被所有与 EGL 相关的模块共享，例如相机采集与视频渲染。

    - `true`：使用当前线程中的 EGL 上下文。
    - `false`：（默认）不使用当前线程中的 EGL 上下文。

    :::warning[注意]
    此属性仅适用于 Android 平台。
    :::

</Slot>

<Slot for="struct-java-html-2-13-2">

是否启用域名限制。

    - `true`：仅连接 DNS 已解析的服务器。
    - `false`：（默认）不限制服务器连接。

</Slot>
