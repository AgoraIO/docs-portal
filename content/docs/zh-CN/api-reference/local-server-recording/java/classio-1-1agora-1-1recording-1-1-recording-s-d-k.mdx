### createChannel()

```cpp
native boolean io.agora.recording.RecordingSDK.createChannel(String appId, String channelKey, String name, int uid, RecordingConfig config, int logLevel)
```

该方法创建并让录制端加入频道，随后开始录制。

#### Parameters

| Name | Description |
| --- | --- |
| appId | 录制端的 appId 必须与 Native/Web SDK 的保持一致。详见 [获取 App ID](https://docs.agora.io/cn/Recording/token?platform=All%20Platforms)。 |
| channelKey | 用于鉴权的动态密钥。录制端的动态密钥必须与 Native/Web SDK 的保持一致。如果 Native/Web SDK 用了 token，该参数必须设为 token。详见 [校验用户权限](https://docs.agora.io/cn/Recording/token?platform=All%20Platforms)。由于录制端暂时未开放 requestToken 和 renewToken 接口，在获取 Token 时，请务必将 [privilegeExpiredTs](https://docs.agora.io/cn/Recording/token_server) 设置为 0，表示权限一旦生成，永不过期。 |
| name | 待录制频道的频道名。 |
| uid | 录制使用的用户 UID。同一个频道里不能出现两个相同的 UID，否则会产生未定义行为。有两种设置方法：<br />- 设置为 0，系统将自动分配一个 UID。<br />- 设置一个唯一的 UID，不能与现在频道内的任何 UID 重复。取值范围：1 到 (2 32 -1)。 |
| config | 录制的详细设置。详见 [RecordingConfig](/zh-CN/api-reference/local-server-recording/java/classio-1-1agora-1-1recording-1-1common-1-1-recording-config)。 |
| logLevel | 生成 log 的等级。设置完成后，只有等级低于所设 logLevel 的 log 才会被生成：<br />- 1: 日志等级为 Fatal。<br />- 2: 日志等级为 Error。<br />- 3: 日志等级为 Warning。<br />- 4: 日志等级为 Notice。<br />- 5: 日志等级为 Info。<br />- 6: 日志等级为 Debug。 |

#### Returns

- 0：方法调用成功。
- &lt; 0：方法调用失败。

### createChannelWithUserAccount()

```cpp
native boolean io.agora.recording.RecordingSDK.createChannelWithUserAccount(String appId, String channelKey, String name, String userAccount, RecordingConfig config, int logLevel)
```

该方法允许录制端使用 User Account 加入频道。

录制端成功加入频道后，在本地触发 [onLocalUserRegistered](/zh-CN/api-reference/local-server-recording/java/interfaceio-1-1agora-1-1recording-1-1-recording-event-handler#a508670ebca9c30b673a962a23137a6a6) 和 [onJoinChannelSuccess](/zh-CN/api-reference/local-server-recording/java/interfaceio-1-1agora-1-1recording-1-1-recording-event-handler#a493b31ae39de3060a852f5e93b260eb4) 回调。

##### `注解`

为保证通信质量，我们建议一个频道内使用同一类型的数据标识用户身份，因此录制端的用户标识数据类型要与 Native/Web SDK 的保持一致。

#### Parameters

| Name | Description |
| --- | --- |
| appId | 录制端的 appId 必须与 Native/Web SDK 的保持一致。详见 [获取 App ID](https://docs.agora.io/cn/Recording/token?platform=All%20Platforms)。 |
| channelKey | 用于鉴权的动态密钥。录制端的动态密钥必须与 Native/Web SDK 保持一致。如果 Native/Web SDK 用了 token，该参数必须设为 token。详见 [校验用户权限](https://docs.agora.io/cn/Recording/token?platform=All%20Platforms)。 |
| name | 待录制频道的频道名。 |
| userAccount | 用户的 User Account。该参数为必填，最大不超过 255 字节，不可填 null。请确保加入频道的 User Account 的唯一性。以下为支持的字符集范围（共 89 个字符）：<br />- 26 个小写英文字母 a-z<br />- 26 个大写英文字母 A-Z<br />- 10 个数字 0-9<br />- 空格<br />- "!", "#", "$", "%", "&", "(", ")", "+", "-", ":", ";", "&lt;", "=", ".", "&gt;", "?", "@", "[", "]", "^", "_", " \{", "\}", "\|", "~", "," |
| config | 录制的详细设置，详见 [RecordingConfig](/zh-CN/api-reference/local-server-recording/java/classio-1-1agora-1-1recording-1-1common-1-1-recording-config)。 |
| logLevel | 生成 log 的等级。设置完成后，只有等级低于所设 logLevel 的 log 才会被生成：<br />- 1: 日志等级为 Fatal。<br />- 2: 日志等级为 Error。<br />- 3: 日志等级为 Warning。<br />- 4: 日志等级为 Notice。<br />- 5: 日志等级为 Info。<br />- 6: 日志等级为 Debug。 |

#### Returns

- 0：方法调用成功。
- &lt; 0：方法调用失败。

### updateWatermarkConfigs()

```cpp
int io.agora.recording.RecordingSDK.updateWatermarkConfigs(LiteraWatermarkConfig[] literaWms, TimestampWatermarkConfig[] timestampWms, ImageWatermarkConfig[] imgWms)
```

该方法添加、更新或删除水印设置。

录制 SDK 支持三种水印：文字水印、时间戳水印和图片水印。

有以下情况：

- 如果你在调用 setVideoMixingLayout 方法时没有设置 LiteraWatermarkConfig、 TimestampWatermarkConfig 或 ImageWatermarkConfig 参数，你可直接调用 updateWatermarkConfigs 方法添加水印。
- 如果你在调用 setVideoMixingLayout 方法时已设置 LiteraWatermarkConfig、 TimestampWatermarkConfig 或 ImageWatermarkConfig 参数添加了水印，你可调用 updateWatermarkConfigs 方法修改水印个数和具体设置，从而增加、更新或删除水印；传值为空则删除全部已添加的水印。

##### `注解`

水印仅适用于合流模式（[RecordingConfig](/zh-CN/api-reference/local-server-recording/java/classio-1-1agora-1-1recording-1-1common-1-1-recording-config) 中的 [isMixingEnabled](/zh-CN/api-reference/local-server-recording/java/classio-1-1agora-1-1recording-1-1common-1-1-recording-config#a0c5cdca435dad61227698d1ceefff0ef) 为 true）。

#### Parameters

| Name | Description |
| --- | --- |
| literaWms | 设置文字水印。 [LiteraWatermarkConfig](/zh-CN/api-reference/local-server-recording/java/classio-1-1agora-1-1recording-1-1common-1-1-common-1-1-litera-watermark-config) 组成的数组。录制 SDK 最多支持 10 个文字水印。 |
| timestampWms | 设置时间戳水印。 [TimestampWatermarkConfig](/zh-CN/api-reference/local-server-recording/java/classio-1-1agora-1-1recording-1-1common-1-1-common-1-1-timestamp-watermark-config) 组成的数组。录制 SDK 只支持 1 个时间戳水印。 |
| imgWms | 设置图片水印。 [ImageWatermarkConfig](/zh-CN/api-reference/local-server-recording/java/classio-1-1agora-1-1recording-1-1common-1-1-common-1-1-image-watermark-config) 组成的数组。录制 SDK 最多支持 4 个图片水印。 |

#### Returns

- 0：方法调用成功。
- &lt; 0：方法调用失败。
