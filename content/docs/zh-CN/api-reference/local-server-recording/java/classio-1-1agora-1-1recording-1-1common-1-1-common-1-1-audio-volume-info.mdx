以数组的形式返回每个说话者的用户 ID 和音量。

## 类成员变量说明

<a id="a6f23ed30b08e430fcbdf6e5ee821d414"></a>

### uid

```cpp
long io.agora.recording.common.Common.AudioVolumeInfo.uid
```

说话者的用户 ID。如果返回的 uid 为 0，则默认为本地用户。

<a id="a3948644250b3414116546a7f592ab1fa"></a>

### volume

```cpp
int io.agora.recording.common.Common.AudioVolumeInfo.volume
```

说话者的音量，取值范围为 [0,255]。
