选择录制启动模式。

## 类成员变量说明

<a id="ae6f0926fae9dc852c9f31dd44c106413"></a>

### AUTOMATICALLY_MODE

```cpp
io.agora.recording.common.Common.TRIGGER_MODE_TYPE.AUTOMATICALLY_MODE =(0)
```

0：（默认）自动模式。此模式下，录制端加入频道即开始录制，退出频道即停止录制。

<a id="ac9d70ff3a64632470f9a3fcd0fb30720"></a>

### MANUALLY_MODE

```cpp
io.agora.recording.common.Common.TRIGGER_MODE_TYPE.MANUALLY_MODE =(1)
```

手动模式。此模式下，可以调用 [startService](/zh-CN/api-reference/local-server-recording/java/classio-1-1agora-1-1recording-1-1-recording-s-d-k#adf5f07d0092f3532de708c45c1ee813a) 和 [stopService](/zh-CN/api-reference/local-server-recording/java/classio-1-1agora-1-1recording-1-1-recording-s-d-k#a2008d6e1c37bc969669ffdc6575b2ba8) 方法灵活开始、暂停录制。
