<a id="setlogfile"></a>
## setLogFile

```cpp
virtual int setLogFile(const char* filePath, unsigned int fileSize, aosl_ref_t ares = AOSL_REF_INVALID) = 0;
```

设置 SDK 日志文件的路径和大小。

SDK 运行期间会将所有日志数据记录在两个日志文件中，每个文件的默认大小为 512 KB。如果将 `fileSize` 设置为 1024 KB，日志文件的总大小为 2 MB。当日志文件总大小超过设置值时，新日志将覆盖旧日志。

:::warning[注意]
为确保日志输出完整，请在调用 [`initialize`](/zh-CN/api-reference/local-server-recording/iagoraservice.cpp#initialize) 后立即调用此方法。
:::

#### 参数

| 参数 | 数据类型 | 描述 |
| --- | --- | --- |
| `filePath` | `const char*` | 日志文件路径指针。请确保该路径所在目录存在且可写。 |
| `fileSize` | `unsigned int` | 每个日志文件的大小（字节）。 |

#### 返回值

- 0：方法调用成功。
- < 0：方法调用失败。

<a id="setlogfilter"></a>
## setLogFilter

```cpp
virtual int setLogFilter(unsigned int filters, aosl_ref_t ares = AOSL_REF_INVALID) = 0;
```

设置 SDK 日志输出过滤器。

日志级别的顺序为 `OFF`、`CRITICAL`、`ERROR`、`WARNING`、`INFO` 和 `DEBUG`。

你可以选择一个日志级别，SDK 会输出该级别及以上级别的日志。例如，如果将日志级别设置为 `WARNING`，则会输出 `CRITICAL`、`ERROR` 和 `WARNING` 级别的日志。

#### 参数

| 参数 | 数据类型 | 描述 |
| --- | --- | --- |
| `filters` | `unsigned int` | <Slot name="iagoraservice-cpp-html-2-1-2" /> |

<Slot for="iagoraservice-cpp-html-2-1-2">

日志输出过滤器。

    - `LOG_LEVEL_NONE (0x0000)`：不输出任何日志文件。
    - `LOG_LEVEL_INFO (0x0001)`：（推荐）输出 `INFO` 级别的日志文件。
    - `LOG_LEVEL_WARN (0x0002)`：输出 `WARN` 级别的日志文件。
    - `LOG_LEVEL_ERROR (0x0004)`：输出 `ERROR` 级别的日志文件。
    - `LOG_LEVEL_FATAL (0x0008)`：输出 `FATAL` 级别的日志文件。

</Slot>

#### 返回值

- 0：方法调用成功。
- < 0：方法调用失败。
