### queryVideoByTimestamp()

```cpp
int com.agora.iotsdk20.IAlarmMgr.queryVideoByTimestamp(final String deviceID, final String ownerUserId, final long timestamp)
```

根据告警时间戳查询告警视频信息。

完成查询后，SDK 会触发 [onAlarmVideoQueryDone](/zh-CN/api-reference/iot-apaas/android/interfacecom-1-1agora-1-1iotsdk20-1-1-i-alarm-mgr-1-1-i-callback#a36b85563f67ca591ed606f89e39aa454) 回调。

#### Parameters

| Name | Description |
| --- | --- |
| deviceID | 待查询设备的设备 ID。 |
| ownerUserId | 设备所属用户的账号 ID。 `null` 表示当前用户的账号 ID。 |
| timestamp | 查询告警的时间戳。 |

#### Returns

- 0: 方法调用成功。
- &lt;0: 方法调用失败。
