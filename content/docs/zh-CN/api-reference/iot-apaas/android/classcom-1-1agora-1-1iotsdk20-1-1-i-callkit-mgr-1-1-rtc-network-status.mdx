### users

```cpp
int com.agora.iotsdk20.ICallkitMgr.RtcNetworkStatus.users
```

返回当前频道内的人数。

- 通信场景下，返回频道内的总人数
- 直播场景下，如果本地用户为观众，则返回频道内的主播数 + 1；如果本地用户为主播，则返回频道内的主播数。
