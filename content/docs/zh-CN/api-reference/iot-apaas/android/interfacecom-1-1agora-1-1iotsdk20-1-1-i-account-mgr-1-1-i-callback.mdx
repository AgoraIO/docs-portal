### onMqttError()

```cpp
default void com.agora.iotsdk20.IAccountMgr.ICallback.onMqttError(final String errMessage)
```

MQTT 客户端出错回调。

当 MQTT 客户端出错时，SDK 会触发该回调报告错误信息。你需要调用 [login](/zh-CN/api-reference/iot-apaas/android/interfacecom-1-1agora-1-1iotsdk20-1-1-i-account-mgr#ae1655fb00e5d6fcb0f2505598dda2d65) 重新登录用户账号。

#### Parameters

| Name | Description |
| --- | --- |
| errMessage | 错误信息。 `XERR_MQTT_DISCONNECT(-10021)`: MQTT 未连接。 |

### onMqttStateChanged()

```cpp
default void com.agora.iotsdk20.IAccountMgr.ICallback.onMqttStateChanged(int mqttState)
```

MQTT 客户端状态回调。

当 MQTT 客户端状态发生改变时，SDK 会触发该回调报告当前 MQTT 客户端的状态。

#### Parameters

| Name | Description |
| --- | --- |
| mqttState | MQTT 客户端状态：<br />- `MQTT_STATE_DISCONNECTED(0x0000)`: MQTT 客户端未连接。<br />- `MQTT_STATE_CONNECTING(0x0001)`: MQTT 客户端正在连接中。<br />- `MQTT_STATE_CONNECTED(0x0002)`: MQTT 客户端已连接。 |
