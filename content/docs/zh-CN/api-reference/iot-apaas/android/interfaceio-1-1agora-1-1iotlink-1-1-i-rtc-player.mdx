## 成员函数说明

<a id="a93409e1dc1c813c1e7b03644e1aedaf8"></a>

### getStateMachine()

```cpp
int io.agora.iotlink.IRtcPlayer.getStateMachine()
```

获取当前 `IRtcPlayer` 的状态。

#### Returns

当前 `IRtcPlayer` 的状态。

- RTCPLAYER_STATE_STOPPED(0x0001): 停止播放音视频。
- RTCPLAYER_STATE_PREPARING(0x0002): 正在准备播放音视频。
- RTCPLAYER_STATE_PLAYING(0x0003): 正在播放音视频。

### start()

```cpp
int io.agora.iotlink.IRtcPlayer.start(final String channelName, final SurfaceView displayView)
```

开始播放音视频。 成功调用该方法后，SDK 会触发 [onPrepareDone](/zh-CN/api-reference/iot-apaas/android/interfaceio-1-1agora-1-1iotlink-1-1-i-rtc-player-1-1-i-callback#a2a3359ffcbd55dcdf0aea8687d31edb1) 回调。

#### Parameters

| Name | Description |
| --- | --- |
| channelName | 频道名。 |
| displayView | 设备的视频显示窗口，详见 `SurfaceView`。 |

#### Returns

- 0: 方法调用成功。
- &lt;0: 方法调用失败。
