### onCallkitError()

```cpp
default void com.agora.iotsdk20.ICallkitMgr.ICallback.onCallkitError(int errCode)
```

报告错误事件。

当呼叫系统中遇到错误或异常事，SDK 会触发该回调。触发后，呼叫过程会被自动清除。

#### Parameters

| Name | Description |
| --- | --- |
| errCode | 错误码，详见 [ErrCode](/zh-CN/api-reference/iot-apaas/android/classcom-1-1agora-1-1iotsdk20-1-1-err-code)。 |

### onRecordingError()


#### Parameters

| Name | Description |
| --- | --- |
| errCode | 错误码，详见 [ErrCode](/zh-CN/api-reference/iot-apaas/android/classcom-1-1agora-1-1iotsdk20-1-1-err-code)。比较常见的是编码导致的问题，对应错误码以 `XERR_CODEC` 为前缀，你可以结合你的业务逻辑进行处理。 |
