<a id="md_readme"></a> 灵隼客户端 Android API 包含如下接口：

| 接口 | 描述 |
| --- | --- |
| [IAgoraIotAppSdk](/zh-CN/api-reference/iot-apaas/android/interfacecom-1-1agora-1-1iotsdk20-1-1-i-agora-iot-app-sdk) | 提供总的服务接口，各子功能通过 [getInstance](/zh-CN/api-reference/iot-apaas/android/classcom-1-1agora-1-1iotsdk20-1-1-a-iot-app-sdk-factory#a7e946301df826ad29c301ac151051d7c) 方法获取 |
| [IAccountMgr](/zh-CN/api-reference/iot-apaas/android/interfacecom-1-1agora-1-1iotsdk20-1-1-i-account-mgr) | 账号注册、登录与登出 |
| [ICallkitMgr](/zh-CN/api-reference/iot-apaas/android/interfacecom-1-1agora-1-1iotsdk20-1-1-i-callkit-mgr) | 来电呼叫管理，包括拨号、接听、挂断等 |
| [IDeviceMgr](/zh-CN/api-reference/iot-apaas/android/interfacecom-1-1agora-1-1iotsdk20-1-1-i-device-mgr) | 设备管理接口，包括设备绑定、设备解绑、设备列表查询、设备分享管理等 |
| [IAlarmMgr](/zh-CN/api-reference/iot-apaas/android/interfacecom-1-1agora-1-1iotsdk20-1-1-i-alarm-mgr) | 设备告警信息管理，包括移动侦察、有人经过等 |
| [IRtcPlayer](/zh-CN/api-reference/iot-apaas/android/interfaceio-1-1agora-1-1iotlink-1-1-i-rtc-player) | 音视频播放器 |
| [IRtmMgr](/zh-CN/api-reference/iot-apaas/android/interfaceio-1-1agora-1-1iotlink-1-1-i-rtm-mgr) | 与设备端之间的消息发送与接收 |
| [IDevMessageMgr](/zh-CN/api-reference/iot-apaas/android/interfacecom-1-1agora-1-1iotsdk20-1-1-i-dev-message-mgr) | 设备系统信息管理，包括设备上线、下线、绑定、解绑等事件管理 |
| [ErrCode](/zh-CN/api-reference/iot-apaas/android/classcom-1-1agora-1-1iotsdk20-1-1-err-code) | 使用 API 过程中可能遇到的报错 |
