### onConnectionStateChanged()

```cpp
default void io.agora.iotlink.IRtmMgr.ICallback.onConnectionStateChanged(int state)
```

设备连接状态改变回调。

#### Parameters

| Name | Description |
| --- | --- |
| state | 设备连接状态。<br />- RTMMGR_STATE_DISCONNECTED(0x0001): 与 RTM 系统未连接。<br />- RTMMGR_STATE_CONNECTING(0x0002): 正在连接 RTM 系统。<br />- RTMMGR_STATE_CONNECTED(0x0003): 已连接 RTM 系统。<br />- RTMMGR_STATE_RECONNECTING(0x0004): 正在重新连接 RTM 系统。可能原因是网络有问题。<br />- RTMMGR_STATE_ABORTED(0x0005): 一般性错误。 |
