### getQRCodeUserId()

```cpp
String com.agora.iotsdk20.IAccountMgr.getQRCodeUserId()
```

获取用于登录的二维码字符串。

app 需要通过获取到的字符串生成一个二维码，当用户使用摄像头扫描该二维码时，即可在新设备上登录其账号。

#### Returns

用于登录的二维码字符串。如果当前账号未登录，则返回一个空的字符串。

### setPublicKey()

```cpp
int com.agora.iotsdk20.IAccountMgr.setPublicKey(final String lsAccessToken, final String inventDeviceName, final String publickKey)
```

设置云存储视频加密的公钥。

为加强云存储视频加密的安全性，你可以在应用层自行生成公钥、私钥，再通过该方法将公钥传入 SDK。例如，只有 SDK 的公钥和你 app 的私钥都正确，用户才能查看加密视频。

成功调用该方法后，SDK 会触发 [onSetPublicKeyDone](/zh-CN/api-reference/iot-apaas/android/interfacecom-1-1agora-1-1iotsdk20-1-1-i-account-mgr-1-1-i-callback#a323a302f0858f0892701e50572087d34) 回调并报告设置结果及公钥信息。

##### `注解`

- 请确保该方法中设置的 lsAccessToken 和 inventDeviceName 参数值分别与 LoginParam 中的 mLsAccessToken 和 mInventDeviceName 参数值一致。
- 声网不会保存你传入的公钥，你需要自行保存并管理。

#### Parameters

| Name | Description |
| --- | --- |
| lsAccessToken | 灵隼平台账号的 Token。 |
| inventDeviceName | 账号的虚拟名称。 |
| publickKey | 待设置的公钥。 |

#### Returns

- 0: 方法调用成功。
- &lt;0: 方法调用失败。
