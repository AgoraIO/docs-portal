本文介绍声网页面录制的计费方式。如果你已与声网销售签约，实际计费信息以合同为准。

![页面录制计费组成](/img/api-center-generated/e4467689c422-webpage-rec-bil.svg)

## 计费规则

本节介绍使用云端录制的页面录制功能的计费规则。

### 计算公式

**页面录制费用 = 页面录制时长 × 页面录制单价**

### 页面录制时长

页面录制时长是从开始页面录制到结束页面录制的总时长。时长用量的精度为**秒**。

### 页面录制单价

页面录制根据录制输出视频的分辨率，将视频档位分为 HD（高清）和 FHD（全高清）两个档位，分别计算各档位视频的费用。单价详情如下表所示：

| 视频档位          | 输出的视频分辨率                                              | 单价（元/千分钟） |
| ----------------- | ------------------------------------------------------------- | ----------------- |
| 高清 (HD)         | 输出分辨率 ≤ 921,600 (1280 × 720)                            | 90                |
| 全高清 (FHD) | 921,600 (1280 × 720) ＜ 输出分辨率 ≤ 2,073,600 (1920 × 1080) | 180               |

你可以参考[设置输出视频属性](/zh-CN/api-reference/cloud-recording/restful/api/reference)设置页面录制输出视频的分辨率。

## 优惠策略

### 特定费用减免

如果在待录制的页面中使用了声网 RTC SDK 实现实时音视频功能，并订阅集合分辨率为高清 (HD) 档位（集合分辨率 ≤ 921,600（1280 × 720））的视频，则声网免除该页面录制过程中的音视频订阅费用，仅收取页面录制费用。订阅其他档位的视频无此优惠。

## 计费示例

假设启动 1 个页面录制进程，进行页面录制 6,000 秒，设置录制输出视频的分辨率为 960 × 720。请计算享受优惠策略前的页面录制费用是多少？

解答：

视频档位：集合分辨率为 960 × 720 = 691,200，属于高清（HD）档位。HD 档位单价为 90 元/千分钟。

录制时长：6,000 秒，换算后为 0.1 千分钟。

页面录制费用 = 各档位的录制时长 × 各档位的录制单价 = 0.1 × 90 = 9 元

## 注意事项

### 影响费用的集成设置

页面录制时，部分集成设置会影响计费：

- 页面录制停止前会持续计费，因此请按需主动停止页面录制或对 `maxRecordingHour` 字段设置合理的值。
- 对于同一个待录制页面，如果开启了两个页面录制任务，声网会收取两次录制费用。

### 时长用量精度

声网在控制台展示项目的每日用量时以分钟为单位，但在结算整月用量时，会把当月产生的音频和各档位的视频时长用量（单位为秒）分别相加，再换算成分钟数，最后**向上取整**。例如一个月产生了 59 秒的音频时长用量，则音频用量数据计为 1 分钟；如果产生了 61 秒的视频时长用量，则视频用量数据计为 2 分钟。月用量误差不超过 1 分钟。
