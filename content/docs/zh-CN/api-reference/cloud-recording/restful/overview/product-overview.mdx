声网云端录制是声网针对音视频通话和直播研发的录制组件，兼容声网 RTC Native 与框架 SDK（1.7.0 或更高版本）及 RTC Web SDK（1.12.0 或更高版本），通过简单的操作方法，帮助开发者快速、灵活地实现录制服务，实现一对一、一对多音视频通话或直播的录制。同声网本地服务端录制相比，声网云端录制无需部署 Linux 服务器，减轻了研发和运维的压力，更轻量便捷。

有了录制功能，你可以将语音聊天、视频聊天以及直播的内容储存下来，提供给更多的人在方便的时间观看。举个例子，某个用户报名参加了某线上课程，除了在规定的时间段上线听课外，他还可以选择在其他时间段观看课程录像，方便复习或补课。该功能可以通过在客户端配置声网云端录制实现。

## 功能概述

下表列出了声网云端录制的主要功能。你可以访问链接，查看各功能详情。

| 功能 | 描述 |
| --- | --- |
| 三种录制模式 | <Slot name="product-overview-html-0-1-1" /> |
| 单流录制下云端截图 | 在单流录制模式下，支持[云端截图](/zh-CN/api-reference/cloud-recording/restful/user-guides/snapshot)。你可以设置截图的时间间隔。云端会自动截取图片并上传至指定的第三方云存储。 |
| 订阅指定的用户 ID | 支持设置订阅白名单或黑名单，以及在录制过程中更新订阅名单。详见[设置订阅名单](/zh-CN/api-reference/cloud-recording/restful/api/reference#订阅名单设置)。 |
| 订阅指定的媒体类型 | <Slot name="product-overview-html-0-4-1" /> |
| 合流录制下设置音视频属性 | 在合流录制模式下，支持设置音视频属性，如码率和分辨率。 |
| 设置合流布局 | 在合流录制模式下，支持自定义合流布局或使用预设的布局，以及设置屏幕（画布）以及用户画面的背景色或背景图。支持在录制过程中更新合流布局或背景色、背景图。 |
| 第三方云存储 | <Slot name="product-overview-html-0-7-1" /> |
| 录制双流 | 如果声网 RTC SDK 启用了双流模式，你可以选择录制大流或小流。 |
| 录制加密频道 | 支持录制加密的频道内的音视频。 |
| 转码 | 声网提供[转码脚本](/zh-CN/api-reference/cloud-recording/restful/user-guides/manage-file/convert-format#转换单流录制文件)，用于合并音视频文件以及转换录制文件格式。 |
| 服务端事件通知回调 | <Slot name="product-overview-html-0-11-1" /> |

<Slot for="product-overview-html-0-1-1">

云端录制支持如下三种录制模式：

        - 单流录制：分别录制频道内每个用户 ID 的音频流和视频流，每个用户 ID 均有其对应的音频文件和视频文件
        - 合流录制：频道内所有或指定用户 ID 的音视频混合录制为一个音视频文件
        - 页面录制：指定网页的页面内容和音频混合录制为一个音视频文件

        三种录制模式的区别详见[核心概念](/zh-CN/api-reference/cloud-recording/restful/overview/concepts#录制模式)。

</Slot>

<Slot for="product-overview-html-0-4-1">

支持订阅如下类型的数据：

        - 仅订阅音频
        - 仅订阅视频
        - 同时订阅音频和视频

</Slot>

<Slot for="product-overview-html-0-7-1">

支持将录制文件存储在以下第三方云存储中：

        - Amazon S3
        - 阿里云
        - 腾讯云
        - 金山云
        - Microsoft Azure
        - 谷歌云
        - 华为云
        - 百度智能云
        - S3 协议云存储（如 Digital Ocean、MinIO 及部分自建云存储）

        你可以自定义录制文件在云存储中的存放路径。

</Slot>

<Slot for="product-overview-html-0-11-1">

声网提供[消息通知服务](/zh-CN/api-reference/cloud-recording/restful/webhook/enable-ncs)。开通该服务后，你会收到云端录制的事件通知，例如：

        - 录制文件的文件名
        - 第一个切片文件的开始时间
        - 流状态改变时的时间戳

</Slot>

## 限制说明

#### 故障迁移

针对网络故障，以及非声网云服务，非声网软件，基础设施和不可抗力等因素可能导致的风险，声网云录制为了更好的用户体验，提供高可用自动任务迁移服务。当故障确认后，该服务会在尽量短的时间（预计 90 秒内）完成，在此期间会存在录制中断，录制文件丢失等风险。

对于频道内较多观众端或对高可用要求极高场景，你需要基于自身业务特点综合考虑能否接受高可用迁移影响，决策是否要采用更高的质量保障措施，例如关键任务多路录制（使用不同 `uid` 发起多路录制任务），或通过[周期性频道查询](/zh-CN/api-reference/cloud-recording/restful/best-practices/recording-status#使用周期性频道查询)和消息通知服务获知录制任务状态，及时重新发起录制任务。

#### 录制文件上传

录制结束后，正常情况下录制文件会在 20 分钟内上传至第三方云存储，但在网络异常等特殊情况下上传时间会达到 24 小时以上。
