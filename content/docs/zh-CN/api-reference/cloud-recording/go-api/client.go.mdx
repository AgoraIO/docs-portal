<a id="newclient"></a>
## NewClient

```go
func NewClient(config *Config) (*Client, error)
```

使用指定配置创建一个云端录制客户端实例。

:::info[信息]
自 v0.8.0 版本新增。
:::

#### 参数

| 参数 | 数据类型 | 描述 |
| --- | --- | --- |
| `config` | `Config` | 云端录制客户端实例的配置，详见 [`Config`](/zh-CN/api-reference/cloud-recording/go-api/struct.go#config)。 |

#### 返回值

- `*Client`：方法调用成功时返回云端录制客户端实例，详见 [`Client`](/zh-CN/api-reference/cloud-recording/go-api/client.go)。
- `error`：方法调用失败时返回错误信息。
