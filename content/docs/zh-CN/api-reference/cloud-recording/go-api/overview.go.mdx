## IndividualRecording

| API | 描述 |
|---|---|
|[`Acquire`](/zh-CN/api-reference/cloud-recording/go-api/individualrecording.go#acquire) | 获取单流云录制资源 ID。 |
|[`Start`](/zh-CN/api-reference/cloud-recording/go-api/individualrecording.go#start) | 启动单流云端录制。 |
|[`Query`](/zh-CN/api-reference/cloud-recording/go-api/individualrecording.go#query) | 查询关闭视频截图上传功能时的单流云端录制状态。 |
|[`QueryVideoScreenshot`](/zh-CN/api-reference/cloud-recording/go-api/individualrecording.go#queryvideoscreenshot) | 查询开启视频截图采集功能时的单流云录制状态。 |
|[`Update`](/zh-CN/api-reference/cloud-recording/go-api/individualrecording.go#update) | 更新单流录制配置。 |
|[`Stop`](/zh-CN/api-reference/cloud-recording/go-api/individualrecording.go#stop) | 停止单流录制。 |
