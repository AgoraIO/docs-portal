## DomainArea

[`DomainArea`](/zh-CN/api-reference/cloud-recording/java-api/enum.java#domainarea) 表示 Open API 网关端点所在的全球区域。

:::info[信息]
自 v0.3.0 版本新增。
:::

选择适合您服务部署区域的区域。

#### 枚举值

| 枚举值 | 描述 |
| --- | --- |
| `US` | US 表示美国的西部和东部地区。 |
| `EU` | EU 表示欧洲的西部和中部地区。 |
| `AP` | AP 表示亚太地区的东南部和东北部。 |
| `CN` | CN 表示中国大陆的东部和北部地区。 |
