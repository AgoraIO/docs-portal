public class AcquireIndividualResourceClientReq {
    private Integer resourceExpiredHour;
    private List<String> excludeResourceIds;
    private Integer regionAffinity;
    private StartIndividualRecordingClientReq startParameter;

#### 成员参数

| 参数 | 数据类型 | 描述 |
| --- | --- | --- |

<Slot for="struct-java-html-1-3-2">

## UpdateLayoutMixRecordingResourceClientReq

```java
public class UpdateLayoutMixRecordingResourceClientReq {
    private String maxResolutionUID;
    private int mixedVideoLayout;
    private String backgroundColor;
    private String backgroundImage;
    private String defaultUserBackgroundImage;
    private List<UpdateLayoutResourceReq.LayoutConfig> layoutConfig;
    private List<UpdateLayoutResourceReq.BackgroundConfig> backgroundConfig;
}
```

用于客户端更新合流录制布局的请求。

:::info[信息]
自 v0.4.0 版本新增。
:::

#### 成员参数

| 参数 | 数据类型 | 描述 |
| --- | --- | --- |
| `maxResolutionUID` | `String` | （可选）仅在竖屏布局下需设置。指定大画面视频窗口的用户 ID。 |
| `mixedVideoLayout` | `int` | <Slot name="struct-java-html-10-2-2" /> |
| `backgroundColor` | `String` | （可选）视频画布的背景颜色。支持 RGB 颜色，格式为 “#” 加 6 位十六进制字符。默认值为 “#000000”，表示黑色。 |
| `backgroundImage` | `String` | （可选）视频画布的背景图像。背景图显示模式为裁剪模式：优先填满画布，图像等比例缩放直至填满整个画布，若图像宽高比与画布不同，则边缘将被裁剪以适配。 |
| `defaultUserBackgroundImage` | `String` | （可选）默认的用户视频画面背景图 URL。当用户停止发送视频流超过 3.5 秒时，画面将切换为该背景图。若为某个 `UID` 单独设置了背景图，该设置将被覆盖。 |
| `layoutConfig` | `List<UpdateLayoutResourceReq.LayoutConfig>` | （可选）用户的视频混图布局配置。每个用户的屏幕布局设置数组，最多支持 17 个用户。详见 [`LayoutConfig`](/zh-CN/api-reference/cloud-recording/java-api/struct.java#updatelayoutresourcereq.layoutconfig)。 |
| `backgroundConfig` | `List<UpdateLayoutResourceReq.BackgroundConfig>` | （可选）背景配置。通过该字段设置视频窗口的背景。详见 [`BackgroundConfig`](/zh-CN/api-reference/cloud-recording/java-api/struct.java#updatelayoutresourcereq.backgroundconfig)。 |

<Slot for="struct-java-html-10-2-2">

（可选）合流视频布局类型。支持以下取值：

    - 0：（默认）浮动布局。最先加入频道的用户显示为大窗口，填满画布，其他用户的视频以小窗口形式从下往上横向排列，最多支持 4 行，每行 4 个窗口，最多支持 17 个用户的视频窗口。
    - 1：自适应布局。根据用户数量自动调整每个用户的视频窗口尺寸，所有用户窗口大小一致，最多支持 17 个窗口。
    - 2：竖屏布局。通过设置 `maxResolutionUID` 显示左侧的大窗口，其他用户的视频窗口在右侧垂直排列，最多 2 列，每列最多 8 个窗口，总共最多 17 个窗口。
    - 3：自定义布局。通过设置 `layoutConfig` 字段实现自定义合流布局。

</Slot>
