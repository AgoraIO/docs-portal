## acquire

```java
public abstract Mono<AcquireResourceRes> acquire(String cname, String uid, boolean enablePostpone, AcquireIndividualResourceClientReq clientRequest);
```

获取单流录制的资源 ID。

:::info[信息]
自 v0.4.0 版本新增。
:::

获取资源 ID 后，需调用 [`start`](/zh-CN/api-reference/cloud-recording/java-api/individualscenario.java#start) API 启动云端录制。

#### 参数

| 参数 | 数据类型 | 描述 |
| --- | --- | --- |
| `cname` | `String` | 待录制的频道名称。 |
| `uid` | `String` | 云录制服务在 RTC 频道中使用的用户 ID，用于标识录制服务。 |
| `enablePostpone` | `boolean` | <Slot name="individualscenario-java-html-0-3-2" /> |
| `clientRequest` | `AcquireIndividualResourceClientReq` | 请求体参数，详见 [`AcquireIndividualResourceClientReq`](/zh-CN/api-reference/cloud-recording/java-api/struct.java#acquireindividualresourceclientreq)。 |

<Slot for="individualscenario-java-html-0-3-2">

- `true`：延迟开始录制。
    - `false`：立即开始录制。

</Slot>

#### 返回值

方法调用成功，返回 [`AcquireResourceRes`](/zh-CN/api-reference/cloud-recording/java-api/struct.java#acquireresourceres) 对象。
