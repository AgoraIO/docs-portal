## IndividualScenario

| API | 描述 |
|---|---|
|[`acquire`](/zh-CN/api-reference/cloud-recording/java-api/individualscenario.java#acquire) | 获取单流录制的资源 ID。 |
|[`start`](/zh-CN/api-reference/cloud-recording/java-api/individualscenario.java#start) | 启动单流云端录制。 |
|[`query`](/zh-CN/api-reference/cloud-recording/java-api/individualscenario.java#query) | 查询关闭视频截图采集时的单路云端录制状态。 |
|[`queryVideoScreenshot`](/zh-CN/api-reference/cloud-recording/java-api/individualscenario.java#queryvideoscreenshot) | 查询开启视频截图时单路云端录制的状态。 |
|[`update`](/zh-CN/api-reference/cloud-recording/java-api/individualscenario.java#update) | 更新单流录制配置。 |
|[`stop`](/zh-CN/api-reference/cloud-recording/java-api/individualscenario.java#stop) | 停止单流录制。 |
