<a id="create"></a>
## create

```java
public static synchronized CloudRecordingClient create(CloudRecordingConfig cloudRecordingConfig)
```

使用指定配置创建 [`CloudRecordingClient`](/zh-CN/api-reference/cloud-recording/java-api/cloudrecordingclient.java) 实例。

:::info[信息]
自 v0.4.0 版本新增。
:::

#### 参数

| 参数 | 数据类型 | 描述 |
| --- | --- | --- |
| `cloudRecordingConfig` | `CloudRecordingConfig` | 云端录制配置。详见 [`CloudRecordingConfig`](/zh-CN/api-reference/cloud-recording/java-api/struct.java#cloudrecordingconfig)。 |

#### 返回值

方法调用成功，返回 [`CloudRecordingClient`](/zh-CN/api-reference/cloud-recording/java-api/cloudrecordingclient.java) 实例。
