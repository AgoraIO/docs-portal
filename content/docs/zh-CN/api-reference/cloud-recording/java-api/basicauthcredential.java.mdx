## BasicAuthCredential

```java
public BasicAuthCredential(String username, String password)
```

创建一个 [`BasicAuthCredential`](/zh-CN/api-reference/cloud-recording/java-api/basicauthcredential.java) 实例。

#### 参数

| 参数 | 数据类型 | 描述 |
| --- | --- | --- |
| `username` | `String` | 从声网控制台获取的[客户 ID](/zh-CN/introduction/glossary#客户-id-和客户密钥)。 |
| `password` | `String` | 从声网控制台获取的[客户密钥](/zh-CN/introduction/glossary#客户-id-和客户密钥)。 |
