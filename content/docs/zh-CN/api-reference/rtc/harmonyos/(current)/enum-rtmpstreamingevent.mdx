## 枚举值

### `FAILED_LOAD_IMAGE`

1: 旁路推流时，添加背景图或水印出错。

### `URL_ALREADY_IN_USE`

2: 该推流 URL 已用于推流。如果你想开始新的推流，请使用新的推流 URL。

### `ADVANCED_FEATURE_NOT_SUPPORT`

3: 功能不支持。

### `REQUEST_TOO_OFTEN`

4: 预留参数。
