<a id="class_encryptionconfig__parameters"></a>

##

<ParameterList>
<a id="encryptionmode"></a>
<Parameter name="encryptionMode">

内置加密模式。详见 [EncryptionMode](/zh-CN/api-reference/rtc/harmonyos/enum-encryptionmode)。建议使用 `AES_128_GCM2` 或 `AES_256_GCM2` 加密模式。这两种模式支持使用盐，安全性更高。

</Parameter>
<a id="encryptionkey"></a>
<Parameter name="encryptionKey">

内置加密密钥，字符串类型，长度无限制。建议使用 32 字节的密钥。

:::caution
注意： 如果未指定该参数或将该参数设置为 `NULL`，则无法启用内置加密，且 SDK 会返回错误码 `-2`。
:::

</Parameter>
<a id="encryptionkdfsalt"></a>
<Parameter name="encryptionKdfSalt">

盐，长度为 32 字节。建议你在服务端使用 OpenSSL 生成盐。

如需在 App 中添加声网内置媒体流加密，详见媒体流加密。

:::caution
注意： 只有在 `AES_128_GCM2` 或 `AES_256_GCM2` 加密模式下，该参数才生效。此时，需确保填入该参数的值不全为 `0`。
:::

</Parameter>
</ParameterList>
