## joinChannel

加入频道。

<a id="api_irtcengine_joinchannel__prototype"></a>

```text
public abstract joinChannel(key: string, channel: string, optionalInfo: string, uid: number): number;
```

<a id="api_irtcengine_joinchannel__detailed_desc"></a>

加入频道后，默认情况下用户订阅频道内所有其他用户的音频流和视频流，因此会产生用量并**影响计费**。如果想取消订阅，可以通过相应的 mute 方法实现。

<a id="api_irtcengine_joinchannel__timing"></a>

### 调用时机

该方法需要在 [create](/zh-CN/api-reference/rtc/harmonyos/initialize#api_irtcengine_initialize) 之后再调用。

<a id="api_irtcengine_joinchannel__restriction"></a>

### 调用限制

- 该方法仅支持用户一次加入一个频道。
- 使用不同 App ID 的 App 不能互通。
- 加入频道前，请确保用于生成 Token 的 App ID 和调用 [create](/zh-CN/api-reference/rtc/harmonyos/initialize#api_irtcengine_initialize) 方法初始化引擎时使用的是同一个 App ID，否则使用 Token 加入频道会失败。

<a id="api_irtcengine_joinchannel__related"></a>

### 相关回调

成功调用该方法加入频道后会触发以下回调：

- 本地会触发 [onJoinChannelSuccess](/zh-CN/api-reference/rtc/harmonyos/channel#callback_irtcengineeventhandler_onjoinchannelsuccess) 和 [onConnectionStateChanged](/zh-CN/api-reference/rtc/harmonyos/network#callback_irtcengineeventhandler_onconnectionstatechanged) 回调。
- 通信场景下的用户和直播场景下的主播加入频道后，远端会触发 [onUserJoined](/zh-CN/api-reference/rtc/harmonyos/channel#callback_irtcengineeventhandler_onuserjoined) 回调。

在网络状况不理想的情况下，客户端可能会与声网服务器失去连接，此时 SDK 会自动尝试重连，重连成功后，本地会触发 [onRejoinChannelSuccess](/zh-CN/api-reference/rtc/harmonyos/channel#callback_irtcengineeventhandler_onrejoinchannelsuccess) 回调。

<a id="api_irtcengine_joinchannel__parameters"></a>

### 参数

### token

在服务端生成的用于鉴权的动态密钥。详见[使用 Token 鉴权](/zh-CN/realtime-media/rtc/build/setup-and-access/token-authentication)。

:::note
注：

- （推荐）如果你的项目开启了安全模式，即选择 APP ID + Token 为鉴权机制，则该参数为必填。
- 如果你的项目仅开启调试模式，即选择 APP ID 为鉴权机制，则无需填入 Token 即可加入频道。成功加入频道 24 小时后会自动退出该频道。
- 如果你需要同时加入多个频道或在频道间频繁切换，声网推荐你使用通配 Token 以避免每加入一个新的频道都需向服务端申请一个新的 Token，详见 使用通配 Token。
:::

### channelId

<a id="api_irtcengine_joinchannel__channelID_desc"></a>

频道名。该参数标识用户进行实时音视频互动的频道。App ID 一致的前提下，填入相同频道名的用户会进入同一个频道进行音视频互动。该参数为长度在 64 字节以内的字符串。以下为支持的字符集范围（共 89 个字符）:

<a id="api_irtcengine_joinchannel__char_support"></a>

- 26 个小写英文字母 a~z
- 26 个大写英文字母 A~Z
- 10 个数字 0~9
- "!"、"#"、"$"、"%"、"&"、"("、")"、"+"、"-"、":"、";"、"&lt;"、"="、"."、"&gt;"、"?"、"@"、"["、"]"、"^"、"_"、"\{"、"\}"、"|"、"~"、","

### optionalInfo

(非必选项) 预留参数。

### uid

用户 ID。该参数用于标识在实时音视频互动频道中的用户。你需要自行设置和管理用户 ID，并确保同一频道内的每个用户 ID 是唯一的。该参数为 32 位有符号整数。取值范围为：-231 到 231-1。如果不指定（即设为 0），SDK 会自动分配一个，并在 onJoinChannelSuccess 回调中返回， 应用层必须记住该返回值并维护，SDK 不对该返回值进行维护。

<a id="api_irtcengine_joinchannel__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。

  - -2：传入的参数无效。例如，使用了不合法的 Token，uid 参数未设置为整型，或 [ChannelMediaOptions](/zh-CN/api-reference/rtc/harmonyos/class-channelmediaoptions) 成员值不合法。你需要填入有效的参数，重新加入频道。
  - -3：[RtcEngine](/zh-CN/api-reference/rtc/harmonyos/rtc-interface-class#class_irtcengine) 对象初始化失败。你需要重新初始化 RtcEngine 对象。
  - -7：RtcEngine 对象尚未初始化。你需要在调用该方法前成功初始化 RtcEngine 对象。
  - -8：RtcEngine 对象内部状态错误。
  - -17：加入频道被拒绝。可能的原因是用户已经在频道中。建议通过 [onConnectionStateChanged](/zh-CN/api-reference/rtc/harmonyos/network#callback_irtcengineeventhandler_onconnectionstatechanged) 回调判断用户是否在频道中。除收到 DISCONNECTED(1) 状态外，不要再次调用该方法加入频道。
  - -102：频道名无效。你需要在 channelId 中填入有效的频道名，重新加入频道。
  - -121：用户 ID 无效。你需要在 uid 中填入有效的用户 ID，重新加入频道。

## leaveChannel

设置频道选项并离开频道。

<a id="api_irtcengine_leavechannel2__prototype"></a>

```text
public abstract leaveChannel(options?: LeaveChannelOptions): number;
```

<a id="api_irtcengine_leavechannel2__detailed_desc"></a>

调用该方法后，SDK 会终止音视频互动、离开当前频道，并会释放会话相关的所有资源。

成功加入频道后，必须调用本方法结束通话，否则无法开始下一次通话。如果你已调用 [joinChannelEx](/zh-CN/api-reference/rtc/harmonyos/channel#api_irtcengineex_joinchannelex) 加入多个频道，调用本方法后会同时离开所有已加入的频道。

:::caution
注意： 该方法是异步操作，调用返回时并没有真正退出频道。
:::

<a id="api_irtcengine_leavechannel2__timing"></a>

### 调用时机

该方法需要在加入频道后调用。

<a id="api_irtcengine_leavechannel2__restriction"></a>

### 调用限制

如果你调用了该方法后立即调用 [destroy](/zh-CN/api-reference/rtc/harmonyos/initialize#api_irtcengine_release) 方法，SDK 将不会触发 onLeaveChannel 回调。

<a id="api_irtcengine_leavechannel2__related"></a>

### 相关回调

成功调用该方法离开频道后会触发以下回调：

- 本地：[onLeaveChannel](/zh-CN/api-reference/rtc/harmonyos/channel#callback_irtcengineeventhandler_onleavechannel) 回调。
- 远端：主播离开频道后，远端会触发 [onUserOffline](/zh-CN/api-reference/rtc/harmonyos/channel#callback_irtcengineeventhandler_onuseroffline) 回调。

## setClientRole

设置直播场景下的用户角色和观众端延时级别。

<a id="api_irtcengine_setclientrole2__prototype"></a>

```text
public abstract setClientRole(role: number, options?: ClientRoleOptions): number;
```

<a id="api_irtcengine_setclientrole2__detailed_desc"></a>

SDK 默认设置用户角色为观众，你可以调用该方法设置用户角色为主播。用户角色（role）确定用户在 SDK 层的权限，包含是否有发流权限等。

<a id="api_irtcengine_setclientrole2__timing"></a>

### 调用时机

该方法在加入频道前后均可调用。

<a id="api_irtcengine_setclientrole2__preview1"></a>

如果你在加入频道前调用该方法设置用户角色为主播、并且通过 [setupLocalVideo](/zh-CN/api-reference/rtc/harmonyos/video/video-rendering#api_irtcengine_setuplocalvideo) 方法设置了本地视频属性，则用户加入频道时会自动开启本地视频预览。

<a id="api_irtcengine_setclientrole2__sdk"></a>

如果你在加入频道后调用该方法切换用户角色，调用成功后，SDK 会自动调用 [muteLocalAudioStream](/zh-CN/api-reference/rtc/harmonyos/publishnsubscribe#api_irtcengine_mutelocalaudiostream) 和 [muteLocalVideoStream](/zh-CN/api-reference/rtc/harmonyos/publishnsubscribe#api_irtcengine_mutelocalvideostream) 修改发布音视频流的状态。

<a id="api_irtcengine_setclientrole2__restriction"></a>

### 调用限制

当用户角色设为主播时，观众端延时级别仅支持设置为 ULTRA_LOW_LATENCY（超低延时）。

在加入频道前调用该方法并将 role 设为 BROADCASTER（主播）时，本地不会触发 [onClientRoleChanged](/zh-CN/api-reference/rtc/harmonyos/channel#callback_irtcengineeventhandler_onclientrolechanged) 回调。

<a id="api_irtcengine_setclientrole2__related"></a>

### 相关回调

如果你在加入频道后成功调用该方法切换用户角色，SDK 会触发下列回调：

- 本地触发 [onClientRoleChanged](/zh-CN/api-reference/rtc/harmonyos/channel#callback_irtcengineeventhandler_onclientrolechanged) 回调。

  :::note
  注： 在加入频道前调用该方法并将 role 设为 AUDIENCE（观众）时，也会触发该回调。
  :::
- 远端触发 [onUserJoined](/zh-CN/api-reference/rtc/harmonyos/channel#callback_irtcengineeventhandler_onuserjoined) 或 [onUserOffline](/zh-CN/api-reference/rtc/harmonyos/channel#callback_irtcengineeventhandler_onuseroffline) 回调。

如果你在加入频道后调用该方法切换用户角色失败，SDK 会触发 [onClientRoleChangeFailed](/zh-CN/api-reference/rtc/harmonyos/channel#callback_irtcengineeventhandler_onclientrolechangefailed)，报告切换失败的原因和当前的用户角色。

<a id="api_irtcengine_setclientrole2__parameters"></a>

### 参数

### role

用户角色。

- BROADCASTER (1): 主播。主播可以发流也可以收流。
- AUDIENCE (2):（默认）观众。观众只能收流不能发流。

:::note
注： 角色为观众的用户无法在频道内发布音视频流。在直播场景下发流时，请确保你的用户角色已切换为主播。
:::

### options

用户具体设置，包含用户级别。详见 [ClientRoleOptions](/zh-CN/api-reference/rtc/harmonyos/class-clientroleoptions)。

<a id="api_irtcengine_setclientrole2__return_values"></a>

  - -1: 一般性的错误（未明确归类）。
  - -2: 参数无效。
  - -5: 调用被拒绝。
  - -7: SDK 尚未初始化。

## onUserJoined

远端用户（通信场景）/主播（直播场景）加入当前频道回调。

<a id="callback_irtcengineeventhandler_onuserjoined__prototype"></a>

```text
onUserJoined?:(uid:number, elapse:number) => void;
```

<a id="callback_irtcengineeventhandler_onuserjoined__detailed_desc"></a>

<a id="callback_irtcengineeventhandler_onuserjoined__detailed_desc_scene"></a>

- 通信场景下，该回调提示有远端用户加入了频道。如果加入之前已经有其他用户在频道中，新加入的用户也会收到这些已有用户加入频道的回调。
- 直播场景下，该回调提示有主播加入了频道。如果加入之前，已经有主播在频道中了，新加入的用户也会收到已有主播加入频道的回调。建议连麦主播不超过 32 人（其中视频连麦主播不超过 17 人）。

<a id="callback_irtcengineeventhandler_onuserjoined__timing"></a>

### 触发时机

该回调在如下情况下会被触发：

- 远端用户/主播加入频道。
- 远端用户加入频道后将用户角色改变为主播。
- 远端用户/主播网络中断后重新加入频道。

<a id="callback_irtcengineeventhandler_onuserjoined__restriction"></a>

### 使用限制

无。

<a id="callback_irtcengineeventhandler_onuserjoined__parameters"></a>

### 参数

### uid

新加入频道的远端用户/主播 ID。

### elapsed

从本地用户调用 joinChannelWithOptions 到该回调触发的延迟（毫秒）。

## onUserOffline

远端用户（通信场景）/主播（直播场景）离开当前频道回调。

<a id="callback_irtcengineeventhandler_onuseroffline__prototype"></a>

```text
onUserOffline?:(uid:number, reason:number) => void;
```

<a id="callback_irtcengineeventhandler_onuseroffline__detailed_desc"></a>

<a id="callback_irtcengineeventhandler_onuseroffline__desc"></a>

用户离开频道一般有以下两个原因：

- 正常离开：远端用户或主播会发送类似“再见”的消息然后主动离开频道。
- 超时掉线：在一定时间内（通信场景为 20 秒，直播场景稍有延时），用户没有收到对方的任何数据包，则判定为对方掉线。在网络较差的情况下，有可能会误报。建议使用 RTM SDK 来做可靠的掉线检测。

<a id="callback_irtcengineeventhandler_onuseroffline__timing"></a>

### 触发时机

在音视频互动过程中，当远端用户或主播离开当前频道时会触发该回调。

<a id="callback_irtcengineeventhandler_onuseroffline__restriction"></a>

### 使用限制

无。

<a id="callback_irtcengineeventhandler_onuseroffline__parameters"></a>

### 参数

### uid

离线的远端用户或主播的 ID。

### reason

远端用户（通信场景）或主播（直播场景）离线的原因：

- USER_OFFLINE_QUIT(0)：用户主动离开。此时离开频道的用户会发送一个类似“再见”的消息。
- USER_OFFLINE_DROPPED(1)：因过长时间收不到对方数据包，SDK 判定该远端用户超时掉线。注意：在网络连接不稳定时，该判定可能会有误。建议使用 RTM SDK 来做可靠的掉线检测。
- USER_OFFLINE_BECOME_AUDIENCE(2)：用户的角色从主播切换为观众。

- [IRtcEngineEventHandler](/zh-CN/api-reference/rtc/harmonyos/rtc-interface-class#class_irtcengineeventhandler)
