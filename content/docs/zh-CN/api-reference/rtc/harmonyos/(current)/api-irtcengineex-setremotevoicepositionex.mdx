## 详情

设置远端用户声音的空间位置和音量，方便本地用户听声辨位。

通过调用该接口设置远端用户声音出现的位置，左右声道的声音差异会产生声音的方位感，从而判断出远端用户的实时位置。在多人在线游戏场景，如吃鸡游戏中，该方法能有效增加游戏角色的方位感，模拟真实场景。

:::caution
注意：

- 为获得最佳听觉体验，建议用户佩戴有线耳机。
- 该方法需要在加入频道后调用。
:::

<a id="api_irtcengineex_setremotevoicepositionex__parameters"></a>

## 参数

<ParameterList>
<a id="uid"></a>
<Parameter name="uid">

远端用户的 ID。

</Parameter>
<a id="pan"></a>
<Parameter name="pan">

设置远端用户声音的空间位置，取值范围为 [-1.0,1.0]:

- -1.0: 声音出现在左边。
- （默认）0.0: 声音出现在正前方。
- 1.0: 声音出现在右边。

</Parameter>
<a id="gain"></a>
<Parameter name="gain">

设置远端用户声音的音量，取值范围为 [0.0,100.0]，默认值为 100.0，表示该用户的原始音量。取值越小，则音量越低。

</Parameter>
<a id="connection"></a>
<Parameter name="connection">

Connection 信息。详见 [RtcConnection](/zh-CN/api-reference/rtc/harmonyos/class-rtcconnection)。

</Parameter>
</ParameterList>
