---
title: "CaptureFormat"
description: "视频帧格式。"
---

<a id="class_videoformat__prototype"></a>

```arkts
export class CaptureFormat {
  public width: number = 960;
  public height: number = 540;
  public fps: number = 15;
}
```

<a id="class_videoformat__parameters"></a>

### `width`

视频帧的宽度（px）。默认值为 960。

### `height`

视频帧的高度（px）。默认值为 540.

### `fps`

视频帧的帧率。默认值为 15。
