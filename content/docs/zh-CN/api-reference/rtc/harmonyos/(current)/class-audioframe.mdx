<a id="class_audioframe__parameters"></a>

### `samplesPerChannel`

每个声道的采样点数。

### `bytesPerSample`

每个采样点的字节数。对于 PCM 来说，一般使用 16 bit，即两个字节。

### `channelNums`

声道数量(如果是立体声，数据是交叉的)。

- 1: 单声道
- 2: 双声道

### `sampleRataHz`

每声道每秒的采样点数。

声音数据缓存区（如果是立体声，数据是交叉存储的）。

缓存区数据大小 `buffer` = `samples` × `channels` × `bytesPerSample`。

### `timestamp`

音频帧的时间戳。
