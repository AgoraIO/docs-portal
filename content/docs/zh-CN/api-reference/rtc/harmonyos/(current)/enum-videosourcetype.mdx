## 枚举值

### `CAMERA_SECONDARY`

1：视频源为第二个摄像头。

### `SCREEN_SECONDARY`

3：视频源为第二个屏幕。

### `CUSTOM`

4：自定义的视频源。

### `MEDIA_PLAYER`

5：视频源为媒体播放器。

### `RTC_IMAGE_PNG`

6：视频源为 PNG 图片。

### `RTC_IMAGE_JPEG`

7：视频源为 JPEG 图片。

### `RTC_IMAGE_GIF`

8：视频源为 GIF 图片。

### `REMOTE`

9：视频源为网络获取的远端视频。

### `TRANSCODED`

10：转码后的视频源。

### `UNKNOWN`

100：未知的视频源。
