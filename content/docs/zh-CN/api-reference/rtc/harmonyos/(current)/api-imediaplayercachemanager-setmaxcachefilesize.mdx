<a id="api_imediaplayercachemanager_setmaxcachefilesize__prototype"></a>


<a id="api_imediaplayercachemanager_setmaxcachefilesize__parameters"></a>

## 参数

### `cacheSize`

缓存媒体文件的总缓存上限，单位为字节。默认为 1 GB。

<a id="api_imediaplayercachemanager_setmaxcachefilesize__return_values"></a>

## 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败，详见 [MediaPlayerReason](/zh-CN/api-reference/rtc/harmonyos/enum-mediaplayerreason)。
