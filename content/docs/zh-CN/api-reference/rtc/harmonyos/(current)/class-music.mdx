<a id="class_music__parameters"></a>

##

### songCode

音乐资源的编号，用于标识一个音乐资源。

### name

音乐资源名称。

### singer

歌手名。

### poster

音乐资源海报的下载地址。

### releaseTime

音乐资源发布的时间。

### type

音乐资源类型：

- 1：左声道伴奏，右声道原唱的单音轨音源。
- 2：只有伴唱的单音轨音源。
- 3：只有原唱的单音轨音源。
- 4：多音轨音源。

### pitchType

歌曲是否支持演唱评分功能：

- 1：歌曲支持演唱评分功能。
- 2：歌曲不支持演唱评分功能。

### durationS

音乐资源总时长 （秒）。

### lyricTypes

支持的歌词类型：

- 0：xml 格式。
- 1：lrc 格式。

### climaxSegments

音乐高潮片段列表，详见 [ClimaxSegment](/zh-CN/api-reference/rtc/harmonyos/class-climaxsegment)。
