## 详情

:::info[注]
该方法需在初始化 [RtcEngine](/zh-CN/api-reference/rtc/harmonyos/rtc-interface-class#class_irtcengine) 之后调用。

<a id="api_imediaplayercachemanager_setcachedir__parameters"></a>

## 参数

缓存文件储存的绝对路径。请确保指定的目录存在且可写。

<a id="api_imediaplayercachemanager_setcachedir__return_values"></a>

## 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败，详见 [MediaPlayerReason](/zh-CN/api-reference/rtc/harmonyos/enum-mediaplayerreason)。
