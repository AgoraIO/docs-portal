```arkts
export  class AudioSpectrumInfo {

}
```

<a id="class_audiospectrumdata__parameters"></a>

### `audioSpectrumData`

音频频谱数据。声网将声音频率分为 256 个频域，通过该参数报告各频域的能量值，每个能量值的取值范围为 [-300,1]，单位为 dBFS。
