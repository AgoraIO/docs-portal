<a id="streamtype"></a>
<Parameter name="streamType">

录制内容：

- STREAM_TYPE_AUDIO：仅音频。
- STREAM_TYPE_VIDEO：仅视频。
- STREAM_TYPE_BOTH：（默认）音视频。

</Parameter>
<a id="maxdurationms"></a>
<Parameter name="maxDurationMs">

最大录制时长，单位为毫秒，默认值为 120000。

</Parameter>
<a id="recorderinfoupdateinterval"></a>
<Parameter name="recorderInfoUpdateInterval">

录制信息更新间隔，单位为毫秒，取值范围为 [1000,10000]。SDK 会根据该值的设置触发 [onRecorderInfoUpdated](/zh-CN/api-reference/rtc/harmonyos/recording#callback_imediarecorderobserver_onrecorderinfoupdated) 回调，报告更新后的录制信息。

</Parameter>
