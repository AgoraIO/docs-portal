## setCameraZoomFactor

<a id="api_irtcengine_setcamerazoomfactor__prototype"></a>

```text
public abstract setCameraZoomFactor(factor: number): number;
```

<a id="api_irtcengine_setcamerazoomfactor__detailed_desc"></a>

### 详情

:::note
注意：

- 该方法必须在 [enableVideo](/zh-CN/api-reference/rtc/harmonyos/video/video-basic#api_irtcengine_enablevideo) 后调用，设置结果在摄像头成功开启后生效，即 SDK 触发 [onLocalVideoStateChanged](/zh-CN/api-reference/rtc/harmonyos/video/video-basic#callback_irtcengineeventhandler_onlocalvideostatechanged) 回调返回本地视频状态为 CAPTURING (1) 后。
:::

<a id="api_irtcengine_setcamerazoomfactor__parameters"></a>

### 参数

### factor

摄像头缩放比例。对不支持超广角的设备，取值范围从 1.0 到最大缩放比例；对支持超广角的设备，取值范围从 0.5 到最大缩放比例。你可以通过 [getCameraMaxZoomFactor](/zh-CN/api-reference/rtc/harmonyos/device-management/video-device#api_irtcengine_getcameramaxzoomfactor) 方法获取设备支持的最大缩放比例。

<a id="api_irtcengine_setcamerazoomfactor__return_values"></a>

### 返回值

- 方法调用成功: 返回设置的 factor 值。
- 方法调用失败: 返回值 &lt; 0。

## switchCamera

切换前置/后置摄像头。

<a id="api_irtcengine_switchcamera__prototype"></a>

```text
public abstract switchCamera(): number;
```

<a id="api_irtcengine_switchcamera__detailed_desc"></a>

<a id="api_irtcengine_switchcamera__desc"></a>

你可以调用该方法在 App 运行期间基于可用摄像头的实际情况来动态切换摄像头，而无需重启视频流或重新配置视频源。

<a id="api_irtcengine_switchcamera__timing"></a>

### 调用时机

该方法必须在摄像头成功开启后调用，即 SDK 触发 [onLocalVideoStateChanged](/zh-CN/api-reference/rtc/harmonyos/video/video-basic#callback_irtcengineeventhandler_onlocalvideostatechanged) 回调，返回本地视频状态为 CAPTURING (1) 后。

<a id="api_irtcengine_switchcamera__restriction"></a>

### 调用限制

该方法仅会对第一路摄像头采集的视频流进行摄像头切换操作，即调用 [startCameraCapture](/zh-CN/api-reference/rtc/harmonyos/video/camera-capture#api_irtcengine_startcameracapture) 时设置为 (0) 的视频源。

<a id="api_irtcengine_switchcamera__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。
