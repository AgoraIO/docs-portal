<a id="class_localtranscoderconfiguration__prototype"></a>

```arkts
export class LocalTranscoderConfiguration {
  public  transcodingVideoStreams:Array<TranscodingVideoStream>;
  public  videoOutputConfiguration:VideoEncoderConfiguration;
  public constructor() {
    this.transcodingVideoStreams = new Array<TranscodingVideoStream>();
    this.videoOutputConfiguration = new VideoEncoderConfiguration();
  }
}
```

<a id="class_localtranscoderconfiguration__parameters"></a>

### `transcodingVideoStreams`

参与本地合图的视频流。详见 [TranscodingVideoStream](/zh-CN/api-reference/rtc/harmonyos/class-transcodingvideostream)。

### `videoOutputConfiguration`

本地合图后，合图视频的编码配置。详见 [VideoEncoderConfiguration](/zh-CN/api-reference/rtc/harmonyos/class-videoencoderconfiguration)。
