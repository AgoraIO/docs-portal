## 枚举值

### UNKNOWN

-1: 未知事件。

### SEEK_BEGIN

0: 开始定位。

### SEEK_COMPLETE

1: 完成定位。

### SEEK_ERROR

2: 定位出错。

### AUDIO_TRACK_CHANGED

5: 当前音轨发生改变。

### BUFFER_LOW

6: 当前缓冲的数据不足以支持播放。

### BUFFER_RECOVER

7: 当前缓冲的数据刚好能支持播放。

### FREEZE_START

8: 音频或视频出现卡顿。

### FREEZE_STOP

9: 音频和视频均停止卡顿。

### SWITCH_BEGIN

10: 开始切换媒体资源。

### SWITCH_COMPLETE

11: 媒体资源切换完成。

### SWITCH_ERROR

12: 媒体资源切换出错。

### FIRST_DISPLAYED

13: 视频首帧出图。

### REACH_CACHE_FILE_MAX_COUNT

14：达到可缓存文件的数量上限。

### REACH_CACHE_FILE_MAX_SIZE

15：达到可缓存文件的大小上限。
