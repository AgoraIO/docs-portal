## 枚举值

### `VIDEO_SOURCE_NOT_READY`

1：指定的视频源未开始进行视频采集，你需要为其创建视频轨道并开始视频采集。

### `INVALID_VIDEO_SOURCE_TYPE`

2：视频源类型无效，你需要重新指定支持的视频源类型。

### `INVALID_IMAGE_PATH`

3：图片路径无效，你需要重新指定正确的图片路径。

### `UNSUPPORT_IMAGE_FORMAT`

4：图片格式无效，需确保图片格式为 PNG、JPEG 或 GIF 中的一种。

### `INVALID_LAYOUT`

5：合图后的视频编码分辨率无效。

### `INTERNAL`

20：内部未知错误。
