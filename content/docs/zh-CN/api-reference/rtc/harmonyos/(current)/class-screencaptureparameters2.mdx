<a id="class_screencaptureparameters2__prototype"></a>

```arkts
export class ScreenCaptureParameters {
  public captureAudio: boolean = false;
  public audioParams: ScreenAudioParameters = new ScreenAudioParameters();
  public captureVideo: boolean = true;
  public videoParams: ScreenVideoParameters = new ScreenVideoParameters();
}
```

<a id="class_screencaptureparameters2__detailed_desc"></a>

<a id="class_screencaptureparameters2__parameters"></a>

### `captureAudio`

屏幕共享时是否采集系统音频：

- true: 采集系统音频。
- false: （默认）不采集系统音频。

:::info[注]
- 为提高屏幕共享时采集系统音频的成功率，请确保你已调用 setAudioScenario 方法并设置音频场景为 GAME_STREAMING。
:::

### `audioParams`

共享屏幕流的音频配置。详见 [AudioCaptureParameters](/zh-CN/api-reference/rtc/harmonyos/class-screenaudioparameters)。

:::warning[注意]
该参数仅在 captureAudio 为 `true` 时生效。
:::

### `captureVideo`

屏幕共享时是否采集屏幕：

- true:（默认）采集屏幕。
- false: 不采集屏幕。

### `videoParams`

共享屏幕流的视频编码配置。详见 [VideoCaptureParameters](/zh-CN/api-reference/rtc/harmonyos/class-screenvideoparameters)。

:::warning[注意]
该参数仅在 captureVideo 为 `true` 时生效。
:::
