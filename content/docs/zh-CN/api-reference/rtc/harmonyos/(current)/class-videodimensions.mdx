<a id="class_videodimensions__prototype"></a>

```arkts
export class VideoDimensions {
  constructor(w : number, h : number) {
    this.width = w;
    this.height = h;
  }
  public width:number;
  public height:number;
}
```

<a id="class_videodimensions__parameters"></a>

### `width`

视频宽度，单位为像素。

### `height`

视频高度，单位为像素。
