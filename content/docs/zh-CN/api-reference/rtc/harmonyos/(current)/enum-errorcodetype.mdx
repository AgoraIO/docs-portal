<a id="enum_errorcodetype__detailed_desc"></a>

### 详情

错误代码意味着 SDK 遇到不可恢复的错误，需要应用程序干预。例如：打开摄像头失败时会返回错误，App 需要提示用户不能使用摄像头。

## 枚举值

<ParameterList>
<a id="err_ok"></a>
<Parameter name="ERR_OK">

0：没有错误。

</Parameter>
<a id="err_failed"></a>
<Parameter name="ERR_FAILED">

1：一般性的错误（没有明确归类的错误原因）。请重新调用方法。

</Parameter>
<a id="err_invalid_argument"></a>
<Parameter name="ERR_INVALID_ARGUMENT">

2：方法中设置了无效的参数。例如指定的频道名中含有非法字符。请重新设置参数。

</Parameter>
<a id="err_not_ready"></a>
<Parameter name="ERR_NOT_READY">

3：SDK 尚未准备好。可能的原因有：

- [RtcEngine](/zh-CN/api-reference/rtc/harmonyos/rtc-interface-class#class_irtcengine) 初始化失败。请重新初始化 RtcEngine。
- 调用方法时用户尚未加入频道。请检查方法的调用逻辑。
- 音频模块未开启。
- 程序集不完整。

</Parameter>
<a id="err_not_supported"></a>
<Parameter name="ERR_NOT_SUPPORTED">

4：RtcEngine 当前状态不支持该操作。可能的原因有：

- 使用内置加密时，设置的加密模式不正确，或加载外部加密库失败。请检查加密的枚举值是否正确，或重新加载外部加密库。

</Parameter>
<a id="err_refused"></a>
<Parameter name="ERR_REFUSED">

5：方法调用被拒绝。可能的原因有：

- [RtcEngine](/zh-CN/api-reference/rtc/harmonyos/rtc-interface-class#class_irtcengine) 初始化失败。请重新初始化 RtcEngine。
- 在加入频道时，将频道名设为空字符 `""`。请重新设置频道名。
- 多频道场景下，在调用 [joinChannelEx](/zh-CN/api-reference/rtc/harmonyos/channel#api_irtcengineex_joinchannelex) 方法加入频道时，设置的频道名已存在。请重新设置频道名。

</Parameter>
<a id="err_buffer_too_small"></a>
<Parameter name="ERR_BUFFER_TOO_SMALL">

6：缓冲区大小不足以存放返回的数据。

</Parameter>
<a id="err_not_initialized"></a>
<Parameter name="ERR_NOT_INITIALIZED">

7：RtcEngine 尚未初始化就调用方法。请确认在调用该方法前已创建 RtcEngine 对象并完成初始化。

</Parameter>
<a id="err_no_permission"></a>
<Parameter name="ERR_NO_PERMISSION">

9：没有操作权限。请检查用户是否授予了 App 音视频设备的使用权限。

</Parameter>
<a id="err_timedout"></a>
<Parameter name="ERR_TIMEDOUT">

<a id="err_join_channel_rejected"></a>
<Parameter name="ERR_JOIN_CHANNEL_REJECTED">

17：加入频道被拒绝。可能的原因有：

- 用户已经在频道中。建议通过 [onConnectionStateChanged](/zh-CN/api-reference/rtc/harmonyos/network#callback_irtcengineeventhandler_onconnectionstatechanged) 回调判断用户是否在频道中。除收到 DISCONNECTED(1) 状态外，不要再次调用该方法加入频道。

</Parameter>
<a id="err_leave_channel_rejected"></a>
<Parameter name="ERR_LEAVE_CHANNEL_REJECTED">

18：离开频道失败。可能的原因有：

- 调用 [leaveChannel](/zh-CN/api-reference/rtc/harmonyos/channel#api_irtcengine_leavechannel2) 前，用户已离开频道。停止调用该方法即可。
- 用户尚未加入频道，就调用 leaveChannel 退出频道。这种情况下无需额外操作。

</Parameter>
<a id="err_already_in_use"></a>

19：资源已被占用，不能重复使用。

</Parameter>
<a id="err_aborted"></a>

</Parameter>
<a id="err_init_net_engine"></a>
<Parameter name="ERR_INIT_NET_ENGINE">

</Parameter>
<a id="err_resource_limited"></a>
<Parameter name="ERR_RESOURCE_LIMITED">

<Parameter name="ERR_INVALID_CHANNEL_NAME">

</Parameter>

109：当前使用的 Token 过期，不再有效。请在服务端申请生成新的 Token，并调用 [renewToken](/zh-CN/api-reference/rtc/harmonyos/channel#api_irtcengine_renewtoken) 更新 Token。

### 弃用：

该枚举已废弃。请改用 [onConnectionStateChanged](/zh-CN/api-reference/rtc/harmonyos/network#callback_irtcengineeventhandler_onconnectionstatechanged) 回调中的 TOKEN_EXPIRED(9)。

</Parameter>
<a id="err_invalid_token"></a>
<Parameter name="ERR_INVALID_TOKEN">

110：Token 无效。一般有以下原因：

- 在控制台中启用了 App 证书，但未使用 App ID + Token 鉴权。当项目启用了 App 证书，就必须使用 Token 鉴权。
- 生成 Token 时填入的 `uid` 字段，和用户加入频道时填入的 uid 不匹配。

### 弃用：

该枚举已废弃。请改用 [onConnectionStateChanged](/zh-CN/api-reference/rtc/harmonyos/network#callback_irtcengineeventhandler_onconnectionstatechanged) 回调中的 INVALID_TOKEN(8)。

</Parameter>
