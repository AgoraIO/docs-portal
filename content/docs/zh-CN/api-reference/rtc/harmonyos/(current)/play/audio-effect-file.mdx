## playEffect

播放指定的本地或在线音效文件。

<a id="api_irtcengine_playeffect3__prototype"></a>

```text
public abstract playEffect(soundId:number,filePath:string,loopCount:number,pitch:number,pan:number,gain:number,publish?:boolean,startPos?:number):Promise<number>;
```

<a id="api_irtcengine_playeffect3__detailed_desc"></a>

<a id="api_irtcengine_playeffect3__playEffect-desc"></a>

你可以多次调用该方法，传入不同的 soundID 和 filePath，同时播放多个音效文件。为获得最佳用户体验，建议同时播放的音效文件不超过 3 个。

<a id="api_irtcengine_playeffect3__timing"></a>

### 调用时机

该方法在加入频道前后均可调用。

<a id="api_irtcengine_playeffect3__restriction"></a>

### 调用限制

无。

<a id="api_irtcengine_playeffect3__related"></a>

### 相关回调

音效文件播放结束后，SDK 会触发 onAudioEffectFinished 回调。

<a id="api_irtcengine_playeffect3__parameters"></a>

### 参数

<ParameterList>
<a id="soundid"></a>
<Parameter name="soundId">

音效的 ID。每个音效的 ID 具有唯一性。

</Parameter>
<a id="filepath"></a>
<Parameter name="filePath">

播放文件的地址。

</Parameter>
<a id="loopcount"></a>
<Parameter name="loopCount">

音效循环播放的次数。

- ≥ 0: 循环播放次数。例如，1 表示循环播放 1 次，即总计播放 2 次。
- -1: 无限循环播放。

</Parameter>
<a id="pitch"></a>
<Parameter name="pitch">

音效的音调，取值范围为 [0.5,2.0]。默认值为 1.0，表示原始音调。取值越小，则音调越低。

</Parameter>
<a id="pan"></a>
<Parameter name="pan">

音效的空间位置。取值范围为 [-1.0,1.0]，例如：

- -1.0：音效出现在左边
- 0.0：音效出现在正前方
- 1.0：音效出现在右边

</Parameter>
<a id="gain"></a>
<Parameter name="gain">

音效的音量。取值范围为 [0.0,100.0]。默认值为 100.0，表示原始音量。取值越小，则音量越低。

</Parameter>
<a id="publish"></a>
<Parameter name="publish">

是否将音效发布至远端：

- `true`: 将音效发布至远端。本地用户和远端用户都能听到音效。
- `false`: 不将音效发布至远端。只有本地用户能听到音效。

</Parameter>
<a id="startpos"></a>
<Parameter name="startPos">

音效文件的播放位置，单位为毫秒。

</Parameter>
</ParameterList>

<a id="api_irtcengine_playeffect3__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。

## playAllEffects

播放所有音效文件。

<a id="api_irtcengine_playalleffects__prototype"></a>

```text
public abstract playAllEffects(loopCount:number,pitch:number,pan:number,gain:number,publish:boolean):number;
```

<a id="api_irtcengine_playalleffects__detailed_desc"></a>

### 详情

多次调用 [preloadEffect](/zh-CN/api-reference/rtc/harmonyos/play/audio-effect-file#api_irtcengine_preloadeffect) 预加载多个音效文件后，你可以调用本方法播放所有预加载的音效文件。

<a id="api_irtcengine_playalleffects__parameters"></a>

### 参数

<ParameterList>
<a id="loopcount-1"></a>
<Parameter name="loopCount">

音效文件循环播放的次数：

- -1: 无限循环播放音效文件，直至调用 [stopEffect](/zh-CN/api-reference/rtc/harmonyos/play/audio-effect-file#api_irtcengine_stopeffect) 或 [stopAllEffects](/zh-CN/api-reference/rtc/harmonyos/play/audio-effect-file#api_irtcengine_stopalleffects) 后停止。
- 0: 播放音效文件一次。
- 1: 播放音效文件两次。

</Parameter>
<a id="pitch-1"></a>
<Parameter name="pitch">

音效的音调。取值范围为 [0.5,2.0]。默认值为 1.0，代表原始音调。取值越小，则音调越低。

</Parameter>
</ParameterList>

<ParameterList>
<a id="pan-1"></a>
<Parameter name="pan">

音效的空间位置。取值范围为 [-1.0,1.0]:

- -1.0: 音效出现在左边。
- 0: 音效出现在正前边。
- 1.0: 音效出现在右边。

</Parameter>
<a id="gain-1"></a>
<Parameter name="gain">

音效的音量。取值范围为 [0,100]。100 为默认值，代表原始音量。取值越小，则音量越低。

</Parameter>
<a id="publish-1"></a>
<Parameter name="publish">

是否将音效发布到远端：

- `true`: 将音效发布到远端。本地和远端用户都能听到该音效。
- `false`: （默认）不将音效发布到远端。只能本地用户能听到该音效。

</Parameter>
</ParameterList>

<a id="api_irtcengine_playalleffects__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。
