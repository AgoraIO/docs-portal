### 详情

该方法获取当前音乐文件播放进度，单位为毫秒。

:::warning[注意]

- ≥ 0: 方法调用成功，返回当前音乐文件播放进度（ms）。0 表示当前音乐文件未开始播放。
- &lt; 0: 方法调用失败。 详见 [错误码](https://doc.shengwang.cn/api-ref/rtc/harmonyos/error-code) 了解详情和解决建议。

## selectMultiAudioTrack

<a id="api_imediaplayer_selectmultiaudiotrack__prototype"></a>

```arkts
public abstract selectMultiAudioTrack(playoutTrackIndex:number, publishTrackIndex: number): number;
```

<a id="api_imediaplayer_selectmultiaudiotrack__detailed_desc"></a>

### 详情

你可以调用该方法分别设置本地播放和发送到远端的音轨。

### 适用场景

在 K 歌场景下，主播可以根据需求选择在本地播放一路音轨（如原声），然后发送另一路音轨至远端（如伴唱）以提升听众体验。

#### `playoutTrackIndex`

用于本地播放的音轨索引。你可以通过 [getStreamInfo](/zh-CN/api-reference/rtc/harmonyos/play/mediaplayer/mediaplayer-info#api_imediaplayer_getstreaminfo) 来获取索引值。

用于发送至远端的音轨索引。你可以通过 [getStreamInfo](/zh-CN/api-reference/rtc/harmonyos/play/mediaplayer/mediaplayer-info#api_imediaplayer_getstreaminfo) 来获取索引值。

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。

## startAudioMixing

开始播放音乐文件。

<a id="api_irtcengine_startaudiomixing2__prototype"></a>

```arkts
public abstract startAudioMixing(filepath: string, loopback: boolean, cycle: number, startpos?:number): number;
```

<a id="api_irtcengine_startaudiomixing2__detailed_desc"></a>

该方法支持播放以 `content://` 开头的 URI 文件。支持的音频格式详见 [RTC SDK 支持播放哪些格式的音频文件](/zh-CN/api-reference/faq/product/audio_format)。如果本地音乐文件不存在、文件格式不支持或无法访问在线音乐文件 URL，则 SDK 会报告 CAN_NOT_OPEN。

<a id="api_irtcengine_startaudiomixing2__timing"></a>

### 调用时机

该方法在加入频道前后均可调用。

<a id="api_irtcengine_startaudiomixing2__restriction"></a>

### 调用限制

- 使用该方法播放时长较短的音效文件可能会导致播放失败。如需播放音效文件，建议使用 [playEffect](/zh-CN/api-reference/rtc/harmonyos/play/audio-effect-file#api_irtcengine_playeffect3)。
- 如需多次调用该方法，请确保调用间隔大于 500 ms。

<a id="api_irtcengine_startaudiomixing2__related"></a>

### 相关回调

调用该方法成功播放音乐文件后，本地会触发 [onAudioMixingStateChanged](/zh-CN/api-reference/rtc/harmonyos/play/audio-mixing#callback_irtcengineeventhandler_onaudiomixingstatechanged) (`PLAYING`) 回调。播放结束后，本地会触发 onAudioMixingStateChanged (`STOPPED`) 回调。

<a id="api_irtcengine_startaudiomixing2__parameters"></a>

### 参数

#### `filePath`

文件路径：

#### `loopback`

是否只在本地播放音乐文件：

- true：只在本地播放音乐文件，只有本地用户能听到音乐。
- false：将本地播放的音乐文件发布至远端，本地用户和远端用户都能听到音乐。

#### `cycle`

音乐文件的播放次数。

- &gt;0: 播放次数。例如，1 表示播放 1 次。
- -1: 无限循环播放。

#### `startPos`

音乐文件的播放位置，单位为毫秒。

<a id="api_irtcengine_startaudiomixing2__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败：
  - -1：一般性的错误（未明确归类）。
  - -2：设置了无效的参数。
  - -3：SDK 尚未准备好：
    - 请检查是否已开启音频模块。
    - 请检查程序集完整性。
    - RtcEngine 初始化失败。请重新初始化 RtcEngine。

### 所属接口类
- [RtcEngine](/zh-CN/api-reference/rtc/harmonyos/rtc-interface-class#class_irtcengine)
