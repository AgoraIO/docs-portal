### 详情

调用该方法前，你需要预先分配一定大小的内存空间用来存储缓存音乐资源的信息。如果你需要设置可缓存的音乐资源数量，可通过 [initialize](/zh-CN/api-reference/rtc/harmonyos/play/drm#api_imusiccontentcenter_initialize) 的 configuration 来设置。

## getInternalSongCode

创建音乐资源的副歌片段编号。

<a id="api_imusiccontentcenter_getinternalsongcode__prototype"></a>

```text
public abstract getInternalSongCode(songCode:bigint,jsonOption:string):bigint
```

<a id="api_imusiccontentcenter_getinternalsongcode__detailed_desc"></a>

:::info[自从]
v4.2.2
:::

<a id="api_imusiccontentcenter_getinternalsongcode__scenario"></a>

### 适用场景

当你需要播放某一音乐资源的副歌片段前，你需要调用此方法，通过 jsonOption 参数和该音乐资源的 songCode 来为该音乐资源的副歌片段创建一个编号，作为该资源的唯一标识。当你获取到该片段的编号后，在你调用相应方法打开、预加载、移除该资源时，将该内部歌曲编号传入 songCode 参数。

<a id="api_imusiccontentcenter_getinternalsongcode__parameters"></a>

### 参数

### songCode

音乐资源编号，用于标识音乐资源。你可以通过调用 [getMusicCollectionByMusicChartId](/zh-CN/api-reference/rtc/harmonyos/play/drm#api_imusiccontentcenter_getmusiccollectionbymusicchartid2) 或 [searchMusic](/zh-CN/api-reference/rtc/harmonyos/play/drm#api_imusiccontentcenter_searchmusic2) 方法来获取音乐资源，并通过由此触发的 [onMusicCollectionResult](/zh-CN/api-reference/rtc/harmonyos/play/drm#callback_imusiccontentcentereventhandler_onmusiccollectionresult) 回调获取音乐资源的编号（songCode）。

### jsonOption

扩展 JSON 字段，默认为 NULL。目前支持传入下列值：

| Key 值 | Value 值 | 示例 |
| --- | --- | --- |
| sceneType | <Slot name="api-center-table-0" /> | \\\{"sceneType"\:1\\\} |
| highPart | 副歌片段的索引。你可以从 [onMusicCollectionResult](/zh-CN/api-reference/rtc/harmonyos/play/drm#callback_imusiccontentcentereventhandler_onmusiccollectionresult) 回调中获取副歌片段的索引然后传值。索引序号从 0 开始。 | \\\{"format": \\\{"highpart": 0\\\}\\\} |

<Slot for="api-center-table-0">

场景类型：

- 1：直播场景：K 歌及背景音乐播放。
- 2：直播场景：背景音乐播放。
- 3：（默认）语聊场景：K 歌。
- 4：语聊场景：背景音乐播放。
- 5：VR 场景：K 歌及背景音乐播放。

:::note
注： 声网会根据你在 sceneType 传入的应用场景进行收费。不同的应用场景对应不同的费率，你可以参考 [计费说明](/zh-CN/solutions/online-ktv/online-ktv-sdk/reference/billing) 查看详细的计费。如果需要切换到不同场景，需要重新调用此方法并传入 sceneType 的值。
:::

</Slot>

<Slot for="api-center-table-1">

是否支持打分：

- 1：支持打分的音乐资源。
- 2：不支持打分的音乐资源。

</Slot>

<Slot for="api-center-table-2">

是否需要副歌片段资源：

- `true`：需要副歌片段资源。
- `false`：不需要副歌片段资源。

<a id="api_imusiccontentcenter_searchmusic2__prototype"></a>

```text
public abstract searchMusic(keyword:string,page:number,pageSize:number,jsonOption?:string):string
```

<a id="api_imusiccontentcenter_searchmusic2__detailed_desc"></a>

### 详情

成功调用该方法后，SDK 会触发 [onMusicCollectionResult](/zh-CN/api-reference/rtc/harmonyos/play/drm#callback_imusiccontentcentereventhandler_onmusiccollectionresult) 回调报告检索到的音乐资源列表。

<a id="api_imusiccontentcenter_searchmusic2__parameters"></a>

### 参数

### keyword

搜索关键词，支持歌曲名、歌手搜索。

### page

想要获取的音乐资源列表的目标页编号。

### pageSize

每页所展示的音乐资源的最大数量，最大值为 50。

### jsonOption

扩展 JSON 字段，默认为 NULL。你可以通过该字段来筛选出你需要的音乐资源，目前支持筛选可打分的音乐资源及音乐资源的副歌片段：

| Key 值 | Value 值 | 示例 |
| --- | --- | --- |
| pitchType | <Slot name="api-center-table-3" /> | \\\{"pitchType"\:1\\\} |
| needHighPart | <Slot name="api-center-table-4" /> | \\\{"needHighPart"\:true\\\} |

<Slot for="api-center-table-3">

是否支持打分：

- 1：支持打分的音乐资源。
- 2：不支持打分的音乐资源。

</Slot>

<Slot for="api-center-table-4">

是否需要副歌片段资源：

- `true`：需要副歌片段资源。
- `false`：不需要副歌片段资源。

</Slot>

<a id="api_imusiccontentcenter_searchmusic2__return_values"></a>

### 返回值

一个 requestId，为本次请求的唯一标识。

### 所属接口类

- [IAgoraMusicContentCenter](/zh-CN/api-reference/rtc/harmonyos/rtc-interface-class#class_imusiccontentcenter)

## setPlayMode

设置音乐资源的播放模式。

<a id="api_imusicplayer_setplaymode__prototype"></a>

```text
abstract setPlayMode(mode:Constants.MusicPlayMode):number
```

<a id="api_imusicplayer_setplaymode__detailed_desc"></a>

你可以调用该方法来设置启用原唱、伴奏或导唱。如不调用该方法进行设置，则默认播放伴奏；如果音乐资源没有伴奏，则播放原唱。

:::caution
注意： 你可以通过 [onMusicCollectionResult](/zh-CN/api-reference/rtc/harmonyos/play/drm#callback_imusiccontentcentereventhandler_onmusiccollectionresult) 回调获取音乐资源的详细信息，并可通过其中的  参数得知需播放的版权音乐所支持的播放类型。
:::

<a id="api_imusicplayer_setplaymode__scenario"></a>

### 适用场景

在线 K 歌、秀场等娱乐场景下，如果你需要播放声网内容中心提供的版权音乐，你可以调用该方法来设置播放模式。

<a id="api_imusicplayer_setplaymode__timing"></a>

### 调用时机

该方法需要在 [createMusicPlayer](/zh-CN/api-reference/rtc/harmonyos/play/drm#api_imusiccontentcenter_createmusicplayer) 之后调用。

<a id="api_imusicplayer_setplaymode__restriction"></a>

### 调用限制

无。

<a id="api_imusicplayer_setplaymode__parameters"></a>

### 参数

### mode

播放模式，详见 [MusicPlayMode](/zh-CN/api-reference/rtc/harmonyos/enum-musicplaymode)。

<a id="api_imusicplayer_setplaymode__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。

  - -2: 参数设置错误，请重新设置参数。

### 所属接口类

- [IAgoraMusicPlayer](/zh-CN/api-reference/rtc/harmonyos/rtc-interface-class#class_imusicplayer)

## onMusicCollectionResult

获取音乐资源列表回调。

<a id="callback_imusiccontentcentereventhandler_onmusiccollectionresult__prototype"></a>

```text
onMusicCollectionResult?:(requestId:string,page:number,pageSize:number,total:number,list:Music[],reason:Constants.MusicContentCenterStateReason) => void
```

<a id="callback_imusiccontentcentereventhandler_onmusiccollectionresult__detailed_desc"></a>

当你调用 [getMusicCollectionByMusicChartId](/zh-CN/api-reference/rtc/harmonyos/play/drm#api_imusiccontentcenter_getmusiccollectionbymusicchartid2) 方法来获取指定榜单的音乐资源列表或调用 [searchMusic](/zh-CN/api-reference/rtc/harmonyos/play/drm#api_imusiccontentcenter_searchmusic2) 来搜索音乐资源时，SDK 会触发此回调报告榜单中音乐资源列表的详细信息。

### 参数

### requestId

请求 ID。本次请求的唯一标识。

### reason

音乐内容中心的请求状态码，详见 [MusicContentCenterStateReason](/zh-CN/api-reference/rtc/harmonyos/enum-musiccontentcenterstatereason)。

### page

当前页面编号，默认从 1 开始。

### pageSize

每页所展示的音乐资源的最大数量，最大值为 50。

### total

列表内音乐资源的总数量。

### list

音乐资源列表的详细信息。详见 [Music](/zh-CN/api-reference/rtc/harmonyos/class-music)。

## onPreLoadEvent

报告预加载音乐资源的事件。

<a id="callback_imusiccontentcentereventhandler_onpreloadevent__prototype"></a>

```text
onPreLoadEvent?:(requestId:string,songCode:bigint,percent:number,lyricUrl:string,state:number,reason:Constants.MusicContentCenterStateReason) => void
```

<a id="callback_imusiccontentcentereventhandler_onpreloadevent__detailed_desc"></a>

当你调用 [preload](/zh-CN/api-reference/rtc/harmonyos/play/drm#api_imusicontentcenter_preload2) 方法预加载音乐资源后，SDK 会触发该回调。

<a id="callback_imusiccontentcentereventhandler_onpreloadevent__parameters"></a>

### 参数

### songCode

音乐资源的编号，用于标识一个音乐资源。

### percent

音乐资源当前的加载进度，取值范围为 [0,100]。

### lyricUrl

歌词下载地址。

### state

当前音乐资源的加载状态：

- 0：音乐资源加载完成。
- 1：音乐资源加载失败。
- 2：音乐资源正在加载中。

### reason

音乐内容中心的请求状态码，详见 [MusicContentCenterStateReason](/zh-CN/api-reference/rtc/harmonyos/enum-musiccontentcenterstatereason)。

## onSongSimpleInfoResult

音乐资源的详细信息回调。

<a id="callback_imusiccontentcentereventhandler_onsongsimpleinforesult__prototype"></a>

```text
onSongSimpleInfoResult?:(requestId:string,songCode:bigint,simpleInfo:string,reason:Constants.MusicContentCenterStateReason) => void
```

<a id="callback_imusiccontentcentereventhandler_onsongsimpleinforesult__detailed_desc"></a>

### 详情

当你调用 [getSongSimpleInfo](/zh-CN/api-reference/rtc/harmonyos/play/drm#api_imusiccontentcenter_getsongsimpleinfo) 获取某一音乐资源的详细信息后，SDK 会触发该回调。

<a id="callback_imusiccontentcentereventhandler_onsongsimpleinforesult__parameters"></a>

### 参数

### requestId

请求 ID。本次请求的唯一标识。

### songCode

音乐资源的编号，用于标识音乐资源。

### simpleInfo

音乐资源的相关信息，包含下列内容：

- 副歌片段的开始和结束的时间（ms）
- 副歌片段的歌词下载地址
- 副歌片段时长（ms）
- 歌曲名称
- 歌手名

### reason

音乐内容中心的请求状态码，详见 [MusicContentCenterStateReason](/zh-CN/api-reference/rtc/harmonyos/enum-musiccontentcenterstatereason)。
