## 枚举值

<ParameterList>
<a id="off"></a>
<Parameter name="OFF">

0: 不输出日志信息。

</Parameter>
<a id="debug"></a>
<Parameter name="DEBUG">

0x080f: 输出所有 API 日志信息。如果你想获取最完整的日志，可以将日志级别设为该等级。

</Parameter>
<a id="info"></a>
<Parameter name="INFO">

0x000f: 输出 CRITICAL、ERROR、WARN 和 INFO 级别的日志信息。建议你将日志级别设为该等级。

</Parameter>
<a id="warn"></a>
<Parameter name="WARN">

0x000e: 输出 CRITICAL、ERROR 和 WARN 级别的日志信息。

</Parameter>
<a id="error"></a>
<Parameter name="ERROR">

0x000c: 输出 CRITICAL 和 ERROR 级别的日志信息。

</Parameter>
<a id="critical"></a>
<Parameter name="CRITICAL">

0x0008: 输出 CRITICAL 级别的日志信息。

</Parameter>
