## 枚举值

### `INTERNAL_FAILURE`

0: 内部原因。

### `DECRYPTION_FAILURE`

1: 媒体流解密错误。请确保接收端和发送端使用的加密模式或密钥一致。

### `ENCRYPTION_FAILURE`

2: 媒体流加密错误。

### `DATASTREAM_DECRYPTION_FAILURE`

3: 数据流解密错误。请确保接收端和发送端使用的加密模式或密钥一致。

### `DATASTREAM_ENCRYPTION_FAILURE`

4: 数据流加密错误。
