## 详情

该方法每次只能添加一张背景图，如果你需要添加多张背景图，则需多次调用该方法。

水印和背景图的总数量需大于等于 0 且小于等于 10。

<a id="api_livetranscoding_addbackgroundimage__parameters"></a>

## 参数

### `backgroundImage`

直播视频上的背景图。必须为 PNG 格式。详见 [AgoraImage](/zh-CN/api-reference/rtc/harmonyos/class-rtcimage)。
