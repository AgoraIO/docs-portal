## muteAllRemoteAudioStreams

取消或恢复订阅所有远端用户的音频流。

<a id="api_irtcengine_muteallremoteaudiostreams__prototype"></a>

```arkts
public abstract muteAllRemoteAudioStreams(muted: boolean): number;
```

<a id="api_irtcengine_muteallremoteaudiostreams__detailed_desc"></a>

成功调用该方法后，本地用户会取消或恢复订阅所有远端用户的音频流，包括在调用该方法后加入频道的用户的音频流。

:::warning[注意]
SDK 默认在加入频道时订阅所有远端用户的音频流，如果要修改此行为，可以在调用 [joinChannelWithOptions](/zh-CN/api-reference/rtc/harmonyos/channel#api_irtcengine_joinchannel2) 加入频道时设置 autoSubscribeAudio 为 `false`，即可在加入频道时取消订阅所有用户的音频流。
:::

<a id="api_irtcengine_muteallremoteaudiostreams__timing"></a>

### 调用时机

该方法需要在加入频道后调用。

<a id="api_irtcengine_muteallremoteaudiostreams__restriction"></a>

### 调用限制

如果在调用该方法之后又调用了 [enableAudio](/zh-CN/api-reference/rtc/harmonyos/audio/audio-basic#api_irtcengine_enableaudio) 或 [disableAudio](/zh-CN/api-reference/rtc/harmonyos/audio/audio-basic#api_irtcengine_disableaudio)，则后调用的方法会生效。

<a id="api_irtcengine_muteallremoteaudiostreams__parameters"></a>

### 参数

#### `muted`

是否取消订阅所有远端用户的音频流：

- true: 取消订阅所有远端用户的音频流。
- false:（默认）订阅所有远端用户的音频流。

<a id="api_irtcengine_muteallremoteaudiostreams__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。 详见 [错误码](https://doc.shengwang.cn/api-ref/rtc/harmonyos/error-code) 了解详情和解决建议。

### 所属接口类
- [RtcEngine](/zh-CN/api-reference/rtc/harmonyos/rtc-interface-class#class_irtcengine)

## muteLocalAudioStream


该方法用于控制是否发布本地采集的音频流。如果不发布本地采集的音频流，也不会禁用音频采集设备，所以不影响音频的采集状态。

加入频道前后均可调用。

<a id="api_irtcengine_mutelocalaudiostream__restriction"></a>

无。

<a id="api_irtcengine_mutelocalaudiostream__related"></a>

<a id="api_irtcengine_mutelocalaudiostream__parameters"></a>

### 参数

#### `muted`

是否取消发布本地音频流。

- true: 取消发布。
- false:（默认）发布。

<a id="api_irtcengine_mutelocalaudiostream__return_values"></a>

### 返回值

- 0: 方法调用成功。
