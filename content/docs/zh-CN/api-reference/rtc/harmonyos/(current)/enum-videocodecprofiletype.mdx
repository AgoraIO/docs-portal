<a id="enum_videocodecprofiletype__parameters"></a>

### `BASELINE`

66: Baseline 级别的视频编码规格，一般用于低阶或需要额外容错的应用，比如视频通话、手机视频等。

### `MAIN`

77: Main 级别的视频编码规格，一般用于主流消费类电子产品，如 MP4、便携的视频播放器、PSP、iPad 等。

### `HIGH`

100: （默认）High 级别的视频编码规格，一般用于广播、视频碟片存储、高清电视。
