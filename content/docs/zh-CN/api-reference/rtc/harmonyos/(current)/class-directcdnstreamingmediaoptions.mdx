## 属性
<ParameterList>
<a id="publishcameratrack"></a>
<Parameter name="publishCameraTrack">

设置是否发布摄像头采集的视频。

- `true`: 发布摄像头采集的视频。
- `false`:（默认）不发布摄像头采集的视频。

</Parameter>
<a id="publishmicrophonetrack"></a>
<Parameter name="publishMicrophoneTrack">

设置是否发布麦克风采集的音频。

- `true`: 发布麦克风采集的音频。
- `false`:（默认）不发布麦克风采集的音频。

</Parameter>
<a id="publishcustomaudiotrack"></a>
<Parameter name="publishCustomAudioTrack">

设置是否发布自定义采集的音频。

- `true`: 发布自定义采集的音频。
- `false`:（默认）不发布自定义采集的音频。

</Parameter>
<a id="publishcustomvideotrack"></a>
<Parameter name="publishCustomVideoTrack">

设置是否发布自定义采集的视频。

- `true`: 发布自定义采集的视频。
- `false`:（默认）不发布自定义采集的视频。

</Parameter>
<a id="customvideotrackid"></a>
<Parameter name="customVideoTrackId">

调用 [createCustomVideoTrack](/zh-CN/api-reference/rtc/harmonyos/video/video-custom-capturenrendering#api_irtcengine_createcustomvideotrack) 方法返回的视频轨道 ID。默认值为 0。

</Parameter>
</ParameterList>
