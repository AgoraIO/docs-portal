<a id="callback_imediaplayersourceobserver_onplayercachestats__prototype"></a>

```arkts
onPlayerCacheStats?:(stats:CacheStatistics) => void
```

<a id="callback_imediaplayersourceobserver_onplayercachestats__detailed_desc"></a>

## 详情

调用 [openWithMediaSource](/zh-CN/api-reference/rtc/harmonyos/mediaplayer-open#api_imediaplayer_openwithmediasource) 方法且设置 enableCache 成员为 `true` 后，SDK 会在媒体文件打开后每秒触发一次该回调，报告当前缓存的媒体文件的统计数据。

<a id="callback_imediaplayersourceobserver_onplayercachestats__parameters"></a>

## 参数

缓存中的媒体资源的相关信息，详见 [CacheStatistics](/zh-CN/api-reference/rtc/harmonyos/class-cachestatistics)。
