<a id="class_screenaudioparameters__prototype"></a>

```arkts
export class ScreenAudioParameters {
  public sampleRate: number = 16000;
  public channels: number = 2;
  public captureSignalVolume : number = 100;
}
```

<a id="class_screenaudioparameters__detailed_desc"></a>

仅适用于 captureAudio 为 `true` 的场景。

<a id="class_screenaudioparameters__parameters"></a>

### `sampleRate`

音频采样率 (Hz)。默认值为 16000。

### `channels`

声道数。默认值为 2，表示双声道。

### `captureSignalVolume`

采集的系统音量。取值范围为 [0,100]。默认值为 100。
