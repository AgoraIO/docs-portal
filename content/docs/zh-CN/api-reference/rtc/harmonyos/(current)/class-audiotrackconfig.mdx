description: "自定义音频轨道的配置选项。"

<a id="class_audiotrackconfig__prototype"></a>

```arkts
export class AudioTrackConfig {
  
  public enableLocalPlayback: boolean = true;
}
```

<a id="class_audiotrackconfig__parameters"></a>

### `enableLocalPlayback`

是否启用本地音频播放：

- `true`：(默认) 启用本地音频播放。
- `false`：不启用本地音频播放。
