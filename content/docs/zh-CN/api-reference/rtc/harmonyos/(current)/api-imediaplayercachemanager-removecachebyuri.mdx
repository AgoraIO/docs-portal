<a id="api_imediaplayercachemanager_removecachebyuri__detailed_desc"></a>

## 详情

:::info[注]
该方法不会删除正在播放中的已缓存媒体文件。
:::

<a id="api_imediaplayercachemanager_removecachebyuri__parameters"></a>

## 参数

### `uri`

待删除的缓存文件的 URI（Uniform Resource Identifier），可用于标识媒体文件。

<a id="api_imediaplayercachemanager_removecachebyuri__return_values"></a>

## 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败，详见 [MediaPlayerReason](/zh-CN/api-reference/rtc/harmonyos/enum-mediaplayerreason)。
