## 详情

该方法每次只能删除一张背景图，如果你需要删除多张背景图，则需多次调用该方法。

<a id="api_livetranscoding_removebackgroundimage__parameters"></a>

## 参数

<ParameterList>
<a id="backgroundimage"></a>
<Parameter name="backgroundImage">

直播视频上的背景图。必须为 PNG 格式。详见 [AgoraImage](/zh-CN/api-reference/rtc/harmonyos/class-rtcimage)。

</Parameter>
</ParameterList>

<a id="api_livetranscoding_removebackgroundimage__return_values"></a>

## 返回值

是否成功删除背景图：

- `true`：成功。
- `false`：失败。
