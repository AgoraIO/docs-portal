## 枚举值

### `NONE`

0: 将背景处理为 Alpha 数据，不作替换，仅分割人像和背景。设置后，你可以调用 [startLocalVideoTranscoder](/zh-CN/api-reference/rtc/harmonyos/local-transcoder#api_irtcengine_startlocalvideotranscoder)，实现人像画中画的效果。

### `COLOR`

1:（默认）背景为纯色。

### `IMG`

2: 背景为 PNG、JPG 格式的图片。

### `BLUR`

3: 背景为虚化处理后的背景。

### `VIDEO`

4: 背景为 MP4、AVI、MKV、FLV 等格式的本地视频。
