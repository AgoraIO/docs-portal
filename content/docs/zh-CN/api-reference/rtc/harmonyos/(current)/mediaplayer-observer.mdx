<a id="api_imediaplayer_registerplayersourceobserver"></a>

## registerPlayerObserver

注册一个播放观测器。

<a id="api_imediaplayer_registerplayersourceobserver__prototype"></a>

```arkts
public abstract registerPlayerObserver(playerObserver:IMediaPlayerObserver);
```

<a id="api_imediaplayer_registerplayersourceobserver__detailed_desc"></a>

<a id="api_imediaplayer_registerplayersourceobserver__timing"></a>

### 调用时机

加入频道前后均可调用。

<a id="api_imediaplayer_registerplayersourceobserver__restriction"></a>

### 调用限制

无。

<a id="api_imediaplayer_registerplayersourceobserver__parameters"></a>

### 参数

#### `playerObserver`

播放观测器，报告播放中的事件，详见 [IMediaPlayerObserver](/zh-CN/api-reference/rtc/harmonyos/rtc-interface-class#class_imediaplayersourceobserver)。

<a id="api_imediaplayer_registerplayersourceobserver__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。 详见 [错误码](https://doc.shengwang.cn/api-ref/rtc/harmonyos/error-code) 了解详情和解决建议。

## onAudioVolumeIndication

媒体播放器音量提示回调。

<a id="callback_imediaplayersourceobserver_onaudiovolumeindication__prototype"></a>

```arkts
onAudioVolumeIndication?:(volume:number) => void
```

<a id="callback_imediaplayersourceobserver_onaudiovolumeindication__detailed_desc"></a>

SDK 每 200 毫秒触发一次该回调，报告媒体播放器当前的音量。

<a id="callback_imediaplayersourceobserver_onaudiovolumeindication__parameters"></a>

### 参数

#### `volume`

播放器的当前音量，取值范围为 [0,255]。

- [IMediaPlayerObserver](/zh-CN/api-reference/rtc/harmonyos/rtc-interface-class#class_imediaplayersourceobserver)

<a id="callback_imediaplayersourceobserver_onplaybufferupdated"></a>

## onPlayBufferUpdated

报告当前缓冲数据能播放的时间。

<a id="callback_imediaplayersourceobserver_onplaybufferupdated__prototype"></a>

```arkts
onPlayBufferUpdated?:(playCachedBuffer:number) => void
```

<a id="callback_imediaplayersourceobserver_onplaybufferupdated__detailed_desc"></a>

播放在线媒体资源的过程中，SDK 会每隔 1 秒触发一次该回调，报告当前缓冲的数据能支持的播放时间。

- 当缓冲数据支持的播放时间小于阈值（默认为 0）时，返回 BUFFER_LOW (6)。
- 当缓冲数据支持的播放时间大于阈值（默认为 0）时，返回 BUFFER_RECOVER (7)。

<a id="callback_imediaplayersourceobserver_onplaybufferupdated__parameters"></a>

### 参数

#### `playCachedBuffer`

当前缓冲的数据能支持的播放时间 (毫秒)。

- [IMediaPlayerObserver](/zh-CN/api-reference/rtc/harmonyos/rtc-interface-class#class_imediaplayersourceobserver)

## onPlayerEvent

报告播放器的事件。

<a id="callback_imediaplayersourceobserver_onplayerevent__prototype"></a>

```arkts
onPlayerEvent?:(eventCode:Constants.MediaPlayerEvent,elapsedTime:number,message:string) => void
```

<a id="callback_imediaplayersourceobserver_onplayerevent__detailed_desc"></a>

- 调用 [seek](/zh-CN/api-reference/rtc/harmonyos/mediaplayer-control#api_imediaplayer_seek) 定位播放后，SDK 会触发该回调，报告定位播放的结果。

<a id="callback_imediaplayersourceobserver_onplayerevent__parameters"></a>

### 参数

#### `eventCode`

播放器事件，详见 [MediaPlayerEvent](/zh-CN/api-reference/rtc/harmonyos/enum-mediaplayerevent)。

#### `elapsedTime`

发生事件的时间 (毫秒)。

#### `message`

事件的信息。

- [IMediaPlayerObserver](/zh-CN/api-reference/rtc/harmonyos/rtc-interface-class#class_imediaplayersourceobserver)

## onPositionChanged

报告当前媒体资源的播放进度。

<a id="callback_imediaplayersourceobserver_onpositionchanged__prototype"></a>

```arkts
onPositionChanged?:(positionMs:number,timestampMs:number) => void
```

<a id="callback_imediaplayersourceobserver_onpositionchanged__detailed_desc"></a>

播放媒体文件时，SDK 每隔 1 秒会自动触发该回调，报告当前播放进度。

<a id="callback_imediaplayersourceobserver_onpositionchanged__parameters"></a>

### 参数

#### `positionMs`

当前播放进度，单位为 ms。

#### `timestampMs`

当前播放进度的 NTP 时间戳，单位为 ms。

- [IMediaPlayerObserver](/zh-CN/api-reference/rtc/harmonyos/rtc-interface-class#class_imediaplayersourceobserver)
