<a id="followencodedimensionratio"></a>
<Parameter name="followEncodeDimensionRatio">

（可选）是否跟随 [setVideoEncoderConfiguration](/zh-CN/api-reference/rtc/harmonyos/video/video-basic#api_irtcengine_setvideoencoderconfiguration) 中设置的视频宽高比：

- `true`：(默认) 跟随。SDK 会将采集到的视频按照已设置的视频宽高比进行裁剪。
- `false`：不跟随。SDK不改变采集到的视频帧宽高比。

</Parameter>
