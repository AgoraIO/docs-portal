```arkts
export class MusicCacheInfo
{
  
  public songCode:bigint = BigInt(0)
  
  public status:number = 0
}
```

<a id="class_musiccacheinfo__detailed_desc"></a>

<a id="class_musiccacheinfo__parameters"></a>

### `songCode`

音乐资源的编号，用于标识音乐资源。

音乐资源的缓存状态：

- MUSIC_CACHE_STATUS_TYPE_CACHED (0)：音乐资源已缓存。
- MUSIC_CACHE_STATUS_TYPE_CACHING (1)：音乐资源正在缓存。
