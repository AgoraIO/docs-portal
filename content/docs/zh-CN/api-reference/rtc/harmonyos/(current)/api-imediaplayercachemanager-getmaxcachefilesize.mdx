## 详情

SDK 默认的缓存文件总缓存上限为 1GB。你可以调用 [setMaxCacheFileSize](/zh-CN/api-reference/rtc/harmonyos/api-imediaplayercachemanager-setmaxcachefilesize) 方法自定义总缓存大小的上限。

<a id="api_imediaplayercachemanager_getmaxcachefilesize__return_values"></a>

## 返回值

- &gt; 0：方法调用成功，返回缓存文件的总缓存上限，单位为字节。
- &lt; 0：方法调用失败，详见 [MediaPlayerReason](/zh-CN/api-reference/rtc/harmonyos/enum-mediaplayerreason)。
