## 枚举值

<ParameterList>
<a id="stopped"></a>
<Parameter name="STOPPED">

0: 远端视频默认初始状态。在 LOCAL_MUTED、REMOTE_MUTED 或 REMOTE_OFFLINE 的情况下，会报告该状态。

</Parameter>
<a id="starting"></a>
<Parameter name="STARTING">

1: 本地用户已接收远端视频首包。

</Parameter>
<a id="decoding"></a>
<Parameter name="DECODING">

2: 远端视频流正在解码，正常播放。在 NETWORK_RECOVERY、LOCAL_UNMUTED、REMOTE_UNMUTED 或 AUDIO_FALLBACK_RECOVERY 的情况下，会报告该状态。

</Parameter>
<a id="frozen"></a>
<Parameter name="FROZEN">

3: 远端视频流卡顿。在 NETWORK_CONGESTION 或 AUDIO_FALLBACK 的情况下，会报告该状态。

</Parameter>
<a id="failed"></a>
<Parameter name="FAILED">

4: 远端视频流播放失败。在 INTERNAL 的情况下，会报告该状态。

</Parameter>
</ParameterList>
