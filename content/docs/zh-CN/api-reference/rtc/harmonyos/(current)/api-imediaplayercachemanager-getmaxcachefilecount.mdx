## 详情

SDK 默认的缓存文件数量上限为 1000。

<a id="api_imediaplayercachemanager_getmaxcachefilecount__return_values"></a>

## 返回值

- &gt; 0：方法调用成功，返回缓存文件数量的上限。
- &lt; 0：方法调用失败，详见 [MediaPlayerReason](/zh-CN/api-reference/rtc/harmonyos/enum-mediaplayerreason)。
