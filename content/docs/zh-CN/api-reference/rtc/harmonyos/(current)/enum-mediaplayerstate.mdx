## 枚举值

### `UNKNOWN`

-1: 未知状态。

### `IDLE`

0: 默认状态。播放器会在你打开媒体文件之前和结束播放之后返回该状态码。

### `OPENING`

1: 正在打开媒体文件。

### `OPEN_COMPLETED`

2: 成功打开媒体文件。

### `PLAYING`

3: 正在播放。

### `PAUSED`

4: 暂停播放。

### `PLAYBACK_COMPLETED`

5: 播放完毕。

### `PLAYBACK_ALL_LOOPS_COMPLETED`

6: 循环播放已结束。

### `STOPPED`

7: 播放已停止。

### `FAILED`

100: 播放失败。
