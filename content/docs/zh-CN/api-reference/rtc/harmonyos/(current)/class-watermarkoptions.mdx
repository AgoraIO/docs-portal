<a id="class_watermarkoptions__parameters"></a>

### `visibleInPreview`

水印是否在本地预览视图中可见：

- true: （默认）水印在本地预览视图中可见。
- false: 水印在本地预览视图中不可见。

### `positionInLandscapeMode`

横屏模式下，显示水印图片的区域。详见 [Rectangle](/zh-CN/api-reference/rtc/harmonyos/class-rectangle)。

### `positionInPortraitMode`

竖屏模式下，显示水印图片的区域。详见 [Rectangle](/zh-CN/api-reference/rtc/harmonyos/class-rectangle)。
