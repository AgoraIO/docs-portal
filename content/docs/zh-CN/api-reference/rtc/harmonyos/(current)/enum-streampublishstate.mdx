## 枚举值

### `IDLE`

0: 加入频道后的初始发布状态。

### `NO_PUBLISHED`

1: 发布失败。可能是因为：

- 本地用户调用 muteLocalAudioStream (true) 或 muteLocalVideoStream (true) 停止发送本地媒体流。
- 本地用户调用 disableAudio 或 disableVideo 关闭本地音频或视频模块。
- 本地用户调用 enableLocalAudio (false) 或 enableLocalVideo (false) 关闭本地音频或视频采集。
- 本地用户角色为观众。

### `PUBLISHING`

2: 正在发布。

### `PUBLISHED`

3: 发布成功。
