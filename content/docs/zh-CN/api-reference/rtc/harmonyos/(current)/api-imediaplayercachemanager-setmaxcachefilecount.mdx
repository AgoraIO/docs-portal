<a id="api_imediaplayercachemanager_setmaxcachefilecount__parameters"></a>

## 参数

### `count`

可缓存的媒体文件数量的上限，默认值为 1000。

<a id="api_imediaplayercachemanager_setmaxcachefilecount__return_values"></a>

## 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败，详见 [MediaPlayerReason](/zh-CN/api-reference/rtc/harmonyos/enum-mediaplayerreason)。
