---
title: "PlayerPlaybackStats"
description: "当前播放的媒体资源的相关信息。"
---
<a id="class_playerplaybackstats__prototype"></a>

```arkts
export class PlayerPlaybackStats
{
  
  public videoFps:number = 0
  
  public videoBitrateInKbps:number = 0
  
  public audioBitrateInKbps:number = 0
  
  public totalBitrateInKbps:number = 0
}
```

<a id="class_playerplaybackstats__detailed_desc"></a>

<a id="class_playerplaybackstats__parameters"></a>

### `videoFps`

视频帧率，单位为 fps。

### `videoBitrateInKbps`

视频码率，单位为 kbps。

### `audioBitrateInKbps`

音频码率，单位为 kbps。

### `totalBitrateInKbps`

媒体流的总码率，单位为 kbps。
