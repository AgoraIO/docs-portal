## 枚举值

### DEFAULT

0: （默认）自动场景，根据用户角色和音频路由自动匹配合适的音质。

### GAME_STREAMING

3: 高音质场景，适用于音乐为主的场景。例如：乐器陪练。

### CHATROOM

5: 聊天室场景，适用于用户需要频繁上下麦的场景。例如：教育场景。

### CHORUS

7: 合唱场景。适用于网络条件良好，要求极低延时的实时合唱场景。

### MEETING

8: 会议场景，适用于人声为主的多人会议。
