## 枚举值

### UNKNOWN

0: 网络质量未知。

### EXCELLENT

1: 网络质量极好。

### GOOD

2: 用户主观感觉和 excellent 差不多，但码率可能略低于 excellent。

### POOR

3: 用户主观感受有瑕疵但不影响沟通。

### BAD

4: 勉强能沟通但不顺畅。

### VBAD

5: 网络质量非常差，基本不能沟通。

### DOWN

6: 完全无法沟通。
