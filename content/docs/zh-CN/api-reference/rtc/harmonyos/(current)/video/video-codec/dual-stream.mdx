## setDualStreamMode

在发送端设置双流模式并设置视频小流。

<a id="api_irtcengine_setdualstreammode2__prototype"></a>

```text
public abstract setDualStreamMode(mode: Constants.SimulcastStreamMode, streamConfig?: SimulcastStreamConfig): number;
```

<a id="api_irtcengine_setdualstreammode2__detailed_desc"></a>

### 详情

SDK 默认在发送端开启小流自适应模式 (AUTO)，即发送端不主动发送小流，**主播身份**的接收端可以调用 [setRemoteVideoStreamType](/zh-CN/api-reference/rtc/harmonyos/video/video-codec/dual-stream#api_irtcengine_setremotevideostreamtype) 发起小流申请，发送端收到申请后开始自动发送小流。

- 如果你想修改此行为，可以调用该方法并修改 mode 为 DISABLE（始终不发送小流）或 ENABLE（始终发送小流）。
- 如果你在进行修改后又想恢复该默认行为，可重新调用该方法，并将 mode 设置为 AUTO。

<a id="api_irtcengine_setdualstreammode2__parameters"></a>

### 参数

### mode

发送视频流的模式。详见 [SimulcastStreamMode](/zh-CN/api-reference/rtc/harmonyos/enum-simulcaststreammode)。

### streamConfig

视频小流的配置。详见 [SimulcastStreamConfig](/zh-CN/api-reference/rtc/harmonyos/class-simulcaststreamconfig)。

:::note
注： 当设置 mode 为 DISABLE 时，再设置 streamConfig 不会生效。
:::

<a id="api_irtcengine_setdualstreammode2__return_values"></a>

### 返回值

<a id="api_irtcengine_setdualstreammode2__ul_bpp_x2z_hqb"></a>

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。 详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。

## setRemoteDefaultVideoStreamType

设置默认订阅的视频流类型。

<a id="api_irtcengine_setremotedefaultvideostreamtype__prototype"></a>

```text
public abstract setRemoteDefaultVideoStreamType(streamType: Constants.VideoStreamType): number;
```

<a id="api_irtcengine_setremotedefaultvideostreamtype__detailed_desc"></a>

取决于发送端的默认行为和调用 [setDualStreamMode](/zh-CN/api-reference/rtc/harmonyos/video/video-codec/dual-stream#api_irtcengine_setdualstreammode2) 的具体设置，接收端调用该方法分为以下几种情况：

- SDK 默认在发送端开启小流自适应模式 (AUTO)，即：发送端仅发送大流，仅**主播身份**的接收端可以调用该方法发起小流申请，发送端收到申请后开始自动发送小流，此时频道内所有用户均可调用该方法切换到小流订阅模式。
- 当发送端调用 setDualStreamMode 并将 mode 设置为 DISABLE（始终不发送小流），则调用该方法不生效。
- 当发送端调用 setDualStreamMode 并将 mode 设置为 ENABLE（始终发送小流），则主播或观众身份的接收端均可调用该方法切换到小流订阅模式。

在接收视频小流时，SDK 会根据视频窗口的大小动态调整对应视频流的大小，以节约带宽和计算资源。视频小流默认的宽高比和视频大流的宽高比一致。根据当前大流的宽高比，系统会自动分配小流的分辨率、帧率及码率。

<a id="api_irtcengine_setremotedefaultvideostreamtype__timing"></a>

### 调用时机

该方法只能在加入频道前调用。SDK 不支持你在加入频道后修改默认订阅的视频流类型。

<a id="api_irtcengine_setremotedefaultvideostreamtype__restriction"></a>

### 调用限制

如果你既调用了该方法，也调用了 [setRemoteVideoStreamType](/zh-CN/api-reference/rtc/harmonyos/video/video-codec/dual-stream#api_irtcengine_setremotevideostreamtype)，则 SDK 以 setRemoteVideoStreamType 中的设置为准。

<a id="api_irtcengine_setremotedefaultvideostreamtype__parameters"></a>

### 参数

### streamType

默认订阅的视频流类型: [VideoStreamType](/zh-CN/api-reference/rtc/harmonyos/enum-videostreamtype)。

<a id="api_irtcengine_setremotedefaultvideostreamtype__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。

### 所属接口类

- [RtcEngine](/zh-CN/api-reference/rtc/harmonyos/rtc-interface-class#class_irtcengine)
