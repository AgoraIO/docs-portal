## setBeautyEffectOptions

设置美颜效果选项。

<a id="api_irtcengine_setbeautyeffectoptions__prototype"></a>

```text
public abstract setBeautyEffectOptions(enabled:boolean,options:BeautyOptions,sourceType?:Constants.MediaSourceType):number;
```

<a id="api_irtcengine_setbeautyeffectoptions__detailed_desc"></a>

开启本地美颜功能，并设置美颜效果选项。

<a id="api_irtcengine_setbeautyeffectoptions__timing"></a>

### 调用时机

请在 [enableVideo](/zh-CN/api-reference/rtc/harmonyos/video/video-basic#api_irtcengine_enablevideo) 或 [startPreview](/zh-CN/api-reference/rtc/harmonyos/video/video-basic#api_irtcengine_startpreview2) 之后调用该方法。

<a id="api_irtcengine_setbeautyeffectoptions__restriction"></a>

### 调用限制

- 该方法依赖于视频增强动态库 `libagora_clear_vision_extension.so`，如果删除该动态库会导致无法正常开启该功能。
- 该功能对设备性能要求较高，调用该方法时 SDK 会自动对当前设备能力进行检查。

<a id="api_irtcengine_setbeautyeffectoptions__parameters"></a>

### 参数

<ParameterList>
<a id="options"></a>
<Parameter name="options">

美颜选项，详细定义见 [BeautyOptions](/zh-CN/api-reference/rtc/harmonyos/class-beautyoptions)。

</Parameter>
</ParameterList>

是否开启美颜功能：

- `true`: 开启美颜功能。
- `false`:（默认）关闭美颜功能。

<a id="api_irtcengine_setbeautyeffectoptions__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。

  - -4：当前设备不支持该功能，可能的原因有：

    - 当前设备能力不满足美颜的使用要求，建议更换性能更高的设备。
