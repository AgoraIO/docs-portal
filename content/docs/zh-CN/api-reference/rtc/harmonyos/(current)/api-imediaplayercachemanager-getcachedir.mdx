<a id="api_imediaplayercachemanager_getcachedir__detailed_desc"></a>

## 详情

如果你在调用该方法前未曾调用 [setCacheDir](/zh-CN/api-reference/rtc/harmonyos/api-imediaplayercachemanager-setcachedir) 方法自定义缓存文件的储存路径，该方法返回的为 SDK 默认的缓存文件储存路径。

<a id="api_imediaplayercachemanager_getcachedir__return_values"></a>

## 返回值

- &lt; 0：方法调用失败，详见 [MediaPlayerReason](/zh-CN/api-reference/rtc/harmonyos/enum-mediaplayerreason)。
