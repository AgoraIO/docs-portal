## pauseAllChannelMediaRelay

暂停向所有目标频道转发媒体流。

<a id="api_irtcengine_pauseallchannelmediarelay__prototype"></a>

```text
public abstract pauseAllChannelMediaRelay():number;
```

<a id="api_irtcengine_pauseallchannelmediarelay__detailed_desc"></a>

### 详情

开始跨频道转发媒体流后，如果你需要暂停向所有频道转发媒体流，可以调用该方法；暂停后，如果要恢复跨频道媒体流转发，可以调用 [resumeAllChannelMediaRelay](/zh-CN/api-reference/rtc/harmonyos/cloud-media-relay/channel-media-relay#api_irtcengine_resumeallchannelmediarelay) 方法。

:::caution
注意： 该方法需要在调用 [startOrUpdateChannelMediaRelay](/zh-CN/api-reference/rtc/harmonyos/cloud-media-relay/channel-media-relay#api_irtcengine_startorupdatechannelmediarelay) 开始跨频道媒体流转发后调用。
:::

<a id="api_irtcengine_pauseallchannelmediarelay__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。

  - -5: 方法调用被拒绝。当前没有正在进行的跨频道媒体流转发。

## startOrUpdateChannelMediaRelay

开始或更新跨频道媒体流转发。

<a id="api_irtcengine_startorupdatechannelmediarelay__prototype"></a>

```text
public abstract startOrUpdateChannelMediaRelay(channelMediaRelayConfiguration: ChannelMediaRelayConfiguration): number;
```

<a id="api_irtcengine_startorupdatechannelmediarelay__detailed_desc"></a>

### 详情

首次成功调用该方法将开始跨频道转发媒体流。如需将流转发到多个目标频道，或退出当前的转发频道，可以再次调用该方法添加或移除转发的目标频道。该功能最多支持将媒体流转发至 6 个目标频道。

成功调用该方法后，SDK 会触发 [onChannelMediaRelayStateChanged](/zh-CN/api-reference/rtc/harmonyos/cloud-media-relay/channel-media-relay#callback_irtcengineeventhandler_onchannelmediarelaystatechanged) 回调，报告当前的跨频道媒体流转发状态。常见状态如下：

- 如果 onChannelMediaRelayStateChanged 回调报告 RUNNING (2) 和 OK (0)， 则表示 SDK 开始在源频道和目标频道之间转发媒体流。
- 如果 onChannelMediaRelayStateChanged 回调报告 FAILURE (3)， 则表示跨频道媒体流转发出现异常。

:::caution
注意：

- 请在成功加入频道后调用该方法。
- 在直播场景中，只有角色为主播的用户才能调用该方法。
- 跨频道媒体流转发功能需要[联系技术支持](https://ticket.shengwang.cn/)开通。
- 该功能不支持 String 型 UID。
:::

<a id="api_irtcengine_startorupdatechannelmediarelay__parameters"></a>

### 参数

### channelMediaRelayConfiguration

跨频道媒体流转发参数配置。详见 [ChannelMediaRelayConfiguration](/zh-CN/api-reference/rtc/harmonyos/class-channelmediarelayconfiguration)。

<a id="api_irtcengine_startorupdatechannelmediarelay__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。

  - -1: 一般性的错误（未明确归类）。
  - -2: 参数无效。
  - -8：内部状态错误。可能因为用户角色不是主播。

## stopChannelMediaRelay

停止跨频道媒体流转发。一旦停止，主播会退出所有目标频道。

<a id="api_irtcengine_stopchannelmediarelay__prototype"></a>

```text
public abstract stopChannelMediaRelay(): number;
```

<a id="api_irtcengine_stopchannelmediarelay__detailed_desc"></a>

### 详情

成功调用该方法后，SDK 会触发 [onChannelMediaRelayStateChanged](/zh-CN/api-reference/rtc/harmonyos/cloud-media-relay/channel-media-relay#callback_irtcengineeventhandler_onchannelmediarelaystatechanged) 回调。如果报告 IDLE (0) 和 OK (0)，则表示已停止转发媒体流。

:::caution
注意：
       如果该方法调用不成功，SDK 会触发 onChannelMediaRelayStateChanged 回调，并报告状态码 SERVER_NO_RESPONSE (2) 或 SERVER_CONNECTION_LOST (8)。你可以调用 [leaveChannel](/zh-CN/api-reference/rtc/harmonyos/channel#api_irtcengine_leavechannel2) 方法离开频道，跨频道媒体流转发会自动停止。
:::

<a id="api_irtcengine_stopchannelmediarelay__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。

  - -5: 方法调用被拒绝。当前没有正在进行的跨频道媒体流转发。
