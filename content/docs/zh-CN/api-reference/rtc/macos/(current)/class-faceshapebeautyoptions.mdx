<a id="class_faceshapebeautyoptions__prototype"></a>

```objectivec
__attribute__((visibility("default"))) @interface AgoraFaceShapeBeautyOptions: NSObject
@property(nonatomic, assign) AgoraFaceShapeStyle shapeStyle;
@property(nonatomic, assign) int styleIntensity;
@end
```

<a id="class_faceshapebeautyoptions__parameters"></a>

## 属性

### `shapeStyle`

美型风格特效选项。详见 [AgoraFaceShapeStyle](/zh-CN/api-reference/rtc/macos/enum-faceshapebeautystyle)。

### `styleIntensity`

美型风格特效的强度，取值范围为 [0.0, 1.0]。默认值为 0.0，表示无美型效果。值越大，美型效果越明显。
