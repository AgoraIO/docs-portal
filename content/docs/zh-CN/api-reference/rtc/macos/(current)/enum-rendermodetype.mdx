## 枚举值

### AgoraVideoRenderModeHidden

（1）：隐藏模式。优先填满窗口，超出窗口尺寸的视频部分将被裁剪。

### AgoraVideoRenderModeFit

（2）：适应模式。优先完整显示视频内容，未填满窗口的区域以黑色填充。

### AgoraVideoRenderModeAdaptive

（3）：自适应模式。该模式已废弃。
