### `自从`

自 v4.0.0 版本新增。

<a id="enum_lowlightenhancemode__parameters"></a>

## 枚举值

### `AgoraLowlightEnhanceModeAuto`

（0）：（默认）自动模式。SDK 会根据环境光自动启用或关闭低光增强功能，以补偿光照不足或防止过度曝光。

### `AgoraLowlightEnhanceModeManual`

（1）：手动模式。需由用户手动启用或关闭低光增强功能。
