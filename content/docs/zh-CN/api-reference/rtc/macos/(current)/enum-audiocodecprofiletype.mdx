## 枚举值

### `AgoraAudioCodecProfileLCAAC`

（0）：（默认）LC-AAC 编解码配置。

### `AgoraAudioCodecProfileHEAAC`

（1）：HE-AAC 编解码配置。

### `AgoraAudioCodecProfileHEAACv2`

（2）：HE-AAC v2 编解码配置。
