## 通用设备管理

<a id="api_irtcengine_enumeratedevices"></a>

## enumerateDevices:

枚举系统中的所有音频和视频设备。

<a id="api_irtcengine_enumeratedevices__prototype"></a>

```objectivec
- (NSArray<AgoraRtcDeviceInfo *> * _Nullable)enumerateDevices:(AgoraMediaDeviceType)type NS_SWIFT_NAME(enumerateDevices(_:));
```

<a id="api_irtcengine_enumeratedevices__detailed_desc"></a>

该方法返回一个 `NSArray` 对象，其中包含系统中的所有音频和视频设备。你可以使用 `NSArray` 类型的 [AgoraRtcDeviceInfo](/zh-CN/api-reference/rtc/macos/class-agorartcdeviceinfo) 对象来枚举设备。

:::info[注]
请勿在主线程中调用此方法。
:::

<a id="api_irtcengine_enumeratedevices__parameters"></a>

### 参数

#### `type`

设备类型，包括音频采集、音频播放、视频采集或视频播放设备。详见 [AgoraMediaDeviceType](/zh-CN/api-reference/rtc/macos/enum-mediadevicetype)。

<a id="api_irtcengine_enumeratedevices__return_values"></a>

### 返回值

- 方法调用成功，返回一个包含所有音频和视频设备的 `NSArray` 对象，详见 [AgoraRtcDeviceInfo](/zh-CN/api-reference/rtc/macos/class-agorartcdeviceinfo)。
- 方法调用失败，返回 nil。

### 所属接口类
- [AgoraRtcEngineKit](/zh-CN/api-reference/rtc/macos/rtc-interface-class#class_irtcengine)

<a id="api_irtcengine_getdeviceinfo"></a>

## getDeviceInfo:

获取当前设备名称。

<a id="api_irtcengine_getdeviceinfo__prototype"></a>

```objectivec
- (AgoraRtcDeviceInfo * _Nullable)getDeviceInfo:(AgoraMediaDeviceType)type NS_SWIFT_NAME(getDeviceInfo(_:));
```

<a id="api_irtcengine_getdeviceinfo__detailed_desc"></a>

你可以通过该方法，根据 `type` 参数的设置，获取当前的音频或视频采集设备。

<a id="api_irtcengine_getdeviceinfo__parameters"></a>

### 参数

#### `type`

设备类型，包括音频采集、音频播放、视频采集或视频播放设备。详见 [AgoraMediaDeviceType](/zh-CN/api-reference/rtc/macos/enum-mediadevicetype)。

<a id="api_irtcengine_getdeviceinfo__return_values"></a>

### 返回值

- 方法调用成功时，返回一个 [AgoraRtcDeviceInfo](/zh-CN/api-reference/rtc/macos/class-agorartcdeviceinfo) 对象。
- 方法调用失败时，返回 nil。

### 所属接口类
- [AgoraRtcEngineKit](/zh-CN/api-reference/rtc/macos/rtc-interface-class#class_irtcengine)

## getDeviceVolume:

```objectivec
- (int)getDeviceVolume:(AgoraMediaDeviceType)type NS_SWIFT_NAME(getDeviceVolume(_:));
```

<a id="api_irtcengine_getdevicevolume__detailed_desc"></a>

<a id="api_irtcengine_getdevicevolume__parameters"></a>

### 参数

#### `type`

设备类型，包括音频采集、音频播放、视频采集或视频播放设备。详见 [AgoraMediaDeviceType](/zh-CN/api-reference/rtc/macos/enum-mediadevicetype)。

<a id="api_irtcengine_monitordevicechange"></a>

## monitorDeviceChange:

监控设备状态变化。

<a id="api_irtcengine_monitordevicechange__prototype"></a>

```objectivec
- (void)monitorDeviceChange:(BOOL)enabled NS_SWIFT_NAME(monitorDeviceChange(_:));
```

<a id="api_irtcengine_monitordevicechange__detailed_desc"></a>

你可以通过该方法监控外部音视频设备（如外接摄像头）的插拔和更换。

<a id="api_irtcengine_monitordevicechange__parameters"></a>

### 参数

#### `enabled`

是否监控设备状态变化：

- YES：开启设备状态监控。
- NO：关闭设备状态监控。

### 所属接口类
- [AgoraRtcEngineKit](/zh-CN/api-reference/rtc/macos/rtc-interface-class#class_irtcengine)

<a id="api_irtcengine_setdevicevolume"></a>

## setDeviceVolume:volume:

设置指定设备的音量。

<a id="api_irtcengine_setdevicevolume__prototype"></a>

```objectivec
- (int)setDeviceVolume:(AgoraMediaDeviceType)type volume:(int)volume NS_SWIFT_NAME(setDeviceVolume(_:volume:));
```

<a id="api_irtcengine_setdevicevolume__detailed_desc"></a>

设置音频或视频采集或播放设备的音量。

:::info[注]
请在加入频道后调用该方法。
:::

<a id="api_irtcengine_setdevicevolume__parameters"></a>

### 参数

#### `type`

设备类型，包括音频采集、音频播放、视频采集或视频播放设备，详见 [AgoraMediaDeviceType](/zh-CN/api-reference/rtc/macos/enum-mediadevicetype)。

#### `volume`

指定设备的音量，取值范围为 [0, 255]。

<a id="api_irtcengine_setdevicevolume__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/macos/error-code)了解详情和解决建议。

### 所属接口类
- [AgoraRtcEngineKit](/zh-CN/api-reference/rtc/macos/rtc-interface-class#class_irtcengine)

<a id="api_irtcengine_statechanged"></a>

## rtcEngine:device:type:stateChanged:

报告设备状态的变化回调。

<a id="api_irtcengine_statechanged__prototype"></a>

```objectivec
- (void)rtcEngine:(AgoraRtcEngineKit * _Nonnull)engine device:(NSString * _Nonnull)deviceId type:(AgoraMediaDeviceType)deviceType stateChanged:(NSInteger)state NS_SWIFT_NAME(rtcEngine(_:device:type:stateChanged:));
```

<a id="api_irtcengine_statechanged__detailed_desc"></a>

:::info[注]
该回调仅适用于 macOS 平台。
:::

<a id="api_irtcengine_statechanged__timing"></a>

### 调用时机

该回调在设备状态发生变化时被触发。

<a id="api_irtcengine_statechanged__parameters"></a>

### 参数

#### `engine`

你使用的 [AgoraRtcEngineKit](/zh-CN/api-reference/rtc/macos/rtc-interface-class#class_irtcengine) 实例。详见 [AgoraRtcEngineKit](/zh-CN/api-reference/rtc/macos/rtc-interface-class#class_irtcengine)。

#### `deviceId`

设备的 ID。

#### `deviceType`

设备类型，详见 [AgoraMediaDeviceType](/zh-CN/api-reference/rtc/macos/enum-mediadevicetype)。

#### `state`

设备的状态：

- 0：已添加。
- 8：已移除。

### 所属接口类
- [AgoraRtcEngineKit](/zh-CN/api-reference/rtc/macos/rtc-interface-class#class_irtcengine)
