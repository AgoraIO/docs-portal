## 枚举值

<ParameterList>
<a id="agorablurlow"></a>
<Parameter name="AgoraBlurLow">

（1）：对自定义背景图像应用低强度模糊，用户几乎可以清晰地看到背景。

</Parameter>
<a id="agorablurmedium"></a>
<Parameter name="AgoraBlurMedium">

（2）：对自定义背景图像应用中等强度模糊，用户难以识别背景中的细节。

</Parameter>
<a id="agorablurhigh"></a>
<Parameter name="AgoraBlurHigh">

（3）：（默认）对自定义背景图像应用高强度模糊，用户几乎无法看到背景中的任何特征。

</Parameter>
