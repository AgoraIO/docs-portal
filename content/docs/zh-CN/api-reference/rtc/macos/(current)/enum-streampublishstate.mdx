## 枚举值

### `AgoraStreamPublishStateIdle`

（0）：加入频道后处于初始发布状态。

### `AgoraStreamPublishStateNoPublished`

（1）：本地流发布失败。可能的原因包括：本地用户调用 [muteLocalAudioStream:](/zh-CN/api-reference/rtc/macos/publishnsubscribe#api_irtcengine_mutelocalaudiostream) （YES ）或 [muteLocalVideoStream:](/zh-CN/api-reference/rtc/macos/publishnsubscribe#api_irtcengine_mutelocalvideostream) （YES ）停止发送本地媒体流；调用 [disableAudio](/zh-CN/api-reference/rtc/macos/audio-basic#api_irtcengine_disableaudio) 或 [disableVideo](/zh-CN/api-reference/rtc/macos/video-basic#api_irtcengine_disablevideo) 禁用本地音频或视频模块；调用 [enableLocalAudio:](/zh-CN/api-reference/rtc/macos/audio-capture#api_irtcengine_enablelocalaudio) （NO ）或 [enableLocalVideo:](/zh-CN/api-reference/rtc/macos/video-basic#api_irtcengine_enablelocalvideo) （NO ）禁用本地音视频采集；或本地用户角色为观众。

### `AgoraStreamPublishStatePublishing`

（2）：正在发布中。

### `AgoraStreamPublishStatePublished`

（3）：发布成功。
