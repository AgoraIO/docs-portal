## enableDualStreamMode:

在发送端启用或关闭不同质量层级的视频流模式。

<a id="api_irtcengine_enabledualstreammode__prototype"></a>

```text
- (int)enableDualStreamMode:(BOOL)enabled NS_SWIFT_NAME(enableDualStreamMode(_:)) __deprecated_msg("use setDualStreamMode: instead.");
```

<a id="api_irtcengine_enabledualstreammode__detailed_desc"></a>

### 废弃

自 v4.2.0 版本废弃，请改用 `setDualStreamMode`。

不同质量层级的视频流是一对视频大流和视频小流的组合：

- 视频大流：高码率，高分辨率。
- 视频小流：低码率，低分辨率。

启用该模式后，你可以调用 [setRemoteVideoStream\:type:](/zh-CN/api-reference/rtc/macos/publishnsubscribe#api_irtcengine_setremotevideostreamtype) 方法，在接收端选择接收高质量或低质量的视频流。

:::note
注：

- 该方法适用于发送端的所有类型的视频流，包括但不限于摄像头采集的视频流、屏幕共享流和自定义采集的视频流。
- 如果你需要在多频道场景中启用不同质量层级的视频流，可以调用 [enableDualStreamModeEx\:streamConfig\:connection:](/zh-CN/api-reference/rtc/macos/publishnsubscribe#api_irtcengineex_enabledualstreammodeex) 方法。
- 你可以在加入频道前或加入频道后调用该方法。
:::
