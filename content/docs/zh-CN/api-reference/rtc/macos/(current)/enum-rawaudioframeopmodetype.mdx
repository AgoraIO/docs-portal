## 枚举值

### AgoraAudioRawFrameOperationModeReadOnly

（0）：只读模式。例如，用户通过 `Agora SDK` 获取音频数据后进行媒体推流。

（2）：读写模式。例如，用户使用自有音效处理模块对音频进行预处理，如变声。
