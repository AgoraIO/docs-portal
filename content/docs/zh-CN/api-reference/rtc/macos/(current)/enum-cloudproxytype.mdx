## 枚举值

### AgoraNoneProxy

（0）：（默认）自动模式。在该模式下，SDK 会尝试直接连接 SD-RTN™，若连接失败，则自动切换为 TCP/TLS 443。

### AgoraUdpProxy

（1）：UDP 协议云代理模式。SDK 始终通过 UDP 传输数据。

### AgoraTcpProxy

（2）：TCP（加密）协议云代理模式。SDK 始终通过 TCP/TLS 443 传输数据。
