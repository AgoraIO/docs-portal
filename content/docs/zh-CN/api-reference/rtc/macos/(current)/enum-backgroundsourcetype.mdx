### `自从`

自 v3.7.200 版本新增。

<a id="enum_backgroundsourcetype__parameters"></a>

## 枚举值

### `AgoraVirtualBackgroundNone`

（0）：将背景处理为 Alpha 数据，不进行替换，仅分离人像与背景。设置该值后，可调用 [startLocalVideoTranscoder:](/zh-CN/api-reference/rtc/macos/local-transcoder#api_irtcengine_startlocalvideotranscoder) 实现画中画效果。

### `AgoraVirtualBackgroundColor`

（1）：（默认）背景为纯色图像。

### `AgoraVirtualBackgroundImg`

（2）：背景为 PNG 或 JPG 格式的图像。

### `AgoraVirtualBackgroundBlur`

（3）：背景为原始背景的模糊版本。

### `AgoraVirtualBackgroundVideo`

（4）：背景为本地视频，支持 MP4、AVI、MKV、FLV 等格式。
