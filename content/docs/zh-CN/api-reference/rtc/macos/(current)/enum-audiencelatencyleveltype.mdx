<a id="enum_audiencelatencyleveltype__detailed_desc"></a>

仅当用户角色设置为 `AgoraClientRoleAudience` 时生效。

<a id="enum_audiencelatencyleveltype__parameters"></a>

## 枚举值

### `AgoraAudienceLatencyLevelLowLatency`

（1）：低延迟。

### `AgoraAudienceLatencyLevelUltraLowLatency`

（2）：（默认）超低延迟。
