## adjustPlaybackSignalVolume:

调节所有远端用户的播放信号音量。

<a id="api_irtcengine_adjustplaybacksignalvolume__prototype"></a>

```objectivec
- (int)adjustPlaybackSignalVolume:(NSInteger)volume NS_SWIFT_NAME(adjustPlaybackSignalVolume(_:));
```

<a id="api_irtcengine_adjustplaybacksignalvolume__detailed_desc"></a>

该方法用于调节本地混音播放的所有远端用户的信号音量。如果你需要调节本地播放的指定远端用户的信号音量，建议调用 `adjustUserPlaybackSignalVolume:` 方法。

<a id="api_irtcengine_adjustplaybacksignalvolume__timing"></a>

### 调用时机

该方法可以在加入频道前或后调用。

<a id="api_irtcengine_adjustplaybacksignalvolume__parameters"></a>

### 参数

#### `volume`

用户的音量。取值范围为 [0,400]。

- 0：静音。
- 100：（默认）原始音量。
- 400：原始音量的四倍（将音频信号放大四倍）。

<a id="api_irtcengine_adjustplaybacksignalvolume__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/macos/error-code)了解详情和解决建议。

### 所属接口类
- [AgoraRtcEngineKit](/zh-CN/api-reference/rtc/macos/rtc-interface-class#class_irtcengine)

## disableAudio

禁用音频模块。

<a id="api_irtcengine_disableaudio__prototype"></a>

```objectivec
- (int)disableAudio NS_SWIFT_NAME(disableAudio());
```

<a id="api_irtcengine_disableaudio__detailed_desc"></a>

音频模块默认启用。你可以调用该方法禁用音频模块。

:::info[注]
该方法会重置内部引擎，并需要一些时间生效。声网建议使用以下 API 分别控制音频模块：

- enableLocalAudio:：是否启用麦克风以创建本地音频流。
- （仅适用于 macOS） enableLoopbackRecording:deviceName:：是否启用回采音频采集。
- muteLocalAudioStream:：是否发布本地音频流。
- muteRemoteAudioStream:mute:：是否订阅并播放远端音频流。
- muteAllRemoteAudioStreams:：是否订阅并播放所有远端音频流。
:::

<a id="api_irtcengine_disableaudio__timing"></a>

### 调用时机

该方法可以在加入频道前或加入频道后调用。离开频道后仍然有效。

<a id="api_irtcengine_disableaudio__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/macos/error-code)了解详情和解决建议。

### 所属接口类
- [AgoraRtcEngineKit](/zh-CN/api-reference/rtc/macos/rtc-interface-class#class_irtcengine)

## enableAudio

启用音频模块。

<a id="api_irtcengine_enableaudio__prototype"></a>

```objectivec
- (int)enableAudio NS_SWIFT_NAME(enableAudio());
```

<a id="api_irtcengine_enableaudio__detailed_desc"></a>

音频模块默认处于启用状态。你在调用 [disableAudio](/zh-CN/api-reference/rtc/macos/audio/audio-basic#api_irtcengine_disableaudio) 方法禁用音频模块后，可以调用该方法重新启用音频模块。

:::info[注]
- 调用该方法会重置整个引擎，导致响应时间变慢。你可以根据实际需求，使用以下方法分别控制音频模块的具体功能：
  - enableLocalAudio:：是否启用麦克风以创建本地音频流。
  - muteLocalAudioStream:：是否发布本地音频流。
  - muteRemoteAudioStream:mute:：是否订阅并播放远端音频流。
  - muteAllRemoteAudioStreams:：是否订阅并播放所有远端音频流。
- 成功调用该方法会重置 enableLocalAudio:、 muteRemoteAudioStream:mute: 和 muteAllRemoteAudioStreams: 的设置，请谨慎使用。
:::

<a id="api_irtcengine_enableaudio__timing"></a>

### 调用时机

该方法可以在加入频道前或加入频道后调用，离开频道后仍然有效。

<a id="api_irtcengine_enableaudio__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/macos/error-code)了解详情和解决建议。

## enableAudioVolumeIndication:smooth:reportVad:

启用用户音量提示的上报功能。

<a id="api_irtcengine_enableaudiovolumeindication__prototype"></a>

```objectivec
- (int)enableAudioVolumeIndication:(NSInteger)interval
                            smooth:(NSInteger)smooth
                         reportVad:(BOOL)reportVad NS_SWIFT_NAME(enableAudioVolumeIndication(_:smooth:reportVad:));
```

<a id="api_irtcengine_enableaudiovolumeindication__detailed_desc"></a>

该方法用于启用 SDK 定期向你报告本地发送音频流用户和瞬时音量最高的最多三位远端用户的音量信息。

<a id="api_irtcengine_enableaudiovolumeindication__timing"></a>

### 调用时机

该方法可以在加入频道前或后调用。

<a id="api_irtcengine_enableaudiovolumeindication__parameters"></a>

### 参数

#### `interval`

设置两次音量提示之间的时间间隔（单位为毫秒）：

- ≤ 0：关闭音量提示功能。
- &gt; 0：两次音量提示之间的时间间隔。确保该参数值大于 10，否则你将无法收到 rtcEngine:reportAudioVolumeIndicationOfSpeakers:totalVolume: 回调。建议设置为大于 100。

#### `smooth`

设置音量提示的灵敏度平滑系数，取值范围为 0 到 10，推荐值为 3。数值越大，音量提示越灵敏。

#### `reportVad`

是否启用本地用户的语音活动检测（Voice Activity Detection）：

- YES：启用语音活动检测。启用后， rtcEngine:reportAudioVolumeIndicationOfSpeakers:totalVolume: 回调中的 vad 参数会报告本地用户的语音活动状态。
- NO：（默认）关闭语音活动检测。关闭后，除非引擎自动检测本地用户的语音活动，否则 vad 参数不会报告本地用户的语音活动状态。

<a id="api_irtcengine_enableaudiovolumeindication__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/macos/error-code)了解详情和解决建议。

### 所属接口类
- [AgoraRtcEngineKit](/zh-CN/api-reference/rtc/macos/rtc-interface-class#class_irtcengine)

## setAudioProfile:scenario:

设置音频配置和音频场景。

<a id="api_irtcengine_setaudioprofile__prototype"></a>

```objectivec
- (int)setAudioProfile:(AgoraAudioProfile)profile scenario:(AgoraAudioScenario)scenario NS_SWIFT_NAME(setAudioProfile(_:scenario:)) __deprecated_msg("use setAudioProfile: instead.");
```

<a id="api_irtcengine_setaudioprofile__detailed_desc"></a>

#### `废弃`

该方法已废弃，请改用 [setAudioProfile:](/zh-CN/api-reference/rtc/macos/audio/audio-basic#api_irtcengine_setaudioprofile2)。

该方法适用于多种音频场景，可根据需要选择。例如，在音乐教学等对音质要求较高的场景中，建议将 `profile` 设置为 `AgoraAudioProfileMusicHighQuality` （4），将 `scenario` 设置为 `AgoraAudioScenarioGameStreaming` （3）。

:::

<a id="callback_irtcengineeventhandler_onactivespeaker__detailed_desc"></a>

成功调用 `enableAudioVolumeIndication` 方法后，SDK 会持续检测哪位远端用户的音量最大。在当前周期内，音量被检测为最大次数最多的远端用户即为最活跃用户。当频道中用户数不少于两人且存在活跃的远端说话人时，SDK 会触发该回调并报告最活跃远端说话人的用户 ID（`speakerUid` ）。

- 如果最活跃的远端说话人始终是同一用户，SDK 只会触发一次该回调。
- 如果最活跃的远端说话人变更为其他用户，SDK 会再次触发该回调并报告新的最活跃远端说话人的用户 ID。
