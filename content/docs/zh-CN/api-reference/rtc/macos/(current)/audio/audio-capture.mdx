## enableLocalAudio:

启用或关闭本地音频采集功能。

<a id="api_irtcengine_enablelocalaudio__prototype"></a>

```text
- (int)enableLocalAudio:(BOOL)enabled NS_SWIFT_NAME(enableLocalAudio(_:));
```

<a id="api_irtcengine_enablelocalaudio__detailed_desc"></a>

[enableLocalAudio:](/zh-CN/api-reference/rtc/macos/audio/audio-capture#api_irtcengine_enablelocalaudio) 方法用于启用或关闭本地音频采集功能。默认情况下，加入频道时会启用音频功能。调用该方法可以停止或重新启动本地音频采集。
该方法与 [muteLocalAudioStream:](/zh-CN/api-reference/rtc/macos/publishnsubscribe#api_irtcengine_mutelocalaudiostream) 的区别如下：

- [enableLocalAudio:](/zh-CN/api-reference/rtc/macos/audio/audio-capture#api_irtcengine_enablelocalaudio)：关闭或重新启用本地音频采集和处理。如果使用该方法关闭或重新启用本地音频采集，可能会导致远端音频播放出现短暂中断。
- [muteLocalAudioStream:](/zh-CN/api-reference/rtc/macos/publishnsubscribe#api_irtcengine_mutelocalaudiostream)：仅停止或恢复发送本地音频流，不影响音频采集状态。

该方法不会影响接收远端音频流。将 `enabled` 设为 NO 适用于只接收远端音频而不发送本地音频的场景。你可以在加入频道前或加入频道后调用该方法。在加入频道前调用时，仅设置设备状态，加入频道后立即生效。

<a id="api_irtcengine_enablelocalaudio__scenario"></a>

### 适用场景

`enableLocalAudio(false)` 适用于只接收远端音频流而不发送本地采集音频的场景。该方法不会影响接收远端音频流。

<a id="api_irtcengine_enablelocalaudio__timing"></a>

### 调用时机

你可以在加入频道前或加入频道后调用该方法。在加入频道前调用时，仅设置设备状态，加入频道后立即生效。

<a id="api_irtcengine_enablelocalaudio__related"></a>

### 相关回调

成功调用该方法后，SDK 会触发 [rtcEngine:localAudioStateChanged:reason:](/zh-CN/api-reference/rtc/macos/audio/audio-basic#callback_irtcengineeventhandler_onlocalaudiostatechanged) 回调，报告 `AgoraAudioLocalStateStopped`（0）或 `AgoraAudioLocalStateRecording`（1）。

<a id="api_irtcengine_enablelocalaudio__parameters"></a>

### 参数

### enabled

- YES：（默认）重新启用本地音频功能，即启动本地音频采集设备（例如麦克风）。
- NO：关闭本地音频功能，即停止本地音频采集。

<a id="api_irtcengine_enablelocalaudio__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。

### 所属接口类

- [AgoraRtcEngineKit](/zh-CN/api-reference/rtc/macos/rtc-interface-class#class_irtcengine)

## enableLoopbackRecording:deviceName:

启用声卡回采功能。

<a id="api_irtcengine_enableloopbackrecording__prototype"></a>

```text
- (int)enableLoopbackRecording:(BOOL)enabled deviceName:(NSString* _Nullable)deviceName NS_SWIFT_NAME(enableLoopbackRecording(_:deviceName:));
```

<a id="api_irtcengine_enableloopbackrecording__detailed_desc"></a>

如果你启用了声卡回采功能，声卡的输出会被混入发送到远端的音频流中。

:::note
注：

- macOS 系统的默认声卡不支持录音功能。从 v4.5.0 起，当你首次调用该方法时，SDK 会自动安装由声网开发的内置虚拟声卡 `AgoraALD`。安装成功后，音频路由会自动切换到虚拟声卡，并使用其进行音频采集。
- 你可以在加入频道前或加入频道后调用该方法。
- 如果你调用 [disableAudio](/zh-CN/api-reference/rtc/macos/audio/audio-basic#api_irtcengine_disableaudio) 方法禁用了音频模块，音频采集也会被禁用。如果你需要启用音频采集，请先调用 [enableAudio](/zh-CN/api-reference/rtc/macos/audio/audio-basic#api_irtcengine_enableaudio) 方法启用音频模块，然后再调用 [enableLoopbackRecording:deviceName:](/zh-CN/api-reference/rtc/macos/audio/audio-capture#api_irtcengine_enableloopbackrecording) 方法。
:::

<a id="api_irtcengine_enableloopbackrecording__parameters"></a>

### 参数

### enabled

是否启用声卡回采功能。

- YES：启用声卡采集。你可以在系统的 **Audio Devices &gt; Output** 中找到虚拟声卡的名称。
- NO：禁用声卡采集。虚拟声卡的名称不会显示在系统的 **Audio Devices &gt; Output** 中。

### deviceName

虚拟声卡的设备名称。默认值为 nil，表示使用 `AgoraALD` 进行声卡回采。

<a id="api_irtcengine_enableloopbackrecording__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。

### 所属接口类

- [AgoraRtcEngineKit](/zh-CN/api-reference/rtc/macos/rtc-interface-class#class_irtcengine)

## muteRecordingSignal:

设置是否静音录制信号。

<a id="api_irtcengine_muterecordingsignal__prototype"></a>

```text
- (int)muteRecordingSignal:(BOOL)muted NS_SWIFT_NAME(muteRecordingSignal(_:));
```

<a id="api_irtcengine_muterecordingsignal__detailed_desc"></a>

如果你已经调用了 [adjustRecordingSignalVolume:](/zh-CN/api-reference/rtc/macos/audio/audio-capture#api_irtcengine_adjustrecordingsignalvolume) 方法调整了录制信号的音量，当你调用该方法并将参数设置为 YES 时，SDK 的行为如下：

- 记录调整后的音量。
- 静音录制信号。

当你再次调用该方法并将参数设置为 NO 时，录制信号音量将恢复为静音前 SDK 记录的音量。

<a id="api_irtcengine_muterecordingsignal__timing"></a>

### 调用时机

该方法可以在加入频道前或后调用。

<a id="api_irtcengine_muterecordingsignal__parameters"></a>

### 参数

### muted

- YES：静音录制信号。
- NO：（默认）不静音录制信号。

<a id="api_irtcengine_muterecordingsignal__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。
