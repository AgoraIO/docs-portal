## clearRemotePositions:

移除所有远端用户的空间位置。

<a id="api_ibasespatialaudioengine_clearremotepositions__prototype"></a>

```objectivec
- (int)clearRemotePositions NS_SWIFT_NAME(clearRemotePositions());
```

<a id="api_ibasespatialaudioengine_clearremotepositions__detailed_desc"></a>

调用该方法后，你将无法再听到任何远端用户的声音。离开频道后，为避免资源浪费，也可以调用该方法。

<a id="api_ibasespatialaudioengine_clearremotepositions__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/macos/error-code)了解详情和解决建议。

## enableSpatialAudio:

启用或关闭空间音效。

<a id="api_irtcengine_enablespatialaudio__prototype"></a>

```objectivec
- (int)enableSpatialAudio:(BOOL)enabled NS_SWIFT_NAME(enableSpatialAudio(_:));
```

<a id="api_irtcengine_enablespatialaudio__detailed_desc"></a>

你可以在加入频道前或加入频道后调用该方法。启用空间音效后，可以调用 [setRemoteUserSpatialAudioParams:params:](/zh-CN/api-reference/rtc/macos/audio/audio-prenpost/spatial-audio#api_irtcengine_setremoteuserspatialaudioparams) 设置远端用户的空间音效参数。

:::info[注]
- 该方法依赖空间音效动态库 AgoraSpatialAudioExtension.xcframework （iOS）或 AgoraSpatialAudioExtension.framework （macOS）。如果该动态库被删除，该功能将无法正常启用。
:::

<a id="api_irtcengine_enablespatialaudio__parameters"></a>

### 参数

#### `enabled`

是否启用空间音效：

- YES：启用空间音效。
- NO：关闭空间音效。

<a id="api_irtcengine_enablespatialaudio__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/macos/error-code)了解详情和解决建议。

### 所属接口类
- [AgoraRtcEngineKit](/zh-CN/api-reference/rtc/macos/rtc-interface-class#class_irtcengine)

## muteAllRemoteAudioStreams:

停止或恢复订阅所有远端用户的音频流。

<a id="api_ibasespatialaudioengine_muteallremoteaudiostreams_ibasespatialaudioengine__prototype"></a>

```objectivec
- (int)muteAllRemoteAudioStreams:(BOOL)mute NS_SWIFT_NAME(muteAllRemoteAudioStreams(_:));
```

<a id="api_ibasespatialaudioengine_muteallremoteaudiostreams_ibasespatialaudioengine__detailed_desc"></a>

调用该方法后，你将停止或恢复订阅所有远端用户的音频流，包括后续加入频道的用户。

:::info[注]
- 请在调用 joinChannelByToken 方法后再调用此方法。
- 使用空间音效时，如需设置是否停止订阅所有远端用户的音频流，声网建议调用此方法，而非 muteAllRemoteAudioStreams: 方法。
- 调用此方法后，你需要调用 updateSelfPosition 和 updateRemotePosition 方法更新本地用户和远端用户的空间位置，否则该方法的设置不会生效。
:::

<a id="api_ibasespatialaudioengine_muteallremoteaudiostreams_ibasespatialaudioengine__parameters"></a>

### 参数

#### `mute`

是否停止订阅所有远端用户的音频流：

- YES：停止订阅所有远端用户的音频流。
- NO：订阅所有远端用户的音频流。

<a id="api_ibasespatialaudioengine_muteallremoteaudiostreams_ibasespatialaudioengine__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/macos/error-code)了解详情和解决建议。

### 所属接口类
- [AgoraSpatialAudioKitBase](/zh-CN/api-reference/rtc/macos/rtc-interface-class#class_ibasespatialaudioengine)

<a id="api_ibasespatialaudioengine_mutelocalaudiostream_ibasespatialaudioengine__detailed_desc"></a>

你可以通过该方法停止或恢复发布本地音频流。 该方法不会影响任何正在进行的音频录制，因为它不会禁用音频采集设备。 使用空间音效时，如果你需要设置是否停止订阅指定用户的音频流，声网推荐你调用该方法，而不是 `AgoraRtcEngine` 下的同名方法。

## destroy

销毁 AgoraLocalSpatialAudioKit 实例。

<a id="api_ilocalspatialaudioengine_release_ilocalspatialaudioengine__prototype"></a>

```objectivec
+ (void)destroy NS_SWIFT_NAME(destroy());
```

<a id="api_ilocalspatialaudioengine_release_ilocalspatialaudioengine__detailed_desc"></a>

该方法会释放 [AgoraLocalSpatialAudioKit](/zh-CN/api-reference/rtc/macos/rtc-interface-class#class_ilocalspatialaudioengine) 下的所有资源。当你不再需要使用空间音效时，可以调用该方法释放资源。调用该方法后，将无法再使用 [AgoraLocalSpatialAudioKit](/zh-CN/api-reference/rtc/macos/rtc-interface-class#class_ilocalspatialaudioengine) 下的任何 API。如需再次使用空间音效，需等待 [destroy](/zh-CN/api-reference/rtc/macos/audio/audio-prenpost/spatial-audio#api_ilocalspatialaudioengine_release_ilocalspatialaudioengine) 方法执行完成后，再调用 [sharedLocalSpatialAudioWithConfig:](/zh-CN/api-reference/rtc/macos/audio/audio-prenpost/spatial-audio#api_ilocalspatialaudioengine_initialize_ilocalspatialaudioengine) 创建新的 [AgoraLocalSpatialAudioKit](/zh-CN/api-reference/rtc/macos/rtc-interface-class#class_ilocalspatialaudioengine) 实例。

:::info[注]
请在调用 [destroy](/zh-CN/api-reference/rtc/macos/audio/audio-prenpost/spatial-audio#api_ilocalspatialaudioengine_release_ilocalspatialaudioengine) 方法之前调用此方法。
:::

## setDistanceUnit:

设置游戏引擎中每个单位距离对应的米数。

<a id="api_ibasespatialaudioengine_setdistanceunit__prototype"></a>

```objectivec
- (int)setDistanceUnit:(float)unit NS_SWIFT_NAME(setDistanceUnit(_:));
```

<a id="api_ibasespatialaudioengine_setdistanceunit__detailed_desc"></a>

声网的空间音效算法中，距离以米为单位进行测量。SDK 默认将游戏引擎中的每个单位距离转换为 1 米。你可以调用 [setDistanceUnit:](/zh-CN/api-reference/rtc/macos/audio/audio-prenpost/spatial-audio#api_ibasespatialaudioengine_setdistanceunit) 方法将游戏引擎中的每个单位距离转换为指定的米数。

<a id="api_ibasespatialaudioengine_setdistanceunit__parameters"></a>

### 参数

#### `unit`

游戏引擎中每个单位距离对应的米数。该参数的值必须大于 0.00，默认值为 1.00（默认）。例如，将 `unit` 设置为 2.00 表示游戏引擎中每个单位距离等于 2 米。值越大，当远端用户远离你时，你听到的声音衰减得越快。

<a id="api_ibasespatialaudioengine_setdistanceunit__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/macos/error-code)了解详情和解决建议。

### 所属接口类
- [AgoraSpatialAudioKitBase](/zh-CN/api-reference/rtc/macos/rtc-interface-class#class_ibasespatialaudioengine)

## setPlayerAttenuation:playerId:forceSet:

<a id="api_ibasespatialaudioengine_setplayerattenuation__prototype"></a>

```objectivec
- (int)setPlayerAttenuation:(double)attenuation playerId:(NSUInteger)playerId forceSet:(BOOL)forceSet NS_SWIFT_NAME(setPlayerAttenuation(_:playerId:forceSet:));
```

<a id="api_ibasespatialaudioengine_setplayerattenuation__detailed_desc"></a>

<a id="api_ibasespatialaudioengine_setplayerattenuation__parameters"></a>

### 参数

#### `attenuation`

远端用户或媒体播放器的声音衰减系数，取值范围为 [0,1]。具体取值说明如下：

- 0：广播模式，音量和音色不会随距离衰减，听到的音量和音色不会因距离变化而变化。
- (0, 0.5)：弱衰减模式，音量和音色在传播过程中仅有轻微衰减，声音传播距离比真实环境更远。
- 0.5：（默认）模拟真实环境中的音量衰减效果，等效于未设置 speaker_attenuation 参数。
- (0.5, 1]：强衰减模式，音量和音色在传播过程中迅速衰减。

#### `playerId`

媒体播放器的 ID。你可以通过调用 [getMediaPlayerId](/zh-CN/api-reference/rtc/macos/play/mediaplayer/mediaplayer-info#api_imediaplayer_getmediaplayerid) 获取设备 ID。

#### `forceSet`

是否强制设置媒体播放器的声音衰减效果：

- YES：强制使用 attenuation 设置媒体播放器的衰减效果，此时在 AgoraSpatialAudioZone 中通过 audioAttenuation 设置的隔音区衰减系数对媒体播放器无效。
- NO：不强制使用 attenuation 设置媒体播放器的声音衰减效果，具体如下：
  - 如果声源和听众分别位于隔音区内外，声音衰减效果由 AgoraSpatialAudioZone 中的 audioAttenuation 决定。
  - 如果声源和听众位于同一隔音区内，或都在隔音区外，声音衰减效果由本方法中的 attenuation 参数决定。

<a id="api_ibasespatialaudioengine_setplayerattenuation__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/macos/error-code)了解详情和解决建议。

## setZones:

设置声源隔音区域。

<a id="api_ibasespatialaudioengine_setzones__prototype"></a>

```objectivec
- (int)setZones:(NSArray<AgoraSpatialAudioZone*> * _Nullable)zones NS_SWIFT_NAME(setZones(_:));
```

<a id="api_ibasespatialaudioengine_setzones__detailed_desc"></a>

在虚拟互动场景中，你可以使用此方法设置隔音区域和声音衰减系数。

- 当声源（可以是用户或媒体播放器）和接收者分别处于隔音区域的内外部时，声音的衰减效果由 AgoraSpatialAudioZone 中的声音衰减系数决定。
- 如果用户或媒体播放器处于同一个隔音区域内，则不受 AgoraSpatialAudioZone 的影响，声音衰减效果由 setPlayerAttenuation:playerId:forceSet: 或 setRemoteAudioAttenuation:userId:forceSet: 中的 attenuation 参数决定。如果你未调用上述方法，SDK 默认的声音衰减系数为 0.5，用于模拟真实环境中的声音衰减。
- 如果声源和接收者分别处于两个不同的隔音区域内，接收者将无法听到声源的声音。

:::info[注]
如果多次调用该方法，以最后一次设置的隔音区域为准。
:::

<a id="api_ibasespatialaudioengine_setzones__parameters"></a>

### 参数

#### `zones`

隔音区域设置。当该参数设置为 nil 时，表示清除所有隔音区域。详见 [AgoraSpatialAudioZone](/zh-CN/api-reference/rtc/macos/class-spatialaudiozone)。
