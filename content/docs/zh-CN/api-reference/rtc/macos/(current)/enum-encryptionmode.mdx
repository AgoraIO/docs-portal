<a id="enum_encryptionmode__detailed_desc"></a>

声网推荐使用 `AgoraEncryptionModeAES128GCM2` 或 `AgoraEncryptionModeAES256GCM2` 加密模式。这两种模式支持使用 salt，以提高安全性。
