## 枚举值

### AgoraRhythmPlayerReasonOK

（0）：节拍文件播放正常，无错误。

### AgoraRhythmPlayerReasonFailed

（1）：通用错误，无具体原因。

### AgoraRhythmPlayerReasonCanNotOpen

（801）：打开节拍文件时出错。

（802）：播放节拍文件时出错。

### AgoraRhythmPlayerReasonFileOverDurationLimit

（803）：节拍文件时长超过限制，最大支持 1.2 秒。
