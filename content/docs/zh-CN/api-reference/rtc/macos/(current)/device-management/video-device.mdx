## queryCodecCapability

查询设备支持的视频编解码能力。

<a id="api_irtcengine_querycodeccapability__prototype"></a>

```objectivec
- (NSArray <AgoraVideoCodecCapInfo *> *_Nullable)queryCodecCapability;
```

<a id="api_irtcengine_querycodeccapability__detailed_desc"></a>

<a id="api_irtcengine_querycodeccapability__return_values"></a>

### 返回值

- 方法调用成功时，返回一个 [AgoraVideoCodecCapInfo](/zh-CN/api-reference/rtc/macos/class-codeccapinfo) 数组，表示设备的视频编码能力，详见 [AgoraVideoCodecCapInfo](/zh-CN/api-reference/rtc/macos/class-codeccapinfo)。
- 方法调用失败时，返回 nil。如果调用超时，请调整调用逻辑，避免在主线程中调用该方法。

- [AgoraRtcEngineKit](/zh-CN/api-reference/rtc/macos/rtc-interface-class#class_irtcengine)

<a id="api_irtcengine_setcameracapturerconfiguration"></a>

## setCameraCapturerConfiguration:

设置视频采集配置。

<a id="api_irtcengine_setcameracapturerconfiguration__prototype"></a>

```objectivec
- (int)setCameraCapturerConfiguration:(AgoraCameraCapturerConfiguration * _Nullable)config NS_SWIFT_NAME(setCameraCapturerConfiguration(_:));
```

<a id="api_irtcengine_setcameracapturerconfiguration__detailed_desc"></a>

在启用本地摄像头采集前调用此方法，例如在调用 [startPreview:](/zh-CN/api-reference/rtc/macos/video/video-basic#api_irtcengine_startpreview2) 和 `joinChannelByToken` 之前。

:::info[注]
如需调整摄像头焦距配置，建议先调用 `queryCameraFocalLengthCapability` 查询设备的焦距能力，并根据查询结果进行配置。
:::

<a id="api_irtcengine_setcameracapturerconfiguration__timing"></a>

### 调用时机

在启用本地摄像头采集前调用，例如在调用 [startPreview:](/zh-CN/api-reference/rtc/macos/video/video-basic#api_irtcengine_startpreview2) 和 `joinChannelByToken` 之前。

<a id="api_irtcengine_setcameracapturerconfiguration__parameters"></a>

### 参数

#### `config`

摄像头采集配置。详见 [AgoraCameraCapturerConfiguration](/zh-CN/api-reference/rtc/macos/class-cameracapturerconfiguration)。

:::info[注]
在此方法中，无需设置 `deviceId` 参数。
:::

<a id="api_irtcengine_setcameracapturerconfiguration__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/macos/error-code)了解详情和解决建议。

- [AgoraRtcEngineKit](/zh-CN/api-reference/rtc/macos/rtc-interface-class#class_irtcengine)

<a id="api_irtcengine_setdevice_irtcengine"></a>

## setDevice:deviceId:

指定具有设备 ID 的设备。

<a id="api_irtcengine_setdevice_irtcengine__prototype"></a>

```objectivec
- (int)setDevice:(AgoraMediaDeviceType)type deviceId:(NSString * _Nonnull)deviceId NS_SWIFT_NAME(setDevice(_:deviceId:));
```

<a id="api_irtcengine_setdevice_irtcengine__detailed_desc"></a>

<a id="api_irtcengine_setdevice_irtcengine__parameters"></a>

### 参数

#### `type`

设备类型，包括音频采集、音频播放、视频采集或视频播放设备。详见 [AgoraMediaDeviceType](/zh-CN/api-reference/rtc/macos/enum-mediadevicetype)。

#### `deviceId`

设备 ID。你可以通过调用 [enumerateDevices:](/zh-CN/api-reference/rtc/macos/device-management/common-device#api_irtcengine_enumeratedevices) 获取设备 ID。连接或断开音频设备不会改变该值。

<a id="api_irtcengine_setdevice_irtcengine__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/macos/error-code)了解详情和解决建议。

- [AgoraRtcEngineKit](/zh-CN/api-reference/rtc/macos/rtc-interface-class#class_irtcengine)
