### 自从

自 v4.6.0 版本新增。

:::note
注： 设置水印类型时，`type` 需与实际提供的数据字段相匹配，不可同时传入多种类型的水印：若 `type` 为 `buffer`，则仅支持设置 `buffer` 字段；若 `type` 为 `image`，则仅支持设置 `imageUrl` 字段。
