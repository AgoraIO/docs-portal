## 媒体播放器缓存

<a id="api_imediaplayercachemanager_enableautoremovecache"></a>

## enableAutoRemoveCache:

设置是否自动删除缓存的媒体文件。

<a id="api_imediaplayercachemanager_enableautoremovecache__prototype"></a>

```objectivec
- (int)enableAutoRemoveCache:(BOOL)enable NS_SWIFT_NAME(enableAutoRemoveCache(_:));
```

<a id="api_imediaplayercachemanager_enableautoremovecache__detailed_desc"></a>

当缓存的媒体文件超过设置的数量或大小限制时，如果启用该功能，SDK 会自动删除最近最少使用的缓存文件。

<a id="api_imediaplayercachemanager_enableautoremovecache__parameters"></a>

### 参数

#### `enable`

是否启用 SDK 自动删除缓存的媒体文件：

- YES：自动删除缓存的媒体文件。
- NO：（默认）不自动删除缓存的媒体文件。

<a id="api_imediaplayercachemanager_enableautoremovecache__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败，详见 AgoraMediaPlayerReason。

### 所属接口类
- [AgoraRtcMediaPlayerCacheManagerProtocol](/zh-CN/api-reference/rtc/macos/rtc-interface-class#class_imediaplayercachemanager)

## cacheDir

获取缓存媒体文件的存储路径。

<a id="api_imediaplayercachemanager_getcachedir__prototype"></a>

```objectivec
- (NSString *)cacheDir NS_SWIFT_NAME(cacheDir());
```

<a id="api_imediaplayercachemanager_getcachedir__detailed_desc"></a>

如果在调用该方法前未调用 [setCacheDir:](/zh-CN/api-reference/rtc/macos/mediaplayer-cache#api_imediaplayercachemanager_setcachedir) 方法设置缓存媒体文件的存储路径，则该方法返回 SDK 默认使用的存储路径。

<a id="api_imediaplayercachemanager_getcachedir__return_values"></a>

### 返回值

- 方法调用成功时，返回缓存媒体文件的存储路径。
- 方法调用失败，返回 nil，详见 AgoraMediaPlayerReason。

### 所属接口类
- [AgoraRtcMediaPlayerCacheManagerProtocol](/zh-CN/api-reference/rtc/macos/rtc-interface-class#class_imediaplayercachemanager)

## maxCacheFileSize

获取缓存媒体文件的聚合存储空间的最大大小。

<a id="api_imediaplayercachemanager_getmaxcachefilesize__prototype"></a>

```objectivec
- (NSInteger)maxCacheFileSize NS_SWIFT_NAME(maxCacheFileSize());
```

<a id="api_imediaplayercachemanager_getmaxcachefilesize__detailed_desc"></a>

你可以调用 [setMaxCacheFileSize:](/zh-CN/api-reference/rtc/macos/mediaplayer-cache#api_imediaplayercachemanager_setmaxcachefilesize) 方法根据你的使用场景设置该限制。默认情况下，缓存媒体文件的聚合存储空间的最大大小为 1 GB。

<a id="api_imediaplayercachemanager_getmaxcachefilesize__return_values"></a>

### 返回值

- 方法调用成功，返回缓存媒体文件的聚合存储空间的最大大小（单位为字节）。
- 方法调用失败，返回小于 0 的错误码，详见 AgoraMediaPlayerReason。

## AgoraRtcMediaPlayer:cacheStats:

上报正在缓存的媒体文件的统计信息。

<a id="callback_imediaplayersourceobserver_onplayercachestats__prototype"></a>

```objectivec
- (void)AgoraRtcMediaPlayer:(id<AgoraRtcMediaPlayerProtocol> _Nonnull)playerKit cacheStats:(AgoraMediaPlayerCacheStatistics *_Nonnull)info NS_SWIFT_NAME(AgoraRtcMediaPlayer(_:cacheStats:));
```

<a id="callback_imediaplayersourceobserver_onplayercachestats__detailed_desc"></a>

<a id="callback_imediaplayersourceobserver_onplayercachestats__timing"></a>

### 触发时机

该回调在你调用 [openWithMediaSource:](/zh-CN/api-reference/rtc/macos/mediaplayer-open#api_imediaplayer_openwithmediasource) 方法并将 `enableCache` 设置为 YES 后，每秒触发一次。

<a id="callback_imediaplayersourceobserver_onplayercachestats__parameters"></a>

### 参数

#### `playerKit`

[AgoraRtcMediaPlayerProtocol](/zh-CN/api-reference/rtc/macos/rtc-interface-class#class_imediaplayer) 实例。详见 [AgoraRtcMediaPlayerProtocol](/zh-CN/api-reference/rtc/macos/rtc-interface-class#class_imediaplayer)。

#### `info`

正在缓存的媒体文件的统计信息。详见 [AgoraMediaPlayerCacheStatistics](/zh-CN/api-reference/rtc/macos/class-cachestatistics)。

### 所属接口类
- [AgoraRtcMediaPlayerDelegate](/zh-CN/api-reference/rtc/macos/rtc-interface-class#class_imediaplayersourceobserver)
