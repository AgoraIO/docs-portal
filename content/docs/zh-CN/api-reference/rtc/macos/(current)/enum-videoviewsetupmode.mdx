## 枚举值

### `AgoraVideoViewSetupReplace`

（0）：（默认）清除所有已添加的视图，并替换为新视图。

### `AgoraVideoViewSetupAdd`

（1）：添加一个视图。

### `AgoraVideoViewSetupRemove`

（2）：删除一个视图。

:::info[注]
当你不再需要使用某个视图时，建议通过将 `setupMode` 设置为 `AgoraVideoViewSetupRemove` 来删除该视图，否则可能会导致渲染资源泄漏。
:::
