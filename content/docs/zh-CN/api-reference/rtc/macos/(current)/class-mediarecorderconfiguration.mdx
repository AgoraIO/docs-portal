## 属性

### storagePath

本地录制文件的绝对路径。路径必须包含文件名和扩展名。例如：iOS：`/App Sandbox/Library/Caches/example.mp4`，macOS：`/Library/Logs/example.mp4`。

:::note
注： 请确保指定路径存在且可写。
:::

### containerFormat

录制文件的封装格式。详见 [AgoraMediaRecorderContainerFormat](/zh-CN/api-reference/rtc/macos/enum-mediarecordercontainerformat)。

### streamType

录制内容类型。详见 [AgoraMediaRecorderStreamType](/zh-CN/api-reference/rtc/macos/enum-mediarecorderstreamtype)。

### maxDurationMs

录制的最大时长，单位为毫秒。默认值为 120000。

### recorderInfoUpdateInterval

录制信息更新的时间间隔，单位为毫秒。取值范围为 [1000, 10000]。SDK 会根据该设置触发 [mediaRecorder\:informationDidUpdated\:uid\:info:](/zh-CN/api-reference/rtc/macos/recording#callback_imediarecorderobserver_onrecorderinfoupdated) 回调以报告录制信息更新。

### width

录制视频的宽度（单位：px）。

:::note
注： 仅在调用 `createMediaRecorder` 且在 [AgoraRecorderStreamInfo](/zh-CN/api-reference/rtc/macos/class-recorderstreaminfo) 中将 `type` 设置为 `AgoraRecorderStreamTypePreview` 时需要设置该参数。宽度 × 高度的最大值不能超过 3840 × 2160。
:::

### height

录制视频的高度（单位：px）。

:::note
注： 仅在调用 `createMediaRecorder` 且在 [AgoraRecorderStreamInfo](/zh-CN/api-reference/rtc/macos/class-recorderstreaminfo) 中将 `type` 设置为 `AgoraRecorderStreamTypePreview` 时需要设置该参数。宽度 × 高度的最大值不能超过 3840 × 2160。
:::

### fps

录制视频的帧率，最大值为 30。例如：5、10、15、24、30 等。

:::note
注： 仅在调用 `createMediaRecorder` 且在 [AgoraRecorderStreamInfo](/zh-CN/api-reference/rtc/macos/class-recorderstreaminfo) 中将 `type` 设置为 `AgoraRecorderStreamTypePreview` 时需要设置该参数。
:::

### sample_rate

录制音频的采样率（单位：Hz）。可设置为 16000、32000、44100 或 48000。

:::note
注： 仅在调用 `createMediaRecorder` 且在 [AgoraRecorderStreamInfo](/zh-CN/api-reference/rtc/macos/class-recorderstreaminfo) 中将 `type` 设置为 `AgoraRecorderStreamTypePreview` 时需要设置该参数。
:::

### channel_num

:::note
注： 仅在调用 `createMediaRecorder` 且在 [AgoraRecorderStreamInfo](/zh-CN/api-reference/rtc/macos/class-recorderstreaminfo) 中将 `type` 设置为 `AgoraRecorderStreamTypePreview` 时需要设置该参数。
:::

录制音频的声道数：

- 1：单声道。
- 2：双声道。

### videoSourceType

录制使用的视频源类型。详见 [AgoraVideoSourceType](/zh-CN/api-reference/rtc/macos/enum-videosourcetype)。

:::note
注： 仅在调用 `createMediaRecorder` 且在 [AgoraRecorderStreamInfo](/zh-CN/api-reference/rtc/macos/class-recorderstreaminfo) 中将 `type` 设置为 `AgoraRecorderStreamTypePreview` 时需要设置该参数。
:::
