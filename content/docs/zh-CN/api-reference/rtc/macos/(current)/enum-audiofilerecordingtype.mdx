## 枚举值

### AgoraAudioFileRecordingTypeMic

（1）：仅录制本地用户音频。

### AgoraAudioFileRecordingTypePlayback

（2）：仅录制所有远端用户音频。

### AgoraAudioFileRecordingTypeMixed

（3）：录制本地用户与所有远端用户的混合音频。
