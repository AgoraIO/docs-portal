自 v4.6.0 版本新增。

<a id="enum_videoeffectaction__parameters"></a>

## 枚举值

### `AgoraVideoEffectActionSave`

（1）：保存当前视频特效的参数。

### `AgoraVideoEffectActionReset`

（2）：将视频特效重置为默认参数。
