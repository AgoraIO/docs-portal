## 枚举值

### `AgoraAreaCodeTypeCN`

（0x1）：中国大陆。

### `AgoraAreaCodeTypeNA`

（0x2）：北美地区。

### `AgoraAreaCodeTypeEUR`

（0x4）：欧洲地区。

### `AgoraAreaCodeTypeAS`

（0x8）：亚洲地区（不包括中国大陆）。

### `AgoraAreaCodeTypeJP`

（0x10）：日本。

### `AgoraAreaCodeTypeIN`

（0x20）：印度。

### `AgoraAreaCodeTypeRU`

（0x1000）：俄罗斯。

### `AgoraAreaCodeTypeGlobal`

（0xFFFFFFFF）：全球范围。
