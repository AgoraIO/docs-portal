## 属性

<ParameterList>
<a id="enablelocalplayback"></a>
<Parameter name="enableLocalPlayback">

是否启用本地音频播放设备：

- YES：（默认）启用本地音频播放设备。
- NO：不启用本地音频播放设备。

</Parameter>
<a id="enableaudioprocessing"></a>
<Parameter name="enableAudioProcessing">

:::note
注： 该参数仅在自定义音频采集中使用 `AgoraAudioTrackTypeDirect` 时生效。
:::

是否启用音频处理模块：

- YES：启用音频处理模块，以应用回声消除（AEC）、噪声抑制（ANS）和自动增益控制（AGC）效果。
- NO：（默认）不启用音频处理模块。

</Parameter>
