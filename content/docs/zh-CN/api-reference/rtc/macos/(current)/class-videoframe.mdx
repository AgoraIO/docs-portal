<a id="class_videoframe__detailed_desc"></a>

缓冲区提供的是指针的指针。该接口无法修改缓冲区的指针，但可以修改缓冲区的内容。

<a id="class_videoframe__parameters"></a>

## 属性

<ParameterList>
<a id="type"></a>
<Parameter name="type">

输入视频帧的格式。该参数必须指定为以下值之一：1：I420；2：BGRA；3：NV21；4：RGBA；5：IMC2；7：ARGB；8：NV12；12：iOS 纹理（`CVPixelBufferRef`）；16：I422。

</Parameter>
<a id="width"></a>
<Parameter name="width">

视频的宽度，单位为像素。

</Parameter>
<a id="height"></a>
<Parameter name="height">

视频的高度，单位为像素。

</Parameter>
<a id="ystride"></a>
<Parameter name="yStride">

对于 YUV 数据，为 Y 缓冲区的每行跨度；对于 RGBA 数据，为总数据长度。

</Parameter>
<a id="ustride"></a>
<Parameter name="uStride">

对于 YUV 数据，为 U 缓冲区的每行跨度；对于 RGBA 数据，该值为 0。

</Parameter>
<a id="vstride"></a>
<Parameter name="vStride">

对于 YUV 数据，为 V 缓冲区的每行跨度；对于 RGBA 数据，该值为 0。

</Parameter>
<a id="ybuffer"></a>
<Parameter name="yBuffer">

对于 YUV 数据，为 Y 缓冲区的指针；对于 RGBA 数据，为数据缓冲区。

</Parameter>
<a id="ubuffer"></a>
<Parameter name="uBuffer">

对于 YUV 数据，为 U 缓冲区的指针；对于 RGBA 数据，该值为 0。

</Parameter>
<a id="vbuffer"></a>
<Parameter name="vBuffer">

对于 YUV 数据，为 V 缓冲区的指针；对于 RGBA 数据，该值为 0。

</Parameter>
<a id="rotation"></a>
<Parameter name="rotation">

视频帧在渲染前的顺时针旋转角度。支持的值包括 0、90、180 和 270 度。

</Parameter>
<a id="rendertimems"></a>
<Parameter name="renderTimeMs">

视频帧渲染时的 Unix 时间戳（毫秒）。该时间戳可用于指导视频帧的渲染。

</Parameter>
<a id="avsynctype"></a>
<Parameter name="avSyncType">

预留参数

</Parameter>
<a id="pixelbuffer"></a>
<Parameter name="pixelBuffer">

将数据填充到 `CVPixelBuffer` 中。

</Parameter>
<a id="alphabuffer"></a>
<Parameter name="alphaBuffer">

使用人像分割算法输出的 Alpha 通道数据。该数据与视频帧大小一致，每个像素值范围为 [0, 255]，其中 0 表示背景，255 表示前景（人像）。通过设置该参数，可以将视频背景渲染为透明、纯色、图像、视频等多种效果。

:::note
注： 请确保 `alphaBuffer` 的大小与视频帧（width × height）完全一致，否则可能导致应用崩溃。
:::

</Parameter>
<a id="alphastitchmode"></a>
<Parameter name="alphaStitchMode">

当视频帧包含 Alpha 通道数据时，表示 `alphaBuffer` 与视频帧的相对位置。详见 [AgoraAlphaStitchMode](/zh-CN/api-reference/rtc/macos/enum-alphastitchmode)。

</Parameter>
<a id="metainfo"></a>
<Parameter name="metaInfo">

视频帧中的元信息。如需使用该参数，请[联系技术支持](https://ticket.shengwang.cn/)。

</Parameter>
<a id="colorspace"></a>
<Parameter name="colorSpace">

视频帧的色彩空间配置，默认采用 Full Range 和 BT.709 标准。详见 [`VideoColorSpace`](https://developer.mozilla.org/en-US/docs/Web/API/VideoColorSpace)。

</Parameter>
</ParameterList>
