## 枚举值

### `AgoraVideoFrameProcessModeReadOnly`

：只读模式。在该模式下，视频帧不会被修改。视频帧观察者作为渲染器使用，不会修改原始帧。

### `AgoraVideoFrameProcessModeReadWrite`

：读写模式。在该模式下，视频帧可以被修改。视频帧观察者作为视频滤镜使用，会处理视频帧并影响 SDK 中后续的视频帧处理。
