<a id="class_leavechanneloptions__prototype"></a>

```objectivec
__attribute__((visibility("default"))) @interface AgoraLeaveChannelOptions : NSObject
@property(nonatomic, assign) BOOL stopAudioMixing;
@property(nonatomic, assign) BOOL stopAllEffect;
@property(nonatomic, assign) BOOL stopMicrophoneRecording;
@end
```

<a id="class_leavechanneloptions__parameters"></a>

## 属性

### `stopAudioMixing`

用户离开频道时是否停止播放和混音音乐文件。

- YES：（默认）停止播放和混音音乐文件。
- NO：不停止播放和混音音乐文件。

### `stopAllEffect`

用户离开频道时是否停止播放所有音效。

- YES：（默认）停止播放所有音效。
- NO：不停止播放任何音效。

### `stopMicrophoneRecording`

用户离开频道时是否停止麦克风录制。

- YES：（默认）停止麦克风录制。
- NO：不停止麦克风录制。
