## 枚举值

<ParameterList>
<a id="agoraaudiodualmonostereo"></a>
<Parameter name="AgoraAudioDualMonoStereo">

（0）：原始模式。

</Parameter>
<a id="agoraaudiodualmonol"></a>
<Parameter name="AgoraAudioDualMonoL">

（1）：左声道模式。该模式用左声道音频替换右声道音频，用户只能听到左声道音频。

</Parameter>
<a id="agoraaudiodualmonor"></a>
<Parameter name="AgoraAudioDualMonoR">

（2）：右声道模式。该模式用右声道音频替换左声道音频，用户只能听到右声道音频。

</Parameter>
<a id="agoraaudiodualmonomix"></a>
<Parameter name="AgoraAudioDualMonoMix">

（3）：混合声道模式。该模式将左声道和右声道音频混合，用户可同时听到左右声道音频。

</Parameter>
