## getPlayoutVolume

获取本地播放音量。

<a id="api_imediaplayer_getplayoutvolume__prototype"></a>

```objectivec
- (int)getPlayoutVolume NS_SWIFT_NAME(getPlayoutVolume());
```

<a id="api_imediaplayer_getstreaminfo"></a>

## getStreamByIndex:

获取媒体流的详细信息。

<a id="api_imediaplayer_getstreaminfo__prototype"></a>

```objectivec
- (AgoraRtcMediaStreamInfo *_Nullable)getStreamByIndex:(int)index NS_SWIFT_NAME(getStreamBy(_:));
```

<a id="api_imediaplayer_getstreaminfo__detailed_desc"></a>

调用该方法可获取指定索引的媒体流的详细信息。

<a id="api_imediaplayer_getstreaminfo__timing"></a>

### 调用时机

在调用 [getStreamCount](/zh-CN/api-reference/rtc/macos/play/mediaplayer/mediaplayer-info#api_imediaplayer_getstreamcount) 方法之后调用该方法。

<a id="api_imediaplayer_getstreaminfo__parameters"></a>

### 参数

#### `index`

媒体流的索引。该参数必须小于 [getStreamCount](/zh-CN/api-reference/rtc/macos/play/mediaplayer/mediaplayer-info#api_imediaplayer_getstreamcount) 的返回值。

<a id="api_imediaplayer_getstreaminfo__return_values"></a>

### 返回值

- 方法调用成功，返回一个 [AgoraRtcMediaStreamInfo](/zh-CN/api-reference/rtc/macos/class-playerstreaminfo) 对象，详见 [AgoraRtcMediaStreamInfo](/zh-CN/api-reference/rtc/macos/class-playerstreaminfo)。
- 方法调用失败，返回 nil。

- [AgoraRtcMediaPlayerProtocol](/zh-CN/api-reference/rtc/macos/rtc-interface-class#class_imediaplayer)

<a id="callback_imediaplayersourceobserver_onplayerplaybackstats"></a>

## AgoraRtcMediaPlayer:playbackStats:

播放媒体文件的统计信息回调。

<a id="callback_imediaplayersourceobserver_onplayerplaybackstats__prototype"></a>

```objectivec
- (void)AgoraRtcMediaPlayer:(id<AgoraRtcMediaPlayerProtocol> _Nonnull)playerKit playbackStats:(AgoraMediaPlayerPlaybackStats *_Nonnull)info NS_SWIFT_NAME(AgoraRtcMediaPlayer(_:playbackStats:));
```

<a id="callback_imediaplayersourceobserver_onplayerplaybackstats__detailed_desc"></a>

<a id="callback_imediaplayersourceobserver_onplayerplaybackstats__timing"></a>

### 触发时机

该回调每秒触发一次，用于报告正在播放的媒体文件的统计信息。

<a id="callback_imediaplayersourceobserver_onplayerplaybackstats__parameters"></a>

### 参数

#### `playerKit`

播放器实例。详见 [AgoraRtcMediaPlayerProtocol](/zh-CN/api-reference/rtc/macos/rtc-interface-class#class_imediaplayer)。

#### `info`

媒体文件的统计信息。详见 [AgoraMediaPlayerPlaybackStats](/zh-CN/api-reference/rtc/macos/class-playerplaybackstats)。

- [AgoraRtcMediaPlayerDelegate](/zh-CN/api-reference/rtc/macos/rtc-interface-class#class_imediaplayersourceobserver)
