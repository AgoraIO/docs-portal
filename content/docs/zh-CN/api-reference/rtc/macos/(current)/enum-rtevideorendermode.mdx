## 枚举值

### AgoraRteVideoRenderModeHidden

（0）：按比例缩放视频尺寸，优先填满视窗。若视频尺寸与视窗不一致，超出部分将被裁剪。

### AgoraRteVideoRenderModeFit

（1）：按比例缩放视频尺寸，优先完整显示视频内容。若视频尺寸与视窗不一致，未填满区域将以黑色填充。
