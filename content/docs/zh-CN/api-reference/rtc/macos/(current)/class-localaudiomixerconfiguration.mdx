## 属性

### audioInputStreams

本地混音的音频流来源，详见 [AgoraMixedAudioStream](/zh-CN/api-reference/rtc/macos/class-mixedaudiostream)。

### syncWithLocalMic

混音后的音频流是否使用本地麦克风采集的音频帧的时间戳。

- YES：（默认）使用本地麦克风采集的音频帧时间戳，可实现所有本地采集音频流的同步。
- NO：使用混音时音频帧的时间戳。
