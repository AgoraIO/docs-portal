description: "共享目标的类型。"
---

<a id="enum_screencapturesourcetype__detailed_desc"></a>

在 [AgoraScreenCaptureSourceInfo](/zh-CN/api-reference/rtc/macos/class-screencapturesourceinfo) 中设置。

<a id="enum_screencapturesourcetype__parameters"></a>

## 枚举值

### `AgoraScreenCaptureSourceTypeUnknown`

（-1）：未知类型。

### `AgoraScreenCaptureSourceTypeWindow`

（0）：共享目标为窗口。

### `AgoraScreenCaptureSourceTypeScreen`

（1）：共享目标为某个显示器的屏幕。

### `AgoraScreenCaptureSourceTypeCustom`

（2）：保留参数。
