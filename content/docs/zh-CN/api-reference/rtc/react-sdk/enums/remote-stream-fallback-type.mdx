媒体流的回退策略选项，用于 [setStreamFallbackOption](/zh-CN/api-reference/rtc/react-sdk/interfaces/iagora-rtcclient#setstreamfallbackoption)。

## Enumeration members

<a id="audio_only"></a>

### AUDIO_ONLY

```ts
AUDIO_ONLY: = 2
```

2: 网络较弱时，先尝试订阅视频小流。如果网络环境无法显示视频，则再回退到订阅纯音频流。

<a id="disable"></a>

### DISABLE

```ts
DISABLE: = 0
```

0: 关闭回退策略，弱网时不对音视频流作回退处理。

<a id="low_stream"></a>

### LOW_STREAM

```ts
LOW_STREAM: = 1
```

1: 在网络条件较差的情况下，自动订阅视频小流。
