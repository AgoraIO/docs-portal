远端视频流的大小类型，可以在 [setRemoteVideoStreamType](/zh-CN/api-reference/rtc/react-sdk/interfaces/iagora-rtcclient#setremotevideostreamtype) 里使用。

## Enumeration members

<a id="high_stream"></a>

### HIGH_STREAM

```ts
HIGH_STREAM: = 0
```

0: 高分辨率、高码率的视频大流。

<a id="low_stream"></a>

### LOW_STREAM

```ts
LOW_STREAM: = 1
```

1: 低分辨率、低码率的视频小流。
