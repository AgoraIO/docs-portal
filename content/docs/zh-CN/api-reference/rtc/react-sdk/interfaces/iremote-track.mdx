远端轨道对象的基础类，为远端音频轨道 [RemoteAudioTrack](/zh-CN/api-reference/rtc/react-sdk/interfaces/iremote-audio-track) 和远端视频轨道 [RemoteVideoTrack](/zh-CN/api-reference/rtc/react-sdk/interfaces/iremote-video-track) 提供一些公共的方法。

- ITrack
  - IRemoteTrack
    - IRemoteAudioTrack
    - IRemoteVideoTrack

## Properties

<a id="isplaying"></a>

### isPlaying

```ts
isPlaying: boolean
```

媒体轨道是否正在页面上播放。

- true: 媒体轨道正在页面上播放。
- false: 媒体轨道没有在页面上播放。

<a id="trackmediatype"></a>

### trackMediaType

```ts
trackMediaType: "audio" | "video"
```

媒体轨道的类型：

- "audio": 音频轨道。
- "video": 视频轨道。

<a id="getrtcrtptransceiver"></a>

### getRTCRtpTransceiver

```ts
getRTCRtpTransceiver(type?: StreamType): RTCRtpTransceiver | undefined
```

获取当前轨道的 [RTCRtpTransceiver](https://developer.mozilla.org/en-US/docs/Web/API/RTCRtpTransceiver) 实例。

该方法目前主要用于视频流的 [端到端加密（Beta）](https://doc.shengwang.cn/doc/rtc/javascript/advanced-features/e2e-encryption)。

如果 SDK 发生断线重连，当前轨道对应的 `RTCRtpTransceiver` 实例可能会发生变化。你可以通过以下回调来获取新的 `RTCRtpTransceiver` 实例： 本地轨道： [ILocalTrack.transceiver-updated](/zh-CN/api-reference/rtc/react-sdk/interfaces/ilocal-track#event_transceiver_updated) 远端轨道： [IRemoteTrack.transceiver-updated](/zh-CN/api-reference/rtc/react-sdk/interfaces/iremote-track#event_transceiver_updated_2)

#### Parameters

| Name | Description |
| --- | --- |
| Optional type: StreamType | 视频流的类型。详见 [StreamType](/zh-CN/api-reference/rtc/react-sdk/enums/stream-type)。 |

#### Returns

Returns RTCRtpTransceiver | undefined

当前轨道的 `RTCRtpTransceiver` 实例。

<a id="once"></a>

### once

```ts
once(event: string, listener: Function): void
```

监听一个指定的事件，当事件触发时会调用传入的回调函数。

当监听后事件第一次触发时，该监听和回调函数就会被立刻移除，也就是只监听一次指定事件。

#### Parameters

| Name | Description |
| --- | --- |
| event: string | 指定事件的名称。 |
| listener: Function | 传入的回调函数。 |

#### Returns

Returns void
