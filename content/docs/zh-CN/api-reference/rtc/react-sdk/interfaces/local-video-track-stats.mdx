本地视频轨道的基本信息，可以通过 [AgoraRTCClient.getLocalVideoStats](/zh-CN/api-reference/rtc/react-sdk/interfaces/iagora-rtcclient#getlocalvideostats) 获取。

- LocalVideoTrackStats

## Properties

<a id="captureframerate"></a>

### Optional captureFrameRate

```ts
captureFrameRate: number
```

视频采集帧率（fps）。

Safari 和 Firefox 上无法获取该值。

<a id="captureresolutionheight"></a>

### captureResolutionHeight

```ts
captureResolutionHeight: number
```

视频采集的分辨率高度。

<a id="captureresolutionwidth"></a>

### captureResolutionWidth

```ts
captureResolutionWidth: number
```

视频采集的分辨率宽度。

<a id="codectype"></a>

### Optional codecType

```ts
codecType: "H264" | "H265" | "VP8" | "VP9" | "AV1X" | "AV1"
```

视频编码格式。

- `"H264"`: 视频编码格式为 H.264。
- `"VP8"`: 视频编码格式为 VP8。
- `"VP9"`: 视频编码格式为 VP9。
- `"AV1X"`: 预留参数，暂不支持。
- `"AV1"`: 视频编码格式为 AV1。

Firefox 上无法获取该值。

<a id="currentpacketlossrate"></a>

### currentPacketLossRate

```ts
currentPacketLossRate: number
```

发送的视频 400ms 内的丢包率。

<a id="encodedelay"></a>

### Optional encodeDelay

```ts
encodeDelay: number
```

视频编码延迟（ms）。

<a id="sendbitrate"></a>

### sendBitrate

```ts
sendBitrate: number
```

视频发送码率 (bps)。

<a id="sendbytes"></a>

### sendBytes

```ts
sendBytes: number
```

发送的视频总字节数 (bytes)。

<a id="sendframerate"></a>

### Optional sendFrameRate

```ts
sendFrameRate: number
```

视频发送帧率（fps）。

Firefox 上无法获取该值。

<a id="sendjitterms"></a>

### sendJitterMs

```ts
sendJitterMs: number
```

发送视频数据包的抖动 (ms)。

<a id="sendpackets"></a>

### sendPackets

```ts
sendPackets: number
```

发送的视频总包数。

<a id="sendpacketslost"></a>

### sendPacketsLost

```ts
sendPacketsLost: number
```

发送的视频总丢包数。

Safari 上无法获取该值。 Firefox 上该字段不准确。

<a id="sendresolutionheight"></a>

### sendResolutionHeight

```ts
sendResolutionHeight: number
```

视频发送的分辨率高度。

<a id="sendresolutionwidth"></a>

### sendResolutionWidth

```ts
sendResolutionWidth: number
```

视频发送的分辨率宽度。

<a id="sendrttms"></a>

### sendRttMs

```ts
sendRttMs: number
```

发送视频数据包的往返时延 (ms)。

<a id="targetsendbitrate"></a>

### targetSendBitrate

```ts
targetSendBitrate: number
```

视频目标发送码率 (bps)，即 [VideoEncoderConfiguration](/zh-CN/api-reference/rtc/react-sdk/interfaces/video-encoder-configuration) 中设置的码率。

<a id="totalduration"></a>

### totalDuration

```ts
totalDuration: number
```

视频总时长，单位为秒。

<a id="totalfreezetime"></a>

### totalFreezeTime

```ts
totalFreezeTime: number
```

视频总卡顿时长，单位为秒。
