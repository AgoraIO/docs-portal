音频数据源处理的设置。用于 [startProcessAudioBuffer](/zh-CN/api-reference/rtc/react-sdk/interfaces/ibuffer-source-audio-track#startprocessaudiobuffer)。

- AudioSourceOptions

## Properties

<a id="cycle"></a>

### Optional cycle

```ts
cycle: number
```

设置循环播放的次数。

<a id="loop"></a>

### Optional loop

```ts
loop: boolean
```

设置是否无限循环。

<a id="startplaytime"></a>

### Optional startPlayTime

```ts
startPlayTime: number
```

设置开始播放的时间。
