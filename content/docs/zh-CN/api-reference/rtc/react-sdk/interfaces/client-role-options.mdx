用户角色具体设置，包含用户级别。 用于 [ClientConfig.clientRoleOptions](/zh-CN/api-reference/rtc/react-sdk/interfaces/client-config#clientroleoptions) 或 [AgoraRTCClient.setClientRole](/zh-CN/api-reference/rtc/react-sdk/interfaces/iagora-rtcclient#setclientrole) 方法。

- ClientRoleOptions

## Properties

<a id="level"></a>

### level

```ts
level: AudienceLatencyLevelType
```

直播场景中的观众延时级别。

注意事项： 仅在用户角色设为 `"audience"` 时生效。 不同的级别会影响计费。
