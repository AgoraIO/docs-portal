`LocalTrack` 为本地轨道的基础类，为音频轨道 [LocalAudioTrack](/zh-CN/api-reference/rtc/react-sdk/interfaces/ilocal-audio-track) 和视频轨道 [LocalVideoTrack](/zh-CN/api-reference/rtc/react-sdk/interfaces/ilocal-video-track) 提供一些公共的方法。

- ITrack
  - ILocalTrack
    - ILocalAudioTrack
    - ILocalVideoTrack

## Events

<a id="event_track_ended"></a>

### track-ended

```ts
track-ended(): void
```

音频或视频轨道被终止，终止的原因可能是：

- 摄像头被拔出
- 麦克风被拔出
- 用户主动停止了屏幕共享
- 用户主动关闭了底层的 MediaStreamTrack
- 媒体设备故障
- 正在使用中的媒体设备的权限被收回

#### Returns

Returns void

<a id="event_transceiver_updated"></a>

### transceiver-updated

```ts
transceiver-updated(transceiver: RTCRtpTransceiver, type?: StreamType): void
```

当前轨道的 `RTCRtpTransceiver` 实例更新回调。

#### Parameters

| Name | Description |
| --- | --- |
| transceiver: RTCRtpTransceiver | 新的 `RTCRtpTransceiver` 实例。 |
| Optional type: StreamType | 当前轨道所属视频流的类型。详见 [StreamType](/zh-CN/api-reference/rtc/react-sdk/enums/stream-type)。 |

#### Returns

Returns void

### close


<a id="getrtcrtptransceiver"></a>

### getRTCRtpTransceiver

```ts
getRTCRtpTransceiver(type?: StreamType): RTCRtpTransceiver | undefined
```

获取当前轨道的 [RTCRtpTransceiver](https://developer.mozilla.org/en-US/docs/Web/API/RTCRtpTransceiver) 实例。

该方法目前主要用于视频流的 [端到端加密（Beta）](https://doc.shengwang.cn/doc/rtc/javascript/advanced-features/e2e-encryption)。

如果 SDK 发生断线重连，当前轨道对应的 `RTCRtpTransceiver` 实例可能会发生变化。你可以通过以下回调来获取新的 `RTCRtpTransceiver` 实例： 本地轨道： [ILocalTrack.transceiver-updated](/zh-CN/api-reference/rtc/react-sdk/interfaces/ilocal-track#event_transceiver_updated) 远端轨道： [IRemoteTrack.transceiver-updated](/zh-CN/api-reference/rtc/react-sdk/interfaces/iremote-track#event_transceiver_updated_2)

#### Parameters

| Name | Description |
| --- | --- |
| Optional type: StreamType | 视频流的类型。详见 [StreamType](/zh-CN/api-reference/rtc/react-sdk/enums/stream-type)。 |

#### Returns

Returns RTCRtpTransceiver | undefined

当前轨道的 `RTCRtpTransceiver` 实例。

<a id="gettracklabel"></a>

### getTrackLabel

```ts
getTrackLabel(): string
```

获取本地轨道的来源描述。

#### Returns

Returns string

可能返回以下值：

- 如果是通过 createMicrophoneAudioTrack 或 createCameraVideoTrack 创建的轨道，返回 MediaDeviceInfo.label 字段。
- 如果是通过 createScreenVideoTrack 创建的轨道，返回屏幕共享的 sourceId。
- 如果是 createCustomAudioTrack 或 createCustomVideoTrack 创建的轨道，返回 MediaStreamTrack.label 字段。

<a id="setenabled"></a>

### setEnabled

```ts
setEnabled(enabled: boolean): Promise<void>
```

##### `自从`

<br /> *4.0.0*

启用/禁用该轨道。

轨道禁用后，播放和发布都将被停止。

禁用轨道不会触发 [LocalTrack.on("track-ended")](/zh-CN/api-reference/rtc/react-sdk/interfaces/ilocal-track#event_track_ended) 事件。 如果该轨道已发布，禁用轨道后，远端会触发 [user-unpublished](/zh-CN/api-reference/rtc/react-sdk/interfaces/iagora-rtcclient#event_user_unpublished) 事件。重新启用后，远端会触发 [user-published](/zh-CN/api-reference/rtc/react-sdk/interfaces/iagora-rtcclient#event_user_published) 事件。 `setEnabled` 和 `setMuted` 不能同时调用。

#### Parameters

| Name | Description |
| --- | --- |
| enabled: boolean | 是否启用该轨道:<br />- true: 启用该轨道。<br />- false: 禁用该轨道。 |

#### Returns

Returns Promise &lt; void &gt;

<a id="setmuted"></a>

### setMuted

```ts
setMuted(muted: boolean): Promise<void>
```

发送或暂停发送该轨道的媒体数据。

##### `自从`

<br /> *4.6.0*

如果该轨道已发布，调用 `setMuted(true)` 后，远端会触发 [user-unpublished](/zh-CN/api-reference/rtc/react-sdk/interfaces/iagora-rtcclient#event_user_unpublished) 事件。再调用 `setMuted(false)` 后，远端会触发 [user-published](/zh-CN/api-reference/rtc/react-sdk/interfaces/iagora-rtcclient#event_user_published) 事件。

与 [setEnabled](/zh-CN/api-reference/rtc/react-sdk/interfaces/ilocal-track#setenabled) 相比，调用该方法响应速度更快且不影响视频采集状态，详见 [setEnabled 和 setMuted 有什么区别？](http://doc.shengwang.cn/faq/integration-issues/diff-setenabled-setmuted)。 `setEnabled` 和 `setMuted` 不能同时调用。

#### Parameters

| Name | Description |
| --- | --- |
| muted: boolean | 是否发送该轨道的媒体数据:<br />- true: 暂停发送该轨道的媒体数据。<br />- false: 恢复发送该轨道的媒体数据。 |

#### Returns

Returns Promise &lt; void &gt;
