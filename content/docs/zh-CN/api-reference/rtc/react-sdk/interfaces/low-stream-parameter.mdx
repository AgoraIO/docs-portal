小流的视频属性，用于 [setLowStreamParameter](/zh-CN/api-reference/rtc/react-sdk/interfaces/iagora-rtcclient#setlowstreamparameter)。

- LowStreamParameter

## Properties

<a id="bitrate"></a>

### Optional bitrate

```ts
bitrate: number
```

小流视频的码率，单位为 Kbps。

<a id="framerate"></a>

### Optional framerate

```ts
framerate: ConstrainULong
```

小流视频的帧率。

可以传入一个 `number`，或一个约束对象，如 `{max: 30, min: 5}`。

关于约束对象的详细说明可以参考 [ConstrainLong](/zh-CN/api-reference/rtc/react-sdk/interfaces/constrain-long)。

<a id="height"></a>

### height

```ts
height: ConstrainULong
```

小流视频的分辨率高。

可以传入一个 `number`，或一个约束对象，如 `{max: 720, min: 480}`。

关于约束对象的详细说明可以参考 [ConstrainLong](/zh-CN/api-reference/rtc/react-sdk/interfaces/constrain-long)。

<a id="width"></a>

### width

```ts
width: ConstrainULong
```

小流视频的分辨率宽。

可以传入一个 `number`，或一个约束对象，如 `{max: 1280, min: 720}`。

关于约束对象的详细说明可以参考 [ConstrainLong](/zh-CN/api-reference/rtc/react-sdk/interfaces/constrain-long)。
