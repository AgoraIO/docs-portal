### RELAY_STATE_IDLE

<ApiSignature>

RELAY_STATE_IDLE: = "RELAY_STATE_IDLE"

</ApiSignature>

SDK 报告转发服务处于空闲状态。在 Web SDK 4.22.0 中，该状态既可能表示初始化后尚未开启服务，也可能出现在临时信令断连恢复期间；不能仅因收到该状态就重新调用 [startChannelMediaRelay](/zh-CN/api-reference/rtc/react-sdk/web-sdk/interfaces/iagorartcclient#startchannelmediarelay)。

<a id="relay_state_running"></a>

### RELAY_STATE_RUNNING

<ApiSignature>

RELAY_STATE_RUNNING: = "RELAY_STATE_RUNNING"

</ApiSignature>

SDK 报告跨频道媒体流转发服务处于运行状态；这不表示最近一次目标频道更新请求一定成功，本次更新结果应以 [updateChannelMediaRelay](/zh-CN/api-reference/rtc/react-sdk/web-sdk/interfaces/iagorartcclient#updatechannelmediarelay) 返回的 Promise 为准。
