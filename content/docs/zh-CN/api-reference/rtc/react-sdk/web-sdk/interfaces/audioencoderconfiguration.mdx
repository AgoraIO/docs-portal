用于创建音频流时指定自定义的编码配置。

你可以在 [AgoraRTC.createCustomAudioTrack](/zh-CN/api-reference/rtc/react-sdk/web-sdk/interfaces/iagorartc#createcustomaudiotrack)、
 [AgoraRTC.createMicrophoneAudioTrack](/zh-CN/api-reference/rtc/react-sdk/web-sdk/interfaces/iagorartc#createmicrophoneaudiotrack) 或
 [AgoraRTC.createBufferSourceAudioTrack](/zh-CN/api-reference/rtc/react-sdk/web-sdk/interfaces/iagorartc#createbuffersourceaudiotrack) 方法中传入该配置对象来自定义本地音频的编码配置。
