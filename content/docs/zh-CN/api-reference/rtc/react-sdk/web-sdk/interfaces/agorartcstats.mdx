<a id="duration"></a>

### Duration

Duration: number

在当前频道内的时长，单位为秒。

<a id="outgoingavailablebandwidth"></a>

### OutgoingAvailableBandwidth

OutgoingAvailableBandwidth: number

上行可用带宽估计，单位为 Kbps。

<a id="rtt"></a>

### RTT

RTT: number

SDK 到声网边缘服务器的 RTT (Round-Trip Time)，单位 ms。

<a id="recvbitrate"></a>

### RecvBitrate

RecvBitrate: number

音视频总接收码率，单位为 bps，瞬间值。

<a id="recvbytes"></a>

### RecvBytes

RecvBytes: number

接收字节数，累计值。

<a id="sendbitrate"></a>

### SendBitrate

SendBitrate: number

音视频总发送码率，单位为 bps，瞬间值。

<a id="sendbytes"></a>

### SendBytes

SendBytes: number

发送字节数，累计值。

<a id="usercount"></a>

### UserCount

UserCount: number

通信场景下，该值为当前频道内的用户人数。

直播场景下，如果本地用户为主播，该值为当前频道内的主播人数；如果本地用户为观众，该值为当前频道内的主播人数 + 1。
