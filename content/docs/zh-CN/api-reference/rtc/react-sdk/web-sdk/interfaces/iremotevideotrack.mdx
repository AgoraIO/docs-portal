### video-element-visible-status

- video-element-visible-status(data?:[CheckVideoVisibleResult](/zh-CN/api-reference/rtc/react-sdk/web-sdk/globals#checkvideovisibleresult)):void

:::info[自从]
*4.8.0*

提示 HTML `<video>` 标签的可见状态和不可见原因。SDK 每 30 秒触发一次该事件。

调用 `remoteVideoTrack.play` 后 SDK 会创建 [HTML `<video>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/video) 标签用于播放视频轨道。当 `remoteVideoTrack.isPlaying` 为 `true` 却看不到图像时，你可通过此事件来进行问题排查。
:::

<ParameterList title="Parameters">
<Parameter name="data" optional>

<ParameterType>

[CheckVideoVisibleResult](/zh-CN/api-reference/rtc/react-sdk/web-sdk/globals#checkvideovisibleresult)

</ParameterType>

`<video>` 标签的可见状态信息。

</Parameter>
</ParameterList>

Returns void
