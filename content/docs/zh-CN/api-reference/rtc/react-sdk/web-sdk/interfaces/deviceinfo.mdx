- 音频采集设备信息可通过 [onMicrophoneChanged](/zh-CN/api-reference/rtc/react-sdk/web-sdk/interfaces/iagorartc#onmicrophonechanged) 获取。
- 视频采集设备信息可通过 [onCameraChanged](/zh-CN/api-reference/rtc/react-sdk/web-sdk/interfaces/iagorartc#oncamerachanged) 获取。
- 音频播放设备信息可通过 [onPlaybackDeviceChanged](/zh-CN/api-reference/rtc/react-sdk/web-sdk/interfaces/iagorartc#onplaybackdevicechanged) 获取。
