<a id="codectype"></a>

### Optional codecType

codecType: "opus"|"aac"|"PCMU"|"PCMA"|"G722"

音频的编码格式。

- `"opus"`: 音频编码格式为 OPUS。
- `"aac"`: 音频编码格式为 AAC。
- `"pcmu"`: 预留参数，暂不支持。
- `"pcma"`: 预留参数，暂不支持。
- `"g722"`: 预留参数，暂不支持。

> Firefox 上无法获取该值。

<a id="currentpacketlossrate"></a>

### currentPacketLossRate

currentPacketLossRate: number

接收的音频400ms内的丢包率。

<a id="end2enddelay"></a>

### end2EndDelay

end2EndDelay: number

音频端到端延迟（ms）。

从远端采集音频到本地播放音频的延迟。该延迟不包括发送端编码和接收端解码的时间。

<a id="freezerate"></a>

### freezeRate

freezeRate: number

接收的音频卡顿率。

<a id="packetlossrate"></a>

### packetLossRate

packetLossRate: number

接收的音频总丢包率。

<a id="publishduration"></a>

### publishDuration

publishDuration: number

远端发布音频时长
 如果为 -1，说明暂时还无法获取发布时长

<a id="receivebitrate"></a>

### receiveBitrate

receiveBitrate: number

接收的音频码率（bps）。

<a id="receivebytes"></a>

### receiveBytes

receiveBytes: number

接收的音频总字节数。

<a id="receivedelay"></a>

### receiveDelay

receiveDelay: number

接收音频延迟 (ms)。

从发送到接收端播放音频的延迟时间。

> Safari 和 Firefox 上该字段不准确。

<a id="receivelevel"></a>

### receiveLevel

receiveLevel: number

接收的音频音量等级，范围为 [0,32767]。

> 该值通过 WebRTC-Stats 获取，不能确保实时性。如果你想获取当前实时的音量等级，调用 [RemoteAudioTrack.getVolumeLevel](/zh-CN/api-reference/rtc/react-sdk/web-sdk/interfaces/iremoteaudiotrack#getvolumelevel)。
