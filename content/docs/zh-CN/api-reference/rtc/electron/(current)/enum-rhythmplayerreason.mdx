## 枚举值

### `RhythmPlayerReasonOk`

0：正常播放节拍音频文件，没有错误。

### `RhythmPlayerReasonFailed`

1：一般性错误，没有明确原因。

### `RhythmPlayerReasonCanNotOpen`

801：打开节拍音频文件出错。

### `RhythmPlayerReasonCanNotPlay`

802：播放节拍音频文件出错。

### `RhythmPlayerReasonFileOverDurationLimit`

803：节拍音频文件时长超出限制。最大时长为 1.2 秒。
