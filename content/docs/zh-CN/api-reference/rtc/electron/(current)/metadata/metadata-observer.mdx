## registerMediaMetadataObserver

注册媒体 metadata 观测器用于接收或发送 metadata。

<a id="api_irtcengine_registermediametadataobserver__prototype"></a>

```typescript
abstract registerMediaMetadataObserver(
    observer: IMetadataObserver,
    type: MetadataType
  ): number;
```

<a id="api_irtcengine_registermediametadataobserver__detailed_desc"></a>

你需要自行实现 [IMetadataObserver](/zh-CN/api-reference/rtc/electron/rtc-interface-class#class_imetadataobserver) 类并在本方法中指定 metadata 类型。本方法允许你为视频流添加同步的 metadata，用于多样化的直播互动，如发送购物链接、电子优惠券和在线测试。

:::info[注]
请在 [joinChannel](/zh-CN/api-reference/rtc/electron/channel#api_irtcengine_joinchannel2) 前调用该方法。
:::

<a id="api_irtcengine_registermediametadataobserver__parameters"></a>

### 参数

#### `observer`

metadata 观测器。详见 [IMetadataObserver](/zh-CN/api-reference/rtc/electron/rtc-interface-class#class_imetadataobserver)。

#### `type`

metadata 类型。目前仅支持 `VideoMetadata`。详见 [MetadataType](/zh-CN/api-reference/rtc/electron/enum-metadatatype)。

<a id="api_irtcengine_registermediametadataobserver__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](/zh-CN/realtime-media/rtc/reference/error-code)了解详情和解决建议。

### 所属接口类
- [IRtcEngine](/zh-CN/api-reference/rtc/electron/rtc-interface-class#class_irtcengine)

## sendMetaData

发送媒体附属信息。

<a id="api_irtcengine_sendmetadata__prototype"></a>

```typescript
abstract sendMetaData(metadata: Metadata, sourceType: VideoSourceType): number;
```

<a id="api_irtcengine_sendmetadata__detailed_desc"></a>

如果成功发送了媒体附属信息，接收端会收到 [onMetadataReceived](/zh-CN/api-reference/rtc/electron/metadata/metadata-observer#callback_imetadataobserver_onmetadatareceived) 回调。

<a id="api_irtcengine_sendmetadata__parameters"></a>

### 参数

#### `metadata`

媒体附属信息。详见 [Metadata](/zh-CN/api-reference/rtc/electron/class-metadata)。

#### `sourceType`

视频源的类型，详见 [VideoSourceType](/zh-CN/api-reference/rtc/electron/enum-videosourcetype)。

<a id="api_irtcengine_sendmetadata__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](/zh-CN/realtime-media/rtc/reference/error-code)了解详情和解决建议。

### 所属接口类
- [IRtcEngine](/zh-CN/api-reference/rtc/electron/rtc-interface-class#class_irtcengine)
