## registerMediaMetadataObserver

注册媒体 metadata 观测器用于接收或发送 metadata。

<a id="api_irtcengine_registermediametadataobserver__prototype"></a>

```text
abstract registerMediaMetadataObserver(
    observer: IMetadataObserver,
    type: MetadataType
  ): number;
```

<a id="api_irtcengine_registermediametadataobserver__detailed_desc"></a>

你需要自行实现 [IMetadataObserver](/zh-CN/api-reference/rtc/electron/rtc-interface-class#class_imetadataobserver) 类并在本方法中指定 metadata 类型。本方法允许你为视频流添加同步的 metadata，用于多样化的直播互动，如发送购物链接、电子优惠券和在线测试。

:::note
注： 请在 [joinChannel](/zh-CN/api-reference/rtc/electron/channel#api_irtcengine_joinchannel2) 前调用该方法。
:::

<a id="api_irtcengine_registermediametadataobserver__parameters"></a>

### 参数

<ParameterList>
<a id="observer"></a>
<Parameter name="observer">

metadata 观测器。详见 [IMetadataObserver](/zh-CN/api-reference/rtc/electron/rtc-interface-class#class_imetadataobserver)。

</Parameter>
<a id="type"></a>
<Parameter name="type">

metadata 类型。目前仅支持 `VideoMetadata`。详见 [MetadataType](/zh-CN/api-reference/rtc/electron/enum-metadatatype)。

</Parameter>
</ParameterList>

<a id="api_irtcengine_registermediametadataobserver__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。
