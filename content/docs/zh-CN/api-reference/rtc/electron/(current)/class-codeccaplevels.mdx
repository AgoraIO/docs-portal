```typescript
export class CodecCapLevels {
  hwDecodingLevel?: VideoCodecCapabilityLevel;
  swDecodingLevel?: VideoCodecCapabilityLevel;
}
```

<a id="class_codeccaplevels__parameters"></a>

## 属性

### `hwDecodingLevel`

硬件解码能力等级，表示设备能够对不同品质视频进行硬件解码的能力。详见 [VIDEO_CODEC_CAPABILITY_LEVEL](/zh-CN/api-reference/rtc/electron/enum-videocodeccapabilitylevel)。

### `swDecodingLevel`

软件解码能力等级，表示设备能够对不同品质视频进行软件解码的能力。详见 [VIDEO_CODEC_CAPABILITY_LEVEL](/zh-CN/api-reference/rtc/electron/enum-videocodeccapabilitylevel)。
