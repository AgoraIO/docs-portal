```text
export class VideoSubscriptionOptions {

  type?: VideoStreamType;

}
```

<a id="class_videosubscriptionoptions__parameters"></a>

## 属性

### type

订阅的视频流类型，默认值为 VideoStreamHigh，即订阅视频大流。详见 [VideoStreamType](/zh-CN/api-reference/rtc/electron/enum-videostreamtype)。

### encodedFrameOnly

是否仅订阅编码后的视频流：

- true：仅订阅编码后的视频数据（结构化数据），SDK 未对该视频数据做解码及渲染。
- false：（默认）订阅原始视频数据和编码后的数据。
