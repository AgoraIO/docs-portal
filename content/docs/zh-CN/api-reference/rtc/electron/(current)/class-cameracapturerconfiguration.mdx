<a id="class_cameracapturerconfiguration__prototype"></a>

```typescript
export class CameraCapturerConfiguration {
  
  deviceId?: string;
  
  format?: VideoFormat;

  followEncodeDimensionRatio?: boolean;

}
```

<a id="class_cameracapturerconfiguration__parameters"></a>

## 属性

### `format`

（可选）视频帧格式。详见 [VideoFormat](/zh-CN/api-reference/rtc/electron/class-videoformat)。

### `deviceId`

（可选）摄像头的 ID。最大长度为 [MaxDeviceIdLengthType](/zh-CN/api-reference/rtc/electron/enum-maxdeviceidlengthtype)。

### `followEncodeDimensionRatio`

（可选）是否跟随 [setVideoEncoderConfiguration](/zh-CN/api-reference/rtc/electron/video/video-basic#api_irtcengine_setvideoencoderconfiguration) 中设置的视频宽高比：

- true：(默认) 跟随。SDK 会将采集到的视频按照已设置的视频宽高比进行裁剪，会同步改变本地预览画面、 onCaptureVideoFrame 和 onPreEncodeVideoFrame 中的视频画面。
- false：不跟随。SDK不改变采集到的视频帧宽高比。
