## getInternalSongCode

创建音乐资源的副歌片段编号。

<a id="api_imusiccontentcenter_getinternalsongcode__prototype"></a>

```typescript
abstract getInternalSongCode(songCode: number, jsonOption: string): number;
```

<a id="api_imusiccontentcenter_getinternalsongcode__detailed_desc"></a>

<a id="api_imusiccontentcenter_getinternalsongcode__scenario"></a>

### 适用场景

当你需要播放某一音乐资源的副歌片段前，你需要调用此方法，通过 `jsonOption` 参数和该音乐资源的 `songCode` 来为该音乐资源的副歌片段创建一个编号，作为该资源的唯一标识。当你获取到该片段的编号后，在你调用相应方法打开、预加载、移除该资源时，将该内部歌曲编号传入 `songCode` 参数。

<a id="api_imusiccontentcenter_getinternalsongcode__parameters"></a>

### 参数

#### `songCode`

音乐资源编号，用于标识音乐资源。你可以通过调用 [getMusicCollectionByMusicChartId](/zh-CN/api-reference/rtc/electron/drm#api_imusiccontentcenter_getmusiccollectionbymusicchartid) 或 [searchMusic](/zh-CN/api-reference/rtc/electron/drm#api_imusiccontentcenter_searchmusic) 方法来获取音乐资源，并通过由此触发的 [onMusicCollectionResult](/zh-CN/api-reference/rtc/electron/drm#callback_imusiccontentcentereventhandler_onmusiccollectionresult) 回调获取音乐资源的编号（`songCode` ）。

#### `jsonOption`

:::info[注]
声网会根据你在 `sceneType` 传入的应用场景进行收费。不同的应用场景对应不同的费率，你可以参考 [计费说明](https://doc.shengwang.cn/doc/online-ktv/android/online-ktv-sdk/overview/billing) 查看详细的计费。如果需要切换到不同场景，需要重新调用此方法并传入 `sceneType` 的值。
:::

扩展 JSON 字段，默认为 null。目前支持传入下列值：

- sceneType：场景类型。1：直播场景，在线 K 歌房和背景音乐播放；2：直播场景，背景音乐播放；3：（默认）声动语聊场景，在线 K 歌房；4：声动语聊场景，背景音乐播放；5：VR 场景，在线 K 歌房和背景音乐播放。示例： \{"sceneType":1\}。
- highPart：副歌片段的索引，从 onMusicCollectionResult 回调中获取，索引从 0 开始。示例： \{"format": \{"highpart": 0\}\}。

<a id="api_imusiccontentcenter_getinternalsongcode__return_values"></a>

### 返回值

- 方法调用成功，返回创建的音乐资源内部编号。
- &lt; 0: 方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/electron/error-code)了解详情和解决建议。

### 所属接口类
- [IMusicContentCenter](/zh-CN/api-reference/rtc/electron/rtc-interface-class#class_imusiccontentcenter)

## getMusicCollectionByMusicChartId

通过音乐榜单的 ID 获取指定榜单的音乐资源列表。

<a id="api_imusiccontentcenter_getmusiccollectionbymusicchartid__prototype"></a>

```typescript
abstract getMusicCollectionByMusicChartId(
    musicChartId: number,
    page: number,
    pageSize: number,
    jsonOption?: string
  ): string;
```

<a id="api_imusiccontentcenter_getmusiccollectionbymusicchartid__detailed_desc"></a>

成功调用该方法后，SDK 会触发 [onMusicCollectionResult](/zh-CN/api-reference/rtc/electron/drm#callback_imusiccontentcentereventhandler_onmusiccollectionresult) 回调报告榜单中音乐资源列表的详细信息。

<a id="api_imusiccontentcenter_getmusiccollectionbymusicchartid__parameters"></a>

### 参数

#### `musicChartId`

音乐榜单的 ID，可以通过 [onMusicChartsResult](/zh-CN/api-reference/rtc/electron/drm#callback_imusiccontentcentereventhandler_onmusicchartsresult) 回调获取。你也可以通过 RESTful API 来[获取曲库所有歌曲列表](https://doc.shengwang.cn/doc/online-ktv/android/ktv-scenario/api/music-content-center#%E8%8E%B7%E5%8F%96%E6%9B%B2%E5%BA%93%E6%89%80%E6%9C%89%E6%AD%8C%E6%9B%B2%E5%88%97%E8%A1%A8)或[获取增量歌曲列表](https://doc.shengwang.cn/doc/online-ktv/android/ktv-scenario/api/music-content-center#%E8%8E%B7%E5%8F%96%E5%A2%9E%E9%87%8F%E6%AD%8C%E6%9B%B2%E5%88%97%E8%A1%A8)。

#### `page`

当前页面编号，默认从 1 开始。

#### `pageSize`

当前音乐资源列表的总页面数量，最大值为 50。

#### `jsonOption`

扩展 JSON 字段，默认为 null。你可以通过该字段来筛选出你需要的音乐资源，目前支持筛选可打分的音乐资源及音乐资源的副歌片段：

- pitchType：音乐资源是否支持评分。
  - 1：可评分的音乐资源。
  - 2：不可评分的音乐资源。

- needHighPart：是否需要合唱片段资源。
  - YES：需要合唱片段资源。
  - NO：不需要合唱片段资源。

<a id="api_imusiccontentcenter_getmusiccollectionbymusicchartid__return_values"></a>

### 返回值

一个 `requestId`，为本次请求的唯一标识。

### 所属接口类
- [IMusicContentCenter](/zh-CN/api-reference/rtc/electron/rtc-interface-class#class_imusiccontentcenter)

## openWithSongCode

通过音乐资源编号打开音乐资源。

<a id="api_imusicplayer_open_imusicplayer__prototype"></a>

```typescript
abstract openWithSongCode(songCode: number, startPos?: number): number;
```

<a id="api_imusicplayer_open_imusicplayer__detailed_desc"></a>

在调用此方法之前，请确保需要播放的音乐资源已加载完成。你可以调用 [isPreloaded](/zh-CN/api-reference/rtc/electron/drm#api_imusiccontentcenter_ispreloaded) 方法来检测音乐资源是否已被预加载，或通过 [onPreLoadEvent](/zh-CN/api-reference/rtc/electron/drm#callback_imusiccontentcentereventhandler_onpreloadevent_imusiccontentcentereventhandler) 回调得知。 调用该方法后会触发 [onPlayerSourceStateChanged](/zh-CN/api-reference/rtc/electron/mediaplayer-observer#callback_imediaplayersourceobserver_onplayersourcestatechanged) 回调。在收到报告播放状态为 `PlayerStateOpenCompleted` 后，你可以调用 [play](/zh-CN/api-reference/rtc/electron/mediaplayer-control#api_imediaplayer_play) 方法播放媒体文件。

:::info[注]
如果你想要打开的音乐资源受数字版权保护，则需要调用此方法打开。对于不受数字版权保护的音乐资源，你可以选择通过调用此方法或 [IMediaPlayer](/zh-CN/api-reference/rtc/electron/rtc-interface-class#class_imediaplayer) 类下的 [open](/zh-CN/api-reference/rtc/electron/mediaplayer-open#api_imediaplayer_open) 方法来打开。
:::

<a id="api_imusicplayer_open_imusicplayer__parameters"></a>

### 参数

#### `songCode`

音乐资源的编号，用于标识音乐资源。

#### `startPos`

设置起始播放位置（毫秒），默认值为 0。

<a id="api_imusicplayer_open_imusicplayer__return_values"></a>

#### `keyword`

搜索关键词，支持歌曲名、歌手搜索。

想要获取的音乐资源列表的目标页编号。
