<a id="class_playerplaybackstats__prototype"></a>

```typescript
export class PlayerPlaybackStats {
  videoFps?: number;
  videoBitrateInKbps?: number;
  audioBitrateInKbps?: number;
  totalBitrateInKbps?: number;
}
```

<a id="class_playerplaybackstats__parameters"></a>

## 属性

### `videoFps`

视频帧率，单位为 fps。

### `videoBitrateInKbps`

视频码率，单位为 kbps。

### `audioBitrateInKbps`

音频码率，单位为 kbps。

### `totalBitrateInKbps`

媒体流的总码率，单位为 kbps。
