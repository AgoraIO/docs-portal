---
title: "Rectangle"
description: "目标区域相对于整个屏幕或窗口的位置，如不填，则表示整个屏幕或窗口。"
---
<a id="class_rectangle__prototype"></a>

```typescript
export class Rectangle {
  
  x?: number;
  
  y?: number;
  
  width?: number;
  
  height?: number;
}
```

<a id="class_rectangle__parameters"></a>

## 属性

### `x`

左上角的横向偏移。

### `y`

左上角的纵向偏移。

### `width`

目标区域的宽度。

### `height`

目标区域的高度。
