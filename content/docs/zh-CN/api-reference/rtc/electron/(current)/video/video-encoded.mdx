## addListener

添加一个 [IMediaEngineEvent](/zh-CN/api-reference/rtc/electron/rtc-interface-class#class_imediaengineevent) 监听器。

<a id="api_imediaengine_addlistener_imediaengine__prototype"></a>

```text
addListener?<EventType extends keyof IMediaEngineEvent>(
      eventType: EventType,
      listener: IMediaEngineEvent[EventType]
    ): void;
```

<a id="api_imediaengine_addlistener_imediaengine__detailed_desc"></a>

成功调用该方法后，你可以通过 [IMediaEngineEvent](/zh-CN/api-reference/rtc/electron/rtc-interface-class#class_imediaengineevent) 监听对应 [IMediaEngine](/zh-CN/api-reference/rtc/electron/rtc-interface-class#class_imediaengine) 对象的事件、获取数据。根据业务需要，你可以为同一事件添加多个监听器。

<a id="api_imediaengine_addlistener_imediaengine__parameters"></a>

### 参数

<ParameterList>
<a id="eventtype"></a>
<Parameter name="eventType">

需要监听的目标事件名。详见 [IMediaEngineEvent](/zh-CN/api-reference/rtc/electron/rtc-interface-class#class_imediaengineevent)。

</Parameter>
<a id="listener"></a>
<Parameter name="listener">

`eventType` 对应的回调函数。以添加 [onPlaybackAudioFrameBeforeMixing](/zh-CN/api-reference/rtc/electron/audio/audio-raw#callback_iaudioframeobserver_onplaybackaudioframebeforemixing) 为例：

```text
const onPlaybackAudioFrameBeforeMixing = (channelId: string, uid: number, audioFrame: AudioFrame) => {};
engine.addListener('onPlaybackAudioFrameBeforeMixing', onPlaybackAudioFrameBeforeMixing);
```

</Parameter>
</ParameterList>

### 所属接口类

- [IMediaEngine](/zh-CN/api-reference/rtc/electron/rtc-interface-class#class_imediaengine)

## registerVideoEncodedFrameObserver

为编码后的视频图像注册视频帧接收观测器。

<a id="api_imediaengine_registervideoencodedframeobserver__prototype"></a>

```text
abstract registerVideoEncodedFrameObserver(
    observer: IVideoEncodedFrameObserver
  ): number;
```

<a id="api_imediaengine_registervideoencodedframeobserver__detailed_desc"></a>

如果你只想要观测编码后的视频帧 (如 H.264 格式)，而不需要对视频进行解码和渲染，声网推荐你通过该方法注册一个 [IVideoEncodedFrameObserver](/zh-CN/api-reference/rtc/electron/rtc-interface-class#class_ivideoencodedframeobserver) 类。

:::note
注： 该方法需要在加入频道前调用。
:::

<a id="api_imediaengine_registervideoencodedframeobserver__parameters"></a>

### 参数

<ParameterList>
<a id="observer"></a>
<Parameter name="observer">

视频帧接收观测器，详见 [IVideoEncodedFrameObserver](/zh-CN/api-reference/rtc/electron/rtc-interface-class#class_ivideoencodedframeobserver)。

</Parameter>
</ParameterList>

<a id="api_imediaengine_registervideoencodedframeobserver__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。

## onEncodedVideoFrameReceived

报告接收端已收到远端发送的待解码视频帧。

<a id="callback_ivideoencodedframeobserver_onencodedvideoframereceived__prototype"></a>

```text
onEncodedVideoFrameReceived?(
    channelId: string,
    uid: number,
    imageBuffer: Uint8Array,
    length: number,
    videoEncodedFrameInfo: EncodedVideoFrameInfo
  ): void;
```

<a id="callback_ivideoencodedframeobserver_onencodedvideoframereceived__detailed_desc"></a>

调用 [setRemoteVideoSubscriptionOptions](/zh-CN/api-reference/rtc/electron/publishnsubscribe#api_irtcengine_setremotevideosubscriptionoptions) 方法并将 `encodedFrameOnly` 设置为 true 时，SDK 会在本地触发该回调，上报接收到的编码后视频帧信息。

<Parameter name="channelId">

频道名。

</Parameter>
<a id="uid"></a>
<Parameter name="uid">

远端用户 ID。

</Parameter>
<a id="imagebuffer"></a>
<Parameter name="imageBuffer">

视频图像 buffer。

</Parameter>
<a id="length"></a>
<Parameter name="length">

视频图像的数据长度。

</Parameter>
<a id="videoencodedframeinfo"></a>
<Parameter name="videoEncodedFrameInfo">

编码后的视频帧信息，详见 [EncodedVideoFrameInfo](/zh-CN/api-reference/rtc/electron/class-encodedvideoframeinfo)。

</Parameter>
