<a id="class_agorarhythmplayerconfig__prototype"></a>

```typescript
export class AgoraRhythmPlayerConfig {
  
  beatsPerMeasure?: number;
  
  beatsPerMinute?: number;
}
```

<a id="class_agorarhythmplayerconfig__parameters"></a>

## 属性

### `beatsPerMeasure`

每小节的拍数，取值范围为 [1,9]。默认值为 4，即每小节包含 1 个强拍和 3 个弱拍。

### `beatsPerMinute`

节拍速度（拍/分钟），取值范围为 [60,360]。默认值为 60，即 1 分钟有 60 拍。
