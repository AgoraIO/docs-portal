## 枚举值

### `AudioSourceMicrophone`

0：（默认）麦克风。

### `AudioSourceCustom`

1：自定义采集到的音频流。

### `AudioSourceMediaPlayer`

2：媒体播放器。

### `AudioSourceLoopbackRecording`

3：在屏幕共享时采集的系统音频流。

### `AudioSourceRemoteUser`

5：指定远端用户的音频流。

### `AudioSourceRemoteChannel`

6：当前频道内所有音频流的合流。

### `AudioSourceUnknown`

100：未知的音频源。
