### `自从`

自 v4.4.0 版本新增。

<a id="enum_faceshapebeautystyle__parameters"></a>

## 枚举值

### `FaceShapeBeautyStyleFemale`

（0）：（默认）女性风格妆特效。

### `FaceShapeBeautyStyleMale`

（1）：男性风格妆特效。

### `FaceShapeBeautyStyleNatural`

（2）：自然风格妆特效，仅对面部特征进行最小调整。
