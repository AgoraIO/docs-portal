## registerAudioFrameObserver

注册音频帧观测器。

<a id="api_imediaplayer_registeraudioframeobserver2_imediaplayer__prototype"></a>

```typescript
abstract registerAudioFrameObserver(
    observer: IAudioPcmFrameSink,
    mode?: RawAudioFrameOpModeType
  ): number;
```

<a id="api_imediaplayer_registeraudioframeobserver2_imediaplayer__detailed_desc"></a>

<a id="api_imediaplayer_registeraudioframeobserver2_imediaplayer__parameters"></a>

### 参数

#### `observer`

音频帧观测器，观测每帧音频的接收，详见 [IAudioPcmFrameSink](/zh-CN/api-reference/rtc/electron/rtc-interface-class#class_iaudiopcmframesink)。

#### `mode`

音频帧的使用模式，详见 [RawAudioFrameOpModeType](/zh-CN/api-reference/rtc/electron/enum-rawaudioframeopmodetype)。

<a id="api_imediaplayer_registeraudioframeobserver2_imediaplayer__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/electron/error-code)了解详情和解决建议。

- [IMediaPlayer](/zh-CN/api-reference/rtc/electron/rtc-interface-class#class_imediaplayer)

## registerVideoFrameObserver

注册视频帧观测器。

<a id="api_imediaplayer_registervideoframeobserver_imediaplayer__prototype"></a>

```typescript
abstract registerVideoFrameObserver(
    observer: IMediaPlayerVideoFrameObserver
  ): number;
```

<a id="api_imediaplayer_registervideoframeobserver_imediaplayer__detailed_desc"></a>

你需要在该方法中实现一个 [IMediaPlayerVideoFrameObserver](/zh-CN/api-reference/rtc/electron/rtc-interface-class#class_imediaplayervideoframeobserver) 类，并根据场景需要，注册该类的回调。成功注册视频帧观测器后，SDK 会在捕捉到每个视频帧时，触发你所注册的回调。

<a id="api_imediaplayer_registervideoframeobserver_imediaplayer__parameters"></a>

### 参数

#### `observer`

视频帧观测器，观测每帧视频的接收。详见 [IMediaPlayerVideoFrameObserver](/zh-CN/api-reference/rtc/electron/rtc-interface-class#class_imediaplayervideoframeobserver)。

<a id="api_imediaplayer_registervideoframeobserver_imediaplayer__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/electron/error-code)了解详情和解决建议。

- [IMediaPlayer](/zh-CN/api-reference/rtc/electron/rtc-interface-class#class_imediaplayer)

## onPlayBufferUpdated

报告当前缓冲数据能播放的时间。

<a id="callback_imediaplayersourceobserver_onplaybufferupdated__prototype"></a>

```typescript
onPlayBufferUpdated?(playCachedBuffer: number): void;
```

<a id="callback_imediaplayersourceobserver_onplaybufferupdated__detailed_desc"></a>

播放在线媒体资源的过程中，SDK 会每隔 1 秒触发一次该回调，报告当前缓冲的数据能支持的播放时间。

- 当缓冲数据支持的播放时间小于阈值（默认为 0）时，返回 `PlayerEventBufferLow` (6)。
- 当缓冲数据支持的播放时间大于阈值（默认为 0）时，返回 `PlayerEventBufferRecover` (7)。

<a id="callback_imediaplayersourceobserver_onplaybufferupdated__parameters"></a>

### 参数

#### `playCachedBuffer`

当前缓冲的数据能支持的播放时间 (毫秒)。

- [IMediaPlayerSourceObserver](/zh-CN/api-reference/rtc/electron/rtc-interface-class#class_imediaplayersourceobserver)
