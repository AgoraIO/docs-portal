## getAudioBufferDelay

获取播放媒体文件时的音频缓冲延迟。

<a id="api_imediaplayer_getaudiobufferdelay__prototype"></a>

```typescript
abstract getAudioBufferDelay(): number;
```

<a id="api_imediaplayer_getaudiobufferdelay__detailed_desc"></a>

<a id="api_imediaplayer_getaudiobufferdelay__parameters"></a>

### 参数

#### `delayMs`

输出参数，表示播放媒体文件时的音频缓冲延迟，单位为毫秒。

<a id="api_imediaplayer_getaudiobufferdelay__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/electron/error-code)了解详情和解决建议。

### 所属接口类
- [IMediaPlayer](/zh-CN/api-reference/rtc/electron/rtc-interface-class#class_imediaplayer)

## getStreamCount

获取当前媒体文件中媒体流的数量。

<a id="api_imediaplayer_getstreamcount__prototype"></a>

```typescript
abstract getStreamCount(): number;
```

<a id="api_imediaplayer_getstreamcount__detailed_desc"></a>

:::info[注]
请在 [open](/zh-CN/api-reference/rtc/electron/play/mediaplayer/mediaplayer-open#api_imediaplayer_open) 后并收到 [onPlayerSourceStateChanged](/zh-CN/api-reference/rtc/electron/play/mediaplayer/mediaplayer-observer#callback_imediaplayersourceobserver_onplayersourcestatechanged) 回调报告播放状态为 `PlayerStateOpenCompleted` 后再调用该方法。
:::

<a id="api_imediaplayer_getstreamcount__return_values"></a>

### 返回值

- 方法调用成功，返回该媒体文件中媒体流的数量。
- &lt; 0: 方法调用失败，详见 MediaPlayerReason。

### 所属接口类
- [IMediaPlayer](/zh-CN/api-reference/rtc/electron/rtc-interface-class#class_imediaplayer)

## getStreamInfo

通过媒体流的索引值获取媒体流信息。

<a id="api_imediaplayer_getstreaminfo__prototype"></a>

```typescript
abstract getStreamInfo(index: number): PlayerStreamInfo;
```

<a id="api_imediaplayer_getstreaminfo__detailed_desc"></a>

<a id="api_imediaplayer_getstreaminfo__timing"></a>

### 调用时机

你需要在 [getStreamCount](/zh-CN/api-reference/rtc/electron/play/mediaplayer/mediaplayer-info#api_imediaplayer_getstreamcount) 后调用该方法。

<a id="api_imediaplayer_getstreaminfo__parameters"></a>

### 参数

#### `index`

媒体流索引值。该参数的值需小于 [getStreamCount](/zh-CN/api-reference/rtc/electron/play/mediaplayer/mediaplayer-info#api_imediaplayer_getstreamcount) 的返回值。

<a id="api_imediaplayer_getstreaminfo__return_values"></a>

### 返回值

- 方法调用成功，返回媒体流信息，详见 PlayerStreamInfo。
- 方法调用失败，返回 null。

### 所属接口类
- [IMediaPlayer](/zh-CN/api-reference/rtc/electron/rtc-interface-class#class_imediaplayer)

<a id="callback_imediaplayersourceobserver_onplayerplaybackstats"></a>

## onPlayerPlaybackStats

报告当前播放的媒体资源的相关信息。

<a id="callback_imediaplayersourceobserver_onplayerplaybackstats__prototype"></a>

```typescript
onPlayerPlaybackStats?(stats: PlayerPlaybackStats): void;
```

<a id="callback_imediaplayersourceobserver_onplayerplaybackstats__detailed_desc"></a>

当媒体资源开始播放后，SDK 会每秒触发一次该回调，报告媒体资源的相关信息。

<a id="callback_imediaplayersourceobserver_onplayerplaybackstats__parameters"></a>

### 参数

#### `stats`

媒体资源的相关信息，详见 [PlayerPlaybackStats](/zh-CN/api-reference/rtc/electron/class-playerplaybackstats)。

### 所属接口类
- [IMediaPlayerSourceObserver](/zh-CN/api-reference/rtc/electron/rtc-interface-class#class_imediaplayersourceobserver)
