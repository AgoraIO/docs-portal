## addListener

添加一个 IMediaPlayerEvent 监听器。

<a id="api_imediaplayer_addlistener_imediaplayer__prototype"></a>

```typescript
addListener?<EventType extends keyof IMediaPlayerEvent>(
      eventType: EventType,
      listener: IMediaPlayerEvent[EventType]
    ): void;
```

<a id="api_imediaplayer_addlistener_imediaplayer__detailed_desc"></a>

成功调用该方法后，你可以通过 [IMediaPlayerEvent](/zh-CN/api-reference/rtc/electron/rtc-interface-class#class_imediaplayerevent) 监听对应 [IMediaPlayer](/zh-CN/api-reference/rtc/electron/rtc-interface-class#class_imediaplayer) 对象的事件、获取数据。根据业务需要，你可以为同一事件添加多个监听器。

<a id="api_imediaplayer_addlistener_imediaplayer__parameters"></a>

### 参数

#### `eventType`

需要监听的目标事件名。详见 [IMediaPlayerEvent](/zh-CN/api-reference/rtc/electron/rtc-interface-class#class_imediaplayerevent)。

#### `listener`

`eventType` 对应的回调函数。以添加 [onPlayerSourceStateChanged](/zh-CN/api-reference/rtc/electron/play/mediaplayer/mediaplayer-observer#callback_imediaplayersourceobserver_onplayersourcestatechanged) 为例：

```typescript
const onPlayerSourceStateChanged = (connection: RtcConnection, elapsed: number) => {};
engine.addListener('onPlayerSourceStateChanged', onPlayerSourceStateChanged);
```

### 所属接口类
- [IMediaPlayer](/zh-CN/api-reference/rtc/electron/rtc-interface-class#class_imediaplayer)

## createMediaPlayer

创建媒体播放器对象。

<a id="api_irtcengine_createmediaplayer__prototype"></a>

```typescript
abstract createMediaPlayer(): IMediaPlayer;
```

<a id="api_irtcengine_createmediaplayer__detailed_desc"></a>

在调用 [IMediaPlayer](/zh-CN/api-reference/rtc/electron/rtc-interface-class#class_imediaplayer) 类下的其他 API 前，你需要先调用该方法创建一个媒体播放器实例。如果你需要创建多个实例，可以多次调用该方法。

<a id="api_irtcengine_createmediaplayer__timing"></a>

### 调用时机

该方法在加入频道前后均可调用。

<a id="api_irtcengine_createmediaplayer__parameters"></a>

### 参数

#### `delegate`

[IRtcEngine](/zh-CN/api-reference/rtc/electron/rtc-interface-class#class_irtcengine) 的事件句柄，详见 [IRtcEngineEventHandler](/zh-CN/api-reference/rtc/electron/rtc-interface-class#class_irtcengineeventhandler)。

<a id="api_irtcengine_createmediaplayer__return_values"></a>

### 返回值

- 方法调用成功：返回 IMediaPlayer 对象。
- 方法调用失败：返回空指针。

### 所属接口类
- [IRtcEngine](/zh-CN/api-reference/rtc/electron/rtc-interface-class#class_irtcengine)

## destroyMediaPlayer

销毁媒体播放器。

<a id="api_irtcengine_destroymediaplayer__prototype"></a>

```typescript
abstract destroyMediaPlayer(mediaPlayer: IMediaPlayer): number;
```

<a id="api_irtcengine_destroymediaplayer__detailed_desc"></a>

<a id="api_irtcengine_destroymediaplayer__parameters"></a>

### 参数

#### `mediaPlayer`

[IMediaPlayer](/zh-CN/api-reference/rtc/electron/rtc-interface-class#class_imediaplayer) 对象。

<a id="api_irtcengine_destroymediaplayer__return_values"></a>

### 返回值

- ≥ 0: 方法调用成功，返回媒体播放器 ID
- &lt; 0: 方法调用失败。详见[错误码](/zh-CN/realtime-media/rtc/reference/error-code)了解详情和解决建议。

### 所属接口类
- [IRtcEngine](/zh-CN/api-reference/rtc/electron/rtc-interface-class#class_irtcengine)

## getMediaPlayerCacheManager

获取 IMediaPlayerCacheManager 实例。

<a id="api_imediaplayercachemanager_getmediaplayercachemanager__prototype"></a>

```typescript
export function getMediaPlayerCacheManager(): IMediaPlayerCacheManager {
  return new IMediaPlayerCacheManagerImpl();
}
```

<a id="api_imediaplayercachemanager_getmediaplayercachemanager__detailed_desc"></a>

在调用 [IMediaPlayerCacheManager](/zh-CN/api-reference/rtc/electron/rtc-interface-class#class_imediaplayercachemanager) 类下的其他 API 前，你需要先调用该方法获取一个媒体播放器缓存管理器的实例。

:::info[注]
由于媒体播放器缓存管理器对象是单例模式，因此多次调用该方法将返回同一个实例。
:::

<a id="api_imediaplayercachemanager_getmediaplayercachemanager__timing"></a>

### 调用时机

请在初始化 [IRtcEngine](/zh-CN/api-reference/rtc/electron/rtc-interface-class#class_irtcengine) 后调用该方法。

<a id="api_imediaplayercachemanager_getmediaplayercachemanager__return_values"></a>

### 返回值

[IMediaPlayerCacheManager](/zh-CN/api-reference/rtc/electron/rtc-interface-class#class_imediaplayercachemanager) 实例。

### 所属接口类
- [IMediaPlayerCacheManager](/zh-CN/api-reference/rtc/electron/rtc-interface-class#class_imediaplayercachemanager)

## removeListener

移除指定的 IMediaPlayerEvent 监听器。

<a id="api_imediaplayer_removelistener_imediaplayer__prototype"></a>

```typescript
removeListener?<EventType extends keyof IMediaPlayerEvent>(
      eventType: EventType,
      listener: IMediaPlayerEvent[EventType]
    ): void;
```

<a id="api_imediaplayer_removelistener_imediaplayer__detailed_desc"></a>

<a id="api_imediaplayer_removelistener_imediaplayer__parameters"></a>

### 参数

#### `eventType`

需要监听的目标事件名。详见 [IMediaPlayerEvent](/zh-CN/api-reference/rtc/electron/rtc-interface-class#class_imediaplayerevent)。

#### `listener`

`eventType` 对应的回调函数。必须传入 [addListener](/zh-CN/api-reference/rtc/electron/play/mediaplayer/mediaplayer-initialize#api_imediaplayer_addlistener_imediaplayer) 中传入的同一个函数对象。以取消监听 [onPlayerSourceStateChanged](/zh-CN/api-reference/rtc/electron/play/mediaplayer/mediaplayer-observer#callback_imediaplayersourceobserver_onplayersourcestatechanged) 为例：

```typescript
const onPlayerSourceStateChanged = (state: MediaPlayerState, ec: MediaPlayerError) => {};
engine.addListener('onPlayerSourceStateChanged', onPlayerSourceStateChanged);
engine.removeListener('onPlayerSourceStateChanged', onPlayerSourceStateChanged);
```

- [IMediaPlayer](/zh-CN/api-reference/rtc/electron/rtc-interface-class#class_imediaplayer)
