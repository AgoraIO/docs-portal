## enableInstantMediaRendering

开启音视频帧加速渲染。

<a id="api_irtcengine_enableinstantmediarendering__prototype"></a>

```typescript
abstract enableInstantMediaRendering(): number;
```

<a id="api_irtcengine_enableinstantmediarendering__detailed_desc"></a>

成功调用该方法后，SDK 会开启加速出图和出声模式，可加快用户加入频道后的首帧出图与出声速度。

:::info[注]
主播端和观众端都需调用该方法开启音视频帧加速渲染才可体验该功能。 一旦成功调用该方法，只能通过调用 [release](/zh-CN/api-reference/rtc/electron/initialize#api_irtcengine_release) 方法销毁 [IRtcEngine](/zh-CN/api-reference/rtc/electron/rtc-interface-class#class_irtcengine) 对象来取消加速渲染。
:::

<a id="api_irtcengine_enableinstantmediarendering__scenario"></a>

### 适用场景

声网推荐在直播场景下，对观众开启该模式。

<a id="api_irtcengine_enableinstantmediarendering__timing"></a>

### 调用时机

该方法需要在加入频道前调用。

<a id="api_irtcengine_enableinstantmediarendering__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/electron/error-code)了解详情和解决建议。

  - -7: [IRtcEngine](/zh-CN/api-reference/rtc/electron/rtc-interface-class#class_irtcengine) 尚未初始化就调用方法。

## setLocalRenderMode

更新本地视图显示模式。

<a id="api_irtcengine_setlocalrendermode2__prototype"></a>

```typescript
abstract setLocalRenderMode(
    renderMode: RenderModeType,
    mirrorMode?: VideoMirrorModeType
  ): number;
```

<a id="api_irtcengine_setlocalrendermode2__detailed_desc"></a>

初始化本地用户视图后，你可以调用该方法更新本地用户视图的渲染和镜像模式。该方法只影响本地用户看到的视频画面，不影响本地视频的发布。

:::info[注]
该方法仅对第一个摄像头 `(PrimaryCameraSource)` 生效。在自定义视频采集或使用其他类型视频源的场景下，你需要使用 [setupLocalVideo](/zh-CN/api-reference/rtc/electron/video-rendering#api_irtcengine_setuplocalvideo) 方法替代该方法。
:::

<a id="api_irtcengine_setlocalrendermode2__timing"></a>

### 调用时机

- 请在调用 [setupLocalVideo](/zh-CN/api-reference/rtc/electron/video-rendering#api_irtcengine_setuplocalvideo) 方法初始化本地视图后，调用该方法。
- 你可以在通话中多次调用该方法，多次更新本地用户视图的显示模式。

<a id="api_irtcengine_setlocalrendermode2__parameters"></a>

### 参数

#### `renderMode`

本地视图显示模式。详见 [RenderModeType](/zh-CN/api-reference/rtc/electron/enum-rendermodetype)。

#### `mirrorMode`

本地视图的镜像模式，详见 [VideoMirrorModeType](/zh-CN/api-reference/rtc/electron/enum-videomirrormodetype)。

:::info[注]
如果你使用前置摄像头，默认启动本地用户视图镜像模式；如果你使用后置摄像头，默认关闭本地视图镜像模式。
:::

<a id="api_irtcengine_setlocalrendermode2__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/electron/error-code)了解详情和解决建议。

### 所属接口类

## setLocalRenderTargetFps

设置本地视频渲染的最大帧率。

<a id="api_irtcengine_setlocalrendertargetfps__prototype"></a>

```typescript
abstract setLocalRenderTargetFps(
    sourceType: VideoSourceType,
    targetFps: number
  ): number;
```

<a id="api_irtcengine_setlocalrendertargetfps__detailed_desc"></a>

<a id="api_irtcengine_setlocalrendertargetfps__scenario"></a>

### 适用场景

在对视频渲染帧率要求不高的场景（例如：屏幕共享、在线教育）下，你可以调用该方法设置本地视频渲染的最大帧率，SDK 进行本地渲染的实际帧率会尽量接近该值，从而减小 CPU 消耗、提升系统性能。

<a id="api_irtcengine_setlocalrendertargetfps__timing"></a>

### 调用时机

该方法在加入频道前后均可调用。

<a id="api_irtcengine_setlocalrendertargetfps__parameters"></a>

### 参数

#### `sourceType`

视频源的类型，详见 [VideoSourceType](/zh-CN/api-reference/rtc/electron/enum-videosourcetype)。

#### `targetFps`

最大渲染帧率 (fps)。支持的参数值为：1、7、10、15、24、30、60。

:::info[注]
请将此参数设置为低于视频实际帧率的渲染帧率，否则设置将不会生效。
:::

<a id="api_irtcengine_setlocalrendertargetfps__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/electron/error-code)了解详情和解决建议。

### 所属接口类
- [IRtcEngine](/zh-CN/api-reference/rtc/electron/rtc-interface-class#class_irtcengine)

## setupLocalVideo

初始化本地视图。

<a id="api_irtcengine_setuplocalvideo__prototype"></a>

```typescript
abstract setupLocalVideo(canvas: VideoCanvas): number;
```

<a id="api_irtcengine_setuplocalvideo__detailed_desc"></a>

该方法初始化本地视图并设置本地用户视频显示属性，只影响本地用户看到的视频画面，不影响本地视频的发布。调用该方法绑定本地视频流的显示视窗 (`view`)，并设置本地用户视图的渲染模式和镜像模式。 退出频道后绑定仍然有效。如果需要停止渲染或解除绑定，可以调用该方法将参数 `view` 设为 null，以停止渲染并清理渲染缓存。

:::info[注]
- 在 Flutter 中你不需要主动调用该方法，请使用 `AgoraVideoView` 渲染本地和远端视图。
:::

<a id="api_irtcengine_setuplocalvideo__scenario"></a>

### 适用场景

在 App 开发中，通常在初始化后调用该方法进行本地视频设置，然后再加入频道。 如果你需要在本地视频预览的画面中同时看到多个预览画面、且不同画面分别处于视频链路上不同观测点，可以重复调用该方法设置不同的 `view`，并针对每个 `view` 设置不同的观测位置。例如：将视频源设置为摄像头，然后对应两个 `view` 分别设置 `position` 为 PositionPostCapturerOrigin 和 PositionPostCapturer，即可在本地视频预览中同时看到没有经过视频前处理的原始画面和已经过视频前处理（美颜、虚拟背景、水印本地预览）的画面。

<a id="api_irtcengine_setuplocalvideo__timing"></a>

### 调用时机

该方法在加入频道前后均可调用。

<a id="api_irtcengine_setuplocalvideo__parameters"></a>

### 参数

#### `canvas`

本地视频显示属性。详见 [VideoCanvas](/zh-CN/api-reference/rtc/electron/class-videocanvas)。

<a id="api_irtcengine_setuplocalvideo__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/electron/error-code)了解详情和解决建议。

## setupRemoteVideo

初始化远端用户视图。

<a id="api_irtcengine_setupremotevideo__prototype"></a>

```typescript
abstract setupRemoteVideo(canvas: VideoCanvas): number;
```

<a id="api_irtcengine_setupremotevideo__detailed_desc"></a>

该方法绑定远端用户和显示视图，并设置远端用户视图在本地显示时的渲染模式和镜像模式，只影响本地用户看到的视频画面。 调用该方法时需要指定远端视频的用户 ID，一般可以在进频道前提前设置好。如果无法在加入频道前得到远端用户的 ID，可以在收到 [onUserJoined](/zh-CN/api-reference/rtc/electron/channel#callback_irtcengineeventhandler_onuserjoined) 回调时调用该方法。 如需解除某个远端用户的绑定视图，可以调用该方法并将 `view` 设置为空。 离开频道后，SDK 会清除远端用户视图的绑定关系。

:::info[注]
- 当使用录制服务时，由于它不会发送视频流，App 无需为它绑定视图。如果 App 无法识别录制服务，可以在收到 [onFirstRemoteVideoDecoded](/zh-CN/api-reference/rtc/electron/video-basic#callback_irtcengineeventhandler_onfirstremotevideodecoded) 回调时再绑定远端用户视图。
- 如果想要停止渲染视图，需要将 `view` 设为 null 后再次调用该方法，以停止渲染并清理渲染缓存。
:::

<a id="api_irtcengine_setupremotevideo__parameters"></a>

### 参数

#### `canvas`

远端视频显示属性。详见 [VideoCanvas](/zh-CN/api-reference/rtc/electron/class-videocanvas)。

<a id="api_irtcengine_setupremotevideo__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/electron/error-code)了解详情和解决建议。

<a id="api_irtcengineex_setupremotevideoex__detailed_desc"></a>


<a id="api_irtcengine_startmediarenderingtracing__detailed_desc"></a>

:::info[注]
- 如果你未调用该方法，SDK 默认以调用 [joinChannel](/zh-CN/api-reference/rtc/electron/channel#api_irtcengine_joinchannel2) 加入频道的时刻为起始点开始打点，自动开始跟踪视频的渲染事件。你可以根据实际业务场景，在合适的时机调用该方法，进行自定义打点。
- 离开当前频道后，SDK 会自动重置该时间点为下一次加入频道的时刻。
:::

### 适用场景

  - -7: [IRtcEngine](/zh-CN/api-reference/rtc/electron/rtc-interface-class#class_irtcengine) 尚未初始化就调用方法。

## onVideoRenderingTracingResult

视频帧渲染事件回调。

<a id="callback_irtcengineeventhandler_onvideorenderingtracingresult__prototype"></a>

```typescript
onVideoRenderingTracingResult?(
    connection: RtcConnection,
    uid: number,
    currentEvent: MediaTraceEvent,
    tracingInfo: VideoRenderingTracingInfo
  ): void;
```

<a id="callback_irtcengineeventhandler_onvideorenderingtracingresult__detailed_desc"></a>

调用 [startMediaRenderingTracing](/zh-CN/api-reference/rtc/electron/video-rendering#api_irtcengine_startmediarenderingtracing) 方法或加入频道后，SDK 会触发该回调，报告视频帧渲染的事件和渲染过程中的指标。开发者可以针对指标进行专项优化，以提高出图效率。

<a id="callback_irtcengineeventhandler_onvideorenderingtracingresult__parameters"></a>

### 参数

#### `connection`

Connection 信息。详见 [RtcConnection](/zh-CN/api-reference/rtc/electron/class-rtcconnection)。

#### `uid`

用户 ID。

#### `currentEvent`

当前视频帧渲染事件。详见 [MediaTraceEvent](/zh-CN/api-reference/rtc/electron/enum-mediatraceevent)。

#### `tracingInfo`

视频帧渲染过程中的指标。开发者需要尽可能降低指标值，以提高出图效率。详见 [VideoRenderingTracingInfo](/zh-CN/api-reference/rtc/electron/class-videorenderingtracinginfo)。
