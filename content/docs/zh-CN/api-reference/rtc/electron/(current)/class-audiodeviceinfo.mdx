<a id="class_audiodeviceinfo__prototype"></a>

```typescript
export class AudioDeviceInfo {
  deviceId?: string;
  deviceTypeName?: string;
  deviceName?: string;
}
```

<a id="class_audiodeviceinfo__parameters"></a>

## 属性

### `deviceId`

设备 ID。

### `deviceName`

设备名称。

### `deviceTypeName`

音频设备类型，如：built-in、USB、HDMI 等。
