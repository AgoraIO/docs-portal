## 枚举值

### `VideoMirrorModeAuto`

0：由 SDK 决定镜像模式。

- 本地视图镜像模式：如果你使用前置摄像头，默认启动本地视图镜像模式；如果你使用后置摄像头，默认关闭本地视图镜像模式。
- 远端用户视图镜像模式：默认关闭远端用户的镜像模式。

### `VideoMirrorModeEnabled`

1：启用镜像模式。

### `VideoMirrorModeDisabled`

2：关闭镜像模式。
