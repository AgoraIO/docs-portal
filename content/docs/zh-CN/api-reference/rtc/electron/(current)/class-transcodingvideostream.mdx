<a id="class_transcodingvideostream__parameters"></a>

## 属性

<ParameterList>
<a id="sourcetype"></a>
<Parameter name="sourceType">

参与本地合图的视频源类型。详见 [VideoSourceType](/zh-CN/api-reference/rtc/electron/enum-videosourcetype)。

</Parameter>
<a id="remoteuseruid"></a>
<Parameter name="remoteUserUid">

远端用户 ID。

:::note
注： 请仅在参与本地合图的视频源类型为 `VideoSourceRemote` 时，使用该参数。
:::

</Parameter>
<a id="imageurl"></a>
<Parameter name="imageUrl">

:::note
注： 请仅在参与本地合图的视频源类型为图片时，使用该参数。
:::

本地图片的路径。示例路径：

- macOS: `~/Pictures/image.png`
- Windows: `C:\\Users\\{username}\\Pictures\\image.png`

</Parameter>
<a id="mediaplayerid"></a>
<Parameter name="mediaPlayerId">

（可选）媒体播放器 ID。当你将 `sourceType` 设置为 `VideoSourceMediaPlayer` 时，需要设置该参数。

</Parameter>
<a id="x"></a>
<Parameter name="x">

参与本地合图的视频的左上角相对于合图画布左上角（原点）的横向位移。

</Parameter>
<a id="y"></a>
<Parameter name="y">

参与本地合图的视频的左上角相对于合图画布左上角（原点）的纵向位移。

</Parameter>
<a id="width"></a>
<Parameter name="width">

参与本地合图的视频的宽度 (px)。

</Parameter>
<a id="height"></a>
<Parameter name="height">

参与本地合图的视频的高度 (px)。

</Parameter>
<a id="zorder"></a>
<Parameter name="zOrder">

参与本地合图的视频所属的图层的编号。取值范围为 [0,100]。

- 0:（默认值）图层在最下层。
- 100: 图层在最上层。

</Parameter>
<a id="alpha"></a>
<Parameter name="alpha">

参与本地合图的视频的透明度。取值范围为 [0.0,1.0]。 0.0 表示透明度为完全透明，1.0 表示透明度为完全不透明。

</Parameter>
<a id="mirror"></a>
<Parameter name="mirror">

:::note
注： 该参数仅对视频源类型为摄像头的视频生效。
:::

是否对参与本地合图的的视频进行镜像：

- true: 将参与本地合图的视频进行镜像。
- false: （默认值）不将参与本地合图的视频进行镜像。

</Parameter>
</ParameterList>
