## 枚举值

<ParameterList>
<a id="audioreverbdrylevel"></a>
<Parameter name="AudioReverbDryLevel">

0: 原始声音强度，即所谓的 dry signal，取值范围 [-20,10]，单位为 dB。

</Parameter>
<a id="audioreverbwetlevel"></a>
<Parameter name="AudioReverbWetLevel">

1: 早期反射信号强度，即所谓的 wet signal，取值范围 [-20,10]，单位为 dB。

</Parameter>
<a id="audioreverbroomsize"></a>
<Parameter name="AudioReverbRoomSize">

2: 所需混响效果的房间尺寸，一般房间越大，混响越强，取值范围 [0,100]，单位为 dB。

</Parameter>
<a id="audioreverbwetdelay"></a>
<Parameter name="AudioReverbWetDelay">

3: Wet signal 的初始延迟长度，取值范围 [0,200]，单位为毫秒。

</Parameter>
<a id="audioreverbstrength"></a>
<Parameter name="AudioReverbStrength">

4: 混响持续的强度，取值范围为 [0,100]。

</Parameter>
</ParameterList>
