## 枚举值

### `LocalAudioStreamStateStopped`

0: 本地音频默认初始状态。

### `LocalAudioStreamStateRecording`

1: 本地音频采集设备启动成功。

### `LocalAudioStreamStateEncoding`

2: 本地音频首帧编码成功。

### `LocalAudioStreamStateFailed`

3: 本地音频启动失败。
