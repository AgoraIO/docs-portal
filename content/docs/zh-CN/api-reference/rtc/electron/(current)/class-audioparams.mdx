<a id="class_audioparams__detailed_desc"></a>

SDK 会根据 [AudioParams](/zh-CN/api-reference/rtc/electron/class-audioparams) 设置以下回调中的音频数据格式：

- [onRecordAudioFrame](/zh-CN/api-reference/rtc/electron/audio/audio-raw#callback_iaudioframeobserverbase_onrecordaudioframe)
- [onPlaybackAudioFrame](/zh-CN/api-reference/rtc/electron/audio/audio-raw#callback_iaudioframeobserverbase_onplaybackaudioframe)
- [onMixedAudioFrame](/zh-CN/api-reference/rtc/electron/audio/audio-raw#callback_iaudioframeobserverbase_onmixedaudioframe)

:::note
注：

- SDK 会通过 [AudioParams](/zh-CN/api-reference/rtc/electron/class-audioparams) 中的 `samplesPerCall`、`sampleRate` 和 `channel` 参数计算采样间隔，并根据该采样间隔触发 [onRecordAudioFrame](/zh-CN/api-reference/rtc/electron/audio/audio-raw#callback_iaudioframeobserverbase_onrecordaudioframe)、[onPlaybackAudioFrame](/zh-CN/api-reference/rtc/electron/audio/audio-raw#callback_iaudioframeobserverbase_onplaybackaudioframe)、[onMixedAudioFrame](/zh-CN/api-reference/rtc/electron/audio/audio-raw#callback_iaudioframeobserverbase_onmixedaudioframe) 和 [onEarMonitoringAudioFrame](/zh-CN/api-reference/rtc/electron/audio/audio-raw#callback_iaudioframeobserverbase_onearmonitoringaudioframe) 回调。
- 采样间隔 = `samplesPerCall`/(`sampleRate` × `channel`)。
- 请确保采样间隔不得小于 0.01 (s)。
:::

## 属性

<ParameterList>
<a id="sample_rate"></a>
<Parameter name="sample_rate">

数据的采样率，单位为 Hz，取值如下：

- 8000
- 16000（默认值）
- 32000
- 44100
- 48000

</Parameter>
<a id="channels"></a>
<Parameter name="channels">

数据的声道数，取值如下：

- 1：单声道（默认值）
- 2：双声道

</Parameter>
<a id="mode"></a>
<Parameter name="mode">

数据的使用模式。详见 [RawAudioFrameOpModeType](/zh-CN/api-reference/rtc/electron/enum-rawaudioframeopmodetype)。

</Parameter>
<a id="samples_per_call"></a>
<Parameter name="samples_per_call">

数据的采样点数，如旁路推流应用中通常为 1024。

</Parameter>
</ParameterList>
