<a id="class_codeccapinfo__prototype"></a>

```typescript
export class CodecCapInfo {
  codecType?: VideoCodecType;
  codecCapMask?: number;
  codecLevels?: CodecCapLevels;
}
```

<a id="class_codeccapinfo__parameters"></a>

## 属性

### `codecType`

视频编解码类型。详见 [VideoCodecType](/zh-CN/api-reference/rtc/electron/enum-videocodectype)。

### `codecCapMask`

SDK 编解码类型的 bit mask。详见 [CodecCapMask](/zh-CN/api-reference/rtc/electron/enum-codeccapmask)。

### `codecLevels`

SDK 支持的编解码能力等级。详见 [CodecCapLevels](/zh-CN/api-reference/rtc/electron/class-codeccaplevels)。
