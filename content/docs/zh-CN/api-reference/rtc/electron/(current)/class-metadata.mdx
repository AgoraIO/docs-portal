<a id="class_metadata__prototype"></a>

```typescript
export class Metadata {
  channelId?: string;
  uid?: number;
  size?: number;
  buffer?: Uint8Array;
  timeStampMs?: number;
}
```

<a id="class_metadata__parameters"></a>

## 属性

### `channelId`

频道名称。

### `uid`

用户 ID。

- 对于接收者：发送该 Metadata 的远端用户的 ID。
- 对于发送者：请忽略。

### `size`

接收到的或发送的 [Metadata](/zh-CN/api-reference/rtc/electron/class-metadata) 的缓存大小。

### `buffer`

接收到的 [Metadata](/zh-CN/api-reference/rtc/electron/class-metadata) 的缓存地址。

### `timeStampMs`

发送 [Metadata](/zh-CN/api-reference/rtc/electron/class-metadata) 的时间戳，单位为毫秒。
