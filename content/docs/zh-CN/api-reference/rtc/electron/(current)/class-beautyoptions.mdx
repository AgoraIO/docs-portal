<ParameterList>

<Parameter name="lighteningContrastLevel">

对比度，常与 `lighteningLevel` 搭配使用。取值越大，明暗对比程度越大。详见 [LighteningContrastLevel](/zh-CN/api-reference/rtc/electron/enum-lighteningcontrastlevel)。

<a id="lighteninglevel"></a>
<Parameter name="lighteningLevel">

美白程度，取值范围为 [0.0,1.0]，其中 0.0 表示原始亮度，默认值为 0.0。取值越大，美白程度越大。

</Parameter>
<a id="smoothnesslevel"></a>
<Parameter name="smoothnessLevel">

磨皮程度，取值范围为 [0.0,1.0]，其中 0.0 表示原始磨皮程度，默认值为 0.0。取值越大，磨皮程度越大。

</Parameter>
<a id="rednesslevel"></a>
<Parameter name="rednessLevel">

红润度，取值范围为 [0.0,1.0]，其中 0.0 表示原始红润度，默认值为 0.0。取值越大，红润程度越大。

</Parameter>
<a id="sharpnesslevel"></a>
<Parameter name="sharpnessLevel">

锐化程度，取值范围为 [0.0,1.0]，其中 0.0 表示原始锐度，默认值为 0.0。取值越大，锐化程度越大。

</Parameter>
