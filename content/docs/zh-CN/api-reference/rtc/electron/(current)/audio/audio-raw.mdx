## registerAudioFrameObserver

注册音频观测器对象。

<a id="api_imediaengine_registeraudioframeobserver__prototype"></a>

```text
abstract registerAudioFrameObserver(observer: IAudioFrameObserver): number;
```

<a id="api_imediaengine_registeraudioframeobserver__detailed_desc"></a>

该方法用于注册音频观测器对象，即注册回调。当需要 SDK 触发 [onMixedAudioFrame](/zh-CN/api-reference/rtc/electron/audio/audio-raw#callback_iaudioframeobserverbase_onmixedaudioframe)、[onRecordAudioFrame](/zh-CN/api-reference/rtc/electron/audio/audio-raw#callback_iaudioframeobserverbase_onrecordaudioframe)、[onPlaybackAudioFrame](/zh-CN/api-reference/rtc/electron/audio/audio-raw#callback_iaudioframeobserverbase_onplaybackaudioframe)、[onPlaybackAudioFrameBeforeMixing](/zh-CN/api-reference/rtc/electron/audio/audio-raw#callback_iaudioframeobserver_onplaybackaudioframebeforemixing) 和 [onEarMonitoringAudioFrame](/zh-CN/api-reference/rtc/electron/audio/audio-raw#callback_iaudioframeobserverbase_onearmonitoringaudioframe) 回调时，需要调用该方法注册回调。

<a id="api_imediaengine_registeraudioframeobserver__timing"></a>

### 调用时机

该方法需要在加入频道前调用。

<a id="api_imediaengine_registeraudioframeobserver__parameters"></a>

接口对象实例。详见 [IAudioFrameObserver](/zh-CN/api-reference/rtc/electron/rtc-interface-class#class_iaudioframeobserver)。建议在收到 [onLeaveChannel](/zh-CN/api-reference/rtc/electron/channel#callback_irtcengineeventhandler_onleavechannel) 后调用，来释放音频观测器对象。

## setEarMonitoringAudioFrameParameters

设置耳返的音频数据格式。

<a id="api_irtcengine_setearmonitoringaudioframeparameters__prototype"></a>

```text
abstract setEarMonitoringAudioFrameParameters(
    sampleRate: number,
    channel: number,
    mode: RawAudioFrameOpModeType,
    samplesPerCall: number
  ): number;
```

<a id="api_irtcengine_setearmonitoringaudioframeparameters__detailed_desc"></a>

该方法用于设置 [onEarMonitoringAudioFrame](/zh-CN/api-reference/rtc/electron/audio/audio-raw#callback_iaudioframeobserverbase_onearmonitoringaudioframe) 回调的耳返音频数据格式。

:::note
注：

- 调用该方法前，你需要先调用 [enableInEarMonitoring](/zh-CN/api-reference/rtc/electron/audio/audio-capture#api_irtcengine_enableinearmonitoring2)，将 `includeAudioFilters` 设置为 `EarMonitoringFilterBuiltInAudioFilters` 或 `EarMonitoringFilterNoiseSuppression`。
- SDK 会通过该方法中的 `samplesPerCall`、`sampleRate` 和 `channel` 参数计算出采样间隔，计算公式为采样间隔 = `samplesPerCall`/(`sampleRate` × `channel`)。请确保采样间隔不小于 0.01 秒。SDK 会根据该采样间隔触发 [onEarMonitoringAudioFrame](/zh-CN/api-reference/rtc/electron/audio/audio-raw#callback_iaudioframeobserverbase_onearmonitoringaudioframe) 回调。
:::

<a id="api_irtcengine_setearmonitoringaudioframeparameters__parameters"></a>

### 参数

<ParameterList>
<a id="samplerate"></a>
<Parameter name="sampleRate">

[onEarMonitoringAudioFrame](/zh-CN/api-reference/rtc/electron/audio/audio-raw#callback_iaudioframeobserverbase_onearmonitoringaudioframe) 中报告音频的采样率 (Hz)，可设置为 8000、 16000、 32000、44100 或 48000。

</Parameter>
<a id="channel"></a>
<Parameter name="channel">

[onEarMonitoringAudioFrame](/zh-CN/api-reference/rtc/electron/audio/audio-raw#callback_iaudioframeobserverbase_onearmonitoringaudioframe) 中报告音频的声道数，可设置为 1 或 2:

- 1: 单声道。
- 2: 双声道。

</Parameter>
<a id="mode"></a>
<Parameter name="mode">

音频帧的使用模式，详见 [RawAudioFrameOpModeType](/zh-CN/api-reference/rtc/electron/enum-rawaudioframeopmodetype)。

</Parameter>
<a id="samplespercall"></a>
<Parameter name="samplesPerCall">

[onEarMonitoringAudioFrame](/zh-CN/api-reference/rtc/electron/audio/audio-raw#callback_iaudioframeobserverbase_onearmonitoringaudioframe) 中报告的音频的采样点数，如旁路推流应用中通常为 1024。

</Parameter>
</ParameterList>

<a id="api_irtcengine_setearmonitoringaudioframeparameters__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。
