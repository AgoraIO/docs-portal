## getUserInfoByUid

通过 UID 获取用户信息。

<a id="api_irtcengine_getuserinfobyuid__prototype"></a>

```typescript
abstract getUserInfoByUid(uid: number): UserInfo;
```

<a id="api_irtcengine_getuserinfobyuid__detailed_desc"></a>

远端用户加入频道后，SDK 会获取到该远端用户的 UID 和 User Account，然后缓存一个包含了远端用户 UID 和 User Account 的映射表，并在本地触发 [onUserInfoUpdated](/zh-CN/api-reference/rtc/electron/channel#callback_irtcengineeventhandler_onuserinfoupdated) 回调。收到回调后，调用该方法传入 UID 来获取包含了指定用户 User Account 的 [UserInfo](/zh-CN/api-reference/rtc/electron/class-userinfo) 对象。

<a id="api_irtcengine_getuserinfobyuid__timing"></a>

### 调用时机

在收到 [onUserInfoUpdated](/zh-CN/api-reference/rtc/electron/channel#callback_irtcengineeventhandler_onuserinfoupdated) 回调后调用。

<a id="api_irtcengine_getuserinfobyuid__related"></a>

### 相关回调

[onUserInfoUpdated](/zh-CN/api-reference/rtc/electron/channel#callback_irtcengineeventhandler_onuserinfoupdated)

<a id="api_irtcengine_getuserinfobyuid__parameters"></a>

### 参数

#### `uid`

用户 ID。

<a id="api_irtcengine_getuserinfobyuid__return_values"></a>

### 返回值

- 方法调用成功，返回 [UserInfo](/zh-CN/api-reference/rtc/electron/class-userinfo) 对象。
- 方法调用失败，则返回 null。

- [IRtcEngine](/zh-CN/api-reference/rtc/electron/rtc-interface-class#class_irtcengine)

## joinChannel

设置媒体选项并加入频道。

<a id="api_irtcengine_joinchannel2__prototype"></a>

```typescript
abstract joinChannel(
    token: string,
    channelId: string,
    uid: number,
    options: ChannelMediaOptions
  ): number;
```

<a id="api_irtcengine_joinchannel2__detailed_desc"></a>

该方法可以在加入频道时设置媒体选项，如是否在频道内发布音视频流等。用户加入频道时是否自动订阅频道内所有远端音视频流。默认情况下，用户订阅频道内所有其他用户的音频流和视频流，因此会产生用量并影响计费。如果想取消订阅，可以通过设置 `options` 参数或相应的 mute 方法实现。

:::info[注]
- 该方法仅支持用户一次加入一个频道。
- 使用不同 App ID 的 App 不能互通。
- 加入频道前，请确保用于生成 Token 的 App ID 和调用 [initialize](/zh-CN/api-reference/rtc/electron/initialize#api_irtcengine_initialize) 方法初始化引擎时使用的是同一个 App ID，否则使用 Token 加入频道会失败。
:::

<a id="api_irtcengine_joinchannel2__timing"></a>

### 调用时机

该方法需要在 [initialize](/zh-CN/api-reference/rtc/electron/initialize#api_irtcengine_initialize) 之后再调用。

<a id="api_irtcengine_joinchannel2__related"></a>

### 相关回调

成功调用该方法加入频道后会触发以下回调：

- 本地会触发 [onJoinChannelSuccess](/zh-CN/api-reference/rtc/electron/channel#callback_irtcengineeventhandler_onjoinchannelsuccess) 和 [onConnectionStateChanged](/zh-CN/api-reference/rtc/electron/network#callback_irtcengineeventhandler_onconnectionstatechanged) 回调。
- 通信场景下的用户和直播场景下的主播加入频道后，远端会触发 [onUserJoined](/zh-CN/api-reference/rtc/electron/channel#callback_irtcengineeventhandler_onuserjoined) 回调。

在网络状况不理想的情况下，客户端可能会与声网服务器失去连接，此时 SDK 会自动尝试重连，重连成功后，本地会触发 [onRejoinChannelSuccess](/zh-CN/api-reference/rtc/electron/channel#callback_irtcengineeventhandler_onrejoinchannelsuccess) 回调。

<a id="api_irtcengine_joinchannel2__parameters"></a>

### 参数

#### `token`

在服务端生成的用于鉴权的动态密钥。详见[使用 Token 鉴权](https://doc.shengwang.cn/doc/rtc/electron/basic-features/token-authentication)。

:::info[注]
- （推荐）如果你的项目开启了安全模式，即选择 APP ID + Token 为鉴权机制，则该参数为必填。
- 如果你的项目仅开启调试模式，即选择 APP ID 为鉴权机制，则无需填入 Token 即可加入频道。成功加入频道 24 小时后会自动退出该频道。
- 如果你需要同时加入多个频道或在频道间频繁切换，声网推荐你使用通配 Token 以避免每加入一个新的频道都需向服务端申请一个新的 Token，详见 [使用通配 Token](https://doc.shengwang.cn/doc/rtc/electron/best-practice/wildcard-token)。
:::

#### `channelId`

频道名。该参数标识用户进行实时音视频互动的频道。App ID 一致的前提下，填入相同频道名的用户会进入同一个频道进行音视频互动。该参数为长度在 64 字节以内的字符串。以下为支持的字符集范围（共 89 个字符）:

- 26 个小写英文字母 a~z
- 26 个大写英文字母 A~Z
- 10 个数字 0~9
- "!"、"#"、"$"、"%"、"&"、"("、")"、"+"、"-"、":"、";"、"&lt;"、"="、"."、"&gt;"、"?"、"@"、"["、"]"、"^"、"_"、"\{"、"\}"、"|"、"~"、","

#### `uid`

用户 ID。该参数用于标识在实时音视频互动频道中的用户。你需要自行设置和管理用户 ID，并确保同一频道内的每个用户 ID 是唯一的。该参数为 32 位无符号整数。建议设置范围：1 到 232-1。如果不指定（即设为 0），SDK 会自动分配一个，并在 [onJoinChannelSuccess](/zh-CN/api-reference/rtc/electron/channel#callback_irtcengineeventhandler_onjoinchannelsuccess) 回调中返回， 应用层必须记住该返回值并维护，SDK 不对该返回值进行维护。

#### `options`

频道媒体设置选项。详见 [ChannelMediaOptions](/zh-CN/api-reference/rtc/electron/class-channelmediaoptions)。

<a id="api_irtcengine_joinchannel2__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/electron/error-code)了解详情和解决建议。

  - -2：传入的参数无效。例如，使用了不合法的 Token， `uid` 参数未设置为整型，或 [ChannelMediaOptions](/zh-CN/api-reference/rtc/electron/class-channelmediaoptions) 成员值不合法。你需要填入有效的参数，重新加入频道。
  - -3： [IRtcEngine](/zh-CN/api-reference/rtc/electron/rtc-interface-class#class_irtcengine) 对象初始化失败。你需要重新初始化 [IRtcEngine](/zh-CN/api-reference/rtc/electron/rtc-interface-class#class_irtcengine) 对象。
  - -7： [IRtcEngine](/zh-CN/api-reference/rtc/electron/rtc-interface-class#class_irtcengine) 对象尚未初始化。你需要在调用该方法前成功初始化 [IRtcEngine](/zh-CN/api-reference/rtc/electron/rtc-interface-class#class_irtcengine) 对象。
  - -8： [IRtcEngine](/zh-CN/api-reference/rtc/electron/rtc-interface-class#class_irtcengine) 对象内部状态错误。可能的原因是：调用 [startEchoTest](/zh-CN/api-reference/rtc/electron/network#api_irtcengine_startechotest3) 开始通话回路测试后，未调用 [stopEchoTest](/zh-CN/api-reference/rtc/electron/network#api_irtcengine_stopechotest) 停止测试就调用该方法加入频道。你需要在该方法前调用 [stopEchoTest](/zh-CN/api-reference/rtc/electron/network#api_irtcengine_stopechotest)。
  - -17：加入频道被拒绝。可能的原因是用户已经在频道中。建议通过 [onConnectionStateChanged](/zh-CN/api-reference/rtc/electron/network#callback_irtcengineeventhandler_onconnectionstatechanged) 回调判断用户是否在频道中。除收到 `ConnectionStateDisconnected` (1) 状态外，不要再次调用该方法加入频道。
  - -102：频道名无效。你需要在 `channelId` 中填入有效的频道名，重新加入频道。
  - -121：用户 ID 无效。你需要在 `uid` 中填入有效的用户 ID，重新加入频道。

- [IRtcEngine](/zh-CN/api-reference/rtc/electron/rtc-interface-class#class_irtcengine)

## joinChannelEx

加入频道。

<a id="api_irtcengineex_joinchannelex__prototype"></a>

```typescript
abstract joinChannelEx(
    token: string,
    connection: RtcConnection,
    options: ChannelMediaOptions
  ): number;
```

<a id="api_irtcengineex_joinchannelex__detailed_desc"></a>

调用该方法，你可以同时加入多个频道。如果你想在不同的设备上加入相同的频道，请确保你在不同设备上使用的用户 ID 都不同。

:::info[注]
如果你已经在一个频道内，你不能用相同的用户 ID 再次加入该频道。 加入频道前，请确保用于生成 Token 的 App ID 和调用 [initialize](/zh-CN/api-reference/rtc/electron/initialize#api_irtcengine_initialize) 方法初始化引擎时使用的是同一个 App ID，否则使用 Token 加入频道会失败。
:::

<a id="api_irtcengineex_joinchannelex__scenario"></a>

<a id="api_irtcengineex_joinchannelex__timing"></a>

## joinChannelWithUserAccount

使用 User Account 和 Token 加入频道，并设置频道媒体选项。

<a id="api_irtcengine_joinchannelwithuseraccount2__prototype"></a>

```typescript
abstract joinChannelWithUserAccount(
    token: string,
    channelId: string,
    userAccount: string,
    options?: ChannelMediaOptions
  ): number;
```

<a id="api_irtcengine_joinchannelwithuseraccount2__detailed_desc"></a>

调用该方法前，如果你未调用 [registerLocalUserAccount](/zh-CN/api-reference/rtc/electron/channel#api_irtcengine_registerlocaluseraccount) 注册一个 User Account，调用该方法加入频道时，SDK 会自动为你创建一个 User Account。先调用 [registerLocalUserAccount](/zh-CN/api-reference/rtc/electron/channel#api_irtcengine_registerlocaluseraccount) 方法注册 Account，再调用此方法加入频道，可以缩短进入频道的时间。 用户成功加入频道后，默认订阅频道内所有其他用户的音频流和视频流，因此产生用量并影响计费。如果想取消订阅，可以通过调用相应的 mute 方法实现。

:::info[注]
为保证通信质量，请确保频道内使用同一类型的数据标识用户身份。即同一频道内需要统一使用 UID 或 User Account。如果有用户通过 Web SDK 加入频道，请确保 Web 加入的用户也是同样类型。

- 该方法仅支持用户一次加入一个频道。
- 使用不同 App ID 的 App 不能互通。
- 加入频道前，请确保用于生成 Token 的 App ID 和调用 [initialize](/zh-CN/api-reference/rtc/electron/initialize#api_irtcengine_initialize) 方法初始化引擎时使用的是同一个 App ID，否则使用 Token 加入频道会失败。
:::

<a id="api_irtcengine_joinchannelwithuseraccount2__timing"></a>

### 调用时机

- 远端：通信场景下的用户和直播场景下的主播加入频道后，远端会分别触发 [onUserJoined](/zh-CN/api-reference/rtc/electron/channel#callback_irtcengineeventhandler_onuserjoined) 和 [onUserInfoUpdated](/zh-CN/api-reference/rtc/electron/channel#callback_irtcengineeventhandler_onuserinfoupdated) 回调。

## preloadChannel

使用 token、channelId、uid 预加载频道。

<a id="api_irtcengine_preloadchannel__prototype"></a>

```typescript
abstract preloadChannel(
    token: string,
    channelId: string,
    uid: number
  ): number;
```

<a id="api_irtcengine_preloadchannel__detailed_desc"></a>

调用该方法可以减少观众频繁切换频道时加入频道的时间，从而缩短观众听到主播首帧音频以及看到首帧画面的耗时，提升观众端的视频体验。 如果当前频道已经成功预加载，观众加入、离开频道后如需再次加入该频道，只要预加载时传入的 Token 仍在有效期内，则无需重新预加载。

:::info[注]
预加载不生效不会影响后续正常加入频道，也不会增加加入频道的耗时。

- 调用该方法时，请确保用户角色设为观众、音频应用场景设为非合唱场景（`AudioScenarioChorus` ），否则预加载不生效。
- 请确保预加载频道时传入的频道名、用户 ID、Token 和后续加入频道时传入的值相同，否则预加载不生效。
- 目前一个 [IRtcEngine](/zh-CN/api-reference/rtc/electron/rtc-interface-class#class_irtcengine) 实例最多支持预加载 20 个频道，如超出限制，仅最新预加载的 20 个频道生效。
:::

<a id="api_irtcengine_preloadchannel__timing"></a>

### 调用时机

为了提升预加载频道的用户体验，声网推荐你在确认频道名、用户信息后、加入频道前，尽早调用该方法。

<a id="api_irtcengine_preloadchannel__parameters"></a>

### 参数

#### `token`

在服务端生成的用于鉴权的动态密钥。详见[使用 Token 鉴权](https://doc.shengwang.cn/doc/rtc/electron/basic-features/token-authentication)。 Token 过期后，根据预加载频道的数量，你可以通过不同方式来传入用于预加载频道的新 Token：

- 预加载一个频道时：调用此方法来传入新的 Token。
- 预加载多个频道时：

  - 如果你使用了通配的 Token，调用 [updatePreloadChannelToken](/zh-CN/api-reference/rtc/electron/channel#api_irtcengine_updatepreloadchanneltoken) 来更新所有预加载频道的 Token。生成通配 Token 时，用户 ID 不得设为 0。详见 [使用通配 Token](https://doc.shengwang.cn/doc/rtc/electron/best-practice/wildcard-token)。
  - 如果你使用了不同的 Token：调用此方法并传入你的用户 ID、对应的频道名和更新后的 Token。

#### `channelId`

待预加载的频道名。该参数标识用户进行实时音视频互动的频道。App ID 一致的前提下，填入相同频道名的用户会进入同一个频道进行音视频互动。 该参数为长度在 64 字节以内的字符串。以下为支持的字符集范围（共 89 个字符）:

- 26 个小写英文字母 a~z
- 26 个大写英文字母 A~Z
- 10 个数字 0~9
- "!"、"#"、"$"、"%"、"&"、"("、")"、"+"、"-"、":"、";"、"&lt;"、"="、"."、"&gt;"、"?"、"@"、"["、"]"、"^"、"_"、"\{"、"\}"、"|"、"~"、","

#### `uid`

用户 ID。该参数用于标识在实时音视频互动频道中的用户。你需要自行设置和管理用户 ID，并确保同一频道内的每个用户 ID 是唯一的。该参数为 32 位无符号整数。建议设置范围：1 到 232-1。如果不指定（即设为 0），SDK 会自动分配一个，并在 [onJoinChannelSuccess](/zh-CN/api-reference/rtc/electron/channel#callback_irtcengineeventhandler_onjoinchannelsuccess) 回调中返回， 应用层必须记住该返回值并维护，SDK 不对该返回值进行维护。

<a id="api_irtcengine_preloadchannel__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/electron/error-code)了解详情和解决建议。

  - -7： [IRtcEngine](/zh-CN/api-reference/rtc/electron/rtc-interface-class#class_irtcengine) 对象尚未初始化。你需要在调用该方法前成功初始化 [IRtcEngine](/zh-CN/api-reference/rtc/electron/rtc-interface-class#class_irtcengine) 对象。
  - -102：频道名无效。你需要填入有效的频道名，重新加入频道。

## setClientRole

<a id="api_irtcengine_setclientrole2__prototype"></a>

```typescript

  ): number;
```

<a id="api_irtcengine_setclientrole2__detailed_desc"></a>

SDK 默认设置用户角色为观众，你可以调用该方法设置用户角色为主播。用户角色（`role` ）确定用户在 SDK 层的权限，包含是否有发流权限等。

用户角色。详见 [ClientRoleType](/zh-CN/api-reference/rtc/electron/enum-clientroletype)。

## onUserOffline

<a id="callback_irtcengineeventhandler_onuseroffline__prototype"></a>

```typescript
onUserOffline?(
    connection: RtcConnection,
    remoteUid: number,
    reason: UserOfflineReasonType
  ): void;
```

<a id="callback_irtcengineeventhandler_onuseroffline__detailed_desc"></a>

用户离开频道一般有以下两个原因：

- 正常离开：远端用户或主播会发送类似“再见”的消息然后主动离开频道。
- 超时掉线：在一定时间内（通信场景为 20 秒，直播场景稍有延时），用户没有收到对方的任何数据包，则判定为对方掉线。在网络较差的情况下，有可能会误报。建议使用 RTM SDK 来做可靠的掉线检测。

<a id="callback_irtcengineeventhandler_onuseroffline__timing"></a>

#### `connection`

Connection 信息。详见 [RtcConnection](/zh-CN/api-reference/rtc/electron/class-rtcconnection)。

#### `remoteUid`

离线的远端用户或主播的 ID。

#### `reason`

远端用户（通信场景）或主播（直播场景）离线的原因，详见 [UserOfflineReasonType](/zh-CN/api-reference/rtc/electron/enum-userofflinereasontype)。
