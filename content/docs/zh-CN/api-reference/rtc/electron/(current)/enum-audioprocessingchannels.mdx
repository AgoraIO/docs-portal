<a id="enum_audioprocessingchannels__detailed_desc"></a>

在演唱会等需要增强真实感的场景中，本地用户可能需要采集立体声并发送立体声信号给远端用户。 例如，在演唱会的舞台上，主唱、吉他手、鼓手分别站在不同的位置，现场设备采集到了三者的立体声，并把立体声信号发送给远端用户，远端用户可以像亲临舞台一样听到来自不同方向的歌声、吉他声和鼓声。 通过该类，你可以设置双声道处理，实现立体声。建议按如下步骤设置：

1. 前处理：调用 [setAdvancedAudioOptions](/zh-CN/api-reference/rtc/electron/audio/audio-prenpost/audio-effect#api_irtcengine_setadvancedaudiooptions) 并在 [AdvancedAudioOptions](/zh-CN/api-reference/rtc/electron/class-advancedaudiooptions) 中设置 `audioProcessingChannels` 为 `AudioProcessingStereo` (2)。
2. 后处理：调用 [setAudioProfile](/zh-CN/api-reference/rtc/electron/audio/audio-basic#api_irtcengine_setaudioprofile) 并将 `profile` 设为 `AudioProfileMusicStandardStereo` (3) 或 `AudioProfileMusicHighQualityStereo` (5)。

:::info[注]
- 立体声设置仅在媒体音量下生效。

如需了解媒体音量和通话音量的区别，
:::

<a id="enum_audioprocessingchannels__parameters"></a>

## 枚举值

### `AudioProcessingMono`

1: （默认）单声道。

### `AudioProcessingStereo`

2: 双声道。
