## 枚举值

### `MediaDeviceStateIdle`

0: 设备就绪。

### `MediaDeviceStateActive`

1: 设备正在使用。

### `MediaDeviceStateDisabled`

2: 设备被禁用。

### `MediaDeviceStatePluggedIn`

3: 设备已插入。

### `MediaDeviceStateNotPresent`

4: 没有此设备。

### `MediaDeviceStateUnplugged`

8: 设备被拔出。
