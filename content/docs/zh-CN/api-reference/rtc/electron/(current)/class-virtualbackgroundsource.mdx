  blur_degree?: BackgroundBlurDegree;

<a id="class_virtualbackgroundsource__parameters"></a>

## 属性

### background_source_type

自定义的背景。详见 [BackgroundSourceType](/zh-CN/api-reference/rtc/electron/enum-backgroundsourcetype)。

### color

自定义的背景图颜色。格式为 RGB 定义下的十六进制整数，不带 # 号，如 0xFFB6C1 表示浅粉色。 默认值为 0xFFFFFF，表示白色。 取值范围为 [0x000000，0xffffff]。如果取值非法，SDK 会用白色背景图替换原背景图。

:::note
注： 该参数仅在自定义背景为以下类型时生效，具体效果如下：

- BackgroundColor：背景图为该参数传入颜色的纯色图片。
- BackgroundImg：如果 `source` 中的图片使用了透明背景，则会使用该参数传入的颜色填充透明背景。
:::

### source

自定义背景的本地绝对路径。支持 PNG、JPG、MP4、 AVI、 MKV 和 FLV 格式。如果路径无效，SDK 会使用原背景图或 `color` 指定的纯色背景。

:::note
注： 该参数仅在自定义背景图类型为 BackgroundImg 或 BackgroundVideo 时生效。
:::

### blur_degree

自定义背景图的模糊程度。详见 [BackgroundBlurDegree](/zh-CN/api-reference/rtc/electron/enum-backgroundblurdegree)。

:::note
注： 该参数仅在自定义背景图类型为 BackgroundBlur 时生效。
:::
