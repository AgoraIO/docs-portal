## 枚举值

### `rtmpStreamingEventFailedLoadImage`

1: 旁路推流时，添加背景图或水印出错。

### `rtmpStreamingEventUrlAlreadyInUse`

2: 该推流 URL 已用于推流。如果你想开始新的推流，请使用新的推流 URL。

### `rtmpStreamingEventAdvancedFeatureNotSupport`

3: 功能不支持。

### `rtmpStreamingEventRequestTooOften`

4: 预留参数。
