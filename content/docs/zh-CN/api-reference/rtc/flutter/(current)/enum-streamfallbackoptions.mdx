## 枚举值

### streamFallbackOptionDisabled

0: 不对音视频流作回退处理，但不能保证音视频流的质量。

### streamFallbackOptionVideoStreamLow

1: 只接收视频小流（低分辨率、低码率视频流）。

### streamFallbackOptionAudioOnly

2: 网络条件较差时，先尝试只接收视频小流；如果因网络环境太差无法显示视频，则再回退到只接收订阅的音频流。
