## 枚举值

### `fitModeCoverPosition`

0: 使用你在 [WatermarkOptions](/zh-CN/api-reference/rtc/flutter/class-watermarkoptions) 中设置的 `positionInLandscapeMode` 和 `positionInPortraitMode` 值。此时 [WatermarkRatio](/zh-CN/api-reference/rtc/flutter/class-watermarkratio) 中的设置无效。

### `fitModeUseImageRatio`

1: 使用你在 [WatermarkRatio](/zh-CN/api-reference/rtc/flutter/class-watermarkratio) 中设置的值。此时 [WatermarkOptions](/zh-CN/api-reference/rtc/flutter/class-watermarkoptions) 中 `positionInLandscapeMode` 和 `positionInPortraitMode` 的设置无效。
