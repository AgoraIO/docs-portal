## 枚举值

### `captureBrightnessLevelInvalid`

-1: SDK 未检测出本地采集的画质亮度级别。请等待几秒，通过下一次回调的 `captureBrightnessLevel` 获取亮度级别。

### `captureBrightnessLevelNormal`

0: 本地采集的画质亮度正常。

### `captureBrightnessLevelBright`

1: 本地采集的画质亮度偏亮。

### `captureBrightnessLevelDark`

2: 本地采集的画质亮度偏暗。
