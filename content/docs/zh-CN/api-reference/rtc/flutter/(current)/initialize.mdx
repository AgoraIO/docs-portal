## registerEventHandler

添加主回调事件。

<a id="api_irtcengine_addhandler__prototype"></a>

```text
void registerEventHandler(RtcEngineEventHandler eventHandler);
```

<a id="api_irtcengine_addhandler__detailed_desc"></a>

接口类 [RtcEngineEventHandler](/zh-CN/api-reference/rtc/flutter/rtc-interface-class#class_irtcengineeventhandler) 用于 SDK 向 App 发送回调事件通知，App 通过继承该接口类的方法获取 SDK 的事件通知。
接口类的所有方法都有缺省（空）实现，App 可以根据需要只继承关心的事件。在回调方法中，App 不应该做耗时或者调用可能会引起阻塞的 API（如 [sendStreamMessage](/zh-CN/api-reference/rtc/flutter/metadata/datastream#api_irtcengine_sendstreammessage)），
否则可能影响 SDK 的运行。

<Parameter name="eventHandler">

待添加的回调事件，详见 [RtcEngineEventHandler](/zh-CN/api-reference/rtc/flutter/rtc-interface-class#class_irtcengineeventhandler)。

</Parameter>
</ParameterList>

## release

销毁 [RtcEngine](/zh-CN/api-reference/rtc/flutter/rtc-interface-class#class_irtcengine) 对象。

<a id="api_irtcengine_release__prototype"></a>

```text
Future<void> release({bool sync = false});
```

<a id="api_irtcengine_release__detailed_desc"></a>

该方法释放 SDK 使用的所有资源。有些 App 只在用户需要时才进行实时音视频通信，不需要时则将资源释放出来用于其他操作，该方法适用于此类情况。
调用该方法后，你将无法再使用 SDK 的其它方法和回调。如需再次使用实时音视频通信功能， 你必须依次重新调用 [createAgoraRtcEngine](/zh-CN/api-reference/rtc/flutter/initialize#api_irtcengine_createagorartcengine) 和 [initialize](/zh-CN/api-reference/rtc/flutter/initialize#api_irtcengine_initialize) 方法创建一个新的 [RtcEngine](/zh-CN/api-reference/rtc/flutter/rtc-interface-class#class_irtcengine) 对象。

:::note
注：

- 该方法为同步调用。需要等待 [RtcEngine](/zh-CN/api-reference/rtc/flutter/rtc-interface-class#class_irtcengine) 资源释放后才能执行其他操作（例如：创建一个新的 [RtcEngine](/zh-CN/api-reference/rtc/flutter/rtc-interface-class#class_irtcengine) 对象），因此建议在子线程中调用该方法，避免主线程阻塞。
- 不建议在 SDK 的回调中调用 [release](/zh-CN/api-reference/rtc/flutter/initialize#api_irtcengine_release)，否则由于 SDK 要等待回调返回才能回收相关的对象资源，会造成死锁。
:::

<a id="api_irtcengine_release__parameters"></a>

### 参数

<ParameterList>
<a id="sync"></a>
<Parameter name="sync">

该方法是否为同步调用：

- true\:该方法为同步调用。
- false\:该方法为异步调用。目前该方法仅支持同步调用，请不要将该参数设置为该值。

</Parameter>
</ParameterList>
