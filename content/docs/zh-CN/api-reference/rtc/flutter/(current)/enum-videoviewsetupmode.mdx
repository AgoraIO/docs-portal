<a id="enum_videoviewsetupmode__parameters"></a>

## 枚举值

### videoViewSetupReplace

0：(默认) 清除已添加的所有视图、替换为新的视图。

### videoViewSetupAdd

1：增加一个视图。

### videoViewSetupRemove

2：删除一个视图。

:::note
注： 当你不再需要使用某个视图时，建议及时设置 `setupMode` 为 videoViewSetupRemove 删除视图，否则可能会导致渲染资源泄漏。
:::
