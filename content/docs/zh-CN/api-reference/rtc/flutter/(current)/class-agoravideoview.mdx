```dart
class AgoraVideoView extends StatefulWidget {
  const AgoraVideoView({
    Key? key,
    required this.controller,
  }) : super(key: key);

  @internal
  final VideoViewControllerBase controller;

  @override
  State<AgoraVideoView> createState() => AgoraVideoViewState();
}
```

<a id="class_agoravideoview__parameters"></a>

## 属性

### `key`

`Widget` 的标识符。详见 Flutter 官方文档关于 key 对象的描述。

### `controller`

控制待渲染的视频类型：

- 如果渲染 [RtcEngine](/zh-CN/api-reference/rtc/flutter/rtc-interface-class#class_irtcengine) 的视频，详见 [VideoViewController](/zh-CN/api-reference/rtc/flutter/class-videoviewcontroller)。
- 如果渲染媒体播放器中的视频，详见 [MediaPlayerController](/zh-CN/api-reference/rtc/flutter/rtc-interface-class#class_mediaplayercontroller)。
