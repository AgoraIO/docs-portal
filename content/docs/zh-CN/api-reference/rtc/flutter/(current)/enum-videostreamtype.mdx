## 枚举值

### videoStreamHigh

0: 视频大流，即高分辨率、高码率视频流。

### videoStreamLow

1: 视频小流，即低分辨率、低码率视频流。

### VIDEO_STREAM_LAYER_1

4: 视频质量层级 1。该质量层级的分辨率仅低于 videoStreamHigh。

### VIDEO_STREAM_LAYER_2

5: 视频质量层级 2。该质量层级的分辨率仅低于 videoStreamLayer1。

### VIDEO_STREAM_LAYER_3

6: 视频质量层级 3。该质量层级的分辨率仅低于 videoStreamLayer2。

### VIDEO_STREAM_LAYER_4

7: 视频质量层级 4。该质量层级的分辨率仅低于 videoStreamLayer3。

### VIDEO_STREAM_LAYER_5

8: 视频质量层级 5。该质量层级的分辨率仅低于 videoStreamLayer4。

### VIDEO_STREAM_LAYER_6

9: 视频质量层级 6。该质量层级的分辨率仅低于 videoStreamLayer5。
