## startRtmpStreamWithoutTranscoding

开始非转码推流。

<a id="api_irtcengine_startrtmpstreamwithouttranscoding__prototype"></a>

```text
Future<void> startRtmpStreamWithoutTranscoding(String url);
```

<a id="api_irtcengine_startrtmpstreamwithouttranscoding__detailed_desc"></a>

声网推荐你使用更加完善的服务端推流功能，详见[实现服务端旁路推流](/zh-CN/realtime-media/media-push)。
调用该方法，你可以向指定的旁路推流地址推送直播音视频流。该方法每次只能向一个地址推送媒体流，如果你需要向多个地址转码推流，则需多次调用该方法。
调用该方法后，SDK 会在本地触发 [onRtmpStreamingStateChanged](/zh-CN/api-reference/rtc/flutter/cloud-media-relay/media-push#callback_irtcengineeventhandler_onrtmpstreamingstatechanged) 回调，报告推流的状态。

:::note
注：

- 请在加入频道后调用该方法。
- 只有直播场景下的主播才能调用该方法。
- 调用该方法推流失败后，如果你想要重新推流，那么请你务必先调用 [stopRtmpStream](/zh-CN/api-reference/rtc/flutter/cloud-media-relay/media-push#api_irtcengine_stoprtmpstream)，再调用该方法重推，否则 SDK 会返回与上次推流失败时一样的错误码。
:::

<a id="api_irtcengine_startrtmpstreamwithouttranscoding__parameters"></a>

### 参数

### url

旁路推流地址。格式为 RTMP 或 RTMPS。字符长度不能超过 1024 字节。不支持中文字符等特殊字符。

<a id="api_irtcengine_startrtmpstreamwithouttranscoding__return_values"></a>

### 返回值

方法成功调用时，无返回值；方法调用失败时，会抛出 [AgoraRtcException](/zh-CN/api-reference/rtc/flutter/class-agorartcexception) 异常，你需要捕获异常并进行处理。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。
