## 枚举值

### `playerStateIdle`

0: 默认状态。播放器会在你打开媒体文件之前和结束播放之后返回该状态码。

### `playerStateOpening`

1: 正在打开媒体文件。

### `playerStateOpenCompleted`

2: 成功打开媒体文件。

### `playerStatePlaying`

3: 正在播放。

### `playerStatePaused`

4: 暂停播放。

### `playerStatePlaybackCompleted`

5: 播放完毕。

### `playerStatePlaybackAllLoopsCompleted`

6: 循环播放已结束。

### `playerStateStopped`

7: 播放已停止。

### `playerStateFailed`

100: 播放失败。
