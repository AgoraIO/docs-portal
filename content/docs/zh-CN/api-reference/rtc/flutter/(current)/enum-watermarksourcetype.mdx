<a id="enum_watermarksourcetype__detailed_desc"></a>

### `自从`

自 v6.6.2 版本新增。

<a id="enum_watermarksourcetype__parameters"></a>

## 枚举值

### `image`

（0）：水印源为图像。

### `buffer`

（1）：水印源为缓冲区。

### `literal`

（2）：水印源为文本字面量。

:::info[注]
仅支持在 Linux 平台使用。
:::

### `timestamps`

（3）：水印源为时间戳。

:::info[注]
仅支持在 Linux 平台使用。
:::
