<a id="class_userinfo__prototype"></a>

```dart
class UserInfo {
  const UserInfo({this.uid, this.userAccount});

  @JsonKey(name: 'uid')
  final int? uid;
  @JsonKey(name: 'userAccount')
  final String? userAccount;
  factory UserInfo.fromJson(Map<String, dynamic> json) =>
      _$UserInfoFromJson(json);
  Map<String, dynamic> toJson() => _$UserInfoToJson(this);
}
```

<a id="class_userinfo__parameters"></a>

## 属性

### `uid`

用户 ID。

### `userAccount`

用户 Account。长度限制为 [MaxUserAccountLengthType](/zh-CN/api-reference/rtc/flutter/enum-maxuseraccountlengthtype)。
