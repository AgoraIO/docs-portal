## 枚举值

### `audioReverbDryLevel`

0: 原始声音强度，即所谓的 dry signal，取值范围 [-20,10]，单位为 dB。

### `audioReverbWetLevel`

1: 早期反射信号强度，即所谓的 wet signal，取值范围 [-20,10]，单位为 dB。

### `audioReverbRoomSize`

2: 所需混响效果的房间尺寸，一般房间越大，混响越强，取值范围 [0,100]，单位为 dB。

### `audioReverbWetDelay`

3: Wet signal 的初始延迟长度，取值范围 [0,200]，单位为毫秒。

### `audioReverbStrength`

4: 混响持续的强度，取值范围为 [0,100]。
