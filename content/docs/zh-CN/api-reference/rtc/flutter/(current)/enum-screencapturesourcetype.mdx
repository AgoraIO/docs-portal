## 枚举值

### `screencapturesourcetypeUnknown`

-1：未知。

### `screencapturesourcetypeWindow`

0：共享目标为某一个窗口。

### `screencapturesourcetypeScreen`

1：共享目标为某一个显示器的屏幕。

### `screencapturesourcetypeCustom`

2：预留参数。
