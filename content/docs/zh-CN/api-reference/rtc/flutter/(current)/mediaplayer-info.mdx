## getAudioBufferDelay

获取播放媒体文件时的音频缓冲延迟。

<a id="api_imediaplayer_getaudiobufferdelay__prototype"></a>

```dart
Future<int> getAudioBufferDelay();
```

<a id="api_imediaplayer_getaudiobufferdelay__detailed_desc"></a>

<a id="api_imediaplayer_getaudiobufferdelay__parameters"></a>

### 参数

#### `delayMs`

输出参数，表示播放媒体文件时的音频缓冲延迟，单位为毫秒。

<a id="api_imediaplayer_getaudiobufferdelay__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/flutter/error-code)了解详情和解决建议。

- [MediaPlayer](/zh-CN/api-reference/rtc/flutter/rtc-interface-class#class_imediaplayer)

## getStreamCount

获取当前媒体文件中媒体流的数量。

<a id="api_imediaplayer_getstreamcount__prototype"></a>

```dart
Future<int> getStreamCount();
```

<a id="api_imediaplayer_getstreamcount__detailed_desc"></a>

:::info[注]
请在 [open](/zh-CN/api-reference/rtc/flutter/mediaplayer-open#api_imediaplayer_open) 后并收到 [onPlayerSourceStateChanged](/zh-CN/api-reference/rtc/flutter/mediaplayer-observer#callback_imediaplayersourceobserver_onplayersourcestatechanged) 回调报告播放状态为 `playerStateOpenCompleted` 后再调用该方法。
:::

<a id="api_imediaplayer_getstreamcount__return_values"></a>

### 返回值

- 方法调用成功，返回该媒体文件中媒体流的数量。
- &lt; 0: 方法调用失败，详见 [MediaPlayerReason](/zh-CN/api-reference/rtc/flutter/enum-mediaplayerreason)。

- [MediaPlayer](/zh-CN/api-reference/rtc/flutter/rtc-interface-class#class_imediaplayer)

<a id="api_imediaplayer_getstreaminfo"></a>

## getStreamInfo

通过媒体流的索引值获取媒体流信息。

<a id="api_imediaplayer_getstreaminfo__prototype"></a>

```dart
Future<PlayerStreamInfo> getStreamInfo(int index);
```

<a id="api_imediaplayer_getstreaminfo__detailed_desc"></a>

<a id="api_imediaplayer_getstreaminfo__timing"></a>

### 调用时机

你需要在 [getStreamCount](/zh-CN/api-reference/rtc/flutter/mediaplayer-info#api_imediaplayer_getstreamcount) 后调用该方法。

<a id="api_imediaplayer_getstreaminfo__parameters"></a>

### 参数

#### `index`

媒体流索引值。该参数的值需小于 [getStreamCount](/zh-CN/api-reference/rtc/flutter/mediaplayer-info#api_imediaplayer_getstreamcount) 的返回值。

<a id="api_imediaplayer_getstreaminfo__return_values"></a>

### 返回值

- 方法调用成功，返回媒体流信息，详见 [PlayerStreamInfo](/zh-CN/api-reference/rtc/flutter/class-playerstreaminfo)。
- 方法调用失败，返回 `NULL`。

- [MediaPlayer](/zh-CN/api-reference/rtc/flutter/rtc-interface-class#class_imediaplayer)

<a id="callback_imediaplayersourceobserver_onplayerplaybackstats"></a>

## onPlayerPlaybackStats

报告当前播放的媒体资源的相关信息。

<a id="callback_imediaplayersourceobserver_onplayerplaybackstats__prototype"></a>

```dart
final void Function(PlayerPlaybackStats stats)? onPlayerPlaybackStats;
```

<a id="callback_imediaplayersourceobserver_onplayerplaybackstats__detailed_desc"></a>

当媒体资源开始播放后，SDK 会每秒触发一次该回调，报告媒体资源的相关信息。

<a id="callback_imediaplayersourceobserver_onplayerplaybackstats__parameters"></a>

### 参数

#### `stats`

媒体资源的相关信息，详见 [PlayerPlaybackStats](/zh-CN/api-reference/rtc/flutter/class-playerplaybackstats)。

- [MediaPlayerSourceObserver](/zh-CN/api-reference/rtc/flutter/rtc-interface-class#class_imediaplayersourceobserver)
