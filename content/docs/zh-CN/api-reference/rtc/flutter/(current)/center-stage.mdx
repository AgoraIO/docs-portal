## 人像锁定

<a id="api_irtcengine_enablecameracenterstage"></a>

## enableCameraCenterStage

开启或关闭人像锁定功能。

<a id="api_irtcengine_enablecameracenterstage__prototype"></a>

```dart
Future<void> enableCameraCenterStage(bool enabled);
```

<a id="api_irtcengine_enablecameracenterstage__detailed_desc"></a>

人像锁定功能默认关闭，你需要调用该方法开启。如果需要关闭该功能，则需重新调用该方法并将 `enabled` 设置为 false。

:::info[注]
该方法仅适用于 iOS 和 macOS。 由于该功能对设备性能要求较高，你需要在以下类型或更高性能的设备上使用该功能：

- iPad：
  - 12.9 英寸 iPad Pro（第五代）
  - 11 英寸 iPad Pro（第三代）
  - iPad（第九代）
  - iPad mini（第六代）
  - iPad Air（第五代）
- 2020 年 M1 MacBook Pro 13 英寸 + iPhone 11（将 iPhone 作为 MacBook 的外接摄像头使用）

声网建议你在开启该功能前，先调用 [isCameraCenterStageSupported](/zh-CN/api-reference/rtc/flutter/center-stage#api_irtcengine_iscameracenterstagesupported) 查询当前设备是否支持人像锁定。
:::

<a id="api_irtcengine_enablecameracenterstage__scenario"></a>

### 适用场景

人像锁定功能可广泛应用于在线会议、秀场、在线教育等场景。主播可以开启该功能，确保无论移动与否，自己始终在画面中心，以便取得良好的展示效果。

<a id="api_irtcengine_enablecameracenterstage__timing"></a>

### 调用时机

该方法必须在摄像头成功开启后调用，即 SDK 触发 [onLocalVideoStateChanged](/zh-CN/api-reference/rtc/flutter/video-basic#callback_irtcengineeventhandler_onlocalvideostatechanged) 回调，返回本地视频状态为 `localVideoStreamStateCapturing` (1) 后。

<a id="api_irtcengine_enablecameracenterstage__parameters"></a>

### 参数

#### `enabled`

是否开启人像锁定功能：

- true：开启人像锁定。
- false：关闭人像锁定。

<a id="api_irtcengine_enablecameracenterstage__return_values"></a>

### 返回值

方法成功调用时，无返回值；方法调用失败时，会抛出 [AgoraRtcException](/zh-CN/api-reference/rtc/flutter/class-agorartcexception) 异常，你需要捕获异常并进行处理。

### 所属接口类

<a id="api_irtcengine_iscameracenterstagesupported"></a>

## isCameraCenterStageSupported

查询摄像头是否支持人像锁定。

<a id="api_irtcengine_iscameracenterstagesupported__prototype"></a>

```dart
Future<bool> isCameraCenterStageSupported();
```

<a id="api_irtcengine_iscameracenterstagesupported__detailed_desc"></a>

在调用 [enableCameraCenterStage](/zh-CN/api-reference/rtc/flutter/center-stage#api_irtcengine_enablecameracenterstage) 开启人像锁定功能前，建议你先调用该方法查询当前设备是否支持人像锁定。

:::info[注]
该方法仅适用于 iOS 和 macOS。
:::

<a id="api_irtcengine_iscameracenterstagesupported__timing"></a>

### 调用时机

该方法必须在摄像头成功开启后调用，即 SDK 触发 [onLocalVideoStateChanged](/zh-CN/api-reference/rtc/flutter/video-basic#callback_irtcengineeventhandler_onlocalvideostatechanged) 回调，返回本地视频状态为 `localVideoStreamStateCapturing` (1) 后。

<a id="api_irtcengine_iscameracenterstagesupported__return_values"></a>

### 返回值

- true: 当前摄像头支持人像锁定。
- false: 当前摄像头不支持人像锁定。
