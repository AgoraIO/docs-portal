<a id="enum_experiencepoorreason__parameters"></a>

## 枚举值

### `experienceReasonNone`

0: 无原因，说明主观体验质量较好。

### `remoteNetworkQualityPoor`

1: 远端用户的网络较差。

### `localNetworkQualityPoor`

2: 本地用户的网络较差。

### `wirelessSignalPoor`

4: 本地用户的 Wi-FI 或者移动数据网络信号弱。

### `wifiBluetoothCoexist`

8: 本地用户同时开启 Wi-Fi 和蓝牙，二者信号互相干扰，导致音频传输质量下降。
