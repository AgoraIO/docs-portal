## adjustCustomAudioPlayoutVolume

调节自定义音频采集轨道在本地播放的音量。

<a id="api_irtcengine_adjustcustomaudioplayoutvolume__prototype"></a>

```dart
Future<void> adjustCustomAudioPlayoutVolume(
      {required int trackId, required int volume});
```

<a id="api_irtcengine_adjustcustomaudioplayoutvolume__detailed_desc"></a>

调用该方法设置音频在本地播放的音量后，如果你想重新调整音量，你可以再次调用该方法。

:::info[注]
在调用该方法前，请确保你已经调用 [createCustomAudioTrack](/zh-CN/api-reference/rtc/flutter/audio-custom-capturenrendering#api_imediaengine_createcustomaudiotrack) 方法创建自定义音频采集轨道。
:::

<a id="api_irtcengine_adjustcustomaudioplayoutvolume__parameters"></a>

### 参数

#### `trackId`

音频轨道 ID。将该参数设置为调用 [createCustomAudioTrack](/zh-CN/api-reference/rtc/flutter/audio-custom-capturenrendering#api_imediaengine_createcustomaudiotrack) 方法返回的自定义音频轨道 ID。

#### `volume`

自定义采集音频的播放音量，取值范围为 [0,100]。0 表示静音，100 表示原始音量。

<a id="api_irtcengine_adjustcustomaudioplayoutvolume__return_values"></a>

### 返回值

方法成功调用时，无返回值；方法调用失败时，会抛出 [AgoraRtcException](/zh-CN/api-reference/rtc/flutter/class-agorartcexception) 异常，你需要捕获异常并进行处理。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/flutter/error-code)了解详情和解决建议。

- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/flutter/error-code)了解详情和解决建议。

### 所属接口类
- [RtcEngine](/zh-CN/api-reference/rtc/flutter/rtc-interface-class#class_irtcengine)

## createCustomAudioTrack

创建一个自定义音频采集轨道。

<a id="api_imediaengine_createcustomaudiotrack__prototype"></a>

```dart
Future<int> createCustomAudioTrack(
      {required AudioTrackType trackType, required AudioTrackConfig config});
```

<a id="api_imediaengine_createcustomaudiotrack__detailed_desc"></a>

如需在频道中发布自定义采集音频，可参考以下步骤：

1. 调用该方法创建音频轨道并获得音频轨道 ID。
2. 调用 [joinChannel](/zh-CN/api-reference/rtc/flutter/channel#api_irtcengine_joinchannel2) 加入频道时，将 [ChannelMediaOptions](/zh-CN/api-reference/rtc/flutter/class-channelmediaoptions) 中的 `publishCustomAudioTrackId` 设置为你想要发布的音频轨道 ID，并将 `publishCustomAudioTrack` 设置为 true。
3. 调用 [pushAudioFrame](/zh-CN/api-reference/rtc/flutter/audio-custom-capturenrendering#api_imediaengine_pushaudioframe) 将 `trackId` 指定为步骤 2 中指定的音频轨道 ID，即可实现在频道内发布对应的自定义音频源。

:::info[注]
该方法需要在加入频道前调用。
:::

<a id="api_imediaengine_createcustomaudiotrack__parameters"></a>

### 参数

#### `trackType`

自定义音频轨道类型。详见 [AudioTrackType](/zh-CN/api-reference/rtc/flutter/enum-audiotracktype)。

:::info[注]
如指定 `audioTrackDirect`，则必须在调用 [joinChannel](/zh-CN/api-reference/rtc/flutter/channel#api_irtcengine_joinchannel2) 加入频道时，将 [ChannelMediaOptions](/zh-CN/api-reference/rtc/flutter/class-channelmediaoptions) 中的 `publishMicrophoneTrack` 设为 false，否则加入频道失败并返回错误码 -2。
:::

#### `config`

自定义音频轨道配置。详见 [AudioTrackConfig](/zh-CN/api-reference/rtc/flutter/class-audiotrackconfig)。

<a id="api_imediaengine_createcustomaudiotrack__return_values"></a>

### 返回值

- 方法调用成功，返回音频轨道 ID 作为该音频轨道的唯一标识。
- 方法调用失败，返回 0xffffffff。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/flutter/error-code)了解详情和解决建议。

## pullAudioFrame

拉取远端音频数据。

<a id="api_imediaengine_pullaudioframe__prototype"></a>

```dart
Future<void> pullAudioFrame(AudioFrame frame);
```

<a id="api_imediaengine_pullaudioframe__detailed_desc"></a>

调用该方法后，App 会采取主动拉取的方式获取远端已解码和混音后的音频数据，用于音频播放。

:::info[注]
该方法和 [onPlaybackAudioFrame](/zh-CN/api-reference/rtc/flutter/audio-raw#callback_iaudioframeobserverbase_onplaybackaudioframe) 回调均可用于获取远端混音后的音频播放数据。在调用 [setExternalAudioSink](/zh-CN/api-reference/rtc/flutter/audio-custom-capturenrendering#api_imediaengine_setexternalaudiosink) 开启外部音频渲染后，App 将无法从 [onPlaybackAudioFrame](/zh-CN/api-reference/rtc/flutter/audio-raw#callback_iaudioframeobserverbase_onplaybackaudioframe) 回调中获得数据。因此，请根据实际的业务需求在该方法和 [onPlaybackAudioFrame](/zh-CN/api-reference/rtc/flutter/audio-raw#callback_iaudioframeobserverbase_onplaybackaudioframe) 回调之间进行选择。二者的处理机制不同，具体区别如下：

- 调用该方法后，App 会主动拉取音频数据。通过设置音频数据，SDK 可以调整缓存，帮助 App 处理延时，从而有效避免音频播放抖动。
- 注册 [onPlaybackAudioFrame](/zh-CN/api-reference/rtc/flutter/audio-raw#callback_iaudioframeobserverbase_onplaybackaudioframe) 回调后，SDK 通过该回调将音频数据传输给 App。App 在处理音频帧的延迟时，可能会导致音频播放抖动。

该方法仅用于拉取远端混音后的音频播放数据，如需获取采集的原始音频数据、混音前每条拉流单独的原始音频播放数据等，可以通过调用 [registerAudioFrameObserver](/zh-CN/api-reference/rtc/flutter/audio-raw#api_imediaengine_registeraudioframeobserver) 注册相应的回调。
:::

<a id="api_imediaengine_pullaudioframe__timing"></a>

### 调用时机

该方法需要在加入频道后调用。 调用该方法前，你需要调用 `setExternalAudioSink(enabled: true)` 开启并设置外部渲染。

<a id="api_imediaengine_pullaudioframe__parameters"></a>

### 参数

#### `frame`

指向 [AudioFrame](/zh-CN/api-reference/rtc/flutter/class-audioframe) 的指针。

<a id="api_imediaengine_pullaudioframe__return_values"></a>

### 返回值

方法成功调用时，无返回值；方法调用失败时，会抛出 [AgoraRtcException](/zh-CN/api-reference/rtc/flutter/class-agorartcexception) 异常，你需要捕获异常并进行处理。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/flutter/error-code)了解详情和解决建议。

<a id="api_imediaengine_pushaudioframe__detailed_desc"></a>

<a id="api_imediaengine_pushaudioframe__timing"></a>

1. 调用 [createCustomAudioTrack](/zh-CN/api-reference/rtc/flutter/audio-custom-capturenrendering#api_imediaengine_createcustomaudiotrack) 创建音频轨道并获得音频轨道 ID。

#### `trackId`

音频轨道 ID。如果你要发布自定义的外部音频源，则将该参数设置为你想要发布的自定义音频轨道 ID。

## setExternalAudioSink

设置外部音频渲染。

<a id="api_imediaengine_setexternalaudiosink__prototype"></a>

```dart
Future<void> setExternalAudioSink(
    {required bool enabled, required int sampleRate, required int channels});
```

<a id="api_imediaengine_setexternalaudiosink__detailed_desc"></a>

调用该方法开启外部音频渲染后，你可以调用 [pullAudioFrame](/zh-CN/api-reference/rtc/flutter/audio-custom-capturenrendering#api_imediaengine_pullaudioframe) 拉取远端音频数据。App 可以对拉取到的原始音频数据进行处理后再渲染，获取想要的音频效果。

:::info[注]
调用该方法开启外部音频渲染后，App 将无法从 [onPlaybackAudioFrame](/zh-CN/api-reference/rtc/flutter/audio-raw#callback_iaudioframeobserverbase_onplaybackaudioframe) 回调中获得数据。
:::

<a id="api_imediaengine_setexternalaudiosink__scenario"></a>

### 适用场景

该方法适用于需要自行渲染音频的场景。

<a id="api_imediaengine_setexternalaudiosink__timing"></a>

### 调用时机

该方法需要在加入频道前调用。

<a id="api_imediaengine_setexternalaudiosink__parameters"></a>

### 参数

#### `enabled`

设置是否开启外部音频渲染：

- true：开启外部音频渲染。
- false：（默认）关闭外部音频渲染。

#### `sampleRate`

外部音频渲染的采样率 (Hz)，可设置为 16000，32000，44100 或 48000。

#### `channels`

外部音频渲染的声道数:

- 1: 单声道
- 2: 双声道

<a id="api_imediaengine_setexternalaudiosink__return_values"></a>

### 返回值

方法成功调用时，无返回值；方法调用失败时，会抛出 [AgoraRtcException](/zh-CN/api-reference/rtc/flutter/class-agorartcexception) 异常，你需要捕获异常并进行处理。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/flutter/error-code)了解详情和解决建议。
