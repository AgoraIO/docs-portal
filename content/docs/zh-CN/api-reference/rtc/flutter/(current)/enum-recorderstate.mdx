## 枚举值

### `recorderStateError`

-1: 音视频流录制出错，错误原因详见 [RecorderReasonCode](/zh-CN/api-reference/rtc/flutter/enum-recorderreasoncode)。

### `recorderStateStart`

2: 音视频流录制开始。

### `recorderStateStop`

3: 音视频流录制停止。
