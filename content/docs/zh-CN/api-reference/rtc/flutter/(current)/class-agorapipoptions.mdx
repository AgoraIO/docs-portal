该类提供平台特定的选项来配置 Android 和 iOS 平台的画中画行为。

<a id="class_agorapipoptions__parameters"></a>

## 属性

<ParameterList>
<a id="autoenterenabled"></a>
<Parameter name="autoEnterEnabled">

是否自动进入画中画模式。

仅适用于 Android 平台。

</Parameter>
<a id="aspectratiox"></a>
<Parameter name="aspectRatioX">

画中画窗口的水平宽高比。

仅适用于 Android 平台。

</Parameter>
<a id="aspectratioy"></a>
<Parameter name="aspectRatioY">

画中画窗口的垂直宽高比。

仅适用于 Android 平台。

</Parameter>
<a id="sourcerecthintleft"></a>
<Parameter name="sourceRectHintLeft">

源矩形提示的左坐标。

用于指定画中画窗口的初始位置。
仅适用于 Android 平台。

</Parameter>
<a id="sourcerecthinttop"></a>
<Parameter name="sourceRectHintTop">

源矩形提示的上坐标。

用于指定画中画窗口的初始位置。
仅适用于 Android 平台。

</Parameter>
<a id="sourcerecthintright"></a>
<Parameter name="sourceRectHintRight">

源矩形提示的右坐标。

用于指定画中画窗口的初始位置。
仅适用于 Android 平台。

</Parameter>
<a id="sourcerecthintbottom"></a>
<Parameter name="sourceRectHintBottom">

源矩形提示的下坐标。

用于指定画中画窗口的初始位置。
仅适用于 Android 平台。

</Parameter>
<a id="seamlessresizeenabled"></a>
<Parameter name="seamlessResizeEnabled">

是否启用画中画窗口的无缝调整大小。

启用后，画中画窗口将平滑调整大小。
默认为 `false`。
仅适用于 Android 平台。

</Parameter>
<a id="useexternalstatemonitor"></a>
<Parameter name="useExternalStateMonitor">

是否使用外部状态监控。

启用后，创建专用线程来监控画中画窗口状态。使用 externalStateMonitorInterval 配置监控频率。
默认为 `false`。
仅适用于 Android 平台。

</Parameter>
<a id="externalstatemonitorinterval"></a>
<Parameter name="externalStateMonitorInterval">

外部状态监控的间隔，单位为毫秒。

仅在 useExternalStateMonitor 为 `true` 时生效。
默认为 100ms。
仅适用于 Android 平台。

</Parameter>
<a id="sourcecontentview"></a>
<Parameter name="sourceContentView">

源内容视图标识符。

设置为 0 以使用根视图作为源。
仅适用于 iOS 平台。

</Parameter>
<a id="contentview"></a>
<Parameter name="contentView">

用于视频渲染的内容视图标识符。

设置为 0 以让 SDK 管理视图。当设置为 0 时，必须通过 videoStreams 提供视频源。
仅适用于 iOS 平台。

</Parameter>
<a id="videostreams"></a>
<Parameter name="videoStreams">

视频转码配置。

仅在 contentView 设置为 0 时生效。当用户让 SDK 管理视图时，所有视频流将放置在画中画窗口的根视图中。
仅适用于 iOS 平台。

</Parameter>
<a id="contentviewlayout"></a>
<Parameter name="contentViewLayout">

画中画视频流的布局配置。

仅在 contentView 设置为 0 时生效。
仅适用于 iOS 平台。

</Parameter>
<a id="preferredcontentwidth"></a>
<Parameter name="preferredContentWidth">

画中画内容的首选宽度。

仅适用于 iOS 平台。

</Parameter>
<a id="preferredcontentheight"></a>
<Parameter name="preferredContentHeight">

画中画内容的首选高度。

仅适用于 iOS 平台。

</Parameter>
<a id="controlstyle"></a>
<Parameter name="controlStyle">

画中画窗口的控制样式。
可用样式：

- 0：显示所有系统控件（默认）
- 1：隐藏前进和后退按钮
- 2：隐藏播放/暂停按钮和进度条（推荐）
- 3：隐藏所有系统控件，包括关闭和恢复按钮

仅适用于 iOS 平台。

</Parameter>
</ParameterList>
