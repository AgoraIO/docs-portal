:::

<a id="enum_camerafocallengthtype__parameters"></a>

## 枚举值

### `cameraFocalLengthDefault`

0：（默认）标准镜头。

### `cameraFocalLengthWideAngle`

1：广角镜头。

### `cameraFocalLengthUltraWide`

2：超广角镜头。

### `cameraFocalLengthTelephoto`

3：（仅适用于 iOS）长焦镜头。
