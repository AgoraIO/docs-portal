## 枚举值

### audioSourceMicrophone

0：（默认）麦克风。

### audioSourceCustom

1：自定义采集到的音频流。

### audioSourceMediaPlayer

2：媒体播放器。

### audioSourceLoopbackRecording

3：在屏幕共享时采集的系统音频流。

### audioSourceRemoteUser

5：指定远端用户的音频流。

### audioSourceRemoteChannel

6：当前频道内所有音频流的合流。

### audioSourceUnknown

100：未知的音频源。
