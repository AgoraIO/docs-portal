## 枚举值

### `audioEncodedFrameObserverPositionRecord`

1: 仅编码本地用户的音频。

### `audioEncodedFrameObserverPositionPlayback`

2: 仅编码所有远端用户的音频。

### `audioEncodedFrameObserverPositionMixed`

3: 编码本地和所有远端用户混音后的音频。
