## 枚举值

<ParameterList>
<a id="audiodualmonostereo"></a>
<Parameter name="audioDualMonoStereo">

<a id="audiodualmonol"></a>
<Parameter name="audioDualMonoL">

1: 左声道模式。该模式用左声道的音频替换右声道的音频，即用户只能听到左声道的音频。

</Parameter>
<a id="audiodualmonor"></a>
<Parameter name="audioDualMonoR">

2: 右声道模式。该模式用右声道的音频替换左声道的音频，即用户只能听到右声道的音频。

</Parameter>
<a id="audiodualmonomix"></a>
<Parameter name="audioDualMonoMix">

3: 混合模式。该模式将左右声道的数据叠加，即用户能同时听到左声道和右声道的音频。

</Parameter>
