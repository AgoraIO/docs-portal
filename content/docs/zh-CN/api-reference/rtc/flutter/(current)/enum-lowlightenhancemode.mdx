## 枚举值

### LowLightEnhanceAuto

0:（默认）自动模式。SDK 会根据环境光亮度自动开启或关闭暗光增强功能，以适时补光和防止过曝。

### LowLightEnhanceManual

1：手动模式。用户需手动开启或关闭暗光增强功能。
