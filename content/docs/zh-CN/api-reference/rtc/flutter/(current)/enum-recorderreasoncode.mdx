## 枚举值

### recorderReasonNone

0: 一切正常。

### recorderReasonWriteFailed

1: 录制文件写入失败。

### recorderReasonNoStream

2: 没有可录制的音视频流或者录制的音视频流中断超过 5 秒。

### recorderReasonOverMaxDuration

3: 录制时长超出上限。

### recorderReasonConfigChanged

4: 录制配置改变。
