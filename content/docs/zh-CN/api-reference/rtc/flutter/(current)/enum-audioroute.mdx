## 枚举值

### `routeDefault`

-1: 使用默认的音频路由。

### `routeHeadset`

0: 音频路由为带麦克风的耳机。

### `routeEarpiece`

1: 音频路由为听筒。

### `routeHeadsetnomic`

2: 音频路由为不带麦克风的耳机。

### `routeSpeakerphone`

3: 音频路由为设备自带的扬声器。

### `routeLoudspeaker`

4: 音频路由为外接的扬声器。（仅适用于 iOS 和 macOS）

### `routeHeadsetbluetooth`

5: 音频路由为使用 HFP 协议的蓝牙设备。

### `routeUsb`

6: 音频路由为 USB 外围设备。（仅适用于 macOS）

### `routeHdmi`

7: 音频路由为 HDMI 外围设备。（仅适用于 macOS）

### `routeDisplayport`

8: 音频路由为 DisplayPort 外围设备。（仅适用于 macOS）

### `routeAirplay`

9: 音频路由为 Apple AirPlay。（仅适用于 macOS）

### `routeBluetoothSpeaker`

10: 音频路由为使用 A2DP 协议的蓝牙设备。
