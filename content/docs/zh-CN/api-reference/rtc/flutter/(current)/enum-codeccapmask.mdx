## 枚举值

### `codecCapMaskNone`

(0)：不支持编解码。

### `codecCapMaskHwDec`

(1 &lt;&lt; 0)：支持硬件解码。

### `codecCapMaskHwEnc`

(1 &lt;&lt; 1)：支持硬件编码。

### `codecCapMaskSwDec`

(1 &lt;&lt; 2)：支持软件解码。

### `codecCapMaskSwEnc`

(1 &lt;&lt; 3)：支持软件编码。
