## 枚举值

### videoPixelDefault

0: 原始视频像素格式。

### videoPixelI420

1: I420 格式。

### videoPixelRgba

4: RGBA 格式。

### videoPixelI422

16: I422 格式。

### videoTextureId3d11texture2d

17: ID3D11TEXTURE2D 格式。目前支持的类型有 `DXGI_FORMAT_B8G8R8A8_UNORM`、`DXGI_FORMAT_B8G8R8A8_TYPELESS` 和 `DXGI_FORMAT_NV12`。
