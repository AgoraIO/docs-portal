## setCameraStabilizationMode

设置摄像头防抖模式。

<a id="api_irtcengine_setcamerastabilizationmode__prototype"></a>

```dart
Future<void> setCameraStabilizationMode(CameraStabilizationMode mode);
```

<a id="api_irtcengine_setcamerastabilizationmode__detailed_desc"></a>

摄像头防抖模式默认关闭，你需要调用该方法开启并设置合适的防抖模式。

:::info[注]
该方法仅适用于 iOS。

- 摄像头防抖只对视频分辨率大于 1280 × 720 以上的场景生效。
- 开启摄像头防抖后，摄像头防抖等级越高，相机的视角就越小、相机时延就越大。为保障用户体验，建议你将 mode 参数设置为 cameraStabilizationModeLevel1。
:::

<a id="api_irtcengine_setcamerastabilizationmode__scenario"></a>

### 适用场景

在移动拍摄、暗光环境拍摄、手持拍摄时，你可以设置摄像头防抖模式，以减小摄像头晃动导致的影响，获得更加稳定、清晰的画面。

<a id="api_irtcengine_setcamerastabilizationmode__timing"></a>

### 调用时机

该方法必须在摄像头成功开启后调用，即 SDK 触发 [onLocalVideoStateChanged](/zh-CN/api-reference/rtc/flutter/video/video-basic#callback_irtcengineeventhandler_onlocalvideostatechanged) 回调，返回本地视频状态为 `localVideoStreamStateCapturing` (1) 后。

<a id="api_irtcengine_setcamerastabilizationmode__parameters"></a>

### 参数

#### `mode`

摄像头的防抖模式。详见 [CameraStabilizationMode](/zh-CN/api-reference/rtc/flutter/enum-camerastabilizationmode)。

<a id="api_irtcengine_setcamerastabilizationmode__return_values"></a>

### 返回值

方法成功调用时，无返回值；方法调用失败时，会抛出 [AgoraRtcException](/zh-CN/api-reference/rtc/flutter/class-agorartcexception) 异常，你需要捕获异常并进行处理。

## startCameraCapture

开始通过摄像头采集视频。

<a id="api_irtcengine_startcameracapture__prototype"></a>

```dart
Future<void> startCameraCapture(
      {required VideoSourceType sourceType,
      required CameraCapturerConfiguration config});
```

<a id="api_irtcengine_startcameracapture__detailed_desc"></a>

调用该方法可以通过指定 `sourceType` 同时开启多路摄像头采集。

:::info[注]
在 iOS 平台上调用该方法前，如果要开启多路摄像头采集，需要在调用该方法前，先调用 [enableMultiCamera](/zh-CN/api-reference/rtc/flutter/device-management/video-device#api_irtcengine_enablemulticamera) 并设置 `enabled` 为 true。
:::

<a id="api_irtcengine_startcameracapture__parameters"></a>

### 参数

#### `sourceType`

视频源的类型。详见 [VideoSourceType](/zh-CN/api-reference/rtc/flutter/enum-videosourcetype)。

:::info[注]
- iOS 设备最多支持 2 路摄像头采集的视频流（要求设备配备多摄像头或支持外接摄像头）。
- Android 设备最多支持 4 路摄像头采集的视频流（要求设备配备多摄像头或支持外接摄像头）。
- 桌面端最多支持 4 路摄像头采集的视频流。
:::

#### `config`

视频采集配置。详见 [CameraCapturerConfiguration](/zh-CN/api-reference/rtc/flutter/class-cameracapturerconfiguration)。

:::info[注]
在 iOS 平台上，该参数无实际作用。请使用 [enableMultiCamera](/zh-CN/api-reference/rtc/flutter/device-management/video-device#api_irtcengine_enablemulticamera) 中的 `config` 参数设置视频采集配置。
:::

<a id="api_irtcengine_startcameracapture__return_values"></a>

### 返回值

方法成功调用时，无返回值；方法调用失败时，会抛出 [AgoraRtcException](/zh-CN/api-reference/rtc/flutter/class-agorartcexception) 异常，你需要捕获异常并进行处理。详见[错误码](/zh-CN/realtime-media/rtc/reference/error-code)了解详情和解决建议。

### 所属接口类
- [RtcEngine](/zh-CN/api-reference/rtc/flutter/rtc-interface-class#class_irtcengine)

## stopCameraCapture

停止通过摄像头采集视频。

<a id="api_irtcengine_stopcameracapture__prototype"></a>

```dart
Future<void> stopCameraCapture(VideoSourceType sourceType);
```

<a id="api_irtcengine_stopcameracapture__detailed_desc"></a>

调用 [startCameraCapture](/zh-CN/api-reference/rtc/flutter/video/camera-capture#api_irtcengine_startcameracapture) 开启一路或多路摄像头采集的视频流后，你可以调用该方法，通过设置 `sourceType` 停止一路或多路摄像头的视频采集。

:::info[注]
在 iOS 平台上，如果要关闭多路摄像头采集，需要在调用该方法之后调用 [enableMultiCamera](/zh-CN/api-reference/rtc/flutter/device-management/video-device#api_irtcengine_enablemulticamera) 并设置 `enabled` 为 false。 如果你正在使用本地合图功能，调用该方法停止通过第一个摄像头采集视频，会造成本地合图中断。
:::

<a id="api_irtcengine_stopcameracapture__parameters"></a>

### 参数

#### `sourceType`

视频源的类型，详见 [VideoSourceType](/zh-CN/api-reference/rtc/flutter/enum-videosourcetype)。

<a id="api_irtcengine_stopcameracapture__return_values"></a>

### 返回值

方法成功调用时，无返回值；方法调用失败时，会抛出 [AgoraRtcException](/zh-CN/api-reference/rtc/flutter/class-agorartcexception) 异常，你需要捕获异常并进行处理。详见[错误码](/zh-CN/realtime-media/rtc/reference/error-code)了解详情和解决建议。

### 所属接口类
- [RtcEngine](/zh-CN/api-reference/rtc/flutter/rtc-interface-class#class_irtcengine)
