## enableInstantMediaRendering

开启音视频帧加速渲染。

<a id="api_irtcengine_enableinstantmediarendering__prototype"></a>

```text
Future<void> enableInstantMediaRendering();
```

<a id="api_irtcengine_enableinstantmediarendering__detailed_desc"></a>

成功调用该方法后，SDK 会开启加速出图和出声模式，可加快用户加入频道后的首帧出图与出声速度。

:::note
注： 主播端和观众端都需调用该方法开启音视频帧加速渲染才可体验该功能。
一旦成功调用该方法，只能通过调用 [release](/zh-CN/api-reference/rtc/flutter/initialize#api_irtcengine_release) 方法销毁 [RtcEngine](/zh-CN/api-reference/rtc/flutter/rtc-interface-class#class_irtcengine) 对象来取消加速渲染。
:::

<a id="api_irtcengine_enableinstantmediarendering__scenario"></a>

### 适用场景

声网推荐在直播场景下，对观众开启该模式。

<a id="api_irtcengine_enableinstantmediarendering__timing"></a>

### 调用时机

该方法需要在加入频道前调用。

<a id="api_irtcengine_enableinstantmediarendering__return_values"></a>

### 返回值

方法成功调用时，无返回值；方法调用失败时，会抛出 [AgoraRtcException](/zh-CN/api-reference/rtc/flutter/class-agorartcexception) 异常，你需要捕获异常并进行处理。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。

<a id="api_irtcengine_setlocalrendermode2__prototype"></a>

```text

    {required RenderModeType renderMode,
    VideoMirrorModeType mirrorMode =
        VideoMirrorModeType.videoMirrorModeAuto});
```

<a id="api_irtcengine_setlocalrendermode2__detailed_desc"></a>

初始化本地用户视图后，你可以调用该方法更新本地用户视图的渲染和镜像模式。该方法只影响本地用户看到的视频画面，不影响本地视频的发布。

注： 该方法仅对第一个摄像头 `(primaryCameraSource)` 生效。在自定义视频采集或使用其他类型视频源的场景下，你需要使用 [setupLocalVideo](/zh-CN/api-reference/rtc/flutter/video/video-rendering#api_irtcengine_setuplocalvideo) 方法替代该方法。
:::

<a id="api_irtcengine_setlocalrendermode2__timing"></a>

- 你可以在通话中多次调用该方法，多次更新本地用户视图的显示模式。

## setupLocalVideo

初始化本地视图。

<a id="api_irtcengine_setuplocalvideo__prototype"></a>

```text
Future<void> setupLocalVideo(VideoCanvas canvas);
```

<a id="api_irtcengine_setuplocalvideo__detailed_desc"></a>

该方法初始化本地视图并设置本地用户视频显示属性，只影响本地用户看到的视频画面，不影响本地视频的发布。调用该方法绑定本地视频流的显示视窗 (`view`)，并设置本地用户视图的渲染模式和镜像模式。
退出频道后绑定仍然有效。如果需要停止渲染或解除绑定，可以调用该方法将参数 `view` 设为 NULL，以停止渲染并清理渲染缓存。

:::note
注：

- 在 Flutter 中你不需要主动调用该方法，请使用 [AgoraVideoView](/zh-CN/api-reference/rtc/flutter/class-agoravideoview) 渲染本地和远端视图。
- 如果你希望在通话中仅更新本地用户视图的渲染或镜像模式，请使用 [setLocalRenderMode](/zh-CN/api-reference/rtc/flutter/video/video-rendering#api_irtcengine_setlocalrendermode2) 方法。
:::

<a id="api_irtcengine_setuplocalvideo__scenario"></a>

### 适用场景

在 App 开发中，通常在初始化后调用该方法进行本地视频设置，然后再加入频道。
如果你需要在本地视频预览的画面中同时看到多个预览画面、且不同画面分别处于视频链路上不同观测点，可以重复调用该方法设置不同的 `view`，并针对每个 `view` 设置不同的观测位置。例如：将视频源设置为摄像头，然后对应两个 `view` 分别设置 `position` 为 PositionPostCapturerOrigin 和 PositionPostCapturer，即可在本地视频预览中同时看到没有经过视频前处理的原始画面和已经过视频前处理（美颜、虚拟背景、水印本地预览）的画面。

## setupRemoteVideo

初始化远端用户视图。

<a id="api_irtcengine_setupremotevideo__prototype"></a>

```text
Future<void> setupRemoteVideo(VideoCanvas canvas);
```

<a id="api_irtcengine_setupremotevideo__detailed_desc"></a>

该方法绑定远端用户和显示视图，并设置远端用户视图在本地显示时的渲染模式和镜像模式，只影响本地用户看到的视频画面。
调用该方法时需要指定远端视频的用户 ID，一般可以在进频道前提前设置好。如果无法在加入频道前得到远端用户的 ID，可以在收到 [onUserJoined](/zh-CN/api-reference/rtc/flutter/channel#callback_irtcengineeventhandler_onuserjoined) 回调时调用该方法。
如需解除某个远端用户的绑定视图，可以调用该方法并将 `view` 设置为空。
离开频道后，SDK 会清除远端用户视图的绑定关系。
在移动端自定义合图布局场景下，你可以调用该方法并针对合图视频流的每一路子视频流设置一个单独的 `view` 进行渲染。

:::note
注：

- 在 Flutter 中你不需要主动调用该方法，请使用 [AgoraVideoView](/zh-CN/api-reference/rtc/flutter/class-agoravideoview) 渲染本地和远端视图。
- 如果你希望在通话中更新远端用户视图的渲染或镜像模式，请使用 [setRemoteRenderMode](/zh-CN/api-reference/rtc/flutter/video/video-rendering#api_irtcengine_setremoterendermode2) 方法。
- 当使用录制服务时，由于它不会发送视频流，App 无需为它绑定视图。如果 App 无法识别录制服务，可以在收到 [onFirstRemoteVideoDecoded](/zh-CN/api-reference/rtc/flutter/video/video-basic#callback_irtcengineeventhandler_onfirstremotevideodecoded) 回调时再绑定远端用户视图。

## setupRemoteVideoEx

初始化远端用户视图。

<a id="api_irtcengineex_setupremotevideoex__prototype"></a>

```text
Future<void> setupRemoteVideoEx(
    {required VideoCanvas canvas, required RtcConnection connection});
```

<a id="api_irtcengineex_setupremotevideoex__detailed_desc"></a>

该方法绑定远端用户和显示视图，并设置远端用户视图在本地显示时的渲染模式和镜像模式，只影响本地用户看到的视频画面。
调用该方法时需要在 [VideoCanvas](/zh-CN/api-reference/rtc/flutter/class-videocanvas) 中指定远端视频的用户 ID，一般可以在进频道前提前设置好。
如果无法在加入频道前得到远端用户的 uid，可以在收到 [onUserJoined](/zh-CN/api-reference/rtc/flutter/channel#callback_irtcengineeventhandler_onuserjoined) 回调时调用该方法。如果启用了视频录制功能，视频录制服务会做为一个哑客户端加入频道，因此其他客户端也会收到它的 [onUserJoined](/zh-CN/api-reference/rtc/flutter/channel#callback_irtcengineeventhandler_onuserjoined) 事件， App 不应给它绑定视图（因为它不会发送视频流）。
如需解除某个远端用户的绑定视图，可以调用该方法并将 `view` 设置为空。
离开频道后，SDK 会清除远端用户视图的绑定关系。

:::note
注：

- 该方法需要在 [joinChannelEx](/zh-CN/api-reference/rtc/flutter/channel#api_irtcengineex_joinchannelex) 之后调用。
- 在 Flutter 中你不需要主动调用该方法，请使用 [AgoraVideoView](/zh-CN/api-reference/rtc/flutter/class-agoravideoview) 渲染本地和远端视图。
- 如果你希望在通话中更新远端用户视图的渲染或镜像模式，请使用 [setRemoteRenderModeEx](/zh-CN/api-reference/rtc/flutter/video/video-rendering#api_irtcengineex_setremoterendermodeex) 方法。
:::

## startMediaRenderingTracing

开启视频帧渲染数据打点。

<a id="api_irtcengine_startmediarenderingtracing__prototype"></a>

```text
Future<void> startMediaRenderingTracing();
```

<a id="api_irtcengine_startmediarenderingtracing__detailed_desc"></a>

成功调用该方法后，SDK 会以调用该方法的时刻作为起点，并通过 [onVideoRenderingTracingResult](/zh-CN/api-reference/rtc/flutter/video/video-rendering#callback_irtcengineeventhandler_onvideorenderingtracingresult) 回调报告视频帧渲染的相关信息。

:::note
注：

- 如果你未调用该方法，SDK 默认以调用 [joinChannel](/zh-CN/api-reference/rtc/flutter/channel#api_irtcengine_joinchannel2) 加入频道的时刻为起始点开始打点，自动开始跟踪视频的渲染事件。你可以根据实际业务场景，在合适的时机调用该方法，进行自定义打点。
- 离开当前频道后，SDK 会自动重置该时间点为下一次加入频道的时刻。
:::

<a id="api_irtcengine_startmediarenderingtracing__scenario"></a>

### 适用场景

声网推荐你将该方法和 App 中的 UI 设置（按钮、滑动条等）结合使用，用于获取符合终端用户实际体验的首帧出图耗时的场景。例如：在终端用户在点击 加入频道 按钮的时刻调用该方法进行打点，然后通过 `onVideoRenderingTracingResult` 回调获取视频帧渲染过程中的各阶段耗时，从而针对各阶段耗时进行专项优化。

<a id="api_irtcengine_startmediarenderingtracing__return_values"></a>

### 返回值

方法成功调用时，无返回值；方法调用失败时，会抛出 [AgoraRtcException](/zh-CN/api-reference/rtc/flutter/class-agorartcexception) 异常，你需要捕获异常并进行处理。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。
