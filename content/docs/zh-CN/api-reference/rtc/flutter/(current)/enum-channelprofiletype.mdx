## 枚举值

### `channelProfileCommunication`

0: 通信场景。声网推荐使用直播场景以获取更好的音视频体验。

### `channelProfileLiveBroadcasting`

1:（默认）直播场景。

### `channelProfileGame`

2: 游戏场景。

:::info[注]
废弃：请改用 channelProfileLiveBroadcasting。
:::

### `channelProfileCloudGaming`

3: 互动场景。该场景对延时进行了优化。如果你的场景中有用户需要频繁互动，建议使用该场景。

:::info[注]
废弃：请改用 channelProfileLiveBroadcasting。
:::
