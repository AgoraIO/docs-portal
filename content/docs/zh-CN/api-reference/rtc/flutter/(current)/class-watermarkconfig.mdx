```dart
class WatermarkConfig implements AgoraSerializable {
  const WatermarkConfig(
      {this.id,
      this.type,
      this.buffer,
      this.timestamp,
      this.literal,
      this.imageUrl,
      this.options});

  @JsonKey(name: 'id')
  final String? id;

  @JsonKey(name: 'type')
  final WatermarkSourceType? type;

  @JsonKey(name: 'buffer')
  final WatermarkBuffer? buffer;

  @JsonKey(name: 'timestamp')
  final WatermarkTimestamp? timestamp;

  @JsonKey(name: 'literal')
  final WatermarkLiteral? literal;

  @JsonKey(name: 'imageUrl')
  final String? imageUrl;

  @JsonKey(name: 'options')
  final WatermarkOptions? options;

  factory WatermarkConfig.fromJson(Map<String, dynamic> json) =>
      _$WatermarkConfigFromJson(json);

  @override
  Map<String, dynamic> toJson() => _$WatermarkConfigToJson(this);
}
```

<a id="class_watermarkconfig__detailed_desc"></a>

### `自从`

自 v6.6.2 版本新增。

<a id="class_watermarkconfig__parameters"></a>

## 属性

### `id`

水印的唯一标识符，建议使用 UUID。

### `type`

水印类型，详见 [WatermarkSourceType](/zh-CN/api-reference/rtc/flutter/enum-watermarksourcetype)。

### `buffer`

水印的缓冲区。详见 [WatermarkBuffer](/zh-CN/api-reference/rtc/flutter/class-watermarkbuffer)。

### `timestamp`

水印的时间戳。

:::info[注]
仅支持在 Linux 平台使用。
:::

### `literal`

水印的文本内容。

:::info[注]
仅支持在 Linux 平台使用。
:::

### `imageUrl`

水印图像文件的 URL，默认值为 `NULL`。

### `options`

水印的配置选项。详见 [WatermarkOptions](/zh-CN/api-reference/rtc/flutter/class-watermarkoptions)。
