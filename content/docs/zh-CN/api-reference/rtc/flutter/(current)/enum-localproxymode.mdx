## 枚举值

### connectivityFirst

0：SDK 优先尝试连接指定的声网私有媒体服务器；如果无法连接到指定的声网私有媒体服务器，则连接声网 SD-RTN™。

### localOnly

1：SDK 只尝试连接指定的声网私有媒体服务器。
