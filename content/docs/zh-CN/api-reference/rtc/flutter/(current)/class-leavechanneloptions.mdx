<a id="class_leavechanneloptions__parameters"></a>

## 属性

### `stopAudioMixing`

离开频道时，是否停止播放音乐文件及混音：

- true：（默认）停止播放音乐文件及混音。
- false： 不停止播放音乐文件及混音。

### `stopAllEffect`

离开频道时，是否停止播放音效：

- true：（默认）停止播放音效。
- false： 不停止播放音效。

### `stopMicrophoneRecording`

离开频道时，是否停止麦克风采集：

- true：（默认）停止麦克风采集。
- false： 不停止麦克风采集。
