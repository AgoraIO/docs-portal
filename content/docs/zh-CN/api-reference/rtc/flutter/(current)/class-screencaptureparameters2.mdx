<a id="captureaudio"></a>
<Parameter name="captureAudio">

:::note
注：

- 受系统限制，采集系统音频仅适用于 Android API 级别为 29 及以上，即 Android 10 及以上。
- 为提高屏幕共享时采集系统音频的成功率，请确保你已调用 [setAudioScenario](/zh-CN/api-reference/rtc/flutter/audio/audio-basic#api_irtcengine_setaudioscenario) 方法并设置音频场景为 `audioScenarioGameStreaming`。
:::

屏幕共享时是否采集系统音频：

- true: 采集系统音频。
- false: （默认）不采集系统音频。

</Parameter>
