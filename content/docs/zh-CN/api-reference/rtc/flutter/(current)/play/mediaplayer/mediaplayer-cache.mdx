## enableAutoRemoveCache

设置是否开启自动清除缓存文件功能。

<a id="api_imediaplayercachemanager_enableautoremovecache__prototype"></a>

```text
Future<void> enableAutoRemoveCache(bool enable);
```

<a id="api_imediaplayercachemanager_enableautoremovecache__detailed_desc"></a>

开启自动清除缓存文件后，当播放器中缓存的媒体文件超过你设置的文件数量或总缓存大小的上限时，SDK 会自动清除近期最少使用的一个缓存文件。

<a id="api_imediaplayercachemanager_enableautoremovecache__parameters"></a>

### 参数

### enable

是否自动清除缓存文件：

- true：开启自动清除缓存文件功能。
- false：（默认）关闭自动清除缓存文件功能。

<a id="api_imediaplayercachemanager_enableautoremovecache__return_values"></a>

### 返回值

方法成功调用时，无返回值；方法调用失败时，会抛出 [AgoraRtcException](/zh-CN/api-reference/rtc/flutter/class-agorartcexception) 异常，你需要捕获异常并进行处理。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。

- &lt; 0：方法调用失败，详见 [MediaPlayerReason](/zh-CN/api-reference/rtc/flutter/enum-mediaplayerreason)。

### 所属接口类

- [MediaPlayerCacheManager](/zh-CN/api-reference/rtc/flutter/rtc-interface-class#class_imediaplayercachemanager)
