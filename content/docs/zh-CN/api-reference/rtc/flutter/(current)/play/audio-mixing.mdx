## adjustAudioMixingPlayoutVolume

调节音乐文件在本地播放的音量。

<a id="api_irtcengine_adjustaudiomixingplayoutvolume__prototype"></a>

```dart
Future<void> adjustAudioMixingPlayoutVolume(int volume);
```

<a id="api_irtcengine_adjustaudiomixingplayoutvolume__detailed_desc"></a>

<a id="api_irtcengine_adjustaudiomixingplayoutvolume__timing"></a>

### 调用时机

你需要在调用 [startAudioMixing](/zh-CN/api-reference/rtc/flutter/play/audio-mixing#api_irtcengine_startaudiomixing2) 并收到 `onAudioMixingStateChanged(audioMixingStatePlaying)` 回调后调用该方法。

<a id="api_irtcengine_adjustaudiomixingplayoutvolume__parameters"></a>

### 参数

#### `volume`

音乐文件音量。取值范围为 [0,100]，100 （默认值）为原始音量。

<a id="api_irtcengine_adjustaudiomixingplayoutvolume__return_values"></a>

### 返回值

方法成功调用时，无返回值；方法调用失败时，会抛出 [AgoraRtcException](/zh-CN/api-reference/rtc/flutter/class-agorartcexception) 异常，你需要捕获异常并进行处理。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/flutter/error-code)了解详情和解决建议。

## getAudioMixingCurrentPosition

获取音乐文件的播放进度。

<a id="api_irtcengine_getaudiomixingcurrentposition__prototype"></a>

```dart
Future<int> getAudioMixingCurrentPosition();
```

<a id="api_irtcengine_getaudiomixingcurrentposition__detailed_desc"></a>

该方法获取当前音乐文件播放进度，单位为毫秒。

:::info[注]
- 你需要在调用 startAudioMixing 并收到 onAudioMixingStateChanged(audioMixingStatePlaying) 回调后调用该方法。
- 如需多次调用 getAudioMixingCurrentPosition，请确保调用间隔大于 500 ms。
:::

<a id="api_irtcengine_getaudiomixingcurrentposition__return_values"></a>

### 返回值

- ≥ 0: 方法调用成功，返回当前音乐文件播放进度（ms）。0 表示当前音乐文件未开始播放。
- &lt; 0: 方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/flutter/error-code)了解详情和解决建议。

### 所属接口类
- [RtcEngine](/zh-CN/api-reference/rtc/flutter/rtc-interface-class#class_irtcengine)

### 适用场景

在 K 歌场景下，主播可以根据需求选择在本地播放一路音轨（如原声），然后发送另一路音轨至远端（如伴唱）以提升听众体验。

用于发送至远端的音轨索引。你可以通过 [getStreamInfo](/zh-CN/api-reference/rtc/flutter/play/mediaplayer/mediaplayer-info#api_imediaplayer_getstreaminfo) 来获取索引值。

## setAudioMixingDualMonoMode

<a id="api_irtcengine_setaudiomixingdualmonomode__prototype"></a>

```dart
Future<void> setAudioMixingDualMonoMode(AudioMixingDualMonoMode mode);
```

<a id="api_irtcengine_setaudiomixingdualmonomode__detailed_desc"></a>

在双声道音频文件中，左声道和右声道可以存储不同的音频数据。根据实际需要，你可以设置声道模式为原始模式、左声道模式、右声道模式或混合模式。

:::info[注]
该方法仅适用于双声道的音频文件。
:::

<a id="api_irtcengine_setaudiomixingdualmonomode__scenario"></a>

### 适用场景

在 KTV 场景中，音频文件的左声道存储了伴奏，右声道存储了原唱的歌声。你可以根据实际需求进行设置：

- 如果你只需听伴奏，则用该方法设置音频文件的声道模式为左声道模式。
- 如果你需要同时听伴奏和原唱，则调用该方法设置声道模式为混合模式。

<a id="api_irtcengine_setaudiomixingdualmonomode__timing"></a>

### 调用时机

```dart
Future<void> setAudioMixingPitch(int pitch);
```

<a id="api_irtcengine_setaudiomixingpitch__detailed_desc"></a>

本地人声和播放的音乐文件混音时，调用该方法可以仅调节音乐文件的音调。

<a id="api_irtcengine_setaudiomixingpitch__timing"></a>

### 调用时机

你需要在调用 [startAudioMixing](/zh-CN/api-reference/rtc/flutter/play/audio-mixing#api_irtcengine_startaudiomixing2) 并收到 `onAudioMixingStateChanged(audioMixingStatePlaying)` 回调后调用该方法。

<a id="api_irtcengine_setaudiomixingpitch__parameters"></a>

### 参数

#### `pitch`

按半音音阶调整本地播放的音乐文件的音调，默认值为 0，即不调整音调。取值范围为 [-12,12]，每相邻两个值的音高距离相差半音。取值的绝对值越大，音调升高或降低得越多。

<a id="api_irtcengine_setaudiomixingpitch__return_values"></a>

### 返回值

```dart

```

<a id="api_irtcengine_setaudiomixingplaybackspeed__detailed_desc"></a>

## startAudioMixing

开始播放音乐文件。

<a id="api_irtcengine_startaudiomixing2__prototype"></a>

```dart
Future<void> startAudioMixing(
      {required String filePath,
      required bool loopback,
      required int cycle,
      int startPos = 0});
```

<a id="api_irtcengine_startaudiomixing2__detailed_desc"></a>

该方法支持播放的音频文件格式见 [RTC SDK 支持播放哪些格式的音频文件](https://doc.shengwang.cn/faq/general-product-inquiry/audio-format)。如果本地音乐文件不存在、文件格式不支持或无法访问在线音乐文件 URL，则 SDK 会报告 audioMixingReasonCanNotOpen。

:::info[注]
- 使用该方法播放时长较短的音效文件可能会导致播放失败。如需播放音效文件，建议使用 playEffect。
- 如需多次调用该方法，请确保调用间隔大于 500 ms。
- 在 Android 平台上调用该方法时，请注意如下事项：
  - 请确保使用 Android 4.2 或以上设备，且 API Level 不低于 16。
  - 如果播放的是在线音乐文件，建议不要使用重定向地址。重定向地址在某些机型上可能无法打开。
  - 如果在模拟器上调用该方法，则请确保音乐文件在 /sdcard/ 目录下，且格式为 MP3。
:::

<a id="api_irtcengine_startaudiomixing2__timing"></a>

### 调用时机

该方法在加入频道前后均可调用。

<a id="api_irtcengine_startaudiomixing2__related"></a>

### 相关回调

调用该方法成功播放音乐文件后，本地会触发 [onAudioMixingStateChanged](/zh-CN/api-reference/rtc/flutter/play/audio-mixing#callback_irtcengineeventhandler_onaudiomixingstatechanged) (`audioMixingStatePlaying`) 回调。播放结束后，本地会触发 [onAudioMixingStateChanged](/zh-CN/api-reference/rtc/flutter/play/audio-mixing#callback_irtcengineeventhandler_onaudiomixingstatechanged) (`audioMixingStateStopped`) 回调。

<a id="api_irtcengine_startaudiomixing2__parameters"></a>

### 参数

#### `filePath`

文件路径：

- Android: 文件路径，需精确到文件名及后缀。支持在线文件的 URL 地址，本地文件的 URI 地址、绝对路径或以 /assets/ 开头的路径。通过绝对路径访问本地文件可能会遇到权限问题，建议使用 URI 地址访问本地文件。例如 content://com.android.providers.media.documents/document/audio%3A14441。
- Windows: 音频文件的绝对路径或 URL 地址，需精确到文件名及后缀。例如 C:\\music\\audio.mp4。
- iOS 或 macOS: 音频文件的绝对路径或 URL 地址，需精确到文件名及后缀。例如 /var/mobile/Containers/Data/audio.mp4。

#### `loopback`

是否只在本地播放音乐文件：

- true：只在本地播放音乐文件，只有本地用户能听到音乐。
- false：将本地播放的音乐文件发布至远端，本地用户和远端用户都能听到音乐。

#### `cycle`

音乐文件的播放次数。

- &gt; 0: 播放次数。例如，1 表示播放 1 次。
- -1: 无限循环播放。

#### `startPos`

音乐文件的播放位置，单位为毫秒。

<a id="api_irtcengine_startaudiomixing2__return_values"></a>

### 返回值

方法成功调用时，无返回值；方法调用失败时，会抛出 [AgoraRtcException](/zh-CN/api-reference/rtc/flutter/class-agorartcexception) 异常，你需要捕获异常并进行处理。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/flutter/error-code)了解详情和解决建议。
