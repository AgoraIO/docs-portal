## 属性

### dimensions

视频编码的分辨率。默认值为 1280 × 720。

### frameRate

视频编码帧率 (fps)。默认值为 15。

### bitrate

视频编码码率 (Kbps)。

### contentHint

屏幕共享视频的内容类型。
