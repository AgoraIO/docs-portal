## 枚举值

### `pubStateIdle`

0: 加入频道后的初始发布状态。

### `pubStateNoPublished`

1: 发布失败。可能是因为：

- 本地用户调用 [muteLocalAudioStream](/zh-CN/api-reference/rtc/flutter/publishnsubscribe#api_irtcengine_mutelocalaudiostream) (true) 或 [muteLocalVideoStream](/zh-CN/api-reference/rtc/flutter/publishnsubscribe#api_irtcengine_mutelocalvideostream) (true) 停止发送本地媒体流。
- 本地用户调用 [disableAudio](/zh-CN/api-reference/rtc/flutter/audio/audio-basic#api_irtcengine_disableaudio) 或 [disableVideo](/zh-CN/api-reference/rtc/flutter/video/video-basic#api_irtcengine_disablevideo) 关闭本地音频或视频模块。
- 本地用户调用 [enableLocalAudio](/zh-CN/api-reference/rtc/flutter/audio/audio-capture#api_irtcengine_enablelocalaudio) (false) 或 [enableLocalVideo](/zh-CN/api-reference/rtc/flutter/video/video-basic#api_irtcengine_enablelocalvideo) (false) 关闭本地音频或视频采集。
- 本地用户角色为观众。

### `pubStatePublishing`

2: 正在发布。

### `pubStatePublished`

3: 发布成功。
