## registerMediaMetadataObserver

注册媒体 metadata 观测器用于接收或发送 metadata。

<a id="api_irtcengine_registermediametadataobserver__prototype"></a>

```dart
void registerMediaMetadataObserver(
      {required MetadataObserver observer, required MetadataType type});
```

<a id="api_irtcengine_registermediametadataobserver__detailed_desc"></a>

你需要自行实现 [MetadataObserver](/zh-CN/api-reference/rtc/flutter/rtc-interface-class#class_imetadataobserver) 类并在本方法中指定 metadata 类型。本方法允许你为视频流添加同步的 metadata，用于多样化的直播互动，如发送购物链接、电子优惠券和在线测试。

:::info[注]
请在 [joinChannel](/zh-CN/api-reference/rtc/flutter/channel#api_irtcengine_joinchannel2) 前调用该方法。
:::

<a id="api_irtcengine_registermediametadataobserver__parameters"></a>

### 参数

#### `observer`

metadata 观测器。详见 [MetadataObserver](/zh-CN/api-reference/rtc/flutter/rtc-interface-class#class_imetadataobserver)。

#### `type`

metadata 类型。目前仅支持 `videoMetadata`。

<a id="api_irtcengine_registermediametadataobserver__return_values"></a>

### 返回值

方法成功调用时，无返回值；方法调用失败时，会抛出 [AgoraRtcException](/zh-CN/api-reference/rtc/flutter/class-agorartcexception) 异常，你需要捕获异常并进行处理。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/flutter/error-code)了解详情和解决建议。

- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/flutter/error-code)了解详情和解决建议。

- [RtcEngine](/zh-CN/api-reference/rtc/flutter/rtc-interface-class#class_irtcengine)

## sendMetaData

发送媒体附属信息。

<a id="api_irtcengine_sendmetadata__prototype"></a>

```dart
Future<void> sendMetaData(
    {required Metadata metadata, required VideoSourceType sourceType});
```

<a id="api_irtcengine_sendmetadata__detailed_desc"></a>

如果成功发送了媒体附属信息，接收端会收到 [onMetadataReceived](/zh-CN/api-reference/rtc/flutter/metadata/metadata-observer#callback_imetadataobserver_onmetadatareceived) 回调。

<a id="api_irtcengine_sendmetadata__parameters"></a>

### 参数

#### `metadata`

媒体附属信息。详见 [Metadata](/zh-CN/api-reference/rtc/flutter/class-metadata)。

#### `sourceType`

视频源的类型，详见 [VideoSourceType](/zh-CN/api-reference/rtc/flutter/enum-videosourcetype)。

<a id="api_irtcengine_sendmetadata__return_values"></a>

### 返回值

方法成功调用时，无返回值；方法调用失败时，会抛出 [AgoraRtcException](/zh-CN/api-reference/rtc/flutter/class-agorartcexception) 异常，你需要捕获异常并进行处理。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/flutter/error-code)了解详情和解决建议。

- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/flutter/error-code)了解详情和解决建议。

- [RtcEngine](/zh-CN/api-reference/rtc/flutter/rtc-interface-class#class_irtcengine)

## setMaxMetadataSize

<a id="api_irtcengine_setmaxmetadatasize__prototype"></a>


<a id="api_irtcengine_setmaxmetadatasize__detailed_desc"></a>

调用 [registerMediaMetadataObserver](/zh-CN/api-reference/rtc/flutter/metadata/metadata-observer#api_irtcengine_registermediametadataobserver) 后，你可以调用本方法来设置媒体附属信息的最大大小。

<a id="api_irtcengine_setmaxmetadatasize__parameters"></a>

### 参数

#### `size`

媒体附属信息的最大大小。

- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/flutter/error-code)了解详情和解决建议。
