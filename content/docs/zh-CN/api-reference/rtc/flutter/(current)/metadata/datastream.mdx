<a id="api_irtcengine_createdatastream2__prototype"></a>

## sendStreamMessage

发送数据流。

<a id="api_irtcengine_sendstreammessage__prototype"></a>

```text
Future<void> sendStreamMessage(
    {required int streamId, required Uint8List data, required int length});
```

<a id="api_irtcengine_sendstreammessage__detailed_desc"></a>

调用 [createDataStream](/zh-CN/api-reference/rtc/flutter/metadata/datastream#api_irtcengine_createdatastream2) 后，你可以调用该方法向频道内所有用户发送数据流消息。
SDK 对该方法的实现进行了如下限制：

- 频道内每个客户端最多可以同时拥有 5 个数据通道，所有数据通道共用的总发包码率限制为 30 KB/s。
- 每个数据通道每秒最多能发送 60 个包，每个包最大为 1 KB。

成功调用该方法后，远端会触发 [onStreamMessage](/zh-CN/api-reference/rtc/flutter/metadata/datastream#callback_irtcengineeventhandler_onstreammessage) 回调，远端用户可以在该回调中获取接收到的流消息；若调用失败，远端会触发 [onStreamMessageError](/zh-CN/api-reference/rtc/flutter/metadata/datastream#callback_irtcengineeventhandler_onstreammessageerror) 回调。

:::note
注： 如你需要更加全面的低延时、高并发、可扩展的实时消息及状态同步解决方案，推荐使用实时消息。

- 该方法需要在加入频道后、且调用 [createDataStream](/zh-CN/api-reference/rtc/flutter/metadata/datastream#api_irtcengine_createdatastream2) 创建数据通道之后调用。
- 该方法仅适用于主播用户。
:::

### 参数

<ParameterList>
<a id="streamid"></a>
<Parameter name="streamId">

数据流 ID。可以通过 [createDataStream](/zh-CN/api-reference/rtc/flutter/metadata/datastream#api_irtcengine_createdatastream2) 获取。

</Parameter>
<a id="data"></a>
<Parameter name="data">

待发送的数据。

</Parameter>
<a id="length"></a>
<Parameter name="length">

数据长度。

</Parameter>
</ParameterList>

<a id="api_irtcengine_sendstreammessage__return_values"></a>

### 返回值

方法成功调用时，无返回值；方法调用失败时，会抛出 [AgoraRtcException](/zh-CN/api-reference/rtc/flutter/class-agorartcexception) 异常，你需要捕获异常并进行处理。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。
