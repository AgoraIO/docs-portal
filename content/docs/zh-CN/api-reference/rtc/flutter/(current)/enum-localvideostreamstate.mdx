## 枚举值

### `localVideoStreamStateStopped`

0: 本地视频默认初始状态。

### `localVideoStreamStateCapturing`

1: 本地视频采集设备启动成功。

### `localVideoStreamStateEncoding`

2: 本地视频首帧编码成功。

### `localVideoStreamStateFailed`

3: 本地视频启动失败。
