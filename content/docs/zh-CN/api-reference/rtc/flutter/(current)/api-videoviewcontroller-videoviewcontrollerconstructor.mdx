```dart
    required this.rtcEngine,
    required this.canvas,
    this.useFlutterTexture = false,
    this.useAndroidSurfaceView = false,
  }) : connection = const RtcConnection();
```

<a id="api_videoviewcontroller_videoviewcontrollerconstructor__detailed_desc"></a>

<a id="api_videoviewcontroller_videoviewcontrollerconstructor__parameters"></a>

## 参数

### `rtcEngine`

[RtcEngine](/zh-CN/api-reference/rtc/flutter/rtc-interface-class#class_irtcengine)。

### `canvas`

本地视频显示属性。详见 [VideoCanvas](/zh-CN/api-reference/rtc/flutter/class-videocanvas)。

### `useFlutterTexture`

:::info[注]
`FlutterTexture` 适用于 Android、iOS、macOS 和 Windows 平台。
:::

是否使用 `FlutterTexture` 渲染视频：

- true: 使用 `FlutterTexture` 渲染视频。
- false: 不使用 `FlutterTexture` 渲染视频。

### `useAndroidSurfaceView`

:::info[注]
Android `SurfaceView` 仅适用于 Android 平台。
:::

是否使用 Android `SurfaceView` 渲染视频：

- true: 使用 Android `SurfaceView` 渲染视频。
- false: 不使用 Android `SurfaceView` 渲染视频。
