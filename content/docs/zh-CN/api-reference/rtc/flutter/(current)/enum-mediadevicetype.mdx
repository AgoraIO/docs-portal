## 枚举值

### `unknownAudioDevice`

-1: 设备类型未知。

### `audioPlayoutDevice`

0: 音频播放设备。

### `audioRecordingDevice`

1: 音频采集设备。

### `videoRenderDevice`

2: 视频渲染设备 (显卡)。

### `videoCaptureDevice`

3: 视频采集设备。

### `audioApplicationPlayoutDevice`

4: 音频应用播放设备。

### `audioVirtualPlayoutDevice`

（仅适用于 macOS。）5: 虚拟音频播放设备（虚拟声卡）。

### `audioVirtualRecordingDevice`

（仅适用于 macOS。）6: 虚拟音频采集设备（虚拟声卡）。
