## 已编码视频数据

<a id="api_imediaengine_registervideoencodedframeobserver"></a>

## registerVideoEncodedFrameObserver

为编码后的视频图像注册视频帧接收观测器。

<a id="api_imediaengine_registervideoencodedframeobserver__prototype"></a>

```dart
void registerVideoEncodedFrameObserver(VideoEncodedFrameObserver observer);
```

<a id="api_imediaengine_registervideoencodedframeobserver__detailed_desc"></a>

如果你只想要观测编码后的视频帧 (如 H.264 格式)，而不需要对视频进行解码和渲染，声网推荐你通过该方法注册一个 [VideoEncodedFrameObserver](/zh-CN/api-reference/rtc/flutter/rtc-interface-class#class_ivideoencodedframeobserver) 类。

:::info[注]
该方法需要在加入频道前调用。
:::

<a id="api_imediaengine_registervideoencodedframeobserver__parameters"></a>

### 参数

#### `observer`

视频帧接收观测器，详见 [VideoEncodedFrameObserver](/zh-CN/api-reference/rtc/flutter/rtc-interface-class#class_ivideoencodedframeobserver)。

<a id="api_imediaengine_registervideoencodedframeobserver__return_values"></a>

### 返回值

方法成功调用时，无返回值；方法调用失败时，会抛出 [AgoraRtcException](/zh-CN/api-reference/rtc/flutter/class-agorartcexception) 异常，你需要捕获异常并进行处理。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/flutter/error-code)了解详情和解决建议。

### 所属接口类
- [MediaEngine](/zh-CN/api-reference/rtc/flutter/rtc-interface-class#class_imediaengine)

<a id="api_imediaengine_unregistervideoencodedframeobserver"></a>

## unregisterVideoEncodedFrameObserver

为编码后的视频图像取消注册视频帧接收观测器。

<a id="api_imediaengine_unregistervideoencodedframeobserver__prototype"></a>

```dart
void unregisterVideoEncodedFrameObserver(VideoEncodedFrameObserver observer);
```

<a id="api_imediaengine_unregistervideoencodedframeobserver__detailed_desc"></a>

<a id="api_imediaengine_unregistervideoencodedframeobserver__parameters"></a>

### 参数

#### `observer`

视频帧观测器，观测每帧视频的接收, 详见 [VideoEncodedFrameObserver](/zh-CN/api-reference/rtc/flutter/rtc-interface-class#class_ivideoencodedframeobserver)。

<a id="api_imediaengine_unregistervideoencodedframeobserver__return_values"></a>

### 返回值

方法成功调用时，无返回值；方法调用失败时，会抛出 [AgoraRtcException](/zh-CN/api-reference/rtc/flutter/class-agorartcexception) 异常，你需要捕获异常并进行处理。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/flutter/error-code)了解详情和解决建议。

### 所属接口类
- [MediaEngine](/zh-CN/api-reference/rtc/flutter/rtc-interface-class#class_imediaengine)

<a id="callback_ivideoencodedframeobserver_onencodedvideoframereceived"></a>

## onEncodedVideoFrameReceived

报告接收端已收到远端发送的待解码视频帧。

<a id="callback_ivideoencodedframeobserver_onencodedvideoframereceived__prototype"></a>

```dart
final void Function(String channelId, int uid, Uint8List imageBuffer, int length,
      EncodedVideoFrameInfo videoEncodedFrameInfo)? onEncodedVideoFrameReceived;
```

<a id="callback_ivideoencodedframeobserver_onencodedvideoframereceived__detailed_desc"></a>

调用 [setRemoteVideoSubscriptionOptions](/zh-CN/api-reference/rtc/flutter/publishnsubscribe#api_irtcengine_setremotevideosubscriptionoptions) 方法并将 `encodedFrameOnly` 设置为 true 时，SDK 会在本地触发该回调，上报接收到的编码后视频帧信息。

<a id="callback_ivideoencodedframeobserver_onencodedvideoframereceived__parameters"></a>

### 参数

#### `channelId`

频道名。

#### `uid`

远端用户 ID。

#### `imageBuffer`

视频图像 buffer。

#### `length`

视频图像的数据长度。

#### `videoEncodedFrameInfo`

编码后的视频帧信息，详见 [EncodedVideoFrameInfo](/zh-CN/api-reference/rtc/flutter/class-encodedvideoframeinfo)。

### 所属接口类
- [VideoEncodedFrameObserver](/zh-CN/api-reference/rtc/flutter/rtc-interface-class#class_ivideoencodedframeobserver)
