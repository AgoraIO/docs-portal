## setAINSMode

设置是否开启 AI 降噪功能并设置降噪模式。

<a id="api_irtcengine_setainsmode__prototype"></a>

```text
Future<void> setAINSMode(
      {required bool enabled, required AudioAinsMode mode});
```

<a id="api_irtcengine_setainsmode__detailed_desc"></a>

你可以调用开方法来开启 AI 降噪功能。该功能可以在保证语音质量的前提下，智能化检测并降低周围环境中多种稳态与非稳态噪声，使人声更加清晰。
稳态噪声指在任何时间点上都具有相同频率的噪声，常见的稳态噪声有：

- 电视机噪声
- 空调噪声
- 工厂机器噪声等

非稳态噪声是指随时间而快速变化的噪声，常见的非稳态噪声有：

- 雷声
- 爆炸声
- 破裂声等

:::note
注：

- 该方法依赖于 AI 降噪动态库，如果删除该动态库会导致无法正常开启该功能。AI 降噪动态库名称见[插件列表](/zh-CN/realtime-media/rtc/build/optimize-and-operate/reduce-app-size)。
- 目前暂不推荐在 Android 6.0 及以下版本的设备上开启该功能。
:::

<a id="api_irtcengine_setainsmode__scenario"></a>

### 适用场景

在语音连麦、在线教育、在线会议等场景中，如果周围环境比较嘈杂，AI 降噪功能可以在保证语音质量的前提下，识别并降低周围的稳态噪声和非稳态噪声，提高语音质量和体验。

## setAudioEffectParameters

设置 SDK 预设人声音效的参数。

<a id="api_irtcengine_setaudioeffectparameters__prototype"></a>

```text
Future<void> setAudioEffectParameters(
  {required AudioEffectPreset preset,
  required int param1,
  required int param2});
```

<a id="api_irtcengine_setaudioeffectparameters__detailed_desc"></a>

调用该方法可以对本地发流用户进行如下设置：

- 3D 人声音效：设置 3D 人声音效的环绕周期。
- 电音音效：设置电音音效的基础调式和主音音高。为方便用户自行调节电音音效，建议你将基础调式和主音音高配置选项与应用的 UI 元素绑定。

设置后，频道内所有用户都能听到该效果。为获取更好的人声效果，建议你在调用该方法前进行以下操作：

- 调用 [setAudioScenario](/zh-CN/api-reference/rtc/flutter/audio/audio-basic#api_irtcengine_setaudioscenario) 将音频场景设为高音质场景，即 `audioScenarioGameStreaming`(3)。
- 调用 [setAudioProfile](/zh-CN/api-reference/rtc/flutter/audio/audio-basic#api_irtcengine_setaudioprofile) 将 `profile` 设为 `audioProfileMusicHighQuality`(4) 或 `audioProfileMusicHighQualityStereo`(5)。

:::note
注：

- 该方法在加入频道前后都能调用。
- 请勿将 [setAudioProfile](/zh-CN/api-reference/rtc/flutter/audio/audio-basic#api_irtcengine_setaudioprofile) 的 `profile` 参数设置为 `audioProfileSpeechStandard`(1) 或 `audioProfileIot`(6)，否则该方法不生效。
- 该方法对人声的处理效果最佳，不建议调用该方法处理含音乐的音频数据。
- 调用 [setAudioEffectParameters](/zh-CN/api-reference/rtc/flutter/audio/audio-prenpost/audio-effect#api_irtcengine_setaudioeffectparameters) 后，不建议调用以下方法，否则 [setAudioEffectParameters](/zh-CN/api-reference/rtc/flutter/audio/audio-prenpost/audio-effect#api_irtcengine_setaudioeffectparameters) 设置的效果会被覆盖：

  - [setAudioEffectPreset](/zh-CN/api-reference/rtc/flutter/audio/audio-prenpost/audio-effect#api_irtcengine_setaudioeffectpreset)
  - [setVoiceBeautifierPreset](/zh-CN/api-reference/rtc/flutter/audio/audio-prenpost/audio-effect#api_irtcengine_setvoicebeautifierpreset)
  - [setLocalVoicePitch](/zh-CN/api-reference/rtc/flutter/audio/audio-prenpost/audio-effect#api_irtcengine_setlocalvoicepitch)
  - [setLocalVoiceEqualization](/zh-CN/api-reference/rtc/flutter/audio/audio-prenpost/audio-effect#api_irtcengine_setlocalvoiceequalization)
  - [setLocalVoiceReverb](/zh-CN/api-reference/rtc/flutter/audio/audio-prenpost/audio-effect#api_irtcengine_setlocalvoicereverb)
  - [setVoiceBeautifierParameters](/zh-CN/api-reference/rtc/flutter/audio/audio-prenpost/audio-effect#api_irtcengine_setvoicebeautifierparameters)
  - [setVoiceConversionPreset](/zh-CN/api-reference/rtc/flutter/audio/audio-prenpost/audio-effect#api_irtcengine_setvoiceconversionpreset)
- 该方法依赖于美声动态库 `libagora_audio_beauty_extension.dll`，如果删除该动态库会导致无法正常开启该功能。
:::

<a id="api_irtcengine_setaudioeffectparameters__parameters"></a>

### 参数

<ParameterList>
<a id="preset"></a>
<Parameter name="preset">

SDK 预设的音效，支持以下设置：

- `roomAcoustics3dVoice`，3D 人声音效。

  - 你需要在使用该枚举前将 [setAudioProfile](/zh-CN/api-reference/rtc/flutter/audio/audio-basic#api_irtcengine_setaudioprofile) 的 `profile` 参数设置 为 `audioProfileMusicStandardStereo`(3) 或 `audioProfileMusicHighQualityStereo`(5)，否则该枚举设置无效。
  - 启用 3D 人声后，用户需要使用支持双声道的音频播放设备才能听到预期效果。
- `pitchCorrection`，电音音效。

</Parameter>
<a id="param1"></a>
<Parameter name="param1">

- 如果 `preset` 设为 `roomAcoustics3dVoice`，则 `param1` 表示 3D 人声音效的环绕周期。取值范围为 [1,60]，单位为秒。默认值为 10，表示人声会 10 秒环绕 360 度。
- 如果 `preset` 设为 `pitchCorrection`，则 `param1` 表示电音音效的基础调式：

  - `1`: （默认）自然大调。
  - `2`: 自然小调。
  - `3`: 和风小调。

</Parameter>
<a id="param2"></a>
<Parameter name="param2">

- 如果 `preset` 设为 `roomAcoustics3dVoice`，你需要将 `param2` 设置为 `0`。
- 如果 `preset` 设为 `pitchCorrection`，则 `param2` 表示电音音效的主音音高：

  - `1`: A
  - `2`: A#
  - `3`: B
  - `4`: (Default) C
  - `5`: C#
  - `6`: D
  - `7`: D#
  - `8`: E
  - `9`: F
  - `10`: F#
  - `11`: G
  - `12`: G#

</Parameter>
</ParameterList>

## setVoiceBeautifierParameters

设置预设美声效果的参数。

<a id="api_irtcengine_setvoicebeautifierparameters__prototype"></a>

```text
Future<void> setVoiceBeautifierParameters(
  {required VoiceBeautifierPreset preset,
  required int param1,
  required int param2});
```

<a id="api_irtcengine_setvoicebeautifierparameters__detailed_desc"></a>

调用该方法可以设置歌唱美声效果的性别特征和混响效果。该方法对本地发流用户进行设置。设置后，频道内所有用户都能听到该效果。
为获取更好的人声效果，建议你在调用该方法前进行以下操作：

- 调用 [setAudioScenario](/zh-CN/api-reference/rtc/flutter/audio/audio-basic#api_irtcengine_setaudioscenario) 将音频场景设为高音质场景，即 `audioScenarioGameStreaming`(3)。
- 调用 [setAudioProfile](/zh-CN/api-reference/rtc/flutter/audio/audio-basic#api_irtcengine_setaudioprofile) 将 `profile` 设为 `audioProfileMusicHighQuality`(4) 或 `audioProfileMusicHighQualityStereo`(5)。

:::note
注：

- 该方法在加入频道前后都能调用。
- 请勿将 [setAudioProfile](/zh-CN/api-reference/rtc/flutter/audio/audio-basic#api_irtcengine_setaudioprofile) 的 `profile` 参数设置为 `audioProfileSpeechStandard`(1) 或 `audioProfileIot`(6)，否则该方法不生效。
- 该方法对人声的处理效果最佳，不建议调用该方法处理含音乐的音频数据。
- 调用 [setVoiceBeautifierParameters](/zh-CN/api-reference/rtc/flutter/audio/audio-prenpost/audio-effect#api_irtcengine_setvoicebeautifierparameters)，不建议调用以下方法，否则 [setVoiceBeautifierParameters](/zh-CN/api-reference/rtc/flutter/audio/audio-prenpost/audio-effect#api_irtcengine_setvoicebeautifierparameters) 设置的效果会被覆盖：

  - [setAudioEffectPreset](/zh-CN/api-reference/rtc/flutter/audio/audio-prenpost/audio-effect#api_irtcengine_setaudioeffectpreset)
  - [setAudioEffectParameters](/zh-CN/api-reference/rtc/flutter/audio/audio-prenpost/audio-effect#api_irtcengine_setaudioeffectparameters)
  - [setVoiceBeautifierPreset](/zh-CN/api-reference/rtc/flutter/audio/audio-prenpost/audio-effect#api_irtcengine_setvoicebeautifierpreset)
  - [setLocalVoicePitch](/zh-CN/api-reference/rtc/flutter/audio/audio-prenpost/audio-effect#api_irtcengine_setlocalvoicepitch)
  - [setLocalVoiceEqualization](/zh-CN/api-reference/rtc/flutter/audio/audio-prenpost/audio-effect#api_irtcengine_setlocalvoiceequalization)
  - [setLocalVoiceReverb](/zh-CN/api-reference/rtc/flutter/audio/audio-prenpost/audio-effect#api_irtcengine_setlocalvoicereverb)
  - [setVoiceConversionPreset](/zh-CN/api-reference/rtc/flutter/audio/audio-prenpost/audio-effect#api_irtcengine_setvoiceconversionpreset)
- 该方法依赖于美声动态库 `libagora_audio_beauty_extension.dll`，如果删除该动态库会导致无法正常开启该功能。
