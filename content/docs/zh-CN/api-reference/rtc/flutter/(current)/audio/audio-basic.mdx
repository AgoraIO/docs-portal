## adjustPlaybackSignalVolume

调节本地播放的所有远端用户信号音量。

<a id="api_irtcengine_adjustplaybacksignalvolume__prototype"></a>

```text
Future<void> adjustPlaybackSignalVolume(int volume);
```

<a id="api_irtcengine_adjustplaybacksignalvolume__detailed_desc"></a>

该方法用于调节所有远端用户混音后在本地播放的信号音量，如果你需要调节指定远端用户在本地播放的信号音量，建议你调用 [adjustUserPlaybackSignalVolume](/zh-CN/api-reference/rtc/flutter/audio/audio-basic#api_irtcengine_adjustuserplaybacksignalvolume)。

<a id="api_irtcengine_adjustplaybacksignalvolume__timing"></a>

### 调用时机

加入频道前后均可调用。

<a id="api_irtcengine_adjustplaybacksignalvolume__parameters"></a>

### 参数

<ParameterList>
<a id="volume"></a>
<Parameter name="volume">

音量，取值范围为 [0,400]。

- 0: 静音。
- 100: （默认）原始音量。
- 400: 原始音量的 4 倍，自带溢出保护。

</Parameter>
</ParameterList>

<a id="api_irtcengine_adjustplaybacksignalvolume__return_values"></a>

### 返回值

方法成功调用时，无返回值；方法调用失败时，会抛出 [AgoraRtcException](/zh-CN/api-reference/rtc/flutter/class-agorartcexception) 异常，你需要捕获异常并进行处理。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。

## disableAudio

关闭音频模块。

<a id="api_irtcengine_disableaudio__prototype"></a>

```text
Future<void> disableAudio();
```

<a id="api_irtcengine_disableaudio__detailed_desc"></a>

音频模块默认开启，你可以调用该方法关闭音频模块。

:::note
注： 该方法重置整个引擎，响应时间较慢，因此声网建议使用如下方法来控制音频模块：

- [enableLocalAudio](/zh-CN/api-reference/rtc/flutter/audio/audio-capture#api_irtcengine_enablelocalaudio)：是否启动麦克风采集并创建本地音频流。
- [enableLoopbackRecording](/zh-CN/api-reference/rtc/flutter/audio/audio-capture#api_irtcengine_enableloopbackrecording)：是否开启声卡采集。
- [muteLocalAudioStream](/zh-CN/api-reference/rtc/flutter/publishnsubscribe#api_irtcengine_mutelocalaudiostream)：是否发布本地音频流。
- [muteRemoteAudioStream](/zh-CN/api-reference/rtc/flutter/publishnsubscribe#api_irtcengine_muteremoteaudiostream)：是否接收并播放远端音频流。
- [muteAllRemoteAudioStreams](/zh-CN/api-reference/rtc/flutter/publishnsubscribe#api_irtcengine_muteallremoteaudiostreams)：是否接收并播放所有远端音频流。
:::

### 调用时机

## enableAudio

启用音频模块。

<a id="api_irtcengine_enableaudio__prototype"></a>

```text
Future<void> enableAudio();
```

<a id="api_irtcengine_enableaudio__detailed_desc"></a>

音频模块默认开启。如果你调用 [disableAudio](/zh-CN/api-reference/rtc/flutter/audio/audio-basic#api_irtcengine_disableaudio) 关闭了音频模块，可调用该方法重新开启。

:::note
注：

- 调用该方法会重置整个引擎，响应时间较慢。你可以根据实际需求用以下方法来独立控制音频模块的某一项功能：

  - [enableLocalAudio](/zh-CN/api-reference/rtc/flutter/audio/audio-capture#api_irtcengine_enablelocalaudio): 是否启动麦克风采集并创建本地音频流。
  - [muteLocalAudioStream](/zh-CN/api-reference/rtc/flutter/publishnsubscribe#api_irtcengine_mutelocalaudiostream): 是否发布本地音频流。
  - [muteRemoteAudioStream](/zh-CN/api-reference/rtc/flutter/publishnsubscribe#api_irtcengine_muteremoteaudiostream): 是否接收并播放远端音频流。
  - [muteAllRemoteAudioStreams](/zh-CN/api-reference/rtc/flutter/publishnsubscribe#api_irtcengine_muteallremoteaudiostreams): 是否接收并播放所有远端音频流。
- 在频道内调用该方法时，会重置 [enableLocalAudio](/zh-CN/api-reference/rtc/flutter/audio/audio-capture#api_irtcengine_enablelocalaudio)、[muteRemoteAudioStream](/zh-CN/api-reference/rtc/flutter/publishnsubscribe#api_irtcengine_muteremoteaudiostream) 和 [muteAllRemoteAudioStreams](/zh-CN/api-reference/rtc/flutter/publishnsubscribe#api_irtcengine_muteallremoteaudiostreams) 的设置，需谨慎使用。

## enableAudioVolumeIndication

启用用户音量提示。

<a id="api_irtcengine_enableaudiovolumeindication__prototype"></a>

```text
Future<void> enableAudioVolumeIndication(
    {required int interval, required int smooth, required bool reportVad});
```

<a id="api_irtcengine_enableaudiovolumeindication__detailed_desc"></a>

该方法允许 SDK 定期向 App 报告本地发流用户和瞬时音量最高的远端用户（最多 3 位）的音量相关信息。

<a id="api_irtcengine_enableaudiovolumeindication__timing"></a>

### 调用时机

加入频道前后均可调用。

<a id="api_irtcengine_enableaudiovolumeindication__related"></a>

### 相关回调

成功调用该方法、且频道内存在发流用户时，SDK 会按设置的时间间隔触发 [onAudioVolumeIndication](/zh-CN/api-reference/rtc/flutter/audio/audio-basic#callback_irtcengineeventhandler_onaudiovolumeindication) 回调。

<a id="api_irtcengine_enableaudiovolumeindication__parameters"></a>

### 参数

<ParameterList>
<a id="interval"></a>
<Parameter name="interval">

指定音量提示的时间间隔：

- ≤ 0: 禁用音量提示功能。
- &gt; 0: 返回音量提示的间隔，单位为毫秒。建议设置到大于 100 毫秒，不得小于 10 毫秒，否则会收不到 [onAudioVolumeIndication](/zh-CN/api-reference/rtc/flutter/audio/audio-basic#callback_irtcengineeventhandler_onaudiovolumeindication) 回调。

</Parameter>
<a id="smooth"></a>
<Parameter name="smooth">

平滑系数，指定音量提示的灵敏度。取值范围为 [0,10]，建议值为 3。数字越大，波动越灵敏；数字越小，波动越平滑。

</Parameter>
<a id="reportvad"></a>
<Parameter name="reportVad">

- true：开启本地人声检测功能。开启后，[onAudioVolumeIndication](/zh-CN/api-reference/rtc/flutter/audio/audio-basic#callback_irtcengineeventhandler_onaudiovolumeindication) 回调的 `vad` 参数会报告是否在本地检测到人声。
- false：（默认）关闭本地人声检测功能。除引擎自动进行本地人声检测的场景外，[onAudioVolumeIndication](/zh-CN/api-reference/rtc/flutter/audio/audio-basic#callback_irtcengineeventhandler_onaudiovolumeindication) 回调的 `vad` 参数不会报告是否在本地检测到人声。

</Parameter>
</ParameterList>

<a id="api_irtcengine_enableaudiovolumeindication__return_values"></a>

### 返回值

方法成功调用时，无返回值；方法调用失败时，会抛出 [AgoraRtcException](/zh-CN/api-reference/rtc/flutter/class-agorartcexception) 异常，你需要捕获异常并进行处理。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。

### 所属接口类

- [RtcEngine](/zh-CN/api-reference/rtc/flutter/rtc-interface-class#class_irtcengine)

## onUserMuteAudio

远端用户（通信场景）/主播（直播场景）停止或恢复发送音频流回调。

<a id="callback_irtcengineeventhandler_onusermuteaudio__prototype"></a>

```text
final void Function(RtcConnection connection, int remoteUid, bool muted)?
      onUserMuteAudio;
```

<a id="callback_irtcengineeventhandler_onusermuteaudio__detailed_desc"></a>

该回调是由远端用户调用 [muteLocalAudioStream](/zh-CN/api-reference/rtc/flutter/publishnsubscribe#api_irtcengine_mutelocalaudiostream) 方法关闭或开启音频发送触发的。

:::note
注： 频道内的用户（通信场景）或主播（直播场景）人数超过 32 人时，该回调可能不准确。
:::
