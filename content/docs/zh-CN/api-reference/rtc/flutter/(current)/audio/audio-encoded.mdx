## registerAudioEncodedFrameObserver

注册音频编码数据观测器。

<a id="api_irtcengine_registeraudioencodedframeobserver__prototype"></a>

```dart
void registerAudioEncodedFrameObserver(
      {required AudioEncodedFrameObserverConfig config,
      required AudioEncodedFrameObserver observer});
```

<a id="api_irtcengine_registeraudioencodedframeobserver__detailed_desc"></a>

:::info[注]
- 请在加入频道后调用该方法。
- 由于该方法和 [startAudioRecording](/zh-CN/api-reference/rtc/flutter/recording#api_irtcengine_startaudiorecording3) 都会设置音频内容和音质，不建议该方法和 [startAudioRecording](/zh-CN/api-reference/rtc/flutter/recording#api_irtcengine_startaudiorecording3) 一起使用。否则，只有后调用的方法会生效。
:::

<a id="api_irtcengine_registeraudioencodedframeobserver__parameters"></a>

### 参数

#### `config`

编码后音频的观测器设置。详见 [AudioEncodedFrameObserverConfig](/zh-CN/api-reference/rtc/flutter/class-audioencodedframeobserverconfig)。

#### `observer`

编码后音频的观测器。详见 [AudioEncodedFrameObserver](/zh-CN/api-reference/rtc/flutter/rtc-interface-class#class_iaudioencodedframeobserver)。

<a id="api_irtcengine_registeraudioencodedframeobserver__return_values"></a>

### 返回值

方法成功调用时，无返回值；方法调用失败时，会抛出 [AgoraRtcException](/zh-CN/api-reference/rtc/flutter/class-agorartcexception) 异常，你需要捕获异常并进行处理。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/flutter/error-code)了解详情和解决建议。

- [RtcEngine](/zh-CN/api-reference/rtc/flutter/rtc-interface-class#class_irtcengine)

## onMixedAudioEncodedFrame

获取本地和所有远端用户混音后的音频编码数据。

<a id="callback_iaudioencodedframeobserver_onmixedaudioencodedframe__prototype"></a>

```dart
final void Function(Uint8List frameBuffer, int length,
      EncodedAudioFrameInfo audioEncodedFrameInfo)? onMixedAudioEncodedFrame;
```

<a id="callback_iaudioencodedframeobserver_onmixedaudioencodedframe__detailed_desc"></a>

调用 [registerAudioEncodedFrameObserver](/zh-CN/api-reference/rtc/flutter/audio/audio-encoded#api_irtcengine_registeraudioencodedframeobserver) 并将音频编码内容设为 audioEncodedFrameObserverPositionMixed 后，你可以通过该回调获取本地和所有远端用户混音、编码后的音频数据。

<a id="callback_iaudioencodedframeobserver_onmixedaudioencodedframe__parameters"></a>

### 参数

#### `frameBuffer`

音频 buffer。

#### `length`

音频数据长度，单位为字节。

#### `audioEncodedFrameInfo`

编码后音频的信息。详见 [EncodedAudioFrameInfo](/zh-CN/api-reference/rtc/flutter/class-encodedaudioframeinfo)。

- [AudioEncodedFrameObserver](/zh-CN/api-reference/rtc/flutter/rtc-interface-class#class_iaudioencodedframeobserver)
