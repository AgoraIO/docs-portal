<a id="class_videoformat__prototype"></a>

```dart
class VideoFormat {
  const VideoFormat({this.width, this.height, this.fps});

  @JsonKey(name: 'width')
  final int? width;
  @JsonKey(name: 'height')
  final int? height;
  @JsonKey(name: 'fps')
  final int? fps;
  factory VideoFormat.fromJson(Map<String, dynamic> json) =>
      _$VideoFormatFromJson(json);
  Map<String, dynamic> toJson() => _$VideoFormatToJson(this);
}
```

<a id="class_videoformat__parameters"></a>

## 属性

### `width`

视频帧的宽度（px）。默认值为 960。

### `height`

视频帧的高度（px）。默认值为 540.

### `fps`

视频帧的帧率。默认值为 15。
