<a id="enum_degradationpreference__parameters"></a>

## 枚举值

<ParameterList>
<a id="maintain_auto"></a>
<Parameter name="MAINTAIN_AUTO">

（-1）：自动模式（默认）。SDK 会根据设置的视频场景自动选择 `MAINTAIN_FRAMERATE`、`MAINTAIN_BALANCED` 或 `MAINTAIN_RESOLUTION`，以实现最佳的整体体验质量（QoE）。

</Parameter>
<a id="maintain_quality"></a>
<Parameter name="MAINTAIN_QUALITY">

（0）：在带宽受限的视频编码过程中，优先降低帧率以保持分辨率。适用于对画质要求较高的场景。

</Parameter>
<a id="maintain_framerate"></a>
<Parameter name="MAINTAIN_FRAMERATE">

（1）：在带宽受限的视频编码过程中，优先降低分辨率以保持帧率。适用于对流畅度要求较高且可接受画质降低的场景。

</Parameter>
<a id="maintain_balanced"></a>
<Parameter name="MAINTAIN_BALANCED">

（2）：在带宽受限的视频编码过程中，同时降低帧率和分辨率。降级程度低于 `MAINTAIN_QUALITY` 和 `MAINTAIN_FRAMERATE`，适用于对流畅度和画质均有要求的场景。

:::note
注： 发送端视频的分辨率可能会发生变化，远端用户需要处理该问题。详见 [onVideoSizeChanged](/zh-CN/api-reference/rtc/cpp-all-platforms/video/video-basic#callback_irtcengineeventhandler_onvideosizechanged)。
:::

</Parameter>
<a id="maintain_resolution"></a>
<Parameter name="MAINTAIN_RESOLUTION">

（3）：在带宽受限的视频编码过程中，优先降低帧率以保持分辨率。适用于对画质要求较高的场景。

</Parameter>
<a id="disabled"></a>
<Parameter name="DISABLED">

（100）：关闭 VQC 调整功能。

</Parameter>
</ParameterList>
