## 枚举值

### `BLUR_DEGREE_LOW`

（1）：对自定义背景图像应用低强度模糊处理，用户几乎可以清晰看到背景。

### `BLUR_DEGREE_MEDIUM`

（2）：对自定义背景图像应用中等强度模糊处理，用户难以识别背景细节。

### `BLUR_DEGREE_HIGH`

（3）：（默认）对自定义背景图像应用高强度模糊处理，用户几乎无法辨识背景特征。
