## addOrUpdateVideoEffect

添加或更新指定视频特效节点和模板的特效。

<a id="api_ivideoeffectobject_addorupdatevideoeffect__prototype"></a>

```text
virtual int addOrUpdateVideoEffect(uint32_t nodeId, const char* templateName) = 0;
```

<a id="api_ivideoeffectobject_addorupdatevideoeffect__detailed_desc"></a>

### 自从

自 v4.6.0 版本新增。

:::note
注： 优先级规则：

- 风格妆 (`VIDEO_EFFECT_NODE_ID::STYLE_MAKEUP`) 节点优先于滤镜特效 (`VIDEO_EFFECT_NODE_ID::FILTER`) 节点。
- 若要应用滤镜特效，必须先移除风格妆特效节点：

```text
removeVideoEffect(VIDEO_EFFECT_NODE_ID::STYLE_MAKEUP);
addOrUpdateVideoEffect(VIDEO_EFFECT_NODE_ID::FILTER, "template name");
```
:::

<a id="api_ivideoeffectobject_addorupdatevideoeffect__parameters"></a>

### 参数

### nodeId

视频特效节点的唯一标识符或标识符组合。详见 [VIDEO_EFFECT_NODE_ID](/zh-CN/api-reference/rtc/cpp-all-platforms/enum-videoeffectnodeid)。
示例：

- 单一特效：`VIDEO_EFFECT_NODE_ID::BEAUTY`
- 组合特效：`VIDEO_EFFECT_NODE_ID::BEAUTY | VIDEO_EFFECT_NODE_ID::STYLE_MAKEUP`

### templateName

特效模板名称。如果设置为 NULL 或空字符串，SDK 会从资源包中加载默认配置。

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。

## setColorEnhanceOptions

设置视频色彩增强效果。

<a id="api_irtcengine_setcolorenhanceoptions__prototype"></a>

```text
virtual int setColorEnhanceOptions(bool enabled, const ColorEnhanceOptions& options, agora::media::MEDIA_SOURCE_TYPE type = agora::media::PRIMARY_CAMERA_SOURCE) = 0;
```

<a id="api_irtcengine_setcolorenhanceoptions__detailed_desc"></a>

### 自从

自 v4.0.0 版本新增。

摄像头采集的视频图像可能存在色彩失真。色彩增强功能可智能调整视频的饱和度和对比度等特性，从而增强视频的色彩丰富度和还原度，使画面更加生动。

:::note
注：

- 请在调用 [enableVideo](/zh-CN/api-reference/rtc/cpp-all-platforms/video/video-basic#api_irtcengine_enablevideo) 方法后调用此方法。
- 色彩增强功能对设备性能有一定要求。开启该功能后，如设备出现严重发热，声网建议你降低色彩增强等级以减少性能消耗，或关闭该功能。
- 此方法依赖美颜特效动态库 libagora_clear_vision_extension.dll。若该动态库被删除，将无法正常启用该功能。
:::

<a id="api_irtcengine_setcolorenhanceoptions__parameters"></a>

### 参数

### enabled

是否开启色彩增强功能：

- true：开启色彩增强。
- false：（默认）关闭色彩增强。

### options

色彩增强选项。详见 [ColorEnhanceOptions](/zh-CN/api-reference/rtc/cpp-all-platforms/class-colorenhanceoptions)。

### type

媒体源类型。详见 [MEDIA_SOURCE_TYPE](/zh-CN/api-reference/rtc/cpp-all-platforms/enum-mediasourcetype)。

- 使用摄像头采集本地视频时，使用默认值 `PRIMARY_CAMERA_SOURCE`。
- 使用自定义视频源时，设置为 `CUSTOM_VIDEO_SOURCE`。
