## registerVideoEncodedFrameObserver

注册用于接收编码后视频帧的观察器对象。

<a id="api_imediaengine_registervideoencodedframeobserver_imediaengine__prototype"></a>

```cpp
virtual int registerVideoEncodedFrameObserver(IVideoEncodedFrameObserver* observer) = 0;
```

<a id="api_imediaengine_registervideoencodedframeobserver_imediaengine__detailed_desc"></a>

如果你只需要监听编码后的视频帧（例如 H.264 格式），而不进行解码和渲染，建议通过此方法注册一个自定义的 [IVideoEncodedFrameObserver](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_ivideoencodedframeobserver) 实例。

:::info[注]
请在加入频道前调用此方法。
:::

<a id="api_imediaengine_registervideoencodedframeobserver_imediaengine__parameters"></a>

### 参数

#### `observer`

编码后视频帧观察器对象。详见 [IVideoEncodedFrameObserver](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_ivideoencodedframeobserver)。

<a id="api_imediaengine_registervideoencodedframeobserver_imediaengine__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/windows/error-code)了解详情和解决建议。

- [IMediaEngine](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_imediaengine)

## onEncodedVideoFrameReceived

报告接收端已接收到远端发送的待解码视频帧。

<a id="callback_ivideoencodedframeobserver_onencodedvideoframereceived__prototype"></a>

```cpp
virtual bool onEncodedVideoFrameReceived(const char* channelId, rtc::uid_t uid, const uint8_t* imageBuffer, size_t length, const rtc::EncodedVideoFrameInfo& videoEncodedFrameInfo) = 0;
```

<a id="callback_ivideoencodedframeobserver_onencodedvideoframereceived__detailed_desc"></a>

#### `自从`

自 v4.6.0 版本新增。

如果你调用了 [setRemoteVideoSubscriptionOptions](/zh-CN/api-reference/rtc/cpp-all-platforms/publishnsubscribe#api_irtcengine_setremotevideosubscriptionoptions) 方法并将 `encodedFrameOnly` 设置为 true，SDK 会在本地触发该回调，报告接收到的编码视频帧信息。

<a id="callback_ivideoencodedframeobserver_onencodedvideoframereceived__parameters"></a>

### 参数

#### `channelId`

频道名。

#### `uid`

远端用户 ID。

#### `imageBuffer`

编码后的视频图像缓冲区。

#### `length`

视频图像的数据长度。

#### `videoEncodedFrameInfo`

编码视频帧的信息。详见 [EncodedVideoFrameInfo](/zh-CN/api-reference/rtc/cpp-all-platforms/class-encodedvideoframeinfo)。

<a id="callback_ivideoencodedframeobserver_onencodedvideoframereceived__return_values"></a>

### 返回值

- true：回调处理成功。
- false：回调处理失败。

- [IVideoEncodedFrameObserver](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_ivideoencodedframeobserver)
