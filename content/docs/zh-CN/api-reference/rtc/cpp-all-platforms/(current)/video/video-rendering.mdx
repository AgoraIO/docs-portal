## enableInstantMediaRendering

启用音视频帧的极速渲染。

<a id="api_irtcengine_enableinstantmediarendering__prototype"></a>

```cpp
virtual int enableInstantMediaRendering() = 0;
```

<a id="api_irtcengine_enableinstantmediarendering__detailed_desc"></a>

#### `自从`

自 v4.1.1 版本新增。

调用该方法后，SDK 会启用极速帧渲染模式，从而加快用户加入频道后首帧的渲染速度。

:::info[注]
主播和观众都需要调用该方法，才能体验音视频帧的极速渲染。如需关闭该模式，只能通过调用 [release](/zh-CN/api-reference/rtc/cpp-all-platforms/initialize#api_irtcengine_release) 销毁 [IRtcEngine](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_irtcengine) 对象。
:::

<a id="api_irtcengine_enableinstantmediarendering__scenario"></a>

### 适用场景

声网建议在直播场景中为观众开启该模式。

<a id="api_irtcengine_enableinstantmediarendering__timing"></a>

### 调用时机

该方法需要在加入频道前调用。

<a id="api_irtcengine_enableinstantmediarendering__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/windows/error-code)了解详情和解决建议。
  - -7：在 IRtcEngine 初始化之前调用了该方法。

### 所属接口类
- [IRtcEngine](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_irtcengine)

## setLocalRenderTargetFps

设置本地视频渲染的最大帧率。

<a id="api_irtcengine_setlocalrendertargetfps__prototype"></a>

```cpp
virtual int setLocalRenderTargetFps(VIDEO_SOURCE_TYPE sourceType, int targetFps) = 0;
```

<a id="api_irtcengine_setlocalrendertargetfps__detailed_desc"></a>

<a id="api_irtcengine_setlocalrendertargetfps__scenario"></a>

### 适用场景

在对视频渲染帧率要求不高的场景（如屏幕共享或在线教育）中，你可以调用该方法设置本地视频渲染的最大帧率。SDK 会尝试将本地渲染的实际帧率保持在该值附近，以降低 CPU 消耗并提升系统性能。

<a id="api_irtcengine_setlocalrendertargetfps__timing"></a>

### 调用时机

你可以在加入频道前或加入频道后调用该方法。

<a id="api_irtcengine_setlocalrendertargetfps__parameters"></a>

### 参数

#### `sourceType`

视频源类型，详见 [VIDEO_SOURCE_TYPE](/zh-CN/api-reference/rtc/cpp-all-platforms/enum-videosourcetype)。

#### `targetFps`

本地视频的采集帧率（fps）。支持的值包括：1、7、10、15、24、30、60。

:::info[注]
将该参数设置为低于实际视频帧率的值，否则设置无效。
:::

<a id="api_irtcengine_setlocalrendertargetfps__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/windows/error-code)了解详情和解决建议。

## setupLocalVideo

初始化本地视频画面。

<a id="api_irtcengine_setuplocalvideo__prototype"></a>

```cpp
virtual int setupLocalVideo(const VideoCanvas& canvas) = 0;
```

<a id="api_irtcengine_setuplocalvideo__detailed_desc"></a>

该方法在本地设备上初始化本地视频流的画面视图，仅影响本地用户看到的视频画面，不影响本地视频的发布。你可以调用该方法将本地视频流绑定到指定的视频视图（`view` ），并设置该视图的渲染模式和镜像模式。 绑定关系在离开频道后仍然有效。若需停止渲染或解绑本地视频与视图的绑定关系，可将 `view` 设置为 NULL。 在实时互动场景中，如果你需要在本地视频预览中同时查看多个不同观察位置的画面，可以多次调用该方法，为每个 `view` 设置不同的观察位置。例如，将视频源设置为摄像头后，配置两个 `view`，其 `position` 分别设置为 `POSITION_POST_CAPTURER_ORIGIN` 和 `POSITION_POST_CAPTURER`，即可同时预览原始未处理的视频帧和经过美颜特效、虚拟背景、水印等预处理后的视频帧。

:::info[注]
若仅需在通话中更新本地视频视图的渲染模式或镜像模式，请改用 `setLocalRenderMode`。
:::

<a id="api_irtcengine_setuplocalvideo__scenario"></a>

### 适用场景

初始化后调用该方法设置本地视频，然后加入频道。在实时互动场景中，如需在本地预览中同时查看多个不同观察位置的画面，可多次调用该方法设置不同的 `view` 和观察位置。

<a id="api_irtcengine_setuplocalvideo__timing"></a>

### 调用时机

你可以在加入频道前或后调用该方法。

<a id="api_irtcengine_setuplocalvideo__parameters"></a>

### 参数

#### `canvas`

本地视频视图及相关设置，详见 [VideoCanvas](/zh-CN/api-reference/rtc/cpp-all-platforms/class-videocanvas)。

<a id="api_irtcengine_setuplocalvideo__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/windows/error-code)了解详情和解决建议。

## setupRemoteVideo

初始化远端用户的视频视图。

<a id="api_irtcengine_setupremotevideo__prototype"></a>

```cpp
virtual int setupRemoteVideo(const VideoCanvas& canvas) = 0;
```

<a id="api_irtcengine_setupremotevideo__detailed_desc"></a>

该方法在本地设备上初始化远端视频流的视频视图，仅影响本地用户所见的视频画面。你可以通过该方法将远端视频流绑定到指定视图，并设置该视图的渲染模式和镜像模式。你需要在调用该方法时指定远端用户的 ID。如果应用尚未获取远端用户的 ID，请在收到 [onUserJoined](/zh-CN/api-reference/rtc/cpp-all-platforms/channel#callback_irtcengineeventhandler_onuserjoined) 回调后再设置。若要解绑远端用户与视图的绑定关系，可将 `view` 参数设置为 NULL。当远端用户离开频道时，SDK 会自动解绑该用户。在移动端进行视频合流布局自定义的场景中，你可以调用该方法，并为合流视频流中的每个子视频流设置独立的 `view` 进行渲染。

:::info[注]
- 若需在通话过程中更新远端视频视图的渲染模式或镜像模式，请使用 setRemoteRenderMode 方法。
- 使用录制服务时，应用无需绑定视图，因为录制服务不会发送视频流。如果你的应用无法识别录制服务，请在 SDK 触发 onFirstRemoteVideoDecoded 回调时将远端用户绑定到视图。
:::

### 参数

远端视频视图及其相关设置。详见 [VideoCanvas](/zh-CN/api-reference/rtc/cpp-all-platforms/class-videocanvas)。

### 返回值

- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/windows/error-code)了解详情和解决建议。

## setupRemoteVideoEx

初始化远端用户的视频视图。

<a id="api_irtcengineex_setupremotevideoex__prototype"></a>

```cpp
virtual int setupRemoteVideoEx(const VideoCanvas& canvas, const RtcConnection& connection) = 0;
```

<a id="api_irtcengineex_setupremotevideoex__detailed_desc"></a>

该方法在本地设备上初始化远端视频流的视图，仅影响你本地看到的画面。调用该方法可以将远端视频流绑定到指定视图，并设置该视图的渲染模式和镜像模式。 你需要在远端用户加入频道前，通过 [VideoCanvas](/zh-CN/api-reference/rtc/cpp-all-platforms/class-videocanvas) 设置远端用户的用户 ID。如果你尚未获取远端用户 ID，可以在收到 [onUserJoined](/zh-CN/api-reference/rtc/cpp-all-platforms/channel#callback_irtcengineeventhandler_onuserjoined) 回调后再设置。 如果启用了视频录制功能，录制服务会以虚拟客户端身份加入频道，其他客户端也会因此收到 [onUserJoined](/zh-CN/api-reference/rtc/cpp-all-platforms/channel#callback_irtcengineeventhandler_onuserjoined) 回调。不要将该虚拟客户端绑定到视图，因为它不会发送任何视频流。 若要解除远端用户与视图的绑定，可将 `view` 参数设置为 NULL。当远端用户离开频道后，SDK 会自动解除绑定。

:::info[注]
若需在通话过程中更新远端视频视图的渲染模式或镜像模式，请使用 [setRemoteRenderModeEx](/zh-CN/api-reference/rtc/cpp-all-platforms/video/video-rendering#api_irtcengineex_setremoterendermodeex) 方法。
:::

## startMediaRenderingTracing

启用视频帧渲染过程的追踪功能。

<a id="api_irtcengine_startmediarenderingtracing__prototype"></a>

```cpp
virtual int startMediaRenderingTracing() = 0;
```

<a id="api_irtcengine_startmediarenderingtracing__detailed_desc"></a>

#### `自从`

自 v4.1.1 版本新增。

从成功调用该方法开始，SDK 会追踪频道中视频帧的渲染状态，并通过 [onVideoRenderingTracingResult](/zh-CN/api-reference/rtc/cpp-all-platforms/video/video-rendering#callback_irtcengineeventhandler_onvideorenderingtracingresult) 回调报告相关信息。

:::info[注]
- 如果你未调用该方法，SDK 会从调用 joinChannel 加入频道时开始追踪视频帧的渲染事件。你可以根据实际应用场景在合适的时间调用该方法，以设置追踪视频渲染事件的起始位置。
- 本地用户离开当前频道后，SDK 会自动从你再次加入频道时开始追踪视频渲染事件。
:::

<a id="api_irtcengine_startmediarenderingtracing__scenario"></a>

### 适用场景

你可以结合应用中的 UI 设置（如按钮、滑块）调用该方法，以提升用户体验。例如，在用户点击“加入频道”按钮时调用该方法，然后通过 [onVideoRenderingTracingResult](/zh-CN/api-reference/rtc/cpp-all-platforms/video/video-rendering#callback_irtcengineeventhandler_onvideorenderingtracingresult) 回调获取视频帧渲染过程所耗费的时间，从而优化相关指标。

<a id="api_irtcengine_startmediarenderingtracing__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/windows/error-code)了解详情和解决建议。
  - -7：在初始化 IRtcEngine 之前调用了该方法。

### 所属接口类
- [IRtcEngine](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_irtcengine)
