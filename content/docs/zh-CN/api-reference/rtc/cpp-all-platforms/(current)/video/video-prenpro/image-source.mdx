## enableVideoImageSource

设置在发布视频流时是否用图片替代当前视频画面。

<a id="api_irtcengine_enablevideoimagesource__prototype"></a>

```cpp
virtual int enableVideoImageSource(bool enable, const ImageTrackOptions& options) = 0;
```

<a id="api_irtcengine_enablevideoimagesource__detailed_desc"></a>

你可以调用该方法，在发布视频流时用自定义图片替代当前的视频画面。启用该功能后，可通过 `options` 参数设置用于替代的视频图片。若关闭该功能，远端用户将看到你发布的原始视频画面。

<a id="api_irtcengine_enablevideoimagesource__timing"></a>

### 调用时机

请在加入频道后调用该方法。

<a id="api_irtcengine_enablevideoimagesource__parameters"></a>

### 参数

#### `enable`

是否用自定义图片替代当前视频画面：

- true：用自定义图片替代当前视频画面。
- false：（默认）不替代当前视频画面。

#### `options`

图片配置，详见 [ImageTrackOptions](/zh-CN/api-reference/rtc/cpp-all-platforms/class-imagetrackoptions)。

<a id="api_irtcengine_enablevideoimagesource__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/windows/error-code)了解详情和解决建议。
