## 属性

### id

水印的唯一标识符，建议使用 UUID。

### type

水印类型，详见 [WATERMARK_SOURCE_TYPE](/zh-CN/api-reference/rtc/cpp-all-platforms/enum-watermarksourcetype)。

### buffer

水印的缓冲区。详见 [WatermarkBuffer](/zh-CN/api-reference/rtc/cpp-all-platforms/class-watermarkbuffer)。

### timestamp

水印的时间戳。

:::note
注： 仅支持在 Linux 平台使用。
:::

### literal

水印的文本内容。

:::note
注： 仅支持在 Linux 平台使用。
:::

### imageUrl

水印图像文件的 URL，默认值为 NULL。

### options

水印的配置选项。详见 [WatermarkOptions](/zh-CN/api-reference/rtc/cpp-all-platforms/class-watermarkoptions)。
