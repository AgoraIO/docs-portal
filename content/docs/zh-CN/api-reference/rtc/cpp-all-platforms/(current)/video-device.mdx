## enableMultiCamera

启用或关闭多摄像头采集功能。

<a id="api_irtcengine_enablemulticamera__prototype"></a>

```cpp
virtual int enableMultiCamera(bool enabled, const CameraCapturerConfiguration& config) = 0;
```

<a id="api_irtcengine_enablemulticamera__detailed_desc"></a>

声网建议你在已有摄像头用于视频采集的场景中，按照以下步骤使用多个摄像头进行视频采集和发布：

1. 调用该方法启用多摄像头采集。
2. 调用 `startPreview` 启动本地视频预览。
3. 调用 [startCameraCapture](/zh-CN/api-reference/rtc/cpp-all-platforms/camera-capture#api_irtcengine_startcameracapture)，并设置 `sourceType`，以使用第二个摄像头开始采集。
4. 调用 [joinChannelEx](/zh-CN/api-reference/rtc/cpp-all-platforms/channel#api_irtcengineex_joinchannelex)，并将 `publishSecondaryCameraTrack` 设置为 true，以发布第二个摄像头采集的视频流。

若需关闭多摄像头采集，请按以下步骤操作：

1. 调用 [stopCameraCapture](/zh-CN/api-reference/rtc/cpp-all-platforms/camera-capture#api_irtcengine_stopcameracapture)。
2. 调用该方法并将 `enabled` 设置为 false。

该方法仅适用于 iOS 平台。 使用该功能时，请确保系统版本为 13.0 或更高。 支持多摄像头采集的最低 iOS 设备型号如下：

- iPhone XR。
- iPhone XS。
- iPhone XS Max。
- iPad Pro 第三代及更新机型。

:::info[注]
你可以在调用 `startPreview` 之前或之后调用该方法启用多摄像头采集：

- 如果在调用 `startPreview` 之前启用，则本地视频预览会同时显示两个摄像头采集的画面。
- 如果在调用 `startPreview` 之后启用，SDK 会先停止当前摄像头采集，然后启用主摄像头和第二个摄像头。本地视频预览会短暂变黑，随后自动恢复。
:::

<a id="api_irtcengine_enablemulticamera__parameters"></a>

### 参数

#### `enabled`

是否启用多摄像头视频采集模式：

- true：启用多摄像头采集模式，SDK 使用多个摄像头进行视频采集。
- false：关闭多摄像头采集模式，SDK 使用单个摄像头进行视频采集。

#### `config`

第二个摄像头的采集配置，详见 [CameraCapturerConfiguration](/zh-CN/api-reference/rtc/cpp-all-platforms/class-cameracapturerconfiguration)。

<a id="api_irtcengine_enablemulticamera__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/windows/error-code)了解详情和解决建议。

### 所属接口类
- [IRtcEngine](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_irtcengine)

## enumerateVideoDevices

枚举系统中的视频设备。

<a id="api_ivideodevicemanager_enumeratevideodevices__prototype"></a>

```cpp
virtual IVideoDeviceCollection* enumerateVideoDevices() = 0;
```

<a id="api_ivideodevicemanager_enumeratevideodevices__detailed_desc"></a>

该方法返回一个 [IVideoDeviceCollection](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_ivideodevicecollection) 对象，包含系统中所有可用的视频设备。你可以通过该对象枚举视频设备。使用完该对象后，必须调用 [release](/zh-CN/api-reference/rtc/cpp-all-platforms/video-device#api_ivideodevicemanager_release_ivideodevicemanager) 方法释放资源。

:::info[注]
该方法仅适用于 Windows 和 macOS 平台。
:::

<a id="api_ivideodevicemanager_enumeratevideodevices__return_values"></a>

### 返回值

- 方法调用成功，返回 [IVideoDeviceCollection](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_ivideodevicecollection) 对象，详见 [IVideoDeviceCollection](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_ivideodevicecollection)。
- 方法调用失败，返回 NULL。

## getCapability

获取指定视频格式下的视频采集设备的帧信息。

<a id="api_ivideodevicemanager_getcapability__prototype"></a>

```cpp
virtual int getCapability(const char* deviceIdUTF8, const uint32_t deviceCapabilityNumber, VideoFormat& capability) = 0;
```

<a id="api_ivideodevicemanager_getcapability__detailed_desc"></a>

调用 [numberOfCapabilities](/zh-CN/api-reference/rtc/cpp-all-platforms/video-device#api_ivideodevicemanager_numberofcapabilities) 获取视频采集设备支持的视频格式数量后，可调用该方法获取指定索引对应的视频帧信息。

:::info[注]
该方法仅适用于 Windows 和 macOS 平台。
:::

<a id="api_ivideodevicemanager_getcapability__parameters"></a>

### 参数

#### `deviceIdUTF8`

视频采集设备的 ID。

#### `deviceCapabilityNumber`

视频格式的索引号。若 [numberOfCapabilities](/zh-CN/api-reference/rtc/cpp-all-platforms/video-device#api_ivideodevicemanager_numberofcapabilities) 的返回值为 i，则该参数的取值范围为 [0, i)。

#### `capability`

输出参数，表示指定视频格式的详细信息，包括宽度（px）、高度（px）和帧率（fps）。详见 [VideoFormat](/zh-CN/api-reference/rtc/cpp-all-platforms/class-videoformat)。

<a id="api_ivideodevicemanager_getcapability__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/windows/error-code)了解详情和解决建议。

## numberOfCapabilities

获取指定视频采集设备支持的视频格式数量。

<a id="api_ivideodevicemanager_numberofcapabilities__prototype"></a>

```cpp
virtual int numberOfCapabilities(const char* deviceIdUTF8) = 0;
```

<a id="api_ivideodevicemanager_numberofcapabilities__detailed_desc"></a>

你可以调用该方法获取指定视频采集设备支持的视频格式数量，然后调用 [getCapability](/zh-CN/api-reference/rtc/cpp-all-platforms/video-device#api_ivideodevicemanager_getcapability) 获取对应的视频帧信息。视频采集设备可能支持多种视频格式，每种格式包含不同的视频帧宽度、高度和帧率组合。

:::info[注]

:::info[注]
对于不支持超广角的设备，该值范围为 1.0 到设备支持的最大变焦倍数；对于支持超广角的设备，该值范围为 0.5 到设备支持的最大变焦倍数。

## switchCamera

切换前后摄像头。

<a id="api_irtcengine_switchcamera__prototype"></a>

```cpp
virtual int switchCamera() = 0;
```

<a id="api_irtcengine_switchcamera__detailed_desc"></a>

你可以调用此方法在应用运行过程中根据实际可用的摄像头动态切换前后摄像头，无需重启视频流或重新配置视频源。

:::info[注]
- 此方法仅切换由第一个摄像头采集的视频流的摄像头，即调用 [startCameraCapture](/zh-CN/api-reference/rtc/cpp-all-platforms/camera-capture#api_irtcengine_startcameracapture) 时视频源设置为 `VIDEO_SOURCE_CAMERA` （0）的视频流。
- 此方法仅适用于 Android 和 iOS 平台。
:::

<a id="api_irtcengine_switchcamera__timing"></a>

### 调用时机

必须在摄像头成功启用后调用，即 SDK 触发 [onLocalVideoStateChanged](/zh-CN/api-reference/rtc/cpp-all-platforms/video-basic#callback_irtcengineeventhandler_onlocalvideostatechanged) 回调并返回本地视频状态为 `LOCAL_VIDEO_STREAM_STATE_CAPTURING` （1）之后。

<a id="api_irtcengine_switchcamera__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/windows/error-code)了解详情和解决建议。
