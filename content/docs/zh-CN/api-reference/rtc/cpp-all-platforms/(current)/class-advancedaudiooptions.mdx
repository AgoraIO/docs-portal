<a id="class_advancedaudiooptions__prototype"></a>

```cpp
struct AdvancedAudioOptions {
  Optional<int> audioProcessingChannels;
};
```

<a id="class_advancedaudiooptions__parameters"></a>

## 属性

### `audioProcessingChannels`

用于音频预处理的声道数：

- 1：单声道。
- 2：立体声。
