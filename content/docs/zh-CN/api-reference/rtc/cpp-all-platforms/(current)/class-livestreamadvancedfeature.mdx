```cpp
struct LiveStreamAdvancedFeature {
  const char* featureName;
  bool opened;
};
```

<a id="class_livestreamadvancedfeature__detailed_desc"></a>

如需启用带转码推流的高级功能，请[联系技术支持](https://ticket.shengwang.cn/)。

<a id="class_livestreamadvancedfeature__parameters"></a>

## 属性

### `featureName`

功能名称，包括 LBHQ（低码率高画质）和 VEO（优化的视频编码器）。

### `opened`

是否启用带转码推流的高级功能：

- true：启用高级功能。
- false：（默认）不启用高级功能。
