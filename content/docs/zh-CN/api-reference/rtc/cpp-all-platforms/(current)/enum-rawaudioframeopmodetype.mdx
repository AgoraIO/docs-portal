## 枚举值

### `RAW_AUDIO_FRAME_OP_MODE_READ_ONLY`

（0）：只读模式，用户仅从 [AudioFrame](/zh-CN/api-reference/rtc/cpp-all-platforms/class-audioframe) 中读取原始数据，不进行任何修改。例如，用户通过声网 SDK 获取数据后进行媒体推流。

### `RAW_AUDIO_FRAME_OP_MODE_READ_WRITE`

（2）：读写模式，用户从 [AudioFrame](/zh-CN/api-reference/rtc/cpp-all-platforms/class-audioframe) 中读取数据，修改后再播放。例如，用户使用自有音效处理模块进行语音预处理，如变声。
