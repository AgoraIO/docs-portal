<ParameterList>
<a id="numchannels"></a>

音频通道数。

<Parameter name="sentSampleRate">

本地用户音频流的发送采样率，单位为 Hz。

<a id="sentbitrate"></a>
<Parameter name="sentBitrate">

本地用户音频流的平均发送码率，单位为 Kbps。

<Parameter name="internalCodec">

内部使用的负载编解码器。

</Parameter>

<Parameter name="txPacketLossRate">

应用抗丢包策略前，从本地客户端到声网服务器的音频丢包率，单位为百分比（%）。

</Parameter>
<a id="audiodevicedelay"></a>
<Parameter name="audioDeviceDelay">

播放或录制音频时，音频设备模块的延迟，单位为毫秒。

</Parameter>
<a id="audioplayoutdelay"></a>
<Parameter name="audioPlayoutDelay">

设备的播放延迟，单位为毫秒。

</Parameter>
<a id="earmonitordelay"></a>
<Parameter name="earMonitorDelay">

耳返延迟，单位为毫秒，即从麦克风输入到耳机输出的延迟。

<Parameter name="aecEstimatedDelay">

声学回声消除（AEC）模块估算的延迟，单位为毫秒，即本地播放音频到本地采集之间的信号延迟。

</Parameter>
