<a id="class_playerupdatedinfo__prototype"></a>

```cpp
struct PlayerUpdatedInfo {
  const char* internalPlayerUuid;
  const char* deviceId;
  int videoHeight;
  int videoWidth;
  int audioSampleRate;
  int audioChannels;
  int audioBitsPerSample;
};
```

<a id="class_playerupdatedinfo__parameters"></a>

## 属性

### `deviceId`

设备 ID。

### `videoHeight`

视频高度（单位：像素）。

### `videoWidth`

视频宽度（单位：像素）。

### `audioSampleRate`

音频采样率（单位：Hz）。

### `audioChannels`

音频通道数。

### `audioBitsPerSample`

每个音频采样点的位数。
