## enableExtension

启用或禁用插件。

<a id="api_irtcengine_enableextension__prototype"></a>

```cpp
virtual int enableExtension(const char* provider, const char* extension, const ExtensionInfo& extensionInfo, bool enable = true) = 0;
```

<a id="api_irtcengine_enableextension__detailed_desc"></a>

通过调用该方法，你可以在不更改处理流程的情况下动态启用或禁用插件。例如，启用或禁用 `Extension_A` 表示数据将被 `Extension_A` 处理或绕过。

:::info[注]
出于兼容性考虑，如果你尚未调用 [registerExtension](/zh-CN/api-reference/rtc/cpp-all-platforms/extension#api_irtcengine_registerextension)， [enableExtension](/zh-CN/api-reference/rtc/cpp-all-platforms/extension#api_irtcengine_enableextension) 会自动注册指定的插件。建议你显式调用 [registerExtension](/zh-CN/api-reference/rtc/cpp-all-platforms/extension#api_irtcengine_registerextension)。
:::

<a id="api_irtcengine_enableextension__parameters"></a>

### 参数

#### `provider`

插件提供方的名称，例如 `agora.io`。

#### `extension`

插件名称，例如 `agora.beauty`。

#### `extensionInfo`

`ExtensionInfo` 对象，表示插件的信息。

#### `enable`

是否启用插件：

- true：（默认）启用插件。
- false：禁用插件。

<a id="api_irtcengine_enableextension__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/windows/error-code)了解详情和解决建议。

### 所属接口类

## loadExtensionProvider

加载扩展。

<a id="api_irtcengine_loadextensionprovider__prototype"></a>

```cpp
virtual int loadExtensionProvider(const char* path, bool unload_after_use = false) = 0;
```

<a id="api_irtcengine_loadextensionprovider__detailed_desc"></a>

该方法用于将 SDK 外部的扩展（例如来自云市场或 SDK 扩展）加载到 SDK 中。

:::info[注]
如果你需要加载多个扩展，需要多次调用该方法。仅适用于 Windows 和 Android 平台。
:::

<a id="api_irtcengine_loadextensionprovider__timing"></a>

### 调用时机

请确保在调用该方法前已初始化 [IRtcEngine](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_irtcengine)。

<a id="api_irtcengine_loadextensionprovider__parameters"></a>

### 参数

#### `path`

扩展库的路径和名称。例如： `/library/libagora_segmentation_extension.dll`。

#### `unload_after_use`

是否在不再使用当前扩展时卸载该扩展：

- true：当 IRtcEngine 被销毁时卸载该扩展。
- false：（推荐）直到进程终止前都不卸载该扩展。

<a id="api_irtcengine_loadextensionprovider__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/windows/error-code)了解详情和解决建议。

### 所属接口类
- [IRtcEngine](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_irtcengine)

## registerExtension

注册一个扩展。

<a id="api_irtcengine_registerextension__prototype"></a>

```cpp
virtual int registerExtension(const char* provider, const char* extension, agora::media::MEDIA_SOURCE_TYPE type = agora::media::UNKNOWN_MEDIA_SOURCE) = 0;
```

<a id="api_irtcengine_registerextension__detailed_desc"></a>

对于 SDK 外部的扩展（例如来自云市场和 SDK 扩展），你需要在调用该方法前先加载它们。对于 SDK 内部的扩展（即包含在完整 SDK 包中的扩展），在初始化 [IRtcEngine](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_irtcengine) 后会自动加载并注册。

:::info[注]
- 如果你想注册多个扩展，需要多次调用此方法。
- SDK 中不同扩展的数据处理顺序由注册顺序决定，即先注册的扩展会优先处理数据。
:::

<a id="api_irtcengine_registerextension__timing"></a>

### 调用时机

声网建议你在初始化 [IRtcEngine](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_irtcengine) 后、加入频道前调用此方法。

- 对于视频扩展（如美颜特效扩展），你需要在调用 enableVideo 或 enableLocalVideo 启用视频模块后再调用此方法。
- 在调用此方法前，你需要先调用 loadExtensionProvider 加载扩展。

<a id="api_irtcengine_registerextension__parameters"></a>

### 参数

#### `provider`

扩展提供方的名称。

#### `extension`

扩展的名称。

#### `type`

扩展的数据源类型，详见 [MEDIA_SOURCE_TYPE](/zh-CN/api-reference/rtc/cpp-all-platforms/enum-mediasourcetype)。

<a id="api_irtcengine_registerextension__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/windows/error-code)了解详情和解决建议。
  - -3：扩展库未加载。声网建议你检查动态库的存储位置或名称。

### 所属接口类
- [IRtcEngine](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_irtcengine)

## onExtensionErrorWithContext

扩展运行异常时触发的回调。

<a id="callback_irtcengineeventhandler_onextensionerrorwithcontext__prototype"></a>

```cpp
virtual void onExtensionErrorWithContext(const ExtensionContext &context, int error, const char* message)
```

<a id="callback_irtcengineeventhandler_onextensionerrorwithcontext__detailed_desc"></a>

当扩展启用失败或运行时发生错误时，会触发该回调，并返回错误码和错误原因。

<a id="callback_irtcengineeventhandler_onextensionerrorwithcontext__parameters"></a>

### 参数

#### `context`

扩展的上下文信息。详见 [ExtensionContext](/zh-CN/api-reference/rtc/cpp-all-platforms/class-extensioncontext)。

#### `error`

错误码。详见扩展提供方的扩展文档。

#### `message`

错误原因。详见扩展提供方的扩展文档。
