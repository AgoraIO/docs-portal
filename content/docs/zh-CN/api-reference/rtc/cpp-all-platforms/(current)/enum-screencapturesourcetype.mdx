<a id="enum_screencapturesourcetype__detailed_desc"></a>

在 [ScreenCaptureSourceInfo](/zh-CN/api-reference/rtc/cpp-all-platforms/class-screencapturesourceinfo) 中设置。

<a id="enum_screencapturesourcetype__parameters"></a>

## 枚举值

### `ScreenCaptureSourceType_Unknown`

（-1）：未知类型。

### `ScreenCaptureSourceType_Window`

（0）：共享目标为窗口。

### `ScreenCaptureSourceType_Screen`

（1）：共享目标为某个显示器的屏幕。

### `ScreenCaptureSourceType_Custom`

（2）：保留参数。
