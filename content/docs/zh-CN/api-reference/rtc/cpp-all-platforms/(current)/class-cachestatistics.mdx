---
title: "CacheStatistics"
description: "用于统计缓存的媒体文件信息。"
---

<a id="class_cachestatistics__prototype"></a>

```cpp
struct CacheStatistics {
  int64_t fileSize;
  int64_t cacheSize;
  int64_t downloadSize;
};
```

<a id="class_cachestatistics__parameters"></a>

## 属性

### `fileSize`

正在播放的媒体文件大小，单位为字节。

### `cacheSize`

期望缓存的媒体文件大小，单位为字节。

### `downloadSize`

已下载的媒体文件大小，单位为字节。
