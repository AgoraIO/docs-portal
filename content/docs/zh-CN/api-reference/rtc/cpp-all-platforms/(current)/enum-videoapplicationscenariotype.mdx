## 枚举值

<ParameterList>
<a id="application_scenario_general"></a>
<Parameter name="APPLICATION_SCENARIO_GENERAL">

（0）：默认通用场景。

</Parameter>
<a id="application_scenario_meeting"></a>
<Parameter name="APPLICATION_SCENARIO_MEETING">

:::note
注： 如果用户调用了 `setDualStreamMode(SIMULCAST_STREAM_MODE mode, const SimulcastStreamConfig& streamConfig)` 并设置为不发送视频小流（`DISABLE_SIMULCAST_STREAM`），则会议场景下低质量流的动态调整将不生效。
:::

（1）：会议场景。适用于会议场景，SDK 会自动启用以下策略：

- 在需要视频小流具备高码率的场景中，SDK 会启用多种抗网络拥塞技术，提升低质量流性能，确保订阅端流畅接收；
- SDK 实时监控视频大流的订阅人数，并动态调整配置：

  - 若无人订阅，自动降低码率和帧率以节省上行带宽；
  - 若有人订阅，则恢复为最近一次调用 [setVideoEncoderConfiguration](/zh-CN/api-reference/rtc/cpp-all-platforms/video/video-basic#api_irtcengine_setvideoencoderconfiguration) 设置的 [VideoEncoderConfiguration](/zh-CN/api-reference/rtc/cpp-all-platforms/class-videoencoderconfiguration) 配置，若未设置，则使用以下默认值：

    - Windows 和 macOS 分辨率为 1280 × 720，Android 和 iOS 为 960 × 540；
    - 帧率为 15 fps；
    - 码率为 Windows 和 macOS 为 1600 Kbps，Android 和 iOS 为 1000 Kbps。
- SDK 还会监控视频小流的订阅人数，并根据订阅情况动态启用或禁用：

  - 若无人订阅，自动禁用以节省上行带宽；
  - 若有人订阅，则启用并恢复为最近一次调用 [setDualStreamMode [2/2]](/zh-CN/api-reference/rtc/cpp-all-platforms/publishnsubscribe#api_irtcengine_setdualstreammode2) 设置的 [SimulcastStreamConfig](/zh-CN/api-reference/rtc/cpp-all-platforms/class-simulcaststreamconfig) 配置，若未设置，则使用以下默认值：分辨率为 480 × 272，帧率为 15 fps，码率为 500 Kbps。

</Parameter>
<a id="application_scenario_1v1"></a>
<Parameter name="APPLICATION_SCENARIO_1V1">

（2）：1 对 1 视频通话场景。适用于一对一直播场景。为满足低延迟和高质量视频的需求，SDK 优化了策略，提升了视频质量、首帧渲染速度、中低端设备的延迟表现以及弱网下的流畅性。

:::note
注： 该枚举值仅适用于主播对主播的场景。
:::

</Parameter>
<a id="application_scenario_liveshow"></a>
<Parameter name="APPLICATION_SCENARIO_LIVESHOW">

（3）：直播秀场景。适用于秀场类场景，强调快速渲染和高画质。SDK 进行了多项性能优化，包括自动启用音视频帧加速渲染以最小化首帧延迟（无需调用 [enableInstantMediaRendering](/zh-CN/api-reference/rtc/cpp-all-platforms/video/video-rendering#api_irtcengine_enableinstantmediarendering)），并启用 B 帧编码以提升图像质量和带宽效率。即使在网络较差或低端设备上，也能提供更佳的视频质量和播放流畅性。

</Parameter>
