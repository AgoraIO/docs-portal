<a id="class_watermarkratio__prototype"></a>

```text
struct WatermarkRatio {
  float xRatio;
  float yRatio;
  float widthRatio;
};
```

<a id="class_watermarkratio__detailed_desc"></a>

- `xRatio` 和 `yRatio` 表示水印左上角的坐标，决定水印左上角相对于屏幕左上角的水平和垂直距离。
- `widthRatio` 表示水印的宽度，SDK 会根据该值按比例计算水印的高度，以保持图像不失真。

<a id="class_watermarkratio__parameters"></a>

## 属性

<ParameterList>
<a id="xratio"></a>
<Parameter name="xRatio">

水印左上角的 x 坐标。表示相对于屏幕左上角的水平位置，取值范围为 [0.0, 1.0]。默认值为 0。

</Parameter>
<a id="yratio"></a>
<Parameter name="yRatio">

水印左上角的 y 坐标。表示相对于屏幕左上角的垂直位置，取值范围为 [0.0, 1.0]。默认值为 0。

</Parameter>
<a id="widthratio"></a>
<Parameter name="widthRatio">

水印的宽度。SDK 会根据该值按比例计算水印的高度，以保持图像不失真。取值范围为 [0, 1]。默认值为 0，表示不显示水印。

</Parameter>
</ParameterList>
