<a id="class_codeccapinfo__prototype"></a>

```cpp
struct CodecCapInfo {
  VIDEO_CODEC_TYPE codecType;
  int codecCapMask;
  CodecCapLevels codecLevels;
};
```

<a id="class_codeccapinfo__parameters"></a>

## 属性

### `codecType`

视频编解码器类型，详见 [VIDEO_CODEC_TYPE](/zh-CN/api-reference/rtc/cpp-all-platforms/enum-videocodectype)。

### `codecCapMask`

SDK 中编解码器类型的位掩码，详见 [CODEC_CAP_MASK](/zh-CN/api-reference/rtc/cpp-all-platforms/enum-codeccapmask)。

### `codecLevels`

编解码能力，详见 [CodecCapLevels](/zh-CN/api-reference/rtc/cpp-all-platforms/class-codeccaplevels)。
