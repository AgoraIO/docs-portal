## 枚举值

<ParameterList>
<a id="remote_audio_state_stopped"></a>
<Parameter name="REMOTE_AUDIO_STATE_STOPPED">

（0）：远端音频处于初始状态。当出现 `REMOTE_AUDIO_REASON_LOCAL_MUTED`、`REMOTE_AUDIO_REASON_REMOTE_MUTED` 或 `REMOTE_AUDIO_REASON_REMOTE_OFFLINE` 时，SDK 会报告该状态。

</Parameter>
<a id="remote_audio_state_starting"></a>
<Parameter name="REMOTE_AUDIO_STATE_STARTING">

（1）：已接收到首个远端音频数据包。

</Parameter>
<a id="remote_audio_state_decoding"></a>
<Parameter name="REMOTE_AUDIO_STATE_DECODING">

（2）：远端音频流已解码并正常播放。当出现 `REMOTE_AUDIO_REASON_NETWORK_RECOVERY`、`REMOTE_AUDIO_REASON_LOCAL_UNMUTED` 或 `REMOTE_AUDIO_REASON_REMOTE_UNMUTED` 时，SDK 会报告该状态。

</Parameter>
<a id="remote_audio_state_frozen"></a>
<Parameter name="REMOTE_AUDIO_STATE_FROZEN">

（3）：远端音频卡顿。当出现 `REMOTE_AUDIO_REASON_NETWORK_CONGESTION` 时，SDK 会报告该状态。

</Parameter>
<a id="remote_audio_state_failed"></a>
<Parameter name="REMOTE_AUDIO_STATE_FAILED">

（4）：远端音频启动失败。当出现 `REMOTE_AUDIO_REASON_INTERNAL` 时，SDK 会报告该状态。

</Parameter>
</ParameterList>
