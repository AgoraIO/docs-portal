<a id="class_codeccaplevels__prototype"></a>

```cpp
struct CodecCapLevels {
  VIDEO_CODEC_CAPABILITY_LEVEL hwDecodingLevel;
  VIDEO_CODEC_CAPABILITY_LEVEL swDecodingLevel;
};
```

<a id="class_codeccaplevels__parameters"></a>

## 属性

### `hwDecodingLevel`

硬件解码能力等级，表示设备对不同质量视频的硬件解码能力。详见 [VIDEO_CODEC_CAPABILITY_LEVEL](/zh-CN/api-reference/rtc/cpp-all-platforms/enum-videocodeccapabilitylevel)。

### `swDecodingLevel`

软件解码能力等级，表示设备对不同质量视频的软件解码能力。详见 [VIDEO_CODEC_CAPABILITY_LEVEL](/zh-CN/api-reference/rtc/cpp-all-platforms/enum-videocodeccapabilitylevel)。
