## 枚举值

### VIDEO_STREAM_HIGH

（0）：视频大流，分辨率和码率最高。

### VIDEO_STREAM_LOW

（1）：视频小流，分辨率和码率最低。

### VIDEO_STREAM_LAYER_1

（4）：多质量层级视频流的第 1 层，分辨率仅次于（0）VIDEO_STREAM_HIGH。

### VIDEO_STREAM_LAYER_2

（5）：多质量层级视频流的第 2 层，分辨率仅次于（4）VIDEO_STREAM_LAYER_1。

### VIDEO_STREAM_LAYER_3

（6）：多质量层级视频流的第 3 层，分辨率仅次于（5）VIDEO_STREAM_LAYER_2。

### VIDEO_STREAM_LAYER_4

（7）：多质量层级视频流的第 4 层，分辨率仅次于（6）VIDEO_STREAM_LAYER_3。

### VIDEO_STREAM_LAYER_5

（8）：多质量层级视频流的第 5 层，分辨率仅次于（7）VIDEO_STREAM_LAYER_4。

### VIDEO_STREAM_LAYER_6

（9）：多质量层级视频流的第 6 层，分辨率仅次于（8）VIDEO_STREAM_LAYER_5。
