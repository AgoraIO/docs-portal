## 枚举值

### RHYTHM_PLAYER_STATE_IDLE

（810）：虚拟节拍器未启用或已被禁用。

### RHYTHM_PLAYER_STATE_OPENING

（811）：正在打开节拍文件。

### RHYTHM_PLAYER_STATE_DECODING

（812）：正在解码节拍文件。

### RHYTHM_PLAYER_STATE_PLAYING

（813）：节拍文件播放中。

### RHYTHM_PLAYER_STATE_FAILED

（814）：虚拟节拍器启动失败。可通过返回的 `errorCode` 排查错误原因，或尝试重新启动虚拟节拍器。
