<a id="class_channelmediaoptions__detailed_desc"></a>

声网支持在同一个 [RtcConnection](/zh-CN/api-reference/rtc/cpp-all-platforms/class-rtcconnection) 中同时发布多个音频流和一个视频流。例如，可以同时将 `publishMicrophoneTrack`、`publishCustomAudioTrack` 和 `publishMediaPlayerAudioTrack` 设置为 true，但 `publishCameraTrack`、`publishScreenCaptureVideo`、`publishScreenTrack`、`publishCustomVideoTrack` 或 `publishEncodedVideoTrack` 中只能有一个设置为 true。

:::note
注： 声网建议你根据业务场景自行设置成员参数值，否则 SDK 会自动为成员参数分配值。
:::
