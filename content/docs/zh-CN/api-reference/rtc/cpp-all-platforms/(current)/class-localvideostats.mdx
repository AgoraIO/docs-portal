<Parameter name="targetBitrate">

当前编码器的目标码率（Kbps），由 SDK 根据当前网络状况估算得出。

</Parameter>
<a id="targetframerate"></a>
<Parameter name="targetFrameRate">

当前编码器的目标帧率（fps）。

</Parameter>

<Parameter name="qualityAdaptIndication">

本地视频流在上报时间间隔内的质量自适应情况（基于目标帧率和目标码率）。详见 [QUALITY_ADAPT_INDICATION](/zh-CN/api-reference/rtc/cpp-all-platforms/enum-qualityadaptindication)。

</Parameter>

<Parameter name="txPacketLossRate">

在应用抗丢包策略前，从本地客户端到声网服务器的视频丢包率（%）。

<a id="capturebrightnesslevel"></a>
<Parameter name="captureBrightnessLevel">

本地摄像头采集的视频图像的亮度等级。详见 [CAPTURE_BRIGHTNESS_LEVEL_TYPE](/zh-CN/api-reference/rtc/cpp-all-platforms/enum-capturebrightnessleveltype)。

</Parameter>
<a id="dualstreamenabled"></a>
<Parameter name="dualStreamEnabled">

是否启用了双流模式。

- false：未启用双流模式。

<Parameter name="hwEncoderAccelerating">

本地视频编码加速类型：

- 0：使用软件编码，无加速。
- 1：使用硬件编码进行加速。

</Parameter>
<a id="simulcastdimensions"></a>
<Parameter name="simulcastDimensions">

不同质量层级的视频流的编码帧尺寸。详见 [VideoDimensions](/zh-CN/api-reference/rtc/cpp-all-platforms/class-videodimensions)。

</Parameter>
