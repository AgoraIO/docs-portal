## createMediaRecorder

创建一个音视频录制器实例。

<a id="api_irtcengine_createmediarecorder__prototype"></a>

```text
virtual agora_refptr<IMediaRecorder> createMediaRecorder(const RecorderStreamInfo& info) = 0;
```

<a id="api_irtcengine_createmediarecorder__detailed_desc"></a>

在开始录制音频和视频流之前，你需要调用该方法创建一个录制器实例。SDK 支持录制来自本地或远端用户的多个音视频流。你可以多次调用该方法创建多个录制器实例，并通过参数 `info` 指定要录制的频道名和远端用户 ID。创建成功后，你需要调用 [setMediaRecorderObserver](/zh-CN/api-reference/rtc/cpp-all-platforms/recording#api_imediarecorder_setmediarecorderobserver) 为录制器实例注册观察者以监听相关回调，然后调用 [startRecording](/zh-CN/api-reference/rtc/cpp-all-platforms/recording#api_imediarecorder_startrecording) 开始录制。

<a id="api_irtcengine_createmediarecorder__parameters"></a>

### 参数

### info

音视频流信息。详见 [RecorderStreamInfo](/zh-CN/api-reference/rtc/cpp-all-platforms/class-recorderstreaminfo)。

<a id="api_irtcengine_createmediarecorder__return_values"></a>

### 返回值

方法调用成功，返回 [IMediaRecorder](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_imediarecorder) 实例。详见 [IMediaRecorder](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_imediarecorder)。
方法调用失败，返回 NULL。

## startAudioRecording [1/3]

开始客户端音频录制。

<a id="api_irtcengine_startaudiorecording1__prototype"></a>

```text
virtual int startAudioRecording(const char* filePath, AUDIO_RECORDING_QUALITY_TYPE quality) = 0;
```

<a id="api_irtcengine_startaudiorecording1__detailed_desc"></a>

调用该方法后，你可以在通话过程中录制频道中所有用户的音频，并生成包含所有声音的录音文件。录音文件仅支持以下格式：

- `.wav`：文件体积大，音频保真度高。
- `.aac`：文件体积小，音频保真度低。

:::note
注：

- 确保你指定的路径存在且可写。
- 必须在调用 `joinChannel` 后调用该方法。如果在录音过程中调用了 `leaveChannel`，录音将自动停止。
:::

<a id="api_irtcengine_startaudiorecording1__parameters"></a>

### 参数

### filePath

本地保存录音文件的绝对路径，包括文件名和扩展名。例如：C:\\music\\audio.aac。

:::note
注： 确保指定的路径存在且可写。
:::

### quality

录音质量，详见 [AUDIO_RECORDING_QUALITY_TYPE](/zh-CN/api-reference/rtc/cpp-all-platforms/enum-audiorecordingqualitytype)。

<a id="api_irtcengine_startaudiorecording1__return_values"></a>

调用该方法后，你可以在通话过程中在客户端录制频道中所有用户的音频，并生成包含所有声音的录音文件。录音文件仅支持以下格式：

<a id="api_irtcengine_startaudiorecording3__prototype"></a>


<a id="api_irtcengine_startaudiorecording3__detailed_desc"></a>

调用 `startAudioRecording` 方法后，你可以在通话过程中在客户端录制频道中用户的音频，并获取录音文件。录音文件支持以下格式：

## startRecording

开始录制音视频流。

<a id="api_imediarecorder_startrecording__prototype"></a>

```text
virtual int startRecording(const media::MediaRecorderConfiguration& config) = 0;
```

<a id="api_imediarecorder_startrecording__detailed_desc"></a>

:::info[自从]
自 v4.0.0 版本新增。
:::

该方法用于开始录制音频和视频流，支持同时录制本地和远端用户的音视频流。
在调用该方法前，请确保：

- 已通过 [createMediaRecorder](/zh-CN/api-reference/rtc/cpp-all-platforms/recording#api_irtcengine_createmediarecorder) 创建录制器实例。
- 已通过 [setMediaRecorderObserver](/zh-CN/api-reference/rtc/cpp-all-platforms/recording#api_imediarecorder_setmediarecorderobserver) 注册录制器观察者以监听录制回调。
- 已加入频道。

该方法支持录制以下内容：

- 以 AAC 编码格式采集的麦克风音频。
- 以 H.264 或 H.265 编码格式采集的摄像头视频。

录制开始后：

- 如果录制过程中视频分辨率发生变化，SDK 会停止录制。
- 如果音频采样率或声道数发生变化，SDK 会继续录制，并生成一个 MP4 文件。

仅当检测到可录制的音视频流时，录制文件才会成功生成。如果没有可录制的流，或录制过程中流中断超过 5 秒，SDK 会停止录制，并触发 [onRecorderStateChanged](/zh-CN/api-reference/rtc/cpp-all-platforms/recording#callback_imediarecorderobserver_onrecorderstatechanged)（`RECORDER_STATE_ERROR`，`RECORDER_REASON_NO_STREAM`）回调。

:::note
注：

- 如果你希望录制本地音视频流，请确保在开始录制前将本地用户角色设置为 `broadcaster`。
- 如果你希望录制远端音视频流，请确保在开始录制前已订阅远端用户的流。
:::

<a id="api_imediarecorder_startrecording__parameters"></a>

### 参数

### config

音视频流录制配置。详见 [MediaRecorderConfiguration](/zh-CN/api-reference/rtc/cpp-all-platforms/class-mediarecorderconfiguration)。

<a id="api_imediarecorder_startrecording__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。

  - -2：参数无效。请确保：

    - 指定的录制文件路径正确且可写。
    - 指定的录制文件格式正确。
    - 最大录制时长设置正确。
  - -4：[IRtcEngine](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_irtcengine) 当前状态不支持该操作。可能是已有录制正在进行，或录制因错误已停止。
  - -7：调用该方法时 [IRtcEngine](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_irtcengine) 尚未初始化。请确保在调用该方法前已创建 [IMediaRecorder](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_imediarecorder) 对象。
