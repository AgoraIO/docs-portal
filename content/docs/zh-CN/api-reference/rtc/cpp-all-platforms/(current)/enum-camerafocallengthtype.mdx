:::

<a id="enum_camerafocallengthtype__parameters"></a>

## 枚举值

### `CAMERA_FOCAL_LENGTH_DEFAULT`

（0）：默认镜头（默认）。

### `CAMERA_FOCAL_LENGTH_WIDE_ANGLE`

（1）：广角镜头。

### `CAMERA_FOCAL_LENGTH_ULTRA_WIDE`

（2）：超广角镜头。

### `CAMERA_FOCAL_LENGTH_TELEPHOTO`

（3）：长焦镜头（仅适用于 iOS 平台）。
