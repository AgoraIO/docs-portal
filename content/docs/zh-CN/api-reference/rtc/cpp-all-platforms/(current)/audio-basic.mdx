## adjustPlaybackSignalVolume

调节所有远端用户的本地播放音量。

<a id="api_irtcengine_adjustplaybacksignalvolume__prototype"></a>

```cpp
virtual int adjustPlaybackSignalVolume(int volume) = 0;
```

<a id="api_irtcengine_adjustplaybacksignalvolume__detailed_desc"></a>

如果你需要调节某个指定远端用户的本地播放音量，建议调用 [adjustUserPlaybackSignalVolume](/zh-CN/api-reference/rtc/cpp-all-platforms/audio-basic#api_irtcengine_adjustuserplaybacksignalvolume) 方法。

<a id="api_irtcengine_adjustplaybacksignalvolume__timing"></a>

### 调用时机

该方法可以在加入频道前或加入频道后调用。

<a id="api_irtcengine_adjustplaybacksignalvolume__parameters"></a>

### 参数

#### `volume`

用户的音量，取值范围为 [0,400]。

- 0：静音。
- 100：（默认）原始音量。
- 400：原始音量的四倍（将音频信号放大四倍）。

<a id="api_irtcengine_adjustplaybacksignalvolume__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/windows/error-code)了解详情和解决建议。

### 所属接口类
- [IRtcEngine](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_irtcengine)

## disableAudio

禁用音频模块。

<a id="api_irtcengine_disableaudio__prototype"></a>

```cpp
virtual int disableAudio() = 0;
```

<a id="api_irtcengine_disableaudio__detailed_desc"></a>

:::info[注]
该方法会重置内部引擎，并需要一定时间生效。声网建议使用以下 API 分别控制音频模块：

- enableLocalAudio：是否启用麦克风以创建本地音频流。

## enableAudio

<a id="api_irtcengine_enableaudio__prototype"></a>

```cpp
virtual int enableAudio() = 0;
```

<a id="api_irtcengine_enableaudio__detailed_desc"></a>

音频模块默认处于启用状态。调用 [disableAudio](/zh-CN/api-reference/rtc/cpp-all-platforms/audio-basic#api_irtcengine_disableaudio) 方法禁用音频模块后，可以调用该方法重新启用音频模块。

:::info[注]

- enableLocalAudio：是否启用麦克风以创建本地音频流。

成功调用该方法会重置 [enableLocalAudio](/zh-CN/api-reference/rtc/cpp-all-platforms/audio-capture#api_irtcengine_enablelocalaudio)、 [muteRemoteAudioStream](/zh-CN/api-reference/rtc/cpp-all-platforms/publishnsubscribe#api_irtcengine_muteremoteaudiostream) 和 [muteAllRemoteAudioStreams](/zh-CN/api-reference/rtc/cpp-all-platforms/publishnsubscribe#api_irtcengine_muteallremoteaudiostreams) 的设置，请谨慎使用。

## enableAudioVolumeIndication

启用用户音量提示的上报功能。

<a id="api_irtcengine_enableaudiovolumeindication__prototype"></a>

```cpp
virtual int enableAudioVolumeIndication(int interval, int smooth, bool reportVad) = 0;
```

<a id="api_irtcengine_enableaudiovolumeindication__detailed_desc"></a>

该方法用于启用 SDK 定期向应用上报本地发送音频流的用户和瞬时音量最大的最多三位远端用户的音量信息。

<a id="api_irtcengine_enableaudiovolumeindication__timing"></a>

### 调用时机

该方法可以在加入频道前或加入频道后调用。

<a id="api_irtcengine_enableaudiovolumeindication__related"></a>

### 相关回调

成功调用该方法后，若频道中有用户发布音频流，SDK 会按照设置的时间间隔触发 [onAudioVolumeIndication](/zh-CN/api-reference/rtc/cpp-all-platforms/audio-basic#callback_irtcengineeventhandler_onaudiovolumeindication) 回调。

<a id="api_irtcengine_enableaudiovolumeindication__parameters"></a>

### 参数

#### `interval`

设置两次音量提示之间的时间间隔（毫秒）：

- ≤ 0：关闭音量提示功能。
- &gt; 0：两次音量提示之间的时间间隔（单位为毫秒）。该值需大于 10，否则无法收到 onAudioVolumeIndication 回调。建议设置为大于 100。

#### `smooth`

设置音量提示的灵敏度平滑系数，取值范围为 0 到 10，推荐值为 3。值越大，提示越灵敏。

#### `reportVad`

是否启用本地用户的语音活动检测（VAD）：

- true：启用语音活动检测。启用后， onAudioVolumeIndication 回调中的 vad 参数会报告本地用户的语音活动状态。
- false：（默认）关闭语音活动检测。关闭后， onAudioVolumeIndication 回调中的 vad 参数不会报告本地用户的语音活动状态，除非引擎自动检测到语音活动。

<a id="api_irtcengine_enableaudiovolumeindication__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/windows/error-code)了解详情和解决建议。

### 所属接口类
- [IRtcEngine](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_irtcengine)

<a id="api_irtcengine_setaudioprofile__prototype"></a>

```cpp
virtual int setAudioProfile(AUDIO_PROFILE_TYPE profile, AUDIO_SCENARIO_TYPE scenario) __deprecated = 0;
```

<a id="api_irtcengine_setaudioprofile__detailed_desc"></a>

#### `废弃`

该方法已废弃。你可以改用 [setAudioProfile [2/2]](/zh-CN/api-reference/rtc/cpp-all-platforms/audio-basic#api_irtcengine_setaudioprofile2) 方法。若需设置音频场景，请调用 [initialize](/zh-CN/api-reference/rtc/cpp-all-platforms/initialize#api_irtcengine_initialize) 方法，并在 [RtcEngineContext](/zh-CN/api-reference/rtc/cpp-all-platforms/class-rtcengineconfig) 结构体中的 `audioScenario` 成员中传入值。

:::info[注]

:::

<a id="api_irtcengine_setaudioprofile__scenario"></a>

最活跃远端说话人回调。

<a id="callback_irtcengineeventhandler_onactivespeaker__prototype"></a>

```cpp
virtual void onActiveSpeaker(uid_t uid)
```

<a id="callback_irtcengineeventhandler_onactivespeaker__detailed_desc"></a>

调用 [enableAudioVolumeIndication](/zh-CN/api-reference/rtc/cpp-all-platforms/audio-basic#api_irtcengine_enableaudiovolumeindication) 方法成功后，SDK 会持续检测哪位远端用户的音量最大。在当前周期内，音量被检测为最大次数最多的远端用户即为最活跃用户。当频道中用户数不少于两人且存在活跃的远端说话人时，SDK 会触发该回调并报告最活跃远端说话人的用户 ID。

- 如果最活跃的远端说话人始终是同一用户，SDK 只会触发一次该回调。
- 如果最活跃的远端说话人变更为其他用户，SDK 会再次触发该回调并报告新的最活跃远端说话人的用户 ID。

<a id="callback_irtcengineeventhandler_onactivespeaker__parameters"></a>

### 参数

#### `uid`

最活跃远端说话人的用户 ID。

## onAudioVolumeIndication

onAudioVolumeIndication 回调。

<a id="callback_irtcengineeventhandler_onaudiovolumeindication__prototype"></a>

```cpp
virtual void onAudioVolumeIndication(const AudioVolumeInfo* speakers, unsigned int speakerNumber, int totalVolume)
```

<a id="callback_irtcengineeventhandler_onaudiovolumeindication__detailed_desc"></a>

默认情况下，该回调处于关闭状态。你可以通过调用 [enableAudioVolumeIndication](/zh-CN/api-reference/rtc/cpp-all-platforms/audio-basic#api_irtcengine_enableaudiovolumeindication) 方法开启该回调。开启后，当频道中有用户发送音频流时，SDK 会按照 [enableAudioVolumeIndication](/zh-CN/api-reference/rtc/cpp-all-platforms/audio-basic#api_irtcengine_enableaudiovolumeindication) 中设置的时间间隔触发该回调。SDK 会同时触发两个独立的 [onAudioVolumeIndication](/zh-CN/api-reference/rtc/cpp-all-platforms/audio-basic#callback_irtcengineeventhandler_onaudiovolumeindication) 回调，分别报告发送音频流的本地用户和瞬时音量最高的最多三位远端用户的音量信息。

:::info[注]
开启该回调后，即使本地用户调用 [muteLocalAudioStream](/zh-CN/api-reference/rtc/cpp-all-platforms/publishnsubscribe#api_irtcengine_mutelocalaudiostream) 方法将音频静音，SDK 仍会继续报告本地用户的音量信息。如果某位远端用户的音量为频道中前三高之一，但停止发布音频流超过 20 秒，该回调将不再包含该用户的信息；如果所有远端用户都停止发布音频流超过 20 秒，SDK 将不再触发远端用户的音量回调。
:::

<a id="callback_irtcengineeventhandler_onaudiovolumeindication__timing"></a>

### 触发时机

当启用音量提示并有用户发送音频流时触发。

<a id="callback_irtcengineeventhandler_onaudiovolumeindication__parameters"></a>

### 参数

#### `speakers`

用户的音量信息。详见 [AudioVolumeInfo](/zh-CN/api-reference/rtc/cpp-all-platforms/class-audiovolumeinfo)。当该回调中的 `speakers` 数组为空时，表示频道中没有远端用户或没有用户发送音频流。

#### `speakerNumber`

用户总数。

- 本地用户的回调中，如果本地用户正在发送音频流， speakerNumber 的值为 1。
- 远端用户的回调中， speakerNumber 的取值范围为 [0, 3]。如果发送音频流的远端用户数量大于或等于 3， speakerNumber 的值为 3。

#### `totalVolume`

说话者的音量，取值范围为 [0, 255]。

- 本地用户的回调中， totalVolume 表示本地用户的音量。
- 远端用户的回调中， totalVolume 表示瞬时音量最高的最多三位远端用户的音量总和。如果调用了 startAudioMixing，则该值为混音后的音量。

### 所属接口类
- [IRtcEngineEventHandler](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_irtcengineeventhandler)
