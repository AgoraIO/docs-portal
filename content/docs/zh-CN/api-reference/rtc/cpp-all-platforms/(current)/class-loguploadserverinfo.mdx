title: "LogUploadServerInfo"
description: "用于配置日志服务器的信息。"
---

<a id="class_loguploadserverinfo__prototype"></a>

```cpp
struct LogUploadServerInfo {
  const char* serverDomain;
  const char* serverPath;
  int serverPort;
  bool serverHttps;
};
```

<a id="class_loguploadserverinfo__parameters"></a>

## 属性

### `serverDomain`

日志服务器的域名。

### `serverPath`

日志在服务器上的存储路径。

### `serverPort`

日志服务器的端口号。

### `serverHttps`

日志服务器是否使用 HTTPS 协议：

- true：使用 HTTPS 协议。
- false：使用 HTTP 协议。
