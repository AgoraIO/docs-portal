<a id="class_faceshapeareaoptions__prototype"></a>

```cpp
struct FaceShapeAreaOptions {
  FACE_SHAPE_AREA shapeArea;
  int shapeIntensity;
};
```

<a id="class_faceshapeareaoptions__detailed_desc"></a>

### `自从`

自 v4.4.0 版本新增。

<a id="class_faceshapeareaoptions__parameters"></a>

## 属性

### `shapeArea`

美型增强区域。详见 [FACE_SHAPE_AREA](/zh-CN/api-reference/rtc/cpp-all-platforms/enum-faceshapearea)。

### `shapeIntensity`

增强强度。不同面部区域的增强强度定义不同，例如方向、范围和预设值。
