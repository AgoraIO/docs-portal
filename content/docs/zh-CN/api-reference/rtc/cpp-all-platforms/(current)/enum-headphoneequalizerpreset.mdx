## 枚举值

### `HEADPHONE_EQUALIZER_OFF`

（0x00000000）：关闭耳机均衡器，播放原始音频。

### `HEADPHONE_EQUALIZER_OVEREAR`

（0x04000001）：启用适用于头戴式耳机的均衡器。

### `HEADPHONE_EQUALIZER_INEAR`

（0x04000002）：启用适用于入耳式耳机的均衡器。
