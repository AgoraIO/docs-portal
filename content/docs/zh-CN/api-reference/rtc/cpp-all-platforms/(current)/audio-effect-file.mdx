## getEffectDuration

获取音效文件的时长。

<a id="api_irtcengine_geteffectduration__prototype"></a>

```cpp
virtual int getEffectDuration(const char* filePath) = 0;
```

<a id="api_irtcengine_geteffectduration__detailed_desc"></a>

:::info[注]
请在加入频道后调用此方法。
:::

<a id="api_irtcengine_geteffectduration__parameters"></a>

### 参数

#### `filePath`

音效文件路径：

- Android：文件路径需精确到文件名和后缀名。支持 URL 地址、绝对路径，或以 /assets/ 开头的文件路径。使用绝对路径访问本地文件可能会遇到权限问题，建议使用 URI 地址。例如： content://com.android.providers.media.documents/document/audio%3A14441。
- Windows：音效文件的绝对路径或 URL 地址（包括文件名后缀）。例如： C:\\music\\audio.mp4。
- iOS 或 macOS：音效文件的绝对路径或 URL 地址（包括文件名后缀）。例如： /var/mobile/Containers/Data/audio.mp4。

<a id="api_irtcengine_geteffectduration__return_values"></a>

### 返回值

- 方法调用成功，返回指定音效文件的总时长（毫秒）。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/windows/error-code)了解详情和解决建议。

## playAllEffects

播放所有音效文件。

<a id="api_irtcengine_playalleffects__prototype"></a>

```cpp
virtual int playAllEffects(int loopCount, double pitch, double pan, int gain, bool publish = false) = 0;
```

<a id="api_irtcengine_playalleffects__detailed_desc"></a>

多次调用 [preloadEffect](/zh-CN/api-reference/rtc/cpp-all-platforms/audio-effect-file#api_irtcengine_preloadeffect) 将多个音效文件预加载到内存后，可以调用该方法为频道内的所有用户播放所有已加载的音效文件。

<a id="api_irtcengine_playalleffects__parameters"></a>

### 参数

#### `loopCount`

音效文件的循环播放次数：

- -1：无限循环播放，直到调用 stopEffect 或 stopAllEffects。
- 0：播放一次。
- 1：播放两次。

#### `pitch`

音效的音调。取值范围为 [0.5, 2.0]，默认值为 1.0（原始音调）。值越小，音调越低。

#### `pan`

音效的空间位置。取值范围为 [-1.0, 1.0]：

- -1.0：音效出现在左侧。
- 0：音效出现在正前方。
- 1.0：音效出现在右侧。

#### `gain`

音效的音量。取值范围为 [0, 100]，默认值为 100（原始音量）。值越小，音量越低。

#### `publish`

是否将音效发布给远端用户：

- true：将音效发布给远端用户，本地和远端用户都能听到。
- false：（默认）不发布音效，只有本地用户能听到。

<a id="api_irtcengine_playalleffects__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/windows/error-code)了解详情和解决建议。

### 所属接口类
- [IRtcEngine](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_irtcengine)

## playEffect

播放指定的本地或在线音效文件。

<a id="api_irtcengine_playeffect3__prototype"></a>

```cpp
virtual int playEffect(int soundId, const char* filePath, int loopCount, double pitch, double pan, int gain, bool publish = false, int startPos = 0) = 0;
```

<a id="api_irtcengine_playeffect3__detailed_desc"></a>

调用 [preloadEffect](/zh-CN/api-reference/rtc/cpp-all-platforms/audio-effect-file#api_irtcengine_preloadeffect) 后，可以调用该方法为频道内所有用户播放指定的音效。每次调用该方法只能播放一个音效。如需同时播放多个音效，需要多次调用该方法。

:::info[注]
- 如果需要播放在线音效文件，声网建议先将其缓存到本地设备，调用 preloadEffect 将其预加载到内存中，再调用该方法播放音效。否则，可能因加载超时或失败导致播放失败或无声。
- 建议同时播放的音效数量不超过三个。
- 该方法中的音效 ID 和文件路径必须与 preloadEffect 中的一致。
- 如果在调用 playEffect 前调用了 preloadEffect，则在 playEffect 执行后文件资源不会被关闭。下次调用 playEffect 时将直接从头开始播放。
- 如果在调用 playEffect 前未调用 preloadEffect，则在 playEffect 执行后资源将被销毁。下次调用 playEffect 时将尝试重新打开文件并从头播放。
:::

<a id="api_irtcengine_playeffect3__timing"></a>

### 调用时机

你可以在加入频道前或后调用该方法。

<a id="api_irtcengine_playeffect3__related"></a>

### 相关回调

成功调用该方法后，SDK 会触发 [onAudioEffectFinished](/zh-CN/api-reference/rtc/cpp-all-platforms/audio-effect-file#callback_irtcengineeventhandler_onaudioeffectfinished) 回调报告音效播放完成。

<a id="api_irtcengine_playeffect3__parameters"></a>

### 参数

#### `soundId`

音效的 ID。

#### `filePath`

本地音效文件的绝对路径或在线音效文件的 URL。支持的音频格式包括：mp3、mp4、m4a、aac、3gp、mkv 和 wav。

#### `loopCount`

音效的循环播放次数：

- -1：无限循环播放，直到调用 stopEffect 或 stopAllEffects。
- 0：播放一次。
- 1：播放两次。

#### `pitch`

音效的音调。取值范围为 0.5 到 2.0，默认值为 `1.0` （原始音调）。值越小，音调越低。

#### `pan`

音效的空间位置。取值范围为 -1.0 到 1.0：

- -1.0：音效定位在左侧。
- 0.0：音效定位在正前方。
- 1.0：音效定位在右侧。

#### `gain`

音效的音量。取值范围为 0 到 100，默认值为 `100` （原始音量）。值越小，音量越低。

#### `publish`

是否将音效发布到远端：

- true：将音效发布到远端。
- false：（默认）不将音效发布到远端。

#### `startPos`

音效文件的播放起始位置，单位为毫秒。

<a id="api_irtcengine_playeffect3__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/windows/error-code)了解详情和解决建议。

### 所属接口类
- [IRtcEngine](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_irtcengine)
