<a id="class_focallengthinfo__prototype"></a>

```cpp
struct FocalLengthInfo {
  int cameraDirection;
  CAMERA_FOCAL_LENGTH_TYPE focalLengthType;
};
```

<a id="class_focallengthinfo__detailed_desc"></a>

:::info[注]
该结构体仅适用于 Android 和 iOS 平台。
:::

<a id="class_focallengthinfo__parameters"></a>

## 属性

### `cameraDirection`

摄像头方向，详见 [CAMERA_DIRECTION](/zh-CN/api-reference/rtc/cpp-all-platforms/enum-cameradirection)。

### `focalLengthType`

焦距类型，详见 [CAMERA_FOCAL_LENGTH_TYPE](/zh-CN/api-reference/rtc/cpp-all-platforms/enum-camerafocallengthtype)。
