<a id="class_mixedaudiostream__prototype"></a>

```cpp
struct MixedAudioStream {
  AUDIO_SOURCE_TYPE sourceType;
  uid_t remoteUserUid;
  const char* channelId;
  track_id_t trackId;
};
```

<a id="class_mixedaudiostream__parameters"></a>

## 属性

### `sourceType`

音频源类型。详见 [AUDIO_SOURCE_TYPE](/zh-CN/api-reference/rtc/cpp-all-platforms/enum-audiosourcetype)。

### `remoteUserUid`

远端用户 ID。

:::info[注]
当本地混音音频流的来源类型为 `AUDIO_SOURCE_REMOTE_USER` 时，需设置该参数。
:::

### `channelId`

:::info[注]
当本地混音音频流的来源类型为 `AUDIO_SOURCE_REMOTE_CHANNEL` 或 `AUDIO_SOURCE_REMOTE_USER` 时，需设置该参数。
:::

频道名。该参数表示用户进行实时音视频互动的频道。在相同 App ID 下，填写相同频道名的用户会进入同一个频道进行音视频互动。字符串长度不得超过 64 字节。支持的字符（共 89 个）：

- 所有小写英文字母：a 到 z。
- 所有大写英文字母：A 到 Z。
- 所有数字字符：0 到 9。
- 特殊字符："!", "#", "$", "%", "&", "(", ")", "+", "-", ":", ";", "&lt;", "=", ".", "&gt;", "?", "@", "[", "]", "^", "_", "\{", "\}", "|", "~", ","

### `trackId`

音频轨道 ID。设置为 [createCustomAudioTrack](/zh-CN/api-reference/rtc/cpp-all-platforms/audio-custom-capturenrendering#api_imediaengine_createcustomaudiotrack_imediaengine) 返回的自定义音频轨道 ID。

:::info[注]
当本地混音音频流的来源类型为 `AUDIO_SOURCE_CUSTOM` 时，需设置该参数。
:::
