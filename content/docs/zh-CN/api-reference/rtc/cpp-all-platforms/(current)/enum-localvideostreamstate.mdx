## 枚举值

### LOCAL_VIDEO_STREAM_STATE_STOPPED

（0）：本地视频处于初始状态。

### LOCAL_VIDEO_STREAM_STATE_CAPTURING

（1）：本地视频采集设备启动成功。当调用 [startScreenCaptureByWindowId](/zh-CN/api-reference/rtc/cpp-all-platforms/video/screencapture#api_irtcengine_startscreencapturebywindowid) 共享最大化窗口时，SDK 也会报告此状态。

### LOCAL_VIDEO_STREAM_STATE_ENCODING

（2）：首帧视频编码成功。

### LOCAL_VIDEO_STREAM_STATE_FAILED

（3）：启动本地视频失败。
