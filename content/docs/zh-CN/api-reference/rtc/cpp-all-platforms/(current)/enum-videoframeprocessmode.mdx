## 枚举值

<ParameterList>
<a id="process_mode_read_only"></a>
<Parameter name="PROCESS_MODE_READ_ONLY">

只读模式。在此模式下不修改视频帧，视频帧观察器作为渲染器存在。

</Parameter>
<a id="process_mode_read_write"></a>
<Parameter name="PROCESS_MODE_READ_WRITE">

读写模式。在此模式下可修改视频帧，视频帧观察器作为视频滤镜存在，会影响 SDK 后续的视频帧处理。

</Parameter>
