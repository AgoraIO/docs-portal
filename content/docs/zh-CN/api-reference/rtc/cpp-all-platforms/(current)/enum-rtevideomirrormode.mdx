## 枚举值

### `kRteVideoMirrorModeAuto`

（0）：由 SDK 决定是否开启镜像模式。

- 本地视图镜像模式：使用前置摄像头时（默认）开启，使用后置摄像头时（默认）关闭。
- 远端用户视图镜像模式：（默认）关闭。

### `kRteVideoMirrorModeEnabled`

（1）：开启镜像模式。

### `kRteVideoMirrorModeDisabled`

（2）：关闭镜像模式。
