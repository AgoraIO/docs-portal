## 枚举值

<ParameterList>
<a id="sub_state_idle"></a>
<Parameter name="SUB_STATE_IDLE">

（0）：加入频道后的初始订阅状态。

</Parameter>
<a id="sub_state_no_subscribed"></a>
<Parameter name="SUB_STATE_NO_SUBSCRIBED">

（1）：订阅远端流失败。可能的原因包括：

- 远端用户：

  - 调用 `muteLocalAudioStream(true)` 或 `muteLocalVideoStream(true)` 停止发送本地媒体流。
  - 调用 [disableAudio](/zh-CN/api-reference/rtc/cpp-all-platforms/audio/audio-basic#api_irtcengine_disableaudio) 或 [disableVideo](/zh-CN/api-reference/rtc/cpp-all-platforms/video/video-basic#api_irtcengine_disablevideo) 禁用本地音频或视频模块。
  - 调用 `enableLocalAudio(false)` 或 `enableLocalVideo(false)` 禁用本地音视频采集。
  - 角色为观众。
- 本地用户：

  - 调用 `muteRemoteAudioStream(true)` 或 `muteAllRemoteAudioStreams(true)` 停止接收远端音频流。
  - 调用 `muteRemoteVideoStream(true)` 或 `muteAllRemoteVideoStreams(true)` 停止接收远端视频流。

</Parameter>
<a id="sub_state_subscribing"></a>
<Parameter name="SUB_STATE_SUBSCRIBING">

（2）：正在订阅远端流。

</Parameter>
<a id="sub_state_subscribed"></a>
<Parameter name="SUB_STATE_SUBSCRIBED">

（3）：已成功接收远端流。

</Parameter>
</ParameterList>
