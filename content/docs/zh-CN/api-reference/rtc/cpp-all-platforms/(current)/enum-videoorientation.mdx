<a id="enum_videoorientation__parameters"></a>

## 枚举值

### `VIDEO_ORIENTATION_0`

（0）：（默认）不旋转。

### `VIDEO_ORIENTATION_90`

（90）：顺时针旋转 90°。

### `VIDEO_ORIENTATION_180`

（180）：顺时针旋转 180°。

### `VIDEO_ORIENTATION_270`

（270）：顺时针旋转 270°。
