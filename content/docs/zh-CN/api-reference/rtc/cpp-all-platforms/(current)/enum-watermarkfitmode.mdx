## 枚举值

### `FIT_MODE_COVER_POSITION`

（0）：使用在 [WatermarkOptions](/zh-CN/api-reference/rtc/cpp-all-platforms/class-watermarkoptions) 中设置的 `positionInLandscapeMode` 和 `positionInPortraitMode` 值， [WatermarkRatio](/zh-CN/api-reference/rtc/cpp-all-platforms/class-watermarkratio) 中的设置无效。

### `FIT_MODE_USE_IMAGE_RATIO`

（1）：使用在 [WatermarkRatio](/zh-CN/api-reference/rtc/cpp-all-platforms/class-watermarkratio) 中设置的值， [WatermarkOptions](/zh-CN/api-reference/rtc/cpp-all-platforms/class-watermarkoptions) 中的 `positionInLandscapeMode` 和 `positionInPortraitMode` 设置无效。
