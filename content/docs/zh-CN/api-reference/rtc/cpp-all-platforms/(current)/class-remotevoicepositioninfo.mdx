---
title: "RemoteVoicePositionInfo"
description: "用于设置远端用户或媒体播放器的空间位置信息。"
---

<a id="class_remotevoicepositioninfo__prototype"></a>

```cpp
struct RemoteVoicePositionInfo {
  float position[3];
  float forward[3];
};
```

<a id="class_remotevoicepositioninfo__parameters"></a>

## 属性

### `position`

世界坐标系中的坐标。该参数是一个长度为 3 的数组，三个值依次表示前、右、上的坐标。

### `forward`

坐标系中 x 轴的单位向量。该参数是一个长度为 3 的数组，三个值依次表示前、右、上的坐标。
