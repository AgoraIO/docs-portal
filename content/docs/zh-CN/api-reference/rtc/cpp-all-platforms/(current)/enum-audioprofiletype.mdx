## 枚举值

<ParameterList>
<a id="audio_profile_default"></a>
<Parameter name="AUDIO_PROFILE_DEFAULT">

（0）：默认音频配置文件。

- 互动直播场景：采样率为 48 kHz，音乐编码，单声道，码率最高为 64 Kbps。
- 通信场景：

  - Windows：采样率为 16 kHz，音频编码，单声道，码率最高为 16 Kbps。
  - Android/macOS/iOS：采样率为 32 kHz，音频编码，单声道，码率最高为 18 Kbps。

</Parameter>
<a id="audio_profile_speech_standard"></a>
<Parameter name="AUDIO_PROFILE_SPEECH_STANDARD">

（1）：采样率为 32 kHz，音频编码，单声道，码率最高为 18 Kbps。

</Parameter>
<a id="audio_profile_music_standard"></a>
<Parameter name="AUDIO_PROFILE_MUSIC_STANDARD">

（2）：采样率为 48 kHz，音乐编码，单声道，码率最高为 64 Kbps。

</Parameter>
<a id="audio_profile_music_standard_stereo"></a>
<Parameter name="AUDIO_PROFILE_MUSIC_STANDARD_STEREO">

（3）：采样率为 48 kHz，音乐编码，立体声，码率最高为 80 Kbps。启用立体声音频需调用 [setAdvancedAudioOptions](/zh-CN/api-reference/rtc/cpp-all-platforms/audio/audio-prenpost/audio-effect#api_irtcengine_setadvancedaudiooptions)，并在 [AdvancedAudioOptions](/zh-CN/api-reference/rtc/cpp-all-platforms/class-advancedaudiooptions) 中将 `audioProcessingChannels` 设置为 `AUDIO_PROCESSING_STEREO`。

</Parameter>
<a id="audio_profile_music_high_quality"></a>
<Parameter name="AUDIO_PROFILE_MUSIC_HIGH_QUALITY">

（4）：采样率为 48 kHz，音乐编码，单声道，码率最高为 96 Kbps。

</Parameter>
<a id="audio_profile_music_high_quality_stereo"></a>
<Parameter name="AUDIO_PROFILE_MUSIC_HIGH_QUALITY_STEREO">

（5）：采样率为 48 kHz，音乐编码，立体声，码率最高为 128 Kbps。启用立体声音频需调用 [setAdvancedAudioOptions](/zh-CN/api-reference/rtc/cpp-all-platforms/audio/audio-prenpost/audio-effect#api_irtcengine_setadvancedaudiooptions)，并在 [AdvancedAudioOptions](/zh-CN/api-reference/rtc/cpp-all-platforms/class-advancedaudiooptions) 中将 `audioProcessingChannels` 设置为 `AUDIO_PROCESSING_STEREO`。

</Parameter>
<a id="audio_profile_iot"></a>
<Parameter name="AUDIO_PROFILE_IOT">

（6）：采样率为 16 kHz，音频编码，单声道，并启用回声消除（AEC）。

</Parameter>
<a id="audio_profile_num"></a>
<Parameter name="AUDIO_PROFILE_NUM">

（7）：枚举边界值。

</Parameter>
</ParameterList>
