## getMaxMetadataSize

当 SDK 请求元数据最大大小时触发的回调。

<a id="api_imetadataobserver_getmaxmetadatasize__prototype"></a>

```text
virtual int getMaxMetadataSize() { return DEFAULT_METADATA_SIZE_IN_BYTE; }
```

<a id="api_imetadataobserver_getmaxmetadatasize__detailed_desc"></a>

调用 [registerMediaMetadataObserver](/zh-CN/api-reference/rtc/cpp-all-platforms/metadata/metadata-observer#api_irtcengine_registermediametadataobserver) 成功注册后，SDK 在每发送一帧视频时会触发该回调。你需要在该回调的返回值中指定元数据的最大大小。

<a id="api_imetadataobserver_getmaxmetadatasize__return_values"></a>

### 返回值

方法调用成功，返回你希望使用的元数据 `buffer` 的最大大小，单位为字节。最大值为 1024 字节。

### 所属接口类

- [IMetadataObserver](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_imetadataobserver)

## registerMediaMetadataObserver

注册元数据观察器。

<a id="api_irtcengine_registermediametadataobserver__prototype"></a>

```text
virtual int registerMediaMetadataObserver(IMetadataObserver *observer, IMetadataObserver::METADATA_TYPE type) = 0;
```

<a id="api_irtcengine_registermediametadataobserver__detailed_desc"></a>

你需要实现 [IMetadataObserver](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_imetadataobserver) 类，并在该方法中指定元数据类型。该方法支持在视频流中添加同步元数据，用于实现更丰富的互动直播场景，例如发送购物链接、数字优惠券和在线问答。成功调用该方法后，SDK 会触发 [getMaxMetadataSize](/zh-CN/api-reference/rtc/cpp-all-platforms/metadata/metadata-observer#api_imetadataobserver_getmaxmetadatasize) 回调。

:::note
注： 请在调用 `joinChannel` 之前调用此方法。
:::

<a id="api_irtcengine_registermediametadataobserver__parameters"></a>

### 参数

### observer

元数据观察器。详见 [IMetadataObserver](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_imetadataobserver)。

### type

元数据类型。详见 [METADATA_TYPE](/zh-CN/api-reference/rtc/cpp-all-platforms/enum-metadatatype)。SDK 当前仅支持 `VIDEO_METADATA`。

<a id="api_irtcengine_registermediametadataobserver__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。

### 所属接口类

- [IRtcEngine](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_irtcengine)
