## 枚举值

### `VIDEO_VIEW_SETUP_REPLACE`

（0）：（默认）清除所有已添加的视图，并替换为新视图。

### `VIDEO_VIEW_SETUP_ADD`

（1）：添加一个视图。

### `VIDEO_VIEW_SETUP_REMOVE`

（2）：删除一个视图。

:::info[注]
当你不再需要使用某个视图时，建议通过将 `setupMode` 设置为 `VIDEO_VIEW_SETUP_REMOVE` 来删除该视图，否则可能会导致渲染资源泄漏。
:::
