---
title: "MusicCacheInfo"
description: "用于描述音乐资源的缓存信息。"
---

<a id="class_musiccacheinfo__prototype"></a>

```cpp
struct MusicCacheInfo {
    int64_t songCode;
    MUSIC_CACHE_STATUS_TYPE status;
};
```

<a id="class_musiccacheinfo__parameters"></a>

## 属性

### `songCode`

音乐资源的 ID，用于标识该资源。

### `status`

音乐资源的缓存状态。详见 [MUSIC_CACHE_STATUS_TYPE](/zh-CN/api-reference/rtc/cpp-all-platforms/enum-musiccachestatustype)。
