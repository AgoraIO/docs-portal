---
<a id="enum_audiofilerecordingtype__detailed_desc"></a>

在 `startAudioRecording` 中设置。

<a id="enum_audiofilerecordingtype__parameters"></a>

## 枚举值

### `AUDIO_FILE_RECORDING_MIC`

（1）：仅录制本地用户音频。

### `AUDIO_FILE_RECORDING_PLAYBACK`

（2）：仅录制所有远端用户音频。

### `AUDIO_FILE_RECORDING_MIXED`

（3）：录制本地用户和所有远端用户的混合音频。
