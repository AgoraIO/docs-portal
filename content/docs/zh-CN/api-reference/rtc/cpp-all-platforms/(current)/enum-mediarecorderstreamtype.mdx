### `自从`

自 v3.5.2 版本新增。

<a id="enum_mediarecorderstreamtype__parameters"></a>

## 枚举值

### `STREAM_TYPE_AUDIO`

（0x01）：仅录制音频。

### `STREAM_TYPE_VIDEO`

（0x02）：仅录制视频。

### `STREAM_TYPE_BOTH`

（0x03）：录制音频和视频（默认）。
