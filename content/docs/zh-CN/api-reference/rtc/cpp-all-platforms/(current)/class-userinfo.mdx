<a id="class_userinfo__prototype"></a>

```cpp
struct UserInfo {
  uid_t uid;
  char userAccount[MAX_USER_ACCOUNT_LENGTH];
};
```

<a id="class_userinfo__parameters"></a>

## 属性

### `uid`

用户 ID。

### `userAccount`

用户 User Account。最大长度为 [MAX_USER_ACCOUNT_LENGTH_TYPE](/zh-CN/api-reference/rtc/cpp-all-platforms/enum-maxuseraccountlengthtype)。
