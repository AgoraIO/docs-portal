定义了 EGL 上下文的不同类型，对应不同的 OpenGL 接口实现。

<a id="enum_eglcontexttype__parameters"></a>

## 枚举值

### EGL_CONTEXT10

（0）：使用 Khronos 定义的 OpenGL 接口 (`javax.microedition.khronos.egl.*`)。

### EGL_CONTEXT14

（1）：使用 Android 定义的 OpenGL 接口 (`android.opengl.*`)。
