## 枚举值

### `RTMP_STREAM_LIFE_CYCLE_BIND2CHANNEL`

（1）：绑定到频道的生命周期。如果所有主播离开频道，CDN 推流将在 30 秒后停止。

### `RTMP_STREAM_LIFE_CYCLE_BIND2OWNER`

（2）：绑定到 RTMP 流拥有者的生命周期。如果拥有者离开频道，CDN 推流将立即停止。
