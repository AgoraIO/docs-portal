<a id="class_contentinspectconfig__prototype"></a>

```cpp
struct ContentInspectConfig {
  const char* extraInfo;
  const char* serverConfig;
  ContentInspectModule modules[MAX_CONTENT_INSPECT_MODULE_COUNT];
  int moduleCount;
};
```

<a id="class_contentinspectconfig__detailed_desc"></a>

SDK 会将视频截图和附加信息上传至声网服务器。上传完成后，声网服务器会将回调通知和附加信息发送至你的服务器。

:::info[注]
一个功能模块最多只能配置一个实例。目前仅支持本地截图上传功能。
:::

<a id="class_contentinspectconfig__parameters"></a>

## 属性

### `extraInfo`

视频内容的附加信息（最大长度为 1024 字节）。

### `serverConfig`

（可选）通过声网 Extensions Marketplace 上传视频截图的服务器配置。仅当 [ContentInspectModule](/zh-CN/api-reference/rtc/cpp-all-platforms/class-contentinspectmodule) 中的 `type` 设置为 `CONTENT_INSPECT_IMAGE_MODERATION` 时该参数才生效。如需使用，请[联系技术支持](https://ticket.shengwang.cn/)。

### `modules`

功能模块。最多可配置 32 个 [ContentInspectModule](/zh-CN/api-reference/rtc/cpp-all-platforms/class-contentinspectmodule) 实例。详见 [ContentInspectModule](/zh-CN/api-reference/rtc/cpp-all-platforms/class-contentinspectmodule)。

:::info[注]
一个功能模块最多只能配置一个实例。目前仅支持本地截图上传功能。
:::

### `moduleCount`

功能模块的数量，即配置的 [ContentInspectModule](/zh-CN/api-reference/rtc/cpp-all-platforms/class-contentinspectmodule) 实例数量，必须与 `modules` 中配置的实例数量一致。最大数量为 32。
