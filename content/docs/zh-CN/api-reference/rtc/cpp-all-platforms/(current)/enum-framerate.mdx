## 枚举值

### `FRAME_RATE_FPS_1`

（1）：1 帧每秒。

### `FRAME_RATE_FPS_7`

（7）：7 帧每秒。

### `FRAME_RATE_FPS_10`

（10）：10 帧每秒。

### `FRAME_RATE_FPS_15`

（15）：15 帧每秒。

### `FRAME_RATE_FPS_24`

（24）：24 帧每秒。

### `FRAME_RATE_FPS_30`

（30）：30 帧每秒。

### `FRAME_RATE_FPS_60`

（60）：60 帧每秒。

:::info[注]
仅适用于 Windows 和 macOS。
:::
