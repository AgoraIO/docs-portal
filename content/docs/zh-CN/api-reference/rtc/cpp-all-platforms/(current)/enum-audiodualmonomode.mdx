## 枚举值

<ParameterList>
<a id="audio_dual_mono_stereo"></a>
<Parameter name="AUDIO_DUAL_MONO_STEREO">

（0）：原始模式。

</Parameter>
<a id="audio_dual_mono_l"></a>
<Parameter name="AUDIO_DUAL_MONO_L">

（1）：左声道模式。该模式将右声道音频替换为左声道音频，用户只能听到左声道音频。

</Parameter>
<a id="audio_dual_mono_r"></a>
<Parameter name="AUDIO_DUAL_MONO_R">

（2）：右声道模式。该模式将左声道音频替换为右声道音频，用户只能听到右声道音频。

</Parameter>
<a id="audio_dual_mono_mix"></a>
<Parameter name="AUDIO_DUAL_MONO_MIX">

（3）：混合声道模式。该模式将左右声道音频混合，用户可同时听到左右声道音频。

</Parameter>
