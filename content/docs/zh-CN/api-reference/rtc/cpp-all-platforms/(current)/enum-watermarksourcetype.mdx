<a id="enum_watermarksourcetype__detailed_desc"></a>

### `自从`

自 v4.6.0 版本新增。

<a id="enum_watermarksourcetype__parameters"></a>

## 枚举值

### `IMAGE`

（0）：水印源为图像。

### `BUFFER`

（1）：水印源为缓冲区。

### `LITERAL`

（2）：水印源为文本字面量。

:::info[注]
仅支持在 Linux 平台使用。
:::

### `TIMESTAMPS`

（3）：水印源为时间戳。

:::info[注]
仅支持在 Linux 平台使用。
:::
