## 枚举值

### `SCREEN_CAPTURE_FRAMERATE_CAPABILITY_15_FPS`

（0）：设备支持最高 15 fps。

### `SCREEN_CAPTURE_FRAMERATE_CAPABILITY_30_FPS`

（1）：设备支持最高 30 fps。

### `SCREEN_CAPTURE_FRAMERATE_CAPABILITY_60_FPS`

（2）：设备支持最高 60 fps。
