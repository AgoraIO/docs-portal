## 属性

<ParameterList>
<a id="sourcetype"></a>
<Parameter name="sourceType">

视频源类型。详见 [VIDEO_SOURCE_TYPE](/zh-CN/api-reference/rtc/cpp-all-platforms/enum-videosourcetype)。

</Parameter>
<a id="remoteuseruid"></a>
<Parameter name="remoteUserUid">

远端用户 ID。

:::note
注： 仅当视频源类型为 `VIDEO_SOURCE_REMOTE` 时使用该参数。
:::

</Parameter>
<a id="imageurl"></a>
<Parameter name="imageUrl">

本地图像的文件路径，例如：Windows: C:\\Users\\\{username\}\\Pictures\\image.png。

:::note
注： 仅当视频源类型为图像时使用该参数。
:::

</Parameter>
<a id="mediaplayerid"></a>
<Parameter name="mediaPlayerId">

媒体播放器 ID。

:::note
注： 仅当视频源类型为 `VIDEO_SOURCE_MEDIA_PLAYER` 时使用该参数。
:::

</Parameter>
<a id="x"></a>
<Parameter name="x">

视频左上角相对于画布原点（画布左上角）的横向偏移。

</Parameter>
<a id="y"></a>
<Parameter name="y">

视频左上角相对于画布原点（画布左上角）的纵向偏移。

</Parameter>
<a id="width"></a>
<Parameter name="width">

视频在画布上的宽度（像素）。

</Parameter>
<a id="height"></a>
<Parameter name="height">

视频在画布上的高度（像素）。

</Parameter>
<a id="zorder"></a>
<Parameter name="zOrder">

视频图层的层级，取值范围为 [0, 100]。

- 0：（默认）图层位于最底层。
- 100：图层位于最顶层。

</Parameter>
<a id="alpha"></a>
<Parameter name="alpha">

视频的透明度，取值范围为 [0.0, 1.0]。

- 0.0：完全透明。
- 1.0：完全不透明。

</Parameter>
<a id="mirror"></a>
<Parameter name="mirror">

:::note
注： 该参数仅对摄像头类型的视频源生效。
:::

是否对视频进行镜像处理。

- true：镜像视频。
- false：（默认）不镜像视频。

</Parameter>
</ParameterList>
