## disableAudioSpectrumMonitor

禁用音频频谱监测。

<a id="api_irtcengine_disableaudiospectrummonitor__prototype"></a>

```cpp
virtual int disableAudioSpectrumMonitor() = 0;
```

<a id="api_irtcengine_disableaudiospectrummonitor__detailed_desc"></a>

调用 [enableAudioSpectrumMonitor](/zh-CN/api-reference/rtc/cpp-all-platforms/audio/audio-spectrum#api_irtcengine_enableaudiospectrummonitor) 后，如需关闭音频频谱监测，可调用该方法。

:::info[注]
你可以在加入频道前或加入频道后调用此方法。
:::

<a id="api_irtcengine_disableaudiospectrummonitor__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/windows/error-code)了解详情和解决建议。

### 所属接口类
- [IRtcEngine](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_irtcengine)

## enableAudioSpectrumMonitor

开启音频频谱监测。

<a id="api_irtcengine_enableaudiospectrummonitor__prototype"></a>

```cpp
virtual int enableAudioSpectrumMonitor(int intervalInMS = 100) = 0;
```

<a id="api_irtcengine_enableaudiospectrummonitor__detailed_desc"></a>

:::info[注]
[enableAudioSpectrumMonitor](/zh-CN/api-reference/rtc/cpp-all-platforms/audio/audio-spectrum#api_irtcengine_enableaudiospectrummonitor) 方法可以在加入频道前或加入频道后调用。
:::

<a id="api_irtcengine_enableaudiospectrummonitor__scenario"></a>

### 适用场景

你可以在加入频道前或加入频道后调用此方法。

<a id="api_irtcengine_enableaudiospectrummonitor__parameters"></a>

### 参数

#### `intervalInMS`

SDK 触发 [onLocalAudioSpectrum](/zh-CN/api-reference/rtc/cpp-all-platforms/audio/audio-spectrum#callback_iaudiospectrumobserver_onlocalaudiospectrum) 和 [onRemoteAudioSpectrum](/zh-CN/api-reference/rtc/cpp-all-platforms/audio/audio-spectrum#callback_iaudiospectrumobserver_onremoteaudiospectrum) 回调的时间间隔，单位为毫秒（默认值为 100，默认）。该参数值不能小于 10，否则调用该方法会失败。

<a id="api_irtcengine_enableaudiospectrummonitor__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/windows/error-code)了解详情和解决建议。
  - -2：参数无效。

### 所属接口类
- [IRtcEngine](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_irtcengine)

## registerAudioSpectrumObserver

注册音频频谱观察器。

<a id="api_irtcengine_registeraudiospectrumobserver__prototype"></a>

```cpp
virtual int registerAudioSpectrumObserver(agora::media::IAudioSpectrumObserver * observer) = 0;
```

<a id="api_irtcengine_registeraudiospectrumobserver__detailed_desc"></a>

成功注册音频频谱观察器并调用 [enableAudioSpectrumMonitor](/zh-CN/api-reference/rtc/cpp-all-platforms/audio/audio-spectrum#api_irtcengine_enableaudiospectrummonitor) 启用音频频谱监测后，SDK 会根据你设置的时间间隔，触发你在 [IAudioSpectrumObserver](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_iaudiospectrumobserver) 中实现的回调。

:::info[注]
你可以在加入频道前或加入频道后调用此方法。
:::

<a id="api_irtcengine_registeraudiospectrumobserver__parameters"></a>

### 参数

#### `observer`

音频频谱观察器。详见 [IAudioSpectrumObserver](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_iaudiospectrumobserver)。

<a id="api_irtcengine_registeraudiospectrumobserver__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/windows/error-code)了解详情和解决建议。

### 所属接口类
- [IRtcEngine](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_irtcengine)

:::info[注]
你可以在加入频道前或加入频道后调用此方法。
:::

<a id="api_irtcengine_unregisteraudiospectrumobserver__parameters"></a>

### 参数

#### `observer`

音频频谱观察器。详见 [IAudioSpectrumObserver](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_iaudiospectrumobserver)。

<a id="api_irtcengine_unregisteraudiospectrumobserver__return_values"></a>

### 返回值

- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/windows/error-code)了解详情和解决建议。

<a id="callback_iaudiospectrumobserver_onlocalaudiospectrum"></a>

## onLocalAudioSpectrum

本地音频频谱数据回调。

<a id="callback_iaudiospectrumobserver_onlocalaudiospectrum__prototype"></a>

```cpp
virtual bool onLocalAudioSpectrum(const AudioSpectrumData& data) = 0;
```

<a id="callback_iaudiospectrumobserver_onlocalaudiospectrum__detailed_desc"></a>

调用 [registerAudioSpectrumObserver](/zh-CN/api-reference/rtc/cpp-all-platforms/audio/audio-spectrum#api_irtcengine_registeraudiospectrumobserver) 注册 [IAudioSpectrumObserver](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_iaudiospectrumobserver) 接口并实现 [onLocalAudioSpectrum](/zh-CN/api-reference/rtc/cpp-all-platforms/audio/audio-spectrum#callback_iaudiospectrumobserver_onlocalaudiospectrum) 回调，同时调用 [enableAudioSpectrumMonitor](/zh-CN/api-reference/rtc/cpp-all-platforms/audio/audio-spectrum#api_irtcengine_enableaudiospectrummonitor) 启用音频频谱监测后，SDK 会按照设置的时间间隔，在编码前触发该回调，报告本地音频频谱数据。

<a id="callback_iaudiospectrumobserver_onlocalaudiospectrum__parameters"></a>

### 参数

#### `data`

本地用户的音频频谱数据。详见 [AudioSpectrumData](/zh-CN/api-reference/rtc/cpp-all-platforms/class-audiospectrumdata)。

<a id="callback_iaudiospectrumobserver_onlocalaudiospectrum__return_values"></a>

### 返回值

- true：接收到频谱数据。
- false：未接收到频谱数据。

### 所属接口类
- [IAudioSpectrumObserver](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_iaudiospectrumobserver)

<a id="callback_iaudiospectrumobserver_onremoteaudiospectrum"></a>

## onRemoteAudioSpectrum

远端音频频谱回调。

<a id="callback_iaudiospectrumobserver_onremoteaudiospectrum__prototype"></a>

```cpp
virtual bool onRemoteAudioSpectrum(const UserAudioSpectrumInfo* spectrums, unsigned int spectrumNumber) = 0;
```

<a id="callback_iaudiospectrumobserver_onremoteaudiospectrum__detailed_desc"></a>

成功调用 [registerAudioSpectrumObserver](/zh-CN/api-reference/rtc/cpp-all-platforms/audio/audio-spectrum#api_irtcengine_registeraudiospectrumobserver) 实现 [onRemoteAudioSpectrum](/zh-CN/api-reference/rtc/cpp-all-platforms/audio/audio-spectrum#callback_iaudiospectrumobserver_onremoteaudiospectrum) 回调，并调用 [enableAudioSpectrumMonitor](/zh-CN/api-reference/rtc/cpp-all-platforms/audio/audio-spectrum#api_irtcengine_enableaudiospectrummonitor) 启用音频频谱监测后，SDK 会按照你设置的时间间隔触发该回调，报告接收到的远端音频数据频谱。

<a id="callback_iaudiospectrumobserver_onremoteaudiospectrum__timing"></a>

### 触发时机

SDK 会按照你设置的时间间隔触发该回调，报告接收到的远端音频数据频谱。

<a id="callback_iaudiospectrumobserver_onremoteaudiospectrum__parameters"></a>

### 参数

#### `spectrums`

远端用户的音频频谱信息。数组长度为 SDK 监测到的远端用户数量。如果该数组为 NULL，表示未检测到远端用户的音频频谱。详见 [UserAudioSpectrumInfo](/zh-CN/api-reference/rtc/cpp-all-platforms/class-useraudiospectruminfo)。

#### `spectrumNumber`

远端用户的数量。

<a id="callback_iaudiospectrumobserver_onremoteaudiospectrum__return_values"></a>

### 返回值

- true：接收到频谱数据。
- false：未接收到频谱数据。

### 所属接口类
- [IAudioSpectrumObserver](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_iaudiospectrumobserver)
