## getEarMonitoringAudioParams

onEarMonitoringAudioFrame 回调的音频格式设置回调。

<a id="api_iaudioframeobserverbase_getearmonitoringaudioparams_iaudioframeobserverbase__prototype"></a>

```cpp
virtual AudioParams getEarMonitoringAudioParams() = 0;
```

<a id="api_iaudioframeobserverbase_getearmonitoringaudioparams_iaudioframeobserverbase__detailed_desc"></a>

调用 [registerAudioFrameObserver](/zh-CN/api-reference/rtc/cpp-all-platforms/audio/audio-raw#api_imediaengine_registeraudioframeobserver_imediaengine) 注册音频帧观察者时，需要实现该回调。注册成功后，SDK 会触发该回调，你可以在返回值中设置音频格式。

:::info[注]
SDK 会根据你在返回值中设置的采样间隔计算公式触发 [onEarMonitoringAudioFrame](/zh-CN/api-reference/rtc/cpp-all-platforms/audio/audio-raw#callback_iaudioframeobserverbase_onearmonitoringaudioframe_iaudioframeobserverbase) 回调。计算公式为：采样间隔（秒） = samplePerCall / (sampleRate × channel)。请确保采样间隔 ≥ 0.01 秒。
:::

<a id="api_iaudioframeobserverbase_getearmonitoringaudioparams_iaudioframeobserverbase__return_values"></a>

### 返回值

方法调用成功时，返回一个 [AudioParams](/zh-CN/api-reference/rtc/cpp-all-platforms/class-audioparams) 对象，表示耳返音频数据格式，详见 [AudioParams](/zh-CN/api-reference/rtc/cpp-all-platforms/class-audioparams)。

- [IAudioFrameObserverBase](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_iaudioframeobserverbase)

## getObservedAudioFramePosition

设置音频数据观察位置。

<a id="api_iaudioframeobserverbase_getobservedaudioframeposition_iaudioframeobserverbase__prototype"></a>

```cpp
virtual int getObservedAudioFramePosition() = 0;
```

<a id="api_iaudioframeobserverbase_getobservedaudioframeposition_iaudioframeobserverbase__detailed_desc"></a>

成功注册音频数据观察器后，SDK 会在每个特定的音频帧处理节点调用该回调，以判断是否触发以下回调：

- [onRecordAudioFrame](/zh-CN/api-reference/rtc/cpp-all-platforms/audio/audio-raw#callback_iaudioframeobserverbase_onrecordaudioframe_iaudioframeobserverbase)
- [onPlaybackAudioFrame](/zh-CN/api-reference/rtc/cpp-all-platforms/audio/audio-raw#callback_iaudioframeobserverbase_onplaybackaudioframe_iaudioframeobserverbase)
- [onPlaybackAudioFrameBeforeMixing](/zh-CN/api-reference/rtc/cpp-all-platforms/audio/audio-raw#callback_iaudioframeobserverbase_onplaybackaudioframebeforemixing_iaudioframeobserverbase)
- [onMixedAudioFrame](/zh-CN/api-reference/rtc/cpp-all-platforms/audio/audio-raw#callback_iaudioframeobserverbase_onmixedaudioframe_iaudioframeobserverbase)
- [onEarMonitoringAudioFrame](/zh-CN/api-reference/rtc/cpp-all-platforms/audio/audio-raw#callback_iaudioframeobserverbase_onearmonitoringaudioframe_iaudioframeobserverbase)

你可以根据实际场景，通过修改 [getObservedAudioFramePosition](/zh-CN/api-reference/rtc/cpp-all-platforms/audio/audio-raw#api_iaudioframeobserverbase_getobservedaudioframeposition_iaudioframeobserverbase) 的返回值设置需要观察的一个或多个位置。 如果需要同时观察多个位置，需使用按位或运算符（|）。为节省系统资源，建议只设置必要的观察位置。

<a id="api_iaudioframeobserverbase_getobservedaudioframeposition_iaudioframeobserverbase__return_values"></a>

### 返回值

一个位掩码，用于设置观察位置，具体取值如下：

- `AUDIO_FRAME_POSITION_PLAYBACK` （0x0001）：可观察所有远端用户混音后的播放音频。对应回调为 [onPlaybackAudioFrame](/zh-CN/api-reference/rtc/cpp-all-platforms/audio/audio-raw#callback_iaudioframeobserverbase_onplaybackaudioframe_iaudioframeobserverbase)。
- `AUDIO_FRAME_POSITION_RECORD` （0x0002）：可观察本地用户采集的音频。对应回调为 [onRecordAudioFrame](/zh-CN/api-reference/rtc/cpp-all-platforms/audio/audio-raw#callback_iaudioframeobserverbase_onrecordaudioframe_iaudioframeobserverbase)。
- `AUDIO_FRAME_POSITION_MIXED` （0x0004）：可观察本地用户与所有远端用户混音后的播放音频。对应回调为 [onMixedAudioFrame](/zh-CN/api-reference/rtc/cpp-all-platforms/audio/audio-raw#callback_iaudioframeobserverbase_onmixedaudioframe_iaudioframeobserverbase)。
- `AUDIO_FRAME_POSITION_BEFORE_MIXING` （0x0008）：可观察单个远端用户混音前的音频。对应回调为 [onPlaybackAudioFrameBeforeMixing](/zh-CN/api-reference/rtc/cpp-all-platforms/audio/audio-raw#callback_iaudioframeobserverbase_onplaybackaudioframebeforemixing_iaudioframeobserverbase)。
- `AUDIO_FRAME_POSITION_EAR_MONITORING` （0x0010）：可观察本地用户的耳返音频。对应回调为 [onEarMonitoringAudioFrame](/zh-CN/api-reference/rtc/cpp-all-platforms/audio/audio-raw#callback_iaudioframeobserverbase_onearmonitoringaudioframe_iaudioframeobserverbase)。

- [IAudioFrameObserverBase](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_iaudioframeobserverbase)

## setEarMonitoringAudioFrameParameters

设置耳返音频数据的格式。

<a id="api_irtcengine_setearmonitoringaudioframeparameters__prototype"></a>

```cpp
virtual int setEarMonitoringAudioFrameParameters(int sampleRate, int channel, RAW_AUDIO_FRAME_OP_MODE_TYPE mode, int samplesPerCall) = 0;
```

<a id="api_irtcengine_setearmonitoringaudioframeparameters__detailed_desc"></a>

该方法用于设置 [onEarMonitoringAudioFrame](/zh-CN/api-reference/rtc/cpp-all-platforms/audio/audio-raw#callback_iaudioframeobserverbase_onearmonitoringaudioframe_iaudioframeobserverbase) 回调中报告的耳返音频数据格式。

:::info[注]
- 在调用该方法前，需先调用 [enableInEarMonitoring](/zh-CN/api-reference/rtc/cpp-all-platforms/audio/audio-capture#api_irtcengine_enableinearmonitoring2)，并将 `includeAudioFilters` 设置为 `EAR_MONITORING_FILTER_BUILT_IN_AUDIO_FILTERS` 或 `EAR_MONITORING_FILTER_NOISE_SUPPRESSION`。
- SDK 会根据该方法中设置的 `samplesPerCall`、 `sampleRate` 和 `channel` 参数计算采样间隔。采样间隔（秒）= `samplesPerCall` /（`sampleRate` × `channel` ）。请确保采样间隔 ≥ 0.01 秒。SDK 会根据采样间隔触发 [onEarMonitoringAudioFrame](/zh-CN/api-reference/rtc/cpp-all-platforms/audio/audio-raw#callback_iaudioframeobserverbase_onearmonitoringaudioframe_iaudioframeobserverbase) 回调。
:::

<a id="api_irtcengine_setearmonitoringaudioframeparameters__parameters"></a>

### 参数

#### `sampleRate`

[onEarMonitoringAudioFrame](/zh-CN/api-reference/rtc/cpp-all-platforms/audio/audio-raw#callback_iaudioframeobserverbase_onearmonitoringaudioframe_iaudioframeobserverbase) 回调中报告的音频采样率。可设置为 8000、16000、32000、44100 或 48000 Hz。

#### `channel`

[onEarMonitoringAudioFrame](/zh-CN/api-reference/rtc/cpp-all-platforms/audio/audio-raw#callback_iaudioframeobserverbase_onearmonitoringaudioframe_iaudioframeobserverbase) 回调中报告的音频通道数。

- 1：单声道。
- 2：立体声。

#### `mode`

音频帧的使用模式，详见 [RAW_AUDIO_FRAME_OP_MODE_TYPE](/zh-CN/api-reference/rtc/cpp-all-platforms/enum-rawaudioframeopmodetype)。

#### `samplesPerCall`

[onEarMonitoringAudioFrame](/zh-CN/api-reference/rtc/cpp-all-platforms/audio/audio-raw#callback_iaudioframeobserverbase_onearmonitoringaudioframe_iaudioframeobserverbase) 回调中每次报告的采样点数量，例如媒体推流时为 1024。

<a id="api_irtcengine_setearmonitoringaudioframeparameters__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/windows/error-code)了解详情和解决建议。

- [IRtcEngine](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_irtcengine)

#### `sampleRate`

回调中返回的采样率。可设置为 8000、16000、32000、44100 或 48000（Hz）。

#### `channel`

音频声道数。可设置为：

- 1：单声道。
- 2：立体声。

#### `mode`

音频帧的使用模式，详见 [RAW_AUDIO_FRAME_OP_MODE_TYPE](/zh-CN/api-reference/rtc/cpp-all-platforms/enum-rawaudioframeopmodetype)。

#### `samplesPerCall`

每次回调的数据采样数，例如媒体推流时为 1024。

:::info[注]
