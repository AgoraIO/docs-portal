## adjustCustomAudioPlayoutVolume

调节本地播放的自定义音频轨道的音量。

<a id="api_irtcengine_adjustcustomaudioplayoutvolume__prototype"></a>

```cpp
virtual int adjustCustomAudioPlayoutVolume(track_id_t trackId, int volume) = 0;
```

<a id="api_irtcengine_adjustcustomaudioplayoutvolume__detailed_desc"></a>

如果你想更改本地播放的音频音量，需要再次调用该方法。

:::info[注]
请确保在调用该方法前，已通过调用 [createCustomAudioTrack](/zh-CN/api-reference/rtc/cpp-all-platforms/audio/audio-custom-capturenrendering#api_imediaengine_createcustomaudiotrack_imediaengine) 创建自定义音频轨道。
:::

<a id="api_irtcengine_adjustcustomaudioplayoutvolume__parameters"></a>

### 参数

#### `trackId`

音频轨道 ID，设置为 [createCustomAudioTrack](/zh-CN/api-reference/rtc/cpp-all-platforms/audio/audio-custom-capturenrendering#api_imediaengine_createcustomaudiotrack_imediaengine) 返回的自定义音频轨道 ID。

#### `volume`

音频源的音量，取值范围为 0 到 100。

- 0：静音。
- 100：原始音量。

<a id="api_irtcengine_adjustcustomaudioplayoutvolume__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/windows/error-code)了解详情和解决建议。

- [IRtcEngine](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_irtcengine)

## createCustomAudioTrack

创建自定义音频轨道。

<a id="api_imediaengine_createcustomaudiotrack_imediaengine__prototype"></a>

```cpp
virtual rtc::track_id_t createCustomAudioTrack(rtc::AUDIO_TRACK_TYPE trackType, const rtc::AudioTrackConfig& config) = 0;
```

<a id="api_imediaengine_createcustomaudiotrack_imediaengine__detailed_desc"></a>

要发布自定义音频源，请按照以下步骤操作：

1. 调用该方法创建一个自定义音频轨道，并获取音频轨道 ID。
2. 调用 `joinChannel` 加入频道。在 [ChannelMediaOptions](/zh-CN/api-reference/rtc/cpp-all-platforms/class-channelmediaoptions) 中，将 `publishCustomAudioTrackId` 设置为你要发布的音频轨道 ID，并将 `publishCustomAudioTrack` 设置为 true。
3. 调用 [pushAudioFrame](/zh-CN/api-reference/rtc/cpp-all-platforms/audio/audio-custom-capturenrendering#api_imediaengine_pushaudioframe)，并将 `trackId` 设置为步骤 2 中设置的音频轨道 ID，即可在频道中发布对应的自定义音频源。

<a id="api_imediaengine_createcustomaudiotrack_imediaengine__timing"></a>

### 调用时机

该方法需要在加入频道前调用。

<a id="api_imediaengine_createcustomaudiotrack_imediaengine__parameters"></a>

### 参数

#### `trackType`

自定义音频轨道的类型，详见 [AUDIO_TRACK_TYPE](/zh-CN/api-reference/rtc/cpp-all-platforms/enum-audiotracktype)。

:::info[注]
如果该参数设置为 `AUDIO_TRACK_DIRECT`，则在调用 `joinChannel` 加入频道时，必须将 [ChannelMediaOptions](/zh-CN/api-reference/rtc/cpp-all-platforms/class-channelmediaoptions) 中的 `publishMicrophoneTrack` 设置为 false，否则加入频道会失败并返回错误码 -2。
:::

#### `config`

自定义音频轨道的配置，详见 [AudioTrackConfig](/zh-CN/api-reference/rtc/cpp-all-platforms/class-audiotrackconfig)。

<a id="api_imediaengine_createcustomaudiotrack_imediaengine__return_values"></a>

### 返回值

- 方法调用成功，返回音频轨道 ID，作为该音频轨道的唯一标识符。
- 方法调用失败，返回 `0xffffffff`。

- [IMediaEngine](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_imediaengine)

音频轨道 ID，设置为 [createCustomAudioTrack](/zh-CN/api-reference/rtc/cpp-all-platforms/audio/audio-custom-capturenrendering#api_imediaengine_createcustomaudiotrack_imediaengine) 返回的自定义音频轨道 ID。

## pullAudioFrame

拉取远端混音后的音频数据。

<a id="api_imediaengine_pullaudioframe_imediaengine__prototype"></a>

```cpp
virtual int pullAudioFrame(IAudioFrameObserverBase::AudioFrame* frame) = 0;
```

<a id="api_imediaengine_pullaudioframe_imediaengine__detailed_desc"></a>

调用该方法后，App 会拉取解码并混音后的音频数据用于播放。该方法需要在加入频道后调用。在调用该方法前，请先调用 [setExternalAudioSink](/zh-CN/api-reference/rtc/cpp-all-platforms/audio/audio-custom-capturenrendering#api_imediaengine_setexternalaudiosink_imediaengine) 启用并设置外部音频渲染。

:::info[注]
[pullAudioFrame](/zh-CN/api-reference/rtc/cpp-all-platforms/audio/audio-custom-capturenrendering#api_imediaengine_pullaudioframe_imediaengine) 和 [onPlaybackAudioFrame](/zh-CN/api-reference/rtc/cpp-all-platforms/audio/audio-raw#callback_iaudioframeobserverbase_onplaybackaudioframe_iaudioframeobserverbase) 回调都可用于获取远端混音后的音频数据。启用外部音频渲染（调用 [setExternalAudioSink](/zh-CN/api-reference/rtc/cpp-all-platforms/audio/audio-custom-capturenrendering#api_imediaengine_setexternalaudiosink_imediaengine) ）后，App 将无法再通过 [onPlaybackAudioFrame](/zh-CN/api-reference/rtc/cpp-all-platforms/audio/audio-raw#callback_iaudioframeobserverbase_onplaybackaudioframe_iaudioframeobserverbase) 回调获取数据。请根据实际业务需求选择使用该方法或 [onPlaybackAudioFrame](/zh-CN/api-reference/rtc/cpp-all-platforms/audio/audio-raw#callback_iaudioframeobserverbase_onplaybackaudioframe_iaudioframeobserverbase) 回调。两者的区别如下：

- 调用 [pullAudioFrame](/zh-CN/api-reference/rtc/cpp-all-platforms/audio/audio-custom-capturenrendering#api_imediaengine_pullaudioframe_imediaengine) 后，App 会自动从 SDK 拉取音频数据。通过设置音频数据参数，SDK 会调整帧缓冲区，帮助 App 处理延迟，有效避免音频播放抖动。
- 注册 [onPlaybackAudioFrame](/zh-CN/api-reference/rtc/cpp-all-platforms/audio/audio-raw#callback_iaudioframeobserverbase_onplaybackaudioframe_iaudioframeobserverbase) 回调后，SDK 会通过回调将音频数据发送给 App。若 App 处理音频帧的过程存在延迟，可能会导致音频抖动。

该方法仅用于获取远端混音后的音频数据。如果你需要获取采集、播放等不同音频处理阶段的数据，可以通过调用 [registerAudioFrameObserver](/zh-CN/api-reference/rtc/cpp-all-platforms/audio/audio-raw#api_imediaengine_registeraudioframeobserver_imediaengine) 注册相应的回调。
:::

<a id="api_imediaengine_pullaudioframe_imediaengine__timing"></a>

### 调用时机

该方法需要在加入频道后调用。

<a id="api_imediaengine_pullaudioframe_imediaengine__parameters"></a>

### 参数

#### `frame`

输出参数，指向 [AudioFrame](/zh-CN/api-reference/rtc/cpp-all-platforms/class-audioframe) 的指针。详见 [AudioFrame](/zh-CN/api-reference/rtc/cpp-all-platforms/class-audioframe)。

<a id="api_imediaengine_pullaudioframe_imediaengine__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/windows/error-code)了解详情和解决建议。

## setExternalAudioSink

设置外部音频渲染器。

<a id="api_imediaengine_setexternalaudiosink_imediaengine__prototype"></a>

```cpp
virtual int setExternalAudioSink(bool enabled, int sampleRate, int channels) = 0;
```

<a id="api_imediaengine_setexternalaudiosink_imediaengine__detailed_desc"></a>

启用外部音频渲染器后，你可以调用 [pullAudioFrame](/zh-CN/api-reference/rtc/cpp-all-platforms/audio/audio-custom-capturenrendering#api_imediaengine_pullaudioframe_imediaengine) 方法拉取远端音频帧，处理后使用自定义音效进行播放，适用于需要使用外部音频数据播放的场景。

:::info[注]
启用外部音频渲染器后，应用将无法从 [onPlaybackAudioFrame](/zh-CN/api-reference/rtc/cpp-all-platforms/audio/audio-raw#callback_iaudioframeobserverbase_onplaybackaudioframe_iaudioframeobserverbase) 回调中获取任何音频数据。
:::

<a id="api_imediaengine_setexternalaudiosink_imediaengine__timing"></a>

### 调用时机

请在加入频道前调用该方法。

<a id="api_imediaengine_setexternalaudiosink_imediaengine__parameters"></a>

### 参数

#### `enabled`

是否启用外部音频渲染器：

- true：启用外部音频渲染器。
- false：（默认）禁用外部音频渲染器。

#### `sampleRate`

外部音频渲染器的采样率（Hz），可设置为 16000、32000、44100 或 48000。

#### `channels`

外部音频渲染器的声道数：

- 1：单声道。
- 2：双声道。

<a id="api_imediaengine_setexternalaudiosink_imediaengine__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/windows/error-code)了解详情和解决建议。

- [IMediaEngine](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_imediaengine)
