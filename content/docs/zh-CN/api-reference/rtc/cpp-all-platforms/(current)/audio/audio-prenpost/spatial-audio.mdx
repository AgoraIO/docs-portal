## muteAllRemoteAudioStreams

停止或恢复订阅所有远端用户的音频流。

<a id="api_ilocalspatialaudioengine_muteallremoteaudiostreams_ilocalspatialaudioengine__prototype"></a>

```text
virtual int muteAllRemoteAudioStreams(bool mute) = 0;
```

<a id="api_ilocalspatialaudioengine_muteallremoteaudiostreams_ilocalspatialaudioengine__detailed_desc"></a>

调用该方法后，本地用户将停止或恢复订阅所有远端用户的音频流，包括后续加入频道的用户。

:::note
注：

- 请在调用 `joinChannel` 方法后调用本方法。
- 使用空间音效时，如需设置是否停止订阅所有远端用户的音频流，声网推荐使用本方法，而非 [IRtcEngine](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_irtcengine) 下的同名方法。
- 调用本方法后，需要调用 [updateSelfPosition](/zh-CN/api-reference/rtc/cpp-all-platforms/audio/audio-prenpost/spatial-audio#api_ilocalspatialaudioengine_updateselfposition_ilocalspatialaudioengine) 和 [updateRemotePosition](/zh-CN/api-reference/rtc/cpp-all-platforms/audio/audio-prenpost/spatial-audio#api_ilocalspatialaudioengine_updateremoteposition) 更新本地用户和远端用户的空间位置，否则本方法的设置不会生效。
:::

<ParameterList>
<a id="mute"></a>

- false：订阅所有远端用户的音频流。

</ParameterList>

  - 如果声源和收听者分别位于隔音区内外，声音衰减效果由 [SpatialAudioZone](/zh-CN/api-reference/rtc/cpp-all-platforms/class-spatialaudiozone) 中的 `audioAttenuation` 决定。
  - 如果声源和收听者位于同一隔音区内或同一隔音区外，声音衰减效果由本方法中的 `attenuation` 决定。

</Parameter>
</ParameterList>

## setZones

设置隔音区域。

<a id="api_ilocalspatialaudioengine_setzones_ilocalspatialaudioengine__prototype"></a>

```text
virtual int setZones(const SpatialAudioZone *zones, unsigned int zoneCount) = 0;
```

<a id="api_ilocalspatialaudioengine_setzones_ilocalspatialaudioengine__detailed_desc"></a>

在虚拟互动场景中，你可以使用该方法设置隔音区域及其声音衰减系数。当声源（用户或媒体播放器）和接收者分别位于隔音区域的内外时，可以模拟现实中声音被建筑物阻隔时的衰减效果：

- 当声源和接收者分别位于隔音区域的内外时，声音的衰减效果由 [SpatialAudioZone](/zh-CN/api-reference/rtc/cpp-all-platforms/class-spatialaudiozone) 中的衰减系数决定。
- 当用户或媒体播放器处于同一个隔音区域内时，不受 [SpatialAudioZone](/zh-CN/api-reference/rtc/cpp-all-platforms/class-spatialaudiozone) 的影响，声音衰减效果由 [setPlayerAttenuation](/zh-CN/api-reference/rtc/cpp-all-platforms/audio/audio-prenpost/spatial-audio#api_ilocalspatialaudioengine_setplayerattenuation_ilocalspatialaudioengine) 或 [setRemoteAudioAttenuation](/zh-CN/api-reference/rtc/cpp-all-platforms/audio/audio-prenpost/spatial-audio#api_ilocalspatialaudioengine_setremoteaudioattenuation) 中的 `attenuation` 参数决定。若未调用上述方法，SDK 默认使用 0.5 的声音衰减系数。
- 当声源和接收者分别位于两个不同的隔音区域中，接收者将无法听到声源。

:::note
注： 如果多次调用该方法，以最后一次设置的隔音区域为准。
:::

:::note
注： 在 Windows 平台上，必须确保 `zones` 数组中的成员数量等于 `zoneCount` 的值，否则可能导致崩溃。
