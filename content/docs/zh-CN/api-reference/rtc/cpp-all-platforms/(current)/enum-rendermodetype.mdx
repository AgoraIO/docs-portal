## 枚举值

### RENDER_MODE_HIDDEN

（1）：隐藏模式。优先填满窗口，超出窗口尺寸的视频部分将被裁剪。

### RENDER_MODE_FIT

（2）：适应模式。优先完整显示全部视频内容，未填满窗口的区域以黑色填充。

### RENDER_MODE_ADAPTIVE

（3）：自适应模式。该枚举已废弃，不推荐使用
