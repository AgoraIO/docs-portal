<a id="class_screenaudioparameters__prototype"></a>

```cpp
struct ScreenAudioParameters {
  int sampleRate;
  int channels;
  int captureSignalVolume;
#if defined(__APPLE__) && !TARGET_OS_IOS
  bool excludeCurrentProcessAudio = true;
#else
#endif
};
```

<a id="class_screenaudioparameters__detailed_desc"></a>

仅当 `captureAudio` 为 true 时生效。

<a id="class_screenaudioparameters__parameters"></a>

## 属性

### `sampleRate`

音频采样率，单位为 Hz。

### `channels`

音频通道数。默认值为 2，表示立体声。

### `captureSignalVolume`

采集的系统音频音量，取值范围为 [0, 100]，默认值为 100。
