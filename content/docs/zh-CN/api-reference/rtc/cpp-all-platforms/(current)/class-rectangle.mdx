---
title: "Rectangle"
description: "用于设置目标区域相对于屏幕或窗口的位置。"
---
<a id="class_rectangle__prototype"></a>

```cpp
struct Rectangle {
  int x;
  int y;
  int width;
  int height;
};
```

<a id="class_rectangle__parameters"></a>

## 属性

### `x`

距左上角的水平偏移量。

### `y`

距左上角的垂直偏移量。

### `width`

目标区域的宽度。

### `height`

目标区域的高度。
