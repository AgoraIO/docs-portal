## 枚举值

<ParameterList>
<a id="voice_beautifier_off"></a>
<Parameter name="VOICE_BEAUTIFIER_OFF">

（0x00000000）：关闭声动语聊美声效果，使用原始语音。

</Parameter>
<a id="chat_beautifier_magnetic"></a>
<Parameter name="CHAT_BEAUTIFIER_MAGNETIC">

（0x01010100）：更具磁性的声音。

:::note
注： 声网建议用于处理男性音色，否则可能会出现声音失真。
:::

</Parameter>
<a id="chat_beautifier_fresh"></a>
<Parameter name="CHAT_BEAUTIFIER_FRESH">

（0x01010200）：更清新的声音。

:::note
注： 声网建议用于处理女性音色，否则可能会出现声音失真。
:::

</Parameter>
<a id="chat_beautifier_vitality"></a>
<Parameter name="CHAT_BEAUTIFIER_VITALITY">

（0x01010300）：更有活力的声音。

:::note
注： 声网建议用于处理女性音色，否则可能会出现声音失真。
:::

</Parameter>
<a id="singing_beautifier"></a>
<Parameter name="SINGING_BEAUTIFIER">

（0x01020100）：歌唱美声效果。

:::note
注： 调用 `setVoiceBeautifierPreset(SINGING_BEAUTIFIER)` 可美化男性音色并添加小房间混响效果，建议用于男性音色，否则可能出现声音失真。调用 `setVoiceBeautifierParameters(SINGING_BEAUTIFIER, param1, param2)` 可美化男性或女性音色并添加混响效果。
:::

</Parameter>
<a id="timbre_transformation_vigorous"></a>
<Parameter name="TIMBRE_TRANSFORMATION_VIGOROUS">

（0x01030100）：更有力量感的声音。

</Parameter>
<a id="timbre_transformation_deep"></a>
<Parameter name="TIMBRE_TRANSFORMATION_DEEP">

（0x01030200）：更深沉的声音。

</Parameter>
<a id="timbre_transformation_mellow"></a>
<Parameter name="TIMBRE_TRANSFORMATION_MELLOW">

（0x01030300）：更圆润的声音。

</Parameter>
<a id="timbre_transformation_falsetto"></a>
<Parameter name="TIMBRE_TRANSFORMATION_FALSETTO">

（0x01030400）：假声效果。

</Parameter>
<a id="timbre_transformation_full"></a>
<Parameter name="TIMBRE_TRANSFORMATION_FULL">

（0x01030500）：更饱满的声音。

</Parameter>
<a id="timbre_transformation_clear"></a>
<Parameter name="TIMBRE_TRANSFORMATION_CLEAR">

（0x01030600）：更清晰的声音。

</Parameter>
<a id="timbre_transformation_resounding"></a>
<Parameter name="TIMBRE_TRANSFORMATION_RESOUNDING">

（0x01030700）：更洪亮的声音。

</Parameter>
<a id="timbre_transformation_ringing"></a>
<Parameter name="TIMBRE_TRANSFORMATION_RINGING">

（0x01030800）：更响亮的声音。

</Parameter>
<a id="ultra_high_quality_voice"></a>
<Parameter name="ULTRA_HIGH_QUALITY_VOICE">

（0x01040100）：超高音质效果，使音频更清晰并还原更多细节。

:::note
注： 为获得更好的音效质量，建议在调用 [setVoiceBeautifierPreset](/zh-CN/api-reference/rtc/cpp-all-platforms/audio/audio-prenpost/audio-effect#api_irtcengine_setvoicebeautifierpreset) 前，将 `setAudioProfile(AUDIO_PROFILE_TYPE profile)` 的 `profile` 设置为 `AUDIO_PROFILE_MUSIC_HIGH_QUALITY`（4）或 `AUDIO_PROFILE_MUSIC_HIGH_QUALITY_STEREO`（5），并将 `scenario` 设置为 `AUDIO_SCENARIO_GAME_STREAMING`（3）。如果音频采集设备本身已具备高保真能力，建议不要启用超高音质，否则 SDK 可能会过度还原音频细节，导致无法获得预期的声音效果。
:::

</Parameter>
