## 枚举值

### `RELAY_STATE_IDLE`

（0）：初始状态。调用 [stopChannelMediaRelay](/zh-CN/api-reference/rtc/cpp-all-platforms/channel-media-relay#api_irtcengine_stopchannelmediarelay) 成功停止跨频道媒体流转发后， [onChannelMediaRelayStateChanged](/zh-CN/api-reference/rtc/cpp-all-platforms/channel-media-relay#callback_irtcengineeventhandler_onchannelmediarelaystatechanged) 回调返回该状态。

### `RELAY_STATE_CONNECTING`

（1）：SDK 正在尝试将媒体流转发至目标频道。

### `RELAY_STATE_RUNNING`

（2）：SDK 已成功将媒体流转发至目标频道。

### `RELAY_STATE_FAILURE`

（3）：发生错误。详见 [onChannelMediaRelayStateChanged](/zh-CN/api-reference/rtc/cpp-all-platforms/channel-media-relay#callback_irtcengineeventhandler_onchannelmediarelaystatechanged) 回调中的 `code`。
