## 枚举值

### `VIDEO_DENOISER_LEVEL_HIGH_QUALITY`

（0）：（默认）在视频降噪过程中提升视频质量，平衡性能消耗与降噪效果。该设置下性能消耗适中，降噪速度适中，整体视频质量最佳。

### `VIDEO_DENOISER_LEVEL_FAST`

（1）：在视频降噪过程中降低性能消耗，优先考虑性能而非降噪质量。该设置下性能消耗较低，降噪速度更快。为避免处理后的视频出现明显拖影（即移动物体后方出现阴影），声网建议在摄像头固定时使用该设置。
