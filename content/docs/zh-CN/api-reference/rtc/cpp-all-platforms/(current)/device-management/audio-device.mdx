## enumeratePlaybackDevices

枚举系统中的音频播放设备。

<a id="api_iaudiodevicemanager_enumerateplaybackdevices__prototype"></a>

```cpp
virtual IAudioDeviceCollection *enumeratePlaybackDevices() = 0;
```

<a id="api_iaudiodevicemanager_enumerateplaybackdevices__detailed_desc"></a>

该方法返回一个 [IAudioDeviceCollection](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_iaudiodevicecollection) 对象，包含系统中的所有音频播放设备。使用该对象后，必须调用 [release](/zh-CN/api-reference/rtc/cpp-all-platforms/device-management/audio-device#api_iaudiodevicemanager_release_iaudiodevicemanager) 方法释放资源。

:::info[注]
该方法仅适用于 Windows 和 macOS 平台。
:::

<a id="api_iaudiodevicemanager_enumerateplaybackdevices__return_values"></a>

### 返回值

- 方法调用成功，返回一个 IAudioDeviceCollection 对象，详见 IAudioDeviceCollection。
- 方法调用失败，返回 NULL。

### 所属接口类
- [IAudioDeviceManager](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_iaudiodevicemanager)

## followSystemLoopbackDevice

设置是否跟随系统默认音频播放设备。

<a id="api_iaudiodevicemanager_followsystemloopbackdevice__prototype"></a>

```cpp
virtual int followSystemLoopbackDevice(bool enable) = 0;
```

<a id="api_iaudiodevicemanager_followsystemloopbackdevice__detailed_desc"></a>

该方法仅适用于 Windows 和 macOS 平台。

<a id="api_iaudiodevicemanager_followsystemloopbackdevice__parameters"></a>

### 参数

#### `enable`

是否跟随系统默认音频播放设备：

- true：跟随系统默认音频播放设备。当系统默认播放设备发生变化时，SDK 会立即切换到对应的声卡采集设备。
- false：不跟随系统默认音频播放设备。仅当当前音频播放设备断开连接时，SDK 才会将声卡采集设备切换为系统默认音频播放设备。

<a id="api_iaudiodevicemanager_followsystemloopbackdevice__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](/zh-CN/realtime-media/rtc/reference/error-code)了解详情和解决建议。

### 所属接口类
- [IAudioDeviceManager](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_iaudiodevicemanager)

## setLoopbackDevice

设置 SDK 的声卡采集设备。

<a id="api_iaudiodevicemanager_setloopbackdevice__prototype"></a>

```cpp
virtual int setLoopbackDevice(const char deviceId[MAX_DEVICE_ID_LENGTH]) = 0;
```

<a id="api_iaudiodevicemanager_setloopbackdevice__detailed_desc"></a>

SDK 默认使用当前播放设备作为声卡采集设备。如果你希望指定其他音频设备作为声卡采集设备，可以调用该方法，并将 `deviceId` 设置为目标设备。你可以通过该方法更改当前使用的音频路由，但不会更改默认音频路由。例如，若默认音频路由为麦克风，在加入频道前调用该方法将音频路由设置为声卡并开始设备测试，SDK 会在声卡上进行测试。测试完成并加入频道后，SDK 仍使用麦克风进行音频采集。

:::info[注]
该方法仅适用于 Windows 和 macOS 平台。
:::

<a id="api_iaudiodevicemanager_setloopbackdevice__scenario"></a>

### 适用场景

该方法适用的典型场景如下： 使用 App A 通过蓝牙耳机播放音乐，同时使用 App B 进行视频通话并通过扬声器播放：

- 如果将声卡采集设备设置为蓝牙耳机，SDK 会将 App A 播放的音乐发布到远端。
- 如果将声卡采集设备设置为扬声器，SDK 不会将 App A 播放的音乐发布到远端。
- 如果先将声卡采集设备设置为蓝牙耳机，之后改用有线耳机播放 App A 的音乐，则需要再次调用该方法，将声卡采集设备设置为有线耳机，SDK 才会继续将音乐发布到远端。

<a id="api_iaudiodevicemanager_setloopbackdevice__parameters"></a>

### 参数

#### `deviceId`

指定 SDK 的声卡采集设备。你可以通过调用 [enumeratePlaybackDevices](/zh-CN/api-reference/rtc/cpp-all-platforms/device-management/audio-device#api_iaudiodevicemanager_enumerateplaybackdevices) 获取设备 ID。最大长度为 [MAX_DEVICE_ID_LENGTH_TYPE](/zh-CN/api-reference/rtc/cpp-all-platforms/enum-maxdeviceidlengthtype)。

<a id="api_iaudiodevicemanager_setloopbackdevice__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](/zh-CN/realtime-media/rtc/reference/error-code)了解详情和解决建议。

## startAudioDeviceLoopbackTest

开始音频设备回路测试。

<a id="api_iaudiodevicemanager_startaudiodeviceloopbacktest__prototype"></a>

```cpp
virtual int startAudioDeviceLoopbackTest(int indicationInterval) = 0;
```

<a id="api_iaudiodevicemanager_startaudiodeviceloopbacktest__detailed_desc"></a>

该方法用于测试本地音频采集设备和播放设备是否正常工作。调用该方法后，音频采集设备会采集本地音频，音频播放设备会播放采集到的音频。SDK 会按照设置的时间间隔触发两个独立的 [onAudioVolumeIndication](/zh-CN/api-reference/rtc/cpp-all-platforms/audio/audio-basic#callback_irtcengineeventhandler_onaudiovolumeindication) 回调，分别报告采集设备（`uid` = 0）和播放设备（`uid` = 1）的音量信息。

:::info[注]
- 该方法仅适用于 Windows 和 macOS 平台。
- 可以在加入频道前或加入频道后调用该方法。
- 该方法仅在主播角色调用时生效。
- 该方法仅测试本地音频设备，不涉及网络状况。
- 测试完成后，请调用 stopAudioDeviceLoopbackTest 停止音频设备回路测试。
:::

<a id="api_iaudiodevicemanager_startaudiodeviceloopbacktest__parameters"></a>

### 参数

#### `indicationInterval`

SDK 触发 [onAudioVolumeIndication](/zh-CN/api-reference/rtc/cpp-all-platforms/audio/audio-basic#callback_irtcengineeventhandler_onaudiovolumeindication) 回调的时间间隔（毫秒）。建议设置为大于 200 毫秒的值。该值不能小于 10 毫秒，否则无法收到 [onAudioVolumeIndication](/zh-CN/api-reference/rtc/cpp-all-platforms/audio/audio-basic#callback_irtcengineeventhandler_onaudiovolumeindication) 回调。

<a id="api_iaudiodevicemanager_startaudiodeviceloopbacktest__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](/zh-CN/realtime-media/rtc/reference/error-code)了解详情和解决建议。

### 所属接口类

## startPlaybackDeviceTest

开始本地音频播放设备测试。

<a id="api_iaudiodevicemanager_startplaybackdevicetest_iaudiodevicemanager__prototype"></a>

```cpp
virtual int startPlaybackDeviceTest(const char *testAudioFilePath) = 0;
```

<a id="api_iaudiodevicemanager_startplaybackdevicetest_iaudiodevicemanager__detailed_desc"></a>

该方法用于测试本地音频播放设备是否正常工作。调用该方法后，SDK 会播放你指定的音频文件。如果你能听到声音，说明播放设备工作正常。调用该方法后，SDK 每 100 毫秒触发一次 [onAudioVolumeIndication](/zh-CN/api-reference/rtc/cpp-all-platforms/audio/audio-basic#callback_irtcengineeventhandler_onaudiovolumeindication) 回调，报告 `uid` = 1 及播放设备的音量信息。该方法与 [startEchoTest](/zh-CN/api-reference/rtc/cpp-all-platforms/network#api_irtcengine_startechotest3) 的区别在于， [startPlaybackDeviceTest](/zh-CN/api-reference/rtc/cpp-all-platforms/device-management/audio-device#api_iaudiodevicemanager_startplaybackdevicetest_iaudiodevicemanager) 仅检测本地音频播放设备是否正常，而 [startEchoTest](/zh-CN/api-reference/rtc/cpp-all-platforms/network#api_irtcengine_startechotest3) 可同时检测音视频设备和网络状况。

:::info[注]
请在加入频道前调用该方法。测试完成后，请调用 [stopPlaybackDeviceTest](/zh-CN/api-reference/rtc/cpp-all-platforms/device-management/audio-device#api_iaudiodevicemanager_stopplaybackdevicetest_iaudiodevicemanager) 停止测试，再加入频道。
:::

<a id="api_iaudiodevicemanager_startplaybackdevicetest_iaudiodevicemanager__parameters"></a>

### 参数

#### `testAudioFilePath`

音频文件路径，UTF-8 编码的字符串。支持的文件格式包括 wav、mp3、m4a 和 aac。支持的采样率包括 8000、16000、32000、44100 和 48000 Hz。

<a id="api_iaudiodevicemanager_startplaybackdevicetest_iaudiodevicemanager__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](/zh-CN/realtime-media/rtc/reference/error-code)了解详情和解决建议。

### 所属接口类
