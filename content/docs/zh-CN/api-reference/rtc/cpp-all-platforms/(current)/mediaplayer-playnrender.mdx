## selectAudioTrack [2/2]

选择播放过程中使用的音轨。

<a id="api_imediaplayer_selectaudiotrack_imediaplayer__prototype"></a>

```cpp
virtual int selectAudioTrack(int index) = 0;
```

<a id="api_imediaplayer_selectaudiotrack_imediaplayer__detailed_desc"></a>

获取音频文件的音轨索引后，可以调用该方法指定要播放的音轨。例如，如果一个多音轨文件的不同音轨存储了不同语言的歌曲，可以调用该方法设置播放语言。

:::info[注]
你需要在调用 [getStreamInfo](/zh-CN/api-reference/rtc/cpp-all-platforms/mediaplayer-info#api_imediaplayer_getstreaminfo) 获取音频流索引值之后再调用该方法。
:::

<a id="api_imediaplayer_selectaudiotrack_imediaplayer__parameters"></a>

### 参数

#### `index`

音轨的索引。

<a id="api_imediaplayer_selectaudiotrack_imediaplayer__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/windows/error-code)了解详情和解决建议。

## setAudioDualMonoMode

设置当前音频文件的声道模式。

<a id="api_imediaplayer_setaudiodualmonomode__prototype"></a>

```cpp
virtual int setAudioDualMonoMode(agora::media::base::AUDIO_DUAL_MONO_MODE mode) = 0;
```

<a id="api_imediaplayer_setaudiodualmonomode__detailed_desc"></a>

在立体声音乐文件中，左声道和右声道可以存储不同的音频数据。你可以根据需要将声道模式设置为原始模式、左声道模式、右声道模式或混合声道模式。例如，在 KTV 场景中，音乐文件的左声道存储伴奏，右声道存储人声。如果你只需要听伴奏，可以调用该方法将声道模式设置为左声道模式；如果你需要同时听到伴奏和人声，可以将声道模式设置为混合声道模式。

:::info[注]
- 调用该方法前需先调用 open 方法。
- 此方法仅适用于立体声音频文件。
:::

<a id="api_imediaplayer_setaudiodualmonomode__parameters"></a>

### 参数

#### `mode`

声道模式，详见 [AUDIO_DUAL_MONO_MODE](/zh-CN/api-reference/rtc/cpp-all-platforms/enum-audiodualmonomode)。

<a id="api_imediaplayer_setaudiodualmonomode__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/windows/error-code)了解详情和解决建议。

### 所属接口类

## setAudioPitch

设置当前媒体资源的音调。

<a id="api_imediaplayer_setaudiopitch__prototype"></a>

```cpp
virtual int setAudioPitch(int pitch) = 0;
```

<a id="api_imediaplayer_setaudiopitch__detailed_desc"></a>

:::info[注]
请在调用 [open](/zh-CN/api-reference/rtc/cpp-all-platforms/mediaplayer-open#api_imediaplayer_open) 方法后调用此方法。
:::

<a id="api_imediaplayer_setaudiopitch__parameters"></a>

### 参数

#### `pitch`

按半音阶设置本地音乐文件的音调（默认值为 0，表示保持原始音调）。取值范围为 -12 到 12，相邻两个值之间的音调差为一个半音。该参数的绝对值越大，音调变化越明显。

<a id="api_imediaplayer_setaudiopitch__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/windows/error-code)了解详情和解决建议。

## setLoopCount

设置音效的循环播放次数。

<a id="api_imediaplayer_setloopcount__prototype"></a>

```cpp
virtual int setLoopCount(int loopCount) = 0;
```

<a id="api_imediaplayer_setloopcount__detailed_desc"></a>

调用该方法可设置音效的循环播放次数。循环播放完成后，SDK 会触发 [onPlayerSourceStateChanged](/zh-CN/api-reference/rtc/cpp-all-platforms/mediaplayer-observer#callback_imediaplayersourceobserver_onplayersourcestatechanged) 回调，并报告播放状态为 `PLAYER_STATE_PLAYBACK_ALL_LOOPS_COMPLETED`。

<a id="api_imediaplayer_setloopcount__parameters"></a>

### 参数

#### `loopCount`

音效的循环播放次数：

- ≥ 0：播放的次数。例如，设置为 0 表示不循环播放，仅播放一次；设置为 1 表示循环播放一次，总共播放两次。
- -1：无限循环播放音频文件。

<a id="api_imediaplayer_setloopcount__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/windows/error-code)了解详情和解决建议。

### 所属接口类
- [IMediaPlayer](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_imediaplayer)

## setPlaybackSpeed

设置当前音频文件的播放速度。

<a id="api_imediaplayer_setplaybackspeed__prototype"></a>

```cpp
virtual int setPlaybackSpeed(int speed) = 0;
```

<a id="api_imediaplayer_setplaybackspeed__detailed_desc"></a>

调用该方法前，需要先调用 [open](/zh-CN/api-reference/rtc/cpp-all-platforms/mediaplayer-open#api_imediaplayer_open) 方法。

<a id="api_imediaplayer_setplaybackspeed__parameters"></a>

### 参数

#### `speed`

播放速度。建议设置为 30 到 400 之间的值，定义如下：

- 30：原始速度的 0.3 倍。
- 100：原始速度。
- 400：原始速度的 4 倍。

<a id="api_imediaplayer_setplaybackspeed__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/windows/error-code)了解详情和解决建议。

