## 枚举值

### `CODEC_CAP_MASK_NONE`

（0）：设备不支持编码或解码功能。

### `CODEC_CAP_MASK_HW_DEC`

（1 &lt;&lt; 0）：设备支持硬件解码功能。

### `CODEC_CAP_MASK_HW_ENC`

（1 &lt;&lt; 1）：设备支持硬件编码功能。

### `CODEC_CAP_MASK_SW_DEC`

（1 &lt;&lt; 2）：设备支持软件解码功能。

### `CODEC_CAP_MASK_SW_ENC`

（1 &lt;&lt; 3）：设备支持软件编码功能。
