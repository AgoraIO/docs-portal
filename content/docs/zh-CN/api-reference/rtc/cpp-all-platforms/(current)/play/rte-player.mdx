## AddView

添加一个渲染视图。

<a id="api_canvas_addview__prototype"></a>

```cpp
bool AddView(View *view, ViewConfig *config, rte::Error *err = nullptr)
```

<a id="api_canvas_addview__detailed_desc"></a>

#### `自从`

自 v4.4.0 版本新增。

当你需要使用播放器播放视频时，可以调用该方法向视频渲染器添加一个视图，以显示视频内容。

:::info[注]
当前仅支持一个视图。
:::

<a id="api_canvas_addview__scenario"></a>

### 适用场景

当你需要使用播放器播放视频时，可以调用此方法将视图添加到视频渲染器中，以显示视频内容。

<a id="api_canvas_addview__timing"></a>

### 调用时机

该方法必须在调用 [SetCanvas](/zh-CN/api-reference/rtc/cpp-all-platforms/play/rte-player#api_player_setcanvas) 之前调用。

<a id="api_canvas_addview__parameters"></a>

### 参数

#### `view`

`HWND` 窗口句柄。

#### `config`

`View` 对象的设置，当前传入 NULL。

#### `err`

状态或错误信息，详见 [Error](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_error)。

<a id="api_canvas_addview__return_values"></a>

### 返回值

视图是否添加成功：

- true：视图添加成功。
- false：添加视图失败。

### 所属接口类
- [Canvas](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_canvas)

#### `自从`

自 v4.4.0 版本新增。

:::info[注]

## SetAbrFallbackLayer

设置已订阅视频流的回退选项。

<a id="api_playerconfig_setabrfallbacklayer__prototype"></a>

```cpp
void SetAbrFallbackLayer(AbrFallbackLayer abr_fallback_layer, Error *err = nullptr)
```

<a id="api_playerconfig_setabrfallbacklayer__detailed_desc"></a>

#### `自从`

自 v4.4.0 版本新增。

在网络状况较差时，SDK 会将视频流的分辨率降级为指定的回退质量层，以保证播放的连续性。不同的质量层对应不同的分辨率和码率。SDK 会持续监测网络状况，在网络恢复后自动将视频流恢复为订阅的质量层。 默认情况下，仅支持回退到 `kRteAbrFallbackLow` 或 `kRteAbrFallbackAudioOnly`。如需更灵活的视频体验，可[联系技术支持](https://ticket.shengwang.cn/)开启 ABR 功能，开启后可回退到所有质量层，并自定义每一层的分辨率。

:::info[注]
如果在调用该方法时未开启 ABR 功能，视频流的回退质量层只能为 `kRteAbrFallbackLow` 或 `kRteAbrFallbackAudioOnly`。
:::

<a id="api_playerconfig_setabrfallbacklayer__scenario"></a>

### 适用场景

一般场景下，可调用该方法并将回退质量层设置为 `kRteAbrFallbackLow` 或 `kRteAbrFallbackAudioOnly`。当网络较差时，SDK 会回退为视频小流或仅接收音频流。 如果对回退视频流的分辨率有更高要求，可[联系技术支持](https://ticket.shengwang.cn/)开启 ABR 功能。开启后，可自定义每一层的分辨率。SDK 会以你指定的最低质量层的分辨率为下限，并根据网络状况在该范围内动态调整分辨率。

<a id="api_playerconfig_setabrfallbacklayer__timing"></a>

### 调用时机

该方法必须在调用 `SetConfigs` 之前调用。

<a id="api_playerconfig_setabrfallbacklayer__parameters"></a>

### 参数

#### `abr_fallback_layer`

视频流的回退质量层，详见 [RteAbrFallbackLayer](/zh-CN/api-reference/rtc/cpp-all-platforms/enum-rteabrfallbacklayer)。当自定义 `kRteAbrFallbackLayer1` 到 `kRteAbrFallbackLayer6` 的分辨率时，可参考下表：

:::info[注]
自定义分辨率时，务必将视频质量层按分辨率从高到低排序；当分辨率相同时，按帧率从高到低排序。
:::

| 视频质量层 | 分辨率 |
| --- | --- |
| `kRteAbrSubscriptionLayer1` | 2160p (4K) |
| `kRteAbrSubscriptionLayer2` | 1440p (2K) |
| `kRteAbrSubscriptionLayer3` | 1080p (HD) |
| `kRteAbrSubscriptionLayer4` | 720p (HD) |
| `kRteAbrSubscriptionLayer5` | 540p (SD) |
| `kRteAbrSubscriptionLayer6` | 480p (SD) |

#### `err`

状态或错误信息，详见 [Error](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_error)。
