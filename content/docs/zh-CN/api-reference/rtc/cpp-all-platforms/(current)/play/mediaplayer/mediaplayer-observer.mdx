## registerAudioFrameObserver [1/2]

注册一个 IAudioPcmFrameSink 音频帧观察者对象。

<a id="api_imediaplayer_registeraudioframeobserver1_imediaplayer__prototype"></a>

```cpp
virtual int registerAudioFrameObserver(media::IAudioPcmFrameSink* observer) = 0;
```

<a id="api_imediaplayer_registeraudioframeobserver1_imediaplayer__detailed_desc"></a>

你需要实现 [IAudioPcmFrameSink](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_iaudiopcmframesink) 类，并根据业务场景注册回调。注册成功后，每当接收到音频帧时，SDK 会触发对应的回调。

<a id="api_imediaplayer_registeraudioframeobserver1_imediaplayer__parameters"></a>

### 参数

#### `observer`

音频帧观察者对象，详见 [IAudioPcmFrameSink](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_iaudiopcmframesink)。

<a id="api_imediaplayer_registeraudioframeobserver1_imediaplayer__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](/zh-CN/realtime-media/rtc/reference/error-code)了解详情和解决建议。

## onPlayBufferUpdated

报告缓冲数据可支持的播放时长。

<a id="callback_imediaplayersourceobserver_onplaybufferupdated__prototype"></a>

```cpp
virtual void onPlayBufferUpdated(int64_t playCachedBuffer) = 0;
```

<a id="callback_imediaplayersourceobserver_onplaybufferupdated__detailed_desc"></a>

当播放在线媒体资源时，SDK 每两秒触发一次该回调，用于报告当前缓冲数据可支持的播放时长。

- 当缓冲数据可支持的播放时长小于阈值（默认值为 0）时，SDK 返回 PLAYER_EVENT_BUFFER_LOW （6）。
- 当缓冲数据可支持的播放时长大于阈值（默认值为 0）时，SDK 返回 PLAYER_EVENT_BUFFER_RECOVER （7）。

<a id="callback_imediaplayersourceobserver_onplaybufferupdated__timing"></a>

### 触发时机

播放在线媒体资源时，SDK 每两秒触发一次该回调。

<a id="callback_imediaplayersourceobserver_onplaybufferupdated__parameters"></a>

### 参数

#### `playCachedBuffer`

缓冲数据可支持的播放时长，单位为毫秒。

### 所属接口类
- [IMediaPlayerSourceObserver](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_imediaplayersourceobserver)

## onReadData

SDK 读取媒体资源数据时触发的回调。

<a id="callback_imediaplayercustomdataprovider_onreaddata__prototype"></a>

```cpp
virtual int onReadData(unsigned char *buffer, int bufferSize) = 0;
```

<a id="callback_imediaplayercustomdataprovider_onreaddata__detailed_desc"></a>

当你调用 [openWithMediaSource](/zh-CN/api-reference/rtc/cpp-all-platforms/play/mediaplayer/mediaplayer-open#api_imediaplayer_openwithmediasource) 方法打开媒体资源时，SDK 会触发该回调，并请求你传入媒体资源数据的缓冲区。

### 参数

输出参数，表示数据缓冲区（字节）。你需要将 SDK 请求的 `bufferSize` 大小的数据写入该缓冲区。

#### `bufferSize`

数据缓冲区的长度（字节）。

<a id="callback_imediaplayercustomdataprovider_onreaddata__return_values"></a>

### 返回值

- 如果数据读取成功，返回实际读取的数据长度（字节）。
