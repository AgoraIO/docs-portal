## enableAutoRemoveCache

设置是否自动删除缓存的媒体文件。

<a id="api_imediaplayercachemanager_enableautoremovecache__prototype"></a>

```cpp
virtual int enableAutoRemoveCache(bool enable) = 0;
```

<a id="api_imediaplayercachemanager_enableautoremovecache__detailed_desc"></a>

启用该功能后，如果缓存的媒体文件数量或大小超过设置的限制，SDK 会自动删除最近最少使用的缓存文件。

<a id="api_imediaplayercachemanager_enableautoremovecache__parameters"></a>

### 参数

#### `enable`

是否启用 SDK 自动删除缓存的媒体文件：

- true：自动删除缓存的媒体文件。
- false：（默认）不自动删除缓存的媒体文件。

<a id="api_imediaplayercachemanager_enableautoremovecache__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败，详见 [MEDIA_PLAYER_REASON](/zh-CN/api-reference/rtc/cpp-all-platforms/enum-mediaplayerreason)。

- [IMediaPlayerCacheManager](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_imediaplayercachemanager)

## getCacheDir

获取待缓存媒体文件的存储路径。

<a id="api_imediaplayercachemanager_getcachedir__prototype"></a>

```cpp
virtual int getCacheDir(char* path, int length) = 0;
```

<a id="api_imediaplayercachemanager_getcachedir__detailed_desc"></a>

如果在调用该方法前未调用 [setCacheDir](/zh-CN/api-reference/rtc/cpp-all-platforms/play/mediaplayer/mediaplayer-cache#api_imediaplayercachemanager_setcachedir) 设置待缓存媒体文件的存储路径，则该方法返回 SDK 使用的默认存储路径。

<a id="api_imediaplayercachemanager_getcachedir__parameters"></a>

### 参数

#### `path`

输出参数，待缓存媒体文件的存储路径。

#### `length`

`path` 缓存文件存储路径字符串的最大长度。

<a id="api_imediaplayercachemanager_getcachedir__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败，详见 [MEDIA_PLAYER_REASON](/zh-CN/api-reference/rtc/cpp-all-platforms/enum-mediaplayerreason)。

- [IMediaPlayerCacheManager](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_imediaplayercachemanager)

## onPlayerCacheStats

上报正在缓存的媒体文件的统计信息。

<a id="callback_imediaplayersourceobserver_onplayercachestats__prototype"></a>

```cpp
virtual void onPlayerCacheStats(const media::base::CacheStatistics& stats)
```

<a id="callback_imediaplayersourceobserver_onplayercachestats__detailed_desc"></a>

调用 [openWithMediaSource](/zh-CN/api-reference/rtc/cpp-all-platforms/play/mediaplayer/mediaplayer-open#api_imediaplayer_openwithmediasource) 方法并将 `enableCache` 设置为 true 后，SDK 每秒触发一次该回调，上报正在缓存的媒体文件的统计信息。

<a id="callback_imediaplayersourceobserver_onplayercachestats__parameters"></a>

### 参数

#### `stats`

媒体文件缓存统计信息。详见 [CacheStatistics](/zh-CN/api-reference/rtc/cpp-all-platforms/class-cachestatistics)。

- [IMediaPlayerSourceObserver](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_imediaplayersourceobserver)
