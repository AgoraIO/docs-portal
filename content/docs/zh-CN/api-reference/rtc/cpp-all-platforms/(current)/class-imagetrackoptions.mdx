## 属性

<ParameterList>
<a id="imageurl"></a>
<Parameter name="imageUrl">

图像的 URL。支持的图像格式包括 JPEG、JPG、PNG 和 GIF。支持从本地的绝对路径或相对路径添加图像。

:::note
注： 在 Android 平台上，不支持从 `/assets/` 添加图像。
:::

</Parameter>
<a id="fps"></a>
<Parameter name="fps">

发布的视频流的帧率，取值范围为 [1, 30]，默认值为 1。

</Parameter>
<a id="mirrormode"></a>
<Parameter name="mirrorMode">

镜像模式，详见 [VIDEO_MIRROR_MODE_TYPE](/zh-CN/api-reference/rtc/cpp-all-platforms/enum-videomirrormodetype)。

</Parameter>
