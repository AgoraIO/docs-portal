<a id="class_deviceinfo__prototype"></a>

```cpp
struct DeviceInfo {
  bool isLowLatencyAudioSupported;
};
```

<a id="class_deviceinfo__detailed_desc"></a>

:::info[注]
该类仅适用于 Android 平台。
:::

<a id="class_deviceinfo__parameters"></a>

## 属性

### `isLowLatencyAudioSupported`

音频设备是否支持超低延迟采集和播放：

- true：设备支持超低延迟采集和播放。
- false：设备不支持超低延迟采集和播放。
