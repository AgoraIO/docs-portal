## adjustAudioMixingPlayoutVolume

调节本地播放的混音音量。

<a id="api_irtcengine_adjustaudiomixingplayoutvolume__prototype"></a>

```cpp
virtual int adjustAudioMixingPlayoutVolume(int volume) = 0;
```

<a id="api_irtcengine_adjustaudiomixingplayoutvolume__detailed_desc"></a>

<a id="api_irtcengine_adjustaudiomixingplayoutvolume__timing"></a>

### 调用时机

你需要在调用 `startAudioMixing` 并收到 [onAudioMixingStateChanged](/zh-CN/api-reference/rtc/cpp-all-platforms/audio-mixing#callback_irtcengineeventhandler_onaudiomixingstatechanged) （`AUDIO_MIXING_STATE_PLAYING` ）回调后调用该方法。

<a id="api_irtcengine_adjustaudiomixingplayoutvolume__parameters"></a>

### 参数

#### `volume`

本地播放的混音音量，取值范围为 0 到 100。（默认）为 100，表示原始音量。

<a id="api_irtcengine_adjustaudiomixingplayoutvolume__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/windows/error-code)了解详情和解决建议。

## getAudioMixingCurrentPosition

获取当前混音的播放进度（毫秒）。

<a id="api_irtcengine_getaudiomixingcurrentposition__prototype"></a>

```cpp
virtual int getAudioMixingCurrentPosition() = 0;
```

<a id="api_irtcengine_getaudiomixingcurrentposition__detailed_desc"></a>

:::info[注]
- 你需要在调用 `startAudioMixing` 并收到 [onAudioMixingStateChanged](/zh-CN/api-reference/rtc/cpp-all-platforms/audio-mixing#callback_irtcengineeventhandler_onaudiomixingstatechanged) （`AUDIO_MIXING_STATE_PLAYING` ）回调后调用此方法。
- 如果需要多次调用 [getAudioMixingCurrentPosition](/zh-CN/api-reference/rtc/cpp-all-platforms/audio-mixing#api_irtcengine_getaudiomixingcurrentposition)，请确保两次调用之间的时间间隔大于 500 毫秒。
:::

<a id="api_irtcengine_getaudiomixingcurrentposition__return_values"></a>

### 返回值

- ≥ 0：方法调用成功，返回当前混音的播放进度（毫秒）。返回 0 表示当前音乐文件尚未开始播放。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/windows/error-code)了解详情和解决建议。

### 所属接口类
- [IRtcEngine](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_irtcengine)

## setAudioMixingDualMonoMode

设置当前音频文件的声道模式。

<a id="api_irtcengine_setaudiomixingdualmonomode__prototype"></a>

```cpp
virtual int setAudioMixingDualMonoMode(media::AUDIO_MIXING_DUAL_MONO_MODE mode) = 0;
```

<a id="api_irtcengine_setaudiomixingdualmonomode__detailed_desc"></a>

在立体声音乐文件中，左右声道可以存储不同的音频数据。你可以根据需要将声道模式设置为原始模式、左声道模式、右声道模式或混合声道模式。

:::info[注]
该方法仅适用于立体声音频文件。
:::

<a id="api_irtcengine_setaudiomixingdualmonomode__scenario"></a>

### 适用场景

在 KTV 场景中，音乐文件的左声道存储伴奏，右声道存储原唱人声。你可以根据实际需求进行设置：

- 如果你只想听到伴奏，调用该方法将声道模式设置为左声道模式。
- 如果你需要同时听到伴奏和原唱人声，调用该方法将声道模式设置为混合模式。

<a id="api_irtcengine_setaudiomixingdualmonomode__timing"></a>

### 调用时机

#### `mode`

```cpp

```

<a id="api_irtcengine_setaudiomixingpitch__detailed_desc"></a>

调用该方法可在本地音乐文件与本地人声混音时，单独调整本地音乐文件的音调。

<a id="api_irtcengine_setaudiomixingpitch__timing"></a>

### 调用时机
