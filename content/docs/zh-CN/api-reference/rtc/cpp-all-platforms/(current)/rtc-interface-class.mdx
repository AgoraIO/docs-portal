## IRtcEngineEventHandler

用于接收 SDK 回调事件通知。

<a id="class_irtcengineeventhandler__detailed_desc"></a>

SDK 通过该类向 App 发送回调事件通知。你可以继承该类中的方法来获取所需的事件通知。该类中的所有方法均提供默认（空）实现，你可以按需选择性地继承部分方法。在回调方法中，应避免执行耗时操作或调用阻塞 API，否则可能影响 SDK 的正常运行。
