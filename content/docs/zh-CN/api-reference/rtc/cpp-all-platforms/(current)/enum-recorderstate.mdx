### `自从`

自 v3.5.2 版本新增。

<a id="enum_recorderstate__parameters"></a>

## 枚举值

### `RECORDER_STATE_ERROR`

（-1）：录制过程中发生错误。详见 [RecorderReasonCode](/zh-CN/api-reference/rtc/cpp-all-platforms/enum-recorderreasoncode)。

### `RECORDER_STATE_START`

（2）：开始音视频录制。

### `RECORDER_STATE_STOP`

（3）：停止音视频录制。
