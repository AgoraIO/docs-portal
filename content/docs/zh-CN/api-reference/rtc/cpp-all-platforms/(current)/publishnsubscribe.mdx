## enableDualStreamMode [1/2]

启用或关闭发送端的双流模式。

<a id="api_irtcengine_enabledualstreammode__prototype"></a>

```cpp
virtual int enableDualStreamMode(bool enabled) __deprecated = 0;
```

<a id="api_irtcengine_enabledualstreammode__detailed_desc"></a>

#### `废弃`

自 v4.2.0 版本废弃，请改用 `setDualStreamMode`。

双流由一对视频大流和视频小流组成：

- 视频大流：高码率、高分辨率。
- 视频小流：低码率、低分辨率。

启用双流模式后，你可以调用 [setRemoteVideoStreamType](/zh-CN/api-reference/rtc/cpp-all-platforms/publishnsubscribe#api_irtcengine_setremotevideostreamtype) 方法，在接收端选择接收高质量或低质量的视频流。

:::info[注]
- 该方法适用于发送端的所有类型的视频流，包括但不限于摄像头采集的视频流、屏幕共享流和自定义采集的视频流。
- 如果你需要在多频道场景中启用双流模式，可以调用 [enableDualStreamModeEx](/zh-CN/api-reference/rtc/cpp-all-platforms/publishnsubscribe#api_irtcengineex_enabledualstreammodeex) 方法。
- 你可以在加入频道前或加入频道后调用该方法。
:::

<a id="api_irtcengine_enabledualstreammode__parameters"></a>

### 参数

#### `enabled`

是否启用双流模式：

- true：启用双流模式。
- false：（默认）关闭双流模式。

<a id="api_irtcengine_enabledualstreammode__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/windows/error-code)了解详情和解决建议。

- [IRtcEngine](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_irtcengine)

## enableDualStreamMode [2/2]

设置发送端的双流模式和视频小流。

<a id="api_irtcengine_enabledualstreammode3__prototype"></a>

```cpp
virtual int enableDualStreamMode(bool enabled, const SimulcastStreamConfig& streamConfig) __deprecated = 0;
```

<a id="api_irtcengine_enabledualstreammode3__detailed_desc"></a>

#### `废弃`

自 v4.2.0 版本废弃，请改用 `setDualStreamMode`。

你可以调用此方法在发送端启用或关闭双流模式。双流模式指同时发送视频大流和视频小流：

- 视频大流：高码率、高分辨率。
- 视频小流：低码率、低分辨率。

启用双流模式后，你可以调用 [setRemoteVideoStreamType](/zh-CN/api-reference/rtc/cpp-all-platforms/publishnsubscribe#api_irtcengine_setremotevideostreamtype) 方法，在接收端选择接收高质量或低质量的视频流。

:::info[注]
- 此方法适用于发送端的所有类型视频流，包括但不限于摄像头采集的视频流、屏幕共享流和自定义采集的视频流。
- 如果你需要在多频道场景中启用双流模式，可以调用 [enableDualStreamModeEx](/zh-CN/api-reference/rtc/cpp-all-platforms/publishnsubscribe#api_irtcengineex_enabledualstreammodeex) 方法。
- 你可以在加入频道前或加入频道后调用此方法。
:::

<a id="api_irtcengine_enabledualstreammode3__parameters"></a>

### 参数

#### `enabled`

是否启用双流模式：

- true：启用双流模式。
- false：（默认）关闭双流模式。

#### `streamConfig`

视频小流的配置。详见 [SimulcastStreamConfig](/zh-CN/api-reference/rtc/cpp-all-platforms/class-simulcaststreamconfig)。

:::info[注]
当 `mode` 设置为 `DISABLE_SIMULCAST_STREAM` 时，设置 `streamConfig` 不生效。
:::

<a id="api_irtcengine_enabledualstreammode3__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/windows/error-code)了解详情和解决建议。

- [IRtcEngine](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_irtcengine)

## muteAllRemoteAudioStreams

停止或恢复接收所有远端音频流。

<a id="api_irtcengine_muteallremoteaudiostreams__prototype"></a>

```cpp
virtual int muteAllRemoteAudioStreams(bool mute) = 0;
```

<a id="api_irtcengine_muteallremoteaudiostreams__detailed_desc"></a>

该方法用于停止或恢复接收所有通过 `joinChannel` 加入或将要加入频道的远端用户的音频流。该方法等效于 [ChannelMediaOptions](/zh-CN/api-reference/rtc/cpp-all-platforms/class-channelmediaoptions) 中的 `autoSubscribeAudio`。

:::info[注]
请确保在加入频道后调用该方法。如果在加入频道后调用 `muteAllRemoteAudioStreams(true)`，本地用户将停止接收频道中所有用户的音频流，包括在调用该方法后加入频道的用户。
:::

<a id="api_irtcengine_muteallremoteaudiostreams__parameters"></a>

### 参数

#### `mute`

是否停止接收所有远端音频流：

- true：停止接收所有远端音频流。
- false：恢复接收所有远端音频流。

<a id="api_irtcengine_muteallremoteaudiostreams__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/windows/error-code)了解详情和解决建议。

- [IRtcEngine](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_irtcengine)

virtual int setDualStreamMode(SIMULCAST_STREAM_MODE mode) = 0;
