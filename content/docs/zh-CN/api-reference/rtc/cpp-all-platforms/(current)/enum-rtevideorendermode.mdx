## 枚举值

### kRteVideoRenderModeHidden

（0）：视频按比例缩放以填满视图。若视频宽高比与视图不一致，超出视图的部分将被裁剪。

### kRteVideoRenderModeFit

（1）：视频按比例缩放以适应视图。若视频宽高比与视图不一致，未被使用的区域将以黑边填充。
