<a id="class_snapshotconfig__prototype"></a>

```cpp
struct SnapshotConfig {
  const char* filePath;
  media::base::VIDEO_MODULE_POSITION position;
};
```

<a id="class_snapshotconfig__parameters"></a>

## 属性

### `filePath`

:::info[注]
请确保指定的路径存在且可写。
:::

截图的本地路径（包含文件扩展名）。例如：

- Windows: `C:\Users\<user_name>\AppData\Local\声网\<process_name>\example.jpg`
- iOS: `/App Sandbox/Library/Caches/example.jpg`
- macOS: `～/Library/Logs/example.jpg`
- Android: `/storage/emulated/0/Android/data/<package name>/files/example.jpg`。

### `position`

截图视频帧在视频处理流程中的位置，详见 [VIDEO_MODULE_POSITION](/zh-CN/api-reference/rtc/cpp-all-platforms/enum-videomoduleposition)。
