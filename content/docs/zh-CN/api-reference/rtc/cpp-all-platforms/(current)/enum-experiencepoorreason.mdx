## 枚举值

### EXPERIENCE_REASON_NONE

（0）：无异常，表示本地用户的体验质量良好。

### REMOTE_NETWORK_QUALITY_POOR

（1）：远端用户的网络质量较差。

### LOCAL_NETWORK_QUALITY_POOR

（2）：本地用户的网络质量较差。

### WIRELESS_SIGNAL_POOR

（4）：本地用户的 Wi-Fi 或蜂窝网络信号较弱。

### WIFI_BLUETOOTH_COEXIST

（8）：本地用户同时开启 Wi-Fi 和蓝牙，信号相互干扰，导致音频传输质量下降。
