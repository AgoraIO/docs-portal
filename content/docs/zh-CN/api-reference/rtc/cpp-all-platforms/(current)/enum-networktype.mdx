## 枚举值

### `NETWORK_TYPE_UNKNOWN`

（-1）：未知网络类型。

### `NETWORK_TYPE_DISCONNECTED`

（0）：SDK 与网络已断开连接。

### `NETWORK_TYPE_LAN`

（1）：局域网（LAN）类型网络。

### `NETWORK_TYPE_WIFI`

（2）：Wi-Fi 类型网络（包括热点）。

### `NETWORK_TYPE_MOBILE_2G`

（3）：移动 2G 网络。

### `NETWORK_TYPE_MOBILE_3G`

（4）：移动 3G 网络。

### `NETWORK_TYPE_MOBILE_4G`

（5）：移动 4G 网络。

### `NETWORK_TYPE_MOBILE_5G`

（6）：移动 5G 网络。
