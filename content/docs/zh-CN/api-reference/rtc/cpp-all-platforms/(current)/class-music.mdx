</Parameter>
<a id="durations"></a>
<Parameter name="durationS">

音乐资源的总时长（单位为秒）。

</Parameter>
<a id="type"></a>
<Parameter name="type">

音乐资源的类型：

- 1：单轨道，左声道为伴奏，右声道为原唱。
- 2：单轨道，仅包含伴奏。
- 3：单轨道，仅包含原唱。
- 4：多轨音频。

</Parameter>
<a id="pitchtype"></a>
<Parameter name="pitchType">

歌曲是否支持音高评分：

- 1：支持音高评分。
- 2：不支持音高评分。

</Parameter>
<a id="lyriccount"></a>
<Parameter name="lyricCount">

该歌曲可用的歌词数量。

</Parameter>
<a id="lyriclist"></a>
<Parameter name="lyricList">

支持的歌词格式：
