<a id="enum_audiencelatencyleveltype__detailed_desc"></a>

仅当用户角色设置为 `CLIENT_ROLE_AUDIENCE` 时生效。

<a id="enum_audiencelatencyleveltype__parameters"></a>

## 枚举值

### `AUDIENCE_LATENCY_LEVEL_LOW_LATENCY`

（1）：低延迟。

### `AUDIENCE_LATENCY_LEVEL_ULTRA_LOW_LATENCY`

（2）：（默认）超低延迟。
