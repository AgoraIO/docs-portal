```cpp
struct VideoDenoiserOptions {

  VIDEO_DENOISER_LEVEL level;
};
```

<a id="class_videodenoiseroptions__detailed_desc"></a>

### `自从`

自 v4.0.0 版本新增。

<a id="class_videodenoiseroptions__parameters"></a>

## 属性

### `mode`

视频降噪模式。详见 [VIDEO_DENOISER_MODE](/zh-CN/api-reference/rtc/cpp-all-platforms/enum-videodenoisermode)。

### `level`

视频降噪等级。详见 [VIDEO_DENOISER_LEVEL](/zh-CN/api-reference/rtc/cpp-all-platforms/enum-videodenoiserlevel)。
