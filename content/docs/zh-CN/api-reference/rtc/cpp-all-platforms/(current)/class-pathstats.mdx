---

<a id="class_pathstats__prototype"></a>

```cpp
struct PathStats {
  MultipathType type;
  int txKBitRate;
  int rxKBitRate;
};
```

<a id="class_pathstats__detailed_desc"></a>

### `自从`

自 v4.6.0 版本新增。

<a id="class_pathstats__parameters"></a>

## 属性

### `type`

网络路径的类型。详见 [MultipathType](/zh-CN/api-reference/rtc/cpp-all-platforms/enum-multipathtype)。

### `txKBitRate`

该路径的传输码率，单位为 Kbps。

### `rxKBitRate`

该路径的接收码率，单位为 Kbps。
