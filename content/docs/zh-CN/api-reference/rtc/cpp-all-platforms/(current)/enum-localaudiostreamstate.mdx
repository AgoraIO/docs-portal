## 枚举值

### `LOCAL_AUDIO_STREAM_STATE_STOPPED`

（0）：本地音频处于初始状态。

### `LOCAL_AUDIO_STREAM_STATE_RECORDING`

（1）：本地音频采集设备已成功启动。

### `LOCAL_AUDIO_STREAM_STATE_ENCODING`

（2）：首帧音频已成功编码。

### `LOCAL_AUDIO_STREAM_STATE_FAILED`

（3）：本地音频启动失败。
