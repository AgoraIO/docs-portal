## pauseAllChannelMediaRelay

暂停向所有目标频道的跨频道媒体流转发。

<a id="api_irtcengine_pauseallchannelmediarelay__prototype"></a>

```cpp
virtual int pauseAllChannelMediaRelay() = 0;
```

<a id="api_irtcengine_pauseallchannelmediarelay__detailed_desc"></a>

你可以在开始跨频道媒体流转发后调用该方法，以暂停向所有目标频道转发媒体流。如需恢复转发，请调用 [resumeAllChannelMediaRelay](/zh-CN/api-reference/rtc/cpp-all-platforms/cloud-media-relay/channel-media-relay#api_irtcengine_resumeallchannelmediarelay) 方法。

:::info[注]
请在调用 [startOrUpdateChannelMediaRelay](/zh-CN/api-reference/rtc/cpp-all-platforms/cloud-media-relay/channel-media-relay#api_irtcengine_startorupdatechannelmediarelay) 方法之后调用此方法。
:::

<a id="api_irtcengine_pauseallchannelmediarelay__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/windows/error-code)了解详情和解决建议。
  - -5：调用被拒绝，当前没有正在进行的跨频道媒体流转发。

### 所属接口类
- [IRtcEngine](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_irtcengine)

## startOrUpdateChannelMediaRelay

开始跨频道媒体流转发，或更新媒体流转发的目标频道。

<a id="api_irtcengine_startorupdatechannelmediarelay__prototype"></a>

```cpp
virtual int startOrUpdateChannelMediaRelay(const ChannelMediaRelayConfiguration &configuration) = 0;
```

<a id="api_irtcengine_startorupdatechannelmediarelay__detailed_desc"></a>

#### `自从`

自 v4.2.0 版本新增。

首次成功调用该方法会将媒体流从源频道转发到目标频道。若需将媒体流转发到其他频道，或停止转发到某个频道，可再次调用该方法更新目标频道。最多支持转发到六个目标频道。

:::info[注]
- 请在加入频道后调用该方法。
- 该方法仅在你是直播频道中的主播时有效。
- 跨频道媒体流转发功能需[联系技术支持](https://ticket.shengwang.cn/)启用。
- 该方法不支持字符串用户 User Account。
:::

<a id="api_irtcengine_startorupdatechannelmediarelay__related"></a>

### 相关回调

成功调用该方法后，SDK 会触发 [onChannelMediaRelayStateChanged](/zh-CN/api-reference/rtc/cpp-all-platforms/cloud-media-relay/channel-media-relay#callback_irtcengineeventhandler_onchannelmediarelaystatechanged) 回调，报告媒体流转发的状态。 常见状态如下：

- 如果 onChannelMediaRelayStateChanged 回调返回 RELAY_STATE_RUNNING （2）和 RELAY_OK （0），表示 SDK 成功开始将媒体流从源频道转发到目标频道。
- 如果 onChannelMediaRelayStateChanged 回调返回 RELAY_STATE_FAILURE （3），表示媒体流转发过程中发生异常。

<a id="api_irtcengine_startorupdatechannelmediarelay__parameters"></a>

### 参数

#### `configuration`

媒体流转发的配置，详见 [ChannelMediaRelayConfiguration](/zh-CN/api-reference/rtc/cpp-all-platforms/class-channelmediarelayconfiguration)。

<a id="api_irtcengine_startorupdatechannelmediarelay__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/windows/error-code)了解详情和解决建议。
  - -1：发生通用错误。
  - -2：参数无效。
  - -8：内部状态错误，可能是因为用户不是主播。

### 所属接口类
- [IRtcEngine](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_irtcengine)

## startOrUpdateChannelMediaRelayEx

开始或更新跨频道媒体流转发。

<a id="api_irtcengineex_startorupdatechannelmediarelayex__prototype"></a>

```cpp
virtual int startOrUpdateChannelMediaRelayEx(const ChannelMediaRelayConfiguration& configuration, const RtcConnection& connection) = 0;
```

<a id="api_irtcengineex_startorupdatechannelmediarelayex__detailed_desc"></a>

#### `自从`

自 v4.2.0 版本新增。

首次成功调用该方法会开始将媒体流从源频道转发到目标频道。若需将媒体流转发到其他频道，或退出当前的某个媒体流转发，可再次调用该方法以更新目标频道。该功能最多支持将媒体流转发到六个目标频道。调用该方法成功后，SDK 会触发 [onChannelMediaRelayStateChanged](/zh-CN/api-reference/rtc/cpp-all-platforms/cloud-media-relay/channel-media-relay#callback_irtcengineeventhandler_onchannelmediarelaystatechanged) 回调，报告媒体流转发的状态：

- 当回调返回 RELAY_STATE_RUNNING （2）和 RELAY_OK （0）时，表示媒体流已开始从源频道转发到目标频道。
- 当回调返回 RELAY_STATE_FAILURE （3）时，表示媒体流转发过程中出现异常。

:::info[注]
- 请在加入频道后调用该方法。
- 该方法仅在你是直播频道中的主播时生效。
- 跨频道媒体流转发功能需[联系技术支持](https://ticket.shengwang.cn/)启用。

## stopChannelMediaRelay

停止跨频道媒体流转发。

<a id="api_irtcengine_stopchannelmediarelay__prototype"></a>

```cpp
virtual int stopChannelMediaRelay() = 0;
```

<a id="api_irtcengine_stopchannelmediarelay__detailed_desc"></a>

调用该方法停止跨频道媒体流转发。一旦转发停止，主播会退出所有目标频道。

:::info[注]
如果方法调用失败，SDK 会触发 [onChannelMediaRelayStateChanged](/zh-CN/api-reference/rtc/cpp-all-platforms/cloud-media-relay/channel-media-relay#callback_irtcengineeventhandler_onchannelmediarelaystatechanged) 回调，并返回 `RELAY_ERROR_SERVER_NO_RESPONSE` （2）或 `RELAY_ERROR_SERVER_CONNECTION_LOST` （8）状态码。你也可以调用 `leaveChannel` 方法离开频道，跨频道媒体流转发将自动停止。
:::

<a id="api_irtcengine_stopchannelmediarelay__related"></a>

### 相关回调

成功调用该方法后，SDK 会触发 [onChannelMediaRelayStateChanged](/zh-CN/api-reference/rtc/cpp-all-platforms/cloud-media-relay/channel-media-relay#callback_irtcengineeventhandler_onchannelmediarelaystatechanged) 回调报告媒体流转发状态。

<a id="api_irtcengine_stopchannelmediarelay__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/windows/error-code)了解详情和解决建议。
  - -5：调用被拒绝，当前没有正在进行的跨频道媒体流转发。

### 所属接口类
- [IRtcEngine](/zh-CN/api-reference/rtc/cpp-all-platforms/rtc-interface-class#class_irtcengine)
