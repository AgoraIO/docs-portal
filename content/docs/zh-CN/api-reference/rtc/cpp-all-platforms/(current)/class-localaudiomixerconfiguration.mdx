<Parameter name="syncWithLocalMic">

混音后的音频流是否使用本地麦克风采集的音频帧的时间戳。

- true：（默认）使用本地麦克风采集的音频帧时间戳。如果希望所有本地采集的音频流同步，请设置为该值。
- false：使用混音时音频帧的时间戳。
