## AddVideoWatermark [1/3]

添加本地视频水印。

<a id="api_irtcengine_addvideowatermark1__prototype"></a>

```text
public abstract int AddVideoWatermark(RtcImage watermark);
```

<a id="api_irtcengine_addvideowatermark1__detailed_desc"></a>

<a id="废弃"></a>

:::error[废弃]
弃用： 该方法已废弃，请使用
[AddVideoWatermark [3/3]](/zh-CN/api-reference/rtc/unity/video/video-prenpro/watermark#api_irtcengine_addvideowatermark3) 作为替代。
:::

该方法将一张 PNG 图片作为水印添加到本地发布的直播视频流上，同一直播频道中的用户，旁路推流观众，甚至采集设备都能看到或采集到该水印图片。如果你仅仅希望在旁路直播推流中添加水印，请参考 [StartRtmpStreamWithTranscoding](/zh-CN/api-reference/rtc/unity/cloud-media-relay/media-push#api_irtcengine_startrtmpstreamwithtranscoding) 中描述的用法。

:::note
注：

- 在本地直播和旁路推流中，URL 的定义不同。本地直播中，URL 指本地直播视频上图片的本地绝对/相对路径；旁路推流中，URL 指旁路推流视频上图片的地址。
- 待添加图片的源文件格式必须是 PNG。如果待添加的 PNG 图片的尺寸与你该方法中设置的尺寸不一致，SDK 会对 PNG 图片进行裁剪，以与设置相符。
- 声网当前只支持在直播视频流中添加一个水印，后添加的水印会替换掉之前添加的水印。
:::

## AddVideoWatermark [2/3]

添加本地视频水印。

<a id="api_irtcengine_addvideowatermark2__prototype"></a>

```text
public abstract int AddVideoWatermark(string watermarkUrl, WatermarkOptions options);
```

<a id="api_irtcengine_addvideowatermark2__detailed_desc"></a>

<a id="废弃-1"></a>

:::error[废弃]
弃用：该方法已废弃，请改用 `addVideoWatermark [3/3]`。
:::

该方法将一张 PNG 图片作为水印添加到本地发布的直播视频流上，同一直播频道中的用户、旁路直播观众和采集设备都能看到或采集到该水印图片。当前只支持在直播视频流中添加一个水印，后添加的水印会替换掉之前添加的水印。
水印坐标和 [SetVideoEncoderConfiguration](/zh-CN/api-reference/rtc/unity/video/video-basic#api_irtcengine_setvideoencoderconfiguration) 方法中的设置有依赖关系：

- 如果视频编码方向（[ORIENTATION_MODE](/zh-CN/api-reference/rtc/unity/enum-orientationmode)）固定为横屏或自适应模式下的横屏，那么水印使用横屏坐标。
- 如果视频编码方向（[ORIENTATION_MODE](/zh-CN/api-reference/rtc/unity/enum-orientationmode)）固定为竖屏或自适应模式下的竖屏，那么水印使用竖屏坐标。
- 设置水印坐标时，水印的图像区域不能超出 [SetVideoEncoderConfiguration](/zh-CN/api-reference/rtc/unity/video/video-basic#api_irtcengine_setvideoencoderconfiguration) 方法中设置的视频尺寸，否则超出部分将被裁剪。

:::note
注：

- 你需要在调用 [EnableVideo](/zh-CN/api-reference/rtc/unity/video/video-basic#api_irtcengine_enablevideo) 方法之后再调用该方法。
- 如果你只是在旁路推流时添加水印，你可以使用该方法或 [StartRtmpStreamWithTranscoding](/zh-CN/api-reference/rtc/unity/cloud-media-relay/media-push#api_irtcengine_startrtmpstreamwithtranscoding) 方法设置水印。
- 待添加水印图片必须是 PNG 格式。该方法支持所有像素格式的 PNG 图片：RGBA、RGB、Palette、Gray 和 Alpha_gray。
- 如果待添加的 PNG 图片的尺寸与你在该方法中设置的尺寸不一致，SDK 会对 PNG 图片进行缩放或裁剪，以与设置相符。
- 如果你已设置本地视频为镜像模式，那么此处的本地水印也为镜像。为避免本地用户看本地视频时的水印也被镜像，建议你不要对本地视频同时使用镜像和水印功能，请在应用层实现本地水印功能。
:::
