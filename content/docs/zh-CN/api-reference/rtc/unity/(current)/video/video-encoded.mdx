## RegisterVideoEncodedFrameObserver

为编码后的视频图像注册视频帧接收观测器。

<a id="api_imediaengine_registervideoencodedframeobserver__prototype"></a>

```csharp
public abstract int RegisterVideoEncodedFrameObserver(IVideoEncodedFrameObserver videoEncodedImageReceiver, OBSERVER_MODE mode = OBSERVER_MODE.INTPTR);
```

<a id="api_imediaengine_registervideoencodedframeobserver__detailed_desc"></a>

如果你只想要观测编码后的视频帧 (如 H.264 格式)，而不需要对视频进行解码和渲染，声网推荐你通过该方法注册一个 [IVideoEncodedFrameObserver](/zh-CN/api-reference/rtc/unity/rtc-interface-class#class_ivideoencodedframeobserver) 类。

:::info[注]
该方法需要在加入频道前调用。
:::

<a id="api_imediaengine_registervideoencodedframeobserver__parameters"></a>

### 参数

#### `videoEncodedImageReceiver`

视频帧接收观测器，详见 [IVideoEncodedFrameObserver](/zh-CN/api-reference/rtc/unity/rtc-interface-class#class_ivideoencodedframeobserver)。

#### `mode`

视频数据回调模式，详见 [OBSERVER_MODE](/zh-CN/api-reference/rtc/unity/enum-observermode)。

<a id="api_imediaengine_registervideoencodedframeobserver__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/unity/error-code)了解详情和解决建议。

- [IMediaEngine](/zh-CN/api-reference/rtc/unity/rtc-interface-class#class_imediaengine)

## UnregisterVideoEncodedFrameObserver

为编码后的视频图像取消注册视频帧接收观测器。

<a id="api_imediaengine_unregistervideoencodedframeobserver__prototype"></a>

```csharp
public abstract int UnRegisterVideoEncodedFrameObserver();
```

<a id="api_imediaengine_unregistervideoencodedframeobserver__detailed_desc"></a>

<a id="api_imediaengine_unregistervideoencodedframeobserver__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/unity/error-code)了解详情和解决建议。

- [IMediaEngine](/zh-CN/api-reference/rtc/unity/rtc-interface-class#class_imediaengine)

<a id="callback_ivideoencodedframeobserver_onencodedvideoframereceived"></a>

## OnEncodedVideoFrameReceived

报告接收端已收到远端发送的待解码视频帧。

<a id="callback_ivideoencodedframeobserver_onencodedvideoframereceived__prototype"></a>

```csharp
public virtual bool OnEncodedVideoFrameReceived(string channelId, uint uid, IntPtr imageBufferPtr, UInt64 length, EncodedVideoFrameInfo videoEncodedFrameInfo)
        {
            return true;
        }
```

<a id="callback_ivideoencodedframeobserver_onencodedvideoframereceived__detailed_desc"></a>

调用 [SetRemoteVideoSubscriptionOptions](/zh-CN/api-reference/rtc/unity/publishnsubscribe#api_irtcengine_setremotevideosubscriptionoptions) 方法并将 `encodedFrameOnly` 设置为 true 时，SDK 会在本地触发该回调，上报接收到的编码后视频帧信息。

<a id="callback_ivideoencodedframeobserver_onencodedvideoframereceived__parameters"></a>

### 参数

#### `channelId`

频道名。

#### `uid`

远端用户 ID。

#### `imageBufferPtr`

视频图像 buffer。

#### `length`

视频图像的数据长度。

#### `videoEncodedFrameInfo`

编码后的视频帧信息，详见 [EncodedVideoFrameInfo](/zh-CN/api-reference/rtc/unity/class-encodedvideoframeinfo)。

<a id="callback_ivideoencodedframeobserver_onencodedvideoframereceived__return_values"></a>

### 返回值

无实际含义。

- [IVideoEncodedFrameObserver](/zh-CN/api-reference/rtc/unity/rtc-interface-class#class_ivideoencodedframeobserver)
