## RegisterVideoEncodedFrameObserver

为编码后的视频图像注册视频帧接收观测器。

<a id="api_imediaengine_registervideoencodedframeobserver__prototype"></a>

```text
public abstract int RegisterVideoEncodedFrameObserver(IVideoEncodedFrameObserver videoEncodedImageReceiver, OBSERVER_MODE mode = OBSERVER_MODE.INTPTR);
```

<a id="api_imediaengine_registervideoencodedframeobserver__detailed_desc"></a>

如果你只想要观测编码后的视频帧 (如 H.264 格式)，而不需要对视频进行解码和渲染，声网推荐你通过该方法注册一个 [IVideoEncodedFrameObserver](/zh-CN/api-reference/rtc/unity/rtc-interface-class#class_ivideoencodedframeobserver) 类。

:::note
注： 该方法需要在加入频道前调用。
:::

</Parameter>
