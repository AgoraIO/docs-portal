## 枚举值

### `RELAY_OK`

0: 一切正常。

### `RELAY_ERROR_SERVER_ERROR_RESPONSE`

1: 服务器回应出错。

### `RELAY_ERROR_SERVER_NO_RESPONSE`

2: 服务器无回应。 该错误可能是网络状况不佳导致的。如果在发起跨频道连麦时报告该错误，你可以稍后重试；如果在跨频道连麦过程中报告该错误，你可以调用 [LeaveChannel [2/2]](/zh-CN/api-reference/rtc/unity/channel#api_irtcengine_leavechannel2) 方法离开频道。 该错误也可能是由于当前的 App ID 未开启跨频道连麦导致的。你可以[联系技术支持](https://ticket.shengwang.cn/)申请开通跨频道连麦。

### `RELAY_ERROR_NO_RESOURCE_AVAILABLE`

3: SDK 无法获取服务，可能是因为服务器资源有限导致。

### `RELAY_ERROR_FAILED_JOIN_SRC`

4: 发起跨频道转发媒体流请求失败。

### `RELAY_ERROR_FAILED_JOIN_DEST`

5: 接受跨频道转发媒体流请求失败。

### `RELAY_ERROR_FAILED_PACKET_RECEIVED_FROM_SRC`

6: 服务器接收跨频道转发媒体流失败。

### `RELAY_ERROR_FAILED_PACKET_SENT_TO_DEST`

7: 服务器发送跨频道转发媒体流失败。

### `RELAY_ERROR_SERVER_CONNECTION_LOST`

8: SDK 因网络质量不佳与服务器断开。你可以调用 [LeaveChannel [2/2]](/zh-CN/api-reference/rtc/unity/channel#api_irtcengine_leavechannel2) 方法离开当前频道。

### `RELAY_ERROR_INTERNAL_ERROR`

9: 服务器内部出错。

### `RELAY_ERROR_SRC_TOKEN_EXPIRED`

10: 源频道的 Token 已过期。

### `RELAY_ERROR_DEST_TOKEN_EXPIRED`

11: 目标频道的 Token 已过期。
