## 属性

### encodingPreference

视频编码器偏好。详见 [ENCODING_PREFERENCE](/zh-CN/api-reference/rtc/unity/enum-encodingpreference)。

### compressionPreference

视频编码的压缩偏好。详见 [COMPRESSION_PREFERENCE](/zh-CN/api-reference/rtc/unity/enum-compressionpreference)。

### encodeAlpha

当视频帧包含 Alpha 通道数据时，设置是否将 Alpha 数据编码并发送至远端：

- true：对 Alpha 数据进行编码发送。
- false：（默认）不对 Alpha 数据进行编码发送。
