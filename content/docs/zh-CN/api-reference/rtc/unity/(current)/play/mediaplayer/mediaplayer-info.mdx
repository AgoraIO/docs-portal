## GetAudioBufferDelay

获取播放媒体文件时的音频缓冲延迟。

<a id="api_imediaplayer_getaudiobufferdelay__prototype"></a>

```csharp
public virtual int GetAudioBufferDelay()
```

<a id="api_imediaplayer_getaudiobufferdelay__detailed_desc"></a>

<a id="api_imediaplayer_getaudiobufferdelay__parameters"></a>

### 参数

#### `delayMs`

输出参数，表示播放媒体文件时的音频缓冲延迟，单位为毫秒。

<a id="api_imediaplayer_getaudiobufferdelay__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/unity/error-code)了解详情和解决建议。

- [IMediaPlayer](/zh-CN/api-reference/rtc/unity/rtc-interface-class#class_imediaplayer)

```csharp

```

<a id="api_imediaplayer_getplayoutvolume__detailed_desc"></a>

请在 [Open](/zh-CN/api-reference/rtc/unity/play/mediaplayer/mediaplayer-open#api_imediaplayer_open) 后并收到 [OnPlayerSourceStateChanged](/zh-CN/api-reference/rtc/unity/play/mediaplayer/mediaplayer-observer#callback_imediaplayersourceobserver_onplayersourcestatechanged) 回调报告播放状态为 `PLAYER_STATE_OPEN_COMPLETED` 后再调用该方法。

## GetStreamInfo

通过媒体流的索引值获取媒体流信息。

<a id="api_imediaplayer_getstreaminfo__prototype"></a>

```csharp
public abstract int GetStreamInfo(Int64 index, ref PlayerStreamInfo info);
```

<a id="api_imediaplayer_getstreaminfo__detailed_desc"></a>

<a id="api_imediaplayer_getstreaminfo__timing"></a>

### 调用时机

你需要在 [GetStreamCount](/zh-CN/api-reference/rtc/unity/play/mediaplayer/mediaplayer-info#api_imediaplayer_getstreamcount) 后调用该方法。

<a id="api_imediaplayer_getstreaminfo__parameters"></a>

### 参数

#### `index`

媒体流索引值。该参数需小于 [GetStreamCount](/zh-CN/api-reference/rtc/unity/play/mediaplayer/mediaplayer-info#api_imediaplayer_getstreamcount) 的 `count` 参数。

#### `info`

输出参数。媒体流的所有信息，详见 [PlayerStreamInfo](/zh-CN/api-reference/rtc/unity/class-playerstreaminfo)。

<a id="api_imediaplayer_getstreaminfo__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/unity/error-code)了解详情和解决建议。

- [IMediaPlayer](/zh-CN/api-reference/rtc/unity/rtc-interface-class#class_imediaplayer)

## OnPlayerPlaybackStats

报告当前播放的媒体资源的相关信息。

<a id="callback_imediaplayersourceobserver_onplayerplaybackstats__prototype"></a>

```csharp
public virtual void OnPlayerPlaybackStats(PlayerPlaybackStats stats)
                {
                }
```

<a id="callback_imediaplayersourceobserver_onplayerplaybackstats__detailed_desc"></a>

当媒体资源开始播放后，SDK 会每秒触发一次该回调，报告媒体资源的相关信息。

<a id="callback_imediaplayersourceobserver_onplayerplaybackstats__parameters"></a>

### 参数

#### `stats`

媒体资源的相关信息，详见 [PlayerPlaybackStats](/zh-CN/api-reference/rtc/unity/class-playerplaybackstats)。

- [IMediaPlayerSourceObserver](/zh-CN/api-reference/rtc/unity/rtc-interface-class#class_imediaplayersourceobserver)
