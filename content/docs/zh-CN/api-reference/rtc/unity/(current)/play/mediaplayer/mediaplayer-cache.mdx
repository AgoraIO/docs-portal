## EnableAutoRemoveCache

设置是否开启自动清除缓存文件功能。

<a id="api_imediaplayercachemanager_enableautoremovecache__prototype"></a>

```text
public abstract int EnableAutoRemoveCache(bool enable);
```

<a id="api_imediaplayercachemanager_enableautoremovecache__detailed_desc"></a>

开启自动清除缓存文件后，当播放器中缓存的媒体文件超过你设置的文件数量或总缓存大小的上限时，SDK 会自动清除近期最少使用的一个缓存文件。

<a id="api_imediaplayercachemanager_enableautoremovecache__parameters"></a>

### 参数

<ParameterList>
<a id="enable"></a>
<Parameter name="enable">

是否自动清除缓存文件：

- true：开启自动清除缓存文件功能。
- false：（默认）关闭自动清除缓存文件功能。

</Parameter>
</ParameterList>

<a id="api_imediaplayercachemanager_enableautoremovecache__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败，详见 [MEDIA_PLAYER_REASON](/zh-CN/api-reference/rtc/unity/enum-mediaplayerreason)。

- [IMediaPlayerCacheManager](/zh-CN/api-reference/rtc/unity/rtc-interface-class#class_imediaplayercachemanager)
