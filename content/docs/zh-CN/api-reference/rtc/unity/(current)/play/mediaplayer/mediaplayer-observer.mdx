## RegisterAudioFrameObserver [1/2]

注册 PCM 音频帧观测器。

<a id="api_imediaplayer_registeraudioframeobserver1_imediaplayer__prototype"></a>

```csharp
public abstract int RegisterAudioFrameObserver(IAudioPcmFrameSink observer);
```

<a id="api_imediaplayer_registeraudioframeobserver1_imediaplayer__detailed_desc"></a>

你需要在该方法中实现一个 [IAudioPcmFrameSink](/zh-CN/api-reference/rtc/unity/rtc-interface-class#class_iaudiopcmframesink) 类，并根据场景需要，注册该类的回调。成功注册音频帧观测器后，SDK 会在捕捉到每个音频帧时，触发你所注册的回调。

<a id="api_imediaplayer_registeraudioframeobserver1_imediaplayer__parameters"></a>

### 参数

#### `observer`

音频帧观测器，观测每帧音频的接收，详见 [IAudioPcmFrameSink](/zh-CN/api-reference/rtc/unity/rtc-interface-class#class_iaudiopcmframesink)。

<a id="api_imediaplayer_registeraudioframeobserver1_imediaplayer__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/unity/error-code)了解详情和解决建议。

- [IMediaPlayer](/zh-CN/api-reference/rtc/unity/rtc-interface-class#class_imediaplayer)

## OnPlayBufferUpdated

报告当前缓冲数据能播放的时间。

<a id="callback_imediaplayersourceobserver_onplaybufferupdated__prototype"></a>

```csharp
public virtual void OnPlayBufferUpdated(Int64 playCachedBuffer) { }
```

<a id="callback_imediaplayersourceobserver_onplaybufferupdated__detailed_desc"></a>

播放在线媒体资源的过程中，SDK 会每隔 1 秒触发一次该回调，报告当前缓冲的数据能支持的播放时间。

- 当缓冲数据支持的播放时间小于阈值（默认为 0）时，返回 `PLAYER_EVENT_BUFFER_LOW` (6)。
- 当缓冲数据支持的播放时间大于阈值（默认为 0）时，返回 `PLAYER_EVENT_BUFFER_RECOVER` (7)。

<a id="callback_imediaplayersourceobserver_onplaybufferupdated__parameters"></a>

### 参数

#### `playCachedBuffer`

当前缓冲的数据能支持的播放时间 (毫秒)。

- [IMediaPlayerSourceObserver](/zh-CN/api-reference/rtc/unity/rtc-interface-class#class_imediaplayersourceobserver)

## OnReadData

读取媒体资源数据回调。

<a id="callback_imediaplayercustomdataprovider_onreaddata__prototype"></a>

```csharp
public virtual int OnReadData(IntPtr bufferPtr, int bufferSize)
        {
            return 0;
        }
```

<a id="callback_imediaplayercustomdataprovider_onreaddata__detailed_desc"></a>

使用 [OpenWithMediaSource](/zh-CN/api-reference/rtc/unity/play/mediaplayer/mediaplayer-open#api_imediaplayer_openwithmediasource) 打开媒体资源时，SDK 会触发该回调向你请求传入媒体资源数据的 Buffer。

<a id="callback_imediaplayercustomdataprovider_onreaddata__parameters"></a>

### 参数

#### `bufferPtr`

输入参数，数据 Buffer，单位为字节。请将 SDK 报告的 `bufferSize` 数据写入到此参数中。

#### `bufferSize`

数据 Buffer 的长度，单位为字节。

<a id="callback_imediaplayercustomdataprovider_onreaddata__return_values"></a>

### 返回值

- 如果读取数据成功，请在返回值中传入你实际读取的数据长度，单位为字节。
- 如果读取数据失败，请在返回值中传入 0。

- [IMediaPlayerCustomDataProvider](/zh-CN/api-reference/rtc/unity/rtc-interface-class#class_imediaplayercustomdataprovider)
