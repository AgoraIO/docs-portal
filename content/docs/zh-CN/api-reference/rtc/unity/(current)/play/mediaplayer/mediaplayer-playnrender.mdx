## SelectAudioTrack [2/2]

指定当前音频文件的播放音轨。

<a id="api_imediaplayer_selectaudiotrack_imediaplayer__prototype"></a>

```text
public abstract int SelectAudioTrack(int index);
```

<a id="api_imediaplayer_selectaudiotrack_imediaplayer__detailed_desc"></a>

获取音频文件的音轨索引后，你可以调用该方法指定任一音轨进行播放。如果一个多音轨文件的不同音轨存放了不同语言的歌曲，你可以调用该方法设置播放语言。

:::note
注： 你需要在调用 [GetStreamInfo](/zh-CN/api-reference/rtc/unity/play/mediaplayer/mediaplayer-info#api_imediaplayer_getstreaminfo) 获取音频流索引值后调用该方法。

## SetAudioDualMonoMode

设置当前音频文件的声道模式。

<a id="api_imediaplayer_setaudiodualmonomode__prototype"></a>

```text
public abstract int SetAudioDualMonoMode(AUDIO_DUAL_MONO_MODE mode);
```

<a id="api_imediaplayer_setaudiodualmonomode__detailed_desc"></a>

在双声道音频文件中，左声道和右声道可以存储不同的音频数据。根据实际需要，你可以设置声道模式为原始模式、左声道模式、右声道模式或混合模式。例如，在 KTV 场景中，音频文件的左声道存储了伴奏，右声道存储了原唱的歌声。如果你只需听伴奏，调用该方法设置音频文件的声道模式为左声道模式；如果你需要同时听伴奏和原唱，调用该方法设置声道模式为混合模式。

:::note
注：

- 你需要在调用 [Open](/zh-CN/api-reference/rtc/unity/play/mediaplayer/mediaplayer-open#api_imediaplayer_open) 后调用该方法。
- 该方法仅适用于双声道的音频文件。
:::

## SetLoopCount

设置循环播放。

<a id="api_imediaplayer_setloopcount__prototype"></a>

```text
public abstract int SetLoopCount(int loopCount);
```

<a id="api_imediaplayer_setloopcount__detailed_desc"></a>

如果你希望循环播放，请调用该方法并设置循环播放次数。
循环播放结束时，SDK 会触发 [OnPlayerSourceStateChanged](/zh-CN/api-reference/rtc/unity/play/mediaplayer/mediaplayer-observer#callback_imediaplayersourceobserver_onplayersourcestatechanged) 回调，向你报告播放状态为 PLAYER_STATE_PLAYBACK_ALL_LOOPS_COMPLETED。

<a id="api_imediaplayer_setloopcount__parameters"></a>

### 参数

<ParameterList>
<a id="loopcount"></a>
<Parameter name="loopCount">

循环播放的次数。

- ≥0：循环次数。例如，设为 0 表示不循环播放，一共播放一次；设为 1 表示循环播放一次，一共播放 2 次。
- -1：无限循环播放。

</Parameter>
</ParameterList>

<a id="api_imediaplayer_setloopcount__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。
