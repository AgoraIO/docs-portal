## PauseAllChannelMediaRelay

暂停向所有目标频道转发媒体流。

<a id="api_irtcengine_pauseallchannelmediarelay__prototype"></a>

```csharp
public abstract int PauseAllChannelMediaRelay();
```

<a id="api_irtcengine_pauseallchannelmediarelay__detailed_desc"></a>

开始跨频道转发媒体流后，如果你需要暂停向所有频道转发媒体流，可以调用该方法；暂停后，如果要恢复跨频道媒体流转发，可以调用 [ResumeAllChannelMediaRelay](/zh-CN/api-reference/rtc/unity/channel-media-relay#api_irtcengine_resumeallchannelmediarelay) 方法。

:::info[注]
该方法需要在调用 [StartOrUpdateChannelMediaRelay](/zh-CN/api-reference/rtc/unity/channel-media-relay#api_irtcengine_startorupdatechannelmediarelay) 开始跨频道媒体流转发后调用。
:::

<a id="api_irtcengine_pauseallchannelmediarelay__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/unity/error-code)了解详情和解决建议。
  - -5: 方法调用被拒绝。当前没有正在进行的跨频道媒体流转发。

### 所属接口类
- [IRtcEngine](/zh-CN/api-reference/rtc/unity/rtc-interface-class#class_irtcengine)

## StartOrUpdateChannelMediaRelay

开始或更新跨频道媒体流转发。

<a id="api_irtcengine_startorupdatechannelmediarelay__prototype"></a>

```csharp
public abstract int StartOrUpdateChannelMediaRelay(ChannelMediaRelayConfiguration configuration);
```

<a id="api_irtcengine_startorupdatechannelmediarelay__detailed_desc"></a>

首次成功调用该方法将开始跨频道转发媒体流。如需将流转发到多个目标频道，或退出当前的转发频道，可以再次调用该方法添加或移除转发的目标频道。该功能最多支持将媒体流转发至 6 个目标频道。 成功调用该方法后，SDK 会触发 [OnChannelMediaRelayStateChanged](/zh-CN/api-reference/rtc/unity/channel-media-relay#callback_irtcengineeventhandler_onchannelmediarelaystatechanged) 回调，报告当前的跨频道媒体流转发状态。常见状态如下：

- 如果 OnChannelMediaRelayStateChanged 回调报告 RELAY_STATE_RUNNING (2) 和 RELAY_OK (0)， 则表示 SDK 开始在源频道和目标频道之间转发媒体流。
- 如果 OnChannelMediaRelayStateChanged 回调报告 RELAY_STATE_FAILURE (3)， 则表示跨频道媒体流转发出现异常。

:::info[注]
- 请在成功加入频道后调用该方法。
- 在直播场景中，只有角色为主播的用户才能调用该方法。
- 跨频道媒体流转发功能需要[联系技术支持](https://ticket.shengwang.cn/)开通。
- 该功能不支持 String 型 UID。
:::

<a id="api_irtcengine_startorupdatechannelmediarelay__parameters"></a>

### 参数

#### `configuration`

跨频道媒体流转发参数配置。详见 [ChannelMediaRelayConfiguration](/zh-CN/api-reference/rtc/unity/class-channelmediarelayconfiguration)。

<a id="api_irtcengine_startorupdatechannelmediarelay__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/unity/error-code)了解详情和解决建议。
  - -1: 一般性的错误（未明确归类）。
  - -2: 参数无效。
  - -8：内部状态错误。可能因为用户角色不是主播。

### 所属接口类
- [IRtcEngine](/zh-CN/api-reference/rtc/unity/rtc-interface-class#class_irtcengine)

## StopChannelMediaRelay

停止跨频道媒体流转发。一旦停止，主播会退出所有目标频道。

<a id="api_irtcengine_stopchannelmediarelay__prototype"></a>

```csharp
public abstract int StopChannelMediaRelay();
```

<a id="api_irtcengine_stopchannelmediarelay__detailed_desc"></a>

成功调用该方法后，SDK 会触发 [OnChannelMediaRelayStateChanged](/zh-CN/api-reference/rtc/unity/channel-media-relay#callback_irtcengineeventhandler_onchannelmediarelaystatechanged) 回调。如果报告 `RELAY_STATE_IDLE` (0) 和 `RELAY_OK` (0)，则表示已停止转发媒体流。

:::info[注]
如果该方法调用不成功，SDK 会触发 [OnChannelMediaRelayStateChanged](/zh-CN/api-reference/rtc/unity/channel-media-relay#callback_irtcengineeventhandler_onchannelmediarelaystatechanged) 回调，并报告状态码 `RELAY_ERROR_SERVER_NO_RESPONSE` (2) 或 `RELAY_ERROR_SERVER_CONNECTION_LOST` (8)。你可以调用 [LeaveChannel [2/2]](/zh-CN/api-reference/rtc/unity/channel#api_irtcengine_leavechannel2) 方法离开频道，跨频道媒体流转发会自动停止。
:::

<a id="api_irtcengine_stopchannelmediarelay__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/unity/error-code)了解详情和解决建议。
  - -5: 方法调用被拒绝。当前没有正在进行的跨频道媒体流转发。

### 所属接口类
- [IRtcEngine](/zh-CN/api-reference/rtc/unity/rtc-interface-class#class_irtcengine)
