## 属性

<ParameterList>
<a id="storagepath"></a>
<Parameter name="storagePath">

:::note
注： 请确保你指定的路径存在并且可写。
:::

录制文件在本地保存的绝对路径，需精确到文件名及格式。例如：

- Windows: `C:\Users\<user_name>\AppData\Local\Agora\<process_name>\example.mp4`
- iOS: `/App Sandbox/Library/Caches/example.mp4`
- macOS: `/Library/Logs/example.mp4`
- Android: `/storage/emulated/0/Android/data/<package name>/files/example.mp4`

</Parameter>
<a id="containerformat"></a>
<Parameter name="containerFormat">

录制文件的格式。详见 [MediaRecorderContainerFormat](/zh-CN/api-reference/rtc/unity/enum-mediarecordercontainerformat)。

</Parameter>
<a id="streamtype"></a>
<Parameter name="streamType">

录制内容。详见 [MediaRecorderStreamType](/zh-CN/api-reference/rtc/unity/enum-mediarecorderstreamtype)。

</Parameter>
<a id="maxdurationms"></a>
<Parameter name="maxDurationMs">

最大录制时长，单位为毫秒，默认值为 120000。

</Parameter>
<a id="recorderinfoupdateinterval"></a>
<Parameter name="recorderInfoUpdateInterval">

录制信息更新间隔，单位为毫秒，取值范围为 [1000,10000]。SDK 会根据该值的设置触发 [OnRecorderInfoUpdated](/zh-CN/api-reference/rtc/unity/recording#callback_imediarecorderobserver_onrecorderinfoupdated) 回调，报告更新后的录制信息。

</Parameter>
<a id="width"></a>
<Parameter name="width">

录制视频的宽度 (px)，宽 × 高的最大值不应超过 3840 × 2160。
该参数仅在 调用 [CreateMediaRecorder](/zh-CN/api-reference/rtc/unity/recording#api_irtcengine_createmediarecorder) 且将 [RecorderStreamInfo](/zh-CN/api-reference/rtc/unity/class-recorderstreaminfo) 中的  `type`设置为 PREVIEW 时需要传入。

</Parameter>
<a id="height"></a>
<Parameter name="height">

录制视频的高度 (px)，宽 × 高的最大值不超过 3840 × 2160。
该参数仅在 调用 [CreateMediaRecorder](/zh-CN/api-reference/rtc/unity/recording#api_irtcengine_createmediarecorder) 且将 [RecorderStreamInfo](/zh-CN/api-reference/rtc/unity/class-recorderstreaminfo) 中的  `type`设置为 PREVIEW 时需要传入。

</Parameter>
<a id="fps"></a>
<Parameter name="fps">

录制视频的帧率，最高值不超过 30，如： 5、10、15、24、30 等。
该参数仅在 调用 [CreateMediaRecorder](/zh-CN/api-reference/rtc/unity/recording#api_irtcengine_createmediarecorder) 且将 [RecorderStreamInfo](/zh-CN/api-reference/rtc/unity/class-recorderstreaminfo) 中的  `type`设置为 PREVIEW 时需要传入。

</Parameter>
<a id="sample_rate"></a>
<Parameter name="sample_rate">

录制音频的采样率 (Hz)，可设置为 16000，32000，44100 或 48000。
该参数仅在 调用 [CreateMediaRecorder](/zh-CN/api-reference/rtc/unity/recording#api_irtcengine_createmediarecorder) 且将 [RecorderStreamInfo](/zh-CN/api-reference/rtc/unity/class-recorderstreaminfo) 中的  `type`设置为 PREVIEW 时需要传入。

</Parameter>
<a id="channel_num"></a>
<Parameter name="channel_num">

录制音频的声道数:

- 1: 单声道
- 2: 双声道

该参数仅在 调用 [CreateMediaRecorder](/zh-CN/api-reference/rtc/unity/recording#api_irtcengine_createmediarecorder) 且将 [RecorderStreamInfo](/zh-CN/api-reference/rtc/unity/class-recorderstreaminfo) 中的 `type`设置为 PREVIEW 时需要传入。

</Parameter>
<a id="videosourcetype"></a>
<Parameter name="videoSourceType">

录制视频源的类型。详见 [VIDEO_SOURCE_TYPE](/zh-CN/api-reference/rtc/unity/enum-videosourcetype)。
该参数仅在 调用 [CreateMediaRecorder](/zh-CN/api-reference/rtc/unity/recording#api_irtcengine_createmediarecorder) 且将 [RecorderStreamInfo](/zh-CN/api-reference/rtc/unity/class-recorderstreaminfo) 中的  `type`设置为 PREVIEW 时需要传入。

</Parameter>
