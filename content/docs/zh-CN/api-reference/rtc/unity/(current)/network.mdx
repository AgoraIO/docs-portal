## Complain

投诉通话质量。

<a id="api_irtcengine_complain__prototype"></a>

```csharp
public abstract int Complain(string callId, string description);
```

<a id="api_irtcengine_complain__detailed_desc"></a>

该方法允许用户就通话质量进行投诉。需要在离开频道后调用。

<a id="api_irtcengine_complain__parameters"></a>

### 参数

#### `callId`

通话 ID。你可以通过调用 [GetCallId](/zh-CN/api-reference/rtc/unity/network#api_irtcengine_getcallid) 获取该参数。

#### `description`

（非必选项）通话的描述。长度应小于 800 字节。

<a id="api_irtcengine_complain__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/unity/error-code)了解详情和解决建议。

  - -1: 一般性的错误（未明确归类）。
  - -2: 参数无效。
  - -7: [IRtcEngine](/zh-CN/api-reference/rtc/unity/rtc-interface-class#class_irtcengine) 尚未初始化就调用方法。

### 所属接口类
- [IRtcEngine](/zh-CN/api-reference/rtc/unity/rtc-interface-class#class_irtcengine)

## EnableEncryption

开启或关闭内置加密。

<a id="api_irtcengine_enableencryption__prototype"></a>

```csharp
public abstract int EnableEncryption(bool enabled, EncryptionConfig config);
```

<a id="api_irtcengine_enableencryption__detailed_desc"></a>

用户离开频道后，SDK 会自动关闭加密。如需重新开启加密，你需要在用户再次加入频道前调用该方法。

:::info[注]
- 同一频道内的所有用户在调用该方法时，必须设置相同的加密模式和密钥。
- 如果开启了内置加密，则不能使用旁路推流功能。
:::

<a id="api_irtcengine_enableencryption__scenario"></a>

### 适用场景

对安全要求较高的场景。

<a id="api_irtcengine_enableencryption__timing"></a>

### 调用时机

该方法需要在加入频道前调用。

<a id="api_irtcengine_enableencryption__parameters"></a>

### 参数

#### `enabled`

是否开启内置加密：

- `true`: 开启内置加密。
- `false`:（默认）关闭内置加密。

#### `config`

配置内置加密模式和密钥。详见 [EncryptionConfig](/zh-CN/api-reference/rtc/unity/class-encryptionconfig)。

<a id="api_irtcengine_enableencryption__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败

  - -2: 调用了无效的参数。需重新指定参数。
  - -4: 设置的加密模式不正确或加载外部加密库失败。需检查枚举值是否正确或重新加载外部加密库。
  - -7: SDK 尚未初始化。需在调用 API 之前已创建 [IRtcEngine](/zh-CN/api-reference/rtc/unity/rtc-interface-class#class_irtcengine) 对象并完成初始化。

### 所属接口类
- [IRtcEngine](/zh-CN/api-reference/rtc/unity/rtc-interface-class#class_irtcengine)

## GetCurrentMonotonicTimeInMs

获取 SDK 当前的 Monotonic Time。

<a id="api_irtcengine_getcurrentmonotonictimeinms__prototype"></a>

```csharp
public abstract long GetCurrentMonotonicTimeInMs();
```

<a id="api_irtcengine_getcurrentmonotonictimeinms__detailed_desc"></a>

Monotonic Time 是指一个单调递增的时间序列，它的值会随着时间的推移而增加。单位为毫秒。 在自定义视频采集、自定义音频采集场景中，为确保音视频同步，声网建议你调用该方法获取 SDK 当前的 Monotonic Time 后，将该值传入采集的视频帧（[VideoFrame](/zh-CN/api-reference/rtc/unity/class-videoframe) ）、音频帧（[AudioFrame](/zh-CN/api-reference/rtc/unity/class-audioframe) ）的时间戳参数。

<a id="api_irtcengine_getcurrentmonotonictimeinms__timing"></a>

### 调用时机

加入频道前后均可调用。

<a id="api_irtcengine_getcurrentmonotonictimeinms__return_values"></a>

### 返回值

- ≥ 0: 方法调用成功，返回 SDK 当前的 Monotonic Time（毫秒）。
- &lt; 0: 方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/unity/error-code)了解详情和解决建议。

### 所属接口类
- [IRtcEngine](/zh-CN/api-reference/rtc/unity/rtc-interface-class#class_irtcengine)

## GetNetworkType

获取本地网络连接类型。

<a id="api_irtcengine_getnetworktype__prototype"></a>

```csharp
public abstract int GetNetworkType();
```

<a id="api_irtcengine_getnetworktype__detailed_desc"></a>

你可以在任何阶段通过该方法获取正在使用的网络类型。

:::info[注]
该方法在加入频道前后均可调用。
:::

<a id="api_irtcengine_getnetworktype__return_values"></a>

### 返回值

- ≥ 0: 方法调用成功，返回本地网络连接类型。

  - 0：网络连接已断开。
  - 1：网络类型为 LAN。
  - 2：网络类型为 Wi-Fi（包含热点）。
  - 3：网络类型为 2G 移动网络。
  - 4：网络类型为 3G 移动网络。
  - 5：网络类型为 4G 移动网络。
  - 6：网络类型为 5G 移动网络。
- &lt; 0: 方法调用失败，返回错误码。

  - -1：网络连接类型未知。

### 所属接口类

## SetLogFileSize

设置 SDK 输出的日志文件的大小。

<a id="api_irtcengine_setlogfilesize__prototype"></a>


<a id="api_irtcengine_setlogfilesize__detailed_desc"></a>

#### `废弃`

弃用： 该方法已废弃，请改用 [Initialize](/zh-CN/api-reference/rtc/unity/initialize#api_irtcengine_initialize) 中的 `logConfig` 参数设置日志文件大小。

默认情况下，SDK 会生成 5 个 SDK 日志文件和 5 个 API 调用日志文件，规则如下：

- SDK 日志文件的名称分别为： `agorasdk.log`、 `agorasdk.1.log`、 `agorasdk.2.log`、 `agorasdk.3.log`、 `agorasdk.4.log`。
- API 调用日志文件的名称分别为： `agoraapi.log`、 `agoraapi.1.log`、 `agoraapi.2.log`、 `agoraapi.3.log`、 `agoraapi.4.log`。
- 每个 SDK 日志文件的默认大小为 2,048 KB；API 调用日志文件的默认大小为 2,048 KB。日志文件均为 UTF-8 编码。
- 最新的日志永远写在 `agorasdk.log` 和 `agoraapi.log` 中。
- 当 `agorasdk.log` 写满后，SDK 会按照以下顺序对日志文件进行操作：

  1. 删除 `agorasdk.4.log` 文件（如有）。
  2. 将 `agorasdk.3.log` 重命名为 `agorasdk.4.log`。
  3. 将 `agorasdk.2.log` 重命名为 `agorasdk.3.log`。
  4. 将 `agorasdk.1.log` 重命名为 `agorasdk.2.log`。
  5. 新建 `agorasdk.log` 文件。
- `agoraapi.log` 文件的覆盖规则与 `agorasdk.log` 相同。

:::info[注]
该方法仅用于设置 `agorasdk.log` 文件的大小，对 `agoraapi.log` 不生效。
:::

<a id="api_irtcengine_setlogfilesize__parameters"></a>

### 参数

#### `fileSizeInKBytes`

单个 `agorasdk.log` 日志文件的大小，单位为 KB，取值范围为 [128,20480]，默认值为 2,048 KB。如果你将 `fileSizeInKByte` 设为小于 128 KB，SDK 会自动调整到 128 KB；如果你将 `fileSizeInKByte` 设为大于 20,480 KB，SDK 会自动调整到 20,480 KB。

## OnNetworkQuality

通话中每个用户的网络上下行 last mile 质量报告回调。

<a id="callback_irtcengineeventhandler_onnetworkquality__prototype"></a>

```csharp
public virtual void OnNetworkQuality(RtcConnection connection, uint remoteUid, int txQuality, int rxQuality) {}
```

<a id="callback_irtcengineeventhandler_onnetworkquality__detailed_desc"></a>

该回调描述每个用户在通话中的 last mile 网络状态，其中 last mile 是指设备到声网边缘服务器的网络状态。 该回调每 2 秒触发一次。如果远端有多个用户，该回调每 2 秒会被触发多次。 该回调通过频道内的广播包反馈网络质量。过多的广播包可能引发广播风暴。为防止广播风暴导致频道内大量数据传输，该回调默认支持同时反馈最多 4 个远端主播的网络质量。

:::info[注]
用户不发流时， `txQuality` 为 `UNKNOWN`；用户不收流时， `rxQuality` 为 `UNKNOWN`。
:::

<a id="callback_irtcengineeventhandler_onnetworkquality__parameters"></a>

### 参数

#### `connection`

Connection 信息。详见 [RtcConnection](/zh-CN/api-reference/rtc/unity/class-rtcconnection)。

#### `remoteUid`

用户 ID。表示该回调报告的是持有该 ID 的用户的网络质量。如果当 uid 为 0 时，返回的是本地用户的网络质量。

#### `txQuality`

该用户的上行网络质量，基于发送码率、上行丢包率、平均往返时延和网络抖动计算。 该值代表当前的上行网络质量，帮助判断是否可以支持当前设置的视频编码属性。 假设上行码率是 1000 Kbps，那么支持直播场景下 640 × 480 的分辨率、15 fps 的帧率没有问题，但是支持 1280 × 720 的分辨率就会有困难。详见 [QUALITY_TYPE](/zh-CN/api-reference/rtc/unity/enum-qualitytype)。

#### `rxQuality`

该用户的下行网络质量，基于下行网络的丢包率、平均往返延时和网络抖动计算。详见 [QUALITY_TYPE](/zh-CN/api-reference/rtc/unity/enum-qualitytype)。
