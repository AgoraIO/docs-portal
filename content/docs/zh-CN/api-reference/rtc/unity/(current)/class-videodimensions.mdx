<a id="class_videodimensions__prototype"></a>

```csharp
public class VideoDimensions
    {
        public VideoDimensions()
        {
            width = 640;
            height = 480;
        }

        public VideoDimensions(int width, int height)
        {
            this.width = width;
            this.height = height;
        }
        public int width { set; get; }
        public int height { set; get; }
    }
```

<a id="class_videodimensions__parameters"></a>

## 属性

### `width`

视频宽度，单位为像素。

### `height`

视频高度，单位为像素。
