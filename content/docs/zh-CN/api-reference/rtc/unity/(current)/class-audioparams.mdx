<a id="class_audioparams__detailed_desc"></a>

你可以在以下 API 中传入 [AudioParams](/zh-CN/api-reference/rtc/unity/class-audioparams) 对象，用于设置对应回调报告的音频数据格式：

- [SetRecordingAudioFrameParameters](/zh-CN/api-reference/rtc/unity/audio/audio-raw#api_irtcengine_setrecordingaudioframeparameters)：设置 [OnRecordAudioFrame](/zh-CN/api-reference/rtc/unity/audio/audio-raw#callback_iaudioframeobserverbase_onrecordaudioframe) 回调的数据格式。
- [SetPlaybackAudioFrameParameters](/zh-CN/api-reference/rtc/unity/audio/audio-raw#api_irtcengine_setplaybackaudioframeparameters)：设置 [OnPlaybackAudioFrame](/zh-CN/api-reference/rtc/unity/audio/audio-raw#callback_iaudioframeobserverbase_onplaybackaudioframe) 回调的数据格式。
- [SetMixedAudioFrameParameters](/zh-CN/api-reference/rtc/unity/audio/audio-raw#api_irtcengine_setmixedaudioframeparameters)：设置 [OnMixedAudioFrame](/zh-CN/api-reference/rtc/unity/audio/audio-raw#callback_iaudioframeobserverbase_onmixedaudioframe) 回调的数据格式。
- [SetEarMonitoringAudioFrameParameters](/zh-CN/api-reference/rtc/unity/audio/audio-raw#api_irtcengine_setearmonitoringaudioframeparameters)：设置 [OnEarMonitoringAudioFrame](/zh-CN/api-reference/rtc/unity/audio/audio-raw#callback_iaudioframeobserverbase_onearmonitoringaudioframe) 回调的数据格式。

:::note
注：

- SDK 会通过 [AudioParams](/zh-CN/api-reference/rtc/unity/class-audioparams) 中的 `samplesPerCall`、`sampleRate` 和 `channel` 参数计算采样间隔，并根据该采样间隔触发 [OnRecordAudioFrame](/zh-CN/api-reference/rtc/unity/audio/audio-raw#callback_iaudioframeobserverbase_onrecordaudioframe)、[OnPlaybackAudioFrame](/zh-CN/api-reference/rtc/unity/audio/audio-raw#callback_iaudioframeobserverbase_onplaybackaudioframe)、[OnMixedAudioFrame](/zh-CN/api-reference/rtc/unity/audio/audio-raw#callback_iaudioframeobserverbase_onmixedaudioframe) 和 [OnEarMonitoringAudioFrame](/zh-CN/api-reference/rtc/unity/audio/audio-raw#callback_iaudioframeobserverbase_onearmonitoringaudioframe) 回调。
- 采样间隔 = `samplesPerCall`/(`sampleRate` × `channel`)。
- 请确保采样间隔不得小于 0.01 (s)。
:::

## 属性

### sample_rate

数据的采样率，单位为 Hz，取值如下：

- 8000
- 16000（默认值）
- 32000
- 44100
- 48000

### channels

数据的声道数，取值如下：

- 1：单声道（默认值）
- 2：双声道

### mode

数据的使用模式。详见 [RAW_AUDIO_FRAME_OP_MODE_TYPE](/zh-CN/api-reference/rtc/unity/enum-rawaudioframeopmodetype)。

### samples_per_call

数据的采样点数，如旁路推流应用中通常为 1024。
