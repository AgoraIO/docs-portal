<a id="class_screencaptureconfiguration__prototype"></a>

```csharp
public class ScreenCaptureConfiguration
    {
        public bool isCaptureWindow;
        public long displayId;
        public Rectangle screenRect;
        public long windowId;

        public ScreenCaptureParameters @params;
        public Rectangle regionRect;

        public ScreenCaptureConfiguration()
        {
            this.isCaptureWindow = false;
            this.displayId = 0;
            this.windowId = 0;
        }

        public ScreenCaptureConfiguration(bool isCaptureWindow, long displayId, Rectangle screenRect, long windowId, ScreenCaptureParameters @params, Rectangle regionRect)
        {
            this.isCaptureWindow = isCaptureWindow;
            this.displayId = displayId;
            this.screenRect = screenRect;
            this.windowId = windowId;
            this.@params = @params;
            this.regionRect = regionRect;
        }
    }
```

<a id="class_screencaptureconfiguration__parameters"></a>

## 属性

### `isCaptureWindow`

是否采集屏幕上的窗口：

- true：采集窗口。
- false：（默认）采集屏幕，不采集窗口。

### `displayId`

（仅适用于 macOS 平台）屏幕的 display ID。

:::info[注]
请仅在 Mac 设备上采集屏幕时使用该参数。
:::

### `screenRect`

（仅适用于 Windows 平台）待共享的屏幕相对于虚拟屏的位置。

:::info[注]
请仅在 Windows 设备上采集屏幕时使用该参数。
:::

### `windowId`

（仅适用于 Windows 和 macOS 平台）窗口 ID。

:::info[注]
请仅在采集窗口时使用该参数。
:::

### `parameters`

（仅适用于 Windows 和 macOS 平台）屏幕共享流的编码参数配置。详见 [ScreenCaptureParameters](/zh-CN/api-reference/rtc/unity/class-screencaptureparameters)。

### `regionRect`

（仅适用于 Windows 和 macOS 平台）待共享区域相对于整个屏幕的位置。详见 [Rectangle](/zh-CN/api-reference/rtc/unity/class-rectangle)。如不填，则表示共享整个屏幕。如果设置的共享区域超出了屏幕的边界，则只共享屏幕内的内容。 如果将 [Rectangle](/zh-CN/api-reference/rtc/unity/class-rectangle) 中的 width 或 height 设为 0，则共享整个屏幕。
