## IRtcEngine

RTC SDK 的基础接口类，实现实时音视频的主要功能。

<a id="class_irtcengine__detailed_desc"></a>

[IRtcEngine](/zh-CN/api-reference/rtc/unity/rtc-interface-class#class_irtcengine) 提供了 App 调用的主要方法。
在调用其他 API 之前，必须先调用 [CreateAgoraRtcEngine](/zh-CN/api-reference/rtc/unity/initialize#api_irtcengine_createagorartcengine) 创建 [IRtcEngine](/zh-CN/api-reference/rtc/unity/rtc-interface-class#class_irtcengine) 对象。

<a id="class_irtcengineeventhandler"></a>

<a id="ariaid-title25"></a>

## IRtcEngineEventHandler

接口类 [IRtcEngineEventHandler](/zh-CN/api-reference/rtc/unity/rtc-interface-class#class_irtcengineeventhandler) 用于 SDK 向 App 发送事件通知，App 通过继承该接口类的方法获取 SDK 的事件通知。

<a id="class_irtcengineeventhandler__detailed_desc"></a>

该接口类的所有方法都有缺省（空）实现， App 可以根据需要只继承关心的事件。

:::note
注：

- 在回调方法中，App 不应该做耗时或者调用可能会引起阻塞的 API（如 `sendMessage`），否则可能影响 SDK 的运行。
- SDK 不再捕获开发者在 [IRtcEngineEventHandler](/zh-CN/api-reference/rtc/unity/rtc-interface-class#class_irtcengineeventhandler) 类回调中自行实现的代码逻辑中的异常。你需要自行处理该异常，否则异常出现时可能引起 App 崩溃。
:::
