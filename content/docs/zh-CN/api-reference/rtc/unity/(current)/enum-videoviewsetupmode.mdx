## 枚举值

### `VIDEO_VIEW_SETUP_REPLACE`

0：(默认) 清除已添加的所有视图、替换为新的视图。

### `VIDEO_VIEW_SETUP_ADD`

1：增加一个视图。

### `VIDEO_VIEW_SETUP_REMOVE`

2：删除一个视图。

:::info[注]
当你不再需要使用某个视图时，建议及时设置 `setupMode` 为 VIDEO_VIEW_SETUP_REMOVE 删除视图，否则可能会导致渲染资源泄漏。
:::
