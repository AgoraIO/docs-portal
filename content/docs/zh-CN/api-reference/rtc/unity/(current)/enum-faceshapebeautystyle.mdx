### `自从`

自 v4.4.0 版本新增。

<a id="enum_faceshapebeautystyle__parameters"></a>

## 枚举值

### `FACE_SHAPE_BEAUTY_STYLE_FEMALE`

（0）：（默认）女性风格妆特效。

### `FACE_SHAPE_BEAUTY_STYLE_MALE`

（1）：男性风格妆特效。

### `FACE_SHAPE_BEAUTY_STYLE_NATURAL`

（2）：自然风格妆特效，仅对面部特征进行最小调整。
