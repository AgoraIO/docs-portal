## 枚举值

### `RECORDER_STATE_ERROR`

-1: 音视频流录制出错，错误原因详见 [RecorderReasonCode](/zh-CN/api-reference/rtc/unity/enum-recorderreasoncode)。

### `RECORDER_STATE_START`

2: 音视频流录制开始。

### `RECORDER_STATE_STOP`

3: 音视频流录制停止。
