<a id="api_irtcengine_createmediaplayer"></a>

## CreateMediaPlayer

创建媒体播放器对象。

<a id="api_irtcengine_createmediaplayer__prototype"></a>

```csharp
public abstract IMediaPlayer CreateMediaPlayer();
```

<a id="api_irtcengine_createmediaplayer__detailed_desc"></a>

在调用 [IMediaPlayer](/zh-CN/api-reference/rtc/unity/rtc-interface-class#class_imediaplayer) 类下的其他 API 前，你需要先调用该方法创建一个媒体播放器实例。如果你需要创建多个实例，可以多次调用该方法。

<a id="api_irtcengine_createmediaplayer__timing"></a>

### 调用时机

该方法在加入频道前后均可调用。

<a id="api_irtcengine_createmediaplayer__parameters"></a>

### 参数

#### `delegate`

[IRtcEngine](/zh-CN/api-reference/rtc/unity/rtc-interface-class#class_irtcengine) 的事件句柄，详见 [IRtcEngineEventHandler](/zh-CN/api-reference/rtc/unity/rtc-interface-class#class_irtcengineeventhandler)。

<a id="api_irtcengine_createmediaplayer__return_values"></a>

### 返回值

- 方法调用成功：返回 [IMediaPlayer](/zh-CN/api-reference/rtc/unity/rtc-interface-class#class_imediaplayer) 对象。
- 方法调用失败：返回空指针。

### 所属接口类
- [IRtcEngine](/zh-CN/api-reference/rtc/unity/rtc-interface-class#class_irtcengine)

## DestroyMediaPlayer

销毁媒体播放器。

<a id="api_irtcengine_destroymediaplayer__prototype"></a>

```csharp
public abstract int DestroyMediaPlayer(IMediaPlayer mediaPlayer);
```

<a id="api_irtcengine_destroymediaplayer__detailed_desc"></a>

<a id="api_irtcengine_destroymediaplayer__parameters"></a>

### 参数

#### `mediaPlayer`

[IMediaPlayer](/zh-CN/api-reference/rtc/unity/rtc-interface-class#class_imediaplayer) 对象。

<a id="api_irtcengine_destroymediaplayer__return_values"></a>

### 返回值

- ≥ 0: 方法调用成功，返回媒体播放器 ID
- &lt; 0: 方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/unity/error-code)了解详情和解决建议。

### 所属接口类
- [IRtcEngine](/zh-CN/api-reference/rtc/unity/rtc-interface-class#class_irtcengine)

## GetMediaPlayerCacheManager

获取 IMediaPlayerCacheManager 实例。

<a id="api_imediaplayercachemanager_getmediaplayercachemanager__prototype"></a>

```csharp
public abstract IMediaPlayerCacheManager GetMediaPlayerCacheManager();
```

<a id="api_imediaplayercachemanager_getmediaplayercachemanager__detailed_desc"></a>

在调用 [IMediaPlayerCacheManager](/zh-CN/api-reference/rtc/unity/rtc-interface-class#class_imediaplayercachemanager) 类下的其他 API 前，你需要先调用该方法获取一个媒体播放器缓存管理器的实例。

:::info[注]
由于媒体播放器缓存管理器对象是单例模式，因此多次调用该方法将返回同一个实例。
:::

<a id="api_imediaplayercachemanager_getmediaplayercachemanager__timing"></a>

### 调用时机

请在初始化 [IRtcEngine](/zh-CN/api-reference/rtc/unity/rtc-interface-class#class_irtcengine) 后调用该方法。

<a id="api_imediaplayercachemanager_getmediaplayercachemanager__return_values"></a>

### 返回值

[IMediaPlayerCacheManager](/zh-CN/api-reference/rtc/unity/rtc-interface-class#class_imediaplayercachemanager) 实例。

### 所属接口类
- [IMediaPlayerCacheManager](/zh-CN/api-reference/rtc/unity/rtc-interface-class#class_imediaplayercachemanager)

## InitEventHandler

<a id="api_imediaplayer_initeventhandler_imediaplayer__prototype"></a>

```csharp
public abstract int InitEventHandler(IMediaPlayerSourceObserver engineEventHandler);
```

<a id="api_imediaplayer_initeventhandler_imediaplayer__detailed_desc"></a>

<a id="api_imediaplayer_initeventhandler_imediaplayer__parameters"></a>

### 参数

#### `engineEventHandler`

待添加的回调事件，详见 [IMediaPlayerSourceObserver](/zh-CN/api-reference/rtc/unity/rtc-interface-class#class_imediaplayersourceobserver)。

<a id="api_imediaplayer_initeventhandler_imediaplayer__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/unity/error-code)了解详情和解决建议。

### 所属接口类
- [IMediaPlayer](/zh-CN/api-reference/rtc/unity/rtc-interface-class#class_imediaplayer)
