## CreateDataStream [1/2]

创建数据流。

<a id="api_irtcengine_createdatastream1__prototype"></a>

```csharp
public abstract int CreateDataStream(ref int streamId, bool reliable, bool ordered);
```

<a id="api_irtcengine_createdatastream1__detailed_desc"></a>

你可以调用该方法创建数据流并提高数据传输的可靠性和有序性。

:::info[注]
如你需要更加全面的低延时、高并发、可扩展的实时消息及状态同步解决方案，推荐使用[实时消息](https://doc.shengwang.cn/doc/rtm2/unity/landing-page)。 在 [IRtcEngine](/zh-CN/api-reference/rtc/unity/rtc-interface-class#class_irtcengine) 生命周期内，每个用户最多只能创建 5 个数据流。离开频道时数据流会被销毁，如需使用需要重新创建数据流。
:::

<a id="api_irtcengine_createdatastream1__timing"></a>

### 调用时机

该方法在加入频道前后均可调用。

<a id="api_irtcengine_createdatastream1__related"></a>

### 相关回调

将 `reliable` 设置为 true 后，如果接收方 5 秒没有收到发送方所发送的数据，会触发 [OnStreamMessageError](/zh-CN/api-reference/rtc/unity/metadata/datastream#callback_irtcengineeventhandler_onstreammessageerror) 回调并获得相应报错信息。

<a id="api_irtcengine_createdatastream1__parameters"></a>

### 参数

#### `streamId`

输出参数，创建好的数据流 ID。

#### `reliable`

:::info[注]
请确保将 `reliable` 和 `ordered` 同时设为 true 或同时设为 false。
:::

是否保证数据可靠性，即接收方是否需要在数据发送后的 5 秒内接收：

- true: 接收方 5 秒内会收到发送方所发送的数据，否则会收到 OnStreamMessageError 回调并获得相应报错信息。
- false: 接收方不保证收到，就算数据丢失也不会报错。

#### `ordered`

是否保证数据有序性，即接收方是否需要收到有序的数据：

- true: 接收方会按照发送方发送的顺序收到数据包。
- false: 接收方不保证按照发送方发送的顺序收到数据包。

<a id="api_irtcengine_createdatastream1__return_values"></a>

### 返回值

- 0: 创建数据流成功。
- &lt; 0：方法调用失败。详见[错误码](/zh-CN/realtime-media/rtc/reference/error-code)了解详情和解决建议。

### 所属接口类
- [IRtcEngine](/zh-CN/api-reference/rtc/unity/rtc-interface-class#class_irtcengine)

## SendStreamMessage

发送数据流。

<a id="api_irtcengine_sendstreammessage__prototype"></a>

```csharp
public abstract int SendStreamMessage(int streamId, byte[] data, uint length);
```

<a id="api_irtcengine_sendstreammessage__detailed_desc"></a>

调用 [CreateDataStream [2/2]](/zh-CN/api-reference/rtc/unity/metadata/datastream#api_irtcengine_createdatastream2) 后，你可以调用该方法向频道内所有用户发送数据流消息。 SDK 对该方法的实现进行了如下限制：

- 频道内每个客户端最多可以同时拥有 5 个数据通道，所有数据通道共用的总发包码率限制为 30 KB/s。
- 每个数据通道每秒最多能发送 60 个包，每个包最大为 1 KB。

成功调用该方法后，远端会触发 [OnStreamMessage](/zh-CN/api-reference/rtc/unity/metadata/datastream#callback_irtcengineeventhandler_onstreammessage) 回调，远端用户可以在该回调中获取接收到的流消息；若调用失败，远端会触发 [OnStreamMessageError](/zh-CN/api-reference/rtc/unity/metadata/datastream#callback_irtcengineeventhandler_onstreammessageerror) 回调。

:::info[注]
如你需要更加全面的低延时、高并发、可扩展的实时消息及状态同步解决方案，推荐使用[实时消息](https://doc.shengwang.cn/doc/rtm2/unity/landing-page)。

- 该方法需要在加入频道后、且调用 CreateDataStream [2/2] 创建数据通道之后调用。
- 该方法仅适用于主播用户。
:::

<a id="api_irtcengine_sendstreammessage__parameters"></a>

### 参数

#### `streamId`

数据流 ID。可以通过 [CreateDataStream [2/2]](/zh-CN/api-reference/rtc/unity/metadata/datastream#api_irtcengine_createdatastream2) 获取。

#### `data`

待发送的数据。

#### `length`

数据长度。

<a id="api_irtcengine_sendstreammessage__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](/zh-CN/realtime-media/rtc/reference/error-code)了解详情和解决建议。

### 所属接口类
- [IRtcEngine](/zh-CN/api-reference/rtc/unity/rtc-interface-class#class_irtcengine)

## OnStreamMessage

接收到对方数据流消息的回调。

<a id="callback_irtcengineeventhandler_onstreammessage__prototype"></a>

```csharp
public virtual void OnStreamMessage(RtcConnection connection, uint remoteUid, int streamId, byte[] data, ulong length, ulong sentTs) { }
```

<a id="callback_irtcengineeventhandler_onstreammessage__detailed_desc"></a>

该回调表示本地用户收到了远端用户调用 [SendStreamMessage](/zh-CN/api-reference/rtc/unity/metadata/datastream#api_irtcengine_sendstreammessage) 方法发送的流消息。

:::info[注]
如你需要更加全面的低延时、高并发、可扩展的实时消息及状态同步解决方案，推荐使用[实时消息](https://doc.shengwang.cn/doc/rtm2/unity/landing-page)。
:::

<a id="callback_irtcengineeventhandler_onstreammessage__parameters"></a>

### 参数

#### `connection`

Connection 信息。详见 [RtcConnection](/zh-CN/api-reference/rtc/unity/class-rtcconnection)。

#### `remoteUid`

发送消息的用户 ID。

#### `streamId`

接收到的消息的 Stream ID。

#### `data`

接收到的数据。

#### `length`

数据长度，单位为字节。

#### `sentTs`

数据流发出的时间。

- [IRtcEngineEventHandler](/zh-CN/api-reference/rtc/unity/rtc-interface-class#class_irtcengineeventhandler)

如你需要更加全面的低延时、高并发、可扩展的实时消息及状态同步解决方案，推荐使用[实时消息](https://doc.shengwang.cn/doc/rtm2/unity/landing-page)。
:::

<a id="callback_irtcengineeventhandler_onstreammessageerror__parameters"></a>

### 参数

#### `connection`

Connection 信息。详见 [RtcConnection](/zh-CN/api-reference/rtc/unity/class-rtcconnection)。

#### `remoteUid`

发送消息的用户 ID。

#### `streamId`

接收到的消息的 Stream ID。

#### `code`

错误码。详见 [错误码](/zh-CN/realtime-media/rtc/reference/error-code)。

丢失的消息数量。

#### `cached`

数据流中断时，后面缓存的消息数量。
