<a id="cputotalusage"></a>
<Parameter name="cpuTotalUsage">

当前系统的 CPU 使用率 (%)。
对于 Windows 平台，在多核环境中，该成员指多核 CPU 的平均使用率。 计算方式为 (100 - 任务管理中显示的系统空闲进程 CPU)/100。

:::note
注：

- [OnLeaveChannel](/zh-CN/api-reference/rtc/unity/channel#callback_irtcengineeventhandler_onleavechannel) 回调中报告的 `cpuTotalUsage` 恒为 0。
- 自 Android 8.1 起，因系统限制，你无法通过该属性获取 CPU 使用率。
:::

</Parameter>

</Parameter>
<a id="gatewayrtt"></a>
<Parameter name="gatewayRtt">

客户端到本地路由器的往返时延 (ms)。

:::note
注： 该属性默认在 iOS 14 之前的设备上开启，在 iOS 14 及之后的设备上关闭。

                        如需在 iOS 14 及之后的设备上启用该属性，请[联系技术支持](https://ticket.shengwang.cn/)。
在 Android 平台上，如需获取 `gatewayRtt`，请确保已在项目 `AndroidManifest.xml` 文件的 `</application>` 后面添加 `android.permission.ACCESS_WIFI_STATE` 权限。
:::

</Parameter>
