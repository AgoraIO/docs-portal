## SetDefaultAudioRouteToSpeakerphone

设置默认的音频路由。

<a id="api_irtcengine_setdefaultaudioroutetospeakerphone__prototype"></a>

```text
public abstract int SetDefaultAudioRouteToSpeakerphone(bool defaultToSpeaker);
```

<a id="api_irtcengine_setdefaultaudioroutetospeakerphone__detailed_desc"></a>

手机设备一般有两个音频路由，一个是位于顶部的听筒，播放声音偏小；一个是位于底部的扬声器，播放声音偏大。设置默认的音频路由，就是在没有外接设备的前提下，设置系统使用听筒还是扬声器播放音频。
不同场景下，系统默认的音频路由也不同。具体如下：

- 语音通话：听筒
- 语音直播：扬声器
- 视频通话：扬声器
- 视频直播：扬声器

调用该 API 可以改变上述默认音频路由。

:::note
注： 该方法仅适用于 Android 和 iOS 平台。
在调用该方法设置默认音频路由后，系统实际音频路由会随着外接音频设备（有线耳机或蓝牙耳机）的连接发生改变。详见[音频路由](/zh-CN/realtime-media/rtc/build/audio/audio-route)。
:::

<a id="api_irtcengine_setdefaultaudioroutetospeakerphone__timing"></a>

### 调用时机

该方法需要在加入频道前调用。如需在加入频道后切换音频路由，请调用 [SetEnableSpeakerphone](/zh-CN/api-reference/rtc/unity/device-management/audio-route#api_irtcengine_setenablespeakerphone)。

<a id="api_irtcengine_setdefaultaudioroutetospeakerphone__related"></a>

### 相关回调

成功改变音频路由后，SDK 会触发 [OnAudioRoutingChanged](/zh-CN/api-reference/rtc/unity/device-management/audio-route#callback_irtcengineeventhandler_onaudioroutingchanged) 回调，报告当前的音频路由。

<a id="api_irtcengine_setdefaultaudioroutetospeakerphone__parameters"></a>

### 参数

<ParameterList>
<a id="defaulttospeaker"></a>
<Parameter name="defaultToSpeaker">

是否使用扬声器作为默认的音频路由：

- true: 设置默认音频路由为扬声器。
- false: 设置默认音频路由为听筒。

</Parameter>
</ParameterList>

<a id="api_irtcengine_setdefaultaudioroutetospeakerphone__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。

### 所属接口类

## SetEnableSpeakerphone

开启或关闭扬声器播放。

<a id="api_irtcengine_setenablespeakerphone__prototype"></a>

```text
public abstract int SetEnableSpeakerphone(bool speakerOn);
```

<a id="api_irtcengine_setenablespeakerphone__detailed_desc"></a>

不同场景下 SDK 默认的音频路由见[音频路由](/zh-CN/realtime-media/rtc/build/audio/audio-route)。

:::note
注： 该方法仅适用于 Android 和 iOS 平台。

- 该方法只设置用户在当前频道内使用的音频路由，不会影响 SDK 默认的音频路由。如果用户离开当前频道并加入新的频道，则用户还是会使用 SDK 默认的音频路由。
- 如果用户使用了蓝牙耳机、有线耳机等外接音频播放设备，则该方法的设置无效，音频只会通过外接设备播放。当有多个外接设备时，音频会通过最后一个接入的设备播放。
:::

<a id="api_irtcengine_setenablespeakerphone__scenario"></a>

### 适用场景

如果 SDK 默认的音频路由或 `setDefaultAudioRouteToSpeakerphone` 的设置无法满足你的需求，你可以调用该方法切换当前的音频路由。

<a id="api_irtcengine_setenablespeakerphone__timing"></a>

### 调用时机

该方法需要在加入频道后调用。

<a id="api_irtcengine_setenablespeakerphone__related"></a>

### 相关回调

成功改变音频路由后，SDK 会触发 [OnAudioRoutingChanged](/zh-CN/api-reference/rtc/unity/device-management/audio-route#callback_irtcengineeventhandler_onaudioroutingchanged) 回调，报告当前的音频路由。

<a id="api_irtcengine_setenablespeakerphone__parameters"></a>

### 参数

<ParameterList>
<a id="speakeron"></a>
<Parameter name="speakerOn">

设置是否开启扬声器播放：

- true: 开启。音频路由为扬声器。
- false: 关闭。音频路由为听筒。

</Parameter>
</ParameterList>

<a id="api_irtcengine_setenablespeakerphone__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。

### 所属接口类

- [IRtcEngine](/zh-CN/api-reference/rtc/unity/rtc-interface-class#class_irtcengine)

## SetRouteInCommunicationMode

选择通话音量模式下的音频路由。

<a id="api_irtcengine_setrouteincommunicationmode__prototype"></a>

```text
public abstract int SetRouteInCommunicationMode(int route);
```

<a id="api_irtcengine_setrouteincommunicationmode__detailed_desc"></a>

该方法用于在通话音量模式（[MODE_IN_COMMUNICATION](https://developer.android.google.cn/reference/kotlin/android/media/AudioManager?hl=en#mode_in_communication)）下，将音频路由从蓝牙耳机切换为听筒、有线耳机或扬声器。

:::note
注： 该方法仅适用于 Android。
该方法与 [SetEnableSpeakerphone](/zh-CN/api-reference/rtc/unity/device-management/audio-route#api_irtcengine_setenablespeakerphone) 同时使用时可能引起冲突。声网建议你单独使用 [SetRouteInCommunicationMode](/zh-CN/api-reference/rtc/unity/device-management/audio-route#api_irtcengine_setrouteincommunicationmode)。
:::

<a id="api_irtcengine_setrouteincommunicationmode__timing"></a>

### 调用时机

加入频道前后均可调用。

<a id="api_irtcengine_setrouteincommunicationmode__related"></a>

### 相关回调

成功调用该方法后，SDK 会触发 [OnAudioRoutingChanged](/zh-CN/api-reference/rtc/unity/device-management/audio-route#callback_irtcengineeventhandler_onaudioroutingchanged) 回调，报告当前的音频路由。

<a id="api_irtcengine_setrouteincommunicationmode__parameters"></a>

### 参数

<ParameterList>
<a id="route"></a>
<Parameter name="route">

期望使用的音频路由:

- -1：系统默认的音频路由。
- 0：带麦克风的耳机。
- 1：听筒。
- 2：不带麦克风的耳机。
- 3：设备自带的扬声器。
- 4：（暂不支持）外接的扬声器。
- 5：蓝牙耳机。
- 6：USB 设备。

</Parameter>
</ParameterList>

<a id="api_irtcengine_setrouteincommunicationmode__return_values"></a>

### 返回值

无实际意义。

### 所属接口类

- [IRtcEngine](/zh-CN/api-reference/rtc/unity/rtc-interface-class#class_irtcengine)
