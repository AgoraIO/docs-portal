## 枚举值

### `AUDIO_FILE_RECORDING_MIC`

1: 仅录制本地用户的音频。

### `AUDIO_FILE_RECORDING_PLAYBACK`

2: 仅录制所有远端用户的音频。

### `AUDIO_FILE_RECORDING_MIXED`

3: 录制本地和所有远端用户混音后的音频。
