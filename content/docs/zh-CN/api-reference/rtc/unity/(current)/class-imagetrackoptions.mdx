<a id="class_imagetrackoptions__prototype"></a>

```csharp
public class ImageTrackOptions
    {
        public string imageUrl { set; get; }
        public int fps { set; get; }

        public ImageTrackOptions()
        {
            imageUrl = "";
            fps = 1;
        }
    };
```

<a id="class_imagetrackoptions__parameters"></a>

## 属性

### `imageUrl`

垫片图片的 URL，目前支持 JPEG、JPG、PNG、GIF 格式的图片。支持从本地绝对路径或相对路径添加垫片图片。

:::info[注]
在 Android 平台上，不支持从 `/assets/` 中添加垫片图片。
:::

### `fps`

视频帧率，取值范围为 [1,30]。默认值为 1。
