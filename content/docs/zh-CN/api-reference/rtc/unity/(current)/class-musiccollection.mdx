<a id="class_musiccollection__prototype"></a>

```csharp
public class MusicCollection
    {
        public int count;
        public int total;
        public int page;
        public int pageSize;
        public Music[] music;
    };
```

<a id="class_musiccollection__parameters"></a>

## 属性

### `count`

此次请求的音乐资源列表中的音乐数量。

### `total`

列表内音乐资源的总数量。

### `page`

当前页面编号，默认从 1 开始。

### `pageSize`

当前音乐资源列表的页面总数量，最大值为 50。

### `musicList`

当前页面列表中音乐资源的详细信息，详见 [Music](/zh-CN/api-reference/rtc/unity/class-music)。
