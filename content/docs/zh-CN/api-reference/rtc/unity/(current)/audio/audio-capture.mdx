## EnableLocalAudio

开启或关闭本地音频采集。

<a id="api_irtcengine_enablelocalaudio__prototype"></a>

```text
public abstract int EnableLocalAudio(bool enabled);
```

<a id="api_irtcengine_enablelocalaudio__detailed_desc"></a>

当用户加入频道时，音频功能默认是开启的。该方法可以关闭或重新开启本地音频功能，即停止或重新开始本地音频采集。
该方法与 [MuteLocalAudioStream](/zh-CN/api-reference/rtc/unity/publishnsubscribe#api_irtcengine_mutelocalaudiostream) 的区别在于：

- [EnableLocalAudio](/zh-CN/api-reference/rtc/unity/audio/audio-capture#api_irtcengine_enablelocalaudio): 开启或关闭本地音频采集及处理。使用 [EnableLocalAudio](/zh-CN/api-reference/rtc/unity/audio/audio-capture#api_irtcengine_enablelocalaudio) 关闭或开启本地采集后，本地听远端播放会有短暂中断。
- [MuteLocalAudioStream](/zh-CN/api-reference/rtc/unity/publishnsubscribe#api_irtcengine_mutelocalaudiostream): 停止或继续发送本地音频流，不影响音频的采集状态。

<a id="api_irtcengine_enablelocalaudio__scenario"></a>

### 适用场景

该方法不影响远端音频流的接收和播放。`enableLocalAudio(false)` 适用于只接收远端音频而不发送本地采集音频的场景。

<a id="api_irtcengine_enablelocalaudio__timing"></a>

### 调用时机

该方法在加入频道前后均可调用。在加入频道前调用只能设置设备状态，在加入频道后才会立即生效。

<a id="api_irtcengine_enablelocalaudio__related"></a>

### 相关回调

音频功能关闭或重新开启后，会收到 [OnLocalAudioStateChanged](/zh-CN/api-reference/rtc/unity/audio/audio-basic#callback_irtcengineeventhandler_onlocalaudiostatechanged) 回调，并报告 `LOCAL_AUDIO_STREAM_STATE_STOPPED`(0) 或 `LOCAL_AUDIO_STREAM_STATE_RECORDING`(1)。

<a id="api_irtcengine_enablelocalaudio__parameters"></a>

### 参数

### enabled

- true: 重新开启本地音频功能，即开启本地音频采集（默认）；
- false: 关闭本地音频功能，即停止本地音频采集。

<a id="api_irtcengine_enablelocalaudio__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。

### 所属接口类

- [IRtcEngine](/zh-CN/api-reference/rtc/unity/rtc-interface-class#class_irtcengine)

## EnableLoopbackRecording

开启声卡采集。

<a id="api_irtcengine_enableloopbackrecording__prototype"></a>

```text
public abstract int EnableLoopbackRecording(bool enabled, string deviceName = "");
```

<a id="api_irtcengine_enableloopbackrecording__detailed_desc"></a>

启用声卡采集功能后，声卡播放的声音会被合到本地音频流中，从而可以发送到远端。

:::note
注：

- 该方法仅适用于 macOS 和 Windows 平台。
- 该方法在加入频道前后都能调用。
- 如果你调用了 [DisableAudio](/zh-CN/api-reference/rtc/unity/audio/audio-basic#api_irtcengine_disableaudio) 关闭音频模块，声卡采集功能也会被关闭。如果你需要再次启用声卡采集功能，需要调用 [EnableAudio](/zh-CN/api-reference/rtc/unity/audio/audio-basic#api_irtcengine_enableaudio) 启用音频模块后再次调用 [EnableLoopbackRecording](/zh-CN/api-reference/rtc/unity/audio/audio-capture#api_irtcengine_enableloopbackrecording)。
:::

<a id="api_irtcengine_enableloopbackrecording__parameters"></a>

### 参数

### enabled

是否开启声卡采集:

- true: 开启声卡采集；系统声音 &gt; 输出界面显示虚拟声卡名称。
- false:（默认）关闭声卡采集；系统声音 &gt; 输出界面不显示虚拟声卡名称。

### deviceName

- macOS: 虚拟声卡的设备名。默认为空，代表使用 AgoraALD 虚拟声卡进行采集。
- Windows: 声卡的设备名。默认为空，代表使用设备自带的声卡进行采集。

<a id="api_irtcengine_enableloopbackrecording__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。

### 所属接口类

- [IRtcEngine](/zh-CN/api-reference/rtc/unity/rtc-interface-class#class_irtcengine)

## MuteRecordingSignal

是否将录音信号静音。

<a id="api_irtcengine_muterecordingsignal__prototype"></a>

```text
public abstract int MuteRecordingSignal(bool mute);
```

<a id="api_irtcengine_muterecordingsignal__detailed_desc"></a>

如果你已经调用 [AdjustRecordingSignalVolume](/zh-CN/api-reference/rtc/unity/audio/audio-capture#api_irtcengine_adjustrecordingsignalvolume) 调节了音频采集信号音量，则调用该方法并设置为 true 时，SDK 的行为如下：

1. 记录调节后的音量。
2. 将音频采集信号静音。

当你再次调用该方法并设置为 false 时，录音信号会恢复为静音前 SDK 记录的音量。

<a id="api_irtcengine_muterecordingsignal__timing"></a>

### 调用时机

加入频道前后均可调用。

<a id="api_irtcengine_muterecordingsignal__parameters"></a>

### 参数

### mute

- true: 静音。
- false:（默认）原始音量。

<a id="api_irtcengine_muterecordingsignal__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。
