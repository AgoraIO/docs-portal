
## SetDistanceUnit

设置游戏引擎单位距离的长度（米）。

<a id="api_ibasespatialaudioengine_setdistanceunit__prototype"></a>

```text
public abstract int SetDistanceUnit(float unit);
```

<a id="api_ibasespatialaudioengine_setdistanceunit__detailed_desc"></a>

游戏引擎里的距离单位是游戏引擎自定义的，而声网空间音频算法的距离单位为米。默认情况下，SDK 会将每单位的游戏引擎距离换算为一米。你可以调用该方法，将游戏引擎里的单位距离换算为指定的米数。

<a id="api_ibasespatialaudioengine_setdistanceunit__parameters"></a>

### 参数

### unit

每单位游戏引擎距离转换后的米数。该参数取值需大于 0.00，默认值为 1.00。例如，将 unit 设为 2.00，表示每单位的游戏引擎距离等于 2 米。
该值越大，当远端用户远离本地用户时，本地用户听到的声音衰减速度越快。

<a id="api_ibasespatialaudioengine_setdistanceunit__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。

## SetPlayerAttenuation

设置媒体播放器的声音衰减属性。

<a id="api_ibasespatialaudioengine_setplayerattenuation__prototype"></a>

```text
public abstract int SetPlayerAttenuation(int playerId, double attenuation, bool forceSet);
```

<a id="api_ibasespatialaudioengine_setplayerattenuation__detailed_desc"></a>

<a id="api_ibasespatialaudioengine_setplayerattenuation__parameters"></a>

### 参数

### playerId

媒体播放器 ID。

### attenuation

媒体播放器的声音衰减系数，取值范围为[0,1]。其中：

- 0：广播模式，即音量和音色均不随距离衰减，无论距离远近，本地用户听到的音量和音色都无变化。
- (0,0.5)：弱衰减模式，即音量和音色在传播过程中仅发生微弱衰减，跟真实环境相比，声音可以传播得更远。
- 0.5：（默认）模拟音量在真实环境下的衰减，效果等同于不设置 `attenuation` 参数。
- (0.5,1]：强衰减模式，即音量和音色在传播过程中发生迅速衰减。

### forceSet

是否强制设定媒体播放器的声音衰减效果：

- true：强制使用 `attenuation` 设置媒体播放器的声音衰减效果，此时 [SpatialAudioZone](/zh-CN/api-reference/rtc/unity/class-spatialaudiozone) 中的 `audioAttenuation` 中设置的隔声区域衰减系数对媒体播放器不生效。
- false：不强制使用 `attenuation` 设置媒体播放器的声音衰减效果，分为以下两种情况。

  - 如果音源和听声者分属于隔声区域内部和外部，则声音衰减效果由 [SpatialAudioZone](/zh-CN/api-reference/rtc/unity/class-spatialaudiozone) 中的 `audioAttenuation` 决定。
  - 如果音源和听声者在同一个隔声区域内或同在隔声区域外，则声音衰减效果由该方法中的 `attenuation` 决定。

<a id="api_ibasespatialaudioengine_setplayerattenuation__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。

<a id="api_ilocalspatialaudioengine_setremoteaudioattenuation__prototype"></a>

```text
public abstract int SetRemoteAudioAttenuation(uint uid, double attenuation, bool forceSet);
```

<a id="api_ilocalspatialaudioengine_setremoteaudioattenuation__detailed_desc"></a>

<a id="api_ilocalspatialaudioengine_setremoteaudioattenuation__parameters"></a>

### 参数

### uid

用户 ID。需与用户加入频道时填写的用户 ID 一致。

### attenuation

针对该用户的声音衰减系数，取值范围为[0,1]。其中：

### forceSet

是否强制设定该用户的声音衰减效果：

- true：强制使用 `attenuation` 设置该用户的声音衰减效果，此时 [SpatialAudioZone](/zh-CN/api-reference/rtc/unity/class-spatialaudiozone) 中的 `audioAttenuation` 中设置的隔声区域衰减系数对该用户不生效。
- false：不强制使用 `attenuation`设置用户的声音衰减效果，分为以下两种情况。

  - 如果音源和听声者分属于隔声区域内部和外部，则声音衰减效果由 [SpatialAudioZone](/zh-CN/api-reference/rtc/unity/class-spatialaudiozone) 中的 `audioAttenuation` 决定。
  - 如果音源和听声者在同一个隔声区域内或同在隔声区域外，则声音衰减效果由该方法中的 `attenuation` 决定。

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。

## SetZones

设置隔声区域。

<a id="api_ibasespatialaudioengine_setzones__prototype"></a>

```text
public abstract int SetZones(SpatialAudioZone[] zones, uint zoneCount);
```

<a id="api_ibasespatialaudioengine_setzones__detailed_desc"></a>

在虚拟互动场景下，你可以通过该方法设置隔声区域和声音衰减系数。当音源（可以为用户或媒体播放器）跟听声者分属于隔声区域内部和外部时，会体验到类似真实环境中声音在遇到建筑隔断时的衰减效果。

- 当音源跟听声者分属于隔声区域内部和外部时，声音的衰减效果由 [SpatialAudioZone](/zh-CN/api-reference/rtc/unity/class-spatialaudiozone) 中的声音衰减系数决定。
- 如果用户或媒体播放器同在一个隔声区域内，则不受 [SpatialAudioZone](/zh-CN/api-reference/rtc/unity/class-spatialaudiozone) 的影响，声音的衰减效果由 [SetPlayerAttenuation](/zh-CN/api-reference/rtc/unity/audio/audio-prenpost/spatial-audio#api_ibasespatialaudioengine_setplayerattenuation) 或 [SetRemoteAudioAttenuation](/zh-CN/api-reference/rtc/unity/audio/audio-prenpost/spatial-audio#api_ilocalspatialaudioengine_setremoteaudioattenuation) 中的 `attenuation` 参数决定。如果不调用 [SetPlayerAttenuation](/zh-CN/api-reference/rtc/unity/audio/audio-prenpost/spatial-audio#api_ibasespatialaudioengine_setplayerattenuation) 或 [SetRemoteAudioAttenuation](/zh-CN/api-reference/rtc/unity/audio/audio-prenpost/spatial-audio#api_ilocalspatialaudioengine_setremoteaudioattenuation)，则 SDK 默认声音的衰减系数为 0.5，即模拟声音在真实环境下的衰减。
- 如果音源跟接收者分别属于两个隔声区域，则接收者无法听到音源。

:::note
注： 如果多次调用该方法，以最后一次设置的隔声区域为准。
:::

<a id="api_ibasespatialaudioengine_setzones__parameters"></a>

### 参数

### zones

隔声区域的设置。详见 [SpatialAudioZone](/zh-CN/api-reference/rtc/unity/class-spatialaudiozone)。当你将该参数设置为 `NULL` 时，表示清除所有隔声区域。

:::note
注： 在 Windows 平台上，需确保 `zones` 数组中的成员个数与 `zoneCount` 的值相等，否则会导致崩溃。
:::

### zoneCount

隔声区域的数量。

<a id="api_ibasespatialaudioengine_setzones__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。

## UpdateSelfPosition

更新本地用户的空间位置。

<a id="api_ibasespatialaudioengine_updateselfposition__prototype"></a>

```text
public abstract int UpdateSelfPosition(float[] position, float[] axisForward, float[] axisRight, float[] axisUp);
```

<a id="api_ibasespatialaudioengine_updateselfposition__detailed_desc"></a>

- 在 [ILocalSpatialAudioEngine](/zh-CN/api-reference/rtc/unity/rtc-interface-class#class_ilocalspatialaudioengine) 类下，该方法需要和 [UpdateRemotePosition](/zh-CN/api-reference/rtc/unity/audio/audio-prenpost/spatial-audio#api_ilocalspatialaudioengine_updateremoteposition) 搭配使用。SDK 会根据该方法和 [UpdateRemotePosition](/zh-CN/api-reference/rtc/unity/audio/audio-prenpost/spatial-audio#api_ilocalspatialaudioengine_updateremoteposition) 设置的参数计算本地和远端用户之间的相对位置，从而计算用户的空间音频参数。

<a id="api_ibasespatialaudioengine_updateselfposition__parameters"></a>

### 参数

### position

在世界坐标系中的坐标。该参数是长度为 3 的数组，三个值依次表示前、右、上的坐标值。前、右、上分别对应 Unity Vector3 的 z、x、y 轴的正方向。

### axisForward

在世界坐标系前轴的单位向量。该参数是长度为 3 的数组，三个值依次表示前、右、上的坐标值。前、右、上分别对应 Unity Vector3 的 z、x、y 轴的正方向。

### axisRight

在世界坐标系右轴的单位向量。该参数是长度为 3 的数组，三个值依次表示前、右、上的坐标值。

### axisUp

在世界坐标系上轴的单位向量。该参数是长度为 3 的数组，三个值依次表示前、右、上的坐标值。

<a id="api_ibasespatialaudioengine_updateselfposition__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。
