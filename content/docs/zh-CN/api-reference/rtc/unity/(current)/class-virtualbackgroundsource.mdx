<a id="class_virtualbackgroundsource__prototype"></a>

```csharp
public class VirtualBackgroundSource
    {
        public VirtualBackgroundSource()
        {
            background_source_type = BACKGROUND_SOURCE_TYPE.BACKGROUND_COLOR;
            color = 0xffffff;
            source = "";
            blur_degree = BACKGROUND_BLUR_DEGREE.BLUR_DEGREE_HIGH;
        }
        public BACKGROUND_SOURCE_TYPE background_source_type;
        public uint color;
        public string source;
        public BACKGROUND_BLUR_DEGREE blur_degree;
    };
```

<a id="class_virtualbackgroundsource__parameters"></a>

## 属性

### `background_source_type`

自定义的背景。详见 [BACKGROUND_SOURCE_TYPE](/zh-CN/api-reference/rtc/unity/enum-backgroundsourcetype)。

### `color`

自定义的背景图颜色。格式为 RGB 定义下的十六进制整数，不带 # 号，如 0xFFB6C1 表示浅粉色。 默认值为 0xFFFFFF，表示白色。 取值范围为 [0x000000，0xffffff]。如果取值非法，SDK 会用白色背景图替换原背景图。

:::info[注]
该参数仅在自定义背景为以下类型时生效，具体效果如下：

- BACKGROUND_COLOR：背景图为该参数传入颜色的纯色图片。
- BACKGROUND_IMG：如果 `source` 中的图片使用了透明背景，则会使用该参数传入的颜色填充透明背景。
:::

### `source`

自定义背景的本地绝对路径。支持 PNG、JPG、MP4、 AVI、 MKV 和 FLV 格式。如果路径无效，SDK 会使用原背景图或 `color` 指定的纯色背景。

:::info[注]
该参数仅在自定义背景图类型为 BACKGROUND_IMG 或 BACKGROUND_VIDEO 时生效。
:::

### `blur_degree`

自定义背景图的模糊程度。详见 [BACKGROUND_BLUR_DEGREE](/zh-CN/api-reference/rtc/unity/enum-backgroundblurdegree)。

:::info[注]
该参数仅在自定义背景图类型为 BACKGROUND_BLUR 时生效。
:::
