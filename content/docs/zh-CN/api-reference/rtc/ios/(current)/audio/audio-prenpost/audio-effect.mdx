## enableVoiceAITuner:type:

启用或关闭语音 AI 调音器。

```objectivec
- (int)enableVoiceAITuner:(BOOL)enabled type:(AgoraVoiceAITunerType)type NS_SWIFT_NAME(enableVoiceAITuner(_:type:));
```

<a id="api_irtcengine_enablevoiceaituner__detailed_desc"></a>

## setAINSMode:mode:

设置是否启用 AI 降噪功能并设置降噪模式。

<a id="api_irtcengine_setainsmode__prototype"></a>

```objectivec
- (int)setAINSMode:(BOOL)enabled mode:(AUDIO_AINS_MODE)mode NS_SWIFT_NAME(setAINSMode(_:mode:));
```

<a id="api_irtcengine_setainsmode__detailed_desc"></a>

你可以调用此方法启用 AI 降噪功能。启用后，SDK 会在保证人声质量的前提下，自动检测并减少音频中的稳定噪声和非稳定噪声。 稳定噪声是指在观察时间内平均统计特性恒定、音量波动极小的噪声信号。常见的稳定噪声来源包括：

- 电视；
- 空调；
- 机械设备等。

非稳定噪声是指在观察时间内音量波动剧烈的噪声信号。常见的非稳定噪声来源包括：

- 雷声；
- 爆炸声；
- 破裂声等。

:::info[注]
该方法依赖 AI 降噪动态库 AgoraAiNoiseSuppressionExtension.xcframework。如果该动态库被删除，则无法启用该功能。
:::

<a id="api_irtcengine_setainsmode__scenario"></a>

### 适用场景

在连麦、在线教育和视频会议等场景中，该功能可检测并减少背景噪声，从而提升体验。

<a id="api_irtcengine_setainsmode__timing"></a>

### 调用时机

你可以在加入频道前或加入频道后调用此方法。

<a id="api_irtcengine_setainsmode__parameters"></a>

### 参数

#### `enabled`

是否启用 AI 降噪功能：

- YES：启用 AI 降噪功能。
- NO：（默认）关闭 AI 降噪功能。

#### `mode`

AI 降噪模式，详见 [AUDIO_AINS_MODE](/zh-CN/api-reference/rtc/ios/enum-audioainsmode)。

<a id="api_irtcengine_setainsmode__return_values"></a>

### 返回值

0：方法调用成功。 &lt; 0：方法调用失败。

## setAudioEffectParameters:param1:param2:

设置 SDK 预设音效的参数。

<a id="api_irtcengine_setaudioeffectparameters__prototype"></a>

```objectivec
- (int)setAudioEffectParameters:(AgoraAudioEffectPreset)preset param1:(int)param1 param2:(int)param2 NS_SWIFT_NAME(setAudioEffectParameters(_:param1:param2:));
```

<a id="api_irtcengine_setaudioeffectparameters__detailed_desc"></a>

调用该方法可为发送音频流的本地用户设置以下参数：

- 3D 人声效果：设置 3D 人声效果的循环周期。
- 音高修正效果：设置音高修正效果的基本调式和主音。

不同的歌曲有不同的调式和主音。声网建议将该方法与界面元素绑定，以便你交互式地调整音高修正效果。 设置音效参数后，频道内所有用户都能听到效果。 为了获得更好的人声效果，建议你在调用该方法前调用以下 API：

- 调用 [setAudioScenario:](/zh-CN/api-reference/rtc/ios/audio/audio-basic#api_irtcengine_setaudioscenario) 将音频场景设置为高音质音频场景，即 `AgoraAudioScenarioGameStreaming` （3）。
- 调用 [setAudioProfile:](/zh-CN/api-reference/rtc/ios/audio/audio-basic#api_irtcengine_setaudioprofile2) 将 `profile` 参数设置为 `AgoraAudioProfileMusicHighQuality` （4）或 `AgoraAudioProfileMusicHighQualityStereo` （5）。

:::info[注]
- 你可以在加入频道前或加入频道后调用该方法。
- 不要将 [setAudioProfile:](/zh-CN/api-reference/rtc/ios/audio/audio-basic#api_irtcengine_setaudioprofile2) 中的 `profile` 参数设置为 `AgoraAudioProfileSpeechStandard` （1），否则该方法不生效。
- 该方法在人声处理方面效果最佳，声网不建议使用该方法处理包含音乐的音频数据。
- 调用 [setAudioEffectParameters:param1:param2:](/zh-CN/api-reference/rtc/ios/audio/audio-prenpost/audio-effect#api_irtcengine_setaudioeffectparameters) 后，不建议再调用以下方法，否则会覆盖该方法设置的效果：

  - [setAudioEffectPreset:](/zh-CN/api-reference/rtc/ios/audio/audio-prenpost/audio-effect#api_irtcengine_setaudioeffectpreset)
  - [setVoiceBeautifierPreset:](/zh-CN/api-reference/rtc/ios/audio/audio-prenpost/audio-effect#api_irtcengine_setvoicebeautifierpreset)
  - [setLocalVoicePitch:](/zh-CN/api-reference/rtc/ios/audio/audio-prenpost/audio-effect#api_irtcengine_setlocalvoicepitch)
  - [setLocalVoiceEqualizationOfBandFrequency:withGain:](/zh-CN/api-reference/rtc/ios/audio/audio-prenpost/audio-effect#api_irtcengine_setlocalvoiceequalization)
  - [setLocalVoiceReverbOfType:withValue:](/zh-CN/api-reference/rtc/ios/audio/audio-prenpost/audio-effect#api_irtcengine_setlocalvoicereverb)
  - [setVoiceBeautifierParameters:param1:param2:](/zh-CN/api-reference/rtc/ios/audio/audio-prenpost/audio-effect#api_irtcengine_setvoicebeautifierparameters)
  - [setVoiceConversionPreset:](/zh-CN/api-reference/rtc/ios/audio/audio-prenpost/audio-effect#api_irtcengine_setvoiceconversionpreset)
- 该方法依赖于语音美声动态库 AgoraAudioBeautyExtension.xcframework （iOS）或 `AgoraAudioBeautyExtension.framework` （macOS）。如果该动态库被删除，则无法正常启用该功能。
:::

<a id="api_irtcengine_setaudioeffectparameters__parameters"></a>

### 参数

#### `preset`

SDK 预设音效的选项，详见 [AgoraAudioEffectPreset](/zh-CN/api-reference/rtc/ios/enum-audioeffectpreset)：

- `AgoraAudioEffectPresetRoomAcous3DVoice` （10）：3D 人声效果。

  - 在设置该枚举值前，你需要将 [setAudioProfile:](/zh-CN/api-reference/rtc/ios/audio/audio-basic#api_irtcengine_setaudioprofile2) 中的 `profile` 参数设置为 `AgoraAudioProfileMusicStandardStereo` （3）或 `AgoraAudioProfileMusicHighQualityStereo` （5），否则设置不生效。
  - 启用 3D 人声效果后，用户需使用立体声播放设备才能听到预期效果。
- `AgoraAudioEffectPresetPitchCorrection` （11）：音高修正效果。

#### `param1`

- 如果将 `preset` 设置为 `AgoraAudioEffectPresetRoomAcous3DVoice`，该参数表示 3D 人声效果的循环周期，单位为秒，取值范围为 [1, 60]。默认值为 10，表示声音每 10 秒环绕一次。
- 如果将 `preset` 设置为 `AgoraAudioEffectPresetPitchCorrection`，该参数表示音高修正效果的基本调式：

  - `1`：（默认）自然大调。
  - `2`：自然小调。
  - `3`：日本五声音阶。

#### `param2`

- 如果将 `preset` 设置为 `AgoraAudioEffectPresetRoomAcous3DVoice`，你需要将该参数设置为 `0`。
- 如果将 `preset` 设置为 `AgoraAudioEffectPresetPitchCorrection`，该参数表示音高修正效果的主音：

  - `1`：A
  - `2`：A#
  - `3`：B
  - `4`：（默认）C
  - `5`：C#
  - `6`：D
  - `7`：D#
  - `8`：E
  - `9`：F
  - `10`：F#
  - `11`：G
  - `12`：G#

<a id="api_irtcengine_setaudioeffectparameters__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/ios/error-code)了解详情和解决建议。

## setLocalVoiceFormant:

设置共振峰比例以改变人声音色。

<a id="api_irtcengine_setlocalvoiceformant__prototype"></a>

```objectivec
- (int)setLocalVoiceFormant:(double)formantRatio;
```

<a id="api_irtcengine_setlocalvoiceformant__detailed_desc"></a>

共振峰比例会影响声音的音色。值越小，声音越低沉；值越大，声音越尖锐。设置共振峰比例后，频道内所有用户都能听到改变后的声音。如果你希望同时改变音色和音调，声网建议同时使用 [setLocalVoiceFormant:](/zh-CN/api-reference/rtc/ios/audio/audio-prenpost/audio-effect#api_irtcengine_setlocalvoiceformant) 和 [setLocalVoicePitch:](/zh-CN/api-reference/rtc/ios/audio/audio-prenpost/audio-effect#api_irtcengine_setlocalvoicepitch) 方法。

<a id="api_irtcengine_setlocalvoiceformant__scenario"></a>

### 适用场景

你可以调用该方法设置本地音频的共振峰比例，以改变人声音色。

<a id="api_irtcengine_setlocalvoiceformant__timing"></a>

### 调用时机

该方法可以在加入频道前或加入频道后调用。

<a id="api_irtcengine_setlocalvoiceformant__parameters"></a>

### 参数

#### `formantRatio`

共振峰比例。取值范围为 [-1.0, 1.0]。默认值为 0.0，表示不改变声音的音色。

:::info[注]
声网建议将该值设置在 [-0.4, 0.6] 范围内，否则声音可能会严重失真。
:::

<a id="api_irtcengine_setlocalvoiceformant__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/ios/error-code)了解详情和解决建议。

## setVoiceBeautifierParameters:param1:param2:

设置预设美声特效的参数。

<a id="api_irtcengine_setvoicebeautifierparameters__prototype"></a>

```objectivec
- (int)setVoiceBeautifierParameters:(AgoraVoiceBeautifierPreset)preset param1:(int)param1 param2:(int)param2 NS_SWIFT_NAME(setVoiceBeautifierParameters(_:param1:param2:));
```

<a id="api_irtcengine_setvoicebeautifierparameters__detailed_desc"></a>

调用该方法为美声特效设置性别特征和混响效果。该方法为发送音频流的本地用户设置参数。设置完成后，频道内所有用户都能听到该效果。为了获得更好的人声效果，建议在调用本方法前调用以下 API：

- 调用 [setAudioScenario:](/zh-CN/api-reference/rtc/ios/audio/audio-basic#api_irtcengine_setaudioscenario) 将音频场景设置为高音质音频场景，即 `AgoraAudioScenarioGameStreaming` （3）。
- 调用 [setAudioProfile:](/zh-CN/api-reference/rtc/ios/audio/audio-basic#api_irtcengine_setaudioprofile2) 将 `profile` 参数设置为 `AgoraAudioProfileMusicHighQuality` （4）或 `AgoraAudioProfileMusicHighQualityStereo` （5）。

:::info[注]
- 你可以在加入频道前或加入频道后调用该方法。
- 请勿将 [setAudioProfile:](/zh-CN/api-reference/rtc/ios/audio/audio-basic#api_irtcengine_setaudioprofile2) 中的 `profile` 参数设置为 `AgoraAudioProfileSpeechStandard` （1），否则该方法不生效。
- 该方法对人声处理效果最佳，不建议用于处理包含音乐的音频数据。
- 调用 [setVoiceBeautifierParameters:param1:param2:](/zh-CN/api-reference/rtc/ios/audio/audio-prenpost/audio-effect#api_irtcengine_setvoicebeautifierparameters) 后，不建议再调用以下方法，否则会覆盖该方法设置的效果：

  - [setAudioEffectPreset:](/zh-CN/api-reference/rtc/ios/audio/audio-prenpost/audio-effect#api_irtcengine_setaudioeffectpreset)
  - [setAudioEffectParameters:param1:param2:](/zh-CN/api-reference/rtc/ios/audio/audio-prenpost/audio-effect#api_irtcengine_setaudioeffectparameters)
  - [setVoiceBeautifierPreset:](/zh-CN/api-reference/rtc/ios/audio/audio-prenpost/audio-effect#api_irtcengine_setvoicebeautifierpreset)
  - [setLocalVoicePitch:](/zh-CN/api-reference/rtc/ios/audio/audio-prenpost/audio-effect#api_irtcengine_setlocalvoicepitch)
  - [setLocalVoiceEqualizationOfBandFrequency:withGain:](/zh-CN/api-reference/rtc/ios/audio/audio-prenpost/audio-effect#api_irtcengine_setlocalvoiceequalization)
  - [setLocalVoiceReverbOfType:withValue:](/zh-CN/api-reference/rtc/ios/audio/audio-prenpost/audio-effect#api_irtcengine_setlocalvoicereverb)
  - [setVoiceConversionPreset:](/zh-CN/api-reference/rtc/ios/audio/audio-prenpost/audio-effect#api_irtcengine_setvoiceconversionpreset)
- 该方法依赖于美声特效动态库 AgoraAudioBeautyExtension.xcframework （iOS）或 `AgoraAudioBeautyExtension.framework` （macOS）。如果该动态库被删除，功能将无法正常启用。
:::

<a id="api_irtcengine_setvoicebeautifierparameters__parameters"></a>

### 参数

#### `preset`

预设音效选项。详见 [AgoraVoiceBeautifierPreset](/zh-CN/api-reference/rtc/ios/enum-voicebeautifierpreset)。

- `SINGING_BEAUTIFIER`：美声特效。

#### `param1`

歌声的性别特征选项：

- `1`：男性音色。
- `2`：女性音色。

#### `param2`

歌声的混响效果选项：

- `1`：小房间混响效果。
- `2`：大房间混响效果。
- `3`：大厅混响效果。

<a id="api_irtcengine_setvoicebeautifierparameters__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/ios/error-code)了解详情和解决建议。
