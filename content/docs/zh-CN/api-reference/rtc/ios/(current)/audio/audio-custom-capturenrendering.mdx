## adjustCustomAudioPlayoutVolume:volume:

调节本地播放的自定义音频轨道的音量。

<a id="api_irtcengine_adjustcustomaudioplayoutvolume__prototype"></a>

```objectivec
- (int)adjustCustomAudioPlayoutVolume:(NSInteger)trackId volume:(NSInteger)volume NS_SWIFT_NAME(adjustCustomAudioPlayoutVolume(_:volume:));
```

<a id="api_irtcengine_adjustcustomaudioplayoutvolume__detailed_desc"></a>

如果你想更改本地播放的音频音量，需要再次调用该方法。

:::info[注]
请确保在调用该方法前已调用 [createCustomAudioTrack:config:](/zh-CN/api-reference/rtc/ios/audio/audio-custom-capturenrendering#api_irtcengine_createcustomaudiotrack) 创建自定义音频轨道。

#### `volume`

音频源的音量。取值范围为 0 到 100。

- 0：静音。
- 100：原始音量。

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](/zh-CN/realtime-media/rtc/reference/error-code)了解详情和解决建议。

## createCustomAudioTrack:config:

创建一个自定义音频轨道。

<a id="api_irtcengine_createcustomaudiotrack__prototype"></a>

```objectivec
- (int)createCustomAudioTrack:(AgoraAudioTrackType)trackType
                       config:(AgoraAudioTrackConfig* _Nonnull)config;
```

<a id="api_irtcengine_createcustomaudiotrack__detailed_desc"></a>

要发布自定义音频源，请按照以下步骤操作：

1. 调用该方法创建一个自定义音频轨道并获取音频轨道 ID。
2. 调用 joinChannelByToken 加入频道。在 AgoraRtcChannelMediaOptions 中，将 publishCustomAudioTrackId 设置为你想要发布的音频轨道 ID，并将 publishCustomAudioTrack 设置为 YES。
3. 调用 pushExternalAudioFrameRawData，并将 trackId 设置为第 2 步中设置的音频轨道 ID，即可在频道中发布相应的自定义音频源。

:::info[注]
请在加入频道前调用此方法。
:::

<a id="api_irtcengine_createcustomaudiotrack__parameters"></a>

### 参数

#### `trackType`

自定义音频轨道的类型，详见 [AgoraAudioTrackType](/zh-CN/api-reference/rtc/ios/enum-audiotracktype)。

- 如果该参数设置为 AgoraAudioTrackTypeDirect，你必须在调用 joinChannelByToken 加入频道时，将 AgoraRtcChannelMediaOptions 中的 publishMicrophoneTrack 设置为 NO，否则加入频道会失败并返回错误码 -2。

#### `config`

自定义音频轨道的配置，详见 [AgoraAudioTrackConfig](/zh-CN/api-reference/rtc/ios/class-audiotrackconfig)。

<a id="api_irtcengine_createcustomaudiotrack__return_values"></a>

### 返回值

- 方法调用成功，返回音频轨道 ID，作为该音频轨道的唯一标识符。
- 方法调用失败，返回 0xffffffff。

### 所属接口类
- [AgoraRtcEngineKit](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_irtcengine)

## pullPlaybackAudioFrameRawData:lengthInByte:

拉取远端音频数据。

<a id="api_irtcengine_pullaudioframe__prototype"></a>

```objectivec
- (BOOL)pullPlaybackAudioFrameRawData:(void * _Nonnull)data
                              lengthInByte:(NSUInteger)lengthInByte NS_SWIFT_NAME(pullPlaybackAudioFrameRawData(_:lengthInByte:));
```

<a id="api_irtcengine_pullaudioframe__detailed_desc"></a>

调用该方法成功后，你可以拉取解码并混音后的远端音频数据用于播放。调用该方法前，请先调用 [enableExternalAudioSink:sampleRate:channels:](/zh-CN/api-reference/rtc/ios/audio/audio-custom-capturenrendering#api_irtcengine_setexternalaudiosink) （`enabled: YES` ）以开启并设置外部音频渲染。

:::info[注]
[pullPlaybackAudioFrameRawData:lengthInByte:](/zh-CN/api-reference/rtc/ios/audio/audio-custom-capturenrendering#api_irtcengine_pullaudioframe) 方法和 `onPlaybackAudioFrame:` 回调都可用于获取远端混音后的音频数据。调用 [enableExternalAudioSink:sampleRate:channels:](/zh-CN/api-reference/rtc/ios/audio/audio-custom-capturenrendering#api_irtcengine_setexternalaudiosink) 开启外部音频渲染后，将无法再通过 `onPlaybackAudioFrame:` 回调获取数据。请根据实际业务需求选择使用该方法或 `onPlaybackAudioFrame:` 回调。两者的具体区别如下：

- 调用 pullPlaybackAudioFrameRawData:lengthInByte: 方法后，你会自动从 SDK 拉取音频数据。通过设置音频数据参数，SDK 会调整帧缓冲区以帮助你处理延迟，有效避免音频播放卡顿。
- 注册 onPlaybackAudioFrame: 回调后，SDK 会通过回调将音频数据发送给你。若处理音频帧存在延迟，可能会导致音频卡顿。

该方法仅用于获取远端混音后的音频数据。如需获取采集、播放等其他音频处理阶段的数据，可通过调用 [setAudioFrameDelegate:](/zh-CN/api-reference/rtc/ios/audio/audio-raw#api_irtcengine_registeraudioframeobserver) 注册相应的回调。
:::

<a id="api_irtcengine_pullaudioframe__timing"></a>

### 调用时机

在加入频道后调用该方法。

<a id="api_irtcengine_pullaudioframe__parameters"></a>

### 参数

#### `data`

输出参数，要拉取的远端音频数据。数据类型为 `byte []`。

#### `lengthInByte`

数据长度（字节）。该参数的值与音频时长，以及在 [enableExternalAudioSink:sampleRate:channels:](/zh-CN/api-reference/rtc/ios/audio/audio-custom-capturenrendering#api_irtcengine_setexternalaudiosink) 中设置的 `sampleRate` 和 `channels` 参数有关。 `lengthInByte` = `sampleRate` / 1000 × 2 × `channels` × 音频时长（毫秒）。

<a id="api_irtcengine_pullaudioframe__return_values"></a>

### 返回值

- YES：调用成功。
- NO：调用失败。

### 所属接口类
- [AgoraRtcEngineKit](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_irtcengine)

## pushExternalAudioFrameRawData:samples:sampleRate:channels:trackId:timestamp:

将外部音频帧推送到 SDK。

<a id="api_irtcengine_pushaudioframe2__prototype"></a>

```objectivec
- (int)pushExternalAudioFrameRawData:(void* _Nonnull)data
                             samples:(NSInteger)samples
                          sampleRate:(NSInteger)sampleRate
                            channels:(NSInteger)channels
                            trackId:(NSInteger)trackId
                           timestamp:(NSTimeInterval)timestamp NS_SWIFT_NAME(pushExternalAudioFrameRawData(_:samples:sampleRate:channels:trackId:timestamp:));
```

<a id="api_irtcengine_pushaudioframe2__detailed_desc"></a>

你可以调用该方法通过音频轨道向 SDK 推送外部音频帧。 调用该方法前，请先完成以下操作：

1. 调用 createCustomAudioTrack 创建自定义音频轨道，并获取音频轨道 ID。
2. 调用 joinChannelByToken 加入频道。在 AgoraRtcChannelMediaOptions 中，将 publishCustomAudioTrackId 设置为要发布的音频轨道 ID，并将 publishCustomAudioTrack 设置为 YES。

<a id="api_irtcengine_pushaudioframe2__parameters"></a>

### 参数

#### `data`

外部音频数据。

#### `samples`

采样点数量。

#### `sampleRate`

外部音频源的采样率（Hz），可设置为 8000、16000、32000、44100 或 48000。

#### `channels`

外部音频源的声道数，可设置为 1（单声道）或 2（立体声）。

#### `trackId`

音频轨道 ID，需设置为调用 `createCustomAudioTrack` 返回的自定义音频轨道 ID。

#### `timestamp`

外部音频帧的时间戳（毫秒）。该参数为必填项，可用于还原采集音频帧的顺序，或在涉及视频的场景中（包括使用自定义视频源的场景）实现音视频同步。

<a id="api_irtcengine_pushaudioframe2__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](/zh-CN/realtime-media/rtc/reference/error-code)了解详情和解决建议。

### 所属接口类
- [AgoraRtcEngineKit](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_irtcengine)

<a id="api_irtcengine_setexternalaudiosource2__parameters"></a>

### 参数

#### `enabled`

是否启用外部音频源：

- YES：启用外部音频源。
- NO：（默认）不启用外部音频源。

#### `sampleRate`

外部音频源的采样率（Hz），可设置为 8000、16000、32000、44100 或 48000。

#### `channels`

外部音频源的声道数，可设置为 1（单声道）或 2（立体声）。

#### `localPlayback`

是否播放外部音频源：

- YES：播放外部音频源。
- NO：（默认）不播放外部音频源。

#### `publish`

是否向远端用户发布音频：

- YES：（默认）发布音频到远端用户。
- NO：不发布音频到远端用户。

<a id="api_irtcengine_setexternalaudiosource2__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](/zh-CN/realtime-media/rtc/reference/error-code)了解详情和解决建议。
