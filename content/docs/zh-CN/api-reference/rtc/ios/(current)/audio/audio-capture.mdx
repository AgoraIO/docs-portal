<a id="api_irtcengine_adjustrecordingsignalvolume"></a>

## adjustRecordingSignalVolume:

调节采集音量。

<a id="api_irtcengine_adjustrecordingsignalvolume__prototype"></a>

```objectivec
- (int)adjustRecordingSignalVolume:(NSInteger)volume NS_SWIFT_NAME(adjustRecordingSignalVolume(_:));
```

<a id="api_irtcengine_adjustrecordingsignalvolume__detailed_desc"></a>

如果你只需要静音音频信号，声网建议使用 [muteRecordingSignal:](/zh-CN/api-reference/rtc/ios/audio/audio-capture#api_irtcengine_muterecordingsignal) 方法。

<a id="api_irtcengine_adjustrecordingsignalvolume__timing"></a>

### 调用时机

该方法可以在加入频道前或后调用。

<a id="api_irtcengine_adjustrecordingsignalvolume__parameters"></a>

### 参数

#### `volume`

用户的音量。取值范围为 [0,400]。

- 0：静音。
- 100：（默认）原始音量。
- 400：原始音量的四倍（将音频信号放大四倍）。

<a id="api_irtcengine_adjustrecordingsignalvolume__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/ios/error-code)了解详情和解决建议。

### 所属接口类
- [AgoraRtcEngineKit](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_irtcengine)

## enableInEarMonitoring:

启用或关闭耳返监听功能。

<a id="api_irtcengine_enableinearmonitoring__prototype"></a>

```objectivec
- (int)enableInEarMonitoring:(BOOL)enabled NS_SWIFT_NAME(enable(inEarMonitoring:));
```

<a id="api_irtcengine_enableinearmonitoring__detailed_desc"></a>

你可以调用该方法启用或关闭耳返监听功能。

:::info[注]
[enableInEarMonitoring:](/zh-CN/api-reference/rtc/ios/audio/audio-capture#api_irtcengine_enableinearmonitoring) 仅在使用有线或蓝牙耳机时有效。
:::

<a id="api_irtcengine_enableinearmonitoring__timing"></a>

### 调用时机

该方法可以在加入频道前或加入频道后调用。

<a id="api_irtcengine_enableinearmonitoring__parameters"></a>

### 参数

#### `enabled`

是否启用耳返监听功能：

- YES：启用耳返监听功能。
- NO：（默认）关闭耳返监听功能。

<a id="api_irtcengine_enableinearmonitoring__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/ios/error-code)了解详情和解决建议。

  - -8：请确保当前音频路由为蓝牙或耳机。

### 所属接口类
- [AgoraRtcEngineKit](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_irtcengine)

## enableLocalAudio:

启用或关闭本地音频采集功能。

<a id="api_irtcengine_enablelocalaudio__prototype"></a>

```objectivec
- (int)enableLocalAudio:(BOOL)enabled NS_SWIFT_NAME(enableLocalAudio(_:));
```

<a id="api_irtcengine_enablelocalaudio__detailed_desc"></a>

[enableLocalAudio:](/zh-CN/api-reference/rtc/ios/audio/audio-capture#api_irtcengine_enablelocalaudio) 方法用于启用或关闭本地音频采集功能。默认情况下，加入频道时会启用音频功能。调用该方法可以停止或重新启动本地音频采集。 该方法与 [muteLocalAudioStream:](/zh-CN/api-reference/rtc/ios/publishnsubscribe#api_irtcengine_mutelocalaudiostream) 的区别如下：

- [enableLocalAudio:](/zh-CN/api-reference/rtc/ios/audio/audio-capture#api_irtcengine_enablelocalaudio)：关闭或重新启用本地音频采集和处理。如果使用该方法关闭或重新启用本地音频采集，可能会导致远端音频播放出现短暂中断。
- [muteLocalAudioStream:](/zh-CN/api-reference/rtc/ios/publishnsubscribe#api_irtcengine_mutelocalaudiostream)：仅停止或恢复发送本地音频流，不影响音频采集状态。

该方法不会影响接收远端音频流。将 `enabled` 设为 NO 适用于只接收远端音频而不发送本地音频的场景。 你可以在加入频道前或加入频道后调用该方法。在加入频道前调用时，仅设置设备状态，加入频道后立即生效。

<a id="api_irtcengine_enablelocalaudio__scenario"></a>

### 适用场景

`enableLocalAudio(false)` 适用于只接收远端音频流而不发送本地采集音频的场景。该方法不会影响接收远端音频流。

<a id="api_irtcengine_enablelocalaudio__timing"></a>

### 调用时机

你可以在加入频道前或加入频道后调用该方法。在加入频道前调用时，仅设置设备状态，加入频道后立即生效。

<a id="api_irtcengine_enablelocalaudio__related"></a>

### 相关回调

成功调用该方法后，SDK 会触发 [rtcEngine:localAudioStateChanged:reason:](/zh-CN/api-reference/rtc/ios/audio/audio-basic#callback_irtcengineeventhandler_onlocalaudiostatechanged) 回调，报告 `AgoraAudioLocalStateStopped` （0）或 `AgoraAudioLocalStateRecording` （1）。

<a id="api_irtcengine_enablelocalaudio__parameters"></a>

### 参数

#### `enabled`

- YES：（默认）重新启用本地音频功能，即启动本地音频采集设备（例如麦克风）。
- NO：关闭本地音频功能，即停止本地音频采集。

<a id="api_irtcengine_enablelocalaudio__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/ios/error-code)了解详情和解决建议。

### 所属接口类
- [AgoraRtcEngineKit](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_irtcengine)

## muteRecordingSignal:

设置是否静音录制信号。

<a id="api_irtcengine_muterecordingsignal__prototype"></a>

```objectivec
- (int)muteRecordingSignal:(BOOL)muted NS_SWIFT_NAME(muteRecordingSignal(_:));
```

<a id="api_irtcengine_muterecordingsignal__detailed_desc"></a>

如果你已经调用了 [adjustRecordingSignalVolume:](/zh-CN/api-reference/rtc/ios/audio/audio-capture#api_irtcengine_adjustrecordingsignalvolume) 方法调整了录制信号的音量，当你调用该方法并将参数设置为 YES 时，SDK 的行为如下：

- 记录调整后的音量。
- 静音录制信号。

当你再次调用该方法并将参数设置为 NO 时，录制信号音量将恢复为静音前 SDK 记录的音量。

<a id="api_irtcengine_muterecordingsignal__timing"></a>

### 调用时机

该方法可以在加入频道前或后调用。

<a id="api_irtcengine_muterecordingsignal__parameters"></a>

### 参数

#### `muted`

- YES：静音录制信号。
- NO：（默认）不静音录制信号。

<a id="api_irtcengine_muterecordingsignal__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/ios/error-code)了解详情和解决建议。

### 所属接口类
- [AgoraRtcEngineKit](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_irtcengine)

## setInEarMonitoringVolume:

设置耳返音量。

<a id="api_irtcengine_setinearmonitoringvolume__prototype"></a>

```objectivec
- (int)setInEarMonitoringVolume:(NSInteger)volume NS_SWIFT_NAME(setInEarMonitoringVolume(_:));
```

<a id="api_irtcengine_setinearmonitoringvolume__detailed_desc"></a>

<a id="api_irtcengine_setinearmonitoringvolume__timing"></a>

### 调用时机

该方法可以在加入频道前或加入频道后调用。

<a id="api_irtcengine_setinearmonitoringvolume__parameters"></a>

### 参数

#### `volume`

用户的音量。取值范围为 [0,400]。

- 0：静音。
- 100：（默认）原始音量。
- 400：原始音量的四倍（将音频信号放大四倍）。

<a id="api_irtcengine_setinearmonitoringvolume__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/ios/error-code)了解详情和解决建议。

  - -2：参数设置不合法，例如耳返音量超出有效范围（小于 0 或大于 400）。
