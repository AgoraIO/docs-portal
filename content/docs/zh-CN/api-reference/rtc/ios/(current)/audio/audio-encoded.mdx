## setAudioEncodedFrameDelegate:config:

注册编码音频数据的观察者。

<a id="api_irtcengine_registeraudioencodedframeobserver__prototype"></a>

```objectivec
- (int)setAudioEncodedFrameDelegate:(id<AgoraAudioEncodedFrameDelegate> _Nullable)delegate config:(AgoraAudioEncodedFrameDelegateConfig * _Nonnull)config NS_SWIFT_NAME(setAudioEncodedFrameDelegate(_:config:));
```

<a id="api_irtcengine_registeraudioencodedframeobserver__detailed_desc"></a>

:::info[注]
该方法需在加入频道后调用。你可以调用该方法或 [startAudioRecordingWithConfig:](/zh-CN/api-reference/rtc/ios/recording#api_irtcengine_startaudiorecording3) 来设置音频文件的录制类型和质量，但声网不建议同时使用这两个方法。只有后调用的方法会生效。
:::

<a id="api_irtcengine_registeraudioencodedframeobserver__parameters"></a>

### 参数

#### `delegate`

编码音频数据的观察者。详见 [AgoraAudioEncodedFrameDelegate](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_iaudioencodedframeobserver)。

#### `config`

编码音频数据的观察者配置。详见 [AgoraAudioEncodedFrameDelegateConfig](/zh-CN/api-reference/rtc/ios/class-audioencodedframeobserverconfig)。

<a id="api_irtcengine_registeraudioencodedframeobserver__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/ios/error-code)了解详情和解决建议。

- [AgoraRtcEngineKit](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_irtcengine)

<a id="callback_iaudioencodedframeobserver_onmixedaudioencodedframe"></a>

## onMixedEncodedAudioFrame:info:

获取本地和所有远端用户的混音编码音频数据回调。

<a id="callback_iaudioencodedframeobserver_onmixedaudioencodedframe__prototype"></a>

```objectivec
- (void)onMixedEncodedAudioFrame:(NSData* _Nonnull)frameData info:(AgoraEncodedAudioFrameInfo* _Nonnull)info NS_SWIFT_NAME(onMixedEncodedAudioFrame(_:info:));
```

<a id="callback_iaudioencodedframeobserver_onmixedaudioencodedframe__detailed_desc"></a>

调用 [setAudioEncodedFrameDelegate:config:](/zh-CN/api-reference/rtc/ios/audio/audio-encoded#api_irtcengine_registeraudioencodedframeobserver) 并将音频配置设置为 `AgoraAudioEncodedFrameObserverPositionMixed` 后，可以通过该回调获取本地和所有远端用户的混音编码音频数据。

<a id="callback_iaudioencodedframeobserver_onmixedaudioencodedframe__timing"></a>

### 触发时机

该回调在调用 [setAudioEncodedFrameDelegate:config:](/zh-CN/api-reference/rtc/ios/audio/audio-encoded#api_irtcengine_registeraudioencodedframeobserver) 并将音频配置设置为 `AgoraAudioEncodedFrameObserverPositionMixed` 后触发。

<a id="callback_iaudioencodedframeobserver_onmixedaudioencodedframe__parameters"></a>

### 参数

#### `frameData`

音频缓冲区。

#### `info`

编码后的音频信息，详见 [AgoraEncodedAudioFrameInfo](/zh-CN/api-reference/rtc/ios/class-encodedaudioframeinfo)。

- [AgoraAudioEncodedFrameDelegate](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_iaudioencodedframeobserver)

<a id="callback_iaudioencodedframeobserver_onplaybackaudioencodedframe"></a>

## onPlaybackEncodedAudioFrame:info:

获取所有远端用户的编码音频数据回调。

<a id="callback_iaudioencodedframeobserver_onplaybackaudioencodedframe__prototype"></a>

```objectivec
- (void)onPlaybackEncodedAudioFrame:(NSData* _Nonnull)frameData info:(AgoraEncodedAudioFrameInfo* _Nonnull)info NS_SWIFT_NAME(onPlaybackEncodedAudioFrame(_:info:));
```

<a id="callback_iaudioencodedframeobserver_onplaybackaudioencodedframe__detailed_desc"></a>

调用 [setAudioEncodedFrameDelegate:config:](/zh-CN/api-reference/rtc/ios/audio/audio-encoded#api_irtcengine_registeraudioencodedframeobserver) 并将编码音频设置为 `AgoraAudioEncodedFrameObserverPositionPlayback` 后，该回调会返回所有远端用户的编码音频数据。

<a id="callback_iaudioencodedframeobserver_onplaybackaudioencodedframe__timing"></a>

### 触发时机

该回调在获取到所有远端用户的编码音频数据时被触发。

<a id="callback_iaudioencodedframeobserver_onplaybackaudioencodedframe__parameters"></a>

### 参数

#### `frameData`

音频缓冲区。

#### `info`

编码后的音频信息，详见 [AgoraEncodedAudioFrameInfo](/zh-CN/api-reference/rtc/ios/class-encodedaudioframeinfo)。

- [AgoraAudioEncodedFrameDelegate](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_iaudioencodedframeobserver)

<a id="callback_iaudioencodedframeobserver_onrecordaudioencodedframe"></a>

## onRecordEncodedAudioFrame:info:

获取本地用户的编码音频数据回调。

<a id="callback_iaudioencodedframeobserver_onrecordaudioencodedframe__prototype"></a>

```objectivec
- (void)onRecordEncodedAudioFrame:(NSData* _Nonnull)frameData info:(AgoraEncodedAudioFrameInfo* _Nonnull)info NS_SWIFT_NAME(onRecordEncodedAudioFrame(_:info:));
```

<a id="callback_iaudioencodedframeobserver_onrecordaudioencodedframe__detailed_desc"></a>

调用 [setAudioEncodedFrameDelegate:config:](/zh-CN/api-reference/rtc/ios/audio/audio-encoded#api_irtcengine_registeraudioencodedframeobserver) 并将编码音频设置为 `AgoraAudioEncodedFrameObserverPositionRecord` 后，该回调返回本地用户的编码音频数据。

<a id="callback_iaudioencodedframeobserver_onrecordaudioencodedframe__timing"></a>

### 触发时机

该回调在获取到本地用户的编码音频数据时被触发。

<a id="callback_iaudioencodedframeobserver_onrecordaudioencodedframe__parameters"></a>

### 参数

#### `frameData`

音频缓冲区。

#### `info`

编码后的音频信息，详见 [AgoraEncodedAudioFrameInfo](/zh-CN/api-reference/rtc/ios/class-encodedaudioframeinfo)。

- [AgoraAudioEncodedFrameDelegate](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_iaudioencodedframeobserver)
