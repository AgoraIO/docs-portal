description: "alphaBuffer 与视频帧的相对位置。"

## 枚举值 [#enum_alphastitchmode__parameters]

### `AgoraNoAlphaStitch`

（0）：（默认）仅显示视频帧，即 `alphaBuffer` 不与视频帧拼接。

### `AgoraAlphaStitchUp`

（1）： `alphaBuffer` 位于视频帧上方。

### `AgoraAlphaStitchBelow`

（2）： `alphaBuffer` 位于视频帧下方。

### `AgoraAlphaStitchLeft`

（3）： `alphaBuffer` 位于视频帧左侧。

### `AgoraAlphaStitchRight`

（4）： `alphaBuffer` 位于视频帧右侧。
