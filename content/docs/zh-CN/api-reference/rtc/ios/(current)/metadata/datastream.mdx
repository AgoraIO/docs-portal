## createDataStream\:reliable\:ordered:

创建数据流。

<a id="api_irtcengine_createdatastream1__prototype"></a>

```text
- (int)createDataStream:(NSInteger * _Nonnull)streamId
               reliable:(BOOL)reliable
                ordered:(BOOL)ordered NS_SWIFT_NAME(createDataStream(_:reliable:ordered:));
```

<a id="api_irtcengine_createdatastream1__detailed_desc"></a>

你可以调用该方法创建一个数据流，以提升数据传输的可靠性和顺序性。你可以在加入频道前或后调用该方法。

:::note
注： 每个用户在 [AgoraRtcEngineKit](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_irtcengine) 的生命周期内最多可创建五个数据流。离开频道时数据流会被销毁，如需继续使用需重新创建。如果你需要更全面的低延时、高并发、可扩展的实时消息和状态同步方案，建议使用实时消息。
:::

<a id="api_irtcengine_createdatastream1__timing"></a>

### 调用时机

你可以在加入频道前或后调用该方法。

<a id="api_irtcengine_createdatastream1__parameters"></a>

### 参数

<ParameterList>
<a id="streamid"></a>
<Parameter name="streamId">

输出参数，创建的数据流 ID。

</Parameter>
<a id="reliable"></a>
<Parameter name="reliable">

设置接收端是否保证在五秒内收到数据流：

- YES：接收端会在五秒内收到发送方发送的数据。如果接收端在五秒内未收到数据，SDK 会触发 [rtcEngine\:didOccurStreamMessageErrorFromUid\:streamId\:error\:missed\:cached:](/zh-CN/api-reference/rtc/ios/metadata/datastream#callback_irtcengineeventhandler_onstreammessageerror) 回调并返回错误码。
- NO：不保证接收端在五秒内收到数据流，延迟或丢失数据不会返回错误信息。

请确保 `reliable` 和 `ordered` 同时设置为 YES 或同时设置为 NO。

</Parameter>
<a id="ordered"></a>
<Parameter name="ordered">

设置接收端是否按发送顺序接收数据流：

- YES：接收端按发送顺序接收数据。
- NO：接收端不按发送顺序接收数据。

</Parameter>
</ParameterList>

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。

## sendStreamMessage\:data:

发送数据流消息。

<a id="api_irtcengine_sendstreammessage__prototype"></a>

```text
- (int)sendStreamMessage:(NSInteger)streamId
                    data:(NSData * _Nonnull)data NS_SWIFT_NAME(sendStreamMessage(_:data:));
```

<a id="api_irtcengine_sendstreammessage__detailed_desc"></a>

调用 [createDataStream\:config:](/zh-CN/api-reference/rtc/ios/metadata/datastream#api_irtcengine_createdatastream2) 后，你可以使用此方法向频道内的所有用户发送数据流消息。SDK 对此方法有以下限制：

- 每个客户端在频道中最多可同时拥有 5 个数据通道，所有数据通道共享的总包比特率上限为 30 KB/s。
- 每个数据通道每秒最多可发送 60 个数据包，每个数据包最大为 1 KB。

:::note
注： 如果你需要一个更全面的解决方案来实现低延迟、高并发和可扩展的实时消息传递和状态同步，建议使用实时消息。

- 必须在调用 [createDataStream\:config:](/zh-CN/api-reference/rtc/ios/metadata/datastream#api_irtcengine_createdatastream2) 并加入频道后调用此方法。
- 此方法仅适用于主播。
:::

<a id="api_irtcengine_sendstreammessage__parameters"></a>

### 参数

<ParameterList>
<a id="streamid-4"></a>
<Parameter name="streamId">

数据流 ID。你可以通过调用 [createDataStream\:config:](/zh-CN/api-reference/rtc/ios/metadata/datastream#api_irtcengine_createdatastream2) 获取该 ID。

</Parameter>
