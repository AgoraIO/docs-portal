## 枚举值 [#enum_capturebrightnessleveltype__parameters]

### `AgoraCaptureBrightnessLevelInvalid`

（-1）：未检测到视频图像的亮度等级。请等待几秒钟，在下一次回调中通过 `captureBrightnessLevel` 获取亮度等级。

### `AgoraCaptureBrightnessLevelNormal`

（0）：视频图像亮度等级正常。

### `AgoraCaptureBrightnessLevelBright`

（1）：视频图像亮度等级过亮。

### `AgoraCaptureBrightnessLevelDark`

（2）：视频图像亮度等级过暗。
