<a id="class_advanceoptions__prototype"></a>

```objectivec
__attribute__((visibility("default"))) @interface AgoraAdvancedVideoOptions : NSObject
@property(assign, nonatomic) AgoraEncodingPreference encodingPreference;
@property(assign, nonatomic) AgoraCompressionPreference compressionPreference;
@property(assign, nonatomic) BOOL encodeAlpha;
@end
```

<a id="class_advanceoptions__parameters"></a>

## 属性

### `encodingPreference`

视频编码器偏好设置，详见 [AgoraEncodingPreference](/zh-CN/api-reference/rtc/ios/enum-encodingpreference)。

### `compressionPreference`

视频编码的压缩偏好设置，详见 [AgoraCompressionPreference](/zh-CN/api-reference/rtc/ios/enum-compressionpreference)。

### `encodeAlpha`

是否对视频帧中存在的 Alpha 数据进行编码并发送到远端：

- YES：编码并发送 Alpha 数据。
- NO：（默认）不编码也不发送 Alpha 数据。
