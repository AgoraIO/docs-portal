<a id="class_pathstats__prototype"></a>

```objectivec
__attribute__((visibility("default"))) @interface AgoraPathStats : NSObject
@property (assign, nonatomic) AgoraMultipathType pathType;
@property (assign, nonatomic) NSUInteger txKBitRate;
@property (assign, nonatomic) NSUInteger rxKBitRate;
@end
```

<a id="class_pathstats__detailed_desc"></a>

### `自从`

自 v4.6.0 版本新增。

<a id="class_pathstats__parameters"></a>

## 属性

### `pathType`

网络路径的类型，详见 [AgoraMultipathType](/zh-CN/api-reference/rtc/ios/enum-multipathtype)。

### `txKBitRate`

该路径的传输码率，单位为 Kbps。

### `rxKBitRate`

该路径的接收码率，单位为 Kbps。
