## 枚举值

### AgoraRtmpStreamLifeCycleBindToChannel

（1）：绑定到频道生命周期。如果所有主播离开频道，CDN 推流将在 30 秒后停止。

### AgoraRtmpStreamLifeCycleBindToOwner

（2）：绑定到 RTMP 流的拥有者。如果拥有者离开频道，CDN 推流将立即停止。
