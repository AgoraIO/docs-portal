title: "AgoraScreenAudioParameters"
description: "AgoraScreenAudioParameters 用于配置共享屏幕流的音频参数。"
---

<a id="class_screenaudioparameters__prototype"></a>

```objectivec
__attribute__((visibility("default"))) @interface AgoraScreenAudioParameters : NSObject
@property(assign, nonatomic) NSInteger captureSignalVolume;
@end
```

<a id="class_screenaudioparameters__detailed_desc"></a>

仅当 `captureAudio` 为 YES 时生效。

## 属性 [#class_screenaudioparameters__parameters]

### `captureSignalVolume`

采集的系统音频音量。取值范围为 [0, 100]，默认值为 100。
