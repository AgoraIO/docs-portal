---

<a id="enum_audiofilerecordingtype__detailed_desc"></a>

在 [startAudioRecordingWithConfig:](/zh-CN/api-reference/rtc/ios/recording#api_irtcengine_startaudiorecording3) 中设置。

## 枚举值 [#enum_audiofilerecordingtype__parameters]

### `AgoraAudioFileRecordingTypeMic`

（1）：仅录制本地用户音频。

### `AgoraAudioFileRecordingTypePlayback`

（2）：仅录制所有远端用户音频。

### `AgoraAudioFileRecordingTypeMixed`

（3）：录制本地用户与所有远端用户的混合音频。
