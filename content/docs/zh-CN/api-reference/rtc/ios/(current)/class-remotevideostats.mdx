## 属性

<ParameterList>
<a id="uid"></a>
<Parameter name="uid">

发送该视频流的远端用户 ID。

</Parameter>
<a id="delay"></a>
<Parameter name="delay">

视频延迟（毫秒）。

:::note
注： 在音视频同步的场景中，你可以从 `networkTransportDelay` 和 `jitterBufferDelay` 获取视频延迟数据。
:::

</Parameter>
<a id="e2edelay"></a>
<Parameter name="e2eDelay">

端到端的视频延迟（毫秒）。即从远端用户采集视频到本地用户接收并渲染视频的时间。

</Parameter>
<a id="width"></a>
<Parameter name="width">

视频的宽度（像素）。

</Parameter>
<a id="height"></a>
<Parameter name="height">

视频的高度（像素）。

</Parameter>
<a id="receivedbitrate"></a>
<Parameter name="receivedBitrate">

自上次统计以来接收到的远端视频码率（Kbps）。

</Parameter>
<a id="rxstreamtype"></a>
<Parameter name="rxStreamType">

视频流的类型。详见 [AgoraVideoStreamType](/zh-CN/api-reference/rtc/ios/enum-videostreamtype)。

</Parameter>
<a id="decoderoutputframerate"></a>
<Parameter name="decoderOutputFrameRate">

远端视频解码的帧率（fps）。

</Parameter>
<a id="rendereroutputframerate"></a>
<Parameter name="rendererOutputFrameRate">

远端视频渲染的帧率（fps）。

</Parameter>
<a id="framelossrate"></a>
<Parameter name="frameLossRate">

远端视频的丢帧率（%）。

</Parameter>
<a id="packetlossrate"></a>
<Parameter name="packetLossRate">

使用抗丢包技术后远端视频的丢包率（%）。

</Parameter>
<a id="totalfrozentime"></a>
<Parameter name="totalFrozenTime">

远端用户加入频道后远端视频流的总卡顿时长（毫秒）。在帧率不低于 5 fps 的视频通话中，若相邻两帧可渲染视频帧的时间间隔超过 500 毫秒，则视为视频卡顿。

</Parameter>
<a id="totalactivetime"></a>
<Parameter name="totalActiveTime">

视频的总可用时长（毫秒）。只要远端用户在加入频道后未停止发送视频流或未关闭视频模块，视频即为可用状态。

</Parameter>
<a id="publishduration"></a>
<Parameter name="publishDuration">

远端视频流的总时长（毫秒）。

</Parameter>
<a id="frozenrate"></a>
<Parameter name="frozenRate">

视频卡顿时长占视频总可用时长的百分比（%）。只要远端用户在加入频道后未停止发送视频流或未关闭视频模块，视频即为可用状态。

</Parameter>
<a id="avsynctimems"></a>
<Parameter name="avSyncTimeMs">

音频领先视频的时间（毫秒）。

:::note
注： 如果该值为负数，表示音频落后于视频。
:::

</Parameter>
<a id="mosvalue"></a>
<Parameter name="mosValue">

在统计周期内远端视频流的质量。该值由声网实时视频 MOS（Mean Opinion Score）算法评估，取值范围为 [0, 500]。将该值除以 100 可得 MOS 评分，范围为 0 到 5，分数越高表示视频质量越好。

:::note
注： 对于纹理视频数据，该参数始终返回 0。
:::

</Parameter>
<a id="rxvideobytes"></a>
<Parameter name="rxVideoBytes">

接收到的视频字节总数（字节），为累计值。

</Parameter>
</ParameterList>
