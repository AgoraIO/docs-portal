## 枚举值

### AgoraRtePlayerStateIdle

（0）：空闲状态。

### AgoraRtePlayerStateOpening

（1）：正在打开 URL 资源。调用 [openWithUrl:startTime:cb:](/zh-CN/api-reference/rtc/ios/play/rte-player#api_player_openwithurl) 后触发该状态。

### AgoraRtePlayerStateOpenCompleted

（2）：成功打开 URL 资源。调用 [openWithUrl:startTime:cb:](/zh-CN/api-reference/rtc/ios/play/rte-player#api_player_openwithurl) 成功后触发该状态。

### AgoraRtePlayerStatePlaying

（3）：正在播放状态。

### AgoraRtePlayerStatePaused

（4）：播放已暂停。成功调用 [pause:](/zh-CN/api-reference/rtc/ios/play/rte-player#api_player_pause_player) 后触发该状态。

### AgoraRtePlayerStatePlaybackCompleted

（5）：播放已完成。

### AgoraRtePlayerStateStopped

（6）：播放已停止。成功调用 [pause:](/zh-CN/api-reference/rtc/ios/play/rte-player#api_player_pause_player) 后触发该状态。

### AgoraRtePlayerStateFailed

（7）：播放失败。发生内部错误时触发该状态。收到该状态后需先调用 [pause:](/zh-CN/api-reference/rtc/ios/play/rte-player#api_player_pause_player)，再调用 [openWithUrl:startTime:cb:](/zh-CN/api-reference/rtc/ios/play/rte-player#api_player_openwithurl) 重新打开资源。
