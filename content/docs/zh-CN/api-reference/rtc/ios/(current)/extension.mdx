## <span id="toc_extension"></span>enableExtensionWithVendor:extension:enabled:sourceType: [#api_irtcengine_enableextension]

启用或禁用扩展功能。

<a id="api_irtcengine_enableextension__prototype"></a>

```objectivec
- (int)enableExtensionWithVendor:(NSString * _Nonnull)provider
                       extension:(NSString * _Nonnull)extension
                         enabled:(BOOL)enabled
                      sourceType:(AgoraMediaSourceType)sourceType NS_SWIFT_NAME(enableExtension(withVendor:extension:enabled:sourceType:));
```

<a id="api_irtcengine_enableextension__detailed_desc"></a>

:::info[注]
- 如果你想启用多个扩展，需要多次调用该方法。
- 成功调用该方法后，不能再加载其他扩展。
:::

### 调用时机 [#api_irtcengine_enableextension__timing]

该方法建议在你加入频道后调用。

### 参数 [#api_irtcengine_enableextension__parameters]

#### `provider`

扩展提供方的名称。

#### `extension`

扩展的名称。

#### `enabled`

是否启用该扩展：

- YES：启用扩展。
- NO：禁用扩展。

#### `sourceType`

扩展的来源类型，详见 [AgoraMediaSourceType](/zh-CN/api-reference/rtc/ios/enum-mediasourcetype)。

### 返回值 [#api_irtcengine_enableextension__return_values]

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/ios/error-code)了解详情和解决建议。

  - -3：扩展库未加载。声网建议你检查动态库的存储位置或名称。

- [AgoraRtcEngineKit](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_irtcengine)

## registerExtensionWithVendor:extension:sourceType: [#api_irtcengine_registerextension]

注册一个扩展。

<a id="api_irtcengine_registerextension__prototype"></a>

```objectivec
- (int)registerExtensionWithVendor:(NSString * _Nonnull)provider
                         extension:(NSString * _Nonnull)extension
                        sourceType:(AgoraMediaSourceType)sourceType NS_SWIFT_NAME(registerExtension(withVendor:extension:sourceType:));
```

<a id="api_irtcengine_registerextension__detailed_desc"></a>

对于 SDK 外部的扩展（例如来自 Extensions Marketplace 和 SDK Extensions 的扩展），你需要在调用此方法前加载它们。对于 SDK 内部的扩展（即包含在完整 SDK 包中的扩展），在初始化 [AgoraRtcEngineKit](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_irtcengine) 后会自动加载并注册。

:::info[注]
- 如果你想注册多个扩展，需要多次调用此方法。
- SDK 中不同扩展的数据处理顺序由注册顺序决定。即先注册的扩展会先处理数据。
:::

### 调用时机 [#api_irtcengine_registerextension__timing]

声网建议你在初始化 [AgoraRtcEngineKit](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_irtcengine) 后、加入频道前调用此方法。

- 对于视频扩展（如美颜特效扩展），你需要在调用 [enableVideo](/zh-CN/api-reference/rtc/ios/video/video-basic#api_irtcengine_enablevideo) 或 [enableLocalVideo:](/zh-CN/api-reference/rtc/ios/video/video-basic#api_irtcengine_enablelocalvideo) 启用视频模块后调用此方法。
- 在调用此方法之前，你需要将扩展动态库（.xcframework）链接到 Xcode 项目中以加载扩展。

### 参数 [#api_irtcengine_registerextension__parameters]

#### `provider`

扩展提供方的名称。

#### `extension`

扩展的名称。

#### `sourceType`

扩展的数据源类型，详见 [AgoraMediaSourceType](/zh-CN/api-reference/rtc/ios/enum-mediasourcetype)。

### 返回值 [#api_irtcengine_registerextension__return_values]

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/ios/error-code)了解详情和解决建议。

  - -3：扩展库未加载。声网建议你检查动态库的存储位置或名称。

- [AgoraRtcEngineKit](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_irtcengine)

## onExtensionErrorWithContext:error:message: [#callback_irtcengineeventhandler_onextensionerrorwithcontext]

当扩展运行异常时触发的回调。

<a id="callback_irtcengineeventhandler_onextensionerrorwithcontext__prototype"></a>

```objectivec
- (void)onExtensionErrorWithContext:(AgoraExtensionContext * _Nonnull)context
                   error:(int)error
                 message:(NSString * _Nullable)message NS_SWIFT_NAME(onExtensionErrorWithContext(_:error:message:));
```

<a id="callback_irtcengineeventhandler_onextensionerrorwithcontext__detailed_desc"></a>

当扩展启用失败或运行时发生错误时，会触发该回调，并报告错误码及原因。

### 触发时机 [#callback_irtcengineeventhandler_onextensionerrorwithcontext__timing]

该回调在扩展启用失败或运行时发生错误时被触发。

### 参数 [#callback_irtcengineeventhandler_onextensionerrorwithcontext__parameters]

#### `context`

扩展的上下文信息。详见 [AgoraExtensionContext](/zh-CN/api-reference/rtc/ios/class-extensioncontext)。

#### `error`

错误码。详情请参见扩展提供方提供的扩展文档。

#### `message`

错误原因。详情请参见扩展提供方提供的扩展文档。

- [AgoraRtcEngineDelegate](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_irtcengineeventhandler)
