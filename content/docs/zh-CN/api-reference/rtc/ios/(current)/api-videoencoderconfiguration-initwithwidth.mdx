<a id="api_videoencoderconfiguration_initwithwidth__prototype"></a>

```objectivec
- (instancetype _Nonnull)initWithWidth:(NSInteger)width
                                height:(NSInteger)height
                             frameRate:(NSInteger)frameRate
                               bitrate:(NSInteger)bitrate
                       orientationMode:(AgoraVideoOutputOrientationMode)orientationMode
                            mirrorMode:(AgoraVideoMirrorMode)mirrorMode NS_SWIFT_NAME(init(width:height:frameRate:bitrate:orientationMode:mirrorMode:));
```

## <span id="api_videoencoderconfiguration_initwithwidth__detailed_desc"></span>参数 [#api_videoencoderconfiguration_initwithwidth__parameters]

### `width`

视频的宽度。

### `height`

视频的高度。

### `frameRate`

视频帧率，详见 [AgoraVideoFrameRate](/zh-CN/api-reference/rtc/ios/enum-framerate)。

### `bitrate`

编码视频的码率。

### `orientationMode`

编码视频的方向模式，详见 [AgoraVideoOutputOrientationMode](/zh-CN/api-reference/rtc/ios/enum-orientationmode)。

### `mirrorMode`

设置本地视频流的镜像模式，仅影响远端用户看到的视频，详见 [AgoraVideoMirrorMode](/zh-CN/api-reference/rtc/ios/enum-videomirrormodetype)。

## 返回值 [#api_videoencoderconfiguration_initwithwidth__return_values]

方法调用成功，返回 [AgoraVideoEncoderConfiguration](/zh-CN/api-reference/rtc/ios/class-videoencoderconfiguration) 对象。

- [AgoraVideoEncoderConfiguration](/zh-CN/api-reference/rtc/ios/class-videoencoderconfiguration)
