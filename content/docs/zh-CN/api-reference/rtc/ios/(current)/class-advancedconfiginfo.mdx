## 属性 [#class_advancedconfiginfo__parameters]

### `logUploadServer`

自定义日志上传服务器。默认情况下，SDK 会将日志上传到声网日志服务器。你可以使用该属性更改日志上传服务器，详见 [LogUploadServerInfo](/zh-CN/api-reference/rtc/ios/class-loguploadserverinfo)。
