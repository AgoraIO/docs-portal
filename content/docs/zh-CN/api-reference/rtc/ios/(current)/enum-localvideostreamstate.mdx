## 枚举值 [#enum_localvideostreamstate__parameters]

### `AgoraVideoLocalStateStopped`

（0）：本地视频处于初始状态。

### `AgoraVideoLocalStateCapturing`

（1）：本地视频采集设备已成功启动。

### `AgoraVideoLocalStateEncoding`

（2）：首帧视频已成功编码。

### `AgoraVideoLocalStateFailed`

（3）：本地视频启动失败。
