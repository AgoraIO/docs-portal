## setAudioMixingDualMonoMode:

设置当前音频文件的声道模式。

<a id="api_irtcengine_setaudiomixingdualmonomode__prototype"></a>

```text
- (int)setAudioMixingDualMonoMode:(AgoraAudioMixingDualMonoMode)mode NS_SWIFT_NAME(setAudioMixingDualMonoMode(_:));
```

<a id="api_irtcengine_setaudiomixingdualmonomode__detailed_desc"></a>

在立体声音乐文件中，左声道和右声道可以存储不同的音频数据。你可以根据需要将声道模式设置为原始模式、左声道模式、右声道模式或混合声道模式。例如，在 KTV 场景中，音乐文件的左声道存储伴奏，右声道存储原唱人声：

- 如果你只想听伴奏，可以将声道模式设置为左声道模式。
- 如果你想同时听到伴奏和原唱人声，可以将声道模式设置为混合模式。

:::note
注： 该方法仅适用于立体声音频文件。

<a id="api_irtcengine_setaudiomixingdualmonomode__scenario"></a>

### 适用场景

在 KTV 场景中，音乐文件的左声道存储伴奏，右声道存储原唱人声。你可以根据实际需求进行设置：

- 如果你只想听到伴奏，调用该方法将声道模式设置为左声道模式。
- 如果你需要同时听到伴奏和原唱人声，调用该方法将声道模式设置为混合模式。

## startAudioMixing:loopback:cycle:

开始播放音乐文件。

<a id="api_irtcengine_startaudiomixing__prototype"></a>

```text
- (int)startAudioMixing:(NSString *  _Nonnull)filePath
               loopback:(BOOL)loopback
                  cycle:(NSInteger)cycle NS_SWIFT_NAME(startAudioMixing(_:loopback:cycle:));
```

<a id="api_irtcengine_startaudiomixing__detailed_desc"></a>

关于该方法支持的音频文件格式，详见[声网 RTC SDK 支持哪些音频文件格式](/zh-CN/api-reference/faq/product/audio_format)。如果本地音乐文件不存在、SDK 不支持该文件格式，或 SDK 无法访问音乐文件的 URL，SDK 会返回 `AgoraAudioMixingReasonCanNotOpen`。

:::note
注：

- 如果你调用该方法播放短音效文件，可能会导致播放失败。声网建议使用 [playEffect:filePath:loopCount:pitch:pan:gain:publish:startPos:](/zh-CN/api-reference/rtc/ios/play/audio-effect-file#api_irtcengine_playeffect3) 方法播放此类文件。
- 如果你需要多次调用该方法，请确保两次调用之间的时间间隔大于 500 毫秒。
:::

<a id="api_irtcengine_startaudiomixing__timing"></a>

### 调用时机

你可以在加入频道前或加入频道后调用该方法。

<a id="api_irtcengine_startaudiomixing__parameters"></a>

### 参数

### filePath

文件路径：

- iOS 或 macOS：音频文件的绝对路径或 URL 地址（包括文件名后缀）。例如：/var/mobile/Containers/Data/audio.mp4。

### loopback

是否只在本地客户端播放音乐文件：

- YES：只在本地客户端播放音乐文件，只有本地用户可以听到音乐。
- NO：将音乐文件发布到远端客户端，本地用户和远端用户都可以听到音乐。

### cycle

音乐文件的播放次数：

- &gt; 0：播放的次数。例如，1 表示播放 1 次。
- -1：无限循环播放该音频文件。

<a id="api_irtcengine_startaudiomixing__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。

  - -1：发生通用错误（无明确原因）。
  - -2：参数无效。
  - -3：SDK 尚未就绪。

    - 音频模块未启用。
    - 程序未完成。
    - [AgoraRtcEngineKit](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_irtcengine) 初始化失败。请重新初始化 [AgoraRtcEngineKit](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_irtcengine)。
