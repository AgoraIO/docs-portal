## <span id="toc_mediaplayer_initialize"></span>createMediaPlayerWithDelegate: [#api_irtcengine_createmediaplayer]

创建一个媒体播放器实例。

<a id="api_irtcengine_createmediaplayer__prototype"></a>

```objectivec
- (id<AgoraRtcMediaPlayerProtocol>_Nullable)createMediaPlayerWithDelegate:(id<AgoraRtcMediaPlayerDelegate>_Nullable)delegate NS_SWIFT_NAME(createMediaPlayer(with:));
```

<a id="api_irtcengine_createmediaplayer__detailed_desc"></a>

在调用 [AgoraRtcMediaPlayerProtocol](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_imediaplayer) 中的任何 API 之前，你需要调用该方法创建一个媒体播放器实例。如果你需要创建多个实例，可以多次调用该方法。

### 调用时机 [#api_irtcengine_createmediaplayer__timing]

你可以在加入频道前或加入频道后调用此方法。

### 参数 [#api_irtcengine_createmediaplayer__parameters]

#### `delegate`

事件回调处理器，详见 [AgoraRtcMediaPlayerDelegate](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_imediaplayersourceobserver)。

### 返回值 [#api_irtcengine_createmediaplayer__return_values]

- 方法调用成功，返回 [AgoraRtcMediaPlayerProtocol](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_imediaplayer) 实例。
- 方法调用失败，返回 nil。

- [AgoraRtcEngineKit](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_irtcengine)

## destroyMediaPlayer: [#api_irtcengine_destroymediaplayer]

销毁媒体播放器实例。

<a id="api_irtcengine_destroymediaplayer__prototype"></a>

```objectivec
- (int)destroyMediaPlayer:(id<AgoraRtcMediaPlayerProtocol>_Nullable)mediaPlayer NS_SWIFT_NAME(destroyMediaPlayer(_:));
```

### <span id="api_irtcengine_destroymediaplayer__detailed_desc"></span>参数 [#api_irtcengine_destroymediaplayer__parameters]

#### `mediaPlayer`

要销毁的媒体播放器实例，类型为 [AgoraRtcMediaPlayerProtocol](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_imediaplayer)。详见 [AgoraRtcMediaPlayerProtocol](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_imediaplayer)。

### 返回值 [#api_irtcengine_destroymediaplayer__return_values]

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/ios/error-code)了解详情和解决建议。

- [AgoraRtcEngineKit](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_irtcengine)

## createMediaPlayerCacheManager [#api_imediaplayercachemanager_getmediaplayercachemanager]

创建一个 AgoraRtcMediaPlayerCacheManagerProtocol 实例。

<a id="api_imediaplayercachemanager_getmediaplayercachemanager__prototype"></a>

```objectivec
- (id<AgoraRtcMediaPlayerCacheManagerProtocol> _Nullable)createMediaPlayerCacheManager NS_SWIFT_NAME(createMediaPlayerCacheManager());
```

<a id="api_imediaplayercachemanager_getmediaplayercachemanager__detailed_desc"></a>

在调用 [AgoraRtcMediaPlayerCacheManagerProtocol](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_imediaplayercachemanager) 中的任何 API 之前，你需要调用此方法以获取媒体播放器的缓存管理器实例。

:::info[注]
[createMediaPlayerCacheManager](/zh-CN/api-reference/rtc/ios/play/mediaplayer/mediaplayer-initialize#api_imediaplayercachemanager_getmediaplayercachemanager) 返回的缓存管理器为单例模式。因此，多次调用此方法会返回相同的实例。
:::

### 调用时机 [#api_imediaplayercachemanager_getmediaplayercachemanager__timing]

确保在调用此方法之前已初始化 [AgoraRtcEngineKit](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_irtcengine)。

### 返回值 [#api_imediaplayercachemanager_getmediaplayercachemanager__return_values]

方法调用成功，返回 [AgoraRtcMediaPlayerCacheManagerProtocol](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_imediaplayercachemanager) 对象。

- [AgoraRtcMediaPlayerCacheManagerProtocol](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_imediaplayercachemanager)

## setVideoFrameDelegate: [#api_imediaplayer_setvideoframedelegate]

注册媒体播放器的视频帧观察者对象。

<a id="api_imediaplayer_setvideoframedelegate__prototype"></a>

```objectivec
- (BOOL)setVideoFrameDelegate:(id<AgoraRtcMediaPlayerVideoFrameDelegate> _Nullable)delegate NS_SWIFT_NAME(setVideoFrameDelegate(_:));
```

<a id="api_imediaplayer_setvideoframedelegate__detailed_desc"></a>

调用该方法注册视频帧观察者后，你可以根据需要在 [AgoraRtcMediaPlayerVideoFrameDelegate](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_agorartcmediaplayervideoframedelegate) 中注册回调。成功注册视频帧观察者后，每当接收到视频帧时，SDK 会触发已注册的回调。

### 参数 [#api_imediaplayer_setvideoframedelegate__parameters]

#### `delegate`

代理实例。设置为 nil 可释放该实例。详见 [AgoraRtcMediaPlayerVideoFrameDelegate](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_agorartcmediaplayervideoframedelegate)。

### 返回值 [#api_imediaplayer_setvideoframedelegate__return_values]

- YES：注册成功。
- NO：注册失败。

- [AgoraRtcMediaPlayerProtocol](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_imediaplayer)
