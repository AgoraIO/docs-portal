## <span id="toc_drm"></span>createMusicPlayerWithDelegate: [#api_imusiccontentcenter_createmusicplayer]

<a id="api_imusiccontentcenter_createmusicplayer__prototype"></a>


<a id="api_imusiccontentcenter_createmusicplayer__detailed_desc"></a>

## destroyMusicPlayer: [#api_imusiccontentcenter_destroymusicplayer]

销毁音乐播放器对象。

<a id="api_imusiccontentcenter_destroymusicplayer__prototype"></a>

```objectivec
- (NSInteger)destroyMusicPlayer:(id<AgoraMusicPlayerProtocol>)musicPlayer;
```

<a id="api_imusiccontentcenter_destroymusicplayer__detailed_desc"></a>

当你不再需要使用音乐播放器时，可以调用此方法销毁音乐播放器对象。如果在销毁后需要再次使用音乐播放器，必须调用 [createMusicPlayerWithDelegate:](/zh-CN/api-reference/rtc/ios/play/drm#api_imusiccontentcenter_createmusicplayer) 方法重新创建一个新的音乐播放器对象。

### 参数 [#api_imusiccontentcenter_destroymusicplayer__parameters]

#### `musicPlayer`

音乐播放器对象。详见 [AgoraMusicPlayerProtocol](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_imusicplayer)。

### 返回值 [#api_imusiccontentcenter_destroymusicplayer__return_values]

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/ios/error-code)了解详情和解决建议。

- [AgoraMusicContentCenter](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_imusiccontentcenter)

## getInternalSongCode:jsonOption: [#api_imusiccontentcenter_getinternalsongcode]

创建音乐资源副歌片段的内部 ID。

<a id="api_imusiccontentcenter_getinternalsongcode__prototype"></a>

```objectivec
- (NSInteger)getInternalSongCode:(NSInteger)songCode jsonOption:(NSString * _Nullable)jsonOption  NS_SWIFT_NAME(getInternalSongCode(songCode:jsonOption:));
```

<a id="api_imusiccontentcenter_getinternalsongcode__detailed_desc"></a>

调用该方法可结合音乐资源的 `songCode` 和 `jsonOption` 参数，为该资源的副歌片段创建一个内部 ID。该 ID 是该资源的唯一标识。获取该 ID 后，你需要在调用打开、预加载或移除资源的方法时，将其作为 `songCode` 参数传入。

### 参数 [#api_imusiccontentcenter_getinternalsongcode__parameters]

#### `songCode`

音乐资源的唯一标识。你可以通过调用 [getMusicCollectionWithMusicChartId:page:pageSize:jsonOption:](/zh-CN/api-reference/rtc/ios/play/drm#api_imusiccontentcenter_getmusiccollectionbymusicchartid) 或 [searchMusicWithKeyWord:page:pageSize:jsonOption:](/zh-CN/api-reference/rtc/ios/play/drm#api_imusiccontentcenter_searchmusic) 方法，并从 [onMusicCollectionResult:result:reason:](/zh-CN/api-reference/rtc/ios/play/drm#callback_imusiccontentcentereventhandler_onmusiccollectionresult) 回调中获取 `songCode`。

#### `jsonOption`

:::info[注]
声网会根据你在 `sceneType` 中指定的频道场景计费。不同的频道场景对应不同的计费标准，详见计费文档。若需切换频道场景，必须重新调用该方法并传入新的 `sceneType` 值。
:::

扩展 JSON 字段，默认为 nil。当前支持以下字段：

- `sceneType`：频道场景。

  - 1：直播场景：在线 K 歌房和背景音乐播放。
  - 2：直播场景：背景音乐播放。
  - 3：（默认）语聊场景：在线 K 歌房。
  - 4：语聊场景：背景音乐播放。
  - 5：VR 场景：在线 K 歌房和背景音乐播放。示例： `{"sceneType":1}`

- `highPart`：副歌片段的索引。你可以从 [onMusicCollectionResult:result:reason:](/zh-CN/api-reference/rtc/ios/play/drm#callback_imusiccontentcentereventhandler_onmusiccollectionresult) 回调中获取该索引并传入。索引从 0 开始。示例： `{"format": {"highpart": 0}}`

### 返回值 [#api_imusiccontentcenter_getinternalsongcode__return_values]

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/ios/error-code)了解详情和解决建议。详见错误码文档获取详细信息和排查建议。

- [AgoraMusicContentCenter](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_imusiccontentcenter)

## getMusicCollectionWithMusicChartId:page:pageSize:jsonOption: [#api_imusiccontentcenter_getmusiccollectionbymusicchartid]

获取指定音乐榜单中的音乐资源列表。

<a id="api_imusiccontentcenter_getmusiccollectionbymusicchartid__prototype"></a>

```objectivec
- (NSString *)getMusicCollectionWithMusicChartId:(NSInteger)musicChartId page:(NSInteger)page pageSize:(NSInteger)pageSize jsonOption:(NSString * _Nullable)jsonOption NS_SWIFT_NAME(getMusicCollection(musicChartId:page:pageSize:jsonOption:));
```

### <span id="api_imusiccontentcenter_getmusiccollectionbymusicchartid__detailed_desc"></span>相关回调 [#api_imusiccontentcenter_getmusiccollectionbymusicchartid__related]

成功调用该方法后，SDK 会触发 `onMusicCollectionResult` 回调报告榜单中的音乐资源详细信息。

### 参数 [#api_imusiccontentcenter_getmusiccollectionbymusicchartid__parameters]

#### `musicChartId`

音乐榜单的 ID，可通过 `onMusicChartsResult` 回调获取。你也可以使用 RESTful API 获取完整的音乐库或增量音乐列表。

#### `page`

当前页码，默认从 1 开始。

#### `pageSize`

每页返回的音乐资源数量，最大值为 50。

#### `jsonOption`

- `pitchType`：是否支持评分。

  - `1`：支持评分的音乐资源。
  - `2`：不支持评分的音乐资源。
- `needHighPart`：是否需要副歌片段资源。

  - `true`：需要副歌片段资源。
  - `false`：不需要副歌片段资源。

## openMediaWithSongCode:startPos: [#api_imusicplayer_open_imusicplayer]

<a id="api_imusicplayer_open_imusicplayer__prototype"></a>

```objectivec
- (NSInteger)openMediaWithSongCode:(NSInteger)songCode startPos:(NSInteger)startPos NS_SWIFT_NAME(openMedia(songCode:startPos:));
```

<a id="api_imusicplayer_open_imusicplayer__detailed_desc"></a>

调用该方法前，请确保要播放的音乐资源已加载完成。你可以通过调用 [isPreloadedWithSongCode:](/zh-CN/api-reference/rtc/ios/play/drm#api_imusiccontentcenter_ispreloaded) 方法，或监听 `onPreLoadEvent` 回调来确认音乐资源是否已预加载。 调用该方法后，SDK 会触发 [AgoraRtcMediaPlayer:didChangedToState:reason:](/zh-CN/api-reference/rtc/ios/play/mediaplayer/mediaplayer-observer#callback_imediaplayersourceobserver_onplayersourcestatechanged) 回调。当你收到播放状态 `AgoraMediaPlayerStateOpenCompleted` 后，可以调用 [play](/zh-CN/api-reference/rtc/ios/play/mediaplayer/mediaplayer-control#api_imediaplayer_play) 方法开始播放。

:::info[注]
如果要打开的音乐资源受数字版权保护，必须使用该方法。对于未受数字版权保护的音乐资源，你可以选择使用该方法或 [open:startPos:](/zh-CN/api-reference/rtc/ios/play/mediaplayer/mediaplayer-open#api_imediaplayer_open) 方法打开。
:::

### 参数 [#api_imusicplayer_open_imusicplayer__parameters]

#### `songCode`

音乐资源的 ID，用于标识音乐内容。

#### `startPos`

- 0：方法调用成功。

- 4：频道场景：声动语聊中的背景音乐播放。
- 5：频道场景：VR 中的在线 K 歌和背景音乐播放。

## searchMusicWithKeyWord:page:pageSize:jsonOption: [#api_imusiccontentcenter_searchmusic]

搜索音乐资源。

<a id="api_imusiccontentcenter_searchmusic__prototype"></a>

```objectivec
- (NSString *)searchMusicWithKeyWord:(NSString *)keyWord page:(NSInteger)page pageSize:(NSInteger)pageSize jsonOption:(NSString * _Nullable)jsonOption NS_SWIFT_NAME(searchMusic(keyWord:page:pageSize:jsonOption:));
```

<a id="api_imusiccontentcenter_searchmusic__detailed_desc"></a>

调用该方法后，SDK 会触发 [onMusicCollectionResult:result:reason:](/zh-CN/api-reference/rtc/ios/play/drm#callback_imusiccontentcentereventhandler_onmusiccollectionresult) 回调，返回检索到的音乐资源列表。

### 参数 [#api_imusiccontentcenter_searchmusic__parameters]

#### `keyWord`

搜索关键词。支持按歌曲标题或歌手名搜索。

#### `page`

要获取的音乐资源列表的目标页码。

#### `pageSize`

每页显示的最大音乐资源数量，最大值为 50。

#### `jsonOption`

可选的扩展 JSON 字段，默认为 nil。你可以使用该字段筛选所需的音乐资源。目前支持以下筛选条件：

- `pitchType`：音乐资源是否支持评分。

  - `2`：不可评分的音乐资源。

示例： `{"pitchType":1}`。

- `needHighPart`：是否需要合唱片段资源。

  - YES：需要合唱片段资源。
  - NO：不需要合唱片段资源。

示例： `{"needHighPart":true}`。

- 方法调用成功时，返回请求 ID，用于标识此次请求的唯一标识符。
