## <span id="toc_mediaplayer_observer"></span>AgoraRtcMediaPlayerGetVideoPixelFormat [#api_agorartcmediaplayervideoframedelegate_agorartcmediaplayergetvideopixelformat]

设置原始视频数据的格式。

<a id="api_agorartcmediaplayervideoframedelegate_agorartcmediaplayergetvideopixelformat__prototype"></a>

```objectivec
- (AgoraVideoFormat)AgoraRtcMediaPlayerGetVideoPixelFormat NS_SWIFT_NAME(AgoraRtcMediaPlayerGetVideoPixelFormat());
```

<a id="api_agorartcmediaplayervideoframedelegate_agorartcmediaplayergetvideopixelformat__detailed_desc"></a>

你需要在调用 [setVideoFrameDelegate:](/zh-CN/api-reference/rtc/ios/video/video-raw#api_irtcengine_registervideoframeobserver) 方法时注册回调。当媒体播放器接收到每一帧视频时，会触发该回调。你可以在该回调的返回值中设置期望的视频数据格式。

### 返回值 [#api_agorartcmediaplayervideoframedelegate_agorartcmediaplayergetvideopixelformat__return_values]

你为原始视频数据设置的期望格式，详见 [AgoraVideoFormat](/zh-CN/api-reference/rtc/ios/enum-videopixelformat)。默认情况下，原始视频像素格式（`AgoraVideoFormatDefault` ）可能是 `I420` 或 `CVPixelBufferRef`。

- [AgoraRtcMediaPlayerVideoFrameDelegate](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_agorartcmediaplayervideoframedelegate)

## AgoraRtcMediaPlayer:didReceivePixelBuffer: [#api_agorartcmediaplayervideoframedelegate_didreceivepixelbuffer]

媒体播放器接收到视频源的像素缓冲区时触发的回调。

<a id="api_agorartcmediaplayervideoframedelegate_didreceivepixelbuffer__prototype"></a>

```objectivec
- (void)AgoraRtcMediaPlayer:(id<AgoraRtcMediaPlayerProtocol> _Nonnull)playerKit
       didReceivePixelBuffer:(CVPixelBufferRef _Nonnull)pixelBuffer NS_SWIFT_NAME(AgoraRtcMediaPlayer(_:didReceivePixelBuffer:));
```

<a id="api_agorartcmediaplayervideoframedelegate_didreceivepixelbuffer__detailed_desc"></a>

触发该回调以报告类型为 `CVPixelBufferRef` 的像素缓冲区的详细信息。你可以使用这些信息进行图像处理与分析、自定义渲染等。

### 调用时机 [#api_agorartcmediaplayervideoframedelegate_didreceivepixelbuffer__timing]

该回调在媒体播放器接收到视频源的像素缓冲区时被触发。

### 参数 [#api_agorartcmediaplayervideoframedelegate_didreceivepixelbuffer__parameters]

#### `playerKit`

媒体播放器对象，详见 [AgoraRtcMediaPlayerProtocol](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_imediaplayer)。

#### `pixelBuffer`

包含像素缓冲区详细信息的 `CVPixelBufferRef` 对象。

- [AgoraRtcMediaPlayerVideoFrameDelegate](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_agorartcmediaplayervideoframedelegate)

## AgoraRtcMediaPlayer:didPlayBufferUpdated: [#callback_imediaplayersourceobserver_onplaybufferupdated]

报告缓冲数据可支持的播放时长。

<a id="callback_imediaplayersourceobserver_onplaybufferupdated__prototype"></a>

```objectivec
- (void)AgoraRtcMediaPlayer:(id<AgoraRtcMediaPlayerProtocol> _Nonnull)playerKit
             didPlayBufferUpdated:(NSInteger)playCachedBuffer NS_SWIFT_NAME(AgoraRtcMediaPlayer(_:didPlayBufferUpdated:));
```

<a id="callback_imediaplayersourceobserver_onplaybufferupdated__detailed_desc"></a>

- 当缓冲数据可支持的播放时长小于阈值（默认值为 0）时，SDK 返回 `AgoraMediaPlayerEventBufferLow` （6）。
- 当缓冲数据可支持的播放时长大于阈值（默认值为 0）时，SDK 返回 `AgoraMediaPlayerEventBufferRecover` （7）。

### 触发时机 [#callback_imediaplayersourceobserver_onplaybufferupdated__timing]

播放在线媒体资源时，SDK 每两秒触发一次该回调。

### 参数 [#callback_imediaplayersourceobserver_onplaybufferupdated__parameters]

#### `playerKit`

播放器实例。详见 [AgoraRtcMediaPlayerProtocol](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_imediaplayer)。

#### `playCachedBuffer`

缓冲数据可支持的播放时长（毫秒）。

- [AgoraRtcMediaPlayerDelegate](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_imediaplayersourceobserver)
