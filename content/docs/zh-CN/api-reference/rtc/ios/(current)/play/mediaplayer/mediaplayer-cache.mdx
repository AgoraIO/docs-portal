## <span id="toc_mediaplayer_cache"></span>enableAutoRemoveCache: [#api_imediaplayercachemanager_enableautoremovecache]

设置是否自动删除缓存的媒体文件。

<a id="api_imediaplayercachemanager_enableautoremovecache__prototype"></a>

```objectivec
- (int)enableAutoRemoveCache:(BOOL)enable NS_SWIFT_NAME(enableAutoRemoveCache(_:));
```

<a id="api_imediaplayercachemanager_enableautoremovecache__detailed_desc"></a>

当缓存的媒体文件超过设置的数量或大小限制时，如果启用该功能，SDK 会自动删除最近最少使用的缓存文件。

### 参数 [#api_imediaplayercachemanager_enableautoremovecache__parameters]

#### `enable`

是否启用 SDK 自动删除缓存的媒体文件：

- YES：自动删除缓存的媒体文件。
- NO：（默认）不自动删除缓存的媒体文件。

### 返回值 [#api_imediaplayercachemanager_enableautoremovecache__return_values]

- 0：方法调用成功。
- &lt; 0：方法调用失败，详见 [AgoraMediaPlayerReason](/zh-CN/api-reference/rtc/ios/enum-mediaplayerreason)。

- [AgoraRtcMediaPlayerCacheManagerProtocol](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_imediaplayercachemanager)

## cacheDir [#api_imediaplayercachemanager_getcachedir]

获取缓存媒体文件的存储路径。

<a id="api_imediaplayercachemanager_getcachedir__prototype"></a>

```objectivec
- (NSString *)cacheDir NS_SWIFT_NAME(cacheDir());
```

<a id="api_imediaplayercachemanager_getcachedir__detailed_desc"></a>

如果在调用该方法前未调用 [setCacheDir:](/zh-CN/api-reference/rtc/ios/play/mediaplayer/mediaplayer-cache#api_imediaplayercachemanager_setcachedir) 方法设置缓存媒体文件的存储路径，则该方法返回 SDK 默认使用的存储路径。

### 返回值 [#api_imediaplayercachemanager_getcachedir__return_values]

- 方法调用成功时，返回缓存媒体文件的存储路径。
- 方法调用失败，返回 nil，详见 [AgoraMediaPlayerReason](/zh-CN/api-reference/rtc/ios/enum-mediaplayerreason)。

- [AgoraRtcMediaPlayerCacheManagerProtocol](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_imediaplayercachemanager)

## maxCacheFileCount [#api_imediaplayercachemanager_getmaxcachefilecount]

获取可缓存的媒体文件的最大数量。

<a id="api_imediaplayercachemanager_getmaxcachefilecount__prototype"></a>

```objectivec
- (NSInteger)maxCacheFileCount NS_SWIFT_NAME(maxCacheFileCount());
```

## maxCacheFileSize [#api_imediaplayercachemanager_getmaxcachefilesize]

获取缓存媒体文件的聚合存储空间的最大大小。

<a id="api_imediaplayercachemanager_getmaxcachefilesize__prototype"></a>

```objectivec
- (NSInteger)maxCacheFileSize NS_SWIFT_NAME(maxCacheFileSize());
```

<a id="api_imediaplayercachemanager_getmaxcachefilesize__detailed_desc"></a>

你可以调用 [setMaxCacheFileSize:](/zh-CN/api-reference/rtc/ios/play/mediaplayer/mediaplayer-cache#api_imediaplayercachemanager_setmaxcachefilesize) 方法根据你的使用场景设置该限制。默认情况下，缓存媒体文件的聚合存储空间的最大大小为 1 GB。

### 返回值 [#api_imediaplayercachemanager_getmaxcachefilesize__return_values]

- 方法调用成功，返回缓存媒体文件的聚合存储空间的最大大小（单位为字节）。
- 方法调用失败，返回小于 0 的错误码，详见 [AgoraMediaPlayerReason](/zh-CN/api-reference/rtc/ios/enum-mediaplayerreason)。

- [AgoraRtcMediaPlayerCacheManagerProtocol](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_imediaplayercachemanager)

## AgoraRtcMediaPlayer:cacheStats: [#callback_imediaplayersourceobserver_onplayercachestats]

上报正在缓存的媒体文件的统计信息。

<a id="callback_imediaplayersourceobserver_onplayercachestats__prototype"></a>

```objectivec
- (void)AgoraRtcMediaPlayer:(id<AgoraRtcMediaPlayerProtocol> _Nonnull)playerKit cacheStats:(AgoraMediaPlayerCacheStatistics *_Nonnull)info NS_SWIFT_NAME(AgoraRtcMediaPlayer(_:cacheStats:));
```

### <span id="callback_imediaplayersourceobserver_onplayercachestats__detailed_desc"></span>触发时机 [#callback_imediaplayersourceobserver_onplayercachestats__timing]

该回调在你调用 [openWithMediaSource:](/zh-CN/api-reference/rtc/ios/play/mediaplayer/mediaplayer-open#api_imediaplayer_openwithmediasource) 方法并将 `enableCache` 设置为 YES 后，每秒触发一次。

### 参数 [#callback_imediaplayersourceobserver_onplayercachestats__parameters]

#### `playerKit`

[AgoraRtcMediaPlayerProtocol](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_imediaplayer) 实例。详见 [AgoraRtcMediaPlayerProtocol](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_imediaplayer)。

#### `info`

正在缓存的媒体文件的统计信息。详见 [AgoraMediaPlayerCacheStatistics](/zh-CN/api-reference/rtc/ios/class-cachestatistics)。

- [AgoraRtcMediaPlayerDelegate](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_imediaplayersourceobserver)
