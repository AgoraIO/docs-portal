## <span id="toc_rte_player"></span>addView:config:error: [#api_canvas_addview]

添加一个渲染视图。

<a id="api_canvas_addview__prototype"></a>

```objectivec
- (BOOL)addView:(AgoraRteView * _Nonnull)view config:(AgoraRteViewConfig* _Nullable)config error:(AgoraRteError* _Nullable)error;
```

#### `自从` [#api_canvas_addview__detailed_desc]

自 v4.4.0 版本新增。

你可以调用该方法将视图添加到视频渲染器中，以显示视频内容。

:::info[注]
当前仅支持一个视图。
:::

### 适用场景 [#api_canvas_addview__scenario]

当你需要使用播放器播放视频时，可以调用此方法将视图添加到视频渲染器中，以显示视频内容。

### 调用时机 [#api_canvas_addview__timing]

你必须在调用 [setCanvas:error:](/zh-CN/api-reference/rtc/ios/play/rte-player#api_player_setcanvas) 之前调用此方法。

### 参数 [#api_canvas_addview__parameters]

#### `view`

视图对象的指针。

- iOS：一个 `UIView` 对象。
- macOS：一个 `NSView` 对象。

#### `config`

视图对象的配置。当前请传入 nil。

#### `error`

状态或错误信息，详见 [AgoraRteError](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_error)。

### 返回值 [#api_canvas_addview__return_values]

- YES：添加视图成功。
- NO：添加视图失败。

- [AgoraRteCanvas](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_canvas)

## setAbrFallbackLayer:error: [#api_playerconfig_setabrfallbacklayer]

设置已订阅远端视频流的分层推流回退选项。

<a id="api_playerconfig_setabrfallbacklayer__prototype"></a>

```objectivec
- (void)setAbrFallbackLayer:(AgoraRteAbrFallbackLayer)layer error:(AgoraRteError * _Nullable)error;
```

#### `自从` [#api_playerconfig_setabrfallbacklayer__detailed_desc]

自 v4.4.0 版本新增。

在网络条件较差时，实时音视频通信的质量可能会下降。调用该方法后，SDK 会在网络变差时将远端视频流的分辨率回退到指定的视频质量层级。每个视频质量层级对应特定的分辨率和码率。SDK 会持续监测网络质量，在网络改善时恢复到原始订阅的视频质量层级。 默认情况下，调用该方法后只能选择回退到 `AgoraRteAbrFallbackLow` 或 `AgoraRteAbrFallbackAudioOnly`。如果你对视频体验有更高要求，可以[联系技术支持](https://ticket.shengwang.cn/)开启 ABR 功能。开启后，可以回退到所有视频质量层级，并自定义每个层级的分辨率。

:::info[注]
如果未开启 ABR 功能，远端视频流的回退质量层级只能设置为 `AgoraRteAbrFallbackLow` 或 `AgoraRteAbrFallbackAudioOnly`。
:::

### 适用场景 [#api_playerconfig_setabrfallbacklayer__scenario]

一般场景下，可调用该方法并将回退质量层设置为 `kRteAbrFallbackLow` 或 `kRteAbrFallbackAudioOnly`。当网络较差时，SDK 会回退为视频小流或仅接收音频流。 如果对回退视频流的分辨率有更高要求，可[联系技术支持](https://ticket.shengwang.cn/)开启 ABR 功能。开启后，可自定义每一层的分辨率。SDK 会以你指定的最低质量层的分辨率为下限，并根据网络状况在该范围内动态调整分辨率。

### 调用时机 [#api_playerconfig_setabrfallbacklayer__timing]

### 参数 [#api_playerconfig_setabrfallbacklayer__parameters]

:::

| 视频质量层级 | 分辨率 |

| `AgoraRteAbrSubscriptionLayer2` | 1440p (2K) |
| `AgoraRteAbrSubscriptionLayer3` | 1080p (HD) |
| `AgoraRteAbrSubscriptionLayer4` | 720p (HD) |
