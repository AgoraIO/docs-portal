## <span id="toc_mediaplayer_info"></span>getAudioBufferDelay [#api_imediaplayer_getaudiobufferdelay]

获取你播放媒体文件时的音频缓冲延迟。

<a id="api_imediaplayer_getaudiobufferdelay__prototype"></a>

```objectivec
- (NSInteger)getAudioBufferDelay NS_SWIFT_NAME(getAudioBufferDelay());
```

### <span id="api_imediaplayer_getaudiobufferdelay__detailed_desc"></span>返回值 [#api_imediaplayer_getaudiobufferdelay__return_values]

- 0：方法调用成功，返回音频缓冲延迟（毫秒）。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/ios/error-code)了解详情和解决建议。你可以使用 `MediaPlayerReason` 检查失败原因。

- [AgoraRtcMediaPlayerProtocol](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_imediaplayer)

## getStreamByIndex: [#api_imediaplayer_getstreaminfo]

获取媒体流的详细信息。

<a id="api_imediaplayer_getstreaminfo__prototype"></a>

```objectivec
- (AgoraRtcMediaStreamInfo *_Nullable)getStreamByIndex:(int)index NS_SWIFT_NAME(getStreamBy(_:));
```

<a id="api_imediaplayer_getstreaminfo__detailed_desc"></a>

调用该方法可获取指定索引的媒体流的详细信息。

### 调用时机 [#api_imediaplayer_getstreaminfo__timing]

在调用 [getStreamCount](/zh-CN/api-reference/rtc/ios/play/mediaplayer/mediaplayer-info#api_imediaplayer_getstreamcount) 方法之后调用该方法。

### 参数 [#api_imediaplayer_getstreaminfo__parameters]

#### `index`

媒体流的索引。该参数必须小于 [getStreamCount](/zh-CN/api-reference/rtc/ios/play/mediaplayer/mediaplayer-info#api_imediaplayer_getstreamcount) 的返回值。

### 返回值 [#api_imediaplayer_getstreaminfo__return_values]

- 方法调用成功，返回一个 [AgoraRtcMediaStreamInfo](/zh-CN/api-reference/rtc/ios/class-playerstreaminfo) 对象，详见 [AgoraRtcMediaStreamInfo](/zh-CN/api-reference/rtc/ios/class-playerstreaminfo)。
- 方法调用失败，返回 nil。

- [AgoraRtcMediaPlayerProtocol](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_imediaplayer)

## AgoraRtcMediaPlayer:playbackStats: [#callback_imediaplayersourceobserver_onplayerplaybackstats]

播放媒体文件的统计信息回调。

<a id="callback_imediaplayersourceobserver_onplayerplaybackstats__prototype"></a>

```objectivec
- (void)AgoraRtcMediaPlayer:(id<AgoraRtcMediaPlayerProtocol> _Nonnull)playerKit playbackStats:(AgoraMediaPlayerPlaybackStats *_Nonnull)info NS_SWIFT_NAME(AgoraRtcMediaPlayer(_:playbackStats:));
```

### <span id="callback_imediaplayersourceobserver_onplayerplaybackstats__detailed_desc"></span>触发时机 [#callback_imediaplayersourceobserver_onplayerplaybackstats__timing]

该回调每秒触发一次，用于报告正在播放的媒体文件的统计信息。

### 参数 [#callback_imediaplayersourceobserver_onplayerplaybackstats__parameters]

#### `playerKit`

播放器实例。详见 [AgoraRtcMediaPlayerProtocol](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_imediaplayer)。

#### `info`

媒体文件的统计信息。详见 [AgoraMediaPlayerPlaybackStats](/zh-CN/api-reference/rtc/ios/class-playerplaybackstats)。

- [AgoraRtcMediaPlayerDelegate](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_imediaplayersourceobserver)
