## 枚举值

### `AgoraMediaPlayerPreloadEventBegin`

（0）：开始预加载媒体资源。

### `AgoraMediaPlayerPreloadEventComplete`

（1）：媒体资源预加载完成。

### `AgoraMediaPlayerPreloadEventError`

（2）：预加载媒体资源过程中发生错误。
