## 枚举值

<ParameterList>
<a id="agoraaudioprofiledefault"></a>
<Parameter name="AgoraAudioProfileDefault">

（0）：默认音频配置文件。

- 互动直播场景：采样率为 48 kHz，音乐编码，单声道，码率最高为 64 Kbps。
- 通信场景：采样率为 32 kHz，音频编码，单声道，码率最高为 18 Kbps。

</Parameter>
<a id="agoraaudioprofilespeechstandard"></a>
<Parameter name="AgoraAudioProfileSpeechStandard">

（1）：采样率为 32 kHz，音频编码，单声道，码率最高为 18 Kbps。

</Parameter>
<a id="agoraaudioprofilemusicstandard"></a>
<Parameter name="AgoraAudioProfileMusicStandard">

（2）：采样率为 48 kHz，音乐编码，单声道，码率最高为 64 Kbps。

</Parameter>
<a id="agoraaudioprofilemusicstandardstereo"></a>
<Parameter name="AgoraAudioProfileMusicStandardStereo">

（3）：采样率为 48 kHz，音乐编码，立体声，码率最高为 80 Kbps。在 iOS 上，如需启用立体声音频，还需调用 [setAdvancedAudioOptions:](/zh-CN/api-reference/rtc/ios/audio/audio-prenpost/audio-effect#api_irtcengine_setadvancedaudiooptions)，并在 [AgoraAdvancedAudioOptions](/zh-CN/api-reference/rtc/ios/class-advancedaudiooptions) 中将 `audioProcessingChannels` 设置为 `AgoraAudioProcessChannelstereo`。

</Parameter>
<a id="agoraaudioprofilemusichighquality"></a>
<Parameter name="AgoraAudioProfileMusicHighQuality">

（4）：采样率为 48 kHz，音乐编码，单声道，码率最高为 96 Kbps。

</Parameter>
<a id="agoraaudioprofilemusichighqualitystereo"></a>
<Parameter name="AgoraAudioProfileMusicHighQualityStereo">

（5）：采样率为 48 kHz，音乐编码，立体声，码率最高为 128 Kbps。在 iOS 上，如需启用立体声音频，还需调用 [setAdvancedAudioOptions:](/zh-CN/api-reference/rtc/ios/audio/audio-prenpost/audio-effect#api_irtcengine_setadvancedaudiooptions)，并在 [AgoraAdvancedAudioOptions](/zh-CN/api-reference/rtc/ios/class-advancedaudiooptions) 中将 `audioProcessingChannels` 设置为 `AgoraAudioProcessChannelstereo`。

</Parameter>
<a id="agoraaudioprofileiot"></a>
<Parameter name="AgoraAudioProfileIot">

（6）：采样率为 16 kHz，音频编码，单声道，并启用回声消除（AEC）。

</Parameter>
</ParameterList>
