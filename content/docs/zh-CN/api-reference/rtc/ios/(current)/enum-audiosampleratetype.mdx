## 枚举值

### `AgoraAudioSampleRateType32000`

（32000）：采样率为 32 kHz。

### `AgoraAudioSampleRateType44100`

（44100）：采样率为 44.1 kHz。

### `AgoraAudioSampleRateType48000`

（48000）：采样率为 48 kHz（默认）。
