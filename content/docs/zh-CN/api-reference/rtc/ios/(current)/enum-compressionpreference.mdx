## 枚举值 [#enum_compressionpreference__parameters]

### `AgoraCompressionAuto`

（-1）：自动模式（默认）。SDK 会根据设置的视频场景自动选择 AgoraCompressionLowLatency 或 AgoraCompressionQuality，以实现最佳用户体验。

### `AgoraCompressionLowLatency`

（0）：低延迟优先。SDK 会压缩视频帧以降低延迟，适用于对流畅性要求较高且可接受视频质量降低的场景。

### `AgoraCompressionQuality`

（1）：高质量优先。SDK 会在保持视频质量的同时压缩视频帧，适用于对视频质量要求较高的场景。
