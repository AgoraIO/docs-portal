## startRtmpStreamWithoutTranscoding:

开始向 CDN 推流（不进行转码）。

<a id="api_irtcengine_startrtmpstreamwithouttranscoding__prototype"></a>

```text
- (int)startRtmpStreamWithoutTranscoding:(NSString* _Nonnull)url NS_SWIFT_NAME(startRtmpStreamWithoutTranscoding(_:));
```

<a id="api_irtcengine_startrtmpstreamwithouttranscoding__detailed_desc"></a>

声网推荐你使用更加完善的服务端推流功能，详见[实现服务端旁路推流](/zh-CN/realtime-media/media-push)。
你可以调用该方法将音频或视频流推送到指定的 CDN 地址。该方法每次只能向一个 CDN 地址推流，如果需要推送到多个地址，请多次调用该方法。

:::note
注：

- 请在加入频道后调用该方法。
- 只有在 `LIVE_BROADCASTING` 频道场景中的主播可以调用该方法。
- 如果推流失败后需要重试，必须先调用 [stopRtmpStream:](/zh-CN/api-reference/rtc/ios/cloud-media-relay/media-push#api_irtcengine_stoprtmpstream) 停止推流，再调用该方法重新推流；否则，SDK 会返回与上次失败相同的错误码。
:::

<a id="api_irtcengine_startrtmpstreamwithouttranscoding__related"></a>

### 相关回调

成功调用该方法后，SDK 会触发 [rtcEngine\:rtmpStreamingChangedToState\:state\:reason:](/zh-CN/api-reference/rtc/ios/cloud-media-relay/media-push#callback_irtcengineeventhandler_onrtmpstreamingstatechanged) 回调报告推流状态。

<a id="api_irtcengine_startrtmpstreamwithouttranscoding__parameters"></a>

### 参数

### url

旁路推流地址。格式为 RTMP 或 RTMPS，字符长度不能超过 1024 字节。不支持中文等特殊字符。

<a id="api_irtcengine_startrtmpstreamwithouttranscoding__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。

  - -2：URL 或转码配置不合法。请检查 URL 和转码配置。
  - -7：调用该方法前未初始化 SDK。
  - -19：旁路推流地址已被使用。请更换其他地址。

### 所属接口类

- [AgoraRtcEngineKit](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_irtcengine)

## rtcEngine\:rtmpStreamingChangedToState\:state\:reason:

RTMP 或 RTMPS 推流状态发生变化时触发的回调。

<a id="callback_irtcengineeventhandler_onrtmpstreamingstatechanged__prototype"></a>


<a id="callback_irtcengineeventhandler_onrtmpstreamingstatechanged__detailed_desc"></a>

当 RTMP 或 RTMPS 推流状态发生变化时，SDK 会触发该回调，用于报告你调用 `addPublishStreamUrl` 或 `removePublishStreamUrl` 的结果。该回调返回推流地址及其当前的推流状态。当出现异常时，你可以通过 `reason` 参数中的详细错误信息进行排查。

## rtcEngineTranscodingUpdated:

发布端的云端转码设置更新时触发的回调。

<a id="callback_irtcengineeventhandler_ontranscodingupdated__prototype"></a>

```text
- (void)rtcEngineTranscodingUpdated:(AgoraRtcEngineKit * _Nonnull)engine NS_SWIFT_NAME(rtcEngineTranscodingUpdated(_:));
```

<a id="callback_irtcengineeventhandler_ontranscodingupdated__detailed_desc"></a>

当你在 [startRtmpStreamWithTranscoding\:transcoding:](/zh-CN/api-reference/rtc/ios/cloud-media-relay/media-push#api_irtcengine_startrtmpstreamwithtranscoding) 方法中更新 [AgoraLiveTranscoding](/zh-CN/api-reference/rtc/ios/class-livetranscoding) 时，SDK 会触发该回调以报告更新信息。

:::note
注： 如果你首次调用 [startRtmpStreamWithTranscoding\:transcoding:](/zh-CN/api-reference/rtc/ios/cloud-media-relay/media-push#api_irtcengine_startrtmpstreamwithtranscoding) 方法设置 [AgoraLiveTranscoding](/zh-CN/api-reference/rtc/ios/class-livetranscoding)，SDK 不会触发该回调。
:::

<a id="callback_irtcengineeventhandler_ontranscodingupdated__timing"></a>

### 触发时机

当发布端的云端转码设置更新时触发。
