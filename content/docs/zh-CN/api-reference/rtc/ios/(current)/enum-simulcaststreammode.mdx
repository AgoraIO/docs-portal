## 枚举值

<ParameterList>
<a id="agoraautosimulcaststream"></a>
<Parameter name="AgoraAutoSimulcastStream">

（-1）：默认情况下，在接收端发出对低质量层级视频流的订阅请求之前，不发送低质量层级视频流；收到订阅请求后，自动开始发送低质量层级视频流。

</Parameter>
<a id="agoradisablesimulcaststream"></a>
<Parameter name="AgoraDisableSimulcastStream">

（0）：从不发送低质量层级视频流。

</Parameter>
<a id="agoraenablesimulcaststream"></a>
<Parameter name="AgoraEnableSimulcastStream">

（1）：始终发送低质量层级视频流。

</Parameter>
