<a id="class_livestreamadvancedfeature__detailed_desc"></a>

如果你希望启用带转码推流的高级功能，请[联系技术支持](https://ticket.shengwang.cn/)。

## 属性 [#class_livestreamadvancedfeature__parameters]

### `featureName`

功能名称，包括 LBHQ（低码率高画质）和 VEO（视频编码器优化）。

### `opened`

是否启用带转码推流的高级功能：

- YES：启用高级功能。
- NO：（默认）不启用高级功能。
