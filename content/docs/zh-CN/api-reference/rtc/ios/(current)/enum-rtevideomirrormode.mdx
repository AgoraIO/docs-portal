### `自从` [#enum_rtevideomirrormode__detailed_desc]

自 v4.4.0 版本新增。

## 枚举值 [#enum_rtevideomirrormode__parameters]

### `AgoraRteVideoMirrorModeAuto`

（0）：SDK 自动决定镜像模式。

- 本地视频视图镜像模式：使用前置摄像头时，默认启用镜像模式；使用后置摄像头时，默认关闭镜像模式。
- 远端用户视图镜像模式：默认关闭镜像模式。

### `AgoraRteVideoMirrorModeEnabled`

（1）：启用镜像模式。

### `AgoraRteVideoMirrorModeDisabled`

（2）：关闭镜像模式。
