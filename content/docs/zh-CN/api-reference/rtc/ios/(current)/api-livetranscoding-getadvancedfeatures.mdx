<a id="api_livetranscoding_getadvancedfeatures__return_values"></a>

## 返回值

- 方法调用成功，返回包含每个高级功能名称及其启用状态的 AgoraLiveStreamAdvancedFeature 对象数组，详见 AgoraLiveStreamAdvancedFeature。
- 方法调用失败，返回 nil。
