## createMediaRecorder:

创建一个媒体录制器实例。

<a id="api_irtcengine_createmediarecorder__prototype"></a>

```text
- (AgoraMediaRecorder * _Nullable)createMediaRecorder:(AgoraRecorderStreamInfo * _Nonnull)info NS_SWIFT_NAME(createMediaRecorder(withInfo:));
```

<a id="api_irtcengine_createmediarecorder__detailed_desc"></a>

在开始音视频流录制之前，你需要调用该方法创建一个媒体录制器实例。SDK 支持录制来自本地或远端用户的多个音视频流。你可以多次调用该方法创建多个录制器实例，并使用 `info` 参数指定要录制的频道名和远端用户 ID。

成功创建录制器实例后，你需要调用 [setMediaRecorderDelegate:](/zh-CN/api-reference/rtc/ios/recording#api_imediarecorder_setmediarecorderobserver) 方法为该录制器注册一个观察者，以监听相关回调，然后调用 [startRecording:](/zh-CN/api-reference/rtc/ios/recording#api_imediarecorder_startrecording) 方法开始录制。

要录制的音视频流的信息，详见 [AgoraRecorderStreamInfo](/zh-CN/api-reference/rtc/ios/class-recorderstreaminfo)。

</Parameter>
</ParameterList>

## startAudioRecording\:quality:

开始客户端录音。

<a id="api_irtcengine_startaudiorecording1__prototype"></a>

```text
- (int)startAudioRecording:(NSString * _Nonnull)filePath
                   quality:(AgoraAudioRecordingQuality)quality NS_SWIFT_NAME(startAudioRecording(_:quality:));
```

<a id="api_irtcengine_startaudiorecording1__detailed_desc"></a>

你可以在通话过程中调用该方法进行客户端录音。该方法会录制频道中所有用户的音频，并生成包含所有用户声音的录音文件。录音文件仅支持以下格式：

- `.wav`：文件体积大，音频保真度高。

:::note
注： 调用该方法时，默认的录音采样率为 32 kHz，且无法修改。

## startAudioRecordingWithConfig:

开始客户端录制并配置录制设置。

<a id="api_irtcengine_startaudiorecording3__prototype"></a>

```text

```

<a id="api_irtcengine_startaudiorecording3__detailed_desc"></a>

调用该方法后，你可以录制频道中用户的音频并生成录音文件。录音文件仅支持以下格式：

- WAV：音频保真度较高但文件较大。例如，采样率为 32000 Hz 的 10 分钟录音文件约为 73 MB。

当你离开频道时，录制会自动停止。该方法支持在通话过程中进行客户端录制。

## startRecording:

开始录制音视频流。

<a id="api_imediarecorder_startrecording__prototype"></a>

```text
- (int)startRecording:(AgoraMediaRecorderConfiguration* _Nonnull)config NS_SWIFT_NAME(startRecording(_:));
```

<a id="api_imediarecorder_startrecording__detailed_desc"></a>

:::info[自从]
自 v4.0.0 版本新增。
:::

该方法用于开始录制音频和视频流。声网 SDK 支持同时录制本地和远端用户的音视频流。
在开始录制前，请确保：

- 已调用 [createMediaRecorder:](/zh-CN/api-reference/rtc/ios/recording#api_irtcengine_createmediarecorder) 创建媒体录制器对象。
- 已调用 [setMediaRecorderDelegate:](/zh-CN/api-reference/rtc/ios/recording#api_imediarecorder_setmediarecorderobserver) 注册媒体录制器观察者以监听录制相关的回调。
- 已加入频道。

该方法支持录制以下数据：

- 通过麦克风采集的音频，编码格式为 AAC。
- 通过摄像头采集的视频，编码格式为 H.264 或 H.265。

录制开始后，如果录制过程中视频分辨率发生变化，SDK 会停止录制。如果音频采样率或声道数发生变化，SDK 会继续录制并生成一个 MP4 文件。仅当检测到可录制的音视频流时，才会生成录制文件。如果在录制过程中未检测到可录制的音视频流，或音视频流中断超过 5 秒，SDK 会停止录制并触发 [mediaRecorder\:stateDidChanged\:uid\:state\:reason:](/zh-CN/api-reference/rtc/ios/recording#callback_imediarecorderobserver_onrecorderstatechanged) 回调（`AgoraMediaRecorderStateError`，`AgoraMediaRecorderReasonCodeNoStream`）。

:::note
注：

- 如果需要录制本地音视频流，请确保本地用户角色在开始录制前已设置为主播。
- 如果需要录制远端用户的音视频流，请确保在开始录制前已订阅目标用户的音视频流。
:::

<ParameterList>

<Parameter name="config">

用于配置音视频流录制的参数，详见 [AgoraMediaRecorderConfiguration](/zh-CN/api-reference/rtc/ios/class-mediarecorderconfiguration)。

</Parameter>

    - 指定的录制文件保存路径正确且可写。
    - 指定的录制文件格式正确。
    - 最大录制时长设置正确。
  - -4：当前 [AgoraRtcEngineKit](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_irtcengine) 的状态不支持该操作。可能是由于已有录制任务正在进行，或录制错误导致录制已停止。
  - -7：调用该方法时 [AgoraRtcEngineKit](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_irtcengine) 尚未初始化。请确保在调用该方法前已创建 [AgoraMediaRecorder](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_imediarecorder) 对象。
