<a id="class_codeccaplevels__prototype"></a>

```objectivec
__attribute__((visibility("default"))) @interface AgoraVideoCodecCapLevels : NSObject
@property(assign, nonatomic) AgoraVideoCodecCapabilityLevel hwDecodingLevel;
@property(assign, nonatomic) AgoraVideoCodecCapabilityLevel swDecodingLevel;
@end
```

<a id="class_codeccaplevels__detailed_desc"></a>

用于表示设备在不同视频质量下的硬件和软件解码能力等级。

<a id="class_codeccaplevels__parameters"></a>

## 属性

### `hwDecodingLevel`

硬件解码能力等级。详见 [AgoraVideoCodecCapabilityLevel](/zh-CN/api-reference/rtc/ios/enum-videocodeccapabilitylevel)。

### `swDecodingLevel`

软件解码能力等级。详见 [AgoraVideoCodecCapabilityLevel](/zh-CN/api-reference/rtc/ios/enum-videocodeccapabilitylevel)。
