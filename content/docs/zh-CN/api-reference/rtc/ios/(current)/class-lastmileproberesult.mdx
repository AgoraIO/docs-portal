---
<a id="class_lastmileproberesult__prototype"></a>

```objectivec
__attribute__((visibility("default"))) @interface AgoraLastmileProbeResult : NSObject
@property (assign, nonatomic) AgoraLastmileProbeResultState state;
@property (assign, nonatomic) NSUInteger rtt;
@property (strong, nonatomic) AgoraLastmileProbeOneWayResult *_Nonnull uplinkReport;
@property (strong, nonatomic) AgoraLastmileProbeOneWayResult *_Nonnull downlinkReport;
@end
```

<a id="class_lastmileproberesult__parameters"></a>

## 属性

### `state`

Last-mile 网络测试的状态，详见 [AgoraLastmileProbeResultState](/zh-CN/api-reference/rtc/ios/enum-lastmileproberesultstate)。

### `rtt`

往返时延，单位为毫秒。

### `uplinkReport`

上行 Last-mile 网络测试的结果，详见 [AgoraLastmileProbeOneWayResult](/zh-CN/api-reference/rtc/ios/class-lastmileprobeonewayresult)。

### `downlinkReport`

下行 Last-mile 网络测试的结果，详见 [AgoraLastmileProbeOneWayResult](/zh-CN/api-reference/rtc/ios/class-lastmileprobeonewayresult)。
