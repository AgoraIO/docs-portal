## 属性

### captureAudio

:::note
注： 为提高屏幕共享时采集系统音频的成功率，请确保已调用 `setAudioScenario` 方法，并将音频场景设置为 `AudioScenarioGameStreaming`。
:::

是否在屏幕共享时采集系统音频：

- YES：采集系统音频。
- NO：（默认）不采集系统音频。

### audioParams

共享屏幕流的音频配置。详见 [AgoraScreenAudioParameters](/zh-CN/api-reference/rtc/ios/class-screenaudioparameters)。

:::note
注： 该参数仅在 `captureAudio` 为 YES 时生效。
:::

### captureVideo

是否在屏幕共享时采集屏幕画面：

- YES：（默认）采集屏幕。
- NO：不采集屏幕。

### videoParams

共享屏幕流的视频配置。详见 [AgoraScreenVideoParameters](/zh-CN/api-reference/rtc/ios/class-screenvideoparameters)。

:::note
注： 该参数仅在 `captureVideo` 为 YES 时生效。
:::
