## <span id="toc_channel"></span>delegate [#api_irtcengine_delegate]

设置并获取 AgoraRtcEngineDelegate。

<a id="api_irtcengine_delegate__prototype"></a>

```objectivec
@property(nonatomic, weak) id<AgoraRtcEngineDelegate> _Nullable delegate;
```

<a id="api_irtcengine_delegate__detailed_desc"></a>

SDK 通过 [AgoraRtcEngineDelegate](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_irtcengineeventhandler) 类向 App 报告 SDK 运行时的各种事件。该类中定义的所有方法都是可选的实现方法。

- [AgoraRtcEngineKit](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_irtcengine)

## getUserInfoByUid:withError: [#api_irtcengine_getuserinfobyuid]

通过传入用户 ID 获取用户信息。

<a id="api_irtcengine_getuserinfobyuid__prototype"></a>

```objectivec
- (AgoraUserInfo* _Nullable)getUserInfoByUid:(NSUInteger)uid withError:(AgoraErrorCode* _Nullable)error NS_SWIFT_NAME(getUserInfo(byUid:withError:));
```

<a id="api_irtcengine_getuserinfobyuid__detailed_desc"></a>

远端用户加入频道后，SDK 会获取该用户的用户 ID 和用户 User Account，并将其缓存在映射表对象中，同时在本地客户端触发 [rtcEngine:didUserInfoUpdatedWithUserId:userInfo:](/zh-CN/api-reference/rtc/ios/channel#callback_irtcengineeventhandler_onuserinfoupdated) 回调。收到该回调后，你可以调用 [getUserInfoByUid:withError:](/zh-CN/api-reference/rtc/ios/channel#api_irtcengine_getuserinfobyuid) 方法并传入 `uid`，从 [AgoraUserInfo](/zh-CN/api-reference/rtc/ios/class-userinfo) 对象中获取指定用户的用户 User Account。

### 调用时机 [#api_irtcengine_getuserinfobyuid__timing]

在收到 [rtcEngine:didUserInfoUpdatedWithUserId:userInfo:](/zh-CN/api-reference/rtc/ios/channel#callback_irtcengineeventhandler_onuserinfoupdated) 回调后调用该方法。

### 参数 [#api_irtcengine_getuserinfobyuid__parameters]

#### `uid`

用户 ID。

#### `error`

错误码，详见 [AgoraErrorCode](/zh-CN/api-reference/rtc/ios/enum-errorcodetype)。

### 返回值 [#api_irtcengine_getuserinfobyuid__return_values]

- 方法调用成功，返回 [AgoraUserInfo](/zh-CN/api-reference/rtc/ios/class-userinfo) 对象，详见 [AgoraUserInfo](/zh-CN/api-reference/rtc/ios/class-userinfo)。
- 方法调用失败，返回 nil。

- [AgoraRtcEngineKit](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_irtcengine)

## joinChannelByToken:channelId:info:uid:joinSuccess: [#api_irtcengine_joinchannel1]

加入一个频道。

<a id="api_irtcengine_joinchannel1__prototype"></a>

```objectivec
- (int)joinChannelByToken:(NSString * _Nullable)token
                channelId:(NSString * _Nonnull)channelId
                     info:(NSString * _Nullable)info
                      uid:(NSUInteger)uid
              joinSuccess:(void(^ _Nullable)(NSString * _Nonnull channel, NSUInteger uid, NSInteger elapsed))joinSuccessBlock NS_SWIFT_NAME(joinChannel(byToken:channelId:info:uid:joinSuccess:));
```

<a id="api_irtcengine_joinchannel1__detailed_desc"></a>

默认情况下，你会订阅频道中其他所有用户的音视频流，从而产生使用量和计费。如需停止订阅指定流或所有远端流，请调用 `muteRemoteAudio/VideoStream` 或 `muteAllRemoteAudio/VideoStreams`。请在调用 [sharedEngineWithConfig:delegate:](/zh-CN/api-reference/rtc/ios/initialize#api_irtcengine_initialize) 方法后调用本方法。

:::info[注]
该方法每次仅支持加入一个频道。 不同 App ID 的用户无法互通。 加入频道前，请确保用于生成 Token 的 App ID 与传入 [sharedEngineWithConfig:delegate:](/zh-CN/api-reference/rtc/ios/initialize#api_irtcengine_initialize) 方法中的 App ID 一致，否则可能导致加入频道失败。
:::

### 调用时机 [#api_irtcengine_joinchannel1__timing]

请在调用 [sharedEngineWithConfig:delegate:](/zh-CN/api-reference/rtc/ios/initialize#api_irtcengine_initialize) 方法后调用本方法。

### 相关回调 [#api_irtcengine_joinchannel1__related]

成功调用该方法后，SDK 会触发以下回调：

- 本地客户端： [rtcEngine:didJoinChannel:withUid:elapsed:](/zh-CN/api-reference/rtc/ios/channel#callback_irtcengineeventhandler_onjoinchannelsuccess) 和 [rtcEngine:connectionChangedToState:reason:](/zh-CN/api-reference/rtc/ios/network#callback_irtcengineeventhandler_onconnectionstatechanged)。
- 远端客户端：如果是 `COMMUNICATION` 频道场景中的用户加入，或 `LIVE_BROADCASTING` 频道场景中的主播加入频道，会触发 [rtcEngine:didJoinedOfUid:elapsed:](/zh-CN/api-reference/rtc/ios/channel#callback_irtcengineeventhandler_onuserjoined) 回调。

当本地客户端因网络状况不佳与声网服务器断开连接时，SDK 会尝试重连。当本地客户端成功重回频道时，SDK 会触发 [rtcEngine:didRejoinChannel:withUid:elapsed:](/zh-CN/api-reference/rtc/ios/channel#callback_irtcengineeventhandler_onrejoinchannelsuccess) 回调。

### 参数 [#api_irtcengine_joinchannel1__parameters]

#### `token`

在你的服务器上生成的用于鉴权的 Token。

:::info[注]
（推荐）如果你的项目启用了安全模式（使用 App ID 和 Token 进行鉴权），该参数为必填。 如果你只启用了测试模式（使用 App ID 进行鉴权），该参数为可选。成功加入频道后，24 小时后会自动退出频道。 如果你需要同时加入多个频道或在频道之间切换，声网建议使用通配符 Token，这样你无需每次加入频道时都申请新的 Token。详见 `使用 Token 实现安全鉴权`。
:::

#### `channelId`

频道名。该参数表示你进行实时音视频互动的频道。在相同 App ID 的前提下，填写相同频道名的用户会进入同一个频道进行音视频互动。字符串长度必须小于 64 字节。支持的字符（共 89 个）：

- 所有小写英文字母：a 到 z。
- 所有大写英文字母：A 到 Z。
- 所有数字字符：0 到 9。
- "!", "#", "$", "%", "&", "(", ")", "+", "-", ":", ";", "&lt;", "=", ".", "&gt;", "?", "@", "[", "]", "^", "_", "\{", "\}", "|", "~", ","。

#### `info`

（可选）预留参数

#### `uid`

用户 ID。该参数用于标识频道内进行实时音视频互动的用户。你需要自行设置并管理用户 ID，确保同一频道内每个用户 ID 唯一。该参数为 32 位无符号整数，取值范围为 1 到 2^32-1。如果未指定用户 ID（或设置为 0），SDK 会自动分配一个随机用户 ID，并通过 [rtcEngine:didJoinChannel:withUid:elapsed:](/zh-CN/api-reference/rtc/ios/channel#callback_irtcengineeventhandler_onjoinchannelsuccess) 回调返回。你必须记录并维护该返回的用户 ID，SDK 不会保存。

#### `joinSuccessBlock`

用户成功加入频道时触发。 `joinSuccessBlock` 的优先级高于 [rtcEngine:didJoinChannel:withUid:elapsed:](/zh-CN/api-reference/rtc/ios/channel#callback_irtcengineeventhandler_onjoinchannelsuccess)。当两者同时实现时， [rtcEngine:didJoinChannel:withUid:elapsed:](/zh-CN/api-reference/rtc/ios/channel#callback_irtcengineeventhandler_onjoinchannelsuccess) 不生效。声网建议将 `joinSuccessBlock` 设置为 nil，以使用 [rtcEngine:didJoinChannel:withUid:elapsed:](/zh-CN/api-reference/rtc/ios/channel#callback_irtcengineeventhandler_onjoinchannelsuccess)。

### 返回值 [#api_irtcengine_joinchannel1__return_values]

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/ios/error-code)了解详情和解决建议。

  - -2：参数无效。例如，Token 无效， `uid` 参数未设置为整数，或 [AgoraRtcChannelMediaOptions](/zh-CN/api-reference/rtc/ios/class-channelmediaoptions) 中的成员值无效。请传入有效参数并重新加入频道。
  - -3：初始化 [AgoraRtcEngineKit](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_irtcengine) 对象失败。请重新初始化该对象。
  - -7： [AgoraRtcEngineKit](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_irtcengine) 对象尚未初始化。请先初始化该对象再调用本方法。
  - -8： [AgoraRtcEngineKit](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_irtcengine) 对象的内部状态错误。常见原因是在调用 [startEchoTestWithConfig:](/zh-CN/api-reference/rtc/ios/network#api_irtcengine_startechotest3) 开始回声测试后，未调用 [stopEchoTest](/zh-CN/api-reference/rtc/ios/network#api_irtcengine_stopechotest) 停止测试就调用本方法加入频道。请先调用 [stopEchoTest](/zh-CN/api-reference/rtc/ios/network#api_irtcengine_stopechotest)。
  - -17：加入频道请求被拒绝。常见原因是用户已在频道中。声网建议使用 [rtcEngine:connectionChangedToState:reason:](/zh-CN/api-reference/rtc/ios/network#callback_irtcengineeventhandler_onconnectionstatechanged) 回调判断用户是否在频道中。仅当收到 `AgoraConnectionStateDisconnected` （1）状态时再调用本方法。
  - -102：频道名无效。请在 `channelId` 中传入有效频道名重新加入。
  - -121：用户 ID 无效。请在 `uid` 中传入有效用户 ID 重新加入频道。

- [AgoraRtcEngineKit](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_irtcengine)

## joinChannelByToken:channelId:uid:mediaOptions:joinSuccess: [#api_irtcengine_joinchannel2]

加入频道并设置媒体选项。

<a id="api_irtcengine_joinchannel2__prototype"></a>

```objectivec
- (int)joinChannelByToken:(NSString * _Nullable)token
                channelId:(NSString * _Nonnull)channelId
                      uid:(NSUInteger)uid
             mediaOptions:(AgoraRtcChannelMediaOptions * _Nonnull)mediaOptions
              joinSuccess:(void(^ _Nullable)(NSString * _Nonnull channel, NSUInteger uid, NSInteger elapsed))joinSuccessBlock NS_SWIFT_NAME(joinChannel(byToken:channelId:uid:mediaOptions:joinSuccess:));
```

<a id="api_irtcengine_joinchannel2__detailed_desc"></a>

与 [joinChannelByToken:channelId:info:uid:joinSuccess:](/zh-CN/api-reference/rtc/ios/channel#api_irtcengine_joinchannel1) 方法相比，该方法新增了 `mediaOptions` 参数，用于设置媒体选项，例如是否在频道内发布音视频流，或在加入频道时是否自动订阅所有远端用户的音视频流。默认情况下，你会订阅频道中所有其他用户的音视频流，从而产生使用量和计费。如需停止订阅其他流，请设置 `mediaOptions` 参数或调用 `muteRemoteAudio/VideoStream` 或 `muteAllRemoteAudio/VideoStreams`。

:::info[注]
- 该方法仅支持用户同时加入一个频道。
- 不同 App ID 的用户无法互通。
- 加入频道前，请确保用于生成 Token 的 App ID 与调用 [sharedEngineWithConfig:delegate:](/zh-CN/api-reference/rtc/ios/initialize#api_irtcengine_initialize) 方法时传入的 App ID 一致，否则可能导致加入频道失败。
:::

### 调用时机 [#api_irtcengine_joinchannel2__timing]

请在调用 [sharedEngineWithConfig:delegate:](/zh-CN/api-reference/rtc/ios/initialize#api_irtcengine_initialize) 之后调用该方法。

### 相关回调 [#api_irtcengine_joinchannel2__related]

调用该方法成功后会触发以下回调：

- 本地客户端： [rtcEngine:didJoinChannel:withUid:elapsed:](/zh-CN/api-reference/rtc/ios/channel#callback_irtcengineeventhandler_onjoinchannelsuccess) 和 [rtcEngine:connectionChangedToState:reason:](/zh-CN/api-reference/rtc/ios/network#callback_irtcengineeventhandler_onconnectionstatechanged) 回调。
- 远端客户端：如果你在 `COMMUNICATION` 模式下加入频道，或作为主播在 `LIVE_BROADCASTING` 模式下加入频道，会触发 [rtcEngine:didJoinedOfUid:elapsed:](/zh-CN/api-reference/rtc/ios/channel#callback_irtcengineeventhandler_onuserjoined) 回调。

当由于网络状况不佳导致本地客户端与声网服务器的连接中断时，SDK 会尝试重新连接服务器。当本地客户端成功重回频道时，SDK 会在本地客户端触发 [rtcEngine:didRejoinChannel:withUid:elapsed:](/zh-CN/api-reference/rtc/ios/channel#callback_irtcengineeventhandler_onrejoinchannelsuccess) 回调。

### 参数 [#api_irtcengine_joinchannel2__parameters]

#### `token`

在你的服务器上生成的用于鉴权的 Token。

:::info[注]
- （推荐）如果你的项目启用了安全模式（使用 App ID 和 Token 进行鉴权），该参数为必填。
- 如果你仅启用了测试模式（使用 App ID 进行鉴权），该参数为可选。成功加入频道后，你将在 24 小时后自动退出频道。
- 如果你需要同时加入不同频道或在频道间切换，声网建议使用通配符 Token，这样你无需每次加入频道时都申请新的 Token。
:::

#### `channelId`

频道名。该参数表示你进行实时音视频互动的频道。在相同 App ID 的前提下，填写相同频道名的用户会进入同一个频道进行音视频互动。字符串长度必须小于 64 字节。支持的字符（共 89 个）：

- 所有小写英文字母：a 到 z。
- 所有大写英文字母：A 到 Z。
- 所有数字字符：0 到 9。
- "!", "#", "$", "%", "&", "(", ")", "+", "-", ":", ";", "&lt;", "=", ".", "&gt;", "?", "@", "[", "]", "^", "_", "\{", "\}", "|", "~", ","。

#### `uid`

用户 ID。该参数用于标识频道内进行实时音视频互动的用户。你需要自行设置并管理用户 ID，确保同一频道内每个用户 ID 唯一。该参数为 32 位无符号整数，取值范围为 1 到 2^32-1。如果未指定用户 ID（或设置为 0），SDK 会自动分配一个随机用户 ID，并通过 [rtcEngine:didJoinChannel:withUid:elapsed:](/zh-CN/api-reference/rtc/ios/channel#callback_irtcengineeventhandler_onjoinchannelsuccess) 回调返回。你必须记录并维护该返回的用户 ID，SDK 不会保存。

#### `mediaOptions`

频道媒体选项。详见 [AgoraRtcChannelMediaOptions](/zh-CN/api-reference/rtc/ios/class-channelmediaoptions)。

#### `joinSuccessBlock`

用户加入频道成功时触发。 `joinSuccessBlock` 的优先级高于 [rtcEngine:didJoinChannel:withUid:elapsed:](/zh-CN/api-reference/rtc/ios/channel#callback_irtcengineeventhandler_onjoinchannelsuccess)。当两者同时实现时， [rtcEngine:didJoinChannel:withUid:elapsed:](/zh-CN/api-reference/rtc/ios/channel#callback_irtcengineeventhandler_onjoinchannelsuccess) 不再生效。声网建议将 `joinSuccessBlock` 设置为 nil，以使用 [rtcEngine:didJoinChannel:withUid:elapsed:](/zh-CN/api-reference/rtc/ios/channel#callback_irtcengineeventhandler_onjoinchannelsuccess)。

### 返回值 [#api_irtcengine_joinchannel2__return_values]

0：方法调用成功。 &lt; 0：方法调用失败。

- -2：参数无效。例如，Token 无效， `uid` 参数未设置为整数，或 [AgoraRtcChannelMediaOptions](/zh-CN/api-reference/rtc/ios/class-channelmediaoptions) 中的成员值无效。你需要传入有效参数并重新加入频道。

预加载指定频道。

<a id="api_irtcengine_preloadchannel__prototype"></a>

```objectivec
- (int)preloadChannelByToken:(NSString * _Nullable)token
                   channelId:(NSString * _Nonnull)channelId
                         uid:(NSUInteger)uid NS_SWIFT_NAME(preloadChannel(byToken:channelId:uid:));
```

<a id="api_irtcengine_preloadchannel__detailed_desc"></a>

该方法用于预加载指定频道。当你作为观众需要频繁切换频道时，调用该方法可以缩短加入频道的时间，从而减少你听到和看到主播的延迟。该方法需要在加入频道前调用。如果你加入了一个已预加载的频道，离开后想要重新加入该频道，除非用于预加载的 Token 过期，否则无需再次调用该方法。为提升预加载频道的用户体验，声网建议你在确认频道名和用户信息后尽早调用该方法。

:::info[注]
- 调用该方法时，请确保将用户角色设置为观众，且未将音频场景设置为 `AgoraAudioScenarioChorus`，否则该方法不生效。
- 你还需要确保用于预加载的频道名、用户 ID 和 Token 与加入频道时传入的值一致，否则该方法不生效。
- 一个 [AgoraRtcEngineKit](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_irtcengine) 实例最多支持预加载 20 个频道，超出限制时，仅最近的 20 个预加载频道生效。
- 预加载频道失败并不意味着无法加入频道，也不会增加加入频道所需的时间。
:::

该方法需要在加入频道前调用。

### 参数 [#api_irtcengine_preloadchannel__parameters]

#### `token`

在你的服务器上生成的用于鉴权的 Token。当用于预加载频道的 Token 过期时，你可以根据预加载的频道数量更新 Token。

- 如果只预加载一个频道，调用该方法传入新的 Token。
- 如果预加载多个频道：

你想要预加载的频道名。该参数表示用户进行实时音视频互动的频道。在相同 App ID 的前提下，填写相同频道名的用户会进入同一个频道进行音视频互动。字符串长度必须小于 64 字节。支持的字符（共 89 个）：

  - -7： [AgoraRtcEngineKit](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_irtcengine) 对象尚未初始化。你需要先初始化该对象再调用此方法。

## registerLocalUserAccount:appId: [#api_irtcengine_registerlocaluseraccount]

<a id="api_irtcengine_registerlocaluseraccount__detailed_desc"></a>

[registerLocalUserAccount:appId:](/zh-CN/api-reference/rtc/ios/channel#api_irtcengine_registerlocaluseraccount) 方法用于注册一个 `userAccount`，注册成功后，该 `userAccount` 可用于在加入频道时标识本地用户身份。 该方法为可选方法。如果你希望使用 `userAccount` 加入频道，可以选择以下任一方式：

- 先调用 [registerLocalUserAccount:appId:](/zh-CN/api-reference/rtc/ios/channel#api_irtcengine_registerlocaluseraccount) 方法注册一个 `userAccount`，再调用 [joinChannelByToken:channelId:userAccount:joinSuccess:](/zh-CN/api-reference/rtc/ios/channel#api_irtcengine_joinchannelwithuseraccount1) 或 [joinChannelByToken:channelId:userAccount:mediaOptions:joinSuccess:](/zh-CN/api-reference/rtc/ios/channel#api_irtcengine_joinchannelwithuseraccount2) 方法加入频道，可缩短进入频道所需时间。

调用该方法成功后，本地会触发 [rtcEngine:didLocalUserRegisteredWithUserId:userAccount:](/zh-CN/api-reference/rtc/ios/channel#callback_irtcengineeventhandler_onlocaluserregistered) 回调，报告本地用户的用户 ID 和 `userAccount`。

:::info[注]

- 请确保 `userAccount` 在频道中唯一。
- 为确保通信顺畅，请统一使用相同的参数类型标识用户。例如，如果某用户使用用户 ID 加入频道，则其他用户也应使用用户 ID；若使用 `userAccount`，则其他用户也应使用 `userAccount`。如果用户使用声网 Web SDK 加入频道，请确保用户 ID 的参数类型一致。
:::

你可以调用该方法设置用户角色为主播或观众。用户角色（`role` ）决定了你在 SDK 层的权限，例如是否可以在频道中发布音视频流。 该方法相比 [setClientRole:](/zh-CN/api-reference/rtc/ios/channel#api_irtcengine_setclientrole1)，支持设置 `audienceLatencyLevel`。你需要将 `audienceLatencyLevel` 与 `role` 搭配使用，以决定你在权限范围内可享受的服务等级。例如，观众可以选择接收低延迟或超低延迟的远端流。 如果你在加入频道前调用该方法将用户角色设置为主播，并通过 [setupLocalVideo:](/zh-CN/api-reference/rtc/ios/video/video-rendering#api_irtcengine_setuplocalvideo) 方法设置本地视频属性，则加入频道时会自动开启本地视频预览。 如果你在加入频道后调用该方法设置用户角色，SDK 会自动调用 [muteLocalAudioStream:](/zh-CN/api-reference/rtc/ios/publishnsubscribe#api_irtcengine_mutelocalaudiostream) 和 [muteLocalVideoStream:](/zh-CN/api-reference/rtc/ios/publishnsubscribe#api_irtcengine_mutelocalvideostream) 方法来改变音视频流的发布状态。

:::info[注]
当用户角色设置为主播时，观众延迟等级只能设置为 `AgoraAudienceLatencyLevelUltraLowLatency`。

- 在加入频道前调用此方法并将 `role` 设置为 `BROADCASTER` 时，本地客户端不会触发 [rtcEngine:didClientRoleChanged:newRole:newRoleOptions:](/zh-CN/api-reference/rtc/ios/channel#callback_irtcengineeventhandler_onclientrolechanged) 回调。
- 在加入频道前调用此方法并将 `role` 设置为 `AUDIENCE` 时，会触发该回调。
:::

### 调用时机 [#api_irtcengine_setclientrole2__timing]

你可以在加入频道前或加入频道后调用此方法。

### 相关回调 [#api_irtcengine_setclientrole2__related]

如果你在加入频道后调用此方法切换用户角色，SDK 会触发以下回调：

- 在本地客户端触发 [rtcEngine:didClientRoleChanged:newRole:newRoleOptions:](/zh-CN/api-reference/rtc/ios/channel#callback_irtcengineeventhandler_onclientrolechanged) 回调。
- 在远端客户端触发 [rtcEngine:didJoinedOfUid:elapsed:](/zh-CN/api-reference/rtc/ios/channel#callback_irtcengineeventhandler_onuserjoined) 或 [rtcEngine:didOfflineOfUid:reason:](/zh-CN/api-reference/rtc/ios/channel#callback_irtcengineeventhandler_onuseroffline) 回调。

如果你在加入频道后调用此方法设置用户角色但失败，SDK 会触发 [rtcEngine:didClientRoleChangeFailed:currentRole:](/zh-CN/api-reference/rtc/ios/channel#callback_irtcengineeventhandler_onclientrolechangefailed) 回调，报告失败原因和当前用户角色。 注意：在加入频道前调用此方法并将 `role` 设置为 `AUDIENCE` 也会触发 [rtcEngine:didClientRoleChanged:newRole:newRoleOptions:](/zh-CN/api-reference/rtc/ios/channel#callback_irtcengineeventhandler_onclientrolechanged) 回调。

:::info[注]
如果你将用户角色设置为观众，则无法在频道中发布音视频流。如果你希望在直播过程中发布媒体流，请确保将用户角色设置为主播。

#### `uid`
