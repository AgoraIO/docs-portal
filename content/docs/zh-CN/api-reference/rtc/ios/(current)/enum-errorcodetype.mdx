## 枚举值

<ParameterList>
<a id="agoraerrorcodenoerror"></a>
<Parameter name="AgoraErrorCodeNoError">

（0）：无错误。

</Parameter>
<a id="agoraerrorcodefailed"></a>
<Parameter name="AgoraErrorCodeFailed">

（1）：通用错误，原因未分类。请重试调用该方法。

</Parameter>
<a id="agoraerrorcodeinvalidargument"></a>
<Parameter name="AgoraErrorCodeInvalidArgument">

（2）：参数无效。例如，频道名包含非法字符。请重新设置参数。

</Parameter>
<a id="agoraerrorcodenotready"></a>
<Parameter name="AgoraErrorCodeNotReady">

（3）：SDK 尚未就绪。可能的原因包括：[AgoraRtcEngineKit](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_irtcengine) 初始化失败；调用方法时无用户加入频道；调用 [rate\:rating\:description:](/zh-CN/api-reference/rtc/ios/network#api_irtcengine_rate) 或 [complain\:description:](/zh-CN/api-reference/rtc/ios/network#api_irtcengine_complain) 方法时用户尚未离开频道；音频模块被禁用；程序不完整。

</Parameter>
<a id="agoraerrorcodenotsupported"></a>
<Parameter name="AgoraErrorCodeNotSupported">

（4）：[AgoraRtcEngineKit](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_irtcengine) 不支持该请求。可能的原因包括：内置加密模式设置错误，或 SDK 加载外部加密库失败。请检查加密模式设置或重新加载外部加密库。

</Parameter>
<a id="agoraerrorcoderefused"></a>
<Parameter name="AgoraErrorCodeRefused">

（5）：请求被拒绝。可能的原因包括：[AgoraRtcEngineKit](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_irtcengine) 初始化失败；加入频道时频道名为空字符串 `""`；调用 [joinChannelExByToken\:connection\:delegate\:mediaOptions\:joinSuccess:](/zh-CN/api-reference/rtc/ios/channel#api_irtcengineex_joinchannelex) 方法加入多个频道时，指定的频道名已被使用。

</Parameter>
<a id="agoraerrorcodebuffertoosmall"></a>
<Parameter name="AgoraErrorCodeBufferTooSmall">

（6）：缓冲区大小不足，无法存储返回数据。

</Parameter>
<a id="agoraerrorcodenotinitialized"></a>
<Parameter name="AgoraErrorCodeNotInitialized">

（7）：在 [AgoraRtcEngineKit](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_irtcengine) 初始化前调用了方法。请确保在调用该方法前已初始化 [AgoraRtcEngineKit](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_irtcengine) 对象。

</Parameter>
<a id="agoraerrorcodeinvalidstate"></a>
<Parameter name="AgoraErrorCodeInvalidState">

（8）：状态无效。

</Parameter>
<a id="agoraerrorcodenopermission"></a>
<Parameter name="AgoraErrorCodeNoPermission">

（9）：无访问权限。请检查应用是否已获得音视频设备的访问权限。

</Parameter>
<a id="agoraerrorcodetimedout"></a>
<Parameter name="AgoraErrorCodeTimedOut">

（10）：超时错误。部分 API 调用需要 SDK 返回执行结果，若超过 10 秒未返回，则触发该错误。

</Parameter>
<a id="agoraerrorcodejoinchannelrejected"></a>
<Parameter name="AgoraErrorCodeJoinChannelRejected">

（17）：加入频道请求被拒绝。可能的原因包括：用户已在频道中。建议通过 connectionChangedToState\:reason: 回调判断用户是否在频道中，除非收到 AgoraConnectionStateDisconnected（1）状态，否则不要调用此方法加入频道；调用 startEchoTestWithConfig: 进行通话测试后，未调用 stopEchoTest 结束测试就尝试加入频道。要加入频道，必须先调用 stopEchoTest 结束测试。

</Parameter>
<a id="agoraerrorcodeleavechannelrejected"></a>
<Parameter name="AgoraErrorCodeLeaveChannelRejected">

（18）：离开频道失败。可能的原因包括：在调用 leaveChannel\:leaveChannelBlock: 方法前用户已离开频道，建议停止调用此方法以清除错误；在加入频道前调用了 leaveChannel\:leaveChannelBlock: 方法，此情况下无需额外操作。

</Parameter>
<a id="agoraerrorcodealreadyinuse"></a>
<Parameter name="AgoraErrorCodeAlreadyInUse">

（19）：资源已被占用。

</Parameter>
<a id="agoraerrorcodeabort"></a>
<Parameter name="AgoraErrorCodeAbort">

（20）：请求被 SDK 放弃，可能是因为请求发送过于频繁。

</Parameter>
<a id="agoraerrorcodeinitnetengine"></a>
<Parameter name="AgoraErrorCodeInitNetEngine">

（21）：由于特定的 Windows 防火墙设置，AgoraRtcEngineKit 初始化失败并崩溃。

</Parameter>
<a id="agoraerrorcoderesourcelimited"></a>
<Parameter name="AgoraErrorCodeResourceLimited">

（22）：由于应用程序使用了过多系统资源或系统资源不足，SDK 分配资源失败。

</Parameter>
<a id="agoraerrorcodeinvalidappid"></a>
<Parameter name="AgoraErrorCodeInvalidAppId">

（101）：指定的 App ID 无效。请使用有效的 App ID 重新加入频道。

</Parameter>
<a id="agoraerrorcodeinvalidchannelid"></a>
<Parameter name="AgoraErrorCodeInvalidChannelId">

（102）：指定的频道名无效。可能的原因是参数类型不正确。请使用有效的频道名重新加入频道。

</Parameter>
<a id="agoraerrorcodenoserverresources"></a>
<Parameter name="AgoraErrorCodeNoServerResources">

（103）：在指定区域无法获取服务器资源。请在调用 sharedEngine 时尝试指定其他区域。

</Parameter>
<a id="agoraerrorcodetokenexpired"></a>
<Parameter name="AgoraErrorCodeTokenExpired">

（109）：当前 Token 已过期。请在服务器上申请新的 Token，并调用 renewToken: 方法。

</Parameter>
<a id="agoraerrorcodeinvalidtoken"></a>
<Parameter name="AgoraErrorCodeInvalidToken">

（110）：Token 无效。常见原因包括：

- 在声网控制台启用了 App 证书，但代码仍使用 App ID 进行鉴权。启用 App 证书后，必须使用 Token 进行鉴权。
- 用于生成 Token 的 uid 与加入频道时使用的 uid 不一致。

</Parameter>
<a id="agoraerrorcodeconnectioninterrupted"></a>
<Parameter name="AgoraErrorCodeConnectionInterrupted">

（111）：网络连接中断。建立连接后，如果 SDK 与服务器失去连接超过 4 秒，会触发此回调。

</Parameter>
<a id="agoraerrorcodeconnectionlost"></a>
<Parameter name="AgoraErrorCodeConnectionLost">

（112）：网络连接丢失。连接中断后，如果 SDK 在 10 秒内无法重新连接到声网边缘服务器，会触发此回调。

</Parameter>
<a id="agoraerrorcodenotinchannel"></a>

</Parameter>
<a id="agoraerrorcodesizetoolarge"></a>

</Parameter>
<a id="agoraerrorcodebitratelimit"></a>
<Parameter name="AgoraErrorCodeBitrateLimit">
