## 枚举值 [#enum_localaudiostreamstate__parameters]

### `AgoraAudioLocalStateStopped`

（0）：本地音频处于初始状态。

### `AgoraAudioLocalStateRecording`

（1）：本地音频采集设备已成功启动。

### `AgoraAudioLocalStateEncoding`

（2）：首帧音频已成功编码。

### `AgoraAudioLocalStateFailed`

（3）：本地音频启动失败。
