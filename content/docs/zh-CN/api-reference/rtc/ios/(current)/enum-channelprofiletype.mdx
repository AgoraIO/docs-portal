## 枚举值 [#enum_channelprofiletype__parameters]

### `AgoraChannelProfileCommunication`

（0）：通信场景。适用于频道中仅有两名用户的场景。

### `AgoraChannelProfileLiveBroadcasting`

（1）：互动直播场景。适用于频道中有两名以上用户的场景。

### `AgoraChannelProfileGame`

（2）：游戏场景。

:::info[注]
该场景已废弃，请改用 `AgoraChannelProfileLiveBroadcasting`。
:::

### `AgoraChannelProfileCloudGaming`

（3）：云游戏场景。对延迟进行了优化，适用于用户之间需要频繁互动的场景。

:::info[注]
该场景已废弃，请改用 `AgoraChannelProfileLiveBroadcasting`。
:::

### `AgoraChannelProfileCommunication_1v1`

（4）：点对点通信场景。

:::info[注]
该场景已废弃，请改用 `AgoraChannelProfileLiveBroadcasting`。
:::
