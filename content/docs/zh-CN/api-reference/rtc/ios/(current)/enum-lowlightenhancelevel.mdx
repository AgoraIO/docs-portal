### `自从` [#enum_lowlightenhancelevel__detailed_desc]

自 v4.0.0 版本新增。

## 枚举值 [#enum_lowlightenhancelevel__parameters]

### `AgoraLowlightEnhanceLevelQuality`

（0）：（默认）在低光增强过程中优先提升视频质量。处理图像的亮度、细节和噪声，性能消耗和处理速度适中，整体视频质量最佳。

### `AgoraLowlightEnhanceLevelFast`

（1）：在低光增强过程中优先提升处理性能。处理图像的亮度和细节，处理速度更快。
