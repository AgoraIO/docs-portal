## 枚举值

### `AgoraMusicContentCenterPreloadStateOK`

（0）：音乐资源加载完成。

### `AgoraMusicContentCenterPreloadStateError`

（1）：音乐资源加载失败。

### `AgoraMusicContentCenterPreloadStatePreloading`

（2）：音乐资源加载中。

### `AgoraMusicContentCenterPreloadStateRemoveCache`

（3）：音乐资源缓存已移除。
