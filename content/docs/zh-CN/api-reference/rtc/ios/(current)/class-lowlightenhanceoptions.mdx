<a id="class_lowlightenhanceoptions__prototype"></a>

```objectivec
__attribute__((visibility("default"))) @interface AgoraLowlightEnhanceOptions : NSObject
@property(nonatomic, assign) AgoraLowlightEnhanceMode mode;
@property(nonatomic, assign) AgoraLowlightEnhanceLevel level;
@end
```

<a id="class_lowlightenhanceoptions__detailed_desc"></a>

用于设置低光增强的模式和强度等级。

<a id="class_lowlightenhanceoptions__parameters"></a>

## 属性

### `mode`

低光增强模式，详见 [AgoraLowlightEnhanceMode](/zh-CN/api-reference/rtc/ios/enum-lowlightenhancemode)。

### `level`

低光增强等级，详见 [AgoraLowlightEnhanceLevel](/zh-CN/api-reference/rtc/ios/enum-lowlightenhancelevel)。
