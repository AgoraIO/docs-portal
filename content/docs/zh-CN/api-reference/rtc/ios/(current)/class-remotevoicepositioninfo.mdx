<a id="class_remotevoicepositioninfo__prototype"></a>

```objectivec
__attribute__((visibility("default"))) @interface AgoraRemoteVoicePositionInfo : NSObject
@property(assign, nonatomic) simd_float3 position;
@property(assign, nonatomic) simd_float3 forward;
@end
```

## 属性 [#class_remotevoicepositioninfo__parameters]

### `position`

世界坐标系中的坐标。该参数是一个长度为 3 的数组，三个值依次表示前方、右方和上方的坐标。

### `forward`

坐标系中 x 轴的单位向量。该参数是一个长度为 3 的数组，三个值依次表示前方、右方和上方的坐标。
