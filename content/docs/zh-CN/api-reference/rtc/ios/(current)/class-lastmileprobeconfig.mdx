## 属性

<ParameterList>
<a id="probeuplink"></a>
<Parameter name="probeUplink">

是否测试上行网络：

- YES：测试上行网络。
- NO：不测试上行网络。例如，在 `LIVE_BROADCASTING` 频道场景中，观众用户无需进行此测试。

</Parameter>
<a id="probedownlink"></a>
<Parameter name="probeDownlink">

是否测试下行网络：

- YES：测试下行网络。
- NO：不测试下行网络。

</Parameter>
<a id="expecteduplinkbitrate"></a>
<Parameter name="expectedUplinkBitrate">

本地用户期望的最大上行码率（bps）。取值范围为 [100000, 5000000]。声网建议参考 `setVideoEncoderConfiguration` 设置该值。

</Parameter>
<a id="expecteddownlinkbitrate"></a>
<Parameter name="expectedDownlinkBitrate">

本地用户期望的最大下行码率（bps）。取值范围为 [100000, 5000000]。

</Parameter>
