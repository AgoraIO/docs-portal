## <span id="toc_image_source"></span>enableVideoImageSource:options: [#api_irtcengine_enablevideoimagesource]

设置在发布视频流时是否用图片替代当前视频画面。

<a id="api_irtcengine_enablevideoimagesource__prototype"></a>

```objectivec
- (int)enableVideoImageSource:(BOOL)enable
                       options:(AgoraImageTrackOptions *_Nullable)options NS_SWIFT_NAME(enableVideoImageSource(_:options:));
```

<a id="api_irtcengine_enablevideoimagesource__detailed_desc"></a>

你可以调用该方法在发布视频流时使用自定义图片替代当前视频画面。启用该功能后，可以通过参数 `options` 设置用于替代的视频图片。禁用该功能后，远端用户将看到你发布的真实视频画面。

### 调用时机 [#api_irtcengine_enablevideoimagesource__timing]

请在加入频道后调用该方法。

### 参数 [#api_irtcengine_enablevideoimagesource__parameters]

#### `enable`

是否用自定义图片替代当前视频画面：

- YES：用自定义图片替代当前视频画面。
- NO：（默认）不替代当前视频画面。

#### `options`

图片配置，详见 [AgoraImageTrackOptions](/zh-CN/api-reference/rtc/ios/class-imagetrackoptions)。

### 返回值 [#api_irtcengine_enablevideoimagesource__return_values]

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/ios/error-code)了解详情和解决建议。
