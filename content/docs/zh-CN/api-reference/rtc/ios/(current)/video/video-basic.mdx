## disableVideo

禁用视频模块。

<a id="api_irtcengine_disablevideo__prototype"></a>

```objectivec
- (int)disableVideo NS_SWIFT_NAME(disableVideo());
```

<a id="api_irtcengine_disablevideo__detailed_desc"></a>

该方法用于禁用视频模块。

:::info[注]
该方法会影响内部引擎，且可在离开频道后调用。调用该方法会重置整个引擎，导致响应时间变慢。你可以根据实际需求，使用以下方法分别控制视频模块的具体功能：

- [enableLocalVideo:](/zh-CN/api-reference/rtc/ios/video/video-basic#api_irtcengine_enablelocalvideo)：是否启用摄像头以创建本地视频流。
- [muteLocalVideoStream:](/zh-CN/api-reference/rtc/ios/publishnsubscribe#api_irtcengine_mutelocalvideostream)：是否发布本地视频流。
- [muteRemoteVideoStream:mute:](/zh-CN/api-reference/rtc/ios/publishnsubscribe#api_irtcengine_muteremotevideostream)：是否订阅并播放远端视频流。
- [muteAllRemoteVideoStreams:](/zh-CN/api-reference/rtc/ios/publishnsubscribe#api_irtcengine_muteallremotevideostreams)：是否订阅并播放所有远端视频流。
:::

<a id="api_irtcengine_disablevideo__timing"></a>

### 调用时机

该方法可在加入频道前或加入频道后调用。

- 如果在加入频道前调用，则进入语音通话模式。
- 如果在加入频道后调用，则从视频通话模式切换为语音通话模式。之后调用 [enableVideo](/zh-CN/api-reference/rtc/ios/video/video-basic#api_irtcengine_enablevideo) 可重新切换为视频通话模式。

<a id="api_irtcengine_disablevideo__related"></a>

### 相关回调

成功调用该方法后，远端会触发 [rtcEngine:didVideoEnabled:byUid:](/zh-CN/api-reference/rtc/ios/video/video-basic#callback_irtcengineeventhandler_onuserenablevideo) （NO ）回调。

<a id="api_irtcengine_disablevideo__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/ios/error-code)了解详情和解决建议。

## enableLocalVideo:

启用或关闭本地视频采集。

<a id="api_irtcengine_enablelocalvideo__prototype"></a>

```objectivec
- (int)enableLocalVideo:(BOOL)enabled NS_SWIFT_NAME(enableLocalVideo(_:));
```

<a id="api_irtcengine_enablelocalvideo__detailed_desc"></a>

该方法用于关闭或重新开启本地视频采集，不影响接收远端视频流。调用 [enableVideo](/zh-CN/api-reference/rtc/ios/video/video-basic#api_irtcengine_enablevideo) 后，默认开启本地视频采集。如果你在频道内调用 [enableLocalVideo:](/zh-CN/api-reference/rtc/ios/video/video-basic#api_irtcengine_enablelocalvideo) 传入 NO 关闭本地视频采集，同时会停止在频道内发布视频流。若需重新开启视频采集，你可以调用 [enableLocalVideo:](/zh-CN/api-reference/rtc/ios/video/video-basic#api_irtcengine_enablelocalvideo) 传入 YES，然后调用 [updateChannelWithMediaOptions:](/zh-CN/api-reference/rtc/ios/channel#api_irtcengine_updatechannelmediaoptions) 并设置 `options` 参数，以在频道内发布本地采集的视频流。

:::info[注]
- 你可以在加入频道前或加入频道后调用该方法。但如果在加入频道前调用，设置仅在加入频道后生效。
- 该方法会启用内部引擎，离开频道后仍然有效。
:::

<a id="api_irtcengine_enablelocalvideo__parameters"></a>

### 参数

#### `enabled`

是否启用本地视频采集。

- YES：（默认）启用本地视频采集。
- NO：关闭本地视频采集。关闭后，远端用户无法接收你的本地视频流，但你仍可接收远端用户的视频流。设置为 NO 时，无需本地摄像头。

<a id="api_irtcengine_enablelocalvideo__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/ios/error-code)了解详情和解决建议。

### 所属接口类
- [AgoraRtcEngineKit](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_irtcengine)

## enableVideo

启用视频模块。

<a id="api_irtcengine_enablevideo__prototype"></a>

```objectivec
- (int)enableVideo NS_SWIFT_NAME(enableVideo());
```

<a id="api_irtcengine_enablevideo__detailed_desc"></a>

默认情况下视频模块处于关闭状态，调用该方法可启用视频模块。如果需要关闭视频模块，需要调用 [disableVideo](/zh-CN/api-reference/rtc/ios/video/video-basic#api_irtcengine_disablevideo) 方法。 该方法可以在加入频道前或加入频道后调用：

- 如果在加入频道前调用，则启用视频模块。
- 如果在语音通话过程中调用，则语音通话会自动切换为视频通话。

:::info[注]
该方法启用内部引擎，离开频道后仍然有效。 调用该方法会重置整个引擎，导致响应时间变慢。你可以根据实际需求，使用以下方法分别控制视频模块的具体功能：

- [enableLocalVideo:](/zh-CN/api-reference/rtc/ios/video/video-basic#api_irtcengine_enablelocalvideo)：是否启用摄像头以创建本地视频流。
- [muteLocalVideoStream:](/zh-CN/api-reference/rtc/ios/publishnsubscribe#api_irtcengine_mutelocalvideostream)：是否发布本地视频流。
- [muteRemoteVideoStream:mute:](/zh-CN/api-reference/rtc/ios/publishnsubscribe#api_irtcengine_muteremotevideostream)：是否订阅并播放远端视频流。
- [muteAllRemoteVideoStreams:](/zh-CN/api-reference/rtc/ios/publishnsubscribe#api_irtcengine_muteallremotevideostreams)：是否订阅并播放所有远端视频流。

成功调用该方法会重置 [enableLocalVideo:](/zh-CN/api-reference/rtc/ios/video/video-basic#api_irtcengine_enablelocalvideo)、 [muteRemoteVideoStream:mute:](/zh-CN/api-reference/rtc/ios/publishnsubscribe#api_irtcengine_muteremotevideostream) 和 [muteAllRemoteVideoStreams:](/zh-CN/api-reference/rtc/ios/publishnsubscribe#api_irtcengine_muteallremotevideostreams)，请谨慎使用。
:::

<a id="api_irtcengine_enablevideo__timing"></a>

### 调用时机

该方法可以在加入频道前或加入频道后调用。

## setVideoEncoderConfiguration:

设置本地视频的编码配置。

<a id="api_irtcengine_setvideoencoderconfiguration__prototype"></a>

```objectivec
- (int)setVideoEncoderConfiguration:(AgoraVideoEncoderConfiguration * _Nonnull)config NS_SWIFT_NAME(setVideoEncoderConfiguration(_:));
```

<a id="api_irtcengine_setvideoencoderconfiguration__detailed_desc"></a>

设置本地视频的编码配置。每个配置文件对应一组视频参数，包括分辨率、帧率和码率。

:::info[注]
- 此方法和 [getMirrorApplied](/zh-CN/api-reference/rtc/ios/video/video-raw#api_ivideoframeobserver_getmirrorapplied) 方法都支持设置镜像效果。声网建议你只使用其中一种方法进行设置，同时使用会导致镜像效果叠加，设置失败。
- 此方法中指定的 `config` 是在理想网络条件下的最大值。如果由于网络不稳定，视频引擎无法使用指定的 `config` 渲染视频，则会依次尝试列表中更低的参数，直到找到可用的配置。
:::

<a id="api_irtcengine_setvideoencoderconfiguration__timing"></a>

### 调用时机

你可以在加入频道前或后调用此方法。如果你在加入频道后不需要重新设置视频编码属性，声网建议你在调用 [enableVideo](/zh-CN/api-reference/rtc/ios/video/video-basic#api_irtcengine_enablevideo) 之前调用此方法，以减少首帧视频渲染时间。

<a id="api_irtcengine_setvideoencoderconfiguration__parameters"></a>

### 参数

#### `config`

视频配置参数。详见 [AgoraVideoEncoderConfiguration](/zh-CN/api-reference/rtc/ios/class-videoencoderconfiguration)。

## setVideoResolution:andFrameRate:bitrate:

手动设置视频编码配置。

<a id="api_irtcengine_setvideoprofile2__prototype"></a>

```objectivec
- (int)setVideoResolution:(CGSize)size andFrameRate:(NSInteger)frameRate bitrate:(NSInteger)bitrate NS_SWIFT_NAME(setVideoResolution(_:andFrameRate:bitrate:)) __deprecated_msg("use setVideoEncoderConfiguration: instead.");
```

<a id="api_irtcengine_setvideoprofile2__detailed_desc"></a>

#### `废弃`

自 v2.3 版本废弃，请改用 [setVideoEncoderConfiguration:](/zh-CN/api-reference/rtc/ios/video/video-basic#api_irtcengine_setvideoencoderconfiguration)。

<a id="api_irtcengine_setvideoprofile2__parameters"></a>

### 参数

#### `size`

你想要设置的视频尺寸。最大值为 1280 × 720。

#### `frameRate`

你想要设置的视频帧率。最大值为 30。你可以设置为 5、10、15、24、30 等。

#### `bitrate`

你想要设置的视频码率。你需要根据宽度、高度和帧率手动计算码率。在相同宽高下，码率会随着帧率的变化而变化：

- 如果帧率为 5 fps，推荐码率除以 2。
- 如果帧率为 15 fps，使用推荐码率。
- 如果帧率为 30 fps，推荐码率乘以 1.5。
- 如果选择其他帧率，请按比例计算码率。

例如，分辨率为 320 × 240，帧率为 15 fps，则码率为 200：

- 如果帧率为 5 fps，码率为 100。
- 如果帧率为 30 fps，码率为 300。

如果你设置的码率超出合理范围，SDK 会自动将其调整到范围内的值。

<a id="api_irtcengine_setvideoprofile2__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/ios/error-code)了解详情和解决建议。

## setVideoScenario:

设置视频应用场景。

<a id="api_irtcengine_setvideoscenario__prototype"></a>

```objectivec
- (int)setVideoScenario:(AgoraApplicationScenarioType)scenarioType  NS_SWIFT_NAME(setVideoScenario(_:));
```

<a id="api_irtcengine_setvideoscenario__detailed_desc"></a>

#### `自从`

自 v4.2.0 版本新增。

调用该方法后，SDK 会根据指定的视频应用场景自动启用最佳实践策略，并调整关键性能指标，以优化视频体验。

:::info[注]
请在加入频道前调用该方法。
:::

<a id="api_irtcengine_setvideoscenario__parameters"></a>

### 参数

#### `scenarioType`

视频应用场景的类型，详见 [AgoraApplicationScenarioType](/zh-CN/api-reference/rtc/ios/enum-videoapplicationscenariotype)。

- `AgoraApplicationMeetingScenario` （1）：适用于会议场景。SDK 会自动启用以下策略：

  - 若低画质视频流需要较高码率，SDK 会自动启用多种应对网络拥塞的技术，以增强低画质视频流的性能，确保订阅端的流畅接收。
  - SDK 实时监控高画质视频流的订阅人数，并根据订阅人数动态调整其配置：

    - 若无人订阅高画质视频流，SDK 会自动降低其码率和帧率以节省上行带宽。
    - 若有人订阅高画质视频流，SDK 会将其重置为最近一次调用 [setVideoEncoderConfiguration:](/zh-CN/api-reference/rtc/ios/video/video-basic#api_irtcengine_setvideoencoderconfiguration) 所设置的配置。如果你未设置过配置，则使用以下默认值：

      - iOS：

        - 分辨率：960 × 540。
        - 帧率：15 fps。
        - 码率：1000 Kbps。
      - macOS：

        - 分辨率：1280 × 720。
        - 帧率：15 fps。
        - 码率：1600 Kbps。
  - SDK 实时监控低画质视频流的订阅人数，并根据订阅人数动态启用或禁用该流。

    - 若无人订阅低画质视频流，SDK 会自动禁用该流以节省上行带宽。
    - 若有人订阅低画质视频流，SDK 会启用该流，并将其重置为最近一次调用 [setDualStreamMode:streamConfig:](/zh-CN/api-reference/rtc/ios/publishnsubscribe#api_irtcengine_setdualstreammode2) 所设置的配置。如果你未设置过配置，则使用以下默认值：

      - 分辨率：480 × 272。
      - 帧率：15 fps。
      - 码率：500 Kbps。
    - 注意：如果你调用了 [setDualStreamMode:streamConfig:](/zh-CN/api-reference/rtc/ios/publishnsubscribe#api_irtcengine_setdualstreammode2) 并设置为永不发送低画质视频流（`AgoraDisableSimulcastStream` ），则会议场景下低画质流的动态调整将不生效。

- `AgoraApplication1V1Scenario` （2）：适用于一对一直播场景。为满足该场景下低延迟和高画质的需求，SDK 会优化策略，提升视频质量、首帧渲染速度、中低端设备的延迟表现，以及弱网环境下的流畅度。

注意：该枚举值仅适用于主播对主播的场景。

- `AgoraApplicationLiveShowScenario` （3）：适用于秀场场景。在该场景中，快速的视频渲染和高画质至关重要。SDK 会进行多项性能优化，包括自动启用音视频帧加速渲染以最小化首帧延迟（无需调用 [enableInstantMediaRendering](/zh-CN/api-reference/rtc/ios/video/video-rendering#api_irtcengine_enableinstantmediarendering) ），以及启用 B 帧编码以提升图像质量和带宽效率。即使在网络较差或低端设备上，SDK 也能提供增强的视频质量和流畅的播放体验。

<a id="api_irtcengine_setvideoscenario__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/ios/error-code)了解详情和解决建议。

  - -1：发生通用错误（无具体原因）。
  - -4：不支持设置视频应用场景。可能原因包括你使用了语音 SDK 而非视频 SDK。
  - -7： [AgoraRtcEngineKit](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_irtcengine) 对象尚未初始化。请在调用该方法前先初始化该对象。

## rtcEngine:localVideoStateChangedOfState:reason:sourceType:

<a id="callback_irtcengineeventhandler_onlocalvideostatechanged__prototype"></a>


<a id="callback_irtcengineeventhandler_onlocalvideostatechanged__detailed_desc"></a>

当本地视频状态发生变化时，SDK 会触发该回调，报告当前本地视频状态及其变化原因。你可以通过该回调及时了解本地视频流的状态变化，并根据变化原因采取相应措施，以更好地管理和排查视频流相关问题。

:::info[注]
请注意，视频帧重复检测仅适用于分辨率大于 200 × 200、帧率大于等于 10 fps 且码率小于 20 Kbps 的视频帧。通常情况下，如果视频采集出现错误，可以通过该回调中的 `reason` 参数排查问题。但在某些设备上，当采集出现问题（如卡顿）时，Android 系统不会抛出任何错误回调，SDK 也无法上报本地视频状态变化的原因。此时，你可以通过以下方式判断是否未采集到视频帧：该回调上报的 `state` 为 `AgoraVideoLocalStateCapturing` 或 `AgoraVideoLocalStateEncoding`，且 [rtcEngine:localVideoStats:sourceType:](/zh-CN/api-reference/rtc/ios/video/video-basic#callback_irtcengineeventhandler_onlocalvideostats) 回调中的 `captureFrameRate` 为 0。
:::

<a id="callback_irtcengineeventhandler_onlocalvideostatechanged__timing"></a>

### 触发时机

该回调在以下情况下被触发， `state` 为 `AgoraVideoLocalStateFailed`， `reason` 为 `AgoraLocalVideoStreamReasonCaptureFailure`：

- 应用切换到后台，系统回收了摄像头资源。
- 摄像头正常启动，但连续四秒未输出视频帧。

当摄像头输出采集的视频帧时，若 SDK 检测到连续 15 帧重复帧，也会触发该回调， `state` 为 `AgoraVideoLocalStateCapturing`， `reason` 为 `AgoraLocalVideoStreamReasonCaptureFailure`。

<a id="callback_irtcengineeventhandler_onuserenablevideo__detailed_desc"></a>

<a id="callback_irtcengineeventhandler_onuserenablevideo__timing"></a>

#### `engine`

#### `enabled`

#### `uid`

远端用户 ID。

## rtcEngine:didVideoMuted:byUid:

远端用户停止或恢复发布视频流时触发的回调。

<a id="callback_irtcengineeventhandler_onusermutevideo__prototype"></a>

```objectivec
- (void)rtcEngine:(AgoraRtcEngineKit * _Nonnull)engine didVideoMuted:(BOOL)muted byUid:(NSUInteger)uid NS_SWIFT_NAME(rtcEngine(_:didVideoMuted:byUid:));
```

<a id="callback_irtcengineeventhandler_onusermutevideo__detailed_desc"></a>

当远端用户调用 [muteLocalVideoStream:](/zh-CN/api-reference/rtc/ios/publishnsubscribe#api_irtcengine_mutelocalvideostream) 方法停止或恢复发布视频流时，SDK 会触发该回调，报告远端用户的视频流状态。

:::info[注]
当通信场景中的用户数或直播场景中的主播数超过 32 时，该回调可能不准确。
:::

<a id="callback_irtcengineeventhandler_onusermutevideo__timing"></a>

#### `engine`

[AgoraRtcEngineKit](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_irtcengine) 对象。详见 [AgoraRtcEngineKit](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_irtcengine)。

#### `muted`

远端用户是否停止发布视频流：

- NO：远端用户恢复发布视频流。
