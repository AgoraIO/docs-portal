<a id="greencapacity"></a>
<Parameter name="greenCapacity">

识别图像中背景纯色的精度范围。取值范围为 [0,1]，默认值为 0.5。值越大，可识别的纯色色阶范围越广。当该值过大时，可能会将人物边缘或人物区域内的纯色误识别为背景。声网建议你根据实际效果动态调整该参数的值。

:::note
注： 仅当 `modelType` 设置为 `SegModelAgoraGreen` 时该参数才生效。
:::
