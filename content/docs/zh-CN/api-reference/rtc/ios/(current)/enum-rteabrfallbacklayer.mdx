<a id="enum_rteabrfallbacklayer__detailed_desc"></a>

:::info[自从]
自 v4.4.0 版本新增。
:::

:::note
注： 要使用 `AgoraRteAbrFallbackLayer1` 到 `AgoraRteAbrFallbackLayer6`，需[联系技术支持](https://ticket.shengwang.cn/)开启 ABR 功能。开启后，你可以自定义每一层的分辨率，并选择任意一层作为视频流回退的最低分辨率。当网络状况较差时，SDK 会以该分辨率为下限，并根据网络状况在该范围内动态调整分辨率。自定义分辨率时，请确保按分辨率从高到低的顺序排列视频质量层；若分辨率相同，则按帧率从高到低排序。
:::

<a id="enum_rteabrfallbacklayer__parameters"></a>

## 枚举值

<ParameterList>
<a id="agorarteabrfallbackdisabled"></a>
<Parameter name="AgoraRteAbrFallbackDisabled">

（0）：不对音视频流进行回退处理，但无法保证音视频流质量。

</Parameter>
<a id="agorarteabrfallbacklow"></a>
<Parameter name="AgoraRteAbrFallbackLow">

（1）：（默认）回退至视频小流。该层具有最低分辨率。

</Parameter>
<a id="agorarteabrfallbackaudioonly"></a>
<Parameter name="AgoraRteAbrFallbackAudioOnly">

（2）：优先接收视频小流；若因网络状况差无法显示视频，则回退为仅接收已订阅的远端音频流。

</Parameter>
<a id="agorarteabrfallbacklayer1"></a>
<Parameter name="AgoraRteAbrFallbackLayer1">

（3）：回退至视频质量层级 1。该层的分辨率和码率仅低于所订阅的最高质量多层视频流。

</Parameter>
<a id="agorarteabrfallbacklayer2"></a>
<Parameter name="AgoraRteAbrFallbackLayer2">

（4）：回退至视频质量层级 2。该层的分辨率仅低于层级 1。

</Parameter>
<a id="agorarteabrfallbacklayer3"></a>
<Parameter name="AgoraRteAbrFallbackLayer3">

（5）：回退至视频质量层级 3。该层的分辨率仅低于层级 2。

</Parameter>
<a id="agorarteabrfallbacklayer4"></a>
<Parameter name="AgoraRteAbrFallbackLayer4">

（6）：回退至视频质量层级 4。该层的分辨率仅低于层级 3。

</Parameter>
<a id="agorarteabrfallbacklayer5"></a>
<Parameter name="AgoraRteAbrFallbackLayer5">

（7）：回退至视频质量层级 5。该层的分辨率仅低于层级 4。

</Parameter>
<a id="agorarteabrfallbacklayer6"></a>
<Parameter name="AgoraRteAbrFallbackLayer6">

（8）：回退至视频质量层级 6。该层的分辨率仅低于层级 5。

</Parameter>
</ParameterList>
