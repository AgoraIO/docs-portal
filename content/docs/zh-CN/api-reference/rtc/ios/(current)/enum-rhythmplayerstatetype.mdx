## 枚举值 [#enum_rhythmplayerstatetype__parameters]

### `AgoraRhythmPlayerStateIdle`

（810）：虚拟节拍器未启用或已被禁用。

### `AgoraRhythmPlayerStateOpening`

（811）：正在打开节拍文件。

### `AgoraRhythmPlayerStateDecoding`

（812）：正在解码节拍文件。

### `AgoraRhythmPlayerStatePlaying`

（813）：正在播放节拍文件。

### `AgoraRhythmPlayerStateFailed`

（814）：虚拟节拍器启动失败。你可以使用返回的 `errorCode` 排查错误原因，或尝试重新启动虚拟节拍器。
