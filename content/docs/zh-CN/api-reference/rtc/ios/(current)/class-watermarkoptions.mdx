<a id="class_watermarkoptions__detailed_desc"></a>

用于设置水印图像的显示配置。

<a id="class_watermarkoptions__parameters"></a>

## 属性

<ParameterList>
<a id="visibleinpreview"></a>
<Parameter name="visibleInPreview">

水印图像是否在本地预览视图中可见：

- YES：（默认）水印在本地预览视图中可见。
- NO：水印在本地预览视图中不可见。

</Parameter>
<a id="positioninlandscapemode"></a>
<Parameter name="positionInLandscapeMode">

横屏模式下水印图像的显示区域，包含以下成员：

- x：水印相对于左上角的水平位置。
- y：水印相对于左上角的垂直位置。
- width：水印区域的宽度（像素）。
- height：水印区域的高度（像素）。

</Parameter>
<a id="positioninportraitmode"></a>
<Parameter name="positionInPortraitMode">

竖屏模式下水印图像的显示区域，包含以下成员：

- x：水印相对于左上角的水平位置。
- y：水印相对于左上角的垂直位置。
- width：水印区域的宽度（像素）。
- height：水印区域的高度（像素）。

</Parameter>
<a id="zorder"></a>
<Parameter name="zOrder">

水印图像的图层顺序，默认值为 0。

</Parameter>
</ParameterList>
