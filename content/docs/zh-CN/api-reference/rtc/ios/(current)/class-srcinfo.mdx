<a id="class_srcinfo__prototype"></a>

```objectivec
__attribute__((visibility("default"))) @interface AgoraMediaPlayerSrcInfo : NSObject
@property(assign, nonatomic) int bitrateInKbps;
@property(copy, nonatomic) NSString *_Nullable name;
@end
```

## 属性 [#class_srcinfo__parameters]

### `bitrateInKbps`

正在播放的媒体资源的视频码率，单位为 Kbps。

### `name`

媒体资源的名称。
