---
title: "AgoraVideoFrameOrientation"
description: "视频画面的顺时针旋转角度。"
---

## 枚举值 [#enum_videoorientation__parameters]

### `AgoraVideoFrameOrientation0`

（0）：（默认）不旋转。

### `AgoraVideoFrameOrientation90`

（90）：顺时针旋转 90 度。

### `AgoraVideoFrameOrientation180`

（180）：顺时针旋转 180 度。

### `AgoraVideoFrameOrientation270`

（270）：顺时针旋转 270 度。
