<a id="enum_qualityadaptindication__parameters"></a>

## 枚举值

### `AgoraVideoQualityAdaptNone`

（0）：本地视频质量无变化。

### `AgoraVideoQualityAdaptUpBandwidth`

（1）：网络带宽增加，导致本地视频质量提升。

### `AgoraVideoQualityAdaptDownBandwidth`

（2）：网络带宽下降，导致本地视频质量下降。
