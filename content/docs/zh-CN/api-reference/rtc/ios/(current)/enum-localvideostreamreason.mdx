<a id="enum_localvideostreamreason__parameters"></a>

## 枚举值

<ParameterList>
<a id="agoralocalvideostreamreasonok"></a>
<Parameter name="AgoraLocalVideoStreamReasonOK">

（0）：本地视频状态正常。

</Parameter>
<a id="agoralocalvideostreamreasonfailure"></a>
<Parameter name="AgoraLocalVideoStreamReasonFailure">

（1）：本地视频失败，原因不明确。

</Parameter>
<a id="agoralocalvideostreamreasondevicenopermission"></a>
<Parameter name="AgoraLocalVideoStreamReasonDeviceNoPermission">

（2）：无权限使用本地视频采集设备。请提示用户授予权限并重新加入频道。

</Parameter>
<a id="agoralocalvideostreamreasondevicebusy"></a>
<Parameter name="AgoraLocalVideoStreamReasonDeviceBusy">

（3）：本地视频采集设备被占用。请提示用户检查摄像头是否被其他 App 占用，或尝试重新加入频道。

</Parameter>
<a id="agoralocalvideostreamreasoncapturefailure"></a>
<Parameter name="AgoraLocalVideoStreamReasonCaptureFailure">

（4）：本地视频采集失败。请提示用户检查视频采集设备是否正常工作，摄像头是否被其他 App 占用，或尝试重新加入频道。

</Parameter>
<a id="agoralocalvideostreamreasoncodecnotsupport"></a>
<Parameter name="AgoraLocalVideoStreamReasonCodecNotSupport">

（5）：本地视频编码失败。

</Parameter>
<a id="agoralocalvideostreamreasoncaptureinbackground"></a>
<Parameter name="AgoraLocalVideoStreamReasonCaptureInBackGround">

（6）：（仅适用于 iOS 平台）App 处于后台运行状态，无法正常进行视频采集。请提示用户切换至前台。

</Parameter>
<a id="agoralocalvideostreamreasoncapturemultipleforegroundapps"></a>
<Parameter name="AgoraLocalVideoStreamReasonCaptureMultipleForegroundApps">

（7）：（仅适用于 iOS 平台）App 处于 Slide Over、Split View 或画中画模式，且摄像头被其他 App 占用，无法正常进行视频采集。请提示用户退出上述模式。

</Parameter>
<a id="agoralocalvideostreamreasoncapturenodevicefound"></a>
<Parameter name="AgoraLocalVideoStreamReasonCaptureNoDeviceFound">

（8）：SDK 无法找到本地视频采集设备。请检查摄像头是否连接正常、是否正常工作，或尝试重新加入频道。

</Parameter>
<a id="agoralocalvideostreamreasoncapturedevicedisconnected"></a>
<Parameter name="AgoraLocalVideoStreamReasonCaptureDeviceDisconnected">

（9）：（仅适用于 macOS 平台）当前使用的视频采集设备已断开连接（如被拔出）。

</Parameter>
<a id="agoralocalvideostreamreasoncapturedeviceinvalidid"></a>
<Parameter name="AgoraLocalVideoStreamReasonCaptureDeviceInvalidId">

（10）：（仅适用于 macOS 平台）SDK 无法在视频设备列表中找到该设备。请检查视频设备 ID 是否有效。

</Parameter>
<a id="agoralocalvideostreamreasonscreencapturewindowminimized"></a>
<Parameter name="AgoraLocalVideoStreamReasonScreenCaptureWindowMinimized">

（11）：（仅适用于 macOS 平台）调用 `startScreenCaptureByWindowId:regionRect:captureParams:` 方法共享窗口时，被共享窗口已最小化，无法进行共享。请提示用户取消最小化该窗口。

</Parameter>
<a id="agoralocalvideostreamreasonscreencapturewindowclosed"></a>
<Parameter name="AgoraLocalVideoStreamReasonScreenCaptureWindowClosed">

（12）：（仅适用于 macOS 平台）被共享的窗口已关闭，或全屏窗口退出了全屏模式，远端用户将无法看到共享内容。为避免黑屏，建议立即停止屏幕共享。常见场景包括：

- 本地用户关闭共享窗口；
- 本地用户先全屏播放幻灯片再共享该窗口，退出全屏后触发该错误码；
- 本地用户先全屏观看网页视频或文档再共享该窗口，退出全屏后触发该错误码。

</Parameter>
<a id="agoralocalvideostreamreasonscreencapturenopermission"></a>
<Parameter name="AgoraLocalVideoStreamReasonScreenCaptureNoPermission">

（22）：无屏幕采集权限。

</Parameter>
<a id="agoralocalvideostreamreasonscreencapturerecoverfromminimized"></a>
<Parameter name="AgoraLocalVideoStreamReasonScreenCaptureRecoverFromMinimized">

（27）：（仅适用于 macOS 平台）屏幕采集的窗口已从最小化状态恢复。

</Parameter>
<a id="agoralocalvideostreamreasonscreencapturedisplaydisconnected"></a>
<Parameter name="AgoraLocalVideoStreamReasonScreenCaptureDisplayDisconnected">

（30）：（仅适用于 macOS 平台）用于屏幕采集的显示器已断开连接，当前屏幕共享已暂停。请提示用户重新开始屏幕共享。

</Parameter>
</ParameterList>
