## 枚举值

### `AgoraCodecMaskNone`

（0）：设备不支持编码和解码。

### `AgoraCodecMaskHwDec`

（1）：设备支持硬件解码。

### `AgoraCodecMaskHwEnc`

（2）：设备支持硬件编码。

### `AgoraCodecMaskSwDec`

（4）：设备支持软件解码。

### `AgoraCodecMaskSwEnc`

（8）：设备支持软件编码。
