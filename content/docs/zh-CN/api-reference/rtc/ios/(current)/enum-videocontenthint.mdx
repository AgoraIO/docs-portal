## 枚举值

### AgoraVideoContentHintNone

（0）：（默认）无内容提示。

### AgoraVideoContentHintMotion

（1）：运动内容。适用于注重流畅性或共享视频片段、电影或视频游戏的场景。

### AgoraVideoContentHintDetails

（2）：静态内容。适用于注重清晰度或共享图片、PPT 幻灯片或文本的场景。
