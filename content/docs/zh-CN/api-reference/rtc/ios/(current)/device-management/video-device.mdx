## <span id="toc_video_device"></span>enableMultiCamera:config: [#api_irtcengine_enablemulticamera]

启用或关闭多摄像头采集模式。

<a id="api_irtcengine_enablemulticamera__prototype"></a>

```objectivec
- (int)enableMultiCamera:(BOOL)enabled config:(AgoraCameraCapturerConfiguration* _Nullable)config NS_SWIFT_NAME(enableMultiCamera(_:config:));
```

<a id="api_irtcengine_enablemulticamera__detailed_desc"></a>

声网建议你在已有摄像头用于视频采集的场景中，按照以下步骤使用多摄像头进行视频采集和发布：

1. 调用该方法启用多摄像头采集模式。
2. 调用 [startPreview:](/zh-CN/api-reference/rtc/ios/video/video-basic#api_irtcengine_startpreview2) 启动本地视频预览。
3. 调用 [startCameraCapture:config:](/zh-CN/api-reference/rtc/ios/video/camera-capture#api_irtcengine_startcameracapture)，并设置 `sourceType` 以使用第二个摄像头进行视频采集。
4. 调用 [joinChannelExByToken:connection:delegate:mediaOptions:joinSuccess:](/zh-CN/api-reference/rtc/ios/channel#api_irtcengineex_joinchannelex)，并将 `publishSecondaryCameraTrack` 设置为 YES，以在频道中发布第二个摄像头采集的视频流。

如果你想关闭多摄像头采集模式，请按以下步骤操作：

1. 调用 [stopCameraCapture:](/zh-CN/api-reference/rtc/ios/video/camera-capture#api_irtcengine_stopcameracapture)。
2. 调用该方法并将 `enabled` 设置为 NO。

使用该功能时，请确保系统版本为 iOS 13.0 或更高。 支持多摄像头采集的最低 iOS 设备型号如下：

- iPhone XR
- iPhone XS
- iPhone XS Max
- iPad Pro 第三代及更新机型

:::info[注]
你可以在调用 [startPreview:](/zh-CN/api-reference/rtc/ios/video/video-basic#api_irtcengine_startpreview2) 之前或之后调用该方法启用多摄像头采集：

- 如果在 [startPreview:](/zh-CN/api-reference/rtc/ios/video/video-basic#api_irtcengine_startpreview2) 之前启用，本地视频预览会同时显示两个摄像头采集的画面。
- 如果在 [startPreview:](/zh-CN/api-reference/rtc/ios/video/video-basic#api_irtcengine_startpreview2) 之后启用，SDK 会先停止当前摄像头采集，然后启用主摄像头和第二个摄像头。本地视频预览会短暂变黑，然后自动恢复正常。
:::

### 参数 [#api_irtcengine_enablemulticamera__parameters]

#### `enabled`

是否启用多摄像头视频采集模式：

- YES：启用多摄像头采集模式，SDK 使用多个摄像头进行视频采集。
- NO：关闭多摄像头采集模式，SDK 使用单个摄像头进行视频采集。

#### `config`

第二个摄像头的采集配置。详见 [AgoraCameraCapturerConfiguration](/zh-CN/api-reference/rtc/ios/class-cameracapturerconfiguration)。

### 返回值 [#api_irtcengine_enablemulticamera__return_values]

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/ios/error-code)了解详情和解决建议。

- [AgoraRtcEngineKit](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_irtcengine)

## setCameraExposureFactor: [#api_irtcengine_setcameraexposurefactor]

设置摄像头曝光值。

<a id="api_irtcengine_setcameraexposurefactor__prototype"></a>

```objectivec
- (CGFloat)setCameraExposureFactor:(CGFloat)exposureFactor NS_SWIFT_NAME(setCameraExposureFactor(_:));
```

#### `自从` [#api_irtcengine_setcameraexposurefactor__detailed_desc]

自 v4.2.2 版本新增。

你可以通过此方法调整摄像头的曝光值，以获得最佳的视频质量。

:::info[注]
- 你必须在调用 [enableVideo](/zh-CN/api-reference/rtc/ios/video/video-basic#api_irtcengine_enablevideo) 方法之后再调用此方法。设置结果在摄像头成功开启后生效，即 SDK 触发 [rtcEngine:localVideoStateChangedOfState:reason:sourceType:](/zh-CN/api-reference/rtc/ios/video/video-basic#callback_irtcengineeventhandler_onlocalvideostatechanged) 回调并返回本地视频状态为 `AgoraVideoLocalStateCapturing` （1）后。
- 在调用此方法前，建议你调用 [isCameraExposureSupported](/zh-CN/api-reference/rtc/ios/device-management/video-device#api_irtcengine_iscameraexposuresupported) 方法检查当前摄像头是否支持调整曝光值。
- 该方法调整的是当前正在使用的摄像头的曝光值，即调用 [setCameraCapturerConfiguration:](/zh-CN/api-reference/rtc/ios/device-management/video-device#api_irtcengine_setcameracapturerconfiguration) 方法时指定的摄像头。
:::

### 参数 [#api_irtcengine_setcameraexposurefactor__parameters]

#### `exposureFactor`

摄像头曝光值（默认值为 0）。值越大，曝光越强。当视频图像过曝时，可以降低曝光值；当视频图像曝光不足且暗部细节丢失时，可以提高曝光值。如果设置的曝光值超出设备支持的范围，SDK 会自动将其调整为设备实际支持的范围。取值范围为 [-8.0, 8.0]。

### 返回值 [#api_irtcengine_setcameraexposurefactor__return_values]

无实际意义。

- [AgoraRtcEngineKit](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_irtcengine)

## setCameraZoomFactor: [#api_irtcengine_setcamerazoomfactor]

设置摄像头的缩放因子。

<a id="api_irtcengine_setcamerazoomfactor__prototype"></a>

```objectivec
- (CGFloat)setCameraZoomFactor:(CGFloat)zoomFactor NS_SWIFT_NAME(setCameraZoomFactor(_:));
```

<a id="api_irtcengine_setcamerazoomfactor__detailed_desc"></a>

你可以调用 [setCameraCapturerConfiguration:](/zh-CN/api-reference/rtc/ios/device-management/video-device#api_irtcengine_setcameracapturerconfiguration) 方法，将 `cameraFocalLengthType` 设置为 `AgoraFocalLengthDefault` （0），然后将摄像头缩放因子设置为小于 1.0 的值，以实现超广角视角的视频采集。该方法适用于配备多镜头后置摄像头的 iOS 设备，例如配有广角、超广角和长焦镜头的设备。

:::info[注]
你必须在调用 [enableVideo](/zh-CN/api-reference/rtc/ios/video/video-basic#api_irtcengine_enablevideo) 之后再调用此方法。设置结果将在摄像头成功开启后生效，即 SDK 触发 [rtcEngine:localVideoStateChangedOfState:reason:sourceType:](/zh-CN/api-reference/rtc/ios/video/video-basic#callback_irtcengineeventhandler_onlocalvideostatechanged) 回调并返回本地视频状态为 `AgoraVideoLocalStateCapturing` （1）之后。
:::

### 参数 [#api_irtcengine_setcamerazoomfactor__parameters]

#### `zoomFactor`

摄像头缩放因子。对于不支持超广角的设备，该值范围为 1.0 到最大缩放因子；对于支持超广角的设备，该值范围为 0.5 到最大缩放因子。你可以通过调用 [cameraMaxZoomFactor](/zh-CN/api-reference/rtc/ios/device-management/video-device#api_irtcengine_getcameramaxzoomfactor) 方法获取设备支持的最大缩放因子。

### 返回值 [#api_irtcengine_setcamerazoomfactor__return_values]

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/ios/error-code)了解详情和解决建议。

- [AgoraRtcEngineKit](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_irtcengine)
