## <span id="toc_audio_route"></span>isSpeakerphoneEnabled [#api_irtcengine_isspeakerphoneenabled]

检查是否启用扬声器播放音频。

<a id="api_irtcengine_isspeakerphoneenabled__prototype"></a>

```objectivec
- (BOOL)isSpeakerphoneEnabled NS_SWIFT_NAME(isSpeakerphoneEnabled());
```

### <span id="api_irtcengine_isspeakerphoneenabled__detailed_desc"></span>调用时机 [#api_irtcengine_isspeakerphoneenabled__timing]

你可以在加入频道前或加入频道后调用该方法。

### 返回值 [#api_irtcengine_isspeakerphoneenabled__return_values]

- YES：（默认）已启用扬声器，音频将从扬声器播放。
- NO：未启用扬声器，音频将从非扬声器设备播放，例如耳机或听筒。

- [AgoraRtcEngineKit](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_irtcengine)

## setDefaultAudioRouteToSpeakerphone: [#api_irtcengine_setdefaultaudioroutetospeakerphone]

设置默认音频播放路由。

<a id="api_irtcengine_setdefaultaudioroutetospeakerphone__prototype"></a>

```objectivec
- (int)setDefaultAudioRouteToSpeakerphone:(BOOL)defaultToSpeaker NS_SWIFT_NAME(setDefaultAudioRouteToSpeakerphone(_:));
```

<a id="api_irtcengine_setdefaultaudioroutetospeakerphone__detailed_desc"></a>

大多数手机有两个音频路由：顶部的听筒和底部的扬声器。听筒音量较低，扬声器音量较高。你可以通过该方法设置在未连接外部音频设备时，音频是通过听筒还是扬声器播放。 在不同场景下，系统的默认音频路由如下：

- 语音通话：听筒。
- 音频直播：扬声器。
- 视频通话：扬声器。
- 视频直播：扬声器。

你可以调用该方法更改默认音频路由。

:::info[注]
调用此方法设置默认音频路由后，系统的实际音频路由会随着外部音频设备（有线耳机或蓝牙耳机）的连接而变化。
:::

### 调用时机 [#api_irtcengine_setdefaultaudioroutetospeakerphone__timing]

该方法需要在加入频道前调用。

### 参数 [#api_irtcengine_setdefaultaudioroutetospeakerphone__parameters]

#### `defaultToSpeaker`

是否将扬声器设置为默认音频路由：

- YES：将扬声器设置为默认音频路由。
- NO：将听筒设置为默认音频路由。

### 返回值 [#api_irtcengine_setdefaultaudioroutetospeakerphone__return_values]

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/ios/error-code)了解详情和解决建议。

- [AgoraRtcEngineKit](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_irtcengine)

## setEnableSpeakerphone: [#api_irtcengine_setenablespeakerphone]

设置是否将音频路由到扬声器。

<a id="api_irtcengine_setenablespeakerphone__prototype"></a>

```objectivec
- (int)setEnableSpeakerphone:(BOOL)enableSpeaker NS_SWIFT_NAME(setEnableSpeakerphone(_:));
```

<a id="api_irtcengine_setenablespeakerphone__detailed_desc"></a>

你可以调用该方法切换当前频道中的音频路由，以满足不同的音频播放需求。

:::info[注]
- 该方法仅设置当前频道中的音频路由，不影响默认音频路由。如果你离开当前频道并加入另一个频道，将使用默认音频路由。
- 如果你使用了蓝牙或有线耳机等外部音频播放设备，该方法不生效。SDK 会通过外部设备播放音频。当你连接多个外部设备时，SDK 会通过最后连接的设备播放音频。
:::

### 适用场景 [#api_irtcengine_setenablespeakerphone__scenario]

如果 SDK 的默认音频路由或 [setDefaultAudioRouteToSpeakerphone:](/zh-CN/api-reference/rtc/ios/device-management/audio-route#api_irtcengine_setdefaultaudioroutetospeakerphone) 的设置无法满足你的需求，可以调用该方法切换当前音频路由。

### 调用时机 [#api_irtcengine_setenablespeakerphone__timing]

请在加入频道后调用该方法。

### 参数 [#api_irtcengine_setenablespeakerphone__parameters]

#### `enableSpeaker`

设置是否启用扬声器或听筒：

- YES：启用设备状态监测，音频路由为扬声器。
- NO：关闭设备状态监测，音频路由为听筒。

### 返回值 [#api_irtcengine_setenablespeakerphone__return_values]

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/ios/error-code)了解详情和解决建议。

- [AgoraRtcEngineKit](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_irtcengine)

## rtcEngine:didAudioRouteChanged: [#callback_irtcengineeventhandler_onaudioroutingchanged]

本地音频路由发生变化时的回调。

<a id="callback_irtcengineeventhandler_onaudioroutingchanged__prototype"></a>

```objectivec
- (void)rtcEngine:(AgoraRtcEngineKit * _Nonnull)engine didAudioRouteChanged:(AgoraAudioOutputRouting)routing NS_SWIFT_NAME(rtcEngine(_:didAudioRouteChanged:));
```

<a id="callback_irtcengineeventhandler_onaudioroutingchanged__detailed_desc"></a>

该回调在本地音频路由发生变化时触发，例如从听筒切换到扬声器。

### 触发时机 [#callback_irtcengineeventhandler_onaudioroutingchanged__timing]

该回调在本地音频路由发生变化时被触发。

### 参数 [#callback_irtcengineeventhandler_onaudioroutingchanged__parameters]

#### `engine`

[AgoraRtcEngineKit](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_irtcengine) 实例。详见 [AgoraRtcEngineKit](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_irtcengine)。

#### `routing`

当前的音频路由。详见 [AgoraAudioOutputRouting](/zh-CN/api-reference/rtc/ios/enum-audioroute)。

- [AgoraRtcEngineDelegate](/zh-CN/api-reference/rtc/ios/rtc-interface-class#class_irtcengineeventhandler)
