加密模式类型，仅在 IoT 场景适用。 0: 不加密 1: 128 位 AES 加密，XTS 模式。 2: 128 位 AES 加密，ECB 模式。 3: 256 位 AES 加密，XTS 模式。 4: 128 位 SM4 加密，ECB 模式。 5: 128 位 AES 加密，GCM 模式。 6: 256 位 AES 加密，GCM 模式。 7: （默认）128 位 AES 加密，GCM 模式。该加密模式需要设置盐值 (`encryptionSalt`)。 8: 256 位 AES 加密，GCM 模式。该加密模式需要设置盐值 (`encryptionSalt`)。 9: 枚举值边界。
