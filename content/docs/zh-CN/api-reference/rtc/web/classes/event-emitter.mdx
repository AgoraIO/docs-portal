`EventEmitter` 类提供了定义、触发和处理事件的方式。

- EventEmitter

  - [IAgoraRTC](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtc)
  - [IAgoraRTCClient](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtcclient)

## Methods

<a id="getlisteners"></a>

### getListeners

```ts
getListeners(event: string): Function[]
```

指定一个事件名，获取当前所有监听这个事件的回调函数。

#### Parameters

| Name | Description |
| --- | --- |
| event: string | 事件名称。 |

#### Returns

Returns Function []

<a id="off"></a>

### off

```ts
off(event: string, listener: Function): void
```

取消一个指定事件的监听。

#### Parameters

| Name | Description |
| --- | --- |
| event: string | 指定事件的名称。 |
| listener: Function | 监听事件时传入的回调函数。 |

#### Returns

Returns void

<a id="on"></a>

### on

```ts
on(event: string, listener: Function): void
```

监听一个指定的事件，当事件触发时会调用传入的回调函数。

#### Parameters

| Name | Description |
| --- | --- |
| event: string | 指定事件的名称。 |
| listener: Function | 传入的回调函数。 |

#### Returns

Returns void

<a id="once"></a>

### once

```ts
once(event: string, listener: Function): void
```

监听一个指定的事件，当事件触发时会调用传入的回调函数。

当监听后事件第一次触发时，该监听和回调函数就会被立刻移除，也就是只监听一次指定事件。

#### Parameters

| Name | Description |
| --- | --- |
| event: string | 指定事件的名称。 |
| listener: Function | 传入的回调函数。 |

#### Returns

Returns void

<a id="removealllisteners"></a>

### removeAllListeners

```ts
removeAllListeners(event?: string): void
```

指定一个事件，取消其所有的监听。

#### Parameters

| Name | Description |
| --- | --- |
| Optional event: string | 指定事件的名称，如果没有指定事件，则取消所有事件的所有监听。 |

#### Returns

Returns void
