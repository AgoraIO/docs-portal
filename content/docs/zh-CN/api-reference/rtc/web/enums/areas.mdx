服务器的访问区域。用于设置 [AgoraRTC.setArea](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtc#setarea)。

## 枚举成员

<a id="asia"></a>

### ASIA

```ts
ASIA: = "ASIA"
```

亚洲区域（中国大陆除外）。

<a id="china"></a>

### CHINA

```ts
CHINA: = "CHINA"
```

中国。

<a id="europe"></a>

### EUROPE

```ts
EUROPE: = "EUROPE"
```

欧洲区域。

<a id="global"></a>

### GLOBAL

```ts
GLOBAL: = "GLOBAL"
```

全球。

<a id="india"></a>

### INDIA

```ts
INDIA: = "INDIA"
```

印度。

<a id="japan"></a>

### JAPAN

```ts
JAPAN: = "JAPAN"
```

日本。

<a id="north_america"></a>

### NORTH_AMERICA

```ts
NORTH_AMERICA: = "NORTH_AMERICA"
```

北美区域。
