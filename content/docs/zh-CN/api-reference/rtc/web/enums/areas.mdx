服务器的访问区域。用于设置 [AgoraRTC.setArea](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtc#setarea)。

## 枚举成员

### ASIA [#asia]

```ts title="TypeScript"
ASIA: = "ASIA"
```

亚洲区域（中国大陆除外）。

### CHINA [#china]

```ts title="TypeScript"
CHINA: = "CHINA"
```

中国。

### EUROPE [#europe]

```ts title="TypeScript"
EUROPE: = "EUROPE"
```

欧洲区域。

### GLOBAL [#global]

```ts title="TypeScript"
GLOBAL: = "GLOBAL"
```

全球。

### INDIA [#india]

```ts title="TypeScript"
INDIA: = "INDIA"
```

印度。

### JAPAN [#japan]

```ts title="TypeScript"
JAPAN: = "JAPAN"
```

日本。

### NORTH_AMERICA [#north_america]

```ts title="TypeScript"
NORTH_AMERICA: = "NORTH_AMERICA"
```

北美区域。
