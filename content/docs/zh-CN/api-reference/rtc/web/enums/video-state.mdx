视频流状态。

## 枚举成员

### VideoStateDecoding [#videostatedecoding]

```ts title="TypeScript"
VideoStateDecoding: = 2
```

2: 视频流正在解码，正常播放。

### VideoStateFrozen [#videostatefrozen]

```ts title="TypeScript"
VideoStateFrozen: = 3
```

3: 视频流卡顿。

### VideoStateStarting [#videostatestarting]

```ts title="TypeScript"
VideoStateStarting: = 1
```

1: 本地用户已接收视频首包。

### VideoStateStopped [#videostatestopped]

```ts title="TypeScript"
VideoStateStopped: = 0
```

0: 视频默认初始状态。
