视频流状态。

## 枚举成员

<a id="videostatedecoding"></a>

### VideoStateDecoding

```ts
VideoStateDecoding: = 2
```

2: 视频流正在解码，正常播放。

<a id="videostatefrozen"></a>

### VideoStateFrozen

```ts
VideoStateFrozen: = 3
```

3: 视频流卡顿。

<a id="videostatestarting"></a>

### VideoStateStarting

```ts
VideoStateStarting: = 1
```

1: 本地用户已接收视频首包。

<a id="videostatestopped"></a>

### VideoStateStopped

```ts
VideoStateStopped: = 0
```

0: 视频默认初始状态。
