跨直播媒体流转发服务的状态码，可以通过 [AgoraRTCClient.on("channel-media-relay-state")](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtcclient#event_channel_media_relay_state) 事件获取。

## 枚举成员

### RELAY_STATE_CONNECTING [#relay_state_connecting]

```ts title="TypeScript"
RELAY_STATE_CONNECTING: = "RELAY_STATE_CONNECTING"
```

SDK 正在连接到跨频道媒体流转发服务。

### RELAY_STATE_FAILURE [#relay_state_failure]

```ts title="TypeScript"
RELAY_STATE_FAILURE: = "RELAY_STATE_FAILURE"
```

跨频道媒体流转发出现错误，错误代码可以参考 [ChannelMediaRelayError](/zh-CN/api-reference/rtc/web/enums/channel-media-relay-error)。

### RELAY_STATE_IDLE [#relay_state_idle]

```ts title="TypeScript"
RELAY_STATE_IDLE: = "RELAY_STATE_IDLE"
```

SDK 已经初始化，但是还没有开启跨频道媒体流转发服务。

### RELAY_STATE_RUNNING [#relay_state_running]

```ts title="TypeScript"
RELAY_STATE_RUNNING: = "RELAY_STATE_RUNNING"
```

跨频道媒体流转发成功。
