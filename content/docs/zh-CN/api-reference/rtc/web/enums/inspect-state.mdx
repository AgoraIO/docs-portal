视频截图上传服务的连接状态。

## 枚举成员

### CLOSED [#closed]

```ts title="TypeScript"
CLOSED: = "CLOSED"
```

SDK 断开与该服务的连接。

### CONNECTED [#connected]

```ts title="TypeScript"
CONNECTED: = "CONNECTED"
```

SDK 已连接该服务。

### CONNECTING [#connecting]

```ts title="TypeScript"
CONNECTING: = "CONNECTING"
```

SDK 正在连接该服务。

### RECONNECTING [#reconnecting]

```ts title="TypeScript"
RECONNECTING: = "RECONNECTING"
```

SDK 正在重新连接该服务。
