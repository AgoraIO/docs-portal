远端视频流的大小类型，可以在 [setRemoteVideoStreamType](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtcclient#setremotevideostreamtype) 里使用。

## 枚举成员

### HIGH_STREAM [#high_stream]

```ts title="TypeScript"
HIGH_STREAM: = 0
```

0: 高分辨率、高码率的视频大流。

### HIGH_STREAM_LAYER1 [#high_stream_layer1]

```ts title="TypeScript"
HIGH_STREAM_LAYER1: = 4
```

ABR 拓展 暂时不对外，以实际客户为主

### HIGH_STREAM_LAYER2 [#high_stream_layer2]

```ts title="TypeScript"
HIGH_STREAM_LAYER2: = 5
```

### HIGH_STREAM_LAYER3 [#high_stream_layer3]

```ts title="TypeScript"
HIGH_STREAM_LAYER3: = 6
```

### HIGH_STREAM_LAYER4 [#high_stream_layer4]

```ts title="TypeScript"
HIGH_STREAM_LAYER4: = 7
```

### HIGH_STREAM_LAYER5 [#high_stream_layer5]

```ts title="TypeScript"
HIGH_STREAM_LAYER5: = 8
```

### HIGH_STREAM_LAYER6 [#high_stream_layer6]

```ts title="TypeScript"
HIGH_STREAM_LAYER6: = 9
```

### LOW_STREAM [#low_stream]

```ts title="TypeScript"
LOW_STREAM: = 1
```

1: 低分辨率、低码率的视频小流。
