---

连接断开的原因。

## 枚举成员

### CHANNEL_BANNED [#channel_banned]

```ts title="TypeScript"
CHANNEL_BANNED: = "CHANNEL_BANNED"
```

当前频道被禁用。

### IP_BANNED [#ip_banned]

```ts title="TypeScript"
IP_BANNED: = "IP_BANNED"
```

当前 IP 被踢出。

### LEAVE [#leave]

```ts title="TypeScript"
LEAVE: = "LEAVE"
```

用户正常退出。

### NETWORK_ERROR [#network_error]

```ts title="TypeScript"
NETWORK_ERROR: = "NETWORK_ERROR"
```

网络异常，经过重试后不可恢复。

### SERVER_ERROR [#server_error]

```ts title="TypeScript"
SERVER_ERROR: = "SERVER_ERROR"
```

服务端返回出现异常，通常是因为集成过程中参数有误。

### TOKEN_EXPIRE [#token_expire]

```ts title="TypeScript"
TOKEN_EXPIRE: = "TOKEN_EXPIRE"
```

当前用户的 Token 已过期。

### UID_BANNED [#uid_banned]

```ts title="TypeScript"
UID_BANNED: = "UID_BANNED"
```

当前用户被踢出。
