连接断开的原因。

## Enumeration members

<a id="channel_banned"></a>

### CHANNEL_BANNED

```ts
CHANNEL_BANNED: = "CHANNEL_BANNED"
```

当前频道被禁用。

<a id="ip_banned"></a>

### IP_BANNED

```ts
IP_BANNED: = "IP_BANNED"
```

当前 IP 被踢出。

<a id="leave"></a>

### LEAVE

```ts
LEAVE: = "LEAVE"
```

用户正常退出。

<a id="network_error"></a>

### NETWORK_ERROR

```ts
NETWORK_ERROR: = "NETWORK_ERROR"
```

网络异常，经过重试后不可恢复。

<a id="server_error"></a>

### SERVER_ERROR

```ts
SERVER_ERROR: = "SERVER_ERROR"
```

服务端返回出现异常，通常是因为集成过程中参数有误。

<a id="token_expire"></a>

### TOKEN_EXPIRE

```ts
TOKEN_EXPIRE: = "TOKEN_EXPIRE"
```

当前用户的 Token 已过期。

<a id="uid_banned"></a>

### UID_BANNED

```ts
UID_BANNED: = "UID_BANNED"
```

当前用户被踢出。
