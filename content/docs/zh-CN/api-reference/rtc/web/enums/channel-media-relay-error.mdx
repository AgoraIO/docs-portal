title: "ChannelMediaRelayError"
description: "ChannelMediaRelayError API 参考。"
---

跨频道媒体流转发中出现的错误码，可以通过 [AgoraRTCClient.on("channel-media-relay-state")](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtcclient#event_channel_media_relay_state) 事件获取。

## 枚举成员

<a id="dest_token_expired"></a>

### DEST_TOKEN_EXPIRED

```ts
DEST_TOKEN_EXPIRED: = "DEST_TOKEN_EXPIRED"
```

目标频道的 Token 已经过期。

<a id="relay_ok"></a>

### RELAY_OK

```ts
RELAY_OK: = "RELAY_OK"
```

一切正常。

<a id="server_connection_lost"></a>

### SERVER_CONNECTION_LOST

```ts
SERVER_CONNECTION_LOST: = "SERVER_CONNECTION_LOST"
```

和跨频道媒体流转发服务断开连接。

<a id="src_token_expired"></a>

### SRC_TOKEN_EXPIRED

```ts
SRC_TOKEN_EXPIRED: = "SRC_TOKEN_EXPIRED"
```

源频道的 Token 已经过期。
