跨频道媒体流转发中出现的错误码，可以通过 [AgoraRTCClient.on("channel-media-relay-state")](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtcclient#event_channel_media_relay_state) 事件获取。

## 枚举成员

### DEST_TOKEN_EXPIRED [#dest_token_expired]

```ts title="TypeScript"
DEST_TOKEN_EXPIRED: = "DEST_TOKEN_EXPIRED"
```

目标频道的 Token 已经过期。

### RELAY_OK [#relay_ok]

```ts title="TypeScript"
RELAY_OK: = "RELAY_OK"
```

一切正常。

### SERVER_CONNECTION_LOST [#server_connection_lost]

```ts title="TypeScript"
SERVER_CONNECTION_LOST: = "SERVER_CONNECTION_LOST"
```

和跨频道媒体流转发服务断开连接。

### SRC_TOKEN_EXPIRED [#src_token_expired]

```ts title="TypeScript"
SRC_TOKEN_EXPIRED: = "SRC_TOKEN_EXPIRED"
```

源频道的 Token 已经过期。
