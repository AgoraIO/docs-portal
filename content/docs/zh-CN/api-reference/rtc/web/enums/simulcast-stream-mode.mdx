发送视频流的模式。

### `自从`

<br /> 4.24.1 <br />

## Enumeration members

<a id="auto_simulcast_stream"></a>

### AUTO_SIMULCAST_STREAM

```ts
AUTO_SIMULCAST_STREAM: = -1
```

-1：默认不发送小流，直至收到接收端发起的订阅小流申请时，开始自动发送小流。

<a id="disable_simulcast_strem"></a>

### DISABLE_SIMULCAST_STREM

```ts
DISABLE_SIMULCAST_STREM: = 0
```

0：始终不发送小流。

<a id="enable_simulcast_stream"></a>

### ENABLE_SIMULCAST_STREAM

```ts
ENABLE_SIMULCAST_STREAM: = 1
```

1：始终发送小流。
