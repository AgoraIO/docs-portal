发送视频流的模式。

### `自从`

<br /> 4.24.1 <br />

## 枚举成员

### AUTO_SIMULCAST_STREAM [#auto_simulcast_stream]

```ts title="TypeScript"
AUTO_SIMULCAST_STREAM: = -1
```

-1：默认不发送小流，直至收到接收端发起的订阅小流申请时，开始自动发送小流。

### DISABLE_SIMULCAST_STREM [#disable_simulcast_strem]

```ts title="TypeScript"
DISABLE_SIMULCAST_STREM: = 0
```

0：始终不发送小流。

### ENABLE_SIMULCAST_STREAM [#enable_simulcast_stream]

```ts title="TypeScript"
ENABLE_SIMULCAST_STREAM: = 1
```

1：始终发送小流。
