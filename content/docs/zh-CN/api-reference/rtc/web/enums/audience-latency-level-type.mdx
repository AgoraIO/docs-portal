---
title: "AudienceLatencyLevelType"
description: "AudienceLatencyLevelType API 参考。"
---

观众延时级别。仅在用户角色为 `"audience"` 时生效。 `1`: 低延时。 `2`: （默认）超低延时。

## 枚举成员

<a id="audience_level_low_latency"></a>

### AUDIENCE_LEVEL_LOW_LATENCY

```ts
AUDIENCE_LEVEL_LOW_LATENCY: = 1
```

低延时。

<a id="audience_level_ultra_low_latency"></a>

### AUDIENCE_LEVEL_ULTRA_LOW_LATENCY

```ts
AUDIENCE_LEVEL_ULTRA_LOW_LATENCY: = 2
```

超低延时。
