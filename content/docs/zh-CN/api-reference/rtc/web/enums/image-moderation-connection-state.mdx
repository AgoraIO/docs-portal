SDK 与第三方视频审核服务之间的连接状态。

## 枚举成员

<a id="closed"></a>

### CLOSED

```ts
CLOSED: = "CLOSED"
```

SDK 断开与该服务的连接。

<a id="connected"></a>

### CONNECTED

```ts
CONNECTED: = "CONNECTED"
```

SDK 已连接该服务。

<a id="connecting"></a>

### CONNECTING

```ts
CONNECTING: = "CONNECTING"
```

SDK 正在连接该服务。

<a id="reconnecting"></a>

### RECONNECTING

```ts
RECONNECTING: = "RECONNECTING"
```

SDK 正在重新连接该服务。
