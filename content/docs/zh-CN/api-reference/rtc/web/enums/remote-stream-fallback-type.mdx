媒体流的回退策略选项，用于 [setStreamFallbackOption](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtcclient#setstreamfallbackoption)。

## 枚举成员

### AUDIO_ONLY [#audio_only]

```ts title="TypeScript"
AUDIO_ONLY: = 2
```

2: 网络较弱时，先尝试订阅视频小流。如果网络环境无法显示视频，则再回退到订阅纯音频流。

### DISABLE [#disable]

```ts title="TypeScript"
DISABLE: = 0
```

0: 关闭回退策略，弱网时不对音视频流作回退处理。

### HIGH_STREAM_LAYER1 [#high_stream_layer1]

```ts title="TypeScript"
HIGH_STREAM_LAYER1: = 3
```

ABR 拓展, 暂时不对外，以实际客户为主

```ts title="TypeScript"
LOW_STREAM: = 1
```

1: 在网络条件较差的情况下，自动订阅视频小流。
