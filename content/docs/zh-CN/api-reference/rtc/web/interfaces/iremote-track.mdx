远端轨道对象的基础类，为远端音频轨道 [RemoteAudioTrack](/zh-CN/api-reference/rtc/web/interfaces/iremote-audio-track) 和远端视频轨道 [RemoteVideoTrack](/zh-CN/api-reference/rtc/web/interfaces/iremote-video-track) 提供一些公共的方法。

- ITrack

  - IRemoteTrack

    - [IRemoteAudioTrack](/zh-CN/api-reference/rtc/web/interfaces/iremote-audio-track)
    - [IRemoteVideoTrack](/zh-CN/api-reference/rtc/web/interfaces/iremote-video-track)

## 事件

<a id="event_first_frame_decoded"></a>

### first-frame-decoded

```ts
first-frame-decoded(): void
```

首帧音频或视频解码时触发。

注意： 该事件只有在本地调用了 [IRemoteTrack.play](/zh-CN/api-reference/rtc/web/interfaces/iremote-track#play) 后才会触发。

#### 返回值

void

<a id="event_transceiver_updated_2"></a>

### transceiver-updated

```ts
transceiver-updated(transceiver: RTCRtpTransceiver): void
```

当前轨道的 `RTCRtpTransceiver` 实例更新回调。

#### 参数

| 名称 | 描述 |
| --- | --- |
| transceiver: RTCRtpTransceiver | 新的 `RTCRtpTransceiver` 实例。 |

#### 返回值

void

## 属性

<a id="isplaying"></a>

### isPlaying

```ts
isPlaying: boolean
```

媒体轨道是否正在页面上播放。

- `true`: 媒体轨道正在页面上播放。
- `false`: 媒体轨道没有在页面上播放。

<a id="trackmediatype"></a>

### trackMediaType

```ts
trackMediaType: "audio" | "video"
```

媒体轨道的类型：

- `"audio"`: 音频轨道。
- `"video"`: 视频轨道。

<a id="getrtcrtptransceiver"></a>

### getRTCRtpTransceiver

```ts
getRTCRtpTransceiver(type?: StreamType): RTCRtpTransceiver | undefined
```

获取当前轨道的 [RTCRtpTransceiver](https://developer.mozilla.org/en-US/docs/Web/API/RTCRtpTransceiver) 实例。

该方法目前主要用于视频流的 [端到端加密（Beta）](https://doc.shengwang.cn/doc/rtc/javascript/advanced-features/e2e-encryption)。

如果 SDK 发生断线重连，当前轨道对应的 `RTCRtpTransceiver` 实例可能会发生变化。你可以通过以下回调来获取新的 `RTCRtpTransceiver` 实例： 本地轨道： [ILocalTrack.transceiver-updated](/zh-CN/api-reference/rtc/web/interfaces/ilocal-track#event_transceiver_updated) 远端轨道： [IRemoteTrack.transceiver-updated](/zh-CN/api-reference/rtc/web/interfaces/iremote-track#event_transceiver_updated_2)

#### 参数

| 名称 | 描述 |
| --- | --- |
| Optional type: StreamType | 视频流的类型。详见 [StreamType](/zh-CN/api-reference/rtc/web/enums/stream-type)。 |

#### 返回值

RTCRtpTransceiver | undefined

当前轨道的 `RTCRtpTransceiver` 实例。

<a id="once"></a>

### once

```ts
once(event: string, listener: Function): void
```

监听一个指定的事件，当事件触发时会调用传入的回调函数。

当监听后事件第一次触发时，该监听和回调函数就会被立刻移除，也就是只监听一次指定事件。

#### 参数

| 名称 | 描述 |
| --- | --- |
| event: string | 指定事件的名称。 |
| listener: Function | 传入的回调函数。 |

#### 返回值

void

<a id="play"></a>

### play

```ts
play(element?: string | HTMLElement): void
```

在页面上播放媒体轨道。

#### 参数

| 名称 | 描述 |
| --- | --- |
| Optional element: string \| HTMLElement | 指定一个 DOM 元素，SDK 将在这个元素下创建 `<video>` 元素播放视频轨道，支持 2 种类型：<br />- `string`: 指定该 DOM 元素的 ID 值。<br />- `HTMLElement`: 直接传入一个 DOM 元素对象。 |

#### 返回值

void
