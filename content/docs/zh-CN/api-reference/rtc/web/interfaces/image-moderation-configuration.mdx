视频审核服务的配置。用于 [setImageModeration](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtcclient#setimagemoderation) 方法。

- ImageModerationConfiguration

## 属性

### Optional extraInfo [#extrainfo]

```ts title="TypeScript"
extraInfo: string
```

附加信息，最大长度为 1024 字节。

SDK 会将附加信息和截图一起上传至声网服务器；截图并上传完成后，声网服务器会将附加信息随回调通知一起发送给你的服务器。

### interval [#interval]

```ts title="TypeScript"
interval: number
```

视频截图的间隔 (ms)，最小值为 `1000`。
