### track-ended

<ApiSignature>

track-ended(): void

</ApiSignature>

音频或视频轨道被终止，终止的原因可能是：

- 摄像头被拔出
- 麦克风被拔出
- 用户主动停止了屏幕共享
- 用户主动关闭了底层的 `MediaStreamTrack`
- 媒体设备故障
- 正在使用中的媒体设备的权限被收回

<a id="setenabled"></a>

### setEnabled

<ApiSignature>

setEnabled(enabled: boolean): Promise&lt;void&gt;

</ApiSignature>

:::info[自从]
*4.0.0*

启用/禁用该轨道。

轨道禁用后，播放和发布都将被停止。

> - 禁用轨道不会触发 [LocalTrack.on("track-ended")](/zh-CN/api-reference/rtc/web/interfaces/ilocaltrack#event_track_ended) 事件。
> - 如果该轨道已发布，禁用轨道后，远端会触发 [user-unpublished](/zh-CN/api-reference/rtc/web/interfaces/iagorartcclient#event_user_unpublished) 事件。重新启用后，远端会触发 [user-published](/zh-CN/api-reference/rtc/web/interfaces/iagorartcclient#event_user_published) 事件。
> - `setEnabled` 和 `setMuted` 不能同时调用。
:::

<ParameterList title="Parameters">
<Parameter name="enabled" type="boolean" required>

是否启用该轨道:

- `true`: 启用该轨道。
- `false`: 禁用该轨道。

</Parameter>
</ParameterList>

<ApiReturnType>

Promise&lt;void&gt;

<a id="setmuted"></a>

### setMuted

<ApiSignature>

setMuted(muted: boolean): Promise&lt;void&gt;

</ApiSignature>

发送或暂停发送该轨道的媒体数据。

:::info[自从]
*4.0.0*

如果该轨道已发布，调用 `setMuted(true)` 后，远端会触发 [user-unpublished](/zh-CN/api-reference/rtc/web/interfaces/iagorartcclient#event_user_unpublished) 事件。再调用 `setMuted(false)` 后，远端会触发 [user-published](/zh-CN/api-reference/rtc/web/interfaces/iagorartcclient#event_user_published) 事件。

> - 与 [setEnabled](/zh-CN/api-reference/rtc/web/interfaces/ilocaltrack#setenabled) 相比，调用该方法响应速度更快且不影响视频采集状态，详见 [setEnabled 和 setMuted 有什么区别？](/zh-CN/reference/faq/integration/set_enabled_set_muted)。
> - `setEnabled` 和 `setMuted` 不能同时调用。
:::

<ParameterList title="Parameters">
<Parameter name="muted" type="boolean" required>

是否发送该轨道的媒体数据:

- `true`: 暂停发送该轨道的媒体数据。
- `false`: 恢复发送该轨道的媒体数据。

</Parameter>
</ParameterList>
