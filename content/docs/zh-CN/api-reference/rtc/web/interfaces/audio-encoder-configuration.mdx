---
title: "AudioEncoderConfiguration"
description: "AudioEncoderConfiguration API 参考。"
---

定义音频编码配置的对象。 用于创建音频流时指定自定义的编码配置。 你可以在 [AgoraRTC.createCustomAudioTrack](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtc#createcustomaudiotrack)、 [AgoraRTC.createMicrophoneAudioTrack](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtc#createmicrophoneaudiotrack) 或 [AgoraRTC.createBufferSourceAudioTrack](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtc#createbuffersourceaudiotrack) 方法中传入该配置对象来自定义本地音频的编码配置。

- AudioEncoderConfiguration

## 属性

### Optional bitrate [#bitrate]

```ts title="TypeScript"
bitrate: number
```

音频码率，单位为 Kbps。

### Optional sampleRate [#samplerate]

```ts title="TypeScript"
sampleRate: number
```

音频采样率，单位为 Hz。

### Optional sampleSize [#samplesize]

```ts title="TypeScript"
sampleSize: number
```

音频采样大小。

### Optional stereo [#stereo]

```ts title="TypeScript"
stereo: boolean
```

是否开启立体声。
