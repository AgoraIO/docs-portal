在配置 [LiveStreamingTranscodingConfig](/zh-CN/api-reference/rtc/web/interfaces/live-streaming-transcoding-config) 时用于添加水印和背景图片。

- LiveStreamingTranscodingImage

## 属性

### Optional alpha [#alpha]

```ts title="TypeScript"
alpha: number
```

图片的透明度。

取值范围为 [0.0,1.0]:

- 0.0: 图片完全透明。
- 1.0: （默认）图片完全不透明。

### Optional height [#height]

```ts title="TypeScript"
height: number
```

图片的高度。

默认值为 160，单位为像素。

### url [#url]

```ts title="TypeScript"
url: string
```

图片的地址，仅支持在线 PNG 文件。

### Optional width [#width]

```ts title="TypeScript"
width: number
```

图片的宽度。

默认值为 160，单位为像素。

### Optional x [#x]

```ts title="TypeScript"
x: number
```

图片左上角和视频帧左上角之间的水平距离。

默认值为 `0`，单位为像素。

### Optional y [#y]

```ts title="TypeScript"
y: number
```

图片左上角和视频帧左上角之间的垂直距离。

默认值为 `0`，单位为像素。
