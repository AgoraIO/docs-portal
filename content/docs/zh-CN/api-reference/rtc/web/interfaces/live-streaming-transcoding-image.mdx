在配置 [LiveStreamingTranscodingConfig](/zh-CN/api-reference/rtc/web/interfaces/live-streaming-transcoding-config) 时用于添加水印和背景图片。

- LiveStreamingTranscodingImage

## 属性

<a id="alpha"></a>

### Optional alpha

```ts
alpha: number
```

图片的透明度。

取值范围为 [0.0,1.0]:

- 0.0: 图片完全透明。
- 1.0: （默认）图片完全不透明。

<a id="height"></a>

### Optional height

```ts
height: number
```

图片的高度。

默认值为 160，单位为像素。

<a id="url"></a>

### url

```ts
url: string
```

图片的地址，仅支持在线 PNG 文件。

<a id="width"></a>

### Optional width

```ts
width: number
```

图片的宽度。

默认值为 160，单位为像素。

<a id="x"></a>

### Optional x

```ts
x: number
```

图片左上角和视频帧左上角之间的水平距离。

默认值为 `0`，单位为像素。

<a id="y"></a>

### Optional y

```ts
y: number
```

图片左上角和视频帧左上角之间的垂直距离。

默认值为 `0`，单位为像素。
