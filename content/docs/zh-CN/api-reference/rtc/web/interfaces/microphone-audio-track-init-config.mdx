创建麦克风音频流时的配置对象，用于 [AgoraRTC.createMicrophoneAudioTrack](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtc#createmicrophoneaudiotrack)。

- [AudioTrackInitConfig](/zh-CN/api-reference/rtc/web/interfaces/audio-track-init-config)

  - MicrophoneAudioTrackInitConfig

## 属性

### Optional AEC [#aec]

```ts title="TypeScript"
AEC: boolean
```

是否开启回声消除：

- `true`: 开启回声消除。
- `false`: 不开启回声消除。

### Optional AGC [#agc]

```ts title="TypeScript"
AGC: boolean
```

是否开启自动增益：

- `true`: 开启自动增益。
- `false`: 不开启自动增益。

### Optional ANS [#ans]

```ts title="TypeScript"
ANS: boolean
```

是否开启噪声抑制：

- `true`: 开启噪声抑制。
- `false`: 不开启噪声抑制。

### Optional encoderConfig [#encoderconfig]

```ts title="TypeScript"
encoderConfig: AudioEncoderConfiguration | AudioEncoderConfigurationPreset
```

控制音频的编码配置。

你可以通过 [AudioEncoderConfigurationPreset](/zh-CN/api-reference/rtc/web/globals#audioencoderconfigurationpreset) 传入 SDK 内置的编码配置；也可以通过传入一个 [AudioEncoderConfiguration](/zh-CN/api-reference/rtc/web/interfaces/audio-encoder-configuration) 来自定义音频编码配置。

Firefox 不支持设置音频编码码率。

### Optional microphoneId [#microphoneid]

```ts title="TypeScript"
microphoneId: string
```

指定麦克风的设备 ID。

你可以通过 [AgoraRTC.getMicrophones](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtc#getmicrophones) 来获取当前的麦克风设备列表。
