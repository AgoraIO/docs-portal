### codecType

<ApiSignature labels="Optional">

codecType: "H264"|"H265"|"VP8"|"VP9"|"AV1X"|"AV1"

</ApiSignature>

视频编码格式。

- `"H264"`: 视频编码格式为 H.264。
- `"VP8"`: 视频编码格式为 VP8。
- `"VP9"`: 视频编码格式为 VP9。
- `"AV1X"`: 预留参数，暂不支持。
- `"AV1"`: 视频编码格式为 AV1。

:::caution[注意]
Firefox 上无法获取该值。
:::
