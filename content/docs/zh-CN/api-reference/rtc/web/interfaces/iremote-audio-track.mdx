远端音频轨道，调用 [subscribe](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtcclient#subscribe) 后通过 [AgoraRTCRemoteUser.audioTrack](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtcremote-user#audiotrack) 对象获取

- IRemoteTrack
  - IRemoteAudioTrack

## Properties

<a id="isplaying"></a>

### isPlaying

```ts
isPlaying: boolean
```

媒体轨道是否正在页面上播放。

- true: 媒体轨道正在页面上播放。
- false: 媒体轨道没有在页面上播放。

### processorDestination

```ts
processorDestination: IAudioProcessor
```

##### `自从`

<br /> *4.13.0*

### trackMediaType

```ts
trackMediaType: "audio" | "video"
```

媒体轨道的类型：

- "audio": 音频轨道。
- "video": 视频轨道。

<a id="getrtcrtptransceiver"></a>

### getRTCRtpTransceiver

```ts
getRTCRtpTransceiver(type?: StreamType): RTCRtpTransceiver | undefined
```

获取当前轨道的 [RTCRtpTransceiver](https://developer.mozilla.org/en-US/docs/Web/API/RTCRtpTransceiver) 实例。

该方法目前主要用于视频流的 [端到端加密（Beta）](https://doc.shengwang.cn/doc/rtc/javascript/advanced-features/e2e-encryption)。

如果 SDK 发生断线重连，当前轨道对应的 `RTCRtpTransceiver` 实例可能会发生变化。你可以通过以下回调来获取新的 `RTCRtpTransceiver` 实例： 本地轨道： [ILocalTrack.transceiver-updated](/zh-CN/api-reference/rtc/web/interfaces/ilocal-track#event_transceiver_updated) 远端轨道： [IRemoteTrack.transceiver-updated](/zh-CN/api-reference/rtc/web/interfaces/iremote-track#event_transceiver_updated_2)

#### Parameters

| Name | Description |
| --- | --- |
| Optional type: StreamType | 视频流的类型。详见 [StreamType](/zh-CN/api-reference/rtc/web/enums/stream-type)。 |

#### Returns

Returns RTCRtpTransceiver | undefined

当前轨道的 `RTCRtpTransceiver` 实例。

<a id="setaudioframecallback"></a>

### setAudioFrameCallback

```ts
setAudioFrameCallback(audioFrameCallback: null | function, frameSize?: number): void
```

设置原始音频数据（PCM）回调。

设置成功后，SDK 会不断地将远端音频轨道的音频帧以 [AudioBuffer](https://developer.mozilla.org/en-US/docs/Web/API/AudioBuffer) 的形式通过回调返回。

你可以通过 `frameSize` 来设置每次回调中音频帧的大小。该设置也会影响回调的间隔， `frameSize` 越大，每次回调的音频数据越多，回调间隔越长。

```text
track.setAudioFrameCallback((buffer) => {
  for (let channel = 0; channel < buffer.numberOfChannels; channel += 1) {
    // Float32Array with PCM data
    const currentChannelData = buffer.getChannelData(channel);
    console.log("PCM data in channel", channel, currentChannelData);
  }
}, 2048);

// ....
// Stop getting the raw audio data
track.setAudioFrameCallback(null);
```

#### Parameters

| Name | Description |
| --- | --- |
| audioFrameCallback: null \| function | 用于接收 [AudioBuffer](https://developer.mozilla.org/en-US/docs/Web/API/AudioBuffer) 的回调函数。设为 `null` 后，SDK 就会停止获取音频原始数据。 |
| Optional frameSize: number | 每次回调的 `AudioBuffer` 中每个声道包含的采样数据个数，只能设为下列值：256, 512, 1024, 2048, 4096, 8192, 16384。默认为 4096。 |

#### Returns

Returns void
