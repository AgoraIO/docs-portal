跨频道媒体流转发的配置。

在调用 [startChannelMediaRelay](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtcclient#startchannelmediarelay) 和 [updateChannelMediaRelay](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtcclient#updatechannelmediarelay) 时，通过该接口设置跨频道媒体流转发的具体信息。

```text
const configuration = AgoraRTC.createChannelMediaRelayConfiguration();
configuration.setSrcChannelInfo({ channelName: "test", token: "xxx", uid: 12345 });
configuration.addDestChannelInfo({ channelName: "test2", token: "xxx", uid: 23456 });
```

- IChannelMediaRelayConfiguration

## 方法

<a id="adddestchannelinfo"></a>

### addDestChannelInfo

```ts
addDestChannelInfo(info: ChannelMediaRelayInfo): void
```

添加目标频道信息。

如果你想将流转发到多个目标频道，可以多次调用该方法。该方法支持最多设置 4 个目标频道。

```text
const config = AgoraRTC.createChannelMediaRelayConfiguration();
config.addDestChannelInfo({ channelName: "test2", token: "xxx", uid: 23456 });
config.addDestChannelInfo({ channelName: "test3", token: "xxx", uid: 23457 });
```

#### 参数

| 名称 | 描述 |
| --- | --- |
| info: ChannelMediaRelayInfo | 频道信息，详见 [ChannelMediaRelayInfo](/zh-CN/api-reference/rtc/web/interfaces/channel-media-relay-info)。 |

#### 返回值

void

<a id="removedestchannelinfo"></a>

### removeDestChannelInfo

```ts
removeDestChannelInfo(channelName: string): void
```

删除通过 [addDestChannelInfo](/zh-CN/api-reference/rtc/web/interfaces/ichannel-media-relay-configuration#adddestchannelinfo) 添加的目标频道。

#### 参数

| 名称 | 描述 |
| --- | --- |
| channelName: string | 待删除的目标频道名。 |

#### 返回值

void

<a id="setsrcchannelinfo"></a>

### setSrcChannelInfo

```ts
setSrcChannelInfo(info: ChannelMediaRelayInfo): void
```

设置源频道信息。

```text
const config = AgoraRTC.createChannelMediaRelayConfiguration();
config.setSrcChannelInfo({ channelName: "test", token: "xxx", uid: 123456 });
```

#### 参数

| 名称 | 描述 |
| --- | --- |
| info: ChannelMediaRelayInfo | 频道信息，详见 [ChannelMediaRelayInfo](/zh-CN/api-reference/rtc/web/interfaces/channel-media-relay-info)。 |

#### 返回值

void
