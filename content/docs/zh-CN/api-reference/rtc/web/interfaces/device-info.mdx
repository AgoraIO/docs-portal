音视频采集设备的信息。

- 音频采集设备信息可通过 [onMicrophoneChanged](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtc#onmicrophonechanged) 获取。
- 视频采集设备信息可通过 [onCameraChanged](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtc#oncamerachanged) 获取。
- 音频播放设备信息可通过 [onPlaybackDeviceChanged](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtc#onplaybackdevicechanged) 获取。

- DeviceInfo

## 属性

### device [#device]

```ts title="TypeScript"
device: MediaDeviceInfo
```

采集设备的设备信息，详见 [MediaDeviceInfo](https://developer.mozilla.org/en-US/docs/Web/API/MediaDeviceInfo)。

### initAt [#initat]

```ts title="TypeScript"
initAt: number
```

SDK 首次检测到采集设备的时间，UNIX 时间戳，单位为 ms。

### state [#state]

```ts title="TypeScript"
state: DeviceState
```

采集设备当前的插拔状态。

### updateAt [#updateat]

```ts title="TypeScript"
updateAt: number
```

采集设备的插拔状态更新时间，UNIX 时间戳，单位为 ms。
