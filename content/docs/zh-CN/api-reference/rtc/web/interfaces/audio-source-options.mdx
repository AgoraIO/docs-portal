音频数据源处理的设置。用于 [startProcessAudioBuffer](/zh-CN/api-reference/rtc/web/interfaces/ibuffer-source-audio-track#startprocessaudiobuffer)。

- AudioSourceOptions

## 属性

### Optional cycle [#cycle]

```ts title="TypeScript"
cycle: number
```

设置循环播放的次数。

### Optional loop [#loop]

```ts title="TypeScript"
loop: boolean
```

设置是否无限循环。

### Optional startPlayTime [#startplaytime]

```ts title="TypeScript"
startPlayTime: number
```

设置开始播放的时间。
