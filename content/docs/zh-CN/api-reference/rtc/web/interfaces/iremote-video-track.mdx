远端视频轨道。 调用 [subscribe](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtcclient#subscribe) 后通过 [AgoraRTCRemoteUser.videoTrack](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtcremote-user#videotrack) 对象获取。

- [IRemoteTrack](/zh-CN/api-reference/rtc/web/interfaces/iremote-track)

## 事件

<a id="event_video_element_visible_status_2"></a>

### video-element-visible-status

```ts
video-element-visible-status(data?: CheckVideoVisibleResult): void
```

##### `自从`

<br /> *4.8.0*

提示 HTML `<video>` 标签的可见状态和不可见原因。SDK 每 30 秒触发一次该事件。

调用 `remoteVideoTrack.play` 后 SDK 会创建 [HTML &lt;video&gt;](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/video) 标签用于播放视频轨道。当 `remoteVideoTrack.isPlaying` 为 `true` 却看不到图像时，你可通过此事件来进行问题排查。

#### 参数

| 名称 | 描述 |
| --- | --- |
| Optional data: CheckVideoVisibleResult | `<video>` 标签的可见状态信息。 |

#### 返回值

void

## 属性

<a id="isplaying"></a>

### isPlaying

```ts
isPlaying: boolean
```

媒体轨道是否正在页面上播放。

- `true`: 媒体轨道正在页面上播放。
- `false`: 媒体轨道没有在页面上播放。

### getCurrentFrameData

```ts
getCurrentFrameData(): ImageData
```

##### `自从`

<br /> *4.1.0*

获取当前渲染的视频帧数据。

只有在播放后才能调用此方法，如果没有调用 [play](/zh-CN/api-reference/rtc/web/interfaces/iremote-video-track#play) 则返回空数据。

ImageData

存储了 RGBA 数据的 `ImageData` 对象。该对象为浏览器原生对象，详见 [ImageData](https://developer.mozilla.org/zh-CN/docs/Web/API/ImageData)。

<a id="getrtcrtptransceiver"></a>

### getRTCRtpTransceiver

```ts
getRTCRtpTransceiver(type?: StreamType): RTCRtpTransceiver | undefined
```

获取当前轨道的 [RTCRtpTransceiver](https://developer.mozilla.org/en-US/docs/Web/API/RTCRtpTransceiver) 实例。

该方法目前主要用于视频流的 [端到端加密（Beta）](https://doc.shengwang.cn/doc/rtc/javascript/advanced-features/e2e-encryption)。

如果 SDK 发生断线重连，当前轨道对应的 `RTCRtpTransceiver` 实例可能会发生变化。你可以通过以下回调来获取新的 `RTCRtpTransceiver` 实例： 本地轨道： [ILocalTrack.transceiver-updated](/zh-CN/api-reference/rtc/web/interfaces/ilocal-track#event_transceiver_updated) 远端轨道： [IRemoteTrack.transceiver-updated](/zh-CN/api-reference/rtc/web/interfaces/iremote-track#event_transceiver_updated_2)

#### 参数

| 名称 | 描述 |
| --- | --- |
| Optional type: StreamType | 视频流的类型。详见 [StreamType](/zh-CN/api-reference/rtc/web/enums/stream-type)。 |

#### 返回值

RTCRtpTransceiver | undefined

当前轨道的 `RTCRtpTransceiver` 实例。

<a id="getvideoelementvisiblestatus"></a>

### getVideoElementVisibleStatus

```ts
getVideoElementVisibleStatus(): CheckVideoVisibleResult | undefined
```

- @自从 <br /> *4.8.0*

获取 HTML `<video>` 标签的可见状态和不可见原因。

调用 `remoteVideoTrack.play` 后 SDK 会创建 [HTML &lt;video&gt;](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/video) 标签用于播放视频轨道。当 `remoteVideoTrack.isPlaying` 为 `true` 却看不到图像时，你可调用该方法进行问题排查。

#### 返回值

[CheckVideoVisibleResult](/zh-CN/api-reference/rtc/web/globals#checkvideovisibleresult) | undefined

[CheckVideoVisibleResult](/zh-CN/api-reference/rtc/web/globals#checkvideovisibleresult) 对象。如果该方法返回 `undefined`，可能为以下原因：

- `remoteVideoTrack.isPlaying` 为 `false`。
- `<video>` 标签不存在。
- `<video>` 标签不是通过 `play` 方法调用产生的。

<a id="once"></a>

### once

```ts
once(event: string, listener: Function): void
```

监听一个指定的事件，当事件触发时会调用传入的回调函数。

当监听后事件第一次触发时，该监听和回调函数就会被立刻移除，也就是只监听一次指定事件。

#### 参数

| 名称 | 描述 |
| --- | --- |
| event: string | 指定事件的名称。 |
| listener: Function | 传入的回调函数。 |

#### 返回值

void

<a id="play"></a>

### play

```ts
play(element: string | HTMLElement, config?: VideoPlayerConfig): void
```

在页面上播放本地视频轨道。

#### 参数

| 名称 | 描述 |
| --- | --- |
| element: string \| HTMLElement | 指定一个 DOM 元素，SDK 将在这个元素下创建 `<video>` 元素播放视频轨道，支持 2 种类型：<br />- `string`: 指定该 DOM 元素的 ID 值。<br />- `HTMLElement`: 直接传入一个 DOM 元素对象。 |
| Optional config: VideoPlayerConfig | 设置播放参数（镜像/显示模式）。详见 [VideoPlayerConfig](/zh-CN/api-reference/rtc/web/interfaces/video-player-config)。对于本地视频轨道，镜像模式默认开启。 |

#### 返回值

void
