### autoReceiveAndPlayAudio

<ApiSignature labels="Optional">

autoReceiveAndPlayAudio: boolean

</ApiSignature>

是否在加入频道时自动接收并尝试播放远端音频。

- `true`：是
- `false`：（默认）否

设置该参数为 `true` 后，SDK 会在用户加入频道时自动接收并尝试播放远端音频，减少入会后等待声音出现的时间。

该功能适用于语聊房、在线会议等需要入会后尽快听到声音的场景，直播观众端等默认需要接收频道内音频的场景，以及对远端音频首帧速度有较高要求的场景。

:::note[注意]
受浏览器自动播放策略影响，页面首次播放音频时仍可能需要用户进行点击或触摸操作。
:::

### autoSubscribe

<ApiSignature labels="Optional">

autoSubscribe: boolean

</ApiSignature>

是否自动订阅主播的媒体流。

- `true`：是
- `false`：（默认）否

在一对一或一对多实时互动场景中，设置该参数为 `true` 可以减少等待主播视频首桢渲染出图的时间。详见频道秒开。

:::note[注意]
如果设置自动订阅主播的媒体流，声网后台会在用户加入频道时就开始下发媒体流，并开始计费。
:::
