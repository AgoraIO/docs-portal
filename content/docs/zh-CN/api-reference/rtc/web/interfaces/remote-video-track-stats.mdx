远端视频轨道的统计数据，包括连接、传输等基本信息，可以通过 [AgoraRTCClient.getRemoteVideoStats](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtcclient#getremotevideostats) 获取。

- RemoteVideoTrackStats

## 属性

### Optional codecType [#codectype]

```ts title="TypeScript"
codecType: "H264" | "H265" | "VP8" | "VP9" | "AV1X" | "AV1"
```

视频编码格式。

- `"H264"`: 视频编码格式为 H.264。
- `"VP8"`: 视频编码格式为 VP8。
- `"VP9"`: 视频编码格式为 VP9。
- `"AV1X"`: 视频编码格式为 AV1，在 Chrome M96 版本之前。
- `"AV1"`: 视频编码格式为 AV1。

Firefox 上无法获取该值。

### currentPacketLossRate [#currentpacketlossrate]

```ts title="TypeScript"
currentPacketLossRate: number
```

接收的视频在 400ms 内的丢包率。

### Optional decodeFrameRate [#decodeframerate]

```ts title="TypeScript"
decodeFrameRate: number
```

视频解码帧率（fps）。

### end2EndDelay [#end2enddelay]

```ts title="TypeScript"
end2EndDelay: number
```

视频端到端延迟（ms）。

从远端采集视频到本地播放视频的延迟。该延迟不包括发送端编码和接收端解码的时间。

### freezeRate [#freezerate]

```ts title="TypeScript"
freezeRate: number
```

最近一秒接收视频的卡顿率。取值范围为 [0.0,1.0]，代表最近一秒内视频卡顿百分比。

### packetLossRate [#packetlossrate]

```ts title="TypeScript"
packetLossRate: number
```

接收的视频总丢包率。

### publishDuration [#publishduration]

```ts title="TypeScript"
publishDuration: number
```

远端发布视频时长 如果为 -1，说明暂时还无法获取发布时长

### receiveBitrate [#receivebitrate]

```ts title="TypeScript"
receiveBitrate: number
```

接收的视频码率（bps）。

### receiveBytes [#receivebytes]

```ts title="TypeScript"
receiveBytes: number
```

接收的视频总字节数。

### receiveDelay [#receivedelay]

```ts title="TypeScript"
receiveDelay: number
```

接收视频延迟 (ms)。

从发送到接收端播放视频的延迟时间。

Safari 和 Firefox 上该字段不准确。

### Optional receiveFrameRate [#receiveframerate]

```ts title="TypeScript"
receiveFrameRate: number
```

视频接收帧率（fps）。

### receivePackets [#receivepackets]

```ts title="TypeScript"
receivePackets: number
```

接收的视频总包数。

### receivePacketsLost [#receivepacketslost]

```ts title="TypeScript"
receivePacketsLost: number
```

接收的视频总丢包数。

### receiveResolutionHeight [#receiveresolutionheight]

```ts title="TypeScript"
receiveResolutionHeight: number
```

接收的视频分辨率高度。

### receiveResolutionWidth [#receiveresolutionwidth]

```ts title="TypeScript"
receiveResolutionWidth: number
```

接收的视频分辨率宽度。

### Optional renderFrameRate [#renderframerate]

```ts title="TypeScript"
renderFrameRate: number
```

视频渲染帧率（fps）。

### totalDuration [#totalduration]

```ts title="TypeScript"
totalDuration: number
```

接收的视频总时长，单位为秒。

### totalFreezeTime [#totalfreezetime]

```ts title="TypeScript"
totalFreezeTime: number
```

接收的视频总卡顿时长，单位为秒。

### transportDelay [#transportdelay]

```ts title="TypeScript"
transportDelay: number
```

传输延迟（ms)。

从远端发送视频到本地接收视频的延迟。
