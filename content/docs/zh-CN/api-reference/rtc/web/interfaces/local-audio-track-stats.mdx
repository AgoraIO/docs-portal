---
title: "LocalAudioTrackStats"
description: "LocalAudioTrackStats API 参考。"
---

本地音频轨道的基本信息，可以通过 [AgoraRTCClient.getLocalAudioStats](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtcclient#getlocalaudiostats) 获取。

- LocalAudioTrackStats

## 属性

### Optional codecType [#codectype]

```ts title="TypeScript"
codecType: "opus" | "aac" | "PCMU" | "PCMA" | "G722"
```

音频的编码格式。

- `"opus"`: 音频编码格式为 OPUS。
- `"aac"`: 音频编码格式为 AAC。
- `"pcmu"`: 预留参数，暂不支持。
- `"pcma"`: 预留参数，暂不支持。
- `"g722"`: 预留参数，暂不支持。

Firefox 上无法获取该值。

### currentPacketLossRate [#currentpacketlossrate]

```ts title="TypeScript"
currentPacketLossRate: number
```

发送的音频 400ms 内的丢包率。

### sendBitrate [#sendbitrate]

```ts title="TypeScript"
sendBitrate: number
```

发送的音频码率 (bps)。

### sendBytes [#sendbytes]

```ts title="TypeScript"
sendBytes: number
```

发送的音频总字节数 (bytes)。

### sendJitterMs [#sendjitterms]

```ts title="TypeScript"
sendJitterMs: number
```

发送音频数据包的抖动 (ms)。

### sendPackets [#sendpackets]

```ts title="TypeScript"
sendPackets: number
```

发送的音频总包数。

### sendPacketsLost [#sendpacketslost]

```ts title="TypeScript"
sendPacketsLost: number
```

发送的音频总丢包数。

Safari 上无法获取该值。

### sendRttMs [#sendrttms]

```ts title="TypeScript"
sendRttMs: number
```

发送音频数据包的往返时延 (ms)。

### sendVolumeLevel [#sendvolumelevel]

```ts title="TypeScript"
sendVolumeLevel: number
```

发送的音频音量等级，范围为 [0,32767]。

该值通过 WebRTC-Stats 获取，不能确保实时性。如果你想获取当前实时的音量等级，调用 [LocalAudioTrack.getVolumeLevel](/zh-CN/api-reference/rtc/web/interfaces/ilocal-audio-track#getvolumelevel)。
