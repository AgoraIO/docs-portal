### codecType

<ApiSignature labels="Optional">

codecType: "opus"|"aac"|"PCMU"|"PCMA"|"G722"

</ApiSignature>

音频的编码格式。

- `"opus"`: 音频编码格式为 OPUS。
- `"aac"`: 音频编码格式为 AAC。
- `"pcmu"`: 预留参数，暂不支持。
- `"pcma"`: 预留参数，暂不支持。
- `"g722"`: 预留参数，暂不支持。

:::caution[注意]
Firefox 上无法获取该值。
:::

### sendVolumeLevel

<ApiSignature>

sendVolumeLevel: number

</ApiSignature>

发送的音频音量等级，范围为 [0,32767]。

:::caution[注意]
该值通过 WebRTC-Stats 获取，不能确保实时性。如果你想获取当前实时的音量等级，调用 [LocalAudioTrack.getVolumeLevel](/zh-CN/api-reference/rtc/web/interfaces/ilocalaudiotrack#getvolumelevel)。
:::
