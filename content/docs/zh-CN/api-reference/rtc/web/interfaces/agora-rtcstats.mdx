当前通话的统计信息，可以通过 [AgoraRTCClient.getRTCStats](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtcclient#getrtcstats) 获取。

- AgoraRTCStats

## 属性

### Duration [#duration]

```ts title="TypeScript"
Duration: number
```

在当前频道内的时长，单位为秒。

### OutgoingAvailableBandwidth [#outgoingavailablebandwidth]

```ts title="TypeScript"
OutgoingAvailableBandwidth: number
```

上行可用带宽估计，单位为 Kbps。

### RTT [#rtt]

```ts title="TypeScript"
RTT: number
```

SDK 到声网边缘服务器的 RTT (Round-Trip Time)，单位 ms。

### RecvBitrate [#recvbitrate]

```ts title="TypeScript"
RecvBitrate: number
```

音视频总接收码率，单位为 bps，瞬间值。

### RecvBytes [#recvbytes]

```ts title="TypeScript"
RecvBytes: number
```

接收字节数，累计值。

### SendBitrate [#sendbitrate]

```ts title="TypeScript"
SendBitrate: number
```

音视频总发送码率，单位为 bps，瞬间值。

### SendBytes [#sendbytes]

```ts title="TypeScript"
SendBytes: number
```

发送字节数，累计值。

### UserCount [#usercount]

```ts title="TypeScript"
UserCount: number
```

通信场景下，该值为当前频道内的用户人数。

直播场景下，如果本地用户为主播，该值为当前频道内的主播人数；如果本地用户为观众，该值为当前频道内的主播人数 + 1。
