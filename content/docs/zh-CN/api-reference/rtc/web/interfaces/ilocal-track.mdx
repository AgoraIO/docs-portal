`LocalTrack` 为本地轨道的基础类，为音频轨道 [LocalAudioTrack](/zh-CN/api-reference/rtc/web/interfaces/ilocal-audio-track) 和视频轨道 [LocalVideoTrack](/zh-CN/api-reference/rtc/web/interfaces/ilocal-video-track) 提供一些公共的方法。

- ITrack

  - ILocalTrack

    - [ILocalAudioTrack](/zh-CN/api-reference/rtc/web/interfaces/ilocal-audio-track)
    - [ILocalVideoTrack](/zh-CN/api-reference/rtc/web/interfaces/ilocal-video-track)

## 事件

### track-ended [#event_track_ended]

```ts title="TypeScript"
track-ended(): void
```

音频或视频轨道被终止，终止的原因可能是：

- 摄像头被拔出
- 麦克风被拔出
- 用户主动停止了屏幕共享
- 用户主动关闭了底层的 `MediaStreamTrack`
- 媒体设备故障
- 正在使用中的媒体设备的权限被收回

#### 返回值

void

### transceiver-updated [#event_transceiver_updated]

```ts title="TypeScript"
transceiver-updated(transceiver: RTCRtpTransceiver, type?: StreamType): void
```

当前轨道的 `RTCRtpTransceiver` 实例更新回调。

#### 参数

| 名称 | 描述 |
| --- | --- |
| transceiver: RTCRtpTransceiver | 新的 `RTCRtpTransceiver` 实例。 |
| Optional type: StreamType | 当前轨道所属视频流的类型。详见 [StreamType](/zh-CN/api-reference/rtc/web/enums/stream-type)。 |

#### 返回值

void

## 属性

### enabled [#enabled]

```ts title="TypeScript"
enabled: boolean
```

本地轨道当前的启用状态。

### isPlaying [#isplaying]

```ts title="TypeScript"
isPlaying: boolean
```

媒体轨道是否正在页面上播放。

- `true`: 媒体轨道正在页面上播放。
- `false`: 媒体轨道没有在页面上播放。

### muted [#muted]

```ts title="TypeScript"
muted: boolean
```

本地媒体轨道当前的静音状态。

### trackMediaType [#trackmediatype]

```ts title="TypeScript"
trackMediaType: "audio" | "video"
```

媒体轨道的类型：

- `"audio"`: 音频轨道。
- `"video"`: 视频轨道。

### close [#close]

```ts title="TypeScript"
close(): void
```

关闭本地轨道，并释放相关采集设备。

一旦本地轨道被关闭，就无法再次使用。如需再次使用本地轨道，需要重新创建。

#### 返回值

void

### getRTCRtpTransceiver [#getrtcrtptransceiver]

```ts title="TypeScript"
getRTCRtpTransceiver(type?: StreamType): RTCRtpTransceiver | undefined
```

获取当前轨道的 [RTCRtpTransceiver](https://developer.mozilla.org/en-US/docs/Web/API/RTCRtpTransceiver) 实例。

该方法目前主要用于视频流的 [端到端加密（Beta）](https://doc.shengwang.cn/doc/rtc/javascript/advanced-features/e2e-encryption)。

如果 SDK 发生断线重连，当前轨道对应的 `RTCRtpTransceiver` 实例可能会发生变化。你可以通过以下回调来获取新的 `RTCRtpTransceiver` 实例： 本地轨道： [ILocalTrack.transceiver-updated](/zh-CN/api-reference/rtc/web/interfaces/ilocal-track#event_transceiver_updated) 远端轨道： [IRemoteTrack.transceiver-updated](/zh-CN/api-reference/rtc/web/interfaces/iremote-track#event_transceiver_updated_2)

#### 参数

| 名称 | 描述 |
| --- | --- |
| Optional type: StreamType | 视频流的类型。详见 [StreamType](/zh-CN/api-reference/rtc/web/enums/stream-type)。 |

#### 返回值

RTCRtpTransceiver | undefined

当前轨道的 `RTCRtpTransceiver` 实例。

### getTrackLabel [#gettracklabel]

```ts title="TypeScript"
getTrackLabel(): string
```

获取本地轨道的来源描述。

#### 返回值

string

可能返回以下值：

- 如果是通过 `createMicrophoneAudioTrack` 或 `createCameraVideoTrack` 创建的轨道，返回 [MediaDeviceInfo.label](https://developer.mozilla.org/en-US/docs/Web/API/MediaDeviceInfo/label) 字段。
- 如果是通过 `createScreenVideoTrack` 创建的轨道，返回屏幕共享的 `sourceId`。
- 如果是 `createCustomAudioTrack` 或 `createCustomVideoTrack` 创建的轨道，返回 [MediaStreamTrack.label](https://developer.mozilla.org/en-US/docs/Web/API/MediaStreamTrack/label) 字段。

### setEnabled [#setenabled]

```ts title="TypeScript"
setEnabled(enabled: boolean): Promise<void>
```

##### `自从`

<br /> *4.0.0*

启用/禁用该轨道。

轨道禁用后，播放和发布都将被停止。

禁用轨道不会触发 [LocalTrack.on("track-ended")](/zh-CN/api-reference/rtc/web/interfaces/ilocal-track#event_track_ended) 事件。 如果该轨道已发布，禁用轨道后，远端会触发 [user-unpublished](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtcclient#event_user_unpublished) 事件。重新启用后，远端会触发 [user-published](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtcclient#event_user_published) 事件。 `setEnabled` 和 `setMuted` 不能同时调用。

#### 参数

| 名称 | 描述 |
| --- | --- |
| enabled: boolean | 是否启用该轨道:<br />- `true`: 启用该轨道。<br />- `false`: 禁用该轨道。 |

#### 返回值

Promise &lt; void &gt;

### setMuted [#setmuted]

```ts title="TypeScript"
setMuted(muted: boolean): Promise<void>
```

发送或暂停发送该轨道的媒体数据。

##### `自从`

<br /> *4.0.0*

如果该轨道已发布，调用 `setMuted(true)` 后，远端会触发 [user-unpublished](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtcclient#event_user_unpublished) 事件。再调用 `setMuted(false)` 后，远端会触发 [user-published](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtcclient#event_user_published) 事件。

与 [setEnabled](/zh-CN/api-reference/rtc/web/interfaces/ilocal-track#setenabled) 相比，调用该方法响应速度更快且不影响视频采集状态，详见 [setEnabled 和 setMuted 有什么区别？](http://doc.shengwang.cn/faq/integration-issues/diff-setenabled-setmuted)。 `setEnabled` 和 `setMuted` 不能同时调用。

#### 参数

| 名称 | 描述 |
| --- | --- |
| muted: boolean | 是否发送该轨道的媒体数据:<br />- `true`: 暂停发送该轨道的媒体数据。<br />- `false`: 恢复发送该轨道的媒体数据。 |

#### 返回值

Promise &lt; void &gt;
