## Properties

<a id="exact"></a>

### Optional exact

exact: number

严格指定采集设备最终输出的值，如果设备不支持指定的值，采集会失败。

<a id="ideal"></a>

### Optional ideal

ideal: number

期望采集设备最终输出的值，如果设备不支持指定的值，会尽量输出一个最靠近的值。

<a id="max"></a>

### Optional max

max: number

采集设备最终输出的值上限。

<a id="min"></a>

### Optional min

min: number

采集设备最终输出的值下限。
