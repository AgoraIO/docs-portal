远端音频轨道的统计数据，包括连接、传输等基本信息，可以通过 [AgoraRTCClient.getRemoteAudioStats](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtcclient#getremoteaudiostats) 获取。

- RemoteAudioTrackStats

## 属性

### Optional codecType [#codectype]

```ts title="TypeScript"
codecType: "opus" | "aac" | "PCMU" | "PCMA" | "G722"
```

音频的编码格式。

- `"opus"`: 音频编码格式为 OPUS。
- `"aac"`: 音频编码格式为 AAC。
- `"pcmu"`: 预留参数，暂不支持。
- `"pcma"`: 预留参数，暂不支持。
- `"g722"`: 预留参数，暂不支持。

Firefox 上无法获取该值。

### currentPacketLossRate [#currentpacketlossrate]

```ts title="TypeScript"
currentPacketLossRate: number
```

接收的音频在 400ms 内的丢包率。

### end2EndDelay [#end2enddelay]

```ts title="TypeScript"
end2EndDelay: number
```

音频端到端延迟（ms）。

从远端采集音频到本地播放音频的延迟。该延迟不包括发送端编码和接收端解码的时间。

### freezeRate [#freezerate]

```ts title="TypeScript"
freezeRate: number
```

接收的音频卡顿率。

### packetLossRate [#packetlossrate]

```ts title="TypeScript"
packetLossRate: number
```

接收的音频总丢包率。

### publishDuration [#publishduration]

```ts title="TypeScript"
publishDuration: number
```

远端发布音频时长 如果为 -1，说明暂时还无法获取发布时长

### receiveBitrate [#receivebitrate]

```ts title="TypeScript"
receiveBitrate: number
```

接收的音频码率（bps）。

### receiveBytes [#receivebytes]

```ts title="TypeScript"
receiveBytes: number
```

接收的音频总字节数。

### receiveDelay [#receivedelay]

```ts title="TypeScript"
receiveDelay: number
```

接收音频延迟 (ms)。

从发送到接收端播放音频的延迟时间。

Safari 和 Firefox 上该字段不准确。

### receiveLevel [#receivelevel]

```ts title="TypeScript"
receiveLevel: number
```

接收的音频音量等级，范围为 [0,32767]。

该值通过 WebRTC-Stats 获取，不能确保实时性。如果你想获取当前实时的音量等级，调用 [RemoteAudioTrack.getVolumeLevel](/zh-CN/api-reference/rtc/web/interfaces/iremote-audio-track#getvolumelevel)。

### receivePackets [#receivepackets]

```ts title="TypeScript"
receivePackets: number
```

接收的音频总包数。

### receivePacketsDiscarded [#receivepacketsdiscarded]

```ts title="TypeScript"
receivePacketsDiscarded: number
```

因过早或过晚到达抖动缓冲器而被丢弃的数据包数量。

### receivePacketsLost [#receivepacketslost]

```ts title="TypeScript"
receivePacketsLost: number
```

接收的音频总丢包数。

### totalDuration [#totalduration]

```ts title="TypeScript"
totalDuration: number
```

接收的音频总时长，单位为秒。

### totalFreezeTime [#totalfreezetime]

```ts title="TypeScript"
totalFreezeTime: number
```

接收的音频总卡顿时长，单位为秒。

### transportDelay [#transportdelay]

```ts title="TypeScript"
transportDelay: number
```

传输延迟（ms)。

从远端发送音频到本地接收音频的延迟。
