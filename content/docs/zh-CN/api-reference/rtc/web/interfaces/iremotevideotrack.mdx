### video-element-visible-status

- video-element-visible-status(data?:[CheckVideoVisibleResult](/zh-CN/api-reference/rtc/web/globals#checkvideovisibleresult)):void

:::info[自从]
*4.8.0*

提示 HTML `&lt;video&gt;` 标签的可见状态和不可见原因。SDK 每 30 秒触发一次该事件。

调用 `remoteVideoTrack.play` 后 SDK 会创建 [HTML `&lt;video&gt;`](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/video) 标签用于播放视频轨道。当 `remoteVideoTrack.isPlaying` 为 `true` 却看不到图像时，你可通过此事件来进行问题排查。
:::

Parameters

- Optional data: [CheckVideoVisibleResult](/zh-CN/api-reference/rtc/web/globals#checkvideovisibleresult)

  `&lt;video&gt;` 标签的可见状态信息。

Returns void

### getCurrentFrameData

- getCurrentFrameData():ImageData

:::info[自从]
*4.1.0*

获取当前渲染的视频帧数据。

### getVideoElementVisibleStatus

- getVideoElementVisibleStatus():[CheckVideoVisibleResult](/zh-CN/api-reference/rtc/web/globals#checkvideovisibleresult)|undefined

- - @自从

   *4.8.0*

获取 HTML `&lt;video&gt;` 标签的可见状态和不可见原因。

调用 `remoteVideoTrack.play` 后 SDK 会创建 [HTML `&lt;video&gt;`](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/video) 标签用于播放视频轨道。当 `remoteVideoTrack.isPlaying` 为 `true` 却看不到图像时，你可调用该方法进行问题排查。
