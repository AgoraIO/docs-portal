### video-element-visible-status

<ApiSignature>

video-element-visible-status(data?: [CheckVideoVisibleResult](/zh-CN/api-reference/rtc/web/globals#checkvideovisibleresult)): void

:::info[自从]

提示 HTML `<video>` 标签的可见状态和不可见原因。SDK 每 30 秒触发一次该事件。
