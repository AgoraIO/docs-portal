基础本地音频轨道，提供了本地音频轨道的主要功能。

可以通过 [AgoraRTC.createCustomAudioTrack](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtc#createcustomaudiotrack) 来获取。

- 通过麦克风采集到的本地音频轨道对象 [MicrophoneAudioTrack](/zh-CN/api-reference/rtc/web/interfaces/imicrophone-audio-track) 继承于此接口，并在本接口的基础上提供了一些麦克风独有的功能。
- 通过音频文件获取到的本地音频轨道对象 [BufferSourceAudioTrack](/zh-CN/api-reference/rtc/web/interfaces/ibuffer-source-audio-track) 继承于此接口，并在本接口的基础上提供了一些音频文件独有的功能。

- [ILocalTrack](/zh-CN/api-reference/rtc/web/interfaces/ilocal-track)

  - ILocalAudioTrack

    - [IBufferSourceAudioTrack](/zh-CN/api-reference/rtc/web/interfaces/ibuffer-source-audio-track)
    - [IMicrophoneAudioTrack](/zh-CN/api-reference/rtc/web/interfaces/imicrophone-audio-track)

```ts title="TypeScript"

```

### isPlaying [#isplaying]

- `true`: 媒体轨道正在页面上播放。

```ts title="TypeScript"

本地媒体轨道当前的静音状态。

```

| --- | --- |
| Optional type: StreamType | 视频流的类型。详见 [StreamType](/zh-CN/api-reference/rtc/web/enums/stream-type)。 |

当前轨道的 `RTCRtpTransceiver` 实例。

### setAudioFrameCallback [#setaudioframecallback]

```ts title="TypeScript"
setAudioFrameCallback(audioFrameCallback: null | function, frameSize?: number): void
```

设置原始音频数据（PCM）回调。

设置成功后，SDK 会不断地将本地音频轨道的音频帧以 [AudioBuffer](https://developer.mozilla.org/en-US/docs/Web/API/AudioBuffer) 的形式通过回调返回。

你可以通过 `frameSize` 来设置每次回调中音频帧的大小。该设置也会影响回调的间隔， `frameSize` 越大，每次回调的音频数据越多，回调间隔越长。

```text title="Text"
track.setAudioFrameCallback((buffer) => {
  for (let channel = 0; channel < buffer.numberOfChannels; channel += 1) {
    // Float32Array with PCM data
    const currentChannelData = buffer.getChannelData(channel);
    console.log("PCM data in channel", channel, currentChannelData);
  }
}, 2048);

// ....
// Stop getting the raw audio data
track.setAudioFrameCallback(null);
```

#### 参数

| 名称 | 描述 |
| --- | --- |
| audioFrameCallback: null \| function | 用于接收 [AudioBuffer](https://developer.mozilla.org/en-US/docs/Web/API/AudioBuffer) 的回调函数。设为 `null` 后，SDK 就会停止获取音频原始数据。 |
| Optional frameSize: number | 每次回调的 `AudioBuffer` 中每个声道包含的采样数据个数，只能设为下列值：256, 512, 1024, 2048, 4096, 8192, 16384。默认为 4096。 |

#### 返回值

void

### setEnabled [#setenabled]

```ts title="TypeScript"
setEnabled(enabled: boolean): Promise<void>
```

##### `自从`

<br /> *4.0.0*

启用/禁用该轨道。

轨道禁用后，播放和发布都将被停止。

禁用轨道不会触发 [LocalTrack.on("track-ended")](/zh-CN/api-reference/rtc/web/interfaces/ilocal-track#event_track_ended) 事件。 如果该轨道已发布，禁用轨道后，远端会触发 [user-unpublished](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtcclient#event_user_unpublished) 事件。重新启用后，远端会触发 [user-published](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtcclient#event_user_published) 事件。 `setEnabled` 和 `setMuted` 不能同时调用。

#### 参数

| 名称 | 描述 |
| --- | --- |
| enabled: boolean | 是否启用该轨道:<br />- `true`: 启用该轨道。<br />- `false`: 禁用该轨道。 |

#### 返回值

Promise &lt; void &gt;

### setMuted [#setmuted]

```ts title="TypeScript"
setMuted(muted: boolean): Promise<void>
```

发送或暂停发送该轨道的媒体数据。

##### `自从`

<br /> *4.0.0*

如果该轨道已发布，调用 `setMuted(true)` 后，远端会触发 [user-unpublished](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtcclient#event_user_unpublished) 事件。再调用 `setMuted(false)` 后，远端会触发 [user-published](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtcclient#event_user_published) 事件。

与 [setEnabled](/zh-CN/api-reference/rtc/web/interfaces/ilocal-audio-track#setenabled) 相比，调用该方法响应速度更快且不影响视频采集状态，详见 [setEnabled 和 setMuted 有什么区别？](http://doc.shengwang.cn/faq/integration-issues/diff-setenabled-setmuted)。 `setEnabled` 和 `setMuted` 不能同时调用。

#### 参数

| 名称 | 描述 |
| --- | --- |
| muted: boolean | 是否发送该轨道的媒体数据:<br />- `true`: 暂停发送该轨道的媒体数据。<br />- `false`: 恢复发送该轨道的媒体数据。 |

#### 返回值

Promise &lt; void &gt;
