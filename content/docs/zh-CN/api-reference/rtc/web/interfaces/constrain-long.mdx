约束对象，一般用于在 [VideoEncoderConfiguration](/zh-CN/api-reference/rtc/web/interfaces/video-encoder-configuration) 中指定采集分辨率/帧率的范围。

- ConstrainLong

## 属性

### Optional exact [#exact]

```ts title="TypeScript"
exact: number
```

严格指定采集设备最终输出的值，如果设备不支持指定的值，采集会失败。

### Optional ideal [#ideal]

```ts title="TypeScript"
ideal: number
```

期望采集设备最终输出的值，如果设备不支持指定的值，会尽量输出一个最靠近的值。

### Optional max [#max]

```ts title="TypeScript"
max: number
```

采集设备最终输出的值上限。

### Optional min [#min]

```ts title="TypeScript"
min: number
```

采集设备最终输出的值下限。
