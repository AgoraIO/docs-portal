---
title: "LocalVideoTrackStats"
description: "LocalVideoTrackStats API 参考。"
---

本地视频轨道的基本信息，可以通过 [AgoraRTCClient.getLocalVideoStats](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtcclient#getlocalvideostats) 获取。

- LocalVideoTrackStats

## 属性

### Optional captureFrameRate [#captureframerate]

```ts title="TypeScript"
captureFrameRate: number
```

视频采集帧率（fps）。

Safari 和 Firefox 上无法获取该值。

### captureResolutionHeight [#captureresolutionheight]

```ts title="TypeScript"
captureResolutionHeight: number
```

视频采集的分辨率高度。

### captureResolutionWidth [#captureresolutionwidth]

```ts title="TypeScript"
captureResolutionWidth: number
```

视频采集的分辨率宽度。

### Optional codecType [#codectype]

```ts title="TypeScript"
codecType: "H264" | "H265" | "VP8" | "VP9" | "AV1X" | "AV1"
```

视频编码格式。

- `"H264"`: 视频编码格式为 H.264。
- `"VP8"`: 视频编码格式为 VP8。
- `"VP9"`: 视频编码格式为 VP9。
- `"AV1X"`: 预留参数，暂不支持。
- `"AV1"`: 视频编码格式为 AV1。

Firefox 上无法获取该值。

### currentPacketLossRate [#currentpacketlossrate]

```ts title="TypeScript"
currentPacketLossRate: number
```

发送的视频 400ms 内的丢包率。

### Optional encodeDelay [#encodedelay]

```ts title="TypeScript"
encodeDelay: number
```

视频编码延迟（ms）。

### sendBitrate [#sendbitrate]

```ts title="TypeScript"
sendBitrate: number
```

视频发送码率 (bps)。

### sendBytes [#sendbytes]

```ts title="TypeScript"
sendBytes: number
```

发送的视频总字节数 (bytes)。

### Optional sendFrameRate [#sendframerate]

```ts title="TypeScript"
sendFrameRate: number
```

视频发送帧率（fps）。

Firefox 上无法获取该值。

### sendJitterMs [#sendjitterms]

```ts title="TypeScript"
sendJitterMs: number
```

发送视频数据包的抖动 (ms)。

### sendPackets [#sendpackets]

```ts title="TypeScript"
sendPackets: number
```

发送的视频总包数。

### sendPacketsLost [#sendpacketslost]

```ts title="TypeScript"
sendPacketsLost: number
```

发送的视频总丢包数。

Safari 上无法获取该值。 Firefox 上该字段不准确。

### sendResolutionHeight [#sendresolutionheight]

```ts title="TypeScript"
sendResolutionHeight: number
```

视频发送的分辨率高度。

### sendResolutionWidth [#sendresolutionwidth]

```ts title="TypeScript"
sendResolutionWidth: number
```

视频发送的分辨率宽度。

### sendRttMs [#sendrttms]

```ts title="TypeScript"
sendRttMs: number
```

发送视频数据包的往返时延 (ms)。

### targetSendBitrate [#targetsendbitrate]

```ts title="TypeScript"
targetSendBitrate: number
```

视频目标发送码率 (bps)，即 [VideoEncoderConfiguration](/zh-CN/api-reference/rtc/web/interfaces/video-encoder-configuration) 中设置的码率。

### totalDuration [#totalduration]

```ts title="TypeScript"
totalDuration: number
```

视频总时长，单位为秒。

### totalFreezeTime [#totalfreezetime]

```ts title="TypeScript"
totalFreezeTime: number
```

视频总卡顿时长，单位为秒。
