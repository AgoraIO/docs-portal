---
title: "VideoEncoderConfiguration"
description: "VideoEncoderConfiguration API 参考。"
---

定义视频编码参数的配置对象。 你可以在 [AgoraRTC.createCameraVideoTrack](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtc#createcameravideotrack) 或者 [AgoraRTC.createScreenVideoTrack](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtc#createscreenvideotrack) 方法中传入自定义的视频编码配置。 SDK 提供了一些预设视频编码配置，详见 [VideoEncoderConfigurationPreset](/zh-CN/api-reference/rtc/web/globals#videoencoderconfigurationpreset)。 受操作系统、浏览器影响，实际的码率可能会和设置的取值范围不同。我们建议将码率设置在 100 Kbps 到 5000 Kbps 之间。

- VideoEncoderConfiguration

## 属性

<a id="bitratemax"></a>

### Optional bitrateMax

```ts
bitrateMax: number
```

传输过程中的最大码率，单位为 Kbps。

<a id="bitratemin"></a>

### Optional bitrateMin

```ts
bitrateMin: number
```

传输过程中的最小码率，单位为 Kbps。

<a id="framerate"></a>

### Optional frameRate

```ts
frameRate: number | ConstrainLong
```

视频帧率，单位为 fps。

支持传入 `number`，或一个约束对象，如 `{max: 30, min: 5}`。

关于约束对象的详细说明可以参考 [ConstrainLong](/zh-CN/api-reference/rtc/web/interfaces/constrain-long)。

<a id="height"></a>

### Optional height

```ts
height: number | ConstrainLong
```

视频的分辨率高。

支持传入 `number`，或一个约束对象，如 `{max: 1280, min: 720}`。

关于约束对象的详细说明可以参考 [ConstrainLong](/zh-CN/api-reference/rtc/web/interfaces/constrain-long)。

<a id="width"></a>

### Optional width

```ts
width: number | ConstrainLong
```

视频的分辨率宽。

支持传入 `number`，或一个约束对象，如 `{max: 1280, min: 720}`。

关于约束对象的详细说明可以参考 [ConstrainLong](/zh-CN/api-reference/rtc/web/interfaces/constrain-long)。
