小流的视频属性，用于 [setLowStreamParameter](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtcclient#setlowstreamparameter)。

- LowStreamParameter

## 属性

### Optional bitrate [#bitrate]

```ts title="TypeScript"
bitrate: number
```

小流视频的码率，单位为 Kbps。

### Optional framerate [#framerate]

```ts title="TypeScript"
framerate: ConstrainULong
```

小流视频的帧率。

可以传入一个 `number`，或一个约束对象，如 `{max: 30, min: 5}`。

关于约束对象的详细说明可以参考 [ConstrainLong](/zh-CN/api-reference/rtc/web/interfaces/constrain-long)。

### height [#height]

```ts title="TypeScript"
height: ConstrainULong
```

小流视频的分辨率高。

可以传入一个 `number`，或一个约束对象，如 `{max: 720, min: 480}`。

关于约束对象的详细说明可以参考 [ConstrainLong](/zh-CN/api-reference/rtc/web/interfaces/constrain-long)。

### width [#width]

```ts title="TypeScript"
width: ConstrainULong
```

小流视频的分辨率宽。

可以传入一个 `number`，或一个约束对象，如 `{max: 1280, min: 720}`。

关于约束对象的详细说明可以参考 [ConstrainLong](/zh-CN/api-reference/rtc/web/interfaces/constrain-long)。
