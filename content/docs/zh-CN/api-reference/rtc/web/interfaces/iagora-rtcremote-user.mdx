---
title: "IAgoraRTCRemoteUser"
description: "IAgoraRTCRemoteUser API 参考。"
---

频道内的远端用户信息，可以通过 [AgoraRTCClient.remoteUsers](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtcclient#remoteusers) 或者 [AgoraRTCClient.on("user-joined")](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtcclient#event_user_joined) 等事件获取。 该对象描述了频道内远端用户的当前状态，包括远端用户 ID、远端是否发布了音频或视频等。 如果检测到远端用户已经发布，可以将这个对象传入 [AgoraRTCClient.subscribe](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtcclient#subscribe) 中发起订阅，订阅成功后可以通过本对象的 [audioTrack](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtcremote-user#audiotrack) 或者 [videoTrack](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtcremote-user#videotrack) 字段获取远端音视频轨道对象用于播放。

- IAgoraRTCRemoteUser

## 属性

### Optional audioTrack [#audiotrack]

```ts title="TypeScript"
audioTrack: IRemoteAudioTrack
```

如果成功订阅了远端用户的音频，这里会保存远端的音频轨道对象。

### hasAudio [#hasaudio]

```ts title="TypeScript"
hasAudio: boolean
```

远端当前是否在发送音频。

- `true`: 远端用户在发送音频。
- `false`: 远端用户没有在发送音频。

### hasVideo [#hasvideo]

```ts title="TypeScript"
hasVideo: boolean
```

远端当前是否在发送视频。

- `true`: 远端用户在发送视频。
- `false`: 远端用户没有在发送视频。

### uid [#uid]

```ts title="TypeScript"
uid: UID
```

远端用户的用户 ID。

### Optional videoTrack [#videotrack]

```ts title="TypeScript"
videoTrack: IRemoteVideoTrack
```

如果成功订阅了远端用户的视频，这里会保存远端的视频轨道对象。
