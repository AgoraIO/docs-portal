### channelCount

<ApiSignature labels="Optional">

channelCount: number

</ApiSignature>

自定义音频轨道的声道数。发送 Multiopus 多声道音频时设置为 `4`、`6` 或 `8`，
 并在创建客户端时将 [ClientConfig.multiopus](/zh-CN/api-reference/rtc/web/interfaces/clientconfig#multiopus) 设置为 `true`。
 传入的 [mediaStreamTrack](/zh-CN/api-reference/rtc/web/interfaces/customaudiotrackinitconfig#mediastreamtrack) 应包含相应数量的声道；该配置不会为输入音频创建额外声道。

### encoderConfig

<ApiSignature labels="Optional">

encoderConfig: [AudioEncoderConfiguration](/zh-CN/api-reference/rtc/web/interfaces/audioencoderconfiguration)|[AudioEncoderConfigurationPreset](/zh-CN/api-reference/rtc/web/globals#audioencoderconfigurationpreset)

</ApiSignature>

控制音频的编码配置。

你可以通过 [AudioEncoderConfigurationPreset](/zh-CN/api-reference/rtc/web/globals#audioencoderconfigurationpreset) 传入 SDK 内置的编码配置；也可以通过传入一个 [AudioEncoderConfiguration](/zh-CN/api-reference/rtc/web/interfaces/audioencoderconfiguration) 来自定义音频编码配置。

:::caution[注意]
Firefox 不支持设置音频编码码率。
:::
