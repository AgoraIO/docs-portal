创建音频轨道时的配置参数。

- AudioTrackInitConfig

  - [MicrophoneAudioTrackInitConfig](/zh-CN/api-reference/rtc/web/interfaces/microphone-audio-track-init-config)

## 属性

### Optional AEC [#aec]

```ts title="TypeScript"
AEC: boolean
```

是否开启回声消除：

- `true`: 开启回声消除。
- `false`: 不开启回声消除。

### Optional AGC [#agc]

```ts title="TypeScript"
AGC: boolean
```

是否开启自动增益：

- `true`: 开启自动增益。
- `false`: 不开启自动增益。

### Optional ANS [#ans]

```ts title="TypeScript"
ANS: boolean
```

是否开启噪声抑制：

- `true`: 开启噪声抑制。
- `false`: 不开启噪声抑制。
