创建音频轨道时的配置参数。

- AudioTrackInitConfig

  - [MicrophoneAudioTrackInitConfig](/zh-CN/api-reference/rtc/web/interfaces/microphone-audio-track-init-config)

## Properties

<a id="aec"></a>

### Optional AEC

```ts
AEC: boolean
```

是否开启回声消除：

- `true`: 开启回声消除。
- `false`: 不开启回声消除。

<a id="agc"></a>

### Optional AGC

```ts
AGC: boolean
```

是否开启自动增益：

- `true`: 开启自动增益。
- `false`: 不开启自动增益。

<a id="ans"></a>

### Optional ANS

```ts
ANS: boolean
```

是否开启噪声抑制：

- `true`: 开启噪声抑制。
- `false`: 不开启噪声抑制。
