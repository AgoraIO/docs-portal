该对象描述了频道内远端用户的当前状态，包括远端用户 ID、远端是否发布了音频或视频等。

如果检测到远端用户已经发布，可以将这个对象传入 [AgoraRTCClient.subscribe](/zh-CN/api-reference/rtc/web/interfaces/iagorartcclient#subscribe) 中发起订阅，订阅成功后可以通过本对象的 [audioTrack](/zh-CN/api-reference/rtc/web/interfaces/iagorartcremoteuser#audiotrack) 或者 [videoTrack](/zh-CN/api-reference/rtc/web/interfaces/iagorartcremoteuser#videotrack) 字段获取远端音视频轨道对象用于播放。

### Optional audioTrack

audioTrack: [IRemoteAudioTrack](/zh-CN/api-reference/rtc/web/interfaces/iremoteaudiotrack)

如果成功订阅了远端用户的音频，这里会保存远端的音频轨道对象。

<a id="hasaudio"></a>

### hasAudio

hasAudio: boolean

远端当前是否在发送音频。

- `true`: 远端用户在发送音频。
- `false`: 远端用户没有在发送音频。

<a id="hasvideo"></a>

### hasVideo

hasVideo: boolean

远端当前是否在发送视频。

- `true`: 远端用户在发送视频。
- `false`: 远端用户没有在发送视频。

<a id="uid"></a>

### uid

uid: [UID](/zh-CN/api-reference/rtc/web/globals#uid)

远端用户的用户 ID。

### Optional videoTrack

videoTrack: [IRemoteVideoTrack](/zh-CN/api-reference/rtc/web/interfaces/iremotevideotrack)

如果成功订阅了远端用户的视频，这里会保存远端的视频轨道对象。
