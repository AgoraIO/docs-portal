通过 [getElectronScreenSources](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtc#getelectronscreensources) 获取的 Electron 下屏幕共享源信息。 详见 [Electron 官方文档](https://www.electronjs.org/docs/api/structures/desktop-capturer-source)。

- ElectronDesktopCapturerSource

## 属性

<a id="id"></a>

### id

```ts
id: string
```

Electron 屏幕共享源的 ID。

<a id="name"></a>

### name

```ts
name: string
```

Electron 屏幕共享源的名称。

<a id="thumbnail"></a>

### thumbnail

```ts
thumbnail: IElectronNativeImage
```

Electron 屏幕共享源的快照。

详见 [ElectronNativeImage](http://electron.atom.io/docs/api/native-image)。
