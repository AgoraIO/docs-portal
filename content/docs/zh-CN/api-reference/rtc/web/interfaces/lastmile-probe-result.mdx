通话前网络质量探测结果。该探测结果反应的是上、下行网络的综合质量。

### `自从`

<br /> *4.24.1* <br />

- LastmileProbeResult

## 属性

### Optional jitter [#jitter]

```ts title="TypeScript"
jitter: number
```

网络抖动 (ms)。

### Optional networkQuality [#networkquality]

```ts title="TypeScript"
networkQuality: number
```

网络质量：

- 1: 很好。
- 2: 一般。
- 3: 较差。
- 4: 很差。

### Optional packetLossRate [#packetlossrate]

```ts title="TypeScript"
packetLossRate: number
```

丢包率。

### Optional rtt [#rtt]

```ts title="TypeScript"
rtt: number
```

往返时延 (ms)。

### state [#state]

```ts title="TypeScript"
state: "complete" | "unavailable"
```

网络质量探测状态：

- `complete`：表示本次网络质量探测是完整的。
- `unavailable`：表示未进行网络质量探测。一个可能的原因是网络连接中断。
