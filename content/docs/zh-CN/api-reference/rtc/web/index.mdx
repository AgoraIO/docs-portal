本文档仅适用于声网 Web SDK 4.x。这是基于 Web SDK 3.x 的全量重构版本，不向下兼容。 查看 [Web SDK 4.x 介绍及迁移指南](https://doc.shengwang.cn/doc/rtc/javascript/overview/migration-guide)。 **查看 3.x 或之前版本的 [API 文档](https://docportal.shengwang.cn/cn/video-legacy/API%20Reference/web/index.html)。**

声网 Web SDK 是通过 HTML 网页加载的 JavaScript 和 Typescript 库。你可以使用声网 Web SDK 在网页浏览器中调用 API 建立连接，控制音视频通话和直播服务。

请务必使用 HTTPS 协议或者 localhost，否则 SDK 无法正常工作。

## AgoraRTCClient 类

调用 [createClient](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtc#createclient) 创建一个本地客户端对象 [AgoraRTCClient](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtcclient)，代表一个通话中的本地用户。 `AgoraRTCClient` 类提供音视频通话的核心功能，主要包含以下方法。

| 方法 | 描述 |
| --- | --- |
| [join](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtcclient#join) | 加入频道 |
| [leave](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtcclient#leave) | 离开频道 |
| [publish](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtcclient#publish) | 发布本地音视频轨道 |
| [unpublish](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtcclient#unpublish) | 取消发布本地音视频轨道 |
| [subscribe](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtcclient#subscribe) | 订阅远端用户的音视频轨道 |
| [unsubscribe](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtcclient#unsubscribe) | 取消订阅远端用户的音视频轨道 |

<a id="local-track"></a>

## LocalTrack 类

`LocalTrack` 是声网 Web SDK 中定义本地音视频轨道的抽象类，可用于本地播放和发布。

SDK 通过不同的方式创建不同的 `LocalTrack`，返回不同的 `LocalTrack` 派生类对象。以下列举了所有的 `LocalTrack` 派生类以及所对应的创建方式。

### 本地音频轨道

根据创建方式的不同，本地音频轨道可分为以下三种。其中 `LocalAudioTrack` 派生自 `LocalTrack`， `MicrophoneAudioTrack` 和 `BufferSourceAudioTrack` 派生自 `LocalAudioTrack`。

| 本地音频轨道 | 描述 |
| --- | --- |
| [LocalAudioTrack](/zh-CN/api-reference/rtc/web/interfaces/ilocal-audio-track) | 最基础的本地音频轨道对象，包含了基础的本地音频控制，如播放、设置音量控制。 <br /> 通过调用 [AgoraRTC.createCustomAudioTrack](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtc#createcustomaudiotrack) 创建。 |
| [MicrophoneAudioTrack](/zh-CN/api-reference/rtc/web/interfaces/imicrophone-audio-track) | 本地麦克风音频轨道对象，比 [LocalAudioTrack](/zh-CN/api-reference/rtc/web/interfaces/ilocal-audio-track) 多一些控制麦克风的方法。 <br /> 通过调用 [AgoraRTC.createMicrophoneAudioTrack](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtc#createmicrophoneaudiotrack) 创建。 |
| [BufferSourceAudioTrack](/zh-CN/api-reference/rtc/web/interfaces/ibuffer-source-audio-track) | 通过读取音频数据源创建的本地音频轨道，比基础的 [LocalAudioTrack](/zh-CN/api-reference/rtc/web/interfaces/ilocal-audio-track) 多一些控制音频数据源的方法。 <br /> 通过调用 [AgoraRTC.createBufferSourceAudioTrack](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtc#createbuffersourceaudiotrack) 创建。 |

### 本地视频轨道

根据创建方式的不同，本地视频可分为以下两种。其中 `LocalVideoTrack` 派生自 `LocalTrack`， `CameraVideoTrack` 派生自 `LocalVideoTrack`。

| 本地视频轨道 | 描述 |
| --- | --- |
| [LocalVideoTrack](/zh-CN/api-reference/rtc/web/interfaces/ilocal-video-track) | 最基础的本地视频轨道对象，包含了基础的本地视频控制，如播放、美颜。 <br /> 通过调用 [AgoraRTC.createCustomVideoTrack](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtc#createcustomvideotrack) 或 [AgoraRTC.createScreenVideoTrack](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtc#createscreenvideotrack) 创建。 |
| [CameraVideoTrack](/zh-CN/api-reference/rtc/web/interfaces/icamera-video-track) | 本地摄像头视频轨道对象，比 [LocalVideoTrack](/zh-CN/api-reference/rtc/web/interfaces/ilocal-video-track) 多一些控制摄像头和编码参数的方法。 <br /> 通过调用 [AgoraRTC.createCameraVideoTrack](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtc#createcameravideotrack) 创建。 |

<a id="remote-track"></a>

## RemoteTrack 类

`RemoteTrack` 是声网 Web SDK 中用于定义远端音视频轨道的抽象类。

在实际操作中，你需要先调用 [AgoraRTCClient.subscribe](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtcclient#subscribe) 订阅远端用户，然后从远端用户对象 [AgoraRTCRemoteUser](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtcremote-user) 中获取派生自 `RemoteTrack` 的 [RemoteAudioTrack](/zh-CN/api-reference/rtc/web/interfaces/iremote-audio-track) 对象和 [RemoteVideoTrack](/zh-CN/api-reference/rtc/web/interfaces/iremote-video-track) 对象。

## 引入方式

如果你通过 `<script>` 的方式引入声网 Web SDK，可以通过访问 [AgoraRTC.createClient](/zh-CN/api-reference/rtc/web/interfaces/iagora-rtc#createclient) 来获取导出的模块。

如果你通过 `npm` 或者模块化的方式引入声网 Web SDK，可以通过以下方式访问 `AgoraRTC`:

```text
import AgoraRTC from "agora-rtc-sdk-ng";
console.log(AgoraRTC.createClient);
```

## 类型模块（适用于 Typescript）

对于 Typescript 开发者，我们提供了 `.d.ts` 文件导出详细的类型定义。通过 npm 集成 SDK 后，你可以在 `node_modules/agora-rtc-sdk-ng` 路径下找到该文件。API 文档的 [Global](/zh-CN/api-reference/rtc/web/globals) 页面列出了所有 SDK 导出的模块和类型。

```text
import AgoraRTC, { IAgoraRTCClient } from "agora-rtc-sdk-ng";

const client: IAgoraRTCClient = AgoraRTC.createClient();
```
