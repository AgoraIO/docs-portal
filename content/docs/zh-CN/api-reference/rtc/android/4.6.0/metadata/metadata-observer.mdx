## getMaxMetadataSize

当 SDK 请求元数据最大大小时触发的回调。

<a id="api_imetadataobserver_getmaxmetadatasize__prototype"></a>

```java
public abstract int getMaxMetadataSize()
```

<a id="api_imetadataobserver_getmaxmetadatasize__detailed_desc"></a>

调用 [registerMediaMetadataObserver](/zh-CN/api-reference/rtc/android/4.6.0/metadata/metadata-observer#api_irtcengine_registermediametadataobserver) 成功注册后，SDK 在每发送一帧视频时会触发该回调。你需要在该回调的返回值中指定元数据的最大大小。

<a id="api_imetadataobserver_getmaxmetadatasize__return_values"></a>

### 返回值

方法调用成功，返回你希望使用的元数据 `buffer` 的最大大小，单位为字节。最大值为 1024 字节。请确保设置返回值。

### 所属接口类
- [IMetadataObserver](/zh-CN/api-reference/rtc/android/4.6.0/full-sdk-api-list#class_imetadataobserver)

## registerMediaMetadataObserver

注册元数据观察器。

<a id="api_irtcengine_registermediametadataobserver__prototype"></a>

```java
public abstract int registerMediaMetadataObserver(IMetadataObserver observer, int type);
```

<a id="api_irtcengine_registermediametadataobserver__detailed_desc"></a>

你需要实现 [IMetadataObserver](/zh-CN/api-reference/rtc/android/4.6.0/full-sdk-api-list#class_imetadataobserver) 类，并在该方法中指定元数据类型。该方法支持你在视频流中添加同步元数据，以实现更丰富的互动直播场景，例如发送购物链接、数字优惠券和在线问答。成功调用该方法后，SDK 会触发 [getMaxMetadataSize](/zh-CN/api-reference/rtc/android/4.6.0/metadata/metadata-observer#api_imetadataobserver_getmaxmetadatasize) 回调。

:::info[注]
请在调用 `joinChannel` 之前调用此方法。
:::

<a id="api_irtcengine_registermediametadataobserver__parameters"></a>

### 参数

#### `observer`

元数据观察器，详见 [IMetadataObserver](/zh-CN/api-reference/rtc/android/4.6.0/full-sdk-api-list#class_imetadataobserver)。

#### `type`

元数据类型。当前 SDK 仅支持以下类型：

- VIDEO_METADATA：视频元数据。

<a id="api_irtcengine_registermediametadataobserver__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](/zh-CN/realtime-media/rtc/reference/error-code)了解详情和解决建议。

### 所属接口类
- [RtcEngine](/zh-CN/api-reference/rtc/android/4.6.0/full-sdk-api-list#class_irtcengine)

<a id="callback_imetadataobserver_onreadytosendmetadata"></a>

## onReadyToSendMetadata

SDK 准备好发送元数据时触发的回调。

<a id="callback_imetadataobserver_onreadytosendmetadata__prototype"></a>

```java
public abstract byte[] onReadyToSendMetadata(long timeStampMs, int sourceType)
```

<a id="callback_imetadataobserver_onreadytosendmetadata__detailed_desc"></a>

:::info[注]
请确保元数据的大小不超过 [getMaxMetadataSize](/zh-CN/api-reference/rtc/android/4.6.0/metadata/metadata-observer#api_imetadataobserver_getmaxmetadatasize) 回调中设置的值。
:::

<a id="callback_imetadataobserver_onreadytosendmetadata__timing"></a>

### 触发时机

该回调在 SDK 准备好发送元数据时被触发。

<a id="callback_imetadataobserver_onreadytosendmetadata__parameters"></a>

### 参数

#### `timeStampMs`

时间戳。

#### `sourceType`

视频数据类型。详见 [VideoSourceType](/zh-CN/api-reference/rtc/android/4.6.0/class-and-enum/enums/enum-videosourcetype)。

<a id="callback_imetadataobserver_onreadytosendmetadata__return_values"></a>

### 返回值

方法调用成功时，返回希望发送的元数据，格式为字节数组。

### 所属接口类
- [IMetadataObserver](/zh-CN/api-reference/rtc/android/4.6.0/full-sdk-api-list#class_imetadataobserver)
