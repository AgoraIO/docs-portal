## clearRemotePositions

移除所有远端用户的空间位置。

<a id="api_ibasespatialaudioengine_clearremotepositions__prototype"></a>

```java
public abstract int clearRemotePositions();
```

<a id="api_ibasespatialaudioengine_clearremotepositions__detailed_desc"></a>

调用该方法后，本地用户将无法再听到任何远端用户的声音。你也可以在离开频道后调用该方法以释放资源。

<a id="api_ibasespatialaudioengine_clearremotepositions__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](/zh-CN/realtime-media/rtc/reference/error-code)了解详情和解决建议。

## enableSpatialAudio

启用或关闭空间音效。

<a id="api_irtcengine_enablespatialaudio__prototype"></a>

```java
public abstract int enableSpatialAudio(boolean enabled);
```

<a id="api_irtcengine_enablespatialaudio__detailed_desc"></a>

注：

- 你可以在加入频道前或加入频道后调用此方法。

<a id="api_irtcengine_enablespatialaudio__parameters"></a>

### 参数

#### `enabled`

是否启用空间音效：

- false：关闭空间音效。

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](/zh-CN/realtime-media/rtc/reference/error-code)了解详情和解决建议。

## muteAllRemoteAudioStreams

停止或恢复订阅所有远端用户的音频流。

<a id="api_ibasespatialaudioengine_muteallremoteaudiostreams_ibasespatialaudioengine__prototype"></a>

```java
public abstract int muteAllRemoteAudioStreams(boolean mute);
```

<a id="api_ibasespatialaudioengine_muteallremoteaudiostreams_ibasespatialaudioengine__detailed_desc"></a>

调用该方法后，本地用户将停止或恢复订阅所有远端用户的音频流，包括后续加入频道的用户。

注：

- 请在调用 joinChannel 方法后调用本方法。
- 使用空间音效时，如需设置是否停止订阅所有远端用户的音频流，声网推荐使用本方法，而非 RtcEngine 下的同名方法。
- 调用本方法后，需要调用 updateSelfPosition 和 updateRemotePosition 方法更新本地用户和远端用户的空间位置，否则本方法的设置不会生效。

<a id="api_ibasespatialaudioengine_muteallremoteaudiostreams_ibasespatialaudioengine__parameters"></a>

### 参数

#### `mute`

是否停止订阅所有远端用户的音频流：

- true：停止订阅所有远端用户的音频流。
- false：订阅所有远端用户的音频流。

<a id="api_ibasespatialaudioengine_muteallremoteaudiostreams_ibasespatialaudioengine__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](/zh-CN/realtime-media/rtc/reference/error-code)了解详情和解决建议。

### 所属接口类
- [IBaseSpatialAudioEngine](/zh-CN/api-reference/rtc/android/full-sdk-api-list#class_ibasespatialaudioengine)

<a id="api_ibasespatialaudioengine_muteremoteaudiostream_ibasespatialaudioengine__detailed_desc"></a>

## setDistanceUnit

设置游戏引擎中每个单位距离对应的米数。

<a id="api_ibasespatialaudioengine_setdistanceunit__prototype"></a>

```java
public abstract int setDistanceUnit(float unit);
```

<a id="api_ibasespatialaudioengine_setdistanceunit__detailed_desc"></a>

在声网的空间音效算法中，距离以米为单位进行计算。SDK 默认将游戏引擎中的每个单位距离转换为 1 米。你可以调用该方法将游戏引擎中的每个单位距离转换为指定的米数。

<a id="api_ibasespatialaudioengine_setdistanceunit__parameters"></a>

### 参数

#### `unit`

游戏引擎中每个单位距离对应的米数。该参数必须大于 0.00，默认值为 1.00。例如，将该参数设置为 2.00 表示游戏引擎中每个单位距离等于 2 米。该值越大，当远端用户远离本地用户时，本地用户听到的声音衰减得越快。

<a id="api_ibasespatialaudioengine_setdistanceunit__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](/zh-CN/realtime-media/rtc/reference/error-code)了解详情和解决建议。

## setPlayerAttenuation

设置媒体播放器的声音衰减属性。

<a id="api_ibasespatialaudioengine_setplayerattenuation__prototype"></a>

```java
public abstract int setPlayerAttenuation(int playerId, double attenuation, boolean forceSet);
```

<a id="api_ibasespatialaudioengine_setplayerattenuation__detailed_desc"></a>

<a id="api_ibasespatialaudioengine_setplayerattenuation__parameters"></a>

### 参数

#### `playerId`

媒体播放器的 ID。你可以通过调用 [getMediaPlayerId](/zh-CN/api-reference/rtc/android/playback/media-player/mediaplayer-info#api_imediaplayer_getmediaplayerid) 获取该 ID。

#### `attenuation`

远端用户或媒体播放器的声音衰减系数，取值范围为 [0,1]。具体说明如下：

- 0：广播模式，音量和音色不随距离衰减，本地用户听到的音量和音色不会因距离变化而变化。
- (0, 0.5)：弱衰减模式，音量和音色在传播过程中仅有轻微衰减，声音传播距离比真实环境更远。
- 0.5：（默认）模拟真实环境中的音量衰减效果，等效于未设置 speaker_attenuation 参数。
- (0.5, 1]：强衰减模式，音量和音色在传播过程中迅速衰减。

#### `forceSet`

是否强制设置媒体播放器的声音衰减效果：

- true：强制使用 attenuation 设置媒体播放器的衰减效果，此时 SpatialAudioZone 中 audioAttenuation 设置的隔音区衰减系数对媒体播放器无效。
- false：不强制使用 attenuation 设置媒体播放器的声音衰减效果，具体如下：
  - 如果声源和听众分别位于隔音区内外，声音衰减效果由 SpatialAudioZone 中的 audioAttenuation 决定。
  - 如果声源和听众位于同一隔音区内或同一隔音区外，声音衰减效果由本方法中的 attenuation 参数决定。

<a id="api_ibasespatialaudioengine_setplayerattenuation__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](/zh-CN/realtime-media/rtc/reference/error-code)了解详情和解决建议。

## setZones

设置隔音区域。

<a id="api_ibasespatialaudioengine_setzones__prototype"></a>

```java
public abstract int setZones(SpatialAudioZone[] zones);
```

<a id="api_ibasespatialaudioengine_setzones__detailed_desc"></a>

在虚拟互动场景中，你可以使用该方法设置隔音区域及声音衰减系数。当声源（可以是用户或媒体播放器）和接收者分别处于隔音区域的内外时，可以体验到类似真实环境中声音遇到建筑隔断时的衰减效果：

- 当声源和接收者分别处于隔音区域的内外时，声音的衰减效果由 SpatialAudioZone 中的声音衰减系数决定。
- 如果用户或媒体播放器处于同一个隔音区域内，则声音衰减效果由 setPlayerAttenuation 或 setRemoteAudioAttenuation 中的 attenuation 参数决定。如果你未调用 setPlayerAttenuation 或 setRemoteAudioAttenuation，SDK 默认的声音衰减系数为 0.5，用于模拟真实环境中的声音衰减。
- 如果声源和接收者分别处于两个不同的隔音区域，接收者将无法听到声源。

:::info[注]
如果多次调用该方法，以最后一次设置的隔音区域为准。
:::

<a id="api_ibasespatialaudioengine_setzones__parameters"></a>

### 参数

#### `zones`

隔音区域设置。当该参数设置为 `null` 时，表示清除所有隔音区域。详见 [SpatialAudioZone](/zh-CN/api-reference/rtc/android/class-and-enum/classes/class-spatialaudiozone)。

<a id="api_ibasespatialaudioengine_setzones__return_values"></a>

### 返回值

- &lt; 0：方法调用失败。详见[错误码](/zh-CN/realtime-media/rtc/reference/error-code)了解详情和解决建议。
