---
title: "Rectangle"
description: "用于设置目标区域相对于屏幕或窗口的位置。"
---
<a id="class_rectangle__prototype"></a>

```java
public static class Rectangle {
  public int x = 0;
  public int y = 0;
  public int width = 0;
  public int height = 0;
}
```

<a id="class_rectangle__detailed_desc"></a>

### `自从`

自 v4.6.0 版本新增。

如果不设置该参数，SDK 默认选择整个屏幕或窗口作为目标区域。

<a id="class_rectangle__parameters"></a>

## 属性

### `x`

距左上角的水平偏移量。

### `y`

距左上角的垂直偏移量。

### `width`

目标区域的宽度。

### `height`

目标区域的高度。
