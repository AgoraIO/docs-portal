<a id="class_advanceoptions__prototype"></a>

```java
static public class AdvanceOptions {
    public ENCODING_PREFERENCE encodingPreference;
    public COMPRESSION_PREFERENCE compressionPreference;
    public boolean encodeAlpha;
  }
```

<a id="class_advanceoptions__parameters"></a>

## 属性

### `encodingPreference`

视频编码器优先级设置，详见 [ENCODING_PREFERENCE](/zh-CN/api-reference/rtc/android/class-and-enum/enums/enum-encodingpreference)。

### `compressionPreference`

视频编码的压缩偏好设置，详见 [COMPRESSION_PREFERENCE](/zh-CN/api-reference/rtc/android/class-and-enum/enums/enum-compressionpreference)。

### `encodeAlpha`

是否对视频帧中存在的 Alpha 数据进行编码并发送给远端：

- true：编码并发送 Alpha 数据。
- false （默认）：不编码和发送 Alpha 数据。
