<a id="class_codeccapinfo__prototype"></a>

```java
public class CodecCapInfo {
  public int codecType;
  public int codecCapMask;
  public CodecCapLevels codecLevels;
}
```

<a id="class_codeccapinfo__parameters"></a>

## 属性

### `codecType`

视频编解码类型：

- 1：VP8。
- 2：H.264。
- 3：（默认）H.265。

### `codecCapMask`

编解码类型的位掩码：

- (0)：设备不支持编码或解码。
- (1 &lt;&lt; 0)：设备支持硬件解码。
- (1 &lt;&lt; 1)：设备支持硬件编码。
- (1 &lt;&lt; 2)：设备支持软件解码。
- (1 &lt;&lt; 3)：设备支持软件编码。

### `codecLevels`

编解码能力。详见 [CodecCapLevels](/zh-CN/api-reference/rtc/android/4.6.0/class-and-enum/classes/class-codeccaplevels)。
