<a id="class_channelmediarelayconfiguration__prototype"></a>

```java
public class ChannelMediaRelayConfiguration {
  private ChannelMediaInfo srcInfo = null;
  private Map<String, ChannelMediaInfo> destInfos = null;
}
```

<a id="class_channelmediarelayconfiguration__parameters"></a>

## 属性

### `srcInfo`

源频道的媒体信息。详见 [ChannelMediaInfo](/zh-CN/api-reference/rtc/android/4.6.0/class-and-enum/classes/class-channelmediainfo)。

### `destInfos`

目标频道的媒体信息集合，键为频道名，值为对应的媒体信息。详见 [ChannelMediaInfo](/zh-CN/api-reference/rtc/android/4.6.0/class-and-enum/classes/class-channelmediainfo)。
