
<a id="api_livetranscoding_removebackgroundimage__detailed_desc"></a>

## 参数

### `backgroundImage`

要移除的背景图像。详见 [AgoraImage](/zh-CN/api-reference/rtc/android/4.6.0/class-and-enum/classes/class-rtcimage)。

<a id="api_livetranscoding_removebackgroundimage__return_values"></a>

## 返回值

- true：移除成功。
- false：移除失败。
