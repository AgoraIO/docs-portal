## 属性

### lanTxBytes

通过局域网发送的字节总数。

### lanRxBytes

通过局域网接收的字节总数。

### wifiTxBytes

通过 Wi-Fi 发送的字节总数。

### wifiRxBytes

通过 Wi-Fi 接收的字节总数。

### mobileTxBytes

通过移动网络发送的字节总数。

### mobileRxBytes

通过移动网络接收的字节总数。

### activePathNum

当前活跃的传输路径数量。

### pathStats

每条活跃传输路径的统计信息数组。详见 [PathStats](/zh-CN/api-reference/rtc/android/class-pathstats)。
