## <span id="toc_camera_capture"></span>startCameraCapture [#api_irtcengine_startcameracapture]

开始视频采集。

<a id="api_irtcengine_startcameracapture__prototype"></a>

```java
public abstract int startCameraCapture(Constants.VideoSourceType sourceType, CameraCapturerConfiguration config);
```

<a id="api_irtcengine_startcameracapture__detailed_desc"></a>

你可以调用该方法，并通过指定 `sourceType` 开始从一个或多个摄像头采集视频。

:::info[注]
在 Android 设备上，如果设备有多个摄像头或支持外接摄像头，你最多可以从 4 个摄像头采集视频。
:::

### 参数 [#api_irtcengine_startcameracapture__parameters]

#### `sourceType`

视频源的类型。详见 [VideoSourceType](/zh-CN/api-reference/rtc/android/enum-videosourcetype)。

:::info[注]
在 Android 设备上，如果设备有多个摄像头或支持外接摄像头，你最多可以从 4 个摄像头采集视频。
:::

#### `config`

视频采集的配置。详见 [CameraCapturerConfiguration](/zh-CN/api-reference/rtc/android/class-cameracapturerconfiguration)。

### 返回值 [#api_irtcengine_startcameracapture__return_values]

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/android/error-code)了解详情和解决建议。

- [RtcEngine](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_irtcengine)

## stopCameraCapture [#api_irtcengine_stopcameracapture]

停止摄像头采集。

<a id="api_irtcengine_stopcameracapture__prototype"></a>

```java
public abstract int stopCameraCapture(Constants.VideoSourceType sourceType);
```

<a id="api_irtcengine_stopcameracapture__detailed_desc"></a>

你可以调用 [stopCameraCapture](/zh-CN/api-reference/rtc/android/video/camera-capture#api_irtcengine_stopcameracapture) 并设置 `sourceType` 参数，停止指定摄像头的视频采集。

:::info[注]
如果你正在使用本地合图功能，调用此方法可能会导致本地合图中断。
:::

### 参数 [#api_irtcengine_stopcameracapture__parameters]

#### `sourceType`

视频源的类型。详见 [VideoSourceType](/zh-CN/api-reference/rtc/android/enum-videosourcetype)。

### 返回值 [#api_irtcengine_stopcameracapture__return_values]

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/android/error-code)了解详情和解决建议。

- [RtcEngine](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_irtcengine)
