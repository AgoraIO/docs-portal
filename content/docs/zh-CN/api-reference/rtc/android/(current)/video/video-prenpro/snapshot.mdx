## enableContentInspect

启用或关闭本地截图上传功能。

<a id="api_irtcengine_enablecontentinspect__prototype"></a>

```text
public abstract int enableContentInspect(boolean enabled, ContentInspectConfig config);
```

<a id="api_irtcengine_enablecontentinspect__detailed_desc"></a>

SDK 会根据在 [ContentInspectConfig](/zh-CN/api-reference/rtc/android/class-contentinspectconfig) 中设置的模块类型和频率，对本地用户发送的视频进行截图并上传。完成截图和上传后，声网服务器会通过 HTTPS 请求将回调通知发送到你的应用服务器，并将所有截图发送到第三方云存储服务。

:::note
注：

- 在调用该方法前，请确保你已在声网控制台启用本地截图上传功能。
- 当视频审核模块设置为使用声网自研扩展（`CONTENT_INSPECT_TYPE_SUPERVISE`）进行视频审核时，需要使用本地截图上传动态库 agora_content_inspect_extension.so。删除该库将禁用截图上传功能。
:::

<a id="api_irtcengine_enablecontentinspect__timing"></a>

### 调用时机

该方法可以在加入频道前或加入频道后调用。

<a id="api_irtcengine_enablecontentinspect__parameters"></a>

### 参数

### enabled

是否启用本地截图上传功能：

- true：启用本地截图上传功能。
- false：关闭本地截图上传功能。

### config

截图上传配置，详见 [ContentInspectConfig](/zh-CN/api-reference/rtc/android/class-contentinspectconfig)。

<a id="api_irtcengine_enablecontentinspect__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。

### 所属接口类

- [RtcEngine](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_irtcengine)

## takeSnapshot [1/2]

截取指定用户的视频流快照并保存为 JPG 图像。

<a id="api_irtcengine_takesnapshot__prototype"></a>

```text
public abstract int takeSnapshot(int uid, String filePath);
```

<a id="api_irtcengine_takesnapshot__detailed_desc"></a>

:::note
注： 该方法为异步方法，调用返回时 SDK 尚未完成快照操作。当用于本地视频快照时，该方法会对 [ChannelMediaOptions](/zh-CN/api-reference/rtc/android/class-channelmediaoptions) 中指定的视频流进行快照。如果用户的视频已进行预处理，例如添加水印或美颜，生成的快照将包含预处理效果。
:::

<a id="api_irtcengine_takesnapshot__timing"></a>

### 调用时机

请在加入频道后调用该方法。

<a id="api_irtcengine_takesnapshot__related"></a>

### 相关回调

调用该方法成功后，SDK 会触发 [onSnapshotTaken](/zh-CN/api-reference/rtc/android/video/video-prenpro/snapshot#callback_irtcengineeventhandler_onsnapshottaken) 回调，报告快照是否成功以及快照的详细信息。

<a id="api_irtcengine_takesnapshot__parameters"></a>

### 参数

### uid

用户 ID。如果要截取本地用户的视频快照，请将 `uid` 设置为 0。

### filePath

:::note
注： 请确保指定的路径存在且可写。
:::

快照的本地路径（包含文件扩展名）。例如：

- Android: `/storage/emulated/0/Android/data/&lt;package name&gt;/files/example.jpg`

<a id="api_irtcengine_takesnapshot__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。

### 所属接口类

- [RtcEngine](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_irtcengine)

## onSnapshotTaken

视频截图结果回调。

<a id="callback_irtcengineeventhandler_onsnapshottaken__prototype"></a>

```text
public void onSnapshotTaken(int uid, String filePath, int width, int height, int errCode)
```

<a id="callback_irtcengineeventhandler_onsnapshottaken__detailed_desc"></a>

该回调在调用 `takeSnapshot` 方法成功后被触发，用于报告截图的详细信息和是否成功。

<a id="callback_irtcengineeventhandler_onsnapshottaken__timing"></a>

### 触发时机

该回调在调用 `takeSnapshot` 方法成功后被触发。

<a id="callback_irtcengineeventhandler_onsnapshottaken__parameters"></a>

### 参数

### uid

用户 ID。`uid` 为 0 表示本地用户。

### filePath

截图的本地路径。

### width

截图的宽度（像素）。

### height

截图的高度（像素）。

### errCode

截图结果的错误码：

- 0：成功。
- &lt; 0：失败：

  - -1：SDK 写入文件或编码 JPEG 图像失败。
  - -2：调用 `takeSnapshot` 方法成功后 1 秒内未找到指定用户的视频流。可能原因包括：本地采集停止、远端停止发布或视频数据处理阻塞。
  - -3：调用 `takeSnapshot` 方法过于频繁。

### 所属接口类

- [IRtcEngineEventHandler](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_irtcengineeventhandler)
