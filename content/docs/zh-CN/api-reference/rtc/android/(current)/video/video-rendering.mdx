## <span id="toc_video_rendering"></span>enableInstantMediaRendering [#api_irtcengine_enableinstantmediarendering]

启用音视频帧的即时渲染。

<a id="api_irtcengine_enableinstantmediarendering__prototype"></a>

```java
public abstract int enableInstantMediaRendering();
```

#### `自从` [#api_irtcengine_enableinstantmediarendering__detailed_desc]

自 v4.1.1 版本新增。

成功调用该方法后，SDK 会启用即时帧渲染模式，从而加快用户加入频道后首帧的渲染速度。

:::info[注]
主播和观众都需要调用该方法，才能体验音视频帧的即时渲染效果。一旦成功调用该方法，只能通过调用 [destroy [2/2]](/zh-CN/api-reference/rtc/android/initialize#api_irtcengine_destroy1) 方法销毁 [RtcEngine](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_irtcengine) 对象来取消即时渲染。
:::

### 适用场景 [#api_irtcengine_enableinstantmediarendering__scenario]

声网建议在直播场景中为观众开启该模式。

### 调用时机 [#api_irtcengine_enableinstantmediarendering__timing]

该方法需要在加入频道前调用。

### 返回值 [#api_irtcengine_enableinstantmediarendering__return_values]

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/android/error-code)了解详情和解决建议。

  - -7：在 [RtcEngine](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_irtcengine) 初始化之前调用该方法。

- [RtcEngine](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_irtcengine)

## setLocalRenderMode [1/2] [#api_irtcengine_setlocalrendermode1]

设置本地视频的显示模式。

<a id="api_irtcengine_setlocalrendermode1__prototype"></a>

```java
public abstract int setLocalRenderMode(int renderMode)
```

#### `废弃` [#api_irtcengine_setlocalrendermode1__detailed_desc]

该方法已废弃，不推荐使用。

你可以调用该方法设置本地视频的显示模式。在通话过程中可以多次调用以动态调整显示模式。

### 参数 [#api_irtcengine_setlocalrendermode1__parameters]

#### `renderMode`

本地视频的显示模式：

- `RENDER_MODE_HIDDEN` （1）：隐藏模式。按比例缩放视频，直到填满视图边界，可能会裁剪视频的一部分内容。
- `RENDER_MODE_FIT` （2）：适应模式。按比例缩放视频，直到某一边适配视图边界，未填满的区域以黑色填充。
- `RENDER_MODE_ADAPTIVE` （3）：自适应模式。该枚举值已废弃，不推荐使用。

### 返回值 [#api_irtcengine_setlocalrendermode1__return_values]

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/android/error-code)了解详情和解决建议。

- [RtcEngine](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_irtcengine)

## setLocalRenderMode [2/2] [#api_irtcengine_setlocalrendermode2]

更新本地视频画面的显示模式。

<a id="api_irtcengine_setlocalrendermode2__prototype"></a>

```java
public abstract int setLocalRenderMode(int renderMode, int mirrorMode);
```

<a id="api_irtcengine_setlocalrendermode2__detailed_desc"></a>

该方法仅影响本地用户看到的视频画面，不影响本地视频的发布。

### 调用时机 [#api_irtcengine_setlocalrendermode2__timing]

确保在调用此方法前已调用 [setupLocalVideo](/zh-CN/api-reference/rtc/android/video/video-rendering#api_irtcengine_setuplocalvideo) 方法初始化本地视频画面。在通话过程中，你可以根据需要多次调用此方法更新本地视频画面的显示模式。

### 参数 [#api_irtcengine_setlocalrendermode2__parameters]

#### `renderMode`

本地视频的显示模式：

- `RENDER_MODE_HIDDEN` (1)：隐藏模式。按比例缩放视频，直到填满视图边界（可能被裁剪）。视频的一条边可能会被裁剪。
- `RENDER_MODE_FIT` (2)：适应模式。按比例缩放视频，直到某一边适配视图边界。由于宽高比不一致而未填满的区域将以黑色填充。
- `RENDER_MODE_ADAPTIVE` (3)：自适应模式（已废弃，不推荐使用）。

#### `mirrorMode`

:::info[注]
如果你使用前置摄像头，SDK 默认启用镜像模式；如果你使用后置摄像头，SDK 默认关闭镜像模式。
:::

本地用户的视频镜像模式：

- `VIDEO_MIRROR_MODE_AUTO` (0)：SDK 自动决定是否启用镜像模式。
- `VIDEO_MIRROR_MODE_ENABLED` (1)：启用本地视图的镜像模式。
- `VIDEO_MIRROR_MODE_DISABLED` (2)：关闭本地视图的镜像模式。

### 返回值 [#api_irtcengine_setlocalrendermode2__return_values]

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/android/error-code)了解详情和解决建议。

- [RtcEngine](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_irtcengine)

## setLocalRenderTargetFps [#api_irtcengine_setlocalrendertargetfps]

设置本地视频渲染的最大帧率。

<a id="api_irtcengine_setlocalrendertargetfps__prototype"></a>

```java
public abstract int setLocalRenderTargetFps(Constants.VideoSourceType sourceType, int targetFps);
```

<a id="api_irtcengine_setlocalrendertargetfps__detailed_desc"></a>

你可以在对视频渲染帧率要求不高的场景中调用该方法，例如屏幕共享或在线教育。SDK 会尝试将本地渲染的实际帧率保持在该值附近，从而降低 CPU 消耗并提升系统性能。

### 适用场景 [#api_irtcengine_setlocalrendertargetfps__scenario]

在对视频渲染帧率要求不高的场景（如屏幕共享或在线教育）中，你可以调用该方法设置本地视频渲染的最大帧率。SDK 会尝试将本地渲染的实际帧率保持在该值附近，以降低 CPU 消耗并提升系统性能。

### 调用时机 [#api_irtcengine_setlocalrendertargetfps__timing]

你可以在加入频道前或后调用该方法。

### 参数 [#api_irtcengine_setlocalrendertargetfps__parameters]

#### `sourceType`

视频源类型，详见 [VideoSourceType](/zh-CN/api-reference/rtc/android/enum-videosourcetype)。

#### `targetFps`

本地视频的采集帧率（fps）。支持的取值包括：1、7、10、15、24、30、60。

:::info[注]
该参数需设置为低于实际视频帧率的值，否则设置不生效。
:::

### 返回值 [#api_irtcengine_setlocalrendertargetfps__return_values]

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/android/error-code)了解详情和解决建议。

- [RtcEngine](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_irtcengine)

## setupLocalVideo [#api_irtcengine_setuplocalvideo]

初始化本地视频画面。

<a id="api_irtcengine_setuplocalvideo__prototype"></a>

```java
public abstract int setupLocalVideo(VideoCanvas local);
```

<a id="api_irtcengine_setuplocalvideo__detailed_desc"></a>

你可以调用该方法将本地视频流绑定到视频画面（`view` ），并设置画面的渲染模式和镜像模式。绑定关系在离开频道后仍然有效。如需停止渲染或解绑本地视频与画面，可将 `view` 设为 `null`。 在实时互动场景中，如果你需要在本地视频预览中同时查看多个预览画面，且每个画面位于视频链路的不同观察位置，可以多次调用该方法设置不同的 `view`，并为每个 `view` 设置不同的观察位置。例如，将视频源设置为摄像头后，配置两个 `view`，其 `position` 分别设置为 `VIDEO_MODULE_POSITION_POST_CAPTURER_ORIGIN` 和 `VIDEO_MODULE_POSITION_POST_CAPTURER`，即可在本地视频预览中同时查看原始未处理的视频帧和经过美颜特效、虚拟背景、水印等预处理后的视频帧。

:::info[注]
如需在通话过程中仅更新本地视频画面的渲染模式或镜像模式，请调用 `setLocalRenderMode`。
:::

### 适用场景 [#api_irtcengine_setuplocalvideo__scenario]

初始化后调用该方法设置本地视频，然后加入频道。在实时互动场景中，如需在本地预览中同时查看多个不同观察位置的画面，可多次调用该方法设置不同的 `view` 和观察位置。

### 调用时机 [#api_irtcengine_setuplocalvideo__timing]

你可以在加入频道前或后调用该方法。

### 参数 [#api_irtcengine_setuplocalvideo__parameters]

#### `local`

本地视频画面及相关设置。详见 [VideoCanvas](/zh-CN/api-reference/rtc/android/class-videocanvas)。

### 返回值 [#api_irtcengine_setuplocalvideo__return_values]

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/android/error-code)了解详情和解决建议。

## setupRemoteVideo [#api_irtcengine_setupremotevideo]

初始化远端视频视图。

<a id="api_irtcengine_setupremotevideo__prototype"></a>

```java
public abstract int setupRemoteVideo(VideoCanvas remote);
```

<a id="api_irtcengine_setupremotevideo__detailed_desc"></a>

该方法在本地设备上初始化远端视频流的视图，仅影响本地用户看到的视频画面。调用该方法可将远端视频流绑定到视频视图，并设置该视图的渲染模式和镜像模式。你需要在该方法中指定远端用户的 ID。如果应用尚未获取远端用户的 ID，请在收到 [onUserJoined](/zh-CN/api-reference/rtc/android/channel#callback_irtcengineeventhandler_onuserjoined) 回调后设置。若要将远端用户与视图解绑，请将 `view` 参数设置为 `null`。一旦远端用户离开频道，SDK 会自动解绑该用户。在移动端进行视频合流布局自定义的场景中，你可以调用该方法，并为合流视频流中的每个子视频流设置独立的 `view` 进行渲染。

:::info[注]
- 若需在通话过程中更新远端视频视图的渲染模式或镜像模式，请使用 [setRemoteRenderMode](/zh-CN/api-reference/rtc/android/video/video-rendering#api_irtcengine_setremoterendermode2) 方法。
- 使用录制服务时，应用无需绑定视图，因为录制服务不会发送视频流。如果你的应用无法识别录制服务，请在 SDK 触发 [onFirstRemoteVideoDecoded](/zh-CN/api-reference/rtc/android/video/video-basic#callback_irtcengineeventhandler_onfirstremotevideodecoded) 回调时将远端用户绑定到视图。
:::

### 参数 [#api_irtcengine_setupremotevideo__parameters]

#### `remote`

远端视频视图及相关设置。详见 [VideoCanvas](/zh-CN/api-reference/rtc/android/class-videocanvas)。

### 返回值 [#api_irtcengine_setupremotevideo__return_values]

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/android/error-code)了解详情和解决建议。

- [RtcEngine](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_irtcengine)


<a id="api_irtcengineex_setupremotevideoex__detailed_desc"></a>

你可以调用该方法将远端视频流绑定到视频视图，并设置视频视图的渲染模式和镜像模式。该方法仅影响本地用户看到的视频视图。 应用需在远端用户加入频道前，通过 [VideoCanvas](/zh-CN/api-reference/rtc/android/class-videocanvas) 指定远端用户 ID。 如果应用尚未获取远端用户 ID，可在收到 [onUserJoined](/zh-CN/api-reference/rtc/android/channel#callback_irtcengineeventhandler_onuserjoined) 回调后设置。 如果启用了视频录制功能，视频录制服务会以虚拟客户端身份加入频道，其他客户端也会因此收到 [onUserJoined](/zh-CN/api-reference/rtc/android/channel#callback_irtcengineeventhandler_onuserjoined) 回调。请勿将虚拟客户端绑定到应用视图，因为其不会发送任何视频流。 如需解除远端用户与视图的绑定，可将 `view` 参数设为 `null`。 远端用户离开频道后，SDK 会自动解除其绑定。

:::info[注]
若需在通话过程中更新远端视频视图的渲染或镜像模式，请使用 [setRemoteRenderModeEx](/zh-CN/api-reference/rtc/android/video/video-rendering#api_irtcengineex_setremoterendermodeex) 方法。
:::

### 适用场景 [#api_irtcengineex_setupremotevideoex__scenario]

该方法适用于多频道场景。

### 参数 [#api_irtcengineex_setupremotevideoex__parameters]

#### `remote`

远端视频视图的设置。详见 [VideoCanvas](/zh-CN/api-reference/rtc/android/class-videocanvas)。

#### `connection`

连接信息。详见 [RtcConnection](/zh-CN/api-reference/rtc/android/class-rtcconnection)。

### 返回值 [#api_irtcengineex_setupremotevideoex__return_values]

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/android/error-code)了解详情和解决建议。

- [RtcEngineEx](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_irtcengineex)

## startMediaRenderingTracing [#api_irtcengine_startmediarenderingtracing]

启用视频帧渲染过程的追踪。

<a id="api_irtcengine_startmediarenderingtracing__prototype"></a>

```java
public abstract int startMediaRenderingTracing();
```

#### `自从` [#api_irtcengine_startmediarenderingtracing__detailed_desc]

自 v4.1.1 版本新增。

从成功调用该方法开始，SDK 会追踪频道中视频帧的渲染状态，并通过 [onVideoRenderingTracingResult](/zh-CN/api-reference/rtc/android/video/video-rendering#callback_irtcengineeventhandler_onvideorenderingtracingresult) 回调上报相关事件信息。

:::info[注]
- 如果你未调用该方法，SDK 会从调用 `joinChannel` 加入频道开始追踪视频帧的渲染事件。
- 本地用户离开当前频道后，SDK 会自动从再次加入频道开始追踪视频渲染事件。
:::

### 适用场景 [#api_irtcengine_startmediarenderingtracing__scenario]

你可以结合应用中的 UI 设置（如按钮、滑块）调用该方法，以提升用户体验。例如，在用户点击“加入频道”按钮时调用该方法，然后通过 [onVideoRenderingTracingResult](/zh-CN/api-reference/rtc/android/video/video-rendering#callback_irtcengineeventhandler_onvideorenderingtracingresult) 回调获取视频帧渲染过程所耗费的时间，从而优化相关指标。

### 相关回调 [#api_irtcengine_startmediarenderingtracing__related]

该方法调用后会触发 [onVideoRenderingTracingResult](/zh-CN/api-reference/rtc/android/video/video-rendering#callback_irtcengineeventhandler_onvideorenderingtracingresult) 回调。

### 返回值 [#api_irtcengine_startmediarenderingtracing__return_values]

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/android/error-code)了解详情和解决建议。

  - -7：在 [RtcEngine](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_irtcengine) 初始化之前调用该方法。

- [RtcEngine](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_irtcengine)

## onVideoRenderingTracingResult [#callback_irtcengineeventhandler_onvideorenderingtracingresult]

<a id="callback_irtcengineeventhandler_onvideorenderingtracingresult__prototype"></a>

```java
public void onVideoRenderingTracingResult(int uid, Constants.MEDIA_TRACE_EVENT currentEvent, VideoRenderingTracingInfo tracingInfo)
```

<a id="callback_irtcengineeventhandler_onvideorenderingtracingresult__detailed_desc"></a>

#### `tracingInfo`

视频帧渲染过程中的各项指标。详见 [VideoRenderingTracingInfo](/zh-CN/api-reference/rtc/android/class-videorenderingtracinginfo)。
