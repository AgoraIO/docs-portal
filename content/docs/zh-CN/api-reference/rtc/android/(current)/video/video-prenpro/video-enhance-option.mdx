## addOrUpdateVideoEffect

为指定的视频特效节点 ID 和模板添加或更新视频特效。

<a id="api_ivideoeffectobject_addorupdatevideoeffect__prototype"></a>

```text
int addOrUpdateVideoEffect(int nodeId, String templateName);
```

<a id="api_ivideoeffectobject_addorupdatevideoeffect__detailed_desc"></a>

### 自从

自 v4.6.0 版本新增。

:::note
注： 优先级规则：

- 风格妆 (`STYLE_MAKEUP`) 节点优先于滤镜特效 (`FILTER`) 节点。
- 若要应用滤镜特效，必须先移除风格妆特效节点：

```text
removeVideoEffect(VIDEO_EFFECT_NODE_ID.STYLE_MAKEUP);
addOrUpdateVideoEffect(VIDEO_EFFECT_NODE_ID.FILTER, "template name");
```
:::

<a id="api_ivideoeffectobject_addorupdatevideoeffect__parameters"></a>

### 参数

### nodeId

视频特效节点的唯一标识符或标识符组合。详见 [VIDEO_EFFECT_NODE_ID](/zh-CN/api-reference/rtc/android/enum-videoeffectnodeid)。例如：

- 单个特效：`VIDEO_EFFECT_NODE_ID.BEAUTY`。
- 组合特效：`VIDEO_EFFECT_NODE_ID.BEAUTY | VIDEO_EFFECT_NODE_ID.STYLE_MAKEUP`。

### templateName

特效模板名称。如果设置为 `null` 或空字符串，SDK 会从资源包中加载默认参数配置。

<a id="api_ivideoeffectobject_addorupdatevideoeffect__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。


<a id="api_irtcengine_getfaceshapeareaoptions__detailed_desc"></a>

### 适用场景

当用户在应用中打开美型区域和塑形强度菜单时，可以调用该方法获取当前的美颜特效选项，然后根据结果刷新用户界面中的菜单并更新 UI。

### 参数

### shapeArea

美颜增强区域。

- `FACE_SHAPE_AREA_NONE`（-1）：（默认）无效区域，不应用美颜效果。
- `FACE_SHAPE_AREA_HEADSCALE`（100）：头部，用于实现小头效果。调整范围为 [0, 100]，值越大头部越小，默认值为 100。
- `FACE_SHAPE_AREA_FOREHEAD`（101）：额头，用于调整发际线高度。调整范围为 [-100, 100]，正值抬高发际线，负值降低发际线，绝对值越大效果越明显，默认值为 50。
- `FACE_SHAPE_AREA_FACECONTOUR`（102）：脸部轮廓，用于实现瘦脸效果。调整范围为 [0, 100]，值越大瘦脸效果越明显，默认值为 10。
- `FACE_SHAPE_AREA_FACELENGTH`（103）：脸长，用于拉长或缩短脸部。调整范围为 [-100, 100]，正值拉长脸部，负值缩短脸部，绝对值越大效果越明显，默认值为 0。
