## 初始化

<a id="api_irtcengine_createmediaplayer"></a>

## createMediaPlayer

创建一个 IMediaPlayer 对象。

<a id="api_irtcengine_createmediaplayer__prototype"></a>

```java
public abstract IMediaPlayer createMediaPlayer();
```

<a id="api_irtcengine_createmediaplayer__detailed_desc"></a>

你需要调用此方法来创建一个媒体播放器实例。如果需要多个实例，可以多次调用此方法。

<a id="api_irtcengine_createmediaplayer__timing"></a>

### 调用时机

你可以在加入频道前或加入频道后调用此方法。

<a id="api_irtcengine_createmediaplayer__return_values"></a>

### 返回值

方法调用成功，返回 [IMediaPlayer](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_imediaplayer) 对象。 方法调用失败，返回 `null`。

### 所属接口类
- [RtcEngine](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_irtcengine)

<a id="api_imediaplayer_destroy_imediaplayer"></a>

## destroy

销毁媒体播放器实例。

<a id="api_imediaplayer_destroy_imediaplayer__prototype"></a>

```java
int destroy();
```

<a id="api_imediaplayer_destroy_imediaplayer__detailed_desc"></a>

<a id="api_imediaplayer_destroy_imediaplayer__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/android/error-code)了解详情和解决建议。

### 所属接口类
- [IMediaPlayer](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_imediaplayer)

<a id="api_imediaplayercachemanager_getmediaplayercachemanager"></a>

## getMediaPlayerCacheManager

获取一个 IMediaPlayerCacheManager 实例。

<a id="api_imediaplayercachemanager_getmediaplayercachemanager__prototype"></a>

```java
public abstract IMediaPlayerCacheManager getMediaPlayerCacheManager();
```

<a id="api_imediaplayercachemanager_getmediaplayercachemanager__detailed_desc"></a>

在调用 [IMediaPlayerCacheManager](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_imediaplayercachemanager) 中的任何 API 之前，你需要调用 [getMediaPlayerCacheManager](/zh-CN/api-reference/rtc/android/mediaplayer-initialize#api_imediaplayercachemanager_getmediaplayercachemanager) 获取媒体播放器的缓存管理器实例。

:::info[注]
[IMediaPlayerCacheManager](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_imediaplayercachemanager) 采用单例模式，因此多次调用 [getMediaPlayerCacheManager](/zh-CN/api-reference/rtc/android/mediaplayer-initialize#api_imediaplayercachemanager_getmediaplayercachemanager) 会返回同一个实例。
:::

<a id="api_imediaplayercachemanager_getmediaplayercachemanager__timing"></a>

### 调用时机

确保在调用 [getMediaPlayerCacheManager](/zh-CN/api-reference/rtc/android/mediaplayer-initialize#api_imediaplayercachemanager_getmediaplayercachemanager) 前已初始化 [RtcEngine](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_irtcengine)。

<a id="api_imediaplayercachemanager_getmediaplayercachemanager__return_values"></a>

### 返回值

方法调用成功，返回 [IMediaPlayerCacheManager](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_imediaplayercachemanager) 实例。

### 所属接口类
- [IMediaPlayerCacheManager](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_imediaplayercachemanager)
