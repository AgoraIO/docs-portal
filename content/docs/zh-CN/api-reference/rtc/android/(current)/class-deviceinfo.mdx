title: "DeviceInfo"
description: "表示音频设备是否支持超低延迟采集和播放。"
---

<a id="class_deviceinfo__prototype"></a>

```java
public class DeviceInfo {
  public boolean isLowLatencyAudioSupported;
}
```

## 属性 [#class_deviceinfo__parameters]

### `isLowLatencyAudioSupported`

是否支持超低延迟音频采集和播放：

- true：设备支持超低延迟音频采集和播放。
- false：设备不支持超低延迟音频采集和播放。
