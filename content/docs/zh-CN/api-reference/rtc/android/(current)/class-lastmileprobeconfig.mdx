<a id="class_lastmileprobeconfig__prototype"></a>

```java
public class LastmileProbeConfig {
  public boolean probeUplink;
  public boolean probeDownlink;
  public int expectedUplinkBitrate;
  public int expectedDownlinkBitrate;
}
```

<a id="class_lastmileprobeconfig__parameters"></a>

## 属性

### `probeUplink`

是否测试上行网络。

- true：测试上行网络。
- false：不测试上行网络。例如，在 `LIVE_BROADCASTING` 频道场景中，观众通常无需测试上行网络。

### `probeDownlink`

是否测试下行网络。

- true：测试下行网络。
- false：不测试下行网络。

### `expectedUplinkBitrate`

本地用户期望的最大上行码率（bps）。取值范围为 [100000, 5000000]。建议参考 [setVideoEncoderConfiguration](/zh-CN/api-reference/rtc/android/video-basic#api_irtcengine_setvideoencoderconfiguration) 设置该值。

### `expectedDownlinkBitrate`

本地用户期望的最大下行码率（bps）。取值范围为 [100000, 5000000]。
