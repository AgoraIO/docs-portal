<a id="api_livetranscoding_setadvancedfeatures__prototype"></a>

```java
public void setAdvancedFeatures(String featureName, Boolean opened)
```

<a id="api_livetranscoding_setadvancedfeatures__detailed_desc"></a>

<a id="api_livetranscoding_setadvancedfeatures__parameters"></a>

## 参数

### `featureName`

高级功能名称，例如 `LBHQ` 和 `VEO`。

### `opened`

是否启用该高级功能：

- true：启用该高级功能。
- false：（默认）禁用该高级功能。
