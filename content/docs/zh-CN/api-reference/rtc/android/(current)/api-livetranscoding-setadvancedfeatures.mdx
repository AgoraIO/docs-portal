---

<a id="api_livetranscoding_setadvancedfeatures__prototype"></a>

```java
public void setAdvancedFeatures(String featureName, Boolean opened)
```

## <span id="api_livetranscoding_setadvancedfeatures__detailed_desc"></span>参数 [#api_livetranscoding_setadvancedfeatures__parameters]

### `featureName`

高级功能名称，例如 `LBHQ` 和 `VEO`。

### `opened`

是否启用该高级功能：

- true：启用该高级功能。
- false：（默认）禁用该高级功能。
