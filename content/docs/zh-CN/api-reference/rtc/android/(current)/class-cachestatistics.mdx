---
title: "CacheStatistics"
description: "用于统计被缓存媒体文件的相关信息。"
---
<a id="class_cachestatistics__prototype"></a>

```java
public class CacheStatistics {
  private long fileSize;
  private long cacheSize;
  private long downloadSize;
}
```

<a id="class_cachestatistics__parameters"></a>

## 属性

### `fileSize`

正在播放的媒体文件大小，单位为字节。

### `cacheSize`

待缓存的媒体文件大小，单位为字节。

### `downloadSize`

已下载的媒体文件大小，单位为字节。
