<a id="class_videolayoutinfo__prototype"></a>

```java
public static class VideoLayoutInfo {
    public int width;
    public int height;
    public int layoutCount;
    public VideoLayout[] layoutList;
  }
```

<a id="class_videolayoutinfo__detailed_desc"></a>

描述合图视频的布局信息。

<a id="class_videolayoutinfo__parameters"></a>

## 属性

### `width`

合图视频的宽度（单位为像素）。

### `height`

合图视频的高度（单位为像素）。

### `layoutCount`

合图视频中布局信息的数量。

### `layoutList`

合图视频中各路视频的详细布局信息，详见 [VideoLayout](/zh-CN/api-reference/rtc/android/class-videolayout)。
