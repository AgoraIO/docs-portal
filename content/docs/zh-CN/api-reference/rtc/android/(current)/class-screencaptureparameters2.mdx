## 属性

<ParameterList>
<a id="captureaudio"></a>
<Parameter name="captureAudio">

:::note
注：

- 由于系统限制，系统音频的采集仅适用于 Android API 等级 29 及以上（即 Android 10 及以上版本）。
- 为提高屏幕共享系统音频采集的成功率，请确保已调用 [setAudioScenario](/zh-CN/api-reference/rtc/android/audio/audio-basic#api_irtcengine_setaudioscenario) 方法并将音频场景设置为 `AUDIO_SCENARIO_GAME_STREAMING`。
:::

设置是否在屏幕共享过程中采集系统音频：

- true：采集系统音频。
- false：（默认）不采集系统音频。

</Parameter>
<a id="videocaptureparameters"></a>
<Parameter name="videoCaptureParameters">

共享屏幕视频流的视频采集参数。详见 [VideoCaptureParameters](/zh-CN/api-reference/rtc/android/class-screenvideoparameters)。

</Parameter>
<a id="capturevideo"></a>
<Parameter name="captureVideo">

:::note
注： 由于系统限制，屏幕采集仅适用于 Android API 等级 21 及以上，即 Android 5 及以上版本。
:::

设置在屏幕共享过程中是否采集屏幕内容：

- true：（默认）采集屏幕。
- false：不采集屏幕。

</Parameter>
