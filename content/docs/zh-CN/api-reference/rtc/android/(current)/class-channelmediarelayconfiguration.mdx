<a id="class_channelmediarelayconfiguration__prototype"></a>

```java
public class ChannelMediaRelayConfiguration {
  private ChannelMediaInfo srcInfo = null;
  private Map<String, ChannelMediaInfo> destInfos = null;
}
```

## 属性 [#class_channelmediarelayconfiguration__parameters]

### `srcInfo`

源频道的媒体信息。详见 [ChannelMediaInfo](/zh-CN/api-reference/rtc/android/class-channelmediainfo)。

### `destInfos`

目标频道的媒体信息集合，键为频道名，值为对应的媒体信息。详见 [ChannelMediaInfo](/zh-CN/api-reference/rtc/android/class-channelmediainfo)。
