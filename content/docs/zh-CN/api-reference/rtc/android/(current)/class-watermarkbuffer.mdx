### 自从

自 v4.6.0 版本新增。

用于定义水印图像的缓冲区数据结构。

<a id="class_watermarkbuffer__parameters"></a>

## 属性

### WATERMARK_BUFFER_FORMAT_I420

指定水印缓冲区的格式为 I420。

### WATERMARK_BUFFER_FORMAT_BGRA

指定水印缓冲区的格式为 BGRA。

### WATERMARK_BUFFER_FORMAT_NV21

指定水印缓冲区的格式为 NV21。

### WATERMARK_BUFFER_FORMAT_RGBA

指定水印缓冲区的格式为 RGBA。

### buffer

存储水印图像的像素数据。详见 `ByteBuffer`。

### width

水印图像的宽度，单位为像素。

### height

水印图像的高度，单位为像素。

### format

水印图像的格式：

- `WATERMARK_BUFFER_FORMAT_I420`：I420 格式。
- `WATERMARK_BUFFER_FORMAT_BGRA`：BGRA 格式。
- `WATERMARK_BUFFER_FORMAT_NV21`：NV21 格式。
- `WATERMARK_BUFFER_FORMAT_RGBA`：RGBA 格式。
