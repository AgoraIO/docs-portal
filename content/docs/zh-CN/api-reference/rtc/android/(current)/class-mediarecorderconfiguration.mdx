<a id="class_mediarecorderconfiguration__parameters"></a>

## 属性

<ParameterList>
<a id="storagepath"></a>
<Parameter name="storagePath">

（必填）本地保存录制文件的绝对路径，路径需包含文件名及扩展名。例如：Android: `/storage/emulated/0/Android/data/<package name>/files/example.mp4`。

:::note
注： 请确保指定路径存在且可写。
:::

</Parameter>
<a id="containerformat"></a>
<Parameter name="containerFormat">

录制文件的封装格式。目前仅支持：

- `CONTAINER_MP4`：MP4 格式。

</Parameter>
<a id="streamtype"></a>
<Parameter name="streamType">

录制内容类型：

- `STREAM_TYPE_AUDIO`：仅录制音频。
- `STREAM_TYPE_VIDEO`：仅录制视频。
- `STREAM_TYPE_BOTH`：（默认）同时录制音频和视频。

</Parameter>
<a id="maxdurationms"></a>
<Parameter name="maxDurationMs">

录制的最⼤时长，单位为毫秒。默认值为 120000。

</Parameter>
<a id="recorderinfoupdateinterval"></a>
<Parameter name="recorderInfoUpdateInterval">

录制信息的更新间隔，单位为毫秒。有效范围为 [1000, 10000]。SDK 会根据该值触发 [onRecorderInfoUpdated](/zh-CN/api-reference/rtc/android/recording#callback_imediarecorderobserver_onrecorderinfoupdated) 回调以更新录制信息。

</Parameter>
<a id="width"></a>
<Parameter name="width">

（必填）录制视频的宽度（像素）。宽高乘积的最大值不得超过 3840 × 2160。

</Parameter>
<a id="height"></a>
<Parameter name="height">

（必填）录制视频的高度（像素）。宽高乘积的最大值不得超过 3840 × 2160。

</Parameter>
<a id="fps"></a>
<Parameter name="fps">

（必填）录制视频的帧率。最大帧率不能超过 30，例如：5、10、15、24、30 等。

</Parameter>
<a id="sample_rate"></a>
<Parameter name="sample_rate">

（必填）录制音频的采样率（Hz）。可设置为 16000、32000、44100、48000。

</Parameter>
<a id="channel_num"></a>
<Parameter name="channel_num">

（必填）录制音频的声道数：

- 1：单声道。
- 2：立体声。

</Parameter>
<a id="videosourcetype"></a>
<Parameter name="videoSourceType">

（必填）录制使用的视频源类型。详见 [VideoSourceType](/zh-CN/api-reference/rtc/android/enum-videosourcetype)。

</Parameter>
</ParameterList>
