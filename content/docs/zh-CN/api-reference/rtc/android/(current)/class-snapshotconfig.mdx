## 属性

### filePath

截图文件的本地路径（包括文件扩展名）。例如：Android: `/storage/emulated/0/Android/data/<package name>/files/example.jpg`。

:::note
注： 请确保指定路径存在且具有可写权限。
:::

### position

截图视频帧在视频处理链中的位置，详见 [VideoModulePosition](/zh-CN/api-reference/rtc/android/enum-videomoduleposition)。
