<a id="class_metadata__prototype"></a>

```java
public class AgoraMetadata {
  public String channelId;
  public int uid;
  public byte[] data;
  public long timeStampMs;
}
```

<a id="class_metadata__parameters"></a>

## 属性

### `channelId`

频道名。

### `uid`

用户 ID。

- 对于接收方：表示发送该 [AgoraMetadata](/zh-CN/api-reference/rtc/android/class-metadata) 的远端用户 ID。
- 对于发送方：该值无效。

### `data`

接收到的 [AgoraMetadata](/zh-CN/api-reference/rtc/android/class-metadata) 的缓冲区地址。

### `timeStampMs`

[AgoraMetadata](/zh-CN/api-reference/rtc/android/class-metadata) 发送时的时间戳（单位为毫秒）。
