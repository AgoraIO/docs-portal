## 属性

<ParameterList>
<a id="appid"></a>
<Parameter name="appId">

启用音乐内容中心的项目的 App ID。

</Parameter>
<a id="token"></a>
<Parameter name="token">

使用音乐内容中心时用于鉴权的 Token。

:::note
注： 声网建议使用 AccessToken2 作为鉴权方式。详见 `Deploying the Token Server`。生成 Token 时，将 `String` 类型的 `mccUid` 作为 `uid` 参数传入。当 Token 即将过期时，可以调用 [renewToken](/zh-CN/api-reference/rtc/android/channel#api_irtcengine_renewtoken) 提供新的 Token。
:::

</Parameter>
<a id="mccuid"></a>
<Parameter name="mccUid">

使用音乐内容中心的用户 ID。可以与加入 RTC 频道时使用的 `uid` 相同，但不能为 0。

</Parameter>
<a id="maxcachesize"></a>
<Parameter name="maxCacheSize">

可缓存的音乐资源数量不得超过 50 个。

</Parameter>
<a id="eventhandler"></a>
<Parameter name="eventHandler">

事件回调接口，详见 [IMusicContentCenterEventHandler](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_imusiccontentcentereventhandler)。
