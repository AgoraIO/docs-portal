## 属性

### pathType

网络路径的类型：

- LAN：局域网。
- WiFi：无线局域网。
- Mobile：移动网络。

### txKBitRate

该路径的传输码率，单位为 Kbps。

### rxKBitRate

该路径的接收码率，单位为 Kbps。
