## AgoraMediaRecorder

用于录制客户端的音频和视频。

<a id="class_imediarecorder__detailed_desc"></a>

### 自从

自 v3.5.2 版本新增。

[AgoraMediaRecorder](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_imediarecorder) 可录制以下内容：

- 本地麦克风采集并由 SDK 编码为 AAC 格式的音频。
- 本地摄像头采集并由 SDK 编码的视频。

:::note
注： 在 `COMMUNICATION` 频道场景下，当频道中存在使用 v3.0.0 之前版本 SDK 的用户时，该功能不可用。
:::

## RtcEngine

调用该类的方法以使用声网 SDK 的全部功能。

<a id="class_irtcengine__detailed_desc"></a>

声网建议在同一线程中调用 [RtcEngine](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_irtcengine) 的 API 方法，避免在多个线程中调用。该类在早期版本中名为 `AgoraAudio`，从 1.0 版本起更名为 [RtcEngine](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_irtcengine)。

<a id="class_irtcengineeventhandler"></a>

<a id="ariaid-title25"></a>

## IRtcEngineEventHandler

封装 SDK 向应用层发送事件回调的方法。

<a id="class_irtcengineeventhandler__detailed_desc"></a>

[IRtcEngineEventHandler](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_irtcengineeventhandler) 是 SDK 用于向应用层发送事件回调的接口类。你可以继承该类以接收所需的事件通知。该接口中的所有方法均为默认空实现，你可以根据需要选择性地重写部分方法。为确保 SDK 正常运行，建议在回调方法中避免执行耗时操作或调用阻塞 API，例如 `SendMessage`。
