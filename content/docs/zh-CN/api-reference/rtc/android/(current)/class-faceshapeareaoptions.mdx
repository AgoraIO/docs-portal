## 属性

<ParameterList>
<a id="shapearea"></a>
<Parameter name="shapeArea">

美型区域。不同区域对应不同的面部调节效果，例如头部缩放、五官比例等。可设置的取值包括：

- `FACE_SHAPE_AREA_NONE`（-1）：无效区域。

- `FACE_SHAPE_AREA_HEADSCALE`（100）：头部缩放。

- `FACE_SHAPE_AREA_FOREHEAD`（101）：额头调整。

- `FACE_SHAPE_AREA_FACECONTOUR`（102）：脸部轮廓。

- `FACE_SHAPE_AREA_FACELENGTH`（103）：脸长调整。

- `FACE_SHAPE_AREA_FACEWIDTH`（104）：脸宽调整。

- `FACE_SHAPE_AREA_CHEEKBONE`（105）：颧骨调整。

- `FACE_SHAPE_AREA_CHEEK`（106）：面颊调整。

- `FACE_SHAPE_AREA_MANDIBLE`（107）：下颌调整。

- `FACE_SHAPE_AREA_CHIN`（108）：下巴调整。

- `FACE_SHAPE_AREA_FACESMALL`（109）：小脸，缩小整体脸部尺寸以获得更纤细的外观。

- `FACE_SHAPE_AREA_EYESCALE`（200）：眼睛大小。

- `FACE_SHAPE_AREA_EYEDISTANCE`（201）：眼距调整。

- `FACE_SHAPE_AREA_EYEPOSITION`（202）：眼睛上下位置。

- `FACE_SHAPE_AREA_EYELID`（203）：下眼睑调整。

- `FACE_SHAPE_AREA_EYEPUPILS`（204）：瞳孔大小。

- `FACE_SHAPE_AREA_EYEINNERCORNER`（205）：眼内角调整。

- `FACE_SHAPE_AREA_EYEOUTERCORNER`（206）：眼外角调整。

- `FACE_SHAPE_AREA_EYEANGLE`（207）：眼角度，调整眼睛的倾斜角度（猫眼效果）。

- `FACE_SHAPE_AREA_NOSELENGTH`（300）：鼻子长度。

- `FACE_SHAPE_AREA_NOSEWIDTH`（301）：鼻子宽度。

- `FACE_SHAPE_AREA_NOSEWING`（302）：鼻翼大小。

- `FACE_SHAPE_AREA_NOSEROOT`（303）：鼻根大小。

- `FACE_SHAPE_AREA_NOSEBRIDGE`（304）：鼻梁大小。

- `FACE_SHAPE_AREA_NOSETIP`（305）：鼻尖大小。

- `FACE_SHAPE_AREA_NOSEGENERAL`（306）：整体鼻型。

- `FACE_SHAPE_AREA_MOUTHSCALE`（400）：嘴巴大小。

- `FACE_SHAPE_AREA_MOUTHPOSITION`（401）：嘴巴位置。

- `FACE_SHAPE_AREA_MOUTHSMILE`（402）：嘴角弧度。

- `FACE_SHAPE_AREA_MOUTHLIP`（403）：嘴唇大小。

- `FACE_SHAPE_AREA_EYEBROWPOSITION`（500）：眉毛位置。

- `FACE_SHAPE_AREA_EYEBROWTHICKNESS`（501）：眉毛粗细。

</Parameter>
<a id="shapeintensity"></a>
<Parameter name="shapeIntensity">

美型强度。不同区域的强度定义包括方向、范围和默认值等。

</Parameter>
<a id="face_shape_area_headscale"></a>
<Parameter name="FACE_SHAPE_AREA_HEADSCALE">

100：头部缩放，缩小头部的大小。取值范围是 [0, 100]。默认值是 0。值越大，头部缩小效果越强。

</Parameter>
<a id="face_shape_area_facelength"></a>
<Parameter name="FACE_SHAPE_AREA_FACELENGTH">

103：脸长，调整脸的垂直长度。取值范围是 [-100, 100]。默认值是 0。正值拉长脸部，负值缩短脸部以获得更圆的外观。绝对值越大，效果越强。

</Parameter>
<a id="face_shape_area_facesmall"></a>
<Parameter name="FACE_SHAPE_AREA_FACESMALL">

109：小脸，缩小整体脸部尺寸以获得更纤细的外观。取值范围是 [0, 100]。默认值是 0。值越大，整体脸部尺寸缩小效果越明显。

</Parameter>
<a id="face_shape_area_eyescale"></a>
<Parameter name="FACE_SHAPE_AREA_EYESCALE">

200：眼睛缩放，调整眼睛的大小。取值范围是 [0, 100]。默认值是 0。值越大，眼睛大小效果越强。

</Parameter>
<a id="face_shape_area_nosewing"></a>
<Parameter name="FACE_SHAPE_AREA_NOSEWING">

</Parameter>
<a id="face_shape_area_nosebridge"></a>
<Parameter name="FACE_SHAPE_AREA_NOSEBRIDGE">

304：鼻梁，调整鼻梁的大小。取值范围是 [0, 100]。默认值是 0。值越大，鼻梁效果越强。

</Parameter>
<a id="face_shape_area_nosetip"></a>
<Parameter name="FACE_SHAPE_AREA_NOSETIP">

305：鼻尖，调整鼻尖的大小。取值范围是 [0, 100]。默认值是 0。值越大，鼻尖效果越强。

</Parameter>
<a id="face_shape_area_nosegeneral"></a>
<Parameter name="FACE_SHAPE_AREA_NOSEGENERAL">

306：鼻子整体，调整鼻子的整体大小。取值范围是 [-100, 100]。默认值是 0。绝对值越大，鼻子整体效果越强，负值表示相反方向。

402：嘴巴微笑，调整嘴巴的微笑程度。取值范围是 [0, 100]。默认值是 0。值越大，嘴巴微笑效果越强。
