---
title: "PreloadState"
description: "PreloadState 表示音乐资源的加载状态。"
---

<a id="class_preloadstate_android__prototype"></a>

```java
class PreloadState {
    public static final int PRELOAD_STATE_COMPLETED = 0;
    public static final int PRELOAD_STATE_FAILED = 1;
    public static final int PRELOAD_STATE_PRELOADING = 2;
    public static final int PRELOAD_STATE_REMOVED = 3;
  }
```

<a id="class_preloadstate_android__parameters"></a>

## 属性

### `PRELOAD_STATE_COMPLETED`

0：音乐资源加载完成。

### `PRELOAD_STATE_FAILED`

1：音乐资源加载失败。

### `PRELOAD_STATE_PRELOADING`

2：音乐资源加载中。

### `PRELOAD_STATE_REMOVED`

3：已移除缓存的音乐资源。
