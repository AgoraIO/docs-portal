<a id="class_mixedaudiostream__parameters"></a>

## 属性

### remoteUserUid

远端用户 ID。

:::note
注： 仅当本地混音音频流的来源类型为 `AUDIO_SOURCE_REMOTE_USER` 时需要设置该参数。
:::

### channelId

频道名。该字符串长度不得超过 64 字节。支持的字符共 89 个：小写英文字母 a 到 z、大写英文字母 A 到 Z、数字 0 到 9，以及以下符号：!、#、$、% 、&、(、)、+、-、:、;、&lt;、=、.、&gt;、?、@、[、]、^、_、\{、\}、|、~、,。

:::note
注： 仅当本地混音音频流的来源类型为 `AUDIO_SOURCE_REMOTE_CHANNEL` 或 `AUDIO_SOURCE_REMOTE_USER` 时需要设置该参数。
:::

### sourceType

音频源类型，详见 [AudioSourceType](/zh-CN/api-reference/rtc/android/enum-audiosourcetype)。

### trackId

音频轨道 ID。

:::note
注： 仅当本地混音音频流的来源类型为 `AUDIO_SOURCE_CUSTOM` 时需要设置该参数。请设置为 [createCustomAudioTrack](/zh-CN/api-reference/rtc/android/audio/audio-custom-capturenrendering#api_irtcengine_createcustomaudiotrack) 返回的自定义音频轨道 ID。
:::
