<a id="api_livetranscoding_setusers__prototype"></a>

```java
public void setUsers(ArrayList<TranscodingUser> users)
```

<a id="api_livetranscoding_setusers__detailed_desc"></a>

该方法用于用新的用户数据替换旧的数据，设置所有参与 CDN 推流的用户。

<a id="api_livetranscoding_setusers__parameters"></a>

## 参数

### `users`

所有参与 CDN 推流的用户。详见 [TranscodingUser](/zh-CN/api-reference/rtc/android/class-transcodinguser)。
