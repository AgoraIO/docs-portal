---
title: "MusicCacheInfo"
description: "用于描述缓存的音乐资源信息。"
---

<a id="class_musiccacheinfo__prototype"></a>

```java
public class MusicCacheInfo {
  public long songCode;
  public int status;
}
```

## 属性 [#class_musiccacheinfo__parameters]

### `songCode`

音乐资源的标识符，用于标识音乐资源。

### `status`

音乐资源的缓存状态：

- `MUSIC_CACHE_STATUS_TYPE_CACHED` (0)：音乐资源已缓存。
- `MUSIC_CACHE_STATUS_TYPE_CACHING` (1)：音乐资源正在缓存中。
