---
title: "LeaveChannelOptions"
description: "用于设置离开频道时的相关选项。"
---

<a id="class_leavechanneloptions__prototype"></a>

```java
public class LeaveChannelOptions {
  public boolean stopAudioMixing;
  public boolean stopAllEffect;
  public boolean stopMicrophoneRecording;
}
```

<a id="class_leavechanneloptions__parameters"></a>

## 属性

### `stopAudioMixing`

离开频道时是否停止播放和混音音乐文件。

- true：（默认）停止播放和混音音乐文件。
- false：不停止播放和混音音乐文件。

### `stopAllEffect`

离开频道时是否停止播放所有音效。

- true：（默认）停止播放所有音效。
- false：不停止播放任何音效。

### `stopMicrophoneRecording`

离开频道时是否停止麦克风录制。

- true：（默认）停止麦克风录制。
- false：不停止麦克风录制。
