<a id="struid"></a>

预留字段，供未来使用。

</Parameter>
<a id="videostate"></a>
<Parameter name="videoState">

子视频流在视频合流画布上的状态：

- 0：正常，子视频流已渲染到混流画布上。
- 1：占位图像，子视频流无视频帧，将以占位图显示在混流画布上。
- 2：黑色图像，子视频流将被黑色图像替代。

</Parameter>
<a id="x"></a>
<Parameter name="x">

子视频流在混流画布上的 X 坐标（单位为 px），即视频左上角相对于画布左上角的水平偏移。

</Parameter>
<a id="y"></a>
<Parameter name="y">

子视频流在混流画布上的 Y 坐标（单位为 px），即视频左上角相对于画布左上角的垂直偏移。

</Parameter>
<a id="width"></a>
<Parameter name="width">

子视频流的宽度（单位为 px）。

</Parameter>
<a id="height"></a>
<Parameter name="height">

子视频流的高度（单位为 px）。

</Parameter>
