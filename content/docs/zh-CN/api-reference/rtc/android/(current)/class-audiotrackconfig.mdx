<a id="class_audiotrackconfig__prototype"></a>

```java
public class AudioTrackConfig {
  public boolean enableLocalPlayback;
  public boolean enableAudioProcessing;
}
```

## 属性 [#class_audiotrackconfig__parameters]

### `enableLocalPlayback`

是否启用本地音频播放设备：

- true：（默认）启用本地音频播放设备。
- false：不启用本地音频播放设备。

### `enableAudioProcessing`

:::info[注]
该参数仅对自定义音频采集中的 `AUDIO_TRACK_DIRECT` 类型生效。
:::

是否启用音频处理模块：

- true：启用音频处理模块，应用回声消除（AEC）、噪声抑制（ANS）和自动增益控制（AGC）效果。
- false：（默认）不启用音频处理模块。
