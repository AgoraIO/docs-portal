## 枚举值

<ParameterList>
<a id="default"></a>
<Parameter name="DEFAULT">

（0）：默认音频配置文件。频道场景为互动直播时，采样率为 48 kHz，音乐编码，单声道，码率上限为 64 Kbps；频道场景为通信时，采样率为 32 kHz，语音编码，单声道，码率上限为 18 Kbps。

</Parameter>
<a id="speech_standard"></a>
<Parameter name="SPEECH_STANDARD">

（1）：采样率为 32 kHz，语音编码，单声道，码率上限为 18 Kbps。

</Parameter>
<a id="music_standard"></a>
<Parameter name="MUSIC_STANDARD">

（2）：采样率为 48 kHz，音乐编码，单声道，码率上限为 64 Kbps。

</Parameter>
<a id="music_standard_stereo"></a>
<Parameter name="MUSIC_STANDARD_STEREO">

（3）：采样率为 48 kHz，音乐编码，立体声，码率上限为 80 Kbps。要实现立体声效果，还需调用 [setAdvancedAudioOptions](/zh-CN/api-reference/rtc/android/audio/audio-prenpost/audio-effect#api_irtcengine_setadvancedaudiooptions)，并在 [AdvancedAudioOptions](/zh-CN/api-reference/rtc/android/class-advancedaudiooptions) 中将 `audioProcessingChannels` 设置为 `AGORA_AUDIO_STEREO_PROCESSING`。

</Parameter>
<a id="music_high_quality"></a>
<Parameter name="MUSIC_HIGH_QUALITY">

（4）：采样率为 48 kHz，音乐编码，单声道，码率上限为 96 Kbps。

</Parameter>
<a id="music_high_quality_stereo"></a>
<Parameter name="MUSIC_HIGH_QUALITY_STEREO">

（5）：采样率为 48 kHz，音乐编码，立体声，码率上限为 128 Kbps。要实现立体声效果，还需调用 [setAdvancedAudioOptions](/zh-CN/api-reference/rtc/android/audio/audio-prenpost/audio-effect#api_irtcengine_setadvancedaudiooptions)，并在 [AdvancedAudioOptions](/zh-CN/api-reference/rtc/android/class-advancedaudiooptions) 中将 `audioProcessingChannels` 设置为 `AGORA_AUDIO_STEREO_PROCESSING`。

</Parameter>
</ParameterList>
