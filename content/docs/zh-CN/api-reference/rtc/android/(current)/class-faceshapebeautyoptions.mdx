## 属性

### FACE_SHAPE_BEAUTY_STYLE_FEMALE

0：（默认）女性美型风格。

### FACE_SHAPE_BEAUTY_STYLE_MALE

1：男性美型风格。

### FACE_SHAPE_BEAUTY_STYLE_NATURAL

2：自然风格，仅对面部特征进行最小调整。

### shapeStyle

美型风格选项：

- `FACE_SHAPE_BEAUTY_STYLE_FEMALE`（0）：（默认）女性风格。
- `FACE_SHAPE_BEAUTY_STYLE_MALE`（1）：男性风格。
- `FACE_SHAPE_BEAUTY_STYLE_NATURAL`（2）：自然风格，仅对面部特征进行最小调整。

### styleIntensity

美型风格的强度，取值范围为 [0.0, 1.0]。

- 默认值为 0.0，表示不进行美型处理。
- 值越大，美型效果越明显。
