## getAudioDeviceInfo

获取音频设备信息。

<a id="api_irtcengine_getaudiodeviceinfo__prototype"></a>

```java
public abstract DeviceInfo getAudioDeviceInfo();
```

<a id="api_irtcengine_getaudiodeviceinfo__detailed_desc"></a>

:::info[注]
你可以在加入频道前或加入频道后调用该方法。
:::

<a id="api_irtcengine_getaudiodeviceinfo__return_values"></a>

### 返回值

方法调用成功，返回 [DeviceInfo](/zh-CN/api-reference/rtc/android/class-deviceinfo) 对象。 方法调用失败，返回 `null`。

## startPlaybackDeviceTest

启动本地音频播放设备测试。

<a id="api_irtcengine_startplaybackdevicetest__prototype"></a>

```java
public abstract int startPlaybackDeviceTest(String audioFileName);
```

<a id="api_irtcengine_startplaybackdevicetest__detailed_desc"></a>

调用该方法后，SDK 会播放你指定的音频文件。如果你能听到音频，说明播放设备工作正常。调用该方法后，SDK 每 100 毫秒触发一次 [onAudioVolumeIndication](/zh-CN/api-reference/rtc/android/audio-basic#callback_irtcengineeventhandler_onaudiovolumeindication) 回调，报告 `uid` 为 1 的播放设备音量信息。该方法与 [startEchoTest](/zh-CN/api-reference/rtc/android/network#api_irtcengine_startechotest3) 的区别在于， [startPlaybackDeviceTest](/zh-CN/api-reference/rtc/android/audio-device#api_irtcengine_startplaybackdevicetest) 仅检测本地音频播放设备是否正常，而 [startEchoTest](/zh-CN/api-reference/rtc/android/network#api_irtcengine_startechotest3) 可同时检测音视频设备和网络状况。

:::info[注]
请在加入频道前调用该方法。测试完成后，请在加入频道前调用 [stopPlaybackDeviceTest](/zh-CN/api-reference/rtc/android/audio-device#api_irtcengine_stopplaybackdevicetest) 停止测试。
:::

<a id="api_irtcengine_startplaybackdevicetest__parameters"></a>

### 参数

#### `audioFileName`

音频文件的路径，UTF-8 编码的字符串。支持的文件格式包括：wav、mp3、m4a 和 aac。支持的采样率包括：8000、16000、32000、44100 和 48000 Hz。

<a id="api_irtcengine_startplaybackdevicetest__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/android/error-code)了解详情和解决建议。

### 所属接口类
- [RtcEngine](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_irtcengine)

<a id="api_irtcengine_startrecordingdevicetest"></a>

## startRecordingDeviceTest

启动音频采集设备测试。

<a id="api_irtcengine_startrecordingdevicetest__prototype"></a>

```java
public abstract int startRecordingDeviceTest(int indicationInterval);
```

<a id="api_irtcengine_startrecordingdevicetest__detailed_desc"></a>

调用该方法后，SDK 会按照设置的时间间隔触发 [onAudioVolumeIndication](/zh-CN/api-reference/rtc/android/audio-basic#callback_irtcengineeventhandler_onaudiovolumeindication) 回调，报告 `uid` = 0 以及采集设备的音量信息。该方法与 [startEchoTest](/zh-CN/api-reference/rtc/android/network#api_irtcengine_startechotest3) 的区别在于， [startRecordingDeviceTest](/zh-CN/api-reference/rtc/android/audio-device#api_irtcengine_startrecordingdevicetest) 仅检测本地音频采集设备是否正常工作，而 [startEchoTest](/zh-CN/api-reference/rtc/android/network#api_irtcengine_startechotest3) 可同时检测音视频设备和网络状况。

:::info[注]
请在加入频道前调用该方法。测试完成后，在加入频道前调用 [stopRecordingDeviceTest](/zh-CN/api-reference/rtc/android/audio-device#api_irtcengine_stoprecordingdevicetest) 停止测试。
:::

<a id="api_irtcengine_startrecordingdevicetest__parameters"></a>

### 参数

#### `indicationInterval`

触发 [onAudioVolumeIndication](/zh-CN/api-reference/rtc/android/audio-basic#callback_irtcengineeventhandler_onaudiovolumeindication) 回调的时间间隔（毫秒）。该值应大于 10，否则将无法收到 [onAudioVolumeIndication](/zh-CN/api-reference/rtc/android/audio-basic#callback_irtcengineeventhandler_onaudiovolumeindication) 回调，且 SDK 返回错误码 -2。建议设置为 100。

<a id="api_irtcengine_startrecordingdevicetest__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/android/error-code)了解详情和解决建议。

  - -2：参数无效，请检查参数设置。

### 所属接口类
- [RtcEngine](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_irtcengine)
