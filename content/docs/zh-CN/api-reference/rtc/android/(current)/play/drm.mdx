## getInternalSongCode [#api_imusiccontentcenter_getinternalsongcode]

创建音乐资源副歌片段的内部标识符。

<a id="api_imusiccontentcenter_getinternalsongcode__prototype"></a>

```java
public abstract long getInternalSongCode(long songCode, String jsonOption);
```

<a id="api_imusiccontentcenter_getinternalsongcode__detailed_desc"></a>

在播放音乐资源的副歌片段前，需调用该方法，结合音乐资源的 `songCode` 和 `jsonOption` 参数创建副歌片段的内部标识符。该标识符作为资源的唯一引用。在调用相关方法以打开、预加载或移除资源时，应将该标识符作为 `songCode` 参数传入。

### 参数 [#api_imusiccontentcenter_getinternalsongcode__parameters]

#### `songCode`

音乐资源的标识符。可通过调用 `getMusicCollectionByMusicChartId` 或 `searchMusic` 获取，并从这两个方法触发的 [onMusicCollectionResult](/zh-CN/api-reference/rtc/android/play/drm#callback_imusiccontentcentereventhandler_onmusiccollectionresult) 回调中获取 `songCode`。

#### `jsonOption`

:::info[注]
`sceneType` 会影响计费方式。不同频道场景的计费标准不同，详见计费文档。若需切换频道场景，必须使用新的 `sceneType` 值重新调用该方法。
:::

扩展 JSON 字段，默认为 `null`。目前支持以下字段：

- sceneType：场景类型。1：直播场景，在线 K 歌房和背景音乐播放；2：直播场景，背景音乐播放；3：（默认）声动语聊场景，在线 K 歌房；4：声动语聊场景，背景音乐播放；5：VR 场景，在线 K 歌房和背景音乐播放。示例： `{"sceneType":1}`。
- highPart：副歌片段的索引，从 [onMusicCollectionResult](/zh-CN/api-reference/rtc/android/play/drm#callback_imusiccontentcentereventhandler_onmusiccollectionresult) 回调中获取，索引从 0 开始。示例： `{"format": {"highpart": 0}}`。

### 返回值 [#api_imusiccontentcenter_getinternalsongcode__return_values]

- 方法调用成功，返回创建的音乐资源内部标识符。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/android/error-code)了解详情和解决建议。

- [IAgoraMusicContentCenter](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_imusiccontentcenter)

## getMusicCollectionByMusicChartId [2/2] [#api_imusiccontentcenter_getmusiccollectionbymusicchartid2]

根据音乐榜单 ID 获取音乐资源列表。

<a id="api_imusiccontentcenter_getmusiccollectionbymusicchartid2__prototype"></a>

```java
public abstract String getMusicCollectionByMusicChartId(int musicChartId, int page, int pageSize, String jsonOption);
```

<a id="api_imusiccontentcenter_getmusiccollectionbymusicchartid2__detailed_desc"></a>

成功调用该方法后，SDK 会触发 [onMusicCollectionResult](/zh-CN/api-reference/rtc/android/play/drm#callback_imusiccontentcentereventhandler_onmusiccollectionresult) 回调，返回榜单中的音乐资源详细信息。

### 相关回调 [#api_imusiccontentcenter_getmusiccollectionbymusicchartid2__related]

成功调用该方法后，SDK 会触发 [onMusicCollectionResult](/zh-CN/api-reference/rtc/android/play/drm#callback_imusiccontentcentereventhandler_onmusiccollectionresult) 回调，返回榜单中的音乐资源详细信息。

### 参数 [#api_imusiccontentcenter_getmusiccollectionbymusicchartid2__parameters]

#### `musicChartId`

音乐榜单的 ID。可通过 [onMusicChartsResult](/zh-CN/api-reference/rtc/android/play/drm#callback_imusiccontentcentereventhandler_onmusicchartsresult) 回调获取。你也可以使用 RESTful API 获取完整音乐库列表或增量音乐列表。

#### `page`

当前页码，从 1 开始。

#### `pageSize`

每页返回的音乐资源数量，最大值为 50。

#### `jsonOption`

可选的 JSON 扩展字段，默认为 `null`。你可以使用该字段筛选所需的音乐资源。目前支持以下筛选项：

- `pitchType`：音乐资源是否支持评分。

  - `2`：不可评分音乐资源。
- `needHighPart`：是否需要合唱片段资源。

  - true：需要合唱片段。
  - false：不需要合唱片段。

示例： `{"pitchType":1}`， `{"needHighPart":true}`。

音乐资源的当前加载状态：

- 0：加载完成。
- 1：加载失败。
- 2：加载中。

#### `reason`

来自 Music Content Center 的请求状态码：

- `MUSIC_CONTENT_CENTER_STATE_REASON_OK` (0)：请求成功。
- `MUSIC_CONTENT_CENTER_STATE_REASON_ERROR` (1)：通用错误，无具体归因。
- `MUSIC_CONTENT_CENTER_STATE_REASON_GATEWAY` (2)：网关错误。可能原因包括：

  - 当前临时 Token 已过期，请重新生成 Token。
  - 提供的 Token 无效，请确保使用的是 Token。
  - 网络错误，请检查网络连接。
- `MUSIC_CONTENT_CENTER_STATE_REASON_PERMISSION_AND_RESOURCE` (3)：权限错误或音乐资源不存在。请确保项目已启用 Music Content Center 访问权限。如有问题请[联系技术支持](https://ticket.shengwang.cn/)。
- `MUSIC_CONTENT_CENTER_STATE_REASON_INTERNAL_DATA_PARSE` (4)：内部数据解析错误。请[联系技术支持](https://ticket.shengwang.cn/)。
- `MUSIC_CONTENT_CENTER_STATE_REASON_MUSIC_LOADING` (5)：加载音乐资源时发生错误。请[联系技术支持](https://ticket.shengwang.cn/)。
- `MUSIC_CONTENT_CENTER_STATE_REASON_MUSIC_DECRYPTION` (6)：解密音乐资源时发生错误。请[联系技术支持](https://ticket.shengwang.cn/)。
- `MUSIC_CONTENT_CENTER_STATE_REASON_HTTP_INTERNAL` (7)：HTTP 内部错误。请稍后重试。
