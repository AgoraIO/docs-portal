## <span id="toc_mediaplayer_initialize"></span>createMediaPlayer [#api_irtcengine_createmediaplayer]

创建一个 IMediaPlayer 对象。

<a id="api_irtcengine_createmediaplayer__prototype"></a>

```java
public abstract IMediaPlayer createMediaPlayer();
```

<a id="api_irtcengine_createmediaplayer__detailed_desc"></a>

你需要调用此方法来创建一个媒体播放器实例。如果需要多个实例，可以多次调用此方法。

### 调用时机 [#api_irtcengine_createmediaplayer__timing]

你可以在加入频道前或加入频道后调用此方法。

### 返回值 [#api_irtcengine_createmediaplayer__return_values]

方法调用成功，返回 [IMediaPlayer](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_imediaplayer) 对象。 方法调用失败，返回 `null`。

- [RtcEngine](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_irtcengine)

## destroy [#api_imediaplayer_destroy_imediaplayer]

销毁媒体播放器实例。

<a id="api_imediaplayer_destroy_imediaplayer__prototype"></a>

```java
int destroy();
```

### <span id="api_imediaplayer_destroy_imediaplayer__detailed_desc"></span>返回值 [#api_imediaplayer_destroy_imediaplayer__return_values]

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/android/error-code)了解详情和解决建议。

- [IMediaPlayer](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_imediaplayer)

## getMediaPlayerCacheManager [#api_imediaplayercachemanager_getmediaplayercachemanager]

获取一个 IMediaPlayerCacheManager 实例。

<a id="api_imediaplayercachemanager_getmediaplayercachemanager__prototype"></a>

```java
public abstract IMediaPlayerCacheManager getMediaPlayerCacheManager();
```

<a id="api_imediaplayercachemanager_getmediaplayercachemanager__detailed_desc"></a>

在调用 [IMediaPlayerCacheManager](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_imediaplayercachemanager) 中的任何 API 之前，你需要调用 [getMediaPlayerCacheManager](/zh-CN/api-reference/rtc/android/play/mediaplayer/mediaplayer-initialize#api_imediaplayercachemanager_getmediaplayercachemanager) 获取媒体播放器的缓存管理器实例。

:::info[注]
[IMediaPlayerCacheManager](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_imediaplayercachemanager) 采用单例模式，因此多次调用 [getMediaPlayerCacheManager](/zh-CN/api-reference/rtc/android/play/mediaplayer/mediaplayer-initialize#api_imediaplayercachemanager_getmediaplayercachemanager) 会返回同一个实例。
:::

### 调用时机 [#api_imediaplayercachemanager_getmediaplayercachemanager__timing]

确保在调用 [getMediaPlayerCacheManager](/zh-CN/api-reference/rtc/android/play/mediaplayer/mediaplayer-initialize#api_imediaplayercachemanager_getmediaplayercachemanager) 前已初始化 [RtcEngine](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_irtcengine)。

### 返回值 [#api_imediaplayercachemanager_getmediaplayercachemanager__return_values]

方法调用成功，返回 [IMediaPlayerCacheManager](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_imediaplayercachemanager) 实例。

- [IMediaPlayerCacheManager](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_imediaplayercachemanager)
