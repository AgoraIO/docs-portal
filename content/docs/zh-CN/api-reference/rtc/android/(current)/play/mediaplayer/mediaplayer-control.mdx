## playPreloadedSrc

播放预加载的媒体资源。

<a id="api_imediaplayer_playpreloadedsrc__prototype"></a>

```text
int playPreloadedSrc(String src);
```

<a id="api_imediaplayer_playpreloadedsrc__detailed_desc"></a>

调用 [preloadSrc](/zh-CN/api-reference/rtc/android/play/mediaplayer/mediaplayer-open#api_imediaplayer_preloadsrc) 将媒体资源预加载到播放列表后，可以调用 [playPreloadedSrc](/zh-CN/api-reference/rtc/android/play/mediaplayer/mediaplayer-control#api_imediaplayer_playpreloadedsrc) 播放该预加载的媒体资源。调用该方法后，如果收到 [onPlayerStateChanged](/zh-CN/api-reference/rtc/android/play/mediaplayer/mediaplayer-observer#callback_imediaplayersourceobserver_onplayersourcestatechanged) 回调并报告 `PLAYER_STATE_PLAYING` 状态，则表示播放成功。
如果想更换要播放的预加载媒体资源，可以再次调用 [playPreloadedSrc](/zh-CN/api-reference/rtc/android/play/mediaplayer/mediaplayer-control#api_imediaplayer_playpreloadedsrc) 并指定新的媒体资源 URL。若想重新播放该媒体资源，需要先调用 [preloadSrc](/zh-CN/api-reference/rtc/android/play/mediaplayer/mediaplayer-open#api_imediaplayer_preloadsrc) 重新预加载后再播放。若想清空播放列表，请调用 [stop](/zh-CN/api-reference/rtc/android/play/rte-player#api_player_stop_player)。

:::note
注： 如果在播放暂停时调用该方法，该方法在播放恢复之前不会生效。
:::

<a id="api_imediaplayer_playpreloadedsrc__parameters"></a>

### 参数

### src

播放列表中媒体资源的 URL，必须与通过 [preloadSrc](/zh-CN/api-reference/rtc/android/play/mediaplayer/mediaplayer-open#api_imediaplayer_preloadsrc) 设置的 `src` 保持一致，否则无法播放该媒体资源。

<a id="api_imediaplayer_playpreloadedsrc__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。

## seek

跳转到新的播放位置。

<a id="api_imediaplayer_seek__prototype"></a>

```text
int seek(long newPos);
```

<a id="api_imediaplayer_seek__detailed_desc"></a>

如果在播放完成后调用 [seek](/zh-CN/api-reference/rtc/android/play/mediaplayer/mediaplayer-control#api_imediaplayer_seek)，即收到回调 [onPlayerStateChanged](/zh-CN/api-reference/rtc/android/play/mediaplayer/mediaplayer-observer#callback_imediaplayersourceobserver_onplayersourcestatechanged)，播放状态为 `PLAYER_STATE_PLAYBACK_COMPLETED` 或 `PLAYER_STATE_PLAYBACK_ALL_LOOPS_COMPLETED`，SDK 会从指定位置开始播放媒体文件，并触发 [onPlayerStateChanged](/zh-CN/api-reference/rtc/android/play/mediaplayer/mediaplayer-observer#callback_imediaplayersourceobserver_onplayersourcestatechanged) 回调，播放状态为 `PLAYER_STATE_PLAYING`。
如果在播放暂停时调用 [seek](/zh-CN/api-reference/rtc/android/play/mediaplayer/mediaplayer-control#api_imediaplayer_seek)，调用成功后，SDK 会跳转到指定位置。要恢复播放，请调用 [resume](/zh-CN/api-reference/rtc/android/play/mediaplayer/mediaplayer-control#api_imediaplayer_resume) 或 [play](/zh-CN/api-reference/rtc/android/play/mediaplayer/mediaplayer-control#api_imediaplayer_play)。

<a id="api_imediaplayer_seek__timing"></a>

### 调用时机

你可以在加入频道前或后调用此方法。

## onSeek

当 SDK 定位媒体资源数据时触发的回调。

<a id="callback_imediaplayercustomdataprovider_onseek__prototype"></a>

```text
long onSeek(long offset, int whence)
```

<a id="callback_imediaplayercustomdataprovider_onseek__detailed_desc"></a>

当你调用 [openWithMediaSource](/zh-CN/api-reference/rtc/android/play/mediaplayer/mediaplayer-open#api_imediaplayer_openwithmediasource) 或 `open` 方法打开自定义媒体资源时，SDK 会触发该回调，请求媒体资源中指定位置的数据。

<a id="callback_imediaplayercustomdataprovider_onseek__parameters"></a>

### 参数

### offset

目标位置相对于起始点的偏移量，单位为字节。该值可以为正数或负数。

### whence

起始点，可设置为以下值之一：

- 0：起始点为数据开头，定位后的实际数据偏移量为 `offset`。
- 1：起始点为当前位置，定位后的实际数据偏移量为当前位置加 `offset`。
- 2：起始点为数据末尾，定位后的实际数据偏移量为整个数据长度加 `offset`。
- 65536：不执行定位操作，返回文件大小。建议在播放 MP3、WAV 等纯音频文件时使用该值。

<a id="callback_imediaplayercustomdataprovider_onseek__return_values"></a>

### 返回值

- `whence` 为 65536 时，返回媒体文件大小。
- `whence` 为 0、1 或 2 时，返回定位后的实际数据偏移量。
- -1：定位失败。
