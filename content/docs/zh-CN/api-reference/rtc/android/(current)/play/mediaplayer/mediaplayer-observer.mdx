## <span id="toc_mediaplayer_observer"></span>registerAudioFrameObserver [#api_imediaplayer_registeraudioframeobserver2_imediaplayer]

注册音频帧观测器对象。

<a id="api_imediaplayer_registeraudioframeobserver2_imediaplayer__prototype"></a>

```java
int registerAudioFrameObserver(IMediaPlayerAudioFrameObserver audioFrameObserver, int mode);
```

### <span id="api_imediaplayer_registeraudioframeobserver2_imediaplayer__detailed_desc"></span>参数 [#api_imediaplayer_registeraudioframeobserver2_imediaplayer__parameters]

#### `audioFrameObserver`

音频帧观测器对象，用于接收每一帧音频数据。详见 [IMediaPlayerAudioFrameObserver](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_imediaplayeraudioframeobserver)。

#### `mode`

音频帧的使用模式：

- `RAW_AUDIO_FRAME_OP_MODE_READ_ONLY` （0）：（默认）只读模式。例如，你通过声网 SDK 获取音频数据后，再推送 RTMP 或 RTMPS 流。
- `RAW_AUDIO_FRAME_OP_MODE_READ_WRITE` （2）：读写模式。你可以从 [AudioFrame](/zh-CN/api-reference/rtc/android/class-audioframe) 中读取音频数据，修改后再播放。例如，你有自己的音频特效处理模块，并进行语音预处理，如变声。

### 返回值 [#api_imediaplayer_registeraudioframeobserver2_imediaplayer__return_values]

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/android/error-code)了解详情和解决建议。

- [IMediaPlayer](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_imediaplayer)

## onPlayBufferUpdated [#callback_imediaplayersourceobserver_onplaybufferupdated]

onPlayBufferUpdated 回调：报告缓冲数据可支持的播放时长。

<a id="callback_imediaplayersourceobserver_onplaybufferupdated__prototype"></a>

```java
void onPlayBufferUpdated(long playCachedBuffer)
```

<a id="callback_imediaplayersourceobserver_onplaybufferupdated__detailed_desc"></a>

该回调在播放在线媒体资源时每两秒触发一次。

- 当缓冲数据可支持的播放时长小于阈值（默认值为 0）时，SDK 返回 `PLAYER_EVENT_BUFFER_LOW` （6）。
- 当缓冲数据可支持的播放时长大于阈值（默认值为 0）时，SDK 返回 `PLAYER_EVENT_BUFFER_RECOVER` （7）。

### 触发时机 [#callback_imediaplayersourceobserver_onplaybufferupdated__timing]

该回调在播放在线媒体资源时每两秒被触发。

### 参数 [#callback_imediaplayersourceobserver_onplaybufferupdated__parameters]

#### `playCachedBuffer`

缓冲数据可支持的播放时长，单位为毫秒。

- [IMediaPlayerObserver](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_imediaplayersourceobserver)

## onReadData [#callback_imediaplayercustomdataprovider_onreaddata]

SDK 读取媒体资源数据时触发的回调。

<a id="callback_imediaplayercustomdataprovider_onreaddata__prototype"></a>

```java
@CalledByNative int onReadData(ByteBuffer buffer, int bufferSize);
```

<a id="callback_imediaplayercustomdataprovider_onreaddata__detailed_desc"></a>

当你调用 [openWithMediaSource](/zh-CN/api-reference/rtc/android/play/mediaplayer/mediaplayer-open#api_imediaplayer_openwithmediasource) 方法打开媒体资源时，SDK 会触发该回调，并请求你传入媒体资源数据的缓冲区。

### 参数 [#callback_imediaplayercustomdataprovider_onreaddata__parameters]

#### `buffer`

数据缓冲区。你需要将 SDK 请求的 `bufferSize` 字节数据写入该缓冲区。详见 `ByteBuffer`。

#### `bufferSize`

数据缓冲区的长度，单位为字节。

### 返回值 [#callback_imediaplayercustomdataprovider_onreaddata__return_values]

- 数据读取成功时，返回实际读取的数据长度（字节）。
- 数据读取失败时，返回 0。

- [IMediaPlayerCustomDataProvider](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_imediaplayercustomdataprovider)
