## open [1/2]

打开媒体资源。

<a id="api_imediaplayer_open__prototype"></a>

```java
int open(String url, long startPos);
```

<a id="api_imediaplayer_open__detailed_desc"></a>

支持播放以 `content://` 开头的 URI 文件。

:::info[注]
该方法为异步调用。
:::

<a id="api_imediaplayer_open__timing"></a>

### 调用时机

该方法可以在加入频道前或后调用。

<a id="api_imediaplayer_open__related"></a>

### 相关回调

调用该方法后，SDK 会触发 [onPlayerStateChanged](/zh-CN/api-reference/rtc/android/play/mediaplayer/mediaplayer-observer#callback_imediaplayersourceobserver_onplayersourcestatechanged) 回调。在收到播放状态为 `OPEN_COMPLETED` 的上报后，你可以调用 [play](/zh-CN/api-reference/rtc/android/play/mediaplayer/mediaplayer-control#api_imediaplayer_play) 方法播放媒体文件。

<a id="api_imediaplayer_open__parameters"></a>

### 参数

#### `url`

媒体文件的路径，支持本地路径和在线路径。

#### `startPos`

播放的起始位置（毫秒，默认值为 0）。

<a id="api_imediaplayer_open__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/android/error-code)了解详情和解决建议。

### 所属接口类
- [IMediaPlayer](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_imediaplayer)

## openWithMediaSource

打开媒体文件并配置播放场景。

<a id="api_imediaplayer_openwithmediasource__prototype"></a>

```java
int openWithMediaSource(MediaPlayerSource source);
```

<a id="api_imediaplayer_openwithmediasource__detailed_desc"></a>

该方法支持打开不同类型的媒体文件，包括以 `content://` 开头的 URI 文件和 `assets` 文件夹中的媒体文件，并设置播放选项。

:::info[注]
该方法为异步调用。如果需要播放媒体文件，请确保在调用 [play](/zh-CN/api-reference/rtc/android/play/mediaplayer/mediaplayer-control#api_imediaplayer_play) 方法之前，已收到 [onPlayerStateChanged](/zh-CN/api-reference/rtc/android/play/mediaplayer/mediaplayer-observer#callback_imediaplayersourceobserver_onplayersourcestatechanged) 回调并报告 `OPEN_COMPLETED`。
:::

<a id="api_imediaplayer_openwithmediasource__timing"></a>

### 调用时机

你可以在加入频道前或加入频道后调用该方法。

<a id="api_imediaplayer_openwithmediasource__parameters"></a>

### 参数

#### `source`

媒体资源，详见 [MediaPlayerSource](/zh-CN/api-reference/rtc/android/class-mediasource)。

<a id="api_imediaplayer_openwithmediasource__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/android/error-code)了解详情和解决建议。

### 所属接口类

## preloadSrc

预加载媒体资源。

<a id="api_imediaplayer_preloadsrc__prototype"></a>

```java
int preloadSrc(String src, long startPos);
```

<a id="api_imediaplayer_preloadsrc__detailed_desc"></a>

调用该方法后，如果在 [onPreloadEvent](/zh-CN/api-reference/rtc/android/play/mediaplayer/mediaplayer-observer#callback_imediaplayersourceobserver_onpreloadevent) 回调中收到 `PLAYER_PRELOAD_EVENT_COMPLETE` 事件，表示预加载成功；如果收到 `PLAYER_PRELOAD_EVENT_ERROR` 事件，表示预加载失败。预加载成功后，如需播放该媒体资源，请调用 [playPreloadedSrc](/zh-CN/api-reference/rtc/android/play/mediaplayer/mediaplayer-control#api_imediaplayer_playpreloadedsrc)；如需清空播放列表，请调用 `stop()`。

:::info[注]
- 在调用此方法前，请确保已成功调用 open 或 openWithMediaSource 打开媒体资源。
- 声网不支持将重复的媒体资源预加载到播放列表中。但你可以将正在播放的媒体资源再次预加载到播放列表中。
:::

<a id="api_imediaplayer_preloadsrc__parameters"></a>

### 参数

#### `src`

媒体资源的 URL。

#### `startPos`

媒体资源预加载到播放列表后开始播放的位置（单位为毫秒）。预加载直播流时，请将该参数设为 0。

<a id="api_imediaplayer_preloadsrc__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/android/error-code)了解详情和解决建议。

### 所属接口类
- [IMediaPlayer](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_imediaplayer)

## switchSrc

切换正在播放的媒体资源。

<a id="api_imediaplayer_switchsrc__prototype"></a>

```java
int switchSrc(String src, boolean syncPts);
```

<a id="api_imediaplayer_switchsrc__detailed_desc"></a>

你可以调用此方法根据当前网络状态切换播放的媒体资源地址。例如：

- 当网络较差时，将播放的媒体资源切换为码率较低的媒体资源地址。
- 当网络良好时，将播放的媒体资源切换为码率较高的媒体资源地址。

调用此方法后，如果收到 [onPlayerEvent](/zh-CN/api-reference/rtc/android/play/mediaplayer/mediaplayer-observer#callback_imediaplayersourceobserver_onplayerevent) 回调报告 `PLAYER_EVENT_SWITCH_COMPLETE` 事件，表示切换成功。如果切换失败，SDK 会自动重试 3 次。如果仍然失败，你将收到 [onPlayerEvent](/zh-CN/api-reference/rtc/android/play/mediaplayer/mediaplayer-observer#callback_imediaplayersourceobserver_onplayerevent) 回调报告 `PLAYER_EVENT_SWITCH_ERROR` 事件，表示切换过程中发生错误。

:::info[注]
- 请确保在调用 open 之后再调用此方法。
- 为确保正常播放，调用此方法时请注意以下事项：
  - 播放暂停时不要调用此方法。
  - 切换过程中不要调用 seek 方法。
  - 切换媒体资源前，请确保播放位置未超过待切换媒体资源的总时长。
:::

<a id="api_imediaplayer_switchsrc__parameters"></a>

### 参数

#### `src`

媒体资源的 URL 地址。

#### `syncPts`

是否在切换前后同步播放位置（毫秒）：

- true：同步切换前后的播放位置。
- false：（默认）不同步切换前后的播放位置。

<a id="api_imediaplayer_switchsrc__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/android/error-code)了解详情和解决建议。

### 所属接口类
- [IMediaPlayer](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_imediaplayer)
