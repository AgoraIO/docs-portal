## <span id="toc_mediaplayer_cache"></span>enableAutoRemoveCache [#api_imediaplayercachemanager_enableautoremovecache]

设置是否自动删除缓存的媒体文件。

<a id="api_imediaplayercachemanager_enableautoremovecache__prototype"></a>

```java
int enableAutoRemoveCache(boolean enable);
```

<a id="api_imediaplayercachemanager_enableautoremovecache__detailed_desc"></a>

当缓存的媒体文件数量或大小超过设置的限制时，启用该功能后，SDK 会自动删除最近最少使用的缓存文件。

### 参数 [#api_imediaplayercachemanager_enableautoremovecache__parameters]

#### `enable`

是否启用 SDK 自动删除缓存的媒体文件：

- true：自动删除缓存的媒体文件。
- false：（默认）不自动删除缓存的媒体文件。

### 返回值 [#api_imediaplayercachemanager_enableautoremovecache__return_values]

- 0：方法调用成功。
- &lt; 0：方法调用失败，详见 [MediaPlayerReason](/zh-CN/api-reference/rtc/android/enum-mediaplayerreason)。

- [IMediaPlayerCacheManager](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_imediaplayercachemanager)

## getCacheDir [#api_imediaplayercachemanager_getcachedir]

获取缓存媒体文件的存储路径。

<a id="api_imediaplayercachemanager_getcachedir__prototype"></a>

```java
String getCacheDir();
```

<a id="api_imediaplayercachemanager_getcachedir__detailed_desc"></a>

如果在调用该方法之前未调用 [setCacheDir](/zh-CN/api-reference/rtc/android/play/mediaplayer/mediaplayer-cache#api_imediaplayercachemanager_setcachedir) 设置缓存媒体文件的存储路径，则该方法返回 SDK 默认使用的存储路径。

### 返回值 [#api_imediaplayercachemanager_getcachedir__return_values]

方法调用成功时，返回缓存媒体文件的存储路径。 方法调用失败，返回空字符串。

- [IMediaPlayerCacheManager](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_imediaplayercachemanager)

## removeOldCache [#api_imediaplayercachemanager_removeoldcache]

删除最少使用的缓存媒体文件。

<a id="api_imediaplayercachemanager_removeoldcache__prototype"></a>

```java
int removeOldCache();
```

<a id="api_imediaplayercachemanager_removeoldcache__detailed_desc"></a>

你可以在缓存文件的存储空间即将达到上限时调用该方法。调用该方法后，SDK 会删除最少使用的缓存媒体文件。

:::info[注]
[removeOldCache](/zh-CN/api-reference/rtc/android/play/mediaplayer/mediaplayer-cache#api_imediaplayercachemanager_removeoldcache) 不会删除当前正在播放的缓存媒体文件。
:::

### 返回值 [#api_imediaplayercachemanager_removeoldcache__return_values]

- 0：方法调用成功。
- &lt; 0：方法调用失败，详见 [MediaPlayerReason](/zh-CN/api-reference/rtc/android/enum-mediaplayerreason)。

- [IMediaPlayerCacheManager](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_imediaplayercachemanager)

## onPlayerCacheStats [#callback_imediaplayersourceobserver_onplayercachestats]

报告正在缓存的媒体文件的统计信息回调。

<a id="callback_imediaplayersourceobserver_onplayercachestats__prototype"></a>

```java
void onPlayerCacheStats(CacheStatistics stats)
```

<a id="callback_imediaplayersourceobserver_onplayercachestats__detailed_desc"></a>

调用 [openWithMediaSource](/zh-CN/api-reference/rtc/android/play/mediaplayer/mediaplayer-open#api_imediaplayer_openwithmediasource) 方法并将 `enableCache` 设置为 true 后，SDK 每秒触发一次该回调。

### 触发时机 [#callback_imediaplayersourceobserver_onplayercachestats__timing]

该回调在调用 [openWithMediaSource](/zh-CN/api-reference/rtc/android/play/mediaplayer/mediaplayer-open#api_imediaplayer_openwithmediasource) 方法并将 `enableCache` 设置为 true 后，每秒触发一次。

### 参数 [#callback_imediaplayersourceobserver_onplayercachestats__parameters]

#### `stats`

正在缓存的媒体文件的统计信息。详见 [CacheStatistics](/zh-CN/api-reference/rtc/android/class-cachestatistics)。

- [IMediaPlayerObserver](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_imediaplayersourceobserver)
