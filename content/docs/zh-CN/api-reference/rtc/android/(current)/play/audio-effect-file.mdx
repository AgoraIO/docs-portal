## playAllEffects

播放所有音效。

<a id="api_irtcengine_playalleffects__prototype"></a>

```text
public abstract int playAllEffects(int loopCount, double pitch, double pan, double gain, boolean publish);
```

<a id="api_irtcengine_playalleffects__detailed_desc"></a>

多次调用 `preloadEffect` 将多个音效预加载到内存后，可以调用该方法为频道内所有用户播放所有预加载的音效。

<a id="api_irtcengine_playalleffects__parameters"></a>

### 参数

### loopCount

音效的循环播放次数：

- `-1`：无限循环播放音效，直到调用 [stopEffect](/zh-CN/api-reference/rtc/android/play/audio-effect-file#api_irtcengine_stopeffect) 或 [stopAllEffects](/zh-CN/api-reference/rtc/android/play/audio-effect-file#api_irtcengine_stopalleffects)。
- `0`：播放一次音效。
- `1`：播放两次音效。

### pitch

音效的音调。取值范围为 0.5 到 2.0，默认值为 1.0（原始音调）。值越小，音调越低。

### pan

音效的空间位置。取值范围为 -1.0 到 1.0：

- `-1.0`：音效从左侧播放。
- `0.0`：音效从前方播放。
- `1.0`：音效从右侧播放。

### gain

音效的音量。取值范围为 [0, 100]，默认值为 100（原始音量）。值越小，音量越低。

### publish

是否将音效发布给远端用户：

- true：将音效发布给远端用户，本地用户和远端用户都能听到音效。
- false：（默认）不发布音效，只有本地用户能听到。

<a id="api_irtcengine_playalleffects__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。

### 所属接口类

- [RtcEngine](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_irtcengine)

## playEffect [1/2]

播放指定的本地或在线音效文件。

<a id="api_irtcengine_playeffect2__prototype"></a>

```text
public abstract int playEffect(int soundId, String filePath, int loopCount, double pitch, double pan, double gain, boolean publish);
```

<a id="api_irtcengine_playeffect2__detailed_desc"></a>

该方法支持播放以 `content://` 开头的 URI 文件。关于支持的音频文件格式，详见[声网 RTC SDK 支持哪些格式的音频文件](/zh-CN/api-reference/faq/product/audio_format)。若本地音乐文件不存在、SDK 不支持该文件格式，或无法访问音乐文件的 URL，SDK 会报告 `AUDIO_MIXING_REASON_CAN_NOT_OPEN`。要同时播放多个音效文件，请使用不同的 `soundId` 和 `filePath` 多次调用该方法。为获得最佳用户体验，声网建议不要同时播放超过三个音频文件。

:::note
注：

- 如果需要播放在线音效文件，建议先将其缓存到本地设备，调用 `preloadEffect` 将文件预加载到内存中，再调用该方法播放音效。否则可能因加载超时或失败导致播放失败或无声。
- 如果在调用 `playEffectEx` 前调用了 `preloadEffectEx`，则 `playEffectEx` 执行后不会关闭文件资源。下次调用 `playEffectEx` 时将从头开始播放。
- 如果未调用 `preloadEffectEx` 就直接调用 `playEffectEx`，则 `playEffectEx` 执行后会销毁资源。下次调用时将尝试重新打开文件并从头播放。
:::

<a id="api_irtcengine_playeffect2__timing"></a>

### 调用时机

你可以在加入频道前或后调用该方法。

<a id="api_irtcengine_playeffect2__related"></a>

### 相关回调

音效文件播放完成后，SDK 会触发 [onAudioEffectFinished](/zh-CN/api-reference/rtc/android/play/audio-effect-file#callback_irtcengineeventhandler_onaudioeffectfinished) 回调。

<a id="api_irtcengine_playeffect2__parameters"></a>

### 参数

### soundId

音效 ID。每个音效文件的 ID 必须唯一。

:::note
注： 如果你已通过调用 `preloadEffect` 将音效预加载到内存中，请确保该参数的值与 `preloadEffect` 中的 `soundId` 相同。
:::

### filePath

:::note
注： 如果你已通过调用 `preloadEffect` 将音效预加载到内存中，请确保该参数的值与 `preloadEffect` 中的 `filePath` 相同。
:::

音效文件路径。支持以下格式：

- 以 `content://` 开头的 URI 地址。
- 以 `/assets/` 开头的路径。
- URL。
- 本地文件的绝对路径（需精确到文件名和扩展名）。

支持的音频格式包括 MP3、AAC、M4A、MP4、WAV 和 3GP。

### loopCount

音效的循环播放次数：

- ≥ 0：播放的次数。例如，1 表示循环播放一次，即总共播放两次。
- -1：无限循环播放该音频文件。

### pitch

音效的音调。取值范围为 0.5 到 2.0，默认值为 1.0，表示原始音调。值越小，音调越低。

### pan

音效的空间位置。取值范围为 -1.0 到 1.0：

- -1.0：音效从用户左侧传来。
- 0.0：音效从用户正前方传来。
- 1.0：音效从用户右侧传来。

### gain

音效的音量。取值范围为 0.0 到 100.0，默认值为 100.0，表示原始音量。值越小，音量越低。

### publish

是否将音效发布给远端用户：

- true：将音效发布给远端用户，本地用户和远端用户都能听到音效。
- false：不将音效发布给远端用户，只有本地用户能听到音效。

<a id="api_irtcengine_playeffect2__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。

### filePath

本地文件的绝对路径或在线文件的 URL。支持的音频格式包括：mp3、mp4、m4a、aac、3gp、mkv 和 wav。

### loopCount

- `1`：播放两次。
