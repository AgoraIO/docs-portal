## <span id="toc_audio_mixing"></span>adjustAudioMixingPlayoutVolume [#api_irtcengine_adjustaudiomixingplayoutvolume]

调节本地播放的混音音量。

<a id="api_irtcengine_adjustaudiomixingplayoutvolume__prototype"></a>

```java
public abstract int adjustAudioMixingPlayoutVolume(int volume);
```

<a id="api_irtcengine_adjustaudiomixingplayoutvolume__detailed_desc"></a>

你需要在调用 `startAudioMixing` 并收到 [onAudioMixingStateChanged](/zh-CN/api-reference/rtc/android/play/audio-mixing#callback_irtcengineeventhandler_onaudiomixingstatechanged) （`AUDIO_MIXING_STATE_PLAYING` ）回调后调用此方法。

### 调用时机 [#api_irtcengine_adjustaudiomixingplayoutvolume__timing]

你需要在调用 `startAudioMixing` 并收到 [onAudioMixingStateChanged](/zh-CN/api-reference/rtc/android/play/audio-mixing#callback_irtcengineeventhandler_onaudiomixingstatechanged) （`AUDIO_MIXING_STATE_PLAYING` ）回调后调用此方法。

### 参数 [#api_irtcengine_adjustaudiomixingplayoutvolume__parameters]

#### `volume`

本地播放的混音音量，取值范围为 0 到 100。（默认值为 100）

- 0：静音。
- 100：原始音量。

### 返回值 [#api_irtcengine_adjustaudiomixingplayoutvolume__return_values]

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/android/error-code)了解详情和解决建议。

- [RtcEngine](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_irtcengine)

## setAudioMixingDualMonoMode [#api_irtcengine_setaudiomixingdualmonomode]

设置当前音频文件的声道模式。

<a id="api_irtcengine_setaudiomixingdualmonomode__prototype"></a>

```java
public abstract int setAudioMixingDualMonoMode(Constants.AudioMixingDualMonoMode mode);
```

<a id="api_irtcengine_setaudiomixingdualmonomode__detailed_desc"></a>

你可以根据需要将音频文件的声道模式设置为原始模式、左声道模式、右声道模式或混合声道模式。例如，在 KTV 场景中，音乐文件的左声道存储伴奏，右声道存储原唱人声。你可以根据实际需求进行设置：

- 如果只想听伴奏，使用该方法将音频文件的声道模式设置为左声道模式。
- 如果需要同时听到伴奏和原唱人声，调用该方法将声道模式设置为混合模式。

:::info[注]
该方法仅适用于立体声音频文件。

在 KTV 场景中，音乐文件的左声道存储伴奏，右声道存储原唱人声。你可以根据实际需求进行设置：

- 如果你只想听到伴奏，调用该方法将声道模式设置为左声道模式。

#### `废弃` [#api_irtcengine_startaudiomixing__detailed_desc]

该方法已废弃。请改用 [startAudioMixing [2/2]](/zh-CN/api-reference/rtc/android/play/audio-mixing#api_irtcengine_startaudiomixing2)。

## onAudioMixingStateChanged [#callback_irtcengineeventhandler_onaudiomixingstatechanged]

音乐文件播放状态变化回调。

<a id="callback_irtcengineeventhandler_onaudiomixingstatechanged__prototype"></a>

```java
public void onAudioMixingStateChanged(int state, int reason)
```

<a id="callback_irtcengineeventhandler_onaudiomixingstatechanged__detailed_desc"></a>

该回调报告当前音乐文件的播放状态和错误码。

### 触发时机 [#callback_irtcengineeventhandler_onaudiomixingstatechanged__timing]

该回调在音乐文件播放状态发生变化时被触发。

### 参数 [#callback_irtcengineeventhandler_onaudiomixingstatechanged__parameters]

#### `state`

音乐文件的播放状态：

- `AUDIO_MIXING_STATE_PLAYING` (710)：音乐文件正在播放。
- `AUDIO_MIXING_STATE_PAUSED` (711)：音乐文件暂停播放。
- `AUDIO_MIXING_STATE_STOPPED` (713)：音乐文件停止播放。
- `AUDIO_MIXING_STATE_FAILED` (714)：播放音乐文件时出现异常，SDK 会通过 `reason` 参数返回具体原因。

#### `reason`

错误码：

- `AUDIO_MIXING_REASON_OK` (0)：没有错误。
- `AUDIO_MIXING_REASON_CAN_NOT_OPEN` (701)：SDK 无法打开音乐文件。
- `AUDIO_MIXING_REASON_TOO_FREQUENT_CALL` (702)：SDK 打开音乐文件过于频繁。
- `AUDIO_MIXING_REASON_INTERRUPTED_EOF` (703)：音乐文件播放被中断。
- `AUDIO_MIXING_REASON_ONE_LOOP_COMPLETED` (721)：音乐文件完成一次循环播放。
- `AUDIO_MIXING_REASON_ALL_LOOPS_COMPLETED` (723)：音乐文件完成所有循环播放。
- `AUDIO_MIXING_REASON_STOPPED_BY_USER` (724)：通过调用 [stopAudioMixing](/zh-CN/api-reference/rtc/android/play/audio-mixing#api_irtcengine_stopaudiomixing) 停止音乐文件播放。

- [IRtcEngineEventHandler](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_irtcengineeventhandler)
