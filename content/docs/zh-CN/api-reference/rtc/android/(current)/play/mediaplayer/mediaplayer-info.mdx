## <span id="toc_mediaplayer_info"></span>getAudioBufferDelay [#api_imediaplayer_getaudiobufferdelay]

获取播放媒体文件时的音频缓冲延迟。

<a id="api_imediaplayer_getaudiobufferdelay__prototype"></a>

```java
int getAudioBufferDelay();
```

### <span id="api_imediaplayer_getaudiobufferdelay__detailed_desc"></span>返回值 [#api_imediaplayer_getaudiobufferdelay__return_values]

- 方法调用成功，返回音频缓冲延迟（单位：毫秒）。
- 方法调用失败，返回小于 0 的错误码。你可以使用 [MediaPlayerReason](/zh-CN/api-reference/rtc/android/enum-mediaplayerreason) 检查错误原因。

- [IMediaPlayer](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_imediaplayer)

## getStreamCount [#api_imediaplayer_getstreamcount]

- [IMediaPlayer](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_imediaplayer)

## getStreamInfo [#api_imediaplayer_getstreaminfo]

获取媒体流的详细信息。

<a id="api_imediaplayer_getstreaminfo__prototype"></a>

```java
MediaStreamInfo getStreamInfo(int index);
```

<a id="api_imediaplayer_getstreaminfo__detailed_desc"></a>

调用 [getStreamCount](/zh-CN/api-reference/rtc/android/play/mediaplayer/mediaplayer-info#api_imediaplayer_getstreamcount) 后，调用该方法获取指定索引的媒体流的详细信息。

### 调用时机 [#api_imediaplayer_getstreaminfo__timing]

在调用 [getStreamCount](/zh-CN/api-reference/rtc/android/play/mediaplayer/mediaplayer-info#api_imediaplayer_getstreamcount) 方法之后调用。

### 参数 [#api_imediaplayer_getstreaminfo__parameters]

#### `index`

媒体流的索引。该参数必须小于 [getStreamCount](/zh-CN/api-reference/rtc/android/play/mediaplayer/mediaplayer-info#api_imediaplayer_getstreamcount) 的返回值。

### 返回值 [#api_imediaplayer_getstreaminfo__return_values]

- 方法调用成功，返回 [MediaStreamInfo](/zh-CN/api-reference/rtc/android/class-playerstreaminfo) 对象。
- 方法调用失败，返回 `null`。

- [IMediaPlayer](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_imediaplayer)

## onPlayerPlaybackStats [#callback_imediaplayersourceobserver_onplayerplaybackstats]

报告正在播放的媒体文件的统计信息回调。

<a id="callback_imediaplayersourceobserver_onplayerplaybackstats__prototype"></a>

```java
void onPlayerPlaybackStats(PlayerPlaybackStats stats)
```

<a id="callback_imediaplayersourceobserver_onplayerplaybackstats__detailed_desc"></a>

该回调在媒体文件播放过程中每秒触发一次。

### 触发时机 [#callback_imediaplayersourceobserver_onplayerplaybackstats__timing]

该回调在媒体文件播放过程中每秒触发一次。

### 参数 [#callback_imediaplayersourceobserver_onplayerplaybackstats__parameters]

#### `stats`

媒体文件的统计信息。详见 [PlayerPlaybackStats](/zh-CN/api-reference/rtc/android/class-playerplaybackstats)。

- [IMediaPlayerObserver](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_imediaplayersourceobserver)
