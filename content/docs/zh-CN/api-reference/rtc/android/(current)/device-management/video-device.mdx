- 方法调用成功，返回 [AgoraFocalLengthInfo](/zh-CN/api-reference/rtc/android/class-focallengthinfo) 对象数组，包含摄像头的方向和焦距类型。
- 方法调用失败，返回空数组。

- [RtcEngine](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_irtcengine)

## setCameraExposureFactor

设置摄像头曝光值。

<a id="api_irtcengine_setcameraexposurefactor__prototype"></a>

```text
public abstract int setCameraExposureFactor(int factor);
```

<a id="api_irtcengine_setcameraexposurefactor__detailed_desc"></a>

:::info[自从]
自 v4.2.2 版本新增。
:::

:::note
注：

- 你必须在调用 [enableVideo](/zh-CN/api-reference/rtc/android/video/video-basic#api_irtcengine_enablevideo) 后再调用此方法。设置结果将在摄像头成功开启后生效，即 SDK 触发 [onLocalVideoStateChanged](/zh-CN/api-reference/rtc/android/video/video-basic#callback_irtcengineeventhandler_onlocalvideostatechanged) 回调并返回本地视频状态为 `LOCAL_VIDEO_STREAM_STATE_CAPTURING`（1）后。
- 在调用此方法前，声网建议调用 [isCameraExposureSupported](/zh-CN/api-reference/rtc/android/device-management/video-device#api_irtcengine_iscameraexposuresupported) 检查当前摄像头是否支持调整曝光值。
- 通过调用此方法，你可以调整当前激活摄像头的曝光值，即调用 [setCameraCapturerConfiguration](/zh-CN/api-reference/rtc/android/device-management/video-device#api_irtcengine_setcameracapturerconfiguration) 时指定的摄像头。
:::

<a id="api_irtcengine_setcameraexposurefactor__parameters"></a>

### 参数

<ParameterList>
<a id="factor"></a>
<Parameter name="factor">

摄像头曝光值。默认值为 0，表示使用摄像头的默认曝光值。值越大，曝光越强。当视频图像过曝时，可以降低曝光值；当视频图像曝光不足且暗部细节丢失时，可以提高曝光值。如果设置的曝光值超出设备支持的范围，SDK 会自动将其调整为设备实际支持的范围。取值范围为 [-20, 20]。

</Parameter>
</ParameterList>

- &lt; 0：方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。

## setCameraZoomFactor

设置摄像头的缩放因子。

<a id="api_irtcengine_setcamerazoomfactor__prototype"></a>

```text
public abstract int setCameraZoomFactor(float factor);
```

<a id="api_irtcengine_setcamerazoomfactor__detailed_desc"></a>

:::note
注： 你必须在调用 [enableVideo](/zh-CN/api-reference/rtc/android/video/video-basic#api_irtcengine_enablevideo) 之后再调用此方法。该设置在摄像头成功开启后生效，即 SDK 触发 [onLocalVideoStateChanged](/zh-CN/api-reference/rtc/android/video/video-basic#callback_irtcengineeventhandler_onlocalvideostatechanged) 回调并返回本地视频状态为 `LOCAL_VIDEO_STREAM_STATE_CAPTURING`（1）后。
:::

<a id="api_irtcengine_setcamerazoomfactor__parameters"></a>

### 参数

<ParameterList>
<a id="factor-1"></a>
<Parameter name="factor">

摄像头缩放因子。你可以通过调用 [getCameraMaxZoomFactor](/zh-CN/api-reference/rtc/android/device-management/video-device#api_irtcengine_getcameramaxzoomfactor) 获取设备支持的最大缩放因子。

</Parameter>
</ParameterList>

<a id="api_irtcengine_setcamerazoomfactor__return_values"></a>

### 返回值

- 方法调用成功，返回摄像头缩放因子 `factor` 的值。
- 方法调用失败，返回小于 0 的值。

## switchCamera [1/2]

切换前置和后置摄像头。

<a id="api_irtcengine_switchcamera__prototype"></a>

```text
public abstract int switchCamera();
```

<a id="api_irtcengine_switchcamera__detailed_desc"></a>

你可以调用该方法在应用运行过程中根据实际可用的摄像头动态切换前置或后置摄像头，无需重启视频流或重新配置视频源。该方法与 `switchCamera`（带参数版本）都可用于切换摄像头。不同之处在于，`switchCamera(String cameraId)` 通过指定摄像头 ID 切换到特定摄像头，而本方法则切换摄像头的方向（前置或后置）。

:::note
注： 该方法仅用于切换由第一个摄像头采集的视频流的摄像头，即调用 [startCameraCapture](/zh-CN/api-reference/rtc/android/video/camera-capture#api_irtcengine_startcameracapture) 时视频源设置为 `VIDEO_SOURCE_CAMERA_PRIMARY`（0）的视频流。
:::

<a id="api_irtcengine_switchcamera__timing"></a>

### 调用时机

必须在摄像头成功启用后调用，即 SDK 触发 [onLocalVideoStateChanged](/zh-CN/api-reference/rtc/android/video/video-basic#callback_irtcengineeventhandler_onlocalvideostatechanged) 回调并返回本地视频状态为 `LOCAL_VIDEO_STREAM_STATE_CAPTURING`（1）之后。

<a id="api_irtcengine_switchcamera__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。

### 所属接口类

- [RtcEngine](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_irtcengine)
