## 枚举值

### AUTO

（0）：由 SDK 决定是否开启镜像模式。

- 本地视频视图镜像模式：使用前置摄像头时，默认开启；使用后置摄像头时，默认关闭。
- 远端用户视图镜像模式：默认关闭。

### ENABLED

（1）：开启镜像模式。

### DISABLED

（2）：关闭镜像模式。
