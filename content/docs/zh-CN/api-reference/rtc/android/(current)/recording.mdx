## <span id="toc_recording"></span>createMediaRecorder [#api_irtcengine_createmediarecorder]

创建用于音视频录制的录制器实例。

<a id="api_irtcengine_createmediarecorder__prototype"></a>

```java
public abstract AgoraMediaRecorder createMediaRecorder(RecorderStreamInfo info);
```

<a id="api_irtcengine_createmediarecorder__detailed_desc"></a>

在开始录制音视频流之前，你需要调用该方法创建一个录制器实例。你可以多次调用该方法创建多个录制器，并通过 `info` 参数指定要录制的频道名和用户 ID。 成功创建录制器后，你需要调用 [setMediaRecorderObserver](/zh-CN/api-reference/rtc/android/recording#api_imediarecorder_setmediarecorderobserver) 为录制器注册观察者以监听录制相关的回调，然后调用 [startRecording](/zh-CN/api-reference/rtc/android/recording#api_imediarecorder_startrecording) 开始录制。

### 参数 [#api_irtcengine_createmediarecorder__parameters]

#### `info`

要录制的音视频流的信息。详见 [RecorderStreamInfo](/zh-CN/api-reference/rtc/android/class-recorderstreaminfo)。

### 返回值 [#api_irtcengine_createmediarecorder__return_values]

- 方法调用成功，返回 [AgoraMediaRecorder](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_imediarecorder) 实例。
- 方法调用失败，返回 `null`。

- [RtcEngine](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_irtcengine)

## startAudioRecording [1/2] [#api_irtcengine_startaudiorecording1]

开始客户端录音。

<a id="api_irtcengine_startaudiorecording1__prototype"></a>

```java
public abstract int startAudioRecording(String filePath, int quality);
```

<a id="api_irtcengine_startaudiorecording1__detailed_desc"></a>

你必须在调用 `joinChannel` 后调用该方法。调用 `leaveChannel` 时，录音会自动停止。 请确保指定的目录存在且可写。

:::info[注]
调用该方法时，默认的录音采样率为 32 kHz，且无法更改。
:::

### 参数 [#api_irtcengine_startaudiorecording1__parameters]

#### `filePath`

本地保存录音文件的绝对路径，包括文件名和扩展名。例如： /sdcard/emulated/0/audio.aac。

:::info[注]
请确保指定路径存在且可写。
:::

#### `quality`

录音质量：

- 0：低质量。采样率为 32 kHz，录制 10 分钟的文件大小约为 1.2 MB。
- 1：中等质量。采样率为 32 kHz，录制 10 分钟的文件大小约为 2 MB。
- 2：高质量。采样率为 32 kHz，录制 10 分钟的文件大小约为 3.75 MB。

### 返回值 [#api_irtcengine_startaudiorecording1__return_values]

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/android/error-code)了解详情和解决建议。

- [RtcEngine](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_irtcengine)

## startAudioRecording [2/2] [#api_irtcengine_startaudiorecording3]

开始客户端录制并应用录制配置。

<a id="api_irtcengine_startaudiorecording3__prototype"></a>

```java
public abstract int startAudioRecording(AudioRecordingConfiguration config);
```

<a id="api_irtcengine_startaudiorecording3__detailed_desc"></a>

调用该方法后，你可以录制频道中用户的音频并获取录音文件。录音文件仅支持以下格式：

- WAV：音频保真度高但文件较大。例如，在 32000 Hz 采样率下，10 分钟录音约为 73 MB。
- AAC：音频保真度较低但文件较小。例如，在 32000 Hz 采样率和 `AUDIO_RECORDING_QUALITY_MEDIUM` 录音质量下，10 分钟录音约为 2 MB。

当用户离开频道时，录制会自动停止。

### 调用时机 [#api_irtcengine_startaudiorecording3__timing]

你必须在加入频道后调用该方法。

### 参数 [#api_irtcengine_startaudiorecording3__parameters]

#### `config`

录制配置。详见 [AudioRecordingConfiguration](/zh-CN/api-reference/rtc/android/class-audiorecordingconfiguration)。

### 返回值 [#api_irtcengine_startaudiorecording3__return_values]

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/android/error-code)了解详情和解决建议。

- [RtcEngine](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_irtcengine)

## startRecording [#api_imediarecorder_startrecording]

开始录制音频和视频流。

<a id="api_imediarecorder_startrecording__prototype"></a>

```java
public int startRecording(MediaRecorderConfiguration config)
```

<a id="api_imediarecorder_startrecording__detailed_desc"></a>

该方法用于开始录制音频和视频流。声网 SDK 支持同时录制本地和远端用户的音视频流。 在调用该方法前，请确保：

- 已使用 [createMediaRecorder](/zh-CN/api-reference/rtc/android/recording#api_irtcengine_createmediarecorder) 创建媒体录制器对象。
- 已使用 [setMediaRecorderObserver](/zh-CN/api-reference/rtc/android/recording#api_imediarecorder_setmediarecorderobserver) 注册媒体录制器观察者以监听录制相关的回调。
- 已加入频道。

该方法支持录制以下数据：

- 由麦克风采集的音频，格式为 AAC。
- 由摄像头采集的视频，格式为 H.264 或 H.265。

录制开始后，如果视频分辨率发生变化，SDK 会停止录制；如果音频采样率或声道数发生变化，SDK 会继续录制并生成一个 MP4 文件。 仅当检测到可录制的音视频流时，才会生成录制文件。如果没有可录制的流，或录制过程中音视频流中断超过 5 秒，SDK 会停止录制并触发 [onRecorderStateChanged](/zh-CN/api-reference/rtc/android/recording#callback_imediarecorderobserver_onrecorderstatechanged) （`RECORDER_STATE_ERROR`, `RECORDER_REASON_NO_STREAM` ）回调。

:::info[注]
- 如果需要录制本地音视频流，请确保本地用户角色在开始录制前已设置为主播。
- 如果需要录制远端用户的音视频流，请确保在开始录制前已订阅远端用户的音视频流。
:::

### 参数 [#api_imediarecorder_startrecording__parameters]

#### `config`

音视频流录制的配置。详见 [MediaRecorderConfiguration](/zh-CN/api-reference/rtc/android/class-mediarecorderconfiguration)。

### 返回值 [#api_imediarecorder_startrecording__return_values]

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/android/error-code)了解详情和解决建议。

  - -2：参数无效。请确保：

    - 指定的录制文件保存路径正确且可写。
    - 指定的录制文件格式正确。
    - 最大录制时长设置正确。
  - -4：当前 [RtcEngine](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_irtcengine) 状态不支持该操作。可能是录制已在进行中，或因错误而停止。
  - -7：在 [RtcEngine](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_irtcengine) 初始化前调用该方法。请确保在调用该方法前已创建 [AgoraMediaRecorder](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_imediarecorder) 对象。

- [AgoraMediaRecorder](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_imediarecorder)

## onRecorderInfoUpdated [#callback_imediarecorderobserver_onrecorderinfoupdated]

<a id="callback_imediarecorderobserver_onrecorderinfoupdated__detailed_desc"></a>

频道名。

#### `uid`

用户 ID。

#### `info`

录制文件信息，详见 [RecorderInfo](/zh-CN/api-reference/rtc/android/class-recorderinfo)。

## onRecorderStateChanged [#callback_imediarecorderobserver_onrecorderstatechanged]

录制状态发生变化时的回调。

<a id="callback_imediarecorderobserver_onrecorderstatechanged__prototype"></a>

```java
@CalledByNative void onRecorderStateChanged(String channelId, int uid, int state, int reason);
```

<a id="callback_imediarecorderobserver_onrecorderstatechanged__detailed_desc"></a>

SDK 在音视频流的录制状态发生变化时会触发该回调，报告当前的录制状态及其变化原因。

### 参数 [#callback_imediarecorderobserver_onrecorderstatechanged__parameters]

#### `channelId`

频道名。

#### `uid`

用户 ID。

#### `state`

当前录制状态：

- `RECORDER_STATE_ERROR` （-1）：录制过程中发生错误。
- `RECORDER_STATE_START` （2）：开始录制音视频流。
- `RECORDER_STATE_STOP` （3）：停止录制音视频流。

#### `reason`

录制状态变化的原因：

- `RECORDER_REASON_NONE` （0）：一切正常。
- `RECORDER_REASON_WRITE_FAILED` （1）：录制文件写入失败。
- `RECORDER_REASON_NO_STREAM` （2）：无可用音视频流，或音视频流中断超过 5 秒。
- `RECORDER_REASON_OVER_MAX_DURATION` （3）：录制时长超过最大限制。
- `RECORDER_REASON_CONFIG_CHANGED` （4）：录制配置发生变化。

- [IMediaRecorderCallback](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_imediarecorderobserver)
