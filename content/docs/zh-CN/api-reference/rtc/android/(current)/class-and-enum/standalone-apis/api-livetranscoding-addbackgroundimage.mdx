<a id="api_livetranscoding_addbackgroundimage__prototype"></a>

```java
public void addBackgroundImage(AgoraImage backgroundImage)
```

<a id="api_livetranscoding_addbackgroundimage__detailed_desc"></a>

如果 `backgroundImageList` 为空，则初始化该列表，并将背景图像添加到该列表中。

<a id="api_livetranscoding_addbackgroundimage__parameters"></a>

## 参数

### `backgroundImage`

要添加的背景图像。详见 [AgoraImage](/zh-CN/api-reference/rtc/android/class-and-enum/classes/class-rtcimage)。
