title: "SrcInfo"
description: "用于获取正在播放媒体资源的视频码率信息。"
---
<a id="class_srcinfo__prototype"></a>

```java
public class SrcInfo {
  private int bitrateInKbps;
  private String name;
}
```

<a id="class_srcinfo__parameters"></a>

## 属性

### `bitrateInKbps`

正在播放的媒体资源的视频码率，单位为 Kbps。

### `name`

媒体资源的名称。
