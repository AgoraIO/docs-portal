---
title: "RecorderStreamInfo"
description: "用于指定待录制的音视频流信息。"
---
<a id="class_recorderstreaminfo__prototype"></a>

```java
public class RecorderStreamInfo {
  public int uid;
  public String channelId;
  public int recorderStreamType;
}
```

<a id="class_recorderstreaminfo__parameters"></a>

## 属性

### `uid`

要录制的远端用户 ID。

### `channelId`

要录制的频道名。

### `recorderStreamType`

录制的视频流类型：

- 0：频道内的远端视频流。
- 1：加入频道前的本地预览视频流。
