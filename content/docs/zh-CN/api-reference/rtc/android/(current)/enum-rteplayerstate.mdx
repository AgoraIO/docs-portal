## 枚举值

<ParameterList>
<a id="idle"></a>
<Parameter name="IDLE">

（0）：空闲状态。

</Parameter>
<a id="opening"></a>
<Parameter name="OPENING">

（1）：正在打开 URL 资源。调用 [openWithUrl](/zh-CN/api-reference/rtc/android/play/rte-player#api_player_openwithurl) 后会返回该状态码。

</Parameter>
<a id="open_completed"></a>
<Parameter name="OPEN_COMPLETED">

（2）：已成功打开 URL 资源。[openWithUrl](/zh-CN/api-reference/rtc/android/play/rte-player#api_player_openwithurl) 成功打开资源后会返回该状态码。

</Parameter>
<a id="playing"></a>
<Parameter name="PLAYING">

（3）：正在播放。

</Parameter>
<a id="paused"></a>
<Parameter name="PAUSED">

（4）：播放已暂停。成功调用 [pause](/zh-CN/api-reference/rtc/android/play/rte-player#api_player_pause_player) 后会返回该状态码。

</Parameter>
<a id="playback_completed"></a>
<Parameter name="PLAYBACK_COMPLETED">

（5）：播放已完成。

</Parameter>
<a id="stopped"></a>
<Parameter name="STOPPED">

（6）：播放已停止。成功调用 [stop](/zh-CN/api-reference/rtc/android/play/rte-player#api_player_stop_player) 后会返回该状态码。

</Parameter>
<a id="failed"></a>
<Parameter name="FAILED">

（7）：播放失败。发生内部错误时会返回该状态码。收到该状态后需先调用 [stop](/zh-CN/api-reference/rtc/android/play/rte-player#api_player_stop_player)，再调用 [openWithUrl](/zh-CN/api-reference/rtc/android/play/rte-player#api_player_openwithurl) 重新打开资源。

</Parameter>
</ParameterList>
