<a id="class_videosubscriptionoptions__parameters"></a>

## 属性

### streamType

期望订阅的视频流类型。默认值为 `REMOTE_VIDEO_STREAM_HIGH`，表示订阅视频大流。详见 `REMOTE_VIDEO_STREAM_TYPE`。

### encodedFrameOnly

是否仅订阅编码后的视频帧：

- true：仅订阅编码后的视频数据（结构化数据），SDK 不解码也不渲染原始视频数据。
- false：同时订阅原始视频数据和编码后的视频数据（默认）。
