```java
public boolean removeBackgroundImage(AgoraImage backgroundImage)
```

## <span id="api_livetranscoding_removebackgroundimage__detailed_desc"></span>参数 [#api_livetranscoding_removebackgroundimage__parameters]

### `backgroundImage`

要移除的背景图像。详见 [AgoraImage](/zh-CN/api-reference/rtc/android/class-rtcimage)。

## 返回值 [#api_livetranscoding_removebackgroundimage__return_values]

- true：移除成功。
- false：移除失败。
