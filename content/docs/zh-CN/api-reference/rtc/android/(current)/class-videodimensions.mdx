---
title: "VideoDimensions"

<a id="class_videodimensions__prototype"></a>

```java
static public class VideoDimensions {
    public int width;
    public int height;
  }
```

## 属性 [#class_videodimensions__parameters]

### `width`

视频的宽度，单位为像素。

### `height`

视频的高度，单位为像素。
