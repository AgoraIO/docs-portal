<a id="class_codeccaplevels__prototype"></a>

```java
public class CodecCapLevels {
  public int hwDecodingLevel;
  public int swDecodingLevel;
};
```

<a id="class_codeccaplevels__parameters"></a>

## 属性

### `hwDecodingLevel`

硬件解码能力等级，表示设备对不同画质的视频进行硬件解码的能力。

### `swDecodingLevel`

软件解码能力等级，表示设备对不同画质的视频进行软件解码的能力。
