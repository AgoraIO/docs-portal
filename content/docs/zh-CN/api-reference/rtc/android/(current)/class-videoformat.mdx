title: "CaptureFormat"
description: "视频帧格式设置。"
---

<a id="class_videoformat__prototype"></a>

```java
static public class CaptureFormat {
  public int width;
  public int height;
  public int fps;
}
```

## 属性 [#class_videoformat__parameters]

### `width`

视频帧的宽度（像素）。默认值为 960。

### `height`

视频帧的高度（像素）。默认值为 540。

### `fps`

视频帧率（帧每秒）。默认值为 15。
