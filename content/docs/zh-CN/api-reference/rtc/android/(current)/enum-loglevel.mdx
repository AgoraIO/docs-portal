## 枚举值

<ParameterList>
<a id="log_level_none"></a>
<Parameter name="LOG_LEVEL_NONE">

（0x0000）：输出等级为 NONE，仅用于不输出任何日志信息。

</Parameter>
<a id="log_level_info"></a>
<Parameter name="LOG_LEVEL_INFO">

（0x0001）：（默认）输出等级为 INFO，输出 `FATAL`、`ERROR`、`WARN` 和 `INFO` 级别的日志信息。建议将日志过滤器设置为该等级。

</Parameter>
<a id="log_level_warn"></a>
<Parameter name="LOG_LEVEL_WARN">

（0x0002）：输出等级为 WARN，输出 `FATAL`、`ERROR` 和 `WARN` 级别的日志信息。

</Parameter>
<a id="log_level_error"></a>
<Parameter name="LOG_LEVEL_ERROR">

（0x0004）：输出等级为 ERROR，输出 `FATAL` 和 `ERROR` 级别的日志信息。

</Parameter>
<a id="log_level_fatal"></a>
<Parameter name="LOG_LEVEL_FATAL">

（0x0008）：输出等级为 FATAL，仅输出 `FATAL` 级别的日志信息。

</Parameter>
