## 枚举值

<ParameterList>
<a id="audio_track_mixable"></a>
<Parameter name="AUDIO_TRACK_MIXABLE">

（0）：可混音音频轨道。支持与其他音频流（如通过麦克风采集的音频流）混音，并在混音后本地播放或发布到频道。延迟高于直通音频轨道。

</Parameter>
<a id="audio_track_direct"></a>
<Parameter name="AUDIO_TRACK_DIRECT">

（1）：直通音频轨道。替代通过麦克风采集的音频流，且不支持与其他音频流混音。延迟低于可混音音频轨道。

:::note
注： 如果该参数设置为 `AUDIO_TRACK_DIRECT`，你必须在调用 `joinChannel` 加入频道时，将 [ChannelMediaOptions](/zh-CN/api-reference/rtc/android/class-channelmediaoptions) 中的 `publishMicrophoneTrack` 设置为 false，否则加入频道会失败并返回错误码 -2。
:::

</Parameter>
</ParameterList>
