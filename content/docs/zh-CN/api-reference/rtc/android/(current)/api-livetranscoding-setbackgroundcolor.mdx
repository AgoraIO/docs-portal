<a id="api_livetranscoding_setbackgroundcolor__prototype"></a>

```java
public void setBackgroundColor(int color)
```

<a id="api_livetranscoding_setbackgroundcolor__detailed_desc"></a>

颜色格式为 RGB 十六进制值。

<a id="api_livetranscoding_setbackgroundcolor__parameters"></a>

## 参数

### `color`

要设置的背景颜色，使用 RGB 十六进制值，仅填写数值，不包含 `#`。例如： `0xFFB6C1` 表示浅粉色。默认值为 `0x000000` （黑色）。（默认）
