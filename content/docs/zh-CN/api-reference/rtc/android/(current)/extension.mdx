## enableExtension

启用或禁用扩展功能。

<a id="api_irtcengine_enableextension__prototype"></a>

```text
public abstract int enableExtension(String provider, String extension, boolean enable);
```

<a id="api_irtcengine_enableextension__detailed_desc"></a>

通过调用该方法，你可以动态启用或禁用扩展功能，而无需更改处理流程。

:::note
注： [enableExtension](/zh-CN/api-reference/rtc/android/extension#api_irtcengine_enableextension) 会在未调用 [registerExtension](/zh-CN/api-reference/rtc/android/extension#api_irtcengine_registerextension) 的情况下自动注册指定扩展，以保证兼容性。建议你显式调用 [registerExtension](/zh-CN/api-reference/rtc/android/extension#api_irtcengine_registerextension)。
:::

<a id="api_irtcengine_enableextension__parameters"></a>

### 参数

### provider

扩展功能提供方的名称，例如 `agora.io`。

### extension

扩展功能的名称，例如 `agora.beauty`。

### enable

是否启用该扩展功能：

- true：（默认）启用扩展功能。
- false：禁用扩展功能。

<a id="api_irtcengine_enableextension__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。

## registerExtension

注册一个扩展。

<a id="api_irtcengine_registerextension__prototype"></a>

```text
public abstract int registerExtension(String provider, String extension, Constants.MediaSourceType sourceType);
```

<a id="api_irtcengine_registerextension__detailed_desc"></a>

- 对于 SDK 外部的扩展（例如来自云市场和 SDK 扩展），你需要在调用 [registerExtension](/zh-CN/api-reference/rtc/android/extension#api_irtcengine_registerextension) 之前先通过 [addExtension](/zh-CN/api-reference/rtc/android/extension#api_irtcengine_addextension) 加载它们。
- 对于 SDK 内部的扩展（即包含在完整 SDK 包中的扩展），在初始化 [RtcEngine](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_irtcengine) 后会自动加载并注册。

:::note
注：

- 如果你想注册多个扩展，需要多次调用此方法。
- SDK 中不同扩展的数据处理顺序由注册顺序决定。即先注册的扩展会先处理数据。
:::

<a id="api_irtcengine_registerextension__timing"></a>

### 调用时机

声网建议你在初始化 [RtcEngine](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_irtcengine) 后、加入频道前调用此方法。

- 对于视频扩展（如美颜特效扩展），你需要在调用 [enableVideo](/zh-CN/api-reference/rtc/android/video/video-basic#api_irtcengine_enablevideo) 或 [enableLocalVideo](/zh-CN/api-reference/rtc/android/video/video-basic#api_irtcengine_enablelocalvideo) 启用视频模块后再调用此方法。
- 在调用此方法之前，你需要先调用 [addExtension](/zh-CN/api-reference/rtc/android/extension#api_irtcengine_addextension) 加载扩展。

<a id="api_irtcengine_registerextension__parameters"></a>

### 参数

### provider

扩展提供方的名称。

### extension

扩展的名称。

### sourceType

扩展的数据源类型，详见 [MediaSourceType](/zh-CN/api-reference/rtc/android/enum-mediasourcetype)。

<a id="api_irtcengine_registerextension__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。

  - -3：扩展库未加载。建议你检查动态库的存储位置或名称。
