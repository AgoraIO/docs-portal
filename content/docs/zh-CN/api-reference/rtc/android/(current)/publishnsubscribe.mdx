## enableDualStreamMode [1/2]

在发送端启用或禁用双流模式。

<a id="api_irtcengine_enabledualstreammode__prototype"></a>

```text
public abstract int enableDualStreamMode(boolean enabled)
```

<a id="api_irtcengine_enabledualstreammode__detailed_desc"></a>

### 废弃

自 v4.2.0 版本废弃，请改用 `setDualStreamMode`。

启用双流模式后，你可以调用 `setRemoteVideoStreamType` 方法，在订阅端选择接收视频大流或视频小流。
双流由以下两种视频流组成：

- 视频大流：高码率、高分辨率。
- 视频小流：低码率、低分辨率。

:::note
注：

- 该方法适用于发送端的所有类型视频流，包括但不限于摄像头采集的视频流、屏幕共享流和自定义采集的视频流。
- 如果你需要在多频道场景中启用双流模式，可以调用 [enableDualStreamModeEx](/zh-CN/api-reference/rtc/android/publishnsubscribe#api_irtcengineex_enabledualstreammodeex) 方法。
- 你可以在加入频道前或加入频道后调用该方法。
:::

### 参数

<ParameterList>
<a id="enabled"></a>
<Parameter name="enabled">

是否启用双流模式：

- true：启用双流模式。
- false：（默认）禁用双流模式。

</Parameter>

停止或恢复订阅所有远端用户的音频流。

<a id="api_irtcengine_muteallremoteaudiostreams__prototype"></a>

```text
public abstract int muteAllRemoteAudioStreams(boolean muted);
```

<a id="api_irtcengine_muteallremoteaudiostreams__detailed_desc"></a>

请在加入频道后调用该方法。本地用户将停止或恢复订阅所有远端用户的音频流，包括之后加入频道的用户。

    - 调用 [muteRemoteVideoStream](/zh-CN/api-reference/rtc/android/publishnsubscribe#api_irtcengine_muteremotevideostream) 或 [muteAllRemoteVideoStreams](/zh-CN/api-reference/rtc/android/publishnsubscribe#api_irtcengine_muteallremotevideostreams) 并将 `muted` 设置为 true，表示停止接收远端视频流。
- `SUB_STATE_SUBSCRIBING` (2)：正在订阅中。
- `SUB_STATE_SUBSCRIBED` (3)：已成功接收远端流。

</Parameter>
<a id="newstate-2"></a>
<Parameter name="newState">

当前的订阅状态：

- `SUB_STATE_IDLE` (0)：加入频道后的初始订阅状态。
- `SUB_STATE_NO_SUBSCRIBED` (1)：订阅远端流失败。可能原因包括：

  - 远端用户：

    - 调用 `muteLocalVideoStream(true)` 停止发送本地视频流。
    - 调用 [disableVideo](/zh-CN/api-reference/rtc/android/video/video-basic#api_irtcengine_disablevideo) 禁用本地视频模块。
    - 调用 `enableLocalVideo(false)` 禁用本地视频采集。
    - 远端用户的角色为观众。
  - 本地用户：

    - 在调用 `joinChannel` 或 [updateChannelMediaOptions](/zh-CN/api-reference/rtc/android/channel#api_irtcengine_updatechannelmediaoptions) 时将 [ChannelMediaOptions](/zh-CN/api-reference/rtc/android/class-channelmediaoptions) 中的 `autoSubscribeVideo` 设置为 false，表示不自动订阅任何视频流。
    - 调用 [muteRemoteVideoStream](/zh-CN/api-reference/rtc/android/publishnsubscribe#api_irtcengine_muteremotevideostream) 或 [muteAllRemoteVideoStreams](/zh-CN/api-reference/rtc/android/publishnsubscribe#api_irtcengine_muteallremotevideostreams) 并将 `muted` 设置为 true，表示停止接收远端视频流。
- `SUB_STATE_SUBSCRIBING` (2)：正在订阅中。
- `SUB_STATE_SUBSCRIBED` (3)：已成功接收远端流。

</Parameter>
