自 v3.4.200 版本新增。

<a id="class_clientroleoptions__parameters"></a>

## 属性

### `audienceLatencyLevel`

互动直播中观众的延迟等级：

- `AUDIENCE_LATENCY_LEVEL_LOW_LATENCY` （1）：低延迟。
- `AUDIENCE_LATENCY_LEVEL_ULTRA_LOW_LATENCY` （2）：超低延迟（默认值）。
