## <span id="toc_audio_raw"></span>getEarMonitoringAudioParams [#api_iaudioframeobserver_getearmonitoringaudioparams]

onEarMonitoringAudioFrame 回调的音频格式设置方法。

<a id="api_iaudioframeobserver_getearmonitoringaudioparams__prototype"></a>

```java
@CalledByNative public abstract AudioParams getEarMonitoringAudioParams();
```

<a id="api_iaudioframeobserver_getearmonitoringaudioparams__detailed_desc"></a>

调用 [registerAudioFrameObserver](/zh-CN/api-reference/rtc/android/audio/audio-raw#api_irtcengine_registeraudioframeobserver) 注册音频帧观察者时，需要实现该回调。SDK 会触发该回调，你可以在该回调的返回值中设置音频格式。

:::info[注]
SDK 会根据你在返回值中设置的采样间隔计算公式触发 [onEarMonitoringAudioFrame](/zh-CN/api-reference/rtc/android/audio/audio-raw#callback_iaudioframeobserver_onearmonitoringaudioframe) 回调。采样间隔（秒） = `samplePerCall` /（`sampleRate` × `channel` ）。请确保采样间隔 ≥ 0.01 秒。
:::

### 返回值 [#api_iaudioframeobserver_getearmonitoringaudioparams__return_values]

耳返音频数据格式，详见 [AudioParams](/zh-CN/api-reference/rtc/android/class-audioparams)。

- [IAudioFrameObserver](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_iaudioframeobserver)

## getObservedAudioFramePosition [#api_iaudioframeobserver_getobservedaudioframeposition]

设置音频数据观察位置。

<a id="api_iaudioframeobserver_getobservedaudioframeposition__prototype"></a>

```java
@CalledByNative public abstract int getObservedAudioFramePosition();
```

<a id="api_iaudioframeobserver_getobservedaudioframeposition__detailed_desc"></a>

成功注册音频数据观察器后，SDK 会在每个特定的音频帧处理节点调用该回调，以判断是否触发以下回调：

- [onRecordAudioFrame](/zh-CN/api-reference/rtc/android/audio/audio-raw#callback_iaudioframeobserver_onrecordaudioframe)
- [onPlaybackAudioFrame](/zh-CN/api-reference/rtc/android/audio/audio-raw#callback_iaudioframeobserver_onplaybackaudioframe)
- [onPlaybackAudioFrameBeforeMixing](/zh-CN/api-reference/rtc/android/audio/audio-raw#callback_iaudioframeobserver_onplaybackaudioframebeforemixing)
- [onMixedAudioFrame](/zh-CN/api-reference/rtc/android/audio/audio-raw#callback_iaudioframeobserver_onmixedaudioframe)
- [onEarMonitoringAudioFrame](/zh-CN/api-reference/rtc/android/audio/audio-raw#callback_iaudioframeobserver_onearmonitoringaudioframe)

你可以根据场景需求，通过修改 [getObservedAudioFramePosition](/zh-CN/api-reference/rtc/android/audio/audio-raw#api_iaudioframeobserver_getobservedaudioframeposition) 的返回值设置需要观察的一个或多个位置。 当需要观察多个位置时，需使用 |（或运算符）。为节省系统资源，建议减少观察的帧位置数量。

### 返回值 [#api_iaudioframeobserver_getobservedaudioframeposition__return_values]

返回一个位掩码，用于设置观察位置，具体取值如下：

- `POSITION_PLAYBACK` （0x0001）：可观察所有远端用户混音后的播放音频，对应 [onPlaybackAudioFrame](/zh-CN/api-reference/rtc/android/audio/audio-raw#callback_iaudioframeobserver_onplaybackaudioframe) 回调。
- `POSITION_RECORD` （0x0002）：可观察本地用户采集的音频，对应 [onRecordAudioFrame](/zh-CN/api-reference/rtc/android/audio/audio-raw#callback_iaudioframeobserver_onrecordaudioframe) 回调。
- `POSITION_MIXED` （0x0004）：可观察本地用户与所有远端用户混音后的播放音频，对应 [onMixedAudioFrame](/zh-CN/api-reference/rtc/android/audio/audio-raw#callback_iaudioframeobserver_onmixedaudioframe) 回调。
- `POSITION_BEFORE_MIXING` （0x0008）：可观察单个远端用户混音前的音频，对应 [onPlaybackAudioFrameBeforeMixing](/zh-CN/api-reference/rtc/android/audio/audio-raw#callback_iaudioframeobserver_onplaybackaudioframebeforemixing) 回调。
- `POSITION_EAR_MONITORING` （0x0010）：可观察本地用户的耳返音频，对应 [onEarMonitoringAudioFrame](/zh-CN/api-reference/rtc/android/audio/audio-raw#callback_iaudioframeobserver_onearmonitoringaudioframe) 回调。

- [IAudioFrameObserver](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_iaudioframeobserver)

### 相关回调 [#api_irtcengine_registeraudioframeobserver__related]

## setEarMonitoringAudioFrameParameters [#api_irtcengine_setearmonitoringaudioframeparameters]

设置耳返音频数据格式。

<a id="api_irtcengine_setearmonitoringaudioframeparameters__prototype"></a>

```java
public abstract int setEarMonitoringAudioFrameParameters(int sampleRate, int channel, int mode, int samplesPerCall);
```

<a id="api_irtcengine_setearmonitoringaudioframeparameters__detailed_desc"></a>

该方法用于设置 [onEarMonitoringAudioFrame](/zh-CN/api-reference/rtc/android/audio/audio-raw#callback_iaudioframeobserver_onearmonitoringaudioframe) 回调中报告的耳返音频数据格式。

:::info[注]
- 在调用该方法前，你需要先调用 `enableInEarMonitoring` 方法，并将 `includeAudioFilters` 设置为 `EAR_MONITORING_FILTER_BUILT_IN_AUDIO_FILTERS` 或 `EAR_MONITORING_FILTER_NOISE_SUPPRESSION`。
- SDK 会根据该方法中设置的 `samplesPerCall`、 `sampleRate` 和 `channel` 参数计算采样间隔。采样间隔（秒）= `samplesPerCall` /（`sampleRate` × `channel` ）。请确保采样间隔 ≥ 0.01 秒。SDK 会根据采样间隔触发 [onEarMonitoringAudioFrame](/zh-CN/api-reference/rtc/android/audio/audio-raw#callback_iaudioframeobserver_onearmonitoringaudioframe) 回调。
:::

### 参数 [#api_irtcengine_setearmonitoringaudioframeparameters__parameters]

#### `sampleRate`

在 [onEarMonitoringAudioFrame](/zh-CN/api-reference/rtc/android/audio/audio-raw#callback_iaudioframeobserver_onearmonitoringaudioframe) 回调中报告的音频采样率。可设置为 8000、16000、32000、44100 或 48000 Hz。

#### `channel`

在 [onEarMonitoringAudioFrame](/zh-CN/api-reference/rtc/android/audio/audio-raw#callback_iaudioframeobserver_onearmonitoringaudioframe) 回调中报告的音频通道数：

- 1：单声道。
- 2：立体声。

#### `mode`

音频帧的使用模式：

- `RAW_AUDIO_FRAME_OP_MODE_READ_ONLY` （0）：（默认）只读模式。例如，用户通过声网 SDK 获取数据后推送 RTMP 或 RTMPS 流。
- `RAW_AUDIO_FRAME_OP_MODE_READ_WRITE` （2）：读写模式。用户从 [AudioFrame](/zh-CN/api-reference/rtc/android/class-audioframe) 中读取数据，修改后再播放。例如，用户有自己的音效处理模块并进行语音预处理，如变声。

#### `samplesPerCall`

在 [onEarMonitoringAudioFrame](/zh-CN/api-reference/rtc/android/audio/audio-raw#callback_iaudioframeobserver_onearmonitoringaudioframe) 回调中报告的每次调用采样数，例如媒体推流时为 1024。

### 返回值 [#api_irtcengine_setearmonitoringaudioframeparameters__return_values]

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/android/error-code)了解详情和解决建议。

- [RtcEngine](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_irtcengine)

### 参数 [#api_irtcengine_setrecordingaudioframeparameters__parameters]

#### `sampleRate`

回调中返回的采样率，可设置为 8000、16000、32000、44100 或 48000 Hz。

#### `channel`

音频声道数，可设置为：

- 1：单声道。
- 2：立体声。

#### `mode`

音频帧的使用模式：

- 0：只读模式。例如，用户通过声网 SDK 获取数据后推送 RTMP 或 RTMPS 流。

## onEarMonitoringAudioFrame [#callback_iaudioframeobserver_onearmonitoringaudioframe]

耳返音频帧回调。

<a id="callback_iaudioframeobserver_onearmonitoringaudioframe__prototype"></a>

```java
public abstract boolean onEarMonitoringAudioFrame(int type, int samplesPerChannel, int bytesPerSample, int channels, int samplesPerSec, ByteBuffer buffer, long renderTimeMs, int avsync_type);
```

<a id="callback_iaudioframeobserver_onearmonitoringaudioframe__detailed_desc"></a>

该回调用于获取耳返音频数据。为了确保获取的数据符合预期，声网建议你通过以下任一方式设置音频数据格式：

- 方法一：调用 [setEarMonitoringAudioFrameParameters](/zh-CN/api-reference/rtc/android/audio/audio-raw#api_irtcengine_setearmonitoringaudioframeparameters) 设置音频数据格式，并调用 [registerAudioFrameObserver](/zh-CN/api-reference/rtc/android/audio/audio-raw#api_irtcengine_registeraudioframeobserver) 注册音频帧观察者对象后，SDK 会根据设置的参数计算采样间隔，并按该间隔触发 [onEarMonitoringAudioFrame](/zh-CN/api-reference/rtc/android/audio/audio-raw#callback_iaudioframeobserver_onearmonitoringaudioframe) 回调。
- 方法二：调用 [registerAudioFrameObserver](/zh-CN/api-reference/rtc/android/audio/audio-raw#api_irtcengine_registeraudioframeobserver) 注册音频帧观察者对象后，在 [getObservedAudioFramePosition](/zh-CN/api-reference/rtc/android/audio/audio-raw#api_iaudioframeobserver_getobservedaudioframeposition) 的返回值中设置音频数据格式。然后 SDK 会根据 [getEarMonitoringAudioParams](/zh-CN/api-reference/rtc/android/audio/audio-raw#api_iaudioframeobserver_getearmonitoringaudioparams) 的返回值计算采样间隔，并按该间隔触发 [onEarMonitoringAudioFrame](/zh-CN/api-reference/rtc/android/audio/audio-raw#callback_iaudioframeobserver_onearmonitoringaudioframe) 回调。

:::info[注]
方法一的优先级高于方法二。如果使用方法一设置音频数据格式，则方法二的设置无效。
:::

### 参数 [#callback_iaudioframeobserver_onearmonitoringaudioframe__parameters]

#### `type`

音频帧类型。

#### `samplesPerChannel`

每个声道中的采样点数。

#### `bytesPerSample`

每个音频采样点的字节数。例如，每个 PCM 音频采样点通常占用 16 位（2 字节）。

#### `channels`

声道数：

- 1：单声道。
- 2：立体声。若为立体声，数据为交错格式。

#### `samplesPerSec`

录音采样率（Hz）。

#### `buffer`

音频缓冲区。缓冲区大小 = `samplesPerChannel` × `channels` × `bytesPerSample`。详见 `ByteBuffer`。

#### `renderTimeMs`

外部音频帧的时间戳（毫秒）。你可以使用该参数在视频或音频相关场景中（包括使用自定义视频源的场景）实现音视频帧同步。

#### `avsync_type`

预留参数。

### 返回值 [#callback_iaudioframeobserver_onearmonitoringaudioframe__return_values]

- true：回调处理成功。
- false：回调处理失败。

- [IAudioFrameObserver](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_iaudioframeobserver)
