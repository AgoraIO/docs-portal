## <span id="toc_audio_capture"></span>adjustRecordingSignalVolume [#api_irtcengine_adjustrecordingsignalvolume]

调节采集音频信号的音量。

<a id="api_irtcengine_adjustrecordingsignalvolume__prototype"></a>

```java
public abstract int adjustRecordingSignalVolume(int volume);
```

<a id="api_irtcengine_adjustrecordingsignalvolume__detailed_desc"></a>

如果你只需要静音音频信号，声网建议使用 [muteRecordingSignal](/zh-CN/api-reference/rtc/android/audio/audio-capture#api_irtcengine_muterecordingsignal) 方法。

### 调用时机 [#api_irtcengine_adjustrecordingsignalvolume__timing]

该方法可以在加入频道前或加入频道后调用。

### 参数 [#api_irtcengine_adjustrecordingsignalvolume__parameters]

#### `volume`

用户的音量，取值范围为 [0,400]：

- 0：静音。
- 100：（默认）原始音量。
- 400：原始音量的四倍（将音频信号放大四倍）。

### 返回值 [#api_irtcengine_adjustrecordingsignalvolume__return_values]

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/android/error-code)了解详情和解决建议。

- [RtcEngine](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_irtcengine)

## enableInEarMonitoring [2/2] [#api_irtcengine_enableinearmonitoring2]

启用或关闭耳返监听功能。

<a id="api_irtcengine_enableinearmonitoring2__prototype"></a>

```java
public abstract int enableInEarMonitoring(boolean enabled, int includeAudioFilters);
```

<a id="api_irtcengine_enableinearmonitoring2__detailed_desc"></a>

:::info[注]
你必须使用有线或蓝牙耳机才能听到耳返监听效果。
:::

### 调用时机 [#api_irtcengine_enableinearmonitoring2__timing]

该方法可以在加入频道前或加入频道后调用。

### 参数 [#api_irtcengine_enableinearmonitoring2__parameters]

#### `enabled`

是否启用耳返监听功能。

- true：启用耳返监听。
- false：（默认）关闭耳返监听。

#### `includeAudioFilters`

:::info[注]
该参数仅在 `enabled` 为 true 时生效。
:::

耳返监听的音频滤镜类型：

- `EAR_MONITORING_FILTER_NONE (1 <<0)`：（1）耳返监听中不添加音频滤镜。
- `EAR_MONITORING_FILTER_BUILT_IN_AUDIO_FILTERS (1 <<1)`：（2）在耳返监听中添加人声特效音频滤镜。如果你实现了美声、音效等功能，用户可以听到添加这些效果后的声音。该枚举值支持使用按位或运算符（|）组合使用。
- `EAR_MONITORING_FILTER_NOISE_SUPPRESSION (1 <<2)`：（4）在耳返监听中添加降噪音频滤镜。该枚举值支持使用按位或运算符（|）组合使用。
- `EAR_MONITORING_FILTER_REUSE_POST_PROCESSING_FILTER (1 <<15)`：复用发送端已处理的音频滤镜用于耳返监听。该枚举值可降低 CPU 使用率，但会增加耳返监听延迟，适用于对延迟不敏感但要求低 CPU 消耗的场景。该枚举值仅支持单独使用，选中后其他音频滤镜配置将自动失效。

### 返回值 [#api_irtcengine_enableinearmonitoring2__return_values]

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/android/error-code)了解详情和解决建议。

  - -8：请确保当前音频路由为蓝牙或有线耳机。

- [RtcEngine](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_irtcengine)

## enableLocalAudio [#api_irtcengine_enablelocalaudio]

启用或关闭本地音频采集功能。

<a id="api_irtcengine_enablelocalaudio__prototype"></a>

```java
public abstract int enableLocalAudio(boolean enabled);
```

<a id="api_irtcengine_enablelocalaudio__detailed_desc"></a>

[enableLocalAudio](/zh-CN/api-reference/rtc/android/audio/audio-capture#api_irtcengine_enablelocalaudio) 用于控制本地音频采集和处理的启用状态。调用该方法关闭或重新启用本地音频采集时，本地用户可能会听到远端音频播放中断。 该方法与 [muteLocalAudioStream](/zh-CN/api-reference/rtc/android/publishnsubscribe#api_irtcengine_mutelocalaudiostream) 的区别如下：

- [enableLocalAudio](/zh-CN/api-reference/rtc/android/audio/audio-capture#api_irtcengine_enablelocalaudio)：控制本地音频采集和处理的启用状态。
- [muteLocalAudioStream](/zh-CN/api-reference/rtc/android/publishnsubscribe#api_irtcengine_mutelocalaudiostream)：仅控制是否发送本地音频流，不影响音频采集状态。

### 适用场景 [#api_irtcengine_enablelocalaudio__scenario]

`enableLocalAudio(false)` 适用于只接收远端音频流而不发送本地采集音频的场景。该方法不会影响接收远端音频流。

### 调用时机 [#api_irtcengine_enablelocalaudio__timing]

你可以在加入频道前或加入频道后调用该方法。在加入频道前调用该方法仅设置设备状态，并在加入频道后立即生效。

### 相关回调 [#api_irtcengine_enablelocalaudio__related]

一旦本地音频功能被关闭或重新启用，SDK 会触发 [onLocalAudioStateChanged](/zh-CN/api-reference/rtc/android/audio/audio-basic#callback_irtcengineeventhandler_onlocalaudiostatechanged) 回调，报告 `LOCAL_AUDIO_STREAM_STATE_STOPPED` （0）或 `LOCAL_AUDIO_STREAM_STATE_RECORDING` （1）。

### 参数 [#api_irtcengine_enablelocalaudio__parameters]

#### `enabled`

是否启用本地音频功能：

- true：（默认）重新启用本地音频功能，即启动本地音频采集设备（如麦克风）。
- false：关闭本地音频功能，即停止本地音频采集。

### 返回值 [#api_irtcengine_enablelocalaudio__return_values]

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/android/error-code)了解详情和解决建议。

- [RtcEngine](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_irtcengine)

## muteRecordingSignal [#api_irtcengine_muterecordingsignal]

设置是否静音录制信号。

<a id="api_irtcengine_muterecordingsignal__prototype"></a>

```java
public abstract int muteRecordingSignal(boolean muted);
```

<a id="api_irtcengine_muterecordingsignal__detailed_desc"></a>

如果你已经调用了 [adjustRecordingSignalVolume](/zh-CN/api-reference/rtc/android/audio/audio-capture#api_irtcengine_adjustrecordingsignalvolume) 方法调整录制信号的音量，当你调用该方法并将参数设置为 true 时，SDK 会执行以下操作：

- 记录当前已调整的音量。
- 静音录制信号。

当你再次调用该方法并将参数设置为 false 时，录制信号的音量会恢复为静音前记录的音量。

### 调用时机 [#api_irtcengine_muterecordingsignal__timing]

该方法可以在加入频道前或后调用。

### 参数 [#api_irtcengine_muterecordingsignal__parameters]

#### `muted`

是否静音录制信号：

- true：静音录制信号。
- false：（默认）不静音录制信号。

### 返回值 [#api_irtcengine_muterecordingsignal__return_values]

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/android/error-code)了解详情和解决建议。

- [RtcEngine](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_irtcengine)

## setInEarMonitoringVolume [#api_irtcengine_setinearmonitoringvolume]

public abstract int setInEarMonitoringVolume(int volume);

### <span id="api_irtcengine_setinearmonitoringvolume__detailed_desc"></span>调用时机 [#api_irtcengine_setinearmonitoringvolume__timing]

  - -2：参数设置不合法，例如耳返音量超出有效范围（小于 0 或大于 400）。
