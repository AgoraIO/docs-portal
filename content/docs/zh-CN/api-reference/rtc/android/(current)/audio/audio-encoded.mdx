## registerAudioEncodedFrameObserver

注册编码音频数据的观察器。

<a id="api_irtcengine_registeraudioencodedframeobserver__prototype"></a>

```text
public abstract int registerAudioEncodedFrameObserver(AudioEncodedFrameObserverConfig config, IAudioEncodedFrameObserver observer);
```

<a id="api_irtcengine_registeraudioencodedframeobserver__detailed_desc"></a>

:::note
注： 调用该方法需在加入频道后进行。你可以调用此方法或 `startAudioRecording` 来设置音频文件的录制类型和质量，但不建议同时使用这两个方法。只有后调用的方法会生效。
:::

<a id="api_irtcengine_registeraudioencodedframeobserver__parameters"></a>

### 参数

### config

编码音频的观察器配置。详见 [AudioEncodedFrameObserverConfig](/zh-CN/api-reference/rtc/android/class-audioencodedframeobserverconfig)。

### observer

编码音频数据的观察器。详见 [IAudioEncodedFrameObserver](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_iaudioencodedframeobserver)。

<a id="api_irtcengine_registeraudioencodedframeobserver__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。

## onMixedAudioEncodedFrame

本地及所有远端用户的混音编码音频数据回调。

<a id="callback_iaudioencodedframeobserver_onmixedaudioencodedframe__prototype"></a>

```text
public abstract void onMixedAudioEncodedFrame(ByteBuffer buffer, int samplesPerChannel, int channels, int samplesPerSec, int codecType);
```

<a id="callback_iaudioencodedframeobserver_onmixedaudioencodedframe__detailed_desc"></a>

调用 [registerAudioEncodedFrameObserver](/zh-CN/api-reference/rtc/android/audio/audio-encoded#api_irtcengine_registeraudioencodedframeobserver) 并将音频配置设置为 `AUDIO_ENCODED_FRAME_OBSERVER_POSITION_MIXED` 后，可以通过该回调获取混音编码音频数据。

<a id="callback_iaudioencodedframeobserver_onmixedaudioencodedframe__parameters"></a>

### 参数

### buffer

音频缓冲区。

### samplesPerChannel

每个声道中的采样数。

### channels

声道数：

- 1：单声道。
- 2：立体声。若为立体声，数据为交错排列。

### samplesPerSec

录制采样率（Hz）。

### codecType

音频编码类型：

- 1：OPUS。
- 8：LC-AAC。
- 9：HE-AAC。
- 11：HE-AAC v2。

## onPlaybackAudioEncodedFrame

<a id="callback_iaudioencodedframeobserver_onplaybackaudioencodedframe__prototype"></a>

```text
public abstract void onPlaybackAudioEncodedFrame(ByteBuffer buffer, int samplesPerChannel, int channels, int samplesPerSec, int codecType);
```

<a id="callback_iaudioencodedframeobserver_onplaybackaudioencodedframe__detailed_desc"></a>

调用 [registerAudioEncodedFrameObserver](/zh-CN/api-reference/rtc/android/audio/audio-encoded#api_irtcengine_registeraudioencodedframeobserver) 并将编码音频设置为 `AUDIO_ENCODED_FRAME_OBSERVER_POSITION_PLAYBACK` 后，可以通过该回调获取所有远端用户的编码音频数据。

<a id="callback_iaudioencodedframeobserver_onplaybackaudioencodedframe__timing"></a>

### 触发时机

该回调在获取远端用户编码音频数据时被触发。

### buffer

音频缓冲区。

### samplesPerChannel

每个声道中的采样数。

### channels

声道数：

- 1：单声道。
- 2：立体声。若为立体声，数据为交错排列。

### samplesPerSec

录音采样率（Hz）。

### codecType

音频编码类型：

- `1`：OPUS。
- `8`：LC-AAC。
- `9`：HE-AAC。
- `11`：HE-AAC v2。

- 2：立体声。若为立体声，数据为交错排列。

### samplesPerSec

录制采样率（Hz）。

### codecType

音频编码类型：

- `1`：OPUS。
- `8`：LC-AAC。
- `9`：HE-AAC。
