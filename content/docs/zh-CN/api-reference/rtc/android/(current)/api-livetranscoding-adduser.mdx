```java
public int addUser(TranscodingUser user)
```

## <span id="api_livetranscoding_adduser__detailed_desc"></span>参数 [#api_livetranscoding_adduser__parameters]

### `user`

要添加的转码用户。详见 [TranscodingUser](/zh-CN/api-reference/rtc/android/class-transcodinguser)。

## 返回值 [#api_livetranscoding_adduser__return_values]

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/android/error-code)了解详情和解决建议。
