<a id="class_watermarkoptions__parameters"></a>

## 属性

<ParameterList>
<a id="visibleinpreview"></a>
<Parameter name="visibleInPreview">

水印是否在本地预览视图中可见：

- true：（默认）水印在本地预览视图中可见。
- false：水印在本地预览视图中不可见。

</Parameter>
<a id="positioninlandscapemode"></a>
<Parameter name="positionInLandscapeMode">

横屏模式下显示水印图像的区域，详见 [Rectangle](/zh-CN/api-reference/rtc/android/class-rectangle)。

</Parameter>
<a id="positioninportraitmode"></a>
<Parameter name="positionInPortraitMode">

竖屏模式下显示水印图像的区域，详见 [Rectangle](/zh-CN/api-reference/rtc/android/class-rectangle)。

</Parameter>
<a id="zorder"></a>
<Parameter name="zOrder">

水印图像的图层顺序，默认值为 0。

</Parameter>
</ParameterList>
