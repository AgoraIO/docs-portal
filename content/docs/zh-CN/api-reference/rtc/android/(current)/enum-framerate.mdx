## 枚举值 [#enum_framerate__parameters]

### `FRAME_RATE_FPS_1`

（1）：1 帧/秒。

### `FRAME_RATE_FPS_7`

（7）：7 帧/秒。

### `FRAME_RATE_FPS_10`

（10）：10 帧/秒。

### `FRAME_RATE_FPS_15`

（15）：15 帧/秒。

### `FRAME_RATE_FPS_24`

（24）：24 帧/秒。

### `FRAME_RATE_FPS_30`

（30）：30 帧/秒。

### `FRAME_RATE_FPS_60`

（60）：不支持。
