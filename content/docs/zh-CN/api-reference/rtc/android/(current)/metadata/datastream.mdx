## <span id="toc_datastream"></span>createDataStream [1/2] [#api_irtcengine_createdatastream1]

创建一个数据流，用于提升数据传输的可靠性和顺序性。

<a id="api_irtcengine_createdatastream1__prototype"></a>

```java
public abstract int createDataStream(boolean reliable, boolean ordered);
```

<a id="api_irtcengine_createdatastream1__detailed_desc"></a>

:::info[注]
每个用户在 [RtcEngine](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_irtcengine) 的生命周期内最多可创建五个数据流。离开频道时，数据流会被销毁，如需继续使用需重新创建。如果你需要一个更全面的低延迟、高并发、可扩展的实时消息和状态同步解决方案，建议使用实时消息。
:::

### 调用时机 [#api_irtcengine_createdatastream1__timing]

你可以在加入频道前或后调用此方法。

### 相关回调 [#api_irtcengine_createdatastream1__related]

将 `reliable` 设置为 true 后，如果接收端在五秒内未收到数据，SDK 会触发 [onStreamMessageError](/zh-CN/api-reference/rtc/android/metadata/datastream#callback_irtcengineeventhandler_onstreammessageerror) 回调并返回错误码。

### 参数 [#api_irtcengine_createdatastream1__parameters]

#### `reliable`

:::info[注]
请确保 `reliable` 和 `ordered` 同时设置为 true 或同时设置为 false。
:::

是否保证接收端在五秒内收到数据流：

- true：接收端会在五秒内收到发送端的数据。如果未收到，SDK 会触发 [onStreamMessageError](/zh-CN/api-reference/rtc/android/metadata/datastream#callback_irtcengineeventhandler_onstreammessageerror) 回调并返回错误码。
- false：不保证接收端在五秒内收到数据，延迟或丢失不会触发错误回调。

#### `ordered`

是否按发送顺序接收数据流：

- true：接收端按发送顺序接收数据。
- false：接收端不按发送顺序接收数据。

### 返回值 [#api_irtcengine_createdatastream1__return_values]

- 方法调用成功，返回创建的数据流 ID。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/android/error-code)了解详情和解决建议。

- [RtcEngine](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_irtcengine)

## sendStreamMessage [#api_irtcengine_sendstreammessage]

发送数据流消息。

<a id="api_irtcengine_sendstreammessage__prototype"></a>

```java
public abstract int sendStreamMessage(int streamId, byte[] message);
```

<a id="api_irtcengine_sendstreammessage__detailed_desc"></a>

调用 `createDataStream` 后，可以使用该方法向频道内的所有用户发送数据流消息。SDK 对该方法有限制：

- 每个频道内的客户端实例最多可同时拥有 5 个数据通道，所有数据通道共享的总包比特率上限为 30 KB/s。
- 每个数据通道每秒最多可发送 60 个数据包，每个数据包最大为 1 KB。

:::info[注]
- 如果你需要更全面的低延迟、高并发、可扩展的实时消息和状态同步解决方案，建议使用实时消息。
- 必须在调用 `createDataStream` 并加入频道后调用该方法。
- 该方法仅适用于主播角色。
:::

### 相关回调 [#api_irtcengine_sendstreammessage__related]

调用成功后会触发远端客户端的 [onStreamMessage](/zh-CN/api-reference/rtc/android/metadata/datastream#callback_irtcengineeventhandler_onstreammessage) 回调，远端用户可通过该回调获取数据流消息。调用失败则会触发远端客户端的 [onStreamMessageError](/zh-CN/api-reference/rtc/android/metadata/datastream#callback_irtcengineeventhandler_onstreammessageerror) 回调。

### 参数 [#api_irtcengine_sendstreammessage__parameters]

#### `streamId`

数据流 ID，通过调用 `createDataStream` 获取。

#### `message`

要发送的消息内容。

### 返回值 [#api_irtcengine_sendstreammessage__return_values]

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/android/error-code)了解详情和解决建议。

- [RtcEngine](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_irtcengine)

<a id="callback_irtcengineeventhandler_onstreammessage__detailed_desc"></a>

#### `streamId`

接收到的消息所属的数据流 ID。
