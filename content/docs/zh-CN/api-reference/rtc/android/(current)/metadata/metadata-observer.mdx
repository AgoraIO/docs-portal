## <span id="toc_metadata_observer"></span>getMaxMetadataSize [#api_imetadataobserver_getmaxmetadatasize]

当 SDK 请求元数据最大大小时触发的回调。

<a id="api_imetadataobserver_getmaxmetadatasize__prototype"></a>

```java
public abstract int getMaxMetadataSize()
```

<a id="api_imetadataobserver_getmaxmetadatasize__detailed_desc"></a>

调用 [registerMediaMetadataObserver](/zh-CN/api-reference/rtc/android/metadata/metadata-observer#api_irtcengine_registermediametadataobserver) 成功注册后，SDK 在每发送一帧视频时会触发该回调。你需要在该回调的返回值中指定元数据的最大大小。

### 返回值 [#api_imetadataobserver_getmaxmetadatasize__return_values]

方法调用成功，返回你希望使用的元数据 `buffer` 的最大大小，单位为字节。最大值为 1024 字节。请确保设置返回值。

- [IMetadataObserver](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_imetadataobserver)

## registerMediaMetadataObserver [#api_irtcengine_registermediametadataobserver]

注册元数据观察器。

<a id="api_irtcengine_registermediametadataobserver__prototype"></a>

```java
public abstract int registerMediaMetadataObserver(IMetadataObserver observer, int type);
```

<a id="api_irtcengine_registermediametadataobserver__detailed_desc"></a>

你需要实现 [IMetadataObserver](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_imetadataobserver) 类，并在该方法中指定元数据类型。该方法支持你在视频流中添加同步元数据，以实现更丰富的互动直播场景，例如发送购物链接、数字优惠券和在线问答。成功调用该方法后，SDK 会触发 [getMaxMetadataSize](/zh-CN/api-reference/rtc/android/metadata/metadata-observer#api_imetadataobserver_getmaxmetadatasize) 回调。

:::info[注]
请在调用 `joinChannel` 之前调用此方法。
:::

### 参数 [#api_irtcengine_registermediametadataobserver__parameters]

#### `observer`

元数据观察器，详见 [IMetadataObserver](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_imetadataobserver)。

#### `type`

元数据类型。当前 SDK 仅支持以下类型：

- `VIDEO_METADATA`：视频元数据。

### 返回值 [#api_irtcengine_registermediametadataobserver__return_values]

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/android/error-code)了解详情和解决建议。

- [RtcEngine](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_irtcengine)

## unregisterMediaMetadataObserver [#api_irtcengine_unregistermediametadataobserver]

取消注册指定的元数据观察者。

<a id="api_irtcengine_unregistermediametadataobserver__prototype"></a>

```java
public abstract int unregisterMediaMetadataObserver(IMetadataObserver observer, int type);
```

### <span id="api_irtcengine_unregistermediametadataobserver__detailed_desc"></span>参数 [#api_irtcengine_unregistermediametadataobserver__parameters]

#### `observer`

元数据观察者。详见 [IMetadataObserver](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_imetadataobserver)。

#### `type`

元数据类型。当前 SDK 仅支持以下类型：

- `VIDEO_METADATA`：视频元数据。

### 返回值 [#api_irtcengine_unregistermediametadataobserver__return_values]

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/android/error-code)了解详情和解决建议。

- [RtcEngine](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_irtcengine)

## onReadyToSendMetadata [#callback_imetadataobserver_onreadytosendmetadata]

SDK 准备好发送元数据时触发的回调。

<a id="callback_imetadataobserver_onreadytosendmetadata__prototype"></a>

```java
public abstract byte[] onReadyToSendMetadata(long timeStampMs, int sourceType)
```

<a id="callback_imetadataobserver_onreadytosendmetadata__detailed_desc"></a>

:::info[注]
请确保元数据的大小不超过 [getMaxMetadataSize](/zh-CN/api-reference/rtc/android/metadata/metadata-observer#api_imetadataobserver_getmaxmetadatasize) 回调中设置的值。
:::

### 触发时机 [#callback_imetadataobserver_onreadytosendmetadata__timing]

该回调在 SDK 准备好发送元数据时被触发。

### 参数 [#callback_imetadataobserver_onreadytosendmetadata__parameters]

#### `timeStampMs`

时间戳。

#### `sourceType`

视频数据类型。详见 [VideoSourceType](/zh-CN/api-reference/rtc/android/enum-videosourcetype)。

### 返回值 [#callback_imetadataobserver_onreadytosendmetadata__return_values]

方法调用成功时，返回希望发送的元数据，格式为字节数组。

- [IMetadataObserver](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_imetadataobserver)
