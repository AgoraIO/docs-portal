## addView

添加一个渲染视图。

<a id="api_canvas_addview__prototype"></a>

```java
public void addView(View view, ViewConfig viewConfig) throws RteException
```

<a id="api_canvas_addview__detailed_desc"></a>

#### `自从`

自 v4.4.0 版本新增。

当你需要使用播放器播放视频时，可以调用该方法将视图添加到视频渲染器中，以显示视频内容。

:::info[注]
当前仅支持一个视图。
:::

<a id="api_canvas_addview__scenario"></a>

### 适用场景

当你需要使用播放器播放视频时，可以调用此方法将视图添加到视频渲染器中，以显示视频内容。

<a id="api_canvas_addview__timing"></a>

### 调用时机

必须在调用 [setCanvas](/zh-CN/api-reference/rtc/android/rte-player#api_player_setcanvas) 之前调用该方法。

<a id="api_canvas_addview__parameters"></a>

### 参数

#### `view`

`SurfaceView` 对象。

#### `viewConfig`

视图的相关设置。

<a id="api_canvas_addview__exception"></a>

### 异常

添加渲染视图失败，SDK 会抛出异常，并返回相应的错误信息。你需要捕获异常并进行处理。

### 所属接口类
- [Canvas](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_canvas)

## openWithUrl

打开一个 URL 资源。

<a id="api_player_openwithurl__prototype"></a>

```java
public void openWithUrl(String url, long startTime, AsyncCallback callback)
```

<a id="api_player_openwithurl__detailed_desc"></a>

#### `自从`

自 v4.4.0 版本新增。

该方法支持通过 URL 打开实时流媒体资源。如果你希望加快打开速度，可以在调用该方法前使用 [preloadWithUrl](/zh-CN/api-reference/rtc/android/rte-player#api_player_preloadwithurl) 预加载资源。 如果资源打开失败，你会收到 [onStateChanged](/zh-CN/api-reference/rtc/android/rte-player#callback_playerobserver_onstatechanged) 回调，播放器状态为 `FAILED`。此时需要先调用 [stop](/zh-CN/api-reference/rtc/android/rte-player#api_player_stop_player)，然后再次调用 [openWithUrl](/zh-CN/api-reference/rtc/android/rte-player#api_player_openwithurl) 重新打开资源。 如果你关闭了自动播放功能，可以在资源打开后调用 [play](/zh-CN/api-reference/rtc/android/rte-player#api_player_play_player) 开始播放。

:::info[注]
该方法目前仅支持以 `rte://` 开头的 URL、CDN 推流 URL 和本地媒体文件。
:::

<a id="api_player_openwithurl__timing"></a>

### 调用时机

该方法必须在 [Player](/zh-CN/api-reference/rtc/android/rte-player#api_player_player_player) 之后调用。

<a id="api_player_openwithurl__related"></a>

### 相关回调

调用该方法后会触发 [onStateChanged](/zh-CN/api-reference/rtc/android/rte-player#callback_playerobserver_onstatechanged) 回调，播放器状态为 `OPENING`，表示正在打开 URL。成功打开后，播放器状态为 `OPEN_COMPLETED`。

<a id="api_player_openwithurl__parameters"></a>

### 参数

#### `url`

要打开的 URL，可以是 CDN 推流 URL、本地媒体文件，或以 `rte://` 为前缀的 URL。

#### `startTime`

播放的起始位置，单位为毫秒。

#### `callback`

异步通知打开 URL 资源结果的回调。你可以通过该回调的 [onResult](/zh-CN/api-reference/rtc/android/rte-player#callback_asynccallback_onresult_asynccallback) 方法获取错误信息。

### 所属接口类
- [Player](/zh-CN/api-reference/rtc/android/rtc-interface-class#class_player)

## setAbrFallbackLayer

设置已订阅远端视频流的回退选项。

<a id="api_playerconfig_setabrfallbacklayer__prototype"></a>

```java
public void setAbrFallbackLayer(Constants.AbrFallbackLayer fallbackLayer) throws RteException
```

<a id="api_playerconfig_setabrfallbacklayer__detailed_desc"></a>

#### `自从`

自 v4.4.0 版本新增。

在网络状况不佳时，SDK 会将已订阅远端视频流的分辨率降级到指定的视频质量层。每个质量层对应特定的分辨率和码率。网络恢复后，SDK 会将视频流恢复至原始质量层。

:::info[注]
如果未开启 ABR 功能，视频流的回退质量层只能设置为 `LOW` 或 `AUDIO_ONLY`。
:::

<a id="api_playerconfig_setabrfallbacklayer__scenario"></a>

### 适用场景

一般场景下，可调用该方法并将回退质量层设置为 `kRteAbrFallbackLow` 或 `kRteAbrFallbackAudioOnly`。当网络较差时，SDK 会回退为视频小流或仅接收音频流。 如果对回退视频流的分辨率有更高要求，可[联系技术支持](https://ticket.shengwang.cn/)开启 ABR 功能。开启后，可自定义每一层的分辨率。SDK 会以你指定的最低质量层的分辨率为下限，并根据网络状况在该范围内动态调整分辨率。

<a id="api_playerconfig_setabrfallbacklayer__timing"></a>

### 调用时机

必须在调用 `setConfigs` 之前调用该方法。

<a id="api_playerconfig_setabrfallbacklayer__parameters"></a>

### 参数

#### `fallbackLayer`

视频流的回退质量层，详见 [AbrFallbackLayer](/zh-CN/api-reference/rtc/android/enum-rteabrfallbacklayer)。

:::info[注]
自定义分辨率时，请确保视频质量层按从高到低的分辨率排序；若分辨率相同，则按帧率从高到低排序。

| 视频质量层 | 分辨率 |
| --- | --- |
| `LAYER1` | 2160p (4K) |
| `LAYER2` | 1440p (2K) |
| `LAYER3` | 1080p (HD) |
| `LAYER4` | 720p (HD) |
| `LAYER5` | 540p (SD) |
| `LAYER6` | 480p (SD) |
:::
