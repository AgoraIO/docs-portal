<a id="class_audiospectrumdata__prototype"></a>

```java
public class AudioSpectrumInfo {
  private float[] audioSpectrumData;
  private int dataLength;
}
```

<a id="class_audiospectrumdata__parameters"></a>

## 属性

### `audioSpectrumData`

音频频谱数据。声网将音频频率划分为 256 个频率域，并通过该参数报告每个频率域的能量值。每个能量值的取值范围为 [-300, 1]，单位为 dBFS。

### `dataLength`

音频频谱数据的长度，固定为 256。
