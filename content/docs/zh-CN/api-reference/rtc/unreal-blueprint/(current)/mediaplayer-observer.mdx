## 音视频观测器

<a id="api_irtcengine_getmediaplayersourceobserver"></a>

## GetMediaPlayerSourceObserver

获取事件处理器。

<a id="api_irtcengine_getmediaplayersourceobserver__prototype"></a>

```cpp
UFUNCTION(BlueprintPure, Category = "Agora|IRtcEngine")
UAgoraBPuIMediaPlayerSourceObserver* GetMediaPlayerSourceObserver();
```

<a id="api_irtcengine_getmediaplayersourceobserver__detailed_desc"></a>

调用该方法获取事件处理器后，你可以调用 [AddBlueprintCallbackExecutor](/zh-CN/api-reference/rtc/unreal-blueprint/mediaplayer-observer#api_imediaplayer_addblueprintcallbackexecutor) 绑定对应的回调执行器。

<a id="api_irtcengine_getmediaplayersourceobserver__timing"></a>

### 调用时机

调用 [GetAgoraRtcEngine](/zh-CN/api-reference/rtc/unreal-blueprint/initialize#api_createagorartcengine) 后。

<a id="api_irtcengine_getmediaplayersourceobserver__restriction"></a>

### 调用限制

无。

<a id="api_irtcengine_getmediaplayersourceobserver__return_values"></a>

### 返回值

返回一个指向 `UAgoraBPuIMediaPlayerSourceObserver` 事件处理器的指针。

<a id="api_imediaplayer_addblueprintcallbackexecutor"></a>

## AddBlueprintCallbackExecutor

添加一个蓝图回调执行器。

<a id="api_imediaplayer_addblueprintcallbackexecutor__prototype"></a>

```cpp
UFUNCTION(BlueprintCallable, Category = "Agora|Event")
void AddBlueprintCallbackExecutor(UAgoraBPuIMediaPlayerSourceObserverCBExecutor* Executor);
```

<a id="api_imediaplayer_addblueprintcallbackexecutor__detailed_desc"></a>

获取事件处理器后，你可以调用该方法绑定回调执行器，用于执行 [IMediaPlayerSourceObserver](/zh-CN/api-reference/rtc/unreal-blueprint/rtc-interface-class#class_imediaplayersourceobserver) 接口类下的相关回调。

<a id="api_imediaplayer_addblueprintcallbackexecutor__timing"></a>

### 调用时机

调用 [GetMediaPlayerSourceObserver](/zh-CN/api-reference/rtc/unreal-blueprint/mediaplayer-observer#api_irtcengine_getmediaplayersourceobserver) 获取事件处理器后。

<a id="api_imediaplayer_addblueprintcallbackexecutor__restriction"></a>

### 调用限制

无。

<a id="api_imediaplayer_addblueprintcallbackexecutor__parameters"></a>

### 参数

#### `Executor`

指向 `UAgoraBPuIMediaPlayerSourceObserverCBExecutor` 类型的指针，用于执行 IMediaPlayerSourceObserver 接口类下的回调逻辑。

## OnAudioVolumeIndication

媒体播放器音量提示回调。

<a id="callback_imediaplayersourceobserver_onaudiovolumeindication__prototype"></a>

```cpp

```

<a id="callback_imediaplayersourceobserver_onaudiovolumeindication__detailed_desc"></a>

<a id="callback_imediaplayersourceobserver_onaudiovolumeindication__parameters"></a>

### 参数

#### `volume`

播放器的当前音量，取值范围为 [0,255]。

## OnPlayBufferUpdated

报告当前缓冲数据能播放的时间。

<a id="callback_imediaplayersourceobserver_onplaybufferupdated__prototype"></a>

```cpp
UFUNCTION(BlueprintNativeEvent, Category = "Agora|Event")
	void OnPlayBufferUpdated(int64 playCachedBuffer);
```

<a id="callback_imediaplayersourceobserver_onplaybufferupdated__detailed_desc"></a>

播放在线媒体资源的过程中，SDK 会每隔 1 秒触发一次该回调，报告当前缓冲的数据能支持的播放时间。

- 当缓冲数据支持的播放时间小于阈值（默认为 0）时，返回 PLAYER_EVENT_BUFFER_LOW (6)。
- 当缓冲数据支持的播放时间大于阈值（默认为 0）时，返回 PLAYER_EVENT_BUFFER_RECOVER (7)。

<a id="callback_imediaplayersourceobserver_onplaybufferupdated__parameters"></a>

### 参数

#### `playCachedBuffer`

当前缓冲的数据能支持的播放时间 (毫秒)。

- [IMediaPlayerSourceObserver](/zh-CN/api-reference/rtc/unreal-blueprint/rtc-interface-class#class_imediaplayersourceobserver)

## OnPlayerEvent

报告播放器的事件。

<a id="callback_imediaplayersourceobserver_onplayerevent__prototype"></a>

```cpp
UFUNCTION(BlueprintNativeEvent, Category = "Agora|Event")
	void OnPlayerEvent(EMEDIA_PLAYER_EVENT eventCode, int64 elapsedTime, const FString& message);
```

<a id="callback_imediaplayersourceobserver_onplayerevent__detailed_desc"></a>

- 调用 [Seek](/zh-CN/api-reference/rtc/unreal-blueprint/mediaplayer-control#api_imediaplayer_seek) 定位播放后，SDK 会触发该回调，报告定位播放的结果。

<a id="callback_imediaplayersourceobserver_onplayerevent__parameters"></a>

### 参数

#### `eventCode`

播放器事件，详见 [EMEDIA_PLAYER_EVENT](/zh-CN/api-reference/rtc/unreal-blueprint/enum-mediaplayerevent)。

#### `elapsedTime`

发生事件的时间 (毫秒)。

#### `message`

事件的信息。

- [IMediaPlayerSourceObserver](/zh-CN/api-reference/rtc/unreal-blueprint/rtc-interface-class#class_imediaplayersourceobserver)

## OnPlayerSourceStateChanged

报告播放器状态改变。

<a id="callback_imediaplayersourceobserver_onplayersourcestatechanged__prototype"></a>


- [IMediaPlayerSourceObserver](/zh-CN/api-reference/rtc/unreal-blueprint/rtc-interface-class#class_imediaplayersourceobserver)

## OnPositionChanged

报告当前媒体资源的播放进度。

<a id="callback_imediaplayersourceobserver_onpositionchanged__prototype"></a>

```cpp
UFUNCTION(BlueprintNativeEvent, Category = "Agora|Event")
	void OnPositionChanged(int64 position_ms, int64 timestampMs);
```

<a id="callback_imediaplayersourceobserver_onpositionchanged__detailed_desc"></a>

播放媒体文件时，SDK 每隔 1 秒会自动触发该回调，报告当前播放进度。

<a id="callback_imediaplayersourceobserver_onpositionchanged__parameters"></a>

### 参数

#### `positionMs`

当前播放进度，单位为 ms。

#### `timestampMs`

当前播放进度的 NTP 时间戳，单位为 ms。

- [IMediaPlayerSourceObserver](/zh-CN/api-reference/rtc/unreal-blueprint/rtc-interface-class#class_imediaplayersourceobserver)
