## 枚举值

### `HEADPHONE_EQUALIZER_OFF`

关闭耳机均衡器，收听原始音频。

### `HEADPHONE_EQUALIZER_OVEREAR`

使用头戴式耳机的均衡器。

### `HEADPHONE_EQUALIZER_INEAR`

使用入耳式耳机的均衡器。
