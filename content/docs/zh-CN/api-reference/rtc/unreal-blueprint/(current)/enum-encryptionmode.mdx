<a id="enum_encryptionmode__detailed_desc"></a>

建议使用 AES_128_GCM2 或 AES_256_GCM2 加密模式。这两种模式支持使用盐，安全性更高。

<a id="enum_encryptionmode__parameters"></a>

## 枚举值

### AES_128_XTS

1: 128 位 AES 加密，XTS 模式。

### AES_128_ECB

2: 128 位 AES 加密，ECB 模式。

### AES_256_XTS

3: 256 位 AES 加密，XTS 模式。

### SM4_128_ECB

4: 128 位 SM4 加密，ECB 模式。

### AES_128_GCM

5: 128 位 AES 加密，GCM 模式。

### AES_256_GCM

6: 256 位 AES 加密，GCM 模式。

### AES_128_GCM2

7:（默认）128 位 AES 加密，GCM 模式。该加密模式需要设置盐（`encryptionKdfSalt`）。

### AES_256_GCM2

8: 256 位 AES 加密，GCM 模式。该加密模式需要设置盐（`encryptionKdfSalt`）。

### MODE_END

枚举值边界。
