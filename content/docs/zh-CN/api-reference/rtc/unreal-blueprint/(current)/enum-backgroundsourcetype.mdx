## 枚举值

### `BACKGROUND_COLOR`

1:（默认）背景为纯色。

### `BACKGROUND_IMG`

2: 背景为 PNG、JPG 格式的图片。

### `BACKGROUND_BLUR`

3: 背景为虚化处理后的背景。

### `BACKGROUND_VIDEO`

4: 背景为 MP4、AVI、MKV、FLV 等格式的本地视频。
