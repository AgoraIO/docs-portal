## 属性

<ParameterList>
<a id="captureaudio"></a>
<Parameter name="captureAudio">

屏幕共享时是否采集系统音频：

- `true`: 采集系统音频。
- `false`: （默认）不采集系统音频。

:::note
注：

- 受系统限制，采集系统音频仅适用于 Android API 级别为 29 及以上，即 Android 10 及以上。
- 为提高屏幕共享时采集系统音频的成功率，请确保你已调用 [SetAudioScenario](/zh-CN/api-reference/rtc/unreal-blueprint/audio/audio-basic#api_irtcengine_setaudioscenario) 方法并设置音频场景为 `AUDIO_SCENARIO_GAME_STREAMING`。
:::

</Parameter>
<a id="audioparams"></a>
<Parameter name="audioParams">

共享屏幕流的音频配置。详见 [FScreenAudioParameters](/zh-CN/api-reference/rtc/unreal-blueprint/class-screenaudioparameters)。

:::caution
注意： 该参数仅在 captureAudio 为 `true` 时生效。
:::

</Parameter>
<a id="capturevideo"></a>
<Parameter name="captureVideo">

屏幕共享时是否采集屏幕：

- `true`:（默认）采集屏幕。
- `false`: 不采集屏幕。

:::note
注： 受系统限制，采集屏幕仅适用于 Android API 级别为 21 及以上，即 Android 5 及以上。
:::

</Parameter>

<Parameter name="videoParams">

:::caution
注意： 该参数仅在 captureVideo 为 `true` 时生效。
:::
