## SendStreamMessage

发送数据流。

<a id="api_irtcengine_sendstreammessage__prototype"></a>

```text
UFUNCTION(BlueprintCallable, Category = "Agora|IRtcEngine")
	int SendStreamMessage(int streamId, const FString& data);
```

<a id="api_irtcengine_sendstreammessage__detailed_desc"></a>

### 详情

调用 [CreateDataStream](/zh-CN/api-reference/rtc/unreal-blueprint/metadata/datastream#api_irtcengine_createdatastream2) 后，你可以调用该方法向频道内所有用户发送数据流消息。

<a id="api_irtcengine_sendstreammessage__limit"></a>

SDK 对该方法的实现进行了如下限制：

- 频道内每个客户端最多可以同时拥有 5 个数据通道，所有数据通道共用的总发包码率限制为 30 KB/s。
- 每个数据通道每秒最多能发送 60 个包，每个包最大为 1 KB。

<a id="api_irtcengine_sendstreammessage__error"></a>

成功调用该方法后，远端会触发 [OnStreamMessage](/zh-CN/api-reference/rtc/unreal-blueprint/metadata/datastream#callback_irtcengineeventhandler_onstreammessage) 回调，远端用户可以在该回调中获取接收到的流消息；若调用失败，远端会触发 [OnStreamMessageError](/zh-CN/api-reference/rtc/unreal-blueprint/metadata/datastream#callback_irtcengineeventhandler_onstreammessageerror) 回调。

:::note
注意：

- 该方法需要在加入频道后、且调用 [CreateDataStream](/zh-CN/api-reference/rtc/unreal-blueprint/metadata/datastream#api_irtcengine_createdatastream2) 创建数据通道之后调用。
- 该方法仅适用于主播用户。
:::

<a id="api_irtcengine_sendstreammessage__parameters"></a>

### 参数

### streamId

数据流 ID。可以通过 CreateDataStream 获取。

### data

待发送的数据。

### length

数据长度。

<a id="api_irtcengine_sendstreammessage__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。

## SendStreamMessageEx

发送数据流。

```text
UFUNCTION(BlueprintCallable, Category = "Agora|IRtcEngine")
	int SendStreamMessageEx(int streamId, const FString& data, const  FRtcConnection& connection);
```

<a id="api_irtcengineex_sendstreammessageex__detailed_desc"></a>

### 详情

调用 [CreateDataStreamEx](/zh-CN/api-reference/rtc/unreal-blueprint/metadata/datastream#api_irtcengineex_createdatastreamex2) 后，你可以调用本方法向频道内所有用户发送数据流消息。

SDK 对该方法的实现进行了如下限制：

- 频道内每个客户端最多可以同时拥有 5 个数据通道，所有数据通道共用的总发包码率限制为 30 KB/s。
- 每个数据通道每秒最多能发送 60 个包，每个包最大为 1 KB。

成功调用该方法后，远端会触发 [OnStreamMessage](/zh-CN/api-reference/rtc/unreal-blueprint/metadata/datastream#callback_irtcengineeventhandler_onstreammessage) 回调，远端用户可以在该回调中获取接收到的流消息；若调用失败，远端会触发 [OnStreamMessageError](/zh-CN/api-reference/rtc/unreal-blueprint/metadata/datastream#callback_irtcengineeventhandler_onstreammessageerror) 回调。

:::note
注意：

- 该方法需要在 [JoinChannelEx](/zh-CN/api-reference/rtc/unreal-blueprint/channel#api_irtcengineex_joinchannelex) 后调用。
- 请确保在调用该方法前，已调用 CreateDataStreamEx 创建了数据通道。
:::

<a id="api_irtcengineex_sendstreammessageex__parameters"></a>

### 参数

数据流 ID。可以通过 CreateDataStreamEx 获取。

### data

待发送的数据。

Connection 信息。详见 [FUABT_RtcConnection](/zh-CN/api-reference/rtc/unreal-blueprint/class-rtcconnection)。
