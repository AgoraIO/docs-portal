## 枚举值

### `AREA_CODE_CN`

中国大陆。

### `AREA_CODE_NA`

北美区域。

### `AREA_CODE_EU`

欧洲区域。

### `AREA_CODE_AS`

除中国以外的亚洲区域。

### `AREA_CODE_JP`

日本。

### `AREA_CODE_IN`

印度。

### `AREA_CODE_GLOB`

全球。
