<a id="api_irtcengine_setheadphoneeqparameters__prototype"></a>

```cpp
UFUNCTION(BlueprintCallable, Category = "Agora|IRtcEngine")
	int SetHeadphoneEQParameters(int lowGain, int highGain);
```

<a id="api_irtcengine_setheadphoneeqparameters__detailed_desc"></a>

## 详情

在空间音频场景下，如果在调用 [SetHeadphoneEQPreset](/zh-CN/api-reference/rtc/unreal-blueprint/api-irtcengine-setheadphoneeqpreset) 方法使用预设的耳机均衡效果后仍未达到预期，你可以通过调用该方法进一步调节耳机均衡效果。

<a id="api_irtcengine_setheadphoneeqparameters__parameters"></a>

## 参数

### `lowGain`

耳机均衡器的低频参数。取值范围为 [-10,10]，取值越大，声音越低沉。

### `highGain`

耳机均衡器的高频参数。取值范围为 [-10,10]，取值越大，声音越尖锐。

<a id="api_irtcengine_setheadphoneeqparameters__return_values"></a>

## 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败

  - -1：一般性的错误（未明确归类）。
