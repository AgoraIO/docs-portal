## 枚举值

### `AUTO_SIMULCAST_STREAM`

-1：默认不发送小流，直至收到接收端发起的订阅小流申请时，开始自动发送小流。

### `DISABLE_SIMULCAST_STREAM`

0：始终不发送小流。

### `ENABLE_SIMULCAST_STREAM`

1：始终发送小流。
