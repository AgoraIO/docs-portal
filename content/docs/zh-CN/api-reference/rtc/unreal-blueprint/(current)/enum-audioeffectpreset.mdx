<a id="enum_audioeffectpreset__detailed_desc"></a>

### 详情

为获取更好的音效，建议在使用预设音效前，调用 [SetAudioProfileAndScenario](/zh-CN/api-reference/rtc/unreal-blueprint/audio/audio-basic#api_irtcengine_setaudioprofile) 并按照如下推荐设置 profile 参数。

| 预设音效 | profile |
| --- | --- |
| <Slot name="api-center-table-0" /> | AUDIO_PROFILE_MUSIC_HIGH_QUALITY_STEREO 或 AUDIO_PROFILE_MUSIC_STANDARD_STEREO |
| 其他预设音效（除 AUDIO_EFFECT_OFF 以外） | AUDIO_PROFILE_MUSIC_HIGH_QUALITY 或 AUDIO_PROFILE_MUSIC_HIGH_QUALITY_STEREO |

<Slot for="api-center-table-0">

- ROOM_ACOUSTICS_VIRTUAL_STEREO
- ROOM_ACOUSTICS_3D_VOICE
- ROOM_ACOUSTICS_VIRTUAL_SURROUND_SOUND

</Slot>
