## 枚举值

### `CAPTURE_BRIGHTNESS_LEVEL_INVALID`

-1: SDK 未检测出本地采集的画质亮度级别。请等待几秒，通过下一次回调的 captureBrightnessLevel 获取亮度级别。

### `CAPTURE_BRIGHTNESS_LEVEL_NORMAL`

0: 本地采集的画质亮度正常。

### `CAPTURE_BRIGHTNESS_LEVEL_BRIGHT`

1: 本地采集的画质亮度偏亮。

### `CAPTURE_BRIGHTNESS_LEVEL_DARK`

2: 本地采集的画质亮度偏暗。
