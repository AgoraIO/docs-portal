## AdjustUserPlaybackSignalVolume

调节本地播放的指定远端用户信号音量。

<a id="api_irtcengine_adjustuserplaybacksignalvolume__prototype"></a>

```text
UFUNCTION(BlueprintCallable, Category = "Agora|IRtcEngine")
	int AdjustUserPlaybackSignalVolume(int64 uid, int volume);
```

<a id="api_irtcengine_adjustuserplaybacksignalvolume__detailed_desc"></a>

<a id="api_irtcengine_adjustuserplaybacksignalvolume__desc"></a>

你可以在通话中调用该方法调节指定远端用户在本地播放的音量。如需调节多个用户在本地播放的音量，则需多次调用该方法。

<a id="api_irtcengine_adjustuserplaybacksignalvolume__timing"></a>

### 调用时机

该方法需要在加入频道后调用。

<a id="api_irtcengine_adjustuserplaybacksignalvolume__restriction"></a>

### 调用限制

无。

<a id="api_irtcengine_adjustuserplaybacksignalvolume__parameters"></a>

### 参数

<ParameterList>
<a id="uid"></a>
<Parameter name="uid">

远端用户 ID。

</Parameter>
<a id="volume"></a>
<Parameter name="volume">

音量，取值范围为 [0,400]。

- 0: 静音。
- 100: （默认）原始音量。
- 400: 原始音量的 4 倍，自带溢出保护。

</Parameter>
</ParameterList>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。

## DisableAudio

关闭音频模块。

<a id="api_irtcengine_disableaudio__prototype"></a>

```text
UFUNCTION(BlueprintCallable, Category = "Agora|IRtcEngine")
	int DisableAudio();
```

<a id="api_irtcengine_disableaudio__detailed_desc"></a>

音频模块默认开启，你可以调用该方法关闭音频模块。

<a id="api_irtcengine_disableaudio__timing"></a>

### 调用时机

加入频道前后均可调用。离开频道后仍然有效。

<a id="api_irtcengine_disableaudio__restriction"></a>

### 调用限制

该方法重置整个引擎，响应时间较慢，因此声网建议使用如下方法来控制音频模块：

- [EnableLocalAudio](/zh-CN/api-reference/rtc/unreal-blueprint/audio/audio-capture#api_irtcengine_enablelocalaudio)：是否启动麦克风采集并创建本地音频流。
- [EnableLoopbackRecording](/zh-CN/api-reference/rtc/unreal-blueprint/audio/audio-capture#api_irtcengine_enableloopbackrecording)：是否开启声卡采集。
- [MuteLocalAudioStream](/zh-CN/api-reference/rtc/unreal-blueprint/publishnsubscribe#api_irtcengine_mutelocalaudiostream)：是否发布本地音频流。
- [MuteRemoteAudioStream](/zh-CN/api-reference/rtc/unreal-blueprint/publishnsubscribe#api_irtcengine_muteremoteaudiostream)：是否接收并播放远端音频流。
- [MuteAllRemoteAudioStreams](/zh-CN/api-reference/rtc/unreal-blueprint/publishnsubscribe#api_irtcengine_muteallremoteaudiostreams)：是否接收并播放所有远端音频流。

<a id="api_irtcengine_disableaudio__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。

### 所属接口类

- [IRtcEngine](/zh-CN/api-reference/rtc/unreal-blueprint/rtc-interface-class#class_irtcengine)

- 调用该方法会重置整个引擎，响应时间较慢。你可以根据实际需求用以下方法来独立控制音频模块的某一项功能：

  - [EnableLocalAudio](/zh-CN/api-reference/rtc/unreal-blueprint/audio/audio-capture#api_irtcengine_enablelocalaudio): 是否启动麦克风采集并创建本地音频流。

## EnableAudioVolumeIndication

启用用户音量提示。

<a id="api_irtcengine_enableaudiovolumeindication__prototype"></a>

```text
UFUNCTION(BlueprintCallable, Category = "Agora|IRtcEngine")
	int EnableAudioVolumeIndication(int interval, int smooth, bool reportVad);
```

<a id="api_irtcengine_enableaudiovolumeindication__detailed_desc"></a>

该方法允许 SDK 定期向 App 报告本地发流用户和瞬时音量最高的远端用户（最多 3 位）的音量相关信息。

<a id="api_irtcengine_enableaudiovolumeindication__timing"></a>

### 调用时机

加入频道前后均可调用。

<a id="api_irtcengine_enableaudiovolumeindication__restriction"></a>

### 调用限制

无。

<a id="api_irtcengine_enableaudiovolumeindication__related"></a>

### 相关回调

成功调用该方法、且频道内存在发流用户时，SDK 会按设置的时间间隔触发 [OnAudioVolumeIndication](/zh-CN/api-reference/rtc/unreal-blueprint/audio/audio-basic#callback_irtcengineeventhandler_onaudiovolumeindication) 回调。

<a id="api_irtcengine_enableaudiovolumeindication__parameters"></a>

### 参数

<ParameterList>
<a id="interval"></a>
<Parameter name="interval">

指定音量提示的时间间隔：

- ≤ 0: 禁用音量提示功能。
- &gt; 0: 返回音量提示的间隔，单位为毫秒。建议设置到大于 100 毫秒，不得小于 10 毫秒，否则会收不到 OnAudioVolumeIndication 回调。

</Parameter>
<a id="smooth"></a>
<Parameter name="smooth">

平滑系数，指定音量提示的灵敏度。取值范围为 [0,10]，建议值为 3。数字越大，波动越灵敏；数字越小，波动越平滑。

</Parameter>
<a id="reportvad"></a>
<Parameter name="reportVad">

- `true`：开启本地人声检测功能。开启后，OnAudioVolumeIndication 回调的 vad 参数会报告是否在本地检测到人声。
- `false`：（默认）关闭本地人声检测功能。除引擎自动进行本地人声检测的场景外，OnAudioVolumeIndication 回调的 vad 参数不会报告是否在本地检测到人声。

</Parameter>
</ParameterList>

<a id="api_irtcengine_enableaudiovolumeindication__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。

### 所属接口类

- [IRtcEngine](/zh-CN/api-reference/rtc/unreal-blueprint/rtc-interface-class#class_irtcengine)

## SetAudioProfileAndScenario

设置音频编码属性和音频场景。

<a id="api_irtcengine_setaudioprofile__prototype"></a>

```text

```

<a id="api_irtcengine_setaudioprofile__detailed_desc"></a>

<a id="api_irtcengine_setaudioprofile__scenario"></a>

### 适用场景

该方法适用于各种音频场景，你可以按需选择。例如，在音乐教学等高音质需求的场景中，建议将 profile 设置为 `AUDIO_PROFILE_MUSIC_HIGH_QUALITY`(4)，scenario 设置为 `AUDIO_SCENARIO_GAME_STREAMING`(3)。

<a id="api_irtcengine_setaudioprofile__timing"></a>

### 调用时机

该方法在加入频道前后均可调用。

<a id="api_irtcengine_setaudioprofile__restriction"></a>

### 调用限制

由于 iOS 系统限制，部分音频路由在通话音量模式下无法识别。因此，如需使用外接声卡，建议将音频应用场景设置为高音质场景 `AUDIO_SCENARIO_GAME_STREAMING`(3)。在这种场景下，SDK 会切换到媒体音量规避该问题。

## SetAudioSessionOperationRestriction

设置 SDK 对 Audio Session 的操作权限。

<a id="api_irtcengine_setaudiosessionoperationrestriction__prototype"></a>

```text
UFUNCTION(BlueprintCallable, Category = "Agora|IRtcEngine")
	int SetAudioSessionOperationRestriction(EAUDIO_SESSION_OPERATION_RESTRICTION restriction);
```

<a id="api_irtcengine_setaudiosessionoperationrestriction__detailed_desc"></a>

### 详情

默认情况下，SDK 和 App 对 Audio Session 都有操作权限。如果你只需使用 App 对 Audio Session 进行操作，你可以调用该方法限制 SDK 对 Audio Session 的操作权限。

该方法在加入频道前后都能调用。一旦调用该方法限制了 SDK 对 Audio Session 的操作权限，该限制会在 SDK 需要更改 Audio Session 时生效。

:::caution

## OnAudioVolumeIndication

<a id="callback_irtcengineeventhandler_onaudiovolumeindication__prototype"></a>

### 详情

该回调默认禁用，你可以通过 [EnableAudioVolumeIndication](/zh-CN/api-reference/rtc/unreal-blueprint/audio/audio-basic#api_irtcengine_enableaudiovolumeindication) 开启。 开启后，只要频道内有发流用户，SDK 会在加入频道后按 EnableAudioVolumeIndication 中设置的时间间隔触发 OnAudioVolumeIndication 回调。每次会触发两个 OnAudioVolumeIndication 回调，一个报告本地发流用户的音量相关信息，另一个报告瞬时音量最高的远端用户（最多 3 位）的音量相关信息。

:::caution
注意：

启用该功能后，如果有用户将自己静音（调用了 [MuteLocalAudioStream](/zh-CN/api-reference/rtc/unreal-blueprint/publishnsubscribe#api_irtcengine_mutelocalaudiostream)），SDK 会继续报告本地用户的音量提示回调。

瞬时音量最高的远端用户静音后 20 秒，远端的音量提示回调中将不再包含该用户；如果远端所有用户都将自己静音，20 秒后 SDK 停止报告远端用户的音量提示回调。
:::

### 参数

<ParameterList>

</Parameter>
<a id="totalvolume"></a>
<Parameter name="totalVolume">

混音后的总音量，取值范围为 [0,255]。

- 在本地用户的回调中，totalVolume 为本地发流用户的音量。
- 在远端用户的回调中，totalVolume 为瞬时音量最高的远端用户（最多 3 位）混音后的总音量。如果用户调用了 [StartAudioMixing](/zh-CN/api-reference/rtc/unreal-blueprint/play/audio-mixing#api_irtcengine_startaudiomixing2)，则 totalVolume 为音乐文件和用户声音的总音量。

</Parameter>
</ParameterList>
