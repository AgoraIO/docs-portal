## EnableMultiCamera

开启或关闭多路摄像头采集。

<a id="api_irtcengine_enablemulticamera__prototype"></a>

```cpp
UFUNCTION(BlueprintCallable, Category = "Agora|IRtcEngine")
	int EnableMultiCamera(bool enabled, const FCameraCapturerConfiguration& config);
```

<a id="api_irtcengine_enablemulticamera__detailed_desc"></a>

### 详情

在已有摄像头采集视频的场景下，声网推荐你采用以下步骤实现多路摄像头采集、发布视频：

1. 调用该方法开启多路摄像头采集。
2. 调用 StartPreview 开启本地视频预览。
3. 调用 StartCameraCapture 并设置 sourceType 指定第二个摄像头开始采集。
4. 调用 JoinChannelEx 并设置 publishSecondaryCameraTrack 为 true，在频道内发布第二路摄像头采集的视频流。

如果要关闭多路摄像头采集，可参考以下步骤：

1. 调用 StopCameraCapture。
2. 调用该方法并将 enabled 设置为 false。

:::info[注]
你可以在 [StartPreview](/zh-CN/api-reference/rtc/unreal-blueprint/video/video-basic#api_irtcengine_startpreview2) 前后调用该方法开启多摄像头采集：

- 如果在 StartPreview 之前开启，则本地视频预览会同时出现两个摄像头采集的画面。
- 如果在 StartPreview 之后开启，SDK 会先停止当前的摄像头采集，然后再开启原摄像头和第二个摄像头，本地视频预览会出现短暂黑屏、然后自动恢复正常。
:::

该方法仅适用于 iOS。

使用多路摄像头采集视频时，请确保系统版本为 13.0 及以上。

支持多路摄像头采集的最低 iOS 设备类型如下所示：

- iPhone XR
- iPhone XS
- iPhone XS Max
- iPad Pro (第三代及以上)

<a id="api_irtcengine_enablemulticamera__parameters"></a>

### 参数

#### `enabled`

是否开启多摄像头视频采集模式：

- true：开启多摄像头采集模式，SDK 使用多路摄像头采集视频。
- false：关闭多摄像头采集模式，SDK 仅使用单路摄像头采集视频。

#### `config`

第二个摄像头的采集配置。详见 [FCameraCapturerConfiguration](/zh-CN/api-reference/rtc/unreal-blueprint/class-cameracapturerconfiguration)。

<a id="api_irtcengine_enablemulticamera__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。 详见 [错误码](https://doc.shengwang.cn/api-ref/rtc/unreal-blueprint/error-code) 了解详情和解决建议。

### 所属接口类
- [IRtcEngine](/zh-CN/api-reference/rtc/unreal-blueprint/rtc-interface-class#class_irtcengine)

## GetCapability

获取视频采集设备在指定的视频格式下的详细视频帧信息。

<a id="api_ivideodevicemanager_getcapability__prototype"></a>

```cpp
UFUNCTION(BlueprintCallable, Category = "Agora|IVideoDeviceManager")
	int GetCapability(const FString & deviceIdUTF8, int deviceCapabilityNumber, FVideoFormat& capability);
```

<a id="api_ivideodevicemanager_getcapability__detailed_desc"></a>

### 详情

:::warning[注意]
该方法仅适用于 Windows 和 macOS。
:::

在调用 [NumberOfCapabilities](/zh-CN/api-reference/rtc/unreal-blueprint/device-management/video-device#api_ivideodevicemanager_numberofcapabilities) 获取视频采集设备支持的视频格式数量后，你可以调用该方法获取指定索引号支持的具体视频帧信息。

<a id="api_ivideodevicemanager_getcapability__parameters"></a>

### 参数

#### `deviceIdUTF8`

视频采集设备的 ID。

#### `deviceCapabilityNumber`

视频格式的索引号。如果 NumberOfCapabilities 的返回值为 i，则该参数取值范围为[0,i)。

#### `capability`

输出参数。表示指定视频格式的具体信息，包括宽度（px），高度（px）和帧率（fps）。详见 [FVideoFormat](/zh-CN/api-reference/rtc/unreal-blueprint/class-videoformat)。

<a id="api_ivideodevicemanager_getcapability__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。 详见 [错误码](https://doc.shengwang.cn/api-ref/rtc/unreal-blueprint/error-code) 了解详情和解决建议。

```cpp
	bool IsCameraTorchSupported();
```

<a id="api_irtcengine_iscameratorchsupported__detailed_desc"></a>

### 详情

:::warning[注意]
- 该方法仅适用于 Android 和 iOS。

## NumberOfCapabilities

获取指定视频采集设备支持的视频格式数量。

<a id="api_ivideodevicemanager_numberofcapabilities__prototype"></a>

```cpp
UFUNCTION(BlueprintCallable, Category = "Agora|IVideoDeviceManager")
	int NumberOfCapabilities(const FString & deviceIdUTF8);
```

<a id="api_ivideodevicemanager_numberofcapabilities__detailed_desc"></a>

### 详情

:::warning[注意]
该方法仅适用于 Windows 和 macOS。
:::

视频采集设备可能支持多种视频格式，每一种格式都支持不同的视频帧宽度、视频帧高度、帧率组合。

你可以通过调用该方法，获取指定的视频采集设备可支持多少种视频格式，然后调用 [GetCapability](/zh-CN/api-reference/rtc/unreal-blueprint/device-management/video-device#api_ivideodevicemanager_getcapability) 获取指定视频格式下的具体视频帧信息。

<a id="api_ivideodevicemanager_numberofcapabilities__parameters"></a>

### 参数

#### `deviceIdUTF8`

视频采集设备的 ID。

<a id="api_ivideodevicemanager_numberofcapabilities__return_values"></a>

### 返回值

- &gt; 0: 方法调用成功。返回该设备支持的视频格式数量。例如：如果指定的摄像头支持 10 种不同的视频格式，则返回值为 10。
- ≤ 0: 方法调用失败。 详见 [错误码](https://doc.shengwang.cn/api-ref/rtc/unreal-blueprint/error-code) 了解详情和解决建议。

### 所属接口类
- [IVideoDeviceManager](/zh-CN/api-reference/rtc/unreal-blueprint/rtc-interface-class#class_ivideodevicemanager)

## QueryCameraFocalLengthCapability

查询摄像头支持的焦距能力。

<a id="api_irtcengine_querycamerafocallengthcapability__prototype"></a>

```cpp
UFUNCTION(BlueprintCallable, Category = "Agora|IRtcEngine")
	int QueryCameraFocalLengthCapability(const TArray<FFocalLengthInfo> & focalLengthInfos);
```

<a id="api_irtcengine_querycamerafocallengthcapability__detailed_desc"></a>

### 详情

如需开启摄像头广角、超广角拍摄模式，建议你先调用该方法查询设备是否具备相应的焦距能力，再根据查询结果调用 [SetCameraCapturerConfiguration](/zh-CN/api-reference/rtc/unreal-blueprint/device-management/video-device#api_irtcengine_setcameracapturerconfiguration) 调整摄像头的焦距配置，以达到最佳的摄像头采集效果。

:::warning[注意]
该方法仅适用于 Android 和 iOS。
:::

<a id="api_irtcengine_querycamerafocallengthcapability__parameters"></a>

### 参数

#### `focalLengthInfos`

输入和输出参数。指向 [FFocalLengthInfo](/zh-CN/api-reference/rtc/unreal-blueprint/class-focallengthinfo) 对象数组的指针：

- 输入值：指向一个 FFocalLengthInfo 对象数组，用于存储焦距信息。
- 输出值：方法执行后，输出查询到的焦距信息。

```cpp

```

<a id="api_irtcengine_setcameraexposurefactor__detailed_desc"></a>

### 详情

当拍摄环境光线不足或过于明亮时，会影响视频采集的画质。为了获得更好的视频效果，你可以使用该方法调节摄像头的曝光系数。

:::warning[注意]
- 该方法仅适用于 Android 和 iOS。
- 该方法必须在 EnableVideo 后调用，设置结果在摄像头成功开启后生效，即 SDK 触发 OnLocalVideoStateChanged 回调返回本地视频状态为 LOCAL_VIDEO_STREAM_STATE_CAPTURING (1) 后。
- 建议你在调用该方法前，先调用 IsCameraExposureSupported 查询当前摄像头是否支持调节曝光系数。
- 当你调用该方法时，设置的是当前正在使用的摄像头的曝光系数，即调用 SetCameraCapturerConfiguration 时指定的摄像头。
:::

<a id="api_irtcengine_setcameraexposurefactor__parameters"></a>

### 参数

#### `factor`

摄像头的曝光系数。默认值为 0，表示使用摄像头的默认曝光量。取值越大，曝光量越大。视频图像过曝时，你可以降低曝光系数；视频图像欠曝且暗部细节丢失时，你可以增加曝光系数。如果你指定的曝光系数超出设备支持的范围，SDK 会自动调节为设备实际支持的范围。

在 Android 平台上，取值范围为 [-20.0,20.0]；在 iOS 平台上，取值范围为 [-8.0,8.0]。

## OnVideoDeviceStateChanged

视频设备变化回调。

<a id="callback_irtcengineeventhandler_onvideodevicestatechanged__prototype"></a>

```cpp
UFUNCTION(BlueprintNativeEvent, Category = "Agora|Event")
	void OnVideoDeviceStateChanged(const FString& deviceId, int deviceType, int deviceState);
```

<a id="callback_irtcengineeventhandler_onvideodevicestatechanged__detailed_desc"></a>

该回调提示系统视频设备状态发生改变，比如被拔出或移除。如果设备已使用外接摄像头采集，外接摄像头被拔开后，视频会中断。

:::info[注]
该回调仅适用于 Windows 和 macOS。
:::

<a id="callback_irtcengineeventhandler_onvideodevicestatechanged__parameters"></a>

### 参数

#### `deviceId`

设备 ID。

#### `deviceType`

设备类型。详见 [FENUMWRAP_MEDIA_DEVICE_TYPE](/zh-CN/api-reference/rtc/unreal-blueprint/enum-mediadevicetype)。

#### `deviceState`

设备状态。详见 [EMEDIA_DEVICE_STATE_TYPE](/zh-CN/api-reference/rtc/unreal-blueprint/enum-mediadevicestatetype)。
