## 枚举值

### `VIDEO_ORIENTATION_0`

0:（默认）顺时针旋转 0 度。

### `VIDEO_ORIENTATION_90`

90: 顺时针旋转 90 度。

### `VIDEO_ORIENTATION_180`

180: 顺时针旋转 180 度。

### `VIDEO_ORIENTATION_270`

270: 顺时针旋转 270 度。
