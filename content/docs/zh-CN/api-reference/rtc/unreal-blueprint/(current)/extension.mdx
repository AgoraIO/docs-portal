## EnableExtension

启用/禁用插件。

<a id="api_irtcengine_enableextension__prototype"></a>

```cpp
UFUNCTION(BlueprintCallable, Category = "Agora|IRtcEngine")
	int EnableExtension(const FString& provider, const FString& extension, bool enable = true, EMEDIA_SOURCE_TYPE type = EMEDIA_SOURCE_TYPE::UNKNOWN_MEDIA_SOURCE);
```

<a id="api_irtcengine_enableextension__detailed_desc"></a>

<a id="api_irtcengine_enableextension__timing"></a>

### 调用时机

建议你在加入频道后调用该方法。

<a id="api_irtcengine_enableextension__restriction"></a>

### 调用限制

- 如果要开启多个插件，需要多次调用该方法。
- 该方法调用成功后，无法再加载其他插件。

<a id="api_irtcengine_enableextension__related"></a>

### 相关回调

频道内调用该方法成功时会触发插件启用回调 [OnExtensionStartedWithContext](/zh-CN/api-reference/rtc/unreal-blueprint/extension#callback_irtcengineeventhandler_onextensionstartedwithcontext) 或插件禁用回调 [OnExtensionStoppedWithContext](/zh-CN/api-reference/rtc/unreal-blueprint/extension#callback_irtcengineeventhandler_onextensionstoppedwithcontext)。

<a id="api_irtcengine_enableextension__parameters"></a>

### 参数

#### `provider`

提供插件的服务商名称。

#### `extension`

插件的名称。

#### `enable`

是否启用插件：

- true: 启用插件。
- false: 禁用插件。

#### `type`

插件的媒体源类型。详见 [EUABT_MEDIA_SOURCE_TYPE](/zh-CN/api-reference/rtc/unreal-blueprint/enum-mediasourcetype)。

<a id="api_irtcengine_enableextension__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。 详见 [错误码](/zh-CN/realtime-media/rtc/reference/error-code) 了解详情和解决建议。
  - -3: 该插件动态库没有被加载。声网推荐你检查该动态库是否存放在预期的位置，或该动态库名是否正确。

### 所属接口类
- [IRtcEngine](/zh-CN/api-reference/rtc/unreal-blueprint/rtc-interface-class#class_irtcengine)

## LoadExtensionProvider

加载插件。

<a id="api_irtcengine_loadextensionprovider__prototype"></a>

```cpp
UFUNCTION(BlueprintCallable, Category = "Agora|IRtcEngine")
	int LoadExtensionProvider(const FString& path, bool unload_after_use);
```

<a id="api_irtcengine_loadextensionprovider__detailed_desc"></a>

该方法用于将 SDK 外部插件（例如云市场插件和 SDK 拓展插件）添加到 SDK 中。

<a id="api_irtcengine_loadextensionprovider__timing"></a>

### 调用时机

请在初始化 [IRtcEngine](/zh-CN/api-reference/rtc/unreal-blueprint/rtc-interface-class#class_irtcengine) 后立即调用该方法。

<a id="api_irtcengine_loadextensionprovider__restriction"></a>

### 调用限制

如果要加载多个插件，需要多次调用该方法。

:::warning[注意]
该方法仅适用于 Windows 和 Android。
:::

<a id="api_irtcengine_loadextensionprovider__parameters"></a>

### 参数

#### `path`

插件的动态库路径和名称。例如： `/library/libagora_segmentation_extension.dll`。

#### `unload_after_use`

是否在插件使用完毕后自动卸载：

- true: 当 IRtcEngine 销毁时自动卸载插件。
- false: 不自动卸载插件，直到进程退出（推荐）。

<a id="api_irtcengine_loadextensionprovider__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。 详见 [错误码](/zh-CN/realtime-media/rtc/reference/error-code) 了解详情和解决建议。

### 所属接口类
- [IRtcEngine](/zh-CN/api-reference/rtc/unreal-blueprint/rtc-interface-class#class_irtcengine)

## RegisterExtension

注册插件。

<a id="api_irtcengine_registerextension__prototype"></a>

```cpp
UFUNCTION(BlueprintCallable, Category = "Agora|IRtcEngine")
	int RegisterExtension(const FString& provider, const FString& extension, EMEDIA_SOURCE_TYPE type);
```

<a id="api_irtcengine_registerextension__detailed_desc"></a>

对于 SDK 外部的插件（例如云市场插件和 SDK 拓展插件），加载插件后，你需要调用该方法注册插件。SDK 内部插件（包含在 SDK 包中的插件）在初始化 [IRtcEngine](/zh-CN/api-reference/rtc/unreal-blueprint/rtc-interface-class#class_irtcengine) 后会自动加载并注册，无需调用该方法。

<a id="api_irtcengine_registerextension__timing"></a>

### 调用时机

- 建议你在初始化 [IRtcEngine](/zh-CN/api-reference/rtc/unreal-blueprint/rtc-interface-class#class_irtcengine) 后、加入频道前调用该方法。
- 对于视频相关插件（例如美颜插件），需要在启用视频模块（[EnableVideo](/zh-CN/api-reference/rtc/unreal-blueprint/video/video-basic#api_irtcengine_enablevideo) / [EnableLocalVideo](/zh-CN/api-reference/rtc/unreal-blueprint/video/video-basic#api_irtcengine_enablelocalvideo) ）之前调用该方法。
- 调用该方法前，需要先调用 [LoadExtensionProvider](/zh-CN/api-reference/rtc/unreal-blueprint/extension#api_irtcengine_loadextensionprovider) 加载插件。

<a id="api_irtcengine_registerextension__restriction"></a>

### 调用限制

- 如果要注册多个插件，需要多次调用该方法。
- 不同插件在 SDK 中处理数据的顺序由插件的注册顺序决定。即先注册的插件会先处理数据。

<a id="api_irtcengine_registerextension__parameters"></a>

### 参数

#### `provider`

提供插件的服务商名称。

#### `extension`

插件的名称。

#### `type`

插件的媒体源类型。详见 [EUABT_MEDIA_SOURCE_TYPE](/zh-CN/api-reference/rtc/unreal-blueprint/enum-mediasourcetype)。

<a id="api_irtcengine_registerextension__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。 详见 [错误码](/zh-CN/realtime-media/rtc/reference/error-code) 了解详情和解决建议。
  - -3: 该插件动态库没有被加载。声网推荐你检查该动态库是否存放在预期的位置，或该动态库名是否正确。

### 所属接口类
- [IRtcEngine](/zh-CN/api-reference/rtc/unreal-blueprint/rtc-interface-class#class_irtcengine)

## OnExtensionErrorWithContext

插件出错回调。

<a id="callback_irtcengineeventhandler_onextensionerrorwithcontext__prototype"></a>

```cpp
UFUNCTION(BlueprintNativeEvent, Category = "Agora|Event")
	void OnExtensionErrorWithContext(const FExtensionContext& context, int error, const FString& message);
```

<a id="callback_irtcengineeventhandler_onextensionerrorwithcontext__detailed_desc"></a>

启用插件失败或者插件运行出错时，插件会触发该回调并报告错误码和错误原因。

<a id="callback_irtcengineeventhandler_onextensionerrorwithcontext__parameters"></a>

### 参数

#### `context`

插件上下文信息，详见 [FExtensionContext](/zh-CN/api-reference/rtc/unreal-blueprint/class-extensioncontext)。

#### `error`

错误码。详见插件服务商提供的插件文档。

#### `message`

错误原因。详见插件服务商提供的插件文档。

### 所属接口类
- [IRtcEngineEventHandler](/zh-CN/api-reference/rtc/unreal-blueprint/rtc-interface-class#class_irtcengineeventhandler)
