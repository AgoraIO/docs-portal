## 枚举值

### `SUB_STATE_IDLE`

0: 加入频道后的初始订阅状态。

### `SUB_STATE_NO_SUBSCRIBED`

1: 订阅失败。可能是因为：

- 远端用户：

  - 调用 [MuteLocalAudioStream](/zh-CN/api-reference/rtc/unreal-blueprint/publishnsubscribe#api_irtcengine_mutelocalaudiostream) (`true`) 或 [MuteLocalVideoStream](/zh-CN/api-reference/rtc/unreal-blueprint/publishnsubscribe#api_irtcengine_mutelocalvideostream) (`true`) 停止发送本地媒体流。
  - 调用 [DisableAudio](/zh-CN/api-reference/rtc/unreal-blueprint/audio-basic#api_irtcengine_disableaudio) 或 [DisableVideo](/zh-CN/api-reference/rtc/unreal-blueprint/video-basic#api_irtcengine_disablevideo) 关闭本地音频或视频模块。
  - 调用 [EnableLocalAudio](/zh-CN/api-reference/rtc/unreal-blueprint/audio-capture#api_irtcengine_enablelocalaudio) (false) 或 [EnableLocalVideo](/zh-CN/api-reference/rtc/unreal-blueprint/video-basic#api_irtcengine_enablelocalvideo) (false) 关闭本地音频或视频采集。
  - 用户角色为观众。
- 本地用户调用以下方法停止接收远端媒体流：

  - 调用 [MuteRemoteAudioStream](/zh-CN/api-reference/rtc/unreal-blueprint/publishnsubscribe#api_irtcengine_muteremoteaudiostream) (`true`)、 [MuteAllRemoteAudioStreams](/zh-CN/api-reference/rtc/unreal-blueprint/publishnsubscribe#api_irtcengine_muteallremoteaudiostreams) (`true`) 停止接收远端音频流。
  - 调用 [MuteRemoteVideoStream](/zh-CN/api-reference/rtc/unreal-blueprint/publishnsubscribe#api_irtcengine_muteremotevideostream) (`true`)、 [MuteAllRemoteVideoStreams](/zh-CN/api-reference/rtc/unreal-blueprint/publishnsubscribe#api_irtcengine_muteallremotevideostreams) (`true`) 停止接收远端视频流。

### `SUB_STATE_SUBSCRIBING`

2: 正在订阅。

### `SUB_STATE_SUBSCRIBED`

3: 收到了远端流，订阅成功。
