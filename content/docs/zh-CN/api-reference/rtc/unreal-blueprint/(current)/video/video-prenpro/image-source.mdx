## EnableVideoImageSource

设置是否开启垫片推流功能。

<a id="api_irtcengine_enablevideoimagesource__prototype"></a>

```text
UFUNCTION(BlueprintCallable, Category = "Agora|IRtcEngine")
	int EnableVideoImageSource(bool enable, const FImageTrackOptions& options);
```

<a id="api_irtcengine_enablevideoimagesource__detailed_desc"></a>

在发布视频流时，你可以调用该方法使用自定义图片来替代当前发布的视频流画面进行推流。

开启该功能后，你可以通过 [FImageTrackOptions](/zh-CN/api-reference/rtc/unreal-blueprint/class-imagetrackoptions) 参数自定义垫片图片；在你关闭垫片功能之后，远端用户看到的依旧是当前你发布的视频流画面。

<a id="api_irtcengine_enablevideoimagesource__timing"></a>

### 调用时机

建议在加入频道后调用该方法。

<a id="api_irtcengine_enablevideoimagesource__restriction"></a>

### 调用限制

无。

<a id="api_irtcengine_enablevideoimagesource__parameters"></a>

### 参数

### enable

是否开启垫片推流：

- `true`：开启垫片推流。
- `false`：（默认）关闭垫片推流。

### options

垫片图片设置，详见 [FImageTrackOptions](/zh-CN/api-reference/rtc/unreal-blueprint/class-imagetrackoptions)。

<a id="api_irtcengine_enablevideoimagesource__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。
