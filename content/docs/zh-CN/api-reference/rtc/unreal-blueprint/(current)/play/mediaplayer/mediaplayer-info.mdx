## GetDuration

获取媒体文件总时长。

<a id="api_imediaplayer_getduration__prototype"></a>

```cpp

	int GetDuration(int64& duration);
```

<a id="api_imediaplayer_getduration__parameters"></a>

### 参数

#### `duration`

输出参数。媒体文件总时长（毫秒）。

<a id="api_imediaplayer_getduration__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。 详见 [错误码](https://doc.shengwang.cn/api-ref/rtc/unreal-blueprint/error-code) 了解详情和解决建议。

## GetPlayoutVolume

获取当前本地播放音量。

<a id="api_imediaplayer_getplayoutvolume__prototype"></a>

```cpp
UFUNCTION(BlueprintCallable, Category = "Agora|IMediaPlayer")
	int GetPlayoutVolume(int & volume);
```

<a id="api_imediaplayer_getplayoutvolume__parameters"></a>

### 参数

UFUNCTION(BlueprintCallable, Category = "Agora|IMediaPlayer")

### 详情

:::warning[注意]
请在 [Open](/zh-CN/api-reference/rtc/unreal-blueprint/play/mediaplayer/mediaplayer-open#api_imediaplayer_open) 后并收到 [OnPlayerSourceStateChanged](/zh-CN/api-reference/rtc/unreal-blueprint/play/mediaplayer/mediaplayer-observer#callback_imediaplayersourceobserver_onplayersourcestatechanged) 回调报告播放状态为 PLAYER_STATE_OPEN_COMPLETED 后再调用该方法。

<a id="api_imediaplayer_getstreamcount__parameters"></a>

### 参数

#### `count`

输出参数。当前媒体文件中媒体流的数量。

<a id="api_imediaplayer_getstreamcount__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败，详见 [FENUMWRAP_MEDIA_PLAYER_REASON](/zh-CN/api-reference/rtc/unreal-blueprint/enum-mediaplayerreason)。

- [IMediaPlayer](/zh-CN/api-reference/rtc/unreal-blueprint/rtc-interface-class#class_imediaplayer)

## GetStreamInfo

通过媒体流的索引值获取媒体流信息。

<a id="api_imediaplayer_getstreaminfo__prototype"></a>

```cpp
UFUNCTION(BlueprintCallable, Category = "Agora|IMediaPlayer")
	int GetStreamInfo(int64 index, FPlayerStreamInfo& info);
```

<a id="api_imediaplayer_getstreaminfo__detailed_desc"></a>

<a id="api_imediaplayer_getstreaminfo__timing"></a>

### 调用时机

你需要在 [GetStreamCount](/zh-CN/api-reference/rtc/unreal-blueprint/play/mediaplayer/mediaplayer-info#api_imediaplayer_getstreamcount) 后调用该方法。

<a id="api_imediaplayer_getstreaminfo__restriction"></a>

### 调用限制

无。

<a id="api_imediaplayer_getstreaminfo__parameters"></a>

### 参数

#### `index`

媒体流索引值。该参数需小于 [GetStreamCount](/zh-CN/api-reference/rtc/unreal-blueprint/play/mediaplayer/mediaplayer-info#api_imediaplayer_getstreamcount) 的 count 参数。

#### `info`

输出参数。媒体流的所有信息，详见 [FPlayerStreamInfo](/zh-CN/api-reference/rtc/unreal-blueprint/class-playerstreaminfo)。

<a id="api_imediaplayer_getstreaminfo__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。 详见 [错误码](https://doc.shengwang.cn/api-ref/rtc/unreal-blueprint/error-code) 了解详情和解决建议。

- [IMediaPlayer](/zh-CN/api-reference/rtc/unreal-blueprint/rtc-interface-class#class_imediaplayer)

<a id="callback_imediaplayersourceobserver_onplayerplaybackstats"></a>

## OnPlayerPlaybackStats

报告当前播放的媒体资源的相关信息。

<a id="callback_imediaplayersourceobserver_onplayerplaybackstats__prototype"></a>

```cpp
UFUNCTION(BlueprintNativeEvent, Category = "Agora|Event")
	void OnPlayerPlaybackStats(const FPlayerPlaybackStats& stats);
```

<a id="callback_imediaplayersourceobserver_onplayerplaybackstats__detailed_desc"></a>

### 详情

当媒体资源开始播放后，SDK 会每秒触发一次该回调，报告媒体资源的相关信息。

<a id="callback_imediaplayersourceobserver_onplayerplaybackstats__parameters"></a>

### 参数

#### `stats`

媒体资源的相关信息，详见 [FPlayerPlaybackStats](/zh-CN/api-reference/rtc/unreal-blueprint/class-playerplaybackstats)。

- [IMediaPlayerSourceObserver](/zh-CN/api-reference/rtc/unreal-blueprint/rtc-interface-class#class_imediaplayersourceobserver)
