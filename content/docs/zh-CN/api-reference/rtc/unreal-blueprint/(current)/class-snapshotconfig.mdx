<a id="class_snapshotconfig__prototype"></a>

```cpp
USTRUCT(BlueprintType)
struct FUABT_SnapshotConfig {

	GENERATED_BODY()

public:

	UPROPERTY(VisibleAnywhere, BlueprintReadWrite)
	FString filePath;

	UPROPERTY(VisibleAnywhere, BlueprintReadWrite)
	EUABT_VIDEO_MODULE_POSITION position = EUABT_VIDEO_MODULE_POSITION::POSITION_PRE_ENCODER;
};
```

<a id="class_snapshotconfig__parameters"></a>

## 属性

### `filePath`

截图的本地保存路径，需精确到文件名及格式，例如：

- Windows: C:\\Users\\&lt;user_name&gt;\\AppData\\Local\\Agora\\&lt;process_name&gt;\\example.jpg
- iOS: /App Sandbox/Library/Caches/example.jpg
- macOS: ～/Library/Logs/example.jpg
- Android: /storage/emulated/0/Android/data/&lt;package name&gt;/files/example.jpg

:::warning[注意]
请确保目录存在且可写。
:::

### `position`

截图的视频帧在视频链路中的位置。详见 [EUABT_VIDEO_MODULE_POSITION](/zh-CN/api-reference/rtc/unreal-blueprint/enum-videomoduleposition)。
