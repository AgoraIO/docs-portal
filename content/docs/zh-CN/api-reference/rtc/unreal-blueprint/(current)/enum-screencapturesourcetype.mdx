## 枚举值

### `ScreenCaptureSourceType_Unknown`

-1：未知。

### `ScreenCaptureSourceType_Window`

0：共享目标为某一个窗口。

### `ScreenCaptureSourceType_Screen`

1：共享目标为某一个显示器的屏幕。

### `ScreenCaptureSourceType_Custom`

2：预留参数。
