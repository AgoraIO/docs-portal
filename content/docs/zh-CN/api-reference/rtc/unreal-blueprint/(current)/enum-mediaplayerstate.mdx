## 枚举值

### `PLAYER_STATE_IDLE`

0: 默认状态。播放器会在你打开媒体文件之前和结束播放之后返回该状态码。

### `PLAYER_STATE_OPENING`

1: 正在打开媒体文件。

### `PLAYER_STATE_OPEN_COMPLETED`

2: 成功打开媒体文件。

### `PLAYER_STATE_PLAYING`

3: 正在播放。

### `PLAYER_STATE_PAUSED`

4: 暂停播放。

### `PLAYER_STATE_PLAYBACK_COMPLETED`

5: 播放完毕。

### `PLAYER_STATE_PLAYBACK_ALL_LOOPS_COMPLETED`

6: 循环播放已结束。

### `PLAYER_STATE_STOPPED`

7: 播放已停止。

### `PLAYER_STATE_FAILED`

100: 播放失败。
