<a id="api_irtcengine_setfaceshapeareaoptions__prototype"></a>

```csharp
public abstract int SetFaceShapeAreaOptions(FaceShapeAreaOptions options, MEDIA_SOURCE_TYPE type = MEDIA_SOURCE_TYPE.PRIMARY_CAMERA_SOURCE);
```

<a id="api_irtcengine_setfaceshapeareaoptions__detailed_desc"></a>

如果在 [SetFaceShapeBeautyOptions](/zh-CN/api-reference/rtc/csharp-windows/api-irtcengine-setfaceshapebeautyoptions) 方法中实现的预设美型效果达不到预期，你可以通过该方法设置美型部位选项，对人脸的各个部位单独微调，实现更加精细的美型效果。

:::error[危险]
美型属于增值服务，计费方式详见 [计费说明](https://doc.shengwang.cn/doc/rtc/android/billing/billing-strategy)。
:::

<a id="api_irtcengine_setfaceshapeareaoptions__timing"></a>

## 调用时机

请在 [SetFaceShapeBeautyOptions](/zh-CN/api-reference/rtc/csharp-windows/api-irtcengine-setfaceshapebeautyoptions) 之后调用该方法。

<a id="api_irtcengine_setfaceshapeareaoptions__restriction"></a>

## 调用限制

- 该方法依赖于视频增强动态库 libagora_clear_vision_extension.dll，如果删除该动态库会导致无法正常开启该功能。
- 该功能对设备性能要求较高，调用该方法时 SDK 会自动对当前设备能力进行检查。

<a id="api_irtcengine_setfaceshapeareaoptions__parameters"></a>

## 参数

### `options`

美型部位选项，详见 [FaceShapeAreaOptions](/zh-CN/api-reference/rtc/csharp-windows/class-faceshapeareaoptions)。

### `type`

效果应用的媒体源类型。详见 [MEDIA_SOURCE_TYPE](/zh-CN/api-reference/rtc/csharp-windows/enum-mediasourcetype)。

:::warning[注意]
在该方法中，该参数仅支持以下两种设置：

- 使用摄像头采集本地视频时，请保持默认值 PRIMARY_CAMERA_SOURCE。
- 如果要使用自定义采集的视频，将该参数设置为 CUSTOM_VIDEO_SOURCE。
:::

<a id="api_irtcengine_setfaceshapeareaoptions__return_values"></a>

## 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。 详见 [错误码](https://doc.shengwang.cn/api-ref/rtc/unity/error-code) 了解详情和解决建议。
  - -4：当前设备不支持该功能，可能的原因有：
    - 当前设备能力不满足美颜的使用要求，建议更换性能更高的设备。
