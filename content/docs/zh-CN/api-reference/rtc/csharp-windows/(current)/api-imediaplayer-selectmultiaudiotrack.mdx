<a id="api_imediaplayer_selectmultiaudiotrack__detailed_desc"></a>

## 详情

你可以调用该方法分别设置本地播放和发送到远端的音轨。

在调用该方法前，你需要通过 [OpenWithMediaSource](/zh-CN/api-reference/rtc/csharp-windows/play/mediaplayer/mediaplayer-open#api_imediaplayer_openwithmediasource) 来打开媒体文件，并通过 [MediaSource](/zh-CN/api-reference/rtc/csharp-windows/class-mediasource) 将 enableMultiAudioTrack 设为 `true`。

<a id="api_imediaplayer_selectmultiaudiotrack__scenario"></a>

## 适用场景

在 K 歌场景下，主播可以根据需求选择在本地播放一路音轨（如原声），然后发送另一路音轨至远端（如伴唱）以提升听众体验。

<a id="api_imediaplayer_selectmultiaudiotrack__parameters"></a>

## 参数

### playoutTrackIndex

用于本地播放的音轨索引。你可以通过 [GetStreamInfo](/zh-CN/api-reference/rtc/csharp-windows/play/mediaplayer/mediaplayer-info#api_imediaplayer_getstreaminfo) 来获取索引值。

### publishTrackIndex

用于发送至远端的音轨索引。你可以通过 [GetStreamInfo](/zh-CN/api-reference/rtc/csharp-windows/play/mediaplayer/mediaplayer-info#api_imediaplayer_getstreaminfo) 来获取索引值。

<a id="api_imediaplayer_selectmultiaudiotrack__return_values"></a>

## 返回值

- &lt; 0: 方法调用失败。
