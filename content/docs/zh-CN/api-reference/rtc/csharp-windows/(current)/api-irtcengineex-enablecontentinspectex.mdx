<a id="api_irtcengineex_enablecontentinspectex__prototype"></a>

```csharp
public abstract int EnableContentInspectEx(bool enabled, ContentInspectConfig config, RtcConnection connection);
```

<a id="api_irtcengineex_enablecontentinspectex__detailed_desc"></a>

该方法可以对多条视频流截图并上传。开启本地截图上传后，SDK 会根据你在 [ContentInspectConfig](/zh-CN/api-reference/rtc/csharp-windows/class-contentinspectconfig) 中设置的模块类型和频率对本地用户发送的视频进行截图和上传。截图完成后，声网服务器会以 HTTPS 请求的形式，向你的服务器发送回调通知，并将所有截图发送至你指定的第三方云存储。

<a id="api_irtcengineex_enablecontentinspectex__timing"></a>

## 调用时机

加入频道前后均可调用。

<a id="api_irtcengineex_enablecontentinspectex__restriction"></a>

## 调用限制

调用该方法前，请确保已 [联系技术支持](https://ticket.shengwang.cn/) 开通本地截图上传服务。

<a id="api_irtcengineex_enablecontentinspectex__parameters"></a>

## 参数

### `enabled`

设置是否开启本地截图上传：

- true：开启本地截图上传。
- false：关闭本地截图上传。

### `config`

本地截图上传配置。详见 [ContentInspectConfig](/zh-CN/api-reference/rtc/csharp-windows/class-contentinspectconfig)。

### `connection`

Connection 信息。详见 [RtcConnection](/zh-CN/api-reference/rtc/csharp-windows/class-rtcconnection)。

<a id="api_irtcengineex_enablecontentinspectex__return_values"></a>

## 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。 详见 [错误码](https://doc.shengwang.cn/api-ref/rtc/unity/error-code) 了解详情和解决建议。
