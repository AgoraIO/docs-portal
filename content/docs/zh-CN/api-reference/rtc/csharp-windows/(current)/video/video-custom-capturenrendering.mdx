## CreateCustomVideoTrack

创建一个自定义的视频轨道。

<a id="api_irtcengine_createcustomvideotrack__prototype"></a>

```text
public abstract video_track_id_t CreateCustomVideoTrack();
```

<a id="api_irtcengine_createcustomvideotrack__detailed_desc"></a>

### 详情

当你需要在频道中发布自定义采集视频时，可参考以下步骤：

1. 调用该方法创建视频轨道并获得视频轨道 ID。
2. 调用 [JoinChannel [2/2]](/zh-CN/api-reference/rtc/csharp-windows/channel#api_irtcengine_joinchannel2) 加入频道时，将 [ChannelMediaOptions](/zh-CN/api-reference/rtc/csharp-windows/class-channelmediaoptions) 中的 customVideoTrackId 设置为你想要发布的视频轨道 ID，并将 publishCustomVideoTrack 设置为 `true`。
3. 调用 [PushVideoFrame](/zh-CN/api-reference/rtc/csharp-windows/video/video-custom-capturenrendering#api_imediaengine_pushvideoframe) 将 videoTrackId 指定为步骤 2 中指定的视频轨道 ID，即可实现在频道内发布对应的自定义视频源。

<a id="api_irtcengine_createcustomvideotrack__return_values"></a>

### 返回值

- 方法调用成功，返回视频轨道 ID 作为该视频轨道的唯一标识。
- 方法调用失败，返回 0xffffffff。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。

## PushVideoFrame

将外部原始视频帧通过自定义视频轨道发布到频道中。

<a id="api_imediaengine_pushvideoframe__prototype"></a>

```text
public abstract int PushVideoFrame(ExternalVideoFrame frame, uint videoTrackId = 0);
```

<a id="api_imediaengine_pushvideoframe__detailed_desc"></a>

### 详情

<a id="api_imediaengine_pushvideoframe__desc1"></a>

当你需要在频道中发布自定义采集视频时，可参考以下步骤：

1. 调用 [CreateCustomVideoTrack](/zh-CN/api-reference/rtc/csharp-windows/video/video-custom-capturenrendering#api_irtcengine_createcustomvideotrack) 方法创建视频轨道并获得视频轨道 ID。

   :::note
   注： 如果你只需推送一路自定义采集的视频流到频道中，可以直接调用 [SetExternalVideoSource](/zh-CN/api-reference/rtc/csharp-windows/video/video-custom-capturenrendering#api_imediaengine_setexternalvideosource) 方法启用外部视频源，此时 SDK 会自动创建一个 videoTrackId 为 0 的视频轨道。
   :::
2. 调用 [JoinChannel [2/2]](/zh-CN/api-reference/rtc/csharp-windows/channel#api_irtcengine_joinchannel2) 加入频道时，将 [ChannelMediaOptions](/zh-CN/api-reference/rtc/csharp-windows/class-channelmediaoptions) 中的 customVideoTrackId 设置为你想要发布的视频轨道 ID，并将 publishCustomVideoTrack 设置为 `true`。
3. 调用该方法将 videoTrackId 指定为步骤 2 中指定的视频轨道 ID，即可实现在频道内发布对应的自定义视频源。

<a id="api_imediaengine_pushvideoframe__desc2"></a>

:::error
危险： 调用该方法后，即使你停止推送外部视频帧到 SDK，自定义采集的视频流仍然会被计入视频时长用量并产生费用，声网建议你根据实际情况采取相应措施避免此类视频计费：

- 如果你不再需要采集外部视频数据，可以调用 [DestroyCustomVideoTrack](/zh-CN/api-reference/rtc/csharp-windows/video/video-custom-capturenrendering#api_irtcengine_destroycustomvideotrack) 销毁自定义采集的视频轨道。
- 如果你只想将采集到的外部视频数据用于本地预览、而不在频道内发布，可以调用 [MuteLocalVideoStream](/zh-CN/api-reference/rtc/csharp-windows/publishnsubscribe#api_irtcengine_mutelocalvideostream) 取消发送视频流，或调用 [UpdateChannelMediaOptions](/zh-CN/api-reference/rtc/csharp-windows/channel#api_irtcengine_updatechannelmediaoptions) 将 publishCustomVideoTrack 设置为 `false`。
:::

<a id="api_imediaengine_pushvideoframe__parameters"></a>

### 参数

### frame

待推送的视频帧。详见 [ExternalVideoFrame](/zh-CN/api-reference/rtc/csharp-windows/class-externalvideoframe)。

### videoTrackId

调用 CreateCustomVideoTrack 方法返回的视频轨道 ID。

:::note
注： 如果你只需推送一路外部视频流，videoTrackId 设置为 0 即可。
:::

<a id="api_imediaengine_pushvideoframe__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。

## SetExternalVideoSource

设置外部视频源。

<a id="api_imediaengine_setexternalvideosource__prototype"></a>

```text
public abstract int SetExternalVideoSource(bool enabled, bool useTexture, EXTERNAL_VIDEO_SOURCE_TYPE sourceType, SenderOptions encodedVideoOption);
```

<a id="api_imediaengine_setexternalvideosource__detailed_desc"></a>

调用该方法启用外部视频源后，你可以调用 [PushVideoFrame](/zh-CN/api-reference/rtc/csharp-windows/video/video-custom-capturenrendering#api_imediaengine_pushvideoframe) 向 SDK 推送外部视频数据。

<a id="api_imediaengine_setexternalvideosource__timing"></a>

### 调用时机

该方法需要在加入频道前调用。

<a id="api_imediaengine_setexternalvideosource__restriction"></a>

### 调用限制

不支持在频道内动态切换视频源。如果已调用该方法启用外部视频源并加入频道，若想切换为内部视频源，必须先退出频道，然后调用该方法关闭外部视频源，再重新加入频道。

<a id="api_imediaengine_setexternalvideosource__parameters"></a>

### 参数

### enabled

是否启用外部视频源：

- `true`: 启用外部视频源。SDK 准备接收外部视频帧。
- `false`:（默认）不启用外部视频源。

### useTexture

是否使用 Texture 格式的外部视频帧：

- `true`: 使用 Texture 格式的外部视频帧。
- `false`: 不使用 Texture 格式的外部视频帧。

### sourceType

外部视频帧是否编码，详见 [EXTERNAL_VIDEO_SOURCE_TYPE](/zh-CN/api-reference/rtc/csharp-windows/enum-externalvideosourcetype)。

### encodedVideoOption

视频编码选项。如果 sourceType 为 ENCODED_VIDEO_FRAME，则需要设置该参数。你可以[联系技术支持](https://ticket.shengwang.cn/)了解如何设置该参数。

<a id="api_imediaengine_setexternalvideosource__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。
