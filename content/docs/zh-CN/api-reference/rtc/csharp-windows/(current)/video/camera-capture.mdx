## StartCameraCapture

开始通过摄像头采集视频。

<a id="api_irtcengine_startcameracapture__prototype"></a>

```csharp
public abstract int StartCameraCapture(VIDEO_SOURCE_TYPE sourceType, CameraCapturerConfiguration config);
```

<a id="api_irtcengine_startcameracapture__detailed_desc"></a>

### 详情

调用该方法可以通过指定 sourceType 同时开启多路摄像头采集。

<a id="api_irtcengine_startcameracapture__parameters"></a>

### 参数

#### `sourceType`

视频源的类型。详见 [VIDEO_SOURCE_TYPE](/zh-CN/api-reference/rtc/csharp-windows/enum-videosourcetype)。

:::info[注]
- 桌面端最多支持 4 路摄像头采集的视频流。
:::

#### `config`

视频采集配置。详见 [CameraCapturerConfiguration](/zh-CN/api-reference/rtc/csharp-windows/class-cameracapturerconfiguration)。

<a id="api_irtcengine_startcameracapture__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。 详见 [错误码](/zh-CN/realtime-media/rtc/reference/error-code) 了解详情和解决建议。

### 所属接口类
- [IRtcEngine](/zh-CN/api-reference/rtc/csharp-windows/rtc-interface-class#class_irtcengine)

## StopCameraCapture

停止通过摄像头采集视频。

<a id="api_irtcengine_stopcameracapture__prototype"></a>

```csharp
public abstract int StopCameraCapture(VIDEO_SOURCE_TYPE sourceType);
```

<a id="api_irtcengine_stopcameracapture__detailed_desc"></a>

### 详情

调用 [StartCameraCapture](/zh-CN/api-reference/rtc/csharp-windows/video/camera-capture#api_irtcengine_startcameracapture) 开启一路或多路摄像头采集的视频流后，你可以调用该方法，通过设置 sourceType 停止一路或多路摄像头的视频采集。

:::warning[注意]
如果你正在使用本地合图功能，调用该方法停止通过第一个摄像头采集视频，会造成本地合图中断。
:::

<a id="api_irtcengine_stopcameracapture__parameters"></a>

### 参数

#### `sourceType`

视频源的类型，详见 [VIDEO_SOURCE_TYPE](/zh-CN/api-reference/rtc/csharp-windows/enum-videosourcetype)。

<a id="api_irtcengine_stopcameracapture__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。 详见 [错误码](/zh-CN/realtime-media/rtc/reference/error-code) 了解详情和解决建议。

### 所属接口类
- [IRtcEngine](/zh-CN/api-reference/rtc/csharp-windows/rtc-interface-class#class_irtcengine)
