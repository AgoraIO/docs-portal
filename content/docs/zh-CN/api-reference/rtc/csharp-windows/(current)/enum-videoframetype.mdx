## 枚举值

### `VIDEO_FRAME_TYPE_BLANK_FRAME`

0: 黑帧。

### `VIDEO_FRAME_TYPE_KEY_FRAME`

3: 关键帧。

### `VIDEO_FRAME_TYPE_DELTA_FRAME`

4: Delta 帧。

### `VIDEO_FRAME_TYPE_B_FRAME`

5: B 帧。

### `VIDEO_FRAME_TYPE_DROPPABLE_FRAME`

6: 丢弃帧。

### `VIDEO_FRAME_TYPE_UNKNOW`

未知帧。
