该方法仅适用于 macOS。

<a id="api_iaudiodevicemanager_getplaybackdeviceinfo2__parameters"></a>

## 参数

### `deviceId`

输出参数，播放设备的设备 ID。

### `deviceName`

输出参数，播放设备的设备名称。

### `deviceTypeName`

输出参数，音频播放设备类型，如：built-in、USB、HDMI 等。
