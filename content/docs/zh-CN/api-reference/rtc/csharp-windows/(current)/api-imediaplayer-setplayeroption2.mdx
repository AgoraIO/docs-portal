```text
public abstract int SetPlayerOption(string key, string value);
```

<a id="api_imediaplayer_setplayeroption2__detailed_desc"></a>

媒体播放器支持通过 key 和 value 来设置选项。

该方法和 [SetPlayerOption [1/2]](/zh-CN/api-reference/rtc/csharp-windows/api-imediaplayer-setplayeroption) 的区别在于，该方法的 value 是 String 型，SetPlayerOption [1/2] 的 value 是 Int 型。二者不可混用。

<a id="api_imediaplayer_setplayeroption2__scenario"></a>

## 适用场景

需要提供技术预览或特别定制功能的场景。一般情况下，你无需调用该方法，使用媒体播放器默认的选项设置即可。
