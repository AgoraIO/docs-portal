<a id="api_irtcengine_setfaceshapebeautyoptions__prototype"></a>

```csharp
public abstract int SetFaceShapeBeautyOptions(bool enabled, FaceShapeBeautyOptions options, MEDIA_SOURCE_TYPE type = MEDIA_SOURCE_TYPE.PRIMARY_CAMERA_SOURCE);
```

<a id="api_irtcengine_setfaceshapebeautyoptions__detailed_desc"></a>

调用该方法可对人脸各部位进行修饰，使用预设的参数一次性实现瘦脸、大眼、瘦鼻等微整形效果，支持微调整体的修饰力度。

:::error[危险]
美型属于增值服务，计费方式详见 [计费说明](https://doc.shengwang.cn/doc/rtc/android/billing/billing-strategy)。
:::

<a id="api_irtcengine_setfaceshapebeautyoptions__timing"></a>

## 调用时机

请在 [EnableVideo](/zh-CN/api-reference/rtc/csharp-windows/video/video-basic#api_irtcengine_enablevideo) 之后调用该方法。

<a id="api_irtcengine_setfaceshapebeautyoptions__restriction"></a>

## 调用限制

- 该方法依赖于视频增强动态库 libagora_clear_vision_extension.dll，如果删除该动态库会导致无法正常开启该功能。
- 该功能对设备性能要求较高，调用该方法时 SDK 会自动对当前设备能力进行检查。

<a id="api_irtcengine_setfaceshapebeautyoptions__parameters"></a>

## 参数

### `enabled`

是否开启美型效果：

- true: 开启美型功能。
- false:（默认）关闭美型功能。

### `options`

美型风格选项，详见 [FaceShapeBeautyOptions](/zh-CN/api-reference/rtc/csharp-windows/class-faceshapebeautyoptions)。

### `type`

效果应用的媒体源类型。详见 [MEDIA_SOURCE_TYPE](/zh-CN/api-reference/rtc/csharp-windows/enum-mediasourcetype)。

:::warning[注意]
在该方法中，该参数仅支持以下两种设置：

- 使用摄像头采集本地视频时，请保持默认值 PRIMARY_CAMERA_SOURCE。
- 如果要使用自定义采集的视频，将该参数设置为 CUSTOM_VIDEO_SOURCE。
:::

<a id="api_irtcengine_setfaceshapebeautyoptions__return_values"></a>

## 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。 详见 [错误码](/zh-CN/realtime-media/rtc/reference/error-code) 了解详情和解决建议。
  - -4：当前设备不支持该功能，可能的原因有：
    - 当前设备能力不满足美颜的使用要求，建议更换性能更高的设备。
