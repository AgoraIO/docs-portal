<a id="api_irtcengine_querycamerafocallengthcapability__detailed_desc"></a>

## 详情

如需开启摄像头广角、超广角拍摄模式，建议你先调用该方法查询设备是否具备相应的焦距能力，再根据查询结果调用 `SetCameraCapturerConfiguration` 调整摄像头的焦距配置，以达到最佳的摄像头采集效果。
