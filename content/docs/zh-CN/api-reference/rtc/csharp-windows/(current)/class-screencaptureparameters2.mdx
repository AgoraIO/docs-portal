<a id="class_screencaptureparameters2__prototype"></a>

```csharp
public class ScreenCaptureParameters2
    {
        public bool captureAudio { set; get; }
        public ScreenAudioParameters audioParams { set; get; }
        public bool captureVideo { set; get; }
        public ScreenVideoParameters videoParams { set; get; }

        public ScreenCaptureParameters2()
        {
            captureAudio = false;
            audioParams = new ScreenAudioParameters();
            captureAudio = true;
            videoParams = new ScreenVideoParameters();
        }
    };
```

<a id="class_screencaptureparameters2__detailed_desc"></a>

<a id="class_screencaptureparameters2__parameters"></a>

## 属性

### `captureAudio`

屏幕共享时是否采集系统音频：

- `true`: 采集系统音频。
- `false`: （默认）不采集系统音频。

:::info[注]
- 为提高屏幕共享时采集系统音频的成功率，请确保你已调用 [SetAudioScenario](/zh-CN/api-reference/rtc/csharp-windows/audio-basic#api_irtcengine_setaudioscenario) 方法并设置音频场景为 `AUDIO_SCENARIO_GAME_STREAMING`。
:::

### `audioParams`

共享屏幕流的音频配置。详见 [ScreenAudioParameters](/zh-CN/api-reference/rtc/csharp-windows/class-screenaudioparameters)。

:::warning[注意]
该参数仅在 captureAudio 为 `true` 时生效。
:::

### `captureVideo`

屏幕共享时是否采集屏幕：

- `true`:（默认）采集屏幕。
- `false`: 不采集屏幕。

### `videoParams`

共享屏幕流的视频编码配置。详见 [ScreenVideoParameters](/zh-CN/api-reference/rtc/csharp-windows/class-screenvideoparameters)。

:::warning[注意]
该参数仅在 captureVideo 为 `true` 时生效。
:::
