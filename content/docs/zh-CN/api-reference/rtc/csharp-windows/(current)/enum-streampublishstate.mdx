## 枚举值

### `PUB_STATE_IDLE`

0: 加入频道后的初始发布状态。

### `PUB_STATE_NO_PUBLISHED`

1: 发布失败。可能是因为：

- 本地用户调用 [MuteLocalAudioStream](/zh-CN/api-reference/rtc/csharp-windows/publishnsubscribe#api_irtcengine_mutelocalaudiostream) (`true`) 或 [MuteLocalVideoStream](/zh-CN/api-reference/rtc/csharp-windows/publishnsubscribe#api_irtcengine_mutelocalvideostream) (`true`) 停止发送本地媒体流。
- 本地用户调用 [DisableAudio](/zh-CN/api-reference/rtc/csharp-windows/audio-basic#api_irtcengine_disableaudio) 或 [DisableVideo](/zh-CN/api-reference/rtc/csharp-windows/video-basic#api_irtcengine_disablevideo) 关闭本地音频或视频模块。
- 本地用户调用 [EnableLocalAudio](/zh-CN/api-reference/rtc/csharp-windows/audio-capture#api_irtcengine_enablelocalaudio) (`false`) 或 [EnableLocalVideo](/zh-CN/api-reference/rtc/csharp-windows/video-basic#api_irtcengine_enablelocalvideo) (`false`) 关闭本地音频或视频采集。
- 本地用户角色为观众。

### `PUB_STATE_PUBLISHING`

2: 正在发布。

### `PUB_STATE_PUBLISHED`

3: 发布成功。
