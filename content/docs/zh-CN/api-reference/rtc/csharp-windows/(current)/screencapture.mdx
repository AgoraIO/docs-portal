## GetScreenCaptureSources

获取可共享的屏幕和窗口对象列表。

<a id="api_irtcengine_getscreencapturesources__prototype"></a>

```csharp
public abstract ScreenCaptureSourceInfo[] GetScreenCaptureSources(SIZE thumbSize, SIZE iconSize, bool includeScreen);
```

<a id="api_irtcengine_getscreencapturesources__detailed_desc"></a>

### 详情

屏幕共享或窗口共享前，你可以调用该方法获取可共享的屏幕和窗口的对象列表，方便用户通过列表中的缩略图选择共享某个显示器的屏幕或某个窗口。列表中包含窗口 ID 和屏幕 ID 等重要信息，你可以获取到 ID 后再调用 [StartScreenCaptureByWindowId](/zh-CN/api-reference/rtc/csharp-windows/screencapture#api_irtcengine_startscreencapturebywindowid) 或 [StartScreenCaptureByDisplayId](/zh-CN/api-reference/rtc/csharp-windows/screencapture#api_irtcengine_startscreencapturebydisplayid) 开启共享。

<a id="api_irtcengine_getscreencapturesources__parameters"></a>

### 参数

#### `thumbSize`

屏幕或窗口的缩略图的目标尺寸（宽高单位为像素）。 SDK 会在保证原图不变形的前提下，缩放原图，使图片最长边和目标尺寸的最长边的长度一致。例如，原图宽高为 400 × 300， thumbSize 为 100 x 100，缩略图实际尺寸为 100 × 75。如果目标尺寸大于原图尺寸，缩略图即为原图，SDK 不进行缩放操作。

#### `iconSize`

程序所对应的图标的目标尺寸（宽高单位为像素）。 SDK 会在保证原图不变形的前提下，缩放原图，使图片最长边和目标尺寸的最长边的长度一致。例如，原图宽高为 400 × 300， iconSize 为 100 × 100，图标实际尺寸为 100 × 75。如果目标尺寸大于原图尺寸，图标即为原图，SDK 不进行缩放操作。

#### `includeScreen`

除了窗口信息外，SDK 是否返回屏幕信息：

- `true`：SDK 返回屏幕和窗口信息。
- `false`：SDK 仅返回窗口信息。

<a id="api_irtcengine_getscreencapturesources__return_values"></a>

### 返回值

[ScreenCaptureSourceInfo](/zh-CN/api-reference/rtc/csharp-windows/class-screencapturesourceinfo) 数组。

## QueryScreenCaptureCapability

查询设备在屏幕共享时支持的最高帧率。

<a id="api_irtcengine_queryscreencapturecapability__prototype"></a>

```csharp
public abstract int QueryScreenCaptureCapability();
```

<a id="api_irtcengine_queryscreencapturecapability__detailed_desc"></a>

### 详情

<a id="api_irtcengine_queryscreencapturecapability__scenario"></a>

### 适用场景

在屏幕共享场景下，如果你想启用高帧率（如 60 fps）、但不确定设备是否支持时，可以先调用该方法查询设备支持的最高帧率。如果设备不支持高帧率，你可以在开启屏幕共享时适当调低屏幕共享流的帧率，以确保共享场景的效果符合预期。

<a id="api_irtcengine_queryscreencapturecapability__return_values"></a>

### 返回值

- 方法调用成功时，返回设备支持的最高帧率。 详见 SCREEN_CAPTURE_FRAMERATE_CAPABILITY。
- &lt;0：方法调用失败。 详见 [错误码](https://doc.shengwang.cn/api-ref/rtc/unity/error-code) 了解详情和解决建议。

## SetScreenCaptureContentHint

设置屏幕共享内容类型。

<a id="api_irtcengine_setscreencapturecontenthint__prototype"></a>

```csharp
public abstract int SetScreenCaptureContentHint(VIDEO_CONTENT_HINT contentHint);
```

<a id="api_irtcengine_setscreencapturecontenthint__detailed_desc"></a>

### 详情

SDK 会根据不同的内容类型，使用不同的算法对共享效果进行优化。如果不调用该方法，SDK 会将屏幕共享的内容默认为 CONTENT_HINT_NONE，即无指定的内容类型。

:::warning[注意]
该方法在开始屏幕共享前后都能调用。
:::

<a id="api_irtcengine_setscreencapturecontenthint__parameters"></a>

### 参数

#### `contentHint`

屏幕共享的内容类型。详见 [VIDEO_CONTENT_HINT](/zh-CN/api-reference/rtc/csharp-windows/enum-videocontenthint)。

<a id="api_irtcengine_setscreencapturecontenthint__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。 详见 [错误码](https://doc.shengwang.cn/api-ref/rtc/unity/error-code) 了解详情和解决建议。

  - -2：传入的参数无效。
  - -8：屏幕共享状态无效。可能因为你已经共享了其他屏幕或窗口。尝试调用 [StopScreenCapture [1/2]](/zh-CN/api-reference/rtc/csharp-windows/screencapture#api_irtcengine_stopscreencapture) 停止当前共享，再重新开始共享屏幕。

### 所属接口类
- [IRtcEngine](/zh-CN/api-reference/rtc/csharp-windows/rtc-interface-class#class_irtcengine)

## StartScreenCapture [2/2]

开始屏幕采集并指定视频源。

<a id="api_irtcengine_startscreencapture2__prototype"></a>

```csharp
public abstract int StartScreenCapture(VIDEO_SOURCE_TYPE sourceType, ScreenCaptureConfiguration config);
```

<a id="api_irtcengine_startscreencapture2__detailed_desc"></a>

:::warning[注意]
该方法仅适用于 macOS 和 Windows 平台。
:::

<a id="api_irtcengine_startscreencapture2__scenario"></a>

### 适用场景

在屏幕共享场景下，你需要调用该方法开始采集屏幕视频流。

SDK 支持一系列开启屏幕采集的方法，它们之间存在以下区别，请根据实际场景选用：

- [StartScreenCaptureByDisplayId](/zh-CN/api-reference/rtc/csharp-windows/screencapture#api_irtcengine_startscreencapturebydisplayid) / [StartScreenCaptureByWindowId](/zh-CN/api-reference/rtc/csharp-windows/screencapture#api_irtcengine_startscreencapturebywindowid)：仅支持采集单个屏幕或窗口，适合仅共享单个屏幕的场景。
- [StartScreenCapture [2/2]](/zh-CN/api-reference/rtc/csharp-windows/screencapture#api_irtcengine_startscreencapture2)：支持指定多个视频源，以采集多路屏幕共享流，用于本地合图或者多频道发布场景。

<a id="api_irtcengine_startscreencapture2__timing"></a>

### 调用时机

该方法在加入频道前后均可调用，区别如下：

- 如果在加入频道前调用该方法，然后调用 [JoinChannel [2/2]](/zh-CN/api-reference/rtc/csharp-windows/channel#api_irtcengine_joinchannel2) 加入频道，并设置 publishScreenCaptureVideo 为 `true`，即可开始屏幕共享。
- 如果在加入频道后调用该方法，然后调用 [UpdateChannelMediaOptions](/zh-CN/api-reference/rtc/csharp-windows/channel#api_irtcengine_updatechannelmediaoptions) 更新频道媒体选项，并设置 publishScreenCaptureVideo 为 `true`，即可开始屏幕共享。

<a id="api_irtcengine_startscreencapture2__restriction"></a>

### 调用限制

- 如果调用该方法开始屏幕采集，则停止屏幕采集时需要调用 [StopScreenCapture [2/2]](/zh-CN/api-reference/rtc/csharp-windows/screencapture#api_irtcengine_stopscreencapture2)。
- 在 Windows 平台上，最多支持 4 路屏幕采集的视频流。

<a id="api_irtcengine_startscreencapture2__parameters"></a>

### 参数

#### `sourceType`

视频源的类型，详见 [VIDEO_SOURCE_TYPE](/zh-CN/api-reference/rtc/csharp-windows/enum-videosourcetype)。

#### `config`

屏幕采集配置。详见 [ScreenCaptureConfiguration](/zh-CN/api-reference/rtc/csharp-windows/class-screencaptureconfiguration)。

<a id="api_irtcengine_startscreencapture2__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。 详见 [错误码](https://doc.shengwang.cn/api-ref/rtc/unity/error-code) 了解详情和解决建议。

## StartScreenCaptureByDisplayId

开始采集指定屏幕的视频流。

<a id="api_irtcengine_startscreencapturebydisplayid__prototype"></a>

```csharp
public abstract int StartScreenCaptureByDisplayId(uint displayId, Rectangle regionRect, ScreenCaptureParameters captureParams);
```

<a id="api_irtcengine_startscreencapturebydisplayid__detailed_desc"></a>

采集一个屏幕或该屏幕部分区域的视频流。

<a id="api_irtcengine_startscreencapturebydisplayid__scenario"></a>

### 适用场景

在屏幕共享场景下，你需要调用该方法开始采集屏幕视频流。有关屏幕共享的实现方法，详见 [屏幕共享](https://doc.shengwang.cn/doc/rtc/unity/basic-features/screen-share)。

<a id="api_irtcengine_startscreencapturebydisplayid__timing"></a>

### 调用时机

该方法在加入频道前后均可调用，区别如下：

- 如果在加入频道前调用该方法，然后调用 [JoinChannel [2/2]](/zh-CN/api-reference/rtc/csharp-windows/channel#api_irtcengine_joinchannel2) 加入频道，并设置 publishScreenTrack 或 publishSecondaryScreenTrack 为 `true`，即可开始屏幕共享。
- 如果在加入频道后调用该方法，然后调用 [UpdateChannelMediaOptions](/zh-CN/api-reference/rtc/csharp-windows/channel#api_irtcengine_updatechannelmediaoptions) 更新频道媒体选项，并设置 publishScreenTrack 或 publishSecondaryScreenTrack 为 `true`，即可开始屏幕共享。

<a id="api_irtcengine_startscreencapturebydisplayid__restriction"></a>

### 调用限制

无。

<a id="api_irtcengine_startscreencapturebydisplayid__parameters"></a>

### 参数

#### `displayId`

指定待共享的屏幕 ID。

#### `regionRect`

（可选）指定待共享区域相对于整个屏幕的位置。如需共享整个屏幕，则填 `nil`。 详见 [Rectangle](/zh-CN/api-reference/rtc/csharp-windows/class-rectangle)。

如果设置的共享区域超出了屏幕的边界，则只共享屏幕内的内容；如果宽或高设为 0，则共享整个屏幕。

#### `captureParams`

屏幕共享的参数配置。默认的视频编码分辨率为 1920 × 1080，即 2073600 像素。该像素值为计费标准。详见 [ScreenCaptureParameters](/zh-CN/api-reference/rtc/csharp-windows/class-screencaptureparameters)。

:::warning[注意]
屏幕共享流的视频属性只需通过该参数设置，与 [SetVideoEncoderConfiguration](/zh-CN/api-reference/rtc/csharp-windows/video-basic#api_irtcengine_setvideoencoderconfiguration) 无关。
:::

<a id="api_irtcengine_startscreencapturebydisplayid__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。 详见 [错误码](https://doc.shengwang.cn/api-ref/rtc/unity/error-code) 了解详情和解决建议。

  - -2：传入的参数无效。
  - -8：屏幕共享状态无效。可能因为你已经共享了其他屏幕或窗口。尝试调用 [StopScreenCapture [1/2]](/zh-CN/api-reference/rtc/csharp-windows/screencapture#api_irtcengine_stopscreencapture) 停止当前共享，再重新开始共享屏幕。

<a id="api_irtcengine_stopscreencapture__detailed_desc"></a>

## UpdateScreenCaptureParameters

更新屏幕采集的参数配置。

<a id="api_irtcengine_updatescreencaptureparameters__prototype"></a>

```csharp
public abstract int UpdateScreenCaptureParameters(ScreenCaptureParameters captureParams);
```

<a id="api_irtcengine_updatescreencaptureparameters__detailed_desc"></a>

### 详情

:::warning[注意]
- 请在开启屏幕共享或窗口共享后调用该方法。
:::

<a id="api_irtcengine_updatescreencaptureparameters__parameters"></a>

### 参数

#### `captureParams`

屏幕共享的编码参数配置。详见 [ScreenCaptureParameters](/zh-CN/api-reference/rtc/csharp-windows/class-screencaptureparameters)。

:::warning[注意]
屏幕共享流的视频属性只需通过该参数设置，与 [SetVideoEncoderConfiguration](/zh-CN/api-reference/rtc/csharp-windows/video-basic#api_irtcengine_setvideoencoderconfiguration) 无关。
:::

<a id="api_irtcengine_updatescreencaptureparameters__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。 详见 [错误码](https://doc.shengwang.cn/api-ref/rtc/unity/error-code) 了解详情和解决建议。

  - -2：传入的参数无效。
  - -8：屏幕共享状态无效。可能因为你已经共享了其他屏幕或窗口。尝试调用 [StopScreenCapture [1/2]](/zh-CN/api-reference/rtc/csharp-windows/screencapture#api_irtcengine_stopscreencapture) 停止当前共享，再重新开始共享屏幕。

## UpdateScreenCaptureRegion

更新屏幕采集的区域。

<a id="api_irtcengine_updatescreencaptureregion__prototype"></a>

```csharp
public abstract int UpdateScreenCaptureRegion(Rectangle regionRect);
```

<a id="api_irtcengine_updatescreencaptureregion__detailed_desc"></a>

### 详情

:::warning[注意]
请在开启屏幕共享或窗口共享后调用该方法。
:::

<a id="api_irtcengine_updatescreencaptureregion__parameters"></a>

### 参数

#### `regionRect`

待共享区域相对于整个屏幕或窗口的位置，如不填，则表示共享整个屏幕或窗口。详见 [Rectangle](/zh-CN/api-reference/rtc/csharp-windows/class-rectangle)。如果设置的共享区域超出了屏幕或窗口的边界，则只共享屏幕或窗口内的内容；如果将 width 或 height 设为 0，则共享整个屏幕或窗口。

<a id="api_irtcengine_updatescreencaptureregion__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。 详见 [错误码](https://doc.shengwang.cn/api-ref/rtc/unity/error-code) 了解详情和解决建议。

  - -2：传入的参数无效。
  - -8：屏幕共享状态无效。可能因为你已经共享了其他屏幕或窗口。尝试调用 [StopScreenCapture [1/2]](/zh-CN/api-reference/rtc/csharp-windows/screencapture#api_irtcengine_stopscreencapture) 停止当前共享，再重新开始共享屏幕。
