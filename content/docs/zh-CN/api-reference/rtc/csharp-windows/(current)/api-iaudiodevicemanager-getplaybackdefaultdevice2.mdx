```csharp
public abstract int GetPlaybackDefaultDevice(ref string deviceId, ref string deviceTypeName, ref string deviceName);
```

<a id="api_iaudiodevicemanager_getplaybackdefaultdevice2__detailed_desc"></a>

## 详情

:::warning[注意]
该方法仅适用于 macOS。
:::

<a id="api_iaudiodevicemanager_getplaybackdefaultdevice2__parameters"></a>

## 参数

### `deviceId`

输出参数，系统默认的音频播放设备 ID。

### `deviceName`

输出参数，系统默认的音频播放设备名称。

### `deviceTypeName`

输出参数，音频设备类型，如：built-in、USB、HDMI 等。

<a id="api_iaudiodevicemanager_getplaybackdefaultdevice2__return_values"></a>

## 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。 详见 [错误码](https://doc.shengwang.cn/api-ref/rtc/unity/error-code) 了解详情和解决建议。
