## 媒体播放器缓存

<a id="api_imediaplayercachemanager_enableautoremovecache"></a>

## EnableAutoRemoveCache

设置是否开启自动清除缓存文件功能。

<a id="api_imediaplayercachemanager_enableautoremovecache__prototype"></a>

```csharp
public abstract int EnableAutoRemoveCache(bool enable);
```

<a id="api_imediaplayercachemanager_enableautoremovecache__detailed_desc"></a>

### 详情

开启自动清除缓存文件后，当播放器中缓存的媒体文件超过你设置的文件数量或总缓存大小的上限时，SDK 会自动清除近期最少使用的一个缓存文件。

<a id="api_imediaplayercachemanager_enableautoremovecache__parameters"></a>

### 参数

#### `enable`

是否自动清除缓存文件：

- `true`：开启自动清除缓存文件功能。
- `false`：（默认）关闭自动清除缓存文件功能。

<a id="api_imediaplayercachemanager_enableautoremovecache__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败，详见 [MEDIA_PLAYER_REASON](/zh-CN/api-reference/rtc/csharp-windows/enum-mediaplayerreason)。

### 所属接口类
- [IMediaPlayerCacheManager](/zh-CN/api-reference/rtc/csharp-windows/rtc-interface-class#class_imediaplayercachemanager)

<a id="api_imediaplayercachemanager_getcachedir"></a>

## GetCacheDir

获取缓存文件的储存路径。

<a id="api_imediaplayercachemanager_getcachedir__prototype"></a>

```csharp
public abstract int GetCacheDir(out string path, int length);
```

<a id="api_imediaplayercachemanager_getcachedir__detailed_desc"></a>

### 详情

如果你在调用该方法前未曾调用 [SetCacheDir](/zh-CN/api-reference/rtc/csharp-windows/mediaplayer-cache#api_imediaplayercachemanager_setcachedir) 方法自定义缓存文件的储存路径，该方法返回的为 SDK 默认的缓存文件储存路径。

<a id="api_imediaplayercachemanager_getcachedir__parameters"></a>

### 参数

#### `path`

输出参数，缓存文件的储存路径。

#### `length`

输入参数，缓存文件储存路径字符串的最大长度。 根据你在 path 中获得的缓存文件储存路径字符串来填写。

<a id="api_imediaplayercachemanager_getcachedir__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败，详见 [MEDIA_PLAYER_REASON](/zh-CN/api-reference/rtc/csharp-windows/enum-mediaplayerreason)。

### 所属接口类
- [IMediaPlayerCacheManager](/zh-CN/api-reference/rtc/csharp-windows/rtc-interface-class#class_imediaplayercachemanager)

## GetMaxCacheFileSize

获取所设置的缓存文件总缓存的上限。

```csharp

```

### 详情

SDK 默认的缓存文件总缓存上限为 1GB。你可以调用 [SetMaxCacheFileSize](/zh-CN/api-reference/rtc/csharp-windows/mediaplayer-cache#api_imediaplayercachemanager_setmaxcachefilesize) 方法自定义总缓存大小的上限。

### 返回值

- &gt; 0：方法调用成功，返回缓存文件的总缓存上限，单位为字节。
- &lt; 0：方法调用失败，详见 [MEDIA_PLAYER_REASON](/zh-CN/api-reference/rtc/csharp-windows/enum-mediaplayerreason)。

### 所属接口类

## RemoveOldCache

删除媒体播放器中近期最少使用的一个缓存媒体文件。

<a id="api_imediaplayercachemanager_removeoldcache__prototype"></a>

```csharp
public abstract int RemoveOldCache();
```

<a id="api_imediaplayercachemanager_removeoldcache__detailed_desc"></a>

### 详情

缓存媒体文件占用过多空间时，你可以调用该方法清理缓存文件。调用该方法后，SDK 会删除最少使用的一个缓存媒体文件。

:::info[注]
当你调用此方法删除缓存媒体文件时，当前正在播放的已缓存媒体文件不会被删除。
:::

<a id="api_imediaplayercachemanager_removeoldcache__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败，详见 [MEDIA_PLAYER_REASON](/zh-CN/api-reference/rtc/csharp-windows/enum-mediaplayerreason)。

### 所属接口类
- [IMediaPlayerCacheManager](/zh-CN/api-reference/rtc/csharp-windows/rtc-interface-class#class_imediaplayercachemanager)
