<a id="api_irtcengine_setaudiomixingplaybackspeed__prototype"></a>

```csharp
public abstract int SetAudioMixingPlaybackSpeed(int speed);
```

<a id="api_irtcengine_setaudiomixingplaybackspeed__detailed_desc"></a>

## 详情

你需要在调用 [StartAudioMixing [2/2]](/zh-CN/api-reference/rtc/csharp-windows/play/audio-mixing#api_irtcengine_startaudiomixing2) 并收到 [OnAudioMixingStateChanged](/zh-CN/api-reference/rtc/csharp-windows/play/audio-mixing#callback_irtcengineeventhandler_onaudiomixingstatechanged) 回调报告播放状态为 AUDIO_MIXING_STATE_PLAYING 后再调用该方法。

<a id="api_irtcengine_setaudiomixingplaybackspeed__parameters"></a>

## 参数

### `speed`

音乐文件的播放速度。推荐取值范围为 [50,400]，其中：

- 50: 0.5 倍速。
- 100: 原始速度。
- 400: 4 倍速。

<a id="api_irtcengine_setaudiomixingplaybackspeed__return_values"></a>

## 返回值

- [IRtcEngine](/zh-CN/api-reference/rtc/csharp-windows/rtc-interface-class#class_irtcengine)
