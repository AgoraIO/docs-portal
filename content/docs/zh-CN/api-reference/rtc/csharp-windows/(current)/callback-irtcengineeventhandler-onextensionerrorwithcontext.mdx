<a id="callback_irtcengineeventhandler_onextensionerrorwithcontext__prototype"></a>

```csharp
public virtual void OnExtensionErrorWithContext(ExtensionContext context, int error, string message){}
```

<a id="callback_irtcengineeventhandler_onextensionerrorwithcontext__detailed_desc"></a>

启用插件失败或者插件运行出错时，插件会触发该回调并报告错误码和错误原因。

<a id="callback_irtcengineeventhandler_onextensionerrorwithcontext__parameters"></a>

## 参数

### `context`

插件上下文信息，详见 [ExtensionContext](/zh-CN/api-reference/rtc/csharp-windows/class-extensioncontext)。

### `error`

错误码。详见插件服务商提供的插件文档。

### `message`

错误原因。详见插件服务商提供的插件文档。
