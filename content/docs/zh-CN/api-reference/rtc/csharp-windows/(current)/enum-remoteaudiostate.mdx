## 枚举值

<ParameterList>
<a id="remote_audio_state_stopped"></a>
<Parameter name="REMOTE_AUDIO_STATE_STOPPED">

0: 远端音频默认初始状态。在 REMOTE_AUDIO_REASON_LOCAL_MUTED、REMOTE_AUDIO_REASON_REMOTE_MUTED 或 REMOTE_AUDIO_REASON_REMOTE_OFFLINE 的情况下，会报告该状态。

</Parameter>
<a id="remote_audio_state_starting"></a>
<Parameter name="REMOTE_AUDIO_STATE_STARTING">

1: 本地用户已接收远端音频首包。

</Parameter>
<a id="remote_audio_state_decoding"></a>
<Parameter name="REMOTE_AUDIO_STATE_DECODING">

2: 远端音频流正在解码，正常播放。在 REMOTE_AUDIO_REASON_NETWORK_RECOVERY、REMOTE_AUDIO_REASON_LOCAL_UNMUTED 或 REMOTE_AUDIO_REASON_REMOTE_UNMUTED 的情况下，会报告该状态。

</Parameter>
<a id="remote_audio_state_frozen"></a>
<Parameter name="REMOTE_AUDIO_STATE_FROZEN">

3: 远端音频流卡顿。在 REMOTE_AUDIO_REASON_NETWORK_CONGESTION 的情况下，会报告该状态。

</Parameter>
<a id="remote_audio_state_failed"></a>
<Parameter name="REMOTE_AUDIO_STATE_FAILED">

4: 远端音频流播放失败。在 REMOTE_AUDIO_REASON_INTERNAL 的情况下，会报告该状态。

</Parameter>
</ParameterList>
