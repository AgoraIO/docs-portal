## 属性

### `uid`

发布视频源的用户 ID。

### `view`

视频显示窗口。

:::warning[注意]
在一个 VideoCanvas 中，你只能选择 view 或 surfaceTexture 其中一个进行设置，如果同时设置，只有 view 中的设置会生效。
:::

### `renderMode`

视频渲染模式，详见 [RENDER_MODE_TYPE](/zh-CN/api-reference/rtc/csharp-windows/enum-rendermodetype)。

### `mirrorMode`

视图镜像模式，详见 [VIDEO_MIRROR_MODE_TYPE](/zh-CN/api-reference/rtc/csharp-windows/enum-videomirrormodetype)。

:::warning[注意]
- 本地视图镜像模式：如果你使用前置摄像头，默认启动本地视图镜像模式；如果你使用后置摄像头，默认关闭本地视图镜像模式。
- 远端用户视图镜像模式：默认关闭远端用户的镜像模式。
:::

### `sourceType`

视频源的类型，详见 [VIDEO_SOURCE_TYPE](/zh-CN/api-reference/rtc/csharp-windows/enum-videosourcetype)。

### `setupMode`

视图设置模式。详见 [VIDEO_VIEW_SETUP_MODE](/zh-CN/api-reference/rtc/csharp-windows/enum-videoviewsetupmode)。

### `mediaPlayerId`

媒体播放器 ID。可通过 [GetId](/zh-CN/api-reference/rtc/csharp-windows/play/mediaplayer/mediaplayer-info#api_imediaplayer_getmediaplayerid) 获取。

当 sourceType 为 VIDEO_SOURCE_MEDIA_PLAYER 时，此参数为必填项。

### `cropArea`

（可选）视频帧的展示区域，详见 [Rectangle](/zh-CN/api-reference/rtc/csharp-windows/class-rectangle)。其中， width 和 height 表示该区域的视频像素宽度和高度。默认值为空值 (宽或高为 0)，表示展示实际分辨率的视频帧。

### `backgroundColor`

视频画布的背景颜色，格式为 RGBA。默认值为 0x00000000，代表黑色。

### `enableAlphaMask`

预留。

### `position`

视频帧在视频链路中的位置。详见 [VIDEO_MODULE_POSITION](/zh-CN/api-reference/rtc/csharp-windows/enum-videomoduleposition)。
