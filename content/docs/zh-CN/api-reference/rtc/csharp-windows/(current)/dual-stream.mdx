## EnableDualStreamMode [1/2]

在发送端开启或关闭双流模式。

<a id="api_irtcengine_enabledualstreammode__prototype"></a>

```csharp
public abstract int EnableDualStreamMode(bool enabled);
```

<a id="api_irtcengine_enabledualstreammode__detailed_desc"></a>

### 详情

#### `弃用：`

从 v4.2.0 起废弃，请改用 [SetDualStreamMode [1/2]](/zh-CN/api-reference/rtc/csharp-windows/video/video-codec/dual-stream#api_irtcengine_setdualstreammode)。

双流指视频大流和视频小流：

- 视频大流：高分辨率、高帧率的视频流。
- 视频小流：低分辨率、低帧率的视频流。

开启双流模式后，你可以在收流端调用 [SetRemoteVideoStreamType](/zh-CN/api-reference/rtc/csharp-windows/video/video-codec/dual-stream#api_irtcengine_setremotevideostreamtype) 选择接收视频大流或视频小流。

:::info[注]
- 该方法适用于发送端发送的所有类型的流，包括且不限于来自摄像头采集的视频流、屏幕共享流、自定义采集的视频流。
- 如果需要在多频道场景下开启视频双流，可以调用 [EnableDualStreamModeEx](/zh-CN/api-reference/rtc/csharp-windows/video/video-codec/dual-stream#api_irtcengineex_enabledualstreammodeex) 方法。
- 该方法可以在加入频道前后调用。
:::

<a id="api_irtcengine_enabledualstreammode__parameters"></a>

### 参数

#### `enabled`

是否开启双流模式。

- `true`: 开启双流模式。
- `false`: (默认) 关闭双流模式。

<a id="api_irtcengine_enabledualstreammode__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。 详见 [错误码](https://doc.shengwang.cn/api-ref/rtc/unity/error-code) 了解详情和解决建议。

## SetDualStreamMode [1/2]

在发送端设置双流模式。

<a id="api_irtcengine_setdualstreammode__prototype"></a>

```csharp
public abstract int SetDualStreamMode(SIMULCAST_STREAM_MODE mode);
```

<a id="api_irtcengine_setdualstreammode__detailed_desc"></a>

### 详情

SDK 默认在发送端开启小流自适应模式 (AUTO_SIMULCAST_STREAM)，即发送端不主动发送小流， **主播身份** 的接收端可以调用 [SetRemoteVideoStreamType](/zh-CN/api-reference/rtc/csharp-windows/video/video-codec/dual-stream#api_irtcengine_setremotevideostreamtype) 发起小流申请，发送端收到申请后开始自动发送小流。

- 如果你想修改此行为，可以调用该方法并修改 mode 为 DISABLE_SIMULCAST_STREAM （始终不发送小流）或 ENABLE_SIMULCAST_STREAM （始终发送小流）。
- 如果你在进行修改后又想恢复该默认行为，可重新调用该方法，并将 mode 设置为 AUTO_SIMULCAST_STREAM。

:::info[注]
该方法和 [EnableDualStreamMode [1/2]](/zh-CN/api-reference/rtc/csharp-windows/video/video-codec/dual-stream#api_irtcengine_enabledualstreammode) 的区别与联系如下：

- 调用该方法并设置 mode 为 DISABLE_SIMULCAST_STREAM 时，跟 EnableDualStreamMode [1/2] `(false)` 的效果相同。
- 调用该方法并设置 mode 为 ENABLE_SIMULCAST_STREAM 时，跟 EnableDualStreamMode [1/2] `(true)` 的效果相同。
- 两种方法均可在加入频道前后调用，若同时使用，则以后调用的方法中的设置为准。
:::

<a id="api_irtcengine_setdualstreammode__parameters"></a>

### 参数

#### `mode`

发送视频流的模式。详见 [SIMULCAST_STREAM_MODE](/zh-CN/api-reference/rtc/csharp-windows/enum-simulcaststreammode)。

<a id="api_irtcengine_setdualstreammode__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。 详见 [错误码](https://doc.shengwang.cn/api-ref/rtc/unity/error-code) 了解详情和解决建议。

## SetRemoteDefaultVideoStreamType

设置默认订阅的视频流类型。

<a id="api_irtcengine_setremotedefaultvideostreamtype__prototype"></a>

```csharp
public abstract int SetRemoteDefaultVideoStreamType(VIDEO_STREAM_TYPE streamType);
```

<a id="api_irtcengine_setremotedefaultvideostreamtype__detailed_desc"></a>

取决于发送端的默认行为和调用 [SetDualStreamMode [2/2]](/zh-CN/api-reference/rtc/csharp-windows/video/video-codec/dual-stream#api_irtcengine_setdualstreammode2) 的具体设置，接收端调用该方法分为以下几种情况：

- SDK 默认在发送端开启小流自适应模式 (AUTO_SIMULCAST_STREAM)，即：发送端仅发送大流，仅 **主播身份** 的接收端可以调用该方法发起小流申请，发送端收到申请后开始自动发送小流，此时频道内所有用户均可调用该方法切换到小流订阅模式。
- 当发送端调用 SetDualStreamMode [2/2] 并将 mode 设置为 DISABLE_SIMULCAST_STREAM （始终不发送小流），则调用该方法不生效。
- 当发送端调用 SetDualStreamMode [2/2] 并将 mode 设置为 ENABLE_SIMULCAST_STREAM （始终发送小流），则主播或观众身份的接收端均可调用该方法切换到小流订阅模式。

在接收视频小流时，SDK 会根据视频窗口的大小动态调整对应视频流的大小，以节约带宽和计算资源。视频小流默认的宽高比和视频大流的宽高比一致。根据当前大流的宽高比，系统会自动分配小流的分辨率、帧率及码率。

<a id="api_irtcengine_setremotedefaultvideostreamtype__timing"></a>

### 调用时机

该方法只能在加入频道前调用。SDK 不支持你在加入频道后修改默认订阅的视频流类型。

<a id="api_irtcengine_setremotedefaultvideostreamtype__restriction"></a>

### 调用限制

如果你既调用了该方法，也调用了 [SetRemoteVideoStreamType](/zh-CN/api-reference/rtc/csharp-windows/video/video-codec/dual-stream#api_irtcengine_setremotevideostreamtype)，则 SDK 以 SetRemoteVideoStreamType 中的设置为准。

<a id="api_irtcengine_setremotedefaultvideostreamtype__parameters"></a>

### 参数

#### `streamType`

默认订阅的视频流类型: [VIDEO_STREAM_TYPE](/zh-CN/api-reference/rtc/csharp-windows/enum-videostreamtype)。

<a id="api_irtcengine_setremotedefaultvideostreamtype__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。 详见 [错误码](https://doc.shengwang.cn/api-ref/rtc/unity/error-code) 了解详情和解决建议。

- [IRtcEngine](/zh-CN/api-reference/rtc/csharp-windows/rtc-interface-class#class_irtcengine)

取决于发送端的默认行为和调用 [SetDualStreamMode [2/2]](/zh-CN/api-reference/rtc/csharp-windows/video/video-codec/dual-stream#api_irtcengine_setdualstreammode2) 的具体设置，接收端调用该方法分为以下几种情况：

- SDK 默认在发送端开启小流自适应模式 (AUTO_SIMULCAST_STREAM)，即：发送端仅发送大流，仅 **主播身份** 的接收端可以调用该方法发起小流申请，发送端收到申请后开始自动发送小流，此时频道内所有用户均可调用该方法切换到小流订阅模式。
- 当发送端调用 SetDualStreamMode [2/2] 并将 mode 设置为 DISABLE_SIMULCAST_STREAM （始终不发送小流），则调用该方法不生效。
- 当发送端调用 SetDualStreamMode [2/2] 并将 mode 设置为 ENABLE_SIMULCAST_STREAM （始终发送小流），则主播或观众身份的接收端均可调用该方法切换到小流订阅模式。

在接收视频小流时，SDK 会根据视频窗口的大小动态调整对应视频流的大小，以节约带宽和计算资源。视频小流默认的宽高比和视频大流的宽高比一致。根据当前大流的宽高比，系统会自动分配小流的分辨率、帧率及码率。

:::warning[注意]
如果发送端已调用 [SetDualStreamModeEx](/zh-CN/api-reference/rtc/csharp-windows/video/video-codec/dual-stream#api_irtcengineex_setdualstreammodeex) 并将 mode 设置为 DISABLE_SIMULCAST_STREAM （始终不发送小流），则调用该方法不生效，你需要在发送端重新调用 SetDualStreamModeEx 修改设置。
:::
