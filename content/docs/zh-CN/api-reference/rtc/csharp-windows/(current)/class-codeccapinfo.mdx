## 属性

### `codecType`

视频编解码类型。详见 [VIDEO_CODEC_TYPE](/zh-CN/api-reference/rtc/csharp-windows/enum-videocodectype)。

### `codecCapMask`

SDK 编解码类型的 bit mask。详见 [CODEC_CAP_MASK](/zh-CN/api-reference/rtc/csharp-windows/enum-codeccapmask)。

### `codecLevels`

SDK 支持的编解码能力等级。详见 [CodecCapLevels](/zh-CN/api-reference/rtc/csharp-windows/class-codeccaplevels)。
