public abstract int AdjustAudioMixingPlayoutVolume(int volume);

无。

#### `volume`

音乐文件音量。取值范围为 [0,100]，100 （默认值）为原始音量。

- &lt; 0: 方法调用失败。 详见 [错误码](https://doc.shengwang.cn/api-ref/rtc/unity/error-code) 了解详情和解决建议。

## GetAudioMixingCurrentPosition

获取音乐文件的播放进度。

<a id="api_irtcengine_getaudiomixingcurrentposition__prototype"></a>

```csharp
public abstract int GetAudioMixingCurrentPosition();
```

<a id="api_irtcengine_getaudiomixingcurrentposition__detailed_desc"></a>

### 详情

该方法获取当前音乐文件播放进度，单位为毫秒。

:::warning[注意]
- 你需要在调用 并收到 OnAudioMixingStateChanged `(AUDIO_MIXING_STATE_PLAYING)` 回调后调用该方法。
- 如需多次调用 GetAudioMixingCurrentPosition，请确保调用间隔大于 500 ms。

### 返回值

- ≥ 0: 方法调用成功，返回当前音乐文件播放进度（ms）。0 表示当前音乐文件未开始播放。
- &lt; 0: 方法调用失败。 详见 [错误码](https://doc.shengwang.cn/api-ref/rtc/unity/error-code) 了解详情和解决建议。

## SetAudioMixingDualMonoMode

设置当前音频文件的声道模式。

<a id="api_irtcengine_setaudiomixingdualmonomode__prototype"></a>

```csharp
public abstract int SetAudioMixingDualMonoMode(AUDIO_MIXING_DUAL_MONO_MODE mode);
```

<a id="api_irtcengine_setaudiomixingdualmonomode__detailed_desc"></a>

在双声道音频文件中，左声道和右声道可以存储不同的音频数据。根据实际需要，你可以设置声道模式为原始模式、左声道模式、右声道模式或混合模式。

<a id="api_irtcengine_setaudiomixingdualmonomode__scenario"></a>

### 适用场景

在 KTV 场景中，音频文件的左声道存储了伴奏，右声道存储了原唱的歌声。你可以根据实际需求进行设置：

- 如果你只需听伴奏，则用该方法设置音频文件的声道模式为左声道模式。
- 如果你需要同时听伴奏和原唱，则调用该方法设置声道模式为混合模式。

<a id="api_irtcengine_setaudiomixingdualmonomode__timing"></a>

### 调用时机

该方法需要在 [StartAudioMixing [2/2]](/zh-CN/api-reference/rtc/csharp-windows/play/audio-mixing#api_irtcengine_startaudiomixing2) 之后，并收到 [OnAudioMixingStateChanged](/zh-CN/api-reference/rtc/csharp-windows/play/audio-mixing#callback_irtcengineeventhandler_onaudiomixingstatechanged) `(AUDIO_MIXING_STATE_PLAYING)` 回调后调用。

<a id="api_irtcengine_setaudiomixingdualmonomode__restriction"></a>

### 调用限制

该方法仅适用于双声道的音频文件。

<a id="api_irtcengine_setaudiomixingdualmonomode__parameters"></a>

### 参数

#### `mode`

声道模式。详见 [AUDIO_MIXING_DUAL_MONO_MODE](/zh-CN/api-reference/rtc/csharp-windows/enum-audiomixingdualmonomode)。

<a id="api_irtcengine_setaudiomixingdualmonomode__return_values"></a>

- &lt; 0: 方法调用失败。 详见 [错误码](https://doc.shengwang.cn/api-ref/rtc/unity/error-code) 了解详情和解决建议。

## StartAudioMixing [1/2]

开始播放音乐文件。

<a id="api_irtcengine_startaudiomixing__prototype"></a>

```csharp
 public abstract int StartAudioMixing(string filePath, bool loopback, int cycle);
```

<a id="api_irtcengine_startaudiomixing__detailed_desc"></a>

该方法支持播放的音频文件格式见 [RTC SDK 支持播放哪些格式的音频文件](https://doc.shengwang.cn/faq/general-product-inquiry/audio-format)。如果本地音乐文件不存在、文件格式不支持或无法访问在线音乐文件 URL，则 SDK 会报告 AUDIO_MIXING_REASON_CAN_NOT_OPEN。

<a id="api_irtcengine_startaudiomixing__timing"></a>

### 调用时机

该方法在加入频道前后均可调用。

<a id="api_irtcengine_startaudiomixing__restriction"></a>

### 调用限制

- 使用该方法播放时长较短的音效文件可能会导致播放失败。如需播放音效文件，建议使用 [PlayEffect](/zh-CN/api-reference/rtc/csharp-windows/play/audio-effect-file#api_irtcengine_playeffect3)。
- 如需多次调用该方法，请确保调用间隔大于 500 ms。

<a id="api_irtcengine_startaudiomixing__related"></a>

### 相关回调

调用该方法成功播放音乐文件后，本地会触发 [OnAudioMixingStateChanged](/zh-CN/api-reference/rtc/csharp-windows/play/audio-mixing#callback_irtcengineeventhandler_onaudiomixingstatechanged) (`AUDIO_MIXING_STATE_PLAYING`) 回调。播放结束后，本地会触发 OnAudioMixingStateChanged (`AUDIO_MIXING_STATE_STOPPED`) 回调。

<a id="api_irtcengine_startaudiomixing__parameters"></a>

### 参数

#### `filePath`

播放文件的地址，支持在线文件的 URL 地址、播放文件的绝对路径，需精确到文件名及后缀。支持的音频格式包括 MP3、AAC、M4A、MP4、WAV、3GP 等。

:::warning[注意]
如果你已通过 [PreloadEffect](/zh-CN/api-reference/rtc/csharp-windows/play/audio-effect-file#api_irtcengine_preloadeffect) 将音效加载至内存，请确保该参数与 PreloadEffect 中设置的 filePath 相同。
:::

#### `loopback`

是否只在本地播放音乐文件：

- true：只在本地播放音乐文件，只有本地用户能听到音乐。
- false：将本地播放的音乐文件发布至远端，本地用户和远端用户都能听到音乐。

#### `cycle`

音乐文件的播放次数。

- &gt;0: 播放次数。例如，1 表示播放 1 次。
- -1: 无限循环播放。

<a id="api_irtcengine_startaudiomixing__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败：
  - -1：一般性的错误（未明确归类）。
  - -2：设置了无效的参数。
  - -3：SDK 尚未准备好：
    - 请检查是否已开启音频模块。
    - 请检查程序集完整性。
    - IRtcEngine 初始化失败。请重新初始化 IRtcEngine。
