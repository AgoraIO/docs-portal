## CreateMediaPlayer

创建媒体播放器对象。

<a id="api_irtcengine_createmediaplayer__prototype"></a>

```text
public abstract IMediaPlayer CreateMediaPlayer();
```

<a id="api_irtcengine_createmediaplayer__detailed_desc"></a>

在调用 [IMediaPlayer](/zh-CN/api-reference/rtc/csharp-windows/rtc-interface-class#class_imediaplayer) 类下的其他 API 前，你需要先调用该方法创建一个媒体播放器实例。如果你需要创建多个实例，可以多次调用该方法。

<a id="api_irtcengine_createmediaplayer__timing"></a>

### 调用时机

该方法在加入频道前后均可调用。

<a id="api_irtcengine_createmediaplayer__restriction"></a>

### 调用限制

无。

<a id="api_irtcengine_createmediaplayer__parameters"></a>

<a id="api_irtcengine_createmediaplayer__return_values"></a>

### 返回值

<a id="api_irtcengine_createmediaplayer__ul_cwj_3ry_hqb"></a>

- 方法调用成功：返回 [IMediaPlayer](/zh-CN/api-reference/rtc/csharp-windows/rtc-interface-class#class_imediaplayer) 对象。
- 方法调用失败：返回空指针。

### 所属接口类

- [IRtcEngine](/zh-CN/api-reference/rtc/csharp-windows/rtc-interface-class#class_irtcengine)

## GetMediaPlayerCacheManager

<a id="api_getmediaplayercachemanager__prototype"></a>

```text
public abstract IMediaPlayerCacheManager GetMediaPlayerCacheManager();
```

<a id="api_getmediaplayercachemanager__detailed_desc"></a>

在调用 [IMediaPlayerCacheManager](/zh-CN/api-reference/rtc/csharp-windows/rtc-interface-class#class_imediaplayercachemanager) 类下的其他 API 前，你需要先调用该方法获取一个媒体播放器缓存管理器的实例。

### 调用限制
