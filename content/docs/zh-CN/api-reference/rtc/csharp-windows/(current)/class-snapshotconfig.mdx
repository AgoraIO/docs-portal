<a id="class_snapshotconfig__prototype"></a>

```csharp
public class SnapshotConfig
    {
        public string filePath;

        public VIDEO_MODULE_POSITION position;
    }
```

<a id="class_snapshotconfig__parameters"></a>

## 属性

### `filePath`

截图的本地保存路径，需精确到文件名及格式，例如：

- Windows: C:\\Users\\&lt;user_name&gt;\\AppData\\Local\\Agora\\&lt;process_name&gt;\\example.jpg

:::warning[注意]
请确保目录存在且可写。
:::

### `position`

截图的视频帧在视频链路中的位置。详见 [VIDEO_MODULE_POSITION](/zh-CN/api-reference/rtc/csharp-windows/enum-videomoduleposition)。
