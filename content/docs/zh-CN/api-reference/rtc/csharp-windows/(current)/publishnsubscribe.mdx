## MuteAllRemoteAudioStreams

取消或恢复订阅所有远端用户的音频流。

<a id="api_irtcengine_muteallremoteaudiostreams__prototype"></a>

```text
public abstract int MuteAllRemoteAudioStreams(bool mute);
```

<a id="api_irtcengine_muteallremoteaudiostreams__detailed_desc"></a>

<a id="api_irtcengine_muteallremoteaudiostreams__desc"></a>

成功调用该方法后，本地用户会取消或恢复订阅所有远端用户的音频流，包括在调用该方法后加入频道的用户的音频流。

<a id="api_irtcengine_muteallremoteaudiostreams__note"></a>

:::caution
注意：

SDK 默认在加入频道时订阅所有远端用户的音频流，如果要修改此行为，可以在调用 [JoinChannel [2/2]](/zh-CN/api-reference/rtc/csharp-windows/channel#api_irtcengine_joinchannel2) 加入频道时设置 autoSubscribeAudio 为 `false`，即可在加入频道时取消订阅所有用户的音频流。
:::

<a id="api_irtcengine_muteallremoteaudiostreams__timing"></a>

### 调用时机

该方法需要在加入频道后调用。

<a id="api_irtcengine_muteallremoteaudiostreams__restriction"></a>

### 调用限制

如果在调用该方法之后又调用了 [EnableAudio](/zh-CN/api-reference/rtc/csharp-windows/audio/audio-basic#api_irtcengine_enableaudio) 或 [DisableAudio](/zh-CN/api-reference/rtc/csharp-windows/audio/audio-basic#api_irtcengine_disableaudio)，则后调用的方法会生效。

<a id="api_irtcengine_muteallremoteaudiostreams__parameters"></a>

### 参数

<ParameterList>
<a id="mute"></a>
<Parameter name="mute">

是否取消订阅所有远端用户的音频流：

- `true`: 取消订阅所有远端用户的音频流。
- `false`:（默认）订阅所有远端用户的音频流。

</Parameter>
</ParameterList>

<a id="api_irtcengine_muteallremoteaudiostreams__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。

### 所属接口类

- [IRtcEngine](/zh-CN/api-reference/rtc/csharp-windows/rtc-interface-class#class_irtcengine)

## MuteLocalAudioStream

<a id="api_irtcengine_mutelocalaudiostream__prototype"></a>

```text
public abstract int MuteLocalAudioStream(bool mute);
```

<a id="api_irtcengine_mutelocalaudiostream__detailed_desc"></a>

该方法用于控制是否发布本地采集的音频流。如果不发布本地采集的音频流，也不会禁用音频采集设备，所以不影响音频的采集状态。

<a id="api_irtcengine_mutelocalaudiostream__timing"></a>

### 调用时机

加入频道前后均可调用。

<a id="api_irtcengine_mutelocalaudiostream__restriction"></a>

无。

<a id="api_irtcengine_mutelocalaudiostream__related"></a>

## SetRemoteVideoSubscriptionOptions

<a id="api_irtcengine_setremotevideosubscriptionoptions__prototype"></a>

```text
 public abstract int SetRemoteVideoSubscriptionOptions(uint uid, VideoSubscriptionOptions options);
```

<a id="api_irtcengine_setremotevideosubscriptionoptions__detailed_desc"></a>

### 详情

当远端发送双流时，可调用此方法来设置远端视频流的订阅选项。SDK 对远端视频流的默认订阅行为取决于注册的视频观测器类型：

- 如果注册的是 [IVideoFrameObserver](/zh-CN/api-reference/rtc/csharp-windows/rtc-interface-class#class_ivideoframeobserver) 观测器，则默认订阅原始数据和编码后的数据。

- 如果注册了两种观测器，则默认跟随后注册的视频观测器。举例来说，如果后注册的是 IVideoFrameObserver 观测器，则默认订阅原始数据和编码后的数据。

如果你想修改以上默认行为，或者想针对不同 `uid` 设置不同的订阅选项，可调用该方法设置。

- 如果某个用户同时在音频订阅黑名单和白名单中，仅订阅黑名单生效。
