## RegisterAudioEncodedFrameObserver

注册音频编码数据观测器。

<a id="api_irtcengine_registeraudioencodedframeobserver__prototype"></a>

```text
public abstract int RegisterAudioEncodedFrameObserver(AudioEncodedFrameObserverConfig config, IAudioEncodedFrameObserver observer);
```

<a id="api_irtcengine_registeraudioencodedframeobserver__detailed_desc"></a>

### 详情

<a id="api_irtcengine_registeraudioencodedframeobserver__note_igp_ygf_3qb"></a>

:::note
注意：

<a id="api_irtcengine_registeraudioencodedframeobserver__ul_mvp_zgf_3qb"></a>

- 请在加入频道后调用该方法。
- 由于该方法和 [StartAudioRecording [3/3]](/zh-CN/api-reference/rtc/csharp-windows/recording#api_irtcengine_startaudiorecording3) 都会设置音频内容和音质，不建议该方法和 StartAudioRecording [3/3] 一起使用。否则，只有后调用的方法会生效。
:::

## OnMixedAudioEncodedFrame

获取本地和所有远端用户混音后的音频编码数据。

<a id="callback_iaudioencodedframeobserver_onmixedaudioencodedframe__prototype"></a>

```text
public virtual void OnMixedAudioEncodedFrame(IntPtr frameBufferPtr, int length,
                                                    EncodedAudioFrameInfo audioEncodedFrameInfo)
        {

        }
```

<a id="callback_iaudioencodedframeobserver_onmixedaudioencodedframe__detailed_desc"></a>

调用 [RegisterAudioEncodedFrameObserver](/zh-CN/api-reference/rtc/csharp-windows/audio/audio-encoded#api_irtcengine_registeraudioencodedframeobserver) 并将音频编码内容设为 AUDIO_ENCODED_FRAME_OBSERVER_POSITION_MIXED 后，你可以通过该回调获取本地和所有远端用户混音、编码后的音频数据。

<a id="callback_iaudioencodedframeobserver_onmixedaudioencodedframe__parameters"></a>

### 参数

### frameBufferPtr

音频 buffer。

### length

音频数据长度，单位为字节。

### audioEncodedFrameInfo

编码后音频的信息。详见 [EncodedAudioFrameInfo](/zh-CN/api-reference/rtc/csharp-windows/class-encodedaudioframeinfo)。
