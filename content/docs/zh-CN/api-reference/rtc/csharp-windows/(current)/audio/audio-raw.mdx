## RegisterAudioFrameObserver

注册音频观测器对象。

<a id="api_imediaengine_registeraudioframeobserver__prototype"></a>

```text
public abstract int RegisterAudioFrameObserver(IAudioFrameObserver audioFrameObserver, AUDIO_FRAME_POSITION position, OBSERVER_MODE mode = OBSERVER_MODE.INTPTR);
```

<a id="api_imediaengine_registeraudioframeobserver__detailed_desc"></a>

该方法用于注册音频观测器对象，即注册回调。当需要 SDK 触发 [OnMixedAudioFrame](/zh-CN/api-reference/rtc/csharp-windows/audio/audio-raw#callback_iaudioframeobserverbase_onmixedaudioframe)、[OnRecordAudioFrame](/zh-CN/api-reference/rtc/csharp-windows/audio/audio-raw#callback_iaudioframeobserverbase_onrecordaudioframe)、[OnPlaybackAudioFrame](/zh-CN/api-reference/rtc/csharp-windows/audio/audio-raw#callback_iaudioframeobserverbase_onplaybackaudioframe)、[OnPlaybackAudioFrameBeforeMixing](/zh-CN/api-reference/rtc/csharp-windows/audio/audio-raw#callback_iaudioframeobserver_onplaybackaudioframebeforemixing) 和 [OnEarMonitoringAudioFrame](/zh-CN/api-reference/rtc/csharp-windows/audio/audio-raw#callback_iaudioframeobserverbase_onearmonitoringaudioframe) 回调时，需要调用该方法注册回调。

<a id="api_imediaengine_registeraudioframeobserver__timing"></a>

### 调用时机

该方法需要在加入频道前调用。

<a id="api_imediaengine_registeraudioframeobserver__restriction"></a>

### 调用限制

无。

<a id="api_imediaengine_registeraudioframeobserver__parameters"></a>

### 参数

### audioFrameObserver

接口对象实例。详见 [IAudioFrameObserver](/zh-CN/api-reference/rtc/csharp-windows/rtc-interface-class#class_iaudioframeobserver)。如果传入 NULL，则表示取消注册。建议在收到 [OnLeaveChannel](/zh-CN/api-reference/rtc/csharp-windows/channel#callback_irtcengineeventhandler_onleavechannel) 后调用，来释放音频观测器对象。

### mode

音频数据回调模式，详见 [OBSERVER_MODE](/zh-CN/api-reference/rtc/csharp-windows/enum-observermode)。

<a id="api_imediaengine_registeraudioframeobserver__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。

## SetEarMonitoringAudioFrameParameters

设置耳返的音频数据格式。

<a id="api_irtcengine_setearmonitoringaudioframeparameters__prototype"></a>

```text
public abstract int SetEarMonitoringAudioFrameParameters(int sampleRate, int channel, RAW_AUDIO_FRAME_OP_MODE_TYPE mode, int samplesPerCall);
```

<a id="api_irtcengine_setearmonitoringaudioframeparameters__detailed_desc"></a>

### 详情

该方法用于设置 [OnEarMonitoringAudioFrame](/zh-CN/api-reference/rtc/csharp-windows/audio/audio-raw#callback_iaudioframeobserverbase_onearmonitoringaudioframe) 回调的耳返音频数据格式。

:::caution
注意：

- 调用该方法前，你需要先调用 [EnableInEarMonitoring](/zh-CN/api-reference/rtc/csharp-windows/audio/audio-capture)，将 includeAudioFilters 设置为 EAR_MONITORING_FILTER_BUILT_IN_AUDIO_FILTERS 或 EAR_MONITORING_FILTER_NOISE_SUPPRESSION。
- SDK 会通过该方法中的 samplesPerCall、sampleRate 和 channel 参数计算出采样间隔，计算公式为采样间隔 = samplesPerCall/(sampleRate × channel)。请确保采样间隔不小于 0.01 秒。SDK 会根据该采样间隔触发 OnEarMonitoringAudioFrame 回调。
:::

<a id="api_irtcengine_setearmonitoringaudioframeparameters__parameters"></a>

### 参数

### sampleRate

OnEarMonitoringAudioFrame 中报告音频的采样率 (Hz)，可设置为 8000、 16000、 32000、44100 或 48000。

### channel

OnEarMonitoringAudioFrame 中报告音频的声道数，可设置为 1 或 2:

- 1: 单声道。
- 2: 双声道。

### mode

音频帧的使用模式，详见 [RAW_AUDIO_FRAME_OP_MODE_TYPE](/zh-CN/api-reference/rtc/csharp-windows/enum-rawaudioframeopmodetype)。

### samplesPerCall

OnEarMonitoringAudioFrame 中报告的音频的采样点数，如旁路推流应用中通常为 1024。

<a id="api_irtcengine_setearmonitoringaudioframeparameters__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。

### 所属接口类

- [IRtcEngine](/zh-CN/api-reference/rtc/csharp-windows/rtc-interface-class#class_irtcengine)

## OnEarMonitoringAudioFrame

获得耳返的原始音频数据。

<a id="callback_iaudioframeobserverbase_onearmonitoringaudioframe__prototype"></a>

```text
public virtual bool OnEarMonitoringAudioFrame(AudioFrame audioFrame)
        {
            return true;
        }
```

<a id="callback_iaudioframeobserverbase_onearmonitoringaudioframe__detailed_desc"></a>

为保证耳返的音频数据格式符合预期，你可以在如下两种方法中任选一种，设置耳返音频数据格式：

- 方法一：调用 [SetEarMonitoringAudioFrameParameters](/zh-CN/api-reference/rtc/csharp-windows/audio/audio-raw#api_irtcengine_setearmonitoringaudioframeparameters) 设置音频数据格式后，调用 [RegisterAudioFrameObserver](/zh-CN/api-reference/rtc/csharp-windows/audio/audio-raw#api_imediaengine_registeraudioframeobserver) 注册音频观测器对象，SDK 会根据该方法中的参数计算采样间隔，并根据该采样间隔触发 OnEarMonitoringAudioFrame 回调。
- 方法二：调用 [RegisterAudioFrameObserver](/zh-CN/api-reference/rtc/csharp-windows/audio/audio-raw#api_imediaengine_registeraudioframeobserver) 注册音频观测器对象后，在  回调的返回值中设置具体的音频观测位置，然后在  回调的返回值中设置音频数据格式，SDK 会根据该回调的返回值计算采样间隔，并根据该采样间隔触发 OnEarMonitoringAudioFrame 回调。

<a id="callback_iaudioframeobserverbase_onearmonitoringaudioframe__attention"></a>

:::note
注：

- 方法一的优先级高于方法二，如果已使用方法一设置了音频数据格式，则使用方法二的设置不生效。
:::

<a id="callback_iaudioframeobserverbase_onearmonitoringaudioframe__parameters"></a>

### 参数

### audioFrame

音频原始数据。详见 [AudioFrame](/zh-CN/api-reference/rtc/csharp-windows/class-audioframe)。

<a id="callback_iaudioframeobserverbase_onearmonitoringaudioframe__return_values"></a>

### 返回值

无实际含义。
