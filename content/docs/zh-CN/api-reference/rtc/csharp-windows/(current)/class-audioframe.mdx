## 属性

<ParameterList>
<a id="type"></a>
<Parameter name="type">

音频帧类型，详见 [AUDIO_FRAME_TYPE](/zh-CN/api-reference/rtc/csharp-windows/enum-audioframetype)。

</Parameter>
<a id="samplesperchannel"></a>
<Parameter name="samplesPerChannel">

每个声道的采样点数。

</Parameter>
<a id="bytespersample"></a>
<Parameter name="bytesPerSample">

每个采样点的字节数。对于 PCM 来说，一般使用 16 bit，即两个字节。

</Parameter>
<a id="channels"></a>
<Parameter name="channels">

声道数量(如果是立体声，数据是交叉的)。

<a id="class_audioframe__ul_zxz_2wt_r4b"></a>

- 1: 单声道
- 2: 双声道

</Parameter>
<a id="samplespersec"></a>
<Parameter name="samplesPerSec">

每声道每秒的采样点数。

</Parameter>
<a id="rawbuffer"></a>
<Parameter name="RawBuffer">

声音数据缓存区（如果是立体声，数据是交叉存储的）。

缓存区数据大小 `buffer` = `samples` × `channels` × `bytesPerSample`。

</Parameter>
<a id="rendertimems"></a>
<Parameter name="renderTimeMs">

外部音频帧的渲染时间戳。

你可以使用该时间戳还原音频帧顺序；在有视频的场景中（包含使用外部视频源的场景），该参数可以用于实现音视频同步。

</Parameter>
<a id="avsync_type"></a>
<Parameter name="avsync_type">

保留参数。

</Parameter>
</ParameterList>
