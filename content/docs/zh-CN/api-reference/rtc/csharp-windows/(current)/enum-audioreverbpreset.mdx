### `弃用：`

自 v3.2.0 废弃。

<a id="enum_audioreverbpreset__parameters"></a>

## 枚举值

### `AUDIO_REVERB_OFF`

原声，即关闭本地语音混响。

### `AUDIO_REVERB_FX_KTV`

KTV（增强版）。

### `AUDIO_REVERB_FX_VOCAL_CONCERT`

演唱会（增强版）。

### `AUDIO_REVERB_FX_UNCLE`

大叔。

### `AUDIO_REVERB_FX_SISTER`

小姐姐。

### `AUDIO_REVERB_FX_STUDIO`

录音棚（增强版）。

### `AUDIO_REVERB_FX_POPULAR`

流行（增强版）。

### `AUDIO_REVERB_FX_RNB`

R&B（增强版）。

### `AUDIO_REVERB_FX_PHONOGRAPH`

留声机。
