## RegisterMediaMetadataObserver

注册媒体 metadata 观测器用于接收或发送 metadata。

<a id="api_irtcengine_registermediametadataobserver__prototype"></a>

```text
public abstract int RegisterMediaMetadataObserver(IMetadataObserver observer, METADATA_TYPE type);
```

<a id="api_irtcengine_registermediametadataobserver__detailed_desc"></a>

### 详情

你需要自行实现 [IMetadataObserver](/zh-CN/api-reference/rtc/csharp-windows/rtc-interface-class#class_imetadataobserver) 类并在本方法中指定 metadata 类型。本方法允许你为视频流添加同步的 metadata，用于多样化的直播互动，如发送购物链接、电子优惠券和在线测试。

调用该方法成功后，SDK 会触发 回调。

:::note
注意： 请在 JoinChannel [2/2] 前调用该方法。
:::

<a id="api_irtcengine_registermediametadataobserver__parameters"></a>

### 参数

### observer

metadata 观测器。详见 [IMetadataObserver](/zh-CN/api-reference/rtc/csharp-windows/rtc-interface-class#class_imetadataobserver)。

### type

metadata 类型。目前仅支持 VIDEO_METADATA。详见 [METADATA_TYPE](/zh-CN/api-reference/rtc/csharp-windows/enum-metadatatype)。

<a id="api_irtcengine_registermediametadataobserver__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。
