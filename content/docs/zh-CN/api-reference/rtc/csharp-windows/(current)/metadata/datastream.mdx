## CreateDataStream [1/2]

创建数据流。

<a id="api_irtcengine_createdatastream__prototype"></a>

```text
public abstract int CreateDataStream(ref int streamId, bool reliable, bool ordered);
```

<a id="api_irtcengine_createdatastream__detailed_desc"></a>

<a id="api_irtcengine_createdatastream__desc"></a>

你可以调用该方法创建数据流并提高数据传输的可靠性和有序性。

<a id="api_irtcengine_createdatastream__timing"></a>

### 调用时机

该方法在加入频道前后均可调用。

<a id="api_irtcengine_createdatastream__restriction"></a>

### 调用限制

在 [IRtcEngine](/zh-CN/api-reference/rtc/csharp-windows/rtc-interface-class#class_irtcengine) 生命周期内，每个用户最多只能创建 5 个数据流。离开频道时数据流会被销毁，如需使用需要重新创建数据流。

<a id="api_irtcengine_createdatastream__related"></a>

### 相关回调

将 reliable 设置为 `true` 后，如果接收方 5 秒没有收到发送方所发送的数据，会触发 [OnStreamMessageError](/zh-CN/api-reference/rtc/csharp-windows/metadata/datastream#callback_irtcengineeventhandler_onstreammessageerror) 回调并获得相应报错信息。

<a id="api_irtcengine_createdatastream__parameters"></a>

### 参数

<ParameterList>
<a id="streamid"></a>
<Parameter name="streamId">

输出参数，创建好的数据流 ID。

</Parameter>
<a id="reliable"></a>
<Parameter name="reliable">

是否保证数据可靠性，即接收方是否需要在数据发送后的 5 秒内接收：

- `true`: 接收方 5 秒内会收到发送方所发送的数据，否则会收到 OnStreamMessageError 回调并获得相应报错信息。
- `false`: 接收方不保证收到，就算数据丢失也不会报错。

:::caution
注意： 请确保将 reliable 和 ordered 同时设为 `true` 或同时设为 `false`。
:::

</Parameter>
<a id="ordered"></a>
<Parameter name="ordered">

是否保证数据有序性，即接收方是否需要收到有序的数据：

- `true`: 接收方会按照发送方发送的顺序收到数据包。
- `false`: 接收方不保证按照发送方发送的顺序收到数据包。

</Parameter>
</ParameterList>

<a id="api_irtcengine_createdatastream__return_values"></a>

### 返回值

- 0: 创建数据流成功。
- &lt; 0：方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。

## SendStreamMessage

发送数据流。

<a id="api_irtcengine_sendstreammessage__prototype"></a>

```text
public abstract int SendStreamMessage(int streamId, byte[] data, uint length);
```

<a id="api_irtcengine_sendstreammessage__detailed_desc"></a>

### 详情

调用 [CreateDataStream [2/2]](/zh-CN/api-reference/rtc/csharp-windows/metadata/datastream#api_irtcengine_createdatastream2) 后，你可以调用该方法向频道内所有用户发送数据流消息。

<a id="api_irtcengine_sendstreammessage__limit"></a>

SDK 对该方法的实现进行了如下限制：

- 频道内每个客户端最多可以同时拥有 5 个数据通道，所有数据通道共用的总发包码率限制为 30 KB/s。
- 每个数据通道每秒最多能发送 60 个包，每个包最大为 1 KB。

<a id="api_irtcengine_sendstreammessage__error"></a>

成功调用该方法后，远端会触发 [OnStreamMessage](/zh-CN/api-reference/rtc/csharp-windows/metadata/datastream#callback_irtcengineeventhandler_onstreammessage) 回调，远端用户可以在该回调中获取接收到的流消息；若调用失败，远端会触发 [OnStreamMessageError](/zh-CN/api-reference/rtc/csharp-windows/metadata/datastream#callback_irtcengineeventhandler_onstreammessageerror) 回调。

:::caution
注意：

- 该方法需要在加入频道后、且调用 [CreateDataStream [2/2]](/zh-CN/api-reference/rtc/csharp-windows/metadata/datastream#api_irtcengine_createdatastream2) 创建数据通道之后调用。
- 该方法仅适用于主播用户。
:::
