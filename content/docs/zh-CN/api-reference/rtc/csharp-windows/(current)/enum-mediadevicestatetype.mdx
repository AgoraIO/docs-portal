## 枚举值

### `MEDIA_DEVICE_STATE_IDLE`

0: 设备就绪。

### `MEDIA_DEVICE_STATE_ACTIVE`

1: 设备正在使用。

### `MEDIA_DEVICE_STATE_DISABLED`

2: 设备被禁用。

### `MEDIA_DEVICE_STATE_PLUGGED_IN`

3: 设备已插入。

### `MEDIA_DEVICE_STATE_NOT_PRESENT`

4: 没有此设备。

### `MEDIA_DEVICE_STATE_UNPLUGGED`

8: 设备被拔出。
