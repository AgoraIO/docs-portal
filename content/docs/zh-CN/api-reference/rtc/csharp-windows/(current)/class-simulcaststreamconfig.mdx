<a id="class_simulcaststreamconfig__prototype"></a>

```csharp
public class SimulcastStreamConfig
    {
        public VideoDimensions dimensions;
        public int kBitrate;
        public int framerate;
    };
```

<a id="class_simulcaststreamconfig__parameters"></a>

## 属性

### `dimensions`

视频尺寸。 详见 [VideoDimensions](/zh-CN/api-reference/rtc/csharp-windows/class-videodimensions)。 默认值为视频大流的 50%。

### `kBitrate`

视频码率 (Kbps)，默认值为 -1。该参数无需设置，SDK 会根据你设定的视频分辨率和帧率自动匹配最合适的码率。

### `framerate`

视频帧率 (fps)。默认值为 5。
