## 属性

### featureName

转码推流高级功能的名称，包含 LBHQ（低码率的高清视频功能） 和 VEO（优化的视频编码器功能）。

### opened

是否启用转码推流的高级功能：

- `true`：开启转码推流的高级功能。
- `false`：（默认）关闭转码推流的高级功能。
