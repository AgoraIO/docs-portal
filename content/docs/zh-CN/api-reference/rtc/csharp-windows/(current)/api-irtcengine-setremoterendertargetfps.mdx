<a id="api_irtcengine_setremoterendertargetfps__detailed_desc"></a>

<a id="api_irtcengine_setremoterendertargetfps__scenario"></a>

## 适用场景

在对视频渲染帧率要求不高的场景（例如：屏幕共享、在线教育）或者远端使用中低端设备的场景下，你可以调用该方法设置视频在远端渲染的最大帧率，SDK 进行远端视频渲染的实际帧率会尽量接近该值，从而减小 CPU 消耗、提升系统性能。

<a id="api_irtcengine_setremoterendertargetfps__timing"></a>

## 调用时机

该方法在加入频道前后均可调用。

<a id="api_irtcengine_setremoterendertargetfps__restriction"></a>

## 调用限制

无。

<a id="api_irtcengine_setremoterendertargetfps__parameters"></a>

## 参数

### targetFps

最大渲染帧率 (fps)。支持的参数值为：1、7、10、15、24、30、60。

:::caution
警告： 请将此参数设置为低于视频实际帧率的渲染帧率，否则设置将不会生效。
:::

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。
