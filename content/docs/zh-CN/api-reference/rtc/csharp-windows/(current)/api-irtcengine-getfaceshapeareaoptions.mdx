<a id="api_irtcengine_getfaceshapeareaoptions__prototype"></a>

```csharp
public abstract int GetFaceShapeAreaOptions(FACE_SHAPE_AREA shapeArea, ref FaceShapeAreaOptions options, MEDIA_SOURCE_TYPE type = MEDIA_SOURCE_TYPE.PRIMARY_CAMERA_SOURCE);
```

<a id="api_irtcengine_getfaceshapeareaoptions__detailed_desc"></a>

调用该方法可以获取美型部位当前设置的参数信息。

<a id="api_irtcengine_getfaceshapeareaoptions__scenario"></a>

## 适用场景

用户在 App 中打开美型部位和修饰力度菜单时，你可以调用该方法获取当前的美型部位选项，然后根据结果刷新用户界面中的菜单，并更新 UI。

<a id="api_irtcengine_getfaceshapeareaoptions__timing"></a>

## 调用时机

请在 [EnableVideo](/zh-CN/api-reference/rtc/csharp-windows/video-basic#api_irtcengine_enablevideo) 之后调用该方法。

<a id="api_irtcengine_getfaceshapeareaoptions__restriction"></a>

## 调用限制

无。

<a id="api_irtcengine_getfaceshapeareaoptions__parameters"></a>

## 参数

### `shapeArea`

美型部位。详见 [FACE_SHAPE_AREA](/zh-CN/api-reference/rtc/csharp-windows/enum-faceshapearea)。

### `options`

美型部位选项，详见 [FaceShapeAreaOptions](/zh-CN/api-reference/rtc/csharp-windows/class-faceshapeareaoptions)。

### `type`

效果应用的媒体源类型。详见 [MEDIA_SOURCE_TYPE](/zh-CN/api-reference/rtc/csharp-windows/enum-mediasourcetype)。

:::warning[注意]
在该方法中，该参数仅支持以下两种设置：

- 使用摄像头采集本地视频时，请保持默认值 PRIMARY_CAMERA_SOURCE。
- 如果要使用自定义采集的视频，将该参数设置为 CUSTOM_VIDEO_SOURCE。
:::

<a id="api_irtcengine_getfaceshapeareaoptions__return_values"></a>

## 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。 详见 [错误码](https://doc.shengwang.cn/api-ref/rtc/unity/error-code) 了解详情和解决建议。
