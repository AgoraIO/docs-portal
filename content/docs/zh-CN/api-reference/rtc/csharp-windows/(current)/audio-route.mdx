## 音频路由

<a id="api_irtcengine_setrouteincommunicationmode"></a>

## SetRouteInCommunicationMode

选择通话音量模式下的音频路由。

<a id="api_irtcengine_setrouteincommunicationmode__prototype"></a>

```csharp
public abstract int SetRouteInCommunicationMode(int route);
```

<a id="api_irtcengine_setrouteincommunicationmode__detailed_desc"></a>

该方法用于在通话音量模式（[MODE_IN_COMMUNICATION](https://developer.android.google.cn/reference/kotlin/android/media/AudioManager?hl=en#mode_in_communication) ）下，将音频路由从蓝牙耳机切换为听筒、有线耳机或扬声器。

<a id="api_irtcengine_setrouteincommunicationmode__timing"></a>

### 调用时机

加入频道前后均可调用。

<a id="api_irtcengine_setrouteincommunicationmode__restriction"></a>

### 调用限制

<a id="api_irtcengine_setrouteincommunicationmode__related"></a>

### 相关回调

成功调用该方法后，SDK 会触发 [OnAudioRoutingChanged](/zh-CN/api-reference/rtc/csharp-windows/audio-route#callback_irtcengineeventhandler_onaudioroutingchanged) 回调，报告当前的音频路由。

<a id="api_irtcengine_setrouteincommunicationmode__parameters"></a>

### 参数

#### `route`

期望使用的音频路由:

- -1：系统默认的音频路由。
- 0：带麦克风的耳机。
- 1：听筒。
- 2：不带麦克风的耳机。
- 3：设备自带的扬声器。
- 4：（暂不支持）外接的扬声器。
- 5：蓝牙耳机。
- 6：USB 设备。

<a id="api_irtcengine_setrouteincommunicationmode__return_values"></a>

### 返回值

无实际意义。
