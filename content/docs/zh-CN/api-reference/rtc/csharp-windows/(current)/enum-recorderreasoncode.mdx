## 枚举值

### RECORDER_REASON_NONE

0: 一切正常。

### RECORDER_ERROR_WRITE_FAILED

1: 录制文件写入失败。

### RECORDER_ERROR_NO_STREAM

2: 没有可录制的音视频流或者录制的音视频流中断超过 5 秒。

### RECORDER_ERROR_OVER_MAX_DURATION

3: 录制时长超出上限。

### RECORDER_ERROR_CONFIG_CHANGED

4: 录制配置改变。
