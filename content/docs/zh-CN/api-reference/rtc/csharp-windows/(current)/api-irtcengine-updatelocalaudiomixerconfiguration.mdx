```text
 public abstract int UpdateLocalAudioMixerConfiguration(LocalAudioMixerConfiguration config);
```

<a id="api_irtcengine_updatelocalaudiomixerconfiguration__detailed_desc"></a>

调用 [StartLocalAudioMixer](/zh-CN/api-reference/rtc/csharp-windows/api-irtcengine-startlocalaudiomixer) 后，如果你希望更新本地音频合流的配置，请调用该方法。

<a id="api_irtcengine_updatelocalaudiomixerconfiguration__timing"></a>

## 调用时机

该方法需要在 StartLocalAudioMixer 之后调用。

<a id="api_irtcengine_updatelocalaudiomixerconfiguration__restriction"></a>

## 调用限制

为了保证音频质量，建议参与本地合流的音频流数量不超过 10 个。

<a id="api_irtcengine_updatelocalaudiomixerconfiguration__parameters"></a>

## 参数

<ParameterList>
<a id="config"></a>
<Parameter name="config">

本地音频合流的配置。详见 [LocalAudioMixerConfiguration](/zh-CN/api-reference/rtc/csharp-windows/class-localaudiomixerconfiguration)。

</Parameter>
</ParameterList>

<a id="api_irtcengine_updatelocalaudiomixerconfiguration__return_values"></a>

## 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。

  - -7：IRtcEngine 对象尚未初始化。你需要在调用该方法前成功初始化 IRtcEngine 对象。
