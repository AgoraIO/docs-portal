## 枚举值

:::warning[注意]
SDK 目前不支持 Alpha 通道。传入的 Alpha 值将被丢弃。
:::

### `VIDEO_PIXEL_DEFAULT`

0: 原始视频像素格式。

### `VIDEO_PIXEL_I420`

1: I420 格式。

### `VIDEO_PIXEL_RGBA`

4: RGBA 格式。

### `VIDEO_PIXEL_I422`

16: I422 格式。
