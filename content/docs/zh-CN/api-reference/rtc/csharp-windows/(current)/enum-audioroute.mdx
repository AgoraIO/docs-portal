## 枚举值

### ROUTE_DEFAULT

-1: 使用默认的音频路由。

### ROUTE_HEADSET

0: 音频路由为带麦克风的耳机。

### ROUTE_EARPIECE

1: 音频路由为听筒。

### ROUTE_HEADSETNOMIC

2: 音频路由为不带麦克风的耳机。

### ROUTE_SPEAKERPHONE

3: 音频路由为设备自带的扬声器。

### ROUTE_LOUDSPEAKER

4：预留。

### ROUTE_BLUETOOTH_DEVICE_HFP

5: 音频路由为使用 HFP 协议的蓝牙设备。

### ROUTE_USB

6：预留。

### ROUTE_HDMI

7：预留。

### ROUTE_DISPLAYPORT

8：预留。

### ROUTE_AIRPLAY

9：预留。

### ROUTE_BLUETOOTH_DEVICE_A2DP

10: 音频路由为使用 A2DP 协议的蓝牙设备。
