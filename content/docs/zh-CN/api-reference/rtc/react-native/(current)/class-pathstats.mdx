<a id="class_pathstats__prototype"></a>

```typescript
export class PathStats {
type?: MultipathType;
txKBitRate?: number;
rxKBitRate?: number;
}
```

<a id="class_pathstats__detailed_desc"></a>

### `自从`

自 v4.6.2 版本新增。

<a id="class_pathstats__parameters"></a>

## 属性

### `type`

网络路径的类型。详见 [MultipathType](/zh-CN/api-reference/rtc/react-native/enum-multipathtype)。

### `txKBitRate`

该路径的传输码率，单位为 Kbps。

### `rxKBitRate`

该路径的接收码率，单位为 Kbps。
