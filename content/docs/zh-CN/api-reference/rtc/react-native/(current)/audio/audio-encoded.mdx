## registerAudioEncodedFrameObserver

注册音频编码数据观测器。

<a id="api_irtcengine_registeraudioencodedframeobserver__prototype"></a>

```text
abstract registerAudioEncodedFrameObserver(
    config: AudioEncodedFrameObserverConfig,
    observer: IAudioEncodedFrameObserver
  ): number;
```

<a id="api_irtcengine_registeraudioencodedframeobserver__detailed_desc"></a>

:::note
注：

- 请在加入频道后调用该方法。
- 由于该方法和 [startAudioRecording](/zh-CN/api-reference/rtc/react-native/recording#api_irtcengine_startaudiorecording3) 都会设置音频内容和音质，不建议该方法和 [startAudioRecording](/zh-CN/api-reference/rtc/react-native/recording#api_irtcengine_startaudiorecording3) 一起使用。否则，只有后调用的方法会生效。
:::

## onMixedAudioEncodedFrame

获取本地和所有远端用户混音后的音频编码数据。

<a id="callback_iaudioencodedframeobserver_onmixedaudioencodedframe__prototype"></a>

```text
onMixedAudioEncodedFrame?(
    frameBuffer: Uint8Array,
    length: number,
    audioEncodedFrameInfo: EncodedAudioFrameInfo
  ): void;
```

调用 [registerAudioEncodedFrameObserver](/zh-CN/api-reference/rtc/react-native/audio/audio-encoded#api_irtcengine_registeraudioencodedframeobserver) 并将音频编码内容设为 AudioEncodedFrameObserverPositionMixed 后，你可以通过该回调获取本地和所有远端用户混音、编码后的音频数据。
