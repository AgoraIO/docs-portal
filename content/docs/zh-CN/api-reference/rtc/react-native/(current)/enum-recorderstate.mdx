## 枚举值

### `RecorderStateError`

-1: 音视频流录制出错，错误原因详见 [RecorderReasonCode](/zh-CN/api-reference/rtc/react-native/enum-recorderreasoncode)。

### `RecorderStateStart`

2: 音视频流录制开始。

### `RecorderStateStop`

3: 音视频流录制停止。
