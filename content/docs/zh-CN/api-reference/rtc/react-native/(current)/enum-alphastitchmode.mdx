## 枚举值

### NoAlphaStitch

0：（默认）仅视频帧，即 `alphaBuffer` 不和视频帧拼接。

### AlphaStitchUp

1：`alphaBuffer` 位于视频帧的上方。

### AlphaStitchBelow

2：`alphaBuffer` 位于视频帧的下方。

### AlphaStitchLeft

3：`alphaBuffer` 位于视频帧的左侧。

### AlphaStitchRight

4：`alphaBuffer` 位于视频帧的右侧。
