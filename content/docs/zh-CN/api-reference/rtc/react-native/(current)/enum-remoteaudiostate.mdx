## 枚举值

<ParameterList>
<a id="remoteaudiostatestopped"></a>
<Parameter name="RemoteAudioStateStopped">

0: 远端音频默认初始状态。在 `RemoteAudioReasonLocalMuted`、`RemoteAudioReasonRemoteMuted` 或 `RemoteAudioReasonRemoteOffline` 的情况下，会报告该状态。

</Parameter>
<a id="remoteaudiostatestarting"></a>
<Parameter name="RemoteAudioStateStarting">

1: 本地用户已接收远端音频首包。

</Parameter>
<a id="remoteaudiostatedecoding"></a>
<Parameter name="RemoteAudioStateDecoding">

2: 远端音频流正在解码，正常播放。在 `RemoteAudioReasonNetworkRecovery`、`RemoteAudioReasonLocalUnmuted` 或 `RemoteAudioReasonRemoteUnmuted` 的情况下，会报告该状态。

</Parameter>
<a id="remoteaudiostatefrozen"></a>
<Parameter name="RemoteAudioStateFrozen">

3: 远端音频流卡顿。在 `RemoteAudioReasonNetworkCongestion` 的情况下，会报告该状态。

</Parameter>
<a id="remoteaudiostatefailed"></a>
<Parameter name="RemoteAudioStateFailed">

4: 远端音频流播放失败。在 `RemoteAudioReasonInternal` 的情况下，会报告该状态。

</Parameter>
</ParameterList>
