## enableDualStreamMode

在发送端开启或关闭双流模式并设置视频小流。

<a id="api_irtcengine_enabledualstreammode3__prototype"></a>

```text
abstract enableDualStreamMode(
    enabled: boolean,
    streamConfig?: SimulcastStreamConfig
  ): number;
```

<a id="api_irtcengine_enabledualstreammode3__detailed_desc"></a>

<a id="废弃"></a>

:::error[废弃]
弃用： 从 v4.2.0 起废弃，请改用 [setDualStreamMode](/zh-CN/api-reference/rtc/react-native/publishnsubscribe#api_irtcengine_setdualstreammode2)。
:::

你可以在发流端调用该方法开启或关闭双流模式。双流指视频大流和视频小流：

- 视频大流：高分辨率、高帧率的视频流。
- 视频小流：低分辨率、低帧率的视频流。

开启双流模式后，你可以在收流端调用 [setRemoteVideoStreamType](/zh-CN/api-reference/rtc/react-native/publishnsubscribe#api_irtcengine_setremotevideostreamtype) 选择接收视频大流或视频小流。

:::note
注：

- 该方法适用于发送端发送的所有类型的流，包括且不限于来自摄像头采集的视频流、屏幕共享流、自定义采集的视频流。
- 如果需要在多频道场景下开启视频双流，可以调用 [enableDualStreamModeEx](/zh-CN/api-reference/rtc/react-native/publishnsubscribe#api_irtcengineex_enabledualstreammodeex) 方法。
- 该方法可以在加入频道前后调用。
:::

## muteAllRemoteAudioStreams

取消或恢复订阅所有远端用户的音频流。

<a id="api_irtcengine_muteallremoteaudiostreams__prototype"></a>

```text
abstract muteAllRemoteAudioStreams(mute: boolean): number;
```

<a id="api_irtcengine_muteallremoteaudiostreams__detailed_desc"></a>

成功调用该方法后，本地用户会取消或恢复订阅所有远端用户的音频流，包括在调用该方法后加入频道的用户的音频流。

:::note
注： SDK 默认在加入频道时订阅所有远端用户的音频流，如果要修改此行为，可以在调用 [joinChannel](/zh-CN/api-reference/rtc/react-native/channel#api_irtcengine_joinchannel2) 加入频道时设置 `autoSubscribeAudio` 为 false，即可在加入频道时取消订阅所有用户的音频流。
如果在调用该方法之后又调用了 [enableAudio](/zh-CN/api-reference/rtc/react-native/audio/audio-basic#api_irtcengine_enableaudio) 或 [disableAudio](/zh-CN/api-reference/rtc/react-native/audio/audio-basic#api_irtcengine_disableaudio)，则后调用的方法会生效。

## setRemoteDefaultVideoStreamType

设置默认订阅的视频流类型。

<a id="api_irtcengine_setremotedefaultvideostreamtype__prototype"></a>

```text
abstract setRemoteDefaultVideoStreamType(streamType: VideoStreamType): number;
```

<a id="api_irtcengine_setremotedefaultvideostreamtype__detailed_desc"></a>

取决于发送端的默认行为和调用 [setDualStreamMode](/zh-CN/api-reference/rtc/react-native/publishnsubscribe#api_irtcengine_setdualstreammode2) 的具体设置，接收端调用该方法分为以下几种情况：

- SDK 默认在发送端开启小流自适应模式 (`AutoSimulcastStream`)，即：发送端仅发送大流，仅主播身份的接收端可以调用该方法发起小流申请，发送端收到申请后开始自动发送小流，此时频道内所有用户均可调用该方法切换到小流订阅模式。
- 当发送端调用 [setDualStreamMode](/zh-CN/api-reference/rtc/react-native/publishnsubscribe#api_irtcengine_setdualstreammode2) 并将 `mode` 设置为 `DisableSimulcastStream`（始终不发送小流），则调用该方法不生效。

在接收视频小流时，SDK 会根据视频窗口的大小动态调整对应视频流的大小，以节约带宽和计算资源。视频小流默认的宽高比和视频大流的宽高比一致。根据当前大流的宽高比，系统会自动分配小流的分辨率、帧率及码率。

:::note
注： 如果你既调用了该方法，也调用了 [setRemoteVideoStreamType](/zh-CN/api-reference/rtc/react-native/publishnsubscribe#api_irtcengine_setremotevideostreamtype)，则 SDK 以 [setRemoteVideoStreamType](/zh-CN/api-reference/rtc/react-native/publishnsubscribe#api_irtcengine_setremotevideostreamtype) 中的设置为准。
:::

<a id="api_irtcengine_setremotevideosubscriptionoptions__prototype"></a>

```text
abstract setRemoteVideoSubscriptionOptions(
    uid: number,
    options: VideoSubscriptionOptions
  ): number;
```

<a id="api_irtcengine_setremotevideosubscriptionoptions__detailed_desc"></a>

当远端发送双流时，可调用此方法来设置远端视频流的订阅选项。SDK 对远端视频流的默认订阅行为取决于注册的视频观测器类型：

- 如果注册的是 [IVideoFrameObserver](/zh-CN/api-reference/rtc/react-native/rtc-interface-class#class_ivideoframeobserver) 观测器，则默认订阅原始数据和编码后的数据。
- 如果注册的是 [IVideoEncodedFrameObserver](/zh-CN/api-reference/rtc/react-native/rtc-interface-class#class_ivideoencodedframeobserver) 观测器，则默认仅订阅编码后的数据。
- 如果注册了两种观测器，则默认跟随后注册的视频观测器。举例来说，如果后注册的是 [IVideoFrameObserver](/zh-CN/api-reference/rtc/react-native/rtc-interface-class#class_ivideoframeobserver) 观测器，则默认订阅原始数据和编码后的数据。

如果你想修改以上默认行为，或者想针对不同 `uid` 设置不同的订阅选项，可调用该方法设置。

## setSubscribeAudioAllowlist

设置音频订阅白名单。

<a id="api_irtcengine_setsubscribeaudioallowlist__prototype"></a>

```text
abstract setSubscribeAudioAllowlist(
    uidList: number[],
    uidNumber: number
  ): number;
```

<a id="api_irtcengine_setsubscribeaudioallowlist__detailed_desc"></a>

你可以调用该方法指定想要订阅的音频流。

:::note
注：

- 该方法在加入频道前后均可调用。
- 音频订阅白名单不受 [muteRemoteAudioStream](/zh-CN/api-reference/rtc/react-native/publishnsubscribe#api_irtcengine_muteremoteaudiostream)、[muteAllRemoteAudioStreams](/zh-CN/api-reference/rtc/react-native/publishnsubscribe#api_irtcengine_muteallremoteaudiostreams) 以及 [ChannelMediaOptions](/zh-CN/api-reference/rtc/react-native/class-channelmediaoptions) 中的 `autoSubscribeAudio` 的影响。
- 设置订阅白名单后，如果离开当前频道后再重新加入频道，白名单依然生效。
- 如果某个用户同时在音频订阅黑名单和白名单中，仅订阅黑名单生效。
:::

<a id="api_irtcengine_setsubscribeaudioallowlist__parameters"></a>

### 参数

<ParameterList>
<a id="uidlist"></a>
<Parameter name="uidList">

音频订阅白名单的用户 ID 列表。
如果你想指定订阅某一发流用户的音频流，将该用户的 ID 加入此列表中。如果你想要将某一用户从订阅白名单中移除，需要重新调用 [setSubscribeAudioAllowlist](/zh-CN/api-reference/rtc/react-native/publishnsubscribe#api_irtcengine_setsubscribeaudioallowlist) 方法更新音频订阅白名单的用户 ID 列表，使其不包含你想移除的用户的 `uid`。

</Parameter>
<a id="uidnumber"></a>
<Parameter name="uidNumber">

白名单用户 ID 列表中的用户数量。

</Parameter>
</ParameterList>

<a id="api_irtcengine_setsubscribeaudioallowlist__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。

- 视频订阅黑名单不受 [muteRemoteVideoStream](/zh-CN/api-reference/rtc/react-native/publishnsubscribe#api_irtcengine_muteremotevideostream)、[muteAllRemoteVideoStreams](/zh-CN/api-reference/rtc/react-native/publishnsubscribe#api_irtcengine_muteallremotevideostreams) 以及 [ChannelMediaOptions](/zh-CN/api-reference/rtc/react-native/class-channelmediaoptions) 中的 `autoSubscribeVideo` 的影响。
- 设置订阅黑名单后，如果离开当前频道后再重新加入频道，黑名单依然生效。
- 如果某个用户同时在音频订阅黑名单和白名单中，仅订阅黑名单生效。
:::
