## 枚举值

### `VideoCodecNone`

0：（默认）不指定编解码格式。SDK 会根据当前视频流的分辨率、设备性能自动匹配适合的编解码格式。

### `VideoCodecVp8`

1：标准 VP8。

### `VideoCodecH264`

2：标准 H.264。

### `VideoCodecH265`

3：标准 H.265。

### `VideoCodecGeneric`

6：Generic。本类型主要用于传输视频裸数据(比如用户已加密的视频帧)，该类型视频帧以回调的形式返回给用户，需要用户自行解码与渲染。

### `VideoCodecGenericJpeg`

20：Generic JPEG。本类型所需的算力较小，可用于算力有限的 IoT 设备。
