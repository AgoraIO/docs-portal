<a id="class_videoformat__prototype"></a>

```typescript
export class VideoFormat {
  
  width?: number;
  
  height?: number;
  
  fps?: number;
}
```

<a id="class_videoformat__parameters"></a>

## 属性

### `width`

视频帧的宽度（px）。默认值为 960。

### `height`

视频帧的高度（px）。默认值为 540.

### `fps`

视频帧的帧率。默认值为 15。
