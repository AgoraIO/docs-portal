<a id="api_irtcengine_adjustrecordingsignalvolume"></a>

## adjustRecordingSignalVolume

调节音频采集信号音量。

<a id="api_irtcengine_adjustrecordingsignalvolume__prototype"></a>

```typescript
abstract adjustRecordingSignalVolume(volume: number): number;
```

<a id="api_irtcengine_adjustrecordingsignalvolume__detailed_desc"></a>

如果你只需将音频信号静音，建议你使用 [muteRecordingSignal](/zh-CN/api-reference/rtc/react-native/audio-capture#api_irtcengine_muterecordingsignal)。

<a id="api_irtcengine_adjustrecordingsignalvolume__timing"></a>

### 调用时机

加入频道前后均可调用。

<a id="api_irtcengine_adjustrecordingsignalvolume__parameters"></a>

### 参数

#### `volume`

音量，取值范围为 [0,400]。

- 0: 静音。
- 100: （默认）原始音量。
- 400: 原始音量的 4 倍，自带溢出保护。

<a id="api_irtcengine_adjustrecordingsignalvolume__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/rn/error-code)了解详情和解决建议。

### 所属接口类
- [IRtcEngine](/zh-CN/api-reference/rtc/react-native/rtc-interface-class#class_irtcengine)

## enableInEarMonitoring

开启耳返功能。

<a id="api_irtcengine_enableinearmonitoring2__prototype"></a>

```typescript
abstract enableInEarMonitoring(
    enabled: boolean,
    includeAudioFilters: EarMonitoringFilterType
  ): number;
```

<a id="api_irtcengine_enableinearmonitoring2__detailed_desc"></a>

该方法用于打开或关闭耳返功能。

:::info[注]
用户必须使用耳机（有线和蓝牙均可）才能听到耳返效果。
:::

<a id="api_irtcengine_enableinearmonitoring2__timing"></a>

### 调用时机

加入频道前后均可调用。

<a id="api_irtcengine_enableinearmonitoring2__parameters"></a>

### 参数

#### `enabled`

开启/关闭耳返功能:

- true: 开启耳返功能。
- false: （默认）关闭耳返功能。

#### `includeAudioFilters`

耳返 Audio filter 类型。详见 [EarMonitoringFilterType](/zh-CN/api-reference/rtc/react-native/enum-earmonitoringfiltertype)。

<a id="api_irtcengine_enableinearmonitoring2__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/rn/error-code)了解详情和解决建议。

  - -8: 请确保当前的音频路由为蓝牙或耳机。

### 所属接口类
- [IRtcEngine](/zh-CN/api-reference/rtc/react-native/rtc-interface-class#class_irtcengine)

## enableLocalAudio

开启或关闭本地音频采集。

<a id="api_irtcengine_enablelocalaudio__prototype"></a>

```typescript
abstract enableLocalAudio(enabled: boolean): number;
```

<a id="api_irtcengine_enablelocalaudio__detailed_desc"></a>

当用户加入频道时，音频功能默认是开启的。该方法可以关闭或重新开启本地音频功能，即停止或重新开始本地音频采集。 该方法与 [muteLocalAudioStream](/zh-CN/api-reference/rtc/react-native/publishnsubscribe#api_irtcengine_mutelocalaudiostream) 的区别在于：

- [enableLocalAudio](/zh-CN/api-reference/rtc/react-native/audio-capture#api_irtcengine_enablelocalaudio): 开启或关闭本地音频采集及处理。使用 [enableLocalAudio](/zh-CN/api-reference/rtc/react-native/audio-capture#api_irtcengine_enablelocalaudio) 关闭或开启本地采集后，本地听远端播放会有短暂中断。
- [muteLocalAudioStream](/zh-CN/api-reference/rtc/react-native/publishnsubscribe#api_irtcengine_mutelocalaudiostream): 停止或继续发送本地音频流，不影响音频的采集状态。

<a id="api_irtcengine_enablelocalaudio__scenario"></a>

### 适用场景

该方法不影响远端音频流的接收和播放。 `enableLocalAudio(false)` 适用于只接收远端音频而不发送本地采集音频的场景。

<a id="api_irtcengine_enablelocalaudio__timing"></a>

### 调用时机

该方法在加入频道前后均可调用。在加入频道前调用只能设置设备状态，在加入频道后才会立即生效。

<a id="api_irtcengine_enablelocalaudio__related"></a>

### 相关回调

音频功能关闭或重新开启后，会收到 [onLocalAudioStateChanged](/zh-CN/api-reference/rtc/react-native/audio-basic#callback_irtcengineeventhandler_onlocalaudiostatechanged) 回调，并报告 `LocalAudioStreamStateStopped` (0) 或 `LocalAudioStreamStateRecording` (1)。

<a id="api_irtcengine_enablelocalaudio__parameters"></a>

### 参数

#### `enabled`

- true: 重新开启本地音频功能，即开启本地音频采集（默认）；
- false: 关闭本地音频功能，即停止本地音频采集。

<a id="api_irtcengine_enablelocalaudio__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/rn/error-code)了解详情和解决建议。

### 所属接口类
- [IRtcEngine](/zh-CN/api-reference/rtc/react-native/rtc-interface-class#class_irtcengine)

## muteRecordingSignal

是否将录音信号静音。

<a id="api_irtcengine_muterecordingsignal__prototype"></a>

```typescript
abstract muteRecordingSignal(mute: boolean): number;
```

<a id="api_irtcengine_muterecordingsignal__detailed_desc"></a>

如果你已经调用 [adjustRecordingSignalVolume](/zh-CN/api-reference/rtc/react-native/audio-capture#api_irtcengine_adjustrecordingsignalvolume) 调节了音频采集信号音量，则调用该方法并设置为 true 时，SDK 的行为如下：

1. 记录调节后的音量。
2. 将音频采集信号静音。

当你再次调用该方法并设置为 false 时，录音信号会恢复为静音前 SDK 记录的音量。

<a id="api_irtcengine_muterecordingsignal__timing"></a>

### 调用时机

加入频道前后均可调用。

<a id="api_irtcengine_muterecordingsignal__parameters"></a>

### 参数

#### `mute`

- true: 静音。
- false:（默认）原始音量。

<a id="api_irtcengine_muterecordingsignal__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/rn/error-code)了解详情和解决建议。

### 所属接口类
- [IRtcEngine](/zh-CN/api-reference/rtc/react-native/rtc-interface-class#class_irtcengine)
