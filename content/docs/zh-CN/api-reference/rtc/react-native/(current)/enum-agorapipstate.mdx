<a id="enum_agorapipstate__detailed_desc"></a>

### `自从`

自 v4.6.2 版本新增。

<a id="enum_agorapipstate__parameters"></a>

## 枚举值

### `pipStateStarted`

0：画中画模式已成功启动。

### `pipStateStopped`

1：画中画模式已停止。

### `pipStateFailed`

2：画中画模式启动失败或遇到错误。
