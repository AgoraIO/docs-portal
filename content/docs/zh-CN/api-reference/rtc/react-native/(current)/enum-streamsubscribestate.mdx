<a id="substatenosubscribed"></a>
<Parameter name="SubStateNoSubscribed">

1: 订阅失败。可能是因为：

- 远端用户：

  - 调用 [muteLocalAudioStream](/zh-CN/api-reference/rtc/react-native/publishnsubscribe#api_irtcengine_mutelocalaudiostream)(true) 或 [muteLocalVideoStream](/zh-CN/api-reference/rtc/react-native/publishnsubscribe#api_irtcengine_mutelocalvideostream)(true) 停止发送本地媒体流。
  - 调用 [disableAudio](/zh-CN/api-reference/rtc/react-native/audio/audio-basic#api_irtcengine_disableaudio) 或 [disableVideo](/zh-CN/api-reference/rtc/react-native/video/video-basic#api_irtcengine_disablevideo) 关闭本地音频或视频模块。
  - 调用 [enableLocalAudio](/zh-CN/api-reference/rtc/react-native/audio/audio-capture#api_irtcengine_enablelocalaudio)(false) 或 [enableLocalVideo](/zh-CN/api-reference/rtc/react-native/video/video-basic#api_irtcengine_enablelocalvideo)(false) 关闭本地音频或视频采集。
  - 用户角色为观众。
- 本地用户调用以下方法停止接收远端媒体流：

  - 调用 [muteRemoteAudioStream](/zh-CN/api-reference/rtc/react-native/publishnsubscribe#api_irtcengine_muteremoteaudiostream)(true)、 [muteAllRemoteAudioStreams](/zh-CN/api-reference/rtc/react-native/publishnsubscribe#api_irtcengine_muteallremoteaudiostreams)(true) 停止接收远端音频流。
  - 调用 [muteRemoteVideoStream](/zh-CN/api-reference/rtc/react-native/publishnsubscribe#api_irtcengine_muteremotevideostream)(true)、 [muteAllRemoteVideoStreams](/zh-CN/api-reference/rtc/react-native/publishnsubscribe#api_irtcengine_muteallremotevideostreams)(true) 停止接收远端视频流。

</Parameter>
