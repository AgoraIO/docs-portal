description: "ContentInspectModule 结构体，用于配置本地截图上传的频率。"
---
<a id="class_contentinspectmodule__prototype"></a>

```typescript
export class ContentInspectModule {

  type?: ContentInspectType;

  interval?: VideoModulePosition;

  position?: VideoModulePosition;
}
```

<a id="class_contentinspectmodule__parameters"></a>

## 属性

### `type`

功能模块的类型。详见 [ContentInspectType](/zh-CN/api-reference/rtc/react-native/enum-contentinspecttype)。

### `interval`

本地截图上传的间隔，单位为秒，取值必须大于 0。默认值为 0，表示不进行截图上传。推荐值为 10 秒，你也可以根据业务需求自行调整。

### `position`

视频观察器的位置。详见 [VideoModulePosition](/zh-CN/api-reference/rtc/react-native/enum-videomoduleposition)。
