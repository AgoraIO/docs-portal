## startRtmpStreamWithoutTranscoding

开始非转码推流。

<a id="api_irtcengine_startrtmpstreamwithouttranscoding__prototype"></a>

```typescript
abstract startRtmpStreamWithoutTranscoding(url: string): number;
```

<a id="api_irtcengine_startrtmpstreamwithouttranscoding__detailed_desc"></a>

声网推荐你使用更加完善的服务端推流功能，详见[实现服务端旁路推流](/zh-CN/realtime-media/media-push)。 调用该方法，你可以向指定的旁路推流地址推送直播音视频流。该方法每次只能向一个地址推送媒体流，如果你需要向多个地址转码推流，则需多次调用该方法。 调用该方法后，SDK 会在本地触发 [onRtmpStreamingStateChanged](/zh-CN/api-reference/rtc/react-native/cloud-media-relay/media-push#callback_irtcengineeventhandler_onrtmpstreamingstatechanged) 回调，报告推流的状态。

:::info[注]
- 请在加入频道后调用该方法。
- 只有直播场景下的主播才能调用该方法。
- 调用该方法推流失败后，如果你想要重新推流，那么请你务必先调用 stopRtmpStream，再调用该方法重推，否则 SDK 会返回与上次推流失败时一样的错误码。
:::

<a id="api_irtcengine_startrtmpstreamwithouttranscoding__parameters"></a>

### 参数

#### `url`

旁路推流地址。格式为 RTMP 或 RTMPS。字符长度不能超过 1024 字节。不支持中文字符等特殊字符。

<a id="api_irtcengine_startrtmpstreamwithouttranscoding__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](/zh-CN/realtime-media/rtc/reference/error-code)了解详情和解决建议。
  - -2：URL 或转码属性参数错误，请检查你的 URL 或参数设置。
  - -7：调用该方法前，未初始化 SDK。
  - -19：该旁路推流 URL 已在使用中，请使用其他旁路推流 URL。

### 所属接口类
- [IRtcEngine](/zh-CN/api-reference/rtc/react-native/rtc-interface-class#class_irtcengine)

## startRtmpStreamWithTranscoding

<a id="api_irtcengine_startrtmpstreamwithtranscoding__prototype"></a>

```typescript
abstract startRtmpStreamWithTranscoding(
    url: string,
    transcoding: LiveTranscoding
```

:::info[注]
- 请在加入频道后调用该方法。
- 只有直播场景下的主播才能调用该方法。
- 调用该方法推流失败后，如果你想要重新推流，那么请你务必先调用 stopRtmpStream，再调用该方法重推，否则 SDK 会返回与上次推流失败时一样的错误码。
:::

<a id="api_irtcengine_startrtmpstreamwithtranscoding__parameters"></a>

旁路推流地址。格式为 RTMP 或 RTMPS。字符长度不能超过 1024 字节。不支持中文字符等特殊字符。

#### `transcoding`

旁路推流的转码属性，详见 [LiveTranscoding](/zh-CN/api-reference/rtc/react-native/class-livetranscoding)。

## onRtmpStreamingStateChanged

旁路推流状态发生改变回调。

<a id="callback_irtcengineeventhandler_onrtmpstreamingstatechanged__prototype"></a>

```typescript
onRtmpStreamingStateChanged?(
    url: string,
    state: RtmpStreamPublishState,
    reason: RtmpStreamPublishReason
  ): void;
```

<a id="callback_irtcengineeventhandler_onrtmpstreamingstatechanged__detailed_desc"></a>

旁路推流状态发生改变时，SDK会触发该回调，并在回调中明确状态发生改变的 URL 地址及当前推流状态。该回调方便推流用户了解当前的推流状态；推流出错时，你可以通过返回的错误码了解出错的原因，方便排查问题。

<a id="callback_irtcengineeventhandler_onrtmpstreamingstatechanged__parameters"></a>

### 参数

#### `url`

推流状态发生改变的 URL 地址。

#### `state`

当前的推流状态，详见 [RtmpStreamPublishState](/zh-CN/api-reference/rtc/react-native/enum-rtmpstreampublishstate)。

#### `reason`

推流状态改变的原因，详见 [RtmpStreamPublishReason](/zh-CN/api-reference/rtc/react-native/enum-rtmpstreampublishreason)。

### 所属接口类
- [IRtcEngineEventHandler](/zh-CN/api-reference/rtc/react-native/rtc-interface-class#class_irtcengineeventhandler)

## onTranscodingUpdated

旁路推流转码设置已被更新回调。

<a id="callback_irtcengineeventhandler_ontranscodingupdated__prototype"></a>

```typescript
onTranscodingUpdated?(): void;
```

<a id="callback_irtcengineeventhandler_ontranscodingupdated__detailed_desc"></a>

[startRtmpStreamWithTranscoding](/zh-CN/api-reference/rtc/react-native/cloud-media-relay/media-push#api_irtcengine_startrtmpstreamwithtranscoding) 方法中的直播参数 [LiveTranscoding](/zh-CN/api-reference/rtc/react-native/class-livetranscoding) 更新时， [onTranscodingUpdated](/zh-CN/api-reference/rtc/react-native/cloud-media-relay/media-push#callback_irtcengineeventhandler_ontranscodingupdated) 回调会被触发并向主播报告更新信息。

:::info[注]
首次调用 [startRtmpStreamWithTranscoding](/zh-CN/api-reference/rtc/react-native/cloud-media-relay/media-push#api_irtcengine_startrtmpstreamwithtranscoding) 方法设置转码参数 [LiveTranscoding](/zh-CN/api-reference/rtc/react-native/class-livetranscoding) 时，不会触发此回调。
:::

- [IRtcEngineEventHandler](/zh-CN/api-reference/rtc/react-native/rtc-interface-class#class_irtcengineeventhandler)
