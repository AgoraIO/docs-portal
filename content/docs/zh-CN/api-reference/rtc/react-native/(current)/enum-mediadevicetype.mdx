## 枚举值

### `UnknownAudioDevice`

-1: 设备类型未知。

### `AudioPlayoutDevice`

0: 音频播放设备。

### `AudioRecordingDevice`

1: 音频采集设备。

### `VideoRenderDevice`

2: 视频渲染设备 (显卡)。

### `VideoCaptureDevice`

3: 视频采集设备。

### `AudioApplicationPlayoutDevice`

4: 音频应用播放设备。

### `AudioVirtualPlayoutDevice`

5: 虚拟音频播放设备（虚拟声卡）。

### `AudioVirtualRecordingDevice`

6: 虚拟音频采集设备（虚拟声卡）。
