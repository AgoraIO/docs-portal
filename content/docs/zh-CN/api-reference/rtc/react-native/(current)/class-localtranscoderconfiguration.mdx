<a id="class_localtranscoderconfiguration__prototype"></a>

```typescript
export class LocalTranscoderConfiguration {

  streamCount?: number;

  videoInputStreams?: TranscodingVideoStream[];

  videoOutputConfiguration?: VideoEncoderConfiguration;

}
```

<a id="class_localtranscoderconfiguration__parameters"></a>

## 属性

### `streamCount`

参与本地合图的视频流的数量。

### `videoInputStreams`

参与本地合图的视频流。详见 [TranscodingVideoStream](/zh-CN/api-reference/rtc/react-native/class-transcodingvideostream)。

### `videoOutputConfiguration`

本地合图后，合图视频的编码配置。详见 [VideoEncoderConfiguration](/zh-CN/api-reference/rtc/react-native/class-videoencoderconfiguration)。
