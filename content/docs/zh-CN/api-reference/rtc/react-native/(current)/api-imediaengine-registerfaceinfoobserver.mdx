<a id="api_imediaengine_registerfaceinfoobserver__prototype"></a>

```typescript
abstract registerFaceInfoObserver(observer: IFaceInfoObserver): number;
```

<a id="api_imediaengine_registerfaceinfoobserver__detailed_desc"></a>

你可以调用该方法注册 [onFaceInfo](/zh-CN/api-reference/rtc/react-native/callback-ifaceinfoobserver-onfaceinfo) 回调获取声网语音驱动插件处理后的人脸信息。调用该方法注册人脸信息观测器时，你可以根据需要注册 [IFaceInfoObserver](/zh-CN/api-reference/rtc/react-native/rtc-interface-class#class_ifaceinfoobserver) 类中的回调。在成功注册人脸信息观测器后，SDK 会在捕捉到经过语音驱动插件转换的人脸信息时，触发你所注册的回调。

:::info[注]
- 该方法需要在加入频道前调用。
- 调用该方法前，你需要确保已调用 [enableExtension](/zh-CN/api-reference/rtc/react-native/extension#api_irtcengine_enableextension) 启用语音驱动插件。
:::

<a id="api_imediaengine_registerfaceinfoobserver__scenario"></a>

## 适用场景

通过声网语音驱动插件处理后的人脸信息为符合 ARkit 标准的 BS（Blend Shape）数据，你可以使用第三方 3D 渲染引擎对 BS 数据进一步处理，例如驱动虚拟人面部作出语音对应的口型变化。

<a id="api_imediaengine_registerfaceinfoobserver__parameters"></a>

## 参数

### `observer`

人脸信息观测器，详见 [IFaceInfoObserver](/zh-CN/api-reference/rtc/react-native/rtc-interface-class#class_ifaceinfoobserver)。

<a id="api_imediaengine_registerfaceinfoobserver__return_values"></a>

## 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/rn/error-code)了解详情和解决建议。
