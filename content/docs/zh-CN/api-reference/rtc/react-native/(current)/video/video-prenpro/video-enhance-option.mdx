## addOrUpdateVideoEffect

添加或更新指定视频特效节点和模板的特效。

<a id="api_ivideoeffectobject_addorupdatevideoeffect__prototype"></a>

```typescript
abstract addOrUpdateVideoEffect(nodeId: number, templateName: string): number;
```

<a id="api_ivideoeffectobject_addorupdatevideoeffect__detailed_desc"></a>

#### `自从`

自 v4.6.2 版本新增。

:::info[注]
优先级规则：

- 风格妆节点优先于滤镜特效节点。
- 若要应用滤镜特效，必须先移除风格妆特效节点。
:::

<a id="api_ivideoeffectobject_addorupdatevideoeffect__parameters"></a>

### 参数

#### `nodeId`

视频特效节点的唯一标识符或标识符组合。详见 [VideoEffectNodeId](/zh-CN/api-reference/rtc/react-native/enum-videoeffectnodeid)。

#### `templateName`

特效模板名称。如果设置为 `NULL` 或空字符串，SDK 会从资源包中加载默认配置。

<a id="api_ivideoeffectobject_addorupdatevideoeffect__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](/zh-CN/realtime-media/rtc/reference/error-code)了解详情和解决建议。

### 所属接口类
- [IVideoEffectObject](/zh-CN/api-reference/rtc/react-native/rtc-interface-class#class_ivideoeffectobject)

## getFaceShapeAreaOptions

获取美型部位选项。

<a id="api_irtcengine_getfaceshapeareaoptions__prototype"></a>

```typescript
abstract getFaceShapeAreaOptions(
    shapeArea: FaceShapeArea,
    type?: MediaSourceType
  ): FaceShapeAreaOptions;
```

<a id="api_irtcengine_getfaceshapeareaoptions__detailed_desc"></a>

调用该方法可以获取美型部位当前设置的参数信息。

<a id="api_irtcengine_getfaceshapeareaoptions__scenario"></a>

### 适用场景

用户在 App 中打开美型部位和修饰力度菜单时，你可以调用该方法获取当前的美型部位选项，然后根据结果刷新用户界面中的菜单，并更新 UI。

<a id="api_irtcengine_getfaceshapeareaoptions__timing"></a>

### 调用时机

请在 [enableVideo](/zh-CN/api-reference/rtc/react-native/video/video-basic#api_irtcengine_enablevideo) 之后调用该方法。

<a id="api_irtcengine_getfaceshapeareaoptions__parameters"></a>

### 参数

#### `shapeArea`

美型部位。详见 [FaceShapeArea](/zh-CN/api-reference/rtc/react-native/enum-faceshapearea)。

#### `type`

效果应用的媒体源类型。详见 [MediaSourceType](/zh-CN/api-reference/rtc/react-native/enum-mediasourcetype)。

:::info[注]
在该方法中，该参数仅支持以下两种设置：

- 使用摄像头采集本地视频时，请保持默认值 PrimaryCameraSource。
- 如果要使用自定义采集的视频，将该参数设置为 CustomVideoSource。
:::

<a id="api_irtcengine_getfaceshapeareaoptions__return_values"></a>

### 返回值

- 方法调用成功，返回 FaceShapeAreaOptions 对象。
- 方法调用失败，返回 null。

### 所属接口类
- [IRtcEngine](/zh-CN/api-reference/rtc/react-native/rtc-interface-class#class_irtcengine)

#### `type`

效果应用的媒体源类型。详见 [MediaSourceType](/zh-CN/api-reference/rtc/react-native/enum-mediasourcetype)。

:::

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](/zh-CN/realtime-media/rtc/reference/error-code)了解详情和解决建议。
  - -4：当前设备不支持该功能，可能的原因有：
    - 当前设备能力不满足美颜的使用要求，建议更换性能更高的设备。

## setColorEnhanceOptions

设置色彩增强功能。

<a id="api_irtcengine_setcolorenhanceoptions__prototype"></a>

```typescript
abstract setColorEnhanceOptions(
    enabled: boolean,
    options: ColorEnhanceOptions,
    type?: MediaSourceType
  ): number;
```

<a id="api_irtcengine_setcolorenhanceoptions__detailed_desc"></a>

摄像头采集到的视频画面可能存在色彩失真的现象。色彩增强功能可以通过智能调节饱和度和对比度等视频特性，提升视频色彩丰富度和色彩还原度，最终使视频画面更生动。 你可以调用该方法开启色彩增强功能并设置色彩增强的效果。

:::info[注]
- 请在 enableVideo 后调用该方法。
- 色彩增强对设备性能有一定要求。开启色彩增强后，如果设备出现严重发烫等问题，建议你将色彩增强等级修改为消耗性能较少的等级或关闭色彩增强功能。
- 该方法依赖于视频增强动态库 libagora_clear_vision_extension.dll，如果删除该动态库会导致无法正常开启该功能。
:::

<a id="api_irtcengine_setcolorenhanceoptions__parameters"></a>

### 参数

#### `enabled`

是否开启色彩增强功能：

- true：开启色彩增强功能。
- false：（默认）关闭色彩增强功能。

#### `options`

色彩增强选项，用于设置色彩增强的效果。详见 [ColorEnhanceOptions](/zh-CN/api-reference/rtc/react-native/class-colorenhanceoptions)。

#### `type`

效果应用的媒体源类型。详见 [MediaSourceType](/zh-CN/api-reference/rtc/react-native/enum-mediasourcetype)。

:::info[注]
在该方法中，该参数仅支持以下两种设置：

- 使用摄像头采集本地视频时，请保持默认值 PrimaryCameraSource。
- 如果要使用自定义采集的视频，将该参数设置为 CustomVideoSource。
:::

<a id="api_irtcengine_setcolorenhanceoptions__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](/zh-CN/realtime-media/rtc/reference/error-code)了解详情和解决建议。
