## enableInstantMediaRendering

开启音视频帧加速渲染。

<a id="api_irtcengine_enableinstantmediarendering__prototype"></a>

```text
abstract enableInstantMediaRendering(): number;
```

<a id="api_irtcengine_enableinstantmediarendering__detailed_desc"></a>

成功调用该方法后，SDK 会开启加速出图和出声模式，可加快用户加入频道后的首帧出图与出声速度。

:::note
注： 主播端和观众端都需调用该方法开启音视频帧加速渲染才可体验该功能。
一旦成功调用该方法，只能通过调用 [release](/zh-CN/api-reference/rtc/react-native/initialize#api_irtcengine_release) 方法销毁 [IRtcEngine](/zh-CN/api-reference/rtc/react-native/rtc-interface-class#class_irtcengine) 对象来取消加速渲染。
:::

<a id="api_irtcengine_enableinstantmediarendering__scenario"></a>

### 适用场景

声网推荐在直播场景下，对观众开启该模式。

<a id="api_irtcengine_enableinstantmediarendering__timing"></a>

### 调用时机

该方法需要在加入频道前调用。

<a id="api_irtcengine_enableinstantmediarendering__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。

  - -7: [IRtcEngine](/zh-CN/api-reference/rtc/react-native/rtc-interface-class#class_irtcengine) 尚未初始化就调用方法。

## setLocalRenderTargetFps

设置本地视频渲染的最大帧率。

<a id="api_irtcengine_setlocalrendertargetfps__prototype"></a>

```text
abstract setLocalRenderTargetFps(
    sourceType: VideoSourceType,
    targetFps: number
  ): number;
```

<a id="api_irtcengine_setlocalrendertargetfps__detailed_desc"></a>

<a id="api_irtcengine_setlocalrendertargetfps__scenario"></a>

### 适用场景

在对视频渲染帧率要求不高的场景（例如：屏幕共享、在线教育）下，你可以调用该方法设置本地视频渲染的最大帧率，SDK 进行本地渲染的实际帧率会尽量接近该值，从而减小 CPU 消耗、提升系统性能。

<a id="api_irtcengine_setlocalrendertargetfps__timing"></a>

### 调用时机

该方法在加入频道前后均可调用。

<a id="api_irtcengine_setlocalrendertargetfps__parameters"></a>

### 参数

<ParameterList>
<a id="sourcetype"></a>
<Parameter name="sourceType">

视频源的类型，详见 [VideoSourceType](/zh-CN/api-reference/rtc/react-native/enum-videosourcetype)。

</Parameter>
<a id="targetfps"></a>
<Parameter name="targetFps">

最大渲染帧率 (fps)。支持的参数值为：1、7、10、15、24、30、60。

:::note
注： 请将此参数设置为低于视频实际帧率的渲染帧率，否则设置将不会生效。
:::

</Parameter>
</ParameterList>

## startMediaRenderingTracing

开启视频帧渲染数据打点。

<a id="api_irtcengine_startmediarenderingtracing__prototype"></a>

```text
abstract startMediaRenderingTracing(): number;
```

<a id="api_irtcengine_startmediarenderingtracing__detailed_desc"></a>

成功调用该方法后，SDK 会以调用该方法的时刻作为起点，并通过 [onVideoRenderingTracingResult](/zh-CN/api-reference/rtc/react-native/video/video-rendering#callback_irtcengineeventhandler_onvideorenderingtracingresult) 回调报告视频帧渲染的相关信息。

:::note
注：

- 如果你未调用该方法，SDK 默认以调用 [joinChannel](/zh-CN/api-reference/rtc/react-native/channel#api_irtcengine_joinchannel2) 加入频道的时刻为起始点开始打点，自动开始跟踪视频的渲染事件。你可以根据实际业务场景，在合适的时机调用该方法，进行自定义打点。
- 离开当前频道后，SDK 会自动重置该时间点为下一次加入频道的时刻。
:::

<a id="api_irtcengine_startmediarenderingtracing__scenario"></a>

### 适用场景

声网推荐你将该方法和 App 中的 UI 设置（按钮、滑动条等）结合使用，用于获取符合终端用户实际体验的首帧出图耗时的场景。例如：在终端用户在点击 加入频道 按钮的时刻调用该方法进行打点，然后通过 `onVideoRenderingTracingResult` 回调获取视频帧渲染过程中的各阶段耗时，从而针对各阶段耗时进行专项优化。

<a id="api_irtcengine_startmediarenderingtracing__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。

  - -7: [IRtcEngine](/zh-CN/api-reference/rtc/react-native/rtc-interface-class#class_irtcengine) 尚未初始化就调用方法。

### 所属接口类

- [IRtcEngine](/zh-CN/api-reference/rtc/react-native/rtc-interface-class#class_irtcengine)
