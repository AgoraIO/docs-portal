## 枚举值

### `VideoFrameTypeBlankFrame`

0: 黑帧。

### `VideoFrameTypeKeyFrame`

3: 关键帧。

### `VideoFrameTypeDeltaFrame`

4: Delta 帧。

### `VideoFrameTypeBFrame`

5: B 帧。

### `VideoFrameTypeDroppableFrame`

6: 丢弃帧。

### `VideoFrameTypeUnknow`

未知帧。
