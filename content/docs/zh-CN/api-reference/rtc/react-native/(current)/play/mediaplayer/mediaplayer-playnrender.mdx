## selectAudioTrack

指定当前音频文件的播放音轨。

<a id="api_imediaplayer_selectaudiotrack_imediaplayer__prototype"></a>

```typescript
abstract selectAudioTrack(index: number): number;
```

<a id="api_imediaplayer_selectaudiotrack_imediaplayer__detailed_desc"></a>

获取音频文件的音轨索引后，你可以调用该方法指定任一音轨进行播放。如果一个多音轨文件的不同音轨存放了不同语言的歌曲，你可以调用该方法设置播放语言。

:::info[注]
你需要在调用 [getStreamInfo](/zh-CN/api-reference/rtc/react-native/play/mediaplayer/mediaplayer-info#api_imediaplayer_getstreaminfo) 获取音频流索引值后调用该方法。
:::

<a id="api_imediaplayer_selectaudiotrack_imediaplayer__parameters"></a>

### 参数

#### `index`

音轨的索引值。

<a id="api_imediaplayer_selectaudiotrack_imediaplayer__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/rn/error-code)了解详情和解决建议。

- [IMediaPlayer](/zh-CN/api-reference/rtc/react-native/rtc-interface-class#class_imediaplayer)

## setAudioDualMonoMode

设置当前音频文件的声道模式。

<a id="api_imediaplayer_setaudiodualmonomode__prototype"></a>

```typescript
abstract setAudioDualMonoMode(mode: AudioDualMonoMode): number;
```

<a id="api_imediaplayer_setaudiodualmonomode__detailed_desc"></a>

在双声道音频文件中，左声道和右声道可以存储不同的音频数据。根据实际需要，你可以设置声道模式为原始模式、左声道模式、右声道模式或混合模式。例如，在 KTV 场景中，音频文件的左声道存储了伴奏，右声道存储了原唱的歌声。如果你只需听伴奏，调用该方法设置音频文件的声道模式为左声道模式；如果你需要同时听伴奏和原唱，调用该方法设置声道模式为混合模式。

:::info[注]
- 你需要在调用 [open](/zh-CN/api-reference/rtc/react-native/play/mediaplayer/mediaplayer-open#api_imediaplayer_open) 后调用该方法。
- 该方法仅适用于双声道的音频文件。
:::

<a id="api_imediaplayer_setaudiodualmonomode__parameters"></a>

### 参数

#### `mode`

声道模式。详见 [AudioDualMonoMode](/zh-CN/api-reference/rtc/react-native/enum-audiodualmonomode)。

<a id="api_imediaplayer_setaudiodualmonomode__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/rn/error-code)了解详情和解决建议。

- [IMediaPlayer](/zh-CN/api-reference/rtc/react-native/rtc-interface-class#class_imediaplayer)

## setAudioPitch

调整当前播放的媒体资源的音调。

<a id="api_imediaplayer_setaudiopitch__prototype"></a>

```typescript
abstract setAudioPitch(pitch: number): number;
```

<a id="api_imediaplayer_setaudiopitch__detailed_desc"></a>

:::info[注]
你需要在调用 [open](/zh-CN/api-reference/rtc/react-native/play/mediaplayer/mediaplayer-open#api_imediaplayer_open) 后调用该方法。
:::

<a id="api_imediaplayer_setaudiopitch__parameters"></a>

### 参数

#### `pitch`

按半音音阶调整本地播放的音乐文件的音调，默认值为 0，即不调整音调。取值范围为 [-12,12]，每相邻两个值的音高距离相差半音。取值的绝对值越大，音调升高或降低得越多。

<a id="api_imediaplayer_setaudiopitch__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/rn/error-code)了解详情和解决建议。

- [IMediaPlayer](/zh-CN/api-reference/rtc/react-native/rtc-interface-class#class_imediaplayer)

## setLoopCount

设置循环播放。

<a id="api_imediaplayer_setloopcount__prototype"></a>

```typescript
abstract setLoopCount(loopCount: number): number;
```

<a id="api_imediaplayer_setloopcount__detailed_desc"></a>

如果你希望循环播放，请调用该方法并设置循环播放次数。 循环播放结束时，SDK 会触发 [onPlayerSourceStateChanged](/zh-CN/api-reference/rtc/react-native/play/mediaplayer/mediaplayer-observer#callback_imediaplayersourceobserver_onplayersourcestatechanged) 回调，向你报告播放状态为 PlayerStatePlaybackAllLoopsCompleted。

<a id="api_imediaplayer_setloopcount__parameters"></a>

### 参数

#### `loopCount`

循环播放的次数。

- ≥0：循环次数。例如，设为 0 表示不循环播放，一共播放一次；设为 1 表示循环播放一次，一共播放 2 次。
- -1：无限循环播放。

<a id="api_imediaplayer_setloopcount__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/rn/error-code)了解详情和解决建议。

- [IMediaPlayer](/zh-CN/api-reference/rtc/react-native/rtc-interface-class#class_imediaplayer)

## setPlaybackSpeed

设置当前音频文件的播放速度。

<a id="api_imediaplayer_setplaybackspeed__prototype"></a>

```typescript
abstract setPlaybackSpeed(speed: number): number;
```

<a id="api_imediaplayer_setplaybackspeed__detailed_desc"></a>

你需要在 [open](/zh-CN/api-reference/rtc/react-native/play/mediaplayer/mediaplayer-open#api_imediaplayer_open) 后调用该方法。

<a id="api_imediaplayer_setplaybackspeed__parameters"></a>

### 参数

#### `speed`

- 30: 0.3 倍速。

- 400: 4 倍速。

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/rn/error-code)了解详情和解决建议。

## setPlayerOptionInInt

设置媒体播放器选项。

<a id="api_imediaplayer_setplayeroption__prototype"></a>

```typescript
abstract setPlayerOptionInInt(key: string, value: number): number;
```

<a id="api_imediaplayer_setplayeroption__detailed_desc"></a>

媒体播放器支持通过 `key` 和 `value` 来设置选项。 该方法和 [setPlayerOptionInString](/zh-CN/api-reference/rtc/react-native/play/mediaplayer/mediaplayer-playnrender#api_imediaplayer_setplayeroption2) 的区别在于，该方法的 `value` 是 Int 型， [setPlayerOptionInString](/zh-CN/api-reference/rtc/react-native/play/mediaplayer/mediaplayer-playnrender#api_imediaplayer_setplayeroption2) 的 `value` 是 String 型。二者不可混用。

<a id="api_imediaplayer_setplayeroption__scenario"></a>

### 适用场景

需要提供技术预览或特别定制功能的场景。一般情况下，你无需调用该方法，使用媒体播放器默认的选项设置即可。

<a id="api_imediaplayer_setplayeroption__timing"></a>

### 调用时机

该方法需要在 [open](/zh-CN/api-reference/rtc/react-native/play/mediaplayer/mediaplayer-open#api_imediaplayer_open) 或 [openWithMediaSource](/zh-CN/api-reference/rtc/react-native/play/mediaplayer/mediaplayer-open#api_imediaplayer_openwithmediasource) 之前调用。

<a id="api_imediaplayer_setplayeroption__parameters"></a>

### 参数

#### `key`

key 值。

#### `value`

value 值。

<a id="api_imediaplayer_setplayeroption__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/rn/error-code)了解详情和解决建议。

- [IMediaPlayer](/zh-CN/api-reference/rtc/react-native/rtc-interface-class#class_imediaplayer)
