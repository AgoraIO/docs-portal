<a id="class_faceshapeareaoptions__prototype"></a>

```typescript
export class FaceShapeAreaOptions {
  shapeArea?: FaceShapeArea;
  shapeIntensity?: number;
}
```

<a id="class_faceshapeareaoptions__parameters"></a>

## 属性

### `shapeArea`

美型部位，详见 [FaceShapeArea](/zh-CN/api-reference/rtc/react-native/enum-faceshapearea)。

### `shapeIntensity`

修饰力度。各部位的修饰力度定义（包括修饰的方向、范围、预设值等）有所不同，详见 [FaceShapeArea](/zh-CN/api-reference/rtc/react-native/enum-faceshapearea)。
