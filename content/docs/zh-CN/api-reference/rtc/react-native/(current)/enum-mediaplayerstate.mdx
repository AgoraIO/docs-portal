## 枚举值

### PlayerStateIdle

0: 默认状态。播放器会在你打开媒体文件之前和结束播放之后返回该状态码。

### PlayerStateOpening

1: 正在打开媒体文件。

### PlayerStateOpenCompleted

2: 成功打开媒体文件。

### PlayerStatePlaying

3: 正在播放。

### PlayerStatePaused

4: 暂停播放。

### PlayerStatePlaybackCompleted

5: 播放完毕。

### PlayerStatePlaybackAllLoopsCompleted

6: 循环播放已结束。

### PlayerStateStopped

7: 播放已停止。

### PlayerStateFailed

100: 播放失败。
