## 枚举值

### `RelayOk`

0: 一切正常。

### `RelayErrorServerErrorResponse`

1: 服务器回应出错。

### `RelayErrorServerNoResponse`

2: 服务器无回应。 该错误可能是网络状况不佳导致的。如果在发起跨频道连麦时报告该错误，你可以稍后重试；如果在跨频道连麦过程中报告该错误，你可以调用 [leaveChannel](/zh-CN/api-reference/rtc/react-native/channel#api_irtcengine_leavechannel2) 方法离开频道。 该错误也可能是由于当前的 App ID 未开启跨频道连麦导致的。你可以[联系技术支持](https://ticket.shengwang.cn/)申请开通跨频道连麦。

### `RelayErrorNoResourceAvailable`

3: SDK 无法获取服务，可能是因为服务器资源有限导致。

### `RelayErrorFailedJoinSrc`

4: 发起跨频道转发媒体流请求失败。

### `RelayErrorFailedJoinDest`

5: 接受跨频道转发媒体流请求失败。

### `RelayErrorFailedPacketReceivedFromSrc`

6: 服务器接收跨频道转发媒体流失败。

### `RelayErrorFailedPacketSentToDest`

7: 服务器发送跨频道转发媒体流失败。

### `RelayErrorServerConnectionLost`

8: SDK 因网络质量不佳与服务器断开。你可以调用 [leaveChannel](/zh-CN/api-reference/rtc/react-native/channel#api_irtcengine_leavechannel2) 方法离开当前频道。

### `RelayErrorInternalError`

9: 服务器内部出错。

### `RelayErrorSrcTokenExpired`

10: 源频道的 Token 已过期。

### `RelayErrorDestTokenExpired`

11: 目标频道的 Token 已过期。
