<a id="class_extensioncontext__prototype"></a>

```typescript
export class ExtensionContext {

  isValid?: boolean;

  uid?: number;

  providerName?: string;

  extensionName?: string;
}
```

<a id="class_extensioncontext__parameters"></a>

## 属性

### `isValid`

[ExtensionContext](/zh-CN/api-reference/rtc/react-native/class-extensioncontext) 中报告的 `uid` 是否有效：

- true： uid 有效。
- false： uid 无效。

### `uid`

用户 ID。0 代表本地用户，大于 0 代表远端用户。

### `providerName`

提供插件的服务商名称。

### `extensionName`

插件的名称。
