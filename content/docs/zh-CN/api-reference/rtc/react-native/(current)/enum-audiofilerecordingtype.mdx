<a id="enum_audiofilerecordingtype__parameters"></a>

## 枚举值

### `AudioFileRecordingMic`

1: 仅录制本地用户的音频。

### `AudioFileRecordingPlayback`

2: 仅录制所有远端用户的音频。

### `AudioFileRecordingMixed`

3: 录制本地和所有远端用户混音后的音频。
