## getAudioDeviceInfo

获取音频设备信息。

<a id="api_irtcengine_getaudiodeviceinfo__prototype"></a>

```text
abstract getAudioDeviceInfo(): DeviceInfo;
```

<a id="api_irtcengine_getaudiodeviceinfo__detailed_desc"></a>

调用该方法后，你可以获取音频设备是否支持极低延时采集和播放。

:::note
注：

- 该方法在加入频道前后均可调用。
:::

<a id="api_irtcengine_getaudiodeviceinfo__return_values"></a>

### 返回值

包含音频设备信息的 [DeviceInfo](/zh-CN/api-reference/rtc/react-native/class-deviceinfo) 对象。

- 非空：方法调用成功。
- 空：方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。

## startPlaybackDeviceTest

启动音频播放设备测试。

<a id="api_iaudiodevicemanager_startplaybackdevicetest__prototype"></a>

```text
abstract startPlaybackDeviceTest(testAudioFilePath: string): number;
```

<a id="api_iaudiodevicemanager_startplaybackdevicetest__detailed_desc"></a>

该方法用于测试本地音频播放设备是否能正常工作。启动测试后，SDK 播放指定的音频文件，测试者如果能听到声音，说明播放设备能正常工作。
调用该方法后，SDK 会每隔 100 毫秒触发一次 [onAudioVolumeIndication](/zh-CN/api-reference/rtc/react-native/audio/audio-basic#callback_irtcengineeventhandler_onaudiovolumeindication) 回调，报告 `uid` = 1 及播放设备的音量信息。
该方法和 [startEchoTest](/zh-CN/api-reference/rtc/react-native/network#api_irtcengine_startechotest3) 的区别在于该方法检测本地的音频播放设备能否正常工作，后者可以检测音视频设备及网络是否正常。

:::note
注： 该方法需要在加入频道前调用。测试完成后，如需加入频道，请确保先调用 [stopPlaybackDeviceTest](/zh-CN/api-reference/rtc/react-native/device-management/audio-device#api_iaudiodevicemanager_stopplaybackdevicetest) 停止设备测试。
:::

<a id="api_iaudiodevicemanager_startplaybackdevicetest__parameters"></a>

### 参数

### testAudioFilePath

音频文件的绝对路径，路径字符串使用 UTF-8 编码格式。

- 支持文件格式: wav、mp3、m4a、aac。
- 支持文件采样率: 8000、16000、32000、44100、48000。

<a id="api_iaudiodevicemanager_startplaybackdevicetest__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。

## stopPlaybackDeviceTest

```text
abstract stopPlaybackDeviceTest(): number;
```

<a id="api_iaudiodevicemanager_stopplaybackdevicetest__detailed_desc"></a>
