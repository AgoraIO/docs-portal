## enableMultiCamera

开启或关闭多路摄像头采集。

<a id="api_irtcengine_enablemulticamera__prototype"></a>

```typescript
abstract enableMultiCamera(
    enabled: boolean,
    config: CameraCapturerConfiguration
  ): number;
```

<a id="api_irtcengine_enablemulticamera__detailed_desc"></a>

在已有摄像头采集视频的场景下，声网推荐你采用以下步骤实现多路摄像头采集、发布视频：

1. 调用该方法开启多路摄像头采集。
2. 调用 startPreview 开启本地视频预览。
3. 调用 startCameraCapture 并设置 sourceType 指定第二个摄像头开始采集。
4. 调用 joinChannelEx 并设置 publishSecondaryCameraTrack 为 true，在频道内发布第二路摄像头采集的视频流。

如果要关闭多路摄像头采集，可参考以下步骤：

1. 调用 stopCameraCapture。
2. 调用该方法并将 enabled 设置为 false。

该方法仅适用于 iOS。 使用多路摄像头采集视频时，请确保系统版本为 13.0 及以上。 支持多路摄像头采集的最低 iOS 设备类型如下所示：

- iPhone XR
- iPhone XS
- iPhone XS Max
- iPad Pro (第三代及以上)

:::info[注]
你可以在 [startPreview](/zh-CN/api-reference/rtc/react-native/video/video-basic#api_irtcengine_startpreview2) 前后调用该方法开启多摄像头采集：

- 如果在 startPreview 之前开启，则本地视频预览会同时出现两个摄像头采集的画面。
- 如果在 startPreview 之后开启，SDK 会先停止当前的摄像头采集，然后再开启原摄像头和第二个摄像头，本地视频预览会出现短暂黑屏、然后自动恢复正常。
:::

<a id="api_irtcengine_enablemulticamera__parameters"></a>

### 参数

#### `enabled`

是否开启多摄像头视频采集模式：

- true：开启多摄像头采集模式，SDK 使用多路摄像头采集视频。
- false：关闭多摄像头采集模式，SDK 仅使用单路摄像头采集视频。

#### `config`

第二个摄像头的采集配置。详见 [CameraCapturerConfiguration](/zh-CN/api-reference/rtc/react-native/class-cameracapturerconfiguration)。

<a id="api_irtcengine_enablemulticamera__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](https://doc.shengwang.cn/api-ref/rtc/rn/error-code)了解详情和解决建议。

### 所属接口类
- [IRtcEngine](/zh-CN/api-reference/rtc/react-native/rtc-interface-class#class_irtcengine)

## queryCameraFocalLengthCapability

<a id="api_irtcengine_querycamerafocallengthcapability__prototype"></a>

```typescript

    focalLengthInfos: FocalLengthInfo[];
    size: number;
  };
```

<a id="api_irtcengine_querycamerafocallengthcapability__detailed_desc"></a>

如需开启摄像头广角、超广角拍摄模式，建议你先调用该方法查询设备是否具备相应的焦距能力，再根据查询结果调用 [setCameraCapturerConfiguration](/zh-CN/api-reference/rtc/react-native/device-management/video-device#api_irtcengine_setcameracapturerconfiguration) 调整摄像头的焦距配置，以达到最佳的摄像头采集效果。

### 返回值

- focalLengthInfos： FocalLengthInfo 对象数组，其中包含摄像头的方向和焦距类型。
- size：实际查询到的焦距信息数量。

## setCameraExposureFactor

设置当前摄像头的曝光系数。

<a id="api_irtcengine_setcameraexposurefactor__prototype"></a>

```typescript
abstract setCameraExposureFactor(factor: number): number;
```

<a id="api_irtcengine_setcameraexposurefactor__detailed_desc"></a>

当拍摄环境光线不足或过于明亮时，会影响视频采集的画质。为了获得更好的视频效果，你可以使用该方法调节摄像头的曝光系数。

:::info[注]
- 该方法必须在 enableVideo 后调用，设置结果在摄像头成功开启后生效，即 SDK 触发 onLocalVideoStateChanged 回调返回本地视频状态为 LocalVideoStreamStateCapturing (1) 后。
- 建议你在调用该方法前，先调用 isCameraExposureSupported 查询当前摄像头是否支持调节曝光系数。
- 当你调用该方法时，设置的是当前正在使用的摄像头的曝光系数，即调用 setCameraCapturerConfiguration 时指定的摄像头。
:::

<a id="api_irtcengine_setcameraexposurefactor__parameters"></a>

### 参数

#### `factor`

摄像头的曝光系数。默认值为 0，表示使用摄像头的默认曝光量。取值越大，曝光量越大。视频图像过曝时，你可以降低曝光系数；视频图像欠曝且暗部细节丢失时，你可以增加曝光系数。如果你指定的曝光系数超出设备支持的范围，SDK 会自动调节为设备实际支持的范围。 在 Android 平台上，取值范围为 [-20.0,20.0]；在 iOS 平台上，取值范围为 [-8.0,8.0]。

## setCameraZoomFactor

设置摄像头放大比例。

<a id="api_irtcengine_setcamerazoomfactor__prototype"></a>

```typescript
abstract setCameraZoomFactor(factor: number): number;
```

<a id="api_irtcengine_setcamerazoomfactor__detailed_desc"></a>

部分 iOS 设备的后置摄像头为多个摄像头组成的融合镜头，如双摄（广角和超广角）或三摄（广角、超广角和长焦），对于这种具备超广角能力的融合镜头，你可以调用 [setCameraCapturerConfiguration](/zh-CN/api-reference/rtc/react-native/device-management/video-device#api_irtcengine_setcameracapturerconfiguration) 将 `cameraFocalLengthType` 设置为 `CameraFocalLengthDefault` (0)（标准镜头），然后调用该方法将摄像头缩放比例设置为小于 1.0 的数值，从而实现超广角的拍摄效果。

:::info[注]
- 该方法必须在 enableVideo 后调用，设置结果在摄像头成功开启后生效，即 SDK 触发 onLocalVideoStateChanged 回调返回本地视频状态为 LocalVideoStreamStateCapturing (1) 后。
:::

<a id="api_irtcengine_setcamerazoomfactor__parameters"></a>

### 参数

#### `factor`

摄像头放大比例。对不支持超广角的设备，取值范围从 1.0 到最大放大比例；对支持超广角的设备，取值范围从 0.5 到最大放大比例。你可以通过 [getCameraMaxZoomFactor](/zh-CN/api-reference/rtc/react-native/device-management/video-device#api_irtcengine_getcameramaxzoomfactor) 方法获取设备支持的最大放大比例。

<a id="api_irtcengine_setcamerazoomfactor__return_values"></a>

### 返回值

- 方法调用成功: 返回设置的 factor 值。
- 方法调用失败: 返回值 &lt; 0。

- [IRtcEngine](/zh-CN/api-reference/rtc/react-native/rtc-interface-class#class_irtcengine)
