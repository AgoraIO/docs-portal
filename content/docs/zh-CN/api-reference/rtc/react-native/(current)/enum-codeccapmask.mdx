## 枚举值

### `CodecCapMaskNone`

(0)：不支持编解码。

### `CodecCapMaskHwDec`

(1 &lt;&lt; 0)：支持硬件解码。

### `CodecCapMaskHwEnc`

(1 &lt;&lt; 1)：支持硬件编码。

### `CodecCapMaskSwDec`

(1 &lt;&lt; 2)：支持软件解码。

### `CodecCapMaskSwEnc`

(1 &lt;&lt; 3)：支持软件编码。
