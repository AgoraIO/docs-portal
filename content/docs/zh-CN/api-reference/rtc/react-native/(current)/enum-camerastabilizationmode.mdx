<a id="enum_camerastabilizationmode__detailed_desc"></a>

摄像头的防抖效果按照 1 &lt; 2 &lt;3 的顺序依次增强，时延也会相应增大。

<a id="enum_camerastabilizationmode__parameters"></a>

## 枚举值

<ParameterList>
<a id="camerastabilizationmodeoff"></a>
<Parameter name="CameraStabilizationModeOff">

-1：（默认）摄像头防抖模式关闭。

</Parameter>
<a id="camerastabilizationmodeauto"></a>
<Parameter name="CameraStabilizationModeAuto">

0：摄像头自动防抖，系统会根据摄像头的状态自动选择一种防抖模式。但是在该模式下的时延较大，建议你不要使用该枚举。

</Parameter>
<a id="camerastabilizationmodelevel1"></a>
<Parameter name="CameraStabilizationModeLevel1">

1：（推荐）摄像头 1 级防抖。

</Parameter>
<a id="camerastabilizationmodelevel2"></a>
<Parameter name="CameraStabilizationModeLevel2">

2：摄像头 2 级防抖。

</Parameter>
<a id="camerastabilizationmodelevel3"></a>
<Parameter name="CameraStabilizationModeLevel3">

3：摄像头 3 级防抖。

</Parameter>
</ParameterList>
