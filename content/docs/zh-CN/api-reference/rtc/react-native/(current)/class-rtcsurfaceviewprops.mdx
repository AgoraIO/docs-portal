<a id="class_rtcsurfaceviewprops__prototype"></a>

```typescript
export interface RtcSurfaceViewProps {
  zOrderOnTop?: boolean;
  zOrderMediaOverlay?: boolean;
}
```

<a id="class_rtcsurfaceviewprops__parameters"></a>

## 属性

### `zOrderOnTop`

是否将 RtcSurfaceView 视图的表层置于窗口上层：

- true: 置于窗口上层。
- false: 不置于窗口上层。

### `zOrderMediaOverlay`

是否将 RtcSurfaceView 视图的表层置于窗口中另一个 RtcSurfaceView 的上层（但依然位于窗口的下层）：

- true: 置于窗口中另一个 RtcSurfaceView 的上层。
- false: 不置于窗口上层。
