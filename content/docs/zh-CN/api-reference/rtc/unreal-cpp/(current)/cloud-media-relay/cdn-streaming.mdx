## setDirectCdnStreamingAudioConfiguration

设置主播端直接向 CDN 推流时的音频编码属性。

<a id="api_irtcengine_setdirectcdnstreamingaudioconfiguration__prototype"></a>

```text
virtual int setDirectCdnStreamingAudioConfiguration(AUDIO_PROFILE_TYPE profile) = 0;
```

<a id="api_irtcengine_setdirectcdnstreamingaudioconfiguration__detailed_desc"></a>

该方法仅对麦克风采集或自采集的音频有效，即对在 [DirectCdnStreamingMediaOptions](/zh-CN/api-reference/rtc/unreal-cpp/class-directcdnstreamingmediaoptions) 中设置 publishMicrophoneTrack 或 publishCustomAudioTrack 为 `true` 时所采集的音频有效。

### 参数

### profile

音频编码属性，包含采样率、码率、编码模式和声道数。详见 [AUDIO_PROFILE_TYPE](/zh-CN/api-reference/rtc/unreal-cpp/enum-audioprofiletype)。

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。

## setDirectCdnStreamingVideoConfiguration

设置主播端直接向 CDN 推流时的视频编码属性。

<a id="api_irtcengine_setdirectcdnstreamingvideoconfiguration__prototype"></a>

```text
virtual
            int setDirectCdnStreamingVideoConfiguration(const VideoEncoderConfiguration& config)
            = 0;
```

<a id="api_irtcengine_setdirectcdnstreamingvideoconfiguration__detailed_desc"></a>

### 详情

该方法仅对摄像头采集、屏幕共享或自采集的视频有效。即对在 [DirectCdnStreamingMediaOptions](/zh-CN/api-reference/rtc/unreal-cpp/class-directcdnstreamingmediaoptions) 中设置 publishCameraTrack 或 publishCustomVideoTrack 为 `true` 时所采集的视频有效。

如果你设置的视频分辨率超出你的摄像头设备支持的范围，SDK 会根据你的设置进行自适应，取最接近、且长宽比与你设置的分辨率一致的值进行采集、编码、推流。你可以通过 [onDirectCdnStreamingStats](/zh-CN/api-reference/rtc/unreal-cpp/cloud-media-relay/cdn-streaming#callback_idirectcdnstreamingeventhandler_ondirectcdnstreamingstats) 回调了解推送的视频流的实际分辨率。

<a id="api_irtcengine_setdirectcdnstreamingvideoconfiguration__parameters"></a>

### 参数

### config

视频编码参数配置。详见 [VideoEncoderConfiguration](/zh-CN/api-reference/rtc/unreal-cpp/class-videoencoderconfiguration)。

:::note
注： 在直接向 CDN 推流时，SDK 目前仅支持将 ORIENTATION_MODE 设为横屏模式（ORIENTATION_MODE_FIXED_LANDSCAPE）或竖屏模式（ORIENTATION_MODE_FIXED_PORTRAIT）。
:::

<a id="api_irtcengine_setdirectcdnstreamingvideoconfiguration__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。

## startDirectCdnStreaming

设置主播端开始直接向 CDN 推流。

<a id="api_irtcengine_startdirectcdnstreaming__prototype"></a>

```text
virtual int startDirectCdnStreaming(IDirectCdnStreamingEventHandler* eventHandler,
            const char* publishUrl, const DirectCdnStreamingMediaOptions& options) = 0;
```

<a id="api_irtcengine_startdirectcdnstreaming__detailed_desc"></a>

### 详情

SDK 不支持同一时间向同一个 URL 重复推流。

**媒体选项说明**

SDK 不支持 publishCameraTrack 和 publishCustomVideoTrack 同时为 `true`，也不支持 publishMicrophoneTrack 和 publishCustomAudioTrack 同时为 `true`。你可以根据场景需求设置媒体选项 ([DirectCdnStreamingMediaOptions](/zh-CN/api-reference/rtc/unreal-cpp/class-directcdnstreamingmediaoptions))。示例如下：

如果你想推送主播端自定义采集的音视频流，请将媒体选项进行如下设置：

- publishCustomAudioTrack 设为 `true` 并调用 [pushAudioFrame](/zh-CN/api-reference/rtc/unreal-cpp/audio/audio-custom-capturenrendering#api_imediaengine_pushaudioframe0)
- publishCustomVideoTrack 设为 `true` 并调用 [pushVideoFrame](/zh-CN/api-reference/rtc/unreal-cpp/video/video-custom-capturenrendering#api_imediaengine_pushvideoframe)
- 确保 publishCameraTrack 为 `false` (默认值)
- 确保 publishMicrophoneTrack 为 `false` (默认值)

自 v4.2.0 起，SDK 支持推送纯音频流。你可以在 [DirectCdnStreamingMediaOptions](/zh-CN/api-reference/rtc/unreal-cpp/class-directcdnstreamingmediaoptions) 中将 publishCustomAudioTrack 或者 publishMicrophoneTrack 设为 `true`，并调用 [pushAudioFrame](/zh-CN/api-reference/rtc/unreal-cpp/audio/audio-custom-capturenrendering#api_imediaengine_pushaudioframe0) 即可推送纯音频流。

:::note
注： 在向 CDN 直接推流时，SDK 目前仅支持推送一路音频流及视频流，或一路纯音频流。
:::

<a id="api_irtcengine_startdirectcdnstreaming__parameters"></a>

### 参数

### eventHandler

详见 [onDirectCdnStreamingStateChanged](/zh-CN/api-reference/rtc/unreal-cpp/cloud-media-relay/cdn-streaming#callback_idirectcdnstreamingeventhandler_ondirectcdnstreamingstatechanged) 及 [onDirectCdnStreamingStats](/zh-CN/api-reference/rtc/unreal-cpp/cloud-media-relay/cdn-streaming#callback_idirectcdnstreamingeventhandler_ondirectcdnstreamingstats)。

### publishUrl

CDN 推流 URL。

### options

主播端的媒体选项。详见 [DirectCdnStreamingMediaOptions](/zh-CN/api-reference/rtc/unreal-cpp/class-directcdnstreamingmediaoptions)。

<a id="api_irtcengine_startdirectcdnstreaming__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。
