## 枚举值

<ParameterList>
<a id="audio_profile_default"></a>
<Parameter name="AUDIO_PROFILE_DEFAULT">

0: 默认值。

<a id="enum_audioprofiletype__default-profile"></a>

- 直播场景下：48 kHz 采样率，音乐编码，单声道，编码码率最大值为 64 Kbps。
- 通信场景下：

  - Windows 平台：16 kHz 采样率，语音编码，单声道，编码码率最大值为 16 Kbps。
  - Android、macOS、iOS 平台：32 kHz 采样率，语音编码，单声道，编码码率最大值为 18 Kbps。

</Parameter>
<a id="audio_profile_speech_standard"></a>
<Parameter name="AUDIO_PROFILE_SPEECH_STANDARD">

1: 指定 32 kHz 采样率，语音编码，单声道，编码码率最大值为 18 Kbps。

</Parameter>
<a id="audio_profile_music_standard"></a>
<Parameter name="AUDIO_PROFILE_MUSIC_STANDARD">

2: 指定 48 kHz 采样率，音乐编码，单声道，编码码率最大值为 64 Kbps。

</Parameter>
<a id="audio_profile_music_standard_stereo"></a>
<Parameter name="AUDIO_PROFILE_MUSIC_STANDARD_STEREO">

3: 指定 48 kHz 采样率，音乐编码，双声道，编码码率最大值为 80 Kbps。

如需实现立体声，你还需要调用 [setAdvancedAudioOptions](/zh-CN/api-reference/rtc/unreal-cpp/audio/audio-prenpost/audio-effect#api_irtcengine_setadvancedaudiooptions) 并在 AdvancedAudioOptions 中设置 audioProcessingChannels 为 AUDIO_PROCESSING_STEREO。

</Parameter>
<a id="audio_profile_music_high_quality"></a>
<Parameter name="AUDIO_PROFILE_MUSIC_HIGH_QUALITY">

4: 指定 48 kHz 采样率，音乐编码，单声道，编码码率最大值为 96 Kbps。

</Parameter>
<a id="audio_profile_music_high_quality_stereo"></a>
<Parameter name="AUDIO_PROFILE_MUSIC_HIGH_QUALITY_STEREO">

5: 指定 48 kHz 采样率，音乐编码，双声道，编码码率最大值为 128 Kbps。

如需实现立体声，你还需要调用 [setAdvancedAudioOptions](/zh-CN/api-reference/rtc/unreal-cpp/audio/audio-prenpost/audio-effect#api_irtcengine_setadvancedaudiooptions) 并在 AdvancedAudioOptions 中设置 audioProcessingChannels 为 AUDIO_PROCESSING_STEREO。

</Parameter>
<a id="audio_profile_iot"></a>
<Parameter name="AUDIO_PROFILE_IOT">

6: 指定 16 kHz 采样率，语音编码，单声道，应用回声消除算法 AEC。

</Parameter>
