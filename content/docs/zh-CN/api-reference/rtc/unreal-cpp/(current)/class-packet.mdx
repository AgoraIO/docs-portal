<a id="class_packet__prototype"></a>

```cpp
struct Packet {
                    const unsigned char* buffer;
                    unsigned int size;

                    Packet() : buffer(NULL), size(0) {}
                    };
```

<a id="class_packet__parameters"></a>

## 属性

### `buffer`

需要发送或接收的数据的缓存地址。

:::warning[注意]
建议 buffer 值不要小于 2048 字节，否则有可能会出现未定义行为（例如崩溃）。
:::

### `size`

将要发送或接收的数据的缓存大小。
