## 属性

### buffer

需要发送或接收的数据的缓存地址。

:::note
注意： 建议 buffer 值不要小于 2048 字节，否则有可能会出现未定义行为（例如崩溃）。
:::

### size

将要发送或接收的数据的缓存大小。
