## 枚举值

### CONTENT_HINT_NONE

（默认）无指定的内容类型。

### CONTENT_HINT_MOTION

内容类型为动画。当共享的内容是视频、电影或视频游戏时，推荐选择该内容类型。

### CONTENT_HINT_DETAILS

内容类型为细节。当共享的内容是图片或文字时，推荐选择该内容类型。
