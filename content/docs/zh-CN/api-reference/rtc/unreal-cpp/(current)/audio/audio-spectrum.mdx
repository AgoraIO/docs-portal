## enableAudioSpectrumMonitor

开启音频频谱监测。

<a id="api_irtcengine_enableaudiospectrummonitor__prototype"></a>

```text
virtual int enableAudioSpectrumMonitor(int intervalInMS = 100) = 0;
```

<a id="api_irtcengine_enableaudiospectrummonitor__detailed_desc"></a>

### 详情

如果你想获取本地或远端用户的音频频谱数据，请注册音频频谱观测器并开启音频频谱监测。

<a id="api_irtcengine_enableaudiospectrummonitor__note_xlb_3yd_3qb"></a>

:::note
注意：

该方法在加入频道前后均可调用。
:::

<a id="api_irtcengine_enableaudiospectrummonitor__parameters"></a>

### 参数

### intervalInMS

SDK 触发 [onLocalAudioSpectrum](/zh-CN/api-reference/rtc/unreal-cpp/audio/audio-spectrum#callback_iaudiospectrumobserver_onlocalaudiospectrum) 和 [onRemoteAudioSpectrum](/zh-CN/api-reference/rtc/unreal-cpp/audio/audio-spectrum#callback_iaudiospectrumobserver_onremoteaudiospectrum) 回调的时间间隔（毫秒）。 默认值为 100 毫秒。取值不得少于 10 毫秒，否则该方法会调用失败。

<a id="api_irtcengine_enableaudiospectrummonitor__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。

  - -2: 参数设置错误。

### 所属接口类

- [IRtcEngine](/zh-CN/api-reference/rtc/unreal-cpp/rtc-interface-class#class_irtcengine)

## onLocalAudioSpectrum

获取本地音频频谱。

<a id="callback_iaudiospectrumobserver_onlocalaudiospectrum__prototype"></a>

```text
virtual bool onLocalAudioSpectrum(const AudioSpectrumData& data) = 0;
```

<a id="callback_iaudiospectrumobserver_onlocalaudiospectrum__detailed_desc"></a>

成功调用 [registerAudioSpectrumObserver](/zh-CN/api-reference/rtc/unreal-cpp/audio/audio-spectrum#api_irtcengine_registeraudiospectrumobserver) 实现 [IAudioSpectrumObserver](/zh-CN/api-reference/rtc/unreal-cpp/rtc-interface-class#class_iaudiospectrumobserver) 中的 onLocalAudioSpectrum 回调并调用 [enableAudioSpectrumMonitor](/zh-CN/api-reference/rtc/unreal-cpp/audio/audio-spectrum#api_irtcengine_enableaudiospectrummonitor) 开启音频频谱监测后，SDK 会按照你设置的时间间隔触发该回调，报告编码前的本地音频数据的频谱。

<a id="callback_iaudiospectrumobserver_onlocalaudiospectrum__parameters"></a>

### 参数

### data

本地用户的音频频谱数据。详见 [AudioSpectrumData](/zh-CN/api-reference/rtc/unreal-cpp/class-audiospectrumdata)。

<a id="callback_iaudiospectrumobserver_onlocalaudiospectrum__return_values"></a>

### 返回值

是否接收频谱数据：

- `true`: 接收。
- `false`: 不接收。

### 所属接口类

- [IAudioSpectrumObserver](/zh-CN/api-reference/rtc/unreal-cpp/rtc-interface-class#class_iaudiospectrumobserver)

## onRemoteAudioSpectrum

获取远端音频频谱。

<a id="callback_iaudiospectrumobserver_onremoteaudiospectrum__prototype"></a>

```text
virtual bool onRemoteAudioSpectrum(const UserAudioSpectrumInfo * spectrums, unsigned int spectrumNumber) = 0;
```

<a id="callback_iaudiospectrumobserver_onremoteaudiospectrum__detailed_desc"></a>

成功调用 [registerAudioSpectrumObserver](/zh-CN/api-reference/rtc/unreal-cpp/audio/audio-spectrum#api_irtcengine_registeraudiospectrumobserver) 实现 [IAudioSpectrumObserver](/zh-CN/api-reference/rtc/unreal-cpp/rtc-interface-class#class_iaudiospectrumobserver) 中的 onRemoteAudioSpectrum 回调并调用 [enableAudioSpectrumMonitor](/zh-CN/api-reference/rtc/unreal-cpp/audio/audio-spectrum#api_irtcengine_enableaudiospectrummonitor) 开启音频频谱监测后，SDK 会按照你设置的时间间隔触发该回调，报告接收到的远端音频数据的频谱。

<a id="callback_iaudiospectrumobserver_onremoteaudiospectrum__parameters"></a>

### 参数

### spectrums

远端用户的音频频谱信息，详见 [UserAudioSpectrumInfo](/zh-CN/api-reference/rtc/unreal-cpp/class-useraudiospectruminfo)。 数组数量等于 SDK 监测到的远端用户数量，数组为空表示没有监测到远端用户的音频频谱。

### spectrumNumber

远端用户的数量。

<a id="callback_iaudiospectrumobserver_onremoteaudiospectrum__return_values"></a>

### 返回值

是否接收频谱数据：

- `true`: 接收。
- `false`: 不接收。

- [IAudioSpectrumObserver](/zh-CN/api-reference/rtc/unreal-cpp/rtc-interface-class#class_iaudiospectrumobserver)
