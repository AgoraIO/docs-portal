## setAINSMode

设置是否开启 AI 降噪功能并设置降噪模式。

<a id="api_irtcengine_setainsmode__prototype"></a>

```text
virtual int setAINSMode(bool enabled,  AUDIO_AINS_MODE mode) = 0;
```

<a id="api_irtcengine_setainsmode__detailed_desc"></a>

你可以调用开方法来开启 AI 降噪功能。该功能可以在保证语音质量的前提下，智能化检测并降低周围环境中多种稳态与非稳态噪声，使人声更加清晰。
                稳态噪声指在任何时间点上都具有相同频率的噪声，常见的稳态噪声有：

- 电视机噪声
- 空调噪声
- 工厂机器噪声等

非稳态噪声是指随时间而快速变化的噪声，常见的非稳态噪声有：

- 雷声
- 爆炸声
- 破裂声等

<a id="api_irtcengine_setainsmode__scenario"></a>

### 适用场景

在语音连麦、在线教育、在线会议等场景中，如果周围环境比较嘈杂，AI 降噪功能可以在保证语音质量的前提下，识别并降低周围的稳态噪声和非稳态噪声，提高语音质量和体验。

<a id="api_irtcengine_setainsmode__timing"></a>

### 调用时机

### mode

降噪模式，详见 [AUDIO_AINS_MODE](/zh-CN/api-reference/rtc/unreal-cpp/enum-audioainsmode)。

## setAudioEffectParameters

设置 SDK 预设人声音效的参数。

<a id="api_irtcengine_setaudioeffectparameters__prototype"></a>

```text
virtual int setAudioEffectParameters(AUDIO_EFFECT_PRESET preset, int param1, int param2) = 0;
```

<a id="api_irtcengine_setaudioeffectparameters__detailed_desc"></a>

### 详情

调用该方法可以对本地发流用户进行如下设置：

- 3D 人声音效：设置 3D 人声音效的环绕周期。
- 电音音效：设置电音音效的基础调式和主音音高。为方便用户自行调节电音音效，建议你将基础调式和主音音高配置选项与应用的 UI 元素绑定。

设置后，频道内所有用户都能听到该效果。

为获取更好的人声效果，建议你在调用该方法前进行以下操作：

- 调用 [setAudioScenario](/zh-CN/api-reference/rtc/unreal-cpp/audio/audio-basic#api_irtcengine_setaudioscenario) 将音频场景设为高音质场景，即 AUDIO_SCENARIO_GAME_STREAMING(3)。
- 调用 [setAudioProfile [2/2]](/zh-CN/api-reference/rtc/unreal-cpp/audio/audio-basic#api_irtcengine_setaudioprofile2) 将 profile 设为 AUDIO_PROFILE_MUSIC_HIGH_QUALITY(4) 或 AUDIO_PROFILE_MUSIC_HIGH_QUALITY_STEREO(5)。

:::caution
注意：

- 该方法在加入频道前后都能调用。
- 请勿将 setAudioProfile [2/2] 的 profile 参数设置为 AUDIO_PROFILE_SPEECH_STANDARD(1)或 AUDIO_PROFILE_IOT(6)，否则该方法不生效。
- 该方法对人声的处理效果最佳，不建议调用该方法处理含音乐的音频数据。
- 调用 setAudioEffectParameters 后，不建议调用以下方法，否则 setAudioEffectParameters 设置的效果会被覆盖：

  - [setAudioEffectPreset](/zh-CN/api-reference/rtc/unreal-cpp/audio/audio-prenpost/audio-effect#api_irtcengine_setaudioeffectpreset)
  - [setVoiceBeautifierPreset](/zh-CN/api-reference/rtc/unreal-cpp/audio/audio-prenpost/audio-effect#api_irtcengine_setvoicebeautifierpreset)
  - [setLocalVoicePitch](/zh-CN/api-reference/rtc/unreal-cpp/audio/audio-prenpost/audio-effect#api_irtcengine_setlocalvoicepitch)
  - [setLocalVoiceEqualization](/zh-CN/api-reference/rtc/unreal-cpp/audio/audio-prenpost/audio-effect#api_irtcengine_setlocalvoiceequalization)
  - [setLocalVoiceReverb](/zh-CN/api-reference/rtc/unreal-cpp/audio/audio-prenpost/audio-effect#api_irtcengine_setlocalvoicereverb)
  - [setVoiceBeautifierParameters](/zh-CN/api-reference/rtc/unreal-cpp/audio/audio-prenpost/audio-effect#api_irtcengine_setvoicebeautifierparameters)
  - [setVoiceConversionPreset](/zh-CN/api-reference/rtc/unreal-cpp/audio/audio-prenpost/audio-effect#api_irtcengine_setvoiceconversionpreset)
- 该方法依赖于美声动态库 `libagora_audio_beauty_extension.dll`，如果删除该动态库会导致无法正常开启该功能。
:::

<a id="api_irtcengine_setaudioeffectparameters__parameters"></a>

### 参数

### preset

SDK 预设的音效，支持以下设置：

- ROOM_ACOUSTICS_3D_VOICE，3D 人声音效。

  - 你需要在使用该枚举前将 setAudioProfile [2/2] 的 profile 参数设置 为 AUDIO_PROFILE_MUSIC_STANDARD_STEREO(3) 或 AUDIO_PROFILE_MUSIC_HIGH_QUALITY_STEREO(5)，否则该枚举设置无效。
  - 启用 3D 人声后，用户需要使用支持双声道的音频播放设备才能听到预期效果。
- PITCH_CORRECTION，电音音效。

### param1

- 如果 preset 设为 ROOM_ACOUSTICS_3D_VOICE ，则 param1 表示 3D 人声音效的环绕周期。取值范围为 [1,60]，单位为秒。默认值为 10，表示人声会 10 秒环绕 360 度。
- 如果 preset 设为 PITCH_CORRECTION，则 param1 表示电音音效的基础调式：

  - `1`: （默认）自然大调。
  - `2`: 自然小调。
  - `3`: 和风小调。

### param2

- 如果 preset 设为 ROOM_ACOUSTICS_3D_VOICE，你需要将 param2 设置为 `0`。
- 如果 preset 设为 PITCH_CORRECTION，则 param2 表示电音音效的主音音高：

  - `1`: A
  - `2`: A#
  - `3`: B
  - `4`: (Default) C
  - `5`: C#
  - `6`: D
  - `7`: D#
  - `8`: E
  - `9`: F
  - `10`: F#
  - `11`: G
  - `12`: G#

<a id="api_irtcengine_setaudioeffectparameters__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。

共振峰比率是影响声音音色的一个参数，共振峰比率取值越小声音会更低沉，取值越大声音会更尖锐。设置共振峰比率后，频道内所有用户都能听到该效果。如果你想要在调整音色的同时改变音调，声网推荐你搭配 [setLocalVoicePitch](/zh-CN/api-reference/rtc/unreal-cpp/audio/audio-prenpost/audio-effect#api_irtcengine_setlocalvoicepitch) 一起使用。

<a id="api_irtcengine_setlocalvoiceformant__timing"></a>

### 调用时机

注： 声网推荐的取值范围为 [-0.4，0.6] ，超出此范围外音效听感可能不佳。

<a id="api_irtcengine_setvoicebeautifierparameters__detailed_desc"></a>

### 详情

调用该方法可以设置歌唱美声效果的性别特征和混响效果。该方法对本地发流用户进行设置。设置后，频道内所有用户都能听到该效果。

为获取更好的人声效果，建议你在调用该方法前进行以下操作：

- 调用 [setAudioScenario](/zh-CN/api-reference/rtc/unreal-cpp/audio/audio-basic#api_irtcengine_setaudioscenario) 将音频场景设为高音质场景，即 AUDIO_SCENARIO_GAME_STREAMING(3)。
- 调用 [setAudioProfile [2/2]](/zh-CN/api-reference/rtc/unreal-cpp/audio/audio-basic#api_irtcengine_setaudioprofile2) 将 profile 设为 AUDIO_PROFILE_MUSIC_HIGH_QUALITY(4) 或 AUDIO_PROFILE_MUSIC_HIGH_QUALITY_STEREO(5)。

:::caution
注意：

- 该方法在加入频道前后都能调用。
- 请勿将 setAudioProfile [2/2] 的 profile 参数设置为 AUDIO_PROFILE_SPEECH_STANDARD(1)或 AUDIO_PROFILE_IOT(6)，否则该方法不生效。
- 该方法对人声的处理效果最佳，不建议调用该方法处理含音乐的音频数据。
- 调用 setVoiceBeautifierParameters，不建议调用以下方法，否则 setVoiceBeautifierParameters 设置的效果会被覆盖：

  - [setAudioEffectPreset](/zh-CN/api-reference/rtc/unreal-cpp/audio/audio-prenpost/audio-effect#api_irtcengine_setaudioeffectpreset)
  - [setAudioEffectParameters](/zh-CN/api-reference/rtc/unreal-cpp/audio/audio-prenpost/audio-effect#api_irtcengine_setaudioeffectparameters)
  - [setVoiceBeautifierPreset](/zh-CN/api-reference/rtc/unreal-cpp/audio/audio-prenpost/audio-effect#api_irtcengine_setvoicebeautifierpreset)
  - [setLocalVoicePitch](/zh-CN/api-reference/rtc/unreal-cpp/audio/audio-prenpost/audio-effect#api_irtcengine_setlocalvoicepitch)
  - [setLocalVoiceEqualization](/zh-CN/api-reference/rtc/unreal-cpp/audio/audio-prenpost/audio-effect#api_irtcengine_setlocalvoiceequalization)
  - [setLocalVoiceReverb](/zh-CN/api-reference/rtc/unreal-cpp/audio/audio-prenpost/audio-effect#api_irtcengine_setlocalvoicereverb)
  - [setVoiceConversionPreset](/zh-CN/api-reference/rtc/unreal-cpp/audio/audio-prenpost/audio-effect#api_irtcengine_setvoiceconversionpreset)
- 该方法依赖于美声动态库 `libagora_audio_beauty_extension.dll`，如果删除该动态库会导致无法正常开启该功能。
:::

### preset

### param1

歌声的性别特征：

- `2`: 女声。

### param2

歌声的混响效果：

- `1`: 歌声在小房间的混响效果。
