<a id="class_directcdnstreamingstats__prototype"></a>

```cpp
struct DirectCdnStreamingStats {
    int videoWidth;
    int videoHeight;
    int fps;
    int videoBitrate;
    int audioBitrate;
};
```

<a id="class_directcdnstreamingstats__parameters"></a>

## 属性

### `videoWidth`

视频的宽度（px）。

### `videoHeight`

视频的高度（px）。

### `fps`

当前视频帧率（fps）。

### `videoBitrate`

当前视频码率（bps）。

### `audioBitrate`

当前音频码率（bps）。
