<a id="class_codeccapinfo__prototype"></a>

```cpp
struct CodecCapInfo {
  VIDEO_CODEC_TYPE codecType;
  int codecCapMask;
  CodecCapLevels codecLevels;
};
```

<a id="class_codeccapinfo__detailed_desc"></a>

<a id="class_codeccapinfo__parameters"></a>

## 属性

### `codecType`

视频编解码类型。详见 [VIDEO_CODEC_TYPE](/zh-CN/api-reference/rtc/unreal-cpp/enum-videocodectype)。

### `codecCapMask`

SDK 编解码类型的 bit mask。详见 [CODEC_CAP_MASK](/zh-CN/api-reference/rtc/unreal-cpp/enum-codeccapmask)。

### `codecLevels`

SDK 支持的编解码能力等级。详见 [CodecCapLevels](/zh-CN/api-reference/rtc/unreal-cpp/class-codeccaplevels)。
