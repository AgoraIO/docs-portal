<a id="api_imusiccontentcenter_getcaches__prototype"></a>

```text
virtual int getCaches(MusicCacheInfo *cacheInfo, int32_t* cacheInfoSize) = 0;
```

<a id="api_imusiccontentcenter_getcaches__detailed_desc"></a>

### 详情

调用该方法前，你需要预先分配一定大小的内存空间用来存储缓存音乐资源的信息。如果你需要设置可缓存的音乐资源数量，可通过 [initialize](/zh-CN/api-reference/rtc/unreal-cpp/play/drm#api_imusiccontentcenter_initialize) 的 configuration 来设置。

当你不再需要使用已缓存的音乐资源时，你需要及时释放内存以防止内存泄漏。

<a id="api_imusiccontentcenter_getcaches__parameters"></a>

### 参数

### cacheInfo

输出参数，指向用于存储已缓存音乐资源的内存缓冲区的指针。

### cacheInfoSize

输入和输出参数。

- 输入值：cacheInfo 数组的长度，即你所分配的 [MusicCacheInfo](/zh-CN/api-reference/rtc/unreal-cpp/class-musiccacheinfo) 结构体的数量。
- 输出值：方法执行完毕后输出的 MusicCacheInfo 结构体的数量。

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。

## getInternalSongCode

创建音乐资源的副歌片段编号。

<a id="api_imusiccontentcenter_getinternalsongcode__prototype"></a>

```text
virtual int getInternalSongCode(int64_t songCode, const char* jsonOption, int64_t& internalSongCode) = 0;
```

<a id="api_imusiccontentcenter_getinternalsongcode__detailed_desc"></a>

<a id="api_imusiccontentcenter_getinternalsongcode__scenario"></a>

### 适用场景

当你需要播放某一音乐资源的副歌片段前，你需要调用此方法，通过 jsonOption 参数和该音乐资源的 songCode 来为该音乐资源的副歌片段创建一个编号，作为该资源的唯一标识。当你获取到该片段的编号后，在你调用相应方法打开、预加载、移除该资源时，将该内部歌曲编号传入 songCode 参数。

<a id="api_imusiccontentcenter_getinternalsongcode__parameters"></a>

### 参数

### songCode

音乐资源编号，用于标识音乐资源。你可以通过调用 [getMusicCollectionWithMusicChartId](/zh-CN/api-reference/rtc/unreal-cpp/play/drm#api_imusiccontentcenter_getmusiccollectionbymusicchartid) 或 [searchMusic](/zh-CN/api-reference/rtc/unreal-cpp/play/drm#api_imusiccontentcenter_searchmusic) 方法来获取音乐资源，并通过由此触发的 [onMusicCollectionResult](/zh-CN/api-reference/rtc/unreal-cpp/play/drm#callback_imusiccontentcentereventhandler_onmusiccollectionresult) 回调获取音乐资源的编号（songCode）。

### jsonOption

扩展 JSON 字段，默认为 NULL。目前支持传入下列值：

| Key 值 | Value 值 | 示例 |
| --- | --- | --- |
| sceneType | <Slot name="api-center-table-0" /> | \\\{"sceneType"\:1\\\} |
| highPart | 副歌片段的索引。你可以从 [onMusicCollectionResult](/zh-CN/api-reference/rtc/unreal-cpp/play/drm#callback_imusiccontentcentereventhandler_onmusiccollectionresult) 回调中获取副歌片段的索引然后传值。索引序号从 0 开始。 | \\\{"format": \\\{"highpart": 0\\\}\\\} |

<Slot for="api-center-table-0">

场景类型：

- 1：直播场景：K 歌及背景音乐播放。
- 2：直播场景：背景音乐播放。
- 3：（默认）语聊场景：K 歌。
- 4：语聊场景：背景音乐播放。
- 5：VR 场景：K 歌及背景音乐播放。

:::note
注： 声网会根据你在 sceneType 传入的应用场景进行收费。不同的应用场景对应不同的费率，你可以参考 [计费说明](/zh-CN/solutions/online-ktv/online-ktv-sdk/reference/billing) 查看详细的计费。如果需要切换到不同场景，需要重新调用此方法并传入 sceneType 的值。
:::

</Slot>

### internalSongCode

输出参数，音乐资源的内部歌曲编号。

<a id="api_imusiccontentcenter_getinternalsongcode__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。

<a id="api_imusicplayer_open__note"></a>

:::note
注： 如果你想要打开的音乐资源受数字版权保护，则需要调用此方法打开。对于不受数字版权保护的音乐资源，你可以选择通过调用此方法或 IMediaPlayer 类下的 [open](/zh-CN/api-reference/rtc/unreal-cpp/play/mediaplayer/mediaplayer-open#api_imediaplayer_open) 方法来打开。
:::

在调用此方法之前，请确保需要播放的音乐资源已加载完成。你可以调用 [isPreloaded](/zh-CN/api-reference/rtc/unreal-cpp/play/drm#api_imusiccontentcenter_ispreloaded) 方法来检测音乐资源是否已被预加载，或通过 [onPreLoadEvent](/zh-CN/api-reference/rtc/unreal-cpp/play/drm#callback_imusiccontentcentereventhandler_onpreloadevent) 回调得知。

调用该方法后会触发 [onPlayerSourceStateChanged](/zh-CN/api-reference/rtc/unreal-cpp/play/mediaplayer/mediaplayer-observer#callback_imediaplayersourceobserver_onplayersourcestatechanged) 回调。在收到报告播放状态为 PLAYER_STATE_OPEN_COMPLETED 后，你可以调用 [play](/zh-CN/api-reference/rtc/unreal-cpp/play/mediaplayer/mediaplayer-control#api_imediaplayer_play) 方法播放媒体文件。

<a id="api_imusicplayer_open__parameters"></a>

### 参数

### songCode

音乐资源的编号，用于标识音乐资源。

### startPos

设置起始播放位置（毫秒），默认值为 0。

<a id="api_imusicplayer_open__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。
