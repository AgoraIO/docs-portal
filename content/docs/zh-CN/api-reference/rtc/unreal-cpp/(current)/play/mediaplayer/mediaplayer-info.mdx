## getDuration

<a id="api_imediaplayer_getduration__prototype"></a>

```cpp

```

<a id="api_imediaplayer_getduration__parameters"></a>

### 参数

#### `duration`

输出参数。媒体文件总时长（毫秒）。

<a id="api_imediaplayer_getduration__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。 详见 [错误码](https://doc.shengwang.cn/api-ref/rtc/unreal-cpp/error-code) 了解详情和解决建议。

## getPlayoutVolume

获取当前本地播放音量。

<a id="api_imediaplayer_getplayoutvolume__prototype"></a>

```cpp
virtual int getPlayoutVolume(int& volume) = 0;
```

<a id="api_imediaplayer_getplayoutvolume__parameters"></a>

### 参数

#### `volume`

输出参数。本地播放音量，取值范围从 0 到 100：

- 0: 无声。

## getStreamInfo

通过媒体流的索引值获取媒体流信息。

<a id="api_imediaplayer_getstreaminfo__prototype"></a>

```cpp
virtual int getStreamInfo(int64_t index, media::base::PlayerStreamInfo* info) = 0;
```

<a id="api_imediaplayer_getstreaminfo__detailed_desc"></a>

<a id="api_imediaplayer_getstreaminfo__timing"></a>

### 调用时机

你需要在 [getStreamCount](/zh-CN/api-reference/rtc/unreal-cpp/play/mediaplayer/mediaplayer-info#api_imediaplayer_getstreamcount) 后调用该方法。

<a id="api_imediaplayer_getstreaminfo__restriction"></a>

### 调用限制

无。

<a id="api_imediaplayer_getstreaminfo__parameters"></a>

### 参数

#### `index`

媒体流索引值。该参数需小于 [getStreamCount](/zh-CN/api-reference/rtc/unreal-cpp/play/mediaplayer/mediaplayer-info#api_imediaplayer_getstreamcount) 的 count 参数。

#### `info`

输出参数。媒体流的所有信息，详见 [PlayerStreamInfo](/zh-CN/api-reference/rtc/unreal-cpp/class-playerstreaminfo)。

<a id="api_imediaplayer_getstreaminfo__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。 详见 [错误码](https://doc.shengwang.cn/api-ref/rtc/unreal-cpp/error-code) 了解详情和解决建议。

### 所属接口类
- [IMediaPlayer](/zh-CN/api-reference/rtc/unreal-cpp/rtc-interface-class#class_imediaplayer)

## onPlayerPlaybackStats

报告当前播放的媒体资源的相关信息。

<a id="callback_imediaplayersourceobserver_onplayerplaybackstats__prototype"></a>

```cpp
virtual void onPlayerPlaybackStats(const media::base::PlayerPlaybackStats& stats) {
    (void)stats;
  }
```

<a id="callback_imediaplayersourceobserver_onplayerplaybackstats__detailed_desc"></a>

### 详情

当媒体资源开始播放后，SDK 会每秒触发一次该回调，报告媒体资源的相关信息。

<a id="callback_imediaplayersourceobserver_onplayerplaybackstats__parameters"></a>

### 参数

#### `stats`

媒体资源的相关信息，详见 [PlayerPlaybackStats](/zh-CN/api-reference/rtc/unreal-cpp/class-playerplaybackstats)。

### 所属接口类
- [IMediaPlayerSourceObserver](/zh-CN/api-reference/rtc/unreal-cpp/rtc-interface-class#class_imediaplayersourceobserver)
