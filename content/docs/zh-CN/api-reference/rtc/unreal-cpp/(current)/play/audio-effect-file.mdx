## getEffectDuration

获取指定音效文件总时长。

<a id="api_irtcengine_geteffectduration__prototype"></a>

```cpp
virtual int getEffectDuration(const char* filePath) = 0;
```

<a id="api_irtcengine_geteffectduration__detailed_desc"></a>

### 详情

:::warning[注意]
该方法需要在加入频道后调用。
:::

<a id="api_irtcengine_geteffectduration__parameters"></a>

### 参数

#### `filePath`

文件路径：

- Android: 文件路径，需精确到文件名及后缀。支持在线文件的 URL 地址，本地文件的 URI 地址、绝对路径或以 `/assets/` 开头的路径。通过绝对路径访问本地文件可能会遇到权限问题，建议使用 URI 地址访问本地文件。例如 `content://com.android.providers.media.documents/document/audio%3A14441`。
- Windows: 音频文件的绝对路径或 URL 地址，需精确到文件名及后缀。例如 `C:\music\audio.mp4`。

<a id="api_irtcengine_geteffectduration__return_values"></a>

### 返回值

- 方法调用成功，返回指定音效文件时长（毫秒）。
- &lt; 0：方法调用失败。 详见 [错误码](https://doc.shengwang.cn/api-ref/rtc/unreal-cpp/error-code) 了解详情和解决建议。

## playAllEffects

播放所有音效文件。

<a id="api_irtcengine_playalleffects__prototype"></a>

```cpp
virtual int playAllEffects(int loopCount, double pitch, double pan, int gain, bool publish = false) = 0;
```

<a id="api_irtcengine_playalleffects__detailed_desc"></a>

### 详情

多次调用 [preloadEffect](/zh-CN/api-reference/rtc/unreal-cpp/play/audio-effect-file#api_irtcengine_preloadeffect) 预加载多个音效文件后，你可以调用本方法播放所有预加载的音效文件。

<a id="api_irtcengine_playalleffects__parameters"></a>

### 参数

#### `loopCount`

音效文件循环播放的次数：

- -1: 无限循环播放音效文件，直至调用 [stopEffect](/zh-CN/api-reference/rtc/unreal-cpp/play/audio-effect-file#api_irtcengine_stopeffect) 或 [stopAllEffects](/zh-CN/api-reference/rtc/unreal-cpp/play/audio-effect-file#api_irtcengine_stopalleffects) 后停止。
- 0: 播放音效文件一次。
- 1: 播放音效文件两次。

#### `pitch`

音效的音调。取值范围为 [0.5,2.0]。默认值为 1.0，代表原始音调。取值越小，则音调越低。

#### `pan`

音效的空间位置。取值范围为 [-1.0,1.0]:

- -1.0: 音效出现在左边。
- 0: 音效出现在正前边。
- 1.0: 音效出现在右边。

#### `gain`

音效的音量。取值范围为 [0,100]。100 为默认值，代表原始音量。取值越小，则音量越低。

#### `publish`

是否将音效发布到远端：

- `true`: 将音效发布到远端。本地和远端用户都能听到该音效。
- `false`: （默认）不将音效发布到远端。只能本地用户能听到该音效。

<a id="api_irtcengine_playalleffects__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。 详见 [错误码](https://doc.shengwang.cn/api-ref/rtc/unreal-cpp/error-code) 了解详情和解决建议。

- [IRtcEngine](/zh-CN/api-reference/rtc/unreal-cpp/rtc-interface-class#class_irtcengine)

## playEffect

播放指定的本地或在线音效文件。

<a id="api_irtcengine_playeffect3__prototype"></a>

```cpp
virtual int playEffect(int soundId,
    const char* filePath,
    int loopCount,
    double pitch,
    double pan,
    int gain,
    bool publish,
    int startPos) = 0;
```

<a id="api_irtcengine_playeffect3__detailed_desc"></a>

你可以多次调用该方法，传入不同的 soundID 和 filePath，同时播放多个音效文件。为获得最佳用户体验，建议同时播放的音效文件不超过 3 个。

<a id="api_irtcengine_playeffect3__timing"></a>

### 调用时机

该方法在加入频道前后均可调用。

<a id="api_irtcengine_playeffect3__restriction"></a>

### 调用限制

如果你需要播放在线音效文件，声网建议先将在线音效文件缓存到本地设备，调用 [preloadEffect](/zh-CN/api-reference/rtc/unreal-cpp/play/audio-effect-file#api_irtcengine_preloadeffect) 将缓存的音效文件预加载到内存中，然后再调用此方法播放音效。否则，可能出现因在线音效文件加载超时、加载失败而导致的播放失败和无声的问题。

<a id="api_irtcengine_playeffect3__related"></a>

### 相关回调

音效文件播放结束后，SDK 会触发 onAudioEffectFinished 回调。

<a id="api_irtcengine_playeffect3__parameters"></a>

### 参数

#### `soundId`

音效的 ID。每个音效的 ID 具有唯一性。

:::warning[注意]
如果你已通过 [preloadEffect](/zh-CN/api-reference/rtc/unreal-cpp/play/audio-effect-file#api_irtcengine_preloadeffect) 将音效加载至内存，请确保该参数与 preloadEffect 中设置的 soundId 相同。
:::

#### `filePath`

播放文件的地址，支持在线文件的 URL 地址、播放文件的绝对路径，需精确到文件名及后缀。支持的音频格式包括 MP3、AAC、M4A、MP4、WAV、3GP 等。

:::warning[注意]
如果你已通过 [preloadEffect](/zh-CN/api-reference/rtc/unreal-cpp/play/audio-effect-file#api_irtcengine_preloadeffect) 将音效加载至内存，请确保该参数与 preloadEffect 中设置的 filePath 相同。
:::

#### `loopCount`

音效循环播放的次数。

- ≥ 0: 循环播放次数。例如，1 表示循环播放 1 次，即总计播放 2 次。
- -1: 无限循环播放。

#### `pitch`

音效的音调，取值范围为 [0.5,2.0]。默认值为 1.0，表示原始音调。取值越小，则音调越低。

#### `pan`

音效的空间位置。取值范围为 [-1.0,1.0]，例如：

- -1.0：音效出现在左边
- 0.0：音效出现在正前方
- 1.0：音效出现在右边

#### `gain`

音效的音量。取值范围为 [0.0,100.0]。默认值为 100.0，表示原始音量。取值越小，则音量越低。

#### `publish`

是否将音效发布至远端：

- `true`: 将音效发布至远端。本地用户和远端用户都能听到音效。
- `false`: 不将音效发布至远端。只有本地用户能听到音效。

#### `startPos`

音效文件的播放位置，单位为毫秒。

<a id="api_irtcengine_playeffect3__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。 详见 [错误码](https://doc.shengwang.cn/api-ref/rtc/unreal-cpp/error-code) 了解详情和解决建议。

- [IRtcEngine](/zh-CN/api-reference/rtc/unreal-cpp/rtc-interface-class#class_irtcengine)
