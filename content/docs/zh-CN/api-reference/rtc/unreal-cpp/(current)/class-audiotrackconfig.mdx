<a id="class_audiotrackconfig__prototype"></a>

```text
struct AudioTrackConfig {

  bool enableLocalPlayback;

  bool enableAudioProcessing;
  AudioTrackConfig() : enableLocalPlayback(true),enableAudioProcessing(false) {}
};
```

<a id="class_audiotrackconfig__parameters"></a>

## 属性

### enableLocalPlayback

是否启用本地音频播放：

- `true`：(默认) 启用本地音频播放。
- `false`：不启用本地音频播放。

### enableAudioProcessing

是否启用音频处理模块：

- `true`：启用音频处理模块，应用回声消除 (AEC)、降噪 (ANS) 和自动增益控制 (AGC) 效果。
- `false`：（默认）不启用音频处理模块。

:::note
注意： 该参数设置仅对 AUDIO_TRACK_DIRECT 类型的自定义音频采集轨道生效。
:::
