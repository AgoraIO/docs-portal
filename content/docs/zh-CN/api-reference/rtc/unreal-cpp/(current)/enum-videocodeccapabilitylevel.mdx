## 枚举值

<ParameterList>
<a id="codec_capability_level_unspecified"></a>
<Parameter name="CODEC_CAPABILITY_LEVEL_UNSPECIFIED">

-1：不支持的视频类型。目前仅支持对 H.264 和 H.265 格式的视频进行查询，如果视频为其他格式，则返回该值。

</Parameter>
<a id="codec_capability_level_basic_support"></a>
<Parameter name="CODEC_CAPABILITY_LEVEL_BASIC_SUPPORT">

5：基本的编解码支持，即：对 1080p、30 fps 以下的视频进行编解码。

</Parameter>
<a id="codec_capability_level_1080p30fps"></a>
<Parameter name="CODEC_CAPABILITY_LEVEL_1080P30FPS">

10：最高支持对 1080p、30 fps 的视频进行编解码。

</Parameter>
<a id="codec_capability_level_1080p60fps"></a>
<Parameter name="CODEC_CAPABILITY_LEVEL_1080P60FPS">

20：最高支持对 1080p、60 fps 的视频进行编解码。

</Parameter>
<a id="codec_capability_level_4k60fps"></a>
<Parameter name="CODEC_CAPABILITY_LEVEL_4K60FPS">

30：最高支持对 4K、30 fps 的视频进行编解码。

</Parameter>
</ParameterList>
