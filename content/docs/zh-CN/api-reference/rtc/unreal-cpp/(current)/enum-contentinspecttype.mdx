## 枚举值

### CONTENT_INSPECT_INVALID

0：（默认）该功能模块无实际功能。请不要将 type 设为该值。

### CONTENT_INSPECT_SUPERVISION

2：使用声网自研插件截图上传。SDK 会对视频流进行截图并上传。

### CONTENT_INSPECT_IMAGE_MODERATION

3：使用云市场插件截图上传。SDK 会使用云市场视频审核插件对视频流进行截图并上传。
