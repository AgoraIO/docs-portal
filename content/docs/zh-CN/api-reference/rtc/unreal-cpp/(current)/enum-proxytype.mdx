## 枚举值

<ParameterList>
<a id="none_proxy_type"></a>
<Parameter name="NONE_PROXY_TYPE">

0: 预留参数，暂不支持。

</Parameter>
<a id="udp_proxy_type"></a>
<Parameter name="UDP_PROXY_TYPE">

1: UDP 协议的云代理，即 Force UDP 云代理模式。在该模式下，SDK 始终通过 UDP 协议传输数据。

</Parameter>
<a id="tcp_proxy_type"></a>
<Parameter name="TCP_PROXY_TYPE">

2: TCP（加密）协议的云代理，即 Force TCP 云代理模式。在该模式下，SDK 始终通过 TLS 443 传输数据。

</Parameter>
<a id="local_proxy_type"></a>
<Parameter name="LOCAL_PROXY_TYPE">

3: 预留参数，暂不支持。

</Parameter>
<a id="tcp_proxy_auto_fallback_type"></a>
<Parameter name="TCP_PROXY_AUTO_FALLBACK_TYPE">

4: 自动模式。在该模式下，SDK 优先连接 SD-RTN™，如果连接失败，自动切换为 TLS 443。

</Parameter>
</ParameterList>
