## getUserInfoByUid

通过 UID 获取用户信息。

<a id="api_irtcengine_getuserinfobyuid__prototype"></a>

```text
virtual int getUserInfoByUid(uid_t uid, rtc::UserInfo* userInfo, const char* channelId = NULL, const char* localUserAccount = NULL) = 0;
```

<a id="api_irtcengine_getuserinfobyuid__detailed_desc"></a>

<a id="api_irtcengine_getuserinfobyuid__getUserInfo_desc"></a>

远端用户加入频道后，SDK 会获取到该远端用户的 UID 和 User Account，然后缓存一个包含了远端用户 UID 和 User Account 的映射表，并在本地触发 [onUserInfoUpdated](/zh-CN/api-reference/rtc/unreal-cpp/channel#callback_irtcengineeventhandler_onuserinfoupdated) 回调。收到回调后，调用该方法传入 UID 来获取包含了指定用户 User Account 的 [UserInfo](/zh-CN/api-reference/rtc/unreal-cpp/class-userinfo) 对象。

<a id="api_irtcengine_getuserinfobyuid__timing"></a>

### 调用时机

在收到 [onUserInfoUpdated](/zh-CN/api-reference/rtc/unreal-cpp/channel#callback_irtcengineeventhandler_onuserinfoupdated) 回调后调用。

<a id="api_irtcengine_getuserinfobyuid__restriction"></a>

### 调用限制

无。

### 相关回调

<a id="api_irtcengine_getuserinfobyuid__parameters"></a>

### 参数

### uid

用户 ID。

### userInfo

输入和输出参数。标识用户的 [UserInfo](/zh-CN/api-reference/rtc/unreal-cpp/class-userinfo) 对象：

- 输入值：一个 UserInfo 对象。
- 输出值：一个包含了用户 User Account 和 UID 的 UserInfo 对象。

### channelId

频道名。该参数标识用户进行实时音视频互动的频道。App ID 一致的前提下，填入相同频道名的用户会进入同一个频道进行音视频互动。该参数为长度在 64 字节以内的字符串。以下为支持的字符集范围（共 89 个字符）:

<a id="api_irtcengine_getuserinfobyuid__d99e180"></a>

- 26 个小写英文字母 a~z
- 26 个大写英文字母 A~Z
- 10 个数字 0~9
- "!"、"#"、"$"、"%"、"&"、"("、")"、"+"、"-"、":"、";"、"&lt;"、"="、"."、"&gt;"、"?"、"@"、"["、"]"、"^"、"_"、"\{"、"\}"、"|"、"~"、","

### localUserAccount

本地用户的 User Account。

## joinChannel [1/2]

加入频道。

<a id="api_irtcengine_joinchannel__prototype"></a>

```text
virtual int joinChannel(const char* token, const char* channelId, const char* info,
                        uid_t uid) = 0;
```

<a id="api_irtcengine_joinchannel__detailed_desc"></a>

加入频道后，默认情况下用户订阅频道内所有其他用户的音频流和视频流，因此会产生用量并**影响计费**。如果想取消订阅，可以通过相应的 mute 方法实现。

<a id="api_irtcengine_joinchannel__timing"></a>

### 调用时机

该方法需要在 [initialize](/zh-CN/api-reference/rtc/unreal-cpp/initialize#api_irtcengine_initialize) 之后再调用。

<a id="api_irtcengine_joinchannel__restriction"></a>

### 调用限制

- 该方法仅支持用户一次加入一个频道。
- 使用不同 App ID 的 App 不能互通。
- 加入频道前，请确保用于生成 Token 的 App ID 和调用 [initialize](/zh-CN/api-reference/rtc/unreal-cpp/initialize#api_irtcengine_initialize) 方法初始化引擎时使用的是同一个 App ID，否则使用 Token 加入频道会失败。

<a id="api_irtcengine_joinchannel__related"></a>

### 相关回调

成功调用该方法加入频道后会触发以下回调：

- 本地会触发 [onJoinChannelSuccess](/zh-CN/api-reference/rtc/unreal-cpp/channel#callback_irtcengineeventhandler_onjoinchannelsuccess) 和 [onConnectionStateChanged](/zh-CN/api-reference/rtc/unreal-cpp/network#callback_irtcengineeventhandler_onconnectionstatechanged) 回调。
- 通信场景下的用户和直播场景下的主播加入频道后，远端会触发 [onUserJoined](/zh-CN/api-reference/rtc/unreal-cpp/channel#callback_irtcengineeventhandler_onuserjoined) 回调。

在网络状况不理想的情况下，客户端可能会与声网服务器失去连接，此时 SDK 会自动尝试重连，重连成功后，本地会触发 [onRejoinChannelSuccess](/zh-CN/api-reference/rtc/unreal-cpp/channel#callback_irtcengineeventhandler_onrejoinchannelsuccess) 回调。

<a id="api_irtcengine_joinchannel__parameters"></a>

### 参数

### token

在服务端生成的用于鉴权的动态密钥。详见[使用 Token 鉴权](/zh-CN/realtime-media/rtc/build/setup-and-access/token-authentication)。

:::note
注：

- （推荐）如果你的项目开启了安全模式，即选择 APP ID + Token 为鉴权机制，则该参数为必填。
- 如果你的项目仅开启调试模式，即选择 APP ID 为鉴权机制，则无需填入 Token 即可加入频道。成功加入频道 24 小时后会自动退出该频道。
- 如果你需要同时加入多个频道或在频道间频繁切换，声网推荐你使用通配 Token 以避免每加入一个新的频道都需向服务端申请一个新的 Token，详见 [使用通配 Token](/zh-CN/realtime-media/rtc/build/security-and-auth/wildcard-token)。
:::

### channelId

<a id="api_irtcengine_joinchannel__d99e178"></a>

频道名。该参数标识用户进行实时音视频互动的频道。App ID 一致的前提下，填入相同频道名的用户会进入同一个频道进行音视频互动。该参数为长度在 64 字节以内的字符串。以下为支持的字符集范围（共 89 个字符）:

<a id="api_irtcengine_joinchannel__d99e180"></a>

- 26 个小写英文字母 a~z
- 26 个大写英文字母 A~Z
- 10 个数字 0~9
- "!"、"#"、"$"、"%"、"&"、"("、")"、"+"、"-"、":"、";"、"&lt;"、"="、"."、"&gt;"、"?"、"@"、"["、"]"、"^"、"_"、"\{"、"\}"、"|"、"~"、","

### info

(非必选项) 预留参数。

### uid

用户 ID。该参数用于标识在实时音视频互动频道中的用户。你需要自行设置和管理用户 ID，并确保同一频道内的每个用户 ID 是唯一的。该参数为 32 位无符号整数。建议设置范围：1 到 232-1。如果不指定（即设为 0），SDK 会自动分配一个，并在 onJoinChannelSuccess 回调中返回， 应用层必须记住该返回值并维护，SDK 不对该返回值进行维护。

<a id="api_irtcengine_joinchannel__return_values"></a>

### 返回值

- 0：方法调用成功。
- &lt; 0：方法调用失败。详见[错误码](/zh-CN/api-reference/rtc/error-code)了解详情和解决建议。

  - -2：传入的参数无效。例如，使用了不合法的 Token，uid 参数未设置为整型，或 [ChannelMediaOptions](/zh-CN/api-reference/rtc/unreal-cpp/class-channelmediaoptions) 成员值不合法。你需要填入有效的参数，重新加入频道。
  - -3：[IRtcEngine](/zh-CN/api-reference/rtc/unreal-cpp/rtc-interface-class#class_irtcengine) 对象初始化失败。你需要重新初始化 IRtcEngine 对象。
  - -7：IRtcEngine 对象尚未初始化。你需要在调用该方法前成功初始化 IRtcEngine 对象。
  - -8：IRtcEngine 对象内部状态错误。可能的原因是：调用 [startEchoTest](/zh-CN/api-reference/rtc/unreal-cpp/network#api_irtcengine_startechotest3) 开始通话回路测试后，未调用 [stopEchoTest](/zh-CN/api-reference/rtc/unreal-cpp/network#api_irtcengine_stopechotest) 停止测试就调用该方法加入频道。你需要在该方法前调用 stopEchoTest。
  - -17：加入频道被拒绝。可能的原因是用户已经在频道中。建议通过 [onConnectionStateChanged](/zh-CN/api-reference/rtc/unreal-cpp/network#callback_irtcengineeventhandler_onconnectionstatechanged) 回调判断用户是否在频道中。除收到 CONNECTION_STATE_DISCONNECTED(1) 状态外，不要再次调用该方法加入频道。
  - -102：频道名无效。你需要在 channelId 中填入有效的频道名，重新加入频道。
  - -121：用户 ID 无效。你需要在 uid 中填入有效的用户 ID，重新加入频道。

### 所属接口类

- [IRtcEngine](/zh-CN/api-reference/rtc/unreal-cpp/rtc-interface-class#class_irtcengine)

## joinChannelEx

加入频道。

<a id="api_irtcengineex_joinchannelex__prototype"></a>

```text
virtual int joinChannelEx(const char* token, const RtcConnection& connection,
                              const ChannelMediaOptions& options,
                              IRtcEngineEventHandler* eventHandler) = 0;
```

<a id="api_irtcengineex_joinchannelex__detailed_desc"></a>

调用该方法，你可以同时加入多个频道。如果你想在不同的设备上加入相同的频道，请确保你在不同设备上使用的用户 ID 都不同。

<a id="api_irtcengineex_joinchannelex__scenario"></a>

### 适用场景

该方法适用于多频道场景。

<a id="api_irtcengineex_joinchannelex__timing"></a>

### 调用时机

该方法需要在 [initialize](/zh-CN/api-reference/rtc/unreal-cpp/initialize#api_irtcengine_initialize) 之后调用。

在多摄像头采集场景下，你需要在调用该方法之后调用 [startPreview [2/2]](/zh-CN/api-reference/rtc/unreal-cpp/video/video-basic#api_irtcengine_startpreview2) 方法设置 sourceType 为 VIDEO_SOURCE_CAMERA_SECONDARY，以确保第二个摄像头采集正常。

<a id="api_irtcengineex_joinchannelex__restriction"></a>

### 调用限制

如果你已经在一个频道内，你不能用相同的用户 ID 再次加入该频道。

加入频道前，请确保用于生成 Token 的 App ID 和调用 [initialize](/zh-CN/api-reference/rtc/unreal-cpp/initialize#api_irtcengine_initialize) 方法初始化引擎时使用的是同一个 App ID，否则使用 Token 加入频道会失败。

<a id="api_irtcengineex_joinchannelex__related"></a>

### 相关回调

成功调用该方法加入频道后会触发以下回调：

- 本地会触发 [onJoinChannelSuccess](/zh-CN/api-reference/rtc/unreal-cpp/channel#callback_irtcengineeventhandler_onjoinchannelsuccess) 和 [onConnectionStateChanged](/zh-CN/api-reference/rtc/unreal-cpp/network#callback_irtcengineeventhandler_onconnectionstatechanged) 回调。

## preloadChannel

使用 token、channelId、uid 预加载频道。

<a id="api_irtcengine_preloadchannel__prototype"></a>

```text
 virtual int preloadChannel(const char* token, const char* channelId, uid_t uid) = 0;
```

<a id="api_irtcengine_preloadchannel__detailed_desc"></a>

<a id="api_irtcengine_preloadchannel__desc1"></a>

调用该方法可以减少观众频繁切换频道时加入频道的时间，从而缩短观众听到主播首帧音频以及看到首帧画面的耗时，提升观众端的视频体验。

<a id="api_irtcengine_preloadchannel__desc2"></a>

如果当前频道已经成功预加载，观众加入、离开频道后如需再次加入该频道，只要预加载时传入的 Token 仍在有效期内，则无需重新预加载。

<a id="api_irtcengine_preloadchannel__note3"></a>

:::note
注： 预加载不生效不会影响后续正常加入频道，也不会增加加入频道的耗时。
:::

<a id="api_irtcengine_preloadchannel__timing"></a>

### 调用时机

为了提升预加载频道的用户体验，声网推荐你在确认频道名、用户信息后、加入频道前，尽早调用该方法。

<a id="api_irtcengine_preloadchannel__restriction"></a>

### 调用限制

- 调用该方法时，请确保用户角色设为观众、音频应用场景设为非合唱场景（AUDIO_SCENARIO_CHORUS），否则预加载不生效。
- 请确保预加载频道时传入的频道名、用户 ID、Token 和后续加入频道时传入的值相同，否则预加载不生效。
- 目前一个 [IRtcEngine](/zh-CN/api-reference/rtc/unreal-cpp/rtc-interface-class#class_irtcengine) 实例最多支持预加载 20 个频道，如超出限制，仅最新预加载的 20 个频道生效。

Token 过期后，根据预加载频道的数量，你可以通过不同方式来传入用于预加载频道的新 Token：

    :::note

  - 如果你使用了不同的 Token：调用此方法并传入你的用户 ID、对应的频道名和更新后的 Token。

- 26 个大写英文字母 A~Z
- 10 个数字 0~9

远端用户加入频道后，SDK 会获取到该远端用户的 UID 和 User Account，然后缓存一个包含了远端用户 UID 和 User Account 的 Mapping 表，并在本地触发该回调。

<a id="callback_irtcengineeventhandler_onuserinfoupdated__parameters"></a>

### 参数

### uid

远端用户 ID。

### info

标识用户信息的 UserInfo 对象，包含用户 UID 和 User Account。详见 [UserInfo](/zh-CN/api-reference/rtc/unreal-cpp/class-userinfo) 类。

## onUserJoined

远端用户（通信场景）/主播（直播场景）加入当前频道回调。

<a id="callback_irtcengineeventhandler_onuserjoined__prototype"></a>

```text
virtual void onUserJoined(uid_t uid, int elapsed) {
    (void)uid;
    (void)elapsed;
    }
```

<a id="callback_irtcengineeventhandler_onuserjoined__detailed_desc"></a>

<a id="callback_irtcengineeventhandler_onuserjoined__detailed_desc_scene"></a>

- 通信场景下，该回调提示有远端用户加入了频道。如果加入之前已经有其他用户在频道中，新加入的用户也会收到这些已有用户加入频道的回调。
- 直播场景下，该回调提示有主播加入了频道。如果加入之前，已经有主播在频道中了，新加入的用户也会收到已有主播加入频道的回调。建议连麦主播不超过 32 人（其中视频连麦主播不超过 17 人）。

<a id="callback_irtcengineeventhandler_onuserjoined__timing"></a>

### 触发时机

该回调在如下情况下会被触发：

- 远端用户/主播加入频道。
- 远端用户加入频道后将用户角色改变为主播。
- 远端用户/主播网络中断后重新加入频道。

<a id="callback_irtcengineeventhandler_onuserjoined__restriction"></a>

### 使用限制

无。

<a id="callback_irtcengineeventhandler_onuserjoined__parameters"></a>

### 参数

### connection

Connection 信息。详见 [RtcConnection](/zh-CN/api-reference/rtc/unreal-cpp/class-rtcconnection)。

### uid

新加入频道的远端用户/主播 ID。

### elapsed

从本地用户调用 joinChannel [1/2] 或 joinChannel [2/2] 到该回调触发的延迟（毫秒）。

## onUserOffline

远端用户（通信场景）/主播（直播场景）离开当前频道回调。

<a id="callback_irtcengineeventhandler_onuseroffline__prototype"></a>

```text
virtual void onUserOffline(uid_t uid, USER_OFFLINE_REASON_TYPE reason) {
    (void)uid;
    (void)reason;
    }
```

<a id="callback_irtcengineeventhandler_onuseroffline__detailed_desc"></a>

<a id="callback_irtcengineeventhandler_onuseroffline__desc"></a>

用户离开频道一般有以下两个原因：

- 正常离开：远端用户或主播会发送类似“再见”的消息然后主动离开频道。
- 超时掉线：在一定时间内（通信场景为 20 秒，直播场景稍有延时），用户没有收到对方的任何数据包，则判定为对方掉线。在网络较差的情况下，有可能会误报。建议使用 RTM SDK 来做可靠的掉线检测。

<a id="callback_irtcengineeventhandler_onuseroffline__timing"></a>

### 触发时机

在音视频互动过程中，当远端用户或主播离开当前频道时会触发该回调。

<a id="callback_irtcengineeventhandler_onuseroffline__restriction"></a>

### 使用限制

无。

<a id="callback_irtcengineeventhandler_onuseroffline__parameters"></a>

### 参数

### uid

离线的远端用户或主播的 ID。

### reason

远端用户（通信场景）或主播（直播场景）离线的原因，详见 [USER_OFFLINE_REASON_TYPE](/zh-CN/api-reference/rtc/unreal-cpp/enum-userofflinereasontype)。
