---
title: "FocalLengthInfo"
description: "摄像头支持的焦距信息，包含摄像头的方向以及焦距类型。"
---

<a id="class_focallengthinfo__prototype"></a>

```cpp
struct FocalLengthInfo {
  int cameraDirection;
  CAMERA_FOCAL_LENGTH_TYPE focalLengthType;
};
```

<a id="class_focallengthinfo__detailed_desc"></a>

:::warning[注意]
仅适用于 Android 和 iOS。
:::

<a id="class_focallengthinfo__parameters"></a>

## 参数

### `cameraDirection`

摄像头方向。详见 [CAMERA_DIRECTION](/zh-CN/api-reference/rtc/unreal-cpp/enum-cameradirection)。

### `focalLengthType`

焦距类型。详见 [CAMERA_FOCAL_LENGTH_TYPE](/zh-CN/api-reference/rtc/unreal-cpp/enum-camerafocallengthtype)。
