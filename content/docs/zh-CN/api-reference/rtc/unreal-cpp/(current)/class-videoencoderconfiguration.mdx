## 属性

<ParameterList>
<a id="dimensions"></a>
<Parameter name="dimensions">

视频编码的分辨率 (px)，详见 [VideoDimensions](/zh-CN/api-reference/rtc/unreal-cpp/class-videodimensions)。该参数用于衡量编码质量，以长 × 宽表示，默认值为 960 × 540。用户可以自行设置分辨率。

</Parameter>
<a id="codectype"></a>
<Parameter name="codecType">

视频编码类型，详见 [VIDEO_CODEC_TYPE](/zh-CN/api-reference/rtc/unreal-cpp/enum-videocodectype)。

</Parameter>
<a id="framerate"></a>
<Parameter name="frameRate">

视频编码的帧率(fps)，默认值为 15。详见 [FRAME_RATE](/zh-CN/api-reference/rtc/unreal-cpp/enum-framerate)。

</Parameter>
<a id="bitrate"></a>
<Parameter name="bitrate">

视频编码码率，单位为 Kbps。该参数无需设置，保留默认值 STANDARD_BITRATE 即可，SDK 会根据你设定的视频分辨率和帧率自动匹配最合适的码率。有关视频分辨率和帧率的对应关系，详见[视频属性](/zh-CN/realtime-media/rtc/build/video/video-profile)。

- STANDARD_BITRATE (0): (默认) 标准码率模式。
- COMPATIBLE_BITRATE (-1): 适配码率模式。一般情况下，声网建议你不要使用该值。

</Parameter>
<a id="minbitrate"></a>
<Parameter name="minBitrate">

最低编码码率，单位为 Kbps。

SDK 会根据网络状况自动调整视频编码码率。将参数设为高于默认值可强制视频编码器输出高质量图片，但在网络状况不佳情况下可能导致网络丢包并影响视频播放的流畅度造成卡顿。因此如非对画质有特殊需求，声网建议不要修改该参数的值。

:::caution
注意： 该参数仅适用于直播场景。
:::

</Parameter>
<a id="orientationmode"></a>
<Parameter name="orientationMode">

视频编码的方向模式，详见 [ORIENTATION_MODE](/zh-CN/api-reference/rtc/unreal-cpp/enum-orientationmode)。

</Parameter>
<a id="degradationpreference"></a>
<Parameter name="degradationPreference">

带宽受限时，视频编码降级偏好。详见 [DEGRADATION_PREFERENCE](/zh-CN/api-reference/rtc/unreal-cpp/enum-degradationpreference)。

:::caution
注意： 当该参数设置为 MAINTAIN_FRAMERATE (1) 或者 MAINTAIN_BALANCED (2) 时，需要同时将 orientationMode 设置为 ORIENTATION_MODE_ADAPTIVE (0)，否则设置不生效。
:::

</Parameter>
<a id="mirrormode"></a>
<Parameter name="mirrorMode">

发送编码视频时是否开启镜像模式，只影响远端用户看到的视频画面。详见 [VIDEO_MIRROR_MODE_TYPE](/zh-CN/api-reference/rtc/unreal-cpp/enum-videomirrormodetype)。

:::caution
注意： 该参数不生效。如需实现镜像显示效果，请在 Unreal Engine 中进行镜像设置。
:::

:::caution
注意： 默认关闭镜像模式。
:::

</Parameter>
<a id="advanceoptions"></a>
<Parameter name="advanceOptions">

视频编码的高级选项。详见 [AdvanceOptions](/zh-CN/api-reference/rtc/unreal-cpp/class-advanceoptions)。

</Parameter>
</ParameterList>
