## 枚举值

:::caution
注意： SDK 目前不支持 Alpha 通道。传入的 Alpha 值将被丢弃。
:::

### VIDEO_PIXEL_DEFAULT

0: 原始视频像素格式。

### VIDEO_PIXEL_I420

1: I420 格式。

### VIDEO_PIXEL_RGBA

4: RGBA 格式。

### VIDEO_PIXEL_I422

16: I422 格式。

### VIDEO_TEXTURE_ID3D11TEXTURE2D

17: ID3D11TEXTURE2D 格式。目前支持的类型有 `DXGI_FORMAT_B8G8R8A8_UNORM`、`DXGI_FORMAT_B8G8R8A8_TYPELESS` 和 `DXGI_FORMAT_NV12`。
