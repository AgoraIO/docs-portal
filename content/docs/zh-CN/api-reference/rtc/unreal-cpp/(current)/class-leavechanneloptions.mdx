```text
struct LeaveChannelOptions {
  bool stopAudioMixing;
  bool stopAllEffect;
  bool stopMicrophoneRecording;
  LeaveChannelOptions() : stopAudioMixing(true), stopAllEffect(true), stopMicrophoneRecording(true) {}
};
```

<a id="class_leavechanneloptions__parameters"></a>

## 属性

### stopAudioMixing

离开频道时，是否停止播放音乐文件及混音：

<a id="class_leavechanneloptions__ul_ttv_f2n_3qb"></a>

- `true`：（默认）停止播放音乐文件及混音。
- `false`： 不停止播放音乐文件及混音。

### stopAllEffect

离开频道时，是否停止播放音效：

<a id="class_leavechanneloptions__ul_tgl_m2n_3qb"></a>

- `true`：（默认）停止播放音效。
- `false`： 不停止播放音效。

### stopMicrophoneRecording

离开频道时，是否停止麦克风采集：

<a id="class_leavechanneloptions__ul_dy1_s2n_3qb"></a>

- `true`：（默认）停止麦克风采集。
- `false`： 不停止麦克风采集。
