## 枚举值

### `kPreloadStateCompleted`

0：音乐资源加载完成。

### `kPreloadStateFailed`

1：音乐资源加载失败。

### `kPreloadStatePreloading`

2：音乐资源正在加载中。

### `kPreloadStateRemoved`

3：缓存的音乐资源已被移除。
