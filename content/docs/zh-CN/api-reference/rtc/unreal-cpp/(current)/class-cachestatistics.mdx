---
title: "CacheStatistics"
description: "缓存文件的统计数据。"
---

<a id="class_cachestatistics__prototype"></a>

```cpp
struct CacheStatistics {
  int64_t fileSize;
  int64_t cacheSize;
  int64_t downloadSize;
};
```

<a id="class_cachestatistics__parameters"></a>

## 属性

### `fileSize`

本次播放的媒体文件的大小，单位为字节。

### `cacheSize`

本次播放的媒体文件已缓存的数据大小，单位为字节。

### `downloadSize`

本次播放已下载的媒体文件大小，单位为字节。
