<a id="class_audioencodedframeobserverconfig__prototype"></a>

```cpp
struct AudioEncodedFrameObserverConfig {
    AUDIO_ENCODED_FRAME_OBSERVER_POSITION postionType;
    AUDIO_ENCODING_TYPE encodingType;
    AudioEncodedFrameObserverConfig()
    : postionType(AUDIO_ENCODED_FRAME_OBSERVER_POSITION_PLAYBACK),
      encodingType(AUDIO_ENCODING_TYPE_OPUS_48000_MEDIUM){}
};
```

<a id="class_audioencodedframeobserverconfig__parameters"></a>

## 属性

### `postionType`

音频编码内容。详见 [AUDIO_ENCODED_FRAME_OBSERVER_POSITION](/zh-CN/api-reference/rtc/unreal-cpp/enum-audioencodedframeobserverposition)。

### `encodingType`

音频编码类型。详见 [AUDIO_ENCODING_TYPE](/zh-CN/api-reference/rtc/unreal-cpp/enum-audioencodingtype)。
