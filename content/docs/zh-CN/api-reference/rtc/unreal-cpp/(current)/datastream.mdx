## createDataStream [1/2]

创建数据流。

<a id="api_irtcengine_createdatastream__prototype"></a>

```cpp
virtual int createDataStream(int* streamId, bool reliable, bool ordered) = 0;
```

<a id="api_irtcengine_createdatastream__detailed_desc"></a>

你可以调用该方法创建数据流并提高数据传输的可靠性和有序性。

<a id="api_irtcengine_createdatastream__timing"></a>

### 调用时机

该方法在加入频道前后均可调用。

<a id="api_irtcengine_createdatastream__restriction"></a>

### 调用限制

在 [IRtcEngine](/zh-CN/api-reference/rtc/unreal-cpp/rtc-interface-class#class_irtcengine) 生命周期内，每个用户最多只能创建 5 个数据流。离开频道时数据流会被销毁，如需使用需要重新创建数据流。

<a id="api_irtcengine_createdatastream__related"></a>

### 相关回调

将 reliable 设置为 `true` 后，如果接收方 5 秒没有收到发送方所发送的数据，会触发 [onStreamMessageError](/zh-CN/api-reference/rtc/unreal-cpp/datastream#callback_irtcengineeventhandler_onstreammessageerror) 回调并获得相应报错信息。

<a id="api_irtcengine_createdatastream__parameters"></a>

### 参数

#### `streamId`

输出参数，创建好的数据流 ID。

#### `reliable`

是否保证数据可靠性，即接收方是否需要在数据发送后的 5 秒内接收：

- `true`: 接收方 5 秒内会收到发送方所发送的数据，否则会收到 onStreamMessageError 回调并获得相应报错信息。
- `false`: 接收方不保证收到，就算数据丢失也不会报错。

:::warning[注意]
请确保将 reliable 和 ordered 同时设为 `true` 或同时设为 `false`。
:::

#### `ordered`

是否保证数据有序性，即接收方是否需要收到有序的数据：

- `true`: 接收方会按照发送方发送的顺序收到数据包。
- `false`: 接收方不保证按照发送方发送的顺序收到数据包。

<a id="api_irtcengine_createdatastream__return_values"></a>

### 返回值

- 0: 创建数据流成功。
- &lt; 0：方法调用失败。 详见 [错误码](https://doc.shengwang.cn/api-ref/rtc/unreal-cpp/error-code) 了解详情和解决建议。

### 所属接口类
- [IRtcEngine](/zh-CN/api-reference/rtc/unreal-cpp/rtc-interface-class#class_irtcengine)

## sendStreamMessage

发送数据流。

<a id="api_irtcengine_sendstreammessage__prototype"></a>

```cpp
virtual int sendStreamMessage(int streamId,
     const char* data,
     size_t length) = 0;
```

<a id="api_irtcengine_sendstreammessage__detailed_desc"></a>

### 详情

调用 [createDataStream [2/2]](/zh-CN/api-reference/rtc/unreal-cpp/datastream#api_irtcengine_createdatastream2) 后，你可以调用该方法向频道内所有用户发送数据流消息。

SDK 对该方法的实现进行了如下限制：

- 频道内每个客户端最多可以同时拥有 5 个数据通道，所有数据通道共用的总发包码率限制为 30 KB/s。
- 每个数据通道每秒最多能发送 60 个包，每个包最大为 1 KB。

成功调用该方法后，远端会触发 [onStreamMessage](/zh-CN/api-reference/rtc/unreal-cpp/datastream#callback_irtcengineeventhandler_onstreammessage) 回调，远端用户可以在该回调中获取接收到的流消息；若调用失败，远端会触发 [onStreamMessageError](/zh-CN/api-reference/rtc/unreal-cpp/datastream#callback_irtcengineeventhandler_onstreammessageerror) 回调。

:::warning[注意]
- 该方法需要在加入频道后、且调用 [createDataStream [2/2]](/zh-CN/api-reference/rtc/unreal-cpp/datastream#api_irtcengine_createdatastream2) 创建数据通道之后调用。
- 该方法仅适用于主播用户。
:::

<a id="api_irtcengine_sendstreammessage__parameters"></a>

### 参数

#### `streamId`

数据流 ID。可以通过 createDataStream [2/2] 获取。

#### `data`

待发送的数据。

#### `length`

数据长度。

<a id="api_irtcengine_sendstreammessage__return_values"></a>

### 返回值

- 0: 方法调用成功。
- &lt; 0: 方法调用失败。 详见 [错误码](https://doc.shengwang.cn/api-ref/rtc/unreal-cpp/error-code) 了解详情和解决建议。

### 所属接口类
- [IRtcEngine](/zh-CN/api-reference/rtc/unreal-cpp/rtc-interface-class#class_irtcengine)

## onStreamMessage

接收到对方数据流消息的回调。

<a id="callback_irtcengineeventhandler_onstreammessage__prototype"></a>

```cpp
virtual void onStreamMessage(uid_t userId, int streamId, const char* data, size_t length, uint64_t sentTs) {
                    (void)userId;
                    (void)streamId;
                    (void)data;
                    (void)length;
                    (void)sentTs;
                  }
```

<a id="callback_irtcengineeventhandler_onstreammessage__detailed_desc"></a>

该回调表示本地用户收到了远端用户调用 [sendStreamMessage](/zh-CN/api-reference/rtc/unreal-cpp/datastream#api_irtcengine_sendstreammessage) 方法发送的流消息。

<a id="callback_irtcengineeventhandler_onstreammessage__parameters"></a>

### 参数

#### `userId`

发送消息的用户 ID。

#### `streamId`

接收到的消息的 Stream ID。

#### `data`

接收到的数据。

#### `length`

数据长度，单位为字节。

#### `sentTs`

数据流发出的时间。

### 所属接口类
- [IRtcEngineEventHandler](/zh-CN/api-reference/rtc/unreal-cpp/rtc-interface-class#class_irtcengineeventhandler)

## onStreamMessageError

接收对方数据流消息发生错误的回调。

<a id="callback_irtcengineeventhandler_onstreammessageerror__prototype"></a>

```cpp
virtual void onStreamMessageError(uid_t userId, int streamId, int code, int missed, int cached) {
                (void)userId;
                (void)streamId;
                (void)code;
                (void)missed;
                (void)cached;
              }
```

<a id="callback_irtcengineeventhandler_onstreammessageerror__detailed_desc"></a>

该回调表示本地用户未收到远端用户调用 [sendStreamMessage](/zh-CN/api-reference/rtc/unreal-cpp/datastream#api_irtcengine_sendstreammessage) 方法发送的流消息。

<a id="callback_irtcengineeventhandler_onstreammessageerror__parameters"></a>

### 参数

#### `userId`

发送消息的用户 ID。

#### `streamId`

接收到的消息的 Stream ID。

#### `code`

错误码。详见 [错误码](https://doc.shengwang.cn/api-ref/rtc/unreal-cpp/error-code)。

#### `missed`

丢失的消息数量。

#### `cached`

数据流中断时，后面缓存的消息数量。

- [IRtcEngineEventHandler](/zh-CN/api-reference/rtc/unreal-cpp/rtc-interface-class#class_irtcengineeventhandler)
