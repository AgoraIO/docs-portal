## 枚举值

### `AUDIO_ENCODED_FRAME_OBSERVER_POSITION_RECORD`

1: 仅编码本地用户的音频。

### `AUDIO_ENCODED_FRAME_OBSERVER_POSITION_PLAYBACK`

2: 仅编码所有远端用户的音频。

### `AUDIO_ENCODED_FRAME_OBSERVER_POSITION_MIXED`

3: 编码本地和所有远端用户混音后的音频。
