## 枚举值

### RHYTHM_PLAYER_REASON_OK

0：正常播放节拍音频文件，没有错误。

### RHYTHM_PLAYER_REASON_FAILED

1：一般性错误，没有明确原因。

### RHYTHM_PLAYER_REASON_CAN_NOT_OPEN

801：打开节拍音频文件出错。

### RHYTHM_PLAYER_REASON_CAN_NOT_PLAY

802：播放节拍音频文件出错。

### RHYTHM_PLAYER_REASON_FILE_OVER_DURATION_LIMIT

803：节拍音频文件时长超出限制。最大时长为 1.2 秒。
