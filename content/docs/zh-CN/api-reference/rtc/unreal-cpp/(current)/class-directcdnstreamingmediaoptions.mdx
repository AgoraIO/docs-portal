## 属性

### publishCameraTrack

设置是否发布摄像头采集的视频。

- `true`: 发布摄像头采集的视频。
- `false`:（默认）不发布摄像头采集的视频。

### publishMicrophoneTrack

设置是否发布麦克风采集的音频。

- `true`: 发布麦克风采集的音频。
- `false`:（默认）不发布麦克风采集的音频。

### publishCustomAudioTrack

设置是否发布自定义采集的音频。

- `true`: 发布自定义采集的音频。
- `false`:（默认）不发布自定义采集的音频。

### publishCustomVideoTrack

设置是否发布自定义采集的视频。

- `true`: 发布自定义采集的视频。
- `false`:（默认）不发布自定义采集的视频。

### customVideoTrackId

调用 [createCustomVideoTrack](/zh-CN/api-reference/rtc/unreal-cpp/video/video-custom-capturenrendering#api_irtcengine_createcustomvideotrack) 方法返回的视频轨道 ID。默认值为 0。
