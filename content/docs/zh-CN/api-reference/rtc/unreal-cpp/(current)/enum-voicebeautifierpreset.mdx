- 为达到更好的效果，建议在调用 [setVoiceBeautifierPreset](/zh-CN/api-reference/rtc/unreal-cpp/audio/audio-prenpost/audio-effect#api_irtcengine_setvoicebeautifierpreset) 前将 [setAudioProfile [2/2]](/zh-CN/api-reference/rtc/unreal-cpp/audio/audio-basic#api_irtcengine_setaudioprofile2) 的 profile 参数设置为 AUDIO_PROFILE_MUSIC_HIGH_QUALITY(4) 或 AUDIO_PROFILE_MUSIC_HIGH_QUALITY_STEREO(5)，且 scenario 参数设置为 AUDIO_SCENARIO_GAME_STREAMING(3)。
