<a id="class_musiccacheinfo__prototype"></a>

```cpp
struct MusicCacheInfo {

    int64_t songCode;

    MUSIC_CACHE_STATUS_TYPE status;
    MusicCacheInfo():songCode(0), status(MUSIC_CACHE_STATUS_TYPE_CACHED) {}
};
```

<a id="class_musiccacheinfo__detailed_desc"></a>

<a id="class_musiccacheinfo__parameters"></a>

## 属性

### `songCode`

音乐资源的编号，用于标识音乐资源。

### `status`

音乐资源的缓存状态，详见 [MUSIC_CACHE_STATUS_TYPE](/zh-CN/api-reference/rtc/unreal-cpp/enum-musiccachestatustype)。
