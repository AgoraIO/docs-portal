## enableMultiCamera

开启或关闭多路摄像头采集。

<a id="api_irtcengine_enablemulticamera__prototype"></a>

```text
#if defined(__APPLE__) && TARGET_OS_IOS
    virtual int enableMultiCamera(bool enabled, const CameraCapturerConfiguration& config) = 0;
#endif
```

<a id="api_irtcengine_enablemulticamera__detailed_desc"></a>

### 详情

在已有摄像头采集视频的场景下，声网推荐你采用以下步骤实现多路摄像头采集、发布视频：

1. 调用该方法开启多路摄像头采集。
2. 调用 [startPreview [2/2]](/zh-CN/api-reference/rtc/unreal-cpp/video/video-basic#api_irtcengine_startpreview2) 开启本地视频预览。
3. 调用 [startCameraCapture](/zh-CN/api-reference/rtc/unreal-cpp/video/camera-capture#api_irtcengine_startcameracapture) 并设置 sourceType 指定第二个摄像头开始采集。
4. 调用 [joinChannelEx](/zh-CN/api-reference/rtc/unreal-cpp/channel#api_irtcengineex_joinchannelex) 并设置 publishSecondaryCameraTrack 为 `true`，在频道内发布第二路摄像头采集的视频流。

如果要关闭多路摄像头采集，可参考以下步骤：

1. 调用 [stopCameraCapture](/zh-CN/api-reference/rtc/unreal-cpp/video/camera-capture#api_irtcengine_stopcameracapture)。
2. 调用该方法并将 enabled 设置为 `false`。

:::note
注：

你可以在 [startPreview [2/2]](/zh-CN/api-reference/rtc/unreal-cpp/video/video-basic#api_irtcengine_startpreview2) 前后调用该方法开启多摄像头采集：

- 如果在 startPreview [2/2] 之前开启，则本地视频预览会同时出现两个摄像头采集的画面。
- 如果在 startPreview [2/2] 之后开启，SDK 会先停止当前的摄像头采集，然后再开启原摄像头和第二个摄像头，本地视频预览会出现短暂黑屏、然后自动恢复正常。
:::

该方法仅适用于 iOS。

使用多路摄像头采集视频时，请确保系统版本为 13.0 及以上。

支持多路摄像头采集的最低 iOS 设备类型如下所示：

- iPhone XR
- iPhone XS
- iPhone XS Max
- iPad Pro (第三代及以上)

<Parameter name="enabled">

- `false`：关闭多摄像头采集模式，SDK 仅使用单路摄像头采集视频。

</Parameter>

## setCameraZoomFactor

设置摄像头缩放比例。

<a id="api_irtcengine_setcamerazoomfactor__prototype"></a>

```text
virtual int setCameraZoomFactor(float factor) = 0;
```

<a id="api_irtcengine_setcamerazoomfactor__detailed_desc"></a>

### 详情

部分 iOS 设备的后置摄像头为多个摄像头组成的融合镜头，如双摄（广角和超广角）或三摄（广角、超广角和长焦），对于这种具备超广角能力的融合镜头，你可以调用 [setCameraCapturerConfiguration](/zh-CN/api-reference/rtc/unreal-cpp/device-management/video-device#api_irtcengine_setcameracapturerconfiguration) 将 cameraFocalLengthType 设置为 CAMERA_FOCAL_LENGTH_DEFAULT (0)（标准镜头），然后调用该方法将摄像头缩放比例设置为小于 1.0 的数值，从而实现超广角的拍摄效果。

:::caution
注意：

- 该方法仅适用于 Android 和 iOS。
- 该方法必须在 [enableVideo](/zh-CN/api-reference/rtc/unreal-cpp/video/video-basic#api_irtcengine_enablevideo) 后调用，设置结果在摄像头成功开启后生效，即 SDK 触发 [onLocalVideoStateChanged](/zh-CN/api-reference/rtc/unreal-cpp/video/video-basic#callback_irtcengineeventhandler_onlocalvideostatechanged) 回调返回本地视频状态为 LOCAL_VIDEO_STREAM_STATE_CAPTURING (1) 后。
:::

<a id="api_irtcengine_setcamerazoomfactor__parameters"></a>

### 参数

<ParameterList>
<a id="factor-1"></a>
<Parameter name="factor">

摄像头缩放比例。对不支持超广角的设备，取值范围从 1.0 到最大缩放比例；对支持超广角的设备，取值范围从 0.5 到最大缩放比例。你可以通过 [getCameraMaxZoomFactor](/zh-CN/api-reference/rtc/unreal-cpp/device-management/video-device#api_irtcengine_getcameramaxzoomfactor) 方法获取设备支持的最大缩放比例。

</Parameter>
</ParameterList>

<a id="api_irtcengine_setcamerazoomfactor__return_values"></a>

### 返回值

- 方法调用成功: 返回设置的 factor 值。
- 方法调用失败: 返回值 &lt; 0。
