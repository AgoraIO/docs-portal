## 枚举值

### `AUDIO_SOURCE_MICROPHONE`

0：（默认）麦克风。

### `AUDIO_SOURCE_CUSTOM`

1：自定义采集到的音频流。

### `AUDIO_SOURCE_MEDIA_PLAYER`

2：媒体播放器。

### `AUDIO_SOURCE_LOOPBACK_RECORDING`

3：在屏幕共享时采集的系统音频流。

### `AUDIO_SOURCE_REMOTE_USER`

5：指定远端用户的音频流。

### `AUDIO_SOURCE_REMOTE_CHANNEL`

6：当前频道内所有音频流的合流。

### `AUDIO_SOURCE_UNKNOWN`

100：未知的音频源。
