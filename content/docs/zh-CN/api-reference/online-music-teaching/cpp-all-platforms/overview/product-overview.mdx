专业音乐老师对学生进行在线音乐教学或陪练，例如一对一或一对多的钢琴陪练。采用声网实时互动技术方案和音乐场景专属的降噪算法，通过 48 kHz 采样率、192 Kbps 码率高度还原音质效果，支持教学白板、曲谱标注和鱼眼镜头畸变矫正等功能，尽力贴近线下教学场景。

## 技术方案

声网为在线音乐教学场景提供两套技术方案：PaaS 技术方案和 aPaaS 技术方案。

### PaaS 技术方案

PaaS 技术方案使用声网 RTC SDK、声网 RTM SDK、声网互动白板 SDK 和声网云端录制服务共同搭建实时互动音乐教学场景。

![在线音乐教学技术架构图](/img/api-center-generated/ac1489b946ef-music-class-paas.png)

### aPaaS 技术方案

aPaaS 技术方案基于 PaaS 方案进行封装，以示例项目的形式实现了多种在线音乐教学或陪练场景。你可以基于示例项目，快速实现以下场景：

| 场景 | 功能 |
| --- | --- |
| 多人合唱教学 | 支持普通合唱和多声部合唱、节拍器与伴奏同步、回声消除、曲库与歌词同步、耳返、音效及无耳机情况下的 3A 算法（回声消除、噪声抑制、自动增益）等功能。 |
| 乐器合奏 | 支持 MIDI 键盘声音输入还原、电子琴盘与 MIDI 键盘联动及 MIDI 信号的 3A 算法及回声消除等功能。 |
| 钢琴陪练 | 支持鱼眼镜头畸变矫正和画面二分显示、乐器与人声优化、节拍器与伴奏同步及回声消除等功能。 |

## 方案优势

#### 鱼眼镜头的画面畸变矫正与分离显示

在乐器陪练场景中，你可以通过声网 SDK 对鱼眼镜头的画面进行畸变矫正和分离显示处理，帮助教师在教学过程中更好地演示和纠正弹奏动作。

#### 双摄像头支持

支持同时开启移动端设备前后摄像头和桌面设备外接摄像头，实现多视角演示。

#### 实时合唱

结合声网互动白板 SDK、歌词同步等组件实现多人视频实时合唱。6 人同时开启视频时，实时合唱延时低至 64 ms。

#### 人声特效

通过音调、声音均衡和混响等设置自定义人声效果。

#### 曲库

声网内容中心提供热门歌曲曲库，教师或学生可以搜索想唱的歌曲，点歌并查看已点列表。

#### 歌词组件

歌词组件支持在歌曲播放时，根据播放进度显示对应的歌词。滑动歌词可以改变歌曲进度。主唱可以改变歌词背景。

#### 超低延时

声网 SD-RTN™ 网络节点覆盖全球 200 多个国家和地区，通过就近接入、智能路由等控制策略，保证全球平均端到端延时 < 400 ms。

#### 稳定可靠

提供 SLA 质量保证，登录成功率 > 99%，全年可用时间高达 99.99%。

#### 极致弱网对抗能力

业界领先的弱网对抗算法，保证在 70% 丢包情况下，音视频通话流畅；70% 丢包情况下，音频通话流畅，真正做到低卡顿、不掉线。

#### 高音质

支持 48 kHz 全频带采样，业界领先的 3A 算法（回声消除、噪声抑制、自动增益）和 AI 音频降噪算法，在嘈杂环境下也能保持语音清澈，提供高品质的教学体验。

#### 高清画质

支持 1080p 高清视频体验。支持 H.265、超分辨率和感知视频编码，在同等分辨率、帧率情况下，视频占用带宽更低，画质体验更好。

#### 丰富的功能组件

- 支持教学白板，包括多种可扩展教具、动态 PPT、H5 课件等。
- 支持屏幕共享、课件共享、笔记共享等。
- 支持课程录制，包括本地录制、云录制、精彩集锦录制等。

#### 课堂质量透明可溯

声网通过如下接口及产品，保障实时音视频的质量：

- 丰富的课前网络和设备检测接口以及完整的课中通话质量回调，排除潜在问题，扫清上课障碍。
- [水晶球](https://analytics-lab.shengwang.cn/analytics/call/search)工具显示端到端全链路的质量监控数据，上课过程可追溯，提供用户行为、运行状态、QoE/QoS 的质量数据，帮助排查定位问题。

#### 全平台适配

- 支持 Windows、macOS、Web、iOS、Android、Electron 等多达 30 种平台和开发架构适配。
- 支持 20000+ 款机型适配，保证全球师生体验的一致性。
