<a id="ttsvendorenum"></a>
## TTSVendorEnum

智能体加入 RTC 频道时使用的 TTS 模块厂商类型。

:::info[信息]
自 v0.3.0 版本新增。
:::

#### 枚举值

| 枚举值 | 描述 |
| --- | --- |
| `MINIMAX` | Minimax TTS 厂商。 |
| `TENCENT` | Tencent TTS 厂商。 |
| `BYTEDANCE` | Bytedance TTS 厂商。 |
| `MICROSOFT` | Microsoft TTS 厂商。 |

<a id="asrvendorenum"></a>
## ASRVendorEnum

智能体加入频道时使用的 ASR 模块厂商类型。

:::info[信息]
自 v0.7.0 版本新增。
:::

#### 枚举值

| 枚举值 | 描述 |
| --- | --- |
| `FENGMING` | Fengming ASR 厂商。 |
| `TENCENT` | Tencent ASR 厂商。 |
| `MICROSOFT` | Microsoft ASR 厂商。 |

<a id="domainarea"></a>
## DomainArea

Open API 网关端点所在的全球区域。

:::info[信息]
自 v0.3.0 版本新增。
:::

#### 枚举值

| 枚举值 | 描述 |
| --- | --- |
| `US` | 表示美国西部和东部地区。 |
| `EU` | 表示欧洲西部和中部地区。 |
| `AP` | 表示亚太地区的东南部和东北部。 |
| `CN` | 表示中国大陆的东部和北部地区。 |

<a id="convoaiserviceregionenum"></a>
## ConvoAIServiceRegionEnum

会话式智能体引擎服务的区域。

:::info[信息]
自 v0.3.0 版本新增。
:::

#### 枚举值

| 枚举值 | 描述 |
| --- | --- |
| `CHINESE_MAINLAND` | 表示会话式智能体引擎服务在中国大陆区域。 |
| `GLOBAL` | 表示会话式智能体引擎服务在除中国大陆以外的全球区域。 |
