## MessageReceipt

```kotlin
data class MessageReceipt(
    val type: ModuleType,
    val chatMessageType: ChatMessageType,
    val turnId: Long,
    val message: String
)
```

[`MessageReceipt`](/zh-CN/api-reference/conversational-ai/android/struct#messagereceipt) 表示消息回执信息，支持通过 `MediaInfo` 处理多种媒体类型。

#### 成员参数

| 参数 | 数据类型 | 描述 |
| --- | --- | --- |
| `type` | `ModuleType` | 模块类型，详见 [`ModuleType`](/zh-CN/api-reference/conversational-ai/android/enum#moduletype)，例如 `llm`、`mllm`、`tts`、`context`。 |
| `chatMessageType` | `ChatMessageType` | 消息错误类型。详见 [`ChatMessageType`](/zh-CN/api-reference/conversational-ai/android/struct#chatmessagetype)。 |
| `turnId` | `Long` | 消息的轮次 ID。 |
| `message` | `String` | <Slot name="struct-android-html-0-4-2" /> |

<Slot for="struct-android-html-0-4-2">

消息内容信息。需要根据 `type` 字段进行解析：

    - `Context` 类型：通常为包含资源信息的 JSON 字符串。

</Slot>

<a id="chatmessagetype"></a>
## ChatMessageType

```kotlin
enum class ChatMessageType(val value: String) {
    Text("text"),
    Image("picture"),
    UNKNOWN("unknown");

    companion object {
        fun fromValue(value: String): ChatMessageType {
            return ChatMessageType.entries.find { it.value == value } ?: UNKNOWN
        }
    }
}
```

用于区分会话系统中不同类型的消息。

#### 成员参数

| 参数 | 数据类型 | 描述 |
| --- | --- | --- |
| `value` | `String` | 用于匹配的字符串值。 |

## ModuleError

```kotlin
data class ModuleError(
    val type: ModuleType,
    val code: Int,
    val message: String,
    val timestamp: Long,
```

| `message` | `String` | 提供详细错误说明的错误描述信息。 |
| `timestamp` | `Long` | 错误发生的时间戳（从 1970 年 1 月 1 日 UTC 起的毫秒数）。 |
| `turnId` | `Long?` | （可选）图片对应的 `turnId`，用于图像上传错误。 |

<a id="conversationalaiapierror"></a>
## ConversationalAIAPIError

```kotlin
sealed class ConversationalAIAPIError : Exception() {
    data class RtmError(val code: Int, val msg: String) : ConversationalAIAPIError()
    data class RtcError(val code: Int, val msg: String) : ConversationalAIAPIError()
    data class UnknownError(val msg: String) : ConversationalAIAPIError()

    val errorCode: Int
        get() = when (this) {
            is RtmError -> this.code
            is RtcError -> this.code
            is UnknownError -> -100
        }

    val errorMessage: String
        get() = when (this) {
            is RtmError -> this.msg
            is RtcError -> this.msg
            is UnknownError -> this.msg
        }
}
```

表示会话式 AI API 中的错误类型。

#### 成员参数

| 参数 | 数据类型 | 描述 |
| --- | --- | --- |
| `errorCode` | `Int` | <Slot name="struct-android-html-15-1-2" /> |
| `errorMessage` | `String` | 错误信息，返回具体的错误描述内容。 |

<Slot for="struct-android-html-15-1-2">

错误码：

    - `RtmError` 或 `RtcError` 返回具体错误码。
    - `UnknownError` 返回 -100。

</Slot>
