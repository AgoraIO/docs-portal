## IConversationalAIAPI

| API | 描述 |
|---|---|
|[`chat`](/zh-CN/api-reference/conversational-ai/android/iconversationalaiapi#chat) | 向智能体发送消息。|
|[`addHandler`](/zh-CN/api-reference/conversational-ai/android/iconversationalaiapi#addhandler) | 注册事件处理器，用于接收智能体会话事件。|
|[`removeHandler`](/zh-CN/api-reference/conversational-ai/android/iconversationalaiapi#removehandler) | 移除已注册的事件处理器。|
|[`subscribeMessage`](/zh-CN/api-reference/conversational-ai/android/iconversationalaiapi#subscribemessage) | 订阅频道以接收智能体对话事件。|
|[`unsubscribeMessage`](/zh-CN/api-reference/conversational-ai/android/iconversationalaiapi#unsubscribemessage) | 取消订阅频道并停止接收事件。|
|[`interrupt`](/zh-CN/api-reference/conversational-ai/android/iconversationalaiapi#interrupt) | 打断智能体当前发言。|
|[`loadAudioSettings`](/zh-CN/api-reference/conversational-ai/android/iconversationalaiapi#loadaudiosettings) | 设置音频参数以优化对话性能。|
|[`destroy`](/zh-CN/api-reference/conversational-ai/android/iconversationalaiapi#destroy) | 销毁 `API` 实例并释放资源。|
