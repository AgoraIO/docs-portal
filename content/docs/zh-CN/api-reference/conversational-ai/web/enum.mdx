<a id="econversationalaiapievents"></a>
## EConversationalAIAPIEvents

`Conversational AI API` 可触发的事件类型。

:::info[信息]
自 1.6.0 版本新增。
:::

#### 枚举值

| 枚举值 | 描述 |
| --- | --- |
| `AGENT_STATE_CHANGED` | （"agent-state-changed"）：智能体状态变更事件。 |
| `AGENT_LISTENING_CHANGED ` | （"agent-listening-changed"）：智能体倾听状态变更事件。 |
| `AGENT_THINKING_CHANGED ` | （"agent-thinking-changed"）：智能体思考状态变更事件。 |
| `AGENT_SPEAKING_CHANGED ` | （"agent-speaking-changed"）：智能体说话状态变更事件。 |
| `AGENT_INTERRUPTED` | （"agent-interrupted"）：智能体被中断事件。 |
| `AGENT_METRICS` | （"agent-metrics"）：智能体指标事件。 |
| `AGENT_ERROR` | （"agent-error"）：智能体错误事件。 |
| `TRANSCRIPT_UPDATED` | （"transcript-updated"）：转录更新事件。 |
| `DEBUG_LOG` | （"debug-log"）：调试日志事件。 |
| `MESSAGE_RECEIPT_UPDATED` | 消息接收状态已更新。 |
| `MESSAGE_ERROR` | （'message-error'）：消息错误事件。 |
| `USER_MANUAL_SOS_RESULT` | （"user.manual_sos.result"）：手动 SoS 结果事件。 |
| `USER_MANUAL_EOS_RESULT` | （"user.manual_eos.result"）：手动 EoS 结果事件。 |
| `AGENT_MANUAL_EOS_RESULT` | （"assistant.manual_eos.result"）：服务端超限自动 EoS 通知事件。 |

<a id="echatmessagepriority"></a>
## EChatMessagePriority

用于设置聊天消息处理优先级。

:::info[信息]
自 1.7.0 版本新增。
:::

#### 枚举值

| 枚举值 | 描述 |
| --- | --- |
| `INTERRUPTED` | （'interrupted'）：中断当前处理并立即处理该消息。 |
| `APPEND` | （'append'）：将消息添加到处理队列中，按顺序处理。 |
| `IGNORE` | （'ignore'）：丢弃该消息，不进行处理。 |

<a id="echatmessagetype"></a>
## EChatMessageType

对话式 AI 系统中支持的聊天消息类型。

:::info[信息]
自 1.7.0 版本新增。
:::

#### 枚举值

| 枚举值 | 描述 |
| --- | --- |
| `TEXT` | （'text'）：文本消息。 |
| `IMAGE` | （'image'）：图片消息。 |
| `UNKNOWN` | （'unknown'）：未知类型的消息。 |

<a id="emoduletype"></a>
## EModuleType

[`EModuleType`](/zh-CN/api-reference/conversational-ai/web/enum#emoduletype) 表示 AI 能力的模块类型。

:::info[信息]
自 1.6.0 版本新增。
:::

#### 枚举值

| 枚举值 | 描述 |
| --- | --- |
| `LLM` | （"llm"）：语言学习模型。 |
| `MLLM` | （"mllm"）：多模态语言学习模型。 |
| `TTS` | （"tts"）：文本转语音模块。 |
| `UNKNOWN` | （"unknown"）：未知的模块类型。 |
| `CONTEXT` | （"context"）：上下文管理模块。 |

<a id="eagentstate"></a>
## EAgentState

[`EAgentState`](/zh-CN/api-reference/conversational-ai/web/enum#eagentstate) 表示会话智能体的状态。

:::info[信息]
自 1.6.0 版本新增。
:::

#### 枚举值

| 枚举值 | 描述 |
| --- | --- |
| `IDLE` | （"idle"）：智能体准备好进行新的交互。 |
| `LISTENING` | （"listening"）：智能体正在接收用户输入。 |
| `THINKING` | （"thinking"）：智能体正在处理接收到的输入。 |
| `SPEAKING` | （"speaking"）：智能体正在输出响应。 |
| `SILENT` | （"silent"）：智能体有意地不做出响应。 |
