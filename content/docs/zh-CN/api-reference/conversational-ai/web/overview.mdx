## ConversationalAIAPI

| API | 描述 |
|---|---|
|[`chat`](/zh-CN/api-reference/conversational-ai/web/conversationalaiapi#chat) | 向对话式智能体发送聊天消息。 |
|[`getInstance`](/zh-CN/api-reference/conversational-ai/web/conversationalaiapi#getinstance) | 获取 [`ConversationalAIAPI`](/zh-CN/api-reference/conversational-ai/web/conversationalaiapi) 的单例实例。 |
|[`init`](/zh-CN/api-reference/conversational-ai/web/conversationalaiapi#init) | 初始化 [`ConversationalAIAPI`](/zh-CN/api-reference/conversational-ai/web/conversationalaiapi) 单例实例。 |
|[`subscribeMessage`](/zh-CN/api-reference/conversational-ai/web/conversationalaiapi#subscribemessage) | 订阅消息频道以获取实时更新。 |
|[`unsubscribe`](/zh-CN/api-reference/conversational-ai/web/conversationalaiapi#unsubscribe) | 取消订阅消息频道并清理资源。 |
|[`destroy`](/zh-CN/api-reference/conversational-ai/web/conversationalaiapi#destroy) | 销毁 [`ConversationalAIAPI`](/zh-CN/api-reference/conversational-ai/web/conversationalaiapi) 实例并清理资源。 |
|[`interrupt`](/zh-CN/api-reference/conversational-ai/web/conversationalaiapi#interrupt) | 向指定的智能体发送中断消息。 |
