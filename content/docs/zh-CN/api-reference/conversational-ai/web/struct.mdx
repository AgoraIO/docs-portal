<a id="tusermanualeventpayload"></a>
## TUserManualEventPayload

```typescript
export type TUserManualEventPayload = {
  success: boolean
  requestId: string
  turnId?: number
  errorMessage?: string
}
```

手动 SoS/EoS 通用载荷。

#### 成员参数

| 参数 | 数据类型 | 描述 |
| --- | --- | --- |
| `success` | `boolean` | 服务端是否成功处理本次手动信令。 |
| `requestId` | `string` | 请求 ID，与调用 `manualSOS` 或 `manualEOS` 后返回的 `requestId` 对应。 |
| `turnId` | `number` | 关联的对话轮次 ID。服务端失败回调未携带 `turn_id` 时可为空。 |
| `errorMessage` | `string` | 服务端返回的原始错误信息。成功时通常为空。 |

<a id="isubtitlehelperitem"></a>
## ISubtitleHelperItem

```typescript
export interface ISubtitleHelperItem<T> {
  uid: string
  stream_id: number
  turn_id: number
  _time: number
  text: string
  status: ETurnStatus
  metadata: T | null
}
```

字幕辅助项接口。

:::info[信息]
自 1.6.0 版本新增。
:::

定义字幕系统中单个字幕项的数据结构。包含用户 ID、流 ID、轮次 ID、时间戳、文本内容、状态和元数据等信息。

#### 成员参数

| 参数 | 数据类型 | 描述 |
| --- | --- | --- |
| `uid` | `string` | 用户的唯一标识符。 |
| `stream_id` | `number` | 流标识符。 |
| `turn_id` | `number` | 会话中的轮次标识符。 |
| `_time` | `number` | 字幕的时间戳（单位为毫秒）。 |
| `text` | `string` | 字幕文本内容。 |
| `status` | `ETurnStatus` | 字幕项的当前状态。详见 `ETurnStatus`。 |
| `metadata` | `T \| null` | 附加的元数据信息。详见 `T`。 |

<a id="tmoduleerror"></a>
## TModuleError

```typescript
export type TModuleError = {
  type: EModuleType
  code: number
  message: string
  timestamp: number
}
```

[`TModuleError`](/zh-CN/api-reference/conversational-ai/web/struct#tmoduleerror) 模块错误类型定义。

:::info[信息]
自 1.6.0 版本新增。
:::

用于表示来自不同 AI 模块的错误信息，包括错误类型、错误码、错误信息和时间戳，便于错误处理和调试。错误码为模块特定内容，应由各模块单独说明。时间戳为 Unix 毫秒格式。错误信息应具备良好可读性，并提供可操作的信息。

#### 成员参数

| 参数 | 数据类型 | 描述 |
| --- | --- | --- |
| `type` | `EModuleType` | 发生错误的模块类型，详见 [`EModuleType`](/zh-CN/api-reference/conversational-ai/web/enum#emoduletype)。 |
| `code` | `number` | 模块特定的错误码。 |
| `message` | `string` | 具备可读性的错误描述信息。 |
| `timestamp` | `number` | 错误发生时的 Unix 毫秒时间戳。 |
