## ConversationalAIAPI

| API | 描述 |
|---|---|
|[`chat`](/zh-CN/api-reference/conversational-ai/client-toolkit/conversationalaiapi#chat) | 向智能体发送消息以进行处理。|
|[`speak`](/zh-CN/api-reference/conversational-ai/client-toolkit/conversationalaiapi#speak) | 绕过大模型，直接让智能体播报文本。|
|[`think`](/zh-CN/api-reference/conversational-ai/client-toolkit/conversationalaiapi#think) | 向大模型注入文本指令并触发推理。|
|[`interrupt`](/zh-CN/api-reference/conversational-ai/client-toolkit/conversationalaiapi#interrupt) | 打断智能体当前正在进行的语音或任务处理。|
|[`manualSOS`](/zh-CN/api-reference/conversational-ai/client-toolkit/conversationalaiapi#manualsos) | 发送手动 SoS 信令。|
|[`manualEOS`](/zh-CN/api-reference/conversational-ai/client-toolkit/conversationalaiapi#manualeos) | 发送手动 EoS 信令。|
|[`loadAudioSettings`](/zh-CN/api-reference/conversational-ai/client-toolkit/conversationalaiapi#loadaudiosettings) | 设置音频最佳实践参数以获得更佳性能。|
|[`subscribeMessage`](/zh-CN/api-reference/conversational-ai/client-toolkit/conversationalaiapi#subscribemessage) | 订阅频道消息。|
|[`unsubscribeMessage`](/zh-CN/api-reference/conversational-ai/client-toolkit/conversationalaiapi#unsubscribemessage) | 取消订阅频道消息。|
|[`addHandler`](/zh-CN/api-reference/conversational-ai/client-toolkit/conversationalaiapi#addhandler) | 添加事件处理器以接收回调。|
|[`removeHandler`](/zh-CN/api-reference/conversational-ai/client-toolkit/conversationalaiapi#removehandler) | 移除事件处理器。|
|[`destroy`](/zh-CN/api-reference/conversational-ai/client-toolkit/conversationalaiapi#destroy) | 销毁 API 实例并释放所有资源。|
