## IsSuccess

```go
func (b Response) IsSuccess() bool
```

判断 [`Response`](/zh-CN/api-reference/conversational-ai/client-toolkit/response.go) 是否表示对话式 AI 引擎 API 的成功响应。

:::info[信息]
自 v0.7.0 版本新增。
:::

:::warning[注意]
如果响应成功，则继续读取成功响应中的数据；否则，读取错误响应中的数据。
:::

#### 返回值

- `true`：响应成功。
- `false`：响应失败。
