## ConvoAIClient

| API | 描述 |
|---|---|
|[`create`](/zh-CN/api-reference/conversational-ai/client-toolkit/convoaiclient.java#create) | 使用指定配置创建 [`ConvoAIClient`](/zh-CN/api-reference/conversational-ai/client-toolkit/convoaiclient.java) 实例。 |
|[`join`](/zh-CN/api-reference/conversational-ai/client-toolkit/convoaiclient.java#join) | 创建一个智能体实例并加入指定的 RTC 频道。 |
|[`leave`](/zh-CN/api-reference/conversational-ai/client-toolkit/convoaiclient.java#leave) | 停止指定的智能体实例并离开 RTC 频道。 |
|[`list`](/zh-CN/api-reference/conversational-ai/client-toolkit/convoaiclient.java#list) | 获取符合指定条件的智能体列表。 |
|[`query`](/zh-CN/api-reference/conversational-ai/client-toolkit/convoaiclient.java#query) | 查询指定智能体实例的当前状态。 |
|[`update`](/zh-CN/api-reference/conversational-ai/client-toolkit/convoaiclient.java#update) | 在运行时调整智能体的参数。 |
|[`interrupt`](/zh-CN/api-reference/conversational-ai/client-toolkit/convoaiclient.java#interrupt) | 中断指定的智能体实例。 |
|[`speak`](/zh-CN/api-reference/conversational-ai/client-toolkit/convoaiclient.java#speak) | 为指定的智能体实例播报自定义消息。 |
