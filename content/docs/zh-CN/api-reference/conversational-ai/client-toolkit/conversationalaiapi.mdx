## chat

```swift
@objc func chat(agentUserId: String, message: ChatMessage, completion: @escaping (ConversationalAIAPIError?) -> Void)
```

向智能体发送消息以进行处理。

你可以使用该方法将文字和图片的消息发送给智能体，并通过完成回调指示操作的成功或失败。

#### 参数

| 参数 | 数据类型 | 描述 |
| --- | --- | --- |
| `agentUserId` | `String` | 智能体的 RTM 用户 ID，必须全局唯一。 |
| `message` | `ChatMessage` | 消息对象，包含图片 URL。详见 [`ChatMessage`](/zh-CN/api-reference/conversational-ai/client-toolkit/struct#chatmessage)。 |
| `completion` | `@escaping (ConversationalAIAPIError?) -> Void` | <Slot name="conversationalaiapi-ios-html-0-3-2" /> |

<Slot for="conversationalaiapi-ios-html-0-3-2">

操作完成时调用的回调函数。

    - 成功时返回 `nil`。
    - 失败时返回错误信息，详见 [`ConversationalAIAPIError`](/zh-CN/api-reference/conversational-ai/client-toolkit/struct#conversationalaiapierror)。

</Slot>

<a id="interrupt"></a>
## interrupt

```swift
@objc func interrupt(agentUserId: String, completion: @escaping (ConversationalAIAPIError?) -> Void)
```

中断智能体当前正在进行的语音或任务处理。

使用该方法可以中断当前正在说话或处理任务的 智能体。

:::warning[注意]
- 如果 `error` 有值，表示消息发送失败。
    - 如果 `error` 为 nil，表示消息发送成功，但不保证智能体成功被中断。
:::

#### 参数

| 参数 | 数据类型 | 描述 |
| --- | --- | --- |
| `agentUserId` | `String` | 智能体的 RTM 用户 ID，必须全局唯一。 |
| `completion` | `(ConversationalAIAPIError?) -> Void` | 操作完成时的回调函数。你可以通过该回调的 `error` 参数得知操作的结果或错误信息，详见 [`ConversationalAIAPIError`](/zh-CN/api-reference/conversational-ai/client-toolkit/struct#conversationalaiapierror)。 |

## loadAudioSettings[1/2]

```swift
@objc func loadAudioSettings()
```

设置音频最佳实践参数以获得最佳性能。

设置用于智能体对话中实现最佳性能所需的音频参数。默认使用 `.aiClient` 音频场景。

示例代码：

```swift
// 在加入频道前设置音频最佳实践参数
api.loadAudioSettings()  // 使用默认场景

// 然后加入频道
rtcEngine.joinChannel(byToken: token, channelId: channelName, info: nil, uid: userId)
```

:::warning[注意]
重要：如果你需要启用音频最佳实践，必须在每次调用 `joinChannel` 之前调用此方法。
:::

## chat

```typescript
public async chat(agentUserId: string, message: IChatMessageText | IChatMessageImage)
```

向对话式智能体发送聊天消息。

:::info[信息]
自 1.7.0 版本新增。
:::

#### 示例代码

```typescript
// Send an image message
const imageMessage: IChatMessageImage = {
  messageType: EChatMessageType.IMAGE,
  imageData: urlImageData
};
await api.chat("user123", imageMessage);
```

#### 参数

| 参数 | 数据类型 | 描述 |
| --- | --- | --- |
| `agentUserId` | `string` | 智能体的唯一标识符。 |
| `message` | `IChatMessageText \| IChatMessageImage` | 要发送的聊天消息，类型为 [`IChatMessageImage`](/zh-CN/api-reference/conversational-ai/client-toolkit/struct?platform=typescript#ichatmessageimage)，详见 [`IChatMessageImage`](/zh-CN/api-reference/conversational-ai/client-toolkit/struct?platform=typescript#ichatmessageimage)。 |

#### 返回值

方法调用成功，返回一个 `Promise`，表示消息发送结果。

## getInstance

```typescript
public static getInstance()
```

获取 [`ConversationalAIAPI`](/zh-CN/api-reference/conversational-ai/client-toolkit/conversationalaiapi?platform=typescript) 的单例实例。

:::info[信息]
自 1.6.0 版本新增。

该方法确保在整个应用程序生命周期中只存在一个 [`ConversationalAIAPI`](/zh-CN/api-reference/conversational-ai/client-toolkit/conversationalaiapi?platform=typescript) 实例。调用前必须先执行 [`init`](/zh-CN/api-reference/conversational-ai/client-toolkit/conversationalaiapi?platform=typescript#init) 方法进行初始化，否则会抛出异常。

#### 返回值

方法调用成功，返回 [`ConversationalAIAPI`](/zh-CN/api-reference/conversational-ai/client-toolkit/conversationalaiapi?platform=typescript) 实例。

<a id="init"></a>
## init

```typescript
public static init(cfg: IConversationalAIAPIConfig)
```

初始化 [`ConversationalAIAPI`](/zh-CN/api-reference/conversational-ai/client-toolkit/conversationalaiapi?platform=typescript) 单例实例。

:::info[信息]
自 1.6.0 版本新增。
:::

该方法用于设置 RTC 和 RTM 引擎、渲染模式以及日志选项。必须在调用 [`ConversationalAIAPI`](/zh-CN/api-reference/conversational-ai/client-toolkit/conversationalaiapi?platform=typescript) 的其他方法之前调用此方法。

- 同一时间只能初始化一个实例。
- 如果已初始化，将抛出错误

#### 参数

| 参数 | 数据类型 | 描述 |
| --- | --- | --- |
| `cfg` | `IConversationalAIAPIConfig` | 用于初始化 API 的配置对象，详见 `IConversationalAIAPIConfig`。 |

#### 返回值

方法调用成功，返回初始化后的 [`ConversationalAIAPI`](/zh-CN/api-reference/conversational-ai/client-toolkit/conversationalaiapi?platform=typescript) 实例。
