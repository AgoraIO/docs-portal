<a id="withstate"></a>
## WithState

```go
func WithState(state int) ListOption
```

设置智能体的状态。

:::info[信息]
自 v0.7.0 版本新增。
:::

#### 参数

| 参数 | 数据类型 | 描述 |
| --- | --- | --- |
| `state` | `int` | <Slot name="listoptions-go-html-1-1-2" /> |

<Slot for="listoptions-go-html-1-1-2">

要查询的智能体状态，支持以下状态：

    - `IDLE`（0）：智能体处于空闲状态。
    - `STARTING`（1）：智能体正在启动。
    - `RUNNING`（2）：智能体正在运行。
    - `STOPPING`（3）：智能体正在停止。
    - `STOPPED`（4）：智能体已完成退出。
    - `RECOVERING`（5）：智能体正在恢复。
    - `FAILED`（6）：智能体已失败。

</Slot>

#### 返回值

方法调用成功，返回 [`ListOption`](/zh-CN/api-reference/conversational-ai/client-toolkit/struct.go#listoption) 函数。
