<a id="chat"></a>
## chat

```kotlin
fun chat(agentUserId: String, message: ChatMessage, completion: (error: ConversationalAIAPIError?) -> Unit)
```

向智能体发送消息。

支持通过 [`ChatMessage`](/zh-CN/api-reference/conversational-ai/client-toolkit/struct.android#chatmessage) 密封类层级发送不同类型的消息：

- [`ImageMessage`](/zh-CN/api-reference/conversational-ai/client-toolkit/struct.android#imagemessage)：用于发送图片消息。

#### 参数

| 参数 | 数据类型 | 描述 |
| --- | --- | --- |
| `agentUserId` | `String` | 智能体用户 ID。 |
| `message` | `ChatMessage` | 消息对象，类型为 [`ImageMessage`](/zh-CN/api-reference/conversational-ai/client-toolkit/struct.android#imagemessage)。详见 [`ChatMessage`](/zh-CN/api-reference/conversational-ai/client-toolkit/struct.android#chatmessage)。 |
| `completion` | `(error: ConversationalAIAPIError?) -> Unit` | 回调函数。调用成功时 `error` 为 null，失败时为非 null。 |

<a id="loadaudiosettings"></a>
## loadAudioSettings

```kotlin
fun loadAudioSettings(scenario: Int = Constants.AUDIO_SCENARIO_AI_CLIENT)
```

设置音频参数以优化智能体对话性能。

:::warning[注意]
你必须在每次调用 `joinChannel` 之前调用此方法，以确保最佳音频质量。
:::

#### 参数

| 参数 | 数据类型 | 描述 |
| --- | --- | --- |
| `scenario` | `Int` | <Slot name="iconversationalaiapi-android-html-6-1-2" /> |

<Slot for="iconversationalaiapi-android-html-6-1-2">

音频场景，默认值为 `AUDIO_SCENARIO_AI_CLIENT`。

    - `AUDIO_SCENARIO_AI_CLIENT`：用于智能体对话场景，优化语音识别和语义理解的音频质量。
    :::warning[注意]
    如果启用数字人功能，请将场景设置为 `AUDIO_SCENARIO_DEFAULT` 以获得更好的混音效果。
    :::

</Slot>

## destroy

fun destroy()
