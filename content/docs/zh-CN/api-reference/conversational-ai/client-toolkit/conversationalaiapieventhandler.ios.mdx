<a id="onmessageerror"></a>
## onMessageError

```swift
@objc func onMessageError(agentUserId: String, error: MessageError)
```

消息处理发生错误时触发的回调。

该回调在消息处理过程中发生错误时被触发。例如，当发送聊天消息失败时，会返回错误信息。

#### 参数

| 参数 | 数据类型 | 描述 |
| --- | --- | --- |
| `agentUserId` | `String` | 智能体的 RTM 用户 ID。 |
| `error` | `MessageError` | 消息错误对象，包含错误类型和错误信息。详见 [`MessageError`](/zh-CN/api-reference/conversational-ai/client-toolkit/struct.ios#messageerror)。 |

## onAgentStateChanged

```swift
@objc func onAgentStateChanged(agentUserId: String, event: StateChangeEvent)
```

智能体状态变化回调。

该回调在智能体状态发生变化时触发，例如从空闲切换为静音、聆听、思考或说话状态。你可以使用该回调更新用户界面或跟踪对话流程。

#### 参数

| 参数 | 数据类型 | 描述 |
| --- | --- | --- |
| `agentUserId` | `String` | 智能体的 RTM 用户 ID。 |
| `event` | `StateChangeEvent` | 智能体状态变化事件。详见 [`StateChangeEvent`](/zh-CN/api-reference/conversational-ai/client-toolkit/struct.ios#statechangeevent)。 |

<a id="onagenterror"></a>
## onAgentError

```swift
@objc func onAgentError(agentUserId: String, error: ModuleError)
```

AI 模块发生错误时的回调。

当模块组件（如 LLM、TTS 等）发生错误时，会调用该回调。可用于错误监控、日志记录以及实现服务降级策略。

:::warning[注意]
该回调不一定与智能体的状态同步，因此不建议在该回调中处理核心业务逻辑。
:::

#### 参数

| 参数 | 数据类型 | 描述 |
| --- | --- | --- |
| `agentUserId` | `String` | 智能体的 RTM 用户 ID。 |
| `error` | `ModuleError` | 模块错误，包含类型、错误码、错误信息和时间戳。详见 [`ModuleError`](/zh-CN/api-reference/conversational-ai/client-toolkit/struct.ios#moduleerror)。 |
