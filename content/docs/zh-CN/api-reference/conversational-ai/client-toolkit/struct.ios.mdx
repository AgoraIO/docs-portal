<a id="imagemessage"></a>
## ImageMessage

```swift
@objc public class ImageMessage: NSObject, ChatMessage {
@objc public let messageType: ChatMessageType = .image
@objc public let uuid: String
@objc public let url: String?
}
```

用于向智能体发送图像内容的消息。

图片采用 URL 形式，即指向图像文件的 HTTP/HTTPS 链接（推荐用于大图）。使用示例：`ImageMessage(uuid = "img_123", url = "https://example.com/image.jpg")`。

#### 成员参数

| 参数 | 数据类型 | 描述 |
| --- | --- | --- |
| `messageType` | `ChatMessageType` | 消息类型。详见 [`ChatMessageType`](/zh-CN/api-reference/conversational-ai/client-toolkit/enum.ios#chatmessagetype)。 |
| `uuid` | `String` | 图像消息的唯一标识符，代理将使用该 `uuid` 来识别图像。 |
| `url` | `String?` | 指向图像文件的 HTTP/HTTPS 链接，代理将使用该链接下载并识别图像。 |

## MessageReceipt

```swift
@objc public class MessageReceipt: NSObject {
    @objc public let moduleType: ModuleType
    @objc public let messageType: ChatMessageType
    @objc public let message: String
    @objc public let turnId: Int

```

用于追踪消息处理状态和元数据的 [`MessageReceipt`](/zh-CN/api-reference/conversational-ai/client-toolkit/struct.ios#messagereceipt) 模型。

包含模块类型、消息类型、图像信息和会话轮次 ID。

#### 成员参数

| 参数 | 数据类型 | 描述 |
| --- | --- | --- |
| `moduleType` | `ModuleType` | 模块类型。详见 [`ModuleType`](/zh-CN/api-reference/conversational-ai/client-toolkit/enum.ios#moduletype)。 |
| `messageType` | `ChatMessageType` | 消息类型。详见 [`ChatMessageType`](/zh-CN/api-reference/conversational-ai/client-toolkit/enum.ios#chatmessagetype)。 |
| `message` | `String` | 图像信息。 |
| `turnId` | `Int` | 会话轮次 ID，用于标识特定的会话轮次。 |

<a id="messageerror"></a>
## MessageError

```swift
@objc public class MessageError: NSObject {
@objc public let type: ChatMessageType
@objc public let code: Int
@objc public let message: String
@objc public let timestamp: TimeInterval
@objc public init(type: ChatMessageType, code: Int, message: String, timestamp: TimeInterval)
}
```

处理和上报消息错误信息的数据类。

包含错误类型、错误码、错误描述和时间戳。

#### 成员参数

| 参数 | 数据类型 | 描述 |
| --- | --- | --- |
| `type` | `ChatMessageType` | 消息错误类型。详见 [`ChatMessageType`](/zh-CN/api-reference/conversational-ai/client-toolkit/enum.ios#chatmessagetype)。 |
| `code` | `Int` | 用于标识特定错误条件的错误码。 |
| `message` | `String` | 错误描述信息，提供详细错误说明，通常为包含资源信息的 JSON 字符串。 |
| `timestamp` | `TimeInterval` | 错误发生的时间戳（自 1970 年 1 月 1 日 UTC 起的毫秒数）。 |

<a id="textmessage"></a>
## TextMessage

```swift
@objc public class TextMessage: NSObject, ChatMessage {
    @objc public let messageType: ChatMessageType = .text
    @objc public let priority: Priority
    @objc public let responseInterruptable: Bool
    @objc public let text: String?
}
```

用于向 智能体代理发送自然语言文本内容的 [`TextMessage`](/zh-CN/api-reference/conversational-ai/client-toolkit/struct.ios#textmessage) 对象。

支持优先级控制和响应可中断设置，实现对 AI 如何处理和响应文本输入的精细化控制。

#### 成员参数

| 参数 | 数据类型 | 描述 |
| --- | --- | --- |
| `messageType` | `ChatMessageType` | 消息类型。详见 [`ChatMessageType`](/zh-CN/api-reference/conversational-ai/client-toolkit/enum.ios#chatmessagetype)。 |
| `priority` | `Priority` | 消息处理优先级，详见 [`Priority`](/zh-CN/api-reference/conversational-ai/client-toolkit/enum.ios#priority)。 |
| `responseInterruptable` | `Bool` | <Slot name="struct-ios-html-4-3-2" /> |
| `text` | `String?` | 消息的文本内容。 |

<Slot for="struct-ios-html-4-3-2">

该消息的响应是否可以被更高优先级的消息中断：

    - `YES`：（默认）响应可被更高优先级的消息中断。
    - `NO`：响应不可被中断。

</Slot>

<a id="statechangeevent"></a>
## StateChangeEvent

```swift
@objc public class StateChangeEvent: NSObject {
@objc public let state: AgentState
@objc public let turnId: Int
@objc public let timestamp: TimeInterval
@objc public let reason: String
@objc public init(state: AgentState, turnId: Int, timestamp: TimeInterval, reason: String)
public override var description: String {
return "StateChangeEvent(state: \(state), turnId: \(turnId), timestamp: \(timestamp), reason: \(reason))"
}
}
```

[`StateChangeEvent`](/zh-CN/api-reference/conversational-ai/client-toolkit/struct.ios#statechangeevent) 表示智能体状态变化事件，包含完整状态信息和时间戳。

用于追踪会话流程并更新用户界面状态指示器。

#### 成员参数

| 参数 | 数据类型 | 描述 |
| --- | --- | --- |
| `state` | `AgentState` | 当前智能体状态。详见 [`AgentState`](/zh-CN/api-reference/conversational-ai/client-toolkit/enum.ios#agentstate)。 |
| `turnId` | `Int` | 会话轮次 ID，用于标识特定的会话轮次。 |
| `timestamp` | `TimeInterval` | 事件发生的时间戳（自 1970 年 1 月 1 日 UTC 起的毫秒数）。 |
| `reason` | `String` | 状态变化的原因。 |

## Metric

```swift
@objc public class Metric: NSObject {
    @objc public let type: ModuleType
    @objc public let name: String
    @objc public let value: Double
    @objc public let timestamp: TimeInterval
    @objc public init(type: ModuleType, name: String, value: Double, timestamp: TimeInterval)
    public override var description: String {
        return "Metric(type: \(type.stringValue), name: \(name), value: \(value), timestamp: \(timestamp))"
    }
}
```

[`Metric`](/zh-CN/api-reference/conversational-ai/client-toolkit/struct.ios#metric) 用于记录和传输系统性能数据。

例如 LLM 推理延迟、TTS 合成延迟等。该数据可用于性能监控、系统优化和用户体验改进。

#### 成员参数

| 参数 | 数据类型 | 描述 |
| --- | --- | --- |
| `type` | `ModuleType` | 指标类型。详见 [`ModuleType`](/zh-CN/api-reference/conversational-ai/client-toolkit/enum.ios#moduletype)。 |
| `name` | `String` | 具体性能项的指标名称。 |
| `value` | `Double` | 指标值，通常为延迟时间（毫秒）或其他定量指标。 |
| `timestamp` | `TimeInterval` | 指标记录的时间戳（自 1970 年 1 月 1 日 UTC 起的毫秒数）。 |

## ConversationalAIAPIConfig

```swift
@objc public class ConversationalAIAPIConfig: NSObject {
@objc public weak var rtcEngine: AgoraRtcEngineKit?
@objc public weak var rtmEngine: AgoraRtmClientKit?
@objc public var renderMode: TranscriptRenderMode
@objc public var enableLog: Bool
}
```

`Conversational AI API` 的初始化配置类。

包含初始化 `Conversational AI API` 所需的配置参数，包括用于音视频通信的 `rtcEngine`、用于消息通信的 `rtmEngine`，以及转写渲染模式设置。

#### 成员参数

| 参数 | 数据类型 | 描述 |
| --- | --- | --- |
| `rtcEngine` | `AgoraRtcEngineKit?` | 用于音视频通信的引擎实例。详见 `AgoraRtcEngineKit`。 |
| `rtmEngine` | `AgoraRtmClientKit?` | 用于实时消息通信的客户端实例。详见 `AgoraRtmClientKit`。 |
| `renderMode` | `TranscriptRenderMode` | 转写渲染模式。详见 [`TranscriptRenderMode`](/zh-CN/api-reference/conversational-ai/client-toolkit/enum.ios#transcriptrendermode)。 |
| `enableLog` | `Bool` | <Slot name="struct-ios-html-11-4-2" /> |

<Slot for="struct-ios-html-11-4-2">

是否启用详细日志记录：

    - `YES`：启用详细日志记录。
    - `NO`：不启用日志记录（默认）。

</Slot>
