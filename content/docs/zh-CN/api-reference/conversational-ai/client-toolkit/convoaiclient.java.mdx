<a id="create"></a>
## create

```java
public static synchronized ConvoAIClient create(ConvoAIConfig convoAIConfig)
```

使用指定配置创建 [`ConvoAIClient`](/zh-CN/api-reference/conversational-ai/client-toolkit/convoaiclient.java) 实例。

:::info[信息]
自 v0.3.0 版本新增。
:::

#### 参数

| 参数 | 数据类型 | 描述 |
| --- | --- | --- |
| `convoAIConfig` | `ConvoAIConfig` | 会话式 AI 引擎的配置参数。详见 [`ConvoAIConfig`](/zh-CN/api-reference/conversational-ai/client-toolkit/struct#convoaiconfig)。 |

#### 返回值

方法调用成功，返回 [`ConvoAIClient`](/zh-CN/api-reference/conversational-ai/client-toolkit/convoaiclient.java) 实例。

<a id="join"></a>
## join

```java
public abstract Mono<JoinConvoAIRes> join(JoinConvoAIReq request);
```

创建一个智能体实例并加入指定的 RTC 频道。

:::info[信息]
自 v0.3.0 版本新增。
:::

#### 参数

| 参数 | 数据类型 | 描述 |
| --- | --- | --- |
| `request` | `JoinConvoAIReq` | 加入对话式 AI 引擎的请求参数。详见 [`JoinConvoAIReq`](/zh-CN/api-reference/conversational-ai/client-toolkit/struct#joinconvoaireq)。 |

#### 返回值

方法调用成功，返回 [`JoinConvoAIRes`](/zh-CN/api-reference/conversational-ai/client-toolkit/struct#joinconvoaires) 实例。

<a id="leave"></a>
## leave

```java
public abstract Mono<Void> leave(String agentId);
```

停止指定的智能体实例并离开 RTC 频道。

:::info[信息]
自 v0.3.0 版本新增。
:::

:::warning[注意]
调用此方法前，请确保已通过调用 [`join`](/zh-CN/api-reference/conversational-ai/client-toolkit/convoaiclient.java#join) 获取智能体 ID。
:::

#### 参数

| 参数 | 数据类型 | 描述 |
| --- | --- | --- |
| `agentId` | `String` | 智能体 ID。 |

<a id="speak"></a>
## speak

```java
public abstract Mono<SpeakConvoAIRes> speak(String agentId, SpeakConvoAIReq request);
```

为指定的智能体实例播报自定义消息。

:::info[信息]
自 v0.4.0 版本新增。
:::

#### 参数

| 参数 | 数据类型 | 描述 |
| --- | --- | --- |
| `agentId` | `String` | 智能体 ID。 |
| `request` | `SpeakConvoAIReq` | 播报自定义消息的请求体，详见 [`SpeakConvoAIReq`](/zh-CN/api-reference/conversational-ai/client-toolkit/struct#speakconvoaireq)。 |

#### 返回值

方法调用成功，返回响应对象 [`SpeakConvoAIRes`](/zh-CN/api-reference/conversational-ai/client-toolkit/struct#speakconvoaires)。详见 [`SpeakConvoAIRes`](/zh-CN/api-reference/conversational-ai/client-toolkit/struct#speakconvoaires)。
