<a id="newclient"></a>
## NewClient

```go
func NewClient(config *Config) (*Client, error)
```

使用指定配置创建一个对话式 AI 引擎 REST Client。

:::info[信息]
自 v0.7.0 版本新增。
:::

#### 参数

| 参数 | 数据类型 | 描述 |
| --- | --- | --- |
| `config` | `Config` | 对话式 AI 引擎 REST Client 的配置，详见 [`Config`](/zh-CN/api-reference/conversational-ai/client-toolkit/struct?platform=go#config)。 |

#### 返回值

- `*Client`：方法调用成功时返回对话式 AI 引擎 REST Client ，详见 [`Client`](/zh-CN/api-reference/conversational-ai/client-toolkit/client.go)。
- `error`：方法调用失败时返回错误信息，详见 `error`。

<a id="join"></a>
## Join

```go
func (c *Client) Join(ctx context.Context, name string, payload *req.JoinPropertiesReqBody) (*resp.JoinResp, error)
```

创建智能体实例并加入指定的 RTC 频道。

:::info[信息]
自 v0.7.0 版本新增。
:::

#### 参数

| 参数 | 数据类型 | 描述 |
| --- | --- | --- |
| `ctx` | `Context` | 用于控制请求生命周期的上下文。 |
| `name` | `string` | 智能体的唯一标识符，不能重复使用。 |
| `payload` | `JoinPropertiesReqBody` | 智能体的配置信息，包括频道信息、Token、LLM 设置、TTS 设置等。详见 [`JoinPropertiesReqBody`](/zh-CN/api-reference/conversational-ai/client-toolkit/struct?platform=go#joinpropertiesreqbody)。 |

#### 返回值

- `*JoinResp`：方法调用成功时返回响应，详见 [`JoinResp`](/zh-CN/api-reference/conversational-ai/client-toolkit/struct?platform=go#joinresp)。
- `error`：方法调用失败时返回错误对象，包含错误信息；调用成功时返回 `nil`。

## Leave

```go
func (c *Client) Leave(ctx context.Context, agentId string) (*resp.LeaveResp, error)
```

停止指定的智能体实例并离开 RTC 频道。

:::info[信息]
自 v0.7.0 版本新增。
:::

:::warning[注意]
调用此方法前，请确保已通过调用 [`Join`](/zh-CN/api-reference/conversational-ai/client-toolkit/client.go#join) 获取智能体 ID。
:::

#### 参数

| 参数 | 数据类型 | 描述 |
| --- | --- | --- |
| `ctx` | `Context` | 用于控制请求生命周期的上下文。 |
| `agentId` | `string` | 智能体 ID。 |

#### 返回值

- `*LeaveResp`：方法调用成功时返回响应，详见 [`LeaveResp`](/zh-CN/api-reference/conversational-ai/client-toolkit/struct?platform=go#leaveresp)。
- `error`：方法调用失败时返回错误信息，成功时返回 `nil`。
