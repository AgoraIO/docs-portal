## NewDefaultLogger

```go
func NewDefaultLogger(level Level) *SampleLogger
```

创建一个具有指定日志级别的默认日志记录器。

:::info[信息]
自 v0.7.0 版本新增。
:::

#### 参数

| 参数 | 数据类型 | 描述 |
| --- | --- | --- |
| `level` | `Level` | 日志级别，详见 [`Level`](/zh-CN/api-reference/conversational-ai/client-toolkit/enum.go#level)。 |

#### 返回值

方法调用成功，返回 [`SampleLogger`](/zh-CN/api-reference/conversational-ai/client-toolkit/samplelogger.go) 对象。详见 [`SampleLogger`](/zh-CN/api-reference/conversational-ai/client-toolkit/samplelogger.go)。
