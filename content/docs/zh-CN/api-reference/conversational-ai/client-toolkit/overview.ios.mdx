## ConversationalAIAPI

| API | 描述 |
|---|---|
|[`chat`](/zh-CN/api-reference/conversational-ai/client-toolkit/conversationalaiapi.ios#chat) | 向智能体发送消息以进行处理。|
|[`interrupt`](/zh-CN/api-reference/conversational-ai/client-toolkit/conversationalaiapi.ios#interrupt) | 打断智能体当前正在进行的语音或任务处理。|
|[`loadAudioSettings`](/zh-CN/api-reference/conversational-ai/client-toolkit/conversationalaiapi.ios#loadaudiosettings) | 设置音频最佳实践参数以获得更佳性能。|
|[`subscribeMessage`](/zh-CN/api-reference/conversational-ai/client-toolkit/conversationalaiapi.ios#subscribemessage) | 订阅频道消息。|
|[`unsubscribeMessage`](/zh-CN/api-reference/conversational-ai/client-toolkit/conversationalaiapi.ios#unsubscribemessage) | 取消订阅频道消息。|
|[`addHandler`](/zh-CN/api-reference/conversational-ai/client-toolkit/conversationalaiapi.ios#addhandler) | 添加事件处理器以接收回调。|
|[`removeHandler`](/zh-CN/api-reference/conversational-ai/client-toolkit/conversationalaiapi.ios#removehandler) | 移除事件处理器。|
|[`destroy`](/zh-CN/api-reference/conversational-ai/client-toolkit/conversationalaiapi.ios#destroy) | 销毁 API 实例并释放所有资源。|
