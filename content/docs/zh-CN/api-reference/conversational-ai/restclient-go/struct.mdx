## Logger

```go

	Debug(ctx Context, module string, v ...interface{})
	Debugf(ctx Context, module string, format string, v ...interface{})
	Error(ctx Context, module string, v ...interface{})
	Errorf(ctx Context, module string, format string, v ...interface{})
	Info(ctx Context, module string, v ...interface{})
	Infof(ctx Context, module string, format string, v ...interface{})
```

| 参数 | 数据类型 | 描述 |

#### 成员参数

| `Params` | `TTSVendorParamsInterface` | TTS 供应商参数，详见 [`TTSMinimaxVendorParams`](/zh-CN/api-reference/conversational-ai/restclient-go/struct#ttsminimaxvendorparams)、[`TTSTencentVendorParams`](/zh-CN/api-reference/conversational-ai/restclient-go/struct#ttstencentvendorparams)、[`TTSBytedanceVendorParams`](/zh-CN/api-reference/conversational-ai/restclient-go/struct#ttsbytedancevendorparams) 和 [`TTSMicrosoftVendorParams`](/zh-CN/api-reference/conversational-ai/restclient-go/struct#ttsmicrosoftvendorparams)。 |
| `SkipPatterns` | `[]int` | <Slot name="struct-go-html-6-3-2" /> |

<Slot for="struct-go-html-6-3-2">

控制 TTS 模块在朗读大语言模型（LLM）响应文本时是否跳过括号内容。启用此功能可防止智能体朗读结构性提示信息，如语气标记、动作描述和系统提示，从而营造更自然沉浸的听觉体验。

    通过指定一个或多个值启用此功能：

    - `1`：跳过中文圆括号（），Unicode 为 \uFF08 和 \uFF09。
    - `2`：跳过中文方括号【】，Unicode 为 \u3010 和 \u3011。
    - `3`：跳过英文圆括号 ()，Unicode 为 \u0028 和 \u0029。
    - `4`：跳过英文方括号 []，Unicode 为 \u005B 和 \u005D。
    - `5`：跳过英文花括号 {}，Unicode 为 \u007B 和 \u007D。

</Slot>
