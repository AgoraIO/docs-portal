## Client

| API | 描述 |
|---|---|
|[`NewClient`](/zh-CN/api-reference/conversational-ai/restclient-go/client.go#newclient) | 使用指定配置创建一个对话式 AI 引擎 REST Client。 |
|[`Join`](/zh-CN/api-reference/conversational-ai/restclient-go/client.go#join) | 创建智能体实例并加入指定的 RTC 频道。 |
|[`Leave`](/zh-CN/api-reference/conversational-ai/restclient-go/client.go#leave) | 停止指定的智能体实例并离开 RTC 频道。 |
|[`Query`](/zh-CN/api-reference/conversational-ai/restclient-go/client.go#query) | 查询指定智能体实例的当前状态。 |
|[`List`](/zh-CN/api-reference/conversational-ai/restclient-go/client.go#list) | 获取符合指定条件的智能体列表。 |
|[`Update`](/zh-CN/api-reference/conversational-ai/restclient-go/client.go#update) | 在运行时调整智能体的参数。 |
|[`Interrupt`](/zh-CN/api-reference/conversational-ai/restclient-go/client.go#interrupt) | 中断指定的智能体实例。 |
|[`GetHistory`](/zh-CN/api-reference/conversational-ai/restclient-go/client.go#gethistory) | 获取指定智能体实例的短期记忆。 |
|[`Speak`](/zh-CN/api-reference/conversational-ai/restclient-go/client.go#speak) | 让指定智能体说出自定义消息。 |
