---
title: "AIGCService API 参考"
---
AIGCService SDK 主要包含以下两大类：

- [`AIGCService`](#aigcservice) 类：提供 AIGC 服务的核心类，包含实现 AIGC 场景各功能的核心方法。
- [`AIGCServiceCallback`](#aigcservicecallback) 类：`AIGCService` 异步方法的事件回调类。

本文提供 AIGCService SDK 的 API 参考。

<a id="aigcservice"></a>
<a id="create"></a>
## AIGCService
### create

```java
AIGCService create();
```

创建 `AIGCService` 实例。

#### 返回值

成功创建后，该方法会返回一个 `AIGCService` 实例。

<a id="initialize"></a>
### initialize

```java
void initialize(AIGCServiceConfig config);
```

初始化 `AIGCService`。

该方法为异步操作。调用结果会在 [`onEventResult`](#oneventresult) 回调中返回。

#### 参数

| 参数 | 描述 |
| --- | --- |
| config | `AIGCService` 初始化参数。详见 [`AIGCServiceConfig`](#aigcserviceconfig)。|

<a id="getroles"></a>
### getRoles

```java
AIRole[] getRoles();
```

获取 SDK 支持的所有的 `AIRole` 数组。

:::warning[注意]
该方法需要在成功调用 `initialize`，且收到 `onEventResult(INITIALIZE, SUCCESS)` 后调用。
:::

#### 返回值

SDK 支持的 [`AIRole`](#airole) 数组。

<a id="setrole"></a>
### setRole

```java
void setRole(String roleId);
```

设置 SDK 使用的 `AIRole`。该方法设置即时生效。

:::warning[注意]
该方法需要在成功调用 `initialize`，且收到 `onEventResult(INITIALIZE, SUCCESS)` 后调用。
:::

#### 参数

| 参数 | 描述 |
| --- | --- |
| `roleId` | 标明 `AIRole` 的 ID。 |

### getCurrentRole

```java

```

:::warning[注意]
该方法需要在成功调用 `initialize`，且收到 `onEventResult(INITIALIZE, SUCCESS)` 后调用。

#### 返回值

<a id="getservicevendors"></a>
### getServiceVendors

```java
ServiceVendorGroup getServiceVendors();
```

获取所有 AI 服务商的信息。

:::warning[注意]
该方法需要在成功调用 `initialize`，且收到 `onEventResult(INITIALIZE, SUCCESS)` 后调用。
:::

#### 返回值

包含了所有 AI 服务商信息的 `ServiceVendorGroup` 对象，由多个 [`STTVendor`](#sttvendor)、[`LLMVendor`](#llmvendor) 和 [`TTSVendor`](#ttsvendor) 组成。

<a id="setservicevendor"></a>
### setServiceVendor

```java
int setServiceVendor(ServiceVendor vendor);
```

设置所使用的 AI 服务商。

:::warning[注意]
该方法需要在成功调用 `initialize`，且收到 `onEventResult(INITIALIZE, SUCCESS)` 后调用。
:::

#### 参数

| 参数 | 描述 |
| --- | --- |
| `vendor` | 设置的服务商对象 `ServiceVendor`，包含 [`STTVendor`](#sttvendor)、[`LLMVendor`](#llmvendor) 和 [`TTSVendor`](#ttsvendor)。每种 Vendor 类型只支持设置一个服务商。|

- 非 0：方法调用失败

<a id="pushtxtdialogue"></a>
### pushTxtDialogue

```java
int pushTxtDialogue(String text, String roundId);
```

推送采集到的文本数据到 SDK 的 LLM 模块，用于 LLM 处理文本数据。

该方法和 `pushMessagesToLLM` 均可用于推送文本数据到 LLM 模块，区别为该方法仅支持推送单条消息，`pushMessagesToLLM` 支持推送多条消息（消息及其上下文语境）。

:::warning[注意]
- 该方法需要在成功调用 `start`，且收到 `onEventResult(START, SUCCESS)` 后调用。
- 建议文本数据的长度不超过 1 KB。对高于 1 KB 的数据我们不保证能正确处理。
:::

#### 参数

| 参数 | 描述 |
| --- | --- |
| `text` | 待推送的文本数据。 |
| `roundId` | <Slot name="aigcservice-android-html-1-2-1" /> |

<Slot for="aigcservice-android-html-1-2-1">

请求的 `roundId`，可为空。用于跟踪后续 LLM/TTS 对应关系的 ID，你可以利用该参数在 UI 层实现相关的业务逻辑。

        - 如果自行设置 `roundId`，为准确区分不同请求，请确保设置的 ID 全局唯一；
        - 如果 `roundId` 为空，SDK 内部会分配一个 `roundId`，并在每形成一个完整句子时更新为新的 `roundId`。

</Slot>

#### 返回值

- 0：方法调用成功
- 非 0：方法调用失败

## AIGCServiceCallback
### onEventResult

```java
void onEventResult(@NonNull ServiceEvent event, @NonNull ServiceCode code, @Nullable String msg);
```

AIGCService 实例事件回调。

该回调在 SDK 调用 `initialize`、`start`、`stop`、`destroy` 后触发，报告对应方法的调用结果。

#### 参数

| 参数 | 描述 |
| --- | --- |
| `event` | 该服务事件的类型，详见 [`ServiceEvent`](#serviceevent)。|
| `code` | 该服务事件的结果，详见 [`ServiceCode`](#servicecode)。|
| `msg` | 事件信息。该字串可能为空。|

<a id="onspeech2textresult"></a>
### onSpeech2TextResult

```java
HandleResult onSpeech2TextResult(String roundId, Data<String> result, boolean isRecognizedSpeech, ServiceCode code)
```

回调语音转文字 (STT) 处理后的结果。

#### 参数

| 参数 | 描述 |
| --- | --- |
| `roundId` | <Slot name="aigcservice-android-html-6-1-1" /> |
| `result` | 语音识别出来的文字（UTF-8 字符集）。 该参数为读写模式。在 `isRecognizedSpeech` 为 `true` 时，如果 `result` 参数被修改，后续流程会用更新后的 `result` 当作后续流程的输入。 |
| `isRecognizedSpeech` | <Slot name="aigcservice-android-html-6-3-1" /> |
| `code` | STT 语音识别结果。详见 [`ServiceCode`](#servicecode)。 |

<Slot for="aigcservice-android-html-6-1-1">

请求的 `roundId`。用于跟踪后续 LLM/TTS 对应关系的 ID，你可以利用该参数在 UI 层实现相关的业务逻辑。

        - 如果你在推送时设置了 `roundId`，回调中沿用你设置的 `roundId`；
        - 如果推送时 `roundId` 为空，SDK 内部会分配一个 `roundId`，并在每形成一个完整句子时更新为新的 `roundId`。

</Slot>

<Slot for="aigcservice-android-html-6-3-1">

该回调返回的 `result` 是否是一个完整的句子：

        - `true`：是
        - `false`：不是

</Slot>

#### 返回值

`HandleResult`，该回调的处理结果类型。你需要设置该返回值：

- `CONTINUE(0)`：SDK 会继续处理后续流程
- `DISCARD(1)`：SDK 会中断处理后续流程

:::warning[注意]
该规则仅在 `isRecognizedSpeech` 返回 `true` 下有效。
:::
