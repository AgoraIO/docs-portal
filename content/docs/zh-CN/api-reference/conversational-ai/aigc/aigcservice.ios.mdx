---
title: "AgoraAIGCService API 参考"
---
AgoraAIGCService SDK 主要包含以下两大类：

- [`AgoraAIGCService`](#aigcservice) 类：提供 AIGC 服务的核心类，包含实现 AIGC 场景各功能的核心方法。
- [`AgoraAIGCServiceDelegate`](#aigcservicecallback) 类：`AgoraAIGCService` 异步方法的事件回调类。

本文提供 AgoraAIGCService SDK 的 API 参考。

<a id="aigcservice"></a>
<a id="create"></a>
## AgoraAIGCService
### create

```objc
+ (instancetype)create;
```

创建 `AgoraAIGCService` 实例。

#### 返回值

成功创建后，该方法会返回一个 `AgoraAIGCService` 实例。

<a id="initialize"></a>
### initialize

```objc
- (void)initialize:(AgoraAIGCConfigure *)config;
```

初始化 `AgoraAIGCService`。

该方法为异步操作。调用结果会在 [`onEventResultWithEvent`](#oneventresult) 回调中返回。

#### 参数

| 参数 | 描述 |
| --- | --- |
| config | `AgoraAIGC` 初始化参数。详见 [`AgoraAIGCConfigure`](#aigcserviceconfig)。|

<a id="pushtxtdialogue"></a>
### pushTxtDialogue

```objc
- (AgoraAIGCServiceCode)pushTxtDialogue:(NSString *)text roundId:(NSString * _Nullable)roundId;
```

推送采集到的文本数据到 SDK 的 LLM 模块，用于 LLM 处理文本数据。

该方法和 `pushMessagesToLlm` 均可用于推送文本数据到 LLM 模块，区别为该方法仅支持推送单条消息，`pushMessagesToLlm` 支持推送多条消息（消息及其上下文语境）。

:::warning[注意]
- 该方法需要在成功调用 `start`，且收到 `onEventResultWithEvent(Start, Success)` 后调用。
- 建议文本数据的长度不超过 1 KB。对高于 1 KB 的数据我们不保证能正确处理。
:::

#### 参数

| 参数 | 描述 |
| --- | --- |
| `text` | 待推送的文本数据。 |
| `roundId` | <Slot name="aigcservice-ios-html-1-2-1" /> |

<Slot for="aigcservice-ios-html-1-2-1">

请求的 `roundId`，可为空。用于跟踪后续 LLM/TTS 对应关系的 ID，你可以利用该参数在 UI 层实现相关的业务逻辑。

        - 如果自行设置 `roundId`，为准确区分不同请求，请确保设置的 ID 全局唯一；
        - 如果 `roundId` 为空，SDK 内部会分配一个 `roundId`，并在每形成一个完整句子时更新为新的 `roundId`。

</Slot>

#### 返回值

该方法调用的结果，详见 [`AgoraAIGCServiceCode`](#servicecode)。

<a id="onspeech2textresult"></a>
### onSpeech2TextWithRoundId

```objc
- (AgoraAIGCHandleResult)onSpeech2TextWithRoundId:(NSString *)roundId
                                           result:(NSString *)result
                                 recognizedSpeech:(BOOL)recognizedSpeech
                                             code:(AgoraAIGCServiceCode)code;
```

报告语音转文字 (STT) 处理后的结果。

#### 参数

| 参数 | 描述 |
| --- | --- |
| `roundId` | <Slot name="aigcservice-ios-html-4-1-1" /> |
| `result` | 语音识别出来的文字（UTF-8 字符集）。该参数为只读模式。 |
| `recognizedSpeech` | <Slot name="aigcservice-ios-html-4-3-1" /> |
| `code` | STT 语音识别结果。详见 [`AgoraAIGCServiceCode`](#servicecode)。 |

<Slot for="aigcservice-ios-html-4-1-1">

请求的 `roundId`。用于跟踪后续 LLM/TTS 对应关系的 ID，你可以利用该参数在 UI 层实现相关的业务逻辑。

        - 如果你在推送时设置了 `roundId`，回调中沿用你设置的 `roundId`；
        - 如果推送时 `roundId` 为空，SDK 内部会分配一个 `roundId`，并在每形成一个完整句子时更新为新的 `roundId`。

</Slot>

<Slot for="aigcservice-ios-html-4-3-1">

该回调返回的 `result` 是否是一个完整的句子：

        - `YES`：是
        - `NO`：不是

- `AgoraAIGCHandleResultContinue`：SDK 会继续处理后续流程
- `AgoraAIGCHandleResultDiscard`：SDK 会中断处理后续流程

:::warning[注意]
该规则仅在 `recognizedSpeech` 返回 `YES` 下有效。
:::
