[开通声网消息通知](/zh-CN/solutions/voip-call/build/monitor-events/receive-webhook)后，声网通知服务器以 HTTPS POST 请求方法向你的服务器发送频道事件通知回调。数据格式为 JSON，字符编码为 UTF-8，签名算法为 HMAC/SHA1 或 HMAC/SHA256。

本页介绍频道事件回调中返回的各事件类型及含义。

## 请求 Header

| 字段名            | 值                 |
| ----------------- | ------------------ |
| `Content-Type`    | `application/json` |
| `Agora-Signature` |声网用密钥（`secret`）和 HMAC/SHA1 算法生成的签名值。你需要使用密钥（`secret`）和 HMAC/SHA1 算法来验证该签名值。详见[验证签名](/zh-CN/solutions/voip-call/build/monitor-events/receive-webhook#验证签名)。          |
| `Agora-Signature-V2` |声网用密钥（`secret`）和 HMAC/SHA256 算法生成的签名值。你需要使用密钥（`secret`）和 HMAC/SHA256 算法来验证该签名值。 详见[验证签名](/zh-CN/solutions/voip-call/build/monitor-events/receive-webhook#验证签名)。            |

## 请求 Body

请求 Body 的示例如下：

```json
{
  "appId": "xxxxxskdsakm",
  "sid": "C86646scxsc87",
  "noticeId": "xxx",
  "eventType": 1,
  "eventName": "CALLING",
  "payload": {
    // ...
  }
}
```

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| `appId` | String | 你的声网项目的 App ID。|
| `sid` | String | 触发该事件的请求 ID，和响应中返回的 `taskId` 一致。你可以使用该字段定位出现异常的请求。|
| `noticeId` | String | 通知 ID，标识来自声网业务服务器的一次事件通知。|
| `eventType` | Number | 事件类型。|
| `eventName` | String | 事件名称。|
| `payload` | Json Object | 通知事件的具体内容。详见[事件类型](#事件类型)。|

## 事件类型

### 01 CALLING

`eventType` 为 `01` 表示通话正在拨打中，`payload` 中包含以下字段：

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `direct` | Number | <Slot name="voip-events-html-0-1-2" /> |
| `detail` | String | 该事件类型代表的具体含义。 |
| `wechat` | String | <Slot name="voip-events-html-0-3-2" /> |
| `agora` | String | <Slot name="voip-events-html-0-4-2" /> |

<Slot for="voip-events-html-0-1-2">

呼叫方向：

    - 1：设备拨打小程序
    - 2：小程序拨打设备

</Slot>

<Slot for="voip-events-html-0-3-2">

微信小程序相关配置项，包含如下字段：

    - `deviceId`：设备 ID。
    - `openId`：小程序用户的唯一 ID。
    - `appId`：微信小程序的 App ID。

</Slot>

<Slot for="voip-events-html-0-4-2">

声网相关配置项，包含如下字段：

    - `channelName`：设备端加入的 RTC 频道名。
    - `robotUID`：微呼叫服务加入 RTC 频道时使用的 UID。
    - `deviceUID`：设备端加入 RTC 频道时使用的 UID。
    - `appId`：声网项目的 App ID。

</Slot>

`payload` 示例：

```json
{
  "direct": 1,
  "detail": "device call wechat",
  "wechat": "{\"appId\":\"xxx\",\"deviceId\":\"xxx\",\"openId\":\"xxx\"}",
  "agora": "{\"channelName\":\"xxx\",\"appId\":\"xxx\",\"robotUID\":\"xxx\",\"deviceUID\":\"xxx\"}"
}
```

    - `appId`：微信小程序的 App ID。

</Slot>

    - `channelName`：设备端加入的 RTC 频道名。
    - `robotUID`：微呼叫服务加入 RTC 频道时使用的 UID。
    - `deviceUID`：设备端加入 RTC 频道时使用的 UID。
    - `appId`：声网项目的 App ID。
