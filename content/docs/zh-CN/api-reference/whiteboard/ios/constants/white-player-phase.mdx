白板回放状态。

## WhitePlayerPhase

```objc
typedef NS_ENUM(NSInteger, WhitePlayerPhase ) { WhitePlayerPhaseWaitingFirstFrame, WhitePlayerPhasePlaying, WhitePlayerPhasePause, WhitePlayerPhaseStopped, WhitePlayerPhaseEnded, WhitePlayerPhaseBuffering, };
```

| Name | Description |
| --- | --- |
| `WhitePlayerPhaseWaitingFirstFrame` | 正在等待白板回放的第一帧。这是白板回放的初始阶段。 |
| `WhitePlayerPhasePlaying` | 白板回放正在播放。 |
| `WhitePlayerPhasePause` | 白板回放已暂停。 |
| `WhitePlayerPhaseStopped` | 白板回放已停止。 |
| `WhitePlayerPhaseEnded` | 白板回放已结束。 |
| `WhitePlayerPhaseBuffering` | 白板回放正在缓存。 |
