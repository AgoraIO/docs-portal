白板场景路径类型。

## WhiteScenePathType

```objc
typedef NS_ENUM(NSInteger, WhiteScenePathType ) { WhiteScenePathTypeEmpty, WhiteScenePathTypePage, WhiteScenePathTypeDir, };
```

| Name | Description |
| --- | --- |
| `WhiteScenePathTypeEmpty` | 路径对应的内容为空。 |
| `WhiteScenePathTypePage` | 路径对应的内容是一个白板页面。 |
| `WhiteScenePathTypeDir` | 路径对应的内容是一个目录，该目录下存在目录或者多个页面。 |
