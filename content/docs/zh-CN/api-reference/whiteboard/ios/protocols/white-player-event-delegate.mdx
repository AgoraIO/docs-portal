<a id="//api/name/phaseChanged:"></a>

### phaseChanged:

```objc
- (void)phaseChanged:(WhitePlayerPhase)phase
```

播放状态切换回调。

#### Parameters

| Name | Description |
| --- | --- |
| `phase` | 白板回放的播放状态。详见 [WhitePlayer](/zh-CN/api-reference/whiteboard/ios/classes/white-player)。 |

### playerStateChanged:

```objc
- (void)playerStateChanged:(WhitePlayerState *)modifyState
```

回放状态发生变化的回调，只会包含实际发生改变的属性。

#### Parameters

| Name | Description |
| --- | --- |
| `modifyState` | 白板回放已经改变的的状态。详见 [WhitePlayerState](/zh-CN/api-reference/whiteboard/ios/classes/white-player-state)。 |
