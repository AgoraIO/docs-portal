### slideUrlInterrupter:completionHandler:

```objc
- (void)slideUrlInterrupter:(NSString *_Nullable)url completionHandler:(SlideUrlInterrupterCallback _Nullable)completionHandler
```

PPT URL 拦截回调。

#### Parameters

| Name | Description |
| --- | --- |
| `url` | 原始 PPT 资源地址。 |
| `completionHandler` | 替换后的 PPT 资源地址的回调闭包，你需要在该回调中实现替换逻辑。完成替换后，你需要调用 `completionHandler` 处理 PPT URL 拦截和替换后的结果。 |

#### Discussion

**Note:**

- 要触发该回调，必须在初始化白板 SDK 时，设置 [WhiteSdkConfiguration](/zh-CN/api-reference/whiteboard/ios/classes/white-sdk-configuration).enableSlideInterrupterAPI(YES) 开启 PPT 拦截替换功能。详见 [WhiteSdkConfiguration](/zh-CN/api-reference/whiteboard/ios/classes/white-sdk-configuration)。

<a id="//api/name/onSlideError:errorMessage:slideId:slideIndex:"></a>

### onSlideError:errorMessage:slideId:slideIndex:

```objc
- (void)onSlideError:(WhiteSlideErrorType)slideError errorMessage:(NSString *)errorMessage slideId:(NSString *)slideId slideIndex:(NSInteger)slideIndex
```

PPT 加载错误回调，用于监听 PPT 渲染错误事件。

#### Parameters

| Name | Description |
| --- | --- |
| `slideError` | 错误类型。包括： - `WhiteSlideErrorTypeResourceError`：当 PPT 依赖的远程资源（如 JSON、PNG）不可用时触发，触发后当前页无法交互。恢复手段：重新渲染当前页或者跳转到下一页。 - `WhiteSlideErrorTypeRuntimeError`：未知的异常导致触发，触发后当前页无法交互。恢复手段：跳转到下一页。 - `WhiteSlideErrorTypeRuntimeWarn`：动画过程中出现未知的警告，触发后动画当前帧表现异常，但不影响下一帧和页面交互。恢复手段：无需特殊处理。 - `WhiteSlideErrorTypeCanvasCrash`：由于内存不足，或者 canvas 被意外移除（在未调用 slide.destroy() 的情况下移除 canvas 元素）导致触发，触发后 canvas 元素白屏。恢复手段：刷新网页，或者销毁 slide 对象并重新创建。 - `WhiteSlideErrorTypeCanvasUnknown`：画布未知错误。 |
| `errorMessage` | 错误信息。 |
| `slideId` | PPT ID。 |
| `slideIndex` | PPT 索引。 |

#### Availability

2.16.93
