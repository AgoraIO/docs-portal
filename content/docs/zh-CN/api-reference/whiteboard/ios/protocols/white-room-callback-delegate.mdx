房间事件回调。

## Methods

<a id="//api/name/firePhaseChanged:"></a>

### firePhaseChanged:

```objc
- (void)firePhaseChanged:(WhiteRoomPhase)phase
```

房间连接状态发生变化回调。

#### Parameters

| Name | Description |
| --- | --- |
| `phase` | 房间的连接状态，详见 [WhiteRoomPhase](/zh-CN/api-reference/whiteboard/ios/constants/white-room-phase)。 |

<a id="//api/name/fireRoomStateChanged:"></a>

### fireRoomStateChanged:

```objc
- (void)fireRoomStateChanged:(WhiteRoomState *)modifyState
```

房间状态属性发生变化回调。

#### Parameters

| Name | Description |
| --- | --- |
| `modifyState` | 发生变化的房间状态属性，详见 [WhiteRoomState](/zh-CN/api-reference/whiteboard/ios/classes/white-room-state)。 |

#### Discussion

该回调仅返回发生变化的房间状态属性，未发生变化的房间状态字段，均为空。

<a id="//api/name/fireCatchErrorWhenAppendFrame:error:"></a>

### fireCatchErrorWhenAppendFrame:error:

```objc
- (void)fireCatchErrorWhenAppendFrame:(NSUInteger)userId error:(NSString *)error
```

同步用户行为发生错误回调。

#### Parameters

| Name | Description |
| --- | --- |
| `userId` | 用户 ID。 |
| `error` | 错误原因。 |

#### Discussion

**Note:**

该回调通常是可以忽略的，你可以根据业务情况自行决定是否监听。

<a id="//api/name/fireCanUndoStepsUpdate:"></a>

### fireCanUndoStepsUpdate:

```objc
- (void)fireCanUndoStepsUpdate:(NSInteger)canUndoSteps
```

可撤销次数发生变化回调。

#### Parameters

| Name | Description |
| --- | --- |
| `canUndoSteps` | 剩余的可撤销次数。 |

#### Discussion

当本地用户调用 [undo](/zh-CN/api-reference/whiteboard/ios/classes/white-room#//api/name/undo) 撤销上一步操作时，会触发该回调，报告剩余的可撤销次数。
