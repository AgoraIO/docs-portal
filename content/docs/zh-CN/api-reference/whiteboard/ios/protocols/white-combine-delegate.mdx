[WhiteCombinePlayer](/zh-CN/api-reference/whiteboard/ios/classes/white-combine-player) 的回调。

## Methods

<a id="//api/name/combinePlayerStartBuffering"></a>

### combinePlayerStartBuffering

```objc
- (void)combinePlayerStartBuffering
```

白板回放播放器或本地播放器开始缓冲回调。

<a id="//api/name/combinePlayerEndBuffering"></a>

### combinePlayerEndBuffering

```objc
- (void)combinePlayerEndBuffering
```

白板回放播放器和本地播放器全部缓冲结束回调。

<a id="//api/name/nativePlayerStartBuffering"></a>

### nativePlayerStartBuffering

```objc
- (void)nativePlayerStartBuffering
```

本地播放器开始缓冲回调。

<a id="//api/name/nativePlayerEndBuffering"></a>

### nativePlayerEndBuffering

```objc
- (void)nativePlayerEndBuffering
```

本地播放器结束缓冲回调。

<a id="//api/name/nativePlayerDidFinish"></a>

### nativePlayerDidFinish

```objc
- (void)nativePlayerDidFinish
```

本地播放器播放结束回调。

<a id="//api/name/combineVideoPlayStateChange:"></a>

### combineVideoPlayStateChange:

```objc
- (void)combineVideoPlayStateChange:(BOOL)isPlaying
```

[WhiteCombinePlayer](/zh-CN/api-reference/whiteboard/ios/classes/white-combine-player) 播放状态发生改变回调。

#### Parameters

| Name | Description |
| --- | --- |
| `isPlaying` | 是否正在播放 |

<a id="//api/name/combineVideoPlayerError:"></a>

### combineVideoPlayerError:

```objc
- (void)combineVideoPlayerError:(NSError *)error
```

[WhiteCombinePlayer](/zh-CN/api-reference/whiteboard/ios/classes/white-combine-player) 无法进行播放，需要重新创建 [WhiteCombinePlayer](/zh-CN/api-reference/whiteboard/ios/classes/white-combine-player) 进行播放。

#### Parameters

| Name | Description |
| --- | --- |
| `error` | 错误原因 |

<a id="//api/name/loadedTimeRangeChange:"></a>

### loadedTimeRangeChange:

```objc
- (void)loadedTimeRangeChange:(NSArray<NSValue*> *)loadedTimeRanges
```

[WhiteCombinePlayer](/zh-CN/api-reference/whiteboard/ios/classes/white-combine-player) 加载时间范围发生改变回调。

#### Parameters

| Name | Description |
| --- | --- |
| `loadedTimeRanges` | 加载时间范围。 |
