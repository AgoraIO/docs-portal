<a id="overview"></a>

互动白板实时房间和回放房间共有的状态。

## Methods

<a id="//api/name/setCustomGlobalStateClass:"></a>

### setCustomGlobalStateClass:

```objc
+ (BOOL)setCustomGlobalStateClass:(Class)clazz
```

设置自定义全局状态。

#### Parameters

| Name | Description |
| --- | --- |
| `clazz` | 自定义全局状态类，自定义的 [WhiteGlobalState](/zh-CN/api-reference/whiteboard/ios/classes/white-global-state) 类必须继承 [WhiteGlobalState](/zh-CN/api-reference/whiteboard/ios/classes/white-global-state)，否则会清空该配置。 **Note:** 如果你使用 Swift，在配置 [WhiteGlobalState](/zh-CN/api-reference/whiteboard/ios/classes/white-global-state) 子类属性时，需要对属性添加 `@objc` 修饰符。 @return `YES`：配置成功。 `No`：配置失败，恢复为 [WhiteGlobalState](/zh-CN/api-reference/whiteboard/ios/classes/white-global-state) 类。 |

#### Discussion

设置后，所有 [WhiteGlobalState](/zh-CN/api-reference/whiteboard/ios/classes/white-global-state) 都会转换为该类的对象。
