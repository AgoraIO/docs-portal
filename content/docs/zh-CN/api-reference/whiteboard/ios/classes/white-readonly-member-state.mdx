<a id="overview"></a>

互动白板实时房间的工具状态（只读）。初始工具为 `pencil`，无默认值。

## Methods

<a id="//api/name/currentApplianceName"></a>

### currentApplianceName

```objc
@property (nonatomic, copy, readonly) WhiteApplianceNameKey currentApplianceName
```

互动白板实时房间内当前使用的工具名称。初始工具为 `pencil`，无默认值。

<a id="//api/name/strokeColor"></a>

### strokeColor

```objc
@property (nonatomic, copy, readonly) NSArray<NSNumber*> *strokeColor
```

线条颜色，为 RGB 格式，例如，(0, 0, 255) 表示蓝色。

<a id="//api/name/strokeWidth"></a>

### strokeWidth

```objc
@property (nonatomic, strong, readonly, nullable) NSNumber *strokeWidth
```

线条粗细。

<a id="//api/name/textSize"></a>

### textSize

```objc
@property (nonatomic, strong, readonly, nullable) NSNumber *textSize
```

字体大小。

<a id="//api/name/textColor"></a>

### textColor

```objc
@property (nonatomic, copy, readwrite, nullable) NSArray<NSNumber*> *textColor
```

文本颜色，为 RGB 格式，例如，(0, 0, 255) 表示蓝色。

<a id="//api/name/pencilEraserSize"></a>

### pencilEraserSize

```objc
@property (nonatomic, strong, readwrite, nullable) NSNumber *pencilEraserSize
```

局部橡皮擦大小。取值范围为 [1,3]，值越大代表尺寸越大。

<a id="//api/name/shapeType"></a>

### shapeType

```objc
@property (nonatomic, strong, readonly, nullable) WhiteApplianceShapeTypeKey shapeType
```

当教具为 `Shape` 时，所选定的 shape 图形。

#### Availability

2.12.24

<a id="//api/name/strokeOpacity"></a>

### strokeOpacity

```objc
@property (nonatomic, strong, readonly, nullable) NSNumber *strokeOpacity
```

线框透明度。

#### Availability

2.16.112 取值范围为 [0.0, 1.0]，0 表示完全透明，1 表示完全不透明。 仅在 `` WhiteSdkConfiguration `.enableAppliancePlugin` 启用时有效。

<a id="//api/name/fillColor"></a>

### fillColor

```objc
@property (nonatomic, copy, readonly, nullable) NSArray<NSNumber*> *fillColor
```

填充样式。

#### Availability

2.16.112 仅在 [WhiteSdkConfiguration](/zh-CN/api-reference/whiteboard/ios/classes/white-sdk-configuration).enableAppliancePlugin 启用时有效

<a id="//api/name/fillOpacity"></a>

### fillOpacity

```objc
@property (nonatomic, strong, readonly, nullable) NSNumber *fillOpacity
```

填充透明度。

#### Availability

2.16.112 取值范围为 [0.0, 1.0]，0 表示完全透明，1 表示完全不透明。 仅在 `` WhiteSdkConfiguration `.enableAppliancePlugin` 启用时有效。
