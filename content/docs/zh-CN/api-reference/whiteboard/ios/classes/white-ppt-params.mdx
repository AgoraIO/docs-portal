### useServerWrap

```objc
@property (nonatomic, assign) BOOL useServerWrap
```

动态 PPT 服务端排版功能的开启状态。

#### Availability

2.12.25

- `YES`：（默认）开启。
- `NO`：关闭。

**Note：**

2021-02-10 之后转换的动态 PPT 支持服务端排版功能，可以确保不同平台排版一致。
