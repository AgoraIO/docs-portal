<a id="overview"></a>

设置白板视角边界的缩放模式和缩放比例。

## Methods

<a id="//api/name/initWithContentMode:"></a>

### initWithContentMode:

```objc
- (instancetype)initWithContentMode:(WhiteContentMode)scaleMode
```

初始化一个 [WhiteContentMode](/zh-CN/api-reference/whiteboard/ios/constants/white-content-mode) 对象。

#### Parameters

| Name | Description |
| --- | --- |
| `scaleMode` | 视角边界的缩放模式，缩放比例默认值为 1.0，即保持视角边界的原始大小。详见 [WhiteContentMode](/zh-CN/api-reference/whiteboard/ios/constants/white-content-mode)。 |

#### Returns

初始化的 [WhiteContentMode](/zh-CN/api-reference/whiteboard/ios/constants/white-content-mode) 对象。

<a id="//api/name/contentMode"></a>

### contentMode

```objc
@property (nonatomic, assign, readonly) WhiteContentMode contentMode
```

视角边界的缩放模式和缩放比例。详见 [WhiteContentMode](/zh-CN/api-reference/whiteboard/ios/constants/white-content-mode)。

<a id="//api/name/scale"></a>

### scale

```objc
@property (nonatomic, assign) CGFloat scale
```

视角边界的缩放比例。只有当 `scaleMode` 的值为 `WhiteContentModeScale`、 `WhiteContentModeAspectFitScale`、 `WhiteContentModeAspectFillScale` 时设置生效。

<a id="//api/name/space"></a>

### space

```objc
@property (nonatomic, assign) CGFloat space
```

视角边界的缩放模式。只有当 `scaleMode` 为 `WhiteContentModeAspectFitSpace` 时设置生效。
