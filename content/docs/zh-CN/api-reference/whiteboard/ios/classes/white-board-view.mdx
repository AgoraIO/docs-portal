<a id="//api/name/disableKeyboardHandler"></a>

### disableKeyboardHandler

```objc
@property (nonatomic, assign) BOOL disableKeyboardHandler
```

是否禁用 SDK 本身对键盘偏移的处理。

#### Discussion

- `YES`:禁用 SDK 本身对键盘偏移的处理。
- `NO`:启用 SDK 本身对键盘偏移的处理。
