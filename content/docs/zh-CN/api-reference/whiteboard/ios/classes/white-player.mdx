### timeInfo

<a id="//api/name/play"></a>

### play

```objc
- (void)play
```

开始白板回放。

<a id="//api/name/pause"></a>

### pause

```objc
- (void)pause
```

暂停白板回放。

<a id="//api/name/stop"></a>

### stop

```objc
- (void)stop
```

停止白板回放。

#### Discussion

**Note:**

白板回放停止后， `WhitePlayer` 资源会被释放。如果想要重新播放，需要重新初始化 `WhitePlayer` 对象。

<a id="//api/name/playbackSpeed"></a>

### playbackSpeed

```objc
@property (nonatomic, assign) CGFloat playbackSpeed
```

白板回放的播放倍速，如 1.0、1.5、2.0 倍速，默认为 1.0。 回放暂停时，返回值不会为 0。

<a id="//api/name/seekToScheduleTime:"></a>

### seekToScheduleTime:

```objc
- (void)seekToScheduleTime:(NSTimeInterval)beginTime
```

设置白板回放的起始播放位置。

#### Parameters

| Name | Description |
| --- | --- |
| `beginTime` | 开始播放位置（秒） |

#### Discussion

白板回放的起始时间点为 0，成功调用该方法后，白板回放会在指定位置开始播放。

## Asynchronous Methods

<a id="//api/name/getPhaseWithResult:"></a>

### getPhaseWithResult:

```objc
- (void)getPhaseWithResult:(void ( ^ ) ( WhitePlayerPhase phase ))result
```

获取白板回放的阶段。

#### Parameters

| Name | Description |
| --- | --- |
| `result` | 回调。返回白板回放的阶段，详见 [WhitePlayerPhase](/zh-CN/api-reference/whiteboard/ios/constants/white-player-phase)。 |

#### Discussion

在 `WhitePlayer` 生命周期内，你可以调用该方法获取白板回放当前所处的阶段。其中初始状态为 `WhitePlayerPhaseWaitingFirstFrame`，表示正在等待白板回放的第一帧。

<a id="//api/name/getPlayerStateWithResult:"></a>

### getPlayerStateWithResult:

```objc
- (void)getPlayerStateWithResult:(void ( ^ ) ( WhitePlayerState *_Nullable state ))result
```

获取白板回放的状态。

#### Parameters

| Name | Description |
| --- | --- |
| `result` | 回调。返回白板回放的状态，详见 [WhitePlayerState](/zh-CN/api-reference/whiteboard/ios/classes/white-player-state)。 |

#### Discussion

如果白板回放的阶段处于 `WhitePlayerPhaseWaitingFirstFrame`，则该方法返回 `null`。

<a id="//api/name/getPlayerTimeInfoWithResult:"></a>

### getPlayerTimeInfoWithResult:

```objc
- (void)getPlayerTimeInfoWithResult:(void ( ^ ) ( WhitePlayerTimeInfo *info ))result
```

获取白板回放的时间信息。

#### Parameters

| Name | Description |
| --- | --- |
| `result` | 回调。返回白板回放的时间信息，详见 [WhitePlayerTimeInfo](/zh-CN/api-reference/whiteboard/ios/classes/white-player-time-info)。 |

#### Discussion

该方法获取的时间信息，包含当前的播放进度，回放的总时长，以及回放的起始时间，单位为秒。

<a id="//api/name/getPlaybackSpeed:"></a>

### getPlaybackSpeed:

```objc
- (void)getPlaybackSpeed:(void ( ^ ) ( CGFloat speed ))result
```

设置白板回放的倍速。

#### Parameters

| Name | Description |
| --- | --- |
| `result` | 回调。返回白板回放的倍速。 |

#### Discussion

该方法获取的是播放倍速，如 1.0、1.5、2.0 倍速。因此回放暂停时，返回值也不会为 0。
