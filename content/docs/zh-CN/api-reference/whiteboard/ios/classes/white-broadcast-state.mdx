<a id="overview"></a>

视角状态，包含视角为主播模式的用户信息。

## Methods

<a id="//api/name/viewMode"></a>

### viewMode

```objc
@property (nonatomic, assign, readonly) WhiteViewMode viewMode
```

主播模式用户的视角模式。

<a id="//api/name/broadcasterId"></a>

### broadcasterId

```objc
@property (nonatomic, assign, nullable, readonly) NSNumber *broadcasterId
```

主播模式用户在房间中的用户 ID。详见 [WhiteBroadcasterInformation](/zh-CN/api-reference/whiteboard/ios/classes/white-broadcaster-information)。

#### Availability

2.4.7

<a id="//api/name/broadcasterInformation"></a>

### broadcasterInformation

```objc
@property (nonatomic, strong, nullable, readonly) WhiteBroadcasterInformation *broadcasterInformation
```

主播模式用户的用户信息。详见 [WhiteBroadcasterInformation](/zh-CN/api-reference/whiteboard/ios/classes/white-broadcaster-information)。
