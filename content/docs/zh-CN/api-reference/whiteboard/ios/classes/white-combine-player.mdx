<a id="overview"></a>

同步本地视频播放器与白板回放播放器的播放状态。某一个进入缓冲状态，另一个则暂停等待。

<a id="//api/name/seekToTime:completionHandler:"></a>

### seekToTime:completionHandler:

```objc
- (void)seekToTime:(CMTime)time completionHandler:(void ( ^ ) ( BOOL finished ))completionHandler
```

定位到视频指定位置。

#### Parameters

| Name | Description |
| --- | --- |
| `time` | 时间长度（s)。 |
| `completionHandler` | 方法调用结果： `YES`：调用已经完成。 `No`：调用未完成。 |

#### Discussion

定位到本地视频播放器的指定位置后，你可以调用该方法，将白板回放播放器调整到对应位置。

<a id="//api/name/updateWhitePlayerPhase:"></a>

### updateWhitePlayerPhase:

```objc
- (void)updateWhitePlayerPhase:(WhitePlayerPhase)phase
```

更新白板回放播放器的播放状态。

#### Parameters

| Name | Description |
| --- | --- |
| `phase` | [WhitePlayer](/zh-CN/api-reference/whiteboard/ios/classes/white-player) 的播放状态。 **Note:** 在该回调中，需要主动调用 [WhitePlayerPhase](/zh-CN/api-reference/whiteboard/ios/constants/white-player-phase) 方法，将状态同步给 [WhitePlayer](/zh-CN/api-reference/whiteboard/ios/classes/white-player)。 |

#### Discussion

当白板回放播放器的播放状态发生变化时，White Player 会触发该回调，向你报告板回放播放器的播放状态。
