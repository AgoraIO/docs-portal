<a id="overview"></a>

白板图片信息。

## Methods

<a id="//api/name/initWithFrame:"></a>

### initWithFrame:

```objc
- (instancetype)initWithFrame:(CGRect)frame
```

设置图片框架并初始化 `WhiteImageInformation` 对象。

#### Parameters

| Name | Description |
| --- | --- |
| `frame` | 图片框架。包括宽高以及左上角坐标（白板坐标系内）。 |

#### Returns

初始化的 `WhiteImageInformation` 对象。

<a id="//api/name/initWithSize:"></a>

### initWithSize:

```objc
- (instancetype)initWithSize:(CGSize)size
```

设置图片尺寸并初始化 `WhiteImageInformation` 对象。

#### Parameters

| Name | Description |
| --- | --- |
| `size` | 图片尺寸。 |

#### Returns

初始化的 `WhiteImageInformation` 对象。

<a id="//api/name/initWithUuid:frame:"></a>

### initWithUuid:frame:

```objc
- (instancetype)initWithUuid:(NSString *)uuid frame:(CGRect)frame
```

设置图片的 UUID 和框架并初始化 `WhiteImageInformation` 对象。

#### Parameters

| Name | Description |
| --- | --- |
| `uuid` | 图片的 UUID，即图片在互动白板实时房间中的唯一标识符。 |
| `frame` | 图片框架。包括宽高以及左上角坐标（白板坐标系内）。 |

#### Returns

初始化的 `WhiteImageInformation` 对象。

<a id="//api/name/uuid"></a>

### uuid

```objc
@property (nonatomic, copy) NSString *uuid
```

图片的 UUID，即图片在互动白板实时房间中的唯一标识符。

<a id="//api/name/centerX"></a>

### centerX

```objc
@property (nonatomic, assign) CGFloat centerX
```

图片的中心在世界坐标系（以白板初始化时的中心点为原点的坐标系）中的横向坐标。

<a id="//api/name/centerY"></a>

### centerY

```objc
@property (nonatomic, assign) CGFloat centerY
```

图片的中心在世界坐标系（以白板初始化时的中心点为原点的坐标系）中的纵向坐标。

<a id="//api/name/width"></a>

### width

```objc
@property (nonatomic, assign) CGFloat width
```

图片的宽度，单位为像素。

<a id="//api/name/height"></a>

### height

```objc
@property (nonatomic, assign) CGFloat height
```

图片的高度，单位为像素。

<a id="//api/name/locked"></a>

### locked

```objc
@property (nonatomic, assign) BOOL locked
```

是否锁定图片。 图片被锁定后，用户无法移动或缩放图片。

#### Discussion

- YES：锁定。
- NO：不锁定。
