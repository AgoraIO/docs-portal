<a id="overview"></a>

白板窗口参数。

## Methods

<a id="//api/name/fullscreen"></a>

### fullscreen

```objc
@property (nonatomic, assign) BOOL fullscreen
```

是否开启窗口最大化，开启后添加的窗口将全屏展示。 默认值为 `NO`。

<a id="//api/name/overwriteStyles"></a>

### overwriteStyles

```objc
@property (nonatomic, copy) NSString *overwriteStyles
```

使用 CSS 覆盖白板窗口样式。
