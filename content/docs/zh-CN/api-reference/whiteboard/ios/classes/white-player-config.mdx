## Other Methods

<a id="//api/name/initWithRoom:roomToken:"></a>

### initWithRoom:roomToken:

```objc
- (instancetype)initWithRoom:(NSString *)roomUuid roomToken:(NSString *)roomToken
```

设置 Room Token 并初始化 `WhitePlayerConfig` 对象。

#### Parameters

| Name | Description |
| --- | --- |
| `roomUuid` | 房间 UUID，即房间唯一标识符。 |
| `roomToken` | 用于鉴权的 Room Token。 |

#### Returns

初始化的 `WhitePlayerConfig` 对象

<a id="//api/name/region"></a>

### region

```objc
@property (nonatomic, strong, nullable) WhiteRegionKey region
```

待回放的互动白板房间所在的数据中心。

#### Discussion

数据中心包括：

- `WhiteRegionCN`：中国杭州。该数据中心为其他数据中心服务区未覆盖的地区提供服务。
- `WhiteRegionUS`：美国硅谷。该数据中心为北美洲、南美洲地区提供服务。
- `WhiteRegionIN`：印度孟买。该数据中心为印度地区提供服务。
- `WhiteRegionSG`：新加坡。该数据中心为新加坡、东亚、东南亚地区提供服务。
- `WhiteRegionEU`：欧洲（法兰克福）。该数据中心为欧洲地区提供服务。

#### Availability

2.11.0

<a id="//api/name/beginTimestamp"></a>

### beginTimestamp

```objc
@property (nonatomic, strong, nullable) NSNumber *beginTimestamp
```

白板回放的起始时间。

#### Discussion

Unix 时间戳（毫秒），表示回放的起始 UTC 时间。例如， `1615370614269` 表示 2021-03-10 18:03:34 GMT+0800。

<a id="//api/name/duration"></a>

### duration

```objc
@property (nonatomic, strong, nullable) NSNumber *duration
```

白板回放的持续时长（秒）。如果没有设置，回放会从起始时间一直持续到退出房间。

<a id="//api/name/mediaURL"></a>

### mediaURL

```objc
@property (nonatomic, strong, nullable) NSString *mediaURL
```

白板回放的音频地址。

#### Discussion

**Note:**

- 即使传入视频地址，也只会播放音频部分。
- 如需显示视频画面，请使用 [WhiteCombinePlayer](/zh-CN/api-reference/whiteboard/ios/classes/white-combine-player) 方法。

<a id="//api/name/step"></a>

### step

```objc
@property (nonatomic, strong) NSNumber *step
```

SDK 回调播放进度的频率（秒）。默认为 0.5 秒。
