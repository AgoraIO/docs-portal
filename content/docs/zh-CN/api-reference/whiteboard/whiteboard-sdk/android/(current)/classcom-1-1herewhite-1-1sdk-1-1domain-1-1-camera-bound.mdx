## 详细描述

[`CameraBound`](/zh-CN/api-reference/whiteboard/whiteboard-sdk/android/classcom-1-1herewhite-1-1sdk-1-1domain-1-1-camera-bound) 类，用于设置视角边界。

视角边界指白板场景内，用户可以移动视角的范围。当视角超出视角边界时，视角会被拉回。

2.5.0
:::

### setDamping()

| void com.herewhite.sdk.domain.CameraBound.setDamping | ( | Double | *damping* | ) |  |
| --- | --- | --- | --- | --- | --- |

设置用户将视角移出视角边界时感受到的阻力。

<ParameterList title="参数">
<Parameter name="damping">

阻力大小，取值范围为 [0.0,1.0]。取值越大，用户感受到的阻力越大。

- `0.0`: 用户将视角移出视角边界时，完全感受不到阻力，但当其手指离开屏幕时，视角会恢复到原位。
- `1.0`: 用户完全无法将视角移出视角边界。

</Parameter>
</ParameterList>
