### setEffectSoundId()

<ApiSignature>

void setEffectSoundId(int soundId, int state)

</ApiSignature>

设置音乐文件播放状态。
&lt;p&gt;
你需要在 Agora RTC SDK 触发的 `rtcEngine.onAudioEffectStateChanged` 回调中调用该方法，
将音乐文件播放状态传递给白板中的 PPT。PPT 根据收到的音频播放状态判断是否显示画面，以确保音画同步。
&lt;/p&gt;
&lt;strong&gt;注意：&lt;/strong&gt;如果你使用的实时音视频 SDK 没有该状态回调方法，会导致播放的 PPT 音画不同步。

#### 参数

<ParameterList title="参数">
<Parameter name="soundId">

播放的音乐 ID。

</Parameter>
<Parameter name="state">

音乐文件播放状态： &lt;ul&gt; &lt;li&gt;810：开始播放音乐&lt;/li&gt; &lt;li&gt;811：音乐被暂停&lt;/li&gt; &lt;li&gt;813：音乐被停止&lt;/li&gt; &lt;li&gt;814：音乐播放失败&lt;/li&gt; &lt;/ul&gt;

</Parameter>
</ParameterList>
