开启/关闭图片拦截替换功能。

该方法可以开启或关闭图片拦截功能。 如果开启，在图片实际插入白板前，SDK 会拦截图片并触发 [`urlInterrupter`](/zh-CN/api-reference/whiteboard/whiteboard-sdk/android/interfacecom-1-1herewhite-1-1sdk-1-1-common-callback#a28839222c6e4b44a001da833300991d4) 回调，你可以在该回调中替换图片的地址。

:::info[注解]
Agora 建议不要开启图片拦截功能，否则会频繁触发回调。
:::

<ParameterList title="参数">
<Parameter name="enableInterrupterAPI">

是否开启图片拦截和替换功能：

- `true`：开启。
- `false`：（默认）关闭。

</Parameter>
</ParameterList>
