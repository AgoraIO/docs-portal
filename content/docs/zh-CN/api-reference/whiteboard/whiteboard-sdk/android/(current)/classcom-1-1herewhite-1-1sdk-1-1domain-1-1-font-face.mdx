<ApiSignature>

FontFace(String name, String src)

</ApiSignature>

<ParameterList title="参数">
<Parameter name="name">

</Parameter>
<Parameter name="src">

字体文件的地址，需要和 CSS 中 `src` 字段的值对应。支持的格式为 `url()`，表示指向远程字体文件位置，例如，`url("https://white-pan.oss-cn-shanghai.aliyuncs.com/Pacifico-Regular.ttf")`。

</Parameter>
</ParameterList>
