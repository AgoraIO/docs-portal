### setEnableAssetsHttps()

<ApiSignature>

WhiteboardViewOptions setEnableAssetsHttps(boolean enableAssetsHttps)

</ApiSignature>

设置是否启用 HTTPS 资源加载。
&lt;p&gt;
WhiteboardView 默认使用 file 方式加载内置白板资源，这是最稳定的运行模式。
对于需要突破 file 协议限制的特殊场景，可通过本方法显式启用
基于 WebViewAssetLoader 的 HTTPS 资源加载方案。

#### 参数

<ParameterList title="参数">
<Parameter name="enableAssetsHttps">

是否启用 HTTPS 资源加载。

</Parameter>
</ParameterList>

<h4 data-toc-hidden="true" id={"返回值-1"}>返回值</h4>

当前 WhiteboardViewOptions 实例，支持链式调用。
