## 详细描述

[`RoomMember`](/zh-CN/api-reference/whiteboard/whiteboard-sdk/android/classcom-1-1herewhite-1-1sdk-1-1domain-1-1-room-member) 类，用于获取实时房间内互动模式（具有读写权限）用户信息。

### 注解

该类仅适用于互动模式的用户。订阅模式的用户不属于房间成员。
