## 类成员变量说明

<a id="af61dc3e90197983fa27df3eb46ecfe0f"></a>

### RESOURCE_ERROR

| com.herewhite.sdk.domain.SlideErrorType.RESOURCE_ERROR |
| --- |

ResourceError: 当 PPT 依赖的远程资源（如 JSON、PNG）不可用时触发， 触发后当前页无法交互。 恢复手段：重新渲染当前页或者跳转到下一页。

<a id="af7f42460d0b1d5dd1ab2e8524e6fc5b4"></a>

### RUNTIME_ERROR

| com.herewhite.sdk.domain.SlideErrorType.RUNTIME_ERROR |
| --- |

RuntimeError: 未知的异常导致触发，触发后当前页无法交互。 恢复手段：跳转到下一页。

<a id="a7344601dbf2533c303ac979d4501695b"></a>

### RUNTIME_WARN

| com.herewhite.sdk.domain.SlideErrorType.RUNTIME_WARN |
| --- |

RuntimeWarn: 动画过程中出现未知的警告，触发后动画当前帧表现异常， 但不影响下一帧和页面交互。 恢复手段：无需特殊处理。

<a id="a2d9829c7de2af4cd855165bd13470b2c"></a>

### CANVAS_CRASH

| com.herewhite.sdk.domain.SlideErrorType.CANVAS_CRASH |
| --- |

CanvasCrash: 由于内存不足，或者 canvas 被意外移除（在未调用 slide.destroy() 的情况下移除 canvas 元素） 导致触发，触发后 canvas 元素白屏。 恢复手段：刷新网页，或者销毁 slide 对象并重新创建。
