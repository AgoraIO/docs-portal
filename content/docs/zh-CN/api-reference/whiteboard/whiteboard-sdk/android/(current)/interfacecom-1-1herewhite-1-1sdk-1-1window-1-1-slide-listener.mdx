### slideUrlInterrupter()

| void com.herewhite.sdk.window.SlideListener.slideUrlInterrupter | ( | String | *sourceUrl*, |
| --- | --- | --- | --- |
|  |  | ResultCaller&lt; String &gt; | *resultCaller* |
|  | ) |  |  |

拦截 PPT 资源 URL 回调。

:::info[自从]
2.16.59
:::

该回调默认禁用。你可以在初始化白板 SDK 时，通过 [`WhiteSdkConfiguration#setEnableSlideInterrupterAPI`](/zh-CN/api-reference/whiteboard/whiteboard-sdk/android/classcom-1-1herewhite-1-1sdk-1-1-white-sdk-configuration#aa056117366231f9c6a94e4c3c8e69ebe) setEnableSlideInterrupterAPI\}(true) 方法开启。

开启后，在 PPT 资源加载时，SDK 会触发该回调，报告资源的原 URL 地址。你需要将替换后的 URL 通过 `resultCaller` 回调到 SDK。

:::info[注解]
不要在此方法中作过多耗时操作。
:::

<h4 data-toc-hidden="true" id={"参数"}>参数</h4>

| sourceUrl | 原 URL 地址。 |
| --- | --- |
| resultCaller | 回调替换后的 URL。 |
