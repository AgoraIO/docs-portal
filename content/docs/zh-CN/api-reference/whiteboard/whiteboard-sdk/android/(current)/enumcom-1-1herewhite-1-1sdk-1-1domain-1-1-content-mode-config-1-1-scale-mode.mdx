## 详细描述

视角边界的缩放模式。

## 类成员变量说明

<a id="a9f3f82766f8757375663b781e33271fc"></a>

### CENTER

<ApiSignature>

com.herewhite.sdk.domain.ContentModeConfig.ScaleMode.CENTER

</ApiSignature>

`CENTER`：（默认）基于设置的 `scale` 缩放视角边界。

<a id="a7a03f55ed45ced75052f7a3667e46d80"></a>

### CENTER_INSIDE

<ApiSignature>

com.herewhite.sdk.domain.ContentModeConfig.ScaleMode.CENTER_INSIDE

</ApiSignature>

`CENTER_INSIDE`：等比例缩放视角边界，使视角边界的长边正好顶住与其垂直的屏幕的两边，以保证在屏幕上完整展示视角边界。

<a id="a7d2e1926ff623f1fd9f4dc9fc075b5eb"></a>

### CENTER_INSIDE_SCALE

<ApiSignature>

com.herewhite.sdk.domain.ContentModeConfig.ScaleMode.CENTER_INSIDE_SCALE

</ApiSignature>

`CENTER_INSIDE_SCALE`：等比例缩放视角边界，使视角边界的长边正好顶住与其垂直的屏幕的两边，以保证在屏幕上完整展示视角边界；在此基础上，再将视角边界缩放指定的倍数。

<a id="a05bbde7b7d73cf9be56e0814a23c6989"></a>

### CENTER_INSIDE_SPACE

<ApiSignature>

com.herewhite.sdk.domain.ContentModeConfig.ScaleMode.CENTER_INSIDE_SPACE

</ApiSignature>

`CENTER_INSIDE_SPACE`：等比例缩放视角边界，使视角边界的长边正好顶住与其垂直的屏幕的两边；在此基础上，在视角边界的四周填充指定的空白空间。

### CENTER_CROP
