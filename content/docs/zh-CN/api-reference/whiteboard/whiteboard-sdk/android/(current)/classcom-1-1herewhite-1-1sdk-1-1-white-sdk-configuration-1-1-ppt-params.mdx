### isUseServerWrap()

<ApiSignature>

- `false`：关闭。

<a id="a21663a076e81bcbeedc8c23511b129ea"></a>

### setUseServerWrap()

<ApiSignature>

void setUseServerWrap(boolean useServerWrap)

</ApiSignature>

开启/关闭动态 PPT 服务端排版功能。

:::info[自从]
2.11.16
:::

自 2021 年 2 月 10 日起，将 PPTX 文件转换为 HTML 网页时，Agora Interactive 白板服务端支持对 PPTX 文件进行排版，以确保 PPTX 文件的文本在各个平台上的呈现保持一致。

:::info[注解]
Note: 自 2.12.27 版本起，`useServerWrap` 的默认值由 `false` 改为 `true`。
:::

<ParameterList title="参数">
<Parameter name="useServerWrap">

是否开启服务端排版功能：

- `true`：（默认）开启。
- `false`：关闭。

</Parameter>
</ParameterList>
