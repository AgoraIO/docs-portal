<a id="a5166438d461fb863e631e0096cc24afe"></a>

### destroy()

```text
public void destroy()
```

销毁白板 WebView 并使当前异步操作失效。先等待 WhiteSdk.leaveRoom 完成，再在主线程销毁视图；销毁后不复用此 View。

## 公开成员函数

<a id="a553ca7dfe1e096b661e3512d0e38c8cf"></a>

### reload()

```text
public void reload()
```

重新加载白板 WebView，并开启新的视图生命周期。此前绑定的 SDK/Room 不可继续使用，应重新初始化和加入房间。
