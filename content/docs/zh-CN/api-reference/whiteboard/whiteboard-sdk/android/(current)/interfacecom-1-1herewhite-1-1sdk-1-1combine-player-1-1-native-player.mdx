### hasEnoughBuffer()

<ApiSignature>

boolean com.herewhite.sdk.combinePlayer.NativePlayer.hasEnoughBuffer()

</ApiSignature>

获取是否能够不经过缓冲，直接播放视频。

<h4 data-toc-hidden="true" id={"返回值"}>返回值</h4>

是否能够不经过缓冲，直接播放视频：

- `true`：可以不经过缓冲，直接播放视频。
- `false`：需要经过缓冲才能播放视频。
