### setupFontFaces()

<ApiSignature>

void com.herewhite.sdk.WhiteSdk.setupFontFaces([FontFace](/zh-CN/api-reference/whiteboard/whiteboard-sdk/android/classcom-1-1herewhite-1-1sdk-1-1domain-1-1-font-face)[] *fontFaces*)

</ApiSignature>

声明在本地白板中可用的字体。

:::info[自从]
2.11.2
:::

调用该方法声明的字体可用于显示 PPT 中的文字和白板工具输入的文字。

该方法和 [`loadFontFaces`](/zh-CN/api-reference/whiteboard/whiteboard-sdk/android/classcom-1-1herewhite-1-1sdk-1-1-white-sdk#a27f75d293d58992a1c9f3d6ae25ae9d9) 都可以声明在本地白板中可用的字体，区别是 `setupFontFaces` 没有回调，因为无法判断字体声明是否正确；`loadFontFaces` 会触发回调，报告每一种的预加载结果。

:::info[注解]
- 该方法只对本地白板生效，不影响远端白板的字体显示。

- 通过该方法声明的字体，只有当被使用时，才会触发下载。
- 不同的字体在不同设备上的渲染可能不同，例如，在某些设备上，要等字体加载完成后，才会渲染文字；而在另外一些设备上，会先使用默认的字体渲染文字，等指定的字体加载完毕后，再整体刷新。
- 每次调用该方法都会覆盖原来的字体声明。
- 请勿同时调用该方法和 `loadFontFaces` 方法。否则，无法预期行为。
:::

<Parameter name="fontFaces">

`FontFace` 实例，详见 [`FontFace`](/zh-CN/api-reference/whiteboard/whiteboard-sdk/android/classcom-1-1herewhite-1-1sdk-1-1domain-1-1-font-face)。

- 该方法只对本地白板生效，不影响远端白板的字体显示。
- 使用该方法预加载的字体，只有当该字体被使用时，才会触发下载。
- 不同的字体在不同设备上的渲染可能不同，例如，在某些设备上，要等字体加载完成后，才会渲染文字；而在另外一些设备上，会先使用默认的字体渲染文字，等指定的字体加载完毕后，再整体刷新。
- 通过该方法预加载的字体无法删除，每次调用都会在原来的基础上新增。
- 请勿同时调用该方法和 `setupFontFaces` 方法。否则，无法预期行为。
:::

<ParameterList title="参数">
<Parameter name="fontFaces">

指定的字体，详见 [`FontFace`](/zh-CN/api-reference/whiteboard/whiteboard-sdk/android/classcom-1-1herewhite-1-1sdk-1-1domain-1-1-font-face)。

</Parameter>
<Parameter name="loadPromise">

`Promise<JSONObject>` 接口实例，详见 [`Promise`](/zh-CN/api-reference/whiteboard/whiteboard-sdk/android/interfacecom-1-1herewhite-1-1sdk-1-1domain-1-1-promise)。你可以通过该接口获取 `loadFontFaces` 的调用结果：
