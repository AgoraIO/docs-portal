为满足不同的需求，声网互动白板提供如下两套客户端 SDK 供你选择：

:::warning[注意]
Fastboard SDK 与 Whiteboard SDK **不互通**，声网建议你根据自身需求从中选择一套使用。
:::

|  | Fastboard SDK | Whiteboard SDK |
| --- | --- | --- |
| SDK 介绍 | 互动白板新一代 SDK。Fastboard SDK 基于 Whiteboard SDK 开发，简化了 API，并提供核心功能的实现和默认 UI；此外，Fastboard SDK 还集成窗口管理器（[window-manager](https://github.com/netless-io/window-manager)）和开源插件库 [netless-app](https://github.com/netless-io/netless-app) 中的部分插件，方便开发者快速添加插件。 | 声网互动白板 PaaS 解决方案，提供丰富的数据和状态回调，支持高度自定义业务逻辑和 UI。 |
| 适用对象 | 适合开发资源有限、排期紧、需要快速上线在线互动教学场景且仍有定制需求的团队。 | 适合开发资源充足、定制化需求较高的团队。 |
| 开发成本 | 低 | 较高 |
| 特性支持 | 所有特性 | 所有特性 |
| 用户界面 | 声网提供默认的白板 UI，包括工具条、页面控制组件、视角控制组件、重做和撤销按钮等，并提供设置 UI 的 API。 | 客户自行实现所有 UI。 |
| 平台支持 | <Slot name="solution-compare-markdown-0-6-1" /> | <Slot name="solution-compare-markdown-0-6-2" /> |

<Slot for="solution-compare-markdown-0-6-1">

- Web: Chrome 58+ 或 Safari 11+ （macOS 10+）
- Android：Android 5.0（SDK API Level 21）及以上版本
- iOS：iOS 9.0 及以上版本，支持平台间互通

</Slot>

<Slot for="solution-compare-markdown-0-6-2">

- Web: Chrome 58+ 或 Safari 11+ （macOS 10+）
- Android：Android 5.0（SDK API Level 21）及以上版本
- iOS：iOS 9.0 及以上版本，支持平台间互通

</Slot>
