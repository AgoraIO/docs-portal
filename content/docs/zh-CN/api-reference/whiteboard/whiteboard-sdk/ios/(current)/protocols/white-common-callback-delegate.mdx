### `– sdkSetupFail:`

SDK 初始化失败回调。

<ApiSignature>

\- (void)sdkSetupFail:(NSError *)*error*

</ApiSignature>

<ParameterList title="Parameters">
<Parameter name="error">

错误信息。

</Parameter>
</ParameterList>

#### Availability

2.9.13

如果 SDK 初始化失败，调用加入实时房间或回放房间时会处于一直无响应状态，需要重新初始化 SDK。

SDK 初始化失败可能由以下原因导致：

- 初始化 SDK 时候，网络异常，导致获取配置信息失败。
- 传入了不合法的 App Identifier。

### `– customMessage:`

接收到网页发送的消息回调。

<ApiSignature>

\- (void)customMessage:(NSDictionary *)*dict*

</ApiSignature>

<ParameterList title="Parameters">
<Parameter name="dict">

字典格式的消息。只有当消息为字典格式时，本地用户才能收到。

</Parameter>
</ParameterList>

#### Discussion

消息回调包括：

- 字典格式的 iframe 数据
- 图片加载失败信息
- ppt 播放/暂停回调信息

当本地用户收到了网页（如 iframe 插件、动态 PPT）发送的消息时会触发该回调。

<a id="//api/name/logger:"></a>

### `– logger:`

获取 SDK 输出的本地调试日志。

<ApiSignature>

\- (void)logger:(NSDictionary *)*dict*

</ApiSignature>

<ParameterList title="Parameters">
<Parameter name="dict">

字典结构的日志消息，每条日志消息包含以下 key：

- `funName`：功能名称。
- `params`：具体的参数设置。

例如，`{"funName": "joinRoom", "params": {"isWritable": 1, "region": "cn-hz"}}`。

</Parameter>
</ParameterList>

#### Availability

v2.13.19

将 [WhiteSdkConfiguration](/zh-CN/api-reference/whiteboard/whiteboard-sdk/ios/classes/white-sdk-configuration) 类中 `log` 设为 `YES` 后，SDK 会触发该回调，返回 SDK 输出的本地调试日志。

如果你需要关闭该回调，可以将 `log` 设为 `NO`。

<a id="//api/name/startRecoveringFromMemoryIssues"></a>

### `– startRecoveringFromMemoryIssues`

白板 SDK 即将开始恢复回调。

<ApiSignature>

\- (void)startRecoveringFromMemoryIssues

</ApiSignature>

#### Discussion

当白板 SDK 因内存不足而崩溃时会触发该回调。
目前只有实时房间会触发该回调。该回调最多会触发三次，超过三次会收到 -500 错误码。

<a id="//api/name/endRecoveringFromMemoryIssues:"></a>

### `– endRecoveringFromMemoryIssues:`

白板 SDK 完成了一次恢复回调。

<ApiSignature>

\- (void)endRecoveringFromMemoryIssues:(BOOL)*success*

</ApiSignature>

<ParameterList title="Parameters">
<Parameter name="success">

本次恢复是否成功。

</Parameter>
</ParameterList>

#### Discussion

当白板 SDK 因内存不足而崩溃后，SDK 完成了一次恢复操作后会触发该回调。
如果恢复失败，SDK 不会主动继续重连。
