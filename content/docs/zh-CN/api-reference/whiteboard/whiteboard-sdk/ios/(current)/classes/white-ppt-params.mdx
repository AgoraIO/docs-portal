## Overview

设置动态 PPT 参数。

<a id="//api/name/scheme"></a>

### `scheme`

`scheme`：更改动态 PPT 请求时的请求协议，可以将 [https://www.example.com/1.pptx](https://www.example.com/1.pptx) 更改成 `scheme://www.example.com/1.pptx`。

<ApiSignature>

@property (nonatomic, copy, nullable) NSString *scheme API_AVAILABLE (ios (11.0))

</ApiSignature>

#### Discussion

该属性配合 iOS 11 WebKit 中 `WKWebViewConfiguration` 类的 `setURLSchemeHandler:forURLScheme:` 方法，可以对 PPT 的资源进行拦截，选择使用本地资源。

### `useServerWrap`

动态 PPT 服务端排版功能的开启状态。

<ApiSignature>

@property (nonatomic, assign) BOOL useServerWrap

</ApiSignature>

#### Availability

2.12.25

- `YES`：（默认）开启。
- `NO`：关闭。

**Note：**

2021-02-10 之后转换的动态 PPT 支持服务端排版功能，可以确保不同平台排版一致。
