## 初始化配置

```text
WhiteSdkConfiguration *config = [[WhiteSdkConfiguration alloc] initWithApp:appIdentifier];
config.useMultiViews = YES;
config.enableAppliancePlugin = YES;
```

## 课件与扩展

originSize、统一页面命令、页状态、forceMaximized、lazy setup 和 LRU 缓存通过本端公开模型设置；页码从 1 开始，scale 为相对适配尺寸。背景来源为 appliance，查询/恢复通过 WhiteSDK；普通图片使用 WhiteRoom.insertImage\:src:。通过 Native delegate 接收加载、初始化和页面事件。
