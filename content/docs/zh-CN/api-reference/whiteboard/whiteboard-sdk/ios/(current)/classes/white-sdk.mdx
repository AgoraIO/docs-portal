### `– setupFontFaces:`

声明在本地白板中可用的字体。

| --- | --- |

#### Availability

2.11.3

调用该方法声明的字体可用于显示 PPT 中的文字和工具输入的文字。

该方法和 [loadFontFaces](/zh-CN/api-reference/whiteboard/whiteboard-sdk/ios/classes/white-sdk#//api/name/loadFontFaces:completionHandler:) 都可以声明在本地白板中可用的字体，区别是 `setupFontFaces` 没有回调，因为无法判断字体声明是否正确；[loadFontFaces](/zh-CN/api-reference/whiteboard/whiteboard-sdk/ios/classes/white-sdk#//api/name/loadFontFaces:completionHandler:) 会触发回调，报告每一种的预加载结果。

**Note:**

- 该方法只对本地白板生效，不影响远端白板的字体显示。
- 通过该方法声明的字体，只有当被使用时，才会触发下载。
- 不同的字体在不同设备上的渲染可能不同，例如，在某些设备上，要等字体加载完成后，才会渲染文字；而在另外一些设备上，会先使用默认的字体渲染文字，等指定的字体加载完毕后，再整体刷新。
- 每次调用该方法都会覆盖原来的字体声明。
- 请勿同时调用该方法和 [loadFontFaces](/zh-CN/api-reference/whiteboard/whiteboard-sdk/ios/classes/white-sdk#//api/name/loadFontFaces:completionHandler:) 方法。否则，无法预期行为。

- 通过该方法预加载的字体无法删除，每次调用都会在原来的基础上新增。
- 请勿同时调用该方法和 [setupFontFaces](/zh-CN/api-reference/whiteboard/whiteboard-sdk/ios/classes/white-sdk#//api/name/setupFontFaces:) 方法。否则，无法预期行为。
