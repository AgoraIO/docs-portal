### `+ prepareWhiteConnectionForAppId:region:expireSeconds:attachingSuperView:`

提前选择最佳接入域名，用于加快用户首次连接速度。

`+ (void)prepareWhiteConnectionForAppId:(NSString *)*appId* region:(WhiteRegionKey)*region* expireSeconds:(NSNumber *_Nullable)*expireSeconds* attachingSuperView:(UIView *_Nullable)*superView*`

<ParameterList title="Parameters">
<Parameter name="appId">

白板项目的唯一标识，详见[获取白板项目的 App Identifier](/zh-CN/realtime-media/whiteboard/whiteboard-sdk/build/setup-and-access/enable-service)。

</Parameter>
<Parameter name="region">

需要选择的数据中心。可选值包括：
 - `WhiteRegionCN`：中国杭州。该数据中心为其他数据中心服务区未覆盖的地区提供服务。
 - `WhiteRegionUS`：美国硅谷。该数据中心为北美洲、南美洲地区提供服务。
 - `WhiteRegionIN`：印度孟买。该数据中心为印度地区提供服务。
 - `WhiteRegionSG`：新加坡。该数据中心为新加坡、东亚、东南亚地区提供服务。
 - `WhiteRegionEU`：欧洲（法兰克福）。该数据中心为欧洲地区提供服务。

</Parameter>
<Parameter name="expireSeconds">

数据缓存时间 (s)，可为空，默认为 24 小时。

</Parameter>
<Parameter name="superView">

挂载的父视图，可为空，默认为 `UIApplication.shared.keyWindow`。

</Parameter>
</ParameterList>

#### Discussion

声网建议在加入白板房间前调用该方法，例如设备检测页、白板房间列表页等，有助于提升加入白板房间的连接速度。

### `– setupFontFaces:`

声明在本地白板中可用的字体。

`- (void)setupFontFaces:(NSArray<WhiteFontFace*> *)*fontFaces*`

<ParameterList title="Parameters">

</ParameterList>

#### Availability

2.11.3

调用该方法声明的字体可用于显示 PPT 中的文字和工具输入的文字。

该方法和 [loadFontFaces](/zh-CN/api-reference/whiteboard/whiteboard-sdk/ios/classes/white-sdk#//api/name/loadFontFaces:completionHandler:) 都可以声明在本地白板中可用的字体，区别是 `setupFontFaces` 没有回调，因为无法判断字体声明是否正确；[loadFontFaces](/zh-CN/api-reference/whiteboard/whiteboard-sdk/ios/classes/white-sdk#//api/name/loadFontFaces:completionHandler:) 会触发回调，报告每一种的预加载结果。

**Note:**

- 该方法只对本地白板生效，不影响远端白板的字体显示。
- 通过该方法声明的字体，只有当被使用时，才会触发下载。
- 不同的字体在不同设备上的渲染可能不同，例如，在某些设备上，要等字体加载完成后，才会渲染文字；而在另外一些设备上，会先使用默认的字体渲染文字，等指定的字体加载完毕后，再整体刷新。
- 每次调用该方法都会覆盖原来的字体声明。
- 请勿同时调用该方法和 [loadFontFaces](/zh-CN/api-reference/whiteboard/whiteboard-sdk/ios/classes/white-sdk#//api/name/loadFontFaces:completionHandler:) 方法。否则，无法预期行为。

- 使用该方法预加载的字体，只有当该字体被使用时，才会触发下载。
- 不同的字体在不同设备上的渲染可能不同，例如，在某些设备上，要等字体加载完成后，才会渲染文字；而在另外一些设备上，会先使用默认的字体渲染文字，等指定的字体加载完毕后，再整体刷新。
- 通过该方法预加载的字体无法删除，每次调用都会在原来的基础上新增。
- 请勿同时调用该方法和 [setupFontFaces](/zh-CN/api-reference/whiteboard/whiteboard-sdk/ios/classes/white-sdk#//api/name/setupFontFaces:) 方法。否则，无法预期行为。
