### `– setupFontFaces:`

<ApiSignature>

\- (void)setupFontFaces:(NSArray &lt;WhiteFontFace *&gt;*)fontFaces;

</ApiSignature>

声明在本地白板中可用的字体。

Declared in SDK/WhiteSDK.h

#### 版本

2.11.3

 调用该方法声明的字体可用于显示 PPT 中的文字和工具输入的文字。

 该方法和 [loadFontFaces](#//api/name/loadFontFaces:completionHandler:) 都可以声明在本地白板中可用的字体，区别是 [setupFontFaces](#//api/name/setupFontFaces:) 没有回调，因为无法判断字体声明是否正确；loadFontFaces 会触发回调，报告每一种的预加载结果。

*Note:**

 - 该方法只对本地白板生效，不影响远端白板的字体显示。
 - 通过该方法声明的字体，只有当被使用时，才会触发下载。
 - 不同的字体在不同设备上的渲染可能不同，例如，在某些设备上，要等字体加载完成后，才会渲染文字；而在另外一些设备上，会先使用默认的字体渲染文字，等指定的字体加载完毕后，再整体刷新。
 - 每次调用该方法都会覆盖原来的字体声明。
 - 请勿同时调用该方法和 [loadFontFaces](#//api/name/loadFontFaces:completionHandler:) 方法。否则，无法预期行为。

#### 参数

| `fontFaces` | 字体配置文件，详见 [WhiteFontFace](/zh-CN/api-reference/whiteboard/whiteboard-sdk/ios/classes/white-font-face)。 |
| --- | --- |

 该方法和 [setupFontFaces](#//api/name/setupFontFaces:) 都可以声明在本地白板中可用的字体，区别是 [setupFontFaces](#//api/name/setupFontFaces:) 没有回调，因为无法判断字体声明是否正确；[loadFontFaces](#//api/name/loadFontFaces:completionHandler:) 会触发回调，报告每一种的预加载结果。

 - 该方法只对本地白板生效，不影响远端白板的字体显示。
