## Overview

设置白板视角边界的缩放模式和缩放比例。

<a id="tasks"></a>

<a id="//api/name/initWithContentMode:"></a>

### `– initWithContentMode:`

初始化一个 [`WhiteContentMode`](/zh-CN/api-reference/whiteboard/whiteboard-sdk/ios/constants/white-content-mode) 对象。

<ApiSignature>

\- (instancetype)initWithContentMode:(WhiteContentMode)*scaleMode*

</ApiSignature>

<ParameterList title="Parameters">
<Parameter name="scaleMode">

视角边界的缩放模式，缩放比例默认值为 1.0，即保持视角边界的原始大小。详见 [WhiteContentMode](/zh-CN/api-reference/whiteboard/whiteboard-sdk/ios/constants/white-content-mode)。

</Parameter>
</ParameterList>
