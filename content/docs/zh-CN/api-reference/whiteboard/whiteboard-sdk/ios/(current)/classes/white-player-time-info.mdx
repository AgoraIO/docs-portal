### `beginTimestamp`

`@property (nonatomic, assign, readonly) NSTimeInterval beginTimestamp`

#### Discussion

UTC 时间戳（秒），你需要自行转换为 UTC 时间。

例如，如果返回 `1615370614269`，表示的 UTC 时间为 2021-03-10 18:03:34 GMT+0800。
