## 变量说明

<a id="add13438cf76753815480b3c747bf1d45"></a>

### maxRetries

```text
maxRetries?: number
```

背景图片重试次数：-1 表示无限重试，或整数 0~10；默认 3。

<a id="a6a65e183f864ad6582555a4ce790face"></a>

### timeoutMs

```text
timeoutMs?: number
```

背景图片单次加载超时，1000~120000 毫秒；默认 15000。

<a id="a63578ce1f40db667ba209d2a9e443cdd"></a>

### retryIntervalMs

```text
retryIntervalMs?: number
```

背景图片重试间隔，0~30000 毫秒；默认 1000。
