## 变量说明

<a id="a9b9ea13a1c1b2e9deb481a38232ceba3"></a>

### enableScale

```text
enableScale?: boolean
```

允许 Slide 内容缩放；默认 false。

<a id="af93f3f59a07a3b62aaf7985702fa8366"></a>

### resolution

```text
resolution?: number
```

Slide 渲染分辨倍率；未显式设置时由 Bridge 按 WebView UA 决定。

<a id="a2e4e4c970fe829cae921bbb17b1adcf9"></a>

### maxResolutionLevel

```text
maxResolutionLevel?: number
```

Slide 最大分辨率级别，0~4；未显式设置时由 Bridge 按 WebView UA 决定。

<a id="ae4adff60ddc9e66052140a39a4b82e69"></a>

### minFPS

```text
minFPS?: number
```

Slide 最小帧率；未显式设置时由内嵌 Bridge 按 WebView UA 决定。

<a id="af7bc0f757ffa402659ce24d88872cb27"></a>

### maxFPS

```text
maxFPS?: number
```

Slide 最大帧率；未显式设置时由内嵌 Bridge 按 WebView UA 决定。

<a id="a014d2c58430be830c82a47976738986d"></a>

### enableGlobalClick

```text
enableGlobalClick?: boolean
```

允许点击 Slide 画面执行下一步；默认 true。

<a id="aa6c78ad6353a57fe373f2933096d6617"></a>

### syncEventQueuePolicy

```text
syncEventQueuePolicy?: SlideSyncEventQueuePolicy
```

fifo（默认）或 latest-pending-render；后者需显式开启，仅合并尚未执行的渲染页，不跳过正在执行的任务，非 interactive 模式仍走 FIFO。

<a id="aeef7c008e59e92698236cb6c0427ca8b"></a>

### navigationButtonMode

```text
navigationButtonMode?: SlideNavigationButtonMode
```

Slide 底部前后按钮行为：page（默认）按页，step 按动画步骤；不改变其他翻页入口。
