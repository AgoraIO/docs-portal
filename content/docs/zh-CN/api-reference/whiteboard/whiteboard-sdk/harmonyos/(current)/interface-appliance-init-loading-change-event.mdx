## 变量说明

<a id="aad16dc1e66f5b6a185098140ee1d0f0b"></a>

### name

```text
name: 'applianceInitLoadingChange'
```

事件名为 applianceInitLoadingChange。

<a id="a40b3a7f2692f1b8933215a33ef7a5590"></a>

### loading

```text
loading: boolean
```

教具初始化是否仍在进行；结合 phase 和 status 判断阶段和结果。

<a id="aaca53f4561d03e44daf17d2b55721e9b"></a>

### phase

```text
phase: 'plugin' | 'worker' | 'scene' | 'ready'
```

初始化阶段：plugin、worker、scene 或 ready。

<a id="a5488e2a50e6f0aebd4c298828a23c6db"></a>

### status

```text
status: 'start' | 'success' | 'timeout' | 'error'
```

初始化阶段结果：start、success、timeout 或 error；loading=false、phase=ready、status=success 表示就绪。
