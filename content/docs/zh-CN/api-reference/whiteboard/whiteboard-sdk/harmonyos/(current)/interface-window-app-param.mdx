## 详细描述

适用版本：**@shengwang/whiteboard 0.2.11**。

controller.addApp(...) 的参数结构，用于指定 App 类型、初始化选项和同步属性。

可从 @shengwang/whiteboard 直接导入 WindowAppParam。仅用于类型声明，不能作为构造函数调用 new。

## 变量说明

<a id="ae1c9c7c0a38c49e06baa4fe5453a7092"></a>

### kind

```text
kind: string
```

必填 App 类型名，例如 Slide、DocsViewer、MediaPlayer 或 Presentation。

<a id="a4142132197510611985998b0ab5bb9e0"></a>

### options

```text
options?: object
```

可选 App 初始化选项，具体字段由 kind 对应的 App 决定。

<a id="ae91a0fa6e2e80949651c2fd3d984a0fe"></a>

### attributes

```text
attributes?: object
```

可选 App 同步属性，具体字段由 kind 对应的 App 决定。

<a id="a9e716967aaf5a486fe7e62bd3c3ef878"></a>

### originSize

```text
originSize?: WindowOriginSize
```

正数 width/height 组成的归一化参考尺寸。WindowParams 用于 MainView；WindowAppParam 用于 Slide/Presentation 并写入 attributes.originSize。
