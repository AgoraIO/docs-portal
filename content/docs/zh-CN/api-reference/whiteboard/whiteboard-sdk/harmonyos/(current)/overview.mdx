内嵌运行时：white-web-sdk 2.16.59、window-manager 1.0.25、appliance-plugin 1.1.45、app-slide 0.2.108。

类型列表 · 成员索引

通过 `ohpm install @shengwang/whiteboard@0.2.11` 集成；组件入房成功后使用 WhiteboardController。

**导入类型名与使用配置是两件事：**包入口导出类型可从包名直接 import；未单独导出的嵌套配置仍可通过公开配置字段填写。接口和类型别名用于描述结构，不能 new；未导出的枚举对象需另行注意调用限制。
