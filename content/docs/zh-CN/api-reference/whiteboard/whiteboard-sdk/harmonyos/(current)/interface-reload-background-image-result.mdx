## 变量说明

<a id="a7516de8a5892868dbad9bb0e88b0a049"></a>

### accepted

```text
accepted: boolean
```

背景图重载请求是否被接收；不表示图片已加载成功。false 时查看可选 reason；此结果类型没有 message 字段。

<a id="a8adec1c41b3a83fc97f04b17c8257b50"></a>

### reloadedCount

```text
reloadedCount: number
```

本次触发重新加载的背景图数量。

<a id="afdfff40a1a7a83c56c79e3c8f6e78c76"></a>

### reason

```text
reason?: 'viewNotFound' | 'sceneNotFocused' | 'resourceNotFound' | 'alreadyLoading'
```

可选拒绝原因：viewNotFound、sceneNotFocused、resourceNotFound 或 alreadyLoading。
