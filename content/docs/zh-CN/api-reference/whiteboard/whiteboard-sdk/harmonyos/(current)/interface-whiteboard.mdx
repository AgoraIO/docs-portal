## 详细描述

适用版本：**@shengwang/whiteboard 0.2.11**。

ArkUI 白板组件；根据 options 初始化并自动入房，接收 controller 和 callbacks。

可从 @shengwang/whiteboard 直接导入 Whiteboard。作为 ArkUI 组件使用。

### options

```text
options: WhiteboardOptions
```

SDK 初始化和入房配置。

### controller

```text
controller: WhiteboardController
```

业务操作 Controller；等待 onRoomReady 再调用房间方法。

<a id="a01512732f22475d39c6e50db76d3d181"></a>

### callbacks

```text
callbacks: WhiteboardCallbacks
```

实际传给组件的回调对象。组件使用此参数，不能只填写 options.callbacks。

<a id="a75171b018f37dde70524737687772ddd"></a>

### webDebug

```text
webDebug: boolean = true
```

ArkWeb 调试开关；正式应用应显式设置 false。
