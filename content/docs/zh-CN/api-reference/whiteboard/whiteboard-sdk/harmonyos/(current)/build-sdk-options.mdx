## 详细描述

适用于 @shengwang/whiteboard 0.2.11。

从包入口导出的参数构造函数，保留 dynamicConfig 和未显式字段的继承语义。一般由 Whiteboard 组件调用；返回的 SdkOptions 类型本身未从包入口单独导出，不要按类型名直接 import。

```text
export function buildSdkOptions(options: WhiteboardOptions): SdkOptions;
```

完整返回字段见 [SdkOptions](/zh-CN/api-reference/whiteboard/whiteboard-sdk/harmonyos/interface-sdk-options)。函数只构造参数，不创建 SDK 或发起入房；未显式配置的可选开关保持缺省。
