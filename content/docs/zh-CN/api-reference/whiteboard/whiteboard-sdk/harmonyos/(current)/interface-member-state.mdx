## 详细描述

适用版本：**@shengwang/whiteboard 0.2.11**。

白板工具状态，包含当前教具、颜色、线宽和文本等属性。

可从 @shengwang/whiteboard 直接导入 MemberState。仅用于类型声明，不能作为构造函数调用 new。
