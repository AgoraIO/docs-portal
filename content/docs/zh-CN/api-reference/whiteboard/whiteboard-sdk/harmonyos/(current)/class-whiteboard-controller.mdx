适用版本：**@shengwang/whiteboard 0.2.11**。

可从 @shengwang/whiteboard 直接导入 WhiteboardController。

组件内部生命周期接口；由 Whiteboard 组件管理，不作为业务入房或销毁入口。

组件解绑不等于所属房间退出完成；清理所有权仍由 SDK 保留，可继续通过 leaveRoom 等待所属 Room 清理。业务不应直接调用此内部绑定接口。

### setWritable

```text
setWritable(writable: boolean) : Promise<boolean>
```

设置用户在房间中是否为互动模式。

#### 参数

| 名称 | 描述 |
| --- | --- |
| writable | 用户在房间中是否为互动模式： - `true`：互动模式，即具有读写权限。 - `false`：订阅模式，即具有只读权限。 |

### moveScene


移动场景。

#### 参数

| 名称 | 描述 |
| --- | --- |
| sourcePath | - 需要移动的场景原路径。必须为场景路径，不能是场景组的路径。 |

@remarks - 该方法只能移动场景，不能移动场景组，即 `sourcePath` 只能是场景路径，不能是场景组路径。 - 该方法支持改变指定场景在当前所属场景组下的位置，也支持将指定场景移至其他场景组。
