### enabled

```text
enabled?: boolean
```

是否开启 WebView 内本地日志。未设置时不启用，需要显式设置为 true。

<a id="aa0008f8906f9bada3efd1a43e1225986"></a>

### enabledUpload

```text
enabledUpload?: boolean
```

上传开关；只有 enabled=true 时生效，不影响已经开启的本地日志写入。
