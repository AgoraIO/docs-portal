## 变量说明

<a id="a997d1d272371471cde939eb1d6584515"></a>

### containerSizeRatio

```text
containerSizeRatio?: number
```

各个端本地显示多窗口内容时，高与宽比例，默认为 9\:16

<a id="a3d78a48246b5e96114bfa4a2052cf3b6"></a>

### chessboard

```text
chessboard?: boolean
```

多窗口区域（主窗口）以外的空间显示 PS 棋盘背景，默认 true

<a id="a6991047500369f16cddef87c7e65bd0d"></a>

### collectorStyles

```text
collectorStyles?: Record<string, string>
```

驼峰形式的 CSS，透传给多窗口时，最小化 div 的 css

<a id="ac298db20eb019d2226a99d20575e2662"></a>

### overwriteStyles

```text
overwriteStyles?: string
```

窗口样式覆盖

<a id="afa40b9c7c578d43b9f432e0c380faf60"></a>

### debug

```text
debug?: boolean
```

是否在网页控制台打印日志

<a id="a94c1b4395e5a92edc6d9b550089fc404"></a>

### prefersColorScheme

```text
prefersColorScheme?: WindowPrefersColorScheme
```

窗口配色模式

<a id="a4201ea4cd8e2a5540600e19085ec44de"></a>

### fullscreen

```text
fullscreen?: boolean
```

是否全屏

<a id="a067402c886461dc74c6c924e3f5a4f24"></a>

### polling

```text
polling?: boolean
```

是否轮询

<a id="aa24eab00830ec2055814f7849804f457"></a>

### useBoxesStatus

```text
useBoxesStatus?: boolean
```

每个窗口独立同步最大化/最小化状态；在入房前配置，同房间客户端保持一致。与 forceMaximized 策略不兼容。

<a id="ab1e7a35c57e68503c3ab13b5ce0e7a26"></a>

### forceMaximized

```text
forceMaximized?: boolean
```

房间级强制最大化；可写端开启后同步到房间。两者不能同时生效；继承房间强制最大化或有效 lazy 模式时忽略本地 useBoxesStatus，否则同时请求两者时独立窗口状态优先。

<a id="ad47df3866cf955bc0564863a4fe138c0"></a>

### lazySetupInMaximizedMode

```text
lazySetupInMaximizedMode?: boolean
```

本地按焦点初始化 App；仅在房间已强制最大化且处于 maximized/minimized 时生效，否则使用 eager 初始化。默认关闭。

<a id="a017d8967d3f39c050211ab96df674c45"></a>

### maxCachedAppsInMaximizedMode

```text
maxCachedAppsInMaximizedMode?: number
```

lazy 模式本地 App runtime 缓存容量；内嵌 Window Manager 默认 4，按 LRU 管理。不是房间 App 数量上限，Slide 保留 runtime 的行为由播放器活动状态管理。

<a id="ae235ff050e954fe0ffd525dc64ebc133"></a>

### builtinAppOptions

```text
builtinAppOptions?: BuiltinAppOptions
```

本地内置 App 配置，不同步到房间；其中 Presentation 配置用于恢复存量 App 前注册。

<a id="a2d309b158606df79270e2427bbce5cc7"></a>

### originSize

```text
originSize?: WindowOriginSize
```

正数 width/height 组成的归一化参考尺寸。WindowParams 用于 MainView；WindowAppParam 用于 Slide/Presentation 并写入 attributes.originSize。

<a id="ab23cb72b7d4cbb0467517c8c9a57eb5d"></a>

### pageScaleRange

```text
pageScaleRange?: PageScaleRange
```

相对适配尺寸的 minScale/maxScale 范围；未配置边界不增加业务限制。
