## 详细描述

适用版本：**@shengwang/whiteboard 0.2.11**。

buildRoomOptions(options) 的返回结构，包含 uuid/isWritable 等 Bridge 入房字段；可接收函数返回值，不是业务 joinRoom() 入口。

当前版本未从 SDK 包入口单独导出此类型名；通过所述配置、参数或返回值使用其结构。
