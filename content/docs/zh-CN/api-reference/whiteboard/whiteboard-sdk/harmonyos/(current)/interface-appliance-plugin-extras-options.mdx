## 详细描述

适用版本：**@shengwang/whiteboard 0.2.11**。

appliancePluginOptions.extras 的扩展配置，包含 cursor、同步、绘制和 Worker 选项。

可从 @shengwang/whiteboard 直接导入 AppliancePluginExtrasOptions。仅用于类型声明，不能作为构造函数调用 new。
