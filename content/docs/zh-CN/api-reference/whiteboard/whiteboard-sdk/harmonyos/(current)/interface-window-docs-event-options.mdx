## 变量说明

<a id="ad9d4e51a2a6984b0c04e2631f048bed1"></a>

### target

```text
target?: string
```

命令目标：mainView 或具体 appId。省略时跟随焦点，无 App 焦点时回退 MainView。

<a id="ac05ed0c6b75e6f965d1e2bbc19afdc98"></a>

### page

```text
page?: number
```

统一课件与 Slide 页码从 1 开始；不是主白板场景的零基索引。

<a id="a171bf819a2d9aadafb83242fc7cfc3f1"></a>

### scale

```text
scale?: number
```

scalePage 命令的相对适配倍率，1 表示适配尺寸；DocsViewer 不支持此命令。
