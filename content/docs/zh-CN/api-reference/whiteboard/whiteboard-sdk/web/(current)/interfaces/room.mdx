### disableSerialization

disableSerialization: boolean;

```text
是否禁止如下方法（默认值是 ``true``）。可修改。

- ``room.redo``
- ``room.undo``
- ``room.duplicate``
- ``room.copy``
- ``room.paste``

房间内所有人的 ``white-web-sdk`` 的版本必须不低于 ``2.9.3`` 时，才能将该值设为 ``false``。房间内任何一个人将该值设为 ``false``，都会导致房间内低于 ``2.9.3`` 的用户前端报错且不能正常使用。
```

主动延迟接收的远端消息，单位是毫秒，默认值 ``0``。将该值设置成大于 ``0`` 的数字，可以人为造成类似网络时延的效果。可修改。

<a id="syncmode"></a>

### syncMode

syncMode: boolean;

```text
默认情况下，所有同步消息会按比较平滑的速度处理，以此保证观感的流畅性。
如果设置此项为 ``true``，则所有消息一经收到立刻处理，从而保证同步的实时性。
```

<a id="usenativeclipboard"></a>

### useNativeClipboard

useNativeClipboard: boolean;

```text
是否使用原生剪贴板。
设为 ``true`` 后，快捷键里的复制和粘贴将失效而使用原生 ``copy`` ``paste`` 事件。
此功能需要浏览器支持以及用户授予剪贴板权限，如果失败，将自动回退到虚拟剪贴板实现。
```
