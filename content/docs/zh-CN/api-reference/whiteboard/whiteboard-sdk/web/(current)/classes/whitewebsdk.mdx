连接的数据中心。支持传入以下值：

| `region` | 数据中心 | 服务区 |
| --- | --- | --- |
| `us-sv` | 美国硅谷 | 北美洲、南美洲 |
| `sg` | 新加坡 | 新加坡、东亚、东南亚 |
| `in-mum` | 印度孟买 | 印度 |
