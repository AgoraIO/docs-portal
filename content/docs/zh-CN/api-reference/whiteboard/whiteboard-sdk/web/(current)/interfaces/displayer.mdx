<a id="screenshottocanvasasync"></a>

### screenshotToCanvasAsync

- screenshotToCanvasAsync(context:CanvasRenderingContext2D, scenePath:string, width:number, height:number, camera:[Camera](/zh-CN/api-reference/whiteboard/whiteboard-sdk/web/globals#camera), ratio?:number, timeout?:number):Promise&lt;void&gt;

- Defined in [index-zh.d.ts:1803](https://github.com/Nero-Hu/Whiteboard-Web-doc/blob/a349dd9/webdoc_full/index-zh.d.ts#L1803)

  等待目标场景的图片加载完成后生成屏幕快照，写入指定的 `CanvasRenderingContext2D` 对象中。

  ### note

  - 该功能处于实验阶段。
  - 如果目标场景的图片无法完成加载，则该函数无法返回屏幕快照，你需要自行处理超时逻辑。
  - 如果你希望生成的屏幕快照不包含图片，请使用 [screenshotToCanvas](/zh-CN/api-reference/whiteboard/whiteboard-sdk/web/interfaces/displayer#screenshottocanvas)。

  Parameters

  - context: CanvasRenderingContext2D

    CanvasRenderingContext2D 对象。
  - scenePath: string

    场景的路径。你可以通过 `room.state.sceneState.scenePath` 获取当前场景。
  - width: number

    屏幕快照的宽度。
  - height: number

    屏幕快照的高度。
  - camera: [Camera](/zh-CN/api-reference/whiteboard/whiteboard-sdk/web/globals#camera)

    视角的描述。详见 [Camera](/zh-CN/api-reference/whiteboard/whiteboard-sdk/web/globals#camera)。
  - Optional ratio: number

    设备像素比。该参数为可选参数，如果不填，则默认值为 1。
  - Optional timeout: number

    图片加载的超时时间 (ms)，默认为永不超时，只能设为大于 `0` 的数。图片的加载时间超过该值后，SDK 会直接进行下一步绘制操作，而不会等待图片加载完成。

  Returns Promise&lt;void&gt;
