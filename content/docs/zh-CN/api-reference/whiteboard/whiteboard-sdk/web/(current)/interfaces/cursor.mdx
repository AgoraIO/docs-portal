### divElement

readonly divElement: HTMLDivElement;

````text
光标的容器，在创建之初为空。
你可以通过如下代码向容器中添加 HTML 元素，以改变光标的外观。

@example
```typescript
const icon = document.createElement("img");
icon.src = "https://my-resources.com/icon.png";
cursor.divElement.append(icon);
```
````
