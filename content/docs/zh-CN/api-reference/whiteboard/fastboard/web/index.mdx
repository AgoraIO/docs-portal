本页提供 **Fastboard Web 1.1.10** 的 TypeScript API 参考。依赖 Whiteboard Web 2.16.59、Window Manager 1.0.25 和 Appliance Plugin 1.1.45。

<a id="createfastboard"></a>
## createFastboard

```typescript
createFastboard<TEventData extends Record<string, any> = any>(options: FastboardOptions): Promise<FastboardApp<TEventData>>;
```

创建一个白板应用（`FastboardApp`）实例。

**参数**

- `options`：Object。白板配置选项。详见 [`FastboardOptions`](#fastboardoptions)。

**返回**

方法调用成功时返回 `FastboardApp` 对象。

<a id="createui"></a>
## createUI

```typescript
function createUI(app?: FastboardApp | null, div?: Element): UI;
```

创建 Fastboard 内置的一套 UI 组件。

**参数**

- `app`：Object。`FastboardApp` 实例，为 `createFastboard` 方法的返回值。
- `div`：HTML Element。容纳白板应用的网页元素。

**返回**

方法调用成功时返回 `UI` 组件。详见 [`UI`](#ui)。

创建一个回放播放器（`FastboardPlayer`）实例。

**参数**

- `options`：Object。回放配置选项。详见 [`FastboardReplayOptions`](#fastboardreplayoptions)。

**返回**

方法调用成功时返回 `FastboardPlayer` 对象。

创建内置回放模式的一套 UI 组件。

<a id="dispatchdocsevent"></a>
## dispatchDocsEvent

```typescript
function dispatchDocsEvent(fastboard: FastboardApp | WindowManager, event: DocsEvent, options?: DocsEventOptions): Promise<DispatchDocsEventResult>;
```

统一控制 MainView、DocsViewer、Slide、Presentation。target 省略时跟随焦点，或指定 mainView/appId；page 从 1 开始，scale=1 为适配尺寸。accepted 表示命令接收，拒绝时检查 reason/message；不保证渲染完成。

<a id="mount"></a>
## mount

```typescript
mount(app: FastboardApp, div: HTMLDivElement, options?: MountProps): {
 update(props?: MountProps | undefined): void;
 destroy(): void;
};
```

:::warning[注意]
自 v0.3.6 起不推荐使用该方法，请改用 [`createUI`](#createui)。
:::

挂载白板应用到 HTML 元素上。

**参数**

- `app`：Object。`FastboardApp` 实例，为 `createFastboard` 方法的返回值。
- `div`：HTML Element。容纳白板应用的网页元素。
- `options`：（可选）Object。白板用户界面（UI）配置选项。详见 [`MountProps`](#mountprops)。

**返回**

方法调用成功时返回如下函数：

- `update`：更新白板的 UI：
  - `props`：UI 配置选项。详见 [`MountProps`](#mountprops)。
- `destroy`：卸载白板应用。

### toggleDottedLine


<a id="insertimage"></a>
### insertImage

```typescript
insertImage(url: string, crossOrigin?: boolean | string): Promise<void>;
```

插入图片。

该方法可以将指定的网络图片插入并展示到当前白板页面上，插入的图片默认置于当前视图的中心。

**参数**

- `url`：String。图片的 URL 地址。请确保 App 客户端能够访问该 URL，否则图片无法正常展示。

  - `true`：（默认）启用 CORS。
  - `false`：禁用 CORS。

<a id="appsintoolbar"></a>
## AppsInToolbar 类

AppsInToolbar 类提供管理工具条上插件按钮的方法。

<a id="push"></a>
### push

```typescript
push(...data: AppInToolbar[]): void;
```

在插件中心的末尾添加插件按钮。

该方法支持一次添加多个新的插件按钮，新添加的插件按钮位于插件中心的最后。

**参数**

- `data`：插件按钮。详见 [`AppInToolbar`](#appintoolbar)。

**示例代码**

```typescript
// 在插件中心添加一个 YouTube 按钮。点击按钮后，在白板应用中插入 Plyr 播放器并播放指定的视频。
apps.push({
    icon: "https://api.iconify.design/logos:youtube-icon.svg?color=currentColor",
    kind: "Plyr",
    label: "YouTube",
    onClick(app) {
        app.manager.addApp({
            kind: "Plyr",
            options: { title: "YouTube" },
            attributes: {
                src: "https://www.youtube.com/embed/bTqVqk7FSmY",
                provider: "youtube",
            },
        });
    },
});
```

<a id="insert"></a>
### insert

```typescript
insert(data: AppInToolbar, index: number): void;
```

在指定位置添加一个插件按钮。

该方法支持一次添加一个新的插件按钮，并支持指定添加的位置。

**参数**

- `data`：插件按钮。详见 [`AppInToolbar`](#appintoolbar)。
- `index`：Number。待添加按钮在插件中心的索引号。取值必须大于等于 0。

<a id="delete"></a>
### delete

```typescript
delete(filter: (data: AppInToolbar) => boolean): void;
```

删除指定的插件按钮。

参数

- `filter`：`filter()` 方法，返回所有需要被删除的按钮组件。你需要在该方法中传入一个回调函数，用于筛选出需要删除的插件按钮。
  - `data`：插件按钮。详见 [`AppInToolbar`](#appintoolbar)。

<a id="clear"></a>
### clear

```typescript
clear(): void;
```

删除所有插件按钮。

该方法可以删除插件中心的所有按钮，但不能删除白板工具条上的插件中心（**apps**）按钮。如果你需要隐藏白板工具条上的插件按钮，可以通过 `mount` 方法的 `options` 参数将 `config.toolbar.apps.enable` 设为 `false`。

## 类型定义
### AppInToolbar

插件按钮。

```typescript
interface AppInToolbar {
    kind: string;
    icon: string;
    label: string;
    onClick: (app: FastboardApp) => void | Promise<unknown>;
}
```

`AppInToolbar` 包含如下属性：

- `kind`：String。插件按钮的唯一标识符。可以是任意字符串。
- `icon`：String。按钮图标的 URL 地址。
- `label`：String。按钮的标题，即显示在按钮下方的文字。建议长度不超过 12 个英文字符，否则文字会显示不全。
- `onClick`：点击按钮时触发的回调：
  - app：`FastboardApp` 对象。

<a id="readable-writable"></a>
## Readable 与 Writable

```typescript
interface Writable<T> extends Readable<T> {}
```

状态对象通过 .value 读取；使用订阅返回的函数解除业务监听。Writable 继承 Readable 的全部成员。

<a id="store-value"></a>
### value

```typescript
readonly value: T;
```

同步读取当前值。

<a id="store-subscribe"></a>
### subscribe

```typescript
subscribe(this: void, run: Subscriber<T>): Unsubscriber;
```

订阅后立即回调当前值，随后在变化时回调；返回解除订阅函数。

<a id="store-reaction"></a>
### reaction

```typescript
reaction(this: void, run: Subscriber<T>): Unsubscriber;
```

只监听后续变化，不立即回调当前值；返回解除订阅函数。

<a id="store-dispose"></a>
### dispose

```typescript
dispose(value?: T): void;
```

释放该状态的所有订阅，可先提供一个最终值。通常由状态所有者销毁时调用。

<a id="store-set"></a>
### set

```typescript
set(this: void, value: T): void;
```

写入新值。SDK 状态的写入会触发对应白板操作。

<a id="store-update"></a>
### update

```typescript
update(this: void, updater: Updater<T>): void;
```

将当前值传给 updater，并写入它返回的新值。

```typescript
const unsubscribe = app.phase.subscribe(phase => console.log(phase));
app.writable.set(true);
const index = app.sceneIndex.value;
// 业务组件卸载时释放自己的监听。
unsubscribe();
```
