## FastboardView 类
### getFastboard

```java
public Fastboard getFastboard()
```

获取 `Fastboard` 对象。

Fastboard SDK 不支持直接初始化 `Fastboard` 对象。你需要先将 `FastboardView` 添加到 app 的布局中，然后调用 `getFastboard` 方法获取 `Fastboard` 对象。

**注意**

请确保在调用其他 API 前先调用该方法获取 `Fastboard` 对象。

**返回**

方法调用成功时返回 `Fastboard` 对象。

<a id="fastroomoptions"></a>
### FastRoomOptions

白板房间的配置选项。

```java
public class FastRoomOptions {
    private final String appId;
    private final String uuid;
    private final String token;
    private final String uid;
    private final boolean writable;

    private final FastRegion fastRegion;

    private Float containerSizeRatio;

    private FastUserPayload userPayload;

    public FastRoomOptions(String appId, String uuid, String token, String uid, FastRegion fastRegion) {
        this(appId, uuid, token, uid, fastRegion, true);
    }

    public FastRoomOptions(String appId, String uuid, String token, String uid, FastRegion fastRegion, boolean writable) {
        this.appId = appId;
        this.uuid = uuid;
        this.token = token;
        this.uid = uid;
        this.fastRegion = fastRegion;
        this.writable = writable;
    }
}
```

`FastRoomOptions` 类包含以下属性：

- `appId`：String。互动白板项目的 AppIdentifier。详见[获取互动白板项目的安全密钥](/zh-CN/realtime-media/whiteboard/fastboard-sdk/build/setup-and-access/enable-service#获取互动白板项目的安全密钥)。
- `uuid`：String。房间的 UUID，即房间的唯一标识符。详见[创建房间](/zh-CN/api-reference/api-ref/whiteboard/restful/create-room)请求成功后响应包体中 `uuid` 参数的值。
- `token`：String。房间的 Room Token，用于加入房间时的用户鉴权。可以通过以下方式获取：
  - 调用[生成 Room Token](/zh-CN/api-reference/api-ref/whiteboard/restful/generate-room-token)。
  - 在 app 服务端用代码生成，详见[在 app 服务端生成 Token](/zh-CN/realtime-media/whiteboard/fastboard-sdk/build/setup-and-access/generate-token#在-app-服务端生成-token)。
- `uid`：String。用户的 UID，即用户的唯一标识符，字符串格式，不能超过 1024 字节。请确保同一房间内每个用户的 uid 唯一。
- `writable`：boolean。用户是否以互动模式加入白板房间：
  - `true`：以互动模式加入白板房间，即具有读写权限。
  - `false`：以订阅模式加入白板房间，即具有只读权限。
- `fastRegion`：数据中心。详见 [`FastRegion`](#fastregion)。
- `containerSizeRatio`：Float。本地显示窗口中，内容的高宽比，默认为 `0.56`，即 `9:16`。
- `userPayload`：用户光标显示的用户信息，包括用户的昵称和头像。详见 [`FastUserPayload`](#fastuserpayload)。

<a id="fastregion"></a>
<a id="fastregion"></a>
### FastRegion

数据中心，包含以下枚举值：

- `CN_HZ`：中国杭州，服务区覆盖东亚、东南亚、以及其他数据中心未覆盖的地区。

- `US_SV`：美国硅谷，服务区覆盖北美洲、南美洲。

- `SG`：新加坡，服务区覆盖新加坡、东亚、东南亚。

- `IN_MUM`：印度孟买，服务区覆盖印度。

- `EU`：欧洲（法兰克福），服务区覆盖欧洲。

### FastUserPayload

```java
public class FastUserPayload {
    private final String nickName;
    private final String avatar;

    public FastUserPayload(String nickName) {
        this(nickName, null);
    }

    public FastUserPayload(String nickName, String avatar) {
        this.nickName = nickName;
        this.avatar = avatar;
    }
}
```

`FastUserPayload` 对象，用于储存光标上显示的用户信息，包含以下成员变量：

- `nickName`：String。用户光标上显示的用户昵称。

- `avatar`：String。（可选）用户光标上显示的用户头像，应传入头像对应的 URL 地址。

<a id="fastboardconfig"></a>
### FastboardConfig

```java
public class FastboardConfig {
    private final boolean enablePreload;
    private final int preloadCount;
    private final boolean autoPreload;
}
```

`Fastboard` 对象的辅助配置，包含以下属性：

- `enablePreload`：boolean。是否开启白板预加载功能：
  - `true`：开启白板预加载。
  - `false`：（默认）关闭白板预加载。
- `preloadCount`：int。预加载的 WebView 数量，默认为 `0`。该属性的实际生效情况受内存容量的限制，你需要根据实际情况适当调整设置。
- `autoPreload`:boolean。该属性仅在 `enablePreload` 为 `true` 时生效。是否启用自动预加载：
  - `true`：（默认）启用自动预加载。开启后可自动预加载白板视图，提升白板加载速度，但会占用额外的内存。
  - `false`：关闭自动预加载。关闭后，你可以调用 [`preloadWhiteboardView`](#preloadwhiteboardview) 手动执行预加载。

### FastAppliance

白板工具，包含以下枚举值：

- `CLICKER(Appliance.CLICKER)`：点击工具。目前主要用于点击 HTML5 文件上的内容。

- `TEXT(Appliance.TEXT)`：文字工具。

- `ERASER(Appliance.ERASER)`：橡皮工具。

- `PENCIL_ERASER(Appliance.PENCIL_ERASER)`：铅笔橡皮工具，用于擦除局部铅笔笔迹。

- `LASER_POINTER(Appliance.LASER_POINTER)`：激光笔。

- `ARROW(Appliance.ARROW)`：箭头。

- `STRAIGHT(Appliance.STRAIGHT)`：直线。

- `PENTAGRAM(Appliance.SHAPE, ShapeType.Pentagram)`：五角星。

- `RHOMBUS(Appliance.SHAPE, ShapeType.Rhombus)`：菱形。

- `TRIANGLE(Appliance.SHAPE, ShapeType.Triangle)`：三角形。

- `BUBBLE(Appliance.SHAPE, ShapeType.SpeechBalloon)`：对话气泡。

```java
public class DocPage {
    private String src;

    private Double width;
```

插入文档的参数设置。`DocPage` 类包含以下属性：

- `src`：String。图片或动态 PPT 页的地址。
  - 图片：URL 地址，可以是你自己生成的 URL 地址，也可以是通过[文档转换功能](/zh-CN/realtime-media/whiteboard/fastboard-sdk/build/extend-whiteboard/convert-files)生成的 URL 地址。你可以从[查询转换任务进度](/zh-CN/api-reference/api-ref/whiteboard/restful/get-file-conversion-task)返回的 `image` 字段中获取该地址。请确保 App 客户端能够访问该 URL，否则无法正常加载图片。

- `width`：int。插入的文档在白板中的宽度（px）。
- `height`：int。插入的文档在白板中的高度（px）。

### FastInsertDocParams

文档的参数设置。

```java
public class FastInsertDocParams {
    private String taskUUID;
    private String taskToken;
    private FastRegion region;
    private ConverterType converterType;
    private String fileType;
    private Boolean dynamicDoc;
    private String title;
}
```

`FastInsertDocParams` 类包含以下属性：

- `taskUUID`：String。文档转换任务的 Task UUID，即[发起文档转换任务](/zh-CN/api-reference/api-ref/whiteboard/restful/start-file-conversion)请求成功时响应包体中 `uuid` 字段的值。
- `taskToken`：String。文档转换任务的 Task Token，必须和[发起文档转换任务](/zh-CN/api-reference/api-ref/whiteboard/restful/start-file-conversion)时传入的 Task Token 一致。
- `converterType`: 枚举。文档转换服务的版本，取值如下：
  - `Projector`: 新版。详见[新版文档转换服务](/zh-CN/realtime-media/whiteboard/fastboard-sdk/build/extend-whiteboard/convert-files)。
  - `WhiteboardConverter`: 旧版（默认值），当前已不再维护。
- `fileType`：String。文档类型：
  - `pdf`：静态文档。
  - `pptx`：动态文档。
- `dynamicDoc`: boolean。文档转换任务类型是否为动态转换任务。
- `title`：String。窗口标题。

### FastStyle

```java
public class FastStyle {
    private int mainColor;
    private boolean darkMode;

    public FastStyle() {
    }

    public int getMainColor() {

    }

    public void setMainColor(@ColorInt int color) {
```

### registerApp

向白板房间注册第三方窗口应用。

### FastRegisterAppParams

用于注册第三方窗口 App 参数的配置类。

```java
public class FastRegisterAppParams {
    private String javascriptString;
    private String kind;
    private String url;
    private Map<String, Object> appOptions;
    private String variable;

    public FastRegisterAppParams(String javascriptString, String kind, String variable, Map<String, Object> appOptions) {
        this.javascriptString = javascriptString;
        this.kind = kind;
        this.appOptions = appOptions;
        this.variable = variable;
    }

    public FastRegisterAppParams(String url, String kind, Map<String, Object> appOptions) {
        this.url = url;
        this.kind = kind;
        this.appOptions = appOptions;
    }

    public String getJavascriptString() {
        return javascriptString;
    }

    public String getKind() {
        return kind;
    }

    public String getUrl() {
        return url;
    }

    public Map<String, Object> getAppOptions() {
        return appOptions;
    }

    public String getVariable() {
        return variable;
    }
}
```

`FastRegisterAppParams` 类提供两种注册方式：

1. **本地脚本注册**：通过本地的 JavaScript 字符串注册（推荐方式，可靠性高）
   - 使用 `FastRegisterAppParams(String javascriptString, String kind, String variable, Map<String, Object> appOptions)` 构造函数
2. **远程包注册**：通过发布包的 URL 进行注册（可能因网络原因失败）
   - 使用 `FastRegisterAppParams(String url, String kind, Map<String, Object> appOptions)` 构造函数

`FastRegisterAppParams` 类包含以下属性：

- `javascriptString`：String。本地 JS 脚本代码，用于本地脚本注册。
- `kind`：String。注册的 App 名称，即 App 的类型名称。
- `url`：String。远程注册包的 URL 地址，用于远程包注册。
- `appOptions`：Map&lt;String, Object&gt;。初始化 App 实例时会被传入的参数。这段配置不会被同步到其他端，属于本地设置。常常用来设置 debug 的开关。
- `variable`：String。挂载在 window 上的变量名，挂载后为 `window.variable`。

**参数**

- `pages`：转换后的文件列表。详见[查询文档转换任务进度](/zh-CN/api-reference/api-ref/whiteboard/restful/get-file-conversion-task)请求成功后返回的响应包体中 `convertedFileList` 参数的值。
- `title`：窗口标题。
- `completionHandler`：方法调用结果回调。传入 `nil`，表示不注册回调。

<a id="dispatchdocsevent"></a>
## dispatchDocsEvent

```typescript
export function dispatchDocsEvent(
  fastboard: FastboardApp | WindowManager,
  event: "prevPage" | "nextPage" | "prevStep" | "nextStep" | "jumpToPage",
  options: DocsEventOptions = {}
)
```

向指定文档发送事件。

该方法仅适用于使用 [`insertDocs`](#insertdocs1) 的两个重载方法插入的文档。

**参数**

- `fastboard`：发送事件的对象，可以传入 [`FastboardApp`](#createfastboard) 或 [`WindowManager`](https://github.com/netless-io/window-manager/blob/master/docs/api.md#mount) 对象。
- `event`：String。需要触发的事件类型，取值如下：
  - `prevPage`：上一页。
  - `nextPage`：下一页。
  - `prevStep`：上一步。向静态文档发送此事件效果与 `prevPage` 相同。
  - `nextStep`：下一步。向静态文档发送此事件效果与 `nextPage` 相同。
  - `jumpToPage`：跳转至指定页面。发送此事件时，需要传入 `options` 以指定页码。
- `options`：（可选）`DocsEventOptions`。事件选项，用于指定文档和跳转页面，详见[`DocsEventOptions`](#docseventoptions)。默认为空对象，代表发送事件给当前焦点所在的文档。

**返回**

- `true`：方法调用成功。
- `false`：方法调用失败。失败原因可能是未找到文档对象或文档不可写。

```typescript
            kind: "Plyr",
            options: { title: "YouTube" },

                src: "https://www.youtube.com/embed/bTqVqk7FSmY",

```

`Rectangle` 接口包含以下属性：

- `originX`：Number。矩形左上角在白板坐标系（以网页元素的中心为原点的坐标系）中的 X 轴坐标。
- `originY`：Number。矩形左上角在白板坐标系（以网页元素的中心为原点的坐标系）中的 Y 轴坐标。
- `width`：矩形的宽度（px）。
- `height`：矩形的高度（px）。

<a id="replayui"></a>
### ReplayUI

回放模式的一套 UI 组件。

```typescript
export interface ReplayUI {
  mount(div: Element, props?: ReplayFastboardProps): ReplayUI;
  update(props?: ReplayFastboardProps): void;
  destroy(): void;
}
```

`ReplayUI` 组件包含以下函数：

- `mount`: 挂载白板 UI 到 HTML 元素上。
  - `div`：HTML Element。容纳白板应用的网页元素。
  - `props`: Object。UI 配置选项，详见 [`FastboardProps`](#fastboardprops)。
- `update`: 用于 UI 配置变更后，更新 Fastboard UI。
  - `props`: Object。UI 配置选项，详见 [`FastboardProps`](#fastboardprops)。
- `destroy`: 移除 UI。
