不可见插件的描述。

### `since`

2.10.0

Agora 支持的自定义插件包括组件插件和不可见插件。二者的主要区别有：

- 不可见插件全局唯一，只能建立一个对象。
- 不可见插件不会显示在白板界面上，但它的 attributes 状态会在全房间自动同步。

- InvisiblePlugin
