声网通过全球部署的虚拟网络，提供可以灵活搭配的 API 组合，提供稳定可靠、功能丰富的实时互动白板。

- [WhiteWebSdk](/zh-CN/api-reference/whiteboard/web/classes/white-web-sdk) 类提供初始化互动白板 SDK、加入互动白板实时房间、创建白板回放的主要方法。
- [Room](/zh-CN/api-reference/whiteboard/web/interfaces/room-callbacks) 接口提供管理互动白板实时房间的方法。
- [Player](/zh-CN/api-reference/whiteboard/web/interfaces/player-callbacks) 接口提供控制白板回放的方法。
- [Displayer](/zh-CN/api-reference/whiteboard/web/interfaces/displayer-callbacks) 接口为 [Room](/zh-CN/api-reference/whiteboard/web/interfaces/room-callbacks) 接口和 [Player](/zh-CN/api-reference/whiteboard/web/interfaces/player-callbacks) 接口的父接口。 [Room](/zh-CN/api-reference/whiteboard/web/interfaces/room-callbacks) 和 [Player](/zh-CN/api-reference/whiteboard/web/interfaces/player-callbacks) 对象都可以调用该接口中的方法。
