调用 [seekToProgressTime](/zh-CN/api-reference/whiteboard/web/interfaces/player#seektoprogresstime) 定位回放的结果。

### `since`

v2.15.0

## 枚举成员

### Override [#override]

```ts title="TypeScript"
Override: = "override"
```

跳转操作被另一个跳转操作覆盖，因此被取消。

### Stopped [#stopped]

```ts title="TypeScript"
Stopped: = "stopped"
```

跳转操作因播放器停止而终止。

### Success [#success]

```ts title="TypeScript"
Success: = "success"
```

成功跳转至指定播放位置。

### SuccessButUnnecessary [#successbutunnecessary]

```ts title="TypeScript"
SuccessButUnnecessary: = "successButUnnecessary"
```

当前播放位置已经是指定播放位置，无需跳转。
