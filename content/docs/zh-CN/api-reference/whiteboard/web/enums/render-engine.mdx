白板上绘画的渲染模式。

### `since`

2.6.0

## 枚举成员

### Canvas [#canvas]

```ts title="TypeScript"
Canvas: = "canvas"
```

Canvas 渲染模式。 2.6.0 版本起，互动白板 SDK 新增 `canvas` 渲染模式，该模式性能较好，但兼容性较差。

### SVG [#svg]

```ts title="TypeScript"
SVG: = "svg"
```

SVG 渲染模式。 2.6.0 及之前版本的互动白板 SDK 默认使用的渲染模式，该模式兼容性较好，但性能较差。
