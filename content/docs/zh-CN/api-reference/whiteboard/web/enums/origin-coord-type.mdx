浮动画布生成的位置和绘制点的对应关系。

### `since`

2.16.48

根据绘制位置生成一个大小约为 256 x 256 px 的浮动画布，后续绘制不超过该画布的范围时，同步绘制笔迹的范围会限定在这个浮动画布中，而不是同步整个画布，从而降低性能消耗。

## 枚举成员

### BottomCenter [#bottomcenter]

```ts title="TypeScript"
BottomCenter: = 2
```

绘制点位于浮动画布的底部中间。

### Center [#center]

```ts title="TypeScript"
Center: = 5
```

绘制点位于浮动画布的中心点。

### Default [#default]

```ts title="TypeScript"
Default: = 0
```

默认为绘制点位于浮动画布的左上角。

### LeftBottom [#leftbottom]

```ts title="TypeScript"
LeftBottom: = 1
```

绘制点位于浮动画布的左下角。

### LeftCenter [#leftcenter]

```ts title="TypeScript"
LeftCenter: = 4
```

绘制点位于浮动画布的左侧居中。

### LeftTop [#lefttop]

```ts title="TypeScript"
LeftTop: = 7
```

绘制点位于浮动画布的左上角。

### RightBottom [#rightbottom]

```ts title="TypeScript"
RightBottom: = 3
```

绘制点位于浮动画布的右下角。

### RightCenter [#rightcenter]

```ts title="TypeScript"
RightCenter: = 6
```

绘制点位于浮动画布的右侧居中。

### RightTop [#righttop]

```ts title="TypeScript"
RightTop: = 9
```

绘制点位于浮动画布的右上角。

### TopCenter [#topcenter]

```ts title="TypeScript"
TopCenter: = 8
```

绘制点位于浮动画布的顶部中间。
