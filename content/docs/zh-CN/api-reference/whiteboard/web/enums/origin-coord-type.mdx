浮动画布生成的位置和绘制点的对应关系。

### `since`

2.16.48

根据绘制位置生成一个大小约为 256 x 256 px 的浮动画布，后续绘制不超过该画布的范围时，同步绘制笔迹的范围会限定在这个浮动画布中，而不是同步整个画布，从而降低性能消耗。

## 枚举成员

<a id="bottomcenter"></a>

### BottomCenter

```ts title="TypeScript"
BottomCenter: = 2
```

绘制点位于浮动画布的底部中间。

<a id="center"></a>

### Center

```ts title="TypeScript"
Center: = 5
```

绘制点位于浮动画布的中心点。

<a id="default"></a>

### Default

```ts title="TypeScript"
Default: = 0
```

默认为绘制点位于浮动画布的左上角。

<a id="leftbottom"></a>

### LeftBottom

```ts title="TypeScript"
LeftBottom: = 1
```

绘制点位于浮动画布的左下角。

<a id="leftcenter"></a>

### LeftCenter

```ts title="TypeScript"
LeftCenter: = 4
```

绘制点位于浮动画布的左侧居中。

<a id="lefttop"></a>

### LeftTop

```ts title="TypeScript"
LeftTop: = 7
```

绘制点位于浮动画布的左上角。

<a id="rightbottom"></a>

### RightBottom

```ts title="TypeScript"
RightBottom: = 3
```

绘制点位于浮动画布的右下角。

<a id="rightcenter"></a>

### RightCenter

```ts title="TypeScript"
RightCenter: = 6
```

绘制点位于浮动画布的右侧居中。

<a id="righttop"></a>

### RightTop

```ts title="TypeScript"
RightTop: = 9
```

绘制点位于浮动画布的右上角。

<a id="topcenter"></a>

### TopCenter

```ts title="TypeScript"
TopCenter: = 8
```

绘制点位于浮动画布的顶部中间。
