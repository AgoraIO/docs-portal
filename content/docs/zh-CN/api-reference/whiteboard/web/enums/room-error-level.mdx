没有可写权限的用户进行写操作时，SDK 的应对方式。

## 枚举成员

### Ignore [#ignore]

```ts title="TypeScript"
Ignore: = "ignore"
```

拦截该操作，但不报错也不打印警告。

### ThrowError [#throwerror]

```ts title="TypeScript"
ThrowError: = "throwError"
```

直接报错。

### Warn [#warn]

```ts title="TypeScript"
Warn: = "warn"
```

拦截该操作，并在浏览器的控制台打印警告。
