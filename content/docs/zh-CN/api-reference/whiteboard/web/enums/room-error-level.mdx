没有可写权限的用户进行写操作时，SDK 的应对方式。

## Enumeration members

<a id="ignore"></a>

### Ignore

```ts
Ignore: = "ignore"
```

拦截该操作，但不报错也不打印警告。

<a id="throwerror"></a>

### ThrowError

```ts
ThrowError: = "throwError"
```

直接报错。

<a id="warn"></a>

### Warn

```ts
Warn: = "warn"
```

拦截该操作，并在浏览器的控制台打印警告。
