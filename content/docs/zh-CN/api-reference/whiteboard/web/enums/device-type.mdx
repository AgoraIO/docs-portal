设备类型。

## 枚举成员

### Desktop [#desktop]

```ts title="TypeScript"
Desktop: = "desktop"
```

桌面设备，即使用键盘和鼠标的设备。

### Surface [#surface]

```ts title="TypeScript"
Surface: = "surface"
```

同时支持键盘、鼠标、触碰板的设备。

### Touch [#touch]

```ts title="TypeScript"
Touch: = "touch"
```

触碰板设备，例如智能手机、平板电脑。
