---

SDK 上报日志的模式。

## 枚举成员

### AlwaysReport [#alwaysreport]

```ts title="TypeScript"
AlwaysReport: = "alwaysReport"
```

（默认）允许 SDK 一直上报。

### BanReport [#banreport]

```ts title="TypeScript"
BanReport: = "banReport"
```

禁止 SDK 上报。

### DependsOnRemote [#dependsonremote]

```ts title="TypeScript"
DependsOnRemote: = "dependsOnRemote"
```

让 SDK 根据浏览器的控制台配置进行上报。
