---
title: "LoggerReportMode"
description: "LoggerReportMode API reference."
---

SDK 上报日志的模式。

## Enumeration members

<a id="alwaysreport"></a>

### AlwaysReport

```ts
AlwaysReport: = "alwaysReport"
```

（默认）允许 SDK 一直上报。

<a id="banreport"></a>

### BanReport

```ts
BanReport: = "banReport"
```

禁止 SDK 上报。

<a id="dependsonremote"></a>

### DependsOnRemote

```ts
DependsOnRemote: = "dependsOnRemote"
```

让 SDK 根据浏览器的控制台配置进行上报。
