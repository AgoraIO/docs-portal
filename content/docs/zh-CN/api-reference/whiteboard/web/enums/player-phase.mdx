白板回放的阶段。

## 枚举成员

### Buffering [#buffering]

```ts title="TypeScript"
Buffering: = "buffering"
```

白板回放正在缓存。

### Ended [#ended]

```ts title="TypeScript"
Ended: = "ended"
```

白板回放已结束。

### Pause [#pause]

```ts title="TypeScript"
Pause: = "pause"
```

白板回放已暂停。

### Playing [#playing]

```ts title="TypeScript"
Playing: = "playing"
```

白板回放正在进行。

### Stopped [#stopped]

```ts title="TypeScript"
Stopped: = "stop"
```

白板回放已停止。

### WaitingFirstFrame [#waitingfirstframe]

```ts title="TypeScript"
WaitingFirstFrame: = "waitingFirstFrame"
```

正在等待白板回放的第一帧。这是白板回放的初始阶段。
