---
title: "LowTaskAnimationInterval"
description: "LowTaskAnimationInterval API 参考。"
---

调整白板绘制的刷新间隔 (ms)。

刷新间隔越低，笔迹显示越流畅，性能消耗越大；刷新间隔越高，笔迹越卡，性能消耗越少。

### `since`

2.16.48

## 枚举成员

<a id="default"></a>

### Default

```ts title="TypeScript"
Default: = 0
```

默认为对其到 60 FPS 的刷新间隔。

<a id="lg"></a>

### Lg

```ts title="TypeScript"
Lg: = 80
```

高刷新间隔。

<a id="md"></a>

### Md

```ts title="TypeScript"
Md: = 60
```

中等刷新间隔。

<a id="sm"></a>

### Sm

```ts title="TypeScript"
Sm: = 40
```

低刷新间隔。

<a id="xl"></a>

### Xl

```ts title="TypeScript"
Xl: = 120
```

超高刷新间隔。

<a id="xs"></a>

### Xs

```ts title="TypeScript"
Xs: = 20
```

超低刷新间隔。
