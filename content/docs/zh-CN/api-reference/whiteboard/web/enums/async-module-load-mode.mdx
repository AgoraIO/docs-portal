异步模块的加载模式。

## Enumeration members

<a id="disablecache"></a>

### DisableCache

```ts
DisableCache: = "disableCache"
```

禁止缓存，每次加载模块的时候都从网上下载。

<a id="storeasbase64"></a>

### StoreAsBase64

```ts
StoreAsBase64: = "storeAsBase64"
```

将模块以 base64 字符串的形式缓存在 indexDB。

<a id="storeasblob"></a>

### StoreAsBlob

```ts
StoreAsBlob: = "storeAsBlob"
```

将模块以 blob 的形式缓存在 indexDB。
