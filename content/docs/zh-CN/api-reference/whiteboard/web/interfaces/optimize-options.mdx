白板绘制性能优化设置。

### `since`

2.16.48

- OptimizeOptions

## Properties

<a id="uselowtaskanimation"></a>

### useLowTaskAnimation

```ts
useLowTaskAnimation: LowTaskAnimationInterval
```

设置白板绘制的刷新间隔。详见 [LowTaskAnimationInterval](/zh-CN/api-reference/whiteboard/web/enums/low-task-animation-interval)。

<a id="usesinglercanvas"></a>

### useSinglerCanvas

```ts
useSinglerCanvas: boolean
```

是否使用单个画布：

- `true`：使用单个画布，应用浮动画布优化策略。
- `false`：（默认）使用双画布交替绘制。

白板默认使用两个画布交替绘制以避免在部分设备上绘制时可能出现的画面闪烁现象，使用单个画布绘制可以避免重绘，降低性能消耗。

<a id="usetopfloatorigincoord"></a>

### useTopFloatOriginCoord

```ts
useTopFloatOriginCoord: OriginCoordType
```

浮动画布生成的位置和绘制点的对应关系，默认为绘制点位于浮动画布的左上角。详见 [OriginCoordType](/zh-CN/api-reference/whiteboard/web/enums/origin-coord-type)。

仅在 `useSinglerCanvas` 为 `true` 时生效。
