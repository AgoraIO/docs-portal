<a id="divelement"></a>

### divElement

```ts
divElement: HTMLDivElement
```

光标的容器，在创建之初为空。 你可以通过如下代码向容器中添加 HTML 元素，以改变光标的外观。

##### `example`

```text
const icon = document.createElement("img");
icon.src = "https://my-resources.com/icon.png";
cursor.divElement.append(icon);
```

<a id="setreactnode"></a>

### setReactNode

```ts
setReactNode(reactNode: any): void
```

通过注入 JSX 结构来改变光标的外观。

##### `example`

```text
cursor.setReactNode(
    <img src="https://my-resources.com/icon.png"/>
);
```

#### Parameters

| Name | Description |
| --- | --- |
| reactNode: any | 描述光标外观的 JSX。 |

#### Returns

Returns void
