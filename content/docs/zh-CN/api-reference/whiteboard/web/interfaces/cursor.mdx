光标。

- Cursor

## 属性

### cursorMember [#cursormember]

```ts title="TypeScript"
cursorMember: CursorMember
```

光标所属用户的信息。

### divElement [#divelement]

```ts title="TypeScript"
divElement: HTMLDivElement
```

光标的容器，在创建之初为空。 你可以通过如下代码向容器中添加 HTML 元素，以改变光标的外观。

##### `example`

```text title="Text"
const icon = document.createElement("img");
icon.src = "https://my-resources.com/icon.png";
cursor.divElement.append(icon);
```

### height [#height]

```ts title="TypeScript"
height: number
```

光标图形的高度。

### memberId [#memberid]

```ts title="TypeScript"
memberId: number
```

光标所属用户的 ID。

### onCursorMemberChanged [#oncursormemberchanged]

```ts title="TypeScript"
onCursorMemberChanged: (cursorMember: CursorMember) => void
```

### width [#width]

```ts title="TypeScript"
width: number
```

光标图形的宽度。

### x [#x]

```ts title="TypeScript"
x: number
```

光标指示区域中心的 X 轴坐标（以白板左上角为原点）。

### y [#y]

```ts title="TypeScript"
y: number
```

光标指示区域中心的 Y 轴坐标（以白板左上角为原点）。

## 方法

### setCursorDescription [#setcursordescription]

```ts title="TypeScript"
setCursorDescription(description: Partial<CursorDescription>): void
```

修改光标的描述。

#### 参数

| 名称 | 描述 |
| --- | --- |
| description: Partial&lt;CursorDescription&gt; | 光标的描述。 |

#### 返回值

void

### setReactNode [#setreactnode]

```ts title="TypeScript"
setReactNode(reactNode: any): void
```

通过注入 JSX 结构来改变光标的外观。

##### `example`

```text title="Text"
cursor.setReactNode(
    <img src="https://my-resources.com/icon.png"/>
);
```

#### 参数

| 名称 | 描述 |
| --- | --- |
| reactNode: any | 描述光标外观的 JSX。 |

#### 返回值

void
