组件插件对象的接口。

- PluginInstance

## 属性

### attributes [#attributes]

```ts title="TypeScript"
attributes: A
```

组件插件对象的属性。

### context [#context]

```ts title="TypeScript"
context: C
```

自定义的组件插件上下文。

### height [#height]

```ts title="TypeScript"
height: number
```

组件插件对象的高。

### identifier [#identifier]

```ts title="TypeScript"
identifier: Identifier
```

组件插件对象在房间内的唯一标识符。

### isDraging [#isdraging]

```ts title="TypeScript"
isDraging: boolean
```

是否正在拖拽组件插件对象。

- `true`：在拖拽。
- `false`：不在拖拽。

### isPlaying [#isplaying]

```ts title="TypeScript"
isPlaying: boolean
```

是否正在播放组件插件对象。

- `true`：在播放。在白板实时房间内，取值一直为 `true`。
- `false`：不在播放。

### isResizing [#isresizing]

```ts title="TypeScript"
isResizing: boolean
```

是否正在改变组件插件对象的大小。

- `true`：在改变。
- `false`：不在改变。

### kind [#kind]

```ts title="TypeScript"
kind: string
```

组件插件的类型，是组件插件的唯一标识符。

### originX [#originx]

```ts title="TypeScript"
originX: number
```

组件插件对象的左上角在世界坐标系（以白板初始化时的中心点为原点的坐标系）中的 X 轴坐标。

### originY [#originy]

```ts title="TypeScript"
originY: number
```

组件插件对象的左上角在世界坐标系（以白板初始化时的中心点为原点的坐标系）中的 Y 轴坐标。

### playbackSpeed [#playbackspeed]

```ts title="TypeScript"
playbackSpeed: number
```

组件插件对象当前的播放速率倍率（若为实时房间，则恒为 `1.0` ）。

### playerTimestamp [#playertimestamp]

```ts title="TypeScript"
playerTimestamp: number
```

组件插件对象当前播放位置的 Unix 时间戳（若为实时房间，则恒为 0）。

### selectable [#selectable]

```ts title="TypeScript"
selectable: boolean
```

能否选中组件插件对象：

- `true`：能选中组件插件对象。
- `false`：不能选中组件插件对象。

### width [#width]

```ts title="TypeScript"
width: number
```

组件插件对象的宽。
