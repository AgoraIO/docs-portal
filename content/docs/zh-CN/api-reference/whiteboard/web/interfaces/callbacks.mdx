### forwardTo

```ts title="TypeScript"
forwardTo<NAME>(name: NAME, toCallbacks: Callbacks<CALLBACKS>): any
```

将注册的回调转到另一个 `Callbacks` 对象。

#### 参数

| 名称 | 描述 |
| --- | --- |
| name: NAME | 注册回调的名称。 |
| toCallbacks: Callbacks&lt;CALLBACKS&gt; | 转到的 `Callbacks` 对象。 |

any
