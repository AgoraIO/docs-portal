`Player` 接口继承 `Displayer` 接口，并且增加用于操作白板回放的属性。

- [Displayer](/zh-CN/api-reference/whiteboard/web/interfaces/displayer)

  - Player

## 属性

<a id="begintimestamp"></a>

### beginTimestamp

```ts title="TypeScript"
beginTimestamp: number
```

回放的起始时间（Unix 时间戳，单位为毫秒）。

<a id="callbacks"></a>

### callbacks

```ts title="TypeScript"
callbacks: Callbacks<CALLBACKS>
```

回调函数。你可以通过如下方式设置回调函数：

##### `example`

```text title="Text"
// 监听到 onSliceChanged 回调
function sliceChangeCallback(slice) {

}

// 注册回调函数
displayer.callbacks.on("onSliceChanged", sliceChangeCallback);

// 注销回调函数
displayer.callbacks.off("onSliceChanged", sliceChangeCallback);

// 仅仅回调一次
displayer.callbacks.once("onSliceChanged", function(slice) {

});
```

<a id="devicetype"></a>

### deviceType

```ts title="TypeScript"
deviceType: DeviceType
```

该客户端的设备类型，决定 SDK 如何处理鼠标事件和触碰事件。

<a id="disablecameratransform"></a>

### disableCameraTransform

```ts title="TypeScript"
disableCameraTransform: boolean
```

是否禁止用户通过触屏手势或鼠标滚轮调整视角（即移动或缩放视角）：

- `true`：禁止用户调整视角。
- `false`：（默认）允许用户调整视角。

**Note**

该属性不影响 `setCameraBound`、 `moveCamera`、 `moveCameraToContain` 方法的使用。

<a id="disableothersselectingbox"></a>

### disableOthersSelectingBox

```ts title="TypeScript"
disableOthersSelectingBox: boolean
```

是否隐藏其他人的鼠标移动到白板组件上时显示的高亮框。

##### `since`

2.12.0

- `true`：隐藏高亮框。
- `false`：（默认）不隐藏高亮框。

**Note**

该属性不影响自己的高亮框显示。

<a id="addmagixeventlistener"></a>

### addMagixEventListener

```ts title="TypeScript"
addMagixEventListener(event: string, listener: EventListener, options?: MagixEventListenerOptions): void
```

```ts title="TypeScript"
addMagixEventListener(event: string, listener: EventsListener, fireInterval: number): void
```

注册自定义事件监听。

成功注册后，你可以接收到对应的自定义事件通知。

**Note**

对于同名的自定义事件，SDK 仅支持触发一个回调。

#### 参数

| 名称 | 描述 |
| --- | --- |
| event: string | 想要监听的自定义事件名称。 |
| listener: EventListener | 自定义事件回调，详见 [EventListener](/zh-CN/api-reference/whiteboard/web/globals#eventlistener)。如果添加多个同名的事件回调，则之前添加的回调会被覆盖。 |
| Optional options: MagixEventListenerOptions | 自从 v2.15.2。 自定义事件监听设置选项。详见 [MagixEventListenerOptions](/zh-CN/api-reference/whiteboard/web/globals#magixeventlisteneroptions)。 |

#### 返回值

void

注册高频自定义事件监听。

成功注册后，你可以接收到对应的自定义事件通知。

**Note**

对于同名的自定义事件，SDK 仅支持触发一个回调。

##### `example`

```text title="Text"
function listener(events) {
    // events 是一个数组
    for (const event of events) {
        // 回调事件 event
    }
}
displayer.addMagixEventListener("my-event", listener, 100);
```

#### 参数

| 名称 | 描述 |
| --- | --- |
| event: string | 想要监听的自定义事件名称。 |
| listener: EventsListener | 自定义事件回调，详见 [EventsListener](/zh-CN/api-reference/whiteboard/web/globals#eventslistener)。如果添加多个同名的事件回调，则之前添加的回调会被覆盖。 |
| fireInterval: number | SDK 触发回调的频率，单位为毫秒。该参数最小值为 500 ms，如果设置为低于该值会被重置为 500 ms。 |

#### 返回值

void

<a id="converttopointinworld"></a>

### convertToPointInWorld

```ts title="TypeScript"
convertToPointInWorld(point: { x: number; y: number }): { x: number; y: number }
```

转换白板上点的坐标。

该方法可以将屏幕坐标系（以屏幕左上角为原点，横轴为 X 轴，正方向向右，纵轴为 Y 轴，正方向向下） 中的坐标转换为世界坐标系（以白板初始化时的中点为原点，横轴为 X 轴，正方向向右，纵轴为 Y 轴，正方向向下） 中的坐标。

#### 参数

| 名称 | 描述 |
| --- | --- |
| point: \{ x: number; y: number \} | 点在屏幕坐标系中的坐标。 |

#### 返回值

\{x: number; y: number \}

点在世界坐标系中的坐标。

- ##### x: number

  点在世界坐标系上的 X 轴坐标。
- ##### y: number

  点在世界坐标系上的 Y 轴坐标。

<a id="createscenescallback"></a>

### createScenesCallback

```ts title="TypeScript"
createScenesCallback(path: string, callbacks?: Partial<ScenesCallbacks>): ScenesCallbacksNode | null
```

创建场景目录的监听器对象。

成功创建监听器对象后，当指定场景目录下的场景、子场景目录发生变化时，SDK 会触发你在 [ScenesCallbacks](/zh-CN/api-reference/whiteboard/web/globals#scenescallbacks) 中实现的回调。 当不再需要使用已创建的监听器时，需要调用 [dispose](/zh-CN/api-reference/whiteboard/web/interfaces/scenes-callbacks-node#dispose) 来释放该监听器对象。

##### `note`

- 该方法需要在加入白板房间后调用。
- 对于每个场景目录，仅支持创建一个监听器对象。如果需要创建新的监听器对象，必须先调用 `dispose` 释放已创建的监听器对象。

#### 参数

| 名称 | 描述 |
| --- | --- |
| path: string | 场景目录的路径。如果你传入的是场景路径，SDK 会将监听对象设置为其父场景目录。 |
| Optional callbacks: Partial&lt;ScenesCallbacks&gt; | 需要监听的回调。详见 `ScenesCallbacks`。 |

#### 返回值

[ScenesCallbacksNode](/zh-CN/api-reference/whiteboard/web/interfaces/scenes-callbacks-node) | null

- 方法调用成功时，返回 [ScenesCallbacksNode](/zh-CN/api-reference/whiteboard/web/interfaces/scenes-callbacks-node) 对象。
- 方法调用失败时，返回 `null`。方法调用失败可能是因为指定的场景目录不存在。

<a id="screenshottocanvasasync"></a>

### screenshotToCanvasAsync

```ts title="TypeScript"
screenshotToCanvasAsync(context: CanvasRenderingContext2D, scenePath: string, width: number, height: number, camera: Camera, ratio?: number, timeout?: number): Promise<void>
```

等待目标场景的图片加载完成后生成屏幕快照，写入指定的 `CanvasRenderingContext2D` 对象中。

##### `note`

- 该功能处于实验阶段。
- 如果目标场景的图片无法完成加载，则该函数无法返回屏幕快照，你需要自行处理超时逻辑。
- 如果你希望生成的屏幕快照不包含图片，请使用 [screenshotToCanvas](/zh-CN/api-reference/whiteboard/web/interfaces/player#screenshottocanvas)。

#### 参数

| 名称 | 描述 |
| --- | --- |
| context: CanvasRenderingContext2D | CanvasRenderingContext2D 对象。 |
| scenePath: string | 场景的路径。你可以通过 `room.state.sceneState.scenePath` 获取当前场景。 |
| width: number | 屏幕快照的宽度。 |
| height: number | 屏幕快照的高度。 |
| camera: Camera | 视角的描述。详见 [Camera](/zh-CN/api-reference/whiteboard/web/globals#camera)。 |
| Optional ratio: number | 设备像素比。该参数为可选参数，如果不填，则默认值为 1。 |
| Optional timeout: number | 图片加载的超时时间 (ms)，默认为永不超时，只能设为大于 `0` 的数。图片的加载时间超过该值后，SDK 会直接进行下一步绘制操作，而不会等待图片加载完成。 |

#### 返回值

Promise &lt; void &gt;
