### getBroadcasterId()

```cpp
Long com.herewhite.sdk.domain.BroadcastState.getBroadcasterId()
```

获取主播模式用户在房间中的用户 ID。

2.4.8 版本前，当房间中没有主播时，错误地返回了 0。 2.4.8 版本修复了该问题。修复后，当房间内没有主播时，返回值为 null。

#### Returns

主播模式用户的用户 ID。
