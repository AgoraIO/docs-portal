`AudioMixerBridge` 接口，用于桥接 Agora RTC SDK 的混音方法和白板 SDK。

### `自从`

2.9.15

当用户同时使用音视频功能和互动白板，且在互动白板中展示的动态 PPT 包含音频文件时，可能遇到以下问题：

- 播放 PPT 内的音频时声音很小。
- 播放 PPT 内的音频时有回声。

为解决上述问题，你可以使用 `AudioMixerBridge` 接口，以调用 RTC SDK 的混音方法播放动态 PPT 中的音频文件。

### `注解`

该接口基于 Agora RTC SDK 的混音方法设计，如果你使用的实时音视频 SDK 不是 Agora RTC SDK，但也具有混音接口和混音状态回调，你也可以调用 `AudioMixerBridge` 接口。

### startAudioMixing()

```cpp
void com.herewhite.sdk.AudioMixerBridge.startAudioMixing(String filepath, boolean loopback, boolean replace, int cycle)
```

开始播放音乐文件及混音。

进行混音后，需要将混音结果通过 `setMediaState` 传递给动态 PPT 内部。

#### Parameters

| Name | Description |
| --- | --- |
| filepath | 指定需要混音的本地或在线音频文件的绝对路径。 |
| loopback | 是否只有本地用户可以听到混音后的音频流：<br />- `true`：只有本地可以听到混音的音频流。<br />- `false`：本地和对方都可以听到混音的音频流。 |
| replace | 是否播放麦克风采集的音频：<br />- `true`： 只播放音频文件，不播放麦克风采集的音频。<br />- `false`: 将音频文件和麦克风采集的音频混音后播放。 |
| cycle | 音乐文件的播放次数。<br />- ≥ 0: 播放次数。例如， `0` 表示不播放； `1` 表示播放 `1` 次。<br />- -1: 无限循环播放。 |
