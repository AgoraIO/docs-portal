### convertToPointInWorld()

```cpp
void com.herewhite.sdk.Displayer.convertToPointInWorld(double x, double y, final Promise<Point > promise)
```

转换白板上点的坐标。

该方法可以将 Android 内部坐标系（以屏幕左上角为原点）中的坐标转换为世界坐标系（以白板初始化时的中点为原点）坐标。

#### Parameters

| Name | Description |
| --- | --- |
| x | 点在 Android 坐标系中的 X 轴坐标。 |
| y | 点在 Android 坐标系中的 Y 轴坐标。 |
| promise | `Promise<Point>` 接口实例，详见 `Promise`。你可以通过该接口获取 `convertToPointInWorld` 的调用结果：<br />- 如果方法调用成功，将返回点在世界坐标系上的坐标。详见 [Point](/zh-CN/api-reference/whiteboard/android/classcom-1-1herewhite-1-1sdk-1-1domain-1-1-point)。<br />- 如果方法调用失败，将返回错误信息。 |


设置白板的背景色。

##### `自从`

2.4.14

##### `**[弃用:](/zh-CN/api-reference/whiteboard/android/deprecated#_deprecated000005)**`

该方法已废弃，请改用 Android 系统的 [setBackgroundColor](https://developer.android.com/reference/android/view/View#setBackgroundColor(int)) 方法。

该方法仅对本地白板有效，不会影响房间内其他用户白板的背景色。

#### Parameters

| Name | Description |
| --- | --- |
| intColor | 白板的背景色，格式为 16 进制 RGBA 定义下的 Hex 值。注意 A 属性不能达到使白板透明的效果。 |
