### setCustomGlobalStateClass()

```cpp
static<T extends GlobalState > void com.herewhite.sdk.domain.WhiteDisplayerState.setCustomGlobalStateClass(Class<T > classOfT) static
```

设置自定义 `GlobalState` 类。

##### `自从`

2.4.8

设置后，所有 `GlobalState` 都会转换为该类的实例。

#### Parameters

| Name | Description |
| --- | --- |
| &lt;T&gt; | 类型约束，自定义的 `GlobalState` 类必须继承 `GlobalState` 类。 |
| classOfT | 自定义的 `GlobalState` 类。 |

### getRoomMembers()

```cpp

```

获取房间的用户列表。

##### `注解`

房间的用户列表仅包含互动模式（具有读写权限）的用户，不包含订阅模式（只读权限）的用户。

#### Returns
