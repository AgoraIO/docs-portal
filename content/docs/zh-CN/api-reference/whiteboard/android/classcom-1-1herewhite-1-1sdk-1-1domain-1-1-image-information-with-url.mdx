### ImageInformationWithUrl()

```cpp
com.herewhite.sdk.domain.ImageInformationWithUrl.ImageInformationWithUrl(Double centerX, Double centerY, Double width, Double height, String url)
```

`ImageInformationWithUrl` 构造方法，用于初始化 `ImageInformationWithUrl` 实例。

#### Parameters

| Name | Description |
| --- | --- |
| centerX | 图片的中心在世界坐标系（以白板初始化时的中心点为原点的坐标系）中的横向坐标。 |
| centerY | 图片的中心在世界坐标系（以白板初始化时的中心点为原点的坐标系）中的纵向坐标。 |
| width | 图片的宽度，单位为像素。 |
| height | 图片的高度，单位为像素。 |
| url | 图片的 URL 地址。必须确保 app 客户端能访问该 URL，否则无法正常展示图片。 |
