`CameraBound` 类，用于设置视角边界。

视角边界指白板场景内，用户可以移动视角的范围。当视角超出视角边界时，视角会被拉回。

### `自从`

2.5.0

### getDamping()

```cpp

```

获取用户将视角移出视角边界时感受到的阻力。

#### Returns

用户将视角移出视角边界时感受到的阻力。返回值范围为 [0.0,1.0]。数值越大，用户感受到的阻力越大。

<a id="ac387fa1a63ff3df2a70276c8d1f52353"></a>

### setDamping()

```cpp
void com.herewhite.sdk.domain.CameraBound.setDamping(Double damping)
```

设置用户将视角移出视角边界时感受到的阻力。

#### Parameters

| Name | Description |
| --- | --- |
| damping | 阻力大小，取值范围为 [0.0,1.0]。取值越大，用户感受到的阻力越大。<br />- `0.0`: 用户将视角移出视角边界时，完全感受不到阻力，但当其手指离开屏幕时，视角会恢复到原位。<br />- `1.0`: 用户完全无法将视角移出视角边界。 |
