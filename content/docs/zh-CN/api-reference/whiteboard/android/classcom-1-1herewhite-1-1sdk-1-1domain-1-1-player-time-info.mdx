### getBeginTimestamp()

```cpp
long com.herewhite.sdk.domain.PlayerTimeInfo.getBeginTimestamp()
```

获取白板回放的起始时间。

该方法会返回单位为毫秒的 Unix 时间戳，你需要自行转换为 UTC 时间。例如，如果返回 `1615370614269`，表示的 UTC 时间为 2021-03-10 18:03:34 GMT+0800。

#### Returns

Unix 时间戳，单位为毫秒。
