## 构造及析构函数说明

<a id="ae4917641a1b574ca9890df07a63be9dd"></a>

### PlayerConfiguration()

```cpp
com.herewhite.sdk.domain.PlayerConfiguration.PlayerConfiguration(String room, String roomToken)
```

回放房间的构造方法，用于初始化回放房间实例。

#### Parameters

| Name | Description |
| --- | --- |
| room | 房间 UUID，即房间唯一标识符，必须和加入互动白板房间实例时设置的房间 UUID 一致。 |
| roomToken | 用于鉴权的 [Room](/zh-CN/api-reference/whiteboard/android/classcom-1-1herewhite-1-1sdk-1-1-room) Token，必须是使用上面传入的房间 UUID 生成的 [Room](/zh-CN/api-reference/whiteboard/android/classcom-1-1herewhite-1-1sdk-1-1-room) Token。 |
