### createSlideApp()

```cpp
static WindowAppParam com.herewhite.sdk.domain.WindowAppParam.createSlideApp(String taskUuid, String prefixUrl, String title) static
```

#### Parameters

| Name | Description |
| --- | --- |
| taskUuid | 转换任务的 UUID。 |
| prefixUrl | 以 http 或 https 开头的 url, 例如 [https://convertcdn.netless.link/dynamicConvert](https://convertcdn.netless.link/dynamicConvert). 请注意不以 / 结尾。 |
| title | 窗口标题。用于展示插入的文档。 |

`WindowAppParam` 对象。
