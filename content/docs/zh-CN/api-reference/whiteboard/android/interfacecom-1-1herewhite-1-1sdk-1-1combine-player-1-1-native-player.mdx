### hasEnoughBuffer()

```cpp
boolean com.herewhite.sdk.combinePlayer.NativePlayer.hasEnoughBuffer()
```

获取是否能够不经过缓冲，直接播放视频。

#### Returns

是否能够不经过缓冲，直接播放视频：

- true：可以不经过缓冲，直接播放视频。
- false：需要经过缓冲才能播放视频。
