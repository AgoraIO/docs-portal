`PptParams` 类，用于设置动态 PPT 参数。

## 成员函数说明

<a id="a0f6ce35f4c09ea8a8ae7f4fd4608399e"></a>

### isUseServerWrap()

```cpp
boolean com.herewhite.sdk.WhiteSdkConfiguration.PptParams.isUseServerWrap()
```

获取是否开启动态 PPT 服务端排版功能。

#### Returns

动态 PPT 服务端排版功能的开启状态：

- `true`：开启。
- `false`：关闭。

<a id="a21663a076e81bcbeedc8c23511b129ea"></a>

### setUseServerWrap()

```cpp
void com.herewhite.sdk.WhiteSdkConfiguration.PptParams.setUseServerWrap(boolean useServerWrap)
```

开启/关闭动态 PPT 服务端排版功能。

##### `自从`

2.11.16

自 2021 年 2 月 10 日起，将 PPTX 文件转换为 HTML 网页时，Agora Interactive 白板服务端支持对 PPTX 文件进行排版，以确保 PPTX 文件的文本在各个平台上的呈现保持一致。

##### `注解`

Note: 自 2.12.27 版本起， `useServerWrap` 的默认值由 `false` 改为 `true`。

#### Parameters

| Name | Description |
| --- | --- |
| useServerWrap | 是否开启服务端排版功能：<br />- `true`：（默认）开启。<br />- `false`：关闭。 |
