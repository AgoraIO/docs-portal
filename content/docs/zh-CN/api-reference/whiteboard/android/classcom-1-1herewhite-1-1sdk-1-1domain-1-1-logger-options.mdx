### getDisableReportLog()

```cpp
Boolean com.herewhite.sdk.domain.LoggerOptions.getDisableReportLog()
```

获取是否关闭日志上报。

#### Returns

是否关闭日志上报：

- `true`：关闭。
- `false`：开启。

### setDisableReportLog()

```cpp
void com.herewhite.sdk.domain.LoggerOptions.setDisableReportLog(Boolean disableReportLog)
```

开启/关闭日志上报。

##### `**[弃用:](/zh-CN/api-reference/whiteboard/android/deprecated#_deprecated000007)**`

该方法已废弃。请使用 `getReportDebugLogMode`、 `getReportQualityMode` 和 `getReportLevelMask`。

#### Parameters

| Name | Description |
| --- | --- |
| disableReportLog | 是否关闭日志上报；<br />- `true`：关闭。<br />- `false`：（默认）开启日志上报。 |
