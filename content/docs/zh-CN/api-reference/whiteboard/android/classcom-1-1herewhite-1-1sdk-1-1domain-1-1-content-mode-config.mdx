### setScale()

```cpp
void com.herewhite.sdk.domain.ContentModeConfig.setScale(Double scale)
```

设置视角边界的缩放比例。

##### `注解`

该方法仅在以下缩放模式下生效：

- `CENTER`
- `CENTER_INSIDE`
- `CENTER_INSIDE_SCALE`
- `CENTER_CROP_SPACE`

#### Parameters

| Name | Description |
| --- | --- |
| scale | 视角边界的缩放比例，默认值为 1.0，即保持视角边界的原始大小。 |
