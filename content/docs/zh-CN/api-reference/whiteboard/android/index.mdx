<a id="md_sdk_mainpage"></a> 声网通过全球部署的虚拟网络，提供可以灵活搭配的 API 组合，提供稳定可靠、功能丰富的实时互动白板。

- `WhiteSdk` 类提供初始化互动白板 SDK、加入互动白板实时房间、创建白板回放的主要方法。
- `Room` 类提供管理互动白板实时房间的方法。
- `Player` 类提供控制白板回放的方法。
- `Displayer` 类为 `Room` 类和 `Player` 类的父类。 `Room` 和 `Player` 实例都可以调用该类中的方法。
