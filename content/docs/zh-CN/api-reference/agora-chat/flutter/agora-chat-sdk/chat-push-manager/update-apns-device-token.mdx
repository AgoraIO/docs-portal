Updates the APNs push token.

**Throws** A description of the issue that caused this exception. See [ChatError](/zh-CN/api-reference/agora-chat/flutter/agora-chat-sdk/chat-error)

## Parameters

| Name | Description |
| --- | --- |
| `token` | The APNs push token. |

```dart title="Dart"
Future<void> updateAPNsDeviceToken(String token)
```

## Implementation [#source]

```dart title="Dart"
Future<void> updateAPNsDeviceToken(String token) async {
  if (Platform.isIOS) {
    Map req = {'token': token};
    Map result = await PushChannel.invokeMethod(
        ChatMethodKeys.updateAPNsPushToken, req);
    try {
      ChatError.hasErrorFromResult(result);
    } on ChatError catch (e) {
      throw e;
    }
  }
}
```
