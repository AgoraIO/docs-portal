Updates the push message style. The default value is [DisplayStyle.Simple](/zh-CN/api-reference/agora-chat/flutter/agora-chat-sdk/display-style).

**Throws** A description of the issue that caused this exception. See [ChatError](/zh-CN/api-reference/agora-chat/flutter/agora-chat-sdk/chat-error)

## Parameters

| Name | Description |
| --- | --- |
| `displayStyle` | The push message display style. |

```dart title="Dart"
Future<void> updatePushDisplayStyle(DisplayStyle displayStyle)
```

<a id="source"></a>

## Implementation

```dart title="Dart"
Future<void> updatePushDisplayStyle(DisplayStyle displayStyle) async {
  Map req = {'pushStyle': displayStyle == DisplayStyle.Simple ? 0 : 1};
  Map result =
      await PushChannel.invokeMethod(ChatMethodKeys.updateImPushStyle, req);
  try {
    ChatError.hasErrorFromResult(result);
  } on ChatError catch (e) {
    throw e;
  }
}
```
