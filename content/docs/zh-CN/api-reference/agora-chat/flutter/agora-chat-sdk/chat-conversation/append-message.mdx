Inserts a message to the end of a conversation in the local database.

Make sure you set the conversation ID as that of the conversation where you want to insert the message.

**Throws** A description of the exception. See [ChatError](/zh-CN/api-reference/agora-chat/flutter/agora-chat-sdk/chat-error).

## Parameters

| Name | Description |
| --- | --- |
| `message` | The message instance. |

```dart title="Dart"
Future<void> appendMessage(ChatMessage message)
```

## Implementation [#source]

```dart title="Dart"
Future<void> appendMessage(ChatMessage message) async {
  Map req = this._toJson();
  req['msg'] = message.toJson();
  Map result = await _emConversationChannel.invokeMethod(
      ChatMethodKeys.appendMessage, req);
  try {
    ChatError.hasErrorFromResult(result);
  } on ChatError catch (e) {
    throw e;
  }
}
```
