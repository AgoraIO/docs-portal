Updates a message in the local database.

The latestMessage of the conversation and other properties will be updated accordingly. The message ID of the message, however, remains the same.

**Throws** A description of the exception. See [ChatError](/zh-CN/api-reference/agora-chat/flutter/agora-chat-sdk/chat-error).

## Parameters

| Name | Description |
| --- | --- |
| `message` | The message to be updated. |

```dart title="Dart"
Future<void> updateMessage(ChatMessage message)
```

## Implementation [#source]

```dart title="Dart"
Future<void> updateMessage(ChatMessage message) async {
  Map req = this._toJson();
  req['msg'] = message.toJson();
  Map result = await _emConversationChannel.invokeMethod(
      ChatMethodKeys.updateConversationMessage, req);
  ChatError.hasErrorFromResult(result);
  try {
    ChatError.hasErrorFromResult(result);
  } on ChatError catch (e) {
    throw e;
  }
}
```
