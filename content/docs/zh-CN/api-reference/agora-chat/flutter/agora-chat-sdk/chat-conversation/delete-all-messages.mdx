Deletes all the messages of the conversation from both the memory and local database.

**Throws** A description of the exception. See [ChatError](/zh-CN/api-reference/agora-chat/flutter/agora-chat-sdk/chat-error).

```dart title="Dart"
Future<void> deleteAllMessages()
```

<a id="source"></a>

## Implementation

```dart title="Dart"
Future<void> deleteAllMessages() async {
  Map result = await _emConversationChannel.invokeMethod(
      ChatMethodKeys.clearAllMessages, this._toJson());
  try {
    ChatError.hasErrorFromResult(result);
  } on ChatError catch (e) {
    throw e;
  }
}
```
