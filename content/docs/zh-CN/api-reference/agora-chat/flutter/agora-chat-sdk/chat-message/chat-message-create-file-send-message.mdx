Creates a file message for sending.

- For a one-to-one chat, it is the username of the peer user.
- For a group chat, it is the group ID.
- For a chat room, it is the chat room ID.

**Return** The message instance.

## Parameters

| Name | Description |
| --- | --- |
| `targetId` | The ID of the message recipient. |
| `filePath` | The file path. |
| `displayName` | The file name. |
| `fileSize` | The file size in bytes. |

```dart title="Dart"
ChatMessage.createFileSendMessage({required String targetId, required String filePath, String? displayName, ChatType chatType = ChatType.Chat, int? fileSize})
```

ChatMessage.createFileSendMessage({

  String? displayName,
