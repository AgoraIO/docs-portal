The contact updates listener callback.

## Parameters

| Name | Description |
| --- | --- |
| [onContactAdded](/zh-CN/api-reference/agora-chat/flutter/agora-chat-sdk/contact-event-handler/on-contact-added) | Current user is added as a contact by another user callback. |
| [onContactDeleted](/zh-CN/api-reference/agora-chat/flutter/agora-chat-sdk/contact-event-handler/on-contact-deleted) | Current user is removed from the contact list by another user callback. |
| [onContactInvited](/zh-CN/api-reference/agora-chat/flutter/agora-chat-sdk/contact-event-handler/on-contact-invited) | Current user receives a friend request callback. |
| [onFriendRequestAccepted](/zh-CN/api-reference/agora-chat/flutter/agora-chat-sdk/contact-event-handler/on-friend-request-accepted) | A friend request is approved callback. |
| [onFriendRequestDeclined](/zh-CN/api-reference/agora-chat/flutter/agora-chat-sdk/contact-event-handler/on-friend-request-declined) | A friend request is declined callback. |
