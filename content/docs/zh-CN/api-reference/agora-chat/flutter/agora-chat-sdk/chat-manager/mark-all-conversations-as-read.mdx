Marks all messages as read.

This method is for the local conversations only.

**Throws** A description of the exception. See [ChatError](/zh-CN/api-reference/agora-chat/flutter/agora-chat-sdk/chat-error).

```dart title="Dart"
Future<void> markAllConversationsAsRead()
```

## Implementation [#source]

```dart title="Dart"
Future<void> markAllConversationsAsRead() async {
  Map result =
      await ChatChannel.invokeMethod(ChatMethodKeys.markAllChatMsgAsRead);
  try {
    ChatError.hasErrorFromResult(result);
  } on ChatError catch (e) {
    throw e;
  }
}
```
