Deletes a reaction.

**Throws** A description of the exception. See [ChatError](/zh-CN/api-reference/agora-chat/flutter/agora-chat-sdk/chat-error).

## Parameters

| Name | Description |
| --- | --- |
| `messageId` | The message ID. |
| `reaction` | The reaction content. |

```dart title="Dart"
Future<void> removeReaction({required String messageId, required String reaction})
```

## Implementation [#source]

```dart title="Dart"
Future<void> removeReaction({
  required String messageId,
  required String reaction,
}) async {
  Map req = {"reaction": reaction, "msgId": messageId};
  Map result =
      await ChatChannel.invokeMethod(ChatMethodKeys.removeReaction, req);
  try {
    ChatError.hasErrorFromResult(result);
  } on ChatError catch (e) {
    throw e;
  }
}
```
