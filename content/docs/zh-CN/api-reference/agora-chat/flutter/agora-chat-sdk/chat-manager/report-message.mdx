Report violation message

**Throws** A description of the exception. See [ChatError](/zh-CN/api-reference/agora-chat/flutter/agora-chat-sdk/chat-error).

## Parameters

| Name | Description |
| --- | --- |
| `messageId` | Violation Message ID |
| `tag` | The report type (For example: involving pornography and terrorism). |
| `reason` | The reason for reporting. |

```dart title="Dart"
Future<void> reportMessage({required String messageId, required String tag, required String reason})
```

## Implementation

```dart title="Dart"
Future<void> reportMessage({
  required String messageId,
  required String tag,
  required String reason,
}) async {
  Map req = {"msgId": messageId, "tag": tag, "reason": reason};
  Map result =
      await ChatChannel.invokeMethod(ChatMethodKeys.reportMessage, req);
  try {
    ChatError.hasErrorFromResult(result);
  } on ChatError catch (e) {
    throw e;
  }
}
```
