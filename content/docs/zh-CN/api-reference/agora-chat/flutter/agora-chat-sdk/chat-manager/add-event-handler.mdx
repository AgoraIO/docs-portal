Adds the chat event handler. After calling this method, you can handle for chat event when they arrive.

## Parameters

| Name | Description |
| --- | --- |
| `identifier` | The custom handler identifier, is used to find the corresponding handler. |
| `handler` | The handler for chat event. See [ChatEventHandler](/zh-CN/api-reference/agora-chat/flutter/agora-chat-sdk/chat-event-handler). |

```dart title="Dart"
void addEventHandler(String identifier, ChatEventHandler handler)
```

## Implementation [#source]

```dart title="Dart"
void addEventHandler(
  String identifier,
  ChatEventHandler handler,
) {
  _eventHandlesMap[identifier] = handler;
}
```
