Enable MeiZu Push on MeiZu devices.

## Parameters

| Name | Description |
| --- | --- |
| `appId` | The app ID for MeiZu Push. |
| `appKey` | The app key for MeiZu Push. |

```dart title="Dart"
void enableMeiZuPush(String appId, String appKey)
```

<a id="source"></a>

## Implementation

```dart title="Dart"
void enableMeiZuPush(String appId, String appKey) {
  _pushConfig.mzAppId = appId;
  _pushConfig.mzAppKey = appKey;
}
```
