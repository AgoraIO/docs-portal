Enables Apple Push Notification service (APNs) on iOS devices.

## Parameters

| Name | Description |
| --- | --- |
| `certName` | The APNs certificate name. |

```dart title="Dart"
void enableAPNs(String certName)
```

<a id="source"></a>

## Implementation

```dart title="Dart"
void enableAPNs(String certName) {
  _pushConfig.enableAPNS = true;
  _pushConfig.apnsCertName = certName;
}
```
