Publishes a custom presence state.

**Throws** A description of the exception. See [ChatError](/zh-CN/api-reference/agora-chat/flutter/agora-chat-sdk/chat-error).

## Parameters

| Name | Description |
| --- | --- |
| `description` | The extension information of the presence state. It can be set as nil. |

```dart title="Dart"
Future<void> publishPresence(String description)
```

## Implementation [#source]

```dart title="Dart"
Future<void> publishPresence(
  String description,
) async {
  Map req = {'desc': description};
  Map result = await _channel.invokeMethod(
      ChatMethodKeys.presenceWithDescription, req);
  try {
    ChatError.hasErrorFromResult(result);
  } on ChatError catch (e) {
    throw e;
  }
}
```
