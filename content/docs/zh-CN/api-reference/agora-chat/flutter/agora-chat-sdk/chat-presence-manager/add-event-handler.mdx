Adds the presence event handler. After calling this method, you can handle for new presence event when they arrive.

## Parameters

| Name | Description |
| --- | --- |
| `identifier` | The custom handler identifier, is used to find the corresponding handler. |
| `handler` | The handle for presence event. See [ChatPresenceEventHandler](/zh-CN/api-reference/agora-chat/flutter/agora-chat-sdk/chat-presence-event-handler). |

```dart title="Dart"
void addEventHandler(String identifier, ChatPresenceEventHandler handler)
```

## Implementation [#source]

```dart title="Dart"
void addEventHandler(
  String identifier,
  ChatPresenceEventHandler handler,
) {
  _eventHandlesMap[identifier] = handler;
}
```
