Declines a group request.

Only the group owner or admin can call this method.

**Throws** A description of the exception. See [ChatError](/zh-CN/api-reference/agora-chat/flutter/agora-chat-sdk/chat-error).

## Parameters

| Name | Description |
| --- | --- |
| `groupId` | The group ID. |
| `username` | The username of the user who sends a request to join the group. |
| `reason` | The reason of declining. |

```dart title="Dart"
Future<void> declineJoinApplication(String groupId, String username, {String? reason})
```

## Implementation [#source]

```dart title="Dart"
Future<void> declineJoinApplication(
  String groupId,
  String username, {
  String? reason,
}) async {
  Map req = {'groupId': groupId, 'username': username};
  req.setValueWithOutNull('reason', reason);

  Map result =
      await _channel.invokeMethod(ChatMethodKeys.declineJoinApplication, req);
  try {
    ChatError.hasErrorFromResult(result);
  } on ChatError catch (e) {
    throw e;
  }
}
```
