Gets the allow list of the group from the server.

Only the group owner or admin can call this method.

**Return** The allow list of the group.

**Throws** A description of the exception. See [ChatError](/zh-CN/api-reference/agora-chat/flutter/agora-chat-sdk/chat-error).

## Parameters

| Name | Description |
| --- | --- |
| `groupId` | The group ID. |

```dart title="Dart"
Future<List<String>> fetchAllowListFromServer(String groupId)
```

## Implementation

```dart title="Dart"
Future<List<String>> fetchAllowListFromServer(String groupId) async {
  Map req = {'groupId': groupId};
  Map result = await _channel.invokeMethod(
      ChatMethodKeys.getGroupWhiteListFromServer, req);
  try {
    List<String> list = [];
    ChatError.hasErrorFromResult(result);
    result[ChatMethodKeys.getGroupWhiteListFromServer]?.forEach((element) {
      if (element is String) {
        list.add(element);
      }
    });
    return list;
  } on ChatError catch (e) {
    throw e;
  }
}
```
