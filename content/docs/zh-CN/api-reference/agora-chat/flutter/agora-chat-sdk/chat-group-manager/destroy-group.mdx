Destroys the group instance.

Only the group owner can call this method.

**Throws** A description of the exception. See [ChatError](/zh-CN/api-reference/agora-chat/flutter/agora-chat-sdk/chat-error).

## Parameters

| Name | Description |
| --- | --- |
| `groupId` | The group ID. |

```dart title="Dart"
Future<void> destroyGroup(String groupId)
```

## Implementation [#source]

```dart title="Dart"
Future<void> destroyGroup(String groupId) async {
  Map req = {'groupId': groupId};
  Map result = await _channel.invokeMethod(ChatMethodKeys.destroyGroup, req);
  try {
    ChatError.hasErrorFromResult(result);
  } on ChatError catch (e) {
    throw e;
  }
}
```
