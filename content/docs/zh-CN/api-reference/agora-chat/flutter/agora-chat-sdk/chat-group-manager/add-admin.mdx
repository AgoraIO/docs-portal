Adds a group admin.

Only the group owner can call this method and group admins cannot.

**Throws** A description of the exception. See [ChatError](/zh-CN/api-reference/agora-chat/flutter/agora-chat-sdk/chat-error).

## Parameters

| Name | Description |
| --- | --- |
| `groupId` | The group ID. |
| `memberId` | The username of the admin to add. |

```dart title="Dart"
Future<void> addAdmin(String groupId, String memberId)
```

## Implementation [#source]

```dart title="Dart"
Future<void> addAdmin(
  String groupId,
  String memberId,
) async {
  Map req = {'groupId': groupId, 'admin': memberId};
  Map result = await _channel.invokeMethod(ChatMethodKeys.addAdmin, req);
  try {
    ChatError.hasErrorFromResult(result);
  } on ChatError catch (e) {
    throw e;
  }
}
```
