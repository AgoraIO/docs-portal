Unmutes group members.

Only the group owner or admin can call this method.

**Throws** A description of the exception. See [ChatError](/zh-CN/api-reference/agora-chat/flutter/agora-chat-sdk/chat-error).

## Parameters

| Name | Description |
| --- | --- |
| `groupId` | The group ID. |
| `members` | The list of members to be muted. |

```dart title="Dart"
Future<void> unMuteMembers(String groupId, List<String> members)
```

## Implementation

```dart title="Dart"
Future<void> unMuteMembers(
  String groupId,
  List<String> members,
) async {
  Map req = {'groupId': groupId, 'members': members};
  Map result = await _channel.invokeMethod(ChatMethodKeys.unMuteMembers, req);
  try {
    ChatError.hasErrorFromResult(result);
  } on ChatError catch (e) {
    throw e;
  }
}
```
