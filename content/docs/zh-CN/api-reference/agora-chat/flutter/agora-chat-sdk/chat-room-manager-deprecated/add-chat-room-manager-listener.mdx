Registers a chat room manager listener.

After registering the chat room manager listener, you can listen for events in [ChatRoomManagerListener](/zh-CN/api-reference/agora-chat/flutter/agora-chat-sdk/chat-room-manager-listener), for example, users joining and exiting the chat room, adding the specified member to the chat group mute list, updating the chat room allow list, and destroying the chat room.

To stop listening for chat room manager, call [removeChatRoomManagerListener](/zh-CN/api-reference/agora-chat/flutter/agora-chat-sdk/chat-room-manager-deprecated/remove-chat-room-manager-listener).

## Parameters

| Name | Description |
| --- | --- |
| `listener` | A chat room listener. See [ChatRoomManagerListener](/zh-CN/api-reference/agora-chat/flutter/agora-chat-sdk/chat-room-manager-listener). |
