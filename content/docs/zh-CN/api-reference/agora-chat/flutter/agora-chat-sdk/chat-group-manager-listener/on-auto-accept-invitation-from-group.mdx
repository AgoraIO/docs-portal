Occurs when the group invitation is accepted automatically. For settings, see [ChatOptions.autoAcceptGroupInvitation](/zh-CN/api-reference/agora-chat/flutter/agora-chat-sdk/chat-options/auto-accept-group-invitation). The SDK will join the group before notifying the app of the acceptance of the group invitation.

## Parameters

| Name | Description |
| --- | --- |
| `groupId` | The group ID. |
| `inviter` | The inviter ID. |
| `inviteMessage` | The invitation message. |

```dart title="Dart"
void onAutoAcceptInvitationFromGroup(String groupId, String inviter, String? inviteMessage)
```
