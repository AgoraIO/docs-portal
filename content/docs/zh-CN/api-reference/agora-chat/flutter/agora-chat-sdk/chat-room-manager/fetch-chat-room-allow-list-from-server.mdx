Gets the allow list from the server.

Only the chat room owner or admin can call this method.

**Return** The chat room allow list.

**Throws** A description of the exception. See [ChatError](/zh-CN/api-reference/agora-chat/flutter/agora-chat-sdk/chat-error).

## Parameters

| Name | Description |
| --- | --- |
| `roomId` | The chat room ID. |

```dart title="Dart"
Future<List<String>> fetchChatRoomAllowListFromServer(String roomId)
```

## Implementation [#source]

```dart title="Dart"
Future<List<String>> fetchChatRoomAllowListFromServer(String roomId) async {
  Map req = {"roomId": roomId};
  Map result = await _channel.invokeMethod(
      ChatMethodKeys.fetchChatRoomWhiteListFromServer, req);

  try {
    ChatError.hasErrorFromResult(result);
    List<String> list = [];
    result[ChatMethodKeys.fetchChatRoomWhiteListFromServer]
        ?.forEach((element) {
      if (element is String) {
        list.add(element);
      }
    });
    return list;
  } on ChatError catch (e) {
    throw e;
  }
}
```
