Removes the specified members from the block list of the chat room.

Only the chat room owner or admin can call this method.

**Throws** A description of the exception. See [ChatError](/zh-CN/api-reference/agora-chat/flutter/agora-chat-sdk/chat-error).

## Parameters

| Name | Description |
| --- | --- |
| `roomId` | The chat room ID. |
| `members` | The list of members to be removed from the block list. |

```dart title="Dart"
Future<void> unBlockChatRoomMembers(String roomId, List members)
```

## Implementation

```dart title="Dart"
Future<void> unBlockChatRoomMembers(
  String roomId,
  List members,
) async {
  Map req = {"roomId": roomId, "members": members};
  Map result =
      await _channel.invokeMethod(ChatMethodKeys.unBlockChatRoomMembers, req);
  try {
    ChatError.hasErrorFromResult(result);
  } on ChatError catch (e) {
    throw e;
  }
}
```
