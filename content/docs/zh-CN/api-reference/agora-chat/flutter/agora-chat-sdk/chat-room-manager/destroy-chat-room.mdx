Destroys a chat room.

Only the chat room owner can call this method.

**Throws** A description of the exception. See [ChatError](/zh-CN/api-reference/agora-chat/flutter/agora-chat-sdk/chat-error).

## Parameters

| Name | Description |
| --- | --- |
| `roomId` | The chat room ID. |

```dart title="Dart"
Future<void> destroyChatRoom(String roomId)
```

## Implementation [#source]

```dart title="Dart"
Future<void> destroyChatRoom(
  String roomId,
) async {
  Map req = {"roomId": roomId};
  Map result =
      await _channel.invokeMethod(ChatMethodKeys.destroyChatRoom, req);
  try {
    ChatError.hasErrorFromResult(result);
  } on ChatError catch (e) {
    throw e;
  }
}
```
