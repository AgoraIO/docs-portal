Adds the room event handler. After calling this method, you can handle for new room event when they arrive.

## Parameters

| Name | Description |
| --- | --- |
| `identifier` | The custom handler identifier, is used to find the corresponding handler. |
| `handler` | The handle for room event. See [ChatRoomEventHandler](/zh-CN/api-reference/agora-chat/flutter/agora-chat-sdk/chat-room-event-handler). |

```dart title="Dart"
void addEventHandler(String identifier, ChatRoomEventHandler handler)
```

## Implementation [#source]

```dart title="Dart"
void addEventHandler(
  String identifier,
  ChatRoomEventHandler handler,
) {
  _eventHandlesMap[identifier] = handler;
}
```
