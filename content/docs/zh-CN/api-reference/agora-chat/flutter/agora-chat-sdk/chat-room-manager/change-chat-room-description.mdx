Modifies the chat room description.

Only the chat room owner can call this method.

**Throws** A description of the exception. See [ChatError](/zh-CN/api-reference/agora-chat/flutter/agora-chat-sdk/chat-error).

## Parameters

| Name | Description |
| --- | --- |
| `roomId` | The chat room ID. |
| `description` | The new description of the chat room. |

```dart title="Dart"
Future<void> changeChatRoomDescription(String roomId, String description)
```

## Implementation [#source]

```dart title="Dart"
Future<void> changeChatRoomDescription(
  String roomId,
  String description,
) async {
  Map req = {"roomId": roomId, "description": description};
  Map result = await _channel.invokeMethod(
      ChatMethodKeys.changeChatRoomDescription, req);
  try {
    ChatError.hasErrorFromResult(result);
  } on ChatError catch (e) {
    throw e;
  }
}
```
