Removes the chat thread listener.

After adding a chat thread manager listener, you can remove this listener if you do not want to listen for it.

| Name | Description |
| --- | --- |
| `listener` | The chat thread listener to be removed. See [ChatThreadManagerListener](/zh-CN/api-reference/agora-chat/flutter/agora-chat-sdk/chat-thread-manager-listener). |
