Registers a group manager listener.

The registered listener needs to be used together with [removeGroupManagerListener](/zh-CN/api-reference/agora-chat/flutter/agora-chat-sdk/chat-group-manager-deprecated/remove-group-manager-listener).

## Parameters

| Name | Description |
| --- | --- |
| `listener` | The group manager listener to be registered. |
