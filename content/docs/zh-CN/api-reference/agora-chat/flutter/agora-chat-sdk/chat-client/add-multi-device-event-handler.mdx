Adds the multi-device event handler. After calling this method, you can handle for new room event when they arrive.

## Parameters

| Name | Description |
| --- | --- |
| `identifier` | The custom handler identifier, is used to find the corresponding handler. |
| `handler` | The handler multi-device event. See [ChatMultiDeviceEventHandler](/zh-CN/api-reference/agora-chat/flutter/agora-chat-sdk/chat-multi-device-event-handler). |

```dart title="Dart"
void addMultiDeviceEventHandler(String identifier, ChatMultiDeviceEventHandler handler)
```

## Implementation [#source]

```dart title="Dart"
void addMultiDeviceEventHandler(
  String identifier,
  ChatMultiDeviceEventHandler handler,
) {
  _multiDeviceEventHandler[identifier] = handler;
}
```
