Start contact and group, chatroom callback.

Reference: Call this method when you ui is ready, then will receive [ChatRoomEventHandler](/zh-CN/api-reference/agora-chat/flutter/agora-chat-sdk/chat-room-event-handler), [ContactEventHandler](/zh-CN/api-reference/agora-chat/flutter/agora-chat-sdk/contact-event-handler), [ChatGroupEventHandler](/zh-CN/api-reference/agora-chat/flutter/agora-chat-sdk/chat-group-event-handler) event.

```dart title="Dart"
Future<void> startCallback()
```

## Implementation [#source]

```dart title="Dart"
Future<void> startCallback() async {
  Map result = await ClientChannel.invokeMethod(ChatMethodKeys.startCallback);
  try {
    ChatError.hasErrorFromResult(result);
  } on ChatError catch (e) {
    throw e;
  }
}
```
