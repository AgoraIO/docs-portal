Initializes the SDK.

## Parameters

| Name | Description |
| --- | --- |
| `options` | The configurations: [ChatOptions](/zh-CN/api-reference/agora-chat/flutter/agora-chat-sdk/chat-options). Ensure that you set this parameter. |

```dart title="Dart"
Future<void> init(ChatOptions options)
```

<a id="source"></a>

## Implementation

```dart title="Dart"
Future<void> init(ChatOptions options) async {
  _options = options;
  EMLog.v('init: $options');
  await ClientChannel.invokeMethod(ChatMethodKeys.init, options.toJson());
  _currentUserId = await getCurrentUsername();
}
```
