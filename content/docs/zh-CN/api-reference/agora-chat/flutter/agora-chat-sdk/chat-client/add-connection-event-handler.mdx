Adds the connection event handler. After calling this method, you can handle for new room event when they arrive.

## Parameters

| Name | Description |
| --- | --- |
| `identifier` | The custom handler identifier, is used to find the corresponding handler. |
| `handler` | The handler for connection event. See [ConnectionEventHandler](/zh-CN/api-reference/agora-chat/flutter/agora-chat-sdk/connection-event-handler). |

```dart title="Dart"
void addConnectionEventHandler(String identifier, ConnectionEventHandler handler)
```

## Implementation [#source]

```dart title="Dart"
void addConnectionEventHandler(
  String identifier,
  ConnectionEventHandler handler,
) {
  _connectionEventHandler[identifier] = handler;
}
```
