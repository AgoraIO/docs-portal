Occurs when all members in the chat room are muted or unmuted.

- `true`: Yes;
- `false`: No.

## Parameters

| Name | Description |
| --- | --- |
| `roomId` | The chatroom ID. |
| `isAllMuted` | Whether all chat room members is muted or unmuted. |
