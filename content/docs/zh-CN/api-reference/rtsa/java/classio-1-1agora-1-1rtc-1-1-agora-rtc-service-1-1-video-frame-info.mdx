### rotation

```cpp
int io.agora.rtc.AgoraRtcService.VideoFrameInfo.rotation
```

已编码视频帧的旋转角度，取值如下：

- `0`：（默认）顺时针旋转 0 度。
- `1`：顺时针旋转 90 度。
- `2`：顺时针旋转 180 度。
- `3`：顺时针旋转 270 度。
