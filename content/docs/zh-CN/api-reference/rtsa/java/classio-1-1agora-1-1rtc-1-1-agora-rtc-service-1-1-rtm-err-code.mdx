### ERR_RTM_FAILED

```cpp
final int io.agora.rtc.AgoraRtcService.RtmErrCode.ERR_RTM_FAILED = 1 static
```

1: 通用错误。你可以根据日志文件排查问题。

### ERR_RTM_INVALID_APP_ID

```cpp
final int io.agora.rtc.AgoraRtcService.RtmErrCode.ERR_RTM_INVALID_APP_ID = 101 static
```

101: 云信令 (原 RTM) App ID 无效。你需要检查 App ID 是否符合要求。

### ERR_RTM_LOGIN_REJECTED


2: 声网服务器拒绝了登录云信令 (原 RTM) 的请求。你需要检查 RTM Token、App ID、User ID 是否符合要求。
