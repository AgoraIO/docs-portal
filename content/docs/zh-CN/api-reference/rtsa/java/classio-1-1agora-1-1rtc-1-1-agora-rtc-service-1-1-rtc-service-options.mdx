### domainLimit

```cpp
boolean io.agora.rtc.AgoraRtcService.RtcServiceOptions.domainLimit
```

是否开启域名限制：

- true: 开启。SDK 只能访问指定域名的网络。
- false: （默认）不开启。SDK 可以访问任意域名的网络。

##### `注解`

- 该参数仅对使用定向物联网卡的场景有效。为保证使用定向物联网卡的设备与其他设备互通， 你需要将该参数设置为 true。
- 开启域名限制前，你需要先联系物联网卡运营商将泛域名 *.agora.io 和 *.agoraio.cn 添加到白名单中，再联系 sales.nosp@m. @she.nosp@m. ngwan.nosp@m. g.cn 进行设置。
