网络事件类型。

## 类成员变量说明

<a id="a81d0cfb58d8dcdfb7cd788feccd9650e"></a>

### NETWORK_EVENT_CHANGE

```cpp
final int io.agora.rtc.AgoraRtcService.NetworkEventType.NETWORK_EVENT_CHANGE = 2 static
```

网络事件类型变更。SDK 会尝试重新加入 RTC 频道和登录 RTM 系统。

### NETWORK_EVENT_DOWN

```cpp
final int io.agora.rtc.AgoraRtcService.NetworkEventType.NETWORK_EVENT_DOWN = 0 static
```

网络连接失败。SDK 会尝试重新加入 RTC 频道和登录 RTM 系统。
