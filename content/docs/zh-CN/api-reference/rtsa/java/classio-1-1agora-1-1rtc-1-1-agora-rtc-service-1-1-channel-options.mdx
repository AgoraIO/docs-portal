### autoConnectRdt

```cpp
boolean io.agora.rtc.AgoraRtcService.ChannelOptions.autoConnectRdt
```

是否主动与远端用户建立 RDT 连接。

- true: 主动建立连接。
- false: 不主动建立连接。

例如，用户 A 设置该参数为 `true`，用户 B 和 C 设置该参数为 `false`，那么加入频道后用户 A 会与 B 和 C 分别建立连接，用户 B 和 C 不会建立连接。
