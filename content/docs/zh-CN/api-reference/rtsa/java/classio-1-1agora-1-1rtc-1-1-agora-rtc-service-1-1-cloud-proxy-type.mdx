云代理类型。

## 类成员变量说明

<a id="a806e0c10c044f81aa86a3fc284ef581a"></a>

### CLOUD_PROXY_AUTO

```cpp
final int io.agora.rtc.AgoraRtcService.CloudProxyType.CLOUD_PROXY_AUTO = 100 static
```

100：自动模式。在该模式下，SDK 优先连接 SD-RTN™，如果连接失败，自动切换到 TCP 协议的云代理。

<a id="a7061bb765b0ba698cf1ebe9c7df7c21c"></a>

### CLOUD_PROXY_NONE

```cpp
final int io.agora.rtc.AgoraRtcService.CloudProxyType.CLOUD_PROXY_NONE = 0 static
```

0：不开启云代理。

<a id="a244dcf5edaa99ce247ed31490212c15c"></a>

### CLOUD_PROXY_TCP

```cpp
final int io.agora.rtc.AgoraRtcService.CloudProxyType.CLOUD_PROXY_TCP = 3 static
```

3：开启 TCP 协议的云代理。

<a id="a313a7226ab06d272e69486a20eeae27a"></a>

### CLOUD_PROXY_UDP

```cpp
final int io.agora.rtc.AgoraRtcService.CloudProxyType.CLOUD_PROXY_UDP = 1 static
```

1：开启 UDP 协议的云代理。
