媒体流加密模式。 建议使用 `AES_128_GCM2` 或 `AES_256_GCM2` 加密模式。这两种模式支持使用盐，安全性更高。

## 类成员变量说明

<a id="aefa13b9a2d5a7bd2d98126cdabefbc02"></a>

### AES_128_ECB

```cpp
final int io.agora.rtc.AgoraRtcService.CryptoMode.AES_128_ECB = 2 static
```

2: 128 位 AES 加密，ECB 模式。

<a id="ad104328d7c1d51c2a176462adf99d709"></a>

### AES_128_GCM

```cpp
final int io.agora.rtc.AgoraRtcService.CryptoMode.AES_128_GCM = 5 static
```

5: 128 位 AES 加密，GCM 模式。

<a id="ab5c0e5c572f82da24ba4044d2737be15"></a>

### AES_128_GCM2

```cpp
final int io.agora.rtc.AgoraRtcService.CryptoMode.AES_128_GCM2 = 7 static
```

7: （默认）128 位 AES 加密，GCM 模式。该加密模式需要设置盐（`salt` ）。

<a id="a9d0fa3f76835ea833d5efa50bc62f61b"></a>

