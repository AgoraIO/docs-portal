### onTokenPrivilegeWillExpire()

```cpp
void io.agora.rtc.AgoraRtcEvents.onTokenPrivilegeWillExpire(int connId, String token)
```

Token 服务即将过期回调。

在调用 [joinChannel](/zh-CN/api-reference/rtsa/java/classio-1-1agora-1-1rtc-1-1-agora-rtc-service#a3dd72e07c6799725a7dcce4b137028e2) 时如果指定了 Token，由于 Token 具有一定的时效，在通话过程中如果 Token 即将失效，SDK 会提前 30 秒触发该回调，提醒应用程序更新 Token。 当收到该回调时，用户需要重新在服务端生成新的 Token，然后调用 [renewToken](/zh-CN/api-reference/rtsa/java/classio-1-1agora-1-1rtc-1-1-agora-rtc-service#ae3308277b86fd9f7b2814b89856a6ed5) 将新生成的 Token 传给 SDK。

#### Parameters

| Name | Description |
| --- | --- |
| connId | Connection ID。 |
| token | 即将服务失效的 Token。 |

### onUserJoined()

```cpp
void io.agora.rtc.AgoraRtcEvents.onUserJoined(int connId, int uid, int elapsed_ms)
```

远端用户加入频道回调。

该回调提示有远端用户加入了频道。如果加入之前，已经有其他用户在频道中了，新加入的用户也会收到这些已有用户加入频道的回调。

该回调在如下情况下会被触发：

- 远端用户加入频道。
- 远端用户网络中断后重新加入频道。

#### Parameters

| Name | Description |
| --- | --- |
| connId | Connection ID。 |
| uid | 用户 ID。 |
| elapsed_ms | 从频道成功创建开始到发生此回调过去的时间（毫秒）。 |

### onUserOffline()

```cpp
void io.agora.rtc.AgoraRtcEvents.onUserOffline(int connId, int uid, int reason)
```

远端用户离开频道回调。

SDK 会在如下场景触发该回调：

- 正常离开：远端用户会发送类似“再见”的消息。接收此消息后，判断用户离开频道。
- 超时掉线：如果本地用户在 20 秒内没有收到远端用户的任何数据包，则判定为对方掉线。在网络较差的情况下，有可能会误报。建议使用云信令 SDK 来做可靠的掉线检测。

#### Parameters

| Name | Description |
| --- | --- |
| connId | Connection ID。 |
| uid | 离开频道的用户 ID。 |
| reason | 用户离开频道原因：<br />- USER_OFFLINE_QUIT (0): 远端用户主动下线。<br />- USER_OFFLINE_DROPPED (1): 远端用户超时掉线。 |
