RDT 通道的连接状态。

## 类成员变量说明

<a id="a7069b80b27759ebbf3bc9153a64878f3"></a>

### RDT_STATE_BLOCKED

```cpp
final int io.agora.rtc.AgoraRtcService.RdtState.RDT_STATE_BLOCKED = 2 static
```

`2`: RDT 通道中的发送缓冲区已满。该状态下用户不可以发送数据消息 (`RDT_STREAM_DATA`)，但可以发送控制消息 (`RDT_STREAM_CMD`)。

<a id="a6bbb58a1ac1af571e5978326df0db39d"></a>

### RDT_STATE_BROKEN

```cpp
final int io.agora.rtc.AgoraRtcService.RdtState.RDT_STATE_BROKEN = 4 static
```

`4`: 与 RDT 通道的连接已损坏，SDK 会尝试重新连接。SDK 不论能否成功连接，都会清空 RDT 通道中发送和接收缓冲区中的历史数据。

<a id="af3534dd4796d0cbfaba8bebe22ebbf2a"></a>

### RDT_STATE_CLOSED

```cpp
final int io.agora.rtc.AgoraRtcService.RdtState.RDT_STATE_CLOSED = 0 static
```

`0`: 初始状态，未连接 RDT 通道。该状态下用户不可以收发 RDT 消息。

<a id="ae98f3a3b0c18e61eb0b74c370df283b8"></a>

### RDT_STATE_OPENED

```cpp
final int io.agora.rtc.AgoraRtcService.RdtState.RDT_STATE_OPENED = 1 static
```

`1`: 已连接 RDT 通道。该状态下用户可以收发 RDT 消息。

<a id="af286021825597470df090aac97319433"></a>

### RDT_STATE_PENDING

```cpp
final int io.agora.rtc.AgoraRtcService.RdtState.RDT_STATE_PENDING = 3 static
```

`3`: 正在重新连接 RDT 通道。

- 如果重新连接成功，则连接状态会变为 RDT_STATE_OPENED，SDK 会保留 RDT 通道中发送和接收缓冲区中的历史数据。
- 如果重新连接失败，则连接状态会变为 RDT_STATE_CLOSED，SDK 会清除 RDT 通道中发送和接收缓冲区中的历史数据。
