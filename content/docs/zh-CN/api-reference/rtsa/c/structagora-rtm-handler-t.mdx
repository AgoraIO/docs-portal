### on_rtm_data

```cpp
void(* on_rtm_data)(const char*rtm_uid, const void*msg, size_t msg_len)
```

RTM 消息回调。

#### Parameters

| Name | Description |
| --- | --- |
| [in] rtm_uid | 发送消息的 RTM 用户 ID。 |
| [in] msg | 收到的消息内容。 |
| [in] msg_len | 消息长度。单位为字节。 |
