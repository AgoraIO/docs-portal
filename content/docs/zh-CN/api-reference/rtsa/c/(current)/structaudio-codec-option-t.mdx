### pcm_channel_num

<ApiSignature>

int pcm_channel_num

</ApiSignature>

内置音频编解码器的 PCM 声道数。此参数为必选参数，可以设为以下值：

- 1: 单声道。
- 2: 双声音。

<a id="a3e3700acda2ff0d8ed34bfa3264277d5"></a>

### pcm_duration

<ApiSignature>

int pcm_duration

</ApiSignature>

音频时长，单位为毫秒。取值范围为 [20,100]，取值需为 10 的倍数。该设置对所有格式的音频数据都有效。

<a id="ab242b3cbbecd058315c7282415d36827"></a>

### pcm_sample_rate

<ApiSignature>

int pcm_sample_rate

</ApiSignature>

内置音频编解码器的 PCM 采样频率 (Hz)。此参数为必选参数，可以设为以下值：

- 8000: 8 kHz。
- 16000: 16 kHz。
- 48000: 48 kHz。
