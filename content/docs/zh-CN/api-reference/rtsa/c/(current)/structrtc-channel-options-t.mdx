## ◆auto_subscribe_audio

| bool auto_subscribe_audio |
| --- |

是否订阅音频。

- true: 订阅。
- false: 不订阅。

<a id="a1fb8613606a7f2660db5f4bc256f84d5"></a>

## ◆auto_subscribe_video

| bool auto_subscribe_video |
| --- |

是否订阅音频。

- true: 订阅。
- false: 不订阅。

<a id="abf884b88afc6821cf8826ebeebe68cc5"></a>

## ◆crypto_opt

| [crypto_option_t](/zh-CN/api-reference/rtsa/c/structcrypto-option-t) crypto_opt |
| --- |

媒体流加密选项。详见 [crypto_option_t](/zh-CN/api-reference/rtsa/c/structcrypto-option-t)。

<a id="a5b22a5c4c25c60162c0db1d3c6bfd255"></a>

## ◆enable_audio_decode

| bool enable_audio_decode |
| --- |

是否对接收到的音频进行解码。

- true: 解码。
- false: 不接吗。

<a id="aa34aaf710f816b54826eb2ef00ce1cff"></a>

## ◆enable_audio_downlink_aec

| bool enable_audio_downlink_aec |
| --- |

是否开启下行回声消除。

- true: 开启。
- false: 不开启。

<a id="a9f0467e026bd689f473dafdeacd76301"></a>

## ◆enable_audio_downlink_aec_pcm_dump

| bool enable_audio_downlink_aec_pcm_dump |
| --- |

开启下行回声消除时是否从音频处理器中转储数据。

- true: 导出。
- false: 不导出。

<a id="a8f34d0553bdc017b0c89eeab3d1702e0"></a>

## ◆enable_audio_jitter_buffer

| bool enable_audio_jitter_buffer |
| --- |

是否开启音频抖动缓冲。

- true: 开启。
- false: 不开启。

<a id="a86f37d1c3b251e110e18a6e2a55bd7c1"></a>

## ◆enable_audio_mixer

| bool enable_audio_mixer |
| --- |

是否开启混音。

- true: 开启。
- false: 不开启。

### 注解

开启混音后，SDK 也会自动开启 enable_audio_jitter_buffer。

<a id="aae90344dd5002b2076e22c06da7c17ff"></a>

## ◆enable_rdt

| bool enable_rdt |
| --- |

是否启用 RDT 传输通道。

- 0: 不启用。
- 其他值: 启用。
