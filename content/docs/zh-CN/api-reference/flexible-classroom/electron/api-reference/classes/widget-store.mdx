---
title: "WidgetStore"
description: "WidgetStore API 参考。"
---

`WidgetStore` 提供活跃插件的数据和状态的访问；提供 WidgetController 实例的直接访问；提供插件相关 API，用于激活、停用和更新插件的状态。

- [EduStoreBase](/zh-CN/api-reference/flexible-classroom/electron/api-reference/classes/edu-store-base)

  - WidgetStore
