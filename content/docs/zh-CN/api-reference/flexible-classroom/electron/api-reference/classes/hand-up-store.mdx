`HandUpStore` 类提供举手上台功能相关能力。

- [EduStoreBase](/zh-CN/api-reference/flexible-classroom/electron/api-reference/classes/edu-store-base)

  - HandUpStore

## 方法

<a id="allowHandsUp"></a>

### allowHandsUp

```ts
allowHandsUp(state: 0 | 1, autoStage: boolean): void
```

配置允许学生举手

#### 参数

| 名称 | 描述 |
| --- | --- |
| state: 0 \| 1 | 是否允许举手，0 不允许，1 允许 |
| autoStage: boolean | 是否开启自动上台 |

#### 返回值

void

<a id="cancelHandUp"></a>

### cancelHandUp

```ts
cancelHandUp(): Promise<void>
```

学生取消举手

#### 返回值

Promise &lt; void &gt;

<a id="onPodium"></a>

### onPodium

```ts
onPodium(userUuid: string, source?: PodiumSrouce): Promise<void>
```

#### 参数

| 名称 | 描述 |
| --- | --- |
| userUuid: string | 用户 ID |
| Optional source: PodiumSrouce | 邀请来源：<br />- 老师从花名册邀请学生上讲台<br />- 学生举手老师同意上讲台 |

Promise &lt; void &gt;
