## 枚举成员

<a id="HIGH_STREAM"></a>

### HIGH_STREAM

```ts
HIGH_STREAM = 0
```

0: High-quality video stream (high-bitrate, high-resolution).

<a id="LOW_STREAM"></a>

### LOW_STREAM

```ts
LOW_STREAM = 1
```

1: Low-quality video stream (low-bitrate, low-resolution).
