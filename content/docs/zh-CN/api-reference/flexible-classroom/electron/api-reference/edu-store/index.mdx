自 Classroom SDK 2.0.x 版本开始，Web端使用 Edu Store 为交互层提供能力支持，对应到 iOS 和 Android 端的 Edu Context。不同的 Store 代表灵动课堂中不同的业务功能模块。每个 Store 包含可观察属性和教室 API 供 App 调用。
