### CarouselSetting

CarouselSetting: \{interval:number;range:number;state:number;type:number\}

#### Type declaration

- interval:number

  轮播列表更新周期，单位：秒
- range:number

  轮播范围，哪些用户可以参与轮播
  1: 全部
  2: 仅设备可用用户
- state:number

  轮播是否开启
  1: 开启
  0: 关闭
- type:number

  轮播类型
  1: 顺序
  2: 随机
