### ReportParams

ReportParams: \{cid?:number;id:number;payload:string;qos:number;requestId?:string;sign:string;src:string;ts:number;vid?:number\}

#### Type declaration

- Optional cid?:number

  当前通话的cid
- id:number

  协议ID
- payload:string

  上报内容, base64(pb二进制内容)
- qos:number

  消息级别
  1: 默认, 101: 测试
- Optional requestId?:string

  上报唯一id
- sign:string

  签名规则: md5(payload=base64(XX)&src=XX&ts=XX)
  保留字段, XX为字段值 32位小写
- src:string

  来源/请求方
- ts:number

  时间戳, 10位, 秒
- Optional vid?:number

  厂商ID
