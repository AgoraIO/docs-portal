Enum representing the types of Agora Cloud Proxy.

## Enumeration members

<a id="Automatic"></a>

### Automatic

```ts
Automatic = 0
```

默认情况下，SDK首先尝试直接连接到 Agora SD-RTN™。如果尝试失败，SDK会自动退回，并在TLS 443上安全地发送媒体。当您不确定最终用户是否在防火墙后面时，这是最佳实践。虽然在TLS 443上传输媒体可能不如使用UDP提供高质量。TLS 443上的连接可以通过大多数防火墙。 目前，只支持在 electron 环境中。

<a id="TCP"></a>

### TCP

```ts
TCP = 2
```

使用 TCP 协议代理。

<a id="UDP"></a>

### UDP

```ts
UDP = 1
```

使用 UDP 协议代理。
