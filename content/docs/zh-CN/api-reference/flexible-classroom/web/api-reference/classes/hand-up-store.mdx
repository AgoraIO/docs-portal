- EduStoreBase

## Methods

<a id="allowHandsUp"></a>

### allowHandsUp

```ts
allowHandsUp(state: 0 | 1, autoStage: boolean): void
```

配置允许学生举手

#### Parameters

| Name | Description |
| --- | --- |
| state: 0 \| 1 | 是否允许举手，0 不允许，1 允许 |
| autoStage: boolean | 是否开启自动上台 |

#### Returns

Returns void
