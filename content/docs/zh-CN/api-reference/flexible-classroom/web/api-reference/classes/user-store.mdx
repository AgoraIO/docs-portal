## 方法

<a id="fetchUserList"></a>

### fetchUserList

```ts
fetchUserList(params: FetchUserParam): Promise<{ count: any; list: any; nextId: any; total: any }>
```

获取用户列表

#### 参数

| 名称 | 描述 |
| --- | --- |
| params: FetchUserParam | 查询条件 |

#### 返回值

Promise &lt; \{count: any; list: any; nextId: any; total: any \} &gt;

用户列表

<a id="kickOutOnceOrBan"></a>

### kickOutOnceOrBan

```ts
kickOutOnceOrBan(userUuid: string, isBan: boolean): Promise<undefined>
```

将用户踢出房间

#### 参数

| 名称 | 描述 |
| --- | --- |
| userUuid: string | 用户 ID |
| isBan: boolean | 是否永久封禁该用户 |

#### 返回值

Promise &lt; undefined &gt;

<a id="updateUserProperties"></a>

### updateUserProperties

```ts
updateUserProperties(users: { cause?: any; properties: any; userUuid: string }[], fromScene?: AgoraRteScene): Promise<void>
```

更新用户自定属性

#### 参数

| 名称 | 描述 |
| --- | --- |
| users: \{ cause?: any; properties: any; userUuid: string \}[] | 要更新的用户属性信息 |
| Optional fromScene: AgoraRteScene | 要更新的用户所在的房间对象，不传默认为当前房间 |

#### 返回值

Promise &lt; void &gt;
