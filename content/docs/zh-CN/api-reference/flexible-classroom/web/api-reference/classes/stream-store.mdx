<a id="publishScreenShare"></a>

### publishScreenShare

```ts
publishScreenShare(fromScene?: AgoraRteScene, streamOptions?: Partial<AgoraStreamStates>): Promise<any>
```

为本地用户创建一条屏幕共享流，返回已创建的流ID与Token。 此方法只允许房间内创建一路屏幕共享流，若房间内需要同时存在多路屏幕流，请使用 publishScreenShareStateless

#### Parameters

| Name | Description |
| --- | --- |
| Optional fromScene: AgoraRteScene | 流所在的房间对象，不传默认为当前房间 |
| Optional streamOptions: Partial&lt;AgoraStreamStates&gt; | 发流选项 |

#### Returns

Returns Promise &lt; any &gt;
