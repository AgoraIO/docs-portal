音频裸数据回调参数

- AgoraRteAudioRawDataConfig

## 属性

<a id="frameSize"></a>

### Optional frameSize

```ts
frameSize?: 256 | 512 | 1024 | 2048 | 4096 | 8192 | 16384
```

每次回调返回的音频数据长度

<a id="sampleRate"></a>

### Optional sampleRate

```ts
sampleRate?: number
```

音频数据的采样率

<a id="stereo"></a>

### Optional stereo

```ts
stereo?: boolean
```

是否启用立体音
