## onRoomPropertiesUpdated

自定义房间属性更新回调。

<a id="api_onroompropertiesupdated__prototype"></a>

```kotlin
fun onRoomPropertiesUpdated(properties: Map<String, Any>,
                            cause: Map<String, Any>?,
                            operator: AgoraEduContextUserInfo?)
```

<a id="api_onroompropertiesupdated__parameters"></a>

### 参数

#### `properties`

已更新的房间属性。

#### `cause`

更新原因。

#### `operator`

操作者 [AgoraEduContextUserInfo](/zh-CN/api-reference/flexible-classroom/android/api-data-type#class_userinfo)，可为空。

<a id="api_onroomclosed"></a>

## onRoomClosed

房间关闭回调。

<a id="api_onroomclosed__prototype"></a>

```kotlin
fun onRoomClosed()
```

<a id="api_onroomclosed__detailed_desc"></a>

房间关闭，房间里的用户会立即被踢出房间，其它用户无法也再加入该房间。
