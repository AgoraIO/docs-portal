<a id="class_groupcontext"></a>

FCRGroupContext 类。

<a id="class_groupcontext__detailed_desc"></a>

FCRGroupContext 类提供的方法用于管理所有的子房间。可通过该类实现分组讨论功能。

<a id="api_getgroupinfo"></a>

## getGroupInfo

获取分组信息。

<a id="api_getgroupinfo__prototype"></a>

```kotlin
abstract fun getGroupInfo(): FCREduContextGroupInfo?
```

<a id="api_getgroupinfo__return_values"></a>

### 返回值

返回分组信息对象 [FCREduContextGroupInfo](/zh-CN/api-reference/flexible-classroom/android/class-groupinfo)。
