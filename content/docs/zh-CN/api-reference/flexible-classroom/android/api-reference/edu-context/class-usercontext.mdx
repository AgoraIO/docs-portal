UserContext 类。

<a id="class_usercontext__detailed_desc"></a>

### 详情

UserContext 类提供的方法用于：

- 控制用户上下台行为。
- 更新用户信息和属性。

<a id="api_updateuserproperties"></a>

## updateUserProperties

新增或更新自定义用户属性。

<a id="api_updateuserproperties__prototype"></a>

```kotlin
abstract fun updateUserProperties(userUuid: String,
                                  properties: MutableMap<String, Any>,
                                  cause: MutableMap<String, Any>?,
                                  callback: EduContextCallback<Unit>? = null)
```

<a id="api_updateuserproperties__detailed_desc"></a>

### 详情

详见 [如何设置自定义用户属性](/zh-CN/api-reference/faq/integration/agora_class_custom_properties)。

属性成功更新后，会触发 [onUserPropertiesUpdated](/zh-CN/api-reference/flexible-classroom/android/api-reference/edu-context/class-userhandler#api_onuserpropertiesupdated) 回调。

<a id="api_updateuserproperties__parameters"></a>

### 参数

#### `userUuid`

用户 ID。

#### `properties`

用户属性。

#### `cause`

更新原因，可为空。

#### `callback`

通过 [EduContextCallback](/zh-CN/api-reference/flexible-classroom/android/api-reference/edu-context/class-callback) 异步获取调用结果。
