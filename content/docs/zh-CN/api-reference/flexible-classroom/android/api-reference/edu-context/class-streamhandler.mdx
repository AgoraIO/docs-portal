## onStreamUpdated

流更新回调。

<a id="api_onstreamupdated__prototype"></a>

```kotlin
fun onStreamUpdated(streamInfo: AgoraEduContextStreamInfo,
                    operator: AgoraEduContextUserInfo? = null)
```

<a id="api_onstreamupdated__parameters"></a>

### 参数

#### `streamInfo`

流信息，详见 [AgoraEduContextStreamInfo](/zh-CN/api-reference/flexible-classroom/android/api-reference/edu-context/api-data-type#class_streaminfo)。

#### `operator`

操作者 [AgoraEduContextUserInfo](/zh-CN/api-reference/flexible-classroom/android/api-reference/edu-context/api-data-type#class_userinfo)，可为空。

## onStreamJoined

流新增回调。

<a id="api_onstreamjoined__prototype"></a>

```kotlin
fun onStreamJoined(streamInfo: AgoraEduContextStreamInfo,
                   operator: AgoraEduContextUserInfo? = null)
```

<a id="api_onstreamjoined__detailed_desc"></a>

房间内新增一路流时，SDK 会触发此回调。

<a id="api_onstreamjoined__parameters"></a>

### 参数

#### `streamInfo`

流信息，详见 [AgoraEduContextStreamInfo](/zh-CN/api-reference/flexible-classroom/android/api-reference/edu-context/api-data-type#class_streaminfo)。

#### `operator`

操作者 [AgoraEduContextUserInfo](/zh-CN/api-reference/flexible-classroom/android/api-reference/edu-context/api-data-type#class_userinfo)，可为空。
