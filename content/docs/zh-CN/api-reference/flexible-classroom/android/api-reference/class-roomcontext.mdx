<a id="api_updateroomproperties"></a>

## updateRoomProperties

新增或更新自定义房间属性。

<a id="api_updateroomproperties__prototype"></a>

```kotlin
abstract fun updateRoomProperties(properties: MutableMap<String, Any>,
                                  cause: MutableMap<String, Any>?,
                                  callback: EduContextCallback<Unit>? = null)
```

<a id="api_updateroomproperties__detailed_desc"></a>

详见 [如何设置自定义房间属性](https://doc.shengwang.cn/faq/integration-issues/class-properties)。

属性成功更新后，会触发 [onRoomPropertiesUpdated](/zh-CN/api-reference/flexible-classroom/android/api-reference/class-roomhandler#api_onroompropertiesupdated) 回调。

<a id="api_updateroomproperties__parameters"></a>

### 参数

#### `properties`

房间属性。

#### `cause`

更新原因。可为空。

#### `callback`

通过 [EduContextCallback](/zh-CN/api-reference/flexible-classroom/android/api-reference/class-callback) 异步获取调用结果。

<a id="api_deleteroomproperties"></a>

## deleteRoomProperties

删除自定义房间属性。

<a id="api_deleteroomproperties__prototype"></a>

```kotlin
abstract fun deleteRoomProperties(keyPaths: MutableList<String>,
                                  cause: MutableMap<String, Any>?,
                                  callback: EduContextCallback<Unit>? = null)
```

<a id="api_deleteroomproperties__parameters"></a>

### 参数

#### `keyPaths`

你想要删除的属性的 key path，如 key1.subkey1。

#### `cause`

删除原因。可为空。

#### `callback`

通过 [EduContextCallback](/zh-CN/api-reference/flexible-classroom/android/api-reference/class-callback) 异步获取调用结果。
