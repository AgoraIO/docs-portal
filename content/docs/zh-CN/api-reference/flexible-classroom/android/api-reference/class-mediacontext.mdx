## MediaContext

MediaContext 类。

<a id="class_media_context__detailed_desc"></a>

MediaContext 类提供的方法用于：

- 管理本地音视频设备。
- 播放本地音频。
- 渲染本地视频。

<a id="api_startaudiomixing"></a>

## startAudioMixing

开始混音。

<a id="api_startaudiomixing__prototype"></a>

```kotlin
abstract fun startAudioMixing(filepath: String, 
                              loopback: Boolean, 
                              replace: Boolean, 
                              cycle: Int)
```

<a id="api_startaudiomixing__detailed_desc"></a>

将麦克风采集的音频流与本地客户端的音乐文件中的音频混合，以便远端用户能更为清晰地听到该音乐文件。

<a id="api_startaudiomixing__parameters"></a>

### 参数

#### `filePath`

需要进行混音的音乐文件路径。

#### `loopback`

是否只在本地客户端播放音乐文件。

#### `replace`

是否将麦克风采集的音频替换为音乐文件。

#### `cycle`

音乐文件的播放次数。设为 -1 表示循环播放。

<a id="api_getsnapshot"></a>

## getSnapshot

视频流截图。

<a id="api_getsnapshot__prototype"></a>

```kotlin
abstract fun getSnapshot(
        roomUuid: String,
        streamUuid: String,
        filePath: String,
        callback: EduContextCallback<FcrSnapshotInfo>?
)
```

<a id="api_getsnapshot__detailed_desc"></a>

从视频流中截图，生成 JPG 文件。每次调用此 API 需间隔至少一秒。

<a id="api_getsnapshot__parameters"></a>

### 参数

#### `roomUuid`

房间 ID。

#### `streamUuid`

流 ID

#### `filePath`

保存截图的本地绝对路径。需完整写出文件名，例如 xxx/xxx/example.jpg。

#### `callback`

调用成功，则返回截图信息 [FcrSnapshotInfo](/zh-CN/api-reference/flexible-classroom/android/api-reference/api-data-type#class_fcrsnapshotinfo)。
