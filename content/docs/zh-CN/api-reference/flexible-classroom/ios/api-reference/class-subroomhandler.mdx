## onSubRoomPropertiesUpdated

子房间自定义属性更新回调。

<a id="api_onsubroompropertiesupdated__prototype"></a>

```swift
void onSubRoomPropertiesUpdated(Map<String, Any> changedProperties,
                                Map<String, Any> cause,
                                AgoraEduContextUserInfo operator)
```

<a id="api_onsubroompropertiesupdated__parameters"></a>

### 参数

#### `changedProperties`

已更新的房间属性。

#### `cause`

更新原因。

#### `operator`

操作者 [AgoraEduContextUserInfo](/zh-CN/api-reference/flexible-classroom/ios/api-data-type#class_userinfo)，可为空。
