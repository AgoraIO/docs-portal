<a id="api_setwidgetinactive__prototype"></a>

```swift
void setWidgetInactive(String widgetId,
                       Callback<Void> success,
                       Callback<Error> failure)
```

<a id="api_setwidgetinactive__parameters"></a>

## 参数

### `widgetId`

Widget 的 ID。

### `isRemove`

是否将该 widgetId 下的信息从服务器移除。

### `success`

请求成功。

### `fail`

调用失败，则返回 [AgoraEduContextError](/zh-CN/api-reference/flexible-classroom/ios/api-data-type#class_error)。
