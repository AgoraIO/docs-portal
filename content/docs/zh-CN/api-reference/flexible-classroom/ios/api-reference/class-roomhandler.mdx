<a id="api_onroompropertiesupdated"></a>

## onRoomPropertiesUpdated

自定义房间属性更新回调。

<a id="api_onroompropertiesupdated__prototype"></a>

```swift
void onRoomPropertiesUpdated(Map<String, Any> changedProperties,
                             Map<String, Any> cause,
                             AgoraEduContextUserInfo operator)
```

<a id="api_onroompropertiesupdated__parameters"></a>

### 参数

#### `changedProperties`

已更新的房间属性。

#### `cause`

更新原因。

#### `operator`

操作者 [AgoraEduContextUserInfo](/zh-CN/api-reference/flexible-classroom/ios/api-reference/api-data-type#class_userinfo)，可为空。

## onRoomPropertiesDeleted

<a id="api_onroompropertiesdeleted__prototype"></a>

```swift
void onRoomPropertiesDeleted(Array<String> keyPaths,
                             Map<String, Any> cause,
                             AgoraEduContextUserInfo operator)
```

<a id="api_onroompropertiesdeleted__parameters"></a>

### 参数

#### `keyPaths`

被删除的属性的 keyPath 数组。

#### `cause`

删除原因。

#### `operator`

操作者 [AgoraEduContextUserInfo](/zh-CN/api-reference/flexible-classroom/ios/api-reference/api-data-type#class_userinfo)，可为空。

<a id="api_onroomclosed"></a>

## onRoomClosed

房间关闭回调。

<a id="api_onroomclosed__prototype"></a>

```swift
void onRoomClosed()
```

<a id="api_onroomclosed__detailed_desc"></a>

房间关闭，房间里的用户会立即被踢出房间，其它用户无法也再加入该房间。
