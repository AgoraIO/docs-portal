AgoraEduMediaContext 类。

<a id="class_media_context__detailed_desc"></a>

### 详情

AgoraEduMediaContext 类提供的方法用于：

- 管理本地音视频设备。
- 播放本地音频。
- 渲染本地视频。

获取本地设备。

<a id="api_getlocaldevices__prototype"></a>

```swift

```

<a id="api_getlocaldevices__parameters"></a>

### 参数

#### `deviceType`

设备类型。详见 [AgoraEduContextDeviceType](/zh-CN/api-reference/flexible-classroom/ios/api-reference/edu-context/api-data-type#enum_devicetype)。

<a id="api_startaudiomixing"></a>

## startAudioMixing

开始混音。

<a id="api_startaudiomixing__prototype"></a>

```swift
AgoraEduContextError startAudioMixing(String filePath,
                                      Boolean loopback,
                                      Boolean replace,
                                      Int cycle)
```

<a id="api_startaudiomixing__detailed_desc"></a>

### 详情

将麦克风采集的音频流与本地客户端的音乐文件中的音频混合，以便远端用户能更为清晰地听到该音乐文件。

<a id="api_startaudiomixing__parameters"></a>

### 参数

#### `filePath`

需要进行混音的音乐文件路径。

#### `loopback`

是否只在本地客户端播放音乐文件。

#### `replace`

是否将麦克风采集的音频替换为音乐文件。

#### `cycle`

音乐文件的播放次数。设为 -1 表示循环播放。

<a id="api_startaudiomixing__return_values"></a>

### 返回值

调用失败，则返回 [AgoraEduContextError](/zh-CN/api-reference/flexible-classroom/ios/api-reference/edu-context/api-data-type#class_error)。

## getSnapshot

视频流截图。

<a id="api_getsnapshot__prototype"></a>

```swift
void getSnapshot(String roomUuid,
                 String streamUuid,
                 String filePath,
                 Callback<FcrSnapshotInfo> success,
                 Callback<AgoraEduContextError> failure)
```

<a id="api_getsnapshot__detailed_desc"></a>

### 详情

从视频流中截图，生成 JPG 文件。每次调用此 API 需间隔至少一秒。

<a id="api_getsnapshot__parameters"></a>

### 参数

#### `roomUuid`

房间 ID。

#### `streamUuid`

流 ID

#### `filePath`

保存截图的本地绝对路径。需完整写出文件名，例如 xxx/xxx/example.jpg。

#### `success`

调用成功，则返回截图信息 [FcrSnapshotInfo](/zh-CN/api-reference/flexible-classroom/ios/api-reference/edu-context/api-data-type#class_fcrsnapshotinfo)。

#### `fail`

调用失败，则返回 [AgoraEduContextError](/zh-CN/api-reference/flexible-classroom/ios/api-reference/edu-context/api-data-type#class_error)。
