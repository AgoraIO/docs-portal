## joinRoom

加入房间。

<a id="api_joinroom__prototype"></a>

```swift
void joinRoom(Callback<Void> success,
              Callback<AgoraEduContextError> fail)
```

<a id="api_joinroom__parameters"></a>

### 参数

#### `success`

调用成功，则返回当前的房间信息 [AgoraEduContextRoomInfo](/zh-CN/api-reference/flexible-classroom/ios/api-reference/edu-context/api-data-type#class_roominfo)。

#### `fail`

调用失败，则返回 [AgoraEduContextError](/zh-CN/api-reference/flexible-classroom/ios/api-reference/edu-context/api-data-type#class_error)。

<a id="api_updateroomproperties"></a>

## updateRoomProperties

新增或更新自定义房间属性。

<a id="api_updateroomproperties__prototype"></a>

```swift
void updateRoomProperties(Map<String, Any> properties,
                          Map<String, Any> cause,
                          Callback<Void> success,
                          Callback<AgoraEduContextError> fail)
```

<a id="api_updateroomproperties__detailed_desc"></a>

详见 [如何设置自定义房间属性](/zh-CN/api-reference/faq/integration/agora_class_custom_properties)。

属性成功更新后，会触发 [onRoomPropertiesUpdated](/zh-CN/api-reference/flexible-classroom/ios/api-reference/edu-context/class-roomhandler#api_onroompropertiesupdated) 回调。

<a id="api_updateroomproperties__parameters"></a>

### 参数

#### `properties`

房间属性。

#### `cause`

更新原因。可为空。

#### `success`

调用成功。

#### `fail`

调用失败，则返回 [AgoraEduContextError](/zh-CN/api-reference/flexible-classroom/ios/api-reference/edu-context/api-data-type#class_error)。

## deleteRoomProperties

<a id="api_deleteroomproperties__prototype"></a>

```swift

                          Map<String, Any> cause,
                          Callback<Void> success,
                          Callback<AgoraEduContextError> fail)
```

<a id="api_deleteroomproperties__parameters"></a>

### 参数

#### `keyPaths`

你想要删除的属性的 key path，如 key1.subkey1。

#### `cause`

删除原因。可为空。

#### `success`

调用成功。

#### `fail`

调用失败，则返回 [AgoraEduContextError](/zh-CN/api-reference/flexible-classroom/ios/api-reference/edu-context/api-data-type#class_error)。
