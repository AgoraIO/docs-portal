AgoraEduUserContext 类。

<a id="class_usercontext__detailed_desc"></a>

### 详情

AgoraEduUserContext 类提供的方法用于：

- 控制用户上下台行为。
- 更新用户信息和属性。

<a id="api_getlocaluserinfo__prototype"></a>

<a id="api_updateuserproperties"></a>

## updateUserProperties

新增或更新自定义用户属性。

<a id="api_updateuserproperties__prototype"></a>

```swift
void updateUserProperties(String userUuid,
                          Map<String, Any> properties,
                          Map<String, Any> cause,
                          Callback<Void> success,
                          Callback<AgoraEduContextError> fail)
```

<a id="api_updateuserproperties__detailed_desc"></a>

### 详情

详见 [如何设置自定义用户属性](/zh-CN/reference/faq/integration/agora_class_custom_properties)。

属性成功更新后，会触发 [onUserPropertiesUpdated](/zh-CN/api-reference/flexible-classroom/ios/api-reference/edu-context/class-userhandler#api_onuserpropertiesupdated) 回调。

<a id="api_updateuserproperties__parameters"></a>

### 参数

#### `userUuid`

用户 ID。

#### `properties`

用户属性。

#### `cause`

更新原因，可为空。

#### `success`

调用成功。

#### `fail`

调用失败，则返回 [AgoraEduContextError](/zh-CN/api-reference/flexible-classroom/ios/api-reference/edu-context/api-data-type#class_error)。

## deleteUserProperties

```swift
                          Map<String, Any> cause,
                          Callback<Void> success,
                          Callback<AgoraEduContextError> fail)
```

<a id="api_deleteuserproperties__parameters"></a>

### 参数

#### `userUuid`

用户 ID。

#### `keyPaths`

你想要删除的属性的 key path，如 "key1.subkey1"。

#### `cause`

删除原因，可为空。

#### `success`

调用成功。

#### `fail`

调用失败，则返回 [AgoraEduContextError](/zh-CN/api-reference/flexible-classroom/ios/api-reference/edu-context/api-data-type#class_error)。
