<a id="api_onremoteuserleft"></a>

## onRemoteUserLeft

远端用户离开房间回调。

<a id="api_onremoteuserleft__prototype"></a>

```swift
void onRemoteUserLeft(AgoraEduContextUserInfo user,
                      AgoraEduContextUserInfo operator,
                      AgoraEduContextUserLeaveReason reason)
```

<a id="api_onremoteuserleft__parameters"></a>

### 参数

#### `user`

离开房间的用户的信息，详见 [AgoraEduContextUserInfo](/zh-CN/api-reference/flexible-classroom/ios/api-reference/edu-context/api-data-type#class_userinfo)。

#### `operator`

操作者 [AgoraEduContextUserInfo](/zh-CN/api-reference/flexible-classroom/ios/api-reference/edu-context/api-data-type#class_userinfo)。如果远端用户是被踢出房间，则返回该参数。

#### `reason`

离开房间的原因，详见 [AgoraEduContextUserLeaveReason](/zh-CN/api-reference/flexible-classroom/ios/api-reference/edu-context/api-data-type#enum_userleavereason)。默认为 normal。

<a id="api_onuserhandsdown"></a>

## onUserHandsDown

用户手放下回调。

<a id="api_onuserhandsdown__prototype"></a>

```swift
void onUserHandsDown(AgoraEduContextUserInfo user)
```

<a id="api_onuserhandsdown__detailed_desc"></a>

### 详情

SDK 会在以下两种情况下触发此回调：

- 用户取消举手申请。
- 用户取消申请被老师接受。

<a id="api_onuserhandsdown__parameters"></a>

### 参数

#### `user`

手放下的用户 [AgoraEduContextUserInfo](/zh-CN/api-reference/flexible-classroom/ios/api-reference/edu-context/api-data-type#class_userinfo)。
