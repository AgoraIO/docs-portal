---
title: "错误排查"
---
在调用 RTM React Native API 时，如果发生错误，SDK 会抛出一个 `ErrorInfo` 类型数据，包含以下属性：

```typescript
type ErrorInfo = {
    error: boolean;        // 本次操作是否出错
    reason: string;        // 本次操作的 API 名称
    operation: string;     // 错误码
    errorCode: number;     // 错误描述
};
```

其中，`errorCode` 和 `reason` 属性分别报告错误码和错误描述，你可以在下面的表格中寻找解决方法：

| `-10003` | `invalidAppId` | <Slot name="error-codes-rn-html-0-3-2" /> |

<Slot for="error-codes-rn-html-0-3-2">

无效 App ID：

    - 检查 App ID 是否错误。
    - 检查 App ID 是否开通了 RTM 服务。

</Slot>

<Slot for="error-codes-rn-html-0-6-2">

无效用户 ID：

    - 检查用户名是否为空。
    - 检查用户名是否包含非法字符。

</Slot>

<Slot for="error-codes-rn-html-0-7-2">

无效频道名称：

    - 检查频道名是否为空。
    - 检查频道名是否包含非法字符。

</Slot>

<Slot for="error-codes-rn-html-0-11-2">

SDK 被服务器拒绝登录：

    - 检查 App ID 是否开通 RTM 服务。
    - 检查 Token 或 `userId` 是否被封禁。

</Slot>

<Slot for="error-codes-rn-html-0-12-2">

由于未知问题 SDK 登录中断：

    - 检查当前网络是否稳定，切换到稳定网络环境中。
    - 当前 `userId` 在其他端登录。

</Slot>

<Slot for="error-codes-rn-html-0-13-2">

没有 RTM 服务权限。可能的原因有：

    - 未在控制台启用 RTM 服务。
    - 服务已欠费。
    - 账号被封停。

</Slot>

<Slot for="error-codes-rn-html-0-17-2">

频道类型无效。SDK 仅支持如下频道类型，请填写正确的值：

    - `MESSAGE`: Message Channel
    - `STREAM`: Stream Channel
    - `USER`: User Channel

</Slot>

<Slot for="error-codes-rn-html-0-18-2">

消息加密参数无效。

    - 检查生成的加密密钥是否为 String 型。
    - 检查生成的加密盐是否为 Uint8Array 型，长度是否为 32 字节。
    - 检查加密方式与加密密钥、加密盐是否匹配。

</Slot>

<Slot for="error-codes-rn-html-0-21-2">

登录操作已取消。可能原因如下：

    - 调用 `login` 方法后，如果你在收到调用结果之前再次调用该方法，则前一次的调用操作会被取消，SDK 会执行后一次的调用。
    - 还未成功登录就调用 `logout` 方法登出。

</Slot>

<Slot for="error-codes-rn-html-0-24-2">

用户未加入该频道：

    - 用户不在线、已离线或未加入该频道
    - 检查 `userId` 是否拼写错误。

</Slot>

<Slot for="error-codes-rn-html-0-25-2">

用户未订阅该频道：

    - 用户不在线、已离线或未加入该频道
    - 检查 `userId` 是否拼写错误。

</Slot>

<Slot for="error-codes-rn-html-0-29-2">

加入该频道失败：

    - 检查已加入频道数量是否超限。
    - 检查频道名是否非法。
    - 检查网络是否断开连接。

</Slot>

<Slot for="error-codes-rn-html-0-30-2">

无效 Topic 名：

    - 检查 Topic 名是否包含非法字符。
    - 检查 Topic 名是否为空。

</Slot>

<Slot for="error-codes-rn-html-0-32-2">

消息长度超出限制。检查消息负载大小是否超限：

    - Message Channel 单个消息包小于 32 KB。
    - Stream Channel 单个消息包小于 1 KB。

</Slot>

<Slot for="error-codes-rn-html-0-43-2">

消息加密失败：

    - 检查加密密钥是否有效。
    - 检查加密盐是否有效。
    - 检查加密方式与加密密钥、加密盐是否匹配。

</Slot>

<Slot for="error-codes-rn-html-0-49-2">

发送用户消息时，远端用户不在线:

    - 检查在调用方法时设置的用户 ID 是否正确。
    - 检查远端用户是否登录系统并处于在线状态。

</Slot>

如果以上措施都为未能解决你的故障，或者你需要解决方案的支持，请将你的需求整理出来并通过邮箱发送到：rtm-support@agora.io。我们会在收到邮件的第一时间与你取得联系。
