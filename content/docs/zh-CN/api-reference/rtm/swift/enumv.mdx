<a id="areacode"></a>
## AgoraRtmAreaCode

访问区域，即 SDK 连接的服务器所在的区域。

|       枚举值      | 描述             |
| --------- | ----- |
|   `CN`    |       `0x00000001`: 中国大陆。    |
|   `NA`    |       `0x00000002`: 北美区域。    |
|   `EU`    |       `0x00000004`: 欧洲区域。    |
|   `AS`    |       `0x00000008`: 除中国大陆以外的亚洲区域。       |
|   `JP`    |       `0x00000010`: 日本。    |
|   `IN`    |       `0x00000020`: 印度。    |
|   `GLOB`  |         `0xFFFFFFFF`: 全球。  |

<a id="joinchannelfeature"></a>
## AgoraRtmJoinChannelFeature

加入频道时设置的事件通知类型，你可以通过位操作同时设置多种事件通知。

| 枚举值 | 描述 |
| --- | --- |
| `presence` | `1`: 设置 Presence 事件通知。 |
| `metadata` | `1 << 1`: 设置 Storage 事件通知。 |
| `lock` | `1 << 2`: 设置 Lock 事件通知。 |
| `beQuiet` | <Slot name="enumv-android-ios-cpp-flutter-swift-harmonyos-html-0-4-1" /> |

<Slot for="enumv-android-ios-cpp-flutter-swift-harmonyos-html-0-4-1">

`1 << 3`: 设置静默模式。该模式的行为如下：

    - 不影响你接收频道内其他用户的事件通知。
    - 频道内其他用户不会收到你加入/离开频道、设置/获取/删除临时状态的事件通知。
    - 调用 `whoNow` 方法查询不到自己。
    - 调用 `whereNow` 方法查询不到自己静默加入的频道。

</Slot>

<a id="subscribechannelfeature"></a>
## AgoraRtmSubscribeChannelFeature

订阅频道时设置的事件通知类型，你可以通过位操作同时设置多种事件通知。

| 枚举值 | 描述 |
| --- | --- |
| `none` | `0`: 不设置事件通知。 |
| `presence` | `1`: 设置 Presence 事件通知。 |
| `metadata` | `1 << 1`: 设置 Storage 事件通知。 |
| `message` | `1 << 2`: 设置消息事件通知。 |
| `lock` | `1 << 3`: 设置 Lock 事件通知。 |
| `beQuiet` | <Slot name="enumv-android-ios-cpp-flutter-swift-harmonyos-html-1-6-1" /> |

<Slot for="enumv-android-ios-cpp-flutter-swift-harmonyos-html-1-6-1">

`1 << 4`: 设置静默模式。该模式的行为如下：

    - 不影响你接收频道内其他用户的事件通知。
    - 频道内其他用户不会收到你订阅/取消订阅频道、设置/获取/删除临时状态的事件通知。
    - 调用 `whoNow` 方法查询不到自己。
    - 调用 `whereNow` 方法查询不到自己静默订阅的频道。

</Slot>
