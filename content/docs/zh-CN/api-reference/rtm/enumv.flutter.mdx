<a id="areacode"></a>
## RtmAreaCode

访问区域，即 SDK 连接的服务器所在的区域。

|       枚举值      | 描述             |
| --------- | ----- |
|   `cn`    |       `0x00000001`: 中国大陆。    |
|   `na`    |       `0x00000002`: 北美区域。    |
|   `eu`    |       `0x00000004`: 欧洲区域。    |
|   `asm`    |       `0x00000008`: 除中国大陆以外的亚洲区域。       |
|   `jp`    |       `0x00000010`: 日本。    |
|   `ind`    |       `0x00000020`: 印度。    |
|   `glob`  |         `0xFFFFFFFF`: 全球。  |

<a id="channeltype"></a>
## RtmChannelType

频道类型。

|       枚举值      | 描述             |
| --------- | ----- |
|    `message`  | `1`: Message Channel         |
|    `stream`  | `2`: Stream Channel       |
| `user` | `3`: User Channel |

<a id="connectionreason"></a>
## RtmConnectionChangeReason

SDK 连接状态改变的原因。

|       枚举值      | 描述             |
| --------- | ----- |
|    `connecting`  | `0`: 建立网络连接中。         |
|    `joinSuccess`  | `1`: 成功加入频道。         |
|    `interrupted`  | `2`: 网络连接中断。        |
|    `bannedByServer`  | `3`: 网络连接被服务器禁止。                    |
|    `joinFailed`  | `4`: SDK 连续 20 分钟无法加入频道，停止重连频道。        |
|    `leaveChannel`  | `5`: 离开频道。            |
|    `invalidAppId`  | `6`: 不是有效的 App ID，无法加入频道。   |
|    `invalidChannelName`  | `7`: 不是有效的频道名，无法加入频道。     |
|    `invalidToken`  | `8`: Token 无效，无法加入频道。   |
|    `tokenExpired`  | `9`: Token 过期，无法加入频道。  |
|    `rejectedByServer`  | `10`: 被服务器禁止连接。    |
|    `settingProxyServer`  | `11`: 由于设置了代理服务器，SDK 尝试重连。    |
|    `renewToken`  | `12`: 更新 Token 引起网络连接状态改变。        |
|    `clientIpAddressChanged`  | `13`: 由于网络类型，或网络运营商的 IP 或端口发生改变，客户端 IP 地址变更，SDK 尝试重连。  |
|    `keepAliveTimeout`  | `14`: SDK 和服务器连接保活超时，进入自动重连状态。  |
|    `rejoinSuccess`  | `15`: 重新加入频道成功。  |
|    `lost`  | `16`: SDK 丢失与服务器的连接。      |
|    `echoTest`  | `17`: 通话回声测试引起连接状态改变。       |
|    `clientIpAddressChangedByUser`  | `18`: 用户变更客户端 IP 地址，SDK 尝试重连。     |
|    `sameUidLogin`  | `19`: 使用相同的用户 ID 从不同的设备加入同一频道。     |
|    `tooManyBroadcasters`  | `20`: 频道内主播人数已达上限。    |
|    `licenseValidationFailure`  | `21`: License 校验失败。    |
|    `certificationVerifyFailure`  | `22`: 服务器证书校验失败。    |
|    `streamChannelNotAvailable`  | `23`: Stream Channel 不存在。    |
|    `inconsistentAppid`  | `24`: App ID 与 Token 不匹配。    |
|    `loginSuccess`  | `10001`: SDK 登录 RTM 系统成功。    |
|    `logout`  | `10002`: SDK 已退出 RTM 系统。    |
|    `presenceNotReady`  | `10003`: Presence 服务未就绪。你需要重新调用 `login` 方法登录 RTM 系统并重新执行对 SDK 的所有操作。    |

<a id="connectionstate"></a>
## RtmConnectionState

SDK 连接状态。

|       枚举值      | 描述             |
| --------- | ----- |
|    `disconnected`  | `1`: SDK 已和服务器断开连接。         |
|    `connecting`  | `2`: SDK 正在连接服务器。         |
|    `connected`  | `3`: SDK 已连上服务器。         |
|    `reconnecting`  | `4`: SDK 和服务器断开连接，正在重新连接服务器。                     |
|    `failed`  | `5`: SDK 无法连接服务器。           |

<a id="encryptionmode"></a>
## RtmEncryptionMode

加密方式。

|       枚举值      | 描述             |
| --------- | ----- |
|   `none`  |         `0`: 不加密。                    |
|   `aes128Gcm`    |      `1`: 128 位 AES 加密，GCM 模式。      |
|   `aes256Gcm`    |      `2`: 256 位 AES 加密，GCM 模式。       |

<a id="locktype"></a>
## RtmLockEventType

Lock 事件类型。

|       枚举值      | 描述             |
| --------- | ----- |
|   `snapshot`  |        `1`: 加入频道时 Lock 的快照信息。        |
|   `lockSet`    |      `2`: 已设置 Lock。 |
|   `lockRemoved`  |        `3`: 已删除 Lock。       |
|   `lockAcquired`    |      `4`: 已获取 Lock。 |
|   `lockReleased`  |        `5`: 已释放 Lock。        |
|   `lockExpired`    |      `6`: Lock 已过期。 |

<a id="loglevel"></a>
## RtmLogLevel

日志信息的输出等级。

|       枚举值      | 描述             |
| --------- | ----- |
|   `none`  |         `0x0000`: 不输出任何日志。                     |
|   `info`    |       `0x0001`: 输出 `fatal`、`error`、`warn`、`info` 级别的日志。我们推荐你将日志级别设为该等级。      |
|   `warn`    |       `0x0002`: 仅输出 `fatal`、`error`、`warn` 级别的日志。        |
|   `error`    |      `0x0004`: 仅输出 `fatal`、`error` 级别的日志。      |
|   `fatal`    |      `0x0008`: 仅输出 `fatal` 级别的日志。      |

<a id="presencetype"></a>
## RtmPresenceEventType

Presence 事件类型。

|       枚举值      | 描述             |
| --------- | ----- |
|   `snapshot`  |        `1`: 加入频道时 Presence 的快照信息。                   |
|   `interval`    |      `2`: 当频道内人数达到设定值后，频道内的事件通知将由实时通知转为定时通知。      |
|   `remoteJoinChannel`    |      `3`: 远端用户加入频道。      |
|   `remoteLeaveChannel`  |        `4`: 远端用户离开频道。                   |
|   `remoteTimeout`    |      `5`: 远端用户连接超时。      |
|   `remoteStateChanged`    |    `6`: 远端用户的临时用户状态改变。      |
|   `errorOutOfService`    |    `7`: 用户加入频道时未启用 Presence。      |

<a id="rtmservicetype"></a>
## RtmServiceType

服务类型。

|       枚举值      | 描述             |
| --------- | ----- |

<a id="storageeventtype"></a>
## RtmStorageEventType

Storage 事件类型。

|       枚举值      | 描述             |
| --------- | ----- |
| `snapshot` | `1`: 用户第一次订阅 Channl Metadata 或 User Metadata，或加入频道时触发，本地用户会收到此类事件通知。 |
|   `set`    | `2`: 当调用 `setChannelMetadata` 或者 `setUserMetadata` 时触发。该事件仅在增量数据更新模式下返回。 |
|  `update`  | `3`: 当调用设置、更新或删除 Channel Metadata 或 User Metadata 的方法时会返回该类型事件。|
|  `remove`  | `4`: 当调用 `removeChannelMetadata` 或者 `removeUserMetadata` 时触发。该事件仅在增量数据更新模式下返回。  |
