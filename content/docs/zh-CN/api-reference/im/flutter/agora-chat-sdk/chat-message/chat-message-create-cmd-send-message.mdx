Creates a command message for sending.

- For a one-to-one chat, it is the username of the peer user.
- For a group chat, it is the group ID.
- For a chat room, it is the chat room ID.

**Return** The message instance.

## Parameters

| Name | Description |
| --- | --- |
| `targetId` | The ID of the message recipient. |
| `action` | The command action. |

```dart
ChatMessage.createCmdSendMessage({required String targetId, required dynamic action, bool deliverOnlineOnly = false, ChatType chatType = ChatType.Chat})
```

## Implementation

```dart
ChatMessage.createCmdSendMessage({
  required String targetId,
  required action,

  ChatType chatType = ChatType.Chat,
```
