Creates an image message for sending.

- For a one-to-one chat, it is the username of the peer user.
- For a group chat, it is the group ID.
- For a chat room, it is the chat room ID.

- `true`: Yes.
- `false`: (default) No. For an image greater than 100 KB, the SDK will compress it and send the thumbnail.

**Return** The message instance.

## Parameters

| Name | Description |
| --- | --- |
| `targetId` | The ID of the message recipient. |
| `filePath` | The image path. |
| `displayName` | The image name. |
| `thumbnailLocalPath` | The local path of the image thumbnail. |
| `sendOriginalImage` | Whether to send the original image. |
| `fileSize` | The image file size in bytes. |
| `width` | The image width in pixels. |
| `height` | The image height in pixels. |
