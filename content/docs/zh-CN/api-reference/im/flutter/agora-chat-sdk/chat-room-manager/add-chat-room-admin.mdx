Adds a chat room admin.

Only the chat room owner can call this method.

**Throws** A description of the exception. See [ChatError](/zh-CN/api-reference/im/flutter/agora-chat-sdk/chat-error).

## Parameters

| Name | Description |
| --- | --- |
| `roomId` | The chat room ID. |
| `admin` | The ID of the chat room admin to be added. |

```dart
Future<void> addChatRoomAdmin(String roomId, String admin)
```

## Implementation

```dart
Future<void> addChatRoomAdmin(
  String roomId,
  String admin,
) async {
  Map req = {"roomId": roomId, "admin": admin};
  Map result =
      await _channel.invokeMethod(ChatMethodKeys.addChatRoomAdmin, req);
  try {
    ChatError.hasErrorFromResult(result);
  } on ChatError catch (e) {
    throw e;
  }
}
```
