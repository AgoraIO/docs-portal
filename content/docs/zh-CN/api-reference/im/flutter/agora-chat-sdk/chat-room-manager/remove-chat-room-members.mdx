Removes the specified members from a chat room.

Only the chat room owner or admin can call this method.

**Throws** A description of the exception. See [ChatError](/zh-CN/api-reference/im/flutter/agora-chat-sdk/chat-error).

## Parameters

| Name | Description |
| --- | --- |
| `roomId` | The chat room ID. |
| `members` | The list of the members to be removed. |

```dart
Future<void> removeChatRoomMembers(String roomId, List<String> members)
```

## Implementation

```dart
Future<void> removeChatRoomMembers(
  String roomId,
  List<String> members,
) async {
  Map req = {"roomId": roomId, "members": members};
  Map result =
      await _channel.invokeMethod(ChatMethodKeys.removeChatRoomMembers, req);
  try {
    ChatError.hasErrorFromResult(result);
  } on ChatError catch (e) {
    throw e;
  }
}
```
