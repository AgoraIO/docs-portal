Updates the chat room announcement.

Only the chat room owner or admin can call this method.

**Throws** A description of the exception. See [ChatError](/zh-CN/api-reference/im/flutter/agora-chat-sdk/chat-error).

## Parameters

| Name | Description |
| --- | --- |
| `roomId` | The chat room ID. |
| `announcement` | The announcement content. |

```dart
Future<void> updateChatRoomAnnouncement(String roomId, String announcement)
```

<a id="source"></a>

## Implementation

```dart
Future<void> updateChatRoomAnnouncement(
  String roomId,
  String announcement,
) async {
  Map req = {"roomId": roomId, "announcement": announcement};
  Map result = await _channel.invokeMethod(
      ChatMethodKeys.updateChatRoomAnnouncement, req);
  try {
    ChatError.hasErrorFromResult(result);
  } on ChatError catch (e) {
    throw e;
  }
}
```
