Gets the current user's role in the chat room. The role types: [ChatRoomPermissionType](/zh-CN/api-reference/im/flutter/agora-chat-sdk/chat-room-permission-type).

**Note** To get the correct value, ensure that you call [ChatRoomManager.fetchChatRoomInfoFromServer](/zh-CN/api-reference/im/flutter/agora-chat-sdk/chat-room-manager/fetch-chat-room-info-from-server) before calling this method.

```dart
ChatRoomPermissionType permissionType final
```
