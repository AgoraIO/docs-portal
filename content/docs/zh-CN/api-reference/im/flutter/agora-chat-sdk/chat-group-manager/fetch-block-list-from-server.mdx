Gets the group block list from server with pagination.

Only the group owner or admin can call this method.

**Return** The group block list.

**Throws** A description of the exception. See [ChatError](/zh-CN/api-reference/im/flutter/agora-chat-sdk/chat-error).

## Parameters

| Name | Description |
| --- | --- |
| `groupId` | The group ID. |
| `pageSize` | The number of groups per page. |
| `pageNum` | The page number, starting from 1. |

```dart
Future<List<String>> fetchBlockListFromServer(String groupId, {int pageSize = 200, int pageNum = 1})
```

## Implementation

```dart
Future<List<String>> fetchBlockListFromServer(
  String groupId, {
  int pageSize = 200,
  int pageNum = 1,
}) async {
  Map req = {'groupId': groupId, 'pageNum': pageNum, 'pageSize': pageSize};
  Map result = await _channel.invokeMethod(
      ChatMethodKeys.getGroupBlockListFromServer, req);
  try {
    ChatError.hasErrorFromResult(result);
    return result[ChatMethodKeys.getGroupBlockListFromServer]
            ?.cast<String>() ??
        [];
  } on ChatError catch (e) {
    throw e;
  }
}
```
