Whether to enable the do-not-disturb mode for push notifications.

- true: Yes.
- false: No. Sets it by ChatPushManager.disableOfflinePush.

```dart
bool noDisturb @Deprecated("Use ChatSilentModeResult property remindType, expireTimestamp and silentModeTime determine whether to enable"), final
```
