Enable Firebase Cloud Messaging (FCM) push on devices that support Google Play.

## Parameters

| Name | Description |
| --- | --- |
| `appId` | The app ID for FCM push. |

```dart
void enableFCM(String appId)
```

<a id="source"></a>

## Implementation

```dart
void enableFCM(String appId) {
  _pushConfig.enableFCM = true;
  _pushConfig.fcmId = appId;
}
```
