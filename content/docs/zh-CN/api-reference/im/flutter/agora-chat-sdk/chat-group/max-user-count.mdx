Gets the maximum number of group members allowed in a group. The parameter is set when the group is created.

**Note** To get the correct value, ensure that you call [ChatGroupManager.fetchGroupInfoFromServer](/zh-CN/api-reference/im/flutter/agora-chat-sdk/chat-group-manager/fetch-group-info-from-server) before calling this method.

```dart
int? maxUserCount final
```
