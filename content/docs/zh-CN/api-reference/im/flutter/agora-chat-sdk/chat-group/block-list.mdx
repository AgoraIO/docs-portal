Gets the block list of the group.

If no block list is found from the server, the return may be empty.

**Note** To get the correct value, ensure that you call [ChatGroupManager.fetchBlockListFromServer](/zh-CN/api-reference/im/flutter/agora-chat-sdk/chat-group-manager/fetch-block-list-from-server) before calling this method.
