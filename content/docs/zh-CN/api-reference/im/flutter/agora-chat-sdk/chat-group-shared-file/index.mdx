The ChatGroupSharedFile class, which manages the chat group shared files.

To get the information of the chat group shared file, call [ChatGroupManager.fetchGroupFileListFromServer](/zh-CN/api-reference/im/flutter/agora-chat-sdk/chat-group-manager/fetch-group-file-list-from-server).

```dart
  List<ChatGroupSharedFile>? list = await ChatClient.getInstance.groupManager.fetchGroupFileListFromServer(groupId);
```
