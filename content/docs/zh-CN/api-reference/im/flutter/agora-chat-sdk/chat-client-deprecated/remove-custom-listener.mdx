Removes the custom listener.

## Parameters

| Name | Description |
| --- | --- |
| `listener` | The custom native listener. |

```dart
@deprecated void removeCustomListener(ChatCustomListener listener)
```

<a id="source"></a>

## Implementation

```dart
@deprecated
void removeCustomListener(ChatCustomListener listener) {
  if (_customListeners.contains(listener)) {
    _customListeners.remove(listener);
  }
}
```
