The class for group message read receipts.

To get the chat group message receipts, call [ChatManager.fetchGroupAcks](/zh-CN/api-reference/im/flutter/agora-chat-sdk/chat-manager/fetch-group-acks).

```dart
  ChatCursorResult<ChatGroupMessageAck> result = await ChatClient.getInstance.chatManager.fetchGroupAcks("msgId");
```
