title: 输入在线媒体流概览

---

输入一路在线媒体流至声网频道内播放相当于创建了一个云端播放器。你可以通过 RESTful API 控制云端播放器，实现对媒体流的输入和播放控制。

:::warning
请确保声网频道的场景为直播，而非通信，否则输入媒体流会失败。
:::

## API 基础信息

- **鉴权**：所有 API 都需要 [RESTful API 鉴权](restful-authentication)。
- **请求**：请求包体使用 JSON。
- **响应**：响应包体使用 JSON。
- **Base URL**：`https://api.sd-rtn.com`

## REST API

- [创建云端播放器](create)：在项目中创建一个云端播放器。
- [更新云端播放器](update)：更新指定云端播放器的可变配置。
- [查询所有云端播放器](list)：分页查询指定项目下的云端播放器。
- [销毁云端播放器](delete)：销毁指定云端播放器。
- [查询消息通知服务器 IP](get-ncs-ip)：获取消息通知服务器 IP 地址，用于配置防火墙白名单。

## 消息通知

开通消息通知服务后，你可以通过 Webhook 接收云端播放器创建成功、运行状态改变和销毁成功等事件。声网会动态调整消息通知服务器的 IP 地址，因此你需要定期查询 IP 地址并更新防火墙白名单。
