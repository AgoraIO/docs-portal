---
title: 响应状态码
description: 控制台 RESTful API 的通用响应状态说明。
---

控制台 RESTful API 在响应中返回 HTTP 状态码和 JSON 响应包体。请求失败时，请结合状态码和响应中的 `message` 字段排查问题。

## 常见状态

| 状态码 | 说明 |
| --- | --- |
| `201` | 请求成功。 |
| 非 `201` | 请求失败，请根据响应包体中的 `message` 字段排查。 |
