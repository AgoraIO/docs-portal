声网云端转码在声网服务器上对媒体流进行转码，并将结果输出到 RTC 频道。你可以从业务服务器发送 HTTPS 请求，管理转码任务和转码模板。

## API 基础信息

- **鉴权**：所有 API 都需要使用 [Basic Auth](authentication)。
- **请求**：请求包体使用 JSON。
- **响应**：响应包体使用 JSON。
- **Base URL**：`https://api.sd-rtn.com`

:::info
云端转码 REST API 仅支持 HTTPS，不支持明文 HTTP 请求。
:::

## REST API

- [获取云端转码资源](acquire)：创建任务前获取 builderToken。
- [创建云端转码](create)：创建任务并开始云端转码。
- [查询云端转码状态](query)：查询云端转码任务的当前状态。
- [更新指定的云端转码](update)：更新已有云端转码任务。
- [销毁云端转码](destroy)：销毁不再需要的云端转码任务。
- [创建或更新转码模板](template-create)：创建或更新转码模板。
- [查询转码模板](template-query)：查询指定 App ID 下的所有转码模板配置。
- [查询消息通知服务器 IP](ncs-query-ip)：获取消息通知服务器 IP 地址，用于配置防火墙白名单。
