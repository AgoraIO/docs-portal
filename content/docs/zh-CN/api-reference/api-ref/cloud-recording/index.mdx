---
title: 云端录制概览
description: 使用 RESTful API 管理云端录制任务。
---

声网云端录制用于录制并保存语音通话、视频通话和互动直播。你可以通过业务服务器向声网服务器发送 HTTPS 请求，在服务端管理录制任务。

如需监听录制状态，启用消息通知服务并通过 Webhook 接收云端录制事件。声网会动态调整消息通知服务器 IP 地址，因此你需要定期查询 IP 地址并更新防火墙白名单。

## API 基础信息

- **鉴权**：所有 API 都需要 [Basic Auth](/zh-CN/api-reference/api-ref/cloud-recording/authentication)。
- **请求**：请求包体使用 JSON。
- **响应**：响应包体使用 JSON。
- **Base URL**: `https://api.sd-rtn.com`

:::info
云端录制 REST API 仅支持 HTTPS，不支持通过 HTTP 明文请求。
:::

## REST APIs

- [获取云端录制资源](/zh-CN/api-reference/api-ref/cloud-recording/acquire)：请求获取一个用于云端录制的 Resource ID。
- [开始云端录制](/zh-CN/api-reference/api-ref/cloud-recording/start)：使用 Resource ID 开始云端录制。请在调用 `acquire` 后尽快调用该方法。
- [更新云端录制设置](/zh-CN/api-reference/api-ref/cloud-recording/update)：更新订阅、页面录制、CDN 推流或存储设置。
- [更新云端录制合流布局](/zh-CN/api-reference/api-ref/cloud-recording/update-layout)：更新合流录制布局。
- [查询云端录制状态](/zh-CN/api-reference/api-ref/cloud-recording/query)：查询云端录制任务状态。
- [停止云端录制](/zh-CN/api-reference/api-ref/cloud-recording/stop)：离开频道并停止录制。
- [查询消息通知服务器 IP](/zh-CN/api-reference/api-ref/cloud-recording/get-ncs-ip)：获取消息通知服务器 IP 地址，用于配置防火墙白名单。
