对于每个声网账号（非每个 App ID），控制台 RESTful API 的调用频率上限为每秒 10 次。如果调用频率超出限制，请参考[如何处理服务端 RESTful API 调用超出频率限制](/zh-CN/reference/faq/integration/restful_api_call_frequency)优化调用频率，或者[联系技术支持](https://ticket.shengwang.cn/)提升频率限制。
