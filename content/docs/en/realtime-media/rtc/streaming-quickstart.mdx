Use this page to adapt the [Realtime Communication quickstart](/en/realtime-media/rtc/get-started-sdk) for a streaming app: a large audience watching one or a few hosts, such as a live-shopping event, a virtual concert, or a game-streaming app. This differs from a standard peer-to-peer video calling app, where every participant publishes and subscribes as an equal peer.

Before you continue, complete the [Realtime Communication quickstart](/en/realtime-media/rtc/get-started-sdk) for your platform. That page covers setting up your project, installing the Agora RTC SDK, initializing the engine, and the basic channel-join flow. This page only documents what to change afterward to support streaming.

## What changes for streaming

Three settings distinguish a streaming app from a standard calling app:

- **Channel profile**: Change the channel profile from **Communication** to **Live Broadcasting**. This profile applies the one-to-many optimizations that a large audience needs.
- **Client role**: In Communication mode, every user is a peer. In Live Broadcasting mode, you assign each user a role — **host** (`Broadcaster`) publishes audio and video to the channel; **audience** only subscribes. Set the role when you join, and change it later by calling `setClientRole`.
- **Audience latency level**: For the audience role, set a latency level to trade off delay against synchronization. A *low-latency* level suits one-way broadcast viewing. An *ultra-low-latency* level suits more interactive formats, where hosts and audience need to react to each other in near real time, such as co-hosting or live auctions.

The sections below show the platform-specific code for these changes.

## Set the channel profile and client role

In the `joinChannel` call from the base quickstart, update `AgoraRtcChannelMediaOptions` to set the streaming profile, the role, and the audience latency level:

```swift
let options = AgoraRtcChannelMediaOptions()
// Change the channel profile from .communication to .liveBroadcasting
options.channelProfile = .liveBroadcasting
// Set the user role to .broadcaster (host) or .audience
options.clientRoleType = .broadcaster
options.publishMicrophoneTrack = true
options.publishCameraTrack = true
options.autoSubscribeAudio = true
options.autoSubscribeVideo = true
// Only takes effect when clientRoleType is .audience
options.audienceLatencyLevel = .lowLatency
agoraKit.joinChannel(
  byToken: token,
  channelId: channelName,
  uid: 0,
  mediaOptions: options
)
```

To change a user's role after joining, call `setClientRole`:

```swift
let role = AgoraClientRole.audience
let options = AgoraClientRoleOptions()
options.audienceLatencyLevel = .lowLatency
agoraKit.setClientRole(role, options: options)
```

## Set the channel mode and client role

Change `mode` from `"rtc"` to `"live"` when you call `createClient`, and set the role to `"host"` or `"audience"` for each user:

```javascript
let client = AgoraRTC.createClient({ mode: "live", codec: "vp8", role: "host" });
```

Join as a host to publish local media:

```js
async function joinChannel() {
  await client.join(appId, channel, token, uid);
  // A host can both publish tracks and subscribe to tracks
  client.setClientRole("host", clientRoleOptions);
  await createLocalMediaTracks();
  await publishLocalTracks();
  displayLocalVideo();
}
```

Join as audience to only subscribe, and set the audience latency level with `level` (`1` is low latency):

```js
async function joinAsAudience() {
  await client.join(appId, channel, token, uid);
  // Low audience latency level for broadcast streaming
  let clientRoleOptions = { level: 1 };
  // Audience can only subscribe to tracks
  client.setClientRole("audience", clientRoleOptions);
}
```

For details on the two channel modes, see [Channel modes](/en/realtime-media/rtc/get-started-sdk#channel-modes) in the base quickstart's reference section.

## Set the channel profile, client role, and audience latency level

Unlike the other platforms, Flutter sets the channel profile once, when you initialize the engine, instead of at join time:

```dart
await _engine.initialize(const RtcEngineContext(
  appId: appId,
  // Change from channelProfileCommunication to channelProfileLiveBroadcasting
  channelProfile: ChannelProfileType.channelProfileLiveBroadcasting,
));
```

Then, in the `joinChannel` call from the base quickstart, set the client role and the audience latency level in `ChannelMediaOptions`:

```dart
await _engine.joinChannel(
  token: token,
  channelId: channel,
  options: const ChannelMediaOptions(
    autoSubscribeVideo: true,
    autoSubscribeAudio: true,
    publishCameraTrack: true,
    publishMicrophoneTrack: true,
    // Use clientRoleBroadcaster to act as a host, or clientRoleAudience for audience
    clientRoleType: ClientRoleType.clientRoleBroadcaster,
    // Only takes effect when clientRoleType is clientRoleAudience
    audienceLatencyLevel: AudienceLatencyLevelType.audienceLatencyLevelLowLatency,
  ),
  uid: 0,
);
```

## Set the channel profile and client role

In the `joinChannel` call from the base quickstart, change the channel profile and add the audience latency level to the audience branch:

```tsx
if (isHost) {
  agoraEngineRef.current?.joinChannel(token, channelName, localUid, {
    // Change the channel profile from ChannelProfileCommunication to ChannelProfileLiveBroadcasting
    channelProfile: ChannelProfileType.ChannelProfileLiveBroadcasting,
    clientRoleType: ClientRoleType.ClientRoleBroadcaster,
    publishMicrophoneTrack: true,
    publishCameraTrack: true,
    autoSubscribeAudio: true,
    autoSubscribeVideo: true,
  });
} else {
  agoraEngineRef.current?.joinChannel(token, channelName, localUid, {
    channelProfile: ChannelProfileType.ChannelProfileLiveBroadcasting,
    clientRoleType: ClientRoleType.ClientRoleAudience,
    publishMicrophoneTrack: false,
    publishCameraTrack: false,
    autoSubscribeAudio: true,
    autoSubscribeVideo: true,
    // Only takes effect for the audience role
    audienceLatencyLevel: AudienceLatencyLevelType.AudienceLatencyLevelLowLatency,
  });
}
```

## Set the channel profile and client role

Unity sets the channel profile in both places: when you initialize the engine, and again in the channel media options when you join. Update both:

```csharp
RtcEngineContext context = new RtcEngineContext();
context.appId = _appID;
// Change from CHANNEL_PROFILE_COMMUNICATION to CHANNEL_PROFILE_LIVE_BROADCASTING
context.channelProfile = CHANNEL_PROFILE_TYPE.CHANNEL_PROFILE_LIVE_BROADCASTING;

RtcEngine.Initialize(context);
```

```csharp
ChannelMediaOptions options = new ChannelMediaOptions();
options.autoSubscribeAudio.SetValue(true);
options.autoSubscribeVideo.SetValue(true);
```

## Set the channel profile and client role

Apply these changes to the **Join Channel** blueprint node from the base quickstart:

- In **IRtcEngine** initialization, connect the **RtcEngineContext** configuration and set **Channel Profile** to `CHANNEL_PROFILE_LIVE_BROADCASTING`.
- In **Make ChannelMediaOptions**, check **Channel Profile Set Value** and set **Channel Profile** to `CHANNEL_PROFILE_LIVE_BROADCASTING`.
- In the same node, check **Client Role Type Set Value** and set **Client Role Type** to `CLIENT_ROLE_BROADCASTER` or `CLIENT_ROLE_AUDIENCE`, to set the user role to host or audience.
