title: Transcoding
description: Transcoding restructures, reformats, and outputs media flows into forms suitable for distribution and composed layouts.
---

## What this capability is

Transcoding transforms media streams through format conversion, layout composition, and output shaping. It is especially important for streaming and multi-view delivery.

## Common forms

- cloud transcoding
- multi-layout composition
- output format transformation

## What to read first

If your main objective is streaming output or multi-layout composition, start from the cloud transcoding path first.
