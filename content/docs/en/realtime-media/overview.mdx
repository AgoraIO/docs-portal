Realtime & Media is the capability domain for teams building products where something needs to happen live, but who still need a clearer map of the technical building blocks involved.

Use this tab when your main question is not "what product am I building?" but "what realtime or media capability do I need to implement?" It is organized as a map of Agora's realtime stack, so you can see how the docs are grouped and how the different parts of the stack relate to one another.

The content in this tab is grouped by technical layer rather than by product scenario. As you move through it, you will see capabilities for live interaction, session processing, media interoperability, large-scale delivery, and device or backend participation. Use this overview to understand what each layer covers, how the sections relate, and where different kinds of technical topics live within the tab.

## Where different topics live

The groups below trace the main technical layers in this tab. Read them as a content map first, then go deeper into the related docs for architecture, APIs, and implementation details.

### Build live interaction

This group covers docs for sessions where users, participants, or services exchange media or state in real time.

- [Voice & Video](/en/realtime-media/rtc): calls, meetings, co-hosting, interactive live rooms, and media quality control
- [Signaling](/en/realtime-media/rtm): channel messaging, presence, state sync, and realtime coordination
- [Chat](/en/realtime-media/im): persistent messaging systems beyond lightweight room coordination
- [Whiteboard](/en/realtime-media/whiteboard): shared visual collaboration inside live sessions

### Process session content

This group covers docs for turning session media into text, archives, composites, or downstream assets during or after the session.

- [Transcription & Translation](/en/realtime-media/speech-to-text): captions, speech understanding, and multilingual live experiences
- [Cloud Recording](/en/realtime-media/cloud-recording): archive, replay, compliance, QA, and post-session review workflows
- [Transcoding](/en/realtime-media/transcoding): mixing, layout composition, and output transformation

### Connect external media systems

This group covers docs for connecting Agora sessions to external streaming infrastructure.

- [Media Push](/en/realtime-media/media-push): send RTC channel media to CDN pipelines or downstream media systems
- [Media Pull](/en/realtime-media/media-pull): bring online media streams into an interactive realtime session
- [RTMP Gateway](/en/realtime-media/rtmp-gateway): connect RTMP-based devices and systems to Agora

### Deliver to larger audiences

This group covers docs for architectures where interactive participation and large-scale playback are handled separately.

- [Fusion CDN](/en/realtime-media/fusion-cdn): multi-CDN distribution for live playback at audience scale

### Run on devices and backend services

This group covers docs for systems that include embedded devices, edge endpoints, operator consoles, or server-side workers.

- [IoT & Edge](/en/realtime-media/rtsa): device and edge connectivity for cameras, terminals, and embedded endpoints
- [RTC Server SDK](/en/realtime-media/rtc-server-sdk): backend participation in media send, receive, subscribe, and control flows
