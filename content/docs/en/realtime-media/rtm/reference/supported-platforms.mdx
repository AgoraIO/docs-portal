This section lists the platforms and products you use to develop apps that interact with Agora SDRTN®.

### Supported browsers

Minimum supported versions:

- Chrome
  - macOS 90.0.4430.72
  - Windows 90.0.4430.72
  - Linux 93.0
  - Android 97.0.4692.70
  - iOS 120.0.6099.199
- Safari
  - macOS 15.6
  - iOS 15.6
- Microsoft Edge
  - macOS 116.0.1938.81
  - Windows 116.0.1938.81
- Firefox
  - macOS 85.0.1
  - Windows 85.0.1 (x64)
