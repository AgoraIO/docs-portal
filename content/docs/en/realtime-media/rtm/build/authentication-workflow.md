# Secure authentication with tokens

Authentication validates the identity of a user before they access a system. Agora uses tokens to authenticate users and their privileges before they access Signaling.

This page shows you how to set up a token server and use it to connect securely to Signaling.

## Understand the tech

Signaling provides two types of channels:

- **Message channels**: Use an RTM token when you call `login`. An RTM token is valid only for the user ID used to generate it.
- **Stream channels**: Use an RTC token when you call `join`. An RTC token is valid only for the channel name and user ID used to generate it.

![Token authentication flow](/images/signaling/authentication-workflow.svg)

To log in to Signaling, your app retrieves an RTM token from your token server and sends it to Agora SDRTN for authentication. To join a stream channel, your app requests an RTC token from the server by supplying a user ID and channel name.

A token contains:

- The [App ID](manage-agora-account.md) of your Agora project
- The user ID of the user to be authenticated
- The stream channel name for RTC tokens
- The Unix timestamp indicating when the token expires

## Prerequisites

Ensure that you have:

- Integrated the Signaling SDK in your project and implemented the framework functionality from [SDK quickstart](sdk-quickstart.mdx)
- The following information from Agora Console:
  - App ID
  - App certificate

## Implement basic authentication

In [SDK quickstart](sdk-quickstart.mdx), the app uses a temporary token obtained from Agora Console. In production, your app should retrieve this token from your own token server.

### Generate a token

This example uses Go to generate an RTM token. To generate an RTC token instead, see [Secure authentication with tokens](https://docs.agora.io/en/video-calling/token-authentication/deploy-token-server).

Before proceeding, make sure that you have:

- [Installed Go](https://golang.org/) 1.14 or later
- Set `GO111MODULE=on` if you use Go earlier than 1.16

Create a `server.go` file containing:

```go
package main

import (
    "encoding/json"
    "errors"
    "fmt"
    rtmtokenbuilder "github.com/AgoraIO/Tools/DynamicKey/AgoraDynamicKey/go/src/rtmtokenbuilder2"
    "log"
    "net/http"
    "strconv"
    "time"
)

type rtmTokenRequest struct {
    Uid string `json:"uid"`
}

var rtmToken string
var rtmUid string

func generateRtmToken(uid string) {
    appID := "Your_App_ID"
    appCertificate := "Your_App_Certificate"
    expireTimeInSeconds := uint32(3600)
    currentTimestamp := uint32(time.Now().UTC().Unix())
    expireTimestamp := currentTimestamp + expireTimeInSeconds

    result, err := rtmtokenbuilder.BuildToken(appID, appCertificate, uid, expireTimestamp)
    if err != nil {
        fmt.Println(err)
        return
    }

    fmt.Printf("Rtm Token: %s\n", result)
    rtmToken = result
}

func rtmTokenHandler(w http.ResponseWriter, r *http.Request) {
    w.Header().Set("Content-Type", "application/json;charset=UTF-8")
    w.Header().Set("Access-Control-Allow-Origin", "*")
    w.Header().Set("Access-Control-Allow-Methods", "POST, OPTIONS")
    w.Header().Set("Access-Control-Allow-Headers", "*")

    if r.Method == "OPTIONS" {
        w.WriteHeader(http.StatusOK)
        return
    }

    if r.Method != "POST" {
        http.Error(w, "Unsupported method. Please check.", http.StatusNotFound)
        return
    }

    var req rtmTokenRequest
    var unmarshalErr *json.UnmarshalTypeError
    decoder := json.NewDecoder(r.Body)
    err := decoder.Decode(&req)
    if err == nil {
        rtmUid = req.Uid
    }
    if err != nil {
        if errors.As(err, &unmarshalErr) {
            errorResponse(w, "Bad request. Please check your params.", http.StatusBadRequest)
        } else {
            errorResponse(w, "Bad request.", http.StatusBadRequest)
        }
        return
    }

    generateRtmToken(rtmUid)
    errorResponse(w, rtmToken, http.StatusOK)
    log.Println(w, r)
}

func errorResponse(w http.ResponseWriter, message string, httpStatusCode int) {
    w.Header().Set("Content-Type", "application/json")
    w.Header().Set("Access-Control-Allow-Origin", "*")
    w.WriteHeader(httpStatusCode)
    resp := map[string]string{
        "token": message,
        "code": strconv.Itoa(httpStatusCode),
    }
    jsonResp, _ := json.Marshal(resp)
    w.Write(jsonResp)
}

func main() {
    http.HandleFunc("/fetch_rtm_token", rtmTokenHandler)
    fmt.Printf("Starting server at port 8082\n")
    if err := http.ListenAndServe(":8082", nil); err != nil {
        log.Fatal(err)
    }
}
```

Then run:

```shell
go mod init sampleServer
go get
go run server.go
```

:::warning
This sample server is for development purposes only. Do not use it in production.
:::

### Log in with a token

Fetch an RTM token from your token server and pass it to the SDK when you call `login`.

```java
rtmClient.login("your_token", new ResultCallback<Void>() {
    @Override
    public void onSuccess(Void responseInfo) {
        // Handle login success
    }

    @Override
    public void onFailure(ErrorInfo errorInfo) {
        // Handle errors
    }
});
```

```kotlin
rtmClient.login("your_token", object : ResultCallback<Void> {
    override fun onSuccess(responseInfo: Void?) {
        // Handle login success
    }

    override fun onFailure(errorInfo: ErrorInfo) {
        // Handle errors
    }
})
```

:::info
- The user ID and app ID used to initialize the Signaling client must match the user ID and app ID used by your token server.
- Ensure that the app certificate is configured correctly, because it is part of the trust chain between your app and Agora SDRTN.
:::

### Join a stream channel using a token

To join a stream channel, fetch an **RTC** token from your token server and pass it to the SDK when you call `join`. For API details, see [API reference](https://docs.agora.io/en/signaling/reference/api).

### Token expiration and renewal

You configure the RTM token validity period in your token generator. The maximum validity period is 24 hours. When an RTM token is about to expire, the `onTokenPrivilegeWillExpire` callback is triggered 30 seconds before expiration. Retrieve a fresh RTM token from your token server and call `renewToken`.

If the token expires, the SDK triggers `onLinkStateEvent` and reports:

- `currentState`: `FAILED`
- `operation`: `SERVER_REJECT`
- `reason`: `Ticket expired`

In this case, log out using `logout`, retrieve a fresh token, and call `login` again.

:::info
An alternative approach is to renew the token proactively at a regular interval so that authentication stays seamless.
:::

## Reference

### BuildToken API reference

This section explains the API parameters for generating `AccessToken2` using Go:

```go
func BuildToken(appId string, appCertificate string, userId string, expire uint32) (string, error) {
    token := accesstoken.NewAccessToken(appId, appCertificate, expire)

    serviceRtm := accesstoken.NewServiceRtm(userId)
    serviceRtm.AddPrivilege(accesstoken.PrivilegeLogin, expire)
    token.AddService(serviceRtm)

    return token.Build()
}
```

| Parameter | Description |
| --- | --- |
| `appId` | The App ID generated when you create a project in Agora Console. |
| `appCertificate` | Your app certificate. |
| `userId` | The user ID used to identify a user or device. Ensure it is globally unique and stable for the lifetime of that user or device. |
| `expire` | The token validity period in seconds. The maximum validity period is 24 hours. |
