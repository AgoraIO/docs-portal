This section lists the platforms and products you use to develop apps that interact with Agora SDRTN®.

- *Platforms*:

  | Target Platform | Operating system version | IDE version |
  | --- | --- | --- |
  | Linux | <ul><li>x86_64: gcc 2.6.35 or higher.</li><li>ARM:<ul><li>arm-linux-gnueabi 4.4.x or higher</li><li>arm-linux-gnueabihf 4.8.x or higher</li><li>aarch64-linux-gnu 4.8.x or higher</li><li>arm-linux-musleabihf 5.2.x or higher</li><li>arm-linux-musleabi 5.5.x or higher</li><li>aarch64-linux-musl 5.5.x or higher</li><li>arm-linux-uclibceabi 4.4.x or higher</li><li>arm-linux-uclibceabihf 4.8.x or higher</li></ul></li><li>MIPS: mips-linux-uclibceabihf 4.7.x or higher.</li></ul> | - |
  | HarmonyOS | ARM: armv7a-harmony-eabi. | - |
  | LiteOS | ARM: arm-liteos-eabi, LiteOS 2.0 or higher. | - |

For a full list of downloadable SDK packages by architecture, C library, and float ABI, see [Resources](/en/realtime-media/iot/reference/resources).
