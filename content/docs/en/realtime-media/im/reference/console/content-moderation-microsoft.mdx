Delivering a safe and appropriate chat environment to your users is essential. Chat gives you multiple options to moderate chat content and handle inappropriate user behavior.

The following message management tools are available:

- Message reporting.
- Message moderation, including text and image moderation, keyword lists, and domain filtering. Message moderation can apply globally, to selected chat groups and chat rooms, or to target user groups.

## Prerequisites

- You have created a valid [Agora developer account](/en/introduction/account#sign-up-for-an-agora-account).
- Moderation is not enabled by default. To use this feature, subscribe to the **Pro** or **Enterprise** [pricing plan](/en/realtime-media/im/reference/pricing-plan-details) and enable it in [Agora Console](https://console.agora.io).

  :::info
  Add-on fees are incurred if you use this feature. See [Pricing](/en/realtime-media/im/reference/pricing#optional-add-on-fee) for details.
  :::

## Enable the moderation feature

To enable moderation features:

1. In [Agora Console](https://console.agora.io/), select your project from the **Project** list at the top of the page.

1. In the sidebar, click **RTC Services**, then click **Open Chat Console** on the **Chat** card.

1. In the Chat Console sidebar, click **Features Overview**.

1. Under **Moderation**, turn on the features that you need. Features that show **Upgrade Your Plan** aren't available on your current plan.

   ![Moderation features in Features Overview](/temp/chat-console/chat-moderation-features.png)

:::info
After enabling the moderation feature, see [Message moderation mechanism](/en/realtime-media/im/build/moderate-and-manage-client-behavior/moderation-mechanism) to understand how message moderation works and how to configure your moderation strategy.
:::

## Message management

The following table summarizes the message management tools provided by Chat:

| Function | Description |
| :------- | :---------- |
| Message reporting | The reporting API allows end users to report objectionable messages directly from their apps. Moderators can view the reports in Agora Console and handle the messages and message senders. |
| Text and image moderation | Uses a third-party moderation provider to automatically moderate text and image messages and block questionable content. |
| Keyword lists | Detect and filter messages that contain keywords in the allow and block lists that you configure. |
| Domain filter | Detects and filters domains contained in messages according to the rules that you set. |

### Implement the reporting feature

The Chat SDK provides a message reporting API, which allows end users to report objectionable messages directly from their apps. After the Chat server receives a report, it stores the report and displays it in Agora Console. Moderators can view the reports in Agora Console and handle the messages and message senders according to their content policy.

After a user reports a message from the app, moderators can review and handle the report in Agora Console. In the Chat Console sidebar, click **Message Report**.

On the **Message Report** page, moderators can filter reports by time period, conversation type, or handling method, and search for a report by user ID, group ID, or chat room ID. Chat supports two handling methods for reports: recalling the message or asking the sender to handle the message.

### Text and image moderation

#### Introduction

Powered by [Microsoft Azure AI Content Safety](https://learn.microsoft.com/en-us/azure/ai-services/content-safety/overview), Chat text and image moderation scans messages for harmful text and image content, such as hate, sexual, violent, or self-harm content, and marks the content for moderation. When a message violates a moderation rule, Chat handles the message as specified in the rule. Test your rules to check whether they meet your requirements.

You can also impose a penalty on users who reach the violation limit within a time period. The moderation penalties include the following:

- Penalties at the app level or in one-to-one chat:
  - **Block**: The user is forced offline immediately and can't log in to Chat until unblocked. For example, if a user sends inappropriate content 5 times within 1 minute, the user is blocked. A blocked user shows **Blocked** in the **Block Status** column on the **User Management** page. To unblock the user, use the **User Management** page or call the [RESTful API](/en/api-reference/api-ref/im/user-system-registration#unbanning-a-user).
  - **Force Offline**: The user is forced offline and needs to log in again to use Chat.
  - **Delete**: The user is deleted. If the user is the owner of a chat group or chat room, the group or room is also deleted.

- Penalties for users in chat groups and chat rooms:
  - **Add to block list**: The user is added to the block list of the group or chat room and can no longer view or receive its messages.
  - **Kick out**: The user is removed from the group or chat room. A user removed from a group is also removed from the message threads that the user joined in the group.
  - **Mute**: The user can't send messages in the group or chat room. A user muted in a group also can't send messages in the message threads that the user joined in the group.

#### Create a moderation rule

To create a text or image moderation rule:

1. In the Chat Console sidebar, click **Text Rule** or **Image Rule**, then click **Create**.

1. Configure the following fields, then click **Save**.

   ![Create a text moderation rule](/temp/chat-console/chat-text-rule.png)

   | Field | Description |
   | :---- | :---------- |
   | **Name** | The rule name. |
   | **Conversation Type** | The moderation scope: **Single Chat**, **Group Chat**, or **Chat Room**. A rule for a specific chat group or chat room overrides the global rules for chat groups and chat rooms. |
   | **Enable** | Whether the rule is on. |
   | **When moderation result is "Rejected"** | The action on a message that violates the rule, such as **Pass** to send the message or **Reject** to block it. Test a rule with **Pass** before you set it to block online messages. |
   | **When moderation service call failed** | The action on a message when the moderation call fails, for example, when the moderation service doesn't return a result within 200 milliseconds: **Pass** or **Reject**. |
   | **Alert end users when they send inappropriate messages** | Whether the app indicates blocked messages. When Chat blocks a message, the SDK returns error `508`, `MESSAGE_EXTERNAL_LOGIC_BLOCKED`. If you choose to alert end users, a red exclamation mark appears next to the blocked message. |
   | **Provider** and **Text model** | The moderation provider, and whether the rule uses keyword lists only or also an AI model. |
   | **User Management** | The penalty for users who reach the violation limit within a time period. |

To change or remove a rule, click **Edit** or **Delete** next to the rule on the **Text Rule** or **Image Rule** page.

#### Apply a rule to target user groups

To apply moderation rules to specific users, group the users with labels:

1. In the Chat Console sidebar, click **Target User Groups**, then click **Create**.

1. Enter a **Tag Name** and click **Save**. Then add users to the label.

1. On the **Text Rule** or **Image Rule** page, click **Target User Group** next to a rule and select the label.

You can create up to 10 labels. Each label can contain up to 1,000 users, and each user can belong to only one label.

#### Test a moderation rule

To test a text or image moderation rule:

1. In the Chat Console sidebar, click **Text Rule Test** or **Image Rule Test**.

1. Select an enabled **Rule**, enter the **Content** to moderate, then click **Run test**. The page shows the moderation result, including the message handling, risk type, and any error description.

### Keyword lists

Keyword lists detect messages that contain keywords in allow lists and block lists that you configure. You can create up to 20 lists, with up to 100,000 keywords across all lists. Changes to keywords take effect after 1 minute.

To create a keyword list:

1. In the Chat Console sidebar, click **Text Word Config**, then click **Create Allow/Block List**.

1. Configure the following fields, then click **Save**.

   ![Create a keyword list](/temp/chat-console/chat-keyword-list.png)

   | Field | Description |
   | :---- | :---------- |
   | **List Name** | The list name, up to 32 characters. |
   | **Moderation Result** | The moderation result for messages that match a keyword in the list. |
   | **Applicable Scope** | The conversations that the list applies to. |
   | **Matching Method** | How Chat matches keywords. For example, with **Inclusive**, a message matches when it contains the keyword: for the keyword "add you", "Can I add you on Facebook" matches, while "Do you mind if I add your Facebook" doesn't. |
   | **Keyword** | Up to 200 keywords, one per line. To add more keywords, open the list after you create it. |

Projects that used the earlier word list can still manage it on the **Word List (Legacy)** page.

### Domain filter

The domain filter detects and filters domains contained in messages according to the rules that you set.

To create a domain filtering rule:

1. In the Chat Console sidebar, click **Domain Filter**, then click **Create**.

1. Configure the following fields, then click **Save**.

   | Field | Description |
   | :---- | :---------- |
   | Rule name | The rule name. |
   | Conversation type | The moderation scope: one-to-one chat, chat groups, or chat rooms. A rule for a specific chat group or chat room overrides the global rules for chat groups and chat rooms. |
   | Enable | Whether the rule is on. |
   | Message handling | Blocks messages that contain the domain, only allows messages that contain the domain, replaces the domain in the message with \*\*\*, or takes no action. |
   | Domain name | The domains in the rule. |
   | User management | The penalty for users who reach the violation limit within a time period: blocking the user, forcing the user offline, or deleting the user. |

To change or remove a rule, edit or delete it on the **Domain Filter** page.

### Check the moderation history

To check moderation records, in the Chat Console sidebar, click **Text History**, **Image History**, **Filter History** for the domain filter, or **List History (Legacy)** for the legacy word list. You can filter records by target type, result, risk, provider, and time period, and search by sender or recipient.

## User management

You can impose a penalty on users for repeated violations. The penalties can apply to the whole app, or only to a specific chat group or chat room. The following table lists the user moderation options that Chat supports:

| Scope | Action | Description |
| :---- | :----- | :---------- |
| Global | Block a user | A blocked user immediately goes offline and can't log in again until unblocked. |
| Global | Force a user offline | The user needs to log in again to use Chat. |
| Global | Delete a user | If the deleted user owns a chat group or chat room, the group or room is also deleted. |
| Chat group | Mute a member | A muted member can't send messages in the group until unmuted. |
| Chat group | Mute all members | Members of a muted group can't send messages until the mute is lifted. |
| Chat group | Manage the block list | Users on the group block list are removed from the group immediately and can't join it again. |
| Chat group | Remove a member | The removed user no longer receives the group's messages until rejoining the group. |
| Chat room | Mute a member | A muted member can't send messages in the chat room until unmuted. |
| Chat room | Mute all members | Members of a muted chat room can't send messages until the mute is lifted. |
| Chat room | Manage the block list | Users on the chat room block list are removed from the room immediately and can't join it again. |
| Chat room | Remove a member | The removed user no longer receives the chat room's messages until rejoining the room. |

### Take global actions on users

To block, force offline, or delete a user:

1. In the Chat Console sidebar, click **User Management**.

1. Search for the user ID. Next to the user, click **More**, then click **Block User**, **Force Offline**, or **Delete User**.

### Take actions on chat group members

To remove a member from a group or add a user to the group block list:

1. In the Chat Console sidebar, click **Group Management**.

1. Search for the group ID. Next to the group, click **More** and select the action.

### Take actions on chat room members

To remove a member from a chat room or add a user to the chat room block list:

1. In the Chat Console sidebar, click **Chatroom Management**.

1. Search for the chat room ID. Next to the chat room, click **More** and select the action.
