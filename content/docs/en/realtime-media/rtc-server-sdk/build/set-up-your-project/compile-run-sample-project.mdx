Agora provides a runnable sample project with the Server Gateway SDK. This page shows you how to run the sample project to send and receive media streams.

## Get the sample project

Download the latest SDK package for your CPU architecture, x86-64 or arm64 (aarch64), from [Downloads](/en/api-reference/sdks?product=server-gateway&platform=linux-cpp), and decompress the file. If you need the SDK for another architecture, [submit a ticket](https://agora-ticket.agora.io/) to technical support.

## Compile the sample project

To compile the sample project, take the following steps:

1. In the decompressed package, go to the sample project folder for your CPU architecture:

    ```bash tab="x86-64"
    cd Agora_Native_SDK_for_Linux_SERVER/rtc/example
    ```

    ```bash tab="arm64"
    cd Agora_Native_SDK_for_Linux_SERVER/example
    ```

1. Run the following commands to build the project and prepare the test data:

    ```bash
    # Build the sample project
    ./build.sh
    # Sync the video and audio data that the project needs
    cd out
    ../sync-data.sh
    # Add the SDK libraries to LD_LIBRARY_PATH
    export LD_LIBRARY_PATH=../../sdk:$LD_LIBRARY_PATH
    ```

## Send media streams from the server

This section shows you how to send media streams from the server with the `sample_send_h264_pcm` project.

### Run the sample

To send H.264 video and PCM audio, run the `sample_send_h264_pcm` project:

```bash
./sample_send_h264_pcm --token YOUR_RTC_TOKEN --channelId demo_channel --videoFile test_data/send_video.h264 --audioFile test_data/send_audio_16k_1ch.pcm
```

Replace `YOUR_RTC_TOKEN` with your temporary token and `demo_channel` with your channel name.

:::info
Use the same channel name that you used to generate the temporary token.
:::

### Use the Web demo to receive streams from the server

To simulate a client that receives the streams in a browser, take the following steps:

1. On a computer or mobile device, open the [Agora Web demo](https://webdemo-global.agora.io/example/quickStart/videoAndVoiceCalling/index.html) and fill in the following fields:

    - **APP ID**: Your App ID. Use the same App ID as the server.
    - **Channel Name**: The channel name that the server uses.
    - **Token**: A valid temporary token.

1. Click **Join** to receive media streams from the server.

    ![Agora Web demo receiving media streams](https://web-cdn.agora.io/docs-files/1650527522676)

This page shows you how to build and run a basic app that uses the Server Gateway SDK to connect to a channel.

To build and run the app, take the following steps:

1. [Create a Maven project](../../quickstart.mdx#create-a-maven-project) and [integrate the SDK](../../quickstart.mdx#integrate-the-sdk).

1. Go to `my-app/src` and remove the `test` folder:

    ```bash
    rm -r test
    ```

1. Open `my-app/src/main/java/com/mycompany/app/App.java` and add the following code. Replace `Your Token` with a valid temporary token and `Your App ID` with your App ID.

    ```java
    import io.agora.rtc.SDK;
    import io.agora.rtc.AgoraRtcConn;
    import io.agora.rtc.AgoraService;
    import io.agora.rtc.AgoraServiceConfig;
    import io.agora.rtc.DefaultRtcConnObserver;
    import io.agora.rtc.RtcConnInfo;

    public class App {
        public static class ConnObserver extends DefaultRtcConnObserver {
            @Override
            public void onConnected(AgoraRtcConn conn, RtcConnInfo rtcConnInfo, int reason) {
                System.out.println("join success");
            }
        }

        public static void main(String[] args) throws Exception {
            String token = "Your Token";
            SDK.load(); // Load the JNI library
            AgoraService service = new AgoraService();
            AgoraServiceConfig config = new AgoraServiceConfig();
            config.setEnableAudioProcessor(0);
            config.setEnableAudioDevice(0);
            config.setEnableVideo(0);
            config.setContext(0);
            config.setAppId("Your App ID");
            service.initialize(config);

            AgoraRtcConn conn = service.agoraRtcConnCreate(null);

            conn.registerObserver(new ConnObserver());

            conn.connect(token, "test_channel", "1");

            Thread.sleep(2000);
            conn.disconnect();
            conn.destroy();
            service.destroy();
        }
    }
    ```

    :::info
    The channel name must match the one you used to generate the temporary token. The code connects to `test_channel`. If you generated the token for a different channel, replace `test_channel` with that channel name.
    :::

1. In `my-app`, create a `lib` folder. Download the `linux-sdk` JAR file from Maven Central and extract it to the `lib` folder:

    ```bash
    mkdir lib
    cd lib
    wget https://repo1.maven.org/maven2/io/agora/rtc/linux-sdk/4.0.1/linux-sdk-4.0.1.jar
    jar xvf linux-sdk-4.0.1.jar
    ```

    :::info
    The version number in the URL and the file name is the SDK version. Replace it with the version that you integrate. For the latest version, see the [release notes](../../reference/release-notes.mdx).
    :::

1. In `my-app`, add the `lib/native/linux/x86_64` folder to `LD_LIBRARY_PATH`:

    ```bash
    export LD_LIBRARY_PATH=lib/native/linux/x86_64/:$LD_LIBRARY_PATH
    ```

1. Build the project:

    ```bash
    mvn package
    ```

1. Run the app:

    ```bash
    java -cp target/agora-rtc-linux-java-1.0-SNAPSHOT.jar App
    ```

    When the app connects to the channel, the console prints the following:

    ```text
    join success
    ```

### Run the server streaming sample

To run the `example_audio_pcm_send` sample project, take the following steps:

1. To send PCM audio, run the `example_audio_pcm_send` project. Change the parameter values as needed:

    ```bash
    python agora_rtc/examples/example_audio_pcm_send.py \
    --appId=0a****************************99 \
    --channelId=test_example \
    --userId=6 \
    --audioFile=./test_data/demo.pcm \
    --sampleRate=16000 \
    --numOfChannels=1
    ```

    The parameters are as follows:

    - `appId`: The App ID of your Agora project.
    - `channelId`: The channel name.
    - `userId`: Your user ID.
    - `audioFile`: The path to the audio file. For testing, you can download Agora's [test data](https://download.agora.io/demo/test/test_data_202408221437.zip) and decompress it to the `Agora-Python-Server-SDK` folder.
    - `sampleRate`: The audio sample rate.
    - `numOfChannels`: The number of audio channels.

1. When the server connects to the channel, the terminal shows output similar to the following:

    ```text
    INFO:common.parse_args:Parsed arguments:Namespace(appId='0a****************************99', token=None, channelId='test_example', connectionNumber='1', userId='6', audioFile='./test_data/demo.pcm', lowdelay=False, videoFile=None, sampleRate=16000, numOfChannels=1, fps=None, width=None, height=None, bitrate=None, message=None, hours='0', mode=1, value=0)
    INFO:common.example_base:------channel_id: test_example, uid: 6
    INFO:common.example_base:connect_and_release: 0, auto_subscribe_audio: 0
    INFO:observer.connection_observer:on_connecting, agora_rtc_conn=<agora.rtc.rtc_connection.RTCConnection object at 0x103c173d0>, local_user_id=0, state=2, internal_uid=0 ,reason=0
    INFO:observer.connection_observer:on_connected, agora_rtc_conn=<agora.rtc.rtc_connection.RTCConnection object at 0x103c173d0>, local_user_id=3997884694, state=3, internal_uid=0 ,reason=1
    ```

1. When the server sends PCM audio, the terminal shows output similar to the following:

    ```text
    INFO:common.push_audio_pcm_file:send pcm: count,ret=1, 0, 3200, 0.1
    INFO:common.push_audio_pcm_file:send pcm: count,ret=2, 0, 3200, 0.1
    ...
    ```

To simulate a client that receives the PCM audio in a browser, use the Agora Web demo:

1. [Open the Web demo](https://webdemo-global.agora.io/index.html) and fill in the initialization settings. Use the same App ID as the server.

1. Select **Basic Voice Calling**, enter the channel name that you passed to `channelId` in **Channel**, then click **Create Client** and **Join Channel**.

1. When a user in the channel publishes a stream, the Web demo fills in that user's ID under **Step 4 Subscribe & Play**. Click **Subscribe & Play** to subscribe to the stream.

    :::warning
    Join the channel in the Web demo before you run the sample project on the server. Otherwise, the Web demo doesn't fill in the user ID under **Step 4 Subscribe & Play** and can't subscribe to the server's stream.
    :::

1. After you subscribe, you hear the audio, and the Web demo shows the user ID of the stream under **Remote Stream:**.

Agora provides a runnable [sample project](https://github.com/AgoraIO-Extensions/Agora-Golang-Server-SDK) on GitHub. This page shows you how to clone and run the project to send and receive media streams.

To run the sample project, take the following steps:

1. Clone the repository:

    ```bash
    git clone -b release/2.2.8 https://github.com/AgoraIO-Extensions/Agora-Golang-Server-SDK.git
    ```

1. Download the Agora SDK to the `agora_sdk` folder (Linux) or the `agora_sdk_mac` folder (macOS):

    ```bash
    make deps
    ```

1. Build the SDK:

    ```bash
    make build
    ```

1. Download the test data for the examples:

    ```bash
    curl -o test_data.zip https://download.agora.io/demo/test/server_sdk_test_data_202410252135.zip
    unzip test_data.zip
    ```

    You can also use your own data. If you do, update the data paths in the examples.

1. Build the basic examples:

    ```bash
    make examples
    ```

1. Run the basic example:

    ```bash
    cd ./bin
    # Get your App ID and App Certificate from Agora Console
    export AGORA_APP_ID=xxxx
    # The App Certificate is required if your project uses token authentication
    export AGORA_APP_CERTIFICATE=xxx
    # On Linux, load the Agora SDK library
    export LD_LIBRARY_PATH=../agora_sdk
    # On macOS, use the following command instead
    # export DYLD_LIBRARY_PATH=../agora_sdk_mac
    ./send_recv_pcm
    ```

Follow the instructions in the [README](https://github.com/AgoraIO-Extensions/Agora-Golang-Server-SDK/blob/main/README.md) to run the advanced examples.
