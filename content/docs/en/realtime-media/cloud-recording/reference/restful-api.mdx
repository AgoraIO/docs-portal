Agora Cloud Recording is managed from your business server through HTTPS requests to Agora's REST API.

## Base URL

```text
https://api.sd-rtn.com
```

:::warning
The Cloud Recording REST API supports HTTPS only. Do not send these requests from client-side applications.
:::

## Authentication

Every request must include Basic HTTP authentication. For details, see [Authenticate REST calls](./restful-authentication).

## Core workflow

Cloud Recording uses the following request flow:

1. Call [`acquire`](/en/api-reference/cloud-recording/restful#acquire) to get a resource ID.
1. Call [`start`](/en/api-reference/cloud-recording/restful#start) within the resource validity window to start recording.
1. Call [`query`](/en/api-reference/cloud-recording/restful#query) during the session to check status.
1. Call [`update`](/en/api-reference/cloud-recording/restful#update) or [`updateLayout`](/en/api-reference/cloud-recording/restful#updatelayout) when you need to adjust the recording.
1. Call [`stop`](/en/api-reference/cloud-recording/restful#stop) to end the session.
