## What this capability is

Fusion CDN Live Streaming integrates multiple CDN providers to improve distribution strategy and playback experience for live systems.

## Common scenarios

- multi-CDN live distribution
- playback quality optimization
- large-scale live delivery

## What to read first

If a live pipeline already exists but needs stronger playback orchestration, start from Fusion CDN instead of beginning from a basic push-only path.
