## What this capability is

On-premise Recording preserves live audio-video content for archive, replay, quality review, compliance, and post-session analysis in infrastructure you operate yourself.

## Main forms

- Self-managed recording deployment
- Internal storage and workflow control

## What the existing Shengwang docs usually contain

- landing page
- quickstart
- user guides
- recording mode guidance
- billing and limits

## What to read first

Start here if you need a self-managed recording path. Move to Cloud Recording when you want a managed service path instead.
