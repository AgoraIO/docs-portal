## v2.16.95

Released on July 28, 2025.

:::info[Note]
The wrapped Web SDK has been upgraded to v2.16.51.
:::

#### New features

**Domain preselection**

This version adds the `WhiteSDK.prepareWhiteConnectionForAppId` method to preselect an optimal access domain, which can improve the connection speed when users join a whiteboard room for the first time.

**Whiteboard window style override**

This version adds the `WhiteWindowParams.overwriteStyles` method to override whiteboard window styles using CSS, allowing for customization of UI details.

#### Fixed issues

- `drawOnlyPencil` does not work on Android 17 and above.

#### API changes

**Added**

- `WhiteSDK.prepareWhiteConnectionForAppId`
- `WhiteWindowParams.overwriteStyles`

```swift
WhiteSDK.prepareWhiteConnectionForAppId(appIdentifier)

let params = WhiteWindowParams()
params.overwriteStyles = [
  "backgroundColor": "#f7f8fa",
]
```

## Understand the tech

This page tracks iOS release notes for the Whiteboard SDK.

## Reference

:::info[Note]
To ensure a consistent user experience across different platforms while enabling native access on each platform, the Whiteboard SDK for iOS is implemented by creating a wrapper for the Whiteboard SDK for Web, rather than being a completely native SDK. Therefore, each iOS SDK version by default includes the updates of the Web SDK version that it is built upon. The corresponding Web SDK version is provided in each iOS release note, so that you can refer to the relevant Web SDK release note for updates.
:::

## v2.16.112

Released on July 28, 2025.

#### New features

**High-performance whiteboard drawing tools**

This release introduces the `appliance-plugin` that provides a set of high-performance whiteboard drawing tools. To use it, install `@netless/appliance-plugin` and enable it with the `WhiteSdkConfiguration.enableAppliancePlugin` configuration option.

Once the plugin is enabled, you can:

- Use the `LASER_PENCIL` tool.
- Use `WhiteMemberState.strokeOpacity` to control stroke opacity.
- Use `WhiteMemberState.fillOpacity` to control fill opacity.
- Use `WhiteMemberState.fillColor` to set fill color.

**PPT rendering error handling**

This version adds the `SlideListener.onSlideError` method for listening to PPT rendering errors. If an error occurs, you can call `WhiteSdk.recoverSlide` to recover rendering.

**Auto focus behavior**

This release adds the `WhiteSdkConfiguration.useWebKeyboardInjection` property, which controls whether WKWebView is allowed to automatically gain input focus.

#### API changes

**Added**

- `WhiteSdkConfiguration.enableAppliancePlugin`
- `WhiteSdkConfiguration.useWebKeyboardInjection`
- `WhiteMemberState.strokeOpacity`
- `WhiteMemberState.fillOpacity`
- `WhiteMemberState.fillColor`
- `SlideListener.onSlideError`
- `WhiteSdk.recoverSlide`

```swift
let config = WhiteSdkConfiguration(
  app: appIdentifier,
  enableAppliancePlugin: true,
  useWebKeyboardInjection: false
)
```

## Understand the tech

This page tracks Web release notes for the Whiteboard SDK.

## Reference

## v2.16.53

Released on May 10, 2025.

#### Improvements

- For security and compliance, the `regions` parameter used when joining a whiteboard room now distinguishes between domestic and international data centers.
- To prevent memory overflows caused by image uploads in formats such as `base64`, the `src` path for inserted images must now be a URL that starts with `http` or `https`.

## v2.16.112

Released on July 28, 2025.

#### New features

**High-performance whiteboard drawing tools**

This release introduces the `appliance-plugin` that provides a set of high-performance whiteboard drawing tools. To use it, install `@netless/appliance-plugin` and enable it with the `WhiteWebSdkConfiguration.enableAppliancePlugin` configuration option.

**PPT rendering error handling**

This version adds slide rendering error callbacks and recovery support for dynamic document rendering.

**Main-view tooling updates**

This release improves whiteboard tool interactions in multi-window and presentation scenarios.

#### API changes

**Added**

- `WhiteWebSdkConfiguration.enableAppliancePlugin`
- Slide rendering error callbacks
- Recovery support for failed slide rendering

```ts
import { WhiteWebSdk } from 'white-web-sdk';

const sdk = new WhiteWebSdk({
  appIdentifier,
  useMobXState: true,
  enableAppliancePlugin: true,
});
```

## v2.16.51

Released on July 28, 2025.

#### New features

**Alternative API domains**

| Domain | Covered region |
| --- | --- |
| `api.whiteboard.sd-rtn.com` | CN, India, Singapore |
| `api.baiban.shengwang.cn` | CN |
| `api.whiteboard.rtelink.com` | US, EU |
| `api.netless.link` | CN, India, Singapore |
| `api.whiteboard.agora.io` | US, EU |

#### Improvements

- Added `onConnection` to indicate that WebSocket is connected and the room snapshot is loading.
- Added the `timeout` parameter to `screenshotToCanvasAsync`.
- Added `commandWheelToZoom` in `ConstructRoomParams` for macOS zoom interaction.

#### Fixed issues

- Fixed the console error `AkkoSocket can't emit when phase is connecting` when WebSocket connection setup takes longer than 2 seconds.

#### API changes

**Added**

- `onConnection`
- The `timeout` parameter in `screenshotToCanvasAsync`
- The `commandWheelToZoom` parameter in `ConstructRoomParams`

```ts
room.callbacks.onConnection = () => {
  console.log('WebSocket connected, room snapshot is loading.');
};

await room.screenshotToCanvasAsync(context, scenePath, width, height, 5000);

const room = await sdk.joinRoom({
  uuid,
  roomToken,
  commandWheelToZoom: true,
});
```
