## Understand the tech

The Fastboard SDK is the latest generation of the Whiteboard SDK launched by Agora to help developers quickly build whiteboard applications. It simplifies the APIs of the Whiteboard SDK and implements the core functionality with a default user interface (UI). In addition, the Fastboard SDK integrates [window-manager](https://github.com/netless-io/window-manager) and extensions from [netless-app](https://github.com/netless-io/netless-app) to allow developers to easily extend the functionality of their whiteboard applications.

## Reference

## v1.7.2

Released on July 28, 2025.

#### New features

**Register third-party window apps**

This version adds the [`registerApp`](../../../reference/uikit-sdk/web/index.mdx#registerapp) method to the `FastRoom` class, allowing you to register third-party window apps in the whiteboard room.

**Set stroke thickness range**

This version introduces the [`setStrokeRange`](../../../reference/uikit-sdk/web/index.mdx#setstrokerange) method in the `FastUiSettings` class.

#### Bug fixes

- The [`setToolboxEdgeMargin`](../../../reference/uikit-sdk/web/index.mdx#settoolboxedgemargin) method did not work when Toolbox Gravity was not specified.
- UI updates did not take effect on the first call of [`setResource`](../../../reference/uikit-sdk/web/index.mdx#setresource).
- The brush color was not in the custom color list when first entering the room after setting it with [`setToolsColors`](../../../reference/uikit-sdk/web/index.mdx#settoolscolors).

#### API changes

- Added `registerApp`
- Added `FastRegisterAppParams`
- Added `setStrokeRange`

## Reference

## v1.4.2

Released on July 28, 2025.

#### Issues fixed

- Setting `drawOnlyApplePencil` does not take effect on some high-version iOS devices.
- The `warning: duplicate UUIDs` error occurs when installing the SDK using Cocoapods.

#### Improvements

Since this version, there is no distinction between YYModel and YYKit when integrating the SDK. Users who previously integrated the SDK using `pod 'Fastboard/core-YYKit'` can switch to `pod 'Fastboard'`.

Released on April 29, 2022.

#### Compatibility changes

This release replaces the framework used to build the whiteboard UI. As of this release, you do not need to add `react` and `react-dom` dependencies when integrating the SDK. For detailed SDK integration steps, see [Fastboard quickstart](../../../build/get-started-uikit/).
