**Supported platforms:** Android, iOS, macOS, Windows, Electron, React Native, and Unity.

3D Spatial Audio brings the real-world sound experience to the virtual world, providing an immersive audio experience for users. Agora's spatial audio technology enables you to simulate the propagation characteristics of sound in a physical environment within a virtual interactive scene.

![Spatial audio comparison](/images/video-sdk/spatial-audio-comparison.png)
 
- Ultra-realistic space shaping effect

  Utilize technologies such as range audio, sound blur, and air attenuation simulation to perfectly simulate the real auditory experience.

  - Set the spatial positions of users in real time to give a sense of change in the distance, direction, and orientation of other users.
  - Update the spatial position of the media player, to add a sense of space to background sounds, accompaniments, and other media resources.
  - Add 3D Spatial Audio effects such as sound blurring and air attenuation by adjusting audio settings to perfectly simulate the real audio experience.

- 3D High Fidelity

  - Sound effects are processed and rendered based on the facial orientation, sound source orientation, and relative position of the sound source in 3D space.
  - Supports 48 kHz full-band sampling and 3D high-fidelity audio processing and rendering.

- Multi-platform support

  Supports iOS, Android, macOS, Windows, Web, Unity, Flutter, React Native, Electron, Unreal and other platforms.

- Ultra-low latency, low power consumption, and low cost

  The spatial audio algorithm adopts an advanced front-end processing mode and synchronizes spatial coordinates through cloud services. The end-cloud collaborative processing mode effectively reduces overall latency and power consumption.

Compared to traditional stereo, which relies on left and right channels, spatial audio technology greatly enhances the depth and realism of sound. The following table highlights these enhancements:

| Feature  | Traditional Stereo | Agora Spatial Audio  |
|:-----------|:------------------|:-----------------------|
| Dimensionality | Left and right dimensions   | Represents sound in a full 3D space using the x, y, and z axes of the world coordinate system, corresponding to right, top, and front dimensions  |
| Spatial Perception   | Adjust the volume of the left and right channels to create a spatial sound| Utilizes advanced spatial audio algorithms to create a realistic soundscape by manipulating parameters like distance, direction, and orientation |
| User Experience  | Flat   | Immersive, three-dimensional, and natural, delivering a realistic auditory experience   |

This page shows you how to implement 3D Spatial Audio in your app.

## Understand the tech

Agora provides a local Cartesian coordinate system calculation scheme for setting up 3D Spatial Audio positions for users and the media player.

#### 3D Spatial Audio for users

Use an instance of `ILocalSpatialAudioEngine` to implement 3D Spatial Audio. Call `updateSelfPosition` and `updateRemotePosition` to specify the spatial coordinates of local and remote users in the channel. Video SDK calculates the relative positions of local and remote users. This enables local users to experience the 3D Spatial Audio of remote users.

![SpatialAudio](/images/video-sdk/spatial-audio-effect-user.svg)

#### 3D Spatial Audio for media player

Call `updateSelfPosition` and `updatePlayerPositionInfo` methods of the `ILocalSpatialAudioEngine` class to update the spatial coordinates of local users and the media player. The SDK calculates the relative positions of local users and the media player. This enables local users to experience the 3D Spatial Audio effect of the media player.

![SpatialAudio](/images/video-sdk/spatial-audio-effect-player.svg)

### Update spatial position
In the user space audio scenario, call the `updateSelfPosition` and `updateRemotePosition` methods to update the positions of the local user and remote users respectively.

In the media player spatial audio scenario, call the `updateSelfPosition` and `updatePlayerPositionInfo` methods to update the position of the local user and the media player, respectively.

Typically, you call these methods when:

- A new user joins the channel.
- The relative positions of the local user, a remote user, or the media player changes.
- There are other changes in your specific scenario.

 <CodeBlockTabsTrigger value="java">Java</CodeBlockTabsTrigger>

float[] forward = new float[]{1.0F, 0.0F, 0.0F};
float[] right = new float[]{0.0F, 1.0F, 0.0F};
float[] up = new float[]{0.0F, 0.0F, 1.0F};

  remoteRightTv.setText(uid + "");

### Set up sound isolation (optional)

To define a sound isolation zone and set a sound attenuation coefficient call `setZones`. This feature simulates the real-world effect of sound attenuation when the sound source is inside a sound isolation zone while the receiver is outside or vice versa. It mimics how sound behaves when encountering obstacles like building partitions.

Optionally, call `setRemoteAudioAttenuation` or `setPlayerAttenuation` to set the sound attenuation properties for the user and media player, respectively, and specify whether to use this setting to forcefully override the sound attenuation factor in `setZones`.

### Pause or turn off spatial audio

During a session, pause or turn off spatial audio as follows.

#### Pause spatial audio for a remote user
To disable a remote user's spatial audio, or to remove a remote user who has exited the channel, call `removeRemotePosition` to delete the user's spatial position information and save computing resources.
:::warning

When a remote user leaves the channel, call `removeRemotePosition` to delete the user's spatial position information. Otherwise, the local user may not be able to hear the spatial audio from other remote users.
:::
To restore the user's spatial audio, call `updateRemotePosition` to reset the remote user's position information.

#### Pause spatial audio for all remote users

If you do not want to continue to experience local spatial audio, call `clearRemotePositions` to delete the spatial position information of all remote users.
:::warning

Calling this method prevents the local user from hearing the audio of all remote users. Agora recommends using this method with caution.
:::
To resume hearing the remote user's audio later, call `muteAllRemoteAudioStreams(false)` to subscribe to the remote audio streams again.

#### Turn off spatial audio

To turn off spatial audio, call the `enableSpatialAudio` method of the `RtcEngine` instance and set the parameter to `false`. This resets all settings related to spatial audio.

To enable spatial audio again, call this method again and set the parameter to `true`, and then call the relevant APIs again to set the spatial audio effect.

Call the `destroy` method of the `ILocalSpatialAudioEngine` class to free up resources.

In the Voice Chat Room app, user avatars are arranged in a grid, each assigned specific coordinates and a direction. As you drag your avatar across the screen, the volume of another user decreases as you move away and disappears when you exceed a certain distance, simulating real-world sound propagation.

This page shows you how to implement 3D Spatial Audio in your app.

## Understand the tech

Agora provides a local Cartesian coordinate system calculation scheme for setting up 3D Spatial Audio positions for users and the media player.

#### 3D Spatial Audio for users

Use an instance of `AgoraLocalSpatialAudioKit` to implement 3D Spatial Audio. Call `updateSelfPosition` and `updateRemotePosition` to specify the spatial coordinates of local and remote users in the channel. Video SDK calculates the relative positions of local and remote users. This enables local users to experience the 3D Spatial Audio of remote users.
 
![SpatialAudio](/images/video-sdk/spatial-audio-effect-user.svg)

#### 3D Spatial Audio for media player

Call `updateSelfPosition` and `updatePlayerPositionInfo` methods of the `AgoraLocalSpatialAudioKit` class to update the spatial coordinates of local users and the media player. The SDK calculates the relative positions of local users and the media player. This enables local users to experience the 3D Spatial Audio effect of the media player.

![SpatialAudio](/images/video-sdk/spatial-audio-effect-player.svg)

## Implement 3D Spatial Audio
The following figure shows the workflow you implement to provide 3D Spatial Audio for users and the media player:

**Spatial audio steps**

![Spatial audio steps](/images/video-sdk/spatial-audio-steps.svg)

### Initialize the spatial audio engine

Call the `sharedLocalSpatialAudioWithConfig` method of the `AgoraLocalSpatialAudioKit` class to initialize spatial audio.

```swift
agoraKit = AgoraRtcEngineKit.sharedEngine(withAppId: KeyCenter.AppId, delegate: self)
let localSpatialConfig = AgoraLocalSpatialAudioConfig()
localSpatialConfig.rtcEngine = agoraKit
localSpatial = AgoraLocalSpatialAudioKit.sharedLocalSpatialAudio(with: localSpatialConfig)
```

### Set the audio profile and scenario

To set the desired audio encoding properties, call `setAudioProfile`.

Call `setAudioScenario` to set the scenario to `AgoraAudioScenario.gameStreaming` for the best sound quality effect.

```swift
agoraKit.setAudioProfile(.musicStandard)
agoraKit.setAudioScenario(.gameStreaming)
```

### Set the audio reception range

To set the maximum number of audio streams that can be received within the audio receiving range, call `setMaxAudioRecvCount`. The recommended `maxCount` value is ≤ 16.

To set the maximum range of receivable audio, in meters, call `setAudioRecvRange`. The recommended value range is ＞ 0.

```swift
localSpatial.setMaxAudioRecvCount(2)
localSpatial.setAudioRecvRange(Float(SCREENSIZE.height))
```

### Update spatial position
In the user space audio scenario, call the `updateSelfPosition` and `updateRemotePosition` methods to update the positions of the local user and remote users respectively.

In the media player spatial audio scenario, call the `updateSelfPosition` and `updatePlayerPositionInfo` methods to update the position of the local user and the media player, respectively.

Typically, you call these methods when:

- A new user joins the channel.
- The relative positions of the local user, a remote user, or the media player changes.
- There are other changes in your specific scenario.

```swift
// Update the local user's position
let pos = getViewCenterPostion(view: selfPostionView)
localSpatial.updateSelfPosition(pos, axisForward: forward, axisRight: right, axisUp: up)

// Update the remote user's position
if remoteUserButton1.tag <= 0 {
  remoteUserButton1.setTitle("\(uid)", for: .normal)
  remoteUserButton1.tag = Int(uid)
  remoteUserButton1.isHidden = false
  localSpatial.updateRemotePosition(uid, positionInfo: getPlayerPostion(view: remoteUserButton1))
} else if remoteUserButton2.tag <= 0 {
  remoteUserButton2.setTitle("\(uid)", for: .normal)
  remoteUserButton2.tag = Int(uid)
  remoteUserButton2.isHidden = false
  localSpatial.updateRemotePosition(uid, positionInfo: getPlayerPostion(view: remoteUserButton2))
}
```

### Set spatial audio parameters

To set spatial audio parameters for the remote user or media player, call `setRemoteUserSpatialAudioParams` or `setSpatialAudioParams`. To implement specific sound effects, refer to the following parameter settings:

- Air attenuation effect

 Set `enable_air_absorb` to `true` and set `speaker_attenuation` to the desired sound attenuation coefficient.

- Sound blur effect

 Set `enable_blur` to `true`

```swift
// Enable air absorption effect
let params = AgoraSpatialAudioParams()
params.enable_air_absorb = true

// Enable sound blur effect
params.enable_blur = true

// Set spatial audio parameters for the media player as an example
mediaPlayer.setSpatialAudioParams(params)
```

### Set up sound isolation (optional)

To define a sound isolation zone and set a sound attenuation coefficient call `setZones`. This feature simulates the real-world effect of sound attenuation when the sound source is inside a sound isolation zone while the receiver is outside or vice versa. It mimics how sound behaves when encountering obstacles like building partitions.

Optionally, call `setRemoteAudioAttenuation` or `setPlayerAttenuation` to set the sound attenuation properties for the user and media player, respectively, and specify whether to use this setting to forcefully override the sound attenuation factor in `setZones`.

```swift
let audioZone = AgoraSpatialAudioZone()
// ID of the soundproof zone
audioZone.zoneSetId = 1
// Sound attenuation coefficient when the soundproof zone interacts with the external environment
audioZone.audioAttenuation = 1
// Forward unit vector from the position
audioZone.forward = forward
// Right unit vector from the position
audioZone.right = right
// Upward unit vector from the position
audioZone.up = up
// Spatial center point of the soundproof zone
audioZone.position = getViewCenterPosition(view: voiceContainerView1)
// Forward length of the soundproof zone
audioZone.forwardLength = Float(voiceContainerView1.frame.width)
// Rightward length of the soundproof zone
audioZone.rightLength = Float(voiceContainerView1.frame.height)
// Upward length of the soundproof zone
audioZone.upLength = Float(maxDistance)
localSpatial.setZones([audioZone])

// Set sound attenuation for a remote user
localSpatial.setRemoteAudioAttenuation(uid, attenuation: 0.5, forceSet: false)
// Set sound attenuation for the media player
localSpatial.setPlayerAttenuation(0.5, playerId: UInt(mediaPlayer.getMediaPlayerId()), forceSet: false)
```

### Set headphone equalization (optional)

To optimize the audio experience, call `setHeadphoneEQPreset` to choose a preset headphone equalizer.

If the preset values do not provide the desired effect, call `setHeadphoneEQParameters` to self-adjust headphone equalization. After you execute this method, the preset values set by `setHeadphoneEQPreset` are overwritten.

```swift
agoraKit.setHeadphoneEQPreset(.overEar)
agoraKit.setHeadphoneEQParameters(10, gain: 10)
```

### Pause or turn off spatial audio

During a session, pause or turn off spatial audio as follows.

#### Pause spatial audio for a remote user
To disable a remote user's spatial audio, or to remove a remote user who has exited the channel, call `removeRemotePosition` to delete the user's spatial position information amd save computing resources.
:::warning

When a remote user leaves the channel, call `removeRemotePosition` to delete the user's spatial position information. Otherwise, the local user may not be able to hear the spatial audio from other remote users.
:::
To restore the user's spatial audio, call `updateRemotePosition` to reset the remote user's position information.

```swift
// Pause spatial audio for the specified remote user locally
localSpatial.removeRemotePosition(uid)

// Resume spatial audio for the specified remote user locally
localSpatial.updateRemotePosition(uid, positionInfo: getPlayerPostion(view: remoteLeftTv))

```

#### Pause spatial audio for all remote users

If you do not want to continue to experience local spatial audio, call `clearRemotePositionsEx` to delete the spatial position information of all remote users.
:::warning

Calling this method prevents the local user from hearing the audio of all remote users. Agora recommends using this method with caution.
:::
To resume hearing the remote user's audio later, call `muteAllRemoteAudioStreams(false)` to subscribe to the remote audio streams again.

```swift
// Remove spatial position information for all remote users
localSpatial.clearRemotePositions()

// Resume subscribing to remote users' audio streams
localSpatial.muteAllRemoteAudioStreams(false)
```

#### Pause the local user's spatial audio

To unpublish the local audio stream, call `muteLocalAudioStream(true)`.

To enable spatial audio again, call the same method with the parameter set to `false`.

```swift
// Mute the local audio stream
localSpatial.muteLocalAudioStream(true)

// Unmute the local audio stream
localSpatial.muteLocalAudioStream(false)
```

#### Turn off spatial audio

To turn off spatial audio, call the `enableSpatialAudio` method of the `AgoraRtcEngineKit` instance and set the parameter to `false`. This resets all settings related to spatial audio.

To enable spatial audio again, call this method again and set the parameter to `true`, and then call the relevant APIs again to set the spatial audio effect.

Call the `destroy` method of the `AgoraLocalSpatialAudioKit` class to free up resources.

```swift
// Disable spatial audio
agoraKit.enableSpatialAudio(false)

// Destroy the ILocalSpatialAudioEngine object
AgoraLocalSpatialAudioKit.destroy()
```

## Understand the tech

Agora provides a local Cartesian coordinate system calculation scheme for setting up 3D Spatial Audio positions for users and the media player.

#### 3D Spatial Audio for users

Use an instance of `ILocalSpatialAudioEngine` to implement 3D Spatial Audio. Call `updateSelfPosition` and `updateRemotePosition` to specify the spatial coordinates of local and remote users in the channel. Video SDK calculates the relative positions of local and remote users. This enables local users to experience the 3D Spatial Audio of remote users.

![SpatialAudio](/images/video-sdk/spatial-audio-effect-user.svg)

#### 3D Spatial Audio for media player

Call `updateSelfPosition` and `updatePlayerPositionInfo` methods of the `ILocalSpatialAudioEngine` class to update the spatial coordinates of local users and the media player. The SDK calculates the relative positions of local users and the media player. This enables local users to experience the 3D Spatial Audio effect of the media player.

![SpatialAudio](/images/video-sdk/spatial-audio-effect-player.svg)

## Prerequisites

Ensure that you have implemented the [SDK quickstart](../../index) in your project. 

To maintain 3D Spatial Audio during broadcasts with Bluetooth headphones, best practice is to adhere to the following structured guidelines:

1. Use the A2DP (Advanced Audio Distribution Profile) transmission protocol for audio playback.
1. Employ Bluetooth headphones exclusively for audio playback purposes.
1. Use alternate devices for audio capture tasks.

Not adhering to these guidelines might result in difficulty experiencing 3D Spatial Audio.

## Implement 3D Spatial Audio
The following figure shows the workflow you implement to provide 3D Spatial Audio for users and the media player:

**Spatial audio steps**

![Spatial audio steps](/images/video-sdk/spatial-audio-steps.svg)

### Initialize the spatial audio engine

Call the `initialize` method of the `ILocalSpatialAudioEngine` class to initialize spatial audio.

```cpp
m_localSpatial = nullptr;

m_rtcEngine->queryInterface(AGORA_IID_LOCAL_SPATIAL_AUDIO, (void**)&m_localSpatial);
LocalSpatialAudioConfig config;
config.rtcEngine = m_rtcEngine;
m_localSpatial->initialize(config);
```

### Set the audio profile and scenario

To set the desired audio encoding properties, call `setAudioProfile`.

Call `setAudioScenario` to set the scenario to `AUDIO_SCENARIO_GAME_STREAMING` for the best sound quality effect.

```cpp
m_rtcEngine->setAudioProfile(AUDIO_PROFILE_MUSIC_STANDARD);
m_rtcEngine->setAudioScenario(AUDIO_SCENARIO_GAME_STREAMING);
```

### Set the audio reception range

To set the maximum number of audio streams that can be received within the audio receiving range, call `setMaxAudioRecvCount`. The recommended `maxCount` value is ≤ 16.

To set the maximum range of receivable audio, in meters, call `setAudioRecvRange`. The recommended value range is ＞ 0.

```cpp
m_localSpatial->setMaxAudioRecvCount(2);
m_localSpatial->setAudioRecvRange(AXIS_MAX_DISTANCE);
```

### Update spatial position
In the user space audio scenario, call the `updateSelfPosition` and `updateRemotePosition` methods to update the positions of the local user and remote users respectively.

In the media player spatial audio scenario, call the `updateSelfPosition` and `updatePlayerPositionInfo` methods to update the position of the local user and the media player, respectively.

Typically, you call these methods when:

- A new user joins the channel.
- The relative positions of the local user, a remote user, or the media player changes.
- There are other changes in your specific scenario.

```cpp
// Update local user position
float pos[3] = { 0 };
CaculateObjectPosition(m_staLocalMove, pos);
float forward[3] = { 1.0f, 0, 0 };
float right[3] = { 0, 1.0f, 0 };
float up[3] = { 0, 0, 1.0f };
m_localSpatial->updateSelfPosition(pos, forward, right, up);

// Update the remote user's position
if (remoteLeftUid == 0) {
  remoteLeftUid = wParam;
  m_staRemoteLeft.ShowWindow(TRUE);
  RemoteVoicePositionInfo posInfo;
  memset(&posInfo, 0, sizeof(RemoteVoicePositionInfo));
  CaculateObjectPosition(m_staRemoteLeft, posInfo.position);
  m_localSpatial->updateRemotePosition(remoteLeftUid, posInfo);
} else if (remoteRightUid == 0) {
  remoteRightUid = wParam;
  m_staRemoteRight.ShowWindow(TRUE);
  RemoteVoicePositionInfo posInfo;
  memset(&posInfo, 0, sizeof(RemoteVoicePositionInfo));
  CaculateObjectPosition(m_staRemoteRight, posInfo.position);
  m_localSpatial->updateRemotePosition(remoteRightUid, posInfo);
}
```

### Set spatial audio parameters

To set spatial audio parameters for the remote user or media player, call `setRemoteUserSpatialAudioParams` or `setSpatialAudioParams`. If you want to achieve specific sound effects, refer to the following parameter settings:

- Air attenuation effect

 Set `enable_air_absorb` to `true` and set `speaker_attenuation` to the desired sound attenuation coefficient.

- Sound blur effect

 Set `enable_blur` to `true`

```cpp
// Enable air absorption effect
spatialAudioParams.enable_air_absorb = true;

// Enable sound blur effect
spatialAudioParams.enable_blur = true;

// Set spatial audio parameters for the media player
m_mediaPlayerLeft->setSpatialAudioParams(spatialAudioParams);
```

### Set up sound isolation (optional)

To define a sound isolation zone and set a sound attenuation coefficient call `setZones`. This feature simulates the real-world effect of sound attenuation when the sound source is inside a sound isolation zone while the receiver is outside or vice versa. It mimics how sound behaves when encountering obstacles like building partitions.

Optionally, call `setRemoteAudioAttenuation` or `setPlayerAttenuation` to set the sound attenuation properties for the user and media player, respectively, and specify whether to use this setting to forcefully override the sound attenuation factor in `setZones`.

```cpp
SpatialAudioZone mediaPlayerLeftZone;
memset(&mediaPlayerLeftZone, 0, sizeof(SpatialAudioZone));
// Sound attenuation coefficient when the soundproof zone interacts with the external environment
mediaPlayerLeftZone.audioAttenuation = 1.0f;

// Spatial center point of the soundproof zone
CaculateObjectPosition(m_staZone, mediaPlayerLeftZone.position);

// Forward unit vector from the position
mediaPlayerLeftZone.forward[0] = 1.0f;
// Right unit vector from the position
mediaPlayerLeftZone.right[1] = 1.0f;
// Upward unit vector from the position
mediaPlayerLeftZone.up[2] = 1.0f;

RECT zoneSize;
CaculateZoneRect(m_staZone, &zoneSize);
// Forward length of the soundproof zone
mediaPlayerLeftZone.forwardLength = zoneSize.bottom - zoneSize.top * 1.0f;
// Rightward length of the soundproof zone
mediaPlayerLeftZone.rightLength = zoneSize.right - zoneSize.left * 1.0f;
// Upward length of the soundproof zone
mediaPlayerLeftZone.upLength = AXIS_MAX_DISTANCE;

m_localSpatial->setZones(&mediaPlayerLeftZone, 1);

// Set sound attenuation for a remote user
m_localSpatial->setRemoteAudioAttenuation(uid, 0.5f, false);
// Set sound attenuation for the media player
m_localSpatial->setPlayerAttenuation(mediaPlayer.getMediaPlayerId(), 0.5f, false);
```

### Set headphone equalization (optional)

To optimize the audio experience, call `setHeadphoneEQPreset` to choose a preset headphone equalizer.

If the preset values do not provide the desired effect, call `setHeadphoneEQParameters` to self-adjust headphone equalization. After you execute this method, the preset values set by `setHeadphoneEQPreset` are overwritten.

```java
m_rtcEngine->setHeadphoneEQPreset(HEADPHONE_EQUALIZER_OVEREAR);
m_rtcEngine->setHeadphoneEQParameters(10, 10);
```

### Pause or turn off spatial audio

During a session, pause or turn off spatial audio as follows.

#### Pause spatial audio for a remote user
To disable a remote user's spatial audio, or to remove a remote user who has exited the channel, call `removeRemotePosition` to delete the user's spatial position information amd save computing resources.
:::warning

When a remote user leaves the channel, call `removeRemotePosition` to delete the user's spatial position information. Otherwise, the local user may not be able to hear the spatial audio from other remote users.
:::
To restore the user's spatial audio, call `updateRemotePosition` to reset the remote user's position information.

```cpp
// Pause spatial audio for a specific remote user locally
m_localSpatial->removeRemotePosition(uid)

// Resume spatial audio for a specific remote user locally
m_localSpatial->updateRemotePosition(uid, getVoicePositionInfo(remoteLeftTv));
```

#### Pause spatial audio for all remote users

If you do not want to continue to experience local spatial audio, call `clearRemotePositions` to delete the spatial position information of all remote users.
:::warning

Calling this method prevents the local user from hearing the audio of all remote users. Agora recommends using this method with caution.
:::
To resume hearing the remote user's audio later, call `muteAllRemoteAudioStreams(false)` to subscribe to the remote audio streams again.

```cpp
// Remove all remote users' spatial positions
m_localSpatial->clearRemotePositions();

// Resume subscribing to remote users' audio streams
m_localSpatial->muteAllRemoteAudioStreams(false);
```

#### Pause the local user's spatial audio

To unpublish the local audio stream, call `muteLocalAudioStream(true)`.

To enable spatial audio again, call the same method with the parameter set to `false`.

```cpp
// Mute the local audio stream
m_localSpatial->muteLocalAudioStream(true);

// Unmute the local audio stream
m_localSpatial->muteLocalAudioStream(false);
```

#### Turn off spatial audio

To turn off spatial audio, call the `enableSpatialAudio` method of the `IRtcEngine` instance and set the parameter to `false`. This resets all settings related to spatial audio.

To enable spatial audio again, call this method again and set the parameter to `true`, and then call the relevant APIs again to set the spatial audio effect.

Call the `release` method of the `IBaseSpatialAudioEngine` class to free up resources.

```cpp
// Disable spatial audio
m_rtcEngine->enableSpatialAudio(false);

// Destroy the ILocalSpatialAudioEngine object
m_localSpatial->release(true);
```

To set spatial audio parameters for the remote user or media player, call `setRemoteUserSpatialAudioParams` or `setSpatialAudioParams`. To implement specific sound effects, refer to the following parameter settings:

- Air attenuation effect

  Set `enable_air_absorb` to `true` and set `speaker_attenuation` to the desired sound attenuation coefficient.

- Sound blur effect

  Set `enable_blur` to `true`

```typescript
rtcEngine.setRemoteUserSpatialAudioParams(
  uid, 
  {
    enable_air_absorb: true,
    speaker_attenuation: 0.5,
    enable_blur: true,
  }
);
```

### Set up sound isolation (optional)

To define a sound isolation zone and set a sound attenuation coefficient call `setZones`. This feature simulates the real-world effect of sound attenuation when the sound source is inside a sound isolation zone while the receiver is outside or vice versa. It mimics how sound behaves when encountering obstacles like building partitions.

Optionally, call `setRemoteAudioAttenuation` or `setPlayerAttenuation` to set the sound attenuation properties for the user and media player, respectively, and specify whether to use this setting to forcefully override the sound attenuation factor in `setZones`.

```typescript
localSpatial.setZones(
  [
    {
      zoneSetId: 1, // ID of the sound isolation zone
      position: [0, 0, 0], // Spatial center of the sound isolation zone
      forward: [1, 0, 0], // Unit vector pointing forward from the position  
      right: [0, 1, 0], // Unit vector pointing right from the position
      up: [0, 0, 1], // Unit vector pointing upward from the position
      forwardLength: 10, // Forward length of the sound isolation zone
      rightLength: 10, // Rightward length of the sound isolation zone
      upLength: 10, // Upward length of the sound isolation zone
      audioAttenuation: 0.5, // Audio attenuation factor when sound passes between the zone and the outside
    }
  ],
  1
);

localSpatial.setRemoteAudioAttenuation(
  mediaPlayer.getMediaPlayerId(), // Media player ID
  0.5, 
  false
);

localSpatial.setPlayerAttenuation(
  mediaPlayer.getMediaPlayerId(), // Media player ID
  0.5, 
  false
);
```

### Set headphone equalization (optional)

To optimize the audio experience, call `setHeadphoneEQPreset` to choose a preset headphone equalizer.

If the preset values do not provide the desired effect, call `setHeadphoneEQParameters` to self-adjust headphone equalization. After you execute this method, the preset values set by `setHeadphoneEQPreset` are overwritten.

```typescript
rtcEngine.setHeadphoneEQPreset(HeadphoneEqualizerPreset.HeadphoneEqualizerOverear);
rtcEngine.setHeadphoneEQParameters(10, 10);
```

### Pause or turn off spatial audio

During a session, pause or turn off spatial audio as follows.

#### Pause spatial audio for a remote user
To disable a remote user's spatial audio, or to remove a remote user who has exited the channel, call `removeRemotePosition` to delete the user's spatial position information and save computing resources.
:::warning

When a remote user leaves the channel, call `removeRemotePosition` to delete the user's spatial position information. Otherwise, the local user may not be able to hear the spatial audio from other remote users.
:::
To restore the user's spatial audio, call `updateRemotePosition` to reset the remote user's position information.

```typescript
// Pause spatial audio for the specified remote user locally
localSpatial.removeRemotePosition(uid);

// Resume spatial audio for the specified remote user locally
localSpatial.updateRemotePosition(
  uid, // Remote user ID
  {
    position: [0, 0, 0], 
    axisForward: [1, 0, 0], 
  }
);
```

#### Pause spatial audio for all remote users

If you do not want to continue to experience local spatial audio, call `clearRemotePositions` to delete the spatial position information of all remote users.
:::warning

Calling this method prevents the local user from hearing the audio of all remote users. Agora recommends using this method with caution.
:::
To resume hearing the remote user's audio later, call `muteAllRemoteAudioStreams(false)` to subscribe to the remote audio streams again.

```typescript
// Remove spatial position information for all remote users
localSpatial.clearRemotePositions();

// Resume subscribing to remote users' audio streams
localSpatial.muteAllRemoteAudioStreams(false);
```

#### Pause the local user's spatial audio

To unpublish the local audio stream, call `muteLocalAudioStream(true)`.

To enable spatial audio again, call the same method with the parameter set to `false`.

```typescript
// Stop publishing the local audio stream
localSpatial.muteLocalAudioStream(true);

// Resume publishing the local audio stream
localSpatial.muteLocalAudioStream(false);
```

#### Turn off spatial audio

To turn off spatial audio, call the `enableSpatialAudio` method of the `IRtcEngine` instance and set the parameter to `false`. This resets all settings related to spatial audio.

To enable spatial audio again, call this method again and set the parameter to `true`, and then call the relevant APIs again to set the spatial audio effect.

Call the `release` method to free up resources.

```typescript
// Disable spatial audio
rtcEngine.enableSpatialAudio(false);

// Release resources
localSpatial.release();
```

## Understand the tech

Agora provides a local Cartesian coordinate system calculation scheme for setting up 3D Spatial Audio positions for users and the media player.

#### 3D Spatial Audio for users

Use an instance of `ILocalSpatialAudioEngine` to implement 3D Spatial Audio. Call `updateSelfPosition` and `updateRemotePosition` to specify the spatial coordinates of local and remote users in the channel. Video SDK calculates the relative positions of local and remote users. This enables local users to experience the 3D Spatial Audio of remote users.

![SpatialAudio](/images/video-sdk/spatial-audio-effect-user.svg)

#### 3D Spatial Audio for media player

Call `updateSelfPosition` and `updatePlayerPositionInfo` methods of the `ILocalSpatialAudioEngine` class to update the spatial coordinates of local users and the media player. The SDK calculates the relative positions of local users and the media player. This enables local users to experience the 3D Spatial Audio effect of the media player.

### Initialize the spatial audio engine

Call the `getLocalSpatialAudioEngine` method of the `ILocalSpatialAudioEngine` class to create an instance of the spatial audio engine. Then, call `initialize` to enable spatial audio.

```typescript
rtcEngine = createAgoraRtcEngine();
localSpatial = rtcEngine.getLocalSpatialAudioEngine()
localSpatial.initialize();
```

### Set the audio profile and scenario

To set the desired audio encoding properties, call `setAudioProfile`.

Call `setAudioScenario` to set the scenario to `AudioScenarioGameStreaming` for the best sound quality effect.

```typescript
rtcEngine.setAudioProfile(AudioProfileType.AudioProfileSpeechStandard);
rtcEngine.setAudioScenario(AudioScenarioType.AudioScenarioGameStreaming);
```

### Set the audio reception range

To set the maximum number of audio streams that can be received within the audio receiving range, call `setMaxAudioRecvCount`. The recommended `maxCount` value is ≤ 16.

To set the maximum range of receivable audio, in meters, call `setAudioRecvRange`. The recommended value range is ＞ 0.

```typescript
localSpatial.setMaxAudioRecvCount(2);
localSpatial.setAudioRecvRange(50);
```

### Update spatial position

In the user space audio scenario, call the `updateSelfPosition` and `updateRemotePosition` methods to update the positions of the local user and remote users respectively.

In the media player spatial audio scenario, call the `updateSelfPosition` and `updatePlayerPositionInfo` methods to update the position of the local user and the media player, respectively.

Typically, you call these methods when:

- A new user joins the channel.
- The relative positions of the local user, a remote user, or the media player changes.
- There are other changes in your specific scenario.

```typescript
// Update the local user's position
localSpatial.updateSelfPosition(
  [0, 0, 0], // position
  [1, 0, 0], // forward axis
  [0, 1, 0], // right axis
  [0, 0, 1]  // upward axis
);

// Update the remote user's position
localSpatial.updateRemotePosition(
  uid, // remote user ID
  {
    position: [0, 0, 0], 
    axisForward: [1, 0, 0], 
  }
);

// Update the media player's position
localSpatial.updatePlayerPositionInfo(
  mediaPlayer.getMediaPlayerId(), // media player ID
  {
    position: [0, 0, 0], 
    axisForward: [1, 0, 0], 
  }
);
```

- Air attenuation effect

rtcEngine.setRemoteUserSpatialAudioParams(

rtcEngine.enableSpatialAudio(false);

This page shows you how to implement 3D Spatial Audio in your game.

## Understand the tech

Agora provides a local Cartesian coordinate system calculation scheme for setting up 3D Spatial Audio positions for users and the media player.

#### 3D Spatial Audio for users

Use an instance of `ILocalSpatialAudioEngine` to implement 3D Spatial Audio. Call `updateSelfPosition` and `updateRemotePosition` to specify the spatial coordinates of local and remote users in the channel. Video SDK calculates the relative positions of local and remote users. This enables local users to experience the 3D Spatial Audio of remote users.

![SpatialAudio](/images/video-sdk/spatial-audio-effect-user.svg)

#### 3D Spatial Audio for media player

Call `updateSelfPosition` and `updatePlayerPositionInfo` methods of the `ILocalSpatialAudioEngine` class to update the spatial coordinates of local users and the media player. The SDK calculates the relative positions of local users and the media player. This enables local users to experience the 3D Spatial Audio effect of the media player.

![SpatialAudio](/images/video-sdk/spatial-audio-effect-player.svg)

## Prerequisites

Ensure that you have implemented the [SDK quickstart](../../index) in your project. 

## Implement 3D Spatial Audio
The following figure shows the workflow you implement to provide 3D Spatial Audio for users and the media player:

**Spatial audio steps**

![Spatial audio steps](/images/video-sdk/spatial-audio-steps.svg)

### Initialize the spatial audio engine

Call the `GetLocalSpatialAudioEngine` method of the `RtcEngine` class to create an instance of the spatial audio engine. Then, call `Initialize` to enable spatial audio.

```csharp
SpatialAudioEngine = RtcEngine.GetLocalSpatialAudioEngine();
var ret = SpatialAudioEngine.Initialize();
```

### Set the audio profile and scenario

To set the desired audio encoding properties, call `SetAudioProfile`.

Call `SetAudioScenario` to set the scenario to `AUDIO_SCENARIO_GAME_STREAMING` for the best sound quality effect.

```csharp      
RtcEngine.SetAudioProfile(AUDIO_PROFILE_TYPE.AUDIO_PROFILE_MUSIC_STANDARD);
RtcEngine.SetAudioScenario(AUDIO_SCENARIO_TYPE.AUDIO_SCENARIO_GAME_STREAMING);
```

### Set the audio reception range

To set the maximum number of audio streams that can be received within the audio receiving range, call `SetMaxAudioRecvCount`. The recommended `maxCount` value is ≤ 16.

To set the maximum range of receivable audio, in meters, call `SetAudioRecvRange`. The recommended value range is ＞ 0.

```csharp
SpatialAudioEngine.SetMaxAudioRecvCount(10);
SpatialAudioEngine.SetAudioRecvRange(30);
```

### Update spatial position
In the user space audio scenario, call the `UpdateSelfPositionEx` and `UpdateRemotePositionEx` methods to update the positions of the local user and remote users respectively.

In the media player spatial audio scenario, call the `UpdateSelfPositionEx` and `UpdatePlayerPositionInfo` methods to update the position of the local user and the media player, respectively.

Typically, you call these methods when:

- A new user joins the channel.
- The relative positions of the local user, a remote user, or the media player changes.
- There are other changes in your specific scenario.

```csharp
// Update the local user's position
// This represents the spatial center of the soundproof area
float[] localUserPosition = new float[] { 0.0f, 0.0f, 0.0f };
// The unit vector pointing forward from the position, corresponding to the z-axis in Unity's Vector3
float[] forward = new float[] { 1.0f, 0.0f, 0.0f };
// The unit vector pointing right from the position, corresponding to the x-axis in Unity's Vector3
float[] right = new float[] { 0.0f, 1.0f, 0.0f };
// The unit vector pointing upward from the position, corresponding to the y-axis in Unity's Vector3
float[] up = new float[] { 0.0f, 0.0f, 1.0f };

var ret = SpatialAudioEngine.UpdateSelfPosition(localUserPosition, forward, right, up);
Debug.Log("UpdateSelfPosition return: " + ret);

// Update the remote user's position
float[] positionRemote = { 0.0f, 1.0f, 0.0f };
float[] forwardRemote = { 0, 0, 0 };
RemoteVoicePositionInfo remoteVoicePositionInfo = new RemoteVoicePositionInfo(positionRemote, forwardRemote);
var ret = SpatialAudioEngine.UpdateRemotePosition(UidUseInMPK, remoteVoicePositionInfo);
Debug.Log("_spatialAudio.UpdateRemotePosition returns: " + ret);
```

### Set spatial audio parameters

To set spatial audio parameters for the remote user or media player, call `SetRemoteUserSpatialAudioParams` or `SetSpatialAudioParams`. If you want to achieve specific sound effects, refer to the following parameter settings:

- Air attenuation effect

 Set `enable_air_absorb` to `true` and set `speaker_attenuation` to the desired sound attenuation coefficient.

- Sound blur effect

 Set `enable_blur` to true

```csharp
SpatialAudioParams audioParams = new SpatialAudioParams();
// Enable air absorption effect
audioParams.enable_air_absorb.SetValue(true);
// Enable sound blur effect
audioParams.enable_blur.SetValue(true);
// Set spatial audio parameters for the media player
RtcEngine.SetRemoteUserSpatialAudioParams(uid, audioParams);
```

### Set up sound isolation (optional)

To define a sound isolation zone and set a sound attenuation coefficient call `setZones`. This feature simulates the real-world effect of sound attenuation when the sound source is inside a sound isolation zone while the receiver is outside or vice versa. It mimics how sound behaves when encountering obstacles like building partitions.

Optionally, call `SetRemoteAudioAttenuation` or `SetPlayerAttenuation` to set the sound attenuation properties for the user and media player, respectively, and specify whether to use this setting to forcefully override the sound attenuation factor in `setZones`.

```csharp
SpatialAudioZone mediaPlayerLeftZone = new SpatialAudioZone();
mediaPlayerLeftZone.zoneSetId = 1;
mediaPlayerLeftZone.audioAttenuation = 1.0f;
float[] voicePosition = { 0.0f, 0.0f, 0.0f };
float[] viewRelativeSizeInAxis = { 1.0f, 1.0f, 1.0f };
// Position in the world coordinate system
mediaPlayerLeftZone.position = new float[] { voicePosition[0], voicePosition[1], 0 };
// Forward unit vector from position, corresponding to the z-axis in Unity's Vector3
mediaPlayerLeftZone.forward = new float[] { 1.0f, 0, 0 };
// Right unit vector from position, corresponding to the x-axis in Unity's Vector3
mediaPlayerLeftZone.right = new float[] { 0, 1.0f, 0 };
// Upward unit vector from position, corresponding to the y-axis in Unity's Vector3
mediaPlayerLeftZone.up = new float[] { 0, 0, 1.0f };
// Forward length of the soundproof zone
mediaPlayerLeftZone.forwardLength = viewRelativeSizeInAxis[1];
// Rightward length of the soundproof zone
mediaPlayerLeftZone.rightLength = viewRelativeSizeInAxis[0];
// Upward length of the soundproof zone
mediaPlayerLeftZone.upLength = viewRelativeSizeInAxis[2];
// Set the spatial audio zone
SpatialAudioEngine.SetZones(new SpatialAudioZone[] { mediaPlayerLeftZone }, 1);
// Set sound attenuation for the user
SpatialAudioEngine.SetRemoteAudioAttenuation(uid, 0.5f, false);
// Set sound attenuation for the media player
SpatialAudioEngine.SetPlayerAttenuation(MediaPlayer.GetId(), 0.5f, false);
```

### Set headphone equalization (optional)

To optimize the audio experience, call `SetHeadphoneEQPreset` to choose a preset headphone equalizer.

If the preset values do not provide the desired effect,, call `SetHeadphoneEQParameters` to self-adjust headphone equalization. After you execute this method, the preset values set by `SetHeadphoneEQPreset` are overwritten.

```csharp
RtcEngine.SetHeadphoneEQPreset(HEADPHONE_EQUALIZER_PRESET.HEADPHONE_EQUALIZER_OVEREAR);
RtcEngine.SetHeadphoneEQParameters(10, 10);
```

### Pause or turn off spatial audio

During a session, pause or turn off spatial audio as follows.

#### Pause spatial audio for a remote user
To disable a remote user's spatial audio, or to remove a remote user who has exited the channel, call `RemoveRemotePosition` to delete the user's spatial position information amd save computing resources.
:::warning

When a remote user leaves the channel, call `removeRemotePosition` to delete the user's spatial position information. Otherwise, the local user may not be able to hear the spatial audio from other remote users.
:::
To restore the user's spatial audio, call `UpdateRemotePosition` to reset the remote user's position information.

```csharp
// Suspend local spatial audio for a specified remote user
SpatialAudioEngine.RemoveRemotePosition(uid);

// Restore the coordinates and orientation of the specified remote user under the local spatial audio system.
float[] position = new float[] { 1.0f, 1.0f, 1.0f };
float[] forward = new float[] { 1.0f, 1.0f, 1.0f };
RemoteVoicePositionInfo positionInfo = new RemoteVoicePositionInfo(position, forward);
SpatialAudioEngine.UpdateRemotePosition(uid, positionInfo);
```

#### Pause spatial audio for all remote users

If you do not want to continue to experience local spatial audio, call `ClearRemotePositions` to delete the spatial position information of all remote users.
:::warning

Calling this method prevents the local user from hearing the audio of all remote users. Agora recommends using this method with caution.
:::
To resume hearing the remote user's audio later, call `MuteAllRemoteAudioStreams(false)` to subscribe to the remote audio streams again.

```csharp
// Delete spatial location information for all remote users
SpatialAudioEngine.ClearRemotePositions();

// Resume subscribing to the remote user's audio stream
SpatialAudioEngine.MuteAllRemoteAudioStreams(false);
```

#### Pause the local user's spatial audio

To unpublish the local audio stream, call `MuteLocalAudioStream(true)`.

To enable spatial audio again, call the same method with the parameter set to `false`.

```csharp
// Mute the local audio stream
SpatialAudioEngine.MuteLocalAudioStream(true);

// Unmute the local audio stream
SpatialAudioEngine.MuteLocalAudioStream(false);
```

#### Turn off spatial audio

To turn off spatial audio, call the `EnableSpatialAudio` method of the `IRtcEngine` instance and set the parameter to `false`. This resets all settings related to spatial audio.

To enable spatial audio again, call this method again and set the parameter to `true`, and then call the relevant APIs again to set the spatial audio effect.

Call the `Dispose` method of the `ILocalSpatialAudioEngine` class to free up resources.

```csharp
// Disable spatial audio
RtcEngine.EnableSpatialAudio(false);

// Destroy the ILocalSpatialAudioEngine object
SpatialAudioEngine.Dispose();
```
