Call `setAINSMode` to enable AI Noise Suppression and select a noise suppression mode:

```dart
Future<void> enableNoiseSuppression() async {
  const enabled = true;
  const mode = AudioAinsMode.AINS_MODE_ULTRALOWLATENCY;

  await _engine.setAINSMode(enabled: enabled, mode: mode);
}
```
