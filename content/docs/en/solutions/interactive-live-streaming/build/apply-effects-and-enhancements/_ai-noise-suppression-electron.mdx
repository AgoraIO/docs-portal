Call `setAINSMode` to enable AI Noise Suppression and select a noise suppression mode:

```javascript
const enabled = true;
const result = rtcEngine.setAINSMode(
  enabled,
  AudioAinsMode.AinsModeUltralowlatency,
);

if (result !== 0) {
  console.error('Failed to enable AI Noise Suppression');
}
```
