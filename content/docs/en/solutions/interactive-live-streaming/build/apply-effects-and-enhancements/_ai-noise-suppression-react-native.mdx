Call `setAINSMode` to enable AI Noise Suppression and select a noise suppression mode:

```typescript
const setAINSMode = () => {
  const enabled = true;
  const mode = AgoraRtcEngine.AudioAinsMode.AINS_MODE_ULTRALOWLATENCY;

  return rtcEngine.setAINSMode(enabled, mode);
};
```
