This quickstart helps you connect Agora's realtime audio transport with OpenAI Realtime-style interaction flows so you can prototype lifelike voice conversations quickly.

## Recommended path

1. Prepare your Agora account and project.
2. Confirm the transport and credential model you want to use.
3. Set up the OpenAI-side model and audio flow.
4. Run the integration locally and validate the round-trip voice path.

## Before you begin

- Prepare an Agora project and App ID.
- Prepare the OpenAI-side credentials and model configuration.
- Confirm whether you are building a browser demo, a device-oriented flow, or a backend-mediated prototype.
