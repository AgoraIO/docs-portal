Agora skills is a set of structured reference files that gives AI coding assistants deep knowledge of the Agora platform. When you ask your assistant to build something with Agora, it can load the relevant skill files covering products, APIs, and platform-specific code examples so it can generate working code without guessing.

Agora Skills also integrates with the [Agora MCP server](mcp.md), which gives your assistant access to live Agora documentation.

## Installation

### Skills CLI (recommended)

```bash
npx skills add github:AgoraIO/skills
```

Skills activate automatically when your agent detects relevant tasks, for example, "build a voice agent", "integrate Agora RTC", or "generate a token".

### Manual installation

Clone the repository once and point your AI coding assistant to the skill files directly.

```bash
git clone https://github.com/AgoraIO/skills.git ~/agora-skills
```

Then point your AI assistant to `skills/agora/`.
