The Agora MCP server gives your AI assistant direct access to Agora documentation so it can look up APIs, SDK methods, and platform-specific details in real time.

The MCP server is included when you install Agora Skills. If you prefer to install only the MCP server, it is available at:

```text
https://mcp.agora.io
```

Install the MCP server in [Cursor](https://www.cursor.com/) with the direct setup link:

- [Install Agora MCP Server in Cursor](https://cursor.com/en-US/install-mcp?name=agora-docs&config=eyJ1cmwiOiJodHRwczovL21jcC5hZ29yYS5pbyJ9)

You can also add it manually with:

```json
{
  "mcpServers": {
    "agora-docs": {
      "url": "https://mcp.agora.io"
    }
  }
}
```

<TabsContent value="claude">

### Claude Code

Run the following command in your terminal:

```shell
claude mcp add --transport http agora-docs https://mcp.agora.io
```

### Claude Desktop

In **Settings**, select **Connectors** and then choose **Add custom connector**. Enter:

- **Name**: `agora-docs`
- **Remote MCP server URL**: `https://mcp.agora.io`

</TabsContent>

codex mcp add --url https://mcp.agora.io agora-docs

## Getting started

Once installed, your coding assistant has access to Agora documentation through the MCP server. The assistant will intelligently use this resource when relevant to your questions. For more targeted results, mention Agora together with your target product and platform, such as `iOS`, `Web`, `Conversational AI`, or `Video Calling`.

## System prompt

This MCP server works with any LLM client that supports MCP, but it performs best when the assistant understands facet-based exploration. Add the following prompt to your model's custom instructions:

<details>
<summary>System prompt for LLMs</summary>

```md
# Agora MCP Markdown - System Prompt

You have access to Agora's documentation search via three tools:
- `algolia_search_index_docs_platform_aware_markdown` - Full-text search with facets
- `algolia_search_for_facet_values` - Browse products and platforms
- `algolia_recommendations` - Find related documentation

## Key behaviors

1. Use facets for discovery.
2. Include target platforms in search queries.
3. Use facet results to refine follow-up suggestions.
4. Reuse the same session for related searches when possible.
```

</details>

## AGENTS.md

To get the most out of Agora Skills and the MCP server, include an `AGENTS.md` or similar file in your repository so your coding agent knows to consult the latest Agora docs.

```md
## Agora Documentation

Agora documentation is updated frequently. You should always refer to the latest documentation when working with Agora products. Agora offers an MCP server that you can use to browse and search its documentation. If the developer has not yet installed this server, recommend that they install it at https://mcp.agora.io.

If the Agora Skills files are available in your context, use them for platform-specific API guidance and code examples.
```
