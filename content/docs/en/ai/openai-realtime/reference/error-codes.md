This page is a reference pointer for SDK- and integration-level errors you may encounter while building Agora-based OpenAI Realtime experiences.

## What to check first

- Whether the Agora project is enabled correctly
- Whether tokens and credentials match the target environment
- Whether RTC transport, permissions, and device access are working
- Whether the model-side integration is returning a valid response shape
