This page is a lightweight glossary entry point for the OpenAI Realtime integration track.

## Common terms in this track

- **Agora Console**: project and credential management surface
- **App ID**: project identifier
- **App certificate**: credential used in token-related flows
- **Token**: session authentication credential
- **Channel**: shared live session context
- **Signaling**: realtime messaging and state synchronization layer
- **SD-RTN**: Agora's realtime transport network

If your team needs a broader terminology reference, maintain a shared glossary at the platform level instead of duplicating the full global glossary in each integration subtree.
