Voice Agent supports **human-to-agent** interaction: a person speaks with an AI agent that uses models to generate a spoken response. You define its instructions, model configuration, and access to your data or tools. Agora provides the real-time connection and the **Conversational AI Engine** that runs the conversation.

## How an app conversation works

Your **client** is the application on the user's browser or device. Your **backend** supplies credentials and starts or stops the agent. The **Conversational AI Engine** connects the agent to the conversation and uses the configured models to respond.

![An app conversation starts with the client joining RTC and requesting an agent from its backend. The backend calls the Agora Engine, which joins an agent to the channel. Audio passes through RTC; the backend stops the agent when the conversation ends.](/images/developer-journey/voice-agent-session.svg)

*This is the basic app flow. The backend controls the session; the client and agent exchange audio through RTC. Model calls, transcripts, and runtime notifications are omitted from the sequence.*

1. The client joins an RTC channel with the credentials provided by your backend.
2. Your backend uses an **Agent SDK or the REST API** to start an agent in the same channel.
3. The engine receives speech and uses your model configuration to produce a response. The agent's audio returns to the client through RTC.
4. When the user ends the conversation, your backend stops the agent and the client leaves the channel.

The Agent SDK runs in your backend and calls the Agora service. It does not replace the client's RTC SDK or host the engine on your server.

For a speech-to-text, language model, and text-to-speech configuration, the models turn speech into text, generate an answer, and turn that answer into speech. Supported realtime multimodal models provide another model path. The model guides explain the configuration for each provider.
