Use this section when you are building a voice agent for a web, mobile, desktop, or backend-assisted app and need more control than the quickstart.

## Recommended path

If you are deciding where to go next, use this order:

1. [Architecture](architecture): Understand how the backend, client, RTC, RTM, and agent session fit together.
2. [Start and stop an agent](start-stop-agent): Learn the minimum agent lifecycle and core API calls.
3. [Use presets](presets): Get a working setup without bringing your own provider credentials.
4. [Build a backend and client from scratch](build-server-client): Follow the full end-to-end tutorial if you want every implementation step.
