Managed mode lets your agent use supported ASR, LLM, and TTS models without your own provider accounts or API keys. Agora provides access to the models. You choose the vendor and model to use for ASR, LLM, and TTS, or let the Platform select them. To use your own provider accounts instead, see [Use your own provider keys (BYOK)](/en/ai/platform/build/use-your-own-keys).

## Understand the tech

An agent's `pipeline` has an `asr`, `llm`, and `tts` block. To use managed mode for a model, set the `credential` in its block to `{ "mode": "managed" }`, and choose a vendor and model from [Supported vendors and models](#supported-vendors-and-models).

You choose the credential mode for each model. For example, an agent can use managed ASR and TTS with your own LLM key. For details, see [Use your own provider keys](/en/ai/platform/build/use-your-own-keys).

If you create an agent without a `pipeline`, the Platform selects managed ASR, LLM, and TTS models. For an example, see [Create an agent](/en/ai/platform/build/start-stop-agent#create-an-agent).

## Choose managed models

To choose the managed models, send a request to [Create an agent](/en/api-reference/api-ref/conversational-ai/platform/create-agent) with a `pipeline`. This example uses Deepgram for ASR, OpenAI for the LLM, and MiniMax for TTS.

```bash
curl --request POST \
  --url <base_url>/v1/projects/<your_app_id>/agents \
  --header 'Authorization: Basic <your_base64_encoded_credentials>' \
  --header 'Content-Type: application/json' \
  --header 'Idempotency-Key: <your_unique_key>' \
  --data '
{
  "agent_name": "Support agent",
  "instructions": "You are a friendly support agent for Acme. Keep your answers short.",
  "pipeline": {
    "mode": "cascaded",
    "asr": {
      "credential": { "mode": "managed" },
      "vendor": "deepgram",
      "model": "nova-3",
      "language": "en-US"
    },
    "llm": {
      "credential": { "mode": "managed" },
      "vendor": "openai",
      "style": "openai",
      "model": "gpt-4.1-mini"
    },
    "tts": {
      "credential": { "mode": "managed" },
      "vendor": "minimax",
      "params": {
        "model": "speech-2.6-turbo",
        "voice_setting": {
          "voice_id": "English_captivating_female1",
          "speed": 1
        }
      }
    }
  }
}'
```

In this example:

- Each block sets `credential.mode` to `managed`. A managed block doesn't accept an `api_key`, and it doesn't need a provider endpoint `url`.
- The `asr` block uses Deepgram Nova 3 for US English.
- The `llm` block uses OpenAI GPT-4.1 Mini.
- The `tts` block uses MiniMax Speech 2.6 Turbo, with the voice and speaking speed in `params`.
