A webhook sends Conversational AI Platform events to your server as they happen, such as when a session starts or ends, or when a call is answered. Use webhooks to keep backend records, trigger follow-up work, and monitor your agents.

You set up webhooks for your project in Agent Studio. Agora sends each event to your receiving URL as an HTTPS `POST` request. Your server verifies the signature and returns `200`.

## Prerequisites

Before you begin, make sure that you have:

- Access to your project in [Agent Studio](/en/ai/platform/studio).
- A public HTTPS endpoint on your server that can receive `POST` requests.

## Create a webhook

To create a webhook:

1. In Agent Studio, select **Webhooks** in the navigation sidebar, then select **New Webhook**.
2. For **Product**, select **Conversational AI Platform (Preview)**.
3. Copy the **Signing secret**, and store it securely on your server. Your server uses it to verify each request. See [Verify the signature](#verify-the-signature).
4. For **Region**, select the region of your receiving server.
5. In **Receiving URL**, enter the HTTPS URL of your endpoint.
6. Under **Subscribe to events**, select the events that you want to receive. You must select at least one. See [Events](#events).
7. Select **Run health check** to confirm that your endpoint is reachable.
8. Select **Save**.

## Events

You can subscribe to the following events:

| Event | Sent when |
|---|---|
| [`1001` Session state changed](/en/ai/platform/reference/event-types#1001-session-state-changed) | The session status changes, such as when the agent joins or leaves the channel, or the session fails to start. |
| [`1002` Session transcripts](/en/ai/platform/reference/event-types#1002-session-transcripts) | Transcript processing for the session finishes or fails. |
| [`1003` Session errors](/en/ai/platform/reference/event-types#1003-session-errors) | A component of the agent reports an error. The error doesn't necessarily end the session. |
| [`1004` Turns finished](/en/ai/platform/reference/event-types#1004-turns-finished) | The session ends. The event contains the data and latency of each turn. |
| [`1101` RTC token expiring](/en/ai/platform/reference/event-types#1101-rtc-token-expiring) | The agent's RTC token is about to expire. |
| [`1201` Telephony state](/en/ai/platform/reference/event-types#1201-telephony-state) | The state of an inbound or outbound phone call changes. |

For the fields of each event, see [Notification event types](/en/ai/platform/reference/event-types).

## Handle a request

Each request contains a JSON body with the event type in `eventType`, the session ID in `sid`, and the event details in `payload`. For the request format and every event's fields, see [Notification event types](/en/ai/platform/reference/event-types#request-body).

When your server receives a request:

1. Verify the signature against the raw request body. See [Verify the signature](#verify-the-signature).
2. Return HTTP status `200` with a JSON body within 10 seconds. To stay within this limit, move slow processing to a background job.
3. Deduplicate by `noticeId`. Agora can send the same event more than once, and events can arrive out of order.

For more rules, see [Respond to notifications](/en/ai/platform/reference/event-types#respond-to-notifications).

## Verify the signature

Each request has an `Agora-Signature-V2` header: an HMAC-SHA256 signature of the raw request body, made with your signing secret. To verify it, compute the same signature and compare it with the header. Reject the request if they don't match.

Compute the signature over the raw body, before you parse it. Parsing and serializing the JSON again can change the bytes and break the match.

```python tab="Python" tabGroup="ai-sdk-language"
import hashlib
import hmac


def verify(raw_body: bytes, signature: str, secret: str) -> bool:
    expected = hmac.new(secret.encode(), raw_body, hashlib.sha256).hexdigest()
    return hmac.compare_digest(expected, signature)
```

```typescript tab="TypeScript" tabGroup="ai-sdk-language"
import { createHmac, timingSafeEqual } from 'node:crypto';

export function verify(rawBody: Buffer, signature: string, secret: string): boolean {
  const expected = createHmac('sha256', secret).update(rawBody).digest('hex');
  return (
    expected.length === signature.length &&
    timingSafeEqual(Buffer.from(expected), Buffer.from(signature))
  );
}
```

```go tab="Go" tabGroup="ai-sdk-language"
import (
	"crypto/hmac"
	"crypto/sha256"
	"encoding/hex"
)

func verify(rawBody []byte, signature, secret string) bool {
	mac := hmac.New(sha256.New, []byte(secret))
	mac.Write(rawBody)
	expected := hex.EncodeToString(mac.Sum(nil))
	return hmac.Equal([]byte(expected), []byte(signature))
}
```

Keep the signing secret on your server. Don't put it in client code.
