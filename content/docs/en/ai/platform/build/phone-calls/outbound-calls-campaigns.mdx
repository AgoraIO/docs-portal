Your agent can call people from a phone number in your project. To place a single call, start a session that dials the number. To call a list of contacts, create a campaign that dials each contact on a schedule you set.

## Understand the tech

An outbound call is a session that uses `telephony` transport instead of an RTC channel. The Platform dials the number from your phone number, and the agent talks to whoever answers. The session ends when the call ends, or when you stop it.

A campaign starts these sessions for you. You give it an agent, the number to call from, and a list of contacts. The campaign dials each contact as a separate session, within its schedule and pacing limits. It calls each contact once.

## Prerequisites

Before you begin, make sure that you have:

- An agent in your project. For details, see [Create an agent and start a session](/en/ai/platform/get-started/start-stop-agent).
- A phone number in your project. For details, see [Import phone numbers](/en/ai/platform/build/phone-calls/import-phone-numbers).

### Set call limits and behavior

In the call policy, set limits and behavior for the call. If you omit a limit, it doesn't apply.

| Field | Description |
|---|---|
| `max_ring_duration_ms` | The maximum time in milliseconds from starting the dial until the call is answered. If nobody answers in time, the dial attempt ends. |
| `max_call_duration_seconds` | The maximum length of the call in seconds, from when it's answered. The session's `lifecycle` limits can end the call earlier. |
| `max_silence_duration_ms` | Hang up when nobody on the call has spoken for this many milliseconds. In a campaign, the minimum is `30000`. |
| `voicemail` | What the agent does when it reaches voicemail: `hangup` ends the call, and `continue` keeps it going. |
| `end_call` | The conditions under which the agent can end the call itself: `on_conversation_complete`, `on_user_request`, `on_voicemail`, and `on_ai_assistant`. Each condition is off unless you set it to `true`. |
| `transfer` | Lets the agent transfer the call to a person at `phone_number`. The agent decides when to transfer based on `description`, and then leaves the call. |

### Set the schedule

In the schedule, set `mode` to one of the following:

- `immediate`: The campaign starts dialing as soon as you create it. Don't pass `start` or `end`.
- `scheduled`: The campaign dials from `start` until `end`. Pass both as local dates and times in `YYYY-MM-DDTHH:MM` format, and set `timezone` to an IANA time zone, such as `America/New_York`.

To limit dialing to certain hours, add `days`. For each weekday, pass up to 10 time ranges in 24-hour `HH:MM` format. Outside these hours, no new calls start. A day you don't list has no dialing. If you omit `days`, the campaign dials at any time between `start` and `end`.

### Set the pacing

In the pacing settings, control how fast the campaign dials. The campaign calls each contact once. Automatic retries aren't available in the Preview.

| Field | Description |
|---|---|
| `max_concurrent` | The maximum number of calls in progress at the same time, from 1 to 10,000. The default is `10`. |
| `max_calls_per_second` | The maximum number of new dials in any one-second window, up to 1,000. Omit it to dial as fast as `max_concurrent` and your project's carrier limits allow. |

A campaign has one of the following statuses:

| Status | Description |
|---|---|
| `scheduled` | The campaign is waiting for its start time. |
| `running` | The campaign is dialing, or can dial during its schedule. |
| `paused` | You paused the campaign. |
| `completed` | The campaign has finished. |
| `canceled` | You canceled the campaign. |
| `failed` | The campaign failed. The details are in `failure`. |

To control a running campaign, use one of the following operations:

- [Pause a campaign](/en/api-reference/api-ref/conversational-ai/platform/pause-campaign): Stops new calls. Calls in progress continue.
- [Resume a campaign](/en/api-reference/api-ref/conversational-ai/platform/resume-campaign): Continues dialing a paused campaign.
- [Cancel a campaign](/en/api-reference/api-ref/conversational-ai/platform/cancel-campaign): Ends the campaign permanently. Contacts that haven't been called change to `canceled`, and you can't resume the campaign.
