When someone calls one of your phone numbers, the Platform starts a session with the agent you route the number to, and the agent answers the call. You assign an agent to each number, and set limits and behavior for its calls.

## Prerequisites

Before you begin, make sure that you have:

- An agent to answer the calls. For details, see [Create an agent and start a session](/en/ai/platform/get-started/start-stop-agent).
- A phone number in your project. For details, see [Import phone numbers](/en/ai/platform/build/phone-calls/import-phone-numbers).

## Route a number to an agent

Assign the agent that answers calls to the number, and set a call policy. A call policy is required whenever you assign an agent. For its fields, see [Set limits and behavior for inbound calls](#set-limits-and-behavior-for-inbound-calls). You can set both when you [import the number](/en/ai/platform/build/phone-calls/import-phone-numbers#import-a-number), or later by updating the number.

<TabsContent value="rest-api">

In the number's `inbound` object, set `agent` to the agent ID, and set a `call_policy`. To update a number, send a request to [Update a phone number](/en/api-reference/api-ref/conversational-ai/platform/update-number), and pass its `ETag` from your last create or retrieve request in the `If-Match` header:

```bash
curl --request PATCH \
  --url https://preview.ai.agora.io/conversational-ai/v1/projects/<your_app_id>/numbers/<number_id> \
  --header 'Authorization: Basic <your_base64_encoded_credentials>' \
  --header 'Content-Type: application/json' \
  --header 'If-Match: <etag>' \
  --data '
{
  "inbound": {
    "agent": "agent_m8w4z1",
    "call_policy": {
      "max_call_duration_seconds": 1800
    }
  }
}'
```

If the number has changed since you read its `ETag`, the request fails with `412 PreconditionFailed`. Retrieve the number again, and retry with its current `ETag`.

</TabsContent>

<TabsContent value="python">

Load the agent and call `assign_number()` with the number's ID or its E.164 number. The SDK reads the number's ETag for you, and retries once if the number changed in the meantime.

```python
from agora_agent import SavedAgent

saved_agent = SavedAgent.get(client, "agent_m8w4z1")
saved_agent.assign_number("num_2v9c4q", max_call_duration_seconds=1800)
```

</TabsContent>

<TabsContent value="typescript">

Load the agent and call `assignNumber()` with the number's ID or its E.164 number. The SDK reads the number's ETag for you, and retries once if the number changed in the meantime.

```ts
import { SavedAgent } from 'agora-agents';

const savedAgent = await SavedAgent.get(client, 'agent_m8w4z1');
await savedAgent.assignNumber('num_2v9c4q', { maxCallDurationSeconds: 1800 });
```

</TabsContent>

<TabsContent value="go">

Load the agent and call `AssignNumber()` with the number's ID or its E.164 number. The SDK reads the number's ETag for you, and retries once if the number changed in the meantime.

```go
savedAgent, err := agentkit.GetSavedAgent(ctx, client, "agent_m8w4z1")
if err != nil {
	log.Fatal(err)
}
maxCallDuration := 1800
_, err = savedAgent.AssignNumber(ctx, "num_2v9c4q", agentkit.AssignNumberOptions{
	MaxCallDurationSeconds: &maxCallDuration,
})

	log.Fatal(err)
}
```

</TabsContent>
</Tabs>

To reject inbound calls to a number, remove its agent. A number without inbound routing also rejects inbound calls.

## Set limits and behavior for inbound calls

The call policy sets limits and behavior for inbound calls:

</TabsList>

<TabsContent value="rest-api">

Set `call_policy` in the number's `inbound` object:

```json
"inbound": {
  "agent": "agent_k3n9x2",
  "call_policy": {
    "max_call_duration_seconds": 1800,
    "max_silence_duration_ms": 60000,
    "end_call": {
      "on_user_request": true,
      "on_fax": true
    }
  }
}
```

</TabsContent>

<TabsContent value="python">

`assign_number()` sets only the duration limits. To set `end_call`, update the number with the low-level API, and pass its current ETag:

```python
current = client.v3.numbers.with_raw_response.get(number_id="num_2v9c4q")
client.v3.numbers.update(
    number_id="num_2v9c4q",
    if_match=current.etag,
    inbound={
        "agent": "agent_k3n9x2",
        "call_policy": {
            "max_call_duration_seconds": 1800,
            "max_silence_duration_ms": 60000,
            "end_call": {"on_user_request": True, "on_fax": True},
        },
    },
)
```

</TabsContent>

<TabsContent value="typescript">

`assignNumber()` sets only the duration limits. To set `end_call`, update the number with the low-level API, and pass its current ETag:

```ts
const { rawResponse } = await client.v3.numbers.get({ id: 'num_2v9c4q' }).withRawResponse();
await client.v3.numbers.update({
  id: 'num_2v9c4q',
  ifMatch: rawResponse.headers.get('etag') ?? '',
  inbound: {
    agent: 'agent_k3n9x2',
    call_policy: {
      max_call_duration_seconds: 1800,
      max_silence_duration_ms: 60000,
      end_call: { on_user_request: true, on_fax: true },
    },
  },
});
```

</TabsContent>

<TabsContent value="go">

`AssignNumber()` sets only the duration limits. To set `end_call`, update the number with the low-level API, and pass its current ETag: This example also imports `github.com/AgoraIO/agora-agents-go/v2/v3`.

```go
callPolicy := map[string]any{
	"max_call_duration_seconds": 1800,
	"max_silence_duration_ms":   60000,
	"end_call": map[string]any{
		"on_user_request": true,
		"on_fax":          true,
	},
}

current, err := client.V3.Numbers.Get(ctx, "num_2v9c4q")
if err != nil {
	log.Fatal(err)
}
_, err = client.V3.Numbers.Update(ctx, "num_2v9c4q", current.ETag, v3.NumberPatch{
	"inbound": map[string]any{
		"agent":       "agent_k3n9x2",
		"call_policy": callPolicy,
	},
})
if err != nil {
	log.Fatal(err)
}
```

</TabsContent>
</Tabs>

| Field | Description |
|---|---|
| `max_call_duration_seconds` | The maximum length of a call in seconds, from when it's answered. |
| `max_silence_duration_ms` | Hang up when nobody on the call has spoken for this many milliseconds. |
| `end_call` | The conditions under which the agent can end the call itself: `on_conversation_complete`, `on_user_request`, `on_fax`, and `on_ai_assistant`. Each condition is off unless you set it to `true`. |

If you omit a limit, it doesn't apply. Transferring calls to a person isn't available in the Preview.
