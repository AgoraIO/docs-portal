Protoface provides real-time AI avatars that add a talking, lip-synced face to your voice agents, enabling natural video conversations with your AI agents.

## Sample configuration

Add an `avatar` block to the `pipeline` when you create or update an agent. For a complete request, see [Create an agent and start a session](/en/ai/platform/get-started/start-stop-agent#create-an-agent). Protoface supports BYOK only. It isn't available in managed mode.

Protoface uses the `generic` avatar vendor. Store your Protoface API key in a secret set. Then set `credential.mode` to `byok` and `credential.api_key` to a reference to the key. For details, see [Use your own provider keys](/en/ai/platform/build/use-your-own-keys).

In the following example, the key is stored as `protoface` in the `support_prod` set:

```json
"avatar": {
  "enabled": true,
  "credential": {
    "mode": "byok",
    "api_key": "$secrets.support_prod.protoface"
  },
  "vendor": "generic",
  "params": {
    "api_base_url": "https://api.protoface.com/v1/agora",
    "avatar_id": "<protoface_avatar_id>",
    "agora_token": "<avatar_rtc_token>",
    "agora_uid": "<avatar_rtc_uid>"
  }
}
```

## Key parameters

<ParameterList title="avatar" required={true}>
  <Parameter name="enabled" type="boolean" required={true}>
    Set to `true` to show the avatar.
  </Parameter>
  <Parameter name="vendor" type="string" required={true}>
    Set to `generic`.
  </Parameter>
  <Parameter name="credential" type="object" required={true}>
    Set `mode` to `byok` and `api_key` to a `$secrets.<set>.<key>` reference to your Protoface API key. Get your API key from the [Protoface dashboard](https://app.protoface.com).
  </Parameter>
  <Parameter name="params" type="object" required={true}>
    <Parameter name="api_base_url" type="string" required={true}>
      The base URL of the Protoface API endpoint. Set to `https://api.protoface.com/v1/agora`.
    </Parameter>
    <Parameter name="avatar_id" type="string" required={true}>
      The ID of the Protoface avatar to use, for example, `av_stock_001`. Find a stock avatar or create your own in the [Protoface dashboard](https://app.protoface.com).
    </Parameter>
    <Parameter name="agora_token" type="string" required={false}>
      The RTC token that authorizes the avatar to join the video channel. Generate this token using your Agora project credentials.
    </Parameter>
    <Parameter name="agora_uid" type="string" required={true}>
      The unique identifier for the avatar's RTC connection. This must be different from other participants in the channel.
    </Parameter>
  </Parameter>
</ParameterList>

For more information about avatars, refer to the [Protoface avatar documentation](https://docs.protoface.com/guides/avatars). For a complete working project, see the [Protoface Agora quickstart](https://github.com/protoface-ai/protoface-quickstart-agora).

This integration is fully supported for use with the Conversational AI Platform. While it has completed functional validation, it is newer to the platform, and additional provider-specific edge cases may be identified as usage scales across a broader range of applications and workloads.
