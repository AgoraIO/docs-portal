Anam provides AI-powered avatars with real-time video rendering, enabling natural video conversations with your AI agents.

## Sample configuration

The following example shows how to configure Anam as the agent's avatar when you create or update an agent. For a complete example, see [Create an agent and start a session](/en/ai/platform/get-started/start-stop-agent#create-an-agent).

Anam supports BYOK only. It isn't available in managed mode. Store your Anam API key in a secret set, and refer to it from the agent. For details, see [Use your own provider keys](/en/ai/platform/build/use-your-own-keys).

<TabsContent value="rest-api">

Add an `avatar` block to the `pipeline`. Set `credential.mode` to `byok` and `credential.fields.api_key` to the reference. In the following example, the key is stored as `anam` in the `support_prod` set:

```json
"avatar": {
  "enabled": true,
  "credential": {
    "mode": "byok",
    "fields": {
      "api_key": "$secrets.support_prod.anam"
    }
  },
  "vendor": "anam",
  "params": {
    "avatar_id": "960f614f-ea88-47c3-9883-f02094f70874",
    "agora_uid": "<avatar_rtc_uid>",
    "agora_token": "<avatar_rtc_token>",
    "sample_rate": 24000,
    "quality": "high",
    "video_encoding": "H264"
  }
}
```

```python
from agora_agent import Agent, AnamAvatar, secret_ref

# client is your configured Agora client
agent = (
    Agent(client=client)
    .with_stt(...)  # configure your ASR vendor
    .with_llm(...)  # configure your LLM vendor
    .with_tts(...)  # configure your TTS vendor
    .with_avatar(
        AnamAvatar(
            api_key=secret_ref("support_prod", "anam"),
            avatar_id="960f614f-ea88-47c3-9883-f02094f70874",
            additional_params={
                "agora_uid": "<avatar_rtc_uid>",
                "agora_token": "<avatar_rtc_token>",
                "sample_rate": 24000,
                "quality": "high",
                "video_encoding": "H264",
            },
        )
    )
)
```

## Key parameters

The `avatar` block takes the following fields. In the SDKs, `AnamAvatar` sets them from its options, and passes any other parameters from its additional parameters option to `params`.

<ParameterList title="avatar" required={true}>
  <Parameter name="enabled" type="boolean" required={true}>
  Set to `true` to show the avatar.
  </Parameter>
  <Parameter name="vendor" type="string" required={true}>
  Set to `anam`.
  </Parameter>
  <Parameter name="credential" type="object" required={true}>
  Set `mode` to `byok` and `fields.api_key` to a `$secrets.<set>.<key>` reference to your Anam API key. Get your API key from the Anam console.
  </Parameter>
  <Parameter name="params" type="object" required={true}>
    <Parameter name="avatar_id" type="string" required={true}>
    The unique identifier for the Anam avatar you want to use.
    </Parameter>
    <Parameter name="agora_uid" type="string" required={true}>
    The unique identifier for the avatar's RTC connection. This must be different from other participants in the channel.
    </Parameter>
    <Parameter name="agora_token" type="string" required={true}>
    The RTC token that authorizes the avatar to join the video channel. Generate this token using your Agora project credentials.
    </Parameter>
    <Parameter name="sample_rate" type="number" defaultValue="24000" possibleValues="16000, 24000, 48000" required={false}>
    The audio sample rate in Hz.
    </Parameter>
    <Parameter name="quality" type="string" defaultValue="high" possibleValues="high, medium, low" required={false}>
    The video quality level.
    </Parameter>
    <Parameter name="video_encoding" type="string" defaultValue="H264" possibleValues="H264, AV1" required={false}>
    The video encoding format.
    </Parameter>
  </Parameter>
</ParameterList>

This integration is fully supported for use with the Conversational AI Platform. While it has completed functional validation, it is newer to the platform, and additional provider-specific edge cases may be identified as usage scales across a broader range of applications and workloads.
