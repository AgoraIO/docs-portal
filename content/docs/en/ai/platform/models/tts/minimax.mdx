MiniMax provides text-to-speech (TTS) with multiple voice styles and low-latency streaming output.

## Sample configuration

Add a `tts` block to the `pipeline` when you create or update an agent. For a complete request, see [Create an agent and start a session](/en/ai/platform/build/start-stop-agent#create-an-agent). MiniMax supports managed mode and BYOK.

### Managed mode

Set `credential.mode` to `managed`. Agora provides access to MiniMax, and you don't need a MiniMax account. For details, see [Use managed mode](/en/ai/platform/build/managed-mode).

```json
"tts": {
  "credential": { "mode": "managed" },
  "vendor": "minimax",
  "params": {
    "model": "speech-2.8-turbo",
    "voice_setting": {
      "voice_id": "English_captivating_female1",
      "speed": 1.0
    },
    "audio_setting": {
      "sample_rate": 44100
    }
  }
}
```

### BYOK

Store your MiniMax API key in a secret set. Then set `credential.mode` to `byok` and `credential.api_key` to a reference to the key. Your MiniMax group ID isn't secret. Pass it in `params`. For details, see [Use your own provider keys](/en/ai/platform/build/use-your-own-keys).

In the following example, the key is stored as `minimax` in the `support-prod` set:

```json
"tts": {
  "credential": {
    "mode": "byok",
    "api_key": "$secrets.support-prod.minimax"
  },
  "vendor": "minimax",
  "url": "wss://api-uw.minimax.io/ws/v1/t2a_v2",
  "params": {
    "group_id": "<your_minimax_group_id>",
    "model": "speech-2.8-turbo",
    "voice_setting": {
      "voice_id": "English_captivating_female1",
      "speed": 1.0
    },
    "audio_setting": {
      "sample_rate": 44100
    }
  }
}
```

## Key parameters

<ParameterList title="tts">
  <Parameter name="vendor" type="string" required={true}>
    Set to `minimax`.
  </Parameter>
  <Parameter name="credential" type="object" required={true}>
    How the agent authenticates with MiniMax. Set `mode` to `managed`, or to `byok` with `api_key` set to a `$secrets.<set>.<key>` reference to your MiniMax API key.
  </Parameter>
  <Parameter name="url" type="string" required={false}>
    A custom WebSocket endpoint for streaming TTS output, for example `wss://api-uw.minimax.io/ws/v1/t2a_v2`. Not needed in managed mode.
  </Parameter>
  <Parameter name="params" type="object" required={true}>
    <Parameter name="group_id" type="string" required={false}>
      The MiniMax group identifier. Required for BYOK.
    </Parameter>
    <Parameter name="model" type="string" required={true}>
      The TTS model to use, for example `speech-02-turbo`. For managed mode, use `speech-2.6-turbo` or `speech-2.8-turbo`.
    </Parameter>
    <Parameter name="voice_setting.voice_id" type="string" required={true}>
      The voice style identifier to use, for example `English_captivating_female1`.
    </Parameter>
    <Parameter name="voice_setting.speed" type="number" required={true}>
      The speaking speed, for example `1.0`.
    </Parameter>
    <Parameter name="audio_setting.sample_rate" type="number" required={true}>
      The audio sampling rate in Hz.
    </Parameter>
  </Parameter>
</ParameterList>
