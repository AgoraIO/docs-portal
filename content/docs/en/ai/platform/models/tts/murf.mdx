Murf provides enterprise-grade AI voice generation with text-to-speech (TTS) models.

## Sample configuration

Add a `tts` block to the `pipeline` when you create or update an agent. For a complete request, see [Create an agent and start a session](/en/ai/platform/get-started/start-stop-agent#create-an-agent). Murf supports BYOK only. It isn't available in managed mode.

Store your Murf API key in a secret set. Then set `credential.mode` to `byok` and `credential.api_key` to a reference to the key. For details, see [Use your own provider keys](/en/ai/platform/build/use-your-own-keys).

In the following example, the key is stored as `murf` in the `support_prod` set:

```json
"tts": {
  "credential": {
    "mode": "byok",
    "api_key": "$secrets.support_prod.murf"
  },
  "vendor": "murf",
  "url": "wss://global.api.murf.ai/v1/speech/stream-input",
  "params": {
    "voiceId": "Matthew",
    "locale": "en-US",
    "rate": 0,
    "pitch": 0,
    "model": "FALCON",
    "sample_rate": 24000
  }
}
```

## Key parameters

<ParameterList title="tts">
  <Parameter name="vendor" type="string" required={true}>
    Set to `murf`.
  </Parameter>
  <Parameter name="credential" type="object" required={true}>
    Set `mode` to `byok` and `api_key` to a `$secrets.<set>.<key>` reference to your Murf API key.
  </Parameter>
  <Parameter name="url" type="string" required={false}>
    The WebSocket endpoint for streaming TTS output, for example `wss://global.api.murf.ai/v1/speech/stream-input`.
  </Parameter>
  <Parameter name="params" type="object" required={false}>
    <Parameter name="voiceId" type="string" required={false}>
      The voice identifier to use, for example `Matthew`.
    </Parameter>
    <Parameter name="locale" type="string" required={false}>
      The locale for the selected voice, for example `en-US`.
    </Parameter>
    <Parameter name="rate" type="number" required={false}>
      The speech rate adjustment. A value of `0` applies the default rate.
    </Parameter>
    <Parameter name="pitch" type="number" required={false}>
      The pitch adjustment. A value of `0` applies the default pitch.
    </Parameter>
    <Parameter name="model" type="string" required={false}>
      The TTS model to use, for example `FALCON`.
    </Parameter>
    <Parameter name="sample_rate" type="number" required={false}>
      The audio sample rate in Hz, for example `24000`.
    </Parameter>
  </Parameter>
</ParameterList>

:::caution[Caution]
The parameters listed on this page are validated for use with the Conversational AI Platform. Required parameters must be provided as documented. Any additional parameters in `params` are passed through directly to Murf without validation. For a full list of supported options, refer to the [Murf documentation](https://murf.ai/api/docs/api-reference/text-to-speech/stream-input).
:::

This integration is fully supported for use with the Conversational AI Platform. While it has completed functional validation, it is newer to the platform, and additional provider-specific edge cases may be identified as usage scales across a broader range of applications and workloads.
