Google Gemini provides real-time streaming transcription. Use it as the ASR model in a cascading pipeline with any supported LLM and TTS vendor.

## Sample configuration

Add an `asr` block to the `pipeline` when you create or update an agent. For a complete request, see [Create an agent and start a session](/en/ai/platform/get-started/start-stop-agent#create-an-agent). Gemini supports BYOK only. It isn't available in managed mode.

Store your Gemini API key in a secret set. Then set `credential.mode` to `byok` and `credential.fields.api_key` to a reference to the key. For details, see [Use your own provider keys](/en/ai/platform/build/use-your-own-keys).

In the following example, the key is stored as `gemini` in the `support_prod` set:

```json
"asr": {
  "credential": {
    "mode": "byok",
    "fields": { "api_key": "$secrets.support_prod.gemini" }
  },
  "vendor": "gemini",
  "model": "gemini-3.5-transcribe-live",
  "language": "en-US",
  "params": {
    "sample_rate": 16000,
    "word_timestamp": true
  }
}
```

## Key parameters

<ParameterList title="asr" required={true}>
 <Parameter name="vendor" type="string" required={true}>
 Set to `gemini`.
 </Parameter>
 <Parameter name="credential" type="object" required={true}>
 How the agent authenticates with Gemini. Set `mode` to `byok` and `fields.api_key` to a `$secrets.<set>.<key>` reference to your Google Gemini API key. You can generate an API key in [Google AI Studio](https://aistudio.google.com/apikey).
 </Parameter>
 <Parameter name="model" type="string" required={true}>
 The Gemini transcription model identifier. Set to `gemini-3.5-transcribe-live` to use Gemini 3.5 Transcribe Live.
 </Parameter>
 <Parameter name="language" type="string" required={true}>
  The BCP-47 language tag identifying the primary language used for agent interaction, for example, `en-US`.
 </Parameter>
 <Parameter name="params" type="object" required={false}>
  <Parameter name="sample_rate" type="integer" required={false}>
   The audio sample rate in Hz. For example, `16000`.
  </Parameter>
  <Parameter name="word_timestamp" type="boolean" required={false}>
   Whether to include word-level timestamps in the transcription results.
  </Parameter>
 </Parameter>
</ParameterList>

:::caution[Caution]
The parameters listed on this page are validated for use with the Conversational AI Platform. Required parameters must be provided as documented. Any additional parameters in `params` are passed through directly to Gemini without validation. For a full list of supported options, refer to the [Google Gemini API documentation](https://ai.google.dev/api/live).
:::
