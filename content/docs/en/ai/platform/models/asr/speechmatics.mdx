Speechmatics provides real-time automatic speech recognition (ASR) with flexible language support and reliable performance for conversational AI applications.

## Sample configuration

The following example shows how to configure Speechmatics as the agent's ASR when you create or update an agent. For a complete example, see [Create an agent and start a session](/en/ai/platform/get-started/start-stop-agent#create-an-agent).

Speechmatics supports BYOK only. It isn't available in managed mode. Store your Speechmatics API key in a secret set, and refer to it from the agent. For details, see [Use your own provider keys](/en/ai/platform/build/use-your-own-keys).

<TabsContent value="rest-api">

Set `credential.mode` to `byok` and `credential.fields.key` to a reference to your Speechmatics API key in a secret set. In the following example, the key is stored as `speechmatics` in the `support_prod` set:

```json
"asr": {
  "credential": {
    "mode": "byok",
    "fields": {
      "key": "$secrets.support_prod.speechmatics"
    }
  },
  "vendor": "speechmatics",
  "language": "en",
  "url": "wss://eu2.rt.speechmatics.com/v2",
  "params": {
    "language": "en"
  }
}
```

from agora_agent import Agent, SpeechmaticsSTT, secret_ref

## Key parameters

The `asr` block takes the following fields. In the SDKs, `SpeechmaticsSTT` sets them from its options, and passes any other Speechmatics parameters from its additional parameters option to `params`.

<ParameterList title="asr" required={true}>
  <Parameter name="vendor" type="string" required={true}>
    Set to `speechmatics`.
  </Parameter>
  <Parameter name="credential" type="object" required={true}>
    How the agent authenticates with Speechmatics. Set `mode` to `byok` and `fields.key` to a `$secrets.<set>.<key>` reference to your Speechmatics API key.
  </Parameter>
  <Parameter name="language" type="string" required={true}>
    The language code to use for transcription. For example, use `en` for English.
  </Parameter>
  <Parameter name="url" type="string" required={false}>
    The WebSocket URL for the Speechmatics streaming API. Specify this to target a particular region, for example, `wss://eu2.rt.speechmatics.com/v2`. Omit it to use the default endpoint.
  </Parameter>
</ParameterList>

:::caution[Caution]
The parameters listed on this page are validated for use with the Conversational AI Platform. Required parameters must be provided as documented. Any additional parameters in `params` are passed through directly to Speechmatics without validation. For a full list of supported options, refer to the [Speechmatics documentation](https://docs.speechmatics.com/api-ref/realtime-transcription-websocket).
:::
