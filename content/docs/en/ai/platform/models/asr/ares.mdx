Adaptive Recognition Engine for Speech (ARES) provides built-in real-time speech-to-text, offering seamless integration with low latency and reliable performance for conversational AI applications.

## Sample configuration

The following example shows how to configure ARES as the agent's ASR when you create or update an agent. For a complete example, see [Create an agent and start a session](/en/ai/platform/get-started/start-stop-agent#create-an-agent).

ARES is available in managed mode only. Agora provides ARES, and you don't need a provider account or API key. For details, see [Use managed mode](/en/ai/platform/build/managed-mode).

<TabsContent value="rest-api">

Set `credential.mode` to `managed` in the `asr` block:

```json
"asr": {
  "credential": { "mode": "managed" },
  "vendor": "ares",
  "language": "en-US",
  "params": {
    "keywords": ["Agora", "Conversational AI", "RTC"]
  }
}
```

</TabsContent>

<TabsContent value="python">

Set the language with turn detection. The SDK can't send ARES keywords to the Platform yet. To set keywords, use the REST API.

```python
from agora_agent import Agent, AresSTT

# client is your configured Agora client
agent = (
    Agent(client=client)
    .with_stt(AresSTT())
    .with_turn_detection({"language": "en-US"})
    .with_llm(...)  # configure your LLM vendor
    .with_tts(...)  # configure your TTS vendor
)
```

</TabsContent>

<TabsContent value="typescript">

Set the language with turn detection. The SDK can't send ARES keywords to the Platform yet. To set keywords, use the REST API.

```ts
import { Agent, AresSTT } from 'agora-agents';

// client is your configured Agora client
const agent = new Agent({ client })
  .withStt(new AresSTT())
  .withTurnDetection({ language: 'en-US' })
  .withLlm(/* configure your LLM vendor */)
  .withTts(/* configure your TTS vendor */);
```

</TabsContent>

<TabsContent value="go">

Set the language with turn detection. The SDK can't send ARES keywords to the Platform yet. To set keywords, use the REST API.

This example also imports the SDK's root package as `Agora "github.com/AgoraIO/agora-agents-go/v2"`.

```go
language := Agora.AsrLanguageEnUs

// client is your configured Agora client
agent := agentkit.NewAgent(client).
	WithStt(vendors.NewAresSTT()).
	WithTurnDetection(&agentkit.TurnDetectionConfig{Language: &language}).
	WithLlm( /* configure your LLM vendor */ ).
	WithTts( /* configure your TTS vendor */ )
```

</TabsContent>

## Key parameters

The `asr` block takes the following fields. In the SDKs, `AresSTT` sets them from its options, and passes any other ARES parameters from its additional parameters option to `params`.

<ParameterList title="asr" required={true}>
 <Parameter name="vendor" type="string" required={true}>
 Set to `ares`.
 </Parameter>
 <Parameter name="credential" type="object" required={true}>
 How the agent authenticates with ARES. Set `mode` to `managed`.
 </Parameter>
 <Parameter name="language" type="string" required={true}>
  The BCP-47 language tag identifying the primary language used for agent interaction.
  See [Supported languages](/en/realtime-media/speech-to-text/reference/supported-languages#real-time-transcription) for the complete list.
 </Parameter>
 <Parameter name="params" type="object" required={false}>
  <Parameter name="keywords" type="array[string]" required={false}>
  Keywords used to improve ASR recognition accuracy for specific terms, such as brand names, product names, or industry jargon. Supports up to 128 keywords. See [Configure ASR keywords](/en/ai/platform/build/shape-the-conversation/asr-keywords) for details.
  </Parameter>
 </Parameter>
</ParameterList>
