Microsoft Azure provides enterprise-grade automatic speech recognition with support for multiple languages and robust noise handling capabilities, optimized for real-time conversational applications.

## Sample configuration

Add an `asr` block to the `pipeline` when you create or update an agent. For a complete request, see [Create an agent and start a session](/en/ai/platform/get-started/start-stop-agent#create-an-agent). Microsoft Azure supports BYOK only. It isn't available in managed mode.

Store your Azure Speech key in a secret set. Then set `credential.mode` to `byok` and `credential.api_key` to a reference to the key. Your Azure region isn't secret. Pass it in `params`. For details, see [Use your own provider keys](/en/ai/platform/build/use-your-own-keys).

In the following example, the key is stored as `microsoft` in the `support-prod` set:

```json
"asr": {
  "credential": {
    "mode": "byok",
    "api_key": "$secrets.support-prod.microsoft"
  },
  "vendor": "microsoft",
  "language": "en-US",
  "params": {
    "region": "eastus",
    "phrase_list": ["agora", "conversational", "ai", "engine"]
  }
}
```

## Key parameters

<ParameterList title="asr" required={true}>
 <Parameter name="vendor" type="string" required={true}>
 Set to `microsoft`.
 </Parameter>
 <Parameter name="credential" type="object" required={true}>
 How the agent authenticates with Microsoft Azure. Set `mode` to `byok` and `api_key` to a `$secrets.<set>.<key>` reference to your Azure Speech key. Get your key from the [Azure Portal](https://portal.azure.com/).
 </Parameter>
 <Parameter name="language" type="string" required={true}>
 The language code for speech recognition, for example, `en-US`, `es-ES`, or `fr-FR`. See [supported languages](https://learn.microsoft.com/en-us/azure/ai-services/speech-service/language-support?tabs=stt) for language codes.
 </Parameter>
 <Parameter name="params" type="object" required={true}>
  <Parameter name="region" type="string" required={true}>
  The Azure region where the speech service is hosted, for example, `eastus` or `westus2`.
  </Parameter>
  <Parameter name="phrase_list" type="array[string]" required={false}>
  A list of words or phrases provided in advance to improve recognition accuracy.
  </Parameter>
 </Parameter>
</ParameterList>

:::caution[Caution]
The parameters listed on this page are validated for use with the Conversational AI Platform. Required parameters must be provided as documented. Any additional parameters in `params` are passed through directly to Microsoft Azure without validation. For a full list of supported options, refer to the [Microsoft Azure Speech-to-Text documentation](https://learn.microsoft.com/en-us/azure/ai-services/speech-service/speech-to-text).
:::
