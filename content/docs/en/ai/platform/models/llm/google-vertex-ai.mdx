Google Vertex AI provides enterprise-grade access to Google's generative AI models with enhanced security, scaling capabilities, and integration with Google Cloud services.

## Sample configuration

The following example shows how to configure Google Vertex AI as the agent's LLM when you create or update an agent. For a complete example, see [Create an agent and start a session](/en/ai/platform/get-started/start-stop-agent#create-an-agent).

Google Vertex AI supports BYOK only. It isn't available in managed mode. Store your Google Cloud credential in a secret set, and refer to it from the agent. For details, see [Use your own provider keys](/en/ai/platform/build/use-your-own-keys).

<TabsContent value="rest-api">

Set `credential.mode` to `byok` and `credential.fields.api_key` to a reference to it. Your project ID and region aren't secret. Pass them in the `url`, replacing `your-project-id` and `us-central1`. In the following example, the credential is stored as `vertex_ai` in the `support_prod` set:

```json
"llm": {
  "credential": {
    "mode": "byok",
    "fields": {
      "api_key": "$secrets.support_prod.vertex_ai"
    }
  },
  "vendor": "vertexai",
  "style": "gemini",
  "model": "gemini-2.0-flash-001",
  "url": "https://us-central1-aiplatform.googleapis.com/v1/projects/your-project-id/locations/us-central1/publishers/google/models/gemini-2.0-flash-001:streamGenerateContent?alt=sse",
  "max_history": 32,
  "failure_message": "Hold on a second."
}
```

Set the system prompt and the greeting with the agent's `instructions` and `greeting`, not in the `llm` block.

</TabsContent>

<TabsContent value="python">

```python
from agora_agent import Agent, VertexAILLM, secret_ref

# client is your configured Agora client
agent = (
    Agent(client=client)
    .with_stt(...)  # configure your ASR vendor
    .with_llm(
        VertexAILLM(
            api_key=secret_ref("support_prod", "vertex_ai"),
            vendor="vertexai",
            project_id="<your_project_id>",
            location="us-central1",
            model="gemini-2.0-flash-001",
            max_history=32,
            failure_message="Hold on a second.",
            system_messages=[
                {"role": "system", "content": "You are a friendly support agent for Acme. Keep your answers short."}
            ],
        )
    )
    .with_tts(...)  # configure your TTS vendor
)
```

## Key parameters

The `llm` block takes the following fields. In the SDKs, the LLM class sets them from its options. Use the `VertexAILLM` class. The SDK builds the endpoint URL from the project ID, the location, and the model.

<ParameterList title="llm">
  <Parameter name="vendor" type="string" required={true}>
    Set to `vertexai`.
  </Parameter>
  <Parameter name="credential" type="object" required={true}>
    Set `mode` to `byok` and `fields.api_key` to a `$secrets.<set>.<key>` reference to your Google Cloud credential. Refer to Google Cloud [REST authentication](https://cloud.google.com/docs/authentication/rest) to get your GCP credentials.
  </Parameter>
  <Parameter name="style" type="string" required={true}>
    Set to `gemini` to use Gemini's message format.
  </Parameter>
  <Parameter name="model" type="string" required={true}>
    Refer to [Vertex AI models](https://cloud.google.com/vertex-ai/generative-ai/docs/learn/models) for available models.
  </Parameter>
  <Parameter name="url" type="string" required={true}>
    Use the Vertex AI endpoint with your Google Cloud project ID and region in the URL path. Refer to the [Google Vertex AI API documentation](https://cloud.google.com/vertex-ai/generative-ai/docs/learn/locations) for details.
  </Parameter>
</ParameterList>

For complete `llm` block options, see [Create an agent](/en/api-reference/api-ref/conversational-ai/platform/create-agent). For advanced configuration options, model capabilities, and detailed parameter descriptions, see the [Google Vertex AI API documentation](https://cloud.google.com/vertex-ai/generative-ai/docs/learn/prompts/system-instructions).
