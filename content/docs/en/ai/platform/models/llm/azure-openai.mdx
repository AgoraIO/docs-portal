Azure OpenAI service provides REST API access to OpenAI's powerful language models through Microsoft Azure's secure infrastructure.

## Sample configuration

Add an `llm` block to the `pipeline` when you create or update an agent. For a complete request, see [Create an agent and start a session](/en/ai/platform/build/start-stop-agent#create-an-agent). Azure OpenAI supports BYOK only. It isn't available in managed mode.

Store your Azure OpenAI API key in a secret set. Then set `credential.mode` to `byok` and `credential.api_key` to a reference to the key. For details, see [Use your own provider keys](/en/ai/platform/build/use-your-own-keys).

In the following example, the key is stored as `azure-openai` in the `support-prod` set:

```json
"llm": {
  "credential": {
    "mode": "byok",
    "api_key": "$secrets.support-prod.azure-openai"
  },
  "vendor": "azure",
  "style": "openai",
  "model": "gpt-4o-mini",
  "url": "https://YOUR_RESOURCE_NAME.openai.azure.com/openai/deployments/YOUR_DEPLOYMENT_NAME/chat/completions?api-version=AZURE_API_VERSION",
  "max_history": 32,
  "failure_message": "Please hold on a second."
}
```

Set the system prompt and the greeting with the agent's `instructions` and `greeting`, not in the `llm` block.

## Key parameters

<ParameterList title="llm">
  <Parameter name="vendor" type="string" required={true}>
    Set to `azure`.
  </Parameter>
  <Parameter name="credential" type="object" required={true}>
    Set `mode` to `byok` and `api_key` to a `$secrets.<set>.<key>` reference to your Azure OpenAI API key. Find your API key in the Azure portal under your OpenAI resource.
  </Parameter>
  <Parameter name="style" type="string" required={false}>
    Set to `openai`.
  </Parameter>
  <Parameter name="model" type="string" required={true}>
    Use the deployment name you created in Azure, not the base model name.
  </Parameter>
  <Parameter name="url" type="string" required={true}>
    Replace `YOUR_RESOURCE_NAME` with your Azure resource name and `YOUR_DEPLOYMENT_NAME` with your model deployment name.
  </Parameter>
</ParameterList>

For complete `llm` block options, see [Create an agent](/en/api-reference/api-ref/conversational-ai/platform/create-agent). For advanced configuration options, deployment setup, and detailed parameter descriptions, see the [Azure OpenAI API documentation](https://learn.microsoft.com/en-us/azure/ai-services/openai/reference).
