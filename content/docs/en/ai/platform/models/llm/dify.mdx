Dify is an open-source LLM application development platform that provides a unified API for multiple LLM providers with workflow orchestration and advanced features.

## Set up Dify

To integrate Dify with Agora Conversational AI, install the plugin, configure your Agora project, and create an endpoint:

1. **Install the Dify plugin**
   1. Log in to the [Dify Console](https://cloud.dify.ai).
   2. Click on **Plugins** in the top navigation bar to open the Marketplace.
   3. Search for the **Agora Conversational AI** plugin.
   4. Click **Install** to install the plugin.
   5. After installation, confirm that the plugin status is **Active** in the Installed Plugins list.

2. **Configure the Agora Console**
   1. Log in to the [Agora Console](https://console.agora.io).
   2. Create a new project or select an existing one.
   3. Enable the **Conversational AI** feature within the selected project.
   4. Record the following information for later use:
      - **App ID** (unique project identifier)
      - **Certificate** (optional, if enabled for enhanced security)
   5. Navigate to the **RESTful API** page and generate a **Customer ID** and **Customer Secret** (required for HTTP Basic Authentication).

3. **Create an Endpoint in Dify**
   1. In the Dify console's left-hand navigation panel, click on the **Agora Conversational AI** plugin you just installed.
   2. Click **Create a new API endpoint** to open the configuration page.
   3. Fill in the following details:
      - **App ID** (copied from the Agora Console)
      - **Customer ID and Customer Secret** (copied from the Agora Console)
      - **TTS** (Text-to-Speech) configuration (e.g., Azure or ElevenLabs)

4. **Save and note the endpoint details**
   1. Save the endpoint configuration. Dify generates an **Endpoint URL**.
   2. Note down this **Dify Endpoint URL** and **Dify endpoint API key** for use in the `llm` configuration.

## Sample configuration

Add an `llm` block to the `pipeline` when you create or update an agent. For a complete request, see [Create an agent and start a session](/en/ai/platform/build/start-stop-agent#create-an-agent). Dify supports BYOK only. It isn't available in managed mode.

Store your Dify endpoint API key in a secret set. Then set `credential.mode` to `byok` and `credential.api_key` to a reference to the key. For details, see [Use your own provider keys](/en/ai/platform/build/use-your-own-keys).

In the following example, the key is stored as `dify` in the `support-prod` set:

```json
"llm": {
  "credential": {
    "mode": "byok",
    "api_key": "$secrets.support-prod.dify"
  },
  "vendor": "dify",
  "style": "dify",
  "model": "default",
  "url": "https://xxxxxx.ai-plugin.io/convoai/dify-completion",
  "max_history": 32,
  "failure_message": "Hold on a moment."
}
```

Set the system prompt and the greeting with the agent's `instructions` and `greeting`, not in the `llm` block.

## Key parameters

<ParameterList title="llm">
  <Parameter name="vendor" type="string" required={true}>
    Set to `dify`.
  </Parameter>
  <Parameter name="credential" type="object" required={true}>
    Set `mode` to `byok` and `api_key` to a `$secrets.<set>.<key>` reference to the same API key configured in your Dify endpoint setup.
  </Parameter>
  <Parameter name="style" type="string" required={true}>
    Set to `dify` to use Dify's message format and workflow processing.
  </Parameter>
  <Parameter name="model" type="string" required={true}>
    Set to `default` to use the model configured in your Dify application.
  </Parameter>
  <Parameter name="url" type="string" required={true}>
    Use the custom endpoint URL from your Dify marketplace integration.
  </Parameter>
</ParameterList>

For complete `llm` block options, see [Create an agent](/en/api-reference/api-ref/conversational-ai/platform/create-agent). For advanced configuration options, workflow setup, and detailed parameter descriptions, see the [Agora Conversational AI - Dify Marketplace](https://marketplace.dify.ai/plugins/plutoless/convoai) documentation.
