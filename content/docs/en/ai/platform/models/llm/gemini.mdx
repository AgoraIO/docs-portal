Google Gemini provides advanced multimodal AI capabilities with fast performance and efficient processing for conversational AI applications.

## Sample configuration

The following example shows how to configure Google Gemini as the agent's LLM when you create or update an agent. For a complete example, see [Create an agent and start a session](/en/ai/platform/get-started/start-stop-agent#create-an-agent).

Google Gemini supports BYOK only. It isn't available in managed mode. Store your Gemini API key in a secret set, and refer to it from the agent. For details, see [Use your own provider keys](/en/ai/platform/build/use-your-own-keys).

<TabsContent value="rest-api">

Set `credential.mode` to `byok` and `credential.fields.api_key` to a reference to the key. In the following example, the key is stored as `gemini` in the `support_prod` set: Don't put the key in the `url` query string.

```json
"llm": {
  "credential": {
    "mode": "byok",
    "fields": {
      "api_key": "$secrets.support_prod.gemini"
    }
  },
  "vendor": "gemini",
  "style": "gemini",
  "model": "gemini-3.6-flash",
  "url": "https://generativelanguage.googleapis.com/v1beta/models/gemini-3.6-flash:streamGenerateContent?alt=sse",
  "max_history": 32,
  "failure_message": "Hold on a second."
}
```

Set the system prompt and the greeting with the agent's `instructions` and `greeting`, not in the `llm` block.

## Key parameters

The `llm` block takes the following fields.

<ParameterList title="llm">
  <Parameter name="vendor" type="string" required={true}>
    Set to `gemini`.
  </Parameter>
  <Parameter name="credential" type="object" required={true}>
    Set `mode` to `byok` and `fields.api_key` to a `$secrets.<set>.<key>` reference to your Gemini API key. Get your API key from [Google AI Studio](https://aistudio.google.com/app/apikey).
  </Parameter>
  <Parameter name="style" type="string" required={true}>
    Set to `gemini` to use Gemini's message format.
  </Parameter>
  <Parameter name="model" type="string" required={true}>
    Refer to [Gemini models](https://ai.google.dev/gemini-api/docs/models/gemini) for available models.
  </Parameter>
  <Parameter name="url" type="string" required={true}>
    The Gemini `streamGenerateContent` endpoint for your model.
  </Parameter>
  <Parameter name="params" type="object" required={false}>
    <Parameter name="ignore_empty" type="boolean" required={false}>
      Set to `true` to handle empty responses appropriately.
    </Parameter>
  </Parameter>
</ParameterList>

For complete `llm` block options, see [Create an agent](/en/api-reference/api-ref/conversational-ai/platform/create-agent). For advanced configuration options, model capabilities, and detailed parameter descriptions, see the [Google Gemini API documentation](https://ai.google.dev/api/generate-content#method:-models.streamgeneratecontent).
