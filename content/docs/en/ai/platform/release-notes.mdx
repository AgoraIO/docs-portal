## Conversational AI Platform (Preview)

The Conversational AI Platform is a new API for building and running voice agents in apps and over the phone, from agent configurations that you save once and reuse. For details, see the [Conversational AI Platform overview](/en/ai/platform) and the API reference for the [Python SDK](/en/api-reference/api-ref/server-sdk/platform/python), [TypeScript SDK](/en/api-reference/api-ref/server-sdk/platform/typescript), [Go SDK](/en/api-reference/api-ref/server-sdk/platform/go), and [REST API](/en/api-reference/api-ref/conversational-ai/platform).

Released on November 26, 2026.

This release adds silence hangup for inbound calls and Agent Preview, adds Agent Studio (Preview), and removes Hume AI TTS.

#### New features

Included in this release:

- **Silence hangup for inbound calls and Agent Preview**

  End a session automatically when nobody speaks for a set time, with an optional reminder before the agent hangs up. Silence hangup now works for inbound calls and Agent Preview sessions, as well as outbound campaigns. The minimum silence period is 30 seconds. See [Set limits and behavior for inbound calls](/en/ai/platform/build/phone-calls/route-inbound-calls#set-limits-and-behavior-for-inbound-calls) and the Agent Studio [Call settings](/en/ai/platform/studio/build/customize-agent#call).

#### Removal notice

:::warning[Important]
These changes may affect your existing integration. Review each change and update your integration as needed.
:::

- **Hume AI TTS is removed.** Hume AI retired its legacy TTS API on November 13, 2026. Hume AI is no longer available as a TTS provider in the Conversational AI Platform API or Agent Studio. If your agents use Hume AI TTS, switch them to another [supported TTS provider](/en/ai/platform/studio/build/supported-vendors#tts-vendors) to avoid runtime failures.

#### Known issues

- **Silence hangup without initial audio**: If the agent has no greeting and the user never speaks, the silence hangup timer doesn't start. A fix is planned for an upcoming engine release.

Released on October 30, 2026.

This release introduces a new API for building and running voice agents in apps and over the phone from shared agent configuration.

#### New features

Included in this release:

- **Reusable agents**

  Save an agent's instructions, variables, greeting, and models once, and use the agent to start any number of sessions and campaigns. See [Create an agent and start a session](/en/ai/platform/get-started/start-stop-agent).

- **Managed mode and BYOK**

  Choose separate ASR, LLM, and TTS models for each agent. Use managed mode to let Agora provide access to supported models, or bring your own provider keys. See [Use managed mode](/en/ai/platform/build/managed-mode) and [Use your own provider keys](/en/ai/platform/build/use-your-own-keys).

- **Project-scoped secrets**

  Store provider API keys in named secret sets, and reference them by name from your agents instead of including the keys in each configuration. See [Use your own provider keys](/en/ai/platform/build/use-your-own-keys).

- **Phone calls**

  Import your SIP phone numbers, and run agents in inbound and outbound phone calls. Route each number's inbound calls to an agent, place outbound calls, and run scheduled outbound campaigns that you can pause, resume, and cancel. See [Import phone numbers](/en/ai/platform/build/phone-calls/import-phone-numbers), [Route inbound calls to an agent](/en/ai/platform/build/phone-calls/route-inbound-calls), and [Make outbound calls and run campaigns](/en/ai/platform/build/phone-calls/outbound-calls-campaigns).

:::info[Info]
During the Preview, agent sessions run in North America (US). Geofencing isn't supported.
:::
