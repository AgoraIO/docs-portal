Agent Studio supports the following vendors. Vendors marked with \* support managed mode, where Agora provides the key and you don't need a provider account. Model usage in managed mode is included in the [unit price](/en/ai/platform/reference/pricing#unit-price). For the other vendors, use [your own key](/en/ai/platform/studio/build/customize-agent#bring-your-own-key).
