MCP (Model Context Protocol) servers let your agent call tools that external services provide. To call your own HTTP endpoints directly, use [custom tools](/en/ai/platform/studio/build/custom-tools) instead.

## Add an MCP server

To add an MCP server to an agent:

1. In the agent editor, go to the **Integrations** section.
2. Select **Add**, then select **MCP server**.
3. Fill in the following fields:

    - **Name**: A name for the server, from 1 to 48 letters and digits.
    - **Endpoint**: The HTTPS URL of the server, up to 2,048 characters.
    - **Headers**: The HTTP headers to send to the server, up to 32. Enter one `Name: value` per line. To authenticate with the server, use a runtime template. Raw credentials work for loading tools, but you can't save them. The **API key** field isn't available yet.
    - **Timeout**: The request timeout, from 1,000 to 100,000 ms. The default is 10,000 ms.
    - **Allowed tools**: The tools that the agent can call. By default, **Allow all tools** is selected. To allow only some tools, select **Load tools** to get the list of tools from the endpoint, then clear the tools that you don't want the agent to call.
    - **Transport**: The MCP transport. Only `streamable_http` is available.

4. Select **Save**. Agent Studio checks the server automatically.
