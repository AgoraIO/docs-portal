Custom tools let your agent call your own HTTP endpoints during a conversation. Use them when you already have an HTTP API and want your agent to call it directly. If you already expose tools through MCP, use an [MCP server](/en/ai/platform/studio/build/integrations#mcp-servers) instead.

## Prerequisites

You need an API that's reachable over HTTPS.

## Add a tool to an agent

To add a tool:

1. In the agent editor, go to the **Integrations** section.
2. Select **Add**, then select **Tool**.
3. Configure the tool.

After you add the tool, the LLM can call it during test sessions and production conversations.

## Tool settings

A tool tells the LLM when to call it and which request to send:

| Setting | Description |
|---|---|
| Name | The tool name shown to the model. It starts with a letter and contains only letters and digits, up to 64 characters. |
| Description | What the tool does, up to 1,024 characters. The model uses it to decide when to call the tool. |
| Parameters | A JSON Schema that describes the tool's arguments. |
| Method | `GET` or `POST`. |
| URL | The HTTPS URL of your endpoint, up to 2,048 characters. |
| Headers | HTTP headers to send, up to 32. They are write-only. |
| Timeout | The request timeout, from 1,000 to 100,000 ms. The default is 10,000 ms. |

For example, the following parameters define a tool that looks up an order:

```json
{
  "type": "object",
  "properties": {
    "order_id": { "type": "string" },
    "include_history": { "type": "boolean" }
  },
  "required": ["order_id"]
}
```

## Prompting tips

Put usage guidance in your system prompt. For example:

```text
Use lookup_order when the user asks about order status. Always confirm the order ID before calling the tool.
```

## Troubleshooting

The following table lists common issues with custom tools:

| Issue | Solution |
|---|---|
| The tool doesn't save | Check the JSON Schema and the tool name format. |
| Your API rejects the request | Check the headers, the request body, and the parameters. |
| The agent never calls the tool | Make the tool's intent clear in its description and in the system prompt. |
