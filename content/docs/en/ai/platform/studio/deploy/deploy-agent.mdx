After you test your agent and confirm that it works as expected, deploy it. Deploying makes the agent's saved configuration live, and connects any phone numbers you selected.

## Prerequisites

Before you deploy, make sure that:

- You have tested your agent and verified that it responds correctly. See [Test your agent](/en/ai/platform/studio/build/test-agent).
- For an **Inbound** or **Outbound** agent, you have set up a SIP trunk and imported a phone number. See [Set up SIP trunk](/en/ai/platform/studio/deploy/sip-trunk) and [Import a number](/en/ai/platform/studio/deploy/import). An **API** agent doesn't need either.

## Deploy an agent

To deploy your agent:

1. In the navigation sidebar, select **Agents**, then select the agent you want to deploy.
2. Select **Deploy agent**.
3. Complete the step for the agent's deployment type:

    | Deployment type | What to do |
    |---|---|
    | **Inbound** | The **Deploy agent** tab opens. In the **Phone number** section, connect a number, then select **Deploy agent**. You can't deploy an Inbound agent without a number. See [Handle inbound calls](/en/ai/platform/studio/deploy/inbound). |
    | **Outbound** | The **Deploy agent** tab opens. In the **Caller ID** section, choose the number to call from, then select **Deploy agent**. See [Make outbound calls](/en/ai/platform/studio/deploy/outbound). |
    | **API** | No configuration is required. A confirmation dialog opens. |

    The following image shows the **Deploy agent** tab for an Inbound agent:

    ![Deploy agent tab for an Inbound agent, with the Phone number, Start from your app, and Retention sections](/temp/agent-studio-preview/deploy-tab-inbound.png)

4. Read the message in the dialog, then select **Publish agent**.

    ![Publish dialog](/temp/agent-studio-preview/publish-dialog.png)

The agent's status changes from **Draft** to **Live**, and its overview page opens. See [Agent analytics](/en/ai/platform/studio/observe/analytics).

## Data retention

For an Inbound or Outbound agent, the **Retention** section of the **Deploy agent** tab controls whether Agora keeps a test session's conversation data. Turn off **Keep transcripts and recordings for 30 days** to discard the data. This setting applies to your next test session, and doesn't change retention for deployed calls.

For API sessions, you set retention when you start each session. See [Choose whether Agora retains conversation data](/en/ai/platform/build/shape-the-conversation/personalize-conversations#choose-whether-agora-retains-conversation-data).

## Manage deployed agents

To view your agents, select **Agents** in the navigation sidebar. To search for an agent, enter its name or agent ID.

## Update a deployed agent

To update a live agent:

1. Select the agent, then select **Edit agent**.
2. Make your changes in the agent editor.
3. Select **Deploy agent**, then select **Publish agent**.
