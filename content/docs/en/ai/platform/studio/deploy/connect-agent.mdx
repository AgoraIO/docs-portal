To connect your app users to a Conversational AI Platform agent, use the [Agora RTC SDK](/en/realtime-media/rtc/get-started-sdk) to join an RTC channel, then start a session from your backend using the Platform API or SDKs.

## Prerequisites

Before you begin, make sure that you have:

- A deployed **API** agent. See [Deploy the agent](/en/ai/platform/studio/quickstart#deploy-the-agent).
- An app that joins an RTC channel. See [Create an agent and start a session](/en/ai/platform/get-started/start-stop-agent).

## Get your connection details

To get the details your backend needs:

1. In the navigation sidebar, select **Agents**, then select your agent.
2. On the agent's overview page, copy the agent ID from the header.
3. Get your project's App ID using the [Agora CLI](/en/introduction/agora-cli).
4. Choose how to authenticate your API requests:

    | Method | What you need |
    |---|---|
    | Token | A token built with your App ID and App Certificate. The token must include the ConvoAI service. To start a session in an RTC channel, it must also include the RTC service. |
    | Basic auth | Your Customer ID and Customer Secret. |

    For details, see [Authentication](/en/api-reference/api-ref/conversational-ai/platform/authentication).

## Start a session

To start a session, send your agent ID with the channel details. For examples in Python, TypeScript, Go, and REST, see [Start a session](/en/ai/platform/get-started/start-stop-agent#start-a-session).
