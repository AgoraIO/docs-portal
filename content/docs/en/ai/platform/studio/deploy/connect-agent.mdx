To have your agent talk to people inside your app, start a session from your backend using the Conversational AI Platform API. An **API** agent is designed for this use. The **Start from your app** section of the **Deploy agent** tab gives you what you need to get started.

## Prerequisites

Before you begin, make sure that you have:

- A [published agent](/en/ai/platform/studio/deploy/deploy-agent).
- An app that joins an RTC channel. See [Create an agent and start a session](/en/ai/platform/get-started/start-stop-agent).

## Get your connection details

To get the details your backend needs:

1. In the navigation sidebar, select **Agents**, then select your agent.
2. Copy the agent ID from the header.
3. Select **Deploy agent**. In the **Start from your app** section, copy your **App ID**.
4. Choose how to authenticate your API requests:

    | Method | What you need |
    |---|---|
    | **RESTful API: Token** | A token built with your App ID and App Certificate. The token must include the ConvoAI service. To start a session in an RTC channel, it must also include the RTC service. |
    | **RESTful API: Basic Auth** | Your Customer ID and Customer Secret. |

    For details, see [Authentication](/en/api-reference/api-ref/conversational-ai/platform/authentication).

## Start a session

To start a session, send your agent ID with the channel details. For examples in Python, TypeScript, Go, and REST, see [Start a session](/en/ai/platform/get-started/start-stop-agent#start-a-session).
