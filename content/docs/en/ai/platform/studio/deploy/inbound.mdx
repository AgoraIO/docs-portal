An **Inbound** agent answers calls to your phone number. After you connect a number and publish the agent, calls to the number are automatically routed to the agent.

## Prerequisites

Before you begin, make sure that you have:

- An **Inbound** agent. To create one, select **Inbound** when you [create an agent](/en/ai/platform/studio/quickstart#create-an-agent).
- A SIP trunk configured for inbound calling. See [Set up SIP trunk](/en/ai/platform/studio/deploy/sip-trunk#inbound-calling-setup).
- An imported phone number. See [Import a number](/en/ai/platform/studio/deploy/import).

## Connect a number to the agent

To connect a number and publish the agent:

1. In the navigation sidebar, select **Agents**, then select your agent.
2. Select **Deploy agent**.
3. In the **Phone number** section, select **Connect**, then choose your number.
4. Select **Deploy agent**.
5. Review the summary, then select **Publish agent**.

    ![Publish dialog that lists the phone number to connect](/temp/agent-studio-preview/publish-dialog-number.png)

Agora publishes the agent, then connects the number. If the number fails to connect, the agent stays live and you can retry the connection separately.
