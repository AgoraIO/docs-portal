The **Sessions** table on an agent's overview page lists its calls and app sessions. Use it to find a session, and to open its details.

## View an agent's sessions

To view the sessions:

1. In the navigation sidebar, select **Agents**, then select your agent.
2. Go to the **Sessions** table. To find a session, filter by **Channel**, or search by **Exact session ID**.
3. To open a session, select the open icon in the **Actions** column.

To view the wider history, select **Session history** or **Call history** at the top of the table.

## Session details

Each session in the table shows the following:

- **Started**: The date and time the session started.
- **User**: The user, with the session ID.
- **Channel**: How the session connected. For example, **App**.
- **Type**: The type of session.
- **Campaign**: The associated campaign, for outbound calls.
- **Duration**: The length of the session.
- **Data points**: The values extracted from the session. See [Analysis](/en/ai/platform/studio/build/customize-agent#analysis).
