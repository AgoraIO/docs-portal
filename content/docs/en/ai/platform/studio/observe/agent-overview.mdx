Each agent has an overview page that helps you monitor, debug, and optimize it with performance metrics and a list of its sessions.

## View an agent's overview

To open the overview page, go to **Agents** in the navigation sidebar, then select a live agent. From the agent editor, select **Back to overview**.

![Agent overview page with performance metrics and the Test agent panel](/temp/agent-studio-preview/overview.png)

You can set the data period to **7 days**, **14 days**, **30 days**, or **Custom**.

## Metrics and charts

The overview page displays the following:

- **Sessions**: The number of sessions in the selected period.
- **Avg duration**: The average length of a session.
- **Billed minutes**: The minutes billed for the agent's sessions.
- **Sessions by channel**: The number of sessions for each channel, by day. Test sessions and app sessions use the **App** channel, and calls use the **Phone** channel.
- **Why sessions ended**: The breakdown of the reasons that ended sessions.
- **Session length**: The distribution of session lengths.
- **Busiest call hours**: The times of day with the most calls.

## Sessions

The **Sessions** table lists the agent's sessions.

![Sessions table with the session history and call history links](/temp/agent-studio-preview/overview-sessions.png)

To find a session, filter by **Channel**, or search by **Exact session ID**. To download the table, select **Export CSV**.

For a description of the columns, see [Session information](/en/ai/platform/studio/observe/agent-analytics#session-information).
