This page guides you through creating and testing your first AI voice agent in the Agent Studio Preview. In less than 10 minutes, you have a working agent that you can speak to in the browser. No telephony setup is required.

## Create an agent

To create your first agent:

1. [Open the Agent Studio Preview](/en/ai/platform/studio#open-the-agent-studio-preview).
2. Select your project from the project selector at the top of the page. The agent uses this project's credentials to connect to Agora, and Agora bills the usage to this project.
3. In the navigation sidebar, select **Agents**.

    ![Agents page with the Inbound, Outbound, and API options](/temp/agent-studio-preview/agents-empty.png)

4. Select **Create agent**.

    ![Create agent panel with a name and three deployment types](/temp/agent-studio-preview/create-agent-panel.png)

5. Enter a name for your agent, or keep the generated name.
6. Under **Deployment type**, select **API**.
7. Select **Create agent**.

    The agent editor opens with a default system prompt and pre-configured models.

    ![Agent editor with the Test agent panel](/temp/agent-studio-preview/agent-editor.png)

## Configure your agent

The agent editor is a single page with a list of sections. For the quickstart, you only need to review the **System prompt** and **Voice & models** sections. Your changes save automatically.

### Review the prompt

The **System prompt** section contains the base instructions that shape how your agent thinks, speaks, and escalates. To start from a prompt for a common use case, select one from the **Template** menu.

To review what the agent says first, select **Edit greeting and failure message**:

- **Greeting**: The first message the agent speaks when the conversation starts. For example, `Hello! How can I help you today?`
- **Failure message**: The message the agent speaks when the LLM fails to produce a response.

### Review selected models

Models determine which ASR, LLM, and TTS services your agent uses to process speech, generate responses, and synthesize voice output.

In the **Voice & models** section, review the selected models. Use the default values to create your first agent.

The default models are provided by Agora, which means you don't need an API key from each vendor. For details, see [Pricing](/en/ai/platform/reference/pricing). To use your own API key or a vendor that Agora doesn't provide, see [Bring your own key](/en/ai/platform/studio/build/customize-agent#bring-your-own-key).

## Test the agent

To talk to your agent:

1. In the **Test agent** panel, select **Start test**.
2. Allow microphone access when prompted.
3. Speak to the agent to verify that it responds correctly.
4. Select **End test** to stop the session.

:::warning
Always select **End test** to stop a test. Closing the **Test agent** panel only releases your browser's audio.
:::
