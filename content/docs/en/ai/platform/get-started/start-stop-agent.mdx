On the Conversational AI Platform, you create an agent once and save it in your project. For each conversation, you start a session that runs the agent in an RTC channel, and you stop the session when the conversation ends. This page shows the code for each step. In a production environment, run this code on your business server.

## Understand the tech

An agent is a saved configuration. A session is a single conversation that runs it. The workflow is as follows:

1. Your server creates an agent and stores the agent ID that the Platform returns. You do this once, not for every conversation.
2. Your server starts a session with the agent ID, the channel name, and the user's UID. The agent and the user, through your app, join the same RTC channel. The agent talks to the user, using the agent's ASR, LLM, and TTS models and Agora's low-latency Software-Defined Real-Time Network (SDRTN®).
3. When the conversation ends, your server stops the session, and the agent leaves the channel.

## Prerequisites

Use the [Agora CLI](/en/introduction/agora-cli) to create or select an Agora project, verify project readiness, and export local credentials:

```bash
agora login
agora project create conv-ai-tutorial
agora project use conv-ai-tutorial
agora project doctor
agora project env --format shell --with-secrets
```

You also need:

- An [RTC token](/en/realtime-media/rtc/build/authenticate-users/integrate-token-generation) for the agent's UID in the channel.
- A client app that can join an Agora RTC channel, such as the [Voice Calling](/en/realtime-media/rtc/voice-quickstart) or [Video Calling](/en/realtime-media/rtc/get-started-sdk) quickstart.

## Create an agent

Create an agent with its name, instructions, greeting, and models. This example declares a `customer_name` variable and uses it in the instructions and the greeting. You pass its value when you start a session.

<Tabs defaultValue="rest-api" groupId="ai-sdk-language" persist>
<TabsList>
  <TabsTrigger value="rest-api">REST API</TabsTrigger>
  <TabsTrigger value="typescript">TypeScript SDK</TabsTrigger>
</TabsList>

<TabsContent value="rest-api">

Send a request to [Create an agent](/en/api-reference/api-ref/conversational-ai/platform/create-agent). The `pipeline` sets the agent's ASR, LLM, and TTS models. In the `Idempotency-Key` header, pass a unique value for each agent you create. If a request times out, retry it with the same key and the same body. The Platform returns the agent it already created instead of creating a duplicate.

```bash
curl --request POST \
  --url https://preview.ai.agora.io/conversational-ai/v1/projects/<your_app_id>/agents \
  --header 'Authorization: Basic <your_base64_encoded_credentials>' \
  --header 'Content-Type: application/json' \
  --header 'Idempotency-Key: <your_unique_key>' \
  --data '
{
  "agent_name": "Support agent",
  "instructions": "You are a friendly support agent for Acme. Address the user as {{customer_name}}. Keep your answers short.",
  "variables": {
    "customer_name": {
      "type": "str",
      "required": true
    }
  },
  "greeting": {
    "mode": "text",
    "on": "each_join",
    "text": "Hi {{customer_name}}, how can I help you today?"
  },
  "pipeline": {
    "mode": "cascaded",
    "asr": {
      "credential": { "mode": "managed" },
      "vendor": "deepgram",
      "model": "nova-3",
      "language": "en-US"
    },
    "llm": {
      "credential": { "mode": "managed" },
      "vendor": "openai",
      "style": "openai",
      "model": "gpt-4.1-mini"
    },
    "tts": {
      "credential": { "mode": "managed" },
      "vendor": "minimax",
      "params": {
        "model": "speech-2.6-turbo",
        "voice_setting": {
          "voice_id": "English_captivating_female1",
          "speed": 1
        }
      }
    }
  }
}'
```

If the request is successful, the response contains the agent ID and the saved configuration:

```json
// 201 Created
{
  "agent_id": "agent_k3n9x2",
  "agent_name": "Support agent",
  "instructions": "You are a friendly support agent for Acme. Address the user as {{customer_name}}. Keep your answers short.",
  "variables": {
    "customer_name": {
      "type": "str",
      "required": true
    }
  },
  "greeting": {
    "mode": "text",
    "on": "each_join",
    "text": "Hi {{customer_name}}, how can I help you today?"
  },
  "pipeline": { ... },  // The pipeline you set in the request.
  "create_ts": 1786543331,
  "update_ts": 1786543331
}
```

</TabsContent>

<TabsContent value="typescript">

```ts
import { Agent, DeepgramSTT, OpenAI, OpenAITTS } from 'agora-agents';

const agent = new Agent({ client })
  .withStt(new DeepgramSTT({ model: 'nova-3', language: 'en-US' }))
  .withLlm(
    new OpenAI({
      model: 'gpt-4.1-mini',
      systemMessages: [
        {
          role: 'system',
          content:
            'You are a friendly support agent for Acme. Address the user as {{customer_name}}. Keep your answers short.',
        },
      ],
      greetingMessage: 'Hi {{customer_name}}, how can I help you today?',
      greetingConfigs: { on: 'each_join' },
    }),
  )
  .withTts(new OpenAITTS({ model: 'tts-1', voice: 'alloy' }))
  .withVariable('customer_name', { type: 'str', required: true });

const savedAgent = await agent.save({ name: 'Support agent' });
console.log(savedAgent.id); // The agent ID
```

</TabsContent>
</Tabs>

Store the agent ID. You use it to start every session that runs this agent.

This agent uses managed mode for its ASR, LLM, and TTS models. Agora provides access to the models, and you don't need provider API keys. To use other models or your own provider accounts, see [Use managed mode](/en/ai/platform/build/managed-mode) and [Use your own provider keys](/en/ai/platform/build/use-your-own-keys).

## Start a session

To start a conversation, start a session with the agent ID and the following details:

- The RTC channel for the conversation.
- The RTC token for the agent's UID.
- The UID the agent uses in the channel. It must be different from the user's UID.
- The UID of the user the agent talks to.
- A value for each required variable that you defined when you created the agent, such as `customer_name`.

<Tabs defaultValue="rest-api" groupId="ai-sdk-language" persist>
<TabsList>
  <TabsTrigger value="rest-api">REST API</TabsTrigger>
  <TabsTrigger value="typescript">TypeScript SDK</TabsTrigger>
</TabsList>

<TabsContent value="rest-api">

Send a request to [Start a session](/en/api-reference/api-ref/conversational-ai/platform/start-session). In `transport`, set:

- `type`: `rtc`, to run the session in an RTC channel. To run the session in a phone call, you use `telephony` instead. For details, see [Make outbound calls and run campaigns](/en/ai/platform/build/phone-calls/outbound-calls-campaigns).
- `channel`: The RTC channel for the conversation.
- `token`: The RTC token for the agent's UID.
- `uid`: The agent's UID.
- `subscribe_uids`: The user's UID.

In `values`, pass the variable values.

```bash
curl --request POST \
  --url https://preview.ai.agora.io/conversational-ai/v1/projects/<your_app_id>/sessions \
  --header 'Authorization: Basic <your_base64_encoded_credentials>' \
  --header 'Content-Type: application/json' \
  --data '
{
  "agent_id": "agent_k3n9x2",
  "values": {
    "customer_name": "Ada"
  },
  "transport": {
    "type": "rtc",
    "channel": "<your_channel_name>",
    "token": "<your_rtc_token>",
    "uid": "1002",
    "subscribe_uids": ["1001"]
  }
}'
```

If the request is successful, the response contains the session ID and its [status](#check-the-session-status):

```json
// 201 Created
{
  "agent_session_id": "a42ac95tp25py49fc37hp94vm67ht52h",
  "status": "running",
  "created_at": 1737111452
}
```

</TabsContent>

<TabsContent value="typescript">

Load the saved agent and call `createSession()`.

```ts
import { SavedAgent } from 'agora-agents';

const savedAgent = await SavedAgent.get(client, 'agent_k3n9x2');
const session = savedAgent.createSession({
  channel: '<your_channel_name>',
  token: '<your_rtc_token>',
  agentUid: '1002',
  remoteUids: ['1001'],
  values: { customer_name: 'Ada' },
});

const sessionId = await session.start();
console.log(sessionId); // The agent_session_id
```

</TabsContent>
</Tabs>

Store the session ID. You use it to check and stop the session.

## Check the session status

A session starts asynchronously. Starting a session successfully confirms that the session exists, not that the agent has joined the channel. To follow the session, retrieve it with its session ID:

<Tabs defaultValue="rest-api" groupId="ai-sdk-language" persist>
<TabsList>
  <TabsTrigger value="rest-api">REST API</TabsTrigger>
  <TabsTrigger value="typescript">TypeScript SDK</TabsTrigger>
</TabsList>

<TabsContent value="rest-api">

Send a request to [Retrieve a session](/en/api-reference/api-ref/conversational-ai/platform/retrieve-session):

```bash
curl --request GET \
  --url https://preview.ai.agora.io/conversational-ai/v1/projects/<your_app_id>/sessions/<agent_session_id> \
  --header 'Authorization: Basic <your_base64_encoded_credentials>'
```

When the agent is in the channel, the response looks like this:

```json
// 200 OK
{
  "agent_session_id": "a42ac95tp25py49fc37hp94vm67ht52h",
  "status": "RUNNING",
  "start_ts": 1735035893,
  "message": "ok"
}
```

</TabsContent>

<TabsContent value="typescript">

```ts
const info = await client.v3.sessions.get({ agentSessionId: '<agent_session_id>' });
console.log(info.status);
```

If you still have the `session` object from Start a session, you can call `await session.getInfo()` instead.

</TabsContent>
</Tabs>

When the agent is in the channel, `status` is `RUNNING`. A session has one of the following statuses:

| Status | Description |
|---|---|
| `IDLE` | The session is idle. |
| `STARTING` | The session is starting, and the agent hasn't joined the channel yet. |
| `RUNNING` | The agent is in the channel. |
| `STOPPING` | The session is stopping. |
| `STOPPED` | The session has ended, and the agent has left the channel. |
| `FAILED` | The session failed. Check `message` for the reason. |

## Stop the session

When the conversation ends, stop the session with its session ID. The agent leaves the channel.

<Tabs defaultValue="rest-api" groupId="ai-sdk-language" persist>
<TabsList>
  <TabsTrigger value="rest-api">REST API</TabsTrigger>
  <TabsTrigger value="typescript">TypeScript SDK</TabsTrigger>
</TabsList>

<TabsContent value="rest-api">

Send a request to [Stop a session](/en/api-reference/api-ref/conversational-ai/platform/stop-session) without a body:

```bash
curl --request POST \
  --url https://preview.ai.agora.io/conversational-ai/v1/projects/<your_app_id>/sessions/<agent_session_id>/stop \
  --header 'Authorization: Basic <your_base64_encoded_credentials>'
```

If the request is successful, the response is an empty JSON object:

```json
// 200 OK
{}
```

</TabsContent>

<TabsContent value="typescript">

```ts
await client.v3.sessions.stop({ agentSessionId: '<agent_session_id>' });
```

If you still have the `session` object from Start a session, you can call `await session.stop()` instead.

</TabsContent>
</Tabs>

A session also stops asynchronously. To confirm that the session has ended, retrieve it and check that `status` is `STOPPED`. If you don't stop a session, it ends when it reaches a limit you set when you start it, such as an idle timeout or a maximum duration.

## Test a configuration without saving an agent

To try a configuration before you save it, start an ephemeral session. You pass the agent configuration instead of an agent ID, and the Platform doesn't save the configuration.

<Tabs defaultValue="rest-api" groupId="ai-sdk-language" persist>
<TabsList>
  <TabsTrigger value="rest-api">REST API</TabsTrigger>
  <TabsTrigger value="typescript">TypeScript SDK</TabsTrigger>
</TabsList>

<TabsContent value="rest-api">

Send a request to [Start an ephemeral session](/en/api-reference/api-ref/conversational-ai/platform/start-ephemeral-session). The request is the same as Start a session, but you pass the agent configuration in `agent` instead of `agent_id`.

```bash
curl --request POST \
  --url https://preview.ai.agora.io/conversational-ai/v1/projects/<your_app_id>/sessions/ephemeral \
  --header 'Authorization: Basic <your_base64_encoded_credentials>' \
  --header 'Content-Type: application/json' \
  --data '
{
  "agent": {
    "instructions": "You are a friendly support agent for Acme. Keep your answers short.",
    "greeting": {
      "mode": "text",
      "on": "each_join",
      "text": "Hi, how can I help you today?"
    },
    "pipeline": {
      "mode": "cascaded",
      "asr": { "credential": { "mode": "managed" }, "vendor": "deepgram", "model": "nova-3", "language": "en-US" },
      "llm": { "credential": { "mode": "managed" }, "vendor": "openai", "style": "openai", "model": "gpt-4.1-mini" },
      "tts": {
        "credential": { "mode": "managed" },
        "vendor": "minimax",
        "params": { "model": "speech-2.6-turbo", "voice_setting": { "voice_id": "English_captivating_female1", "speed": 1 } }
      }
    }
  },
  "transport": {
    "type": "rtc",
    "channel": "<your_channel_name>",
    "token": "<your_rtc_token>",
    "uid": "1002",
    "subscribe_uids": ["1001"]
  }
}'
```

The response has the same format as Start a session.

</TabsContent>

<TabsContent value="typescript">

Call `createSession()` on an `Agent` instead of a saved agent. The SDK starts an ephemeral session when you set a Platform session option, such as `maxDuration` in seconds.

```ts
import { Agent, DeepgramSTT, OpenAI, OpenAITTS } from 'agora-agents';

const testAgent = new Agent({ client })
  .withStt(new DeepgramSTT({ model: 'nova-3', language: 'en-US' }))
  .withLlm(
    new OpenAI({
      model: 'gpt-4.1-mini',
      systemMessages: [
        { role: 'system', content: 'You are a friendly support agent for Acme. Keep your answers short.' },
      ],
      greetingMessage: 'Hi, how can I help you today?',
      greetingConfigs: { on: 'each_join' },
    }),
  )
  .withTts(new OpenAITTS({ model: 'tts-1', voice: 'alloy' }));

const session = testAgent.createSession({
  channel: '<your_channel_name>',
  token: '<your_rtc_token>',
  agentUid: '1002',
  remoteUids: ['1001'],
  maxDuration: 600,
});
const sessionId = await session.start();
```

</TabsContent>
</Tabs>

{/* TODO(platform-confirm): The TypeScript SDK has no explicit ephemeral option. Without a secret reference, a variable, or a Platform session option such as `maxDuration`, `values`, or `dataPolicy`, `Agent.createSession()` uses the Voice Agent API instead. `idleTimeout` alone doesn't select the Platform. */}

Check and stop an ephemeral session the same way as any other session.

When the configuration works as you want, save it with [Create an agent](#create-an-agent), or apply it to an existing agent with [Update an agent](/en/api-reference/api-ref/conversational-ai/platform/update-agent).
