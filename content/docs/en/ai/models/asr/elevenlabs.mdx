### Key parameters

<ParameterList title="params" required={true}>
  <Parameter name="api_key" type="string" required={true}>
    The ElevenLabs API key used to authenticate requests. You must provide a valid key for the service to function.
  </Parameter>
  <Parameter name="model_id" type="string" required={false}>
    The ElevenLabs realtime speech-to-text model. For example, `scribe_v2_realtime`. For supported models, refer to the [ElevenLabs documentation](https://elevenlabs.io/docs/api-reference/speech-to-text/v-1-speech-to-text-realtime).
  </Parameter>
  <Parameter name="language_code" type="string" required={false}>
    The language of the audio, as an ISO 639-1 or ISO 639-3 code. For example, `en` for English. If you set this parameter, it takes precedence over `asr.language`.
  </Parameter>
</ParameterList>

:::caution[Caution]
The parameters listed on this page are validated for use with Conversational AI Engine. Required parameters must be provided as documented. Any additional parameters are passed through directly to the underlying vendor without validation. For a full list of supported options, refer to the [ElevenLabs realtime speech-to-text documentation](https://elevenlabs.io/docs/api-reference/speech-to-text/v-1-speech-to-text-realtime).
:::

This integration is fully supported for use with Conversational AI Engine. While it has completed functional validation, it is newer to the platform, and additional provider-specific edge cases may be identified as usage scales across a broader range of applications and workloads.
