Tavus provides lifelike AI avatars that see, hear, and respond in real time, enabling natural video conversations with your AI agents.

### Sample configuration

Tavus integrates through the `generic` avatar vendor. The following examples show how to configure a Tavus avatar when starting a conversational AI agent.

<TabsContent value="python">

```python
from agora_agent import Agent
from agora_agent.agentkit.vendors import GenericAvatar

# client is your configured Agora client
agent = (
    Agent(client)
    .with_stt(...)  # configure your STT vendor
    .with_llm(...)  # configure your LLM vendor
    .with_tts(...)  # configure your TTS vendor
    .with_avatar(GenericAvatar(
        api_key='<TAVUS_API_KEY>',
        api_base_url='https://tavusapi.com/v2/conversations/agora',
        avatar_id='<TAVUS_FACE_ID>',
        agora_uid='<AGORA_UID>',
    ))
)
```

```go
import "github.com/AgoraIO/agora-agents-go/v2/agentkit/vendors"

// client is your configured Agora client
agent := agentkit.NewAgent(client).WithStt(/* configure your STT vendor */).
  WithLlm(/* configure your LLM vendor */).
  WithTts(/* configure your TTS vendor */).
  WithAvatar(
    vendors.NewGenericAvatar(vendors.GenericAvatarOptions{
        APIKey:     "<TAVUS_API_KEY>",
        APIBaseURL: "https://tavusapi.com/v2/conversations/agora",
        AvatarID:   "<TAVUS_FACE_ID>",
        AgoraUID:   "<AGORA_UID>",
    }),
)
```

### Key parameters

<ParameterList title="params" required={true}>
  <Parameter name="api_key" type="string" required={true}>
    The API key used for authentication with Tavus. Get your API key from your Tavus account. For details, refer to [Tavus authentication](https://docs.tavus.io/api-reference/authentication).
  </Parameter>
  <Parameter name="api_base_url" type="string" required={true}>
    The base URL of the Tavus API endpoint. Set to `https://tavusapi.com/v2/conversations/agora`.
  </Parameter>
  <Parameter name="avatar_id" type="string" required={true}>
    The ID of the Tavus face (formerly called a replica) to render the avatar. Find or create a face in the [Tavus Developer Portal](https://maker.tavus.io/dev/faces).
  </Parameter>
  <Parameter name="agora_token" type="string" required={false}>
    The RTC token that authorizes the avatar to join the video channel. Generate this token using your Agora project credentials.
  </Parameter>
  <Parameter name="agora_uid" type="string" required={true}>
    The unique identifier for the avatar's RTC connection. This must be different from other participants in the channel.
  </Parameter>
</ParameterList>

For more information about Tavus faces and conversations, refer to the [Tavus documentation](https://docs.tavus.io).

This integration is fully supported for use with Conversational AI Engine. While it has completed functional validation, it is newer to the platform, and additional provider-specific edge cases may be identified as usage scales across a broader range of applications and workloads.
