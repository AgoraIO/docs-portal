LemonSlice provides AI-powered avatar agents that generate synchronized video and audio responses in real time, enabling natural video conversations with your AI agents.

### Sample configuration

The following examples show how to configure a LemonSlice avatar when starting a conversational AI agent.

### Key parameters

<ParameterList title="params" required={true}>
  <Parameter name="api_key" type="string" required={true}>
  The API key used for authentication with LemonSlice. Get your API key from your LemonSlice account.
  </Parameter>
  <Parameter name="api_base_url" type="string" required={true}>
  The base URL of the LemonSlice API endpoint. Set to `https://lemonslice.com/api/liveai/agora`.
  </Parameter>
  <Parameter name="avatar_id" type="string" required={true}>
  Fixed value that identifies the vendor integration. Always set to `lemonslice`.
  </Parameter>
  <Parameter name="agent_image_url" type="string" required={false}>
  A publicly accessible URL to the avatar image. Provide exactly one of `agent_id`, `agent_image_url`, or `agent_image_base64`.
  </Parameter>
  <Parameter name="agent_id" type="string" required={false}>
  The ID of a LemonSlice agent to use as the avatar. Provide exactly one of `agent_id`, `agent_image_url`, or `agent_image_base64`. If you provide `agent_id`, LemonSlice also uses that agent's configured settings as defaults for `agent_prompt` and `agent_idle_prompt`.
  </Parameter>
    <Parameter name="agent_image_base64" type="string" required={false}>
  A base64-encoded avatar image. Provide exactly one of `agent_id`, `agent_image_url`, or `agent_image_base64`.
  </Parameter>
  <Parameter name="aspect_ratio" type="string" required={false}>
  The output aspect ratio for the avatar video. One of `2x3`, `9x16`, or `1x1`. Defaults to `2x3`.
  </Parameter>
  <Parameter name="agora_token" type="string" required={false}>
  The RTC token that authorizes the avatar to join the video channel. Generate this token using your Agora project credentials.
  </Parameter>
  <Parameter name="agora_uid" type="string" required={true}>
  The unique identifier for the avatar's RTC connection. This must be different from other participants in the channel.
  </Parameter>
  <Parameter name="action_patterns" type="array[integer]" required={false}>
  The bracket types whose content triggers avatar gestures. Uses the same IDs as `tts.skip_patterns`:

  - `1`: Chinese parentheses `（）`
  - `2`: Chinese square brackets `【】`
  - `3`: Parentheses `( )`
  - `4`: Square brackets `[ ]`
  - `5`: Curly braces `{ }`

  For example, `[4]` or `[3, 4]`. Gestures are disabled by default. If you don't set this parameter, or set it to an empty array or `null`, the avatar doesn't perform gestures. For details, see [Trigger avatar gestures](#trigger-avatar-gestures).
  </Parameter>
</ParameterList>

For advanced configuration options, refer to the [LemonSlice Agora integration](https://lemonslice.com/docs/agora) page or the [LemonSlice API documentation](https://lemonslice.com/docs/api-reference/create-self-managed-session).

### Trigger avatar gestures

You can make the avatar perform gestures from the agent's text. Set `action_patterns` to the bracket types you want to use, and instruct the LLM to put LemonSlice action names inside those brackets. Conversational AI Engine sends each bracketed action name in the agent's text to LemonSlice.

`action_patterns` and the TTS `skip_patterns` setting use the same bracket IDs, but work independently:

- `action_patterns` selects which bracketed text triggers avatar gestures.
- `skip_patterns` selects which bracketed text the agent doesn't speak.

If you set only `action_patterns`, the avatar performs the gesture, and the agent also reads the bracketed text aloud. To trigger gestures silently, set both to the same bracket ID. The following examples use square brackets (`4`) for both. In the SDKs, pass `action_patterns` in the avatar's additional parameters.

#### Prompt the LLM for gestures

When the agent's text contains a configured bracket pair, Conversational AI Engine sends the text inside it, up to 40 characters, to LemonSlice as an action name. LemonSlice ignores action names it doesn't recognize.

- In your system prompt, tell the LLM which LemonSlice action names to use, and which brackets to put them in.
- If your prompt also uses brackets for notes that aren't gestures, such as tone indicators, use a different bracket pair for gestures.

#### Limitations

- Gestures work with agents that use an LLM and TTS. They aren't supported with MLLM agents or SIP calls.
- Gestures are triggered by text from LLM responses, the [Broadcast a message using TTS](/en/api-reference/api-ref/conversational-ai/speak) API, and assistant text sent through Signaling. Pre-recorded audio greetings don't trigger gestures.

This integration is fully supported for use with Conversational AI Engine. While it has completed functional validation, it is newer to the platform, and additional provider-specific edge cases may be identified as usage scales across a broader range of applications and workloads.
