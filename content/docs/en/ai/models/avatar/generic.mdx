---
title: Generic avatar provider
description: Integrate a custom avatar provider into Voice Agent through the generic avatar interface.
---

The `generic` avatar vendor lets you connect a custom avatar provider to Voice Agent when a built-in vendor integration does not fit your use case.

## Sample configuration

The following example shows a starting `avatar` configuration you can use when you [start a conversational AI agent](../../../api-reference/conversational-ai/rest-api/agent/join.md).

```json
"avatar": {
  "vendor": "generic",
  "params": {
    "api_key": "<avatar_api_key>",
    "api_base_url": "<avatar_api_base_url>",
    "avatar_id": "<avatar_id>",
    "agora_token": "<agora_token>",
    "agora_uid": "<agora_uid>"
  }
}
```

## Key parameters

- `vendor`: Set to `generic`.
- `params.api_key`: API key used to authenticate with the avatar provider.
- `params.api_base_url`: Base URL for the avatar provider API.
- `params.avatar_id`: Unique identifier of the avatar to render.
- `params.agora_token`: RTC token that allows the avatar endpoint to join the channel.
- `params.agora_uid`: Unique RTC UID used by the avatar participant. It must differ from every other participant in the channel.

Use this option when your team already has an avatar backend or when you need a vendor that is not yet covered by a built-in integration.
