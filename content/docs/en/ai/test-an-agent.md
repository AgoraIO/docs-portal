title: Test an agent
description: Validate session control, voice behavior, state sync, and event flow before promoting the agent toward production.
---

## Recommended validation areas

- whether the agent can be created and stopped reliably
- whether TTS responses sound correct and arrive at the right time
- whether transcript, state, and error UI stay synchronized
- whether interruption, recovery, and failure behavior match expectations
