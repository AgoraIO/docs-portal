## Connect to the Agora Doc MCP Server

Choose one of the following ways to connect to the MCP server:

#### Trae

**Manual configuration:**

Add the following configuration manually in Trae under Settings > MCP:

```json title=
{
  "mcpServers": {
    "shengwang-docs": {
      "type": "http",
      "url": "https://mcp.agora.io"
    }
  }
}
```

#### Claude Code

**Add with the `CLI`:**

```bash
claude mcp add --transport http shengwang-docs https://mcp.agora.io
```

**Or configure it manually:**

Create or edit `.mcp.json` in the project root, then add the following section:

```json
{
  "mcpServers": {
    "shengwang-docs": {
      "type": "http",
      "url": "https://mcp.agora.io"
    }
  }
}
```

#### Codex

**Add with the `CLI`:**

```bash
codex mcp add shengwang-docs --url https://mcp.agora.io
```

**Or configure it manually:**

Create or edit `.codex/config.toml` in the project root, then add the following section:

```text
[mcp_servers.shengwang-docs]
url = "https://mcp.agora.io"
```

## MCP tools

The server supports documentation lookup:

- Search Agora product guides.
- Search SDK API references.
- Discover available filter values when a tool exposes this capability.

Your MCP client discovers tools through `tools/list`. It exposes each tool's name, description, and input schema to your assistant.
Use these definitions as the source of truth for tool names and arguments.

Before calling a tool, the assistant should:

1. Inspect the tools exposed by the connected server.
2. Select a tool whose description matches the product, platform, and task.
3. Read its input schema. Supply every required field and use the declared types for queries and filters.
4. Read the result before deciding whether another search is needed.

Search results can contain excerpts rather than complete pages. Open the returned documentation URL when you need the full guide.
For pages on `docs.agora.io`, append `.md` to read the Markdown version.

## Use MCP tools

Describe the task in natural language. Let the assistant select tools from the connected server.

```text
Use the connected Agora documentation tools to find the Web video calling quickstart.
Inspect the tool descriptions and input schemas before calling a tool.
Read the matching guide and explain how two people can join the same call.
```

For a voice agent:

```text
Use the connected Agora documentation tools to find the Web Conversational AI quickstart.
Read the guide and explain the required setup for a browser voice demo.
Include links to the documentation you use.
```

If a tool is unavailable, refresh the tool list before selecting another tool.
If MCP is unavailable or returns no useful content, use [llms.txt](https://docs.agora.io/llms.txt) to find the relevant documentation.
Follow the index links and fetch the matching page as Markdown.
