## Static platform variant pattern

| Platform | Static route pattern |
| --- | --- |

| iOS | `content/docs/en/realtime-media/ios/...` |
| Web | `content/docs/en/realtime-media/web/...` |

Code-language tabs are only for one conceptual page with language-specific commands or examples.

### POST `/v1/projects/{projectId}/agents`

Use headings, tables, code fences, and directive callouts when no structured API source is available.

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `projectId` | string | Yes | Agora project ID. |
| `name` | string | Yes | Agent display name. |
| `rtc` | string | No | Realtime media mode. |

:::warning[Prefer structured sources]
OpenAPI YAML or JSON should remain source data for the OpenAPI lane instead of being flattened into hand-written Markdown.
:::

```json title="request.json"
{
  "name": "demo-agent",
  "rtc": "voice"
}
```
