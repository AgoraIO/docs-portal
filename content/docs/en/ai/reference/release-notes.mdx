This document tracks notable changes and improvements to the Conversational AI Engine.

## Releases

### v2.7

Released on May 20, 2026.

#### New features

Included in this release:

- **New MLLM provider**
  - [xAI Grok](../models/mllm/xai.mdx)

- **New Avatar providers**
  - [Generic avatar (Beta)](../models/avatar/generic.mdx)

- **Greeting interruption control**

  The `properties.llm.greeting_configs` object in the [Start a conversational AI agent](../../api-reference/conversational-ai/rest-api/agent/join.md) API now supports an `interruptable` parameter, which controls whether user speech can interrupt a greeting during playback.

#### Improvements

These changes may affect your existing integration. Review each change and update your integration as needed.

- **Response status codes updated**

  This release adjusts the HTTP response status codes and `reason` values returned by the REST API. New status codes `401`, `429`, and `500` are added. New `reason` values `ServiceNotEnabled`, `AccountSuspended`, and `ResourceAllocationFailed` are introduced. The existing `InvalidRequest` reason is replaced by `InvalidRequestBody`, `MissingRequiredField`, and `InvalidFieldValue`. For details, see [Status codes and error messages](../../api-reference/conversational-ai/rest-api/status-codes.mdx).

  If your integration relies on `reason` values for error handling, retry logic, or alerting, update your logic to handle the new values accordingly.

- **Query conversation turns API now returns paginated results**

  The [Query conversation turn information](../../api-reference/conversational-ai/rest-api/agent/turns.md) API no longer returns all turns in a single response. Results are now paginated, defaulting to page 1 with up to 50 turns per page.

  This affects sessions with more than 50 conversation turns. Update your integration to handle the new `total_turn_count` and `pagination` fields in the response, and retrieve subsequent pages as needed.

  This release also adds the `112 turns finished` notification event as an alternative way to retrieve turn data after a session ends.

- **`on_listening_action` default behavior change**

  The default value of `on_listening_action` in the [Send a custom instruction](../../api-reference/conversational-ai/rest-api/agent/think.md) API has changed from `inject` to `interrupt`. When set to `interrupt`, the API immediately interrupts the current flow and initiates a new round of dialogue. If you rely on the previous default behavior, explicitly set `on_listening_action` to `inject` in your requests.

#### API changes

This release introduces the following changes to the REST API.

- Changes to [**Start a conversational AI agent**](../../api-reference/conversational-ai/rest-api/agent/join.md)
  - **New parameters**
    - `properties.llm.greeting_configs.interruptable`: Controls whether user speech can interrupt a greeting during playback.

- Changes to [**Query conversation turn information**](../../api-reference/conversational-ai/rest-api/agent/turns.md)
  - **New query parameters**
    - Adds `page_index` and `page_size`.
  - **New response parameters**
    - Adds `agent_id`, `name`, `channel`, `total_turn_count`, and `pagination`.

- Changes to [**Send a custom instruction**](../../api-reference/conversational-ai/rest-api/agent/think.md)
  - **Behavior changes**
    - `on_listening_action` now defaults to `interrupt`.

- Changes to [**Notification event types**](../build/event-types.mdx)
  - **New events**
    - `112 turns finished`

### v2.6

Released on April 22, 2026.

#### New features

Included in this release:

- **New TTS provider**
  - [Deepgram](../models/tts/deepgram.mdx)

- **New endpoint: Send a custom instruction**

  Adds a new endpoint to inject a custom text instruction into the agent's current conversation pipeline. The instruction is processed as user input, enabling scenarios such as implicit instruction injection, client-side event triggering, and voice and text collaboration. For details, see [Send a custom instruction](../../api-reference/conversational-ai/rest-api/agent/think.md).

- **MLLM turn detection refactoring**

  Introduces a new `mllm.turn_detection` object for configuring turn detection when using MLLM. When defined, this overrides the top-level `turn_detection` object. Supported modes vary by vendor:

  - OpenAI Realtime API: `agora_vad`, `server_vad`, `semantic_vad`
  - Google Gemini Live: `agora_vad`, `server_vad`

- **Interruption control**

  Adds a new top-level `interruption` object for unified management of agent interruption behavior.

#### Improvements

- **New agent state callbacks**

  Adds `onAgentListeningChanged`, `onAgentThinkingChanged`, and `onAgentSpeakingChanged` to the Android, iOS, and web toolkit event handler interfaces.

- **Added `name` field to all NCS event payloads**

  Returns the agent name provided when starting the agent.

#### API changes

- **New endpoint**
  - [Send a custom instruction](../../api-reference/conversational-ai/rest-api/agent/think.md)

- Changes to [**Start a conversational AI agent**](../../api-reference/conversational-ai/rest-api/agent/join.md)
  - **New parameters**
    - `interruption`
    - `greeting_configs.delay_ms`
    - `llm.headers`
    - `mllm.enable`
    - `mllm.turn_detection`
    - `mllm.turn_detection.server_vad_config.idle_timeout_ms`
    - `mllm.vendor = gemini`
  - **Behavior changes**
    - `turn_detection` now handles SoS and EoS only.
  - **Deprecated fields**
    - `advanced_features.enable_mllm`
    - `turn_detection.config.start_of_speech.mode = keywords`
    - `turn_detection.config.start_of_speech.mode = disabled`
  - **Removed fields**
    - `mllm.style`
    - `mllm.create_response`
    - `mllm.interrupt_response` for OpenAI Realtime API

- Changes to [**Notification event types**](../build/event-types.mdx)
  - **New fields**
    - `name`

### v2.5

Released on March 31, 2026.

#### New features

Included in this release:

- **Preset model configurations**

  Adds a `preset` parameter to the Join API. Pass a comma-separated list of preset names to apply predefined configurations for ASR, LLM, and TTS providers. When you use a preset, the corresponding provider is supplied through Agora-managed accounts. For details, see [Pricing](pricing.mdx).

  Available presets:

  - ASR: `deepgram_nova_2`, `deepgram_nova_3`
  - LLM: `openai_gpt_4o_mini`, `openai_gpt_4_1_mini`, `openai_gpt_5_nano`, `openai_gpt_5_mini`
  - TTS: `minimax_speech_2_6_turbo`, `minimax_speech_2_8_turbo`, `openai_tts_1`

- **Pause state detection**

  Adds semantic pause detection to help the agent wait for further user input instead of forwarding pause-like utterances to the LLM.

- **Conversation turn insights**

  Adds support for querying per-turn start, end, and latency metrics after a session ends.

- **Real-time TTS parameter updates with custom LLM**

  Adds support for updating TTS parameters during a conversation in custom LLM scenarios.

- **New TTS provider**
  - [Murf (Beta)](../models/tts/murf.mdx)

- **New Avatar provider**
  - [Anam (Beta)](../models/avatar/anam.mdx)

#### Improvements

- **Migration from HeyGen API to LiveAvatar (Beta) API**

  Updates the HeyGen avatar configuration to use the [LiveAvatar (Beta)](../models/avatar/heygen.mdx) API.

#### API changes

- **New endpoint: Query conversation turns**
  - [Query conversation turn information](../../api-reference/conversational-ai/rest-api/agent/turns.md)

- Changes to [**Start a conversational AI agent**](../../api-reference/conversational-ai/rest-api/agent/join.md)
  - **New parameters**
    - `preset`
    - `pause_state_enabled`
  - **Deleted deprecated fields**
    - `properties.silence_timeout`
    - `properties.advanced_features.enable_aivad`
    - `properties.llm.silence_message`
