## What this capability is

Status Page provides visibility into platform service health so teams can quickly distinguish product issues from upstream availability issues.

## Common scenarios

- checking service state
- synchronizing during incidents
- operational triage

## What to read first

When the first question is "is the platform healthy" rather than "is our code wrong," Status Page should be the first stop.
