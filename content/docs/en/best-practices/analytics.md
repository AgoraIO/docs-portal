## What this capability is

Analytics handle quality observation, issue playback, and data analysis, making them a core governance surface after launch.

## Common scenarios

- call quality analysis
- issue diagnosis
- realtime session replay

## What to read first

If the system is already live or quality troubleshooting is frequent, analytics should be one of the first governance capabilities you add.
