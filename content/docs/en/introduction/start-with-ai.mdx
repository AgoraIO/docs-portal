Use AI coding assistants to build with Agora faster. With access to Agora's documentation, your assistant can look up product guidance, API details, and platform-specific implementation patterns while you work.

## What this path includes

This page combines the three core AI-assisted build surfaces:

- **Agora Skills** for structured product and API guidance
- **Agora MCP server** for live documentation access inside coding assistants
- **llms.txt and markdown exports** for agent-friendly document retrieval when MCP is unavailable

## Agora Skills

Agora Skills is a set of structured reference files that gives AI coding assistants deeper knowledge of Agora's platform. When you ask your assistant to build something with Agora, it can load the relevant skill files covering products, APIs, and platform-specific code examples so it generates code with less guessing.

Skills also integrates with the Agora MCP server, which gives your assistant live access to Agora documentation. For repository details and updates, see the [Agora Skills repository](https://github.com/AgoraIO/skills).

### Install Agora Skills

#### Skills CLI (recommended)

```bash
npx skills add github:AgoraIO/skills
```

Skills activate automatically when your agent detects relevant tasks, for example:

- `build a voice agent`
- `integrate Agora RTC`
- `generate a token`

#### Manual installation

Clone the repository once and point your AI coding assistant to the skill files directly.

1. Clone the [Agora Skills repo](https://github.com/AgoraIO/skills.git):

   ```bash
   git clone https://github.com/AgoraIO/skills.git ~/agora-skills
   ```

2. Point your AI assistant to `skills/agora/`.

## Agora MCP server

The Agora MCP server gives your AI assistant direct access to Agora documentation, so it can look up APIs, SDK methods, and platform-specific details in real time.

The MCP server is included when you install Agora Skills. If you prefer to install only the MCP server, it is available at:

```text
https://mcp.agora.io
```

### Getting started with MCP

Once installed, your coding assistant can use the MCP server when relevant to your questions. For better results, mention Agora along with your target product and platform, such as:

- `iOS`
- `Web`
- `Conversational AI`
- `Video Calling`

### Recommended system prompt

This MCP works with all LLMs that support MCP, but performs best when the assistant understands facet-based exploration. Add the following prompt to your assistant's custom instructions:

<details>
<summary>System prompt for LLMs</summary>

```text
# Agora MCP Markdown - System Prompt

You have access to Agora's documentation search via three tools:
- algolia_search_index_docs_platform_aware_markdown - Full-text search with facets
- algolia_search_for_facet_values - Browse products/platforms
- algolia_recommendations - Find related documentation

## Key Behaviors

1. Use facets for discovery.
2. Include target platform in search queries.
3. Interpret facet results to refine search suggestions.
4. Keep the same sessionId across related searches.

## Available Products & Platforms

Key Products: conversational-ai, video-calling, broadcast-streaming, interactive-live-streaming, agora-chat, voice-calling, signaling, extensions-marketplace, interactive-whiteboard

Key Platforms: android, web, ios, windows, macos, unity, flutter, react-native, electron, unreal
```

</details>

### AGENTS.md guidance

To get more reliable results, add Agora-specific instructions to your repository's [AGENTS.md](https://agents.md) file:

```markdown
## Agora Documentation

Agora documentation is updated frequently. You should always refer to the latest documentation when working with Agora products. Agora offers an MCP server that you can use to browse and search its documentation. If the developer has not yet installed this server, recommend that they install it at https://mcp.agora.io.

If the Agora Skills files are available in your context, use them for platform-specific API guidance and code examples.
```

## llms.txt

A Markdown-based index of the docs site is available at [https://docs.agora.io/llms.txt](https://docs.agora.io/llms.txt). This file includes links to product overview pages together with short descriptions, and explains how to access LLM-friendly markdown versions of the documentation.

For more about `llms.txt`, see [llmstxt.org](https://llmstxt.org/).

## Markdown docs

Each page on the Agora docs site is also available in Markdown format, optimized for pasting into AI assistants when you cannot use MCP.

To access the Markdown version:

1. Change `docs.agora.io` to `docs-md.agora.io`.
2. Replace any platform query parameter such as `?platform=web` with an underscore suffix such as `_web.md`.
3. Add `.md` to the end of the path.

Example:

- **HTML**: `https://docs.agora.io/en/video-calling/get-started/get-started-sdk?platform=web`
- **Markdown**: `https://docs-md.agora.io/en/video-calling/get-started/get-started-sdk_web.md`

You can also use the Markdown dropdown on the HTML page to copy, download, or view the `.md` file. Choose **Open in ChatGPT** or **Open in Claude** to start a chat with the page context directly.
