## What this category includes

Based on the current Shengwang documentation structure, media services cover recording, pushing, pulling, transcoding, and gateway-style delivery features that extend a realtime session into a production media workflow.

## When to move into media services

### Your RTC or AI flow already works

Once the live session path is stable and you need to record, publish, ingest, or transform media, media services become the next logical area.

### You need production delivery workflows

If the requirement now includes archive, replay, broadcast distribution, protocol conversion, or external media ingestion, this category is usually the right follow-up path.
