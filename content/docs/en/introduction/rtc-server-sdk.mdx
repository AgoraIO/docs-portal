![Server Gateway overview](/images/server-gateway/server-gateway-overview.png)

RTC Server SDK is a self-hosted server-side media path that enables backend applications to send, receive, and control audio and video streams with apps built on Agora's Voice and Video SDKs. It lets cloud applications use Agora's global realtime network while keeping infrastructure control on the server side.

## Common scenarios

- call centers and service backends
- network testing and synthetic participants
- AI-powered interactive classes and media automation
- server-side media injection, mixing, and routing

## Key capabilities

<CardGrid>
  <FeatureCard title="Support for call centers, education, and testing">
    Fit scenarios such as call centers, network testing, and AI-powered interactive classes with a single server-side codebase.
  </FeatureCard>
  <FeatureCard title="Multi-format sending and receiving">
    Support sending and receiving YUV, PCM, and encoded audio and video formats for greater flexibility in server-side media workflows.
  </FeatureCard>
  <FeatureCard title="Configurable sending and receiving processes">
    Send and receive media simultaneously, or operate in send-only or receive-only modes. The service also supports pushing media streams directly to a CDN.
  </FeatureCard>
  <FeatureCard title="Multi-channel sending and receiving">
    Send and receive media streams across multiple channels at the same time from the same backend system.
  </FeatureCard>
  <FeatureCard title="Audio mixing and media encryption">
    Mix multiple audio streams and apply media encryption for more controlled and secure server-side participation.
  </FeatureCard>
  <FeatureCard title="Restrict media zones">
    Restrict media to selected zones so traffic connects only to Agora servers in those regions, regardless of where end users are located.
  </FeatureCard>
</CardGrid>
