Agora CLI is Agora's command-line tool for local setup. If your first goal is to get an Agora demo running, this is the first tool to install. It takes you from account login to a working starter app, then helps with project switching, credential export, and diagnosis when something fails.

## Install the Agora CLI

The CLI is distributed as a native Go binary.

<Tabs>
<TabsList>
  <TabsTrigger value="mac-linux">macOS and Linux</TabsTrigger>
  <TabsTrigger value="windows-powershell">Windows (PowerShell)</TabsTrigger>
</TabsList>

<TabsContent value="mac-linux">

```bash
curl -fsSL https://raw.githubusercontent.com/AgoraIO/cli/main/install.sh | sh -s -- --add-to-path
agora --help
```

If `agora` is not available after installation, run the installer again with `--add-to-path` or add the install directory to your shell profile manually.

</TabsContent>

<TabsContent value="windows-powershell">

```powershell
irm https://raw.githubusercontent.com/AgoraIO/cli/main/install.ps1 | iex
agora --help
```

If your execution policy blocks inline scripts, download `install.ps1` and run:

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

</TabsContent>
</Tabs>

## Fastest use

For the shortest local setup path, initialize an official starter and run it locally.

<Tabs>
<TabsList>
  <TabsTrigger value="typescript">TypeScript</TabsTrigger>
  <TabsTrigger value="python">Python</TabsTrigger>
  <TabsTrigger value="go">Go</TabsTrigger>
</TabsList>

<TabsContent value="typescript">

```bash
agora login
agora init my-nextjs-demo --template nextjs
cd my-nextjs-demo
pnpm install
pnpm dev
```

</TabsContent>

<TabsContent value="python">

```bash
agora login
agora init my-python-demo --template python
cd my-python-demo
bun install
bun run dev
```

</TabsContent>

<TabsContent value="go">

```bash
agora login
agora init my-go-demo --template go
cd my-go-demo
make setup
make dev
```

</TabsContent>
</Tabs>

If that works, you can move on to application-specific work. If not, use the commands below to inspect project state and credentials.

## What the CLI handles

Most work with the CLI falls into a small set of repeatable tasks. It is easier to think of them as a short command flow rather than as a reference table.

### Sign in

Use this first when a machine has not been authenticated yet.

```bash
agora login
```

### Bootstrap a starter

Use `agora init` when you want the CLI to clone an official starter, bind it to a project, and write the right environment file in one step.

```bash
agora init my-demo --template nextjs
```

### Create or switch projects

Use these commands when you are building from scratch or need to change which Agora project later commands should target.

```bash
agora project create my-project --feature rtc --feature convoai
agora project use my-project
```

### Export credentials

Use this when you need project credentials in a shell-friendly format for local setup or debugging.

```bash
agora project env --shell
```

### Diagnose setup problems

Use this when the starter runs incorrectly and you want the CLI to check readiness, credentials, and feature enablement.

```bash
agora project doctor
```

For build-from-scratch paths, you usually create or switch projects first, then export credentials into the local environment.
