![Interactive Whiteboard overview](/images/interactive-whiteboard/interactive-whiteboard-overview.png)

Interactive Whiteboard enables realtime visual collaboration with features such as drawing, annotation, and document sharing on a shared digital canvas. It integrates with voice, video, and live streaming to support remote learning, brainstorming, collaborative meetings, and similar visual workflows.

## Common scenarios

- remote learning and online education
- brainstorming and collaborative meetings
- shared annotation and explanation
- document presentation and visual collaboration

## Key capabilities

<CardGrid>
  <FeatureCard title="Editing and room tools">
    Includes standard tools for drawing, writing, notation, and erasing, along with advanced tools for content sharing, multi-user editing, control, room management, and more.
  </FeatureCard>
  <FeatureCard title="File conversion">
    Server-side file conversion prepares content for whiteboard presentation, including PPT, PPTX, Word, and PDF to image conversion, plus PPTX to webpage workflows.
  </FeatureCard>
  <FeatureCard title="Extensions">
    Powerful extensions can expand the whiteboard experience with richer functionality, while extension management tooling helps load and manage them in the whiteboard runtime.
  </FeatureCard>
  <FeatureCard title="SDK options">
    Choose between Interactive Whiteboard SDK for deeper customization and Fastboard SDK for a faster build with a ready-to-use UI.
  </FeatureCard>
  <FeatureCard title="RESTful APIs">
    RESTful APIs support token generation, room management, screenshot management, scene management, and file conversion.
  </FeatureCard>
  <FeatureCard title="Stability and reliability">
    Agora's globally distributed clustered server system, backup strategy, and disaster recovery planning work together to keep the whiteboard service highly available.
  </FeatureCard>
</CardGrid>
