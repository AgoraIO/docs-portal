Agora MCP is an MCP server for live Agora documentation access inside your coding tool. It lets an assistant search current docs while generating code, checking APIs, or troubleshooting. If your agent is about to implement against Agora APIs or compare product paths, this is usually the next tool to install after the CLI.

## Install the MCP server

`Agora MCP` is included when you install [Agora Skills](/en/introduction/agora-skills), but you can also install the MCP server on its own:

```text
https://mcp.agora.io
```

## Fastest use

Install the server in your coding tool, then ask the agent to search Agora docs before writing code.

```text
Use Agora MCP to find the current web quickstart for Conversational AI and explain the minimum setup for a browser voice demo.
```

## When MCP helps

MCP is most useful when the risky part of the task is documentation freshness. That usually means the agent needs to confirm the latest SDK methods, parameters, and error-handling guidance, compare product or platform paths before implementation, or read the official quickstart before generating code. In debugging, it is especially useful because it replaces stale assumptions with current product documentation.

You will usually get better results if your prompt names three things clearly: the Agora product, the target platform, and the task type. A request like “use Agora MCP to check the current Web quickstart for Conversational AI” works better than a generic request because it narrows both the search space and the expected output.

If your repository includes `AGENTS.md` or similar instructions, tell the coding agent to prefer Agora MCP for product-specific lookups. This makes the docs check part of the normal workflow instead of an optional extra step.

When an MCP client is not available, these fallback resources still help:

- `https://docs.agora.io/llms.txt`
- `https://docs-md.agora.io/...` for Markdown page versions
