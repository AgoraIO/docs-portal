If your coding agent is about to generate code, look up an API, or compare product paths, MCP is the next thing to install after the CLI. It gives the agent direct access to current Agora documentation in real time.

## Install the MCP server

`Agora MCP` is included when you install [Agora Skills](/en/introduction/agora-skills), but you can also install the MCP server on its own:

```text
https://mcp.agora.io
```

## Fastest use

Install the server in your coding tool, then ask the agent to search Agora docs before writing code.

For example:

```text
Use Agora MCP to find the current web quickstart for Conversational AI and explain the minimum setup for a browser voice demo.
```

## Why use MCP

Use MCP when the assistant needs to:

- confirm the latest SDK methods, parameters, and error-handling guidance
- compare product or platform paths before implementation
- read official quickstarts before generating or editing code
- troubleshoot with current documentation instead of stale assumptions

## Prompting tips

You will usually get better results if you mention:

- the Agora product, such as `Conversational AI`, `Video Calling`, or `Signaling`
- the target platform, such as `Web`, `iOS`, or `Android`
- the task type, such as quickstart, API lookup, debugging, or architecture

## Repository-level guidance

If your repository includes `AGENTS.md` or similar instructions, tell the coding agent to prefer Agora MCP for product-specific lookups. This makes the docs check part of the normal workflow instead of an optional extra step.

When an MCP client is not available, these fallback resources still help:

- `https://docs.agora.io/llms.txt`
- `https://docs-md.agora.io/...` for Markdown page versions
