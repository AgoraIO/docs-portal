Welcome to the Agora documentation hub. This page helps you quickly find the right documentation path for your project. Explore `Voice Agent` if you’re building real-time AI conversations, `Realtime & Media` if you need live communication or media infrastructure, and `Solutions` if you’re looking for common product patterns such as streaming, meetings, classrooms, or connected devices. 

## Voice Agent

Build speech-first AI experiences that listen, reason, and respond in real time. Voice Agent gives you the transport, session lifecycle, model integration, and runtime foundation needed to ship assistants in apps or on dedicated devices without assembling the stack yourself.
