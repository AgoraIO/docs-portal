See the [Agora platform overview](/en/introduction/about-agora) for the SDK and service architecture. For definitions of App ID, App Certificate, and token, see [Platform concepts](/en/introduction/core-concepts#project-credentials-and-authentication).

## How to build

Start with an AI-assisted workflow, or follow a quickstart in code. Both paths cover project setup and a first working session.

### Build with AI

[Start with AI](/en/introduction/start-with-ai) explains how to prepare your coding assistant and run an official starter. [Agora Skills](/en/introduction/agora-skills) provides integration guidance, [Agora CLI](/en/introduction/agora-cli) handles project setup and diagnostics, and [Agora MCP](/en/introduction/agora-mcp) provides documentation lookup.
