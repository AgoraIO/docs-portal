RTSA brings realtime audio, video, and signaling to smart devices with a lightweight design optimized for low-resource and battery-powered systems. It supports seamless cross-platform development across mobile, PC, web, and smart displays, and is designed for live streaming, remote control, and interactive IoT applications.

## Common scenarios

- smart cameras and video doorbells
- smart displays, wearables, and embedded terminals
- device-to-device media interop and remote control
- interactive IoT products with realtime media

## Key capabilities

<CardGrid>
  <FeatureCard title="Highly integrated">
    IoT SDK integrates both realtime communication and signaling services so you can build features like live streaming and remote control in the same runtime.
  </FeatureCard>
  <FeatureCard title="Lightweight design">
    Designed for low-resource embedded systems, the package footprint can be as small as `400 kB`, reducing pressure on constrained devices.
  </FeatureCard>
  <FeatureCard title="Low power consumption">
    Low hardware requirements make RTSA suitable for battery-powered devices such as video doorbells and similar endpoints.
  </FeatureCard>
  <FeatureCard title="Cross-platform">
    Compatible with Web, mobile, PC, and smart displays while supporting a wide range of chipsets and operating systems.
  </FeatureCard>
  <FeatureCard title="Excellent resistance to poor networks">

  </FeatureCard>
  <FeatureCard title="Interoperable with the full Agora platform">
