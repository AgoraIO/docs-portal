Recording captures live interaction content for archive, replay, review, compliance, and post-session analysis. You can choose a managed cloud recording path through RESTful APIs or a self-managed Linux deployment for on-premise recording workflows.

## Cloud Recording

Cloud Recording is a RESTful API-based solution for recording realtime voice, video, and interactive streaming sessions directly to your cloud storage. It supports customizable recording layouts, multiple file formats, and redundant recorder strategies for higher reliability.

### Cloud Recording features

<CardGrid>
  <FeatureCard title="High reliability">
    Supports globally distributed cluster deployment and can automatically back up files on Agora's cloud servers when third-party cloud storage fails.
  </FeatureCard>
  <FeatureCard title="Advanced security">
    Provides end-to-end security mechanisms for voice and video calls, data transmission, and storage.
  </FeatureCard>
  <FeatureCard title="Broad compatibility">
    Supports major third-party cloud storage providers including Amazon S3, Alibaba Cloud, Tencent Cloud, Kingsoft Cloud, Qiniu Cloud, Microsoft Azure, Google Cloud, Huawei Cloud, and Baidu AI Cloud.
  </FeatureCard>
  <FeatureCard title="Ease of use">
    RESTful APIs make it straightforward to start, stop, and query recordings with a relatively simple integration model.
  </FeatureCard>
</CardGrid>

## On-Premise Recording

On-Premise Recording is a Linux-deployed recording component for recording audio and video calls or live broadcasts into MP4 files. It is suited to teams that want self-managed infrastructure, flexible deployment, and more control over layouts, capture scope, and local outputs.

### On-Premise Recording features

<CardGrid>
  <FeatureCard title="Flexible recording modes">
    Choose between single-stream recording for separate MP4 files per UID or converged recording for combined audio and video in one MP4 output.
  </FeatureCard>
  <FeatureCard title="Comprehensive media support">
    Record audio only, video only, or both together, with compatibility across Agora RTC Native, framework, and Web SDK versions supported by the source product.
  </FeatureCard>
  <FeatureCard title="Advanced layout control">
    Configure mixed-stream layouts, define user positions and sizes on the canvas, and set background images in converged recording mode.
  </FeatureCard>
  <FeatureCard title="Selective recording">
    Record specific UIDs and apply text, timestamp, or static image watermarks to recorded video files.
  </FeatureCard>
  <FeatureCard title="Enterprise-grade infrastructure">
    Deploy on supported Linux distributions with cluster support, proxy configuration, cloud proxy services, and end-to-end security for encrypted channels.
  </FeatureCard>
  <FeatureCard title="Local screenshot capture">
    Capture JPG screenshots from live streams to local paths and access raw video data in YUV, JPG, and encoded frame formats.
  </FeatureCard>
</CardGrid>
