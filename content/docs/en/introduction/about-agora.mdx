Agora provides SDKs and cloud services for real-time voice, video, and AI conversations. You can connect people with each other or with AI agents through two interaction models:

- **Human-to-human** communication uses **Realtime Communication (RTC)** for voice calls, video calls, and live streaming.
- **Human-to-agent** interaction connects a person with a **voice agent** for a live conversation.

**Conversational AI Engine** is Agora's product for building voice agents. It runs conversations using your configured models and tools, while **RTC** carries the live audio between the user and the agent.

![Two peer scenarios: people communicate with each other using RTC, or with an AI agent built with Conversational AI Engine. Both use Agora's real-time media connection.](/images/developer-journey/interaction-models-overview.svg)

## How the Agora platform works

Real-time conversations require continuous audio or video capture, delivery, and playback between connected participants. Your application provides the user interface and business logic: client SDKs capture and play media, your backend manages access and sessions, and Agora services carry media between participants. For voice agents, Conversational AI Engine also uses your configured models and tools to generate responses.

### How people connect with RTC

![RTC clients receive credentials from your backend, join the same channel, and publish and subscribe to live audio and video.](/images/developer-journey/rtc-connection.svg)

Clients in the same Agora project join the same **channel**, a logical group for exchanging media. **Publishing** sends audio or video; **subscribing** receives it. In a two-way call, both people publish and subscribe. In a live stream, hosts publish and audiences subscribe. See the [Realtime Communication overview](/en/realtime-media/rtc) for the integration details.

### How people connect with a voice agent

![Your backend uses the Agent SDK to start or stop the Agora-hosted Conversational AI Engine session. The agent joins the RTC channel and exchanges audio with the client.](/images/developer-journey/voice-agent-connection.svg)

Your backend uses the **Agent SDK** to start and stop a session. The Agora-hosted **Conversational AI Engine** adds an agent to the RTC channel and uses your configured models and tools to respond. The person's client and the agent exchange audio through RTC.

The same application can support **human-to-human** and **human-to-agent** interaction. See the [Voice Agent overview](/en/ai) for model options, business tools such as [MCP tools](/en/ai/build/mcp-tools), and app or device integrations.

## How other services fit in

RTC carries the live audio and video. Conversational AI Engine adds the voice agent. These services extend that interaction with application data, media processing, or connections to other systems. Add the services your application needs.

| Product or integration | How it connects to your application |
| --- | --- |
| [Signaling](/en/realtime-media/rtm) | Exchanges application messages, presence, and shared state alongside RTC audio and video. |
| [Chat](/en/realtime-media/im) | Adds persistent one-to-one or group messaging alongside voice and video calls. |
| [Interactive Whiteboard](/en/realtime-media/whiteboard) | Adds a shared canvas for drawing and document collaboration while participants talk through RTC. |
| [Cloud Recording](/en/realtime-media/cloud-recording) | Records RTC audio and video, including [agent conversations](/en/ai/best-practices/record-agent-conversation), to cloud storage. |
| [Speech-to-Text](/en/realtime-media/speech-to-text) | Converts RTC audio into live transcripts, captions, or translated text. |
| [Cloud Transcoding](/en/realtime-media/transcoding) | Mixes and transcodes RTC audio and video, then publishes processed streams back to RTC channels. |
| [Media Pull](/en/realtime-media/media-pull) | Injects online media streams into RTC channels. |
| [Media Gateway](/en/realtime-media/rtmp-gateway) | Connects RTMP or SRT media sources to RTC channels. |
| [Media Push](/en/realtime-media/media-push) | Sends RTC audio and video to a CDN or external streaming platform. |
| [Server Gateway](/en/realtime-media/rtc-server-sdk) | Lets your server application send and receive audio and video in RTC channels. |
| [SIP integration](/en/ai/studio/deploy/sip-trunk) | Connects phone users with voice agents for inbound and outbound calls through a SIP trunk. |
| [Agora Analytics](/en/realtime-media/agora-analytics/product-overview) | Analyzes RTC call usage and quality to help diagnose connection and media issues. |

Browse the [related services directory](/en/realtime-media/overview) for more options.

Your project identifies your application, and each service defines its own authentication requirements. For project credentials, and for what your client and backend each handle, see [Platform concepts](/en/introduction/core-concepts).

## How to build

Choose a development workflow after identifying the interaction your application needs. AI-assisted development and direct coding can both produce RTC or Voice Agent applications.

### Build with AI

Three tools support your coding assistant during development:

| Tool | Role |
| --- | --- |
| [Agora Skills](/en/introduction/agora-skills) | Provides Agora-specific workflow and implementation guidance. |
| [Agora CLI](/en/introduction/agora-cli) | Prepares a supported starter, configures projects, and diagnoses setup problems. |
| [Agora MCP](/en/introduction/agora-mcp) | Lets your coding assistant look up Agora documentation. |

[Start with AI](/en/introduction/start-with-ai) combines these tools into a development workflow. A **coding assistant** helps you write the application; a **voice agent** talks with users inside the application. Documentation MCP serves the coding assistant, while runtime MCP tools serve the voice agent.

### Build with code

Use RTC client SDKs to connect people to media and Agent SDKs to control Conversational AI Engine sessions from your backend. Start with the [Voice Agent quickstart](/en/ai/get-started/quickstart), or the RTC [voice](/en/realtime-media/rtc/voice-quickstart) or [video](/en/realtime-media/rtc/get-started-sdk) quickstart.

### Build in Console

The [No-code agent builder](/en/ai/studio/quickstart) lets you configure and test an agent visually in Agora Console. This workflow is available for Voice Agent only.
