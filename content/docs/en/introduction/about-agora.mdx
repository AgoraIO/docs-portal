Agora is a realtime engagement platform built on low-latency session infrastructure, messaging and state synchronization, conversational AI orchestration, and media services that help you capture, transform, and analyze live communication.

## The platform in four layers

- **Realtime sessions:** Voice Calling, Video Calling, Broadcast Streaming, and IoT SDK all describe the same underlying need: keep people, devices, or audiences connected with low latency and stable media delivery.
- **Messaging and state:** Signaling adds realtime metadata synchronization, message channels, topics, presence, storage, and locking so apps can coordinate users and workflows beyond raw media.
- **Conversational intelligence:** Conversational AI Engine layers ASR, LLM, TTS, interruption handling, memory, and agent control on top of the realtime session model.
- **Media services and operations:** Cloud Recording, On-Premise Recording, Cloud Transcoding, Interactive Whiteboard, and Analytics extend the live path with capture, layout processing, collaboration, monitoring, and governance.

## What teams usually build

- Voice, video, and live-broadcast apps built on low-latency sessions.
- AI assistants, copilots, tutors, support agents, and other voice-driven conversational products.
- Messaging, presence, and event-driven coordination flows that complement live media.
- Recording, transcoding, captioning, whiteboard, and analytics workflows that turn a live session into a production-ready system.
