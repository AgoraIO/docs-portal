This is a sample guide for testing documentation versions. No real product configuration is required.

## Before you start

Choose an empty local directory for your sample workspace.

## Configure the workspace

1. Create a `workspace.json` file.
2. Give the workspace a name.
3. Enable the sample guide’s new workflow.

```json
{
  "name": "sample-workspace",
  "workflow": "new"
}
```
