Agora Skills is a product-aware instruction pack for coding agents. It helps an assistant choose the right Agora workflow, follow official build paths, and avoid mixing unrelated setup steps. If your agent can already read docs but still struggles to decide what to build or which starter to use, Skills is the next layer to add.

## Install Agora Skills

<Tabs>
<TabsList>
  <TabsTrigger value="skills-cli">Skills CLI</TabsTrigger>
  <TabsTrigger value="manual">Manual installation</TabsTrigger>
</TabsList>

<TabsContent value="skills-cli">

```bash
npx skills add github:AgoraIO/skills
```

Skills activate automatically when the agent detects a relevant Agora task.

</TabsContent>

<TabsContent value="manual">

Clone the repository and point your coding assistant to the Agora skill files:

```bash
git clone https://github.com/AgoraIO/skills.git ~/agora-skills
```

Use `skills/agora/` as the directory entry point, or load `SKILL.md` directly if your tool expects a single root file.

</TabsContent>
</Tabs>

## Fastest use

Install Skills, then ask the agent to choose the correct Agora path before it starts scaffolding or editing code.

```text
Use Agora Skills and Agora MCP to help me build a web-based conversational AI demo.
Check the official docs first, choose the right starter, and use the Agora CLI for setup.
```

## When Skills helps

Skills is useful when documentation lookup alone is not enough. It teaches the agent how Agora work is organized: which product path a task belongs to, which official starter is most relevant, and which setup sequence should happen before custom code starts.

That makes it most valuable when the hard part of the task is choosing the correct Agora product path, selecting the right starter, or following a multi-step setup flow that mixes docs lookup with local execution. It is also useful in troubleshooting when product context matters as much as API syntax.

Skills works especially well together with [Agora MCP](/en/introduction/agora-mcp). MCP helps the agent read fresh documentation, while Skills helps it decide how to use that information in an Agora-specific workflow.
