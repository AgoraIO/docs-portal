<a id="class_extensioncontext__prototype"></a>

```java
public class ExtensionContext {
  public boolean isValid;
  public int uid;
  public String providerName;
  public String extensionName;
}
```

<a id="class_extensioncontext__parameters"></a>

## 属性

### `isValid`

`uid` 是否有效：

- true： uid 有效。
- false： uid 无效。

### `uid`

用户 ID。0 表示本地用户，大于 0 表示远端用户。

### `providerName`

扩展提供方的名称。

### `extensionName`

扩展的名称。
