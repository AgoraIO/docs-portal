### `自从`

自 v4.4.0 版本新增。

<a id="enum_rtevideorendermode__parameters"></a>

## 枚举值

### `HIDDEN`

（0）：按比例缩放视频尺寸，优先填满视口。若视频尺寸与视口不一致，超出部分将被裁剪。

### `FIT`

（1）：按比例缩放视频尺寸，优先完整显示视频内容。若视频尺寸与视口不一致，未填满区域将显示黑边。
