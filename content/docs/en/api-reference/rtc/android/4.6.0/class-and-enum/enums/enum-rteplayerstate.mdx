### `自从`

自 v4.4.0 版本新增。

<a id="enum_rteplayerstate__parameters"></a>

## 枚举值

### `IDLE`

（0）：空闲状态。

### `OPENING`

（1）：正在打开 URL 资源。调用 [openWithUrl](/en/api-reference/rtc/android/playback/rte-player#api_player_openwithurl) 后会返回该状态码。

### `OPEN_COMPLETED`

（2）：已成功打开 URL 资源。 [openWithUrl](/en/api-reference/rtc/android/playback/rte-player#api_player_openwithurl) 成功打开资源后会返回该状态码。

### `PLAYING`

（3）：正在播放。

### `PAUSED`

（4）：播放已暂停。成功调用 [pause](/en/api-reference/rtc/android/playback/rte-player#api_player_pause_player) 后会返回该状态码。

### `PLAYBACK_COMPLETED`

（5）：播放已完成。

### `STOPPED`

（6）：播放已停止。成功调用 [stop](/en/api-reference/rtc/android/playback/rte-player#api_player_stop_player) 后会返回该状态码。

### `FAILED`

（7）：播放失败。发生内部错误时会返回该状态码。收到该状态后需先调用 [stop](/en/api-reference/rtc/android/playback/rte-player#api_player_stop_player)，再调用 [openWithUrl](/en/api-reference/rtc/android/playback/rte-player#api_player_openwithurl) 重新打开资源。
