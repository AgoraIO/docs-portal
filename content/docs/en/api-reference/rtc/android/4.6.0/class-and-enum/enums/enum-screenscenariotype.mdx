## 枚举值

### `SCREEN_SCENARIO_DOCUMENT`

（1）：文档场景。优先保证屏幕共享的视频质量，并降低接收端的共享视频延迟。适用于共享文档、幻灯片和表格的场景。

### `SCREEN_SCENARIO_GAMING`

（2）：游戏场景。优先保证屏幕共享的流畅性。适用于共享游戏的场景。

### `SCREEN_SCENARIO_VIDEO`

（3）：视频场景。优先保证屏幕共享的流畅性。适用于共享电影或直播视频的场景。
