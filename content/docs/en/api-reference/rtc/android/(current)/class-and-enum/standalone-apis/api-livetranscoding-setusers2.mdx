<a id="api_livetranscoding_setusers2__prototype"></a>

```java
public void setUsers(Map<Integer, TranscodingUser> users)
```

<a id="api_livetranscoding_setusers2__detailed_desc"></a>

该方法用于批量设置所有参与 CDN 推流的用户，并用新的用户数据替换旧的数据。

<a id="api_livetranscoding_setusers2__parameters"></a>

## 参数

### `users`

所有参与 CDN 推流的用户。详见 [TranscodingUser](/en/api-reference/rtc/android/class-and-enum/classes/class-transcodinguser)。
