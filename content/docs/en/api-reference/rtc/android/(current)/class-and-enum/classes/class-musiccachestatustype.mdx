<a id="class_musiccachestatustype__prototype"></a>

```java
class MusicCacheStatusType {
  public static final int MUSIC_CACHE_STATUS_TYPE_CACHED = 0;
  public static final int MUSIC_CACHE_STATUS_TYPE_CACHING = 1;
}
```

<a id="class_musiccachestatustype__parameters"></a>

## 属性

### `MUSIC_CACHE_STATUS_TYPE_CACHED`

（0）：音乐资源已缓存。

### `MUSIC_CACHE_STATUS_TYPE_CACHING`

（1）：音乐资源正在缓存。
