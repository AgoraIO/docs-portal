Conversational AI REST API requests require authentication. Use one of the following methods:

- **[Token authentication](#token-authentication) (recommended)**: Generate a token with your App ID and App Certificate, and set `Authorization: agora token=<your_token>`.
- **[Basic HTTP authentication](#basic-http-authentication)**: Generate a Base64-encoded credential from your customer ID and customer secret, and set `Authorization: Basic <base64_credentials>`.

:::info
Implement authentication on the server to mitigate the risk of data leakage.
:::

## Token authentication

Token authentication uses a token generated on your server with your App ID and App Certificate. To authenticate with a token, include the `Authorization` header in each request:

```text
Authorization: agora token=<your_token>
```

### Prerequisites

Before you begin, get the following values from [Agora Console](https://console.agora.io):

- **App ID**: A unique string that identifies your project.
- **App Certificate**: A string used to generate tokens.

:::warning
Never expose your App Certificate in client-side code or public repositories. Generate tokens on your server only.
:::

The Agora RESTful API only supports HTTPS with TLS 1.0, 1.1, or 1.2 for encrypted communication. Requests over plain HTTP are not supported and will fail to connect.

Tokens expire after a maximum of 86400 seconds.

### Use the token

Put the same token in both of the following places:

- **`Authorization` header**: The token authenticates the REST API request.
- **`properties.token` in the request body**: The token lets the agent join the RTC channel.

The token parameters must match the agent request:

- `channelName` must match `properties.channel`.
- The account or UID must match `properties.agent_rtc_uid`.

### Use a temporary token for testing

For testing, you can generate a temporary token in Agora Console. A temporary token is valid for 24 hours. For details, see [Credentials](/en/introduction/console-setup#credentials). Use the channel name you entered when you generated the token as `properties.channel` in your request.

In production, generate tokens on your server using the Conversational AI SDK or the token builder library.

### Using the Conversational AI SDK

If you already use the Conversational AI SDK in your project, use the SDK token generation utility to generate tokens. The utility generates a token with the RTC and RTM services. The token parameters must match the agent request:

- `channelName` must match `properties.channel`.
- `uid` must match `properties.agent_rtc_uid`.
- The SDK token utility accepts only numeric UIDs. To use string UIDs, generate the token with the [token builder library](#using-the-token-builder-library) and set `enable_string_uid` to `true` in the request body.

The following examples generate a token with the SDK and use it in the REST API `Authorization` header:

```js tab="Node.js"
const https = require('https');
const { generateConvoAIToken } = require('agora-agents');

// Keep these credentials on the server and never expose them to clients.
const appId = '<your_app_id>';
const appCertificate = '<your_app_certificate>';

const channelName = '<your_channel_name>';
const agentUid = '<your_agent_uid>';
const tokenExpirationInSeconds = 86400;

const token = generateConvoAIToken({
  appId,
  appCertificate,
  channelName,
  uid: Number(agentUid),
  tokenExpire: tokenExpirationInSeconds,
});

const data = JSON.stringify({
  name: '<agent_identifier>',
  pipeline_id: '<your_agents_pipeline_id>',
  properties: {
    channel: channelName,
    token,
    agent_rtc_uid: agentUid,
    remote_rtc_uids: ['<remote_user_uid>'],
    enable_string_uid: false,
  },
});

const options = {
  hostname: 'api.agora.io',
  path: `/api/conversational-ai-agent/v2/projects/${appId}/join`,
  method: 'POST',
  headers: {
    Authorization: 'agora token=' + token,
    'Content-Type': 'application/json',
    'Content-Length': Buffer.byteLength(data),
  },
};

const req = https.request(options, (res) => {
  console.log(`Status code: ${res.statusCode}`);
  res.on('data', (d) => {
    process.stdout.write(d);
  });
});

req.on('error', (error) => {
  console.error(error);
});

req.write(data);
req.end();
```

```go tab="Golang"
package main

import (
	"bytes"
	"encoding/json"
	"fmt"
	"io"
	"log"
	"net/http"
	"strconv"

	"github.com/AgoraIO/agora-agents-go/v2/agentkit"
)

func main() {
	// Keep these credentials on the server and never expose them to clients.
	appID := "<your_app_id>"
	appCertificate := "<your_app_certificate>"

	channelName := "<your_channel_name>"
	agentUID := "<your_agent_uid>"
	tokenExpirationInSeconds := 86400

	uid, err := strconv.Atoi(agentUID)
	if err != nil {
		log.Fatal(err)
	}

	token, err := agentkit.GenerateConvoAIToken(agentkit.GenerateConvoAITokenOptions{
		AppID:          appID,
		AppCertificate: appCertificate,
		ChannelName:    channelName,
		UID:            uid,
		TokenExpire:    tokenExpirationInSeconds,
	})
	if err != nil {
		log.Fatal(err)
	}

	data, err := json.Marshal(map[string]any{
		"name":        "<agent_identifier>",
		"pipeline_id": "<your_agents_pipeline_id>",
		"properties": map[string]any{
			"channel":           channelName,
			"token":             token,
			"agent_rtc_uid":     agentUID,
			"remote_rtc_uids":   []string{"<remote_user_uid>"},
			"enable_string_uid": false,
		},
	})
	if err != nil {
		log.Fatal(err)
	}

	url := fmt.Sprintf("https://api.agora.io/api/conversational-ai-agent/v2/projects/%s/join", appID)
	req, err := http.NewRequest(http.MethodPost, url, bytes.NewReader(data))
	if err != nil {
		log.Fatal(err)
	}
	req.Header.Set("Authorization", "agora token="+token)
	req.Header.Set("Content-Type", "application/json")

	res, err := http.DefaultClient.Do(req)
	if err != nil {
		log.Fatal(err)
	}
	defer res.Body.Close()

	body, err := io.ReadAll(res.Body)
	if err != nil {
		log.Fatal(err)
	}
	fmt.Printf("Status code: %d\n", res.StatusCode)
	fmt.Println(string(body))
}
```

```python tab="Python"
data = json.dumps({
    "name": "<agent_identifier>",
    "pipeline_id": "<your_agents_pipeline_id>",
    "properties": {
        "channel": channel_name,
        "token": token,
        "agent_rtc_uid": agent_uid,
        "remote_rtc_uids": ["<remote_user_uid>"],

request = urllib.request.Request(

    method="POST",

        "Authorization": "agora token=" + token,
        "Content-Type": "application/json",
    },

try:
    with urllib.request.urlopen(request) as response:
        print(f"Status code: {response.status}")
        print(response.read().decode("utf-8"))
except urllib.error.HTTPError as error:
    print(f"Status code: {error.code}")
    print(error.read().decode("utf-8"))
```

### Using the token builder library

The [AgoraDynamicKey repository](https://github.com/AgoraIO/Tools/tree/master/DynamicKey/AgoraDynamicKey) provides open-source token generation libraries for multiple languages, including `ConvoAITokenBuilder` and the ConvoAI service.

Install the token builder library for your language:

The following examples use `ConvoAITokenBuilder.buildToken` to generate a token with the ConvoAI, RTC, and RTM services:

```js tab="Node.js"
const https = require('https');
const { ConvoAITokenBuilder } = require('agora-token');

const appId = '<your_app_id>';
const appCertificate = '<your_app_certificate>';
const channelName = '<your_channel_name>';
const agentUid = '<your_agent_uid>';
const tokenExpire = 86400; // Token lifetime, 24 hours, in seconds
const privilegeExpire = 3600; // RTC and RTM privilege lifetime, 1 hour, in seconds

const token = ConvoAITokenBuilder.buildToken(
  appId,
  appCertificate,
  channelName,
  agentUid,
  tokenExpire,
  privilegeExpire,
);

const options = {
  hostname: 'api.agora.io',
  path: `/api/conversational-ai-agent/v2/projects/${appId}/join`,
  method: 'POST',
  headers: {
    Authorization: 'agora token=' + token,
    'Content-Type': 'application/json',
  },
};

https.request(options).end();
```

The privilege lifetime must not exceed the token lifetime. To set the RTC role or each RTC and RTM privilege separately, use `buildTokenWithPrivilege` (`BuildTokenWithPrivilege` in Go, `build_token_with_privilege` in Python). It also adds the ConvoAI service automatically.

## Basic HTTP authentication

Basic HTTP authentication uses your Agora customer ID and customer secret. Generate a Base64-encoded credential from the `customer_id:customer_secret` string, then include it in the `Authorization` header:

```text
Authorization: Basic <base64_credentials>
```

<include cwd>content/includes/en/shared/console/restful-credentials.mdx</include>

### Generate an authorization header using a third-party tool

For testing and debugging, you can use a [third-party online tool](https://www.debugbear.com/basic-auth-header-generator) to quickly generate your Authorization header. Enter your Customer ID as the Username and your Customer Secret as the Password. Your generated header should look like this:

```text
Authorization: Basic NDI1OTQ3N2I4MzYy...YwZjA=
```

### Generate an authorization header using code

The following examples read your customer ID and customer secret from the `AGORA_CUSTOMER_KEY` and `AGORA_CUSTOMER_SECRET` environment variables, and print the value to use in the `Authorization` header:

```java tab="Java"
import java.nio.charset.StandardCharsets;
import java.util.Base64;

public class BasicAuthHeader {

    public static void main(String[] args) {
        // Read your customer ID and customer secret from environment variables
        String customerKey = System.getenv("AGORA_CUSTOMER_KEY");
        String customerSecret = System.getenv("AGORA_CUSTOMER_SECRET");

        // Join the customer ID and customer secret, then encode them with Base64
        String plainCredentials = customerKey + ":" + customerSecret;
        String base64Credentials = Base64.getEncoder()
                .encodeToString(plainCredentials.getBytes(StandardCharsets.UTF_8));

        // Create the Authorization header value
        String authorizationHeader = "Basic " + base64Credentials;
        System.out.println(authorizationHeader);
    }
}
```

