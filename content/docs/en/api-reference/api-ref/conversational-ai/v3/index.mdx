The Conversational AI REST API v3 lets you save agents, secrets, and phone numbers in your project, and use them to start agent sessions and outbound call campaigns from your server.

## API basics

- **Base URL**: `https://api.agora.io/api/conversational-ai-agent/v3/projects/<appid>`, where `<appid>` is the Agora App ID for your project.
- **Request**: Request and response bodies use JSON.
- **Versioning**: Create, retrieve, and update responses include an `ETag` header. Pass it in the `If-Match` header when an endpoint requires it.
- **Request ID**: Every response includes an `Agora-Request-Id` header. Include it when you contact Agora support.

## REST APIs

The v3 APIs are organized by resource. You save agents, secrets, and phone numbers in your project, then reference them when you start sessions and campaigns.

### Agents

An agent is a saved configuration that defines how your agent behaves, including its instructions, variables, greeting, and the models in its pipeline. Use these endpoints to manage agents that you start sessions and campaigns from.

- [Create an agent](create-agent): Save an agent configuration.
- [List agents](list-agents): Retrieve the agents in your project.
- [Retrieve an agent](retrieve-agent): Retrieve the configuration of an agent.
- [Update an agent](update-agent): Change the configuration of an agent.
- [Delete an agent](delete-agent): Delete an agent.

### Sessions

A session runs one agent in an RTC channel or a phone call. Use these endpoints to start sessions from a saved or inline agent, check their status, and stop them.

- [Start a session](start-session): Start a session with a saved agent.
- [Start an ephemeral session](start-ephemeral-session): Start a session with an agent configuration you pass in the request.
- [List sessions](list-sessions): Retrieve the sessions that match your filters.
- [Retrieve a session](retrieve-session): Retrieve the status of a session.
- [Stop a session](stop-session): Stop a running session.

### Secrets

A secret set stores vendor API keys and other credentials, so your agent configurations reference secrets instead of containing them. Secret values are write-only and are never returned.

- [Create a secret set](create-secret-set): Store credentials in a named secret set.
- [List secret sets](list-secret-sets): Retrieve the secret sets in your project.
- [Retrieve a secret set](retrieve-secret-set): Retrieve the key names in a secret set.
- [Update a secret set](update-secret-set): Add, change, or remove keys.
- [Replace a secret set](replace-secret-set): Replace all the keys in a set.
- [Delete a secret set](delete-secret-set): Delete a set and all its keys.
- [Set a secret key](set-secret-key): Add a key or replace its value.
- [Delete a secret key](delete-secret-key): Remove a key from a set.

### Phone numbers

A phone number connects your agents to the phone network through your SIP trunk. Agents call from a registered number, and you can assign an agent to answer inbound calls to it.

- [Create a phone number](create-number): Register a phone number and its SIP trunk.
- [List phone numbers](list-numbers): Retrieve the phone numbers in your project.
- [Retrieve a phone number](retrieve-number): Retrieve a number and its SIP trunk settings.
- [Update a phone number](update-number): Change the settings of a number.
- [Delete a phone number](delete-number): Remove a number from your project.

### Campaigns

A campaign calls a list of contacts with a saved agent, on a schedule or right away. Each call starts a telephony session. Use these endpoints to create campaigns and control them while they run.

- [Create a campaign](create-campaign): Dial a list of contacts with a saved agent.
- [List campaigns](list-campaigns): Retrieve the campaigns in your project.
- [Retrieve a campaign](retrieve-campaign): Retrieve a campaign and its contact counts.
- [Update a campaign](update-campaign): Change the pacing, schedule, or call settings.
- [Pause a campaign](pause-campaign): Stop placing new calls.
- [Resume a campaign](resume-campaign): Continue dialing a paused campaign.
- [Cancel a campaign](cancel-campaign): End a campaign permanently.
- [Delete a campaign](delete-campaign): Delete a finished or canceled campaign.
