Conversational AI Platform REST API requests require authentication. Use one of the following methods:

- **[Token authentication](#token-authentication) (recommended)**: Generate a token with your App ID and App Certificate, and set `Authorization: agora token=<your_token>`.
- **[Basic HTTP authentication](#basic-http-authentication)**: Generate a Base64-encoded credential from your customer ID and customer secret, and set `Authorization: Basic <base64_credentials>`.

:::info
Implement authentication on the server to mitigate the risk of data leakage.
:::

## Token authentication

Token authentication uses a token generated on your server with your App ID and App Certificate. To authenticate with a token, include the `Authorization` header in each request:

```text
Authorization: agora token=<your_token>
```

### Prerequisites

Before you begin, get the following values from [Agora Console](https://console.agora.io):

- **App ID**: A unique string that identifies your project.
- **App Certificate**: A string used to generate tokens.

:::warning
Never expose your App Certificate in client-side code or public repositories. Generate tokens on your server only.
:::

Tokens expire after a maximum of 86400 seconds.

### Choose the token services

A token grants access to one or more services. The services you need depend on where you use the token:

- **`Authorization` header**: The token authenticates the REST API request. Every request needs this.
- **`transport.token` in the request body**: The token lets the agent join the RTC channel. You pass it when you [start a session](start-session) or [start an ephemeral session](start-ephemeral-session) with an RTC transport, and when you renew it with [Update a session](update-session). Only a token that includes the RTC service with the join channel privilege works here.

| Services | Authenticates REST requests | Lets the agent join the channel | How to generate |
| --- | --- | --- | --- |
| ConvoAI | Yes | No | [Build a token with specific services](#build-a-token-with-specific-services) |
| ConvoAI + RTC | Yes | Yes | [Build a token with specific services](#build-a-token-with-specific-services) |
| ConvoAI + RTC + RTM | Yes | Yes | [Build a ConvoAI token](#build-a-convoai-token) (recommended for RTC sessions) |

A token with the ConvoAI service is enough for every request that doesn't join an RTC channel. These include:

- Managing agents, secrets, phone numbers, and campaigns.
- Listing, retrieving, and stopping sessions.
- Sending session actions, such as Speak.
- Starting telephony sessions.

To start an RTC session, you can use the same token in both places, or generate a separate token for each. If you use separate tokens, put the REST authentication token in the `Authorization` header and the RTC token in `transport.token`.

When the token includes the RTC service, the token parameters must match the session request:

- `channelName` must match `transport.channel`.
- The account or UID must match `transport.uid`.

### Use a temporary token for testing

For testing, you can generate a temporary token in Agora Console. A temporary token is valid for 24 hours. For details, see [Credentials](/en/introduction/console-setup#credentials). When you start an RTC session, use the channel name you entered when you generated the token as `transport.channel` in your request.

In production, generate tokens on your server using the token builder library.

### Using the token builder library

The [AgoraDynamicKey repository](https://github.com/AgoraIO/Tools/tree/master/DynamicKey/AgoraDynamicKey) provides open-source token generation libraries for multiple languages, including `ConvoAITokenBuilder` and the ConvoAI service.

Install the token builder library for your language:


#### Build a ConvoAI token

`ConvoAITokenBuilder.buildToken` generates a token with the ConvoAI, RTC, and RTM services. Use it to start an RTC session, with the same token in the `Authorization` header and in `transport.token`:

```js tab="Node.js"
const { ConvoAITokenBuilder } = require('agora-token');

const appId = '<your_app_id>';
const appCertificate = '<your_app_certificate>';
const channelName = '<your_channel_name>';
const agentUid = '<your_agent_uid>';
const tokenExpire = 86400; // Token lifetime, 24 hours, in seconds
const privilegeExpire = 3600; // RTC and RTM privilege lifetime, 1 hour, in seconds

const token = ConvoAITokenBuilder.buildToken(
  appId,
  appCertificate,
  channelName,
  agentUid,
  tokenExpire,
  privilegeExpire,
);
```

```go tab="Golang"
import "github.com/AgoraIO/Tools/DynamicKey/AgoraDynamicKey/go/src/convoaitokenbuilder"

const tokenExpire = 24 * 60 * 60 // Token lifetime, 24 hours, in seconds
const privilegeExpire = 60 * 60 // RTC and RTM privilege lifetime, 1 hour, in seconds

token, err := convoaitokenbuilder.BuildToken(
	appID,
	appCertificate,
	channelName,
	agentUID,
	tokenExpire,
	privilegeExpire,
)
if err != nil {
	// Handle the error
}
```

```python tab="Python"
from src.convoai_token_builder import ConvoAITokenBuilder

token_expire = 86400     # Token lifetime, 24 hours, in seconds
privilege_expire = 3600  # RTC and RTM privilege lifetime, 1 hour, in seconds

token = ConvoAITokenBuilder.build_token(
    app_id, app_certificate, channel_name, agent_uid, token_expire, privilege_expire
)
```

The privilege lifetime must not exceed the token lifetime. To set the RTC role or each RTC and RTM privilege separately, use `buildTokenWithPrivilege` (`BuildTokenWithPrivilege` in Go, `build_token_with_privilege` in Python). It also adds the ConvoAI service automatically.

#### Build a token with specific services

To control exactly which services a token includes, build it with the `AccessToken2` API. The following examples build a token with the ConvoAI service only. Use this token in the `Authorization` header for requests that don't join an RTC channel:

```js tab="Node.js"
const { AccessToken2, ServiceConvoAI } = require('agora-token/src/AccessToken2');

const tokenExpire = 86400; // Token lifetime, 24 hours, in seconds

const accessToken = new AccessToken2(appId, appCertificate, null, tokenExpire);
accessToken.add_service(new ServiceConvoAI());
const token = accessToken.build();
```

```go tab="Golang"
import accesstoken "github.com/AgoraIO/Tools/DynamicKey/AgoraDynamicKey/go/src/accesstoken2"

const tokenExpire = 24 * 60 * 60 // Token lifetime, 24 hours, in seconds

accessToken := accesstoken.NewAccessToken(appID, appCertificate, tokenExpire)
accessToken.AddService(accesstoken.NewServiceConvoAI())
token, err := accessToken.Build()
```

```python tab="Python"
from src.AccessToken2 import AccessToken, ServiceConvoAI

token_expire = 86400  # Token lifetime, 24 hours, in seconds

access_token = AccessToken(app_id, app_certificate, expire=token_expire)
access_token.add_service(ServiceConvoAI())
token = access_token.build()
```

The following examples build a token with the ConvoAI and RTC services. You can use this token in the `Authorization` header and in `transport.token`. Each RTC privilege lifetime must not exceed the token lifetime:

```js tab="Node.js"
const { AccessToken2, ServiceConvoAI, ServiceRtc } = require('agora-token/src/AccessToken2');

rtc.add_privilege(ServiceRtc.kPrivilegePublishAudioStream, privilegeExpire);
rtc.add_privilege(ServiceRtc.kPrivilegePublishVideoStream, privilegeExpire);
rtc.add_privilege(ServiceRtc.kPrivilegePublishDataStream, privilegeExpire);

accessToken.add_service(rtc);
accessToken.add_service(new ServiceConvoAI());
const token = accessToken.build();
```

### Send a request with a token

The following example lists the agents in your project. It works with a token that has only the ConvoAI service, because it doesn't join an RTC channel:

```bash
curl --request GET \
  --url 'https://preview.ai.agora.io/conversational-ai/v1/projects/<your_app_id>/agents?limit=20' \
  --header 'Authorization: agora token=<your_token>'
```

The following example starts an RTC session with a saved agent, using a token with the ConvoAI, RTC, and RTM services, such as one from [`ConvoAITokenBuilder.buildToken`](#build-a-convoai-token). It uses the same token in the `Authorization` header and in `transport.token`:

```bash
curl --request POST \
  --url https://preview.ai.agora.io/conversational-ai/v1/projects/<your_app_id>/sessions \
  --header 'Authorization: agora token=<your_token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "agent_id": "<your_agent_id>",
    "transport": {
      "type": "rtc",
      "channel": "<your_channel_name>",
      "token": "<your_token>",
      "uid": "1001",
      "subscribe_uids": ["1002"]
    },
    "lifecycle": {
      "idle_timeout_ms": 120000
    }
  }'
```

The token must be generated for `<your_channel_name>` and UID `1001`. To create an agent first, see [Create an agent](create-agent).

## Basic HTTP authentication

Basic HTTP authentication uses your Agora customer ID and customer secret. Generate a Base64-encoded credential from the `customer_id:customer_secret` string, then include it in the `Authorization` header:

```text
Authorization: Basic <base64_credentials>
```

<include cwd>content/includes/en/shared/console/restful-credentials.mdx</include>

### Generate an authorization header using a third-party tool

For testing and debugging, you can use a [third-party online tool](https://www.debugbear.com/basic-auth-header-generator) to quickly generate your Authorization header. Enter your Customer ID as the Username and your Customer Secret as the Password. Your generated header should look like this:

```text
Authorization: Basic NDI1OTQ3N2I4MzYy...YwZjA=
```

### Generate an authorization header using code

The following examples read your customer ID and customer secret from the `AGORA_CUSTOMER_KEY` and `AGORA_CUSTOMER_SECRET` environment variables, and print the value to use in the `Authorization` header:

```java tab="Java"
import java.nio.charset.StandardCharsets;
import java.util.Base64;

public class BasicAuthHeader {

    public static void main(String[] args) {
        // Read your customer ID and customer secret from environment variables
        String customerKey = System.getenv("AGORA_CUSTOMER_KEY");
        String customerSecret = System.getenv("AGORA_CUSTOMER_SECRET");

        // Join the customer ID and customer secret, then encode them with Base64
        String plainCredentials = customerKey + ":" + customerSecret;
        String base64Credentials = Base64.getEncoder()
                .encodeToString(plainCredentials.getBytes(StandardCharsets.UTF_8));

        // Create the Authorization header value
        String authorizationHeader = "Basic " + base64Credentials;
        System.out.println(authorizationHeader);
    }
}
```

```go tab="Golang"
package main

import (
	"encoding/base64"
	"fmt"
	"os"

	customerSecret := os.Getenv("AGORA_CUSTOMER_SECRET")

	// Join the customer ID and customer secret, then encode them with Base64
	plainCredentials := customerKey + ":" + customerSecret
```
