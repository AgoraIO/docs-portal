---
title: "How can I get the URL of the M3U8 file?"
---

The URL of the M3U8 file consists of the domain of your cloud storage and the filename. You can copy the URL in your cloud storage.

![](https://web-cdn.agora.io/docs-files/1556174270602)

You can get the filename of the M3U8 file from the following fields:

- The `fileList` field in the responses of [`query`](/en/cloud-recording/reference/restful-api#query) and [`stop`](/en/cloud-recording/reference/restful-api#stop).
- The `fileList` field in the [`cloud_recording_file_infos`](/en/cloud-recording/reference/rest-api-overview#4-cloud_recording_file_infos) callback event.
