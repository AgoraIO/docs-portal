# Build Conversational AI Engine with the Java SDK

This article introduces beginners to using the Agora Java SDK to build Conversational AI Engine.

The Java SDK is designed to help developers integrate Agora RESTful APIs more easily. The SDK provides the following features:

- Simplified communication: By encapsulating RESTful API request and response handling, it makes communication with RESTful APIs much easier.
- Availability protection: When DNS resolution fails, network errors occur, or requests time out, it automatically switches to the optimal domain name to ensure REST service availability.
- Ease of use: Provides concise and easy-to-understand APIs so that you can easily implement common features such as creating and stopping conversational AI agents.
- Other advantages: Built with Java, it is efficient, concurrent, and extensible.

## Prerequisites

Before you start, make sure that:

- [Java 1.8](https://www.oracle.com/cn/java/technologies/downloads/) or later.
- You have followed [Enable the Service](./enable-service.md) and completed the following steps in the Agora Console:
  - Enable Agora Conversational AI Engine for your project.
  - Get the App ID: a string randomly generated by Agora to identify your project and call the Conversational AI Agent RESTful API.
  - Get the Customer ID and Customer Secret: used for HTTP authentication when calling the Agora Conversational AI Engine RESTful API.
  - Generate a temporary token: A token, also called a dynamic key, is used to authenticate users when they join an RTC channel. A temporary token is valid for 24 hours. In production, refer to [Use Token Authentication](https://doc.shengwang.cn/doc/rtc/android/basic-features/token-authentication) to generate tokens on your app server.
- You have followed [Build a Video Calling App](https://doc.shengwang.cn/doc/rtc/android/get-started/quick-start) to integrate Real-Time Engagement SDK v4.5.1 or later, and implemented basic real-time audio and video capabilities in your app.
- You have obtained the API key and callback URL from your large language model (LLM) provider.
- You have followed the official documentation of your text-to-speech (TTS) provider to obtain authentication information such as token and appid, and understand the relevant parameter configuration.

## Create a Project and Install the SDK

1. Create a Java project in your IDE. Using IntelliJ IDEA as an example, set the project name and save path, and set **Build system** to **Maven**. After that, click **Create**.

2. Add the following lines to the `<dependencies>` section of the `pom.xml` file in your project to add the REST Client dependency:

```xml
<dependencies>
    <dependency>
        <groupId>io.agora</groupId>
        <artifactId>agora-rest-client-core</artifactId>
        <version>0.3.0</version>
    </dependency>
</dependencies>
```

## Build Conversational AI Engine

This section explains the core Java code used to build Conversational AI Engine. You can choose how to read this section based on your needs:

- **Run it quickly**: If you only want to run the sample code quickly and do not care about implementation details, you can copy the full sample code below into `Main.java`, configure the relevant parameters by referring to [Define variables](#define-variables), and then jump to [Talk with the Agent](#talk-with-the-agent).

#### Full `Main.java` Example

```java
package io.agora;

import io.agora.rest.AgoraException;
import io.agora.rest.core.BasicAuthCredential;
import io.agora.rest.core.Credential;
import io.agora.rest.core.DomainArea;
import io.agora.rest.services.convoai.ConvoAIClient;
import io.agora.rest.services.convoai.ConvoAIConfig;
import io.agora.rest.services.convoai.ConvoAIServiceRegionEnum;
import io.agora.rest.services.convoai.req.JoinConvoAIReq;
import io.agora.rest.services.convoai.req.ListConvoAIReq;
import io.agora.rest.services.convoai.res.JoinConvoAIRes;
import io.agora.rest.services.convoai.res.ListConvoAIRes;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;

import java.util.ArrayList;
import java.util.HashMap;
import java.util.Map;

public class Main {
    private static final Logger logger = LoggerFactory.getLogger(Main.class);
    // Agora parameter configuration
    public static final String APP_ID = "<your appId>";
    public static final String CNAME = "<your cname>";
    public static final String AGENT_RTC_UID = "<your agent rtc uid>";
    public static final String USERNAME = "<the username of basic auth credential>";
    public static final String PASSWORD = "<the password of basic auth credential>";
    public static final String AGENT_RTC_TOKEN = "<your agent rtc token>";

    // LLM parameter configuration
    public static final String LLM_URL = "<your LLM URL>";
    public static final String LLM_API_KEY = "<your LLM API Key>";
    public static final String LLM_MODEL = "<your LLM model>";

    // TTS parameter configuration (Bytedance TTS used as an example)
    public static final String TTS_BYTEDANCE_TOKEN = "<your bytedance tts token>";
    public static final String TTS_BYTEDANCE_APP_ID = "<your bytedance tts app id>";
    public static final String TTS_BYTEDANCE_CLUSTER = "<your bytedance tts cluster>";
    public static final String TTS_BYTEDANCE_VOICE_TYPE = "<your bytedance tts voice type>";

    public static void main(String[] args) throws Exception {
        Credential credential = new BasicAuthCredential(USERNAME, PASSWORD);
        ConvoAIConfig config = ConvoAIConfig.builder().
                appId(APP_ID).
                credential(credential).
                domainArea(DomainArea.CN).
                serverRegion(ConvoAIServiceRegionEnum.CHINESE_MAINLAND).
                build();

        ConvoAIClient convoAIClient = ConvoAIClient.create(config);

        String name = APP_ID + ":" + CNAME;

        JoinConvoAIRes joinConvoAIRes;
        try {
            joinConvoAIRes = convoAIClient.join(JoinConvoAIReq.builder()
                    .name(name)
                    .properties(JoinConvoAIReq.Properties.builder()
                            .token(AGENT_RTC_TOKEN)
                            .channel(CNAME)
                            .agentRtcUId(AGENT_RTC_UID)
                            .remoteRtcUIds(new ArrayList<String>() {
                                {
                                    add("*");
                                }
                            })
                            .enableStringUId(false)
                            .idleTimeout(120)
                            .advancedFeatures(JoinConvoAIReq.AdvancedFeatures.builder()
                                    .enableAIVad(true)
                                    .build())
                            .llmPayload(JoinConvoAIReq.LLMPayload.builder()
                                    .url(LLM_URL)
                                    .apiKey(LLM_API_KEY)
                                    .params(new HashMap<String, Object>() {
                                        {
                                            put("model", LLM_MODEL);
                                            put("max_tokens", 1024);
                                            put("username", "Jack");
                                        }
                                    })
                                    .systemMessages(new ArrayList<Map<String, Object>>() {
                                        {
                                            add(new HashMap<String, Object>() {
                                                {
                                                    put("content", "You are a helpful chatbot.");
                                                    put("role", "system");
                                                }
                                            });
                                        }
                                    })
                                    .maxHistory(30)
                                    .greetingMessage("Hello, how can I help you?")
                                    .build())
                            .ttsPayload(JoinConvoAIReq.TTSPayload.builder()
                                    .vendor(JoinConvoAIReq.TTSVendorEnum.BYTEDANCE)
                                    .params(JoinConvoAIReq.BytedanceTTSVendorParams.builder().
                                            token(TTS_BYTEDANCE_TOKEN).
                                            cluster(TTS_BYTEDANCE_CLUSTER).
                                            voiceType(TTS_BYTEDANCE_VOICE_TYPE).
                                            appId(TTS_BYTEDANCE_APP_ID).
                                            speedRatio(1.0F).
                                            volumeRatio(1.0F).
                                            pitchRatio(1.0F).
                                            emotion("happy").
                                            build())
                                    .build())
                            .vadPayload(JoinConvoAIReq.VADPayload.builder()
                                    .interruptDurationMs(160)
                                    .prefixPaddingMs(300)
                                    .silenceDurationMs(480)
                                    .threshold(0.5F)
                                    .build())
                            .asrPayload(JoinConvoAIReq.ASRPayload.builder()
                                    .language("zh-CN")
                                    .build())
                            .build())
                    .build()).block();
        } catch (AgoraException e) {
            logger.error("Failed to start the agent, err: {}", e.getMessage());
            return;
        } catch (Exception e) {
            logger.error("Unknown exception, err: {}", e.getMessage());
            return;
        }

        if (joinConvoAIRes == null) {
            logger.error("Failed to start the agent");
            return;
        }

        logger.info("Start the agent successfully, joinConvoAIRes:{}", joinConvoAIRes);

        String agentId = joinConvoAIRes.getAgentId();

        Thread.sleep(3000);

        // List the agent
        ListConvoAIRes listConvoAIRes;
        try {
            listConvoAIRes = convoAIClient.list(ListConvoAIReq.builder()
                    .channel(CNAME)
                    .state(2)
                    .build()).block();
        } catch (AgoraException e) {
            logger.error("Failed to list the agent, err: {}", e.getMessage());
            return;
        } catch (Exception e) {
            logger.error("Unknown exception, err: {}", e.getMessage());
            return;
        }

        if (listConvoAIRes == null) {
            logger.error("Failed to list the agent");
            return;
        }

        logger.info("List the agent successfully, listConvoAIRes:{}", listConvoAIRes);

        Thread.sleep(120000);

        // Stop the agent
        try {
            convoAIClient.leave(agentId).block();
            logger.info("Leave the agent successfully, agentId:{}", agentId);
        } catch (AgoraException e) {
            logger.error("Failed to leave the agent, err: {}", e.getMessage());
        } catch (Exception e) {
            logger.error("Unknown exception, err: {}", e.getMessage());
        }

    }
}
```

### Define Variables

Add the following code to `Main.java` to define the key parameters required to create a conversational AI agent:

```java
// Agora parameter configuration
public static final String APP_ID = "<your appId>";

public static final String AGENT_RTC_UID = "<your agent rtc uid>";
public static final String USERNAME = "<the username of basic auth credential>";
public static final String PASSWORD = "<the password of basic auth credential>";
public static final String AGENT_RTC_TOKEN = "<your agent rtc token>";

// LLM parameter configuration
public static final String LLM_URL = "<your LLM URL>";
public static final String LLM_API_KEY = "<your LLM API Key>";
public static final String LLM_MODEL = "<your LLM model>";

// TTS parameter configuration (Bytedance TTS used as an example)
public static final String TTS_BYTEDANCE_TOKEN = "<your bytedance tts token>";
public static final String TTS_BYTEDANCE_APP_ID = "<your bytedance tts app id>";
public static final String TTS_BYTEDANCE_CLUSTER = "<your bytedance tts cluster>";
public static final String TTS_BYTEDANCE_VOICE_TYPE = "<your bytedance tts voice type>";
```

The parameters you need to configure can be divided into three categories:

- Agora parameter configuration:
  - `APP_ID`: your Agora App ID.
  - `CNAME`: the RTC channel name that the conversational AI agent joins. You need to fill in the channel name used when creating the temporary token.
  - `AGENT_RTC_UID`: the user ID of the conversational AI agent in the RTC channel. By default, an integer UID is used, for example `123`. If you need to use a string UID, set `enableStringUId` to `true` in the later steps.
  - `USERNAME` and `PASSWORD`: your Agora Customer ID and Customer Secret.
  - `AGENT_RTC_TOKEN`: the token used by the conversational AI agent to join the RTC channel. You can simply use the temporary token.
- LLM parameter configuration:
  - `LLM_URL`: the LLM API callback URL.
  - `LLM_API_KEY`: the LLM API key.
  - `LLM_MODEL`: the large language model name.
- TTS parameter configuration: The sample code uses Bytedance TTS as an example. You can choose another TTS provider based on your actual needs and refer to [`TTSPayload`](https://doc.shengwang.cn/api-ref/convoai/java/java-api/struct#ttspayload) for detailed configuration.

### Create and Initialize the Client

In the `main` method, create a [`BasicAuthCredential`](https://doc.shengwang.cn/api-ref/convoai/java/java-api/basicauthcredential#basicauthcredential) instance to configure HTTP Basic Authentication, initialize a [`ConvoAIConfig`](https://doc.shengwang.cn/api-ref/convoai/java/java-api/struct#convoaiconfig) instance, and then call [`create`](https://doc.shengwang.cn/api-ref/convoai/java/java-api/convoaiclient#create) to create the Conversational AI Engine REST client:

```java
public static void main(String[] args) throws Exception {
    // Create the HTTP Basic Authentication credential
    Credential credential = new BasicAuthCredential(USERNAME, PASSWORD);
    // Initialize REST client configuration
    ConvoAIConfig config = ConvoAIConfig.builder().
            appId(APP_ID).
            credential(credential).
            domainArea(DomainArea.CN).
            serverRegion(ConvoAIServiceRegionEnum.CHINESE_MAINLAND).
            build();

    // Create the Conversational AI Engine REST client
    ConvoAIClient convoAIClient = ConvoAIClient.create(config);

    // ... following code
}
```

### List Current Conversational AI Agents

Use [`list`](https://doc.shengwang.cn/api-ref/convoai/java/java-api/convoaiclient#list) to get the list of currently running conversational AI agents:

```java
Thread.sleep(3000);

// List the agent
ListConvoAIRes listConvoAIRes;
try {
    listConvoAIRes = convoAIClient.list(ListConvoAIReq.builder()
            .channel(CNAME)
            .state(2)
            .build()).block();
} catch (AgoraException e) {
    logger.error("Failed to list the agent, err: {}", e.getMessage());

    logger.error("Unknown exception, err: {}", e.getMessage());

if (listConvoAIRes == null) {
    logger.error("Failed to list the agent");
    return;

```

## Talk with the Agent

This section explains how to let the agent and the user join the same RTC channel and interact with each other.

### User Joins the Channel

In your app, use a different user ID from the agent, but the same token and channel name, to join the RTC channel.

> Info
> You can also use the [Real-Time Engagement Web Demo](https://webdemo.agora.io/index.html) to join the RTC channel. After completing **Initialization Settings**, choose **Quick Start - Audio and Video Call** from the left-side menu, and enter a different user ID from the agent, together with the same token and channel name, to join the RTC channel.

### Agent Joins the Channel

In IntelliJ IDEA, click the `Run` button in the upper-right corner (`shift + F10`) to start the agent.

If it runs successfully, you will see logs similar to the following:

```shell
[main] INFO io.agora.Main - Start the agent successfully, joinConvoAIRes:JoinConvoAIRes{agentId='1NT29X0WPCExxxxxWIOYAX0PDQLA5EX', createTs=1742892557, status='RUNNING'}
[main] INFO io.agora.Main - List the agent successfully, listConvoAIRes:ListConvoAIRes{data=Data{count=1, list=[Agent{agentId='1NT29X0WPCExxxxxWIOYAX0PDQLA5EX', startTs=1742892560, status='RUNNING'}]}, meta=Meta{total=1, cursor=''}, status='ok'}
[main] INFO io.agora.Main - Leave the agent successfully, agentId:1NT29X0WPCExxxxxWIOYAX0PDQLA5EX
```

After that, the agent joins the RTC channel and sends a greeting to the user.

> Note
> After the agent joins the channel, if there are no other users in the channel, the agent automatically leaves after a period of time. In this sample code, the value is set to 120 seconds.

### User Talks with the Agent

After both sides join the channel, the user can talk directly with the agent, and the agent responds by voice.
