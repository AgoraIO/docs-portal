# Use RESTful API to Build Conversational AI Engine

This article explains how to call the Agora Conversational AI Engine RESTful API to create a Conversational AI Agent and enable interactive conversations with an AI agent.

## Prerequisites

Before you start, make sure that:

- You have followed [Enable the Service](./enable-service.md) and completed the following steps in the Agora Console:
  - Enable Agora Conversational AI Engine for your project.
  - Get the App ID: a string randomly generated by Agora to identify your project and call the Conversational AI Agent RESTful API.
  - Get the Customer ID and Customer Secret: used for HTTP authentication when calling the Agora Conversational AI Engine RESTful API.
  - Generate a temporary token: A token, also called a dynamic key, is used to authenticate users when they join an RTC channel. A temporary token is valid for 24 hours. In production, refer to [Use Token Authentication](https://doc.shengwang.cn/doc/rtc/android/basic-features/token-authentication) to generate tokens on your app server.
- You have followed [Build a Video Calling App](https://doc.shengwang.cn/doc/rtc/android/get-started/quick-start) to integrate Real-Time Engagement SDK v4.5.1 or later, and implemented basic real-time audio and video capabilities in your app.

> Info
> If you want to use embedded smart hardware to talk with an AI agent, you can integrate RTSA C SDK v1.9.x or later and refer to [Implement Media Streaming and Signaling Transmission](https://doc.shengwang.cn/doc/rtsa/c/get-started/implement-transmission) to build basic real-time audio and video capabilities on your device.

- You have obtained the API key and callback URL from your large language model (LLM) provider.
- You have followed the official documentation of your text-to-speech (TTS) provider to get authentication information such as token and appid, and understand the relevant parameter configurations.

## Implementation Flow

The following diagram shows the process of enabling voice interaction with an agent:

![image](https://doc.shengwang.cn/img/convoai/quick-start.svg)

### Join an RTC Channel

In your app, call `joinChannel` to join an RTC channel.

### Create a Conversational AI Agent

Call [Create a Conversational AI Agent](../operations/start-agent.md) to create an agent instance, and pass in the channel name and token used in the previous step so the agent joins the same RTC channel.

> Tip
> - Agora recommends that you go to [**Playground**](https://console.shengwang.cn/product/ConversationAI?tab=Playground) in the console to quickly try conversations with an AI agent. After you configure the parameters correctly and complete the trial, click **View code** in the upper-right corner to copy the automatically generated server-side API sample code.
> - You can use either of the following authentication methods:
>   - Recommended: When using RTC token authentication, you can put the token directly into the `Authorization` field of the HTTP request header. For example: `Authorization: agora token="007abcxxxxxxx123"`.
>   - When using HTTP Basic Authentication, you can use a [third-party online tool](https://www.debugbear.com/basic-auth-header-generator) to quickly generate the `Authorization` value. Enter the Customer ID and Customer Secret into the `Username` and `Password` fields respectively, and you will get a result like `Authorization: Basic NDI1OTQ3N2I4MzYy...YwZjA=`. Replace `Authorization: agora token="007abcxxxxxxx123"` in the sample below with that result.

#### Request

```shell
curl --request POST \
  --url https://api.agora.io/cn/api/conversational-ai-agent/v2/projects/<your_app_id>/join \
  --header 'Authorization: agora token="007abcxxxxxxx123"' \
  --data '
{
  "name": "unique_name",
  "properties": {
    "channel": "channel_name",
    "token": "token",
    "agent_rtc_uid": "0",
    "remote_rtc_uids": [
      "123"
    ],
    "asr": {
      "language": "zh-CN"
    },
    "llm": {
      "url": "https://api.xxxx/v1/xxxx",
      "api_key": "xxx",
      "system_messages": [
        {
          "role": "system",
          "content": "You are a helpful chatbot."
        }
      ],
      "greeting_message": "Hello, how can I help you?",
      "failure_message": "Sorry, I can't answer that question.",
      "max_history": 10,
      "params": {
        "model": "xxxx",
      }
    },
    "tts": {
      "vendor": "minimax",
      "params": {
        "key": "your-minimax-key",
        "model": "speech-01-turbo",
        "voice_setting": {
          "voice_id": "female-shaonv",
          "speed": 1,
          "vol": 1,
          "pitch": 0,
          "emotion": "happy"
        },
        "audio_setting": {
          "sample_rate": 16000
        }
      }
    }
  }
}
'
```

#### Response

If the call succeeds, you receive the following response:

```json
/// 200 OK
{
  // highlight-start
  "agent_id": "1NT29X10YHxxxxxWJOXLYHNYB",
  // highlight-end
  "create_ts": 1737111452,
  "status": "RUNNING"
}
```

At the same time, the agent joins the RTC channel and greets the user, and the user can start talking to the agent.

### Stop the Conversational AI Agent

When the conversation between the user and the agent ends, you can call [Stop a Conversational AI Agent](../operations/stop-agent.md) and pass in the `agent_id` returned when the agent was created to make the specified agent leave the RTC channel.

#### Request

```shell
curl --request POST \
// highlight-start
  --url https://api.agora.io/cn/api/conversational-ai-agent/v2/projects/<your_app_id>/agents/<agentid>/leave \
  --header 'Authorization: agora token="007abcxxxxxxx123"' \
// highlight-end
```

#### Response

If the call succeeds, you receive the following response:

```json
/// 200 OK
{}
```

- Currently, the limit for Peak Concurrent Users when a single App ID calls the server-side API is 20. To increase the quota, [contact technical support](https://ticket.shengwang.cn).
