# Build Conversational AI Engine with the Go SDK

This article introduces beginners to using the Agora Go SDK to build Conversational AI Engine.

The Go SDK is designed to help developers integrate Agora RESTful APIs more easily. The SDK provides the following features:

- Simplified communication: By encapsulating RESTful API request and response handling, it makes communication with RESTful APIs much easier.
- Availability protection: When DNS resolution fails, network errors occur, or requests time out, it automatically switches to the optimal domain name to ensure REST service availability.
- Ease of use: Provides concise and easy-to-understand APIs so that you can easily implement common features such as creating and stopping conversational AI agents.
- Other advantages: Built with Go, it is efficient, concurrent, and extensible.

## Prerequisites

Before you start, make sure that:

- You have integrated [Go](https://go.dev/dl/) 1.18 or later.
- You have followed [Enable the Service](./enable-service.md) and completed the following steps in the Agora Console:
  - Enable Agora Conversational AI Engine for your project.
  - Get the App ID: a string randomly generated by Agora to identify your project and call the Conversational AI Agent RESTful API.
  - Get the Customer ID and Customer Secret: used for HTTP authentication when calling the Agora Conversational AI Engine RESTful API.
  - Generate a temporary token: A token, also called a dynamic key, is used to authenticate users when they join an RTC channel. A temporary token is valid for 24 hours. In production, refer to [Use Token Authentication](https://doc.shengwang.cn/doc/rtc/android/basic-features/token-authentication) to generate tokens on your app server.
- You have followed [Build a Video Calling App](https://doc.shengwang.cn/doc/rtc/android/get-started/quick-start) to integrate Real-Time Engagement SDK v4.5.1 or later, and implemented basic real-time audio and video capabilities in your app.
- You have obtained the API key and callback URL from your large language model (LLM) provider.
- You have followed the official documentation of your text-to-speech (TTS) provider to obtain authentication information such as token and appid, and understand the relevant parameter configuration.

## Create a Project and Install the SDK

#### Create a Project

Follow these steps to create and configure a new project.

1. Create an empty project folder named `test-convoai`.
2. Go to the `test-convoai` directory and run the following command to initialize the Go module:

```shell
go mod init test-convoai
```

3. Under the project path, create an empty `main.go` file. In this file, you will implement a minimal Conversational AI Engine task.

#### Install the SDK

Under the project path, run the following commands to install the Go SDK:

```shell
# Install the Go SDK
go get -u github.com/AgoraIO-Community/agora-rest-client-go
# Update dependencies
go mod tidy
```

## Build Conversational AI Engine

This section explains the core Go code used to build Conversational AI Engine. You can choose how to read this section based on your needs:

- **Run it quickly**: If you only want to run the sample code quickly and do not care about implementation details, you can copy the full sample code below into `main.go`, configure the relevant parameters by referring to [Define variables](#define-variables), and then jump to [Talk with the Agent](#talk-with-the-agent).

#### Full `main.go` Example

```go
package main

import (
	"context"
	"log"
	"time"

	"github.com/AgoraIO-Community/agora-rest-client-go/agora/auth"
	"github.com/AgoraIO-Community/agora-rest-client-go/agora/domain"
	agoraLogger "github.com/AgoraIO-Community/agora-rest-client-go/agora/log"
	agoraUtils "github.com/AgoraIO-Community/agora-rest-client-go/agora/utils"
	"github.com/AgoraIO-Community/agora-rest-client-go/services/convoai"
	"github.com/AgoraIO-Community/agora-rest-client-go/services/convoai/req"
)

const (
	appId                 = "<your appId>"
	cname                 = "<your cname>"
	agentRtcUid           = "<your agent rtc uid>"
	username              = "<the username of basic auth credential>"
	password              = "<the password of basic auth credential>"
	agentRtcToken         = "<your agent rtc token>"
	llmURL                = "<your LLM URL>"
	llmAPIKey             = "<your LLM API Key>"
	llmModel              = "<your LLM model>"
	ttsBytedanceToken     = "<your bytedance tts token>"
	ttsBytedanceAppId     = "<your bytedance tts app id>"
	ttsBytedanceCluster   = "<your bytedance tts cluster>"
	ttsBytedanceVoiceType = "<your bytedance tts voice type>"
)

func main() {
	log.SetFlags(log.LstdFlags | log.Lshortfile)

	// Initialize Conversational AI Engine REST client configuration
	config := &convoai.Config{
		AppID:      appId,
		Credential: auth.NewBasicAuthCredential(username, password),
		// Specify the server region. Available options: CN, EU, AP, US
		// The REST client automatically switches to the best domain name for the configured region
		DomainArea: domain.CN,
		// Specify the log output level. Available options: DebugLevel, InfoLevel, WarningLevel, ErrLevel
		// To disable log output, set logger to DiscardLogger
		Logger: agoraLogger.NewDefaultLogger(agoraLogger.DebugLevel),
		// Specify the service region. Available options: ChineseMainlandServiceRegion, GlobalServiceRegion
		// ChineseMainlandServiceRegion and GlobalServiceRegion are two different services
		ServiceRegion: convoai.ChineseMainlandServiceRegion,
	}

	// Initialize the Conversational AI Engine REST client
	convoaiClient, err := convoai.NewClient(config)
	if err != nil {
		log.Fatalln(err)
	}
	ctx := context.Background()

	name := appId + ":" + cname

	// Create the conversational AI agent
	joinResp, err := convoaiClient.Join(ctx, name, &req.JoinPropertiesReqBody{
		Token:           agentRtcToken,
		Channel:         cname,
		AgentRtcUId:     agentRtcUid,
		RemoteRtcUIds:   []string{"*"},
		EnableStringUId: agoraUtils.Ptr(false),
		IdleTimeout:     agoraUtils.Ptr(120),
		LLM: &req.JoinPropertiesCustomLLMBody{
			Url:    llmURL,
			APIKey: llmAPIKey,
			SystemMessages: []map[string]any{
				{
					"role":    "system",
					"content": "You are a helpful chatbot.",
				},
			},
			Params: map[string]any{
				"model":      llmModel,
				"max_tokens": 1024,
			},
			MaxHistory:      agoraUtils.Ptr(30),
			GreetingMessage: "Hello, how can I help you?",
		},
		TTS: &req.JoinPropertiesTTSBody{
			Vendor: req.BytedanceTTSVendor,
			Params: &req.TTSBytedanceVendorParams{
				Token:       ttsBytedanceToken,
				AppId:       ttsBytedanceAppId,
				Cluster:     ttsBytedanceCluster,
				VoiceType:   ttsBytedanceVoiceType,
				SpeedRatio:  1.0,
				VolumeRatio: 1.0,
				PitchRatio:  1.0,
				Emotion:     "happy",
			},
		},
	})
	if err != nil {
		log.Fatalln(err)
	}

	if joinResp.IsSuccess() {
		log.Printf("Join success:%+v", joinResp)
	} else {
		log.Printf("Join failed:%+v", joinResp)
		return
	}

	agentId := joinResp.SuccessResp.AgentId

	log.Printf("agentId:%s", agentId)

	defer func() {
		// Stop the conversational AI agent
		leaveResp, err := convoaiClient.Leave(ctx, agentId)
		if err != nil {
			log.Fatalln(err)
		}

		if leaveResp.IsSuccess() {
			log.Printf("Leave success:%+v", leaveResp)
		} else {
			log.Printf("Leave failed:%+v", leaveResp)
			return
		}
	}()

	// List conversational AI agents
	listResp, err := convoaiClient.List(ctx,
		req.WithState(2),
		req.WithLimit(10),
	)
	if err != nil {
		log.Fatalln(err)
	}

	if listResp.IsSuccess() {
		log.Printf("List success:%+v", listResp)
	} else {
		log.Printf("List failed:%+v", listResp)
		return
	}

	if listResp.SuccessRes.Data.Count > 0 {
		for _, agent := range listResp.SuccessRes.Data.List {
			log.Printf("Agent:%+v\n", agent)
		}
	} else {
		log.Printf("No agent found\n")
	}

	// Keep the agent running for 60 seconds
	time.Sleep(time.Second * 60)
}
```

### Define Variables

Add the following code to `main.go` to define or configure the key parameters required to create a conversational AI agent:

```go
const (
	// Agora parameter configuration
	appId         = "<your appId>"
	cname         = "<your cname>"
	agentRtcUid   = "<your agent rtc uid>"
	username      = "<the username of basic auth credential>"
	password      = "<the password of basic auth credential>"
	agentRtcToken = "<your agent rtc token>"

	// LLM parameter configuration
	llmURL    = "<your LLM URL>"
	llmAPIKey = "<your LLM API Key>"
	llmModel  = "<your LLM model>"

	// TTS parameter configuration (Bytedance TTS used as an example)
	ttsBytedanceToken     = "<your bytedance tts token>"
	ttsBytedanceAppId     = "<your bytedance tts app id>"
	ttsBytedanceCluster   = "<your bytedance tts cluster>"
	ttsBytedanceVoiceType = "<your bytedance tts voice type>"
)
```

The parameters you need to configure can be divided into three categories:

- Agora parameter configuration:
  - `appId`: your Agora App ID.
  - `cname`: the RTC channel name that the conversational AI agent joins. You need to fill in the channel name used when creating the temporary token.
  - `agentRtcUid`: the user ID of the conversational AI agent in the RTC channel. By default, an integer UID is used, for example `123`. If you need to use a string UID such as `"123"`, set `EnableStringUId` to `true` in the later code.
  - `username` and `password`: your Agora Customer ID and Customer Secret.
  - `agentRtcToken`: the token used by the conversational AI agent to join the RTC channel. You can simply use the temporary token.
- LLM parameter configuration:
  - `llmURL`: the LLM API callback URL.
  - `llmAPIKey`: the LLM API key.
  - `llmModel`: the large language model name.
- TTS parameter configuration: The sample code uses Bytedance TTS as an example. You can choose another TTS provider based on your actual needs and refer to [`JoinPropertiesTTSBody`](https://doc.shengwang.cn/api-ref/convoai/go/go-api/struct#joinpropertiesttsbody) for detailed configuration.

## Talk with the Agent

This section explains how to let the agent and the user join the same RTC channel and interact with each other.

### User Joins the Channel

In your app, use a different user ID from the agent, but the same token and channel name, to join the RTC channel.

> Info
> You can also use the [Real-Time Engagement Web Demo](https://webdemo.agora.io/index.html) to join the RTC channel. After completing **Initialization Settings**, choose **Quick Start - Audio and Video Call** from the left-side menu, and enter a different user ID from the agent, together with the same token and channel name, to join the RTC channel.

### Agent Joins the Channel

Under the project path, run the following command to start the agent:

```shell
go run main.go
```

If it runs successfully, you will see logs similar to the following:

```shell
DEBUG agora-rest-client-go 2025/03/20 07:20:34 client.go:148: http response:{"agent_id":"1NT29X0XEAxxxxxxPHSDRNZYF","create_ts":1742455234,"status":"RUNNING"}
2025/03/20 15:20:34 main.go:103: Join success:&{Response:{BaseResponse:0xc0002169c0 ErrResponse:{Detail: Reason:}} SuccessResp:{AgentId:1NT29X0XEAxxxxxxPHSDRNZYF CreateTs:1742455234 Status:RUNNING}}
2025/03/20 15:20:34 main.go:111: agentId:1NT29X0XEAxxxxxxPHSDRNZYF
```

After that, the agent joins the RTC channel and sends a greeting to the user.

> Note
> After the agent joins the channel, if there are no other users in the channel, the agent automatically leaves after a period of time. In this sample code, the value is set to 120 seconds.

### User Talks with the Agent

After both sides join the channel, the user can talk directly with the agent, and the agent responds by voice.
