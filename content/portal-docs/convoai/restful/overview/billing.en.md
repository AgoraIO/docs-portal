# Billing

This article describes the billing model of Agora Conversational AI Engine.

## Cost Components

| Billable Item | Unit Price | Free Quota |
| --- | --- | --- |
| [RTC call](https://doc.shengwang.cn/doc/rtc/android/billing/billing-strategy) charges | CNY 0.007/minute | 10,000 minutes per month |
| Conversational AI Engine service charges | CNY 0.021/minute | 1,000 total minutes (one-time grant) |
| ASR processing charges | - Fengming ASR (default): CNY 0.077/minute<br>- Third-party ASR: see vendor documentation | 1,000 total Fengming ASR minutes (one-time grant) |
| LLM inference charges | See LLM vendor documentation | / |
| TTS synthesis charges | See TTS vendor documentation | / |
| Graceful interruption charges (value-added service) | CNY 0.042/minute | None |

Possible charges incurred when using Agora Conversational AI Engine are as follows:

- **RTC call charges**: Agora Conversational AI Engine must be used together with the Agora RTC SDK. After a user joins an RTC channel, RTC call charges apply at CNY 0.007/minute. Each App ID includes a free quota of 10,000 minutes per month. For details, see [RTC Billing](https://doc.shengwang.cn/doc/rtc/android/billing/billing-strategy).
- **Conversational AI Engine service charges**: After you call the server-side API [Create a Conversational AI Agent](../operations/start-agent.md) and join an RTC channel, the call incurs Conversational AI Engine service charges at CNY 0.021/minute. Each Agora account receives a one-time free quota of 1,000 minutes for its lifetime. This quota does not refresh monthly, so plan usage accordingly.

> Note
> Since Agora Conversational AI Engine v1.6.0, the ASR module supports custom configuration and ASR service charges are billed separately from the Conversational AI Engine service charge. The Conversational AI Engine service charge was adjusted accordingly to CNY 0.021/minute. When using the default Fengming ASR service, the total price remains unchanged at CNY 0.098/minute.

- **ASR processing charges**: Charges incurred when using Automatic Speech Recognition (ASR) services. Supported configurable ASR providers include Fengming ASR or third-party ASR services (currently Tencent Cloud and Microsoft). Agora Conversational AI Engine uses Fengming ASR by default at CNY 0.077/minute, and includes a one-time free quota of 1,000 minutes.
- **LLM inference charges**: Charges incurred when calling a third-party large language model (LLM). See your LLM provider's documentation for pricing.
- **TTS synthesis charges**: Charges incurred when calling a third-party text-to-speech (TTS) service. See your TTS provider's documentation for pricing.
- **Graceful interruption charges**: Graceful interruption is an optional value-added feature. When enabled, users can interrupt the AI agent at any time and get a quick response, enabling more natural and fluid conversations. When you enable graceful interruption while calling [Create a Conversational AI Agent](../operations/start-agent.md), the call incurs an additional graceful interruption charge of CNY 0.042/minute.

## Billing Method

Agora Conversational AI Engine uses a **postpaid** billing model. When you use the Conversational AI Engine service in a project, Agora charges the corresponding fees, publishes a monthly bill, and deducts the payment. For details, see [Billing, Charges, and Account Suspension](https://doc.shengwang.cn/faq/account-and-billing/billing-account). At the end of each month, Agora totals the Conversational AI Engine usage generated by all projects under your developer account, multiplies it by the corresponding unit prices, and calculates the total fee for that month. Agora rounds the total monthly fee to two decimal places.

### Top-up Packages

You can go to [**Console**](https://console.shengwang.cn/) > **Packages** > **Prepaid Packages** > **Conversational AI Engine** to purchase top-up packages. These packages can offset usage incurred by Conversational AI Engine voice calls (excluding RTC calls) and provide discounts. Agora currently provides the following four package tiers:

| Package Name | Price | Quota | Discount |
| --- | --- | --- | --- |
| Conversational AI Engine 5K Top-up Package | CNY 469 | - 5K minutes of Conversational AI Engine audio task duration<br>- 5K minutes of Fengming ASR processing duration | 96% |
| Conversational AI Engine 20K Top-up Package | CNY 1799 | - 20K minutes of Conversational AI Engine audio task duration<br>- 20K minutes of Fengming ASR processing duration | 92% |
| Conversational AI Engine Graceful Interruption 5K Top-up Package | CNY 669 | - 5K minutes of Conversational AI Engine audio task duration<br>- 5K minutes of graceful interruption duration<br>- 5K minutes of Fengming ASR processing duration | 96% |
| Conversational AI Engine Graceful Interruption 20K Top-up Package | CNY 2579 | - 20K minutes of Conversational AI Engine audio task duration<br>- 20K minutes of graceful interruption duration<br>- 20K minutes of Fengming ASR processing duration | 92% |

> Note
> - In graceful interruption packages, AI voice call duration, graceful interruption duration, and Fengming ASR processing duration are calculated independently and do not affect one another when usage is deducted.
> - Packages include an equal amount of Fengming ASR minutes by default. Even if Fengming ASR is not actually used, for example when a third-party ASR provider is configured, the system still treats the package as fully sold and currently does not support price refunds or minute replacement.
> - A package purchased in the middle of the month can offset unsettled usage for the current month.
> - Top-up packages are valid for one year. Any unused minutes expire after that.
> - Top-up packages are officially applied during settlement on the 6th of each month. Therefore, from the 1st to the 6th, the system displays the remaining package balance after the previous month's settlement; from the 7th to the end of the month, it displays the balance after the current month's settlement.

## View Usage

The Agora Console provides product usage statistics. You can follow these steps to view Conversational AI Engine usage:

1. Sign in to the [Agora Console](https://console.shengwang.cn/) and go to **All Products** > **Conversational AI Engine** in the left navigation pane.
2. On the Conversational AI Engine page, click the **Usage Statistics** tab.
3. The Usage Statistics page displays detailed usage for the current project. You can choose the usage display method, statistics method, query time range, and other options.

> Note
> - Only usage data from the past year is available for the current project.
> - Usage shown in the Agora Console is for reference only. The bill is the final source of truth.

## Billing Examples

This section shows how to calculate total charges for monthly Conversational AI Engine usage under a single Agora developer account.

> Info
> The prices of third-party LLM and TTS services in the examples are based on real market prices and are provided for illustration only. For actual charges and billing rules, refer to the billing documentation of the corresponding vendor.

### Example 1

User A joins a channel and starts a voice conversation with an agent created by the Conversational AI Engine. Graceful interruption is not enabled. The interaction lasts 10 minutes, and User A and the agent leave the channel at the same time. During those 10 minutes:

- User A subscribed audio: 10 minutes
- Conversational AI Engine audio processing: 10 minutes
- Fengming ASR: 10 minutes
- Third-party LLM calls: 500 input tokens, 800 output tokens
- Third-party TTS service: 800 characters converted
- Graceful interruption: 0 minutes

The module charges are as follows:

| Billing Item | Usage | Unit Price | Charge | Total |
| --- | --- | --- | --- | --- |
| User A audio subscription | 10 minutes | CNY 0.007/minute | CNY 0.07 | 0.07 + 0.21 + 0.77 + 0.0074 + 0.28 = CNY 1.3374 |
| Conversational AI Engine audio processing | 10 minutes | CNY 0.021/minute | CNY 0.21 |  |
| Fengming ASR | 10 minutes | CNY 0.077/minute | CNY 0.77 |  |
| LLM calls | - 500 input tokens<br>- 800 output tokens | - Input: CNY 2 per million tokens<br>- Output: CNY 8 per million tokens | 2 * 500 / 1000000 + 8 * 800 / 1000000 = CNY 0.0074 |  |
| TTS service | 800 characters converted | CNY 3.5 per 10,000 characters | 3.5 * 800 / 10000 = CNY 0.28 |  |
| Graceful interruption | 0 minutes | CNY 0.042/minute | CNY 0 |  |

## FAQ

#### If all users leave the channel but the agent does not, will billing continue?

Yes. Conversational AI Engine usage is billed based only on whether there is an active (`RUNNING`) agent at the backend. To avoid unnecessary charges, Agora recommends that you:

- Call [POST Stop a Conversational AI Agent](../operations/stop-agent.md) when the last user leaves the channel so the agent exits the channel.
- Set an appropriate maximum idle time (`idle_timeout`) when calling [POST Create a Conversational AI Agent](../operations/start-agent.md). When the agent remains idle beyond that value, it stops automatically and leaves the channel.

#### Can top-up packages be purchased cumulatively?

Yes. Top-up packages support cumulative purchase. If you buy multiple packages, the system deducts usage in the order in which the packages were purchased. For example:

If you purchased a 20K-minute top-up package on August 15, 2024, and then purchased a 5K-minute top-up package on August 16, 2024, then when the bill is issued on September 1, the system first deducts usage from the earlier 20K-minute package and then from the later 5K-minute package.

#### After the AI voice call duration in a graceful interruption package is used up, can the remaining graceful interruption duration still be used?

Yes. AI voice call duration and graceful interruption duration in a graceful interruption package are calculated independently and do not affect one another when usage is deducted.

#### Can a top-up package be refunded?

Currently, top-up packages are non-refundable.
