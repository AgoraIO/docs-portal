## 适合什么时候看这页

如果你还没有准备好马上写代码，但想先确认智能体体验、语音风格和基本链路，这页适合作为第一站。

## 你能完成什么

- 在浏览器里快速创建一个语音智能体原型
- 先验证声音、提示词和模型行为
- 再决定后续是走 REST API、服务端 SDK 还是客户端集成

## 推荐顺序

1. 先明确你的目标场景，例如客服、陪伴、设备助手或应用内语音入口。
2. 用 Agent Studio 先跑通一轮对话体验。
3. 如果体验方向正确，再进入 [Voice AI quickstart](/docs/convoai/restful/get-started/quick-start) 或 [REST API](/?tab=api-reference)。
