## Accounts and projects

Before integrating any Agora capability, teams usually need to create an account, sign in to Console, and create a project.

## Typical tasks

- Create and manage Agora projects
- Retrieve App ID and base credentials
- Manage project setup across environments

## Recommendation

If you are just getting started with Agora, finish account and credential setup before moving into product-specific integration work.
