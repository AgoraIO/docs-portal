## Why a product matrix matters

Readers do not always arrive with product names in mind. Some arrive with a use case, others with a technical problem, and others with an API they need to call.

The matrix helps explain how capability domains, product layers, and operational surfaces connect.

## Product layers

### AI product layer

This layer covers voice agents, model orchestration, context handling, and conversational interaction.

- [Open Conversational AI Engine overview](/docs/convoai/restful/overview/product-overview)

### Realtime engagement layer

This layer covers audio, video, messaging, and state synchronization as the low-latency foundation.

- [Open Realtime & Media](/?tab=realtime-media)

### Media services layer

This layer covers recording, transcription, streaming IO, media transformation, and delivery workflows.

- [Open audio modality guidance](/docs/convoai/restful/user-guides/audio-modality)

### Platform operations layer

This layer covers console setup, billing, security, release notes, and production governance.

- [Open Best Practices](/?tab=best-practices)

## How to use the matrix

Use the matrix to answer two questions:

1. Which layer should I enter first?
2. Which adjacent layer will I probably need next?
