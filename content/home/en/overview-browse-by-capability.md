## Capability domains

### AI Agents

Use this area for conversational AI, agent integration, model orchestration, context handling, and multimodal interaction.

- [Open AI Agents](/?tab=overview&page=overview-ai-agents)

### Realtime Audio & Video

Use this area for RTC sessions, channel access, device permissions, auth, and the low-latency audio-video foundation.

- [Open Realtime Audio & Video](/?tab=overview&page=overview-realtime-audio-video)

### Media Services

Use this area for recording, publishing, ingest, transcoding, and delivery workflows.

- [Open Media Services](/?tab=overview&page=overview-media-services)

### Messaging

Use this area for RTM, state synchronization, messaging workflows, and event-driven coordination.

- [Open Messaging](/?tab=overview&page=overview-messaging)

### Realtime Messaging RTM

Use this area for channel messaging, presence, state synchronization, and signaling workflows.

- [Open Realtime Messaging RTM](/?tab=overview&page=overview-rtm)

### Realtime Transcription & Translation

Use this area for live speech transcription, translation, captions, and multilingual understanding.

- [Open Realtime Transcription & Translation](/?tab=overview&page=overview-speech-to-text)

### Realtime Streaming Acceleration RTSA

Use this area for smart-device connectivity, terminal media streaming, and device-oriented realtime transport.

- [Open RTSA](/?tab=overview&page=overview-rtsa)

### RTC Server SDK

Use this area for backend media send/receive, server-side RTC control, and media handling.

- [Open RTC Server SDK](/?tab=overview&page=overview-rtc-server-sdk)

### Fusion CDN Live Streaming

Use this area for live distribution, playback optimization, and multi-CDN delivery.

- [Open Fusion CDN Live Streaming](/?tab=overview&page=overview-fusion-cdn)

### Interactive Whiteboard

Use this area for multi-user whiteboard collaboration, online teaching, and visual interaction.

- [Open Interactive Whiteboard](/?tab=overview&page=overview-whiteboard)

## Reading strategy

Capability domains should reduce decision cost. They are not a replacement for product documentation, but they help new readers enter the right area before they commit to a deeper product-specific path.
