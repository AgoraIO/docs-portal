## What this capability is

Security covers token strategy, access control, basic authentication, and production operating boundaries so teams can reduce exposure and runtime risk.

## Common scenarios

- token authentication
- HTTP basic auth
- regional access control
- pre-launch security review

## What to read first

If the system is moving toward production, security should be reviewed in parallel with architecture design rather than deferred to the end.
