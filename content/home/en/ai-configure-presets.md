## Why presets matter

When one agent system supports multiple scenarios, presets help you turn recurring configuration groups into stable reusable entry points instead of rebuilding parameter sets each time.

## What presets usually contain

- voice role and speaking style
- LLM model and prompting
- ASR and TTS vendor settings
- interruption, memory, and context behavior

## Practical guidance

Start with the smallest preset set that supports the main scenario, then branch into support, companionship, device, or education variants only when needed.
