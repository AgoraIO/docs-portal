## When to start here

Use this page if you are not ready to write code yet and want to validate the agent experience, voice behavior, and initial flow first.

## What this path helps you do

- prototype a voice agent in the browser
- validate voice, prompting, and model behavior
- decide whether to continue with REST APIs, server SDKs, or client integration

## Recommended sequence

1. Confirm the target scenario such as support, companionship, device assistant, or in-app voice entry.
2. Run a first conversation in Agent Studio.
3. If the experience direction feels right, continue into the [Voice AI quickstart](/docs/convoai/restful/get-started/quick-start) or the [API reference](/?tab=api-reference).
