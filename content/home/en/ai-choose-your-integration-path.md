## Start from the layer you are blocked on

### You only need to validate the experience first

Open [Start with Agent Studio](/?tab=ai&page=ai-start-with-agent-studio).

### You want the fastest executable path

Open the [Voice AI quickstart](/docs/convoai/restful/get-started/quick-start).

### Your backend needs lifecycle and configuration control

Start from REST APIs or server SDKs:

- [Create and start an agent](/docs/convoai/restful/operations/start-agent)
- [Go SDK](/docs/convoai/restful/get-started/quick-start-go)
- [Java SDK](/docs/convoai/restful/get-started/quick-start-java)

### Your client needs to handle voice and events

Add client-facing guides for audio, subtitles, and business state:

- [Realtime audio](/docs/convoai/restful/user-guides/audio-modality)
- [Transcripts and subtitles](/docs/convoai/restful/user-guides/realtime-sub)
- [Business data](/docs/convoai/restful/user-guides/custom-data)

## Principles after you choose

- Run one shortest closed loop before expanding model behavior.
- Add auth, state, and events before polishing “smarter” behavior.
- Confirm the entry path first, then drill down into Build, Connect, Operate, and Reference.
