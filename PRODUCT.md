# Product

## Register

product

## Users

Agora documentation readers and maintainers use this portal to find product guides, API references, localized content, and versioned SDK documentation while working through implementation tasks.

## Product Purpose

`docs-portal` presents Shengwang/Agora documentation through a Fumadocs-powered, metadata-driven shell with search, navigation, localization, API references, and version/platform-aware docs structure.

## Brand Personality

Clear, technical, restrained.

## Anti-references

Avoid marketing-site ornament, oversized decorative cards in task surfaces, custom controls that differ from standard shadcn/radix affordances, and dense selector-heavy CSS for component skins.

## Design Principles

- Keep docs chrome quiet so content and navigation remain primary.
- Use familiar product UI patterns for search, dropdowns, tabs, sidebars, and mobile sheets.
- Prefer metadata-driven behavior and shared primitives over one-off shell code.
- Keep localization and version switching explicit, crawlable, and accessible.
- Preserve a compact, scannable layout for repeated documentation workflows.

## Accessibility & Inclusion

Use semantic controls and links, maintain keyboard navigation and focus states, preserve crawlable locale/version links where routing depends on them, and keep contrast suitable for long reading sessions.
