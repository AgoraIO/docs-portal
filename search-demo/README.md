# CN search demo: local Meilisearch

Task 3 only starts an empty Meilisearch service. The 25-document KB is not uploaded until Task 4. This service is for local development, not production or PR preview.

## Start

Install Docker Desktop with Docker Compose, then from the repository root:

1. Copy `search-demo/.env.example` to `search-demo/.env`. Replace `MEILI_MASTER_KEY` with a random secret of at least 16 bytes, such as a value generated by `openssl rand -hex 32`. Do not commit `.env` or share the key.
2. Start the service:

   ```bash
   docker compose --env-file search-demo/.env -f search-demo/docker-compose.yml up -d meilisearch
   ```

3. Check readiness:

   ```bash
   docker compose --env-file search-demo/.env -f search-demo/docker-compose.yml ps
   curl --fail http://127.0.0.1:7700/health
   ```

   A ready server returns `{"status":"available"}`. Data persists in the Compose volume `meili-data` between restarts. The port is bound only to the local machine.

4. Stop without deleting indexed data:

   ```bash
   docker compose --env-file search-demo/.env -f search-demo/docker-compose.yml down
   ```

`MEILI_HOST` and `MEILI_INDEX_UID` are reserved for the Task 4 indexer. Never use `MEILI_MASTER_KEY` in browser code. The future browser search client must use a restricted search-only key.
